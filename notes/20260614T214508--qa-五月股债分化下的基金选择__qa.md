* 引子
2025年5月的基金月报，股债两类资产再次出现分化：A股主要指数上涨1-2%，中证全债指数微跌0.06%。权益基金普涨，固收基金涨跌互现——可转债基金+1.75%，利率债基金-0.19%。这种"股强债弱"的格局给投资者提出了一个问题：在分化市中，基金该怎么选？

* Q1: 5月股债分化的直接触发因素是什么？
  *结论*：A股受中美关税缓和+央行降准降息驱动；债市受关税缓和利好（利空债市）+LPR降息已充分定价（利多有限）压制。
  *形式化*：A股驱动 = 外部（中美关税缓和） + 内部（降准降息） → 主要股指涨1-2% ≠ 债市驱动 = 关税缓和（利空） + LPR降息已定价（利多有限） → 国债收益率短端↓5bp/长端↑5bp
  *怎么想到的*：
  - A股：中美关税缓和→风险偏好提升→降准降息→资金面宽松
  - 债市：中美关税缓和→风险偏好提升→资金从债市流向股市→利空债市；LPR降息落地但市场已充分定价→利多有限
  - 结果：短端国债收益率↓5bp（资金面宽松），长端↑5bp（风险偏好提升）
  *边界*：若中美摩擦重新升级或央行收紧流动性，股债分化格局可能逆转。

* Q2: 为什么信用债表现远好于利率债？
  *结论*：因为信用债收益率下行幅度更大（1年期AAA/AA分别↓9bp/↓10bp），且中证企业债指数+0.43% > 中证国债-0.19%。
  *形式化*：信用债表现 > 利率债 ← 信用债收益率↓（1年期AAA/AA↓9/10bp） + 中证企业债+0.43% > 中证国债-0.19%
  *怎么想到的*：
  - 看收益率变动：1年期AAA↓9bp，AA↓10bp，信用债下行幅度远大于利率债
  - 看债券指数：中证企业债+0.43%，中证中票+0.43%，中证短融+0.17% > 中证国债-0.19%
  - 原因：信用债受益于资金面宽松+信用利差收窄
  *边界*：若经济超预期恶化导致信用风险上升，信用债利差可能走阔，此时利率债反而更抗跌。

* Q3: 行业基金内部为什么出现分化？
  *结论*：环保/医药/国防军工/银行/纺织服饰涨超6%，电子跌超2%，差异来自产业政策（创新药/公募新规） vs 行业周期。
  *形式化*：行业分化 = f(产业政策, 行业周期) → 医药（创新药政策）+6% ≠ 电子（行业周期下行）-2%
  *怎么想到的*：
  - 看政策：国家创新药利好政策→医药生物板块上涨；公募新规利好→银行板块上涨
  - 看行业周期：电子板块处于行业周期下行→下跌
  *边界*：若政策转向或行业周期切换，行业分化格局可能逆转。

* Q4: 全球市场为什么集体收涨？
  *结论*：美股/欧股/港股/日经全线上涨，标普+6.15%，日经+5.53%，恒生+5.29%，差异来自美联储政策预期和地缘风险。
  *形式化*：全球收涨 = f(美联储, 地缘) → 美股/亚太（经济强+风险偏好高） ≠ 欧股（能源冲击）
  *怎么想到的*：
  - 看美联储：美国PMI 53.0%（荣枯线之上）→经济强→美股涨
  - 看地缘：中东冲突→布伦特原油+2.57%→欧股承压（但5月欧股也涨，说明其他因素更强）
  - 看避险：黄金+0.51%，资金从欧股流向黄金
  *边界*：若中东冲突升级或美联储推迟降息，全球收涨格局可能逆转。

* Q5: 可转债基金为什么又是表现最好的？
  *结论*：因为可转债兼具股债特性，在"股强债弱"格局中双重受益——A股上涨推动转债价格上涨，短端利率下行提供债底保护。
  *形式化*：可转债 = 股性（A股涨→转债涨） + 债性（短端利率↓→债底保护） → 中证转债+1.75%（所有券种中最好）
  *怎么想到的*：
  - 看历史：5月可转债基金表现最好（延续4月趋势）
  - 看逻辑：A股涨1-2%→转股价值上升→转债价格上涨；短端国债收益率↓5bp→债底稳固
  *边界*：若A股回调但债市继续下跌，可转债基金的股性和债性都会承压。

* Q6: 对于持有"固收+"产品的投资者，5月数据说明了什么？
  *结论*：在"股强债弱"格局中，固收+产品需要更高的权益暴露才能跑赢纯债基金，但也要承担更高的波动。
  *形式化*：固收+策略 = 纯债（微跌） + 权益增强（涨1-2%） → 股强债弱时，权益暴露越高越好 ≠ 股弱债长时，权益暴露越低越好
  *怎么想到的*：
  - 看债券基金：中证全债-0.06%（微跌）
  - 看可转债基金：+1.75%（股强债弱时受益）
  - 看偏股基金：+5-6%（纯权益）
  - 固收+在股强债弱时表现居中，但风险更低
  *边界*：若后续股债分化加剧（如6月的"股债双收"或7月的"股涨债跌"），固收+的表现将取决于权益暴露度。

* Q7: 从5月数据看，短端和长端利率债的表现为什么分化？
  *结论*：短端利率债受益于资金面宽松（1年期国债↓5bp），长端利率债受风险偏好提升压制（5/10年期国债↑5bp）。
  *形式化*：短端 vs 长端 = 资金面（短端受益） vs 风险偏好（长端承压） → 收益率曲线陡峭化
  *怎么想到的*：
  - 看收益率变动：1年期国债↓5bp，5/10年期国债↑5bp
  - 看驱动因素：央行降准降息→短端利率↓；中美关税缓和→风险偏好↑→长端利率↑
  - 收益率曲线陡峭化：短端↓+长端↑→曲线变陡
  *边界*：若央行进一步降准降息，长端利率也可能下行；若风险偏好下降，长端利率反而会下行。

* 收口
晨星5月基金月报的核心价值在于：用"股强债弱"这个分化格局，展示不同基金类别的表现差异，并提醒投资者关注后续分化风险——权益暴露越高，在股强时弹性越大，在股弱时回撤也越大。
