#+subtitle:  当基金业绩翻倍以后…
#+date:       [2026-06-14 Sun 21:36]
#+filetags:   :qa:
#+identifier: 20260614T213636

* 引子
2025年有85只基金收益率翻倍，看着诱人，但历史告诉我们要冷静。作者用2011-2025年的数据做了一项统计：前一年排在前四分位的基金，下一年继续排在前四分位的概率只有28-30%，跟掷骰子差不多。更扎心的是，能连续三年保持前四分位的基金只有3%。翻倍基金的"高光"为何难以延续？

* Q1: 一年翻倍的基金，到底做对了什么？
  *结论*：不是能力，是押注——把90%以上的仓位集中在当年表现最好的两个行业上，赌中了就翻倍。
  *形式化*：翻倍基金 = 90%仓位 × 当年最佳行业（如通讯80%+涨幅） → 业绩翻倍
  *怎么想到的*：
  - 数据分析：沪深300全年涨20%，但通讯和有色金属涨超80%，全仓梭这两个行业就能翻倍
  - 持仓验证：2025年收益率前三的基金，几乎全部仓位都押在科技相关板块
  - 极端案例：永赢科技智选90%+仓位在通讯和电子，前十大集中度90%，业绩翻两倍
  *边界*：若当年没有极端行业分化，或者押错了行业，这种策略会亏得很惨；若行业分化程度不够，也赚不到翻倍

* Q2: 为什么前一年排前四分位的基金，下一年大概率排不回去？
  *结论*：行业轮动是常态，能年年押中下一年最强行业的人几乎不存在，"行业找到了基金"而非"基金找到了行业"。
  *形式化*：今年前25% → 明年继续前25%的概率 = 28-30% ≈ 随机概率25% → 业绩持续性≈0
  *怎么想到的*：
  - 统计数据：2021年前四分位基金，后续五年每年维持前四分位的数量很少
  - 熊市验证：2018年前四分位基金，后续表现与牛市基金无本质区别
  - 主动vs被动：主动基金和指数基金都体现同样的随机性，不是主动基金独有的问题
  *边界*：若基金经理具备真正的行业轮动能力（极罕见），可能打破这个规律；若市场风格持续多年（如2019-2020大盘蓝筹），短期持续性会更强

* Q3: 为什么"连胜"三年后概率暴跌到3%？
  *结论*：三年时间足以覆盖完整的行业轮动周期，押中一次容易，连续押中三次的概率接近零。
  *形式化*：单年前25%概率 = 30% × 连续三年 = 30%³ ≈ 3% → 概率暴跌
  *怎么想到的*：
  - 数学推理：每年30%的概率，连续三年就是30%的立方
  - 行业轮动：三年通常覆盖一个完整的行业轮动周期，能每次都押中下一个热点行业的概率极低
  - 现实验证：2011-2025年的数据确实显示，能连续三年维持前四分位的基金只有3%
  *边界*：若基金经理有真正的长期选股能力（而非行业押注），可能打破这个规律；若市场出现长期结构性趋势（如科技十年牛市），概率会上升

* Q4: 为什么糟糕的业绩反而有持续性？
  *结论*：好业绩靠运气（押中行业），差业绩靠实力（能力不足或风格严重错配），所以输家更容易持续输。
  *形式化*：前25%基金 → 下一年各四分位概率均等（随机） vs 后25%基金 → 下一年继续后25%或被清盘概率更高（非随机）
  *怎么想到的*：
  - 数据发现：无论主动还是被动基金，当年排在最后四分位的基金，下一年继续垫底或被清盘的概率更高
  - 逻辑解释：好业绩可能是"行业送的礼物"，差业绩可能是"能力的真实反映"
  - 投资策略：避开输家比追逐赢家更有确定性
  *边界*：若差业绩是暂时的市场风格错配（如价值基金在成长牛市中），可能反转；若差业绩是能力问题，确实会持续

* Q5: 行业基金也逃不出"业绩随机性"，为什么？
  *结论*：即使投资范围限定在单一行业，细分板块的轮动同样难以持续预测，行业内选股的超额也不稳定。
  *形式化*：行业基金 = 行业β + 选股α → 行业β随轮动变化，选股α不稳定 → 业绩随机
  *怎么想到的*：
  - 细分轮动：即使看好科技行业，芯片、AI、软件等细分板块的轮动也难以持续把握
  - 数据验证：行业基金中长期持续取得同类前四分位业绩的产品几乎不存在
  - 逻辑推演：如果连在自己擅长的行业内都无法持续做出超额，跨行业轮动更是天方夜谭
  *边界*：若行业处于长期结构性增长期（如新能源十年），行业基金的持续性会更好；若行业进入成熟期或衰退期，波动会更大

* Q6: 投资者为什么容易被"翻倍基"伤害？
  *结论*：买入时预期过高，业绩波动时心态崩溃，追涨杀跌导致实际收益远低于基金净值涨幅。
  *形式化*：看到翻倍业绩 → 高预期买入 → 业绩回归均值 → 心态崩溃赎回 → 实际收益 << 基金净值涨幅
  *怎么想到的*：
  - 心理机制：翻倍业绩会锚定投资者预期，认为"明年还能赚100%"
  - 行为后果：一旦出现回撤，恐慌性赎回，错过后续风格反弹
  - 实际损失：基金可能长期表现不错，但投资者的追涨杀跌让实际收益大打折扣
  *边界*：若投资者能接受"翻倍不可持续"的事实，降低预期，长期持有反而可能获得不错的收益

* Q7: 怎么正确使用历史业绩来选基金？
  *结论*：看完整周期（至少3-5年），看业绩归因（钱是怎么赚的），看基金经理经验（是否经历过多轮牛熊）。
  *形式化*：选基金 = 完整周期表现（3-5年）∩ 业绩归因清晰（不是纯行业押注）∩ 基金经理经验（多轮牛熊）
  *怎么想到的*：
  - 周期要求：至少覆盖牛市、熊市、震荡市，才能看清基金的真实能力
  - 归因工具：通过晨星基金小程序查业绩归因，了解超额收益来源
  - 经验门槛：优先选择有长期业绩记录的基金和基金经理，避免用真金白银承担额外不确定性
  *边界*：过去表现不保证未来，但长期稳定的表现至少说明基金经理有持续进化的能力；若基金经理更换，历史业绩参考性下降

* 收口
作者用15年的数据揭示了一个残酷真相：基金的短期业绩接近随机游走，翻倍业绩更多是"押中行业"的运气而非能力，而避开持续输家比追逐短暂赢家更重要——投资者应该看完整周期的业绩归因，而非被一年的高收益迷了眼。
