* 引子
大多数投资者只看基金赚没赚钱，却忽略业绩比较基准。其实基准传达了基金的投资方向、风格和策略，是识别基金经理真实能力的第一道标尺。本文教普通投资者怎么从基准读出基金的本质。

* Q1: 看基准为什么比看收益率更重要？
  *结论*: 收益率只告诉你结果，基准才能帮你判断基金经理靠什么赚钱。
  *形式化*: 绝对收益 = 市场水涨 + 基金经理能力；基准过滤 → 超额收益 ≈ 基金经理真实能力
  *怎么想到的*:
  - 2025年大盘成长指数涨24.85%，某基金只涨20%，看似赚钱实际跑输基准5%
  - 2023年大盘成长跌16.96%，某基金只跌10%，看似亏钱实际跑赢基准7%
  - 不看基准会被绝对收益骗：牛市赚钱可能是市场带的，熊市少亏才是本事
  *边界*: 基准必须和基金风格匹配，拿大盘成长基金和中证500比没有意义。

* Q2: 怎么从基准判断基金的投什么？
  *结论*: 基准的指数构成直接暴露基金的投资方向、区域和主题。
  *形式化*: 基准含半导体指数 → 投半导体赛道；基准含恒生指数 → 投港股；基准含中债 → 有债底仓
  *怎么想到的*:
  - 沪深300 → 大盘蓝筹稳健；中证500 → 大中盘偏弹性
  - 恒生指数/标普500 → 跨市场配置
  - 半导体/创新药指数 → 单一赛道、高弹性高回撤
  *边界*: 基准只反映基金合同约定的方向，如果基金经理实际漂移，基准就失效了。

* Q3: 合成基准到底在说什么？
  *结论*: 合成基准揭示基金的资产配置策略——股债比例、市场分布、货币敞口。
  *形式化*: 沪深300×50% + 中证全债×50% → 股债均衡；沪深300×60% + 恒生×30% + 中债×10% → A股为主港股为辅债打底
  *怎么想到的*:
  - 股债比例直接反映基金的进攻性
  - 多个市场指数叠加说明基金在跨市场配置
  - 加入活期利率说明基金保留现金应对申赎
  *边界*: 合成基准越复杂（4-6因子），投资者越难一眼看懂基金在做什么。

* Q4: 为什么指数基金比主动基金更依赖基准？
  *结论*: 指数基金的核心目标就是跟踪基准，基准等于它的"产品说明书"。
  *形式化*: 指数基金目标 = 精准跟踪基准 → 跟踪误差 + 跟踪偏离 → 判断基金做得好不好
  *怎么想到的*:
  - 主动基金可以适度偏离基准去赚超额收益
  - 指数基金偏离基准反而是失误，偏离越大越差
  - 选指数基金本质上就是选一个你看好的基准
  *边界*: 增强型指数基金介于主动和被动之间，需要看它允许多少偏离。

* Q5: 为什么价格指数和全收益指数的差异很重要？
  *结论*: 用价格指数做基准会降低超额收益的实现难度，误导投资者。
  *形式化*: 价格指数（不含分红）≠ 全收益指数（含分红再投）→ 沪深300十年股息占比70.65% → 用价格指数更容易跑赢
  *怎么想到的*:
  - 分红是股票收益的重要组成部分，不含分红的基准天然"更容易赢"
  - 如果基金用价格指数做基准，所谓超额收益可能只来自没算分红
  - 投资者据此高估了基金经理的真实能力
  *边界*: 短期看分红影响不大，但长期（5年以上）累积差异会非常显著。

* Q6: 基准调整后投资者该做什么？
  *结论*: 看调整方向是否改变了基金的战略定位，不匹配就考虑赎回。
  *形式化*: 基准变更 → 判断方向：更聚焦/更分散/跨市场 → 匹配自身需求？→ 留或走
  *怎么想到的*:
  - 文中案例：港股通权重从55%升到80%，基金更聚焦港股
  - 如果投资者本来想要均衡配置，这个变化就偏离了初衷
  - 关注公告、评估方向、做决定，三步不能省
  *边界*: 基准调整有时只是精细化和贴合实际，不一定意味着策略大变。
