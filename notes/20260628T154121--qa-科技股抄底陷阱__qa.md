* 引子

晨星美股研究团队认为，美股一季度的下跌并非关税冲击所致，而是科技股估值泡沫破裂后的自我修正。AI概念股在DeepSeek出现前就已经见顶，说明问题不在外部冲击，而在内部估值。文章给出了二季度价值股优于成长股的核心判断，并提醒投资者不要因为下跌就抄底科技股。

* Q1: 科技股下跌真因是关税吗？

  *结论*：不是，主因是大型科技股自身估值过高后的回调，10只权重股的负回报就超过了整体市场跌幅。

  *形式化*：归因: 10只权重股拖累 > 整体市场跌幅 → 非系统性冲击

  *怎么想到的*：
  - 晨星对美国市场指数做了一季度归因分析
  - 发现仅10只股票的负回报就超过了指数整体跌幅
  - 说明其他股票其实在涨，市场并非全面下跌
  - 这10只股票大多与AI产业链深度绑定

  *边界*：如果关税政策超预期升级，外部因素可能压过内部因素成为主因。

* Q2: 为什么DeepSeek不是AI股转折点？

  *结论*：多数AI概念股估值在DeepSeek引发关注之前就已经见顶，DeepSeek只是加速了暴露而非原因。

  *形式化*：估值见顶时间 < DeepSeek出现时间 → 内因非外因

  *怎么想到的*：
  - 晨星观察到AI概念股估值早于DeepSeek见顶
  - 说明泡沫破裂是自发性的，与外部事件无关
  - 过高的估值叠加市场情绪转变导致调整
  - DeepSeek只是让问题更快暴露的催化剂

  *边界*：如果DeepSeek没有出现，调整可能更晚发生但幅度未必更小。

* Q3: 价值股为什么能逆势上涨？

  *结论*：价值股前期处于估值低位，基本面持续改善，一季度的修复只是回归合理价值的过程。

  *形式化*：估值低位 + 基本面改善 → 下跌时抗跌 + 上涨时领涨

  *怎么想到的*：
  - 价值股在估值低位成功筑底后逆市上扬4.59%
  - 成长股估值溢价从年初24%收缩至3%
  - 晨星重新评估公允价值后认为价值股仍有安全边际
  - 资金从高估值成长股流向低估值价值股

  *边界*：如果经济衰退超预期，价值股的基本面改善可能不足以支撑估值。

* Q4: 小盘股现在能买吗？

  *结论*：估值虽低但时机未到，三个宏观条件（宽松周期、利率下行、经济复苏）短期内难以同时满足。

  *形式化*：低估值 ≠ 马上涨，需: 宽松 ∩ 利率下行 ∩ 复苏 → 缺一不可

  *怎么想到的*：
  - 小盘股历史上在三种宏观共振时表现最佳
  - 美联储预计今年降息三次但长期利率下半年才下行
  - 美国经济增长率逐季放缓直到2026年初
  - 三个条件无法在短期内形成合力

  *边界*：如果通胀超预期回落，利率下行可能提前到来。

* Q5: 护城河宽的企业现在为什么值得买？

  *结论*：大部分宽护城河企业估值已降至区间底部，经济放缓期它们比缺乏竞争力的企业更有稳定性。

  *形式化*：护城河宽 → 经济下行时盈利稳定 + 当前估值底部 → 高安全边际

  *怎么想到的*：
  - 晨星预计美国经济增长率逐季放缓
  - 盈利增长受挑战时缺乏竞争力的公司更艰难
  - 护城河来源（转换成本、无形资产、网络效应等）提供抗风险能力
  - 当前估值底部介入提供较高安全边际

  *边界*：护城河本身不能抵御系统性风险，市场整体下跌时仍会回撤。

* Q6: 公用事业板块为什么需要警惕？

  *结论*：尽管AI可能推动电力需求增长，但当前定价已过度透支未来增长潜力，泡沫正在加剧。

  *形式化*：AI电力需求预期 → 公用事业定价过度反映 → 泡沫化

  *怎么想到的*：
  - 公用事业是当前唯一估值泡沫加剧的板块
  - 市场将AI对电力的需求增长预期过度定价
  - 即使需求真的增长，价格可能已经提前反映了
  - 这是少数被晨星明确警告的板块

  *边界*：如果AI电力需求增长远超预期，当前定价可能反而显得合理。

* 收口

晨星的核心贡献是：用归因分析证明科技股下跌是内因非外因，并指出在经济放缓期应转向有护城河的价值股而非抄底高估值成长股。
