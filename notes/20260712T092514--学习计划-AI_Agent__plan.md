# AI Agent 学习计划

> 目标：从零建立对 AI Agent 的**可操作理解**——不是"知道 AI Agent 是什么"，而是"能判断 AI Agent 能做什么、做不了什么、下一步会往哪走"。
>
> 方法论基础：肖璟《如何快速了解一个行业》的假设驱动 + MECE 拆解 + DIKW 模型。

---

## 学习前：三个假设（先猜，再证）

在开始学习前，先写下你的初始假设——粗糙不怕，关键是**可证伪**。

```markdown
*我的初始假设（2026-07-12）：*

H1: AI Agent 的本质是"LLM 做决策 + 工具做执行"的闭环。
   对 or 错？验证方式：读 ReAct 原论文，看是否符合。

H2: 当前 Agent 的技术瓶颈不在模型能力，在工程可靠性（成功率、成本、延迟）。
   对 or 错？验证方式：跑一个最小 Agent demo，看卡在哪。

H3: 最先落地的 Agent 形态是"垂直场景 + 强约束 + 易验证"——代码助手、客服、数据分析。
   对 or 错？验证方式：找 2024-2025 年融资最多的 Agent 创业公司，看它们集中在哪些场景。
```

> 每学完一个模块，回来修订一个假设。学习结束时对比——看哪些猜对了、哪些猜错了、为什么错。

## 阶段零：建立最小领域认知（~3-5 天）

> 肖璟：如果对所研究话题缺乏基本了解，先与业内人士交流，或找高质量综述材料研读。

### 0.1 综述论文（2-3 天）

| 优先级 | 论文 / 材料 | 为什么读 | 要回答什么问题 |
|:-----:|:----------|:--------|:------------|
| ⭐ | [Lilian Weng: LLM Powered Autonomous Agents](https://lilianweng.github.io/posts/2023-06-23-agent/) | Agent 最清晰的框架综述 | Agent 由哪几块组成？各自解决什么问题？ |
| ⭐ | [ReAct 论文](https://arxiv.org/abs/2210.03629) | Agent 推理+行动的经典方法 | LLM 怎么做到"边想边做"？ |
| ⭐ | [GPT-4 Technical Report](https://arxiv.org/abs/2303.08774) 中 tool use / function calling 章节 | 了解 LLM 怎么用工具 | 模型级别提供了什么能力？ |

读论文的**目标不是全读懂**——是回答三个问题后合上：

```
Q1. Agent 最核心的三块是什么？（答：规划+工具+记忆）
Q2. 这三块每块当前做到什么程度了？
Q3. 行业认为最大的卡点在哪？
```

### 0.2 行研报告扫读（1 天）

肖璟推荐：对照商业模式画布按图索骥。

| 机构 | 报告 | 重点看 |
|:---:|:----|:-----|
| a16z | "The State of AI Agent" 或类似报告 | 他们怎么切分赛道？头部公司有哪些？ |
| Sequoia / Coatue | 生成式 AI 报告中 Agent 相关章节 | 投资人觉得价值在哪？ |
| 国内券商（中金/华泰） | AI Agent 相关策略报告 | 国内视角怎么理解？ |

> 读报告的目标：**拿到投资人视角的"赛道地图"**——谁在哪玩、分几类、谁是头部。

### 0.3 画出"最小知识地图"

读完以上材料后，合上电脑——**在一张纸上画出 AI Agent 的结构**：

```
画出来应该像这样（验证你的 MECE）：

AI Agent
  ├─→ 认知层（LLM 做什么？）
  ├─→ 工具层（调用什么外部能力？）
  ├─→ 记忆层（短期？长期？）
  ├─→ 评估层（怎么知道 Agent 做对了？）
  └─→ 应用层（落地在哪些场景？）

每层 → 列出 3-5 个关键技术/产品/论文
```

**如果你画不出来 → 说明阶段零没完成，回去补。**

## 阶段一：MECE 拆解 + 逐层深入（~2-3 周）

> 肖璟：将所有情况逐一拆解，构建所有可能情景，列出子假设。

### 1.1 技术栈多层拆解

```
                        AI Agent 知识结构
                              │
            ┌─────────────────┼─────────────────┐
            │                 │                 │
       [感知层]           [推理/规划层]        [行动层]
       怎么理解世界        怎么做决策           怎么执行
            │                 │                 │
       ├─ 文本理解       ├─ Prompt Chaining  ├─ API 调用
       ├─ 多模态理解     ├─ Chain of Thought ├─ 代码执行
       ├─ 环境感知       ├─ ReAct            ├─ 浏览器操作
       └─ 意图识别       ├─ Tree of Thought  └─ 数据库 CRUD
                         ├─ Plan-and-Execute
                         └─ Multi-Agent 编排
                              │
                       [记忆层] ←→ [评估层]

       每层的子项 → 就是你的子假设 → 逐个验证
```

### 1.2 每周深一层（假设驱动）

**第 1 周：推理/规划层**

```
假设：Agent 的能力上限 ≈ LLM 的规划能力上限
    │
    ├─→ 子假设 1：CoT 能解决单链任务 → 读 CoT 论文 + 跑一个 demo 验证
    ├─→ 子假设 2：ReAct 引入工具调用 → 读 ReAct + 看 LangChain ReAct 实现
    └─→ 子假设 3：复杂任务需要 Tree of Thought → 是否需要？什么场景下需要？
```

验证后修订假设。

**第 2 周：工具 + 记忆层**

```
假设：工具调用是 Agent 最成熟的层，记忆层是最不成熟的层
    │
    ├─→ 验证工具：看 OpenAI Function Calling / Anthropic Tool Use 文档
    └─→ 验证记忆：读 RAG 论文 / MemGPT / LangMem 中短期记忆对比
```

**第 3 周：应用层（哪些场景先跑通）**

```
假设：代码 Agent > 客服 Agent > 数据分析 Agent > 复杂规划 Agent（落地成熟度排序）
    │
    ├─→ 验证：看 GitHub Copilot / Devin / Cursor 的使命达成率
    ├─→ 验证：看 Intercom / Ada / Cresta 等客服 Agent 的落地效果
    └─→ 验证：看哪些场景"叫好不叫座"？为什么？
```

### 1.3 每周末：POV 更新

肖璟在景气度那一章的核心思想：**方向对不对，要高频验证。**

每个周末花 30 分钟做三件事：

```
① 本周 AI Agent 圈发生了什么？（看 Twitter/X + 技术博客 + 论文）
② 跟我上周的假设对上了吗？
③ 下周应该验证哪个子假设？
```

## 阶段二：动手验证（贯穿全程）

> 肖璟：理论学完要用案例内化。

### 2.1 最小可行 Agent（MVP）

| 周 | 做什么 | 验证什么假设 |
|:--:|:------|:----------|
| W1 | 用 LangChain / LlamaIndex 搭一个最简单的 ReAct Agent | Agent 的基本闭环能不能走通？ |
| W2 | 让它能调用工具（查天气/搜 Wikipedia） | 工具调用的门槛在哪？ |
| W3 | 加一个长期记忆（简单的向量数据库） | 记忆层的难度是？ |
| W4 | 跑一个有意义的实际任务（自动总结周报 / 自动发邮件） | 成功率和成本怎么样？ |

**目标不是做一个好产品，是在做失败的过程中理解每层的真实难度。**

### 2.2 失败日志

每次 Agent 出错就记下来：

```markdown
* 时间：2026-07-20
* 任务：让 Agent 搜索最新 AI 新闻并总结
* 失败方式：调用了错误的工具 API（给了旧版的 Wikipedia endpoint）
* 失败原因：工具描述写得不够精确
* 这揭示了什么：Agent 对工具描述的质量高度敏感 → 
  → 子假设补充：Agent 工程的 80% 工作量在工具描述和 prompt tuning
```

## 验收标准：学习结束时你能回答这 5 个问题

学习 4-6 周后，你应该能**脱离笔记**回答：

```
Q1: AI Agent 的三大核心能力是什么？它们的成熟度排序是？
    → 如果答不出：你漏了某一层

Q2: 目前 Agent 落地最难的部分是什么？是模型不行还是工程不行？
    → 如果答不清：你的第二阶段动手做得不够

Q3: 如果你是创业者，你会选哪个 Agent 场景切入？为什么？
    → 如果你选不出来：你的应用层验证不够

Q4: 你的初始假设（阶段零写的三个）对了几个？为什么对/错？
    → 这个对比才是学习真正的收获——"你以为的 vs 实际情况的差距"

Q5: 未来 6 个月 AI Agent 最可能发生什么变化？
    → 如果你能给出一个可证伪的预判——你的行业认知已经建立起来了
```

---

## 时间安排建议

```
阶段零（最小认知）: ~3-5 天 — 论文+报告+画地图
阶段一（逐层深入）: ~2-3 周 — 每周深一层，周末 POV 更新
阶段二（动手验证）: 贯穿全程 — 每周一个 MVP 迭代
阶段三（持续跟踪）: 贯穿全程 — 每日 15min + 每周 30min + 每月 1h
```

总投入：**每天 1-1.5 小时，6 周后你建立的理解，比漫无目的读 6 个月博客要深。**
