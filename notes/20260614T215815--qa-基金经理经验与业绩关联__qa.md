* 引子
投资者常把"资深"等同于"优秀"，但晨星研究显示，基金经理的经验年限与业绩并无显著正相关。真正决定长期业绩的，是基金经理的性格特质——能否在牛市保持清醒、在熊市保持纪律、在市场狂热时拒绝跟风。

* Q1: 为什么10年经验的基金经理不一定比5年经验的业绩好？
  *结论*：经验年限只代表"活下来"，不代表"活得好"，关键看经验是否转化为投资纪律。
  *形式化*：经验 = 时间 × 反思深度 → 有时间无反思 = 1年经验重复10次
  *怎么想到的*：
  - 晨星研究发现经验年限与业绩无显著正相关
  - 关键不在"经历过什么"，而在"从经历中学到什么"
  - 有些10年经验经理仍在重复错误，有些5年经验经理已建立成熟框架
  - 案例：王宗合10年+经验，但管理的鹏华匠心精选3年跌38%
  *边界*：在特定市场环境下（如单边牛市），经验丰富的经理可能更有优势，但长期看性格>经验。

* Q2: 牛市中最考验基金经理的能力是什么？
  *结论*：不是赚多少，而是能否拒绝"趁火打劫"的诱惑，保持风险意识。
  *形式化*：牛市考验 = 风险识别能力 + 自律能力 → 拒绝追高 → 控制回撤
  *怎么想到的*：
  - 2020年很多基金经理把行情当能力，忽视潜在风险
  - 调研时问绩优经理"组合风险在哪"，回答"业绩这么好，不存在风险"
  - 高集中度、高估值风险被忽视，导致2021-2023年大幅回撤
  - 对比：有经理在2020年说"这么高收益是市场赏的，不能指望年年如此"
  *边界*：在牛市中，保守的经理可能短期跑输，但长期看这种"保守"恰恰是最大的超额收益来源。

* Q3: 基金定期报告中如何识别基金经理的"自我服务偏见"？
  *结论*：业绩好时强调内部因素（选股能力），业绩差时甩锅外部因素（市场风格），这是危险信号。
  *形式化*：自我服务偏见 = 成功归己 + 失败归因市场 → 缺乏反思 → 重复犯错
  *怎么想到的*：
  - 美国研究：59%成功归因内部，83%失败归因外部
  - 语言分析："战胜基准因为消费配置"=归己，"业绩受逆风影响"=甩锅
  - 有偏见的经理更愿承担风险、更多交易，但业绩反而更差
  - 投资者可通过季报"小作文"观察基金经理归因方式
  *边界*：偶尔甩锅可能是情绪宣泄，但持续甩锅说明缺乏反思能力，这类经理应回避。

* Q4: 为什么"敬畏市场"的基金经理长期业绩更好？
  *结论*：谦逊的经理承认市场不可预测，建立风控流程；自负的经理高估自己，忽视风险。
  *形式化*：敬畏市场 = 承认无知 + 建立纪律 → 控制回撤 → 长期复利
  *怎么想到的*：
  - 2020年保持清醒的经理在2021-2023年熊市中"守住了钱"
  - 自视过高的经理把成功归因能力，忽视运气成分
  - 经历教训后完善投资流程和风控措施
  - 案例：2020年某经理说"市场赏的，不能指望年年如此"，后续3年跌幅可控
  *边界*：敬畏市场不等于保守，而是在进攻和防守之间找到平衡，这需要经验和反思的结合。

* Q5: 普通投资者如何"看性格选基金经理"？
  *结论*：读季报看归因方式、看牛市中是否限购、看最大回撤控制能力。
  *形式化*：性格识别 = 归因风格 + 风控记录 + 牛市行为 → 选择谦逊+纪律型
  *怎么想到的*：
  - 季报"小作文"看成功/失败时如何归因
  - 牛市中是否主动限购（2020年少有经理限购）
  - 最大回撤是否可控（对比同类基金）
  - 是否经历过完整周期（至少一轮牛熊）
  *边界*：性格判断需要时间，不宜频繁更换基金；历史表现不保证未来，但行为模式有一定延续性。

* 收口
基金经理的经验是必要条件，但非充分条件；真正决定长期业绩的是性格——能否在顺境中保持谦逊，在逆境中保持纪律，这种品质比10年、20年经验更稀缺也更珍贵。
