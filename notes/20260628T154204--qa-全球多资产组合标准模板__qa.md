* 引子

高盛用全球所有可投资金融资产的流通市值做了一个"标准"全球多资产组合——股票约60%、债券约40%、黄金和另类资产加起来不到10%。这个组合不是"正确答案"，而是一个中性的起点。中国的现实是QDII基金仅占非货公募的4%，"本土偏好"严重到投资者可能错失了全球90%以上的股票机会。

* Q1: 为什么用市值加权作为全球配置的起点？

  *结论*：市值加权代表"中立"——不押注任何市场，只反映各市场在经济中的实际份额。

  *形式化*：`市值加权 = 不主动下注 → 反映各市场在全球经济中的真实份额`

  *怎么想到的*：
  - 国际机构常用的做法是以市值加权指数为基准
  - 市值综合反映了市场和资产的表现
  - 背后对应的是该市场在全球经济中的相对份额
  - 这是一个不做主动判断的"中立"起点

  *边界*：市值加权反映的是过去和当前的经济权重，不代表未来表现。

* Q2: 这个"标准"组合是静态的吗？

  *结论*：完全不同时代股债比例剧烈变动——70年代黄金占20%，90年代股债60/40，危机后40/60。

  *形式化*：`70年代: 黄金≈20% | 90年代: 股60债40 | 危机后: 股40债60 | 当前: 股≈60债≈40`

  *怎么想到的*：
  - 70-80年代高通胀，黄金在组合中占比一度达20%
  - 90年代末科技泡沫推动股票占比升至近六成
  - 全球金融危机后股债比例逆转为40/60
  - 资产相对价值持续变动，"最优配置"因时代而异

  *边界*：历史规律不保证未来重复，当前比例只是当下的快照。

* Q3: 为什么晨星说战术配置"听起来很美但实际很难"？

  *结论*：因为最优配置只有事后才知道，多数战术配置基金跑输"什么都不做"的60/40组合。

  *形式化*：`理论: 阶段增强 → 更优风险调整收益 | 实际: 多数战术基金 < 60/40基础组合`

  *怎么想到的*：
  - 1990年以来，阶段性增加比特币、REITs等另类资产能提升收益
  - 但"最优配置"只有事后诸葛才能知道
  - 晨星大量研究显示多数战术基金跑输基础60/40
  - 说明择时和主动调仓对多数人来说是负期望游戏

  *边界*：极少数有持续择时能力的投资者可能例外，但无法事先识别。

* Q4: 中国投资者的"本土偏好"有多严重？

  *结论*：中国股票仅占全球股市3%，但中国投资者QDII配比仅4%——错失90%以上国际机会。

  *形式化*：`中国股票占全球: 3% | 中国投资者海外配比: 4% | 本土偏好 → 错失>90%全球股票机会`

  *怎么想到的*：
  - MSCI世界指数中中国仅占约3%
  - 其余97%是国际股票
  - 中国投资者QDII占非货公募仅4%
  - 本土偏好让投资者大幅超配本国市场

  *边界*：本土偏好有信息优势，熟悉的公司确实更容易判断。

* Q5: 配置不同市场时，应该怎么排优先级？

  *结论*：把研究精力放在体量大、占比高的主流市场上，小众市场不超配。

  *形式化*：`主流市场(美、欧、日): 体量大 → 优先配置 | 小众(越南、沙特): <1% → 不重仓`

  *怎么想到的*：
  - 越南、沙特等小众市场占比不到1%
  - 重仓配置意味着大幅超配，承担更高主动风险
  - 需要建立在非常充分的认知基础上
  - 有限精力应优先放在更重要的市场上

  *边界*：如果有特殊信息优势或深度研究能力，小市场可能产生超额收益。

* Q6: 债券在组合中的角色为什么被反复强调？

  *结论*：债券长期占比40%-60%，与股票低相关性使其成为风险调整收益的关键。

  *形式化*：`股票 + 债券: 低相关性 → 降低整体波动 → 提升风险调整收益 → 60/40经久不衰`

  *怎么想到的*：
  - 全球组合中债券占比长期在40%-60%
  - 股债相关性通常较低
  - 增加债券敞口有助于提升风险调整后收益
  - 这解释了60/40组合经久不衰的原因

  *边界*：在利率上行周期，股债可能同跌，低相关性会被打破。

* Q7: 黄金占比小但波动大，配置时应该注意什么？

  *结论*：黄金近30年在全球组合中占比不到10%，且波动极高，应慎重控制配比。

  *形式化*：`黄金: 占比<10% + 波动极高 + 受投机驱动 → 慎重控制配比`

  *怎么想到的*：
  - 各国央行买入黄金推动金价飙升
  - 但黄金在全球组合中占比近30年都在10%以下
  - 历史波动性极高
  - 价格走势在很大程度上受投机性买家驱动

  *边界*：如果出现极端金融体系风险，黄金的对冲价值会显现。

* Q8: 偏离"标准"组合的本质是什么？

  *结论*：偏离等于主动表达投资观点——可能超额收益，也可能亏损，必须充分认知风险。

  *形式化*：`中性配置: 不表态 | 偏离: 主动表态 → 超额收益 or 额外亏损`

  *怎么想到的*：
  - 威廉·夏普描述的"虚构全球投资者"是基准
  - 现实中没有人是完全"平均"的
  - 高配或低配本质上是在做主动决策
  - 偏离可能意味着超额收益，也可能带来亏损

  *边界*：如果对偏离的资产没有深入认知，偏离更多是赌博而非投资。

* 收口

作者贡献了一个"全球配置的思维框架"：以市值加权为起点、破除本土偏好、排优先级、重视债券、控制黄金配比、偏离基准要有理有据——标准模板是地图，不是目的地。
