* 引子

晨星2026全球展望报告的核心主张是"不做预测只谈应对"。2025年证明了华尔街的预测反复打脸，所以晨星选择不提供具体点位，而是帮投资者识别长期结构性机会和潜在风险。报告围绕三条主线展开：贸易摩擦与货币政策的不确定性、AI军备竞赛的潜在风险、弱美元下的货币对冲机会，以及中国"反内卷"政策带来的结构性机会。

* Q1: 为什么晨星"不做预测只谈应对"？

  *结论*：因为即便是规模最大的机构也预测不准，应对框架比点位在2026年更有价值。

  *形式化*：`华尔街2025: 多次预测 → 多次打脸 | 晨星: 放弃预测 → 构建应对框架`

  *怎么想到的*：
  - 2025年地缘政治一夜改变市场走向
  - 华尔街头部机构对美股预测多次变脸
  - 人类天生有"在错误时间行动"的倾向
  - 不预测、只应对是承认不可知论

  *边界*：如果市场进入高度可预测的单边市，应对框架的价值会下降。

* Q2: 2026年两种主要不确定性分别是什么？

  *结论*：贸易摩擦（关税可能继续加码）和货币政策（各国央行步调不一致）。

  *形式化*：`不确定性 = 贸易摩擦(关税加码) + 货币政策(央行步调不一)`

  *怎么想到的*：
  - 美国尚未消化已实施关税的影响，明年可能进一步提高
  - 如果对中国加征新关税，可能引发更大范围动荡
  - 美联储已重启降息，其他央行倾向于按兵不动或小幅下降
  - 央行政策差异是市场波动的重要来源

  *边界*：如果贸易紧张缓和或央行协调行动，不确定性会降低。

* Q3: AI为什么是2026年影响最深的技术变革？

  *结论*：AI支出已达每年数千亿美元，但商业模式不明、成本超支风险高，类似90年代互联网泡沫。

  *形式化*：`AI: 年支出数千亿 + 数据中心疯狂扩建 → 商业模式不明 + 能源限制 + 成本超支风险 → 类似互联网泡沫`

  *怎么想到的*：
  - 超大型科技公司数据中心资本支出每年数千亿
  - 2026年预计达美国上市能源行业总支出的四倍以上
  - 算力需求带来巨大能源和环境压力
  - GPU和服务器实际寿命可能低于预期，无法实现计划回报
  - 晨星美国指数与AI指数重叠超30%，被动投资者已大量暴露

  *边界*：如果AI加速落地并产生真实盈利，当前担忧会被证明过度。

* Q4: 持有宽基美股指数的投资者，为什么已经被动重仓了AI？

  *结论*：因为晨星美国指数与AI指数重叠超30%，买指数就等于三成配在AI上。

  *形式化*：`买美股指数 = 30%被动配在AI → 无需主动追就已经大量暴露`

  *怎么想到的*：
  - 晨星美国指数与晨星AI指数重叠超过30%
  - 投资者即使不主动买AI主题基金，也已经通过指数大量暴露
  - AI指数价格/公允价值比自2023年起在74%-114%之间波动
  - 超过100%说明部分时段处于高估状态

  *边界*：如果AI公司在指数中权重继续上升，被动暴露会更大。

* Q5: 弱美元为什么是全球配置的转折点？

  *结论*：美元长期强势周期结束，为非美市场提供了估值吸引力和货币升值双重机会。

  *形式化*：`美元强势周期结束 → 美国投资者: 增配非美(估值+货币升值) | 非美投资者: 管理美元敞口(对冲或分散)`

  *怎么想到的*：
  - 2025年美元大幅下跌是转折点
  - 美国投资者增加非美配置可分散风险并对冲美元疲软
  - 非美投资者需要管理美元配置，货币对冲可转化为潜在回报
  - 关键是平衡对冲成本与分散收益

  *边界*：美元如果反转走强，非美配置的汇兑收益会变成亏损。

* Q6: 中国"反内卷"政策的机会为什么只适合长期投资者？

  *结论*：因为政策落地需要数年，短期投资者等不起，深度研究的长期投资者反而最可能受益。

  *形式化*：`反内卷: 限产调结构削补贴 → 产能向龙头集中 → 盈利改善 → 数年兑现 → 只适合长期投资者`

  *怎么想到的*：
  - 化解产能过剩需要限产、调结构、削补贴
  - 市占率高、盈利稳定的龙头公司更可能受益
  - 电动汽车和电池行业是典型案例
  - 钢铁、光伏等行业缺乏明确龙头，效果不确定
  - 政策落地需数年，回报周期长

  *边界*：政策执行力度如果不及预期，时间窗口会进一步拉长。

* Q7: 晨星给出的三条"不变"建议是什么？

  *结论*：独立视角（逆势布局）、理解周期（抵制从众）、贴合自身需求（分散配置）。

  *形式化*：`三条建议: 独立视角(买失宠资产) + 理解周期(狂热时冷静) + 贴合需求(分散抗冲击)`

  *怎么想到的*：
  - 独立视角：最优质机会藏在暂时失宠的资产中
  - 理解周期：繁荣孕育萧条，抵制从众行为
  - 贴合自身需求：组合核心意义是满足实际需求，不只是追回报
  - 三条都指向同一个底层逻辑：不跟风、不冲动

  *边界*：逆势布局可能面临阶段性亏损，需要心理承受力支撑。
