* 引子
QDII基金让普通投资者能投海外，但海外市场的信息差和投研门槛远高于国内。晨星从环球股票、大中华区股票、美元债三个方向选出四只QDII基金，核心看点是：基金经理有没有真正的海外投研能力和团队支持。

* Q1: 选QDII权益基金最该看什么？
  *结论*: 看基金经理的全球投资经验+平台研究资源，不看过往业绩。
  *形式化*: QDII权益 = 海外经验 × 研究平台 × 策略清晰度 → 缺一跑输
  *怎么想到的*:
  - 李耀柱全球市场投资经验仅4年，但广发有国际业务部+对接高盛/摩根研究
  - 宁君9年港股经验+富国海外权益投研团队支持
  - 海外投资最缺的是研究和信息，没有平台支持个人能力再强也难持续
  *边界*: 如果基金公司缩减海外研究投入，基金经理的能力会打折扣。

* Q2: 广发全球精选为什么能在QDII中排名靠前？
  *结论*: 李耀柱抓住了信息技术股的大趋势，广发平台提供了研究支撑。
  *形式化*: 全球成长股 + 信息技术集中 + 英伟达/Meta/台积电 → 三年同类排名8%
  *怎么想到的*:
  - 基金重仓信息技术行业，正好赶上AI行情
  - 用宏观定赛道、中观选竞争优势、自下而上估值的框架清晰
  - 对接高盛和摩根的研究资源，弥补了个人海外经验的不足
  *边界*: 如果AI行情退潮，集中押注信息技术可能面临较大回撤。

* Q3: 宁君从纯成长转向加高股息为什么是好事？
  *结论*: 说明她在拓展能力圈、控制回撤，不赌单一风格。
  *形式化*: 成长股 → 成长+高股息 → 进攻+防守 → 回撤收窄 + 泡泡玛特等牛股
  *怎么想到的*:
  - 宁君的核心选股逻辑始终是竞争壁垒+成长空间+估值
  - 2023年加高股息不是风格漂移，而是增加组合防御性
  - 泡泡玛特2024年上半年买入，说明对新业态保持敏锐
  *边界*: 高股息策略在成长风格占优时可能跑输纯成长基金。

* Q4: QDII美元债基金的核心价值是什么？
  *结论*: 获取海外债券收益+汇率分散，适合做资产配置的底仓。
  *形式化*: QDII美元债 = 美元信用债（中短久期）+ 美债波段操作 → 收益增强 + 风险可控
  *怎么想到的*:
  - 祁广东10年美元债经验+易方达国际固收团队，管理6年+
  - 郑涛20年海外债经验，2020年后从高收益地产债转向投资级
  - 两只债基都强调信用风险控制和分散配置
  *边界*: 美元升值时人民币份额受益，美元贬值时会侵蚀收益。

* Q5: 为什么中资美元债基金要关注地产债配置变化？
  *结论*: 2020年前后中资美元地产债风险格局完全不同，回避了高风险才是本事。
  *形式化*: 2020年前：地产债违约率低 → 配置高收益地产债 → 超额高；2020年后：违约率↑ → 转向投资级 → 避坑
  *怎么想到的*:
  - 郑涛2020年后主动降低地产债仓位，转向投资级债券
  - 说明基金经理有风险判断能力，不是追逐收益
  - 严格分散配置、不碰无评级品种，是长期稳健的体现
  *边界*: 如果中资美元债市场整体转向，基金经理及时调整策略的能力是关键。

* Q6: 为什么QDII基金特别依赖基金公司平台？
  *结论*: 海外投研靠个人不如靠团队，平台资源决定持续超额能力。
  *形式化*: QDII超额 = 个人能力 + 公司海外团队 + 外部券商资源 → 缺一不可
  *怎么想到的*:
  - 广发有国际业务部+对接高盛/摩根
  - 易方达国际固收团队人数和经验行业前列
  - 中银有专门的海外宏观策略研究员
  *边界*: 如果基金经理离职但平台和策略稳定，基金还能持续；如果核心人员离开且无接替，需要警惕。

* 收口
晨星选这四只QDII的标准：基金经理经验只是门槛，真正的差异化来自基金公司有没有持续的海外投研投入和团队支持。对个人投资者来说，QDII的核心价值是分散配置，而不是赌海外收益比国内高。
