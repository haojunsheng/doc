* 引子

文章颠覆了"黄金是稳赚不赔的抗通胀神器"这一常见认知，指出黄金是无息资产、没有内在价值、价格完全由供需决定。长期能跑赢通胀但短期波动巨大。央行囤金是出于配置考量而非投资逻辑，普通投资者也应将黄金视为"保险"而非赚钱工具。

* Q1: 为什么说黄金"不值钱"？

  *结论*：黄金是无息资产，不产生任何现金流，无法通过折现模型评估价值，价格完全由供需决定。

  *形式化*：无息资产 → 无现金流 → 无内在价值 → 纯供需定价

  *怎么想到的*：
  - 资产价值来源于未来产生现金流
  - 黄金不会产生股息、利息或票息
  - 无法用折现模型评估现值
  - 价值只取决于市场愿意支付的价格
  - 这一点与石油、小麦等商品无异

  *边界*：如果重新建立金本位制，黄金将获得制度性需求支撑。

* Q2: 黄金短期能抗通胀吗？

  *结论*：不能，1995-2004年黄金有近10年跑输通胀，且黄金波动远大于物价波动。

  *形式化*：短期: 黄金波动 >> 物价波动 → 抗通胀无效

  *怎么想到的*：
  - 长期看黄金确实大幅跑赢通胀
  - 但短期表现不稳定
  - 1995-2004近10年落后于通胀
  - 每年对比看金价与通胀率不同步
  - 1980-1990最大回撤57%
  - 2011-2015回撤超40%

  *边界*：在高通胀+地缘危机叠加的极端时期（如1970年代），黄金短期抗通胀效果很好。

* Q3: 央行为什么囤金？

  *结论*：四个原因——平衡外汇储备、外汇储备多元化、稳定法定货币信用、对冲地缘风险，都是配置逻辑而非投资逻辑。

  *形式化*：央行囤金 = 储备平衡 + 多元化 + 稳定货币 + 对冲地缘

  *怎么想到的*：
  - 黄金在各国央行金融储备中占重要地位
  - 平衡外汇储备是国际清偿力的组成部分
  - 外汇储备多元化降低集中风险
  - 黄金储备增强主权货币国际信任度
  - 黄金不受任何国家货币政策直接影响

  *边界*：如果全球进入数字货币主导时代，黄金的货币属性可能进一步弱化。

* Q4: 黄金在组合中扮演什么角色？

  *结论*：保险角色——通过与其它资产的低相关性甚至负相关性降低组合整体风险，在极端事件中提供保护。

  *形式化*：黄金 = 保险 = 低相关性 + 极端事件保护

  *怎么想到的*：
  - 黄金与其它金融资产相关性低
  - 有时甚至呈负相关
  - 纳入组合能有效降低整体风险
  - 面对极端风险（恶性通胀、货币体系崩溃）提供保护
  - 适量配置平衡风险提升稳定性

  *边界*：如果黄金与股票相关性持续上升（如危机时同涨同跌），保险价值会打折扣。

* Q5: 普通人应该投资黄金还是配置黄金？

  *结论*：配置而非投资——目标是降低组合风险而非获取高收益，需要长期持有而非短期交易。

  *形式化*：投资黄金 = 追求收益（不适合） | 配置黄金 = 对冲风险（适合）

  *怎么想到的*：
  - 单纯投资黄金抗通胀需要择时和运气
  - 10年周期也可能被套住
  - 研究金价走势比分析股票更困难
  - 配置角度利用低相关性降低风险
  - 不将其视为短期高收益工具

  *边界*：如果投资者有极强的宏观判断能力，投资黄金也可以获得超额收益。
