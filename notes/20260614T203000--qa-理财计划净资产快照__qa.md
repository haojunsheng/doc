* 引子
理财计划的第一步不是记账，而是「算清楚你现在有多少钱」。这个「多少钱」不是月收入、不是存款余额，而是「净资产」——总资产减总负债。文章把资产和负债分别按流动性拆成四类，再用「资产集中度」和「现金垫厚度」两个维度给财务状况做体检。它回答的是：你到底站在哪条起跑线上。

* Q1: 为什么理财计划的第一步是算净资产而不是记账？
  *结论*：净资产是「家底照片」，记账是「日常流水」，先有照片才知道流水该往哪流。
  *形式化*：净资产 = 总资产 - 总负债；理财计划步骤 = ① 算净资产 → ② 记账 → ③ 分析调整。
  *怎么想到的*：
  - 净资产告诉你「此刻你有多少钱」，是静态快照；记账告诉你「过去一段时间钱怎么动」，是动态过程。
  - 没有净资产，你不知道结余该拿去还债、投资还是消费——因为你不清楚负债压力有多大。
  - 净资产为负或勉强为正，说明当前财务状况需要立即制定计划；净资产为正且稳定，说明有余力做更长远的规划。
  *边界*：如果净资产为负但未来收入增长可期（如刚毕业负债创业者），当前负值不代表长期财务健康；反之，净资产为正但全是无法变现的资产（如偏远房产），数字好看但流动性差。

* Q2: 为什么要按流动性把资产分成流动和非流动？
  *结论*：流动性决定「你能不能马上用这笔钱」，非流动资产是财富但不是现金。
  *形式化*：总资产 = 流动资产（现金/存款/股票/基金）+ 非流动资产（房产/汽车/收藏品）。
  *怎么想到的*：
  - 流动资产可以立刻变现应对突发事件（失业、疾病、意外），是财务安全的缓冲垫。
  - 非流动资产虽然价值高，但变现周期长、成本高（卖房要几个月、卖车要折价）。
  - 只看总资产不看流动性，会高估自己的抗风险能力——「我有200万资产」但其中190万是房子，手里只有10万现金，遇到急事一样抓瞎。
  *边界*：如果非流动资产是核心城市优质房产，虽然流动性差但可以通过抵押贷款快速变现，实际流动性比表面高。

* Q3: 为什么要检查「某类资产过度集中」？
  *结论*：资产集中 = 风险集中，一旦该类资产大跌，净资产会跟着跳水。
  *形式化*：资产集中度 = 某类资产 / 总资产；集中度 > 60-70% → 风险偏高；如房产占比过高 → 房价下跌 → 净资产缩水。
  *怎么想到的*：
  - 中国很多家庭净资产中房产占比超过70%，房价一跌，纸面财富瞬间蒸发。
  - 分散配置的核心逻辑是「不要把所有鸡蛋放一个篮子」，这里「篮子」不是指多只股票，而是指大类资产（房产、股票、现金、债券）。
  - 集中度检查能暴露「看似富裕实则脆弱」的财务结构。
  *边界*：如果集中的是国债、存款等低风险资产，集中度高不等于危险；如果集中的是单一股票或加密货币，哪怕占比30%也危险。

* Q4: 现金垫为什么要3-6个月生活费？
  *结论*：3-6个月是「失业缓冲期」，够你找到下一份工作而不被迫卖资产或借高利贷。
  *形式化*：现金垫 = 流动资产中可随时支取的部分；3个月 = 保守下限；6个月 = 宽裕上限。
  *怎么想到的*：
  - 失业后找到新工作的平均周期是1-3个月，3个月是「最坏情况」的保底线。
  - 如果行业不景气或经济下行，找工作可能需要更久，6个月是安全边际。
  - 现金垫不足 → 失业时被迫卖股票（可能割肉）、借消费贷（高利息）、卖房（周期长且折价），都是「被迫贱卖资产」的财务灾难。
  *边界*：如果收入来源多元（多份兼职、租金收入），现金垫可以低于3个月；如果收入单一且行业波动大，6个月也不够。

* Q5: 净资产为负或勉强为正意味着什么？
  *结论*：说明当前财务状况脆弱，需要立即制定理财计划止血。
  *形式化*：净资产 < 0 → 资不抵债；0 < 净资产 < 6个月支出 → 财务脆弱；净资产 > 6个月支出 → 有缓冲空间。
  *怎么想到的*：
  - 净资产为负意味着「卖掉所有资产还不够还债」，这是财务危机的信号灯。
  - 净资产勉强为正说明缓冲能力极弱，任何大额支出（医疗、失业、意外）都可能击穿财务防线。
  - 这两种情况都意味着「你应该开始理财计划了」——不是投资计划，是止血计划：砍支出、还高息债、建现金垫。
  *边界*：如果净资产为负但负债是长期低息房贷，且收入稳定，不一定需要紧急处理；如果净资产为正但全是借来的（如信用卡套现买房），实际风险比负值还高。

* 收口
作者真正贡献的是一个「财务体检起点」：净资产是体重秤（告诉你多重），流动/非流动性拆分是体脂率（告诉你结构是否健康），现金垫厚度是血压（告诉你抗风险能力）——做完这三项检查，你才知道理财计划该从哪里下手。
