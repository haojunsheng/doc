#+subtitle:   过去十年，哪些基金为中国投资者创造了最多财富？

* 引子
过去十年，公募基金依靠业绩增长累计为中国投资者创造了6.27万亿元的财富。但财富创造极度集中：前10只基金清一色是被动指数产品，7只跟踪宽基指数，2只黄金ETF，1只美股宽基指数。而财富损失最大的基金，大多是聚焦单一赛道的主题行业指数基金或风格极致的主动基金。这篇文章揭示了一个残酷真相：长期创造财富的，不是"最聪明的主动选股"，而是"最朴素的宽基指数"。

* Q1: 为什么"业绩增长创造的财富"要用"基金规模×收益率"来衡量？
  *结论*：因为只有规模足够大，收益率的提升才能真正转化为投资者口袋里的真金白银。
  *形式化*：财富创造 = 基金规模 × 业绩增长率 → 规模大 + 收益高 = 创造财富多
  *怎么想到的*：
  - 问题：一只基金年收益50%，但规模只有1亿，只让投资者赚了5000万
  - 另一只基金年收益10%，但规模1000亿，让投资者赚了100亿
  - 结论：财富创造的绝对金额取决于"规模×收益率"，而非单纯的收益率
  - 这也是为什么榜单上的基金都是"规模庞大的指数基金"
  *边界*：如果基金规模是"短期冲高"来的（如2021年冠军基金），后续回吐会减少财富创造

* Q2: 为什么"宽基指数基金"能创造最多财富？
  *结论*：因为宽基指数分散配置、费率低、长期稳健，适合长期持有，规模容易做大。
  *形式化*：宽基指数 = 分散配置 + 低费率 + 长期稳健 → 规模大 + 持有时间长 → 财富创造多
  *怎么想到的*：
  - 前10只基金中7只跟踪宽基指数（如沪深300、中证500）
  - 宽基指数覆盖多个行业，不会因单一行业回调而大幅回撤
  - 低费率（如ETF费率0.2%）让投资者长期持有成本更低
  - 规模大意味着覆盖的投资者群体广，财富创造效应被放大
  *边界*：如果市场长期熊市（如日本"失去的三十年"），宽基指数也会长期不赚钱

* Q3: 为什么"主题行业指数基金"反而让投资者亏钱？
  *结论*：因为主题基金在短期行情中涨幅吸引大量资金，但随后回调让追高的投资者被套牢。
  *形式化*：主题基金 = 极致风格 + 短期高收益 → 资金追高涌入 → 市场回调 → 投资者亏损
  *怎么想到的*：
  - 文章明确说"极致风格带来的高收益往往难以持续，一旦市场环境发生变化，回撤也可能同样剧烈"
  - 消费和医药基金在2019-2020年表现亮眼，吸引大量资金流入
  - 但随后回调"至今尚未完全从回撤中修复"
  - 逻辑：投资者在高点买入，在低点割肉或套牢，实际收益远低于基金净值增长率
  *边界*：如果投资者能在低点买入、长期持有，主题基金也能赚钱；关键是"买入时点"

* Q4: 前海开源新经济"2021年冠军"为什么反而让投资者亏钱？
  *结论*：因为2021年接近100%的涨幅吸引了大量追高资金，但2022-2023年40%的跌幅让这些资金被套牢。
  *形式化*：2021年涨幅100% → 规模从1.3亿暴增至143亿 → 2022-2023年跌40% → 投资者亏损
  *怎么想到的*：
  - 2021年冠军=接近100%涨幅，吸引大量资金涌入
  - 规模从2020年底1.3亿→2021年底143亿，增长100倍
  - 但2022-2023年累计跌近40%，这些在高点买入的投资者被套牢
  - 即使2024-2025年反弹，仍难以弥补此前回撤
  - 教训：基金净值增长率≠投资者实际收益率，资金流入时点是关键
  *边界*：如果投资者在2022年底部买入，2024-2025年反弹后可能已经回本甚至盈利

* Q5: 为什么"易方达、华夏"能创造最多财富？
  *结论*：因为它们的核心资产集中在"规模大+业绩稳健"的产品上，如指数基金和宽基基金。
  *形式化*：易方达/华夏 = 核心产品规模大 + 业绩稳健 → 财富创造4369亿/3308亿
  *怎么想到的*：
  - 易方达创造4369亿财富（第一），华夏创造3308亿（第二）
  - 易方达旗下有沪深300ETF、中证500ETF等规模庞大的指数基金
  - 华夏旗下有沪深300ETF、上证50ETF等宽基指数基金
  - 这些产品费率低、规模大、长期稳健，适合长期持有
  - 结论：基金公司的财富创造能力取决于"核心产品的规模和业绩"
  *边界*：如果核心产品业绩下滑或规模萎缩，财富创造能力会下降

* Q6: 为什么"华泰柏瑞"能跻身财富创造前十？
  *结论*：因为华泰柏瑞以被动指数产品为特色，旗下有规模庞大的沪深300ETF等产品。
  *形式化*：华泰柏瑞 = 被动指数产品特色 + 规模大 → 财富创造前十
  *怎么想到的*：
  - 文章明确说"以被动指数产品为特色的华泰柏瑞基金，也跻身财富创造前十的基金公司之列"
  - 华泰柏瑞旗下有沪深300ETF（规模超2000亿）等明星产品
  - 被动指数产品费率低、规模大、长期稳健
  - 结论：即使不是头部基金公司，只要在被动指数领域有特色，也能创造大量财富
  *边界*：如果被动指数产品规模被其他公司超越，华泰柏瑞的排名会下降

* Q7: 从"消费和医药基金让投资者亏钱"能推断出什么？
  *结论*：说明即使是"好赛道"（如消费、医药），如果买入时点不对（如在高点追高），也会亏钱。
  *形式化*：好赛道（消费、医药）+ 买入时点错误（高点追高）→ 实际收益为负
  *怎么想到的*：
  - 消费和医药在2019-2020年表现亮眼，吸引大量资金流入
  - 但随后回调"至今尚未完全从回撤中修复"
  - 说明：即使赛道本身没问题，如果投资者在高点买入，也会被套牢
  - 教训：投资不仅要看"买什么"，更要看"什么时候买"

* 收口
晨星通过十年财富创造数据揭示了一个核心洞见：长期创造财富的不是"最聪明的主动选股"或"最热门的赛道"，而是"最朴素的宽基指数+长期持有"——因为宽基指数分散配置、费率低、规模大，适合长期持有，而极致风格的主题基金虽然短期涨幅惊人，但追高的投资者往往在高点买入、低点割肉，最终反而亏钱。
