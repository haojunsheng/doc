#+subtitle:   基金波动大，买银行理财就稳赢了？

* 引子

很多被股市和基金"伤害"的投资者转向银行理财，认为它"稳赚不赔"。但资管新规后，银行理财已经打破刚性兑付，"保本保息"成为历史。文章揭开银行理财"保本"和"低风险"的真相：不是银行机构更安全，而是它主要投资债券等固定收益类资产。

* Q1: 银行理财的"保本保收益"是怎么运作的？

  *结论*：刚性兑付本质是用新投资者的钱给老投资者兜底，不是投资真的不会亏。

  *形式化*：刚性兑付 = 新产品资金 → 兑付老产品本息；本质 = 庞氏结构，不是无风险

  *怎么想到的*：
  - 银行承诺保本保收益，如果投资亏损或没达到承诺收益
  - 就拿新发售产品募集的资金给上一批投资人兑付
  - 只要不断有新投资者加入，前面的人就能拿到钱
  - 但一旦后续资金续不上，就会出现巨大风险

  *边界*：在资管新规前的特殊历史阶段，这种模式确实维持了较长时间。但系统性风险一直在积累，最终监管出手打破。

* Q2: 为什么资管新规要打破刚性兑付？

  *结论*：刚性兑付制造不公平收益分配和系统性风险，违背"投资者风险自担"的资管本质。

  *形式化*：刚性兑付 = 有人亏损 → 用别人钱补 → 不公平 + 风险积累；打破 = 回归资管本质

  *怎么想到的*：
  - 大家一起投资，凭什么有人亏了钱可以拿别人的钱连本带息补上？
  - 这种模式本质是风险积累，不是消除风险
  - 资管行业本质是"受人之托、代客理财、投资者风险自担"
  - 管理人只拿管理费，赚的钱给客户，赔的钱也该客户自己承担

  *边界*：打破刚兑后，投资者需要自己承担风险。这要求投资者具备基本的金融知识和风险意识。

* Q3: 银行理财的"低风险"到底从哪来？

  *结论*：银行理财的"低风险"不是因为银行机构安全，而是因为它主要投资债券、存单等固定收益类资产。

  *形式化*：银行理财 ≈ 债券基金 ≈ 固定收益类资产；风险来源 = 底层资产，不是发行机构

  *怎么想到的*：
  - 资管产品的风险收益特征由底层资产决定
  - 银行理财 95% 是固定收益类产品，近 70% 投债券、存单、现金
  - 固定收益类资产本质是借贷，风险收益比股票低
  - 但"低风险"不等于"无风险"，债券也有波动和亏损可能

  *边界*：如果银行理财配置了可转债、高收益债等风险较高的固收产品，或者加了杠杆，那风险就会上升。投资者需要看底层持仓。

* Q4: 为什么买银行理财不如买债券基金？

  *结论*：两者底层资产相似，但公募基金信息更透明、费用更清晰、业绩可比较。

  *形式化*：银行理财 ≈ 债券基金（底层）；但银行理财 = 黑箱（不透明）；公募基金 = 玻璃箱（透明）

  *怎么想到的*：
  - 银行理财整体 3.2% 资产直接投公募基金，其中 75% 是债基
  - 也就是说，买某些银行理财等于间接买债券基金
  - 但公募基金每日净值、季报半年报、持仓、基金经理履历都公开
  - 银行理财像"黑箱"，历史表现难查，业绩无法横向比较

  *边界*：如果投资者极度厌恶波动且不在乎透明度，银行理财的简单性可能更适合。但长期来看，透明度是做出正确决策的前提。

* Q5: 银行理财也会买基金，这意味着什么？

  *结论*：银行理财间接购买公募基金，说明基金是更基础、更透明的投资工具。

  *形式化*：银行理财 → 3.2% 资产 → 公募基金（75% 债基）→ 投资者被双重收费

  *怎么想到的*：
  - 银行理财整体 3.2% 资产直接投公募基金
  - 其中 75% 是债券型基金
  - 这意味着某些银行理财的底层就是公募债基
  - 但通过银行理财买，投资者多了一层费用，还丧失了透明度

  *边界*：银行理财配置基金可能是为了弥补自身投研能力不足，或者满足特定配置需求。不是所有银行理财都这样做。

* 收口

文章的核心洞见是：不要看产品形式，要看底层资产。银行理财的"安全"来自它主要投资债券，而不是银行机构的信用背书。在资管新规后，所有资管产品都是"风险自担"，投资者应该关注底层投向，而不是发行机构的名气。
