* 引子
2026年2月是中国资本市场的"政策催化月"。政治局会议释放稳增长信号，两会推出AI、新能源等产业政策，带动A股震荡上行。中小盘指数表现领先大盘，中证1000涨3.71%，沪深300仅涨0.17%。债市在央行流动性呵护下也表现良好，中证全债指数涨0.17%。这篇文章揭示了一个关键规律：政策利好是2月市场上涨的核心驱动力。

* Q1: 为什么"中小盘风格"在2月表现最好？
  *结论*：因为政策利好主要集中在科技成长和顺周期板块，这些板块以中小盘股为主。
  *形式化*：政策利好（AI、新能源、基建）→ 科技成长+顺周期板块↑ → 中小盘股↑ → 中证1000涨3.71%
  *怎么想到的*：
  - 数据：中证1000涨3.71%，中证500涨3.46%，沪深300仅涨0.17%
  - 行业表现：综合、钢铁、建筑材料涨超8%，银行、非银金融跌超3%
  - 政策驱动：政治局会议强调"高水平科技自立自强"、"发展新质生产力"
  - 逻辑：科技成长和顺周期板块以中小盘为主，政策利好直接受益
  *边界*：如果政策转向或经济数据走弱，中小盘风格的优势会消失

* Q2: 为什么PMI连续2个月处于收缩区间（49.0%），股市还能上涨？
  *结论*：因为股市反映的是"预期"而非"当下"，政策利好让投资者相信未来经济会好转。
  *形式化*：PMI<50（收缩）+ 政策利好（稳增长信号）→ 投资者预期未来改善 → 股市↑
  *怎么想到的*：
  - PMI是"先行指标"，反映当前经济状况
  - 但股市是"预期的折现"，反映的是投资者对未来的判断
  - 政治局会议释放"稳就业、稳企业、稳市场、稳预期"信号
  - 投资者相信政策会推动经济复苏，所以提前买入
  *边界*：如果后续经济数据继续走弱（如PMI跌破48%），投资者的预期会逆转

* Q3: 为什么"1年期国债收益率上行2bp，5年和10年期下行3-4bp"？
  *结论*：因为短端受春节资金面扰动，长端受政策预期和避险情绪支撑。
  *形式化*：短端（1年期）：春节资金面紧张 → 收益率↑；长端（5/10年期）：政策预期回暖 + 地缘避险 → 收益率↓
  *怎么想到的*：
  - 春节因素：春节前资金面紧张，短端利率上行
  - 政策预期：两会释放稳增长信号，市场预期未来利率会下行
  - 地缘避险：美伊冲突升级，资金涌入长债避险
  - 结果：收益率曲线陡峭化（短端更平，长端更陡）
  *边界*：如果春节后资金面宽松超出预期，短端利率也会下行

* Q4: 为什么"钢铁板块"在2月表现强势？
  *结论*：因为《钢铁行业稳增长工作方案》推出，市场预期行业格局优化、集中度提升。
  *形式化*：政策（钢铁稳增长方案）→ 供给侧控制 + 落后产能退出 → 行业集中度↑ → 钢铁股↑
  *怎么想到的*：
  - 政策文件：《钢铁行业稳增长工作方案（2025-2026年）》
  - 核心内容：推进供给总量控制与落后产能退出
  - 市场预期：供给减少→行业集中度提升→龙头企业盈利改善
  - 结果：钢铁板块涨超8%
  *边界*：如果政策执行力度不足或需求端（如房地产）继续走弱，钢铁股会回调

* Q5: 为什么"固收+"基金在2月表现亮眼？
  *结论*：因为A股和可转债在2月表现良好，固收+基金的权益敞口分享了上涨红利。
  *形式化*：固收+ = 纯债 + 股票/可转债 → 2月A股↑ + 可转债↑0.89% → 固收+净值↑
  *怎么想到的*：
  - 数据：可转债基金涨0.33%，积极债券基金涨0.25%，普通债券基金涨0.19%
  - 纯债基金涨0.17%，说明债券部分贡献有限
  - 问题出在权益敞口：中证转债涨0.89%（受A股拖累）
  - 结论：固收+的"+"在股市上涨时是增项
  *边界*：如果股市下跌，可转债也会跟跌，固收+基金会跑输纯债基金

* Q6: 为什么"QDII全球新兴市场股债混合基金"能涨6.62%？
  *结论*：因为日股、韩股在2月大幅上涨，这类基金重仓这些市场。
  *形式化*：全球新兴市场基金 = 日股 + 韩股 + 其他新兴市场 → 日股↑10.31% + 韩股↑ → 基金↑6.62%
  *怎么想到的*：
  - 数据：日经225涨10.31%，富时100涨7.04%，法国CAC40涨5.60%
  - 日股受益于日元贬值+企业治理改革+全球资金涌入
  - 韩股受益于半导体产业链回暖+AI主题
  - 全球新兴市场基金通常重仓日韩市场
  *边界*：如果日元大幅升值或地缘冲突再起，日韩股市可能回调

* Q7: 从"银行、非银金融跌超3%"能推断出什么？
  *结论*：说明2月的市场主线是"科技成长+顺周期"，传统金融板块被资金抛弃。
  *形式化*：政策利好（科技、基建）→ 资金从传统金融流向科技成长+顺周期 → 银行、非银金融↓
  *怎么想到的*：
  - 银行和传统金融股通常是"价值风格"和"大盘风格"
  - 2月市场风格是"中小盘+成长"，银行和传统金融不符合这个风格
  - 政策利好集中在科技、基建，不在传统金融
  - 结果：资金从银行、非银金融流出，流向科技、钢铁、建材
  *边界*：如果市场风格转向"价值"或"大盘"，银行和非银金融会补涨

* 收口
晨星2月基金月报揭示了一个关键规律：政策利好是市场上涨的"第一推动力"——政治局会议释放的稳增长信号、两会推出的产业政策，直接决定了2月的市场风格（中小盘+科技成长+顺周期）。投资者要理解政策，才能理解市场在交易什么。
