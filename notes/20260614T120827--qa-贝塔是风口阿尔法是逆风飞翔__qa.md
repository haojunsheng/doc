* 引子

"创造阿尔法""赚取时代的贝塔",这些词在基金宣传中经常出现。但阿尔法和贝塔到底是什么意思?对我们挑基金有什么指导意义?本文用"飞猪理论"的比喻,帮你理解这两个希腊字母的真正含义。

* Q1: 贝塔是什么?为什么叫"躺平的贝塔"?

  *结论*:贝塔是跟随市场波动获得的收益,就像站在风口,猪不需要努力就能顺势起飞。

  *形式化*:贝塔 = 市场平均收益 = 风口(躺平就能赚)

  *怎么想到的*:
  - 上世纪60年代,威廉·夏普首次把金融资产收益拆成阿尔法和贝塔
  - 贝塔是跟随市场波动获得的部分
  - 套用雷军的飞猪理论:贝塔指的就是那个风口,只要风吹起来,猪不需要努力就能起飞
  - 前几年市场好时,很多人都觉得炒股赚钱不难,但过去两年绝大部分股票投资者都亏钱

  *边界*:贝塔不只是概念,还是可量化的系统性风险指标。比较基准的贝塔设定为1。

* Q2: 贝塔系数怎么看?

  *结论*:贝塔>1表现激进(涨跌都比基准猛),贝塔=1与基准相当,贝塔<1相对温和。

  *形式化*:贝塔>1:激进(涨跌更猛);贝塔=1:与基准相当;贝塔<1:温和(涨跌较少)

  *怎么想到的*:
  - 根据股票或基金的历史表现,计算它们与市场表现的相关性
  - 贝塔>1:涨跌与大盘一致,但涨起来和跌起来都比基准猛
  - 贝塔=1:与基准几乎同涨同跌,涨跌幅几乎相当
  - 贝塔<1:涨跌虽与基准一致,但表现相对温和

  *边界*:贝塔基于历史数据计算,不代表未来一定保持。且不同市场环境下,贝塔可能会变化。

* Q3: 阿尔法是什么?为什么叫"冒险的阿尔法"?

  *结论*:阿尔法是市场平均分以外的收益,就像风停了还能继续做飞猪,或者不摔在地上。

  *形式化*:阿尔法 = 超额收益 = 逆风飞翔(真本领)

  *怎么想到的*:
  - 阿尔法是市场平均分以外的收益
  - 用来衡量基金经理战胜市场的能力
  - 飞猪理论:当风小了或停了,还能继续做飞猪,或者不摔在地上的,就是有阿尔法能力的猪
  - 举例:科技板块平均收益30%,A基金收益80%(阿尔法50%),B基金30%(阿尔法0),C基金20%(阿尔法-10%)

  *边界*:阿尔法只是一个相对概念,有阿尔法不代表一定有正收益。且阿尔法的获取具有很大的不确定性。

* Q4: 为什么贝塔的影响比阿尔法强大得多?

  *结论*:因为贝塔是平均分,阿尔法是超额分,平均分的影响远大于超额分。

  *形式化*:贝塔(平均分) >> 阿尔法(超额分)

  *怎么想到的*:
  - 从绝对收益角度看,贝塔的影响比阿尔法强大得多
  - 就像某次考试特别难,平均分从80降到50
  - 平时考95的优等生,这次也只考了65
  - 这不是优等生的问题,而是试题(市场)的问题
  - 只要在这个市场中,谁都无法规避贝塔(系统性风险)

  *边界*:这是从平均情况来看。如果基金经理能持续创造正阿尔法,长期来看阿尔法的影响会累积。

* Q5: 为什么"贝塔易得,阿尔法难求"?

  *结论*:因为获取阿尔法需要超越大多数市场参与者的认知和能力,且具有很大不确定性。

  *形式化*:贝塔 = 被动跟随(低成本);阿尔法 = 主动超越(高成本 + 不确定性)

  *怎么想到的*:
  - 基金经理获取阿尔法主要靠选股和择时
  - 这要求他们具备超越大多数市场参与者的认知和能力
  - 阿尔法的获取具有很大不确定性
  - 阿尔法只是基于历史业绩计算的结果,无法作为预测性指标使用
  - 获取阿尔法的成本也比贝塔高(主动管理基金费率远高于指数基金)

  *边界*:这是从平均情况来看,不排除有些基金经理确实有持续创造阿尔法的能力。但这类基金经理很少。

* Q6: 怎么看基金的阿尔法和贝塔?

  *结论*:在晨星官网的"风险统计"中查看,阿尔法看超额收益,贝塔看波动性。

  *形式化*:晨星官网 → 基金主页 → 风险统计 → 阿尔法 + 贝塔

  *怎么想到的*:
  - 晨星将基金实际收益与用贝塔计算的预期收益的差额称为阿尔法系数
  - 贝塔衡量组合相较于基准的波动大小
  - 阿尔法为正说明在承担的风险下获得了超越基准的收益
  - 可以在晨星官网搜索基金,在"风险统计"中看到阿尔法和贝塔系数

  *边界*:阿尔法和贝塔只是历史数据,不能预测未来业绩。且不同基准下的阿尔法和贝塔不可直接比较。

* 收口

贝塔是市场平均分,阿尔法是超额分。理解这两个概念,有助于我们更好地分析基金的历史收益来源,但不能作为预测未来的指标。投资时,应该关注的是风险调整后的收益,而不是追求虚无缥缈的"阿尔法"。
