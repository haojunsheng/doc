# 全局地图

## 一句话摘要

摄影是用光的艺术——光有四大要素：质量（软硬）、方向、强度、颜色；硬光塑造轮廓，软光柔化皮肤；光的方向比软硬更能决定观感；闪光灯不只是"照亮"，更是"塑造光线"的工具。

# 逐段伴读记录

## P11 光的质量

### 核心概念

> **光源面积越大，光线越软；光源距离越近，光线越软。**

> **判断软硬的标准：看影子边缘——锋利=硬，模糊=软。**

**点睛**：太阳够大吧？但离我们太远，所以是硬光源。阴天云层一挡，太阳变面光源，光线立刻变软。

### 黄金半小时

> 日出后跟日落前的那俩半个小时——太阳高度角小，光线穿过厚大气层，从直射变散射，光线特别完美。

### 硬光/软光不是绝对的

硬光可以拍人（Frank Ockenfels / Bruce Gilden 都是硬光大师）。关键不在用什么光，在于你想表达什么。

---

## P12 光的方向 + 环境光

### 核心判断

> **光的方向比光的软硬更能决定一张照片的观感。**

同样硬光，从正午头顶照 vs 从黄金半小时斜射——观感完全不同。

### 观察光线的四要素

1. **强度**（有多亮）
2. **色温**（偏暖还是偏冷）
3. **质量**（软硬）
4. **方向**（从哪来）

### 阳光十六法则

```
阳光十六阴天八，多云十一日暮四，乌云压顶五点六，雪天落雨同日暮。
```

**用法**：晴天 F16，快门 = ISO 倒数。ISO 125 → 1/125s。

**用影子判断天气**：
- 晴天 F16 = 影子黑、清晰、边缘锋利
- 多云 F11 = 影子发灰、边缘柔和
- 阴天 F8 = 影子几乎不可见

## P13 人为光

### 闪光灯 ≠ 照亮

闪光灯的真正用途：
1. **制造特效**（频闪、运动轨迹）
2. **点亮前景，压暗背景**——分离主体
3. **给逆光人物补光**

### 闪光灯 vs 常亮灯

| | 闪光灯 | 常亮灯 |
|---|---|---|
| 发光方式 | 瞬间闪亮 | 持续点亮 |
| 效果 | 捕捉瞬间 | 记录轨迹 |
| 参数设置 | 根据闪光灯功率 | 根据环境光测光 |
| 优点 | 功率大、凝固动作 | 所见即所得 |

### 平方反比定律

> **距离翻倍 → 光强降为 1/4。**

**实战用途**：让模特远离白墙 + 闪光灯近距离打亮模特 → 白墙变黑墙。

### 生活光源布光

作者实拍案例：一盏小台灯（套塑料袋柔光）+ 手电筒（斜后上方打亮右脸）+ 电视白屏（正面补眼神光）= 看起来像棚拍。

## 读后一句话（不可跳过）

**读者原话**（L2 - 有判断）：

> "学习光源本质上还是在学习使用曝光三要素。一个是调整相机以更好的处理曝光三要素，另外一个是改变外界条件以更好的处理曝光三要素。"

**伴读回应**：

这个判断把前后知识串起来了——这三课表面在讲"光"，底层还是在讲曝光三角：

- **调整相机**（光圈/快门/ISO）→ 改变传感器接收到的光
- **改变外界条件**（光源方向/质量/强度）→ 改变照射到被摄体的光

两种手段，同一个目的。这也是为什么 P11-P13 放在 P3-P6 之后——先懂"相机怎么控光"，才能懂"光本身怎么控"。

## 旁逸：光与曝光三角的对应关系

**读者追问**："那具体是怎么和曝光三要素对应的呢？"

### 对应表

| 光要素 | 对应的曝光三角参数 | 关系 |
|---|---|---|
| **光的质量（软硬）** | 光圈 | 软光类似大光圈效果（柔和）；硬光类似小光圈效果（高对比） |
| **光的方向** | 测光模式 + 曝光补偿 | 逆光需要 +EV；侧光可能需要 +0.5~1 EV |
| **光的强度** | 快门 + ISO | 强光=快门快+ISO 低；弱光=快门慢+ISO 高 |
| **光的颜色** | 白平衡 | 暖光相机偏蓝中和；冷光相机偏黄中和 |
| **人为光（闪光灯）** | 全部三个 | 闪光灯功率影响有效曝光量 |

### 核心洞察

> 光是从"外部条件"的角度讲，曝光三角是从"内部设置"的角度讲。两者是同一件事的两面。

```
光的质量（软硬）     →  影响你对光圈的选择
光的方向            →  影响你对测光模式和曝光补偿的调整
光的强度            →  影响你对快门和 ISO 的组合
光的颜色            →  影响你对白平衡的设置
人为光（闪光灯）     →  同时影响全部三个参数
```

## 伴读手记

这三节课是"摄影入门课"里**最接近"创作"**的部分。前七课（光圈/焦段/ISO/测光/相机选择/好照片标准）都在打基础，这三课开始教你**怎么看见光、怎么用光**。

最重要的收获是**"看影子"**这个方法论——不用买测光表，不用背参数，只需要看影子的边缘就知道光的质量、方向、软硬。

最实用的收获是**"阳光十六法"**——户外无测光表时的快速曝光口诀。

最反直觉的收获是**"闪光灯不只是照亮"**——它能压暗背景、分离主体、塑造氛围。
