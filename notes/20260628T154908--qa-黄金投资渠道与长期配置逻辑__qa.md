* 引子
黄金从1970年35美元涨到现在3250美元，50年接近100倍。背后推手是美元脱钩、金融危机、去美元化、央行增持、保险资金入场。但黄金不产生现金流、涨跌周期常以十年计——它适合做长期组合的"压舱石"，不适合当短线交易的工具。

* Q1: 黄金50年涨了100倍的底层推力是什么？
  *结论*: 美元与黄金脱钩+全球宽松+去美元化+央行持续增持，四轮驱动。
  *形式化*: 1971脱钩 → 10年↑ → 2008危机+宽松 → ↑ → 去美元化+央行买 → ↑
  *怎么想到的*:
  - 1971年美元与黄金脱钩后，金价迎来十年上涨周期
  - 2008年金融危机后美联储宽松+美国负债率攀升+去美元化
  - 全球央行增持黄金对冲国际风险
  - 中国央行连续四年增持（2022-2025年合计444吨）
  - 2025年保险资金也被允许投资黄金
  *边界*: 若美元信用重新走强（如美国财政纪律恢复），黄金的核心推力会减弱。

* Q2: 中国央行为什么连续四年增持黄金？
  *结论*: 对冲国际风险+推动人民币国际化，充足黄金储备增强货币信用。
  *形式化*: 国际风险↑ + 人民币国际化需求 → 央行增持黄金 → 货币信用↑
  *怎么想到的*:
  - 2022-2025四年分别增持62.21/224.88/44.17/12.75吨
  - 充足黄金储备可增强本国货币国际信用
  - 推动人民币国际化的背景
  - 对冲地缘政治复杂变化带来的不确定性
  *边界*: 若人民币国际化进展超预期（如成为主要储备货币），黄金需求增速可能放缓。

* Q3: 黄金ETF为什么在2024年后交易量大增？
  *结论*: 金价突破2020-2023横盘区间后，二级市场参与热情爆发。
  *形式化*: 2020-2023横盘 → 2024突破 → 2025前5月日均成交 > 2020全年
  *怎么想到的*:
  - 黄金价格在2024年向上突破2020-2023年构筑的横盘区间
  - 二级市场黄金ETF交易量显著攀升
  - 2025年仅前五个月日均成交额就大幅超过2020年全年
  - 投资者通过二级市场账户便捷参与黄金投资
  *边界*: 若金价重新回到横盘区间且无突破迹象，交易量可能回落。

* Q4: 实物黄金和纸黄金各自的优缺点是什么？
  *结论*: 实物在手有安全感但储存麻烦，纸黄金便捷但只是电子凭证。
  *形式化*: 实物: 安全感↑ + 观赏价值 + 储存成本↑ ‖ 纸黄金: 便捷↑ + 无储存风险 - 只是凭证
  *怎么想到的*:
  - 实物黄金：银行金条/金币，心理安全感强，可观赏佩戴，但储存成本高、买卖手续繁琐、有安全风险
  - 纸黄金：手机银行购买，电子凭证免去保存实物风险，但无实物在手
  *边界*: 若出现极端金融风险（如银行体系危机），纸黄金作为银行负债可能面临兑付风险。

* Q5: 黄金TD、期货、黄金股为什么不适合长期投资？
  *结论*: 三者都带杠杆或受企业因素影响，投资难度和风险远高于实物/ETF。
  *形式化*: TD/期货/期权: 自带杠杆 → 可能爆仓/期权归零 ‖ 黄金股: 金价+经营+市场波动 → 复杂
  *怎么想到的*:
  - 黄金TD（延期交收）、期货、期权自带杠杆
  - 不适合长期投资，更多是短期交易工具
  - 可能因爆仓或期权过期损失100%本金
  - 黄金公司股票还受企业自身经营情况和市场波动影响
  - 与实物黄金、纸黄金、黄金ETF比起来，投资难度和风险高了不少
  *边界*: 若投资者具备专业风控能力且短期交易纪律严格，TD/期货可作为辅助工具。

* Q6: 黄金为什么适合作为长期资产配置？
  *结论*: 与股票/债券相关性极低+抗通胀能力不俗，能降低组合整体波动。
  *形式化*: ρ(黄金, 股/债) ≈ 0 + 抗通胀能力 → 组合波动↓ + 长期保值
  *怎么想到的*:
  - 黄金与股票、债券等其他资产极低的业绩相关性
  - 不俗的长期抗通胀能力
  - 历史上上涨和下跌周期历时较长（1980-2001下跌20年）
  - 适合构建长期投资组合、降低波动性
  *边界*: 黄金不产生现金流，依赖现金流的投资者需在组合中搭配生息资产。

* Q7: 黄金的涨跌周期给投资者什么警示？
  *结论*: 一个涨跌周期可能长达20年——买在高点需要极长耐心才能回本。
  *形式化*: 1980高点(700美元) → 2001触底(25年) → 2007才超越前高(27年)
  *怎么想到的*:
  - 1980年达到700美元顶峰后进入下跌周期
  - 直到2001年才触底回升
  - 2007年才超越1980年高点
  - 一个周期长达20-27年
  - 这就是黄金适合作为长期资产配置的原因
  *边界*: 若未来全球货币体系发生重大变革（如数字货币主导），黄金的历史周期规律可能被打破。

* 收口
黄金50年涨100倍不是"黄金永远涨"的证明，而是"货币信用永远在缓慢侵蚀"的镜像。配置黄金的理由不是赌它涨，而是让你的组合在极端情景下有一条退路。
