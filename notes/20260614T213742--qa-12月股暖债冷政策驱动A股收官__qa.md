* 引子
12月的A股以11天连阳收官，上证指数涨2.34%，深证成指涨4.22%，但债市却在"利好政策"与"股债跷跷板"的夹击下震荡走弱。PMI时隔8个月重回扩张区间，政策面暖风频吹，但债市对宏观数据反应钝化。权益基金多数录涨，固收基金内部出现明显分化。

* Q1: PMI重回扩张区间，为什么债市反而跌了？
  *结论*：PMI回升是经济企稳信号，市场预期"稳增长加码"的必要性下降，债市的"避险溢价"被压缩。
  *形式化*：PMI 49.2% → 50.1%（扩张） = 经济企稳信号↑ → 稳增长政策预期↓ → 债市避险需求↓ → 债市承压
  *怎么想到的*：
  - PMI回升：制造业PMI时隔8个月重回扩张区间，生产、新订单、原材料库存等分项均上升
  - 市场逻辑：经济越稳，市场越不需要"降息降准"等宽松政策，债市的"政策预期溢价"消失
  - 数据验证：12月中证全债指数下跌0.07%，债市对PMI回升反应负面
  *边界*：若PMI回升是短期扰动、后续再次回落，债市可能重新走强；若通胀超预期上行，债市跌幅会更大

* Q2: 政治局会议和中央经济工作会议的"利好"为什么没能撑起债市？
  *结论*：政策面"稳中求进"的定调已被市场充分定价，真正的利好需要"超预期"，而这次只是"符合预期"。
  *形式化*：政策定调"稳中求进" = 市场已预期 → 无超预期增量 → 债市反应钝化
  *怎么想到的*：
  - 政策内容：政治局会议和中央经济工作会议延续"稳中求进"，强调稳市场、强创新
  - 市场预期：市场早已预期到"适度宽松货币政策"和"更加积极有为财政政策"
  - 实际效果：债市在政策落地后短暂修复，但未能持续，说明利好已被提前消化
  *边界*：若政策力度超预期（如大幅降准降息），债市可能重新走强；若政策执行不及预期，债市会进一步下跌

* Q3: 为什么信用债表现优于利率债？
  *结论*：信用债的票息优势在震荡市中更受青睐，而利率债对政策预期更敏感，利好兑现后反而下跌。
  *形式化*：信用债 = 票息高 + 对政策敏感度低 → 表现好 vs 利率债 = 票息低 + 对政策敏感度高 → 表现差
  *怎么想到的*：
  - 数据对比：中证国债及政金债指数-0.25%，中证企业债/中票/短融指数均录得正收益
  - 逻辑解释：利率债的定价主要受政策预期驱动，利好兑现就是"卖出信号"；信用债的票息在震荡市中提供缓冲
  - 市场环境：PMI回升利好信用风险预期，信用利差收窄，信用债受益
  *边界*：若经济超预期复苏，信用利差可能走阔，信用债表现会差于利率债；若政策超预期宽松，利率债会重新领涨

* Q4: 权益基金中成长风格优于价值风格，背后的逻辑是什么？
  *结论*：成长风格受益于"科技创新"政策主线和AI算力需求，价值风格的传统行业（如金融、地产）缺乏催化剂。
  *形式化*：成长风格 × 政策主线（科技创新）+ AI算力需求 → 表现好 vs 价值风格 × 传统行业（金融地产）缺乏催化剂 → 表现差
  *怎么想到的*：
  - 政策催化：政治局会议和中央经济工作会议明确"稳市场、强创新"，科技自立自强是核心
  - 行业表现：国防军工、有色金属、通信板块涨幅超10%，AI算力需求推动通信板块大涨
  - 风格映射：成长风格重仓科技、通信，价值风格重仓金融、地产，前者受益后者承压
  *边界*：若政策重心从"科技创新"转向"消费复苏"，价值风格可能重新占优；若AI算力需求见顶，成长风格会失去核心驱动

* Q5: 为什么QDII基金中"全球新兴市场"和"商品"表现好，而"大中华区"和"环球债券"表现差？
  *结论*：全球新兴市场受益于日股和贵金属上涨，大中华区受制于港股拖累，环球债券受海外利率上行压制。
  *形式化*：全球新兴市场 = 日股↑ + 金银铜↑ → 表现好 vs 大中华区 = 港股↓ → 表现差 vs 环球债券 = 海外利率↑ → 表现差
  *怎么想到的*：
  - 全球新兴市场：日股上涨（日经225涨0.84%）+ 金银铜等贵金属上涨，推动该类别录得1.53%涨幅
  - 大中华区：恒生指数下跌0.61%，拖累亚洲股债混合基金和大中华区股票基金录得2%以上跌幅
  - 环球债券：美联储降息25bp但点阵图隐含进一步降息空间，海外利率上行压制债市，77只环球债券基金仅1只正收益
  *边界*：若港股企稳反弹，大中华区基金可能重新走强；若美联储暂停降息，环球债券会进一步承压

* Q6: 可转债基金在固收类中表现最好（2.84%），为什么？
  *结论*：可转债兼具股债双重属性，在A股回暖时能分享权益上涨收益，在债市下跌时又有债底保护。
  *形式化*：可转债 = 债券属性（债底保护）+ 股票属性（转股价值随A股↑） → 股暖债冷时表现最佳
  *怎么想到的*：
  - 市场环境：A股回暖（上证涨2.34%）推动转股价值上升，债市下跌但可转债有债底保护
  - 数据验证：中证转债指数12月录得2.13%涨幅，是所有细分券种中表现最好的
  - 策略优势：可转债基金在"股暖债冷"环境中能同时受益于权益上涨和债券票息
  *边界*：若A股大幅下跌，可转债的转股价值会缩水，跌幅可能超过纯债；若债市大跌，可转债的债底保护也会减弱

* Q7: 为什么医药基金12月跌得最惨（行业股票-5.97%，行业混合-7.06%）？
  *结论*：医药板块缺乏政策催化剂，且前期估值偏高，在市场风格从"防御"转向"成长"时被资金抛弃。
  *形式化*：医药 = 缺乏政策催化 + 前期估值偏高 + 市场风格从防御→成长 → 资金流出 → 跌幅最大
  *怎么想到的*：
  - 政策环境：12月政策主线是"科技创新"和"商业航天"，医药不在核心催化范围内
  - 市场风格：成长风格占优，医药作为传统防御板块被资金减持
  - 估值压力：前期医药板块估值偏高，缺乏新催化剂时容易遭遇"杀估值"
  *边界*：若政策重心转向"民生保障"或"医疗基建"，医药可能重新走强；若市场风格从成长回归防御，医药会重新受青睐

* 收口
作者通过12月的基金月报揭示了一个核心规律：政策面暖风频吹时，权益市场会率先反应（尤其是成长风格），而债市在"利好兑现"和"股债跷跷板"的双重压力下反而承压——投资者需要根据政策主线和行业轮动来动态配置，而非简单"买涨卖跌"。
