# 摄影基础四课：深度总结

## 一、四参数的本质

| 参数 | 控制什么 | 副作用 | 比喻 |
|---|---|---|---|
| **光圈** | 单位时间进光量（孔的大小） | 景深（清晰范围） | 水龙头开多大 |
| **快门** | 光照时间长短 | 运动模糊/凝固 | 水龙头开多久 |
| **ISO** | 传感器对光的敏感度 | 噪点 | 信号放大器增益 |
| **焦段** | 取景范围（视角） | 透视关系、空间压缩 | 你站到哪里 |

## 二、曝光三角：一个乘法公式

```
总曝光量 ∝ (1 / F²) × 快门时间 × ISO
```

三个参数可以在**总曝光量不变**的前提下互相补偿——这就是"互易律"。

**补偿的本质**：你牺牲一个参数的"副作用"，换取另一个参数的自由。

| 操作 | 获得 | 代价 |
|---|---|---|
| 开大光圈换更快快门 | 运动凝固 | 景深变浅（背景糊） |
| 放慢快门换更小光圈 | 全景深 | 运动模糊、手震风险 |
| 提高 ISO 换更快快门/更小光圈 | 曝光充足 | 噪点增多 |

## 三、焦段的特殊地位

**焦段不在曝光三角内。** F 值已经把焦段"约掉"了——F8 在 28mm 和 200mm 上的曝光量一样。

但焦段**间接决定透视**：
- 广角 → 必须走近 → 近摄 → 距离比大 → 透视夸张
- 长焦 → 必须走远 → 远摄 → 距离比小 → 透视压缩

> **焦段不改变透视；焦段决定的拍摄距离才改变透视。**

## 四、曝光补偿 vs ISO

| | 曝光补偿 | ISO |
|---|---|---|
| 是什么 | 指令（"我要亮一档"） | 物理参数（传感器灵敏度） |
| 副作用 | 无直接（由实现方式决定） | 直接带来噪点 |
| 实现 | 相机自动选（改快门/光圈/ISO） | 你直接改 |
| 使用场景 | "相机测的不对我想要更亮" | "光圈快门都锁死了必须提亮" |

**本质**：曝光补偿是"甩锅给相机"，ISO 是"你亲自下场"。

## 五、机器视觉 vs 人眼视觉

这是四课的**哲学核心**：

| | 人眼 | 相机 |
|---|---|---|
| 时间感知 | 连续、实时 | 可凝固（高速快门）或累积（慢门） |
| 清晰范围 | 固定（眼球对焦） | 可选择（光圈控制景深） |
| 感光能力 | 有限、不能积累 | 可积累（ISO + 长时间曝光） |
| 色彩感知 | 大脑自动白平衡 | 需要手动/算法校正 |

> **摄影不是复制现实，而是用机器的方式重新编码现实。**

曝光三角是**实现这种超越的工具**——它让我们看到人眼看不到的东西：高速子弹、星轨、黑暗中积累的光。

杉本博司《剧院》：2-3 小时曝光把整部电影压缩成一块纯白人眼永远看不见的画面——这是机器视觉的极致表达。

## 六、"正确"的终极标准

经过讨论，我们得出的结论：

> **"正确曝光"是数学概念（18%灰），"正确摄影"是美学概念（让特定的人在特定情境下得到他想要的感受）。**

四个参数没有"正确值"，只有**适合特定目的的值**。Anderson 用 500mm 街头快拍、Gilden 用 28mm 怼脸特写——都是"错误"焦段的正确用法。

**"让观者舒服"** 的完整表述：

> 让特定的人在特定的情境下得到他想要的感受——这要求摄影师先搞清楚"我在给谁看、在什么情境下看"。
