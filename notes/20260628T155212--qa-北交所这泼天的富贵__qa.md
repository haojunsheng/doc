* 引子
北证50指数11月突然暴涨26%，但成分股平均流通市值仅11亿，流动性差、质地不如主板。首批8只北交所主题基金成立两年亏损10%-40%。作者提醒：别光看吃肉，也要看挨打。

* Q1: 北证50为何突然爆发？
  *结论*: 市场风格从大盘切到小盘，北交所作为最纯粹的"小盘指数"被资金选中。
  *形式化*: 弃大炒小 → 北证50(平均11亿) = 最纯小盘指数 → 资金涌入
  *怎么想到的*:
  - 权重股平均流通市值仅11.07亿，中证1000为62.7亿
  - 近期中小票表现极为强势
  - 做市商门槛降低、扩容消息催化
  - 但核心驱动力是风格轮动
  *边界*: 若市场风格从大盘切回大盘，北证50会迅速回落。

* Q2: 北证50估值便宜吗？
  *结论*: 不便宜了——已经进入到炒作阶段，"价值回归"叙事站不住脚。
  *形式化*: 年初: 无人问津 → 当前: 暴涨26% → 估值已不便宜 → 炒作阶段
  *怎么想到的*:
  - 作者明确说"从估值角度已经不便宜了"
  - 之前一路下滑到年中无人问津
  - 现在演绎到炒作阶段
  - 最甜蜜也最危险的阶段
  *边界*: 若北交所公司业绩超预期增长，高估值可能被消化。

* Q3: 北交所公司质地到底差在哪？
  *结论*: 很多是上不主板和科创板的"退而求其次"，天然质量低于主板公司。
  *形式化*: 北交所 = 不满足主板/科创板条件的公司 → 质地↓ → 风险↑
  *怎么想到的*:
  - 北交所定位"服务型中小企业"
  - 很多公司不满足主板或科创板上市条件才去北交所
  - 长期投资者需慎选
  *边界*: 若北交所改革深化、引入优质公司，整体质地会改善。

* Q4: 流动性差在北交所意味着什么？
  *结论*: 上市即巅峰、日成交不足百万，进去了可能出不来。
  *形式化*: 流动性差 → 买卖价差大 → 进去了出不来 → 上市即巅峰
  *怎么想到的*:
  - 对个人投资者设门槛，散户不多
  - 机构嫌弃质地不好参与不多
  - 很多股票日成交不足百万
  - 11月前宛如一潭死水
  *边界*: 若引入更多机构投资者、降低门槛，流动性可能改善。

* Q5: 北交所主题基金为何亏损？
  *结论*: 成立时恰逢市场高点+北交所下跌两年，封闭基金让投资者无法止损。
  *形式化*: 2021年11月成立 → 恰逢高点 → 两年封闭(无法赎回) → 亏10%-40%
  *怎么想到的*:
  - 首批8只基金2021年11月23日成立
  - 两年封闭期明天才打开申赎
  - 成立至今大部分亏10%-40%
  - 封闭基金锁住了投资者
  *边界*: 若市场继续上涨，封闭基金打开时可能已回本——但投资者体验极差。

* Q6: 北交所没有ETF是好事还是坏事？
  *结论*: 是好事——没有场内ETF阻止了追高散户的冲动买入，减少日内巨亏。
  *形式化*: 无ETF → 无法日内追高 → 避免"11%追入当日亏7%"的惨剧
  *怎么想到的*:
  - 目前只有场外指数基金，无场内ETF
  - 昨天盘中涨超11%后回落，收盘仅涨4.5%
  - 若有ETF，追高者当日可能亏7%
  - 作者认为这"拯救了一批头铁血热的投资者"
  *边界*: 若北交所推出ETF产品，散户入场便利性大增，波动也会加剧。

* 收口
北交所的"富贵"不是这些公司值钱了，而是市场风格暂时轮动到了小盘——没有流动性和基本面支撑的暴涨，终究是脆弱的。
