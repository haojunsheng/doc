* 引子
一份公募基金改革方案初稿流出，最重磅的条款是：基金经理业绩低于基准10%或负收益，薪酬下降50%。晨星中国用2024年底数据跑了一下——如果这个方案今天执行，三年期考核有56%的基金经理要降薪。

* Q1: 多少基金会触发降薪？
  *结论*: 按三年期考核，56%的基金低于基准10%或负收益，涉及6.27万亿规模。
  *形式化*: 三年期考核 → 56%基金(4715只)触发降薪线 → 规模占比21.9%
  *怎么想到的*:
  - 一年期：21%触发（2348只）
  - 三年期：56%触发（4715只）——因为近三年市场差
  - 五年期：12%触发（621只）
  - 三年期最惨，规模6.27万亿占全部21.9%
  *边界*: 如果市场转牛，触发比例会大幅下降。

* Q2: 为什么三年期比一年期惨那么多？
  *结论*: 近三年市场持续下行，基金经理再优秀也难在熊市中跑赢基准10%。
  *形式化*: 一年(21%) → 三年(56%) → 五年(12%) → 三年是最近三年熊市的"重灾区"
  *怎么想到的*:
  - 2022-2024年市场连续下跌
  - 三年期考核刚好覆盖了这轮完整下跌
  - 五年期包含了2020-2021年的牛市，拉低了比例
  - 一年期只反映最近一年，部分基金已反弹
  *边界*: 如果2025年市场持续向好，三年期触发比例会快速下降。

* Q3: 债券基金和指数基金会不会被误伤？
  *结论*: 债券基金极少触发(1%)，指数基金完全不会触发——方案可能按类型差异化考核。
  *形式化*: 债券基金触发率(1%) << 股票基金触发率 → 被动指数基金触发率≈0%
  *怎么想到的*:
  - 债券基金三年期仅1%低于基准10%
  - 被动指数基金三年和五年都没有触发
  - 方案初稿提到"结合产品与业绩比较基准情况"
  - 暗示不同类型基金考核标准可能不同
  *边界*: 如果方案一刀切不区分类型，少数债券基金经理仍会被误伤。

* Q4: 基金经理能设"低标准"基准来规避吗？
  *结论*: 方案留了两道防线——偏离度指标纳入考核+后续出台基准指引，堵住了"低标准"的后门。
  *形式化*: 防规避 = 偏离度指标(考核体系) + 基准指引(规范制定) → 低标准基准难以成立
  *怎么想到的*:
  - 方案明确"业绩与基准偏离度指标纳入考核"
  - 后续将出台《公募基金业绩比较基准指引》
  - 费率改革部分也强调强化基准约束作用
  - 说明监管已经预判了这个漏洞
  *边界*: 如果基准指引不够具体，基金公司仍有"灵活操作"空间。

* Q5: 降薪50%对行业意味着什么？
  *结论*: 打破"旱涝保收"，从规模导向转向业绩导向——公募基金行业的根本性变革。
  *形式化*: 旧模式(规模↑+业绩差→薪酬不变) → 新模式(业绩<基准→薪酬↓50%)
  *怎么想到的*:
  - 长期以来公募基金"重规模轻回报"
  - 基金经理薪酬主要跟规模挂钩
  - 这次直接把薪酬和业绩绑定
  - 延期支付+追索机制进一步强化
  *边界*: 如果降薪导致大量优秀基金经理流失到私募，可能适得其反。

* Q6: 投资者能从中得到什么？
  *结论*: 长期看基金经理会更重视风险控制和长期业绩，但短期可能引发基金经理"保守化"。
  *形式化*: 降薪压力 → 基金经理行为变化 → {正面: 更重视风控; 负面: 不敢偏离基准→指数化}
  *怎么想到的*:
  - 正面：不再追求短期排名，更关注长期回报
  - 负面：可能趋向"抄指数"——不跑赢也不跑输
  - 极端情况：基金经理回避高风险高回报机会
  - 最终效果取决于考核细节和执行力度
  *边界*: 如果降薪只针对"跑输10%以上"而非"任何跑输"，基金经理仍有动力争取超额收益。

* 收口
黄威的核心发现是：如果方案按目前版本落地，超过一半的公募基金经理将面临降薪——这不是小修小补，而是行业运行逻辑的根本性转向。
