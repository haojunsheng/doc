* 引子
2026年中国楼市出现了一个关键分化信号：新房供给在主动收缩，二手房供给却在持续增加。结果是新房价格有望2027年率先企稳，而二手房价格2028年前都难以实质性回升。同一个市场，两种资产，走势背离的根源在于供给端的可控性差异。

* Q1: 新房凭什么能先企稳？
  *结论*: 新房供给侧经历了主动收缩——新开工降22%、土地购置降49%、库存增速从7%降至接近零。
  *形式化*: 供给收缩(新开工↓22% + 拿地↓49%) + 去库存提速(待售面积增速7%→1%) → 供需再平衡 → 价格企稳
  *怎么想到的*:
  - 开发商拿地更谨慎，新增土地购置面积同比降49%
  - 政府收购闲置住房专项债翻倍，加速去库存
  - 2026年全国住宅库存预计净下降2%
  *边界*: 若购房意愿继续低迷（仅10%预期涨价、16%计划购房），仅靠需求端企稳可能不够。

* Q2: 二手房为什么难以实质性回升？
  *结论*: 二手房供给来自业主个体决策，政策无法统一调控，供给过剩需数年消化。
  *形式化*: 二手房供给(业主个体决策) ≠ 新房供给(开发商/政府可控) → 政策失灵 → 过剩数年
  *怎么想到的*:
  - 新房可通过减少开工、收缩土地出让主动调节
  - 二手房挂牌量取决于业主个体，政策工具很难直接控制
  - 更多业主挂牌出售 → 供给持续增加 → 价格承压
  *边界*: 若改善型需求大幅回暖、或业主因预期好转而集体惜售，去化速度可能加快。

* Q3: 新房和二手房价格走势为何背离？
  *结论*: 新房供给可控且正在收缩，二手房供给不可控且在增加，两者供需方向完全相反。
  *形式化*: 新房：供给↓ + 库存↓ → 价格↑；二手房：供给↑ + 库存↑ → 价格↓
  *怎么想到的*:
  - 新房：开发商和政府合力收缩供给
  - 二手房：业主持续挂牌增加供给，核心地段新房也在抢占二手房竞争力
  - 一线城市二手房跌幅甚至大于二三线，说明核心城市新房替代效应更强
  *边界*: 若开发商在核心地段拿地减少、或政策大量收购二手房转为保障房，二手房供给压力会缓解。

* Q4: 购房负担能力真的改善了吗？
  *结论*: 房价收入比从9.3降至8.5，但这是房价下跌带来的被动改善，不是收入增长。
  *形式化*: 房价收入比↓(9.3→8.5) = 房价↓ ÷ 收入持平 → 被动改善，非真实购买力↑
  *怎么想到的*:
  - 购房负担改善主要因为房价跌了，不是收入涨了
  - 央行还有10-20bp降息空间，融资成本可进一步降
  - 租金回报率从2.10%升至2.26%，但仍低于无风险利率
  *边界*: 若经济下行导致收入减少、或失业率上升，负担能力的"改善"可能被抵消。

* Q5: 城市间楼市分化遵循什么规律？
  *结论*: 需求强的高线城市（上海、杭州）率先出清，北方多数城市库存压力仍重。
  *形式化*: 高线城市(需求强) → 去化快 → 先企稳；北方城市(需求弱) → 去化慢 → 慢企稳
  *怎么想到的*:
  - 上海、杭州存量房源去化效率明显更高
  - 北京等北方城市库存压力较重
  - 政策端上海放宽社保年限、深圳放松限购，高能级城市政策空间更大
  *边界*: 若北方城市产业和人口持续流出，分化可能进一步加剧而非收敛。

* Q6: 开发商股价4月以来重估的逻辑是什么？
  *结论*: 市场定价的是"新房供给收缩→价格企稳→开发商利润率修复"的预期。
  *形式化*: 政策推动销售回暖 + 供给收缩确定性高 → 市场预期新房价格先稳 → 开发商利润修复 → 股价重估
  *怎么想到的*:
  - 新房供给收缩是确定性最高的数据点（新开工-22%、拿地-49%）
  - 去库存政策（专项债翻倍）提供了短期催化
  - 市场提前交易2027年价格企稳的预期
  *边界*: 若2027年新房价格未能企稳、或开发商债务危机蔓延，这波重估可能被证伪。

* 收口
晨星的核心贡献是点破了一个被忽视的结构性差异：新房和二手房不是同一种资产——新房供给是可控变量，二手房供给是分散决策，两者的价格走势可以长期背离。
