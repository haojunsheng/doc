# 全局地图

## 一句话摘要

赛道基金（主题投资）在牛市中是"最锋利的矛"，但在熊市中是"亏钱的毒药"。想要在主题基金上真正赚到钱，需要三个前提：长期跑赢的主题 + 能抓住风口的基金 + 在市场低估时上车。对大多数普通投资者来说，*行业主题基金更适合作为"卫星持仓"而非"核心配置"*。

## 结构地图

- 开篇："老登资产"与"小登资产"之争
  - 01 赛道的"诱惑"与"陷阱"
    - 主题投资的逻辑：选定主题 → 筛选企业 → 构建组合
    - 行业涨时涨得快，跌时跌得狠
    - 投资者实际收益远低于基金总回报
  - 02 主题投资成功的前提
    - 前提一：长期跑赢市场的主题
    - 前提二：能抓住风口的基金
    - 前提三：在市场低估时上车
  - 03 行业主题基金在组合中的角色
    - 行业基金与大盘相关性高（0.6 以上）
    - 更适合作为"卫星持仓"而非"核心配置"

# 全文复盘

## 理解轨迹

现象引入 → 赛道基金的诱惑与陷阱 → 三个前提条件 → 行业基金的定位。整篇文章的论证路径是*先展示诱惑，再揭示风险，最后给出定位*。

## 读后一句话

*L2 判断*：这篇文章的真正价值不在于否定赛道投资，而在于揭示了一个残酷的真相——*赛道基金的"高收益"是一种"幸存者偏差"的幻象*。你看到的成功案例是少数在高点卖出的人，而大多数在高点买入的人还在套牢中。对普通投资者来说，与其追逐赛道，不如做好资产配置。

## 终局问题

如果你现在持有某只赛道基金，你能回答这三个问题吗：1）这个主题能长期跑赢市场吗？2）这只基金能抓住风口吗？3）你是在市场低估时买入的吗？

## 术语表

- **主题投资 (Thematic Investing)**：选定特定投资主题，筛选相关企业构建投资组合
- **投资者回报**：投资者实际拿到的收益，考虑了资金流入流出的时机
- **基金总回报**：基金本身的净值回报率，不考虑投资者的买卖时机
- **卫星持仓**：组合中占比小、用于增强收益的部分
- **核心配置**：组合中占比大、用于构建基础收益的部分
