## 二、曝光三角：所有参数的统一框架

### 核心公式

```
总曝光量 ∝ (1 / F²) × 快门时间 × ISO
```

### 三参数本质

| 参数 | 控制什么 | 副作用 | 维度 |
|---|---|---|---|
| **光圈** | 单位时间进光量 | 景深（清晰范围） | 空间 |
| **快门** | 光照时间长短 | 运动模糊/凝固 | 时间 |
| **ISO** | 传感器灵敏度 | 噪点 | 信号 |

### 互易律

三参数可以在**总曝光量不变**的前提下互相补偿——你牺牲一个参数的"副作用"，换取另一个参数的自由。

### 曝光补偿 vs ISO

| | 曝光补偿 | ISO |
|---|---|---|
| 是什么 | 指令（"我要亮一档"） | 物理参数（传感器灵敏度） |
| 副作用 | 无直接（由实现方式决定） | 直接带来噪点 |
| 大多数情况 | 用它 | 光圈快门都被锁死时用它 |

## 三、焦段的特殊地位

### 核心结论

**焦段不在曝光三角内。** F 值已经把焦段"约掉"了——F8 在 28mm 和 200mm 上的曝光量一样。

### 焦段与透视

**焦段不直接影响透视；焦段决定的拍摄距离才改变透视。**

```
广角 → 必须走近 → 近摄 → 距离比大 → 透视夸张
长焦 → 必须走远 → 远摄 → 距离比小 → 透视压缩
```

### 焦段选择逻辑

| 题材 | 推荐焦段 | 原因 |
|---|---|---|
| 肖像 | 85mm/105mm | 距离合适（2-3m），适合聊天 |
| 风光 | 中长焦为主 | 视角窄→取舍→与众不同 |
| 街拍 | 28mm/35mm | 抵近→视觉冲击力 |
| 静物 | 50mm/微距 | 视角自然，方便布光 |

## 四、测光：相机怎么思考

### 18% 中性灰

相机测光系统把任何东西都当成 18% 灰色来测——拍白雪变灰雪，拍黑猫变灰猫。

**曝光补偿** = 你对相机测光的纠正。

| 场景 | 操作 |
|---|---|
| 雪景/白墙 | +1~2 EV |
| 黑猫/黑背景 | -1~2 EV |
| 逆光人脸 | +1~2 EV |
| 日出日落 | -0.5~1 EV |

### 光比

光比 = 暗面与亮面的受光比例。光比越大，明暗反差越大。

## 五、光：摄影的核心语言

### 光的四大要素

| 要素 | 核心要点 |
|---|---|
| **质量（软硬）** | 看影子边缘：锋利=硬，模糊=软 |
| **方向** | 比软硬更能决定观感 |
| **强度** | 决定曝光预算 |
| **颜色** | 用白平衡控制 |

### 光的质量

- 光源面积越大 → 光越软
- 光源距离越近 → 光越软
- **黄金半小时**：日出后/日落前，光线完美

### 光的方向

- 顺光：测光准确
- 侧光：可能需要 +0.5~1 EV
- 逆光：需要 +1~2 EV 或点测光

### 人为光

| | 闪光灯 | 常亮灯 |
|---|---|---|
| 发光方式 | 瞬间闪亮 | 持续点亮 |
| 优点 | 功率大、凝固动作 | 所见即所得 |
| 用途 | 压暗背景、分离主体、逆光补光 | 视频、预览效果 |

### 平方反比定律

> 距离翻倍 → 光强降为 1/4。

**实战**：让模特远离白墙 + 闪光灯近距离打亮 → 白墙变黑墙。

### 光与曝光三角的对应

| 光要素 | 对应的曝光三角参数 |
|---|---|
| 光的质量 | 光圈 |
| 光的方向 | 测光模式 + 曝光补偿 |
| 光的强度 | 快门 + ISO |
| 光的颜色 | 白平衡 |

## 六、好照片的标准

### 核心判断

> **好照片 = 视觉上好看 + 拍摄难度高**

### 可复现概率

> **复现成本越高，照片越好。**

复现成本包括：设备成本、时间成本、关系成本、知识成本、机会成本。

### 分析照片六步法

1. 曝光参数
2. 镜头焦段
3. 拍摄距离和快门时机（最重要）
4. 构图（前景/中景/背景）
5. 后期
6. 创作背景

## 七、四大题材实战总结

### 静物：摆 > 拍

> **静物其实是你自己——你观察世界的角度。**

- 食物两种角度：正上方（广角、大而全）vs 斜上 45°（中长焦、小而准）
- 共性：软光 + 白平衡准确 + 画面简洁
- 人为干预 > 静物本身

### 人物：聊 > 拍

> **会聊天比会拍照片更重要。**

- 技术只是及格线，交流才是决定因素
- 85mm/105mm 离 2-3m = 社交区距离，适合聊天
- 捕捉眼神和瞬息万变的神态
- 获得许可 ≠ 获得信任

### 风光：减法 > 加法

> **不是你想让别人看见什么，你不想让别人看见什么。**

- 广角不是万能的——大部分场景有边
- 中长焦更好：视角窄→取舍→与众不同
- 机位选择 > 拍摄参数
- 简洁是核心

### 街拍：近 > 远

> **抵近拍摄是必须要克服的心理障碍。**

- 28mm/35mm + 离主体约 1m = 街拍最佳组合
- 长焦偷拍 = 心理素质不行
- 三类街拍：错位巧合 / 光影几何 / 直给型
- 构图没法讲：大量阅片→直觉

## 八、机器视觉 vs 人眼视觉

| | 人眼 | 相机 |
|---|---|---|
| 时间感知 | 连续、实时 | 可凝固（高速快门）或累积（慢门） |
| 清晰范围 | 固定（眼球对焦） | 可选择（光圈控制景深） |
| 感光能力 | 有限、不能积累 | 可积累（ISO + 长时间曝光） |
| 色彩感知 | 大脑自动白平衡 | 需要手动/算法校正 |

> **摄影不是复制现实，而是用机器的方式重新编码现实。**

---

## 九、选购相机的逻辑

### 八要素排序

1. 预算
2. 画幅（全幅画质好，非全幅轻便）
3. **体积重量**（决定你是否愿意带出门）
4. 像素（够用即可，警惕高像素陷阱）
5. 动态范围（极端光比才重要）
6. 高感成像（暗光拍摄重要）
7. RAW 质量 + 存储速度
8. "高科技"功能（最不重要）

### 核心结论

> **最好的相机 = 最顺手的相机 = 最能满足你需求的相机。**

## 十二、下一步行动建议

### 日常练习

1. **每次按快门前问自己**："现在光从哪来？是硬是软？我该怎么利用它？"
2. **街拍时离主体 1m 以内**拍一张——感受"近了就是不一样"
3. **拍食物时用两种角度**对比（正上方 vs 斜上 45°）
4. **逆光场景 +1~2 EV**——让主体亮起来

### 长期积累

1. **大量阅片**：至少熟悉 50 位著名摄影师的作品和生平
2. **持续拍摄**：第一年拍 2-3 万张
3. **观察光线**：养成日常观察影子和光方向的习惯
4. **分析照片**：用六步法拆解好照片
