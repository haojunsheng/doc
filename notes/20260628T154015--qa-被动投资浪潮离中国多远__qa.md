* 引子
2024年1月美国被动基金规模首次超越主动基金，25%主动基金十年期跑赢指数。中国被动基金规模也在逐年提升，但主动基金仍占大半壁江山。本文拆解美国被动投资逆袭的底层逻辑，以及中国是否会走同一条路。

* Q1: 美国主动基金为何"失宠"？
  *结论*: 市场有效性高+机构占比高，主动选股择时很难跑赢指数，投资者用脚投票。
  *形式化*: 主动基金 25% 跑赢指数 → 75% 白交管理费 → 资金流出
  *怎么想到的*:
  - 截至2023年6月仅25%主动基金十年期跑赢被动
  - 自2015年起主动基金几乎年年净赎回
  - 投资者不傻，打不过就加入
  - 市场越有效，主动越难创造超额
  *边界*: 若市场有效性下降（如散户占比提升、信息不对称加剧），主动基金可能有超额空间。

* Q2: 费率为何成了压垮主动基金的稻草？
  *结论*: 收益不可控但成本可控，低费率让被动基金在长跑中天然领先。
  *形式化*: 到手收益 = 投资回报 - 成本 → 回报不可控，成本可控 → 降成本 = 增收益
  *怎么想到的*:
  - 到手收益 = 投资回报 - 投资成本
  - 投资回报无法预测，但成本可以事先把控
  - 主动基金需大量研究员和资源，费率高
  - 被动基金"躺赢"运营成本低，费率天然低
  *边界*: 若主动基金能持续创造覆盖费率的阿尔法，高费率就合理。

* Q3: 基金公司如何应对费率战？
  *结论*: 两条路——降主动费率续命，或转型被动基金产品线。
  *形式化*: 费率战 → 主动基金勒紧裤腰带 或 转产被动基金
  *怎么想到的*:
  - 有些主动基金业绩和基准差不多，降费率就能跑赢
  - 更多基金公司选择发行低费被动基金、压缩主动产品线
  - 晨星预计未来十年美国基金费率每年降2.5%
  - 两种策略本质都是向成本低头
  *边界*: 若某基金公司建立不可替代的品牌溢价（如桥水），费率战影响有限。

* Q4: 中国被动基金何时能逆袭？
  *结论*: 趋势已启动但时间不确定，需等市场有效性提升和明星基金经理神话破灭。
  *形式化*: 中国: 主动基金 >> 被动基金 → 结构行情反转 + 明星经理"踩雷" → 被动↑
  *怎么想到的*:
  - 2019-2020年明星经理大幅跑赢市场，吸引大量资金
  - 近几年极致反转，主动基金"踏空"+"抱团"踩雷
  - 管理费高+跑不过指数，投资者开始质疑
  - 但美国从1976年首只指数基金到超越主动用了几十年
  *边界*: 若A股散户比例长期高企、市场有效性提升慢，被动逆袭会延迟。

* Q5: 指数基金真能"躺赢"吗？
  *结论*: 能获取市场贝塔，但分散化也意味着放弃超额收益的可能性。
  *形式化*: 指数基金 = 市场贝塔 + 低费 + 分散 - 超额收益
  *怎么想到的*:
  - 指数基金目标是跟踪指数，不选股不择时
  - 好处是低费、透明、不受人为因素干扰
  - 分散投资不受规模容量限制
  - 代价是永远无法跑赢市场
  *边界*: 若指数成分股严重高估（如某赛道泡沫），指数基金也会高位接盘。

* 收口
被动投资在美国的逆袭不是政策推动，而是投资者在"跑不过指数+高费率"的现实下做出的市场化选择——中国正走在同一条路上，只是慢了几步。
