- *x*：主流经济学把政府当成市场外的分配者或干预者，看不清中国政府"亲自下场生产蛋糕"的机制，因而既解释不了中国增长，也读不懂房价、债务、贸易冲突等身边现象。
- *f*：以"地方政府投融资"为主线，把政府当主角，用"事权划分—分税制—土地财政—土地金融—招商引资—地区竞争"这套微观机制，还原政府如何既做大蛋糕又制造失衡，并把这些微观行为连到宏观现象。
- *f(x)*：看到房价、地方债、贸易战，先追问"背后是哪级政府、什么投融资行为推出来的"；评价政策先看财权事权与激励指向；现实与理论不符时先"置身事内"理解机制，而非讥讽。

# x：作者在讨论什么问题

开篇用类比落地：湖北 GDP 一度与阿根廷相当，中国每个省都抵得上一个中型国家，省内差异极大（新疆面积是海南 47 倍，广东 GDP 是西藏 62 倍）。如此超大规模的治理，意味着"政府"从来不是一个可以一笔带过的黑箱。但主流新古典经济学抽象掉了政治与历史，把政府当作市场之外的分配者或干预者。这造成两个盲区：既解释不了中国为何能高速增长，也读不懂身边的房价、地方债、贸易冲突。作者要处理的问题就是——我们该如何真正理解政府（尤其是地方政府）在中国经济发展中"亲自下场生产蛋糕"的角色与机制。

# f：作者怎样回答

回答的核心是把政府设为全书主角，并以"地方政府投融资"为单一主线，串起一套微观机制：

1. **事权划分三原则**（第一章）：外部性与受益范围、信息复杂性、激励相容，决定哪些事归哪级政府。比如跨省污染归中央协调，复杂本地信息归基层。
2. **分税制→土地财政**（第二章）：1994 年分税制上收财权，地方为发展经济另谋出路，靠土地出让和相关税收撑起占地方预算近九成的"第二财政"。
3. **土地金融与城投**（第三章）：法律规定地方政府不能直接贷款，于是成立城投公司，以土地为抵押撬动银行信贷，"土地财政"加杠杆变成"土地金融"，既推动工业化城市化，也累积债务。
4. **政府下场投资**（第四章）：京东方等产业的崛起，靠地方国资、城投与产业引导基金直接做股权投资，而非仅靠补贴。
5. **地区竞争**（第八章）："官场+市场"体制把官员晋升与地区经济表现挂钩，刺激各地招商引资竞争，也带来地方保护、债务冲动等代价。

这条微观链最终连到宏观：低价工业用地招商+限制商住用地推高地价，制造了房价、债务与内外失衡（第五至七章）。

```
分税制上收财权
      │
      ▼
土地财政（第二财政，≈预算89%）
      │
      ▼
土地金融：城投以土地抵押撬动信贷
      │
      ▼
招商竞争·下场投资 → 工业化/城市化
      │
      ▼
宏观后果：房价·债务·内外失衡
```

# f(x)：怎样回应这个世界

接受这套机制后，面对中国经济现象的理解顺序会改变：

- **看见**：遇到房价、地方债、贸易战，先追问"背后是哪一级政府、什么投融资行为推出来的"，而不是简单归咎市场失灵。
- **判断**：评价一个地区或一项政策，先看"财权与事权是否匹配、激励指向何方"，而非只看市场效率高低。
- **克制**：现实与舶来理论不符时，先"置身事内"理解其历史和约束，不再把现象变成讥讽对象。
- **认知升级**：记住"发展过程≠发展目标"——过去有效的"生产型政府+组织学习"模式，不必然适用于未来，需向"服务型政府+探索创新"转型。
