#+subtitle:   西贝"预制菜风波"背后：餐饮行业利润增长点在哪？

* 引子
西贝预制菜风波把餐饮行业的成本困境摆上台面。晨星股票分析团队从食材、人工、租金三大成本项拆解餐饮行业利润变化，发现2025年利润率有望小幅提升。

* Q1: 为什么食材成本回落对餐饮利润影响最大？
  *结论*: 食材占总成本40%，它的波动直接决定利润好坏。
  *形式化*: 食材成本占比40% + 价格大幅波动 → 利润挤压或释放 → 2023Q2后回落 → 2025年毛利率提升
  *怎么想到的*:
  - 食材是餐饮最大成本项，40%的权重意味着每降1%就释放0.4%利润率
  - 餐饮企业不能随便涨价，原材料波动只能自己扛
  - 2022年大涨让行业承压，2023Q2后回落给了喘息空间
  *边界*: 大宗价格降幅收窄后，2026年食材成本红利可能消退。

* Q2: 人工成本压力为什么看起来"温和"但实际棘手？
  *结论*: 薪资涨幅只有4%看似可控，但高端餐饮和传统中餐依赖人力难以替代。
  *形式化*: 人工占成本30% + 涨4% ≈ 行业增速 → 占比稳定；但劳动密集型业态 → 难以自动化 → 持续承压
  *怎么想到的*:
  - 全国平均薪资涨7%，餐饮只有4%，说明行业在压缩人力开支
  - 占比稳定不代表人便宜了，只是收入也在涨
  - 高端餐饮、传统中餐对厨师依赖度高，自动化空间小
  *边界*: 如果经济回暖带动薪资回升到7%，餐饮人工成本压力会骤增。

* Q3: 租金下行为什么对餐饮是实质性利好？
  *结论*: 租金占成本15%，从2020年持续下降，直接转化为利润。
  *形式化*: 地产调整 → 商铺租金持续下降 → 餐饮拿铺成本降低 → 利润率提升
  *怎么想到的*:
  - 2024年下半年百街租金降到24.25元/平米/天，一线61%、二线83%区域下滑
  - 更极端的是外卖业态兴起，可以选更小更便宜的场地
  - 加上自动化设备压缩厨房面积，对空间需求在下降
  *边界*: 如果地产企稳反弹，租金利好可能反转；但目前看2025年仍会走低。

* Q4: 为什么餐饮新开店增速放缓是好事？
  *结论*: 新玩家减少意味着价格战缓和，存量品牌获得更稳定的竞争环境。
  *形式化*: 新开店增速2% << 疫情前 → 价格战减少 → 存量品牌份额稳定 → 利润率改善
  *怎么想到的*:
  - 新进入者通常用价格战抢市场，存量企业被迫跟价
  - 连锁品牌凭供应链和采购优势，在效率上碾压单体店
  - 消费趋理性时，连锁的稳定品质和性价比更获信任
  *边界*: 如果行业利润率真的提升，新玩家可能重新涌入，竞争再次加剧。

* Q5: 连锁品牌为什么能在行业洗牌中胜出？
  *结论*: 标准化供应链和集中采购让连锁品牌在成本和品质上都占优。
  *形式化*: 连锁品牌 = 集中采购降本 + 标准化出品 + 性价比定位 → 消费理性化趋势下胜出
  *怎么想到的*:
  - 连锁品牌食材采购成本比单体店低，议价能力强
  - 出品品质稳定，消费者怕踩坑时更选连锁
  - "性价比"消费趋势恰好匹配连锁品牌的优势
  *边界*: 如果连锁品牌过度扩张导致供过于求，也会面临单店利润下降。

* Q6: 2025年餐饮行业利润真能提升吗？
  *结论*: 成本端三管齐下（食材降、租金降、人工稳），但需求端是最大变量。
  *形式化*: 食材↓ + 租金↓ + 人工稳定 → 成本端利好 → 但需求个位数增长 → 利润提升空间有限
  *怎么想到的*:
  - 晨星预计2025年餐饮销售额增长4.8%，远低于疫情前10%
  - 成本下降是确定的，但收入增长乏力限制了利润弹性
  - 节假日脉冲式增长后迅速回落，说明消费意愿没有真正恢复
  *边界*: 如果宏观经济恢复带动消费信心回升，利润弹性会大得多。

* 收口
晨星这篇研究的核心贡献是：把餐饮行业的利润拆解成食材40%+人工30%+租金15%的三项成本框架，让投资者看清每一分利润从哪里来、往哪里去。
