* 引子

很多投资者发现：基金显示赚了10%，自己怎么只赚了5%甚至亏了？这不是基金在骗你，而是基金回报和投资者回报是两回事。这篇文章告诉你为什么75%的投资者实际收益都跑不赢基金。

* Q1: 基金回报和投资者回报有什么区别？

  *结论*：基金回报是基金经理赚的，投资者回报是你实际到手的——两者几乎不可能相等。

  *形式化*:
  - 基金总回报: 按净值计算 → 反映基金经理能力
  - 投资者回报: 考虑申赎时点 → 反映你的真实体验
  - 除非买入持有不动，否则两者必然不同

  *怎么想到的*：
  - 基金总回报不考虑期间资金的流入流出
  - 投资者回报考虑了申赎行为的影响
  - 定投例子: 基金三年年化2.9%，投资者实际年化-0.4%

  *边界*：基金总回报是评估基金经理的指标，投资者回报是评估你投资体验的指标。

* Q2: 为什么投资者回报普遍低于基金回报？

  *结论*：因为普通投资者容易追涨杀跌，在错误的时点买入卖出。

  *形式化*:
  - 2012-2021年数据: 75%偏股型基金的投资者收益 < 基金收益
  - 原因1: 选错基金（追短跑冠军）
  - 原因2: 选错时点（追涨杀跌）

  *怎么想到的*：
  - 晨星研究发现每年超过半数基金的投资者收益落后于基金收益
  - 平均有75%的偏股型基金投资者收益不及基金收益
  - 两个主要原因: 单纯基于历史业绩选基金 + 非理性投资行为

  *边界*：这是统计结论，不代表所有投资者都这样。坚持买入持有策略的投资者回报接近基金回报。

* Q3: 为什么追短跑冠军容易掉坑？

  *结论*：因为市场风格会轮动，上一年的冠军基金下一年可能垫底。

  *形式化*:
  - 2017年前十基金 → 持有1年后: 半数落后同类平均
  - 持有5年后: 半数排在同类后1/2，2只排后10%
  - 原因: 风格轮动 + 行业轮动 → 业绩反转

  *怎么想到的*：
  - A股有明显的风格轮动: 大盘价值 ↔ 中小盘成长
  - 行业轮动: 周期股 → TMT → 消费医药 → 新能源AI
  - 基金经理有"能力圈"，顺风时表现好，逆风时业绩反转

  *边界*：不是所有短跑冠军都会反转，但概率足够高，不值得去赌。

* Q4: 追涨杀跌是怎么侵蚀收益的？

  *结论*：因为你在低点不敢买，在高点疯狂买——买在了最贵的时候。

  *形式化*:
  - 基金收益低点: 资金净流入少 / 净流出
  - 基金收益高点: 资金大量流入
  - 结果: 在高点买入的资金多 → 下跌时亏损更大

  *怎么想到的*：
  - 某主题基金的累计收益曲线与净申赎份额的关系
  - 投资者在收益低点时赎回或不敢买入
  - 在收益高点时大量买入，正好接盘

  *边界*: 定投可以部分克服这个问题，因为定投会在低点买入更多份额。

* Q5: 怎么缩小投资者回报和基金回报的差距？

  *结论*：两个方法——选对基金（不追短跑冠军），以及管住手（避免非理性行为）。

  *形式化*:
  - 方法1: 不基于历史业绩选基金 → 避免业绩反转陷阱
  - 方法2: 避免追涨杀跌、赎旧买新、过度交易 → 减少收益损耗
  - 核心: 投资的目标感和定力

  *怎么想到的*：
  - 普通投资者缺乏专业知识，倾向简单通过历史业绩选基金
  - 非理性行为是造成收益率损耗的重要原因
  - 晨星建议: 制定投资计划，坚持执行，避免情绪化操作

  *边界*：完全消除差距不现实，但通过纪律性投资可以显著缩小差距。

* 收口

投资者回报和基金回报的差距，本质上是"你的行为"和"基金经理的能力"之间的差距——管好自己的手，比找到好基金更重要。
