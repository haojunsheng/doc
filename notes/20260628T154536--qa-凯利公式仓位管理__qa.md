* 引子

投资世界最大的矛盾是：胜率高的机会太少，但下错注的代价太大。凯利公式从数学上解了这个题——最优仓位取决于胜率和赔率的组合，而非"觉得会涨多少"。这篇文章的核心洞见不是公式本身，而是公式背后的三个投资原则。

* Q1: 凯利公式到底在解决什么问题？

  *结论*：在"永远不输完"的前提下，让长期复利增长最大化——它算的是最优仓位，不是最优方向。

  *形式化*：最优仓位 f = (p × b - q) / b
  f = 仓位 | p = 胜率 | b = 净赔率 | q = 败率

  *怎么想到的*：
  - 香农和索普面临的核心问题：预测胜率不到100%，每次该下注多少？
  - 凯利推导的公式保证两个结果：永远不输完 + 复利增长最快
  - 公式只依赖两个输入：胜率和净赔率

  *边界*：公式在资本市场难以直接应用，因为没人能精确算出胜率和赔率——输入是垃圾，输出也是垃圾。

* Q2: 为什么"拉长投资期限"就是提高胜率？

  *结论*：因为时间越长，市场正收益概率越高——持有10年比持有1年赚钱概率大得多。

  *形式化*：持有1个月：正收益概率 ≈ 55%
  持有10年：正收益概率 ≈ 95%
  → 时间↑ = 胜率↑

  *怎么想到的*：
  - 2006-2025年任意月份买入沪深300，持有期越长正收益概率越高
  - 长期持有不仅提高胜率，还降低收益离散程度（减少极端亏损）
  - 这是"看似被动但实则有效"的提升胜率方法

  *边界*：这个结论基于"市场长期向上"的假设——如果市场长期下跌（如日本股市"失落的三十年"），时间不会提高胜率。

* Q3: 为什么"孤注一掷"在数学上是错的？

  *结论*：因为最优仓位对赔率波动极度敏感——高赔率投资如果下重注，一次大亏就能抹掉所有累积收益。

  *形式化*：高收益 = 高波动
  高波动 + 高仓位 = 一次大亏抹掉累积收益
  凯利公式：高赔率 → 最优仓位反而更低

  *怎么想到的*：
  - 凯利公式告诉我们：最优仓位与赔率成反比（赔率高时下注应更小）
  - 牛市中主题投资、杠杆操作看起来很美好，但下行风险一旦显现就致命
  - 索普和香农的核心原则：理性控制仓位，不因短期收益好就加码

  *边界*：如果胜率100%（不存在），最优仓位才是100%——但只要胜率<100%，全仓就是数学上的错误。

* Q4: 为什么麦道夫的"稳定收益"反而是危险信号？

  *结论*：因为高收益+零波动在数学上不可能——如果真有这种机会，凯利公式会告诉你该下重注，而不是"稳定"。

  *形式化*：真实高收益 = 必然有波动
  高收益 + 零波动 = 骗局 or 未暴露风险

  *怎么想到的*：
  - 索普评估麦道夫基金时发现：收益高但几乎没有波动——表现"稳定得反常"
  - 17年后证明是庞氏骗局——用新钱付旧收益，没有真实投资
  - 凯利公式的视角：如果策略真实有效，应该有波动，且波动与收益匹配

  *边界*：某些策略（如套利）确实可以在低波动下获得稳定收益——但规模有限，不会向个人投资者开放大额资金。

* Q5: 凯利公式给普通投资者的三个核心启示是什么？

  *结论*：(1) 胜率是核心输入，拉长持有期提高胜率；(2) 体系化策略比运气更可靠；(3) 永远不要全仓单一投资。

  *形式化*：凯利三原则：
  1. 提高胜率 → 拉长持有期
  2. 体系 > 运气 → 纪律执行
  3. 拒绝孤注一掷 → 仓位 < 100%

  *怎么想到的*：
  - 胜率是凯利公式的第一变量，长期持有是最现实的提升胜率方法
  - 香农和索普的成功靠的是两年准备+严格执行，不是一夜暴富
  - 最优仓位永远小于100%——只要胜率不是100%

  *边界*：这三个原则不依赖公式计算——即使不懂凯利公式，理解方向性关系也足够指导实践。

* Q6: 为什么"体系化策略"比"好运"更重要？

  *结论*：因为好运不可复制，而体系可以——长期投资结果取决于可执行的策略，而非某次幸运判断。

  *形式化*：好运 = 随机、不可复制
  体系 = 可复制、可执行、有纪律
  长期结果 = 体系 × 时间

  *怎么想到的*：
  - 香农和索普花两年时间完善理论、发表论文、制造设备
  - 他们到达赌场后按策略严格执行，不是凭感觉下注
  - 索普后来把这套理念带入华尔街，开创量化投资

  *边界*：体系不能消除运气的影响——再好的策略也可能在短期内跑输。但长期来看，体系的优势会显现。

* 收口

凯利公式的真正价值不是那个公式本身，而是它揭示的三个投资原则：时间提高胜率、体系胜过好运、仓位决定生死。索普用这套方法在赌场和华尔街都赢了——而麦道夫的反面教训告诉我们，"稳定高收益"本身就是最大的风险信号。
