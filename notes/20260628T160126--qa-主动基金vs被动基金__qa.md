* 引子
晨星中国基金主动被动晴雨表覆盖2555只基金、3.5万亿规模。核心发现：63%主动偏股基金2022年跑赢同组被动，中长期超额显著。但消费行业主动基金难以获取超额，中小盘主动战胜率从73%暴跌至43%。

* Q1: 为何美国主动跑不赢被动而中国能跑赢？
  *结论*: 市场有效性不同——美国市场有效性高难寻错误定价，中国市场结构性机会多。
  *形式化*: 美国: 有效性高 → 主动难赢 → 低费被动胜出 → 中国: 有效性低 → 主动能赢
  *怎么想到的*:
  - 美国主动基金难以战胜被动基金
  - 但中国63%主动偏股基金跑赢同组被动
  - 原因是新兴市场结构性机会更多
  - 主动经理能挖掘市场错误定价
  *边界*: 若A股有效性持续提升（机构化+信息透明），主动超额会收窄。

* Q2: 用被动基金而非指数做基准有何意义？
  *结论*: 投资者买的是有成本的指数基金而非无成本指数，用被动基金做基准更贴近现实。
  *形式化*: 可投资基准 = 被动基金(有成本) ≠ 指数(无成本) → 更贴近实际
  *怎么想到的*:
  - 投资者实际可买的是指数基金/ETF
  - 指数基金有管理费、跟踪误差等成本
  - 用同组被动基金做基准更公平
  - 晨星美国主动被动晴雨表采用类似方法
  *边界*: 若某被动基金费率极高或跟踪误差大，作为基准会有偏差。

* Q3: 中小盘主动战胜率为何从73%暴跌至43%？
  *结论*: 2022年中小盘风格剧烈切换+市场环境严峻，主动经理难以应对快速轮动。
  *形式化*: 中小盘主动: 73% → 43% → 风格轮动↑ + 环境严峻 → 主动失效
  *怎么想到的*:
  - 2021年中小盘主动战胜率73%
  - 2022年暴跌至43%
  - 大盘成长(66%)和大盘平衡(63%)仍保持高战胜率
  - 说明中小盘主动经理应对逆风能力弱
  *边界*: 若2023年中小盘风格回归稳定，中小盘主动战胜率可能回升。

* Q4: 消费行业主动为何难以获取超额？
  *结论*: 消费行业研究透明度高、定价有效，主动经理难以找到错误定价机会。
  *形式化*: 消费行业 = 研究透明 + 定价有效 → 错误定价↓ → 主动超额↓(28%-52%)
  *怎么想到的*:
  - 消费行业主动基金一年/三年/五年战胜率28%-52%
  - 在所有行业中表现最差
  - 消费股覆盖充分、信息透明
  *边界*: 若消费行业出现结构性变化（如新消费趋势），主动经理可能找到机会。

* Q5: 医药和科技传媒通讯行业为何主动能持续超额？
  *结论*: 行业复杂度高、研究壁垒强，主动经理的专业知识能创造信息优势。
  *形式化*: 医药/TMT = 高复杂度 + 高壁垒 → 信息不对称 → 主动超额(>60%)
  *怎么想到的*:
  - 医药行业基金中长期战胜率超60%
  - 科技、传媒及通讯行业基金同样超60%
  - 这些行业专业性强、研究成本高
  - 主动经理的深度研究能创造价值
  *边界*: 若AI辅助研究普及、信息不对称降低，这些行业的主动超额可能收窄。

* Q6: 投资者该选主动还是被动？
  *结论*: 取决于个人能力——能选到绩优主动经理选主动，否则选低费被动更稳妥。
  *形式化*: 选基金 = 能选绩优主动(选主动) vs 不能(选低费被动)
  *怎么想到的*:
  - 主动基金整体强于被动但不代表每只都强
  - 选择绩优主动基金是难题
  - 被动基金风格稳定且费率低廉
  - 需结合风险偏好和收益预期选择
  *边界*: 若未来主动基金整体超额收窄，被动基金会成为更优默认选项。

* 收口
中国主动基金能跑赢被动，不是因为中国市场无效，而是因为"机构化程度不够+信息不对称"给了主动经理超额空间——但这个空间正在缩小。
