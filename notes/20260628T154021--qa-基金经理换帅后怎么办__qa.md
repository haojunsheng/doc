* 引子
易方达行业领先混合基金经理冯波卸任，彭珂接任。冯波管理15年取得同类排名前26%，但近五年质量成长风格遭遇逆风。新任基金经理彭珂只有一年多投资经验，且管理的另一只基金业绩落后同类。持有人面临一个经典问题：换帅后走还是留？

* Q1: 冯波为什么在这个时点卸任？
  *结论*: 表面是"工作需要"，实际可能是业绩回撤+公司内部调整的综合结果。
  *形式化*: 15年管理 + 近5年风格逆风 → 冯波卸任 + 继续管其他基金
  *怎么想到的*:
  - 冯波仍管理研究精选和竞争优势企业
  - 说明不是全面退出，而是局部交接
  - 近5年质量成长风格遭遇逆风是公开事实
  - 15年老将通常不会主动放弃旗舰基金
  *边界*: 如果冯波完全离开易方达，可能是个人职业规划；留部分基金说明是内部调整。

* Q2: 彭珂能接好吗？
  *结论*: 目前无法判断——经验太短、历史业绩落后、没有经历过完整市场周期。
  *形式化*: 彭珂 = 11年从业 + 1年投资管理 + 接管6天 + 科益基金落后同类
  *怎么想到的*:
  - 接管时只有6天管理经验在这只基金上
  - 管理的易方达科益混合一年多业绩落后同类平均
  - 没有经历过完整的牛熊考验
  - 晨星明确说"需要经过完整市场周期考验"
  *边界*: 如果彭珂有很强的研究员背景且投资框架成熟，短期落后不说明问题。

* Q3: 冯波的长期业绩还值得参考吗？
  *结论*: 15年前26%的排名证明过能力，但近5年落后说明风格与市场不匹配。
  *形式化*: 冯波长期排名(前26%) ≠ 近5年排名(偏低) → 风格漂移或市场变化
  *怎么想到的*:
  - 15年维度看，他是优秀的
  - 近5年维度看，他是落后的
  - 质量成长风格在这5年遭遇逆风
  - 说明基金经理有能力但风格跟市场不匹配
  *边界*: 当市场风格切回成长时，冯波的能力可能重新兑现。

* Q4: 持有人应该赎回吗？
  *结论*: 取决于你对新经理的信心和基金在组合中的角色，不建议仅因换帅赎回。
  *形式化*: 赎回决策 = 新经理信心 + 基金角色 + 替代选项 → 不因单一事件决定
  *怎么想到的*:
  - 换帅不等于基金策略必然变差
  - 但新经理没有足够历史数据验证
  - 如果基金是核心仓位且风格依赖经理，需要更谨慎
  - 如果基金是卫星仓位，可以观察一个完整年度
  *边界*: 如果新经理上任后立刻大幅调仓偏离原策略，持有人应重新评估。

* Q5: 怎么评估新经理的真实能力？
  *结论*: 至少需要一个完整市场周期（3-5年）才能判断，短期业绩说明不了什么。
  *形式化*: 评估新经理 = 完整周期(3-5年) + 多维度(业绩/风控/风格一致性) → 长期判断
  *怎么想到的*:
  - 晨星明确说"需要经过完整市场周期考验"
  - 一年以内的业绩波动很大
  - 要看风控能力、风格一致性、下行保护
  - 短期排名不能说明问题
  *边界*: 如果新经理在极端市场（如大跌）中表现出很好的风控，可以提前加分。

* Q6: 这次换帅暴露了什么风险？
  *结论*: 暴露了单一基金经理依赖风险——当策略绑定个人而非制度时，换帅就是系统性冲击。
  *形式化*: 策略绑定个人 → 换帅 = 策略风险；策略绑定制度 → 换帅 = 运营风险
  *怎么想到的*:
  - 冯波管理15年，基金打上了他的风格烙印
  - 彭珂从研究员上来，风格完全不同
  - 持有人买的是冯波，现在变成了彭珂
  - 如果公司有成熟的投资体系，换帅影响会小很多
  *边界*: 如果基金公司有成熟的投资委员会和风控体系，个人离职影响会被制度缓冲。

* 收口
晨星这次没有给出明确建议，但潜台词很清楚：在看到新经理证明自己之前，不确定性就是不确定性——持有人应该知道这一点，而不是假装风险不存在。
