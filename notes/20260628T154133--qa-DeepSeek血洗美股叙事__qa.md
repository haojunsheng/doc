* 引子
DeepSeek-R1模型训练成本降低95%、开源免费，直接打破"算力越多越好"的AI叙事，引发美股科技股抛售。晨星文章借此事揭示：资本市场被叙事驱动，故事让人绕过理智用情绪决策，被宏大叙事迷惑的普通投资者往往最后血本无归。

* Q1: DeepSeek为什么能血洗美股？
  *结论*: 训练成本降95%+开源免费，打破了"算力越多越好"的信仰，动摇了AI价值链持续吸金的叙事。
  *形式化*: 成本降95% + 开源免费 → 算力信仰崩塌 → 科技股抛售潮
  *怎么想到的*:
  - DeepSeek-R1性能对标顶尖模型但成本仅5%
  - 开源免费打破了少数公司垄断
  - 半导体、能源等"AI受益股"集体跳水
  *边界*: 若DeepSeek后续证明性能不稳定或商业化受阻，叙事可能修复。

* Q2: 叙事怎么影响资产价格？
  *结论*: 资产价格反映预期，叙事塑造信念从而改变预期和行为，让投资者用情绪而非理智决策。
  *形式化*: 叙事 → 塑造信念 → 改变预期 → 改变行为 → 影响价格
  *怎么想到的*:
  - "重要对象项目"实验证明故事能让130美元的东西卖3612美元
  - 金融行业也在利用叙事销售主题基金
  - 越是难被证伪的叙事生命力越强
  *边界*: 当叙事被明确证伪时（如业绩不达预期），价格会剧烈修正。

* Q3: 为什么AI叙事之前没人质疑？
  *结论*: 因为英伟达等公司的业绩似乎验证了叙事，形成了自我强化的共识循环。
  *形式化*: 英伟达业绩好 → 验证AI叙事 → 更多人相信 → 更多资金涌入 → 业绩更好
  *怎么想到的*:
  - DeepSeek出现前"英伟达会繁荣"是几乎所有人的共识
  - 这条预设路径看起来必然成立
  - 主流叙事没考虑发展过程中会产生输家
  *边界*: 一旦有证据表明AI投入无法转化为盈利，叙事就会松动。

* Q4: 科技巨头花几十亿做AI赚到钱了吗？
  *结论*: 没有，Alphabet和Meta自己都没想清楚AI高投入怎么转化为更高盈利，但市场不担心。
  *形式化*: 高投入(AI) ≠ 高盈利(未验证) → 市场忽略风险 → 叙事支撑估值
  *怎么想到的*:
  - 谷歌母公司Alphabet和Meta投入数十亿美元
  - 两家都没找到AI盈利模式
  - 股价表现说明市场暂时不计较
  *边界*: 若持续看不到盈利路径，市场耐心会耗尽。

* Q5: 为什么故事是投资者最大的敌人？
  *结论*: 故事绕过大脑和理智，让行动完全受情绪驱使，明知是故事还因赚钱不愿抽身。
  *形式化*: 故事 → 绕过理智 → 情绪驱动 → 明知是故事 → 不愿抽身 → 最终亏损
  *怎么想到的*:
  - 买入故事期待的结局是"变富过上幸福生活"
  - 实际是情绪驱动而非理性分析
  - 害怕错过+正在赚钱=不愿面对现实
  *边界*: 专业投资者可以利用叙事周期，在叙事破裂前退出。

* Q6: 宏大叙事破裂时谁买单？
  *结论*: 被宏大叙事迷惑的盲信普通投资者血本无归，推高炒作的人早已离场。
  *形式化*: 炒作机器停止 → 推高者已离场 → 盲信普通投资者接盘 → 血本无归
  *怎么想到的*:
  - 有人出于经济利益尽可能长时间推高炒作
  - 害怕错过的人一股脑往里冲
  - 炒作停止后接盘的是最后进场的普通人
  *边界*: 若叙事没有破裂而是逐步兑现，早期投资者反而受益。

* Q7: 听到"不容错过"的主题应该怎么想？
  *结论*: 多问一句：这个叙事能被证伪吗？投入者赚到钱了吗？谁在推这个故事？
  *形式化*: "不容错过" → 问三个问题：①能证伪吗 ②赚到钱吗 ③谁在推 → 再决定
  *怎么想到的*:
  - 晨星建议"更加谨慎地思考"
  - 关键是区分叙事和现实
  - 好到令人难以置信的叙事往往最脆弱
  *边界*: 谨慎不等于错过，等叙事被部分验证后再入场也不迟。

* 收口
晨星借DeepSeek事件讲了一个朴素的道理：AI会改变世界，但改变世界不一定会让你赚钱——投资靠的是分析，不是故事。
