* 引子

2025年沪深300涨了21.54%，但不少基民账户还是绿的。为什么？因为牛市里的大部分收益集中在少数几天——错过这10天，全年收益就从+21%变成-1.37%。这不是2025年的特例，而是21年数据的铁律。

* Q1: 为什么2025年指数涨了很多人还是亏钱？

  *结论*：因为牛市收益集中在少数交易日，而多数人频繁操作时恰好错过了这些关键日。

  *形式化*：全年收益21.54% → 错过最好的10天 → 收益变成-1.37%

  *怎么想到的*：
  - 2025年单日涨幅最大的10天大多出现在市场刚砸出深坑之后
  - 如果恰好在最好的一天之前清仓、大涨后追进去，就完美错过了肉
  - 复利效应下，错过10天就能让正收益变负

  *边界*：这是极端假设——没人能精准错过所有好日。但方向是对的：你离场的频率越高，撞上关键日的概率越大。

* Q2: 错过最好的10天vs躲过最差的10天，哪个对收益影响大？

  *结论*：躲过最差的10天确实能改善收益，但错过最好的10天才是更隐蔽的杀手——因为大涨往往来得猝不及防。

  *形式化*：大跌 → 恐慌离场 → 错过接下来的大涨 = 双重损失

  *怎么想到的*：
  - 统计显示躲过大跌能明显改善收益，这也是多数人想做的
  - 但大涨多出现在熊市末尾或牛市初期，恐慌情绪让人不敢进场
  - 结果：躲过了下跌，也错过了反弹

  *边界*：精准躲过大跌本身难度极高——21年里大盘单日涨跌概率基本55开，靠主观判断躲跌和抛硬币差不多。

* Q3: 为什么"躲过大涨"比"躲过大跌"更容易做到？

  *结论*：因为躲过大涨只需要一个动作——买入分散的指数并持有不动；而躲过大跌需要持续预测，成功率极低。

  *形式化*：躲大涨 = 买指数 + 持有；躲大跌 = 预测 + 频繁操作

  *怎么想到的*：
  - 买入相对分散的指数并长期持有，就能保证不错过关键上涨日
  - 这比天天判断"明天涨跌"要容易得多
  - 对普通投资者来说，先保证"不缺席"比"精准择时"更现实

  *边界*：持有不等于无脑持有——如果指数本身编制有问题或者费率过高，长期持有也会侵蚀收益。

* Q4: 为什么"追涨"也很难赚到钱？

  *结论*：因为追涨通常意味着你已经错过了表现最好的N天，剩下的收益空间有限。

  *形式化*：追高买入 = 最佳涨幅已过 → 后续收益低于预期

  *怎么想到的*：
  - 行业或指数的上涨往往集中在少数几天
  - 当你看到大涨再进去时，最重要的涨幅可能已经走完
  - 追涨的本质是"买在别人出货的时候"

  *边界*：如果是真正的长期趋势（比如产业变革），早期追涨仍有空间。但多数人追的是短期热点，此时最佳时机已过。

* Q5: 在投资这场考试里，怎么拿到"及格分"？

  *结论*：先保证不错过大涨——买入分散指数、长期持有、减少操作，拿到市场平均分再说。

  *形式化*：及格分 = 市场平均收益 = 买指数 + 持有 + 少动

  *怎么想到的*：
  - 过去21年里，单日涨幅超1%的交易日不到20%
  - 80%的时间行情平淡甚至难熬，但坚持住才能抓住那20%
  - 在拿到60分之前就去研究怎么考80分，是本末倒置

  *边界*：指数投资不等于没有风险——市场整体下跌时指数基金也会亏钱，只是不会因"选错个股"而额外亏钱。

* 收口

投资里最反直觉的事实之一：决定你全年收益的，不是你的判断力，而是你在那最关键的10天里有没有在场。与其天天想着怎么躲过大跌，先保证自己别错过大涨——买指数、持有、少动，这三板斧比任何择时策略都管用。
