* 引子
泡泡玛特年内暴涨后单周跌12%，老铺黄金跌13%，中证香港创新药指数涨50%后单周回调8.5%。新消费和创新药两大热门板块同步震荡——是上车机会还是见顶信号？四位基金经理给出了截然不同的答案。

* Q1: 熊潇雅为什么能提前两年抓到泡泡玛特？
  *结论*: 她2023年Q1在公司估值不高、业绩低谷时布局，看中的是海外门店快速盈利的扩张空间。
  *形式化*: 低估值+业绩低谷买入 → 海外扩张验证 → 估值↑+业绩↑ → 超额收益
  *怎么想到的*:
  - 熊潇雅喜欢在公司估值不高、业绩低谷时布局
  - 她通过调研上市公司、供应链和海外业务人员发现泡泡玛特海外门店能迅速盈利
  - 背后逻辑：海外市场对潮文化IP接受度高，产品能卖高价
  - 公司后期海外业务快速增长验证了她的判断
  *边界*: 若海外市场对潮文化IP的热度消退（如审美疲劳），海外扩张的盈利模型会失效。

* Q2: 萧楠为什么遗憾没赚够？
  *结论*: 他在底部低估了泡泡玛特的独特性和时代潮流力量，2022年疫情波动中大幅减持。
  *形式化*: 底部买入 → 疫情波动恐慌减持 → 股价大涨后持仓不变但占比↑ → 遗憾少赚
  *怎么想到的*:
  - 萧楠2021年下半年开始重仓泡泡玛特，持仓占比4.48%
  - 2021-2022年股价大幅波动给组合带来损失
  - 基于基本面考量大幅减持至0.75%
  - 2024年以来股价大涨，持股数量不变但占比回到4.09%
  - 他反思：低估了一家年轻公司的可能性、独特性和时代潮流力量
  *边界*: 若2022年的宏观冲击更严重（如长期封控），减持可能是正确的风控决策。

* Q3: 萧楠为什么2025年又开始减持？
  *结论*: 他认为新消费公司上市时第一成长曲线基本走完，面临第二曲线不明朗和竞争者涌入的不确定性。
  *形式化*: 估值↑ → 第一成长曲线走完 + 第二曲线不明朗 + 竞争者蜂拥 → 减持
  *怎么想到的*:
  - 泡泡玛特估值持续提升
  - 萧楠判断新消费公司上市时第一成长曲线基本走完
  - 后面面临第二曲线不明朗、竞争者蜂拥而入
  - 这是基于成长策略框架的决策而非短期情绪
  *边界*: 若泡泡玛特成功开拓出第二曲线（如海外大规模扩张超预期），减持逻辑失效。

* Q4: 戴军为什么不碰这些股票？
  *结论*: 他认为泡泡玛特、老铺黄金、蜜雪都属于"泡沫定价"——把偶然性因素过度资本化。
  *形式化*: 偶然性因素(政策红利+潮流风口) → 过度资本化 → 泡沫定价 → 不碰
  *怎么想到的*:
  - 戴军将股票按净资产/净现金流/成长/泡沫四种方式定价
  - 他认为这些股票属于泡沫定价
  - 泡沫定价特点：将短期政策红利、潮流风口等非持续性变量过度资本化
  - 还认为低价不是竞争壁垒，市场默认利润可持续很久是荒谬的
  *边界*: 若新消费公司能证明其利润具备持续性和可复制性（如品牌护城河加深），泡沫定价判断可能过于保守。

* Q5: 创新药为什么突然爆发？
  *结论*: 工程师红利带来性价比优势+治疗载体缺乏重大革新，国内药企研发效率高吸引海外合作。
  *形式化*: 工程师红利 + 研发效率高 → 海外药企引进临床产品 → 创新药爆发
  *怎么想到的*:
  - 刘晓认为创新药爆发源于工程师红利带来的性价比优势
  - 当前治疗载体缺乏重大革新
  - 国内药企研发效率高于海外，国外药企选择从国内引进一期/二期临床产品到海外做三期
  - 詹成认为这是国内医药企业厚积薄发带来的质变
  *边界*: 若海外药企因政治因素（如中美摩擦）减少从国内引进产品，创新药爆发逻辑会受阻。

* Q6: 创新药的风险在哪里？
  *结论*: 管线定价无业绩支撑+单一大品种估值透支未来+2027年产品上市时业绩可能不及预期。
  *形式化*: 管线定价(无业绩) + 估值透支 + 2027年业绩兑现风险 → 选股需谨慎
  *怎么想到的*:
  - 刘晓坦承创新药通过管线定价，暂没有业绩支撑，很难把握机会
  - 需对单一大品种且估值透支未来海外市场空间的标的保持谨慎
  - 需防范2027年产品上市时业绩不及预期的风险
  - 詹成认为目前估值已经基本合理
  *边界*: 若创新药产品提前上市或海外授权金额超预期，业绩兑现风险会降低。

* Q7: 基金经理对热门板块的分歧说明了什么？
  *结论*: 投资框架决定选股选择——没有对错，只有框架与标的的匹配度。
  *形式化*: 投资框架A → 选泡泡玛特 ‖ 投资框架B → 不选泡泡玛特 → 都合理
  *怎么想到的*:
  - 熊潇雅和萧楠基于成长框架参与泡泡玛特
  - 戴军基于企业竞争力框架认为泡沫不参与
  - 刘晓和詹成对创新药一谨慎一乐观，源于不同风险偏好
  - 文章明确说"能否把握机会取决于基金经理的投资能力"
  *边界*: 若市场风格发生根本变化（如成长股整体失宠），所有成长框架都可能失效。

* 收口
基金经理的分歧不是谁对谁错，而是各自框架在筛选——投资者该学的不是跟谁买，而是让自己的框架变得比基金经理更锋利。
