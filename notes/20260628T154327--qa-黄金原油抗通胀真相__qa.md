* 引子

黄金和原油被当作"抗通胀神器"，但长期数据讲了一个完全不同的故事：原油50年没回到历史高点，黄金曾跑输A股近十年，两者都经历过持续20年的熊市。这篇文章的核心问题是：黄金和原油在组合里到底应该扮演什么角色？

* Q1: 为什么高通胀时期原油表现比黄金更稳定？

  *结论*：因为原油本身就是CPI的组成部分，油价上涨直接等于通胀；黄金和通胀之间还隔着实际利率这个变量。

  *形式化*：油价↑ = CPI↑ → 直接抗通胀
  黄金 ← 通胀 - 实际利率 → 间接 + 可能被利率压制

  *怎么想到的*：
  - 通胀反映商品和服务价格整体上涨，原油是其中重要组成
  - 黄金是无息资产，实际利率上升会提高持有黄金的机会成本
  - 1987-1990年间黄金甚至跑输通胀——利率因素压过了通胀因素

  *边界*：如果通胀伴随实际利率下降（如滞胀），黄金和原油会同时表现很好——此时黄金的"劣势"变成优势。

* Q2: 为什么长期来看黄金和原油的表现远不如想象中好？

  *结论*：两者都经历"超级周期"——牛市和熊市各持续10-20年，长期持有可能跑输股票甚至债券。

  *形式化*：黄金：1970-1980牛市 → 1980-2000熊市（-60%）→ 2000-2011牛市 → 2011-2020震荡
  原油：1970s牛市 → 1980-1999熊市 → 1999-2008牛市 → 2008至今未回高点

  *怎么想到的*：
  - 黄金在2024年之前有近十年大幅落后于A股
  - 原油在2026年暴涨前，长期收益甚至逊于债券
  - 两者波动特征更接近股票而非"安全资产"

  *边界*：如果恰好在周期底部入场、顶部离场，回报会极好——但择时本身极难，熊市太长让人无法坚持。

* Q3: 为什么"商品当核心底仓"是危险的？

  *结论*：因为商品的熊市太长（10-20年），单靠商品投资可能大半生都无法回本，跟人生收支周期严重不匹配。

  *形式化*：人生收支周期：30-40年
  商品超级周期：10-20年熊市
  错配：可能一辈子都遇不到下一个牛市

  *怎么想到的*：
  - 1980年买入黄金，到2000年才回本——20年
  - 2008年买入原油，至今未回高点——18年
  - 商品波动"大涨大跌是家常便饭"，不是稳健资产

  *边界*：如果投资者期限极长（如30年以上）且能承受50%以上回撤，商品作为核心持仓的逻辑可以成立——但普通人做不到。

* Q4: 黄金和原油在组合中的正确角色是什么？

  *结论*：卫星持仓，不超15%——利用它们在特定时期（高通胀、地缘冲击）的对冲能力和与传统资产的低相关性。

  *形式化*：组合 = 核心底仓（股债）+ 卫星持仓（商品≤15%）
  卫星作用：特定时期对冲 + 分散风险

  *怎么想到的*：
  - 它们在特定时期（高通胀阶段）表现出色，能有效守护购买力
  - 与股票、债券的长期相关性较低，能分散组合风险
  - 但波动剧烈，重仓会让组合整体风险特征恶化

  *边界*：15%上限是经验值——如果组合整体很保守，可以稍高；如果组合本身已经很激进，商品配比应更低。

* Q5: 为什么黄金和原油的择时风险极高？

  *结论*：因为它们的牛熊周期太长，一旦在牛转熊的高位入场，可能10-20年无法回本。

  *形式化*：正确时点入场 → 赚大钱
  错误时点入场 → 10-20年无法回本

  *怎么想到的*：
  - 黄金1980年见顶后跌了20年，最大回撤超60%
  - 原油2008年见顶后至今未回高点
  - "大涨大跌是家常便饭"意味着择时错误代价极大

  *边界*：如果采用定投方式分散入场时点，可以部分降低择时风险——但长期来看，定投商品仍可能跑赢不了定投股票。

* Q6: 这篇文章颠覆了什么常见认知？

  *结论*：黄金和原油不是"安全资产"——它们是波动接近股票的长期过山车，抗通胀能力只在特定时期成立。

  *形式化*：常见认知：黄金原油 = 安全 + 抗通胀
  实际数据：黄金原油 = 长期过山车 + 阶段性抗通胀

  *怎么想到的*：
  - 很多投资者认为"实物资产安全性更高"，但数据显示黄金和原油的波动特征更接近风险资产
  - 黄金曾跑输A股近十年，原油长期收益逊于债券
  - "抗通胀"标签让人忽视了它们的长期持有成本

  *边界*：文章基于历史数据，如果未来进入新的商品超级周期（如能源转型驱动），历史规律可能被打破——但无法预测何时开始。

* 收口

作者用长期数据把黄金和原油从"抗通胀神器"拉回"组合卫星"的正位——它们有价值，但价值只在特定时期和特定比例内成立，重仓持有是拿人生周期赌商品周期。
