* 引子
晨星基金研究团队从投研团队、投资流程、策略可持续性四个维度，选出四只值得关注的权益基金：易方达逆向投资、中泰开阳价值优选、景顺长城成长之星、泓德泓华。每只基金的共同点是基金经理稳定、策略清晰、风控意识强。

* Q1: 晨星选基金最看重什么？
  *结论*: 投研团队、投资流程、策略可持续性——不是短期业绩排名。
  *形式化*: 晨星选基 = 团队(稳定+能力) + 流程(可复制) + 策略(可持续) ≠ 短期排名
  *怎么想到的*:
  - 晨星强调独立性和投资者利益优先
  - 研究方法以长期投资为导向
  - 四只基金的基金经理任职都超过5年
  - 每只都有清晰可描述的投资框架
  *边界*: 当基金公司发生大规模投研团队变动时，晨星的评估结论可能失效。

* Q2: 杨嘉文的逆向投资是什么逻辑？
  *结论*: 回避市场关注度高的行业和个股，在关注度低的地方找估值合理的好公司。
  *形式化*: 逆向投资 = 回避高关注 + 深耕低关注 + 均衡配置(单行业<20% + 单股<5%)
  *怎么想到的*:
  - 杨嘉文有13年从业+7年公募经验
  - 管理易方达科瑞混合7年证明A股能力
  - 组合50只左右，相对均衡
  - 2023年配备研究助理强化支持
  *边界*: 当市场风格持续偏向热门赛道时，逆向策略可能长期跑输。

* Q3: 田瑀为什么敢只持有20只？
  *结论*: 高集中度来自深度基本面研究——每只都是长期紧密跟踪的高置信度标的。
  *形式化*: 高集中度(20只) = 深度研究 + 高置信度 + 风险源多元化(单风险源<20%)
  *怎么想到的*:
  - 田瑀有13年从业+8年A股经验
  - 2016年起就用相似策略管理集合理财
  - 研究员团队精简但稳定
  - 团队主导研究方向，对研究员要求极高
  *边界*: 当市场风格不在他的研究覆盖范围内时，高集中度可能错过机会。

* Q4: 周寒颖的选股框架有什么特别？
  *结论*: 把成长股分成三类——稳定成长、高速成长、高股息——用不同标准筛选。
  *形式化*: 周寒颖选股 = 三类成长股(稳定+高速+高股息) + 估值历史区间 + 20%高股息仓位
  *怎么想到的*:
  - 海外投资经验带来的全球视野
  - 中观产业链+自下而上个股结合
  - 考察未来三年成长空间
  - 高股息要求股息率>5%
  - 卖出触发：估值高位/增长趋势变化/逻辑证伪
  *边界*: 当市场风格不在成长股上时，框架的有效性会打折扣。

* Q5: 秦毅为什么注重景气度？
  *结论*: 在成长股框架中加了景气度维度——上行时持有，下行时减持来控制回撤。
  *形式化*: 秦毅策略 = 高质量成长 + 景气度跟踪(月度/季度数据) → 景气↓则减仓控回撤
  *怎么想到的*:
  - 7年A股投资经验+7年管理泓德泓华
  - 信息技术、工业、原材料、医药都有选股能力
  - 低换手率说明不是频繁交易
  - 注重公司质地(商业模式+壁垒+格局)
  *边界*: 当行业景气度因政策突变而急剧转向时，月度/季度跟踪可能滞后。

* Q6: 这四只基金的共同点是什么？
  *结论*: 基金经理稳定任职5年以上+策略清晰可描述+风控意识强+重视基本面研究。
  *形式化*: 共同点 = 稳定任职(5年+) + 策略可描述 + 风控意识 + 基本面驱动
  *怎么想到的*:
  - 杨嘉文7年、田瑀5年+、周寒颖4年+、秦毅7年
  - 每只都有明确的投资框架可复述
  - 都有明确的风险控制手段（集中度限制/估值区间/景气度跟踪）
  - 都不依赖短期市场热点
  *边界*: 当基金经理离职时，这些共同点的价值需要重新评估。

* Q7: 晨星推荐等于值得买吗？
  *结论*: 不等于——推荐是基于流程和团队的评估，不是对未来业绩的保证。
  *形式化*: 晨星推荐 = 流程评估(过去+现在) ≠ 业绩保证(未来)
  *怎么想到的*:
  - 晨星强调研究方法的可持续性
  - 四只基金的风险评价从"中等"到"偏高"不等
  - 中泰开阳风险评价"偏高"但仍被推荐
  - 说明推荐的核心是策略可持续性而非风险低
  *边界*: 当基金经理发生风格漂移或核心投研人员离职时，推荐的基础就动摇了。

* 收口
晨星这次选四只基金的底层逻辑跟它一贯的方法论一致：不选业绩冠军，选策略稳定、团队可靠、风控到位的"长跑选手"——本质上是在选"不亏钱"的能力，而非"赚最多"的能力。
