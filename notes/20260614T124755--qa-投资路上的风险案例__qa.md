* 引子

投资路上充满陷阱——从追涨杀跌到风格漂移，从费用侵蚀到风险错配。通过真实案例学习，可以帮助投资者避免常见错误。

* Q1: 为什么投资者容易追涨杀跌？

  *结论*：因为人性驱使——贪婪和恐惧是投资最大的敌人。

  *形式化*: 追涨杀跌 = 贪婪（涨时追） + 恐惧（跌时杀） → 高买低卖 → 亏损

  *怎么想到的*：
  - 投资者在市场狂热时追高买入
  - 市场回调时恐慌卖出
  - 高买低卖导致亏损

  *边界*：如果投资者有明确的投资计划和纪律，可以避免追涨杀跌。

* Q2: 什么是风格漂移？为什么要警惕？

  *结论*：风格漂移是基金投资风格偏离其宣称的风格，可能导致投资者承担未预期的风险。

  *形式化*: 风格漂移: 基金实际风格 ≠ 宣称风格 → 投资者风险暴露偏离预期

  *怎么想到的*：
  - 基金宣称是价值型，但实际买了大量成长股
  - 风格漂移可能导致投资者承担未预期的风险
  - 需要定期监控基金持仓

  *边界*：如果基金经理的风格漂移能带来更好的收益，投资者可能会接受。

* Q3: 为什么费用对长期收益影响很大？

  *结论*：费用是确定的成本，长期累积会大幅侵蚀收益。

  *形式化*: 高费用 → 收益侵蚀 → 长期损失巨大

  *怎么想到的*：
  - 费用包括管理费、托管费、销售服务费等
  - 看似每年1-2%，20-30年累积起来非常可观
  - 低成本投资是指数基金的核心优势

  *边界*：如果主动基金能持续创造超额收益，高费用可能是值得的。

* Q4: 为什么投资者常常高估自己的风险承受能力？

  *结论*：因为在牛市中所有人都觉得自己能承受高风险。

  *形式化*: 风险认知偏差: 牛市 → 高估风险承受能力 → 熊市 → 恐慌卖出

  *怎么想到的*：
  - 牛市中投资者往往高估自己的风险承受能力
  - 熊市来临时才发现自己无法承受
  - 导致在底部恐慌卖出

  *边界*：如果投资者经过完整的市场周期考验，风险认知会更准确。

* Q5: 为什么分散化投资很重要？

  *结论*：分散化可以降低非系统性风险，避免"把所有鸡蛋放在一个篮子里"。

  *形式化*: 分散化: 资产↓ + 行业↓ + 地区↓ → 非系统性风险↓

  *怎么想到的*：
  - 单一资产/行业/地区的波动性大
  - 分散化可以降低组合的整体波动性
  - 避免因单一资产的大幅下跌而遭受重大损失

  *边界*：分散化不能消除系统性风险——市场整体下跌时，分散化组合也会下跌。

* Q6: 为什么投资计划比市场预测更重要？

  *结论*：因为市场预测几乎不可能准确，而投资计划可以帮助投资者保持纪律。

  *形式化*: 投资计划 > 市场预测 → 纪律性操作 → 更好的长期结果

  *怎么想到的*：
  - 市场预测的准确率极低
  - 投资计划可以帮助投资者在市场波动时保持冷静
  - 纪律性操作比预测市场更重要

  *边界*：如果投资者有明确的择时策略，适度预测市场也是合理的。
