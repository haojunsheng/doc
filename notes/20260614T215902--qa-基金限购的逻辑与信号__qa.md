* 引子
2023年中小盘股一枝独秀，北证50在11月涨了近40%，中小盘基金规模暴增。但当基民终于决定"上车"时，发现基金开始限购了。文章解释了基金限购的真正原因：不是不想赚钱，而是规模增长可能成为"业绩杀手"，尤其是对中小盘和量化基金。

* Q1: 为什么基金公司要"放着钱不赚"发限购公告？
  *结论*：规模增长可能稀释收益、影响策略执行，限购是保护现有持有人利益。
  *形式化*：规模↑ → 策略容量不足 → 收益↓ → 限购保护现有投资者
  *怎么想到的*：
  - 基金公司靠规模收管理费，理论上规模越大越赚钱
  - 但中小盘基金规模暴增后，"双十原则"限制买入单只股票上限
  - 大量现金涌入要么稀释收益，要么追高买入现有持仓
  - 限购是"控规模、保业绩"的理性选择
  *边界*：大盘价值基金（买入持有、换手率低）受规模影响较小，限购需求低；中小盘/量化基金规模是"致命毒药"。

* Q2: "双十原则"如何限制中小盘基金的规模？
  *结论*：单只股票持仓上限10%+同一股票全公司持仓上限10%，中小盘基金规模天花板远低于大盘基金。
  *形式化*：双十原则 = 单只股票≤10%净值 + 全公司≤10%市值 → 中小盘基金规模上限低
  *怎么想到的*：
  - 中小盘股票市值小，基金规模大很容易买到10%上限
  - 现有持仓买到上限后，只能找更多股票或买次优标的
  - 基金经理被迫买大盘股，投资风格"变味"
  - 案例：某基金从大盘成长逐渐飘向超大盘成长
  *边界*：大盘蓝筹股流动性好、市值大，"双十原则"约束较小；中小盘股流动性差、市值小，约束显著。

* Q3: 为什么说中小盘基金的规模是"致命毒药"？
  *结论*：规模增长破坏"灵活"策略优势，基金经理面临"拒绝规模保持风格"vs"拥抱规模调整策略"的两难。
  *形式化*：中小盘策略 = 灵活+高换手 → 规模↑ → 灵活性↓ → 策略失效
  *怎么想到的*：
  - 中小盘基金主打"灵活"，换手率偏高，挣交易的钱
  - 规模增长后，买入卖出需要更长时间，"船大难掉头"
  - 基金经理面临两选一：限购保风格，或扩规模调策略
  - 调整策略意味着能力圈拓展，之前挣超额的交易能力不再适用
  *边界*：量化基金通过模型优化可承接更大规模，但策略容量仍有上限；大盘价值基金规模影响较小。

* Q4: 基金限购的金额档位代表什么信号？
  *结论*：限购1000元以上主要限机构，限购10万元以上限大户，限购1万或1000元基本劝退散户。
  *形式化*：限购金额↓ → 信号越强 → 基金经理对后市越谨慎
  *怎么想到的*：
  - 限购1000万元以上：主要限制机构，对散户影响不大
  - 限购10万元以上：限制散户中的大户
  - 限购1万或1000元：基本劝退散户，说明基金经理认为"别再来了"
  - 基金经理宁愿不要奖金也不要你送钱，这是"风险警示"
  *边界*：限购不等于市场一定跌，只是基金经理认为当前规模已超策略容量；如果基金经理判断错误，限购反而错失机会。

* Q5: 晨星如何评价基金公司的"信托责任"？
  *结论*：看历史上是否在市场过热时主动限购，选择对投资者有利的业绩而非对基金公司有利的规模。
  *形式化*：信托责任 = 专业判断 + 投资者利益优先 → 市场热时限购 → 长期信任
  *怎么想到的*：
  - 限购在海外基金市场很常见，通过限购甚至关闭申购控制规模
  - 晨星评价基金公司时关注限购历史
  - 两方面：基金经理是否有自由度提出限购，公司是否支持限购
  - 2020年末如果更多基金能更早更严格限购，能"拯救"很多高位站岗的基民
  *边界*：限购是专业判断，但判断可能错误；长期看，愿意牺牲规模保业绩的公司更值得信任。

* 收口
基金限购不是"阻碍你挣钱"，而是基金经理发出的"风险警示"——宁愿不要规模也要保护现有持有人利益，这种行为是基金公司专业性和信托责任的体现，也是投资者应该珍惜的信号。
