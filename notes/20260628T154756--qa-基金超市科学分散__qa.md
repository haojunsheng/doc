* 引子

"不要把鸡蛋放一个篮子里"被用到投资里，变成了"基金超市"——买几十只基金以为分散了风险。但晨星研究发现：86%的投资者掉入"天真的分散"陷阱，持仓丰富多元但风险一点没降低。核心问题是：分散投资的关键不是数量，而是资产之间的"相关性"。

* Q1: 为什么"天真的分散"不能降低风险？

  *结论*：因为组合风险不取决于持仓数量，而取决于持仓之间的相关性——如果都同涨同跌，买100个也没用。

  *形式化*：组合风险 = f(相关性) ≠ f(数量)
  高相关性 + 多资产 = 没分散

  *怎么想到的*：
  - 马科维茨的现代投资组合理论：组合风险取决于不同持仓的相对变化趋势和幅度
  - 如果两个资产同涨同跌、涨跌幅相近，相关系数接近1，分散效果为零
  - 86%的投资者掉入天真分散陷阱——以为多买就能分散

  *边界*：天真分散在极端行情（如全市场普跌）时可能提供一定缓冲——但这是因为持仓里碰巧有低相关资产，不是因为"买得多"本身有效。

* Q2: 为什么买10只科技基金不等于分散？

  *结论*：因为科技细分赛道之间的相关系数高达0.8-0.9——本质上都是股票，且是同一行业的股票。

  *形式化*：科技基金 + 半导体基金 + AI基金 = 0.8-0.9相关性 ≈ 同一类资产
  类比：吃遍牛的不同部位 ≠ 改善饮食

  *怎么想到的*：
  - 医药、消费、金融、科技行业与沪深300相关系数大多在0.7以上
  - 科技细分赛道之间相关系数几乎都处于0.8-0.9
  - 底层核心资产都是股票，彼此间相关性天然更高

  *边界*：如果科技行业整体崩溃，这些基金确实会一起跌——但在行业正常运行时，细分赛道之间仍有微小差异，不是完全没分散。

* Q3: 真正有效的分散需要什么？

  *结论*：在不同大类资产之间配置——股票、债券、商品、不动产之间相关性长期保持低水平，四五只基金就能达到不错的分散效果。

  *形式化*：有效分散 = 低相关性大类资产（股、债、商品）
  低相关性 → 四五只基金 → 不错效果

  *怎么想到的*：
  - 不同大类资产之间的相关性长期保持较低水平
  - 在不同大类资产中各选一只代表性基金，四五只就够了
  - 股票类内部再细分行业的分散效果远不如跨大类资产

  *边界*：大类资产之间的低相关性是长期统计——危机时期所有资产可能同跌（如2020年3月的流动性危机），短期分散效果会消失。

* Q4: 持有多少个资产后分散效果开始递减？

  *结论*：5个以内时新增低相关性资产效果显著；超过10个后，再新增的边际效果非常有限。

  *形式化*：1-5个资产：新增低相关资产 → 波动↓↓
  10+个资产：新增低相关资产 → 波动↓（微弱）

  *怎么想到的*：
  - 新增资产与现有持仓相关性越低，降低波动效果越显著
  - 超过5个后，尤其是10个以上，边际效果变得非常有限
  - 持有过多还增加交易成本和管理负担

  *边界*：5个是经验数字——具体取决于这5个资产之间的相关性。如果5个资产相关性都高，增加到10个低相关资产仍然有效。

* Q5: 为什么"沪深300 + 少数行业卫星"比"各行业基金均分"更好？

  *结论*：因为各行业基金组合起来≈类宽基指数——与其自己拼凑，不如直接买宽基+精选卫星。

  *形式化*：各行业基金均分 ≈ 类宽基指数 → 分散效果≈宽基
  宽基 + 少数行业卫星 → 更精简 + 更低成本 + 同样分散

  *怎么想到的*：
  - 消费、科技、医药、金融各来一点，可能不知不觉搭出类宽基组合
  - 与宽基指数行业配置相差不大时，直接买宽基更省事
  - 精简持仓降低维护和交易成本

  *边界*：如果投资者对某些行业有深入研究并确信能跑赢，超配这些行业作为卫星持仓是合理的——但大多数人高估了自己的行业判断力。

* Q6: 构建组合的正确流程是什么？

  *结论*：五步——设目标、评资源、评风险、定大类配比、选代表性低成本品类。

  *形式化*：目标 → 资源 → 风险 → 大类配比 → 选品类

  *怎么想到的*：
  - 先有长期目标才能制定配置方案
  - 大类资产配置决定组合整体风险收益特征
  - 选品类时优先选高代表性、低成本的品类

  *边界*：这套流程适合有时间和精力做规划的投资者——如果连风险偏好都没概念，先用晨星风险测评了解自己。

* Q7: 已经开了"基金超市"的人怎么优化？

  *结论*：三步——摸清风险画像、梳理行业配比、精简高度重合持仓。

  *形式化*：优化三步：风险画像 → 行业配比 → 精简重合

  *怎么想到的*：
  - 先对比现有持仓与风险画像的匹配度，调整大类配置
  - 对比宽基指数看行业配置，如果差不多就直接用宽基替代
  - 排查持仓重叠度，75%以上重叠的基金只保留代表性更高、费率更低的

  *边界*：精简持仓可能涉及卖出已有浮亏的基金——从理性角度应该忽略沉没成本，但心理上很多人做不到。

* 收口

作者把分散投资从"买得多"提升到"买得对"——分散的效果不取决于数量而取决于相关性，跨大类资产的四五只基金远胜同一行业的几十只基金。
