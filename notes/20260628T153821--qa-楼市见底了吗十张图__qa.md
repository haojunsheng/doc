* 引子
2024年一季度新房销售同比降33%，购房者观望情绪仅13%看好房价回升。央行三箭齐发调利率、降首付、放宽公积金，本文从供需十张图判断楼市位置——需求端2024年见底，供应端2024年见顶。

* Q1: 需求端三个指标为何同时向下？
  *结论*: 房价下跌→信心崩塌→观望加重，形成需求萎缩的负反馈。
  *形式化*: 房价↓ → 信心↓ → 观望↑ → 需求↓ → 房价↓↓
  *怎么想到的*:
  - 一季度新房销售同比降33%，说明购买意愿极低
  - 仅13%受访者认为房价会回升，仅18%计划半年内买房
  - 房价下跌是观望情绪的原因而非结果
  - 政策虽密集但尚未扭转预期
  *边界*: 若政策力度超预期（如大规模收储、一线城市全面松绑），信心修复可能加速。

* Q2: 房贷利率降了为何仍救不了需求？
  *结论*: 利率降的是月供，收入预期不恢复，购房决策不会启动。
  *形式化*: 购房决策 = 月供负担 × 收入预期 → 利率↓ 但 收入预期↓↓ → 决策仍↓
  *怎么想到的*:
  - 五年期LPR从4.20%降至3.95%，降幅25bp
  - 取消全国首套二套利率下限
  - 但购房观望比例仍高达70%以上，说明问题不在利率
  - 房价下跌预期下，越降利率越觉得"明天更便宜"
  *边界*: 若经济企稳、就业改善，利率杠杆才会生效。

* Q3: 期房为何被现房挤出？
  *结论*: 交付不确定性打破了"买期房等交楼"的传统模式。
  *形式化*: 期房占比 78.9% → 69.3%，现房增速 >> 期房增速
  *怎么想到的*:
  - 2023Q1到期房占78.9%，2024Q1降至69.3%
  - 现房销售面积增速远超期房
  - 购房者规避烂尾风险，愿意为确定性付溢价
  - 预计未来几季度现房增速仍超期房
  *边界*: 若政府强化预售资金监管、恢复交付信用，期房偏好可能回升。

* Q4: 三线城市为何成房价跌幅重灾区？
  *结论*: 三线人口净流出+库存高+产业弱，供需失衡最严重。
  *形式化*: 三线 = 人口流出 + 库存高 + 就业弱 → 房价跌幅 >> 一二线
  *怎么想到的*:
  - 一二线相对坚挺抗跌
  - 三线同比跌幅最大
  - 三线去库存压力在销售低迷城市尤为显著
  *边界*: 若核心城市带动周边三线协同发展，三线跌幅可能收敛。

* Q5: 二手房为何"量涨价跌"？
  *结论*: 挂牌量持续增加压制价格，政策利好只带动成交不带动定价权。
  *形式化*: 挂牌量↑↑ → 供过于求 → 价格↓，政策↑ → 成交↑ 但 挂牌量仍↑
  *怎么想到的*:
  - 2023年9月起二手房销售受益于政策利好
  - 但挂牌量仍在不断增加
  - 大部分城市二手房供过于求
  - 一季度二手房价依旧疲软
  *边界*: 若挂牌量开始下降（房东惜售或退出），价格才有支撑。

* Q6: 住宅库存四万亿何时消化？
  *结论*: 需求回暖+收储+以旧换新三管齐下，库存2024年见顶。
  *形式化*: 待售住宅4万亿 → 去化手段(收储+以旧换新+租赁) → 2024年见顶
  *怎么想到的*:
  - 截至2024年3月底住宅待售接近4万亿
  - 政府和城投以收购、以旧换新、租赁介入去化
  - 现房偏好有利于消化存量
  - 预计2024年去库存压力见顶
  *边界*: 若新房开工不能有效控制，新增供应会抵消去库存成果。

* Q7: 新房供应为何主动收缩？
  *结论*: 土地储备缩减+销售回款慢，开发商无力也无意扩大开工。
  *形式化*: 销售↓ → 回款↓ → 拿地↓ → 新开工↓ → 供应收缩
  *怎么想到的*:
  - 2024Q1新开工住宅面积继续下滑
  - 住宅竣工面积同比负增长
  - 土地储备缩减+去库存压力双重制约
  - 预计全年新开工显著下降
  *边界*: 若政府大规模收储存量房、限制新增供地，供需关系改善可能加速。

* 收口
2024年中国楼市处于"需求见底、供应见顶"的底部区间，但见底不等于马上涨——信心修复和库存去化仍需时间。
