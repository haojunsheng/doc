* 引子
2026年4月是中国公募基金的"丰收月"。在地缘政治风险（美伊对峙）和政策利好（政治局会议、AI产业政策）的双重作用下，股债市场携手上行。上证指数涨5.67%，深证成指涨12.29%，中证全债指数涨0.57%。成长风格基金碾压价值风格，科技板块单月飙升20%+。这篇文章揭示了市场上涨的结构性特征和背后的驱动因素。

* Q1: 为什么4月能实现"股债双收"？
  *结论*：因为地缘风险降温+政策利好释放，同时利好股市（风险偏好修复）和债市（流动性宽松）。
  *形式化*：美伊停火协议 + 政治局会议释放积极信号 → 股市风险偏好修复 + 债市流动性宽松 → 股债双收
  *怎么想到的*：
  - 时间线：上旬美伊对峙→市场承压；达成停火→风险偏好修复→股市反弹
  - 中旬一季报披露+AI产业政策→科技股大涨
  - 下旬政治局会议定调"经济开局平稳向好"→市场信心进一步提振
  - 债市逻辑：资金面宽松+短端利率下行→长端跟随→债券普涨
  *边界*：如果地缘冲突升级或政策转向收紧，股债双收的格局会打破

* Q2: 为什么信用债收益率上行，而国债收益率下行？
  *结论*：因为国债受流动性宽松推动，信用债受经济回暖预期和信用利差走阔影响。
  *形式化*：国债：流动性宽松 → 需求增加 → 价格↑ → 收益率↓；信用债：经济回暖 → 信用利差预期↑ → 收益率↑
  *怎么想到的*：
  - 数据：1年期国债收益率下行6bp至1.16%，1年期AAA信用债上行23bp至1.81%
  - 国债逻辑：央行公开市场操作保持平稳，银行流动性充裕，机构买入国债
  - 信用债逻辑：经济回暖→企业违约风险下降→但投资者要求更高信用补偿→利差扩大
  - 另一个解释：首批特别国债发行→新券换老券行情→机构调整仓位→信用债承压
  *边界*：如果经济数据再次走弱或央行收紧流动性，国债收益率可能上行，信用债收益率反而可能下行

* Q3: 为什么"固收+"基金表现比纯债基金好？
  *结论*：因为可转债在4月暴涨6.13%，固收+基金通过配置可转债分享了权益市场上涨的红利。
  *形式化*：固收+ = 纯债 + 可转债（6.13%）+ 股票 → 收益增强 > 纯债（仅债券收益）
  *怎么想到的*：
  - 数据：可转债基金涨7.70%，积极债券基金涨1.84%，普通债券基金涨0.85%
  - 可转债特性：既有债券的保底，又有股票的弹性
  - 4月A股回暖→正股上涨→可转债跟涨→固收+受益
  - 纯债基金没有权益敞口，只能享受债券的微涨（0.57%）
  *边界*：如果股市大跌，可转债也会跟跌，固收+基金会跑输纯债基金

* Q4: 为什么QDII环球债券基金反而收跌？
  *结论*：因为海外债券（尤其是美债）在4月面临通胀预期升温+降息预期走弱的压力。
  *形式化*：通胀预期↑ + 美联储降息预期↓ → 美债收益率↑ → 美债价格↓ → QDII环球债券基金收跌
  *怎么想到的*：
  - 数据：78只环球债券基金中仅13只正收益，整体平均-0.45%
  - 海外背景：布伦特原油涨7.08%→通胀预期抬升→市场预期美联储不会降息→美债承压
  - 对比：国内债市流动性宽松，海外债市面临通胀压力，环境完全不同
  - 黄金下跌1.02%也印证了"降息预期走弱"的逻辑
  *边界*：如果美联储突然转向降息（如经济衰退），QDII环球债券基金会反弹

* Q5: 为什么成长风格碾压价值风格？
  *结论*：因为4月的市场主线是AI算力、半导体等科技成长板块，传统价值股（银行、交运）反而下跌。
  *形式化*：AI产业政策 + 一季报业绩催化 → 科技成长股大涨 → 成长风格碾压价值风格
  *怎么想到的*：
  - 数据：大盘成长基金涨14.31%，大盘价值基金仅涨1.89%
  - 行业表现：电子、通信涨超10%，银行、交运、食品饮料下跌
  - 驱动因素：数字经济与人工智能政策加码 + 设备更新政策 + 一季报超预期
  - 成长股对流动性更敏感，4月流动性宽松进一步推升估值
  *边界*：如果AI产业政策退潮或业绩证伪，成长风格会回调；如果经济复苏超预期，价值风格会补涨

* Q6: 为什么QDII亚太股票基金涨12.20%，而QDII美国股票基金涨11.15%？
  *结论*：因为亚太市场（尤其港股、日韩股市）在4月受益于地缘风险降温和估值修复，涨幅超过美股。
  *形式化*：亚太市场估值洼地 + 地缘降温 + 全球资金再配置 → 涨幅 > 美股（估值已高）
  *怎么想到的*：
  - 数据：日经225涨17.85%，恒生指数涨3.01%，标普500涨9.30%
  - 日本股市受益于日元贬值+企业治理改革+全球资金涌入
  - 港股虽然涨幅小，但亚太基金可能重仓日韩市场
  - 美股虽然涨，但估值已经偏高，上涨空间有限
  *边界*：如果日元大幅升值或地缘冲突再起，日本股市可能回调，亚太基金会受影响

* Q7: 从"短债基金0.21%、货币基金0.09%"能推断出什么？
  *结论*：4月收益率曲线陡峭化（短端利率下行更快），短端资产收益被压缩。
  *形式化*：收益率曲线陡峭化 → 短端利率↓ > 长端利率↓ → 短债收益 < 长债收益
  *怎么想到的*：
  - 文章提到"4月牛平行情下长端资产表现优于短端资产"
  - 牛平行情=收益率曲线陡峭化=短端利率下行更快
  - 短债基金主要投资1年期以内债券，利率下行=再投资收益降低
  - 货币基金更是只投资超短期工具，收益最低
  *边界*：如果收益率曲线平坦化（如加息预期），短债基金收益会改善

* 收口
晨星4月基金月报揭示了一个关键规律：市场上涨的结构比总量更重要——同样是"股债双收"，成长风格和固收+吃肉，价值风格和纯债基金喝汤；同样是QDII，亚太股票基金赚12%，环球债券基金亏0.45%。投资者需要看清结构，才能理解自己的钱从哪里来。
