* 引子

GMO联合创始人杰里米·格兰特姆因成功预测多个泡沫而被称为"泡沫预言家"。文章通过他的经历和观点揭示了泡沫的本质：狂热乐观主义、宏大叙事、以及"创新必然伴随泡沫"的规律。

* Q1: 为什么格兰特姆对"泡沫"有切身的认识？

  *结论*：因为他年轻时投资微盘股血本无归，从此成为坚定的价值投资者。

  *形式化*：泡沫初体验 = 微盘股炒作 + 血本无归；结果 = 价值投资信仰

  *怎么想到的*：
  - 商学院毕业后做管理咨询，觉得无聊
  - 发现投资领域同学都很开心，因为微盘股火热
  - 把几乎所有钱投入微盘股，最初股价快速上涨
  - 第二年微盘股迅速崩塌，血本无归

  *边界*：这次失败是好事，让他认识到了泡沫的本质，但代价很大。

* Q2: 为什么高市盈率往往预示着危机而不是繁荣？

  *结论*：因为高市盈率反映了过度乐观的预期，而预期往往落空。

  *形式化*：高市盈率 = 过度乐观 + 泡沫风险；历史 = 高市盈率 → 危机

  *怎么想到的*：
  - 格兰特姆回顾四个繁荣时期：20年代、70年代、90年代、2000年初
  - 这些时期市盈率都很高，投资情绪最高
  - 但紧随其后的是大萧条、经济衰退、互联网泡沫破裂、金融危机
  - 市场接下来发生的和传统金融学教的完全相反

  *边界*：高市盈率不一定立即崩盘，但长期回报率往往较低。

* Q3: 为什么"宏大叙事"是泡沫的温床？

  *结论*：因为跨时代的创新吸引过多资本，导致产能过剩和泡沫。

  *形式化*：宏大叙事 = 跨时代创新 + 过多资本 + 泡沫；规律 = 炒作 → 崩溃 → 重生

  *怎么想到的*：
  - 20年代：铁路、无线电、电话、汽车
  - 90年代：互联网改变一切
  - 创新越宏大，越容易在短期内获得过多关注
  - 泡沫和崩盘不可避免

  *边界*：泡沫和现实发生的社会进步不矛盾，长期这些创新确实改变了世界。

* Q4: 为什么最具潜力的赛道也会有泡沫？

  *结论*：因为即使是最真实的发展趋势，也可能在短期内被过度炒作。

  *形式化*：真实趋势 + 过度炒作 = 泡沫；例子：亚马逊跌92%

  *怎么想到的*：
  - 互联网确实改变了世界
  - 但1999年亚马逊在崩盘中股价下跌92%
  - 1999年的"明星"中80%已经不复存在
  - 最具潜力的赛道也难保不会有泡沫

  *边界*：长期来看，真正有竞争力的公司会存活并成长，但短期泡沫会让投资者损失惨重。

* Q5: 为什么"垄断"不是投资的万能钥匙？

  *结论*：因为政府监管可能打击垄断企业，而且垄断地位也可能被颠覆。

  *形式化*：垄断 = 高回报 + 护城河；风险 = 政府监管 + 技术颠覆

  *怎么想到的*：
  - 垄断企业有护城河，能获得高稳定回报
  - 过去十年涌现许多垄断企业，形成赢家通吃
  - 但政府逐渐从沉睡中醒来，开始打击垄断
  - 投资时不能忽视政府这只"看得见的大手"

  *边界*：监管打击不等于垄断消失，但可能影响垄断企业的盈利能力。

* 收口

宏大叙事是泡沫的温床。跨时代的创新吸引过多资本，导致泡沫和崩盘。但泡沫和现实进步不矛盾——创新在短期被过度炒作，中期崩溃，长期改变世界。投资时既要看到趋势，也要警惕泡沫。
