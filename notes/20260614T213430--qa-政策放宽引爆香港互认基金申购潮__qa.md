* 引子
2025年1月1日起，香港互认基金面向内地投资者的销售比例上限从50%放宽至80%。政策闸门一开，内地资金如潮水般涌入，一季度固收类基金被疯抢至暂停申购。但好景不长，4月美国关税风波来袭，资金流向急剧反转。全年走下来，港股互认基金最终全线净流入，但背后的资产偏好轮动却暗流涌动。

* Q1: 销售上限放宽为何能引爆年初抢购？
  *结论*：政策从50%提至80%，相当于给内地投资者打开了海外配置的闸门，压抑的多元化需求集中释放。
  *形式化*：销售上限50% → 80% = 内地投资者可申购额度↑60% + 海外配置需求释放 → 一季度抢购潮
  *怎么想到的*：
  - 政策直接效应：额度从50%提到80%，意味着每只基金能卖给内地投资者的量增加了60%
  - 需求侧动力：内地低利率环境下，投资者急需海外高收益资产来填补收益缺口
  - 时机叠加：年初配置需求旺盛，政策放开恰逢其时，形成共振效应
  *边界*：若海外市场同时大幅下跌，额度再宽也无人问津；若A股强劲反弹，资金可能留在本土

* Q2: 固收基金先扬后抑的资金转向说明了什么？
  *结论*：投资者从"求稳"转向"逐险"，A股企稳后资金从固收搬家到权益，说明境内权益市场的吸引力重新占上风。
  *形式化*：A股↓ → 固收↑（避险） → A股企稳↑ → 固收↓ + 权益↑（逐险）
  *怎么想到的*：
  - 一季度：A股低迷，内地投资者涌入海外固收寻求稳健收益
  - 二三季度：A股和亚洲股市企稳回升，风险偏好修复
  - 资金轮动：部分固收资金赎回，转向权益类资产，固收出现净流出
  *边界*：若A股反弹力度不足或持续时间短，资金可能回流固收；若海外利率大幅上行，固收吸引力会重新上升

* Q3: 为什么摩根国际债券能全年吸金130亿，而汇丰高收益债却净流出？
  *结论*：环球债分散风险能力强，亚洲高收益债集中度高且额度耗尽，"大而全"胜过"窄而锐"。
  *形式化*：环球债 = 全球分散 + 低相关 → 持续吸金 vs 亚洲高收益 = 集中度高 + 额度耗尽 → 净流出
  *怎么想到的*：
  - 产品差异：摩根国际债券是唯一环球债券型互认基金，汇丰两只产品聚焦亚洲高收益
  - 额度限制：汇丰两只产品内地销售额度耗尽，想买也买不到
  - 市场环境：高收益债对信用风险敏感，波动大，进取型产品在震荡市吸引力下降
  *边界*：若全球利率大幅下降，高收益债的票息优势会重新显现；若额度不限制，资金流入可能不同

* Q4: 摩根凭什么全年净流入226亿，稳坐基金公司头把交椅？
  *结论*：产品线全、明星基金多、品牌信任深，形成"产品矩阵+品牌溢价"的双重护城河。
  *形式化*：摩根 = 环球债（130亿）+ 亚洲股息（前三季吸金榜）+ 亚洲总收益债（80亿） → 226亿
  *怎么想到的*：
  - 全能选手：固收有摩根国际债券、摩根亚洲总收益，权益有摩根亚洲股息，覆盖多资产类别
  - 业绩支撑：多只产品回报领先同类，形成赚钱效应
  - 规模效应：规模越大，品牌越强，资金越愿意涌入，形成正循环
  *边界*：若核心基金经理离职或业绩大幅滑坡，规模优势可能迅速瓦解；若市场风格剧变，全线产品可能同时承压

* Q5: 权益基金上半年净流出、全年却净流入，这中间发生了什么？
  *结论*：市场情绪从"极度悲观"修复到"重新乐观"，资金从"逃离权益"转向"拥抱权益"，三四季度成为转折点。
  *形式化*：上半年A股低迷 → 权益净流出 → 三季度亚洲股票率先转正 → 四季度环球股票跟进 → 全年净流入
  *怎么想到的*：
  - 时间节点：上半年市场调整，投资者恐慌性赎回权益类互认基金
  - 转折动力：A股企稳回升，亚洲股市反弹，风险偏好修复
  - 资金回流：投资者重新发现权益资产价值，资金从固收和现金类回流权益
  *边界*：若市场在三季度再次大幅调整，资金可能永不回流权益；若债券收益率大幅上升，固收会重新分流资金

* Q6: 混合型基金中，瑞士百达吸金、施罗德净流出的差距在哪？
  *结论*：全球配置的灵活性战胜区域聚焦的局限性，"东方不亮西方亮"的策略在分化市场中更有效。
  *形式化*：瑞士百达 = 全球灵活配置（股债20-70%） vs 施罗德 = 亚洲市场聚焦 → 吸金王 vs 净流出王
  *怎么想到的*：
  - 配置范围：瑞士百达可投资全球各类资产，施罗德聚焦亚洲市场
  - 市场环境：2025年亚洲市场波动大，全球分散更能平滑波动
  - 业绩差异：灵活配置在震荡市中更容易做出超额收益
  *边界*：若亚洲市场进入强劲牛市，区域聚焦的产品可能反弹更猛；若全球市场齐跌，分散配置也难独善其身

* 收口
作者用2025年香港互认基金的资金流向数据，揭示了一个核心规律：政策闸门一开，资金会先涌向最安全的资产（固收），等风险偏好修复后再转向高收益资产（权益），而产品线的广度和深度决定了基金公司能否在这场资金迁徙中胜出。
