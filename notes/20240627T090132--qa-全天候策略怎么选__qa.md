* 引子

"全天候"是投资界穿越牛熊的梦想。文章梳理了三种经典全天候策略：达里欧的全天候、布朗的永久组合、现代版塔木德。它们思路相似——不预测环境，让组合在任何天气下都能活。但三者的风险收益特征差异很大，选哪个取决于你要"稳"还是"赚"。

* Q1: 达里欧的全天候策略核心逻辑是什么？

  *结论*：把经济分成四个象限（通胀/通缩 × 增长加速/减速），每个象限配置最受益的资产。

  *形式化*：经济四象限 → 每象限配最受益资产 → 全天候稳定回报

  *怎么想到的*：
  - 达里欧认为影响经济只有两个变量：增速和通胀
  - 两变量各有"超预期/低于预期"两种状态，组成四象限
  - 股票利好增长超预期，国债利好增长低于预期，黄金利好通胀超预期

  *边界*：假设四象限之间互相抵消，但如果出现滞胀（经济差+通胀高），所有资产都可能同时跌。

* Q2: 布朗的永久组合跟达里欧有什么本质区别？

  *结论*：布朗不预测环境，四类资产各25%永远不动；达里欧会调比例。

  *形式化*：布朗: 股25% + 债25% + 金25% + 现25% = 永远不变
           达里欧: 股30% + 债40% + 金15% + 商品... = 更偏保守

  *怎么想到的*：
  - 布朗强调"不预测、不偏好"，真正拥抱不确定性
  - 他提出组合三要素：安全性、稳定性、简单性
  - 达里欧虽然也声称被动，但55%债券比例透露了保守偏好

  *边界*：布朗的25%股票在长期牛市里会跑输大盘，太保守可能也是一种代价。

* Q3: 塔木德组合为什么收益更高但不太推荐普通人？

  *结论*：塔木德2/3仓位押风险资产，收益高但回撤也猛，2022年跌了23%。

  *形式化*：塔木德: 2/3风险资产 → 收益↑ 回撤↑
           达里欧/布朗: ~50%风险资产 → 收益↓ 回撤↓

  *怎么想到的*：
  - 塔木德建议：1/3土地+1/3商业+1/3备用，现代版约2/3股票类
  - 2022年最大回撤23%，2009年金融危机回撤高达40%
  - 达里欧和布朗同期回撤只有12-16%

  *边界*：如果你投资期限极长（20年+）且能承受40%回撤，塔木德长期收益更好。

* Q4: 全天候策略真的能"不预测"吗？

  *结论*：表面上不预测，但资产选择和比例分配本身就是一种预测。

  *形式化*：声称: 不预测 → 实际: 选哪些资产 + 配多少 = 隐性预测

  *怎么想到的*：
  - 达里欧选55%债券，隐含假设是债券在多数环境下能提供正回报
  - 如果未来长期处于高债负+低增长环境（如日本90年代），债券可能不灵
  - 布朗的25%等权也隐含假设四类资产长期都不归零

  *边界*：在利率长期下行+政府信用稳定的前提下，这个假设成立。

* Q5: 普通人应该选哪种全天候策略？

  *结论*：没有标准答案，取决于你能承受多大回撤和追求多高收益。

  *形式化*：选策略 = f(你能忍的回撤, 你追求的收益, 你的投资期限)

  *怎么想到的*：
  - 文章明确说"不存在完美的组合"
  - 达里欧/布朗适合求稳的人（最大回撤12-16%）
  - 塔木德适合能扛波动、看长期的人（最大回撤23-40%）

  *边界*：如果你连10%的回撤都睡不着，任何全天候策略都不适合，该去存定期。

* 收口

作者用三种策略的对比说明了一个朴素的道理：资产配置没有唯一标准答案，每种方案都是风险和收益的权衡，选哪个取决于你想睡得好还是赚得多。
