* 引子
基金规模增长超出策略容量会导致交易冲击成本上升、持股被迫偏大盘、换手率下降、流动性恶化。晨星以广发创新升级基金为例，展示了规模从13亿涨到146亿过程中，基金经理被迫放弃中盘股、换手率从372%降到103%、流动性显著恶化，最终在小盘股行情中排名垫底。

* Q1: 什么是基金的策略容量？
  *结论*: 基金经理在不损害超额收益的前提下能管理的最大资金规模，超出后被迫偏离策略。
  *形式化*: 策略容量 = 超额收益可持续的最大规模 → 超出 → 策略变形 → 超额消失
  *怎么想到的*:
  - 规模增长初期有规模效应好处
  - 但超出管理能力后交易冲击成本、流动性限制等问题出现
  - 基金经理被迫改变策略，超额收益能力受损
  *边界*: 策略容量不是固定值，会随市场流动性变化而演变。

* Q2: 规模增长对基金有哪三大冲击？
  *结论*: 交易冲击成本上升、投资流程效率下降、小市值公司买不到理想仓位。
  *形式化*: 规模↑ → 交易冲击成本↑ + 流程效率↓ + 小票买不够 → 超额收益↓
  *怎么想到的*:
  - 大单交易会影响股价，产生冲击成本
  - 买卖耗时变长影响投资效率
  - 小市值或流动性差的公司无法买到目标仓位
  *边界*: 在流动性极度宽松的市场中，冲击成本会暂时降低。

* Q3: 广发创新升级基金规模从13亿涨到146亿发生了什么变化？
  *结论*: 换手率从372%降到103%，中盘股占比从35%降到12%，平均流通市值从313亿涨到1056亿。
  *形式化*: 规模13亿→146亿 → 换手率372%→103% + 中盘股35%→12% + 市值313→1056亿
  *怎么想到的*:
  - 2019-2020年基金年化回报93.31%，吸引大量申购
  - 基金经理被迫从自下而上选股转向中观+自下而上结合
  - 中盘股选股超额收益犹在，但低配中盘导致2021-2023年排名95%
  *边界*: 这是单只基金案例，不同基金经理应对规模扩张的能力不同。

* Q4: 为什么规模大了就买不了中盘股？
  *结论*: 中盘股流动性有限，大资金买卖冲击成本高，基金经理被迫转向超大盘股。
  *形式化*: 中盘股流动性 ⊂ 规模冲击 → 买不够目标仓位 → 被迫买超大盘
  *怎么想到的*:
  - 基金增持隆基绿能、药明康德等超大盘股替代中盘
  - 超大盘占比从19%升到29%，中盘从35%降到12%
  - 平均流通市值增长237%，远超基准的207%
  *边界*: 若中盘股流动性整体改善（如市场活跃度提升），限制会减弱。

* Q5: 基金限购了为什么规模还在涨？
  *结论*: 限购分1万/10万/100万三档，2020年Q1仍吸纳35亿净现金流，叠加净值增长规模涨了73%。
  *形式化*: 限购 ≠ 暂停申购 → 35亿净申购 + 净值增长 → 规模仍涨73%
  *怎么想到的*:
  - 基金公司采取限购措施控制规模值得肯定
  - 但限购只是限制了新申购，净申购仍可观
  - 净值增长本身也会推升规模
  *边界*: 若基金公司完全暂停申购，规模增长只来自净值增长。

* Q6: 怎么判断一只基金是否超出了策略容量？
  *结论*: 综合看平均流通市值、换手率、组合流动性在规模增长时是否发生异常变化。
  *形式化*: 规模增长时 → 观察{平均流通市值, 换手率, 流动性}是否异常偏离 → 判断是否超限
  *怎么想到的*:
  - 单一数据点难以精确判断，需综合多个指标
  - 平均流通市值异常增长说明被迫买大盘
  - 换手率大幅下降说明短期机会捕捉能力丧失
  - 变现天数增加说明组合流动性恶化
  *边界*: 策略容量判断是动态的，需要结合当时市场环境分析。

* Q7: 基金公司控制规模有哪些手段？
  *结论*: 限购（分档限制申购金额）和暂停申购是最直接的手段，晨星更青睐严格规模监控的基金公司。
  *形式化*: 规模监控 → 限购(分档) → 暂停申购 → 保护策略容量
  *怎么想到的*:
  - 广发创新升级曾采取1万/10万/100万三档限购
  - 晨星认为基金公司应在流动性问题初露端倪时就采取行动
  - 严格的规模监控流程是基金基本面的加分项
  *边界*: 基金公司有做大规模的商业动机，不是所有公司都会主动限购。

* 收口
晨星用广发创新升级的完整案例揭示了一条因果链：业绩好→资金涌入→规模超限→策略变形→超额消失——这就是"规模诅咒"。
