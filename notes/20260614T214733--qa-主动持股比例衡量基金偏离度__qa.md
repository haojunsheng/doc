* 引子
监管在2025年10月底发布基金业绩比较基准征求意见稿，要求主动基金对标基准，通过清晰的偏离逻辑创造可持续超额收益。在这个背景下，主动持股比例（Active Share）这个指标进入了大众视野——它衡量的是基金持仓与基准指数之间的偏离程度，是观察基金"主动程度"的量化工具。

* Q1: 主动持股比例是怎么算出来的？
  *结论*：通过对比基金持仓与基准指数成分股的差异来计算——包括对基准内证券赋予不同权重、剔除基准内部分证券、纳入基准外证券三个方面。
  *形式化*：主动持股比例 = Σ|基金权重 - 基准权重| ÷ 2 → 100%表示完全偏离，0%表示完全复制
  *怎么想到的*：
  - 计算逻辑：对比基金持仓与基准指数成分股的权重差异
  - 三个来源：对基准内证券赋予不同权重、剔除基准内部分证券、纳入基准外证券
  - 极端情况：100%表示持仓与基准无任何重合，0%表示持仓与基准完全一致（如ETF）
  *边界*：若基准选择不当（如成长型基金选择价值型指数），主动持股比例会虚高，无法真实反映偏离情况

* Q2: 为什么国内主动偏股基金的主动持股比例普遍很高？
  *结论*：三个原因——风格偏好中小盘（低配大盘）、行业超配（电力设备、食品饮料、电子）、个股集中（追求弹性）。
  *形式化*：高主动持股比例 = 中小盘风格偏好 + 行业超配 + 个股集中 → 89.82%平均值
  *怎么想到的*：
  - 风格偏好：大部分主动基金经理更偏好中小盘风格，明显低配大盘风格
  - 行业超配：过去市场环境使基金经理超配电力设备、食品饮料和电子，低配银行和非银金融
  - 个股集中：为追求组合弹性，很多基金持仓集中在少数股票上
  - 数据验证：截至2025年6月底，主动持股比例平均值89.82%，中位数91.73%，80%以上占87%，90%以上占59%
  *边界*：若市场风格从"中小盘"转向"大盘"，高主动持股比例可能变成劣势；若基金经理能力不足，高主动只是"盲目主动"

* Q3: 为什么中小盘基金的主动持股比例普遍高于大盘股基金？
  *结论*：大盘指数权重集中于大市值龙头，留给主动管理的可操作空间有限；中小盘股票数量庞大，具备超额收益潜力的标的覆盖面更广。
  *形式化*：中小盘基金 = 股票数量多 + 超额收益潜力大 → 主动持股比例高 vs 大盘股基金 = 龙头集中 + 操作空间有限 → 主动持股比例低
  *怎么想到的*：
  - 大盘指数特征：沪深300权重集中于大市值龙头，龙头股表现往往强于指数整体
  - 中小盘优势：中小盘股票数量庞大，基金经理易通过精选个股与基准形成差异化
  - 数据验证：中小盘基金的主动持股比例普遍高于大盘股基金
  *边界*：若大盘股进入长期牛市，大盘股基金可能更占优；若中小盘股流动性不足，高主动持股比例可能带来冲击成本

* Q4: 为什么成长风格基金的主动持股比例高于平衡风格基金？
  *结论*：平衡风格"兼顾价值与成长"的定位决定了持仓与宽基基准重合度更高，成长风格则更偏向特定板块，与基准差异更大。
  *形式化*：成长风格 = 偏向特定板块 → 与基准差异大 → 主动持股比例高 vs 平衡风格 = 兼顾价值与成长 → 与基准重合度高 → 主动持股比例低
  *怎么想到的*：
  - 投资策略：平衡风格基金"兼顾价值与成长"，持仓与宽基基准重合度更高
  - 风格特征：成长风格更偏向特定板块（如科技、新能源），与基准差异更大
  - 数据验证：成长风格基金的主动持股比例高于平衡风格基金
  *边界*：若市场风格从"成长"转向"价值"，成长风格基金的主动持股比例可能变成劣势；若平衡风格基金的行业配置更分散，风险可能更低

* Q5: 为什么两只基金官方基准相同，主动持股比例却差异巨大？
  *结论*：投资策略的差异（均衡vs集中）会导致主动持股比例显著不同——东方岳均衡配置（单一行业<20%）主动比例70%，万家宏观择时（单一行业>70%）主动比例近100%。
  *形式化*：东方岳 = 均衡配置（单一行业<20%） → 主动比例70% vs 万家宏观 = 集中配置（单一行业>70%） → 主动比例近100%
  *怎么想到的*：
  - 东方岳策略：相对均衡的组合构建，单一行业占比控制在20%以内，对银行、非银金融保持中性配置，前十大重仓股占比25%
  - 万家宏观策略：更为集中的策略，历史单一行业占比均在70%以上且大幅轮换，前十大重仓股占比80%
  - 策略差异：即使官方基准相同，投资策略的差异也会导致主动持股比例显著不同
  *边界*：若市场风格从"行业轮动"转向"个股分化"，集中配置的超额收益会下降；若市场波动加大，高主动持股比例会放大风险

* Q6: 主动持股比例有哪些局限性？
  *结论*：高主动不代表能力强、对业绩预测性有限、依赖于基准选择——不能只看这一个指标。
  *形式化*：主动持股比例 = 描述性工具 ≠ 业绩预测工具 → 需结合其他指标综合判断
  *怎么想到的*：
  - 不代表能力：基金可通过增加基准外个股持仓提升主动持股比例，但如果基金经理能力不足，只是"盲目主动"
  - 预测性有限：晨星对美国市场的研究发现，主动持股比例对业绩的预测作用受市场环境影响极大
  - 依赖基准：若基准选择不当，主动持股比例会虚高，无法真实反映偏离情况
  *边界*：需结合风险调整后收益、跟踪误差、投资风格箱、费率水平等其他指标，以及投研团队经验、投资流程稳定性等定性因素综合判断

* 收口
作者通过主动持股比例这个指标，揭示了国内主动偏股基金的"主动程度"——平均89.82%的主动持股比例说明大部分基金确实在"主动管理"，但高主动不等于高业绩，投资者需要结合基金经理能力、投资策略、市场环境等因素综合判断，而非单纯追求"高主动"或"低主动"。
