* 引子

晨星2025年四季度市场观察报告，面对的全球背景是：多国股市创近20年新高、美国高科技投资占GDP比重超过互联网泡沫峰值、美元结束十年强势周期。核心问题是：这轮上涨是繁荣延续还是泡沫前奏。作者用"估值隐含回报"（VIR）作为标尺，发现发达市场尤其是美国的长期回报空间已被大幅压缩，新兴市场反而更具吸引力。

* Q1: 估值隐含回报（VIR）怎么判断一个市场还值不值得买？

  *结论*：VIR拆解资产收益来源来估算长期预期回报——发达市场VIR下降说明未来回报被提前透支。

  *形式化*：`VIR高 = 长期回报空间大 → 值得配 | VIR低 = 回报被透支 → 谨慎`

  *怎么想到的*：
  - 晨星将不同资产的收益来源拆解分析
  - 据此估算该类资产未来的长期预期回报水平
  - 过去两年发达市场"拔估值"行情透支了未来回报
  - 美国VIR显著下降，新兴市场下降幅度最小

  *边界*：VIR基于当前估值和盈利预期，如果盈利增长超预期，VIR会回升。

* Q2: 为什么美国大盘股估值远超小盘股，这说明了什么？

  *结论*：AI追捧导致美国大盘股估值畸形偏高，高科技投资占GDP已超过互联网泡沫峰值。

  *形式化*：`AI追捧 → 大盘股估值↑↑ > 小盘股 | 高科技投资/GDP > 互联网泡沫峰值 → 过热信号`

  *怎么想到的*：
  - 投资者对AI相关大型科技股的追捧是主因
  - AI可能提升生产率，但目前增长主要来自投资热潮和财富效应
  - 美国高科技投资占GDP比重已超过当年互联网泡沫峰值
  - 大盘股估值偏高使全球其他市场显得更有"性价比"

  *边界*：如果AI确实带来生产力革命，当前估值可能被事后证明合理。

* Q3: 为什么新兴市场反而更具长期吸引力？

  *结论*：新兴市场过去12个月表现更好、VIR更高，得益于增长预期改善和美元走弱带来的汇兑回报。

  *形式化*：`新兴市场: 表现优 + VIR高 + 增长预期改善 + 美元走弱汇兑回报 → 吸引力>发达市场`

  *怎么想到的*：
  - 新兴市场过去12个月表现优于发达市场
  - 长期估值隐含回报保持在相对高位
  - 增长预期改善 + 美元走弱带来的汇兑回报提升
  - 与三年前相比，新兴市场VIR下降幅度最小

  *边界*：新兴市场波动更大、政治风险更高，不适合所有投资者。

* Q4: 美联储降息了，为什么长期债券仍有风险？

  *结论*：短端利率因降息下滑，但长端利率维持高位——投资者要求更高期限溢价补偿风险。

  *形式化*：`降息 → 短端利率↓ | 长端利率: 供需+情绪+财政风险 → 仍高位 → 长期债券可能缩水`

  *怎么想到的*：
  - 美联储9月正式启动降息
  - 短端利率因降息显著下滑
  - 长端利率依然维持高位，反映投资者要求更高期限溢价
  - 若经济实现软着陆，长期美债仍可能面临价值缩水

  *边界*：如果经济衰退，长期美债会因避险需求而上涨。

* Q5: 美元走弱为什么能提升非美资产回报？

  *结论*：美元贬值让非美资产在换算回美元时获得额外汇兑收益，瑞典克朗和巴西雷亚尔资产表现突出。

  *形式化*：`美元走弱 → 非美资产汇兑收益↑ → 美元计价回报 = 资产回报 + 汇率收益`

  *怎么想到的*：
  - 2025年以来美元持续走低，与十年强势周期形成对比
  - 汇率波动扩大了不同市场资产回报差异
  - 对美国投资者而言，美元贬值显著提升非美资产回报
  - 瑞典克朗和巴西雷亚尔计价的资产表现最突出

  *边界*：如果美元反转走强，汇兑收益会变成汇兑损失。

* Q6: 中国在高关税环境下为什么仍能展现经济韧性？

  *结论*：净出口对GDP贡献依然可观，出口企业拓展非美市场并借助转口贸易绕开关税壁垒。

  *形式化*：`高关税 → 中国: 拓展非美市场 + 转口贸易 → 净出口贡献可观 → 抵消房地产下行`

  *怎么想到的*：
  - 美国平均关税率升至约15%，为上世纪30年代以来最高
  - 中国净出口对实际GDP增长贡献依然可观
  - 出口企业积极拓展非美市场缓解关税冲击
  - 部分中国产品通过东亚国家转口贸易绕开关税壁垒

  *边界*：如果关税继续加码或转口贸易被堵，韧性会受考验。

* Q7: 面对"高处不胜寒"的全球市场，投资者应该怎么做？

  *结论*：回归长期视角——关注VIR更高的新兴市场、管理美元敞口、警惕长期债券风险。

  *形式化*：`应对: 看VIR(新兴市场>发达) + 管理美元敞口(对冲或分散) + 警惕长债风险`

  *怎么想到的*：
  - 发达市场VIR显著下降，美国回报空间被压缩
  - 新兴市场VIR保持高位，更具长期吸引力
  - 美元走弱是配置非美资产的窗口期
  - 降息利好短期债券但长期债券仍有风险
  - 整体波动与分化将成为新常态

  *边界*：如果全球经济超预期复苏，发达市场的上涨空间可能被重新打开。

* 收口

作者贡献了一个"估值隐含回报"的分析框架：用VIR判断各市场长期吸引力，发现发达市场尤其是美国已被AI追捧透支，新兴市场反而更具性价比——高处不胜寒时，需要从被忽略的地方找机会。
