* 引子
2026年3月是全球资本市场的"压力测试月"。中东地缘冲突推高油价41%，全球股市集体下挫，A股沪指从高位跌至3800点附近。但债券市场在避险情绪支撑下表现分化——短端利率下行，长端利率上行。这篇文章揭示了一个关键规律：在地缘冲击下，"股债跷跷板效应"和"风格轮动"同时发生，大盘价值风格成为避风港。

* Q1: 为什么油价暴涨41%会导致全球股市下跌？
  *结论*：因为油价暴涨推升通胀预期，市场担心企业成本上升+央行加息，盈利预期和估值双杀。
  *形式化*：油价↑41% → 通胀预期↑ → 企业成本↑ + 央行加息预期↑ → 盈利↓ + 估值↓ → 股市↓
  *怎么想到的*：
  - 油价是生产成本的重要组成部分，油价暴涨=企业成本上升
  - 通胀预期上升=市场预期央行会加息抑制通胀
  - 加息=企业融资成本上升+股票估值折现率上升=股价下跌
  - 数据：布伦特原油涨41.42%，全球主要股指均收跌（日经225跌13.62%）
  *边界*：如果地缘冲突缓解导致油价暴跌，股市会迎来反弹

* Q2: 为什么"大盘价值风格"在3月表现最好？
  *结论*：因为价值股（如银行、公用事业）盈利稳定、估值低，在地缘冲击下成为避险资金的避风港。
  *形式化*：地缘冲击 → 风险偏好↓ → 资金从成长股（高估值、高波动）流向价值股（低估值、稳定）→ 大盘价值风格占优
  *怎么想到的*：
  - 数据：大盘价值基金跌2.85%，中盘成长基金跌11.79%，差距巨大
  - 行业表现：银行、公用事业、煤炭上涨，有色、军工、传媒跌超15%
  - 逻辑：价值股盈利来自当前业务（如银行贷款、电力销售），不依赖未来增长预期
  - 成长股依赖未来增长，在地缘冲击下不确定性增加，被抛售
  *边界*：如果地缘风险缓解+市场风险偏好回升，成长风格会重新占优

* Q3: 为什么"固收+"基金在3月反而下跌？
  *结论*：因为固收+基金配置了股票和可转债，3月A股和可转债大跌拖累了净值。
  *形式化*：固收+ = 纯债 + 股票/可转债 → 3月A股↓ + 可转债↓7.41% → 固收+净值↓
  *怎么想到的*：
  - 数据：可转债基金跌8.35%，积极债券基金跌1.70%，普通债券基金跌0.39%
  - 纯债基金涨0.27%，说明债券部分没问题
  - 问题出在权益敞口：中证转债跌7.41%（受A股拖累）
  - 结论：固收+的"+"在股市上涨时是增项，在下跌时是减项
  *边界*：如果股市企稳反弹，固收+基金会重新跑赢纯债基金

* Q4: 为什么"短端利率下行，长端利率上行"？
  *结论*：因为短端受央行流动性呵护（避险资金涌入），长端受通胀预期压制（担心未来加息）。
  *形式化*：短端利率↓（央行宽松 + 避险资金）≠ 长端利率↑（通胀预期 + 加息预期）→ 收益率曲线陡峭化
  *怎么想到的*：
  - 数据：1年期国债收益率下行10bp至1.22%，10年期上行4bp至1.82%
  - 短端逻辑：地缘冲击→避险资金涌入短债→需求增加→价格↑→收益率↓
  - 长端逻辑：油价暴涨→通胀预期↑→市场预期未来加息→长债被抛售→价格↓→收益率↑
  - 结果：收益率曲线陡峭化（短端更平，长端更陡）
  *边界*：如果央行明确释放宽松信号（如降准），长端利率也会下行

* Q5: 为什么"医药基金"在3月表现最好？
  *结论*：因为医药板块在地缘冲击中属于"防御性行业"，需求刚性、受油价影响小。
  *形式化*：医药行业 = 需求刚性 + 与油价弱相关 → 地缘冲击中跌幅小 → 医药基金表现好
  *怎么想到的*：
  - 数据：行业混合-医药基金跌0.91%，行业股票-医药基金跌2.44%，是所有行业基金中跌幅最小的
  - 对比：科技基金跌10%+，传媒基金跌15%+
  - 逻辑：医药是"刚需"，无论地缘冲突如何，人们都要看病吃药
  - 科技、传媒等板块依赖全球供应链和消费信心，受地缘冲击影响大
  *边界*：如果地缘冲突缓解+市场反弹，医药基金会跑输科技基金

* Q6: 为什么"QDII商品基金"能逆势上涨8.44%？
  *结论*：因为商品基金主要投资原油和黄金等大宗商品，油价暴涨直接推升了净值。
  *形式化*：商品基金 = 原油 + 黄金 + 其他商品 → 油价↑41% → 商品基金↑8.44%
  *怎么想到的*：
  - 背景：布伦特原油涨41.42%，是3月最大的宏观事件
  - 商品基金通常配置能源、贵金属、农产品等
  - 油价暴涨=能源类资产升值=商品基金受益
  - 对比：黄金反而跌11.54%（因为美联储偏鹰，加息预期压制黄金）
  - 说明：商品基金的收益结构复杂，不是所有商品都涨
  *边界*：如果油价暴跌（如地缘缓解），商品基金会回调

* Q7: 从"沪指跌至3800点附近"能推断出什么？
  *结论*：说明3月的地缘冲击是"短期情绪冲击"而非"趋势性下跌"，市场在3800点附近找到了支撑。
  *形式化*：沪指从高位跌至3800点 → 跌幅可控 + 有支撑 → 短期冲击而非趋势反转
  *怎么想到的*：
  - 背景：3月初沪指在更高位置，月底跌至3800点
  - 跌幅：上证指数跌6.51%，深证成指跌7.01%
  - 但PMI重返扩张区间（50.4%），经济基本面没有恶化
  - 两会释放稳增长信号，政策面有支撑
  - 结论：下跌主要来自地缘冲击和情绪面，不是经济基本面恶化
  *边界*：如果地缘冲突进一步升级（如霍尔木兹海峡封锁），3800点可能被击穿

* 收口
晨星3月基金月报揭示了一个关键规律：地缘冲击下的市场反应是有"结构"的——资金从成长股流向价值股，从中小盘流向大盘，从股市流向短债，这种"避险迁移"不是恐慌，而是投资者在重新定价风险。理解这个结构，才能理解自己的钱在经历什么。
