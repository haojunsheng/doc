* 引子

这是一篇用虚构角色"小韭"讲述的投资避坑故事。虽然文章本身是叙事形式，但它浓缩了新手投资者最常犯的错误：追涨杀跌、盲目跟风、不设止损、频繁换仓。每一个"小韭"踩过的坑，都是真实投资者交过的学费。

* Q1: 新手最容易犯的第一个错误是什么？

  *结论*：追涨杀跌——在别人乐观时买入，在别人恐慌时卖出，正好做反了。

  *形式化*：新手行为：涨 → 买，跌 → 卖；正确行为：跌 → 买，涨 → 卖

  *怎么想到的*：
  - 塞勒斯列的 7 个成功特质第一条就是"在他人恐慌时果断买入、在他人乐观时卖掉"
  - 新手往往相反：看到别人赚钱就追进去，看到下跌就慌忙卖出
  - 这种行为本质是"顺势而为"，但在投资里往往是错的

  *边界*：如果是趋势跟踪策略（如动量策略），追涨杀跌可能有效。但对普通投资者，这通常是亏损的根源。

* Q2: 为什么"听消息买股票"是个危险策略？

  *结论*：因为你听到的消息已经是"二手信息"——知道的人太多，价格已经反映了。

  *形式化*：消息传播：内幕 → 机构 → 散户；价格反应：早已发生 → 你进场时已是尾声

  *怎么想到的*：
  - 有效市场假说认为价格已经反映了所有公开信息
  - 当你听到"好消息"时，价格可能已经涨过了
  - 听消息买股票本质是"基于公开信息做决策"，在半强式有效市场中很难赚钱

  *边界*：在极度无效的市场（如某些小盘股、新兴市场），信息不对称可能更严重，散户有机会挖掘未被充分反映的信息。

* Q3: 为什么频繁换仓会吃掉你的收益？

  *结论*：因为每次交易都有成本，而成本会复利侵蚀你的长期收益。

  *形式化*：频繁交易 → 交易成本 ↑ → 净收益 ↓；持有不动 → 成本最低 → 复利最大

  *怎么想到的*：
  - 交易成本包括佣金、印花税、买卖价差等
  - 每次交易都会吃掉一部分收益，长期累积下来非常可观
  - 更重要的是，频繁换仓意味着你在"择时"——而大多数人的择时是错误的

  *边界*：如果市场发生根本性变化（如行业长期衰退），不换仓反而会承受更大损失。关键是区分"短期波动"和"长期趋势"。

* Q4: 新手应该怎么设置止损？

  *结论*：止损不是"跌了就卖"，而是"跌破了预设的关键位置再卖"——纪律比情绪重要。

  *形式化*：止损 = 预设规则触发 → 执行；情绪 = 恐惧驱动 → 乱卖

  *怎么想到的*：
  - 止损的核心是"提前设定规则"，而不是"跌了再决定"
  - 没有止损的人往往在最低点割肉，因为恐惧让他们无法承受更大的损失
  - 有止损的人可能在"错误的位置"出场，但至少不会遭受毁灭性打击

  *边界*：止损的前提是你买入时的逻辑被证伪了。如果只是因为短期波动就触发止损，可能会错过长期恢复。

* Q5: 为什么"分散投资"是新手最好的保护？

  *结论*：因为分散投资能避免"一把亏光"——即使某只股票跌 50%，你的整体组合也不会崩盘。

  *形式化*：集中投资 = 1 只股票跌 50% → 组合跌 50%；分散 = 1 只跌 50% → 组合跌 5%

  *怎么想到的*：
  - 新手往往重仓一两只"看好的股票"，一旦判断错误就损失惨重
  - 分散投资的核心是"不要把所有鸡蛋放在一个篮子里"
  - 指数基金本质就是分散投资的极致——持有整个市场，避免个股风险

  *边界*：过度分散也会稀释收益。如果你有能力研究个股，适度集中可能获得更高回报。但对新手来说，分散更安全。

* 收口

"小韭"的故事告诉我们：投资最大的敌人不是市场，是自己的情绪和偏见。避免追涨杀跌、不听消息、不频繁交易、设好止损、做好分散——这五条是新手最该刻在脑子里的纪律。
