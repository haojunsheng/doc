# 即时零售行业分析

> 分析日期：2026-07-12 | 框架：生命周期 × 五维矩阵

---

## 一、行业定义与颗粒度

### 1.1 边界

**即时零售** = 本地实体供给 + 即时配送网络，履约时效 30 分钟至 2 小时的零售形态。

三条边界把它和邻居分开：
- **vs 传统电商 1-3 天**：时效 ≤ 2h + 专人直送，非快递物流
- **vs 社区团购次日达**：即时履约，非集单拼团
- **vs 餐饮外卖**：品类从"吃喝"扩展到生鲜/日百/医药/3C 等万物到家

### 1.2 分类口径

| 标准 | 映射 |
|:---|:---|
| 国标 GB/T 4754-2017 | 无独立类目，横跨 F521/F522/F525 |
| 申万 | 无独立行业 |
| GICS | Consumer Staples Discretionary 下特定 niche |
| **本报告用口径** | 按履约模式分三大类（见下） |

### 1.3 三种履约模式 = 本报告颗粒度

```
即时零售
 ├─ 平台模式（Platform）        美团闪电仓、京东到家、饿了么、抖音小时达
 │    轻资产：连本地商家 + 配送网，不持有库存
 ├─ 自营前置仓（Front Warehouse） 叮咚买菜、朴朴超市、美团买菜/小象超市
 │    重资产：自建前置仓 + 自采自销 + 即时配送
 └─ 混合（Platform + 配送）      早期闪购：商家上线、导流、骑手配送
```

> 本报告以**即时零售整体行业**为对象，但区分平台 vs 自营两种不同经济特性——UE 模型和护城河本质不同，不可混同分析。

## 二、生命周期定位

### 2.1 渗透率判据 → **成长期（过渡态）**

渗透率是判据，但口径不一，需三口径交叉看：

| 口径 | 公式 | 当前估算 | 对应阶段 |
|:---|:---|:---|:---|
| 社零口径 | GMV ÷ 社会消费品零售总额 | ≈ **2-5%** | → 导入期末/成长初期 |
| 网上零售口径 | GMV ÷ 网上零售总额 | ≈ **8-12%** | → 成长期 |
| 本地生活口径 | GMV ÷ 本地生活总盘子 | ≈ **10-15%** | → 成长期中后段 |

**本报告取**：成长期中后段（渗透率约 **15-20%**，按"可渗透本地供给池"口径）。

### 2.2 过渡态含义——三维度并重

> 成长期末期 (~30-35%) 行业罕见单一维度主导，规模性、防守性、盈利性需**同等深度展开**：市场增速仍高但边界收窄、格局走向高度集中、利润拐点已出现。

过渡态证据：
- 增速从 2021 +50% 回落到 2025 +20-25%（但仍高于社零 ~5% 和网上零售 ~10%）
- 新玩家仍涌入（抖音、京东）但存量玩家已开始盈利（美团闪购 2024 年城市层面主营利润正值、叮咚 2024 全年非 GAAP 持续为正）
- 部分玩家退出/收缩（每日优鲜破产、叮咚退出多城）→ 产能出清开始

## 三、按阶段核心分析（过渡态：三重点并重）

### 3.1 可行性——**已验证** ✅

即时零售的导入期已过，关键是确认"跑通"了两件事：

#### 销售可行性（需求真伪）

| 对标类型 | 结论 | 论据 |
|:---|:---|:---|
| 时间对标 | ✅ 需求永恒 | "快速搞定一顿/应急购物"自古存在——干粮→方便面→外卖→即时零售，方案升级，需求不变 |
| 空间对标 | ✅ 成熟市场有参照 | DoorDash（美国 ~67% 市占+盈利）、Coupang Eats、iFood 均已跑通 |
| 频次×弹性 | 🟡 品类分化 | 生鲜/日百：高频+低弹性=最佳；数码/鲜花：低频+高弹性=靠节庆脉冲 |

#### 利润可行性（UE 模型）

```
单均利润 = 客单价 × 毛利率 − 履约 − 获客分摊 − 平台运营费

2024E 参考值：
  客单价：45-60 元（叮咚 ~57，美团闪购 ~55-65）
  毛利率：自营 20-30% / 平台抽佣 3-8%
  履约：5-10 元/单（客单价 10-18%）
  UE 状态：平台模式接近转正；自营前置仓（叮咚）已全年非 GAAP 盈利
```

**结论**：不是伪需求，UE 跑得通但**利润薄**——赚钱靠规模和效率，不靠溢价。

---

### 3.2 规模性——**成长核心** ✅✅✅

#### TAM / SAM / SOM 三层框

```
┌────────────────────────────────────────────────┐
│  TAM：本地零售全量（社零）≈ 40-45 万亿 CNY       │
│  ┌────────────────────────────────────────┐    │
│  │  SAM：适合即时的品类（生鲜+日百+医药+快消）│    │
│  │        ≈ 10-15 万亿                      │    │
│  │  ┌──────────────────────────────┐      │    │
│  │  │  SOM：2025 实际 GMV ≈ 1.0 万亿 │      │    │
│  │  └──────────────────────────────┘      │    │
│  └────────────────────────────────────────┘    │
└────────────────────────────────────────────────┘

SAM ÷ TAM ≈ 25-35%（品类可线上化率）
SOM ÷ SAM ≈ 8-12%（渗透率——成长早期数字）
SOM ÷ TAM ≈ 2-4%（极小，代表巨大空间）
```

#### 三种测算方法交叉验证

| 方法 | 逻辑 | 2025E GMV |
|:---|:---|:---|
| 需求导向 | 城镇家庭 4.9 亿户 × 渗透率 × 50 次/年 × 55 元 | ≈ 0.8-1.2 万亿 |
| 供给导向 | 主流平台加总（美团+京东+饿了么+抖音+叮咚+朴朴） | ≈ 0.9-1.1 万亿 |
| 对标成熟市场 | 韩/日/美即时零售占社零 8-12%，中国若达 3-5% | ≈ 1.2-2.0 万亿（空间） |

**共识**：2025 年即时零售 GMV ≈ **1.0-1.2 万亿 CNY**，同比 +20-30%。

#### 天花板讨论

| 场景 | 假设 | GMV |
|:---|:---|:---|
| 乐观 | SAM/TAM 40% × SOM/SAM 30% | ≈ 5 万亿 |
| 中性 | SAM/TAM 30% × SOM/SAM 20% | ≈ 3 万亿 |
| 保守 | 品类瓶颈 | ≈ 1.5 万亿 |

#### 增长驱动力加权

| 驱动力 | 权重 | 说明 |
|:---|:---|:---|
| 用户增长 | ≈ 30% | 城镇渗透 40%→55%，仍是最强驱动力 |
| 频次增长 | ≈ 25% | 年人均 30→40 次（习惯养成） |
| 客单价 | ≈ 15% | 50→55 元（提篮率/品类升级） |
| 品类泛化 | ≈ 20% | 医药、3C、鲜花等非餐增量 |
| 下沉市场 | ≈ 10% | 三四线从 0→1，基数低增速快 |

品类扩张路径（阶段式）：

| 阶段 | 品类 | 特征 |
|:---|:---|:---|
| 2018-2020 | 餐饮、商超、水果 | 高频低客单 |
| 2020-2023 | 生鲜前置仓 | 高频刚需、重资产 |
| 2023-2025 | 医药、酒水、鲜花 | 中高频高毛利 |
| 2024-2026E | 3C、宠物、酒类 | 高客单、发现式消费 |
| 2026E+ | "万物到家" | 全品类泛化，SAM 上移 |

### 3.3 防守性——**格局初成型，网络效应为主** 🟡✅

#### 护城河五要素评估

| 要素 | 可独占？ | 即时零售情况 |
|:---|:---|:---|
| 劳动力（骑手） | ❌ | "公地"共享；壁垒在**算法调度**而非独占骑手 |
| 土地（前置仓位置） | 🟡 部分 | 先发优势可被更高租金击破 |
| 资本 | ✅ 阶段性 | 决定烧钱存活期；非长期护城河 |
| 技术 | ✅ | 美团超脑调度 = 硬壁垒 |
| **数据** | ✅✅ | 消费者行为→需求预测→备货→飞轮，**核心壁垒** |

#### 核心飞轮（网络效应型）

```
更多用户 → 订单密度上升 → 骑手单均成本下降
    ↑                              ↓
更多商家入驻 ← GMV 更高 ← 时效提升/履约成本降低
```

#### 护城河风险

- **地域割裂**：网络效应本地化（北京的网络效应无法平移广州）
- **品类同质化**→ 平台可替代、用户切换成本低、补贴敏感
- **抖音"内容+"路径**可能用**发现式消费**打破美团"搜索式"的同质化

---

### 3.4 盈利性——**集中度高 + 利润拐点已现** ✅

#### 市场份额与 CRn

| 平台 | 模式 | GMV（2024E） | 市占率 | 同比增速 |
|:---|:---|:---|:---|:---|
| 美团闪购 / 小象超市 | 平台+自营 | ≈ 2,500-2,800 亿 | **≈ 35-40%** | +25-35% |
| 京东小时购 / 秒送 | 平台 | ≈ 700-800 亿 | ≈ 10-15% | +40-45% |
| 饿了么即时零售 | 平台 | ≈ 600-800 亿 | ≈ 8-12% | +15-20% |
| 抖音小时达 | 平台+内容 | ≈ 1,500-2,000 亿 | ≈ 5-8% | +100%+（低基数） |
| 叮咚 / 朴朴 | 自营前置仓 | ≈ 700-900 亿 | ≈ 8-12% | 分化 |
| 其他 | — | — | ≈ 5% | — |

> CR5 ≈ **90%+** ；CR3 ≈ **70-80%** → 已是**极高寡占型结构**。

#### 产能周期位置

```
Stage 1       Stage 2       Stage 3        Stage 4
供不应求 →  产能激增  →  产能出清/兼并 → 格局改善
2018-2020    2020-2022    2023-2025      2026+
                          ▲ 现在在这里
```

- 疫情催化期（2020-2022）：需求爆发+资本涌入
- 出清期（2023-）：每日优鲜破产、叮咚退出多城、前置仓理性收缩
- 2026+ 展望：格局改善、头部份额进一步强化

#### 集中度天花板

预计终局 CR3 ≈ **60-70%**（低于外卖 CR2 ≈ 90%，高于传统零售 CR5 < 10%）。

留出第二梯队空间的原因：
1. 品类差异大（生鲜 vs 数码 vs 医药），单平台难全品类最优
2. 内容平台（抖音/小红书）以发现式消费差异化切入
3. 下沉市场本地化供给难被全国平台全包

---

### 3.5 估值——**PEG→PE 过渡**

成长期 + 盈利初步兑现 → 正处于 PEG/PS 过渡到 PE 的阶段：

| 标的 | 估值法 | 当前状态 |
|:---|:---|:---|
| 美团整体 | 分部估值（PE + SOTP） | 闪购贡献增长溢价，外卖贡献利润底盘 |
| 叮咚买菜 | PE（已盈利） | 小市值、防御型 |
| 朴朴 | PS / 一级市场 | 区域深耕，估值取决于扩张节奏 |
| 行业非上市 | GMV 倍数 0.5-1.5x | 一级市场常用 |

**股价变化公式**：市值 = 净利润 × PE

中长期 PE 中枢由**行业增速**决定（即时零售 20-25% 增速 → 高于消费板块）；短期波动由情绪驱动。

**投资成熟期逻辑**（2026+）：集中度回升 → 龙头议价权增强 → 利润走阔 → PE 修复 → **戴维斯双击**（估值+业绩）。过渡态需跟踪集中度→利润→估值这条传导链条何时启动。

## 四、外部因素校准

### 4.1 PEST

| 维度 | 变量 | 影响 |
|:---|:---|:---|
| **P** | 商务部"县域商业三年行动计划"鼓励即时零售下沉；**骑手社保合规**（职业伤害保障已扩至全国 ~1,000 万人参加）；最高法典型案例认定"合作协议"不能规避劳动关系 | 🟢 鼓励 + 🟡 合规成本灰犀牛（或压缩 2-4pct 利润率） |
| **E** | 消费温和复苏、CPI 低位、"消费降级与体验升级并存" | 🟡 低价高频品类受益；高客单品类承压 |
| **S** | 老龄化、一人户增长、健康意识、懒人经济 | 🟢+ 独居/双职工家庭最依赖即时零售 |
| **T** | AI 调度、无人配送车/无人机、IoT 智能仓 | 🟢 降本增效长期杠杆，短期资本开支 |

### 4.2 货币三价

```
央行发出来的钱
 ├─ 购买力（CPI）      低位运行 → 客单价提升乏力 → 平台靠提频非提价增长
 ├─ 利率               低利率 → 融资成本低 → 价格/补贴战可持续，延缓盈利兑现
 └─ 汇率               人民币温和贬值 → 港股估值承压（美团等）
```

**关键影响**：低利率+低通胀让补贴战有资本持续打 → "增量不增收"现象仍在。

### 4.3 交易拥挤度

一级市场**本地生活赛道最后的大型战场**（继 O2O 百团、外卖烧钱、社区团购烧钱之后）。多方围堵美团：京东借供应链、抖音借流量、饿了么借阿里生态。对美团而言是**必须守住的腹地**——威胁外卖基本盘的高频→低频延伸。

## 五、景气度跟踪

### 5.1 产业链核心驱动环节

```
上游：本地供给（商超/便利店/前置仓/品牌商区域仓）
  │
  ├── 中游：平台撮合（流量分发 + 营销 + 履约）
  │
  └── 下游：即时配送网络（骑手众包 + 自营）—— 这是瓶颈环节
        │
         └── 消费端

纵向驱动逻辑：骑手供给密度 → 预判履约能力上限；订单密度 → 预判单均成本走向；补贴率 → 预判利润修复节奏
```

### 5.2 关键高频指标

| 类别 | 指标 | 频率 | 来源 |
|:---|:---|:---|:---|
| 需求端 | 日均订单量、MAU、用户频次 | 日/月 | 财报、QuestMobile |
| 供给端 | 前置仓数量、闪电仓开仓速度 | 月 | 财报、行业调研 |
| 履约端 | 平均配送时长、准时率、骑手人效 | 实时/日 | 平台披露 |
| 价格端 | 补贴率（优惠券/客单价）、佣金率 | 季 | 财报、商家端 |
| 财务端 | 美团核心本地商业分部经营利润率、闪购 UE | 季 | 美团季报 |
| 对标端 | 社零/网上零售增速 | 月 | 国家统计局 |
| 竞对端 | 抖音小时达 GMV（估算）、京东秒送订单量 | 不定期 | 券商、媒体 |

### 5.3 景气度判断框架

```
景气度 = f（订单量增速, 单均经济模型, 竞争强度）

🟢 上行：订单量 > 20% + UE 改善 + 补贴边际递减
🟡 震荡：订单量 10-20% + UE 持平 + 补贴战持续
🔴 下行：订单量 < 10% + UE 恶化 + 补贴强度回升

2025 中判断：🟡 震荡上行
  - 订单量 ≈ 20%（仍高但边际放缓）
  - UE 改善（美团闪购已盈利）
  - 但抖音/京东持续补贴，竞争强度不降反升
```

## 六、综合判断

### 一句话核心观点

> **即时零售处于成长期中后段（过渡态）：可行性已验证（UE 跑通、盈利已现），规模性仍有 3-5 倍空间但增速中枢下移，防守上网络效应+数据算法构成软护城河，盈利上集中度回升+利润拐点的双击传导链条正在启动。**

### 三个关键信号（6-12 个月观察）

| # | 信号 | 含义 |
|:--|:---|:---|
| **1** | 美团闪购 / 小象单季经营利润能否**持续为正**（非一次性调节） | 标志平台模式整体盈利拐点 |
| **2** | 抖音小时达能否突破 **15% 市占**并形成独立消费心智 | 决定终局是"寡头稳固"还是"多头拉锯" |
| **3** | 前置仓（叮咚/朴朴）能否**重启扩张**而非仅防守盈利 | 决定自营模式的长期天花板 |

### 参与者启示

| 角色 | 启示 |
|:---|:---|
| **投资者** | 美团闪购 = 盈利弹性标的（看 UE 改善的戴维斯双击）；叮咚 = 防御型利润修复标的；一级市场闪电仓模式窗口期已进入后半段 |
| **创业者** | 平台模式新玩家 CR3 70%+，门槛极高；机会在**垂直品类即时零售**（医药/宠物/3C）或**下沉县域本地化供给** |
| **品牌方** | 即时零售是"渠道增量+品牌曝光"的新阵地，权衡低价补贴对品牌的损耗 |
| **政策研究** | 关注骑手社保合规（3-5 年内或压缩 2-4 pct 利润率）、佣金率上限政策 |
