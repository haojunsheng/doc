#+subtitle:  复杂市场环境下，投资者该如何理解基金业绩？

#+filetags:   :qa:
#+identifier: 20260614T115908
#+source:     Morningstar 晨星（中国）

* 引子

同样买基金，有人赚30%有人亏15%——差距不在运气，在"你能不能看懂净值背后的故事"。这篇文章用2023年上半年的真实数据告诉你：基金业绩分化不是玄学，是风格、行业、选股三层叠加的结果。看懂这三层，你才能分清基金经理是真本事还是踩了风口。

* Q1: 基金净值涨了，为什么我没赚钱？

  *结论*：净值是结果，不是原因——你赚没赚钱，取决于你买的时候市场风格站在哪一边。

  *形式化*：基金业绩 = 市场风格β + 行业配置α + 个股选择α + 运气ε

  *怎么想到的*：
  - 2023年上半年，中证800成长指数跌6.16%，中证800价值指数涨3.35%
  - 偏股基金里，价值风格普遍跑赢成长风格
  - 说明：即使基金经理能力相当，风格站对方向就已经赢了第一步

  *边界*：在风格不显著的单边行情里（比如普涨或普跌），风格因子的解释力会下降。

* Q2: 市场风格到底是什么？它怎么影响我的基金？

  *结论*：风格是市场在"喜欢什么类型公司"上的集体偏好，它像风——顺风时猪都能飞，逆风时鹰也难飞。

  *形式化*：旧: 成长股 = 高估值高预期 → 顺风；新: 成长股 = 高估值逆风 → 被锤

  *怎么想到的*：
  - 2021年以来价值风格逆转，成长股受宏观环境影响持续下跌
  - 消费和新能源相关股票受冲击最大，而传统价值股（银行、能源）反而上涨
  - 基金经理如果死守成长风格，再强的选股能力也扛不住系统性逆风

  *边界*：风格轮动不是规律，是概率——没人能预测风格何时切换，只能应对。

* Q3: 基金经理的选股能力，怎么从业绩里拆出来？

  *结论*：真正厉害的基金经理，是在风格逆风时还能靠选股跑出超额收益的人。

  *形式化*：好基金 = 风格顺风时跟涨 + 风格逆风时靠选股少亏甚至赚钱

  *怎么想到的*：
  - 大成高新技术产业（000628）：成长风格逆风，但基金经理靠通信、家电、石油石化选股贡献超额收益
  - 工银创新动力（000893）：价值风格顺风，但同类价值基金里也排名前列，说明选股有真本事
  - 关键证据：在完整市场周期（牛熊都经历过）里还能跑赢同类，才是真能力

  *边界*：短期（1年内）业绩可能完全由风格驱动，看不出选股能力——至少要看3-5年。

* Q4: 行业配置是怎么影响基金业绩的？

  *结论*：押对行业可能让你一年翻倍，也可能让你一年腰斩——行业集中度是双刃剑。

  *形式化*：行业集中度高 = 弹性大 + 风险大；行业分散 = 弹性小 + 风险小

  *怎么想到的*：
  - 2023年TMT板块（通信+50%、传媒+42%）和房地产（-14%）、商贸零售（-23%）形成极端对比
  - 广发睿毅领先（005233）重仓航空和零售，结果这两个行业基本面持续恶化，基金业绩落后
  - 说明：行业选择不是"选好的"，是"选对的时候选对的"

  *边界*：行业分散不是万能药——过度分散可能稀释收益，关键是理解你在赌什么。

* Q5: 看基金业绩，最该看什么？

  *结论*：别只看最近一年的排名，要看完整周期里的表现——牛市赚多少、熊市亏多少、能不能持续跑赢同类。

  *形式化*：好基金 ≠ 某一年排名第一；好基金 = 每个完整周期都排前1/3

  *怎么想到的*：
  - 景顺长城鼎益（162605）：2017-2020连续四年跑赢中证800，但2021年后风格逆转，业绩落后
  - 广发创新升级（002939）：2019-2020年成长风格顺风时大赚，2021年后重仓新能源亏损
  - 关键：基金经理的投资方法是否稳定、是否知行合一，比短期业绩更重要

  *边界*：历史不代表未来——基金经理换人、策略漂移、市场结构变化都可能打破过往规律。

* 收口

基金业绩不是黑箱，是风格、行业、选股三层叠加的透明结果——你要学会拆开看，而不是盯着净值叹气。
