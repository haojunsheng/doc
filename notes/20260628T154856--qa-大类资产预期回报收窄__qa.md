* 引子

2025年A股、港股、黄金表现居前，美股和中国债券黯淡。进入2026年，多家国际资管机构都在做同一件事：下调全球股票资产的长期回报预期。晨星汇总了这些研究，发现一个关键趋势——高收益资产正在变得越来越稀缺，美债和美股的预期回报已经非常接近。

* Q1: 为什么几乎所有机构都在下调美股长期回报预期？

  *结论*：因为2025年全球股市上涨后估值抬高了——同样的盈利和股息水平，更高的价格意味着更低的预期回报。

  *形式化*：股价↑ + 基本面不变 → 股息率↓ + 估值↑ → 预期回报↓

  *怎么想到的*：
  - 除先锋领航外，几乎所有机构都下调了美股长期回报预期
  - 发达市场和新兴市场股票回报预期也普遍下调
  - 2025年全球股市两位数涨幅是下调的直接原因

  *边界*：如果美国企业盈利增长超预期或估值继续扩张，实际回报可能高于机构预测——但这是"看多"的假设，不是机构的基准假设。

* Q2: 为什么晨星最看好新兴市场（尤其是中国）？

  *结论*：因为新兴市场估值相对更低、增长潜力更大——自2024年起晨星就多次表示更看好新兴市场的长期回报潜力。

  *形式化*：新兴市场：估值低 + 增长潜力大 → 长期预期回报 > 美股
  中国市场：新兴市场中最被看好的部分

  *怎么想到的*：
  - 晨星自2024年起多次表示相较于美股更看好新兴市场
  - 尤其是中国市场被特别提及
  - 即便经历了2025年上涨后适度下调，仍然是最看好的

  *边界*：新兴市场"看好"的前提是估值优势和增长潜力能够兑现——如果地缘风险或治理问题恶化，理论上的高回报可能无法实现。

* Q3: 为什么美债和美股的预期回报正在"趋同"？

  *结论*：因为美股预期回报被下调（估值高了），而美债收益率处于高位——两者的收益预期差正在收窄。

  *形式化*：美股预期回报：3.1%-6.7%（下调中）
  美债收益率：高位 → 预期回报↑
  结果：美股 ≈ 美债（收益接近）

  *怎么想到的*：
  - 多数机构测算中美股和美债收益预期差正在收窄
  - 先锋领航和锐联认为未来十年美债整体表现会优于美股
  - 债券波动低于股票，在收益接近时性价比更高

  *边界*：如果美联储大幅降息，美债收益率会下行，收益预期差可能重新扩大——但这是不确定的。

* Q4: 为什么"历史回报"不能直接用来做配置决策？

  *结论*：因为当前环境已经变化——用过去高利率时期的债券收益率来预测未来，会过于乐观。

  *形式化*：历史回报 ≠ 未来回报
  环境变了 → 历史参考失效

  *怎么想到的*：
  - 历史数据存在局限性，当前环境与过去不同
  - 如果简单参考过去高利率时期债券收益率，会对债券未来表现过于乐观
  - 预期回报是基于当前已知信息的概率性预测

  *边界*：历史回报不是完全没用——它提供了长期参考区间，但不能作为精确预测的依据。

* Q5: 预期回报的测算为什么值得信赖？

  *结论*：因为它依托稳定的模型和框架，不会出现大幅波动——与短期市场预测不同，长期预期回报的测算结果更为稳定。

  *形式化*：短期预测 = 波动大、不可靠
  长期预期回报 = 稳定模型 + 动态参数 → 相对稳定

  *怎么想到的*：
  - 不同机构围绕股息率、估值水平、盈利增长预期等因素搭建模型
  - 每家机构定期结合市场变化调整参数，动态修正预测
  - 与预测短期涨跌不同，长期预期回报依托稳定框架

  *边界*：模型假设可能出错——如果全球经济结构发生根本性变化（如去全球化加速），历史模型的适用性会下降。

* Q6: 面对"高收益资产变稀缺"的现实，投资者应该怎么做？

  *结论*：降低收益预期，通过多元配置管理风险，与时间站在同一边——而不是追逐单一资产的高回报。

  *形式化*：高收益稀缺 → 不追单一资产 → 多元配置 + 长期持有

  *怎么想到的*：
  - 当前环境下高收益资产正在变得越来越稀缺
  - 客观理性看待市场新变化，适当降低收益预期
  - 多元配置管理风险，与时间站在同一边

  *边界*：如果投资者有明确的短期资金需求，"与时间站在同一边"就不适用——短期资金应该放在低波动资产里。

* Q7: 为什么"美债替代美股"在当前环境下是合理的？

  *结论*：因为两者预期回报接近，但债券波动更低——对近期有资金需求或风险偏好低的投资者，可以在不明显牺牲回报的前提下降低波动。

  *形式化*：美股 ≈ 美债（预期回报接近）
  美债波动 < 美股波动
  → 低风险偏好：美债替代部分美股

  *怎么想到的*：
  - 多数机构测算中美股和美债收益预期差已经很小
  - 债券波动低于股票是结构性特征
  - 对近期有资金支出需求的投资者，降低波动比追求更高回报更重要

  *边界*：如果美股预期回报重新上升（如企业盈利增长超预期），"美债替代"的逻辑就不成立了——需要持续跟踪和动态调整。

* 收口

晨星汇总多家机构研究后传递了一个核心信息：2025年普涨之后，全球大类资产的预期回报都在下调，高收益资产正在变稀缺。对投资者来说，最理性的应对是降低预期、多元配置、与时间同行——而不是试图在越来越贵的资产里找高回报。
