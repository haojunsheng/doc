* 引子
特朗普2025年1月20日宣誓就职第二个任期，华尔街满怀期待牛市，结果100天内美股差点跌入熊市，美债不涨反跌，黄金飙升突破3400美元。屈辰晨用十张图复盘这段"预期全错"的时期，揭示关税政策如何重塑全球资产配置逻辑。

* Q1: 美股为什么差点跌入熊市？
  *结论*: 科技股调整叠加关税冲击，标普距熊市仅一步之遥，波动率创历史高位。
  *形式化*: 科技股回调 × 关税政策冲击 → 标普最大回撤19.4% → 距熊市(20%)仅0.6%
  *怎么想到的*:
  - 2月中创历史新高，4月关税宣布后急转直下
  - 最大回撤达19.4%，这是2020年来最惨开局
  - 68个交易日中有10天涨跌幅≥2%，占比15%（2024年仅3%）
  - 特朗普反复变调关税政策放大了波动
  *边界*: 如果关税政策迅速落地且不再反复摇摆，波动率会显著下降。

* Q2: 美债为什么不涨反跌？
  *结论*: 关税推高通胀预期，美债从避险资产变成抛售对象，30年期收益率4天飙升45bp。
  *形式化*: 关税 → 通胀预期↑ → 美债价格↓ → 收益率↑（与股债跷跷板脱钩）
  *怎么想到的*:
  - 正常逻辑：股市跌→买国债→国债价格涨→收益率降
  - 这次反常：关税引发通胀担忧，晨星上调通胀预期0.6个百分点
  - 30年期美债收益率4天涨45bp，1990年来仅出现3次
  - 机构为应对赎回加速抛售，形成负反馈循环
  *边界*: 当市场认为关税是短期冲击而非持续通胀压力时，美债避险属性会恢复。

* Q3: 黄金为什么能突破历史新高？
  *结论*: 黄金同时对冲衰退、地缘政治和高通胀三重担忧，特朗普上任后这三样全占了。
  *形式化*: 衰退风险 + 地缘风险 + 通胀风险 → 黄金从2755→突破3400美元（+23%）
  *怎么想到的*:
  - 黄金是经济衰退、地缘冲突、高通胀的硬通货
  - 特朗普上任后这三类担忧同时上升
  - 关税政策→通胀预期↑→黄金涨
  - 美股波动→衰退担忧→黄金涨
  *边界*: 当关税落地且被市场消化、衰退概率下降时，黄金的避险溢价会收窄。

* Q4: 比特币为什么也跌了？
  *结论*: 比特币与科技股风险属性相似，在避险情绪高涨时跟着跌，"加密货币总统"的利好抵不过宏观利空。
  *形式化*: 特朗普利好监管 × 宏观利空占优 → 比特币100天累计跌9%
  *怎么想到的*:
  - 特朗普自称"加密货币总统"，市场预期放松监管
  - 但比特币走势与科技股高度相关
  - 关税恐慌→风险资产抛售→比特币跟着跌
  - 停战消息刺激反弹，但整体仍下跌
  *边界*: 当加密货币监管政策真正落地放松时，比特币会脱钩科技股走独立行情。

* Q5: 关税能缩小美国贸易逆差吗？
  *结论*: 不能，因为贸易逆差的根源是储蓄投资失衡，关税解决不了结构性问题。
  *形式化*: 贸易逆差根源 = 储蓄投资失衡 ⊃ 关税能解决的范围 → 关税≠解药
  *怎么想到的*:
  - 美国经常账户逆差自2020年起再度扩大
  - 晨星宏观团队指出根源是储蓄投资失衡而非贸易政策
  - 关税只能改变进口来源，不增加国内储蓄
  - 今非昔比：进口占GDP从3.7%(1930s)升到14%(2024)
  *边界*: 如果关税配合大规模产业政策重塑制造业，长期逆差可能收窄，但短期无效。

* Q6: 美股为什么在特朗普任内表现历届最差？
  *结论*: 高波动+关税不确定性+通胀预期，让特朗普第二任期的股市表现在历任总统中垫底。
  *形式化*: 标普在历任总统任期内的平均表现 → 特朗普第二任期排末尾
  *怎么想到的*:
  - 数据显示标普每日回报率分布最差
  - 美股2025年在全球主要资产中表现垫底
  - 其他发达国家股指普遍小涨，黄金大涨
  - 投资者预期的"振兴经济"完全没兑现
  *边界*: 如果后续关税政策明朗化且企业盈利超预期，历史排名可能被改写。

* Q7: 经济衰退概率有多大？
  *结论*: 晨星宏观团队预测未来12个月衰退概率40%，关税引发的供需双重冲击是主因。
  *形式化*: 关税 → 供需双杀 → GDP增长预测下调1.6个百分点 → 衰退概率40%
  *怎么想到的*:
  - 高关税推高物价→消费需求下降
  - 出口受阻→供给端产出下降
  - 美联储2%通胀目标更难实现
  - 滞胀风险上升
  *边界*: 如果关税迅速取消或大幅削减，衰退概率会快速回落。

* 收口
