* 引子
2020年公募基金发行市场"爆款"、"日光基"频现，全年偏股型基金募集近1.5万亿。三年过去，这5只当时规模最大的"当红炸子基"业绩惨淡，跌幅普遍超过40%。文章通过数据揭示了一个规律：新基金卖得最火的时候，往往是市场最热的时候，也是阶段性顶部。

* Q1: 为什么2020年的爆款基金三年后业绩惨淡？
  *结论*：高位建仓+投资者赎回踩踏，导致"买在山顶"。
  *形式化*：发行高峰 ≈ 市场顶部 → 高位建仓 → 市场转熊 → 净值暴跌 → 投资者赎回 → 规模缩水
  *怎么想到的*：
  - 新基金发行量和市场情绪正相关，2020年7-11月是A股阶段性高点
  - 新基金有3-6个月建仓期，发行后市场往往就开始调整
  - 5只基金平均跌幅40-50%，同期沪深300下跌约30%
  - 规模缩水68-86%，说明投资者割肉离场
  *边界*：如果发行时市场处于低位（如2018年底），新基金反而能获得较好收益。规律失效于市场周期转折点。

* Q2: 基金公司和渠道为什么热衷于发新基金？
  *结论*：新基金认购费不打折+基金公司规模导向+基民"买新不买旧"偏见，三方利益驱动。
  *形式化*：新基金认购费（1-1.5%）> 老基金申购费（0.1-0.15%）→ 渠道激励 → 基金公司规模增长 → 管理费收入增加
  *怎么想到的*：
  - 数据显示2020年偏股新发基金占总量70%，但产品高度同质化
  - 渠道"尾佣"机制导致销售导向而非投资者需求导向
  - 基民误以为净值1元=低估，把"打新股"思维搬到基金
  - 基金公司"一次性营销"比持续营销更省事
  *边界*：在成熟市场（如美国），新基金发行主要目的是完善产品线，而非规模扩张。市场不同，动机不同。

* Q3: 新基金建仓期3-6个月对投资者意味着什么？
  *结论*：建仓期内无法赎回，投资者可能眼睁睁看着基金在眼前亏损。
  *形式化*：建仓期 = 锁定期 → 市场下跌时无法止损 → 被动承受损失
  *怎么想到的*：
  - 2020年7月发行的基金，建仓期覆盖7-12月，正好是调整期
  - 基金经理不可能短时间满仓，导致仓位不足错过反弹或无法及时止损
  - 投资者想跑都跑不掉，只能看着净值下跌
  - 对比：老基金可以随时调仓，灵活性更高
  *边界*：如果建仓期内市场持续上涨，建仓期反而是优势，可享受逐步加仓的平滑成本。

* Q4: "基金赚钱基民不赚钱"的根源是什么？
  *结论*：销售机构的佣金机制导致"卖热不卖好"，投资者在最高位买入。
  *形式化*：投资者到手收益 = 基金投资回报 - 交易成本 - 错误择时损失
  *怎么想到的*：
  - 2022年主动偏股基金平均持有成本2.61%（管理费+托管费+交易费）
  - 渠道以尾佣为导向，而非以投资者风险偏好为导向
  - 鼓励频繁买卖赚手续费，加剧"追涨杀跌"
  - 2023年基民体验差："基金和基民都不挣钱，只有基金公司和销售挣钱"
  *边界*：如果投资者能坚持定投或长期持有，可以规避择时错误，但需要克服人性。

* Q5: 从2023年数据看，新基金发行规模创10年新低意味着什么？
  *结论*：2023年市场冰点对应新基金发行最低点，这反而是较好的布局时机。
  *形式化*：新基金发行规模 ∝ 1/市场估值 → 发行冰点 = 投资良机
  *怎么想到的*：
  - 2023年平均募集规模仅3.3亿，创10年新低
  - 历史规律：2015年和2020年发行高峰对应阶段性顶部
  - 逆向思考：发行困难时建仓成本低，未来收益空间大
  - 类比：2018年底发行困难，2019-2020年这些基金表现优异
  *边界*：发行低迷不一定是底部信号，需结合估值、政策等多因素判断。

* 收口
文章用5只爆款基金的兴衰史，揭示了一个反直觉的规律：新基金的火爆程度与其未来业绩呈负相关，投资者应该在人声鼎沸时保持冷静，在无人问津时适度贪婪。
