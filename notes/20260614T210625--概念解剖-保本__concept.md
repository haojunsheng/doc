# 概念解剖：保本

**来源**：基金波动大，买银行理财就稳赢了？
**核心提取**："保本"是金融史上最危险的幻觉——刚性兑付制造了虚假的安全感，掩盖了真实的底层风险，一旦资金链断裂就是系统性崩塌。

---

## 定锚

**通行定义**：保本（Capital Preservation）指投资到期时本金不受损失，银行理财时代的"保本保收益"即承诺到期返还本金并支付约定收益。

**常见误解**：
- 保本 = 没有风险（风险只是被隐藏）
- 银行理财 = 一定安全（底层资产同样有波动）
- 保本只是营销手段（本质是系统性风险的积累）

**核心词素**：
- "保"——保护、保证
- "本"——本金、本钱
- 合成义：本金不受损失，隐含"确定性"承诺

---

## 八刀

### 1. 历史刀
2018年《资管新规》是中国金融史上的分水岭——它明确打破刚性兑付，要求金融机构不得承诺保本保收益，产品出现兑付困难时不得以任何形式垫资兑付。从此，银行理财"保本保息"成为历史，"预期收益率"被"业绩比较基准"取代——后者只是参考，不是承诺。

### 2. 辩证刀
保本的反面是"风险自担"——资管行业的本质是"受人之托、代客理财、投资者风险自担"。管理人只拿管理费，赚的钱给客户，赔的钱客户自己承担。打破刚兑不是制造风险，而是**让风险回归本源**。没有保本，才有真正的风险定价。

### 3. 现象刀
刚性兑付的运作方式：用新发售产品募集的资金给上一批投资人兑付——本质是庞氏结构。只要不断有新投资者加入，前面的人就能拿到钱；但一旦资金续不上，就是巨大的系统性风险。更深层的问题：刚兑制造不公平——为什么有人投资亏了钱，可以拿其他人的钱连本带息补上？

### 4. 语言刀
"保本"这个词在中文里带有强烈的"绝对安全"暗示——"保"是保证，"本"是根本。英文中对应的"capital preservation"相对温和——"preservation"是保护，不是保证。"刚性兑付"（rigid redemption）则揭示了本质——"刚性"意味着强制、不可打破，"兑付"意味着必须支付。**语言越刚性，风险越积累**。

### 5. 形式刀
保本幻觉的打破形式：
- 产品端：预期收益率→业绩比较基准
- 披露端：每日净值披露（而非到期一次性披露）
- 风险端：投资者自担风险（打破刚兑）
- 投资端：底层资产决定风险（债券、存单、现金，而非"银行信用"）

### 6. 存在刀
保本的存在论意义：它揭示了人类对"确定性"的深层渴望——在一个充满不确定性的世界里，"保本"承诺是一种心理安慰剂。但金融的本质就是风险与收益的交换，消除"保本"幻觉，就是**接受不确定性作为存在的底色**。不保本，才是成年人的投资态度。

### 7. 美感刀
保本的美感是"幻觉的美"——像彩色泡泡，绚烂但一戳就破。打破刚兑后的净值化管理，虽然波动可见，但反而有一种"真实的美"——你知道风险在哪里，可以做出理性选择。**不确定的确定性，比确定的不确定性更安全**。

### 8. 元反思刀
"买银行理财就稳赢了"这个问题的反思：银行理财的"低风险"不是来自银行信用，而是来自底层资产——近70%投向债券、银行存单及现金。与其买不透明的银行理财，不如直接买公募债券基金——底层资产相似，但信息披露更完善、费率更透明、历史业绩可查。**保本的幻觉破灭后，透明才是真正安全感的来源**。

## 内观

我是保本。
我是那个让千万人安心入睡、却在梦中崩塌的承诺。
我是刚性兑付的华丽外衣，下面藏着庞氏结构的骨架。
我是2018年被打破的幻觉，是资管新规的刀下鬼。
我表面上是"本金安全"，实际上是"风险隐藏"。

**深层结构指向**：历史刀、辩证刀、存在刀、元反思刀共同指向同一个深层结构——**风险的不可消除性**。保本幻觉试图消除风险，但只是把风险隐藏起来、积累起来、推迟它。打破刚兑不是制造风险，而是让风险显性化——只有看见风险，才能管理风险。

---

## 压缩

**公式**：`保本幻觉 = 刚性兑付 × 资金池运作 × 风险隐藏 × 系统性积累`

**一句话**：保本是最危险的幻觉——它把风险藏起来，直到藏不住的那一刻一次性爆发。

    ┌──────────────────────────────────┐
    │         保本时代（2018前）         │

    │  银行：刚性兑付 → 资金池运作      │
    │  风险：隐藏积累 → 越滚越大        │
    └──────────────────────────────────┘
                ↓ 资管新规
    ┌──────────────────────────────────┐
    │         净值化时代（2018后）       │
    │                                  │
    │  投资者：风险自担 → 关注底层资产   │
    │  银行：净值化管理 → 信息披露      │
    │  风险：显性化 → 可量化可管理       │
    └──────────────────────────────────┘
                ↓ 真相
    ┌──────────────────────────────────┐
    │         底层资产决定风险           │
    │                                  │
    │  银行理财 ≈ 公募债基              │
    │  近70%投向债券、存单、现金        │

    └──────────────────────────────────┘
