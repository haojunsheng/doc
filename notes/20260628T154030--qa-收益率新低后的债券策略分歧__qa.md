* 引子
2024Q2债券基金净流入超万亿，创五年新高。10年期国债收益率跌至2.1%的历史低位，30年国债价格自2023年以来涨超15%。海内外基金经理面对同一张收益率曲线，应对截然不同：贝莱德加仓国债至16%，富达从30%降至18%，汇丰只配6%。国内纯债基金也出现保守和灵活波段两派。

* Q1: 为什么中国债券收益率能创历史新低？
  *结论*: 央行维持宽松 + 避险情绪升温 + 降息预期三重叠加，把收益率买到了地板价。
  *形式化*: 宽松货币 + 避险情绪 + 降息预期 → 资金涌入债市 → 收益率↓↓
  *怎么想到的*:
  - 与其他央行不同，中国央行维持宽松旨在"重振经济活力"
  - 房地产动荡 + 消费疲软 + 地缘政治紧张 → 风险偏好↓ → 债券配置需求极旺
  - 10年期国债8月初跌至2.1%
  *边界*: 如果经济复苏信号明确或通胀抬头，降息预期会逆转，收益率可能急速反弹。

* Q2: 为什么中国债券回报在亚洲表现靠前，尽管收益率最低？
  *结论*: 中国债券回报主要来自价格上涨（资本利得），而非票息收入。
  *形式化*: 中国债券: 低票息 + 价格↑↑ = 总回报靠前 | 印度/印尼: 高票息 + 价格↑ = 总回报
  *怎么想到的*:
  - 中国10年期国债收益率2.6%，印度7.2%，印尼6.5%
  - 但中国三年年化回报接近5%，仅次于印度6.5%和印尼5.7%
  - "债券价格的上涨是该期间中国债券总回报的主要贡献因素"
  *边界*: 如果收益率停止下行甚至回升，中国债券的价格涨幅会消失，回报率优势不再。

* Q3: 为什么贝莱德和富达对国债的操作完全相反？
  *结论*: 贝莱德看长期利率下行趋势，富达担忧短期供给冲击和央行"喊话"风险。
  *形式化*: 贝莱德: 长期悲观(经济弱) → 加仓国债 | 富达: 短期谨慎(供给+央行) → 减仓国债
  *怎么想到的*:
  - 贝莱德认为"房地产挑战+消费低迷+供给过剩 → 利率更长时间维持低位"
  - 富达虽长期乐观，但担心"长端政府债券供应增加"和"央行关于长端收益率过低的提示"
  - 贝莱德国债仓位从4%升至16%，富达从30%降至18%
  *边界*: 如果央行真的收紧货币政策或大量国债供给入场，贝莱德的激进加仓会遭遇损失。

* Q4: 汇丰为什么只配6%国债，它看到了什么别人没看到的？
  *结论*: 汇丰认为中国国债价格已被高估，更愿意通过离岸点心债获取人民币敞口。
  *形式化*: 汇丰逻辑: 国债价格↑↑ = 高估 → 减持至6% | 点心债: 离岸人民币公司债 → 60%配置
  *怎么想到的*:
  - 汇丰团队明确认为"中国债券价格处于被高估的状态"
  - 但"对久期仍持乐观态度"，只是选择离岸公司债而非国债
  - 看好的是人民币国际化进程中点心债市场的活跃发行
  *边界*: 如果离岸信用风险暴露（如中资企业违约），汇丰的"曲线救国"策略会适得其反。

* Q5: 国内纯债基金的两派策略差异在哪？
  *结论*: 工银偏保守（利率债仓位15→20%），万家鑫璟灵活波段（30%+仓位频繁操作）。
  *形式化*: 工银: 低仓位 + 稳健 = 守 | 万家: 高仓位 + 波段 = 攻
  *怎么想到的*:
  - 工银认为"强刺激政策推动增长的概率偏低"，宏观环境好但短期需跟踪风险
  - 万家认为"收益率低于过去十年低点，但与未来经济增速和通胀比并无估值压力"
  - 万家去年Q3加仓→Q4减仓→今年Q1再加仓，操作灵活
  *边界*: 如果利率反转上行，万家的灵活仓位能快速减仓止损，但若波段节奏踩错，会跑输工银的保守策略。

* Q6: 债券基金狂吸金1万亿，投资者该追还是该怕？
  *结论*: 过去回报不可持续，应避免追高；但中国债市多样化蕴含机会，选经验丰富的团队。
  *形式化*: 债基吸金: 回报强→资金↑→? | 文章提醒: 勿追历史业绩 + 选团队
  *怎么想到的*:
  - 文章明确说"过去的回报未必具有可持续性，避免仅基于过去业绩做投资决策"
  - 但也指出"庞大而多样化的中国债券市场蕴含的机遇不应被忽视"
  - 核心建议是选"投资经验丰富、投资能力强、有可复制投资流程的团队"
  *边界*: 如果债券市场继续走牛而投资者因谨慎空仓，会错过低利率环境下的资本利得机会。

* 收口
这篇文章最有价值的地方不是告诉你债券该买还是该卖，而是把同一收益率曲线下四家机构的分歧操作和理由全部摊开——贝莱德看长期、富达看短期、汇丰看估值、国内两派看政策节奏，谁对谁错只有在事后来看。
