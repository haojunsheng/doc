#+subtitle:   追求超额的风，还是刮到了ETF

* 引子
ETF（交易所交易基金）过去被视为"被动投资"的代名词，但海外正在兴起一种新物种——主动ETF。截至2025年底，美国市场已有近3000只主动ETF，规模占比从2018年的不到3%提升至10%。2025年主动ETF吸引了创纪录的4792亿美元资金净流入，占全年ETF资金净流入总额的三分之一。这篇文章揭示了主动ETF崛起的逻辑、优势和陷阱。

* Q1: 为什么"主动ETF"能在海外快速增长？
  *结论*：因为主动ETF结合了"ETF的税收优势+低费率+交易灵活性"和"主动管理的超额收益潜力"。
  *形式化*：主动ETF = ETF结构（节税+低费+灵活交易）+ 主动策略（选股+配置）→ 规模快速增长
  *怎么想到的*：
  - 税收优势：ETF的实物申赎机制减少资本利得，降低投资者税负
  - 费率优势：主动ETF平均费率0.63%，传统主动基金1.02%，低近40bp
  - 交易灵活性：可以像股票一样实时买卖，持仓透明度高
  - 2025年数据：4792亿美元资金净流入，占ETF总流入的1/3
  *边界*：如果税收优势消失（如政策变化）或费率优势被抹平，主动ETF的吸引力会下降

* Q2: 为什么"ARK Innovation"会成为主动ETF的反面教材？
  *结论*：因为无法暂停申购导致规模膨胀，被迫偏离原有策略（从中盘成长漂移到大盘成长），最终业绩反转。
  *形式化*：无法暂停申购 + 资金持续流入 → 规模膨胀 → 策略漂移（中盘→大盘）→ 业绩反转
  *怎么想到的*：
  - 背景：ARK Innovation聚焦中盘成长，2019-2020年业绩亮眼
  - 问题：无法关闭申购，资金持续流入，规模快速膨胀
  - 后果：被迫增加大盘股持仓来缓解流动性压力，投资风格从"中盘成长"漂移到"大盘成长"
  - 结果：2021年业绩大幅反转，投资者遭受损失
  - 教训：主动策略有"规模容量"限制，ETF形式无法通过"暂停申购"控制规模
  *边界*：如果策略本身容量大（如大盘宽基策略），这个问题影响较小

* Q3: "跟风盘"如何影响了ARK Innovation的业绩？
  *结论*：因为持仓透明度太高，市场监控ARK的交易动向并跟风买入，推高股价后反噬基金业绩。
  *形式化*：日度持仓披露 → 市场监控交易动向 → 跟风买入 → 股价↑ → 基金被迫高位加仓 → 业绩↓
  *怎么想到的*：
  - 背景：大多数主动ETF像被动ETF一样每日披露持仓
  - 现象：ARK买入的股票次日股价平均上涨3.5%（无其他基本面原因）
  - 逻辑：市场监控ARK的交易动向，提前跟风买入，推高股价
  - 后果：ARK被迫在高位加仓已有持仓，稀释超额收益
  - 反转：市场情绪反转后，跟风盘变成"跟卖盘"，拖累基金业绩
  *边界*：如果持仓披露频率降低（如季度披露），跟风效应会减弱

* Q4: 为什么"75%以上的股票型主动ETF都是大盘风格"？
  *结论*：因为大盘风格策略的规模容量大，中小盘策略容易遇到规模瓶颈。
  *形式化*：大盘风格 = 选股空间大 + 流动性充足 → 规模容量大 → 适合ETF形式；中小盘风格 → 规模容量小 → 不适合ETF形式
  *怎么想到的*：
  - 问题：主动策略依赖精选个股，选股空间有限
  - 大盘风格：覆盖数百只大盘股，流动性好，即使规模增长也不影响操作
  - 中小盘风格：选股空间小，流动性差，规模增长会稀释超额收益
  - 数据：美国1500多只股票型主动ETF中，75%以上都是大盘风格
  - 结论：ETF形式更适合"容量大"的策略，不适合"容量小"的策略
  *边界*：如果市场出现"中小盘风格持续占优"，大盘风格主动ETF会跑输

* Q5: 为什么"JPMorgan Equity Premium Income ETF"能成为2025年吸金冠军？
  *结论*：因为它采用的是"备兑开仓策略"（Covered Call），这是一种基于规则的策略，规模容量大、费率低。
  *形式化*：备兑开仓策略 = 持有指数 + 卖出看涨期权 → 规模容量大 + 费率低 → 资金持续流入
  *怎么想到的*：
  - 背景：2025年吸金最多的主动ETF是JPMorgan的两只产品
  - 策略：基于标普500和纳斯达克指数的备兑开仓策略
  - 特点：不是传统的"精选个股"，而是基于规则的策略
  - 优势：规模容量大（因为基于指数）、费率低、投资流程透明
  - 结论：主动ETF的成功不靠"选股能力"，靠"策略容量+费率优势"
  *边界*：如果市场单边大涨，备兑开仓策略会限制上涨空间，跑输纯指数基金

* Q6: "定制化篮子申赎模式"为什么对主动ETF很重要？
  *结论*：因为主动策略需要灵活调整持仓，标准股票篮子申赎模式限制了基金经理的操作空间。
  *形式化*：定制化篮子申赎 → 基金经理灵活调整持仓 → 提升交易效率 + 降低冲击成本
  *怎么想到的*：
  - 背景：当前国内ETF采用"严格对标指数权重的标准股票篮子"申赎
  - 问题：主动策略需要灵活调整持仓，标准篮子限制了操作空间
  - 解决方案：定制化篮子允许基金经理用非标准组合进行申赎
  - 好处：提升交易效率、降低冲击成本、保护策略机密性
  - 结论：如果中国要推出主动ETF，需要引入定制化篮子申赎模式
  *边界*：定制化篮子可能增加操作复杂度和监管难度

* Q7: 从"缓冲ETF（Buffer ETF）兴起"能推断出什么？
  *结论*：说明主动ETF正在从"选股策略"向"基于规则的策略"演进，以解决规模容量和费率问题。
  *形式化*：缓冲ETF = 跟踪指数 + 期权策略（牺牲上涨空间换取下跌保护）→ 规则化 + 低费率 → 规模容量大
  *怎么想到的*：
  - 背景：2025年发行较多的主动ETF是"缓冲ETF"
  - 策略：结合期权，跟踪指数表现的同时提供一定比例的损失缓冲
  - 特点：基于规则，不是传统的"精选个股"
  - 优势：规模容量大、费率低、投资流程透明
  - 趋势：主动ETF正在从"选股策略"向"规则化策略"演进
  *边界*：如果市场出现极端行情（如股灾），缓冲ETF的期权策略可能失效

* 收口
晨星通过主动ETF的海外实践揭示了一个核心洞见：主动ETF的成功不靠"选股能力"，靠"策略容量+费率优势"——传统的主动选股策略规模容量小、费率高，不适合ETF形式；而基于规则的策略（如备兑开仓、缓冲策略）规模容量大、费率低，更适合ETF形式。未来主动ETF的竞争，不是"谁选股更聪明"，而是"谁的策略更适合ETF结构"。
