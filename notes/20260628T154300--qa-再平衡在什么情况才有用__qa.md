* 引子

市场回到2021年高点，不少人后悔当初没高抛低吸。择时太难，于是"再平衡"被奉为懒人神器。但数据说话：再平衡在有些组合上能多赚5%-6%，在有些组合上反而是减分项。关键区别不在操作本身，在你选的资产对。

* Q1: 再平衡创造收益的数学条件是什么？

  *结论*：两类资产长期收益接近 + 期间波动差距大 = 再平衡效果最好。

  *形式化*：再平衡收益 ≈ (波动差距) × 频率 / (长期收益差距 + 1)

  *怎么想到的*：
  - 再平衡本质是"低买高卖"的机械化执行
  - 收益来自高卖低买的价差，价差越大收益越大
  - 如果长期收益差距大，强势资产不操作反而赚更多

  *边界*：两类资产完全同涨同跌时（如成长&价值），再平衡几乎零收益。

* Q2: 为什么A股+现金/A股+债券效果最好？

  *结论*：三者年化收益差距不超3%，但A股波动远大于债券和现金，造成巨大价差空间。

  *形式化*：A股(高波动) + 债券/现金(低波动) + 收益相近 → 年多赚0.5%，十年+5~6%

  *怎么想到的*：
  - 收益相近意味着没有"踏空"成本
  - 波动差异大意味着每次再平衡都能捡到便宜
  - 十年复利累积后差异显著

  *边界*：该结论基于过去十年数据，若未来A股收益大幅下降，效果减弱。

* Q3: 为什么A股+黄金、A股+全球股票做再平衡反而亏？

  *结论*：长期收益差距大时，再平衡等于强制限制强势资产的权重。

  *形式化*：再平衡: 强势资产权重 ← 人为压低 | 不操作: 强势资产权重 ← 自然升高

  *怎么想到的*：
  - 黄金/全球股票长期跑赢A股
  - 再平衡要求卖掉涨得多的，补到涨得少的
  - 相当于自动减仓了表现最好的资产

  *边界*：若黄金/全球股票未来长期跑输A股，结论反转。

* Q4: 谁也无法预测未来哪类资产赢，那再平衡意义何在？

  *结论*：意义从"提升收益"切换到"控制风险"——没人能预判，所以需要纪律。

  *形式化*：再平衡价值 = 收益增量大? (×) → 风险可控性 ✓

  *怎么想到的*：
  - 拉长到20年看，中国股票跑赢债券现金，再平衡效果显著
  - 但站在任一时点，你不知道未来谁会赢
  - 不再平衡会让组合仓位随涨跌漂移，风险逐渐失控

  *边界*：如果你确实能稳定预测资产表现（几乎没人能），那不需要再平衡。

* Q5: 再平衡最大的隐性收益是什么？

  *结论*：不是多赚，是让组合风险始终留在你能承受的舒适区间。

  *形式化*：股票+现金组合: 不操作 → 股票占比飙升 → 风险超承受 | 操作 → 占比回归 → 风险可控

  *怎么想到的*：
  - 不再平衡时股票涨了占比越来越大
  - 市场反转时仓位已超出承受力
  - 被迫在低点割肉的概率大幅上升

  *边界*：固定比例再平衡在极端单边市中（如长期大牛市）会牺牲部分收益。

* Q6: 再平衡发挥作用的根本前提是什么？

  *结论*：你得先有一个明确的"初始配置"比例，否则再平衡无从谈起。

  *形式化*：再平衡 = 拉回目标比例 → 没有目标比例 = 操作无依据

  *怎么想到的*：
  - 再平衡是相对于某个基准的操作
  - 基准来自你的投资目标和风险承受能力
  - 没有目标的再平衡只是随机交易

  *边界*：目标本身可以随人生阶段变化，但每个时点必须有明确配置。

* 收口

作者用五组实测数据戳破了"再平衡万能"的幻觉：它不是收益机器，而是风险纪律。真正决定长期回报的，是你敢不敢在不确定性中保持一个多元结构。
