# 全局地图

## 一句话摘要

行业分析不是一套模板打天下——先判断行业在生命周期的哪个位置，再决定用可行性、规模性、防守性、盈利性、估值这五把尺子中的哪一把。

# 逐段伴读记录

---

## 第1段： analysts' "无所不知"是怎么来的

### 翻译（直译/意译合并——中文原著无需翻译）

原文要点：肖璟经常被问"如何快速了解一个行业"。他发现分析师——尤其是麦肯锡式的咨询分析师和投资领域的券商分析师——被要求在一两周内摸透一个全新的行业。大学时他觉得分析师遥不可及，入行后经历了"祛魅"：研究分析并不是门槛特别高的工作。

### 结构标注

全书问题的引子——用"分析师为什么无所不知"这个读者已有的困惑，制造出学习动机。先立一个"他们也是普通人，只是掌握了方法"的信念，降低读者的心理门槛。

---

## 第2段：两个问题——理论与实际的鸿沟 + 知识割裂

### 翻译

原文要点：商学院教的框架和产业界实际应用之间有鸿沟（实习生背景很好但仍生搬硬套），课本提供的多个概念模型之间彼此割裂——这是市面上所有框架两个致命伤。

### 结构标注

指出痛点——为后面肖璟的"整合框架"铺路。作者要做的不是发明新坑，是把已有的坑连起来。

### 注疏

> **问**：你有没有过这种感觉——学了一堆模型，真到用的时候不知道该用哪个？

如果有，肖璟要做的其实是**教学法的改进**，不是学术创新。他把散落的珠子串成一条链，链的顺序由生命周期决定。

---

## 第3段：第1章 主框架——行业不同发展阶段的分析重点

### 翻译（核心骨架段）

肖璟引入**产业生命周期**作为行研框架的轴心：

- **导入期** — 重点分析**可行性**（这个商业模式成不成？）
- **成长期** — 重点分析**规模性**（市场有多大？公司能上市吗？）
- **成熟期** — 重点分析**防守性**（护城河宽不宽？）→ **盈利性**（龙头能分多少钱？）→ **估值**（花多少钱买划算？）

### 结构标注

全书最重要的一段——这是肖璟的**核心取景框**。后面所有章节（Ch2-8）都是对这五个维度的展开。

### 注疏

> **问**：这个框架让你想到什么？

这个结构其实暗合**-first-principles thinking**——你不能用同一把尺子量所有东西。一个还在验证商业模式的行业，你跟他谈护城河有什么用？一个已经成熟的行业，你还在谈"商业模式可行性"就是在答非所问。

肖璟的贡献不在于发明了PEST或护城河——这些概念巴菲特、波特、安索夫早就在用。他的贡献是给了一面**取景框**：**什么时候看什么**。

---

## 第4段：可行性分析（Ch2）

### 翻译

判断商业模式可行性有两招：

1. **时间对标** — 看历史上有没有类似需求出现过。如果有，说明需求真实；如果历史上反复失败，要警惕。
2. **空间对标** — 看成熟市场（美日韩）有没有类似成功案例。底层假设：人类底层需求相通，成熟市场的今天可能是新兴市场的明天。

然后用**UE模型（单位经济模型）**量化：一个最小交易单位（比如一次外卖、一笔保单）的收入和成本结构。如果最小单位都算不过来，商业模式就是空中楼阁。

市场规模也要手动测算——三种情形下搜不到现成数据：来不及（行业太新）、没动力（行业太小）、做不到（行业不透明）。TAM/SAM/SOM三口径覆盖不同颗粒度。

### 结构标注

分析工具层——不是肖璟的原创（Steve Blank的TAM/SAM/SOM、对标法是常用工具），但做了中国市场的实操落地。

### 注疏

> **问**：空间对标法的一个隐含假设是什么？人类底层需求相通——这是个什么假设？

它其实隐含了一种**趋同论**：中国的发展路径会重复美日韩。这在某些行业（消费电子、互联网）成立，在另一些行业（政策高度干预的行业：教育、医疗、房地产）可能不成立。读者自己判断边界。

---

## 第5段：防守性分析（Ch4）——护城河二元框架

### 翻译

肖璟对巴菲特护城河理论的重新分类：

- **资源垄断**：独占五大生产要素（劳动力、土地、资本、技术、数据）中的某些——比如独家矿产、专利墙、数据垄断。
- **网络效应**：用户越多产品越有价值（微信、支付宝、FB），迁移成本极高。

护城河的本质是**独占**——要么独占资源，要么独占关系。其他因素（成本优势、品牌）是这两种独占带来的**结果**，不是护城河本身。

### 结构标注

肖璟的原创整合——把晨星多尔西的框架（无形资产、成本优势、网络效应、转换成本）重新归并为两条路径，逻辑更清晰。

### 注疏

> **问**：肖璟把"成本优势"视为护城河的**结果**而非**原因**，这和很多人的直觉相悖。你接受吗？

举例：沃尔玛的成本优势来自哪？来自规模经济——来自它门店的数量和密度——这其实是**网络效应**的一种变体（门店网络越密，物流成本越低）。如果你接受这个推理，那么肖璟的框架就是自洽的。

---

## 第6段：盈利性分析（Ch5）——行业集中度 + 产能周期

### 翻译

核心指标是 **CRn**（行业前 n 家市占率之和）。

**产能周期四阶段**：
1. 供不应求 → 产能利用率满
2. 产能激增 → 供给过剩，价格战
3. 产能出清 → 弱者退出
4. 格局改善 → 集中度回升，龙头利润修复

行业集中度随生命周期**先降后升**：导入期高（少数先驱）→ 成长期降（大量进入者）→ 成熟期升（整合/出清）。

集中度天花板因行业而异——可以用**空间对标法**参考成熟市场的终局集中度。空调CR3高（70%+），白酒CR3低（10-20%），这是行业自身属性（标准化程度、规模经济强度、监管）决定的。

### 结构标注

工具层——产能周期四阶段模型 + 集中度天花板判断。

### 碰撞

> **核心问题**：作者这段最想说服你接受的一个点是什么？你接受吗？

他想让你接受的：**行业集中度是盈利能力的先行指标**——集中度提升 → 龙头议价权增强 → 行业利润率改善。投资成熟期行业，核心逻辑就是集中度提升。

你同意吗？

## 第7段：估值（Ch6）

### 翻译

不同生命周期阶段适用不同估值方法：

- 导入期：收入少甚至没收入，用**PS（市销率）**
- 成长期：增速快但利润薄，用**PEG（市盈率相对盈利增长比率）**
- 成熟期：盈利稳定，用**PE/PB**

估值变化来自两部分：盈利增长（接住实打实的业绩）+ 估值变化（PE的变动——市场情绪）。逻辑上，PE的长期中枢由行业增速决定。

### 结构标注

工具层——标准估值教科书内容按生命周期重新排列。

---

## 第8段：外部因素（Ch7）+ 景气度（Ch8）

### 翻译

**外部因素** = PEST（政治/经济/社会/技术）+ **货币三种价格**（购买力、利率、汇率）+ **交易拥挤度**。

**景气度** = 用一篮子行业指标预判业绩增速。景气度上行 → 业绩超预期概率高 → 估值扩张。景气度下行 → 业绩低于预期 → 估值压缩。

### 结构标注

PEST是框架，货币三种价格是肖璟把货币政策对行业的影响做了一个统一处理。交易拥挤度是偏市场微观结构的指标。景气度指标体系在实操层面各家券商有不同版本，书中给的是他团队用的版本。

---

## 第9段：研究本质（Ch10）——三种信息差

### 翻译

研究 = 输入-处理-输出资讯的过程。投资的盈利来自**信息差**：

1. **时间差** — 比别人更早知道（前提：信息准确且未大规模传播）
2. **广度差** — 知道别人没覆盖的领域/角度
3. **深度差** — 对同样的事实，挖掘出更深的洞见

时间差越来越难（信息传播太快），广度差靠勤奋，深度差靠方法论——本书能帮你的主要在深度差。

### 结构标注

肖璟的方法论原创——把研究和赚钱的关系说得非常直白。研究不是目的，信息差才是；信息差不是目的，赚钱才是。这对学术圈的读者来说可能刺耳，但这就是作者的底色。

### 注疏

> **问**：三种信息差中，你觉得普通人（非机构）最容易建立哪一种？

深度差。因为你不是内幕消息链上的人（时间差没戏），你覆盖的广度不可能比券商分析师广（广度差受制于精力），但你可以在**有限的几个行业**里比市场平均理解更深。这就是巴菲特说的"能力圈"——深度偏好于广度。

## 第10段：AI与研究（Ch13）——末章

### 翻译

生成式AI（ChatGPT、Claude等）对行研流程的重塑：

- 可以帮你快速翻译、总结大量文档
- 可以帮你搭建初步的分析框架

- **关键判断**：AI不会替代分析师，但**会用AI的分析师**会替代**不会用AI的分析师**

## Ch1 深度：主框架的展开（用户选读）

### 补充段1：研究对象——"行业"是什么

**原文要点**：行业定义尴尬——按《国民经济行业分类》，行业是"从事相同性质的经济活动的所有单位的集合"。但《南方周末》和今日头条经济活动"性质相同"吗？一个是纸媒，一个是算法平台。又都算传媒行业。

行业边界不是固定的。从横向看——汽水、狗粮、洗护用品可以分属不同行业，也可以统称"快消"。从纵向看——半导体设计、制造、封测完全不同，但同属半导体产业链。

所以谈行业要先定**颗粒度**。找现成的行业分类标准做口径对齐，否则你说万亿市场他说千亿起步，对不上。

**结构标注**：地基段——先校准研究对象。不在定义上花大力气，但必须提醒读者：行业不是自然范畴，是人为切割。切割方式不同，结论不同。

### 补充段2：基本框架——为什么现有框架不够

原文指出两个致命伤：(1) 商学院框架与产业应用有鸿沟——名校实习生照样生搬硬套；(2) 知识点之间割裂——商业模式讲了、产业链讲了，彼此什么关系不知道。结果各个行业都用同一套模板，看似全覆盖实则蜻蜓点水。分析煤炭行业和分析新能源汽车用同一个模板，能得出什么有用结论？

### 补充段3：导入期 / 成长期 / 成熟期画像

**导入期**：产品还没定型 + 只有创新者用户 + 融资侧两套平行现象（真创业 + 骗子蹭概念 + 市值管理）。充电桩、人形机器人典型。

**成长期**：优质产品破圈 → 早期大众入场 → 供不应求 → 毛利率漂亮 → 外部竞争者涌入 → 开始卷。新能源汽车典型。

**成熟期**：新增客户消失 + 产品标准化 + 价格下压 + 毛利率下滑。两条岔路：第二增长曲线 / 稳定市场周期化。

**结构标注**：肖璟把一个常见误解给杀死了——"成熟"不等于"死亡"。成熟期行业如果有稳固格局和定价权，反而可能是现金流最好的阶段（白酒、空调）。

## Ch10-11 深度：研究本质 + 分析方法（用户选读）

### 三种信息差（核心骨架段）

```
信息差类型    怎么赚                难度        时效
──────────────────────────────────────────────────────
时间差        比别人先知道          极难(信息透明)   越来越窄
广度差        知道别人不知道的领域   中等           长期有效
深度差        对同样事实挖得更深     靠方法论       最持久
```

**时间差**：罗斯柴尔德家族的故事——但在微信群时代几乎不可能。另类数据（爬虫、卫星图、信用卡流水）是当代制造时间差的工具。

**广度差**：覆盖别人没覆盖的行业/角度。

**深度差**：同样一份财报，你读出了别人没读出的东西。深度差靠方法论——本书能帮的主要在这一层。

**隐含前提**：市场是无效的，深度研究能产生超额收益。如果市场是强有效的，深度差不存在。

### DIKW 模型

```
原始数据 ──→ 信息 ──→ 知识 ──→ 智慧
(Data)     (Info)    (Knowledge)  (Wisdom)
  │           │          │           │
  ▼           ▼          ▼           ▼
未经加工    经处理且    经过滤、    能挖掘有用
的事实     有逻辑关系  提炼、整合  信息、做出
                                正确判断
                                的方法论
```

关键区分：**事实判断**（客观可证伪）vs **价值判断**（因人而异）。高质量的价值判断必须有事实判断支撑。

多数人的研究停在"信息"层（收集数据），没到"知识"层（形成判断），更没到"智慧"层（方法论）。

### 信息茧房

你看到的世界不是完整的世界。肖璟的解法：每形成一个判断，问自己"最强反驳是什么"。

### 假设驱动

传统研究：先搜集所有信息 → 整理成报告。假设驱动：先初步调研 → 提出假设 → 找证据验证/证伪 → 修正 → 循环。

假设可以错，但有假设比没假设强——因为没假设你连找证据的方向都没有。

### MECE / 金字塔 / SCQR

标准麦肯锡方法论——不是肖璟原创，但是行研必须掌握的思维工具。结论先行 + 以上统下 + 相互独立完全穷尽 + 情景-冲突-问题-解答。

## 实操：美团行研记录（按肖璟框架）

### 生命周期定位

本地生活服务业 → **成长期末段/成熟期早期**。外卖渗透率 ~28%（一二线 >50%），增速从 60% 降至 15-20%，商业模式早已验证（UE 为正、上市公司盈利），但 2024-2025 年字节抖省省/京东到家/抖音外卖同时进入。

### 规模性

- 餐饮外卖 TAM：餐饮零售总额 5.5 万亿 × 线上化率 ~28% = 当前 SAM ~1.5 万亿
- 2030 SAM ~2.5 万亿（假设线上化率 → 40%）
- 参考韩国线上化率 ~50%+，天花板 40-50% 之间，中间 1.5-2x 空间
- 美团 TAM 不只是外卖——本地生活整个池子（到店餐饮、酒旅、闪购、社区团购、到店综合）15-20 万亿级
- UE：美团外卖单均 UE ~1.5-2 元（密度越大配送成本越低）

### 防守性（护城河二问）

**资源垄断（弱）**：不独占土地、不垄断关键技术、骑手灵活用工不可独占。

**网络效应（强）**：
- 7 亿年交易用户 + 千万级商户 → 供需匹配效率 → 竞争者冷启动几乎不可能
- 密度效应：相邻订单越多 → 单均配送成本越低 → UE 越宽 → 正循环
- 数据飞轮：用户和商户经营数据 → 供需匹配效率持续提升

**2024-2025 威胁**：抖音用**流量垄断**+**内容分发**切入团购及外卖——不完全在同一维度打，是用"内容 → 即时配送"重新框战场。美团的反击是把外卖进一步与到店融合（"到家到店一体化"），护城河纵向外拓。

**判断**：护城河深，但不是无死角——抖音攻侧翼，美团守纵深。

### 盈利性

- CR2 ~ 90%（美团 ~65% + 饿了么 ~25%）
- 全球对标：韩国 ~85%、美国 ~70% → 寡占型
- 集中度下一步：按肖璟逻辑 → 外卖已跨过"成长期集中度下降"，随增速放缓应自然提升
- **但**：抖音威胁不是"抢外卖份额"——是在外卖侧蚕食 + 在到店侧用内容流量蚕食，后者利润率远高于配送
- 外卖产能周期：2018-2022 运力供给不足 → 2024-2025 抖音/京东加入抢商家资源 → 四家补贴消耗 → **产能过剩阶段**，集中度短暂下降后回升

**天花板**：韩国 Baemin 一家独大。如果中国外卖终局 CR1 >70%（美团单边），还有上行空间。但抖音把"赛道"和"城堡"边界模糊了。

### 估值

- 当前 PE 15-20x（历史区间 15-50x）
- 低 PE 定价三件事：外卖增速放缓 + 团购受抖音冲击 + 社区团购亏损收窄仍有不确定性
- 若集中度进一步上升（美团稳态利润走阔），PE 走阔
- 关键：如果抖音外卖份额 >15%，是正面挑战，PE 被压在 15x 合理；如果抖音烧不动配送，PE 回到 25-30x 不意外

### 外部因素校准

- 政治：2021 反垄断处罚 34 亿但定性为"规范发展"中性偏好
- 经济：必选消费韧性 > 可选消费，外卖偏刚需
- 利率/汇率：港股对美联储加息敏感 + 人民币贬值对海外投资人是利空
- 交易拥挤度：中概互联网 ETF 持仓集中 → 如果看空情绪拥挤反而是不差的入场点

### 景气度

- 上行：外卖渗透率爬坡 + 骑手供给增速放缓 + 到店修复
- 下行：抖音外卖份额 >10% + 宏观断崖 + 骑手社保政策提高成本
- 当前：中性偏上——美团外卖 UE 持续改善 + 调整后净利润转正

### 综合判断

```
维度         判断    信号
─────────────────────────────────
生命周期      成长期末/成熟期早期   渗透率 28%, 增速 15-20%
可行性         ✅ 早已验证        上市公司盈利 3 年+
规模性         ✅ 中等空间         TAM 还有 1.5-2x
防守性         ⚠️ 深但有侧翼威胁   配送网络 +7亿用户, 但抖音攻到店
盈利性         🟡 集中度存疑       CR2 90%, 但抖音增加变数
估值           ⚠️ 低 PE 定价       PE 15-20x, 反映悲观预期
─────────────────────────────────
综合判断      ⭐⭐⭐½      买入 650-700 HKD 以下 / 中性 700-900 / 高估 >900
```

### 肖璟框架在美团上的缺口

肖璟的护城河二元框架假设护城河里只有一条船（独占资源或独占关系），但**两个不同形态的护城河交叉覆盖同一批商家/用户**时，谁赢谁失不是用 CRn 能观测的——这是平台形态的竞合。

美团 vs 抖音不是"谁的护城河更深"——是"配送网络的密度优势"vs"内容平台的流量爆发力"，两个维度在同一批商户身上角力。肖璟的框架没有处理这个。

## 维度一：可行性（Feasibility）——"这事成不成"

> **适用阶段**：导入期（行业刚诞生、商业模式未被验证）。
> **核心问题**：这个商业模式跑得通吗？

### 1.1 评估分两步

| 步骤 | 评估什么 | 核心问题 |
|:---:|:------:|:-------:|
| 第一步 | **销售可行性** | 卖得出去吗？需求是真实的还是伪需求？ |
| 第二步 | **利润可行性** | 能赚到钱吗？收入能覆盖成本吗？ |

导入期很多公司不赚钱（京东烧了10年、B站至今仍亏），但**必须让投资者看到未来能赚钱的可能性**。

### 1.2 销售可行性：两种对标法判需求真伪

**时间对标**——往前看，历史上是否有同样需求被不同方案满足过。

> 底层假设：**需求是永恒的，方案是变化的**。成功的商业模式不是创造新需求，是用新方案满足已有需求。

| 永恒需求 | 历代解决方案 |
|:------:|:---------:|
| 在家快速吃饭 | 干粮 → 方便面 → 电话外卖 → 互联网外卖 → 预制菜 |
| 出行 | 走路 → 轿子马车 → 汽车 → 网约车 |
| 传递文字 | 飞鸽传书 → 电报 → 短信微信 |
| 听音频资讯 | 茶馆说书 → 广播电台 → 播客 |

反例：**共享篮球**——以前没有篮球租赁需求（篮球不贵、不占地方、打球总能找到球），共享篮球在满足一个从未存在过的需求 → 伪需求。

**空间对标**——横向看，成熟市场（美日韩）有无成功案例。

> 底层假设：**人类底层需求相通**，成熟市场的经验可作参考。

这就是孙正义的"时光机理论"和 C2C（Copy to China）模式的底层逻辑。案例：海外有 Yahoo → 搜狐 / 海外有 Google → 百度 / 海外有 eBay+PayPal → 淘宝+支付宝 / 海外有 Twitter → 微博。

**失政情形**：对标对象本身也是新生事物（Clubhouse 2021年国内跟风者全部失败）或政治/经济/技术/社会文化差异过大。

### 1.3 需求排序矩阵：频次 × 弹性

通过销售可行性后（需求确实存在），还要看**这个需求好不好赚钱**——用两个维度排序：

```
              弹性小              弹性大
           (刚性需求)           (可替代)
         ┌──────────────┬──────────────┐
  频次高 │  ✅ 最佳        │  🟡 还行       │
         │  例：吃饭、理发   │  例：猪肉      │
         │  毛利 40-60%    │  可换牛羊肉    │
         ├──────────────┼──────────────┤
  频次低 │  🟡 凑合        │  ❌ 最差       │
         │  例：婚庆       │  例：景点骑马   │
         │  一辈子一次     │  可选可不选    │
         └──────────────┴──────────────┘
```

**简单判据**：频次高 + 弹性小，至少占一样，才可能有好收入。

中欧商学院龚焱教授的东南亚太阳能案例：当地人缺电但不缺照明（已适应黑暗），**真正刚需是制冰**——不做调研找不到这个。

### 1.4 成本面：标准化程度决定能不能赚钱

- 标准化程度越高 → 综合成本越低 → 规模复制越容易
- 海底捞选火锅不选川菜，就是因为火锅标准化程度高
- 但标准化也限制定价：SaaS 软件比战略咨询便宜，因为前者高度标准化，后者高度定制

### 1.5 利润可行性：UE 模型（单位经济模型）

**核心公式**：如果最小运作单位都赚不到钱，规模化复制就不可行。

**最小运作单位因行业而异**：

| 行业 | 最小运作单位 |
|:---:|:---------:|
| 餐饮 | 一家门店（"单店模型"） |
| 网约车 | 一辆车一年 |
| 美妆 | 一款单品（如一瓶护手霜） |
| 外卖 | 一个订单 |
| 剧本杀 | 一家门店（案例中单店利润率 38.2%） |

华创证券剧本杀 UE 模型案例：门店最大支出是 DM（主持人）工资 + 租金，算下来利润率 38.2% → 可以考虑开更多店。

### 1.6 验证方式的两种思路

| 方法 | 谁做 | 怎么做 |
|:---:|:---:|:-----|
| **调研法** | 有资本优势的快消品企业 | 问卷调查 + 24h 用户追踪 + 甚至翻垃圾桶 + 焦点访谈 |
| **试错法** | 创业者和 VC | 创业者亲自下场 / 赛道投资（红杉中国投了美团+大众点评、饿了么、唯品会+聚美优品，让创业者帮自己验证哪个模式行） |

二级市场参考：投资有快速迭代能力的企业，或买行业 ETF / 主题基金。

> **肖璟的核心信仰**：投资 = 权衡胜率 × 赔率。导入期目标不是 100% 胜率，而是确保**胜率不是 0%**。

## 维度二：规模性（Scalability）——"市场有多大"

> **适用阶段**：成长期。
> **核心问题**：这个市场能孕育出上市公司吗？未来 3-5 年增速多少？

### 2.1 三种情形下必须自己测算

| 情形 | 原因 | 例子 |
|:---:|:----:|:---:|
| 来不及 | 行业太新 | 共享单车（初期每天投放数千辆，统计跟不上） |
| 没动力 | 行业太小，数据卖不出去 | 糖葱薄饼、照片修复 |
| 做不到 | 行业不透明/保密 | 军工、部分服务业 |

### 2.2 三种市场口径（核心框架）

```
      ┌─────────────────────────────┐
      │      TAM（潜在市场）           │  ← 全行业天花板
      │   ┌─────────────────────┐   │
      │   │   SAM（可服务市场）    │   │  ← 当前已被满足的需求
      │   │   ┌─────────────┐   │   │
      │   │   │ SOM（可获得） │   │   │  ← 一家公司拿到的
      │   │   └─────────────┘   │   │
      │   └─────────────────────┘   │
      └─────────────────────────────┘
```

**关键比率**：
- SAM ÷ TAM = 渗透率（判断行业在哪个阶段）
- SOM ÷ SAM = 市场份额（判断公司竞争力）

**不同阶段关注不同口径**：

| 行业阶段 | 关注口径 | 为什么 |
|:------:|:------:|:------|
| 导入期 | TAM | 判断公司能不能上市（A股科创板要求营收 ≥3亿） |
| 成长期 | TAM + SAM | 判断离瓶颈还有多远 |
| 成熟期 | SAM + SOM | 集中度提升逻辑（龙头吃份额） |

投资人刘小鹰的经验法则：**细分市场容量看不到 500 亿的基本不投**。

### 2.3 三种测算方法（含公式）

#### 方法 1：需求导向——算 TAM

**核心公式**：

```
市场规模 = 目标客户数 × 渗透率 × 客均订单量 × 客单价
```

**案例 1：中国一年消费多少猪肉？**
- 目标客户：13.87 亿（不含回民等少数民族）
- 渗透率：97%（扣除 3% 素食者）
- 客均订单量 = 每餐肉量(100g) × 猪肉占比(50%) × 2餐 × 365天
- 客单价：12元/千克（用低价估天花板）
- **结果：约 5900 亿元**

**案例 2：北京家用地毯**
- 目标客户：2000万人口
- 渗透率：50%
- 客均订单量：0.25 张/年（每 4 年换一次）
- 客单价：200元
- **结果：5 亿元**

**进阶情形**（渗透率不稳定，成长期）→ 拆成新增购买 + 替换购买两部分：

**现制茶饮 2030 年规模测算**（案例 9）：
- 目标客户：2.5 亿城镇青年（3.57 亿 × 70%城镇化率）
- 渗透率：80%（从当前 74% 推）
- 年消费杯数：44.2 杯/年（对标台湾当前 0.85 杯/周）
- 杯单价：18.8 元（从当前 14 元按年增 3% 推）
- **结果：1661.92 亿元**（卖方测算 2260 亿元——关键假设不同）

> **提高精度的两个办法**：(1) 更细分分颗粒度（分层/分年龄/分区域）；(2) 更可靠的假设（对标法 > 拍脑袋，草根调研 > 专家访谈 > 纯直觉）。

#### 方法 2：供给导向——算 SOM

适用：评估某家具体公司/门店能挣多少钱。

**核心思路**：找瓶颈环节（供给能力的极限）。

**案例：蜜雪冰城单店年销售额**
1. 找流程：点单+收银（30秒） → 制作（120秒/杯） → 瓶颈在制作
2. 加人优化：3人制作 + 1人点单收银 → 40秒/杯
3. 忙时闲时拆分：忙时 5h（满负荷） + 闲时 7h（半负荷）
4. 一天销量：765杯 × 6元/杯 × 30天 ≈ 14万元/月

> **学浑水做瑞幸做空调研**：92 名全职 + 1418 名兼职，全国 53 城市门店全天候录像——供给导向的极端版本。

**案例：香港工银大厦楼下星巴克年销售额**（麦肯锡面试题）= 纯供给导向题。

#### 方法 3：供需匹配——"以大见小"或"以小见大"

**强假设**：供需之间存在稳定比例关系。

适用两种情况：
- 行业已是成熟期，TAM ≈ SAM（供需平衡）
- 产品是中间品/互补品，与下游保持稳定匹配关系

**案例 5：香港有多少台 ATM？**
- "以小见大"：中文大学 1万师生 / 5台 ATM = 2000人/台
- 香港 700 万人 / 2000 = **约 3500 台**

**案例 6：某县级市金融从业者数量**
- "以大见小"：全国 141178万人口 / 1831.6万从业者 = 77人/从业者
- 县级市人口 ÷ 77 = 结果

> **注意**：供需匹配法不能用来证明"落后于平均"——因为算出来就是平均水平。

**案例 7：中国住宅电梯保有量**（综合案例）
1. 一线城市电梯总量（市场监管局数据）× 住宅占比（~50%，上海 50-60%，北京 48-50%）
2. 新一线城市 + 推算宁波佛山（用 99人/电梯均值 × 人口）× 住宅占比（~55%）
3. 二线三线继续拆分

> **肖璟心法**：把需要推测的**未知量拆解成多个可以找到或合理假设的已知量**。

### 2.4 测算终极检验

- **量级对不对**？——和常识对对标
- **假设是否保守？**——天花板用低价估、渗透率高估一点
- **三种方法交叉验证**——同一道题用需求导向和供给导向各算一遍，看差距

## 维度三：防守性（Defensibility）——"护城河宽不宽"

> **适用阶段**：成熟期。
> **核心问题**：如果竞争对手来了，守得住吗？会被替代品革命吗？

### 3.1 护城河二元框架（肖璟原创整合）

晨星多尔西原有 4 要素（无形资产、成本优势、网络效应、转换成本）有两个问题：漏掉了重要护城河 + 有些互为因果。

肖璟重新归纳为**两条路径**：

```
                  护城河
                 ╱      ╲
                ╱        ╲
      资源垄断护城河    网络效应护城河
      (独占生产要素)    (独占生产关系)
          │                 │
    ┌─────┼─────┐           │
    ▼     ▼     ▼           ▼
  劳动力 土地 资本 技术 数据   用户网络
```

**关键澄清**：成本优势、品牌、转换成本，都是护城河带来的**结果**，不是护城河本身。

### 3.2 五类生产要素逐一分析

#### 劳动力（一般很难构建护城河）
- 人自由、可替代
- 例外：极少数稀缺人才（明星、明星企业家、明星老师）
- 但违约金给够了就能挖走 → 护城河脆弱
- 案例：经纪公司/MCN/教育培训机构/画廊——合同越来越短（8年→3年），音乐人自己发抖音

#### 土地（能构建，两种形式）
- **资源禀赋**：
  - 采矿业：高品位富矿利润天然高
  - 戴比尔斯：曾控制全球 90% 产量 → 操控价格
  - 沙特阿美：顶级油气资源 → 全球市值最高
  - 茅台：红缨子高粱 + 贵州气温湿度微生物 → "老天爷给饭吃"
  - 风电/水电/光伏对地形气候海拔有特定要求
- **位置优势**：
  - 房子位置 → 影响交易成本（运输+交付）
  - 深圳华强北：硬件创业者都住在因为采购成本极低
  - 新加坡：马六甲海峡出海口 → 船舶修理业务天然好做

#### 资本（重资产行业天然壁垒）
- 汽车/金融/房地产/互联网等行业资金门槛极高
- 马太效应：有钱人更容易借钱 → 资本壁垒自我强化
- 某 VC 合伙人认识的"富二代"在别墅区挨家敲门，一晚上募集 8000 万美元
- **但**：所有护城河都能用钱绕开 → 资本是"最硬也最软"的护城河
- 2018年 52 家造车新势力 → 2020 年只剩 9 家

#### 技术（专利/版权/秘方/know-how）
- **专利**：
  - EDA 领域：新思科技 4463 项专利（31%）+ 楷登 3119 项（21.6%）
  - IBM 专利墙：1997 一年注册的专利就一面墙
  - 华为排名全球第四（2022年）
  - **软肋**：技术更新周期短 → 4G 专利到 5G 大打折扣
- **版权**：
  - 迪士尼米老鼠：1928年创作，原本1984年到期 → 两次游说国会延期（"米老鼠条款"）→ 803亿美元收入历史第四
  - 版权比专利更持久
- **秘方/know-how**：
  - 可口可乐：全球仅 2 人知道 → 不能同乘一架飞机
  - 片仔癀/云南白药：国家级保密配方
  - 锂电池负极原材料配比：璞泰来四大核心技术之一
  - 农夫山泉钟睒睒评恒大冰泉"砸 13 亿广告三年亏 40 亿"：**拼的是对水的知识积累**

> **消费者要的是带孔墙，不是电钻** — 技术壁垒的极限：另一条技术路线可以绕过（激光枪替代电钻）。

#### 数据（数字经济时代最重要的护城河）
- 机器学习 = 投喂大量数据 → 算法迭代 → 数据成为护城河
- 肖璟亲身案例：GradChef（留学推荐工具）收集几万条数据 → 远远不够（上千本科院校 × 上百专业 × 冷门专业只有一两个样本点）→ 被教育集团收购 → **数据护城河他们跨不过去**
- 数字经济 2023 年 56.1 万亿元，占 GDP 44% → 数据是数字经济的基础

### 3.3 网络效应护城河

（篇幅所限此处引用书中第 4 章下半部分）

网络效应 = 用户越多 → 产品越有价值 → 迁移成本越高 → 新用户更多

- 典型：微信、支付宝、Facebook、美团外卖（商家-骑手-用户三边网络）
- 与资源垄断的区别：网络效应是**关系**的独占（不是资源的独占）
- 衡量：用户数 × 连接数 → 梅特卡夫定律

### 3.4 护城河与生命周期

成熟期三种可能：
1. 被替代品革命 → 衰退期
2. 找到第二增长曲线 → 从导入期重新开始
3. 防守成功 → 进入**稳定市场周期化**（周期性行业：银行/白酒）

## 维度四：盈利性（Profitability）——"头部能分多少钱"

> **适用阶段**：成熟期 + 稳定市场周期化。
> **核心问题**：行业格局往哪走？龙头的利润弹性来自哪里？

### 4.1 核心指标：行业集中度（CRn）

**CRn** = 前 n 名公司的市占率之和。常见 CR3/CR4/CR5/CR8。

**市场结构判据**：

| CR8 区间 | 市场结构 | 投资逻辑 |
|:-------:|:------:|:-------:|
| 0-20% | 分散竞争型 | 挑成长空间大的给溢价 |
| 20-40% | 低集中竞争型 | 看谁份额扩张 |
| 40-70% | 低集中寡占型 | 龙头享受估值溢价 |
| 70-100% | 极高寡占型 | 寡头 PE 差异不大 |

**历史验证**：从有色金属到家电，营业利润率随 CR8 同方向变化。

> **数据陷阱**：CRn 通常只覆盖上市公司。餐饮住宿行业 CR8 数据 90%+ 不是因为集中度高，是因为上市的餐饮公司极少 —— 要手动用上市公司营收加总 ÷ 全行业市场规模。

### 4.2 行业集中度为什么变化——产能周期四阶段

**肖璟的核心原创框架**：

```
Stage 1          Stage 2          Stage 3          Stage 4
供不应求    →   产能激增    →   产能出清    →   格局改善
│               │               │               │
▼               ▼               ▼               ▼
订单排到门口     跟风者涌入        弱者倒闭/被兼并    集中度回升
产能利用率 100%  供过于求价格战    部分厂商退出       龙头利润修复
毛利率最高      毛利率受压        幸存者扛住         戴维斯双击
```

**对应行业生命周期的集中度变化**：

```
集中度
  │
  │ ╲                                    ╱─── 衰退期（少数存活）
  │  ╲             成熟期              ╱
  │   ╲           ╱───╲          ╱───
  │    ╲    ╱────╱     ╲   ╱────
  │     ╲──╱ 成长期       ╲╱ 产能出清
  │     导入期（先驱少）
  └──────────────────────────────── 时间
```

| 阶段 | 集中度方向 | 原因 |
|:---:|:--------:|:----:|
| 导入期 | 高（少数先驱） | 只有创新者入场 |
| 成长期 | **下降** | 商业模式验证 → 大量进入者 |
| 成熟期 | **回升** | 兼并重组、产能出清 |
| 衰退期 | 高（少数苟活） | 替代品威胁、市场萎缩 |

**A 股四大行业 CR3 实证**：
- 白酒（必选消费）：集中度低位震荡
- 空调（可选消费）：集中度上升到高位
- 挖掘机（周期）：集中度明显上升
- 智能手机（科技）：集中度快速上升

### 4.3 集中度天花板因行业而异

**终局集中度不同**：空调 CR3 70%+ vs 白酒 CR3 10-20% → 由行业自身属性决定。

**判断天花板的方法：空间对标**——看成熟市场同一行业的 CRn。

| 行业 | 中国 CRn | 国际对标 | 方向 |
|:---:|:-------:|:------:|:---:|
| 空调 | 高(70%+) | 日本 80%+ | 已触顶 |
| 白酒 | 低(10-20%) | 分散 | 周期震荡 |
| 智能手机 | 高 | 韩国 80%+ | 已触顶 |
| 运动饮料 | 中等 | 美国 60% | 有空间 |

### 4.4 影响集中度变化的外因

| 因素 | 方向 | 传导 |
|:---:|:---:|:----|
| 经济下行 | 集中度升 | 中小企业先死，龙头熬到春天 |
| 经济上行 | 集中度降 | 中小企业活下来抢份额 |
| 刺激需求政策 | 集中度降 | 阿猫阿狗都活 |
| 限制供给政策 | 集中度升 | 落后产能出清（供给侧改革、双碳） |

### 4.5 产能周期的触发机制（宏观 → 微观）

产能 = 资本 + 劳动力充分利用后的最高产出。

产能利用率 = 实际产量 ÷ 最大产能。

企业家调产能的逻辑：
1. 需求提升 → 先满负荷生产
2. 确认是长期需求才扩产能（因为投产能是真金白银）
3. 调整时滞 → 系统性超调 → 产能周期

**稳定市场周期化**：成熟期行业 TAM ≈ SAM，供需随宏观和产能周期波动 → 从成长股变周期股。银行、白酒是典型。

## 维度五：估值（Valuation）——"值多少钱买"

> **适用阶段**：成熟期（但全阶段需要）。
> **核心问题**：这个阶段该用什么估值方法？PE 中枢在哪？

### 5.1 基础公式

```
公司市值 = 净利润（基本面） × 估值倍数（PE）
```

PE = 公司市值 ÷ 净利润 = **净利润保持不变情况下的回本周期**。

包子店例：年净利 100 万，卖 500 万 → PE = 5 倍 → 5 年回本。

**一般规律**：业绩增速越快 → 估值倍数越高（今年赚 100 万，明年赚 1000 万 → PE = 100 倍也合理）。

### 5.2 各阶段适用估值方法

| 行业阶段 | 估值方法 | 原因 |
|:------:|:------:|:----|
| 导入期 | VC 估值法 / PS（市销率） | 没利润甚至没收入 |
| 成长期 | PEG（市盈率相对盈利增长比） | 利润在增长但不高 |
| 成熟期（稳定周期化） | PE / PB | 盈利稳定 |
| 衰退期 | 低估值 / 清算估值 | 给很低，且"低≠买入" |

### 5.3 PE 变化的来源

```
股价变化 = 盈利增长（接住业绩） + 估值变化（PE 变动，市场情绪）
```

- 中长期 PE 中枢由**行业增速**决定
- 短期 PE 波动由**市场情绪**驱动
- 投资成熟期行业：赚钱来自集中度提升 → 龙头利润走阔 → PE 修复 → **戴维斯双击**

## 维度六：外部因素（Political/Economic/Social/Technological）

> **适用阶段**：全阶段校准。
> **核心问题**：还有什么外部力量会改变行业的走向？

### 6.1 政治因素

**产业政策两大类型**：
- **扶持性**：口头鼓励 / 补贴减税 / 直接投资 / 强制使用
- **限制性**：限制准入 / 限制供给 / 限制价格 / 限制受众

**国际政治**（对中国市场冲击最大的两项）：
1. 美国货币政策（美联储加息/降息）
2. 美国外交政策（贸易战/科技封锁）

> "水可载舟亦可覆舟"——曾经推动行业发展的驱动力（如税收优惠）到期后也会变成限制性因素。

### 6.2 经济因素 A：经济周期

**行业对经济周期敏感度排序**：

```
金融 > 周期 > 消费 > 成长
```

| 类型 | 敏感度 | 细分 |
|:---:|:----:|:----|
| 金融 | 最高 | 银行和宏观一荣俱荣一损俱损 |
| 周期 | 高 | 钢铁/有色/工程机械/交建——经济好才有需求 |
| 消费 | 分化 | 必选（调味/农林牧渔）抗周期；可选（汽车/服装/休闲食品）跟随周期 |
| 成长 | 低 | 新能源汽车等——渗透率提升的正效应 > 经济下行的负效应 |

**周期影响海外**：海外需求占比高 + 原材料高度依赖进口的行业还会受海外周期影响。

### 6.3 经济因素 B：经济发展水平

当前中国人均 GDP 12,174 美元（2023年），正在跨越"1-3 万美元"阶段。

对标美英德日韩等 11 国数据，三件事会发生：
1. **农业规模化**：98%+ 还是小农户 → 集约化空间巨大
2. **制造业升级+转移**：高技术占比提升；纺织/皮革外迁
3. **服务化+消费升级**：
   - 生产性服务业（CRO/CMO/CSO 独立化）
   - 观光游 → 休闲度假游转型
   - 人均收入 2000→5000 美元阶段是关键切换点

### 6.4 货币因素：三种价格的历史性统一框架

**货币三种价格** = 三个市场的价格：

```
央行发出来的钱
    │
    ├─→ 想买商品的人 → 商品市场 → 货币购买力（物价/通胀）
    ├─→ 想贷款的人   → 利率市场 → 利率
    └─→ 想换外币的人 → 外汇市场 → 汇率
```

| 价格 | 上升对行业的影响 |
|:---:|:------------|
| 货币购买力 ↓（通胀） | 必调价行业受益（调味品/榨菜/农产品）；恶性通胀全行业受伤 |
| 利率 ↓ | 借贷成本降 → 企业扩投资 + 消费者加消费 → 经济复苏 |
| 利率 ↑ | 借贷成本升 → 估值承压 + 投资收缩 |
| 人民币贬值 | 利好出口，利空进口 |
| 人民币升值 | 利好进口，利空出口 |

**经典案例**：PayPal "美国版余额宝" 2008 年金融危机后 → 美国长期零利率 → 货币基金收益率骤降 → PayPal 2011 年清盘此功能。

### 6.5 社会文化

**人口统计学**：
- 老龄化加速：60+ 2025年破 3 亿（>20%），2035年破 4 亿（>30%）
- 劳动力供给收缩（15-64岁占比 2010 年触顶）→ 催生自动化需求
- 体力劳动者减少 → 薪酬提升 → 韩国工业机器人密度 5 年翻番
- **工程师红利**：2024 年高校毕业生 1179 万 → 中国制造业升级的真正壁垒

**文化变迁**：
- 健康意识觉醒：沙拉轻食崛起 / 碳酸饮料下滑 → 无糖饮料和包装水上升
- **国潮**：00 后文化自信 → 李宁/毛戈平/茶颜悦色爆发

### 6.6 技术因素

**技术创新三大作用**：
1. 让新兴行业商业模式**变得可行**（没有移动互联网就没有网约车）
2. **降本增效** → 新品类替代旧品类
3. 创造**新渠道**（电商让小家电崛起）

**创新层级金字塔**（从底向上）：
```
        生态参与者
        ┌────────┐
        │ 应用层  │  ← 商业模式创新
        ├────────┤
        │ 操作系统 │
        ├────────┤
        │ 硬件层   │
        ├────────┤
        │ 基础设施 │  ← 技术创新
        └────────┘
```

一般创新从底层向上走。PC 互联网 → 移动互联网两条完整波形，每个层级的颠覆都是在上一个层级剧变后完成的。

**技术成熟度曲线**（Gartner Hype Cycle）：
1. 萌芽期 → 期望低
2. 热度涌入 → 泡沫膨胀
3. 泡沫破裂 → 估值低谷
4. 产业落地 → 期望恢复稳定 → 成熟

> 看点：多家龙头同时加资本开支 + 大规模产线落地 = 技术进入产业化阶段。

### 6.7 外部因素小结

| 维度 | 核心变量 |
|:---:|:------|
| 政治 | 产业政策（扶持/限制）/ 国际政治（美国货币+外交） |
| 经济 | 经济周期 + 经济发展水平 |
| 货币 | 购买力/利率/汇率 |
| 社会 | 人口统计学 + 文化变迁 |
| 技术 | 创新推动作用 + 成熟度曲线 |

## 维度七：景气度（Heat Index）——"接下来毛利率会不会涨"

> **适用阶段**：全阶段，特别适用于轮动和择时。
> **核心问题**：下季度/下一年的业绩会不会超预期？

### 7.1 为什么需要景气度

中长期判断（前六维）都是建立在假设上。外部因素会变、历史经验可能失效。

问题：**公司财报按季更新，太慢**。等报表出来再做研究，很可能别人已经减完了。

**解法**：找一篮子**高频指标**（按月/周/日更新）先于报表判方向。

**景气度指标的两个必要条件**：
1. 能反映基本面 → 判断业绩方向
2. 更新频次够高 → 领先于报表

两类指标：
- **前瞻性指标** → 感知趋势
- **高频同步指标** → 跟踪验证

### 7.2 纵向——产业链上下游找核心驱动环节

**原理**：下游需求不给力 → 上游也不会好；找到核心驱动环节 → 判断整条产业链。

| 产业链 | 核心驱动环节 |
|:-----:|:----------|
| 新能源汽车 | **下游**——新能源汽车销量 |
| 5G | **中游**——移动通信基站设备 |
| 房地产 | **中游**——房地产销售 |
| 半导体 | 下游消费电子 + 汽车对芯片的需求 |
| IDC/AI | **中游**——软件业务收入 |

**房地产对产业链的影响**：

```
房地产销售上涨
    │
    ├─→ 上游受益：工程机械、金属矿采选、建筑、煤炭/油气
    └─→ 下游受益：家电、家具、装修、餐饮教育医疗家政配套
```

> 房地产客单价极高 + 产业链又长又宽 → "行业之王"。

### 7.3 横向——行业本身的关键指标

| 行业类别 | 关键景气度指标 | 为什么 |
|:------:|:------------:|:-----|
| **上游原材料** | 价格 + 库存 | 成本相对固定，价格涨的全部变利润 |
| **中游制造业** | 产销量 | 价格波动小 → 量是利润的明牌 |
| **必选消费** | CPI（通胀） | 可跟涨不影响销量 → 涨价全变利润 |
| **可选消费** | 房地产销售 | 家电/汽车/建材/家具是地产后周期 |
| **服务业** | 宏观总量指标 | 金融/交运/公用事业与宏观同步 |
| **新兴行业** | 自身产业周期 | 渗透率/产品迭代 |

**白酒行业详例**（书中唯一一节完整景气度案例）：

核心指标——**批价（批发价）**。

| 批价信号 | 含义 |
|:------:|:---|
| 批价上行 | 供不应求 → 可提计划外供货 / 投更高端非标品 / 直销投放 → 业绩向好 |
| 批价下行 | 需求变弱或供给过剩 → 风险 |

**批价作为核心指标的三优势**：
1. 数据可得性强——"今日酒价"公众号每天更新
2. 及时反映供需——批价上涨 → 出厂价上限上调 → 业绩直接受益
3. 体现品牌力——批价稳定上涨 = 护城河加宽 = 估值溢价

**数据佐证**：
- 茅台股价 vs 批价：相关系数 **0.95**（2017-2021）
- 五粮液股价 vs 批价：相关系数 **0.81**
- 2019年茅台批价跌破 2000 → 股价跌超 10% → 年内破 3000 → 股价接近翻倍

**补充指标**：
| 指标 | 含义 | 怎么拿 |
|:---:|:----|:-----|
| 经销商库存 | 远超往年且非主动囤货 → 销售变差或压货 | 草根调研 + 专家访谈 |
| 经销商打款 | 提前打款且金额多 → 预期乐观 | 专家访谈 |
| 开瓶率低 | 囤货需求而非真实消费 → 未来隐患 | 草根调研 |

> **注意**：短期几百元批价波动可能只是"拆箱令"等政策因素或经销商趋同交易——**不能刻舟执剑，要理解指标背后的逻辑。**

## 第10章：研究基础——"研究的本质是什么"

### 10.1 研究 = 输入·处理·输出（核心定义）

OECD 定义：研究及开发活动是为了增加知识储备而进行的**创造性和系统性**的工作。

肖璟极简版：**研究 = 输入资讯 → 处理资讯 → 输出资讯**。

| 类型 | 对应 | 是什么 |
|:---:|:----:|:------|
| 一手研究 | 行万里路 | 实验、观察、分析——搞出新东西 |
| 二手研究 | 读万卷书 | 总结已有知识，用新形式呈现 |

> 无论哪种，本质都是对资讯的加工——你在微信群看到一条消息、判断真伪、据此交易，就已经是"研究"了。

### 10.2 三种信息差——研究如何创造财富（肖璟方法论最值钱的一段）

**核心命题**：研究不直接赚钱，**信息差**才赚钱。

```
信息差类型    怎么赚                难度        时效        适合谁
──────────────────────────────────────────────────────────────────────
时间差        比别人先知道          极难        越来越窄     机构（有另类数据来源的）
广度差        知道别人不知道的领域   中等        长期有效     媒体/广告/多行业从业者
深度差        对同样事实挖得更深     靠方法论    最持久        ✅ 普通人最该建
```

#### 时间差——可遇不可求

**经典案例**：罗斯柴尔德家族比官方信使早一天知道拿破仑战败 → 资本市场上赚 40%。

**为什么现在不行**：
- 微信群消息已经传了好几手
- 假消息泛滥 → 你可能成为"接盘侠"
- 条件极苛刻：信息准确 + 一手 + 未大规模传播

**当代制造时间差的机构武器（三类）**：

| 方法 | 怎么做 | 案例 |
|:---:|:------|:----|
| **爬虫技术** | 抓取电商平台实时消费品销售数据 → 卖给投资机构 | 肖璟朋友在大学创立的公司 → 爬茅台电商销量 |
| **遥感卫星** | 分析卫星图片预测农作物产量 → 卖给期货公司/基金 | 肖璟大学师兄的遥感团队 |
| **草根调研** | 线下门店蹲点数客流/销量 | (a) 日本 Media Create：2000+ 游戏店实时销量 → 做空任天堂；(b) 浑水瑞幸：1418 名兼职 + 25000 张小票 → 虚增销量 |

> **时间的门槛**：以上三种方式个人投资者很难做到——肖璟也没打算教你做这些。

#### 广度差——容易踩坑

**查理·芒格的 Lollapalooza 效应**：利用历史/心理/生理/数学/工程/生物/物理/化学/统计/经济等学科的 100+ 种模型做投资决策 → **多元思维模型**。

**但肖璟警告**：刻意追求广度会患上 **FOMO（错失恐惧症）**——焦虑 + 影响对深度的探索。

> "浅尝辄止的信息接收方式很难让我们沉淀下什么东西。"
>
> **正确顺序**：先在一个领域深耕建立深度差 → 再追求广度差。

例外职业：媒体/广告行业的人必须追求广度（要持续输出有意思的内容）。

#### 深度差——普通人最该建的护城河

深度差 = 比别人更懂市场（供给侧 + 需求侧）。

**供给侧——**投资与自己行业相关的股票：
- "春江水暖鸭先知"——你比市场更懂 → 你也有时间差优势
- 深入了解 → 比别人更有信心 → 遇到回撤不会轻易丢筹码

**需求侧——**比市场上的大多数人更懂用户。

案例 1：XVC 胡博予——2013年看完 Consumer Reports 对 Model S 的"完美车评" → 去门店试驾 + 花几小时刷海外车评 → 买特斯拉股票 → 不到一年涨近 3 倍后离场。

案例 2：肖璟投资腾讯——好友玩《王者荣耀》+ 环游中国发现不少人在玩 → 270-300 港元买入 → 500-600 港元卖出 → 环游中国的路费赚回来了。

> **核心结论**：深度差是资本市场中唯一能确保持续盈利的前提。**研究的首要目标是深度差。**

### 10.3 DIKW 模型——资讯的四个深度层级

```
┌────────────────────────────────────────────────────────┐
│                DIKW 模型                                │
│                                                        │
│   智慧 (Wisdom)   ← Know-why（知道为什么）              │
│      ↑                 能够挖掘有用信息、做出正确判断    │
│   知识 (Knowledge) ← Know-how（知道怎么办）             │
│      ↑                 经过滤/提炼/整合/分析            │
│   信息 (Information)← 经处理且有逻辑关系的数据          │
│      ↑                                                  │
│   数据 (Data)     ← 未经加工的原始材料                  │
│                                                        │
└────────────────────────────────────────────────────────┘
```

**肖璟上班时间的例子**：
- **数据**："我这一周每天几点上班" → 原始纪录
- **信息**："平均每天迟到 15 分钟" → 加过分析过后的数据
- **知识**："我需要更早起床" → 得出了 Know-how
- **智慧**："我不够自律" → 到了 Know-why 层级

**财经资讯的 DIKW 对应**：

| 层级 | 财经内容示例 |
|:---:|:----------|
| 数据 | 某公司某季度营收 100 亿 |
| 信息 | 同比加速增长，环比放缓 |
| 知识 | 可能是市场份额提升但季节性波动大 |
| 智慧 | 建议买入/卖出/持有（基于深层逻辑） |

> 多数人的研究停在"信息"层（收集了一堆数据），没到"知识"层（形成判断），更没到"智慧"层（方法论）。

### 10.4 事实判断 vs 价值判断

| 类型 | 定义 | 例子 | 特点 |
|:---:|:----|:----|:----|
| **事实判断** | 对客观存在的判断——"是什么" | "A 国税负比 B 国高" | 可证实/证伪，有唯一解 |
| **价值判断** | 对好坏/有用与否的判断——"应该怎样" | "A 国税负太高了，应该降低" | 因人而异，不存在"绝对正确" |

你的所有事实判断的总和 = **世界观**。你的所有价值判断的总和 = **价值观**。

真相只有一个，价值观因人而异、随时间变化（唐代以丰腴为美 → 现代推崇匀称有肌肉）。

**关键原则**：高质量的价值判断必须有事实判断的支撑 → 否则只是情绪输出。

> 对象媒人介绍了对象：你不会只听媒人说帅不帅 → 你会看照片。别人说的话是价值判断，照片是事实判断。

### 10.5 资讯的广度分类 + 深度 × 广度矩阵

**按广度分三层**：
- **宏观资讯**：国家/地区层面（人口/经济/金融/策略轮动/资金偏好）
- **中观资讯**：行业层面
- **微观资讯**：企业/产品层面

**深度 × 广度矩阵**（把 DIKW 和广度融合）：

```
            数据        信息        知识        智慧
宏观      美国CPI     通胀高于均值  应避险     美联储加息逻辑
中观      CRn=60%     集中度在提升 龙头最受益  产能周期位置
微观      营收100亿   同比+20%    份额在扩张  护城河加深逻辑
```

### 10.6 信息茧房 + 系统1 vs 系统2

**信息茧房**（Information Cocoon）：
- 算法推荐 → 只接触与你立场一致的信息 → 越来越确信自己是对的
- 根源是选择性心理——人倾向于接触与自己原有立场一致的内容
- 不是你接触的信息带你站队，是**你先站队然后才选择性接触信息**

**解法**：关闭算法推荐服务——2022 年 3 月《互联网信息服务算法推荐管理规定》已要求平台必须给用户关闭选项。

**系统1 vs 系统2**（Kahneman）——肖璟用来解释"非理性赋权"：
- 系统1 = 直觉/快速反应 → 被价值观干扰 → 造成确认偏误
- 系统2 = 理性思考/深度推理 → 数据驱动/金融建模 → 理性赋权

## 第11章：麦肯锡的"资讯料理法"——研究怎么用三步落地

### 11.1 研究的三步骤类比

```
备菜（输入）  →  烹饪（处理）  →  摆盘（输出）
搜集资讯        提炼观点        呈现结论
```

每个麦肯锡分析师的基本功。

### 11.2 备菜：如何输入资讯——克服两个难点

#### 难点 1：数量上——信息过载（"不要尝试把大海煮沸"）

**错误做法**：像没头苍蝇一样不断点开链接（路线 A：低效试错）
**正确做法**：**假设驱动** → 有的放矢（路线 B：一步到位）

**假设驱动三步法**：

**步骤 1：做出假设**
> 先基于逻辑和常识形成一个初步判断。

例：消费降级 = 消费者买更便宜的东西 → 两个可能原因：
- 能力层面：钱不够花了（假设先采信这个）
- 意愿层面：更注重性价比

即使假设被证伪 → 也是有价值的（排除了错误路径）。

**步骤 2：拆解假设 — MECE 原则（不重不漏）**

肖璟把"钱不够花"拆解成 4 个子假设：

```
钱不够花了
    ├─→ 主动收入变少了（打工/创业）
    ├─-> 被动收入变少了（投资收益）
    ├─-> 应付本金和利息变多了（贷款/信用卡）
    └─-> 投资/理财变多了
```

**MECE 原则（Mutually Exclusive, Collectively Exhaustful）= "不重不漏"**：

| 情形 | 是什么 | 反例 |
|:---:|:-----|:----|
| ✅ 不重不漏 | 全集 = 四季，子集 = 春夏秋冬 | — |
| ❌ 不重但漏 | 全集 = 所有菜肴，子集 = 中餐 + 日本料理 | 忽略西餐韩餐 |
| ❌ 又重又漏 | 全集 = 所有女人，子集 = 辣妹 + 妈妈 | "辣妈"既属于辣妹也属于妈妈，重叠了 |
| ❌ 不漏但重 | 全集 = 所有人，子集 = 喜欢运动 + 不喜欢运动 + 喜欢打篮球 | 喜欢运动包含了喜欢打篮球的人 |

**MECE 三好处**：
1. 子集不重叠 → 可分配任务给不同团队/个人，避免重复
2. 子集不遗漏 → 所有子假设论证完 → 大假设也成立
3. 拆解降低难度 → 准备 CFA 看似难 → 拆成"今天只复习经济学第 1 章"容易启动

**步骤 3：验证子假设**

用可获取的指标验证每个子假设：
- 主动收入 → 城镇居民人均可支配收入增速 / 城镇调查失业率
- 被动收入 → 沪深 300 涨幅 / 理财产品平均收益率
- 应付本金和利息 → 居民杠杆率 / 信用卡逾期率
- 投资理财 → 居民新增存款增速 / 基金发行份额

指标可以从统计局/央行/数据终端获取。

> 如果一开始对话题缺乏基本了解 → 先业内人士访谈 + 搜索引擎找高质量综述 → 快速建立框架认知。

#### 难点 2：质量上——观点极化（"确认偏误"）

**表现**：
- 自媒体号如果"理性客观中立" → 两面不讨好 → 吸引不到粉丝
- 把观点拆成正反两方各做一两个号 → 每个号都能收获几百万粉丝

**三大成因**：
1. **宏观：经济下行激化矛盾** → 没有增量 → 存量再分配 → 矛盾公开化
2. **中观：算法导致信息茧房** → 越来越同质化的内容推送
3. **微观：内容极端收割流量** → 矛盾就是焦点 → 平台推送激发互动的内容 → 内容提供方更极端

**解法三步**：

| 步骤 | 做什么 | 操作 |
|:---:|:------|:----|
| 1️⃣ 拓宽输入渠道 | 关算法推荐 + 多找与自己观点不一致的媒体 + 尝试证伪它们 | 承认自己的判断可能有误 |
| 2️⃣ 做好资讯拣选 | 事实判断 = 新鲜食材 / 价值判断 = 加工食品 | 事实判断要验证事实 / 价值判断要看背后有没有支撑 |
| 3️⃣ 理性赋权资讯 | 用系统2而不是系统1 → 数据驱动/建模 | 多源信息不要凭直觉赋权，要有逻辑 |

**类比**：别人的价值判断像午餐肉——加工过但不是不能吃。**关键是确认原材料是否优质**（背后有没有经过验证的事实判断作为支撑）。

> 择偶例子：有人看重颜值（"基因为了让后代好看"）/ 有人更在乎性格（"原生家庭爸爸不帅但温柔"）→ 只是价值观不同导致权重差异。投资也一样：当你持有某只股票时，倾向于为利好赋权更多、利空赋权更少 → 确认偏误。

### 11.3 烹饪：如何处理资讯——金字塔原理

**记忆力测试**：10 种商品名称要 30 秒记住 → 超大部分人失败 → **George Miller: 人脑短时记忆 7±2 个信息单位**。

**解法**：分层 + 分类（金字塔）：
- 10 种 → 分为水果/零食/奶制品 3 类 → 每类 3-4 个
- 在短时记忆容量内

**核心结构**：

```
              ┌──────────────────┐
              │    核心观点       │  ← Know-how 或 Know-why
              │  （顶层：一句话）  │
              └────────┬─────────┘
         ┌─────────────┼─────────────┐
    ┌────┴────┐  ┌────┴────┐  ┌────┴────┐
    │关键论述1│  │关键论述2│  │关键论述3│  ← 中层：3-5个支撑
    └────┬────┘  └────┬────┘  └────┬────┘
    ┌────┴────┐  ┌────┴────┐  ┌────┴────┐
    │数据/案例│  │数据/案例│  │数据/案例│  ← 底层：事实
    └─────────┘  └─────────┘  └─────────┘
```

**构建金字塔四步法**：

| 步骤 | 做什么 |
|:---:|:------|
| 1️⃣ 罗列资讯 | 所有重要资讯写在便笺纸上/Excel 上，写出完整语句不是关键词 |
| 2️⃣ 寻找规律 | 提炼不同资讯的共性，按逻辑分组 |
| 3️⃣ 提炼要点 | 分别为每个组提炼一个要点 |
| 4️⃣ 归纳核心 | 思考每组的要点对问题意味着什么 → 提炼最高层级核心观点 |

**书中完整案例——给朋友 H 的房企催款邮件：**

**版本 1**：想到哪写到哪 → 信息密集但无结构 → 读者什么都记不住。

**版本 2**（用金字塔原理重构）：

**核心**：你需要及时向 ABC 房企催款

**论述 1：融资不好融**
- 国家严控融资 + 严控上市
- 海外违约 + 境内信托额度从 60 亿降到 20 亿

**论述 2：资产不够卖**
- 卖参股公司 XYZ 股份
- ABC 汽车和物业想卖但卖不出好价格

**论述 3：房子不好卖**
- 没钱拿地 → 未来可售房源变少
- 买房者怕交不了房 → 销售受阻

> 同样的内容，有结构的版本 2 比版本 1 传达效率高得多。

#### 金字塔原理的两个附加要求

**要求 1：有深度——学会区分"总结"与"提炼"**

- **总结** = 同义互换/缩句 → 没有信息增量（"我找不到钥匙和身份证，而且延误了报税"）
- **提炼** = 多问几次 **"So what?"** → 不断提升到更高层级

例子：
```
"找不到钥匙和身份证 + 延误报税"
    → So what?
"我最近什么事情都没做好"
    → So what?
"我需要好好休息"  ← 有操作性的结论
```

三条资讯：
```
PMI 连续 4 个月低于荣枯线
出口同比连续 3 个月下滑
GDP 增速跌破当年目标

→ Know-what：宏观经济不太景气（太浅）
→ So what?：应当出台稳增长政策了  ← 有深度的提炼
```

**要求 2：有逻辑——归纳推理 + 演绎推理 + 排序**

归纳推理维度：
- **性质**：事实(What) / 成因(Why) / 做法(How)
- **影响**：正面 / 负面
- **时间**：过去 / 现在 / 未来
- **空间**：外部 / 内部
- **类别**：具体理论框架（如 3 种现金流）

常见演绎推理结构：
- 需做到 X → 你无法做到 X → 你需要建立做 X 的能力
- 需要 X → 你的重心不在 X → 你需要转移重心到 X
- 你朝 X 发展 → 但 Y 比较有利 → 你需要转向 Y
- 你认为 X 是问题 → 但调查显示 Y 才是 → 你需要转移重心到 Y
- 绩效不如预期 → 问题出在 X → 你需要设法解决 X

排序规则：时间次序 / 等级次序（大小/重要/紧急）/ 传统次序。

### 11.4 摆盘：如何输出资讯——SCQR 框架

**核心教训**（肖璟在谷歌时的导师陈楸帆——著名科幻小说家，星云奖得主）：

> "解題归解题，沟通归沟通。"
>
> **解题顺序**：先建立假设 → 搜集资讯 → 验证 → 得方案
>
> **沟通顺序**：先给方案 → 再说理由 →（受众需要时补充过程）

#### SCQR 框架 = "空雨湿伞"模型

```
S (Situation)    —— 天空飘来一朵云   —— 情景：描述当前状态
C (Complication) —— 很可能要下雨     —— 冲突：出了什么问题/变化
Q (Question)     —— 可能会被淋湿     —— 问题：要回答什么
R (Resolution)   —— 带上伞出门       —— 解答：方案/观点
```

经典引入案例：林肯《葛底斯堡演说》的 SCQ 部分：
> "87 年前，我们的先辈在这片大陆上建立了一个新国家，它孕育于自由之中，奉行一切人生来平等的原则。现在我们正进行一场伟大的内战，以考验这个国家……"

> **R 部分要"快准狠"**——不要加那么多拖泥带水的条件状语。

#### 四种受众类型 × 四种输出顺序

调整 SCQR 的关键：**根据受众调整顺序**。

| 受众类型 | 沟通顺序 | 为什么 |
|:------:|:------:|:------|
| **路人**（短视频/陌生网站） | **CQSR** | 没有背景知识 → 先用冲突吸引眼球 → 再给方案 |
| **观众**（感兴趣但不了解） | **SCQR** | 有兴趣 → 适合用完整故事线引入 |
| **大老板**（时间宝贵） | **RSCQ** | 直接给结论 → 有兴趣再补细节 |
| **直属领导**（已有深入理解） | **R（只给结论）** | 只需解答 → 铺垫浪费时间 |

> 麦肯锡内部培训的讽刺漫画：汇报人 PPT 第一页："我们破产了。" 参会者满意："这就是我喜欢他的原因，演讲总是直击重点。"

**短视频的套路**= CQSR 的典型应用：
- 前半段 20 秒唤起需求（恐惧/欲望）
- 后半段满足需求给答案
- 最精彩的镜头/最激烈的冲突 → 剪辑到开头

> **不能刻舟执剑** —— 具体的沟通方式还要针对受众的具体情况灵活调整。

| 技巧 | 语法 | 用途 |
|:---:|:----:|:----|
| 站点限定 | `site:gov.cn` | 搜政府官网内容 |
| 文件类型 | `filetype:pdf` | 找研报/政策原文 |
| 精准搜索 | `"关键词"` | 排除分词干扰 |
| 排除内容 | `三体 -动画` | 过滤无关结果 |
| 通配符 | `风口*肖璟` | 记不全时用 |
| 时间范围 | 百度搜"搜索工具" | 限制发布时段 |

**推荐搜索工具矩阵**：

| 工具 | 用途 |
|:---:|:----|
| 百度 | 中文综合搜索 |
| 搜狗 | 微信文章搜索 |
| Bing | 引入 ChatGPT 辅助 |
| **i 问财** | **金融垂直搜索**（"三年累计分红<年均净利润30%"→输出股票列表） |
| **Perplexity** | **AI 总结搜索**（爬网页 + LLM 总结） |
| **秘塔 AI 搜索** | 国产 Perplexity 替代品 |
| Wolfram\|Alpha | 语义搜索（不支持中文但可自动翻译） |
| 百度学术/谷歌学术 | 学术论文搜索 |

**百科工具使用提醒**：
- 百度百科/维基百科/搜狗百科/Investopedia 都可查专有名词
- **但不直接引用**（质量参差）——看词条**底部来源** → 追踪到原始可靠来源
- **B站**已成为券商分析师的入门科普渠道——先看几个视频再开始研究

### 12.5 社交网络——垂直社区 + 专家网络

**社交媒体筛选原则**：
1. 更加包容——多听不同观点
2. 摒弃只输出价值判断、无事实判断支撑的内容

**垂直社区（质量较高）**：

| 社区 | 领域 |
|:---:|:----|
| 经管之家（原人大经济论坛） | 学术资料和数据 |
| 丁香园论坛 | 医学/药学/生命科学 |
| GitHub/CSDN/StackOverflow/V2EX | 程序员/工程师 |
| 聚宽/掘金量化/BigQuant | 量化投资者 |

> **警告**：非垂直/无门槛社区（豆瓣/B站/知乎）到千万用户量级时面临**内容下沉**——氛围不可逆变化。

**专家网络**：

| 渠道 | 特点 |
|:---:|:----|
| **凯盛融英 Capvision** / 商霖华通 BCC / 格理 GLG / 高临 Third Bridge | 专家网络公司（数千元/小时） |
| **在行 App** | 个人投资者可选（几百元） |
| **领英 / 各行业微信群** | 直接联系——无中间商 |

**专家访谈操作指南**（肖璟 McKinsey 12 年经验总结）：

| 步骤 | 做法 |
|:---:|:----|
| **前提** | 先通过公开渠道掌握基本知识——不要问"芯片怎么工作"，问产业层面的真问题 |
| **判断能力圈** | 看履历——管理者善大局但不熟细节 / 一线专家细节到位但缺宏观 |
| **拟定大纲** | 1 小时访谈 → 10个问题（最多15个）——太少不够深、太多蜻蜓点水 |
| **开场** | 先破冰恭维 → 快速介绍目的 → 防止跑题 |
| **场地** | 对方熟悉的相关场景可能有奇效——在喜茶门店聊奶茶行业 |
| **变换问法** | 受限于保密协议时——把"贵公司激励方案"换成"如果让您来设计" |
| **启发式追问** | "3家加一起市占率有70%吗？" → "估计80%" → "A比B和C高多少？" → 推算份额 |
| **事实依据** | 追问判断的事实和逻辑——不接受无依据的结论 |
| **录音整理** | 剪映语音转文字 + ChatGPT 整理 |
| **限时整理** | 访后尽快出会议纪要 |

> **防骗提醒**：某些早期投资机构借"有投资意向"之名让已投同行参与访谈→诱导泄露商业机密。

### 12.6 研究机构报告——五类机构各有优劣

| 机构类型 | 代表 | 阅读价值 |
|:------:|:---:|:-------|
| **官方研究部门** | 央行/商务部/美联储 | 更新频次低 → 主要挖掘数据 |
| **学术研究机构** | 西南财大/密歇根/NBER | 专题报告有深度 |
| **咨询公司** | 麦肯锡/BCG/贝恩/罗兰贝格 | 通常质量较高——兼顾获客/维护客户关系/平衡生产力 |
| **买方机构** | 公募/私募 | 大部分不公开——基金经理对外分享的可能不是"真心话"（跟风者帮抬轿） |
| **卖方机构** | **券商/投行** | **最常阅读——研究重点** |

**券商研报四类**：

| 类型 | 内容 |
|:---:|:----|
| 宏观研报 | 经济指标 + 政策 → 判断周期阶段 → 大类资产配置 |
| 策略研报 | 大势研判 + 行业比较 + 主题投资——宏观和行研之间的桥梁 |
| 行业研报 | 商业模式/产业链/竞争格局/发展空间——**本书对应** |
| 公司研报 | 单一公司深度分析 |

**筛选优质研报四思路**：

| 思路 | 操作 |
|:---:|:----|
| 看热度 | "近一周/一月热门研报"——群众的眼睛是雪亮的 |
| 看团队 | 新财富/金牛奖/水晶球/金麒麟获奖团队；或公募分仓收入排名 |
| 看推荐 | 分析师专门路演 / 个人公众号收录 |
| 看内容 | 假设合理/论据扎实/观点明确/可证伪/逻辑严密 |

**研读注意**：
- "报喜不报忧"是常态——绝口不提的地方可能有问题
- 只强调市场空间不提竞争格局 → 竞争格局可能很糟
- 分析师强烈推荐后突然沉默 → 基本面恶化或估值过高

### 12.7 专业数据库——投研基础设施

**金融数据库对比**：

| 数据库 | 特点 |
|:---:|:----|
| **万得(Wind)** | 国内最常用——全面（图表下方常见数据源） |
| Choice(东方财富) | 价格便宜——国外数据有限 |
| iFinD(同花顺) | 价格便宜——国外数据有限 |
| **CEIC(环亚经济)** | 宏观经济数据全面——经济学家青睐 |
| 彭博(Bloomberg) | 全球老大——价格极贵 + 需硬件终端 |
| Capital IQ(标普全球) | 全球上市公司/非上市公司/资管/固收 |
| 萝卜投研(通联数据) | 海量行业数据库——搜图表超方便 |
| 天眼查/企查查 | 企业工商信息/知识产权/司法风险 |
| IT桔子/36氪创投平台 | 企业融资信息 |

**数据陷阱两类**：
1. 数据有错（肖璟在彭博找到过错得离谱的数据）
2. 口径改变（社会融资规模过去 10 年调整数次 → 原始数据源查口径）

> **最终心法**：投研追求"模糊的正确"——不同渠道数据打架时交叉验证取区间值，不必追求标准答案。

## 第13章：生成式 AI 与研究

### 13.1 生成式 AI 在各行各业的冲击（裁员潮实证）

| 公司 | 发生了什么 |
|:---:|:---------|
| BuzzFeed | 2023.1 裁员 12% + 与 OpenAI 合作内容创作 → 股价当日涨 120% |
| Stack Overflow | ChatGPT 后浏览量腰斩（"LLM killed the platform" - Musk）→ 裁员 28% |
| 多邻国 | 用 ChatGPT 后裁减数千名翻译（4 人团队裁 2 个） |
| 心动游戏 | 砍掉部分原画外包团队 |
| 某游戏外包公司 | 引入 AI 后原画师被裁过半 |
|高盛预测 | 3 亿全职岗位或被取代 |
| 麦肯锡预测 | 2045 年一半工作被 AI 接管 |

> 肖璟安慰：1940 年不存在的工作中如今占 60% ——新技术摧毁旧岗位，也创造新岗位（AI 模型安全专家/AI 转型顾问/AI 绘画师）。

### 13.2 用 AI 做投资的几种姿势

肖璟在书末列了一张 AI 在投资研究流程中的使用地图（**当时看来已落地**）：

| 阶段 | AI 怎么用 |
|:---:|:---------|
| 案头研究 | 行业扫盲、概念解释、产业链梳理 |
| 数据收集 | 爬数据 + 表格清洗 |
| 数据分析 | 财务建模辅助 + 敏感性分析 |
| 资讯追踪 | 监控新闻 + 研报摘要 |
| 写作辅助 | 初稿框架 + 核对计算 |

### 13.3 AI 幻觉（Hallucination）

**这是肖璟认定 AI 在行研中的最大风险。**

表现：
- 编造文献引用
- 编造数据（看似真实但查无此数）
- 逻辑自洽但前提错

**肖璟的法则**：所有 AI 给的数字和文献 → **必须回到一手来源交叉验证**。

### 13.4 AI 工具推荐（截至书写作时）

作者的态度："更新太快——关注使用思路，不追具体工具。"

核心角色定位：

```
AI 对行研的角色 = "腿"——让你跑得更快
                        +
               "不是你"——方向还是你定
```

> "不会用 AI 的分析师会被会用 AI 的分析师替代"——这是 2024 年的话。现在看，已经被验证了。
