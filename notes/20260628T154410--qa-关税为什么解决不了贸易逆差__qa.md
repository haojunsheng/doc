* 引子
特朗普4月2日"对等关税"远超市场预期，全球市场剧烈波动。但晨星宏观团队指出一个被忽视的经济学常识：加征关税无法从根本上解决美国经常账户赤字，因为进口减少会推高美元，进而打击出口，形成自我抵消的循环。

* Q1: 关税为什么解决不了贸易逆差？
  *结论*: 进口减少→美元升值→出口受阻→贸易逆差不变，这是一个自我抵消的循环。
  *形式化*: 关税↑ → 进口↓ → 美元↑ → 出口↓ → 逆差≈不变（自我抵消环）
  *怎么想到的*:
  - 经常账户赤字 = 资本净流入
  - 进口减少→美元支出降低→美元升值
  - 美元升值→美国商品在海外变贵→出口下降
  - 进口减少的好处被出口减少抵消
  - 资本净流入没变，赤字也没变
  *边界*: 如果关税配合资本管制或财政赤字削减，逆差可能真正收窄。

* Q2: 历史上有没有前车之鉴？
  *结论*: 2010年代美国页岩气革命让能源从进口变出口，但美元升值20%抵消了其他行业的出口竞争力。
  *形式化*: 页岩气革命 → 能源出口↑ → 美元↑20% → 其他行业出口↓ → 整体逆差没变
  *怎么想到的*:
  - 美国从能源第一大进口国变成出口国
  - 按理说贸易逆差应该缩小
  - 但美元升值让其他行业出口变难
  - 逆差被其他商品的进口增加对冲了
  *边界*: 如果那次美元升值幅度较小，或者美国制造业竞争力足够强，结果可能不同。

* Q3: 这次关税为什么和第一任期不一样？
  *结论*: 第一任期关税是谈判筹码（加了又撤），第二任期是真正的重商主义政策，身边认同的人更多。
  *形式化*: 第一任期(筹码:加→谈判→撤) ≠ 第二任期(政策:持续加→制造业回流)
  *怎么想到的*:
  - 第一任期对加墨加税几天就取消了，换取边境安全让步
  - 特朗普说"从80年代就想用关税恢复制造业主导地位"
  - 第二任期身边认同这个想法的人更多
  - 所以这次关税可能持续更久、影响更大
  *边界*: 如果美国经济数据急剧恶化，特朗普可能回归第一任期模式（加了就撤）。

* Q4: 关税对美国经济自身有什么影响？
  *结论*: 晨星预测GDP累计增长下调1.1个百分点，未来12个月衰退概率40%-50%。
  *形式化*: 高关税长期维持 → GDP增长↓1.1% + 衰退概率40%-50% → "自找的经济灾难"
  *怎么想到的*:
  - 关税推高物价→消费需求下降
  - 出口受阻→供给端产出下降
  - 不确定性→企业推迟投资
  - 晨星明确说这是"自找的经济灾难"
  *边界*: 如果关税只维持几个月就大幅削减，对GDP的影响会有限。

* Q5: 投资者怎么度过关税动荡期？
  *结论*: 全球分散配置+自下而上选有护城河的公司+不被市场噪音左右。
  *形式化*: 度过动荡 = 全球配置(不押注单一国家) + 选有经济护城河公司 + 过滤噪音
  *怎么想到的*:
  - 没人能准确知道未来会发生什么
  - 押注单一市场极具风险
  - 有持久竞争优势的公司更能应对冲击
  - 散户的最大优势是资金自有性，不用被迫短期兑现
  *边界*: 当投资者面临短期流动性需求时，"过滤噪音不操作"的策略可能不适用。

* Q6: 自由贸易秩序会终结吗？
  *结论*: 关贸总协定70年推动的自由贸易正在逆转，但完全脱钩不太可能——互联程度太高。
  *形式化*: GATT/WTO 70年(关税36%→3.8%) → 特朗普逆转(2.5%→25.5%) → 但完全脱钩不可能
  *怎么想到的*:
  - 1948年发达国家平均关税36%，90年代降到3.8%
  - 这次一步回到25.5%，一个世纪来最高
  - 但当前全球经济互联程度前所未有
  - 完全脱钩的成本大到不可承受
  *边界*: 如果全球分裂成两个平行贸易体系，"完全脱钩"就不是不可能。

* 收口
晨星的核心观点是经济学的基本常识：关税是自我抵消的——你减少了进口，也打击了出口，最终逆差没变，还搭上了经济增长。这不是贸易政策，是经济自残。
