#+subtitle:   基金可以"合理"跑输多久？聊聊业绩背后的能力与运气
#+date:       [2025-07-15 10:00]
#+filetags:   :qa:
#+identifier: 20260614T214308

* 引子
晨星2017年的一项研究显示：在约5500只主动管理股票型基金中，虽然三分之二在15年内跑赢了基准，但这些"长跑赢家"的最长连续跑输期中位数高达10年。更讽刺的是，那些15年跑输的基金，最长连续赢期也有11-12年。这篇文章的核心问题是：基金短期跑输基准，到底是能力问题还是运气问题？

* Q1: 研究的核心发现是什么？
  *结论*：长期赢家有10年跑输期，长期输家有11-12年赢期——能力和运气在15年的时间尺度上仍然难以区分。
  *形式化*：研究发现 = 长期赢家（15年跑赢）最长跑输期中位数=10年 + 长期输家（15年跑输）最长赢期=11-12年 → 能力≠运气
  *怎么想到的*：
  - 数据：约5500只基金，2003-2017年15年数据
  - 赢家：三分之二跑赢基准，但最长连续跑输期中位数=10年
  - 输家：最长连续赢期=11-12年
  - 讽刺：现实中，基金连续三年跑输就会让投资者失去耐心
  *边界*：如果研究时间更长（如20年或30年），结论可能更稳健；如果研究时间更短（如5年），结论可能更模糊。

* Q2: 为什么"长期赢家"也会有10年的跑输期？
  *结论*：因为市场具有随机性，即使基金经理有真正的能力，也可能在某些年份因运气不好而跑输。
  *形式化*：跑输期 = f(能力, 运气) → 有能力 + 运气不好 → 10年跑输 ≠ 没能力
  *怎么想到的*：
  - 蒙特卡洛模拟：生成"虚拟基金经理"，分三组（有能力/中庸/没能力），10000次模拟
  - 模拟结果与真实数据一致——"有能力"的基金经理平均也有10年跑输期
  - 这说明：即使有能力，运气不好也会导致长期跑输
  *边界*：如果基金经理的"能力"不稳定（如风格漂移），模拟结果可能失真。

* Q3: 如果投资者买到一只连续跑输10年的基金，选到"有能力"基金经理的概率有多大？
  *结论*：45%——也就是说，即使连续跑输10年，仍有近一半的概率选到的是"有能力"的基金经理。
  *形式化*：P(有能力|连续跑输10年) = 45% → P(平庸) = 32% + P(没能力) = 22% → 概率差异不悬殊
  *怎么想到的*：
  - 蒙特卡洛模拟：假设投资者买到一只连续跑输10年的基金
  - 计算选到"有能力"/"平庸"/"没能力"基金经理的概率
  - 结果：45%/32%/22%，差异并不悬殊
  - 这说明：连续跑输10年不能"一票否决"基金经理的能力
  *边界*：如果跑输期更长（如15年），概率会变化；如果市场环境变化（如从牛市到熊市），概率也会变化。

* Q4: 为什么"能力"和"运气"在基金业绩中难以区分？
  *结论*：因为市场表现和基金业绩具有随机性，即使通过15年的业绩考察，都难以得出确定的结论。
  *形式化*：能力 vs 运气 = 随机性干扰 → 15年业绩 ≠ 能力的充分证据
  *怎么想到的*：
  - 研究样本：5500只基金×15年数据，样本量已经很大
  - 但即使样本量这么大，仍然难以区分能力和运气
  - 这说明：基金业绩的"信噪比"很低，需要更长的时间或更多的数据才能区分
  *边界*：如果基金经理有真正的长期能力（如15年期业绩前10%），可以大概率排除运气；但如果只是3-5年的业绩优秀，很难区分能力和运气。

* Q5: 这项研究对投资者有什么实际指导意义？
  *结论*：核心指导是"不要仅凭短期业绩判断基金经理"——3-5年的业绩不足以区分能力，15年的业绩也只能提供概率性判断。
  *形式化*：投资指导 = 不要仅凭短期业绩判断 → 3-5年业绩 ≠ 能力 + 15年业绩 ≈ 概率性判断 → 关注长期、关注过程
  *怎么想到的*：
  - 研究发现：长期赢家可能输10年，长期输家可能赢11-12年
  - 这意味着：短期业绩（3-5年）几乎无法判断基金经理的能力
  - 投资者应该关注长期业绩（10年以上）和投资过程（策略是否稳定）
  *边界*：如果基金经理更换或策略变化，历史评估结论可能失效。

* Q6: 为什么说"蒙特卡洛模拟"在这个研究中是必要的？
  *结论*：因为模拟可以提供一个"基准"——如果没有真实数据，我们不知道10年的跑输期是"正常"还是"异常"。
  *形式化*：模拟价值 = 提供基准（无能力基金经理的最长跑输期） → 对比真实数据 → 判断基金经理是否有能力
  *怎么想到的*：
  - 真实数据：有能力基金经理平均10年跑输期
  - 模拟：生成"虚拟基金经理"，10000次模拟最长跑输期分布
  - 模拟结果与真实数据一致→说明10年跑输期是"正常"的，不是"异常"的
  *边界*：模拟假设基金经理的能力是稳定的，如果基金经理的能力随时间变化（如风格漂移），模拟结果可能失真。

* Q7: 从这项研究看，投资者应该怎样看待基金的"业绩比较基准"？
  *结论*：业绩比较基准是"参照物"而非"目标"——基金跑输基准不代表基金经理能力差，跑赢基准也不代表基金经理能力强。
  *形式化*：业绩比较基准 = 参照物（同类比较） ≠ 目标（必须跑赢） → 跑输≠能力差 + 跑赢≠能力强
  *怎么想到的*：
  - 研究显示：长期赢家也可能跑输10年，长期输家也可能赢11-12年
  - 这说明：基准只是"参照物"，不是"能力的证明"
  - 投资者应该关注"长期是否在同类中领先"，而不是"每个时期是否跑赢基准"
  *边界*：如果基金长期（10年以上）持续跑输基准，可能需要重新评估基金经理的能力。

* 收口
这篇文章的核心价值在于：用晨星的研究数据揭示"基金业绩的信噪比很低"——3-5年的业绩几乎无法判断基金经理的能力，15年的业绩也只能提供概率性判断，投资者应该关注长期、关注过程、关注风险调整后收益。
