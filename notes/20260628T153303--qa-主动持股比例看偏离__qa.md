#+subtitle:   主动基金经理集体"高偏离"？这个指标帮你精准避雷

#+filetags:   :qa:
#+identifier: 20260628T153303

* 引子
国内主动偏股基金普遍大幅偏离业绩比较基准，平均主动持股比例接近90%。证监会新规将基准提升至核心地位，要求基金回归定位。本文用主动持股比例这个指标，帮投资者看清基金到底在做什么。

* Q1: 主动持股比例到底衡量什么？
  *结论*: 它数的是基金持仓和基准指数有多少不重合。
  *形式化*: 基金持仓 ≠ 基准持仓 → Active Share → 基金 = 主动部分 + 被动部分
  *怎么想到的*:
  - 两只基金跟踪误差可能一样，但一只靠行业押注、一只靠个股精选
  - 收益类指标分不清这两种，必须直接对比持仓
  - 把每只股票的权重差取绝对值求和÷2，一个数搞定
  *边界*: 基准本身选错了（成长基金拿价值指数做基准），数字再高也是假高。

* Q2: 为什么国内主动基金偏离度这么高？
  *结论*: 基金经理在风格、行业、个股三个层面都在偏离基准。
  *形式化*: 基金实际偏好 ≠ 基准构成 → 低配银行非银 + 超配电力电子 + 集中持股 → 偏离叠加
  *怎么想到的*:
  - 基准（沪深300）偏大盘价值，基金经理偏中小盘成长
  - 赛道型选手单一行业占比极高，偏离被拉大
  - 集中持股 vs 分散的基准，个股层面权重差自然大
  *边界*: 中小盘基金偏离高不等于乱操作，因为中小盘本身可选空间大、基准分散。

* Q3: 高主动持股比例就一定代表能力强吗？
  *结论*: 不是，高偏离只是手段，不是能力证明。
  *形式化*: 高偏离 ≠ 高能力；偏离 + 选股强 → 收益；偏离 + 选股弱 → 盲目偏离
  *怎么想到的*:
  - 只要买基准外的股票就能拉高主动持股比例
  - 但买了不等于能赚钱，还需要选股能力配合
  - 晨星研究表明它受市场风格影响大，小盘行情好时高偏离才受益
  *边界*: 市场风格切换时，高偏离基金可能从领先变垫底。

* Q4: 怎么用主动持股比例区分不同投资策略？
  *结论*: 同类型基金之间比较，能看出基金经理的真实打法。
  *形式化*: 同类基金A偏离70% + 行业分散 + 低集中度 → 保守策略；B偏离100% + 行业集中 + 高集中度 → 激进策略
  *怎么想到的*:
  - 东方岳和万家宏观同属大盘平衡、同对标沪深300
  - 东方岳主动持股70%，万家接近100%，背后是完全不同的组合构建思路
  - 一个分散保守、一个集中激进，风险收益特征完全不同
  *边界*: 必须同类比较，拿大盘成长跟中小盘比偏离度没有意义。

* Q5: 为什么中小盘基金偏离度远高于大盘基金？
  *结论*: 中小盘股票多、空间大，基金经理容易做出差异化。
  *形式化*: 沪深300权重集中 + 龙头少 → 操作空间小；中证500股票多 + 覆盖面广 → 选股空间大
  *怎么想到的*:
  - 大盘指数权重集中在少数龙头，龙头表现往往强于指数整体
  - 中小盘股票数量大，有超额收益潜力的标的更多
  - 中小盘基金平均主动持股比例96%，大盘成长仅90%，差距来自市场结构
  *边界*: 如果中小盘基准本身编制不好或覆盖不足，偏离度也会虚高。

* Q6: 新规后基金会怎样调整？
  *结论*: 基金会更重视基准，但不会都变成被动指数。
  *形式化*: 新规约束 → 薪酬挂钩基准 → 基金回归"风险收益对称" → 主动部分有逻辑地偏离
  *怎么想到的*:
  - 证监会用薪酬激励+费率调节双重机制推基准约束
  - 过去忽视基准的模式不可持续
  - 但主动基金的价值在于创造超额收益，关键是有清晰的偏离逻辑而非乱偏离
  *边界*: 如果基金公司只是表面合规、实际换汤不换药，投资者仍需警惕。

* 收口
晨星这篇文章的核心贡献是：用一个简单持仓对比指标，把"基金到底有多主动"从模糊感觉变成可量化数字，让投资者在同类别基金之间看清基金经理的真实打法差异。
