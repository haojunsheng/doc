* 引子

伊朗冲突让油价一季度几乎翻倍，全球资产经历了一轮"预期修正"。但4月反弹让人产生幻觉——波动好像过去了。晨星季度报告提醒：如果地缘风险持续，一季度的剧本完全可能重演。这篇文章的核心问题是：油价冲击对经济和资产定价的实际影响到底有多大？

* Q1: 油价如何成为全球资产重定价的触发器？

  *结论*：油价翻倍 → 通胀预期升温 → 利率将在更久保持高位 → 所有资产按新利率重新折现 → 杀估值。

  *形式化*：油价翻倍 → 通胀↑ → 利率高位更久 → 折现率↑ → 资产价格↓

  *怎么想到的*：
  - 油价上涨直接推高通胀预期，这是所有资产定价的锚
  - 利率高位更久意味着未来现金流折现值下降，高估值资产首当其冲
  - 2月28日冲突爆发后全球股市普遍下跌，印证了这条传导链

  *边界*：这条链成立的前提是油价上涨被认定为"持续性的"——如果油价快速回落，传导链会中断。

* Q2: 为什么"杀估值"而不是"杀盈利"？

  *结论*：因为冲击来自利率预期变化而非经济衰退，企业盈利未受直接影响，但未来现金流的折现率上升了。

  *形式化*：盈利不变 + 折现率↑ → 估值↓
  对比：衰退 = 盈利↓ + 折现率↓（可能）

  *怎么想到的*：
  - 全球GDP增长预计从3.3%放缓至2.8%，幅度温和
  - 油价对通胀影响仅0.5个百分点，不是恶性通胀
  - 美国金融和信息技术行业受冲击最明显——这些行业估值对利率最敏感

  *边界*：如果油价持续高位导致企业融资成本大幅上升、投资萎缩，就会从"杀估值"转向"杀盈利"。

* Q3: 黄金为什么没起到避险作用？

  *结论*：黄金的避险叙事被趋势交易覆盖——动量资金主导了金价，当利率上行时，同一批资金反身卖出。

  *形式化*：正常避险：恐慌 → 买黄金 → 金价↑
  实际发生：利率↑ + 美元强 → 资金流出 → 金价↓

  *怎么想到的*：
  - 2025年黄金创1979年以来最大涨幅，大量趋势交易和动量资金涌入
  - 自我强化机制：涨 → 资金流入 → 更涨 → 更多资金
  - 3月10年期美债收益率上行 + 美元走强，资金机制反向运转

  *边界*：黄金的避险功能在地缘恐慌初期仍然有效——只有当金价完全被趋势交易主导时，避险属性才被覆盖。

* Q4: 油价对经济的实际影响有多大？

  *结论*：比想象中温和——全球GDP增长放缓0.5个百分点，通胀上行0.5个百分点；但油价若到100美元，影响翻倍。

  *形式化*：85美元/桶 → GDP -0.5% + 通胀 +0.5%
  100美元/桶 → GDP -1.0% + 通胀 +1.5%

  *怎么想到的*：
  - IMF预测假设布油均价85美元，较2025年涨21%
  - 不利情景下100美元会进一步拖累增长和通胀
  - 真正影响资产价格的不是经济影响本身，而是对货币政策的预期改变

  *边界*：IMF预测基于"油价不持续恶化"的假设——如果霍尔木兹海峡完全中断，影响会远超模型。

* Q5: 为什么市场从"降息预期"变成了"加息预期"？

  *结论*：油价推升通胀 → 央行需要更长时间维持高利率 → 甚至可能加息来锚定通胀预期。

  *形式化*：2025年12月：市场定价降息0.5%
  2026年4月：市场定价不降息 / 加息

  *怎么想到的*：
  - 美联储此前定价降息0.5个百分点，现在调整为不降息
  - 对英格兰银行和欧洲央行，市场甚至开始定价2026年加息
  - 油价上涨让"通胀何时回落至目标"的时间表被推迟

  *边界*：如果油价快速回落或经济出现衰退迹象，加息预期会迅速逆转——市场定价本身也是动态的。

* Q6: 晨星对美联储后续路径的判断跟市场有何不同？

  *结论*：晨星认为美联储2026年维持利率不变，2027-2028年累计降息1.25个百分点——比市场预期更乐观。

  *形式化*：市场：2026年不降息
  晨星：2026年不动 → 2027-2028降息1.25% → 2029年10Y=3.25%

  *怎么想到的*：
  - 晨星认为油价冲击是暂时的，通胀影响消退后降息会启动
  - 中长期低利率仍是支持经济增长的重要条件
  - 晨星的降息幅度超过市场预期，意味着他们对经济软着陆更有信心

  *边界*：如果油价持续高位演变为能源驱动型通胀，晨星的降息路径就不会实现——久期会成为负担。

* Q7: 三种情景下投资组合应如何应对？

  *结论*：短暂冲击可控；中期中断要区分赢家和输家；油价持续高位则需减久期、警惕新兴市场主权债。

  *形式化*：短暂冲击 → 持有不动
  中期中断 → 分化：赢家 vs 输家
  持续高位 → 减久期 + 信用利差扩大 + 新兴市场两位数损失

  *怎么想到的*：
  - 情景一：快速逆转，组合可控——不需要大调
  - 情景二：较长但部分受控，市场开始定价差异化——需要选股
  - 情景三：油价持续高位，久期成为负担，信用利差扩大——需要主动防御

  *边界*：三种情景的划分依赖对地缘政治的判断——而地缘政治本身就是最难预测的变量。

* 收口

作者用一条清晰的传导链（油价 → 通胀 → 利率 → 资产价格）解释了全球市场一季度的重定价，并指出真正的风险不是经济影响本身，而是市场对此的预期已经发生根本性转变。
