#+title:     高主动持股比例不等于高业绩
#+subtitle:  主动偏离是否能带来更好的业绩？
#+date:       [2026-06-14 Sun 21:45]
#+filetags:   :qa:
#+identifier: 20260614T214539
#+source:     https://www.morningstar.cn/articles/a869a5a252eeb0daa0b77ad918bf2b03.html

* 引子
国内主动偏股基金的"主动程度"相当高——超半数基金的主动持股比例超过90%。但随着业绩比较基准新规推进，有人担忧：主动基金的投资灵活度被限制后，会不会影响超额收益？作者用2024年的数据回答了一个核心问题：更高的偏离度真的能带来更好的业绩吗？

* Q1: 为什么高主动持股比例不等于高业绩？
  *结论*：2024年数据显示，主动持股比例0-80%、80%-90%、90%-100%的偏股基金战胜率没有明显差异，"主动"不等于"赚钱"。
  *形式化*：主动持股比例↑ ≠ 战胜率↑ → 高主动 ≠ 高业绩
  *怎么想到的*：
  - 数据验证：2024年主动持股比例三个区间的基金战胜率无显著差异
  - 逻辑解释：主动持股比例只是"描述性工具"（告诉你基金有多主动），不是"业绩预测工具"（不能预测未来业绩）
  - 投资策略：高主动持股比例可能只是"盲目的主动"，不能带来更高的收益
  *边界*：若基金经理能力不足却过度偏离基准，反而会加大业绩波动；若基金经理能力出众，适度偏离可能创造超额收益

* Q2: 为什么主动持股比例骤降需要警惕？
  *结论*：主动持股比例骤降可能是规模膨胀导致选股困难，也可能是基金经理主动更改策略，都需要重新评估投资价值。
  *形式化*：主动持股比例骤降 = 规模↑导致选股困难 或 策略变更 → 需要重新评估
  *怎么想到的*：
  - 规模效应：资产规模大幅增加，基金选股困难，无法像过去一样"主动"
  - 策略变更：基金经理主动更改策略，如从主动投资改为指数增强
  - 案例验证：中欧均衡成长混合2024年将策略改为对标沪深300的指数增强，主动持股比例从90%降至不足60%
  *边界*：若策略变更是主动的且合理的（如适应新市场环境），可能并非坏事；若策略变更是被动的（如规模失控），则需要警惕

* Q3: 为什么主动持股比例骤升也需要警惕？
  *结论*：主动持股比例骤升可能是因为押注单一行业（如超配AI主题），导致组合风险高度集中在单一主题或板块。
  *形式化*：主动持股比例骤升 = 押注单一行业（如AI） → 组合风险高度集中 → 一旦行业风险事件发生，净值大幅下滑
  *怎么想到的*：
  - 风险集中：前海开源沪港深龙头精选2025年主动持股比例从60%升至近100%，84%持仓集中在医药一个行业
  - 后果严重：一旦医药行业发生风险事件，组合净值将大幅下滑
  - 投资者需谨慎：结合自身风险承受能力决策，避免过度暴露于单一主题
  *边界*：若基金经理对单一行业有深入研究且风险可控，集中配置可能带来超额收益；若只是追热点，风险极大

* Q4: 什么是"伪主动"基金？
  *结论*："伪主动"基金宣称采用主动管理、收取高额主动费率，但持仓与基准高度重合，扣除费用后几乎不可能跑赢基准。
  *形式化*：伪主动 = 主动持股比例<60% + 高费率（如1.2%） → 持仓与基准高度重合 → 扣除费用后几乎不可能跑赢基准
  *怎么想到的*：
  - 定义标准：晨星将主动持股比例低于60%的基金定义为"伪主动"基金
  - 数据验证：1749只主动偏股型基金中，2025年6月底有20只基金的主动持股比例低于60%
  - 费率问题：这些基金的管理费并没有比其他基金明显偏低，仍然收取1.2%的行业通行管理费率
  - 投资者损害：收着高昂的主动管理费率，做的却是复制指数的工作，对投资者不利
  *边界*：若"伪主动"基金费率足够低，投资者可能接受；若"伪主动"基金有其他的价值（如更好的风险控制），可能并非完全负面

* Q5: 为什么"伪主动"基金损害投资者利益？
  *结论*：投资者支付高额的主动管理费，但获得的是接近指数的回报，不如直接买低费率的指数基金。
  *形式化*：投资者支付：高费率（1.2%） 获得：接近指数的回报 → 不如买低费率（0.15%）的指数基金
  *怎么想到的*：
  - 主动基金的核心意义：战胜基准，体现在与基准的"不同"
  - "伪主动"的问题：持仓和指数成分股高度重合，算不上"合格"的主动管理者
  - 更好的选择：指数的回报完全可以通过更低费率买被动基金来获，没必要为"伪主动"买单
  *边界*：若"伪主动"基金有其他的价值（如更好的风险控制、更低的波动性），可能并非完全负面；若"伪主动"基金费率足够低，投资者可能接受

* Q6: 新规下，主动偏股基金如何平衡"主动风险"与"偏离超额"？
  *结论*：以基准为锚，审慎权衡能力、偏离带来的超额收益与潜在风险，避免"盲目的主动"和"伪主动"两个极端。
  *形式化*：新规下主动管理 = 基准为锚 ∩ 能力圈 ∩ 偏离度 ∩ 风险控制 → 避免盲目主动（高偏离低能力）和伪主动（低偏离高费率）
  *怎么想到的*：
  - 两个极端：高主动持股比例≠高业绩（盲目主动），低主动持股比例=伪主动（价值缺失）
  - 平衡之道：基金经理需要以基准为锚，在控制主动风险和通过偏离获取超额之间取得平衡
  - 综合评估：将主动持股比例与其他指标（风险调整后收益、跟踪误差、费率等）结合，综合判断基金价值
  *边界*：若基金经理能力不足，过度偏离基准会加大波动；若基金经理能力出众，适度偏离可能创造超额收益

* 收口
作者通过分析主动持股比例与业绩的关系，揭示了一个反直觉的真相：高主动持股比例不等于高业绩，"盲目的主动"和"伪主动"都会损害投资者利益——投资者应该关注基金经理的能力圈和投资流程，而非单纯追求"高主动"或"低主动"。
