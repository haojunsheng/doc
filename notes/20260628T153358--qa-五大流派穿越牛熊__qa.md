* 引子
晨星把权益和固收基金经理分成五大流派，通过代表性人物拆解每种风格穿越牛熊的核心逻辑。选基金不在于追明星，而在于找到和自己风险偏好匹配的策略。

* Q1: 长期价值派穿越牛熊靠什么？
  *结论*: 靠"好公司+好价格"的坚守，不追波段、不割肉。
  *形式化*: 低估值好公司 × 低换手长持有 → 熊市抗跌 + 牛市不缺席 → 复利积累
  *怎么想到的*:
  - 杨鑫鑫和姜诚的共同点：都等好价格再买，不追高
  - 分散+低换手是外在表现，本质是对企业价值有判断、有耐心
  - 2022年沪深300跌20%，姜诚赚4.46%，说明策略在极端行情有效
  *边界*: 价值陷阱出现时——公司看似便宜但基本面持续恶化，坚守反而亏钱。

* Q2: 硬核成长派和长期价值派的本质区别是什么？
  *结论*: 成长派赚的是产业趋势的钱，价值派赚的是估值修复的钱。
  *形式化*: 成长派：行业萌芽期布局 → 业绩驱动股价 → 波动大但弹性高；价值派：低价买好公司 → 等市场定价 → 波动小但靠时间
  *怎么想到的*:
  - 谢治宇早期换手300%降到100%，说明从交易转向陪伴企业成长
  - 成长派的核心是判断产业趋势，不是判断估值高低
  - 两者都看公司质地，但一个重增速、一个重安全边际
  *边界*: 产业趋势判断错了或介入太早，成长派可能承受巨大回撤。

* Q3: GARP均衡派真的能跑赢纯价值或纯成长吗？
  *结论*: 单一行情难居榜首，但牛熊交替间有"涨多跌少"的潜质。
  *形式化*: 成长 ≠ 估值 → GARP要求两者兼顾 → 放弃极端收益 → 换取极端行情生存
  *怎么想到的*:
  - 周云和刘旭的共同点：都看估值安全边际，也看公司质地
  - 刘旭从大盘成长切到大盘价值，说明动态调整比死守一种风格更灵活
  - 均衡派的核心是"不偏不倚"，牺牲锐度换稳定性
  *边界*: 市场风格极度分化时，均衡派两头都不沾，可能跑输集中配置的选手。

* Q4: 固收+增强派为什么能跑赢纯债？
  *结论*: 靠10%-30%权益敞口做收益增强，债券打底保安全。
  *形式化*: 纯债底仓（70%-90%）+ 权益增强（10%-30%）→ 债稳股增 → 收益↑ 风险可控
  *怎么想到的*:
  - 低利率环境下纯债收益被压缩，必须找增强来源
  - 王晓晨股票、转债、债券都高度分散，不是靠集中押注增强
  - 祝松在牛市加转债仓位、调整前减仓，说明择时也是增强手段之一
  *边界*: 股债双杀时，固收+增强派两头承压，增强变亏损。

* Q5: 纯债稳健派的核心竞争力是什么？
  *结论*: 严格信用筛选 + 灵活久期管理，追求绝对收益和极低回撤。
  *形式化*: 高等级债券 + 低久期 + 低杠杆 → 回撤极小 → 夏普比率高
  *怎么想到的*:
  - 黎颖芳在利率波动加剧时反而缩窄久期，说明风控优先于收益
  - 黄纪亮AAA以下占比控制在20%以下，低评级个券不超0.5%
  - 两家纯债基金共同点：不碰高风险品种，赚确定的钱
  *边界*: 利率单边下行时，低久期策略会跑输长久期基金。

* Q6: 选流派时最该看什么指标？
  *结论*: 看策略一致性和可复制性，不看短期业绩排名。
  *形式化*: 短期排名 = 运气 + 风格适配；策略一致性 = 框架稳定 × 执行纪律
  *怎么想到的*:
  - 晨星反复强调"清晰框架、严格风控、独立判断"是五派共有特质
  - 谢治宇换手从300%降到100%是框架进化的表现，不是风格漂移
  - 刘旭随周期动态调整但底层逻辑不变，说明好策略有弹性但不变形
  *边界*: 基金经理变更或核心逻辑改变时，历史策略一致性不再有效。

* 收口
这篇文章的真正贡献不是教投资者选哪个流派，而是给出一个分类框架：看清基金经理靠什么赚钱、在什么环境下有效，才能做出适合自己的选择。
