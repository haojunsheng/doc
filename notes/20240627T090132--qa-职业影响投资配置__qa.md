* 引子

做投资配置时，大多数人只考虑股票、债券这些金融资产，却忽略了一个巨大的"隐性资产"——你的职业和收入能力。晨星旗下Ibbotson首创的方法论把人力资本纳入配置框架：一个收入稳定的教授，本质上已经"持有"了大量债券，所以金融资产可以更激进。

* Q1: 为什么要把人力资本纳入资产配置？

  *结论*：因为你的总收入=金融资本增值+人力资本收入，只看金融资产会做出错误决策。

  *形式化*：总资产 = 金融资产 + 人力资本(未来收入折现)
           只看金融资产 → 忽略风险敞口重叠 → 配置偏差

  *怎么想到的*：
  - 文章指出：人的总财富包括可交易的金融资本和不可交易的人力资本
  - 人力资本随年龄增长减少，金融资本随年龄增长增加
  - 不考虑人力资本就像只看半张地图做导航

  *边界*：人力资本难以精确量化（未来收入不确定），只能做粗略估计。

* Q2: 为什么教授可以比基金经理更激进？

  *结论*：因为教授的收入像债券（稳定可预期），已经"隐持"了大量低风险资产。

  *形式化*：教授: 人力资本≈债券(稳定) → 金融资产可激进(多配股)
           基金经理: 人力资本≈股票(随市场波动) → 金融资产需保守

  *怎么想到的*：
  - 阎志鹏教授自己的案例：收入稳定如国债，所以少配债多配股
  - 逻辑：如果人力资本已经是"债券"，金融资产就该去配"股票"来平衡
  - 反过来，一个收入随股市涨跌的人，金融资产应该偏保守

  *边界*：如果教授的 tenure 并不稳定（如非升即走），这个类比就不成立。

* Q3: 硅谷银行员工犯了什么经典错误？

  *结论*：人力资本和金融资产都押在同一家公司，风险完全没分散。

  *形式化*：硅谷银行员工: 工资(来自银行) + 退休金(投银行股票) = 100%集中
           结果: 银行倒闭 → 失业+退休金亏损 = 双杀

  *怎么想到的*：
  - 18%的退休金资产投了自家银行股票
  - 银行倒闭后同时失去工作和投资
  - 这是人力资本和金融资产相关性最高的极端案例

  *边界*：不是所有公司员工都该避开自家股票，但高比例集中肯定危险。

* Q4: 互联网大厂员工为什么这几年资产大缩水？

  *结论*：因为他们的工资依赖互联网行业，投资也集中在互联网，双重押注同一赛道。

  *形式化*：大厂员工: 工资(互联网) + 期权(互联网) + 投资(中概股) = 行业集中
           结果: 行业下行 → 降薪+期权贬值+投资亏损 = 三重打击

  *怎么想到的*：
  - 文章指出这是国内版的"硅谷银行陷阱"
  - 工资、期权、投资三个来源都依赖同一个行业的景气度
  - 任何单一行业波动都会同时打击三个收入来源

  *边界*：如果你在互联网行业但投资完全分散（如全球指数+债券），风险就小得多。

* Q5: 普通人怎么把人力资本框架用起来？

  *结论*：先判断你的职业收入像债券还是股票，然后在金融资产中做反向配置。

  *形式化*：职业像债券(稳定) → 金融资产多配股票
           职业像股票(波动大) → 金融资产多配债券/现金

  *怎么想到的*：
  - 公务员/教师/医生 → 收入稳定 → 金融资产可以更积极
  - 创业者/销售/自由职业者 → 收入波动大 → 金融资产需保守
  - 关键：让两类资产的风险属性互补，而不是叠加

  *边界*：行业判断比职业判断更重要——一个"稳定职业"如果所在行业在衰退，人力资本也不安全。

* 收口

作者通过一个被忽视的维度——职业风险——揭示了为什么很多人"分散投资"仍然亏钱：他们的人力资本和金融资产在暗中高度正相关，一荣俱荣一损俱损。
