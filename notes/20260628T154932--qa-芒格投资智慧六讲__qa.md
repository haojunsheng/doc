* 引子
芒格去世后，晨星重温2006年韦斯科金融年会上的对话，围绕机会成本、理性、嫉妒、学习、错误、风险六主题。每一条都指向同一个核心：投资是认知纪律的较量，不是智力的较量。

* Q1: 巴菲特为何放弃新兴市场选富国银行？
  *结论*: 机会成本思维——任何选择都要跟已有持仓比较，不是孤立判断好坏。
  *形式化*: 投资决策 = 新标的 vs 已有持仓 → 认知不够或收益不够 → 放弃
  *怎么想到的*:
  - 巴菲特说买新兴市场不如加仓富国银行踏实
  - 关键不是标的是否"好"，而是比已有持仓是否更好
  - 两个自问：认知是否更高？风险调整收益是否更高？
  - 都是否就该放弃
  *边界*: 若已有持仓逻辑被证伪，即便新标的不够好也应切换。

* Q2: 市场"常识"为何是投资最大的敌人？
  *结论*: 常识往往是集体幻觉，被常识牵着走等于在泡沫高点接盘。
  *形式化*: 市场常识 = 集体情绪 → 追常识 = 追高 → 保持理性 = 独立判断
  *怎么想到的*:
  - 芒格呼吁避免受市场"常识"干扰
  - 他的投资记录就是严谨独立思考的见证
  - 成功投资者必须立足现实、摆脱情绪和认知干扰
  *边界*: 有些"常识"是对的（如均值回归），关键区分常识和规律。

* Q3: 嫉妒为何是七宗罪中最糟糕的？
  *结论*: 嫉妒让人追高、忽视风险、忘记更好的选择——既亏钱又不快乐。
  *形式化*: 嫉妒 → 追涨 → 亏钱 + 不快乐 → 双重惩罚
  *怎么想到的*:
  - 风投规模1999年后增10倍但大部分打水漂
  - 看到高回报就冲进去分一杯羹
  - 即使知道有泡沫也抵抗不住
  - 巴菲特和芒格从不跟风
  *边界*: 若别人的高回报来自真正的研究发现而非泡沫，跟进不叫嫉妒叫学习。

* Q4: 雅可比"反向思考"如何用在投资中？
  *结论*: 列出买的所有理由后，反过来想不买的理由，让研究更完整。
  *形式化*: 买入理由(N条) + 不买理由(N条) → 完整视角 → 更优决策
  *怎么想到的*:
  - 雅可比建议"始终反向思考"
  - 芒格认为不能说服对立面说明了解不够透彻
  - 列出买的所有理由再列不买的理由
  - 确保研究过程完整
  *边界*: 若反向思考后仍然倾向买入，说明决策更坚定；若犹豫则说明研究不够。

* Q5: 芒格说的"错误墙"两面是什么意思？
  *结论*: 一面纪念做错的，一面纪念没做但能致富的——两种愚蠢都值得铭记。
  *形式化*: 错误墙 = 做错的 + 没做但能赚的 → 两种愚蠢 → 双重学习
  *怎么想到的*:
  - 克里斯·戴维斯有面"错误墙"纪念失败投资
  - 芒格建议再加一面：没做却能致富的事
  - 忘记错误是可怕的错误
  - 现实不会主动提醒你
  *边界*: 若市场环境变了，过去的"错误"可能在新环境下是对的。

* Q6: 芒格为何敬佩约翰·阿里亚加不杠杆？
  *结论*: 真正的风险控制不是追求高回报，而是确保最坏情况也不会被打倒。
  *形式化*: 不杠杆 → 危机时零压力 → 疯狂世界中被动位置↓
  *怎么想到的*:
  - 阿里亚加1500万平方英尺资产中有300万空置
  - 因为没有杠杆，危机来了连眉头都不皱
  - 一般开发商不断贷款扩张
  - 有意识排除风险才能在疯狂世界中不被动
  *边界*: 若永远不杠杆，可能错过合理加杠杆的机会——关键是"不被动"。

* 收口
芒格六讲归一：投资的敌人不在外部市场，在自己——不比较就乱买、被常识就追高、见别人赚钱就嫉妒、不反向思考就片面、忘错误就重蹈覆辙、加杠杆就失去从容。
