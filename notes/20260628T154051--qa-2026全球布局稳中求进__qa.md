* 引子

晨星CEO Kunal Kapoor 与三位区域策略师（美洲Preston、欧洲Michael、亚洲Kai）的圆桌对话，核心问题是：2026年该怎么配。三位策略师各自回顾了2025年的意外变量——关税冲击、AI热潮、市场韧性——并给出了2026年的风险清单和行动建议。整篇的底色是"不确定性是主旋律"，但每个人开出的药方不同。

* Q1: 晨星做市场展望的价值在哪，不是预测的话？

  *结论*：晨星的价值在于用10年视角过滤噪音，不跟风短期爆发。

  *形式化*：`跟风: 涨 → 推荐 → 不可持续 | 晨星: 退后10年 → 评估护城河 → 过滤噪音`

  *怎么想到的*：
  - Kai Wang明确吐槽"金融预测准确性太难验证"
  - 但晨星不做单年预测，而是用长期视角评估持续增长能力
  - 短期爆发的公司隐含的长期增长率往往不可持续
  - 展望的价值是给投资者一个"退后一步"的视角

  *边界*：长期视角可能错过短期交易机会，对短线投资者无意义。

* Q2: 2025年最超预期的变量是什么，三位策略师怎么看？

  *结论*：关税政策和AI投资热度是最大意外，但市场韧性更令人惊讶。

  *形式化*：`预期: 关税冲击 → 市场崩盘 | 实际: 冲击 → 快速反弹 → 几乎被遗忘`

  *怎么想到的*：
  - Preston: 关税是最意外变量，AI投资热情远超想象
  - Michael: 市场韧性最意外，4月关税冲击后迅速恢复
  - Kai: 亚洲AI股估值离谱，营收极低负现金流的公司也能高估值上市
  - 三人都没预料到市场这么快消化了负面冲击

  *边界*：如果关税成本开始传导到消费价格，韧性可能被打破。

* Q3: AI投资热潮到底站得住脚吗？

  *结论*：只有当AI真正推动实体经济效率提升时，估值才站得住——现在还不到时候。

  *形式化*：`AI支出计划 + 股价上涨 ≠ 估值成立 | AI提升实体效率 → 估值成立`

  *怎么想到的*：
  - Preston认为关键不是AI支出多少，而是能否推动更广泛经济领域的效率
  - 亚洲部分AI公司营收极低、负现金流、只有概念就能高融资
  - 英伟达占美国指数8%、全球指数6%，被动投资者集中度风险极高
  - 客服自动回复级别的应用不够，需要结构性颠覆

  *边界*：如果AI加速落地到实体经济，当前估值可能被证明合理。

* Q4: 被动持有AI权重股的投资者，2026年该做什么？

  *结论*：警惕集中度风险，避免在个股和行业层面进一步加仓AI。

  *形式化*：`英伟达占指数8% + 主动加仓 → 过度集中 → 需要减配或至少不加`

  *怎么想到的*：
  - 英伟达在主要指数中权重已经很大
  - 被动投资者实际上已经"被动"重仓了AI
  - 如果再在个股层面加仓英伟达，集中度风险过高
  - 行业层面追逐AI主题也会加剧风险

  *边界*：如果AI继续跑赢，减配会拖累短期回报。

* Q5: 2026年最大的潜在波动源是什么？

  *结论*：关税传导到消费价格 + 高通胀导致降息落空 + 信贷违约率上升。

  *形式化*：`关税 → 消费价格传导 → 通胀上升 → 降息泡汤 → 消费回调 + 违约上升`

  *怎么想到的*：
  - Preston: 目前关税对消费价格传导有限，如果改变则连锁反应
  - 高通胀可能让美联储降息计划泡汤
  - 信用卡违约率已高于疫情前，如果利率维持高位可能进一步恶化
  - Michael补充: 失业率已在小幅上升，消费者支出预期可能落空

  *边界*：如果关税不再升级或企业自行吸收成本，这条传导链会断。

* Q6: 欧洲和亚洲各自的核心机会和软肋是什么？

  *结论*：欧洲宏观顺风但消费恢复存疑；亚洲分化严重但产能过剩行业龙头有机会。

  *形式化*：`欧洲: 宏观顺风 + 利率下行空间 | 但: 消费能否恢复？国防股风险？ | 亚洲: 科技强 + 产能过剩行业龙头机会 | 但: 房地产拖累财富效应`

  *怎么想到的*：
  - 欧洲：宏观经济从低位回升，通胀受控，利率有下行空间
  - 欧洲风险：消费者支出能否恢复、乌克兰战争结束对国防股的影响
  - 亚洲：阿里腾讯在向超大规模科技公司演进，中国产能过剩政策利好龙头
  - 亚洲软肋：房地产下行影响财富效应，中国消费更多受财富效应驱动

  *边界*：欧洲消费数据如果超预期，上行空间很大；亚洲房地产如果企稳，消费会跟上。

* Q7: 当前投资者最该警惕的行为偏差是什么？

  *结论*：FOMO（害怕错过）让投资者在高位跟风，推高估值后大幅回落。

  *形式化*：`FOMO: 看到涨 → 追高 → 估值极高 → 大幅回落`

  *怎么想到的*：
  - Kai Wang举了泡泡玛特的例子：Labubu火爆 → 投资者追母公司股票 → 估值推极高 → 股价大幅回落
  - 这不是个案，是各市场的普遍现象
  - FOMO驱动的决策往往在高点买入

  *边界*：如果趋势持续，FOMO可能短期获利，但长期大概率亏钱。

* Q8: 三位策略师自己的组合做了什么调整？

  *结论*：都在减持高估标的腾现金，Preston考虑用AI股对冲职业风险。

  *形式化*：`Michael/Kai: 减持高估 → 腾现金 → 备波动 | Preston: 考虑配AI → 对冲职业风险`

  *怎么想到的*：
  - Michael承认自己现金仓位太低，正在减持明显高估的标的
  - Kai也在看减持空间，并用比特币走势观察市场情绪
  - Preston思考的是"人力资本"对冲：白领职业可能被AI冲击，所以配AI股
  - 三人共同点：都承认需要留有余地应对波动

  *边界*：腾现金意味着如果市场继续上涨，短期会跑输。
