* 引子
"基金赚钱、基金销售赚钱、基民不赚钱"是中国基金市场三大顽疾。晨星战略顾问陈鹏在2023资产管理年会演讲指出，解法不是降费而是商业模式转型——从"以产品销售为中心"转向"以客户为中心的买方投顾"。

* Q1: 基民不赚钱的根因是什么？
  *结论*: 商业模式问题——以产品销售为中心的模式让销售利益与投资者利益不一致。
  *形式化*: 基民不赚钱 = 销售导向(卖产品) ≠ 客户导向(帮赚钱)
  *怎么想到的*:
  - 基金赚钱+销售赚钱+基民不赚钱 = 三方利益不一致
  - 销售机构佣金来自卖产品规模，不来自客户收益
  - 以产品销售为中心的业务模式出现了问题
  *边界*: 若基金公司真正践行客户利益至上，销售导向的矛盾会缓和。

* Q2: 隐性成本为何比显性成本更可怕？
  *结论*: 交易费（隐性成本）在高换手基金中可达6.8%，直接吞噬收益却不被投资者感知。
  *形式化*: 显性成本(管理费) < 隐性成本(交易费6.8%) → 隐性成本才是大头
  *怎么想到的*:
  - 基金投资有显性成本（管理费）和隐性成本（交易费）
  - 中国股市换手率高导致交易费用高
  - 有些基金交易成本达6.8%，输在起跑线
  - 投资者往往只看管理费不看交易费
  *边界*: 若市场换手率下降或交易费率降低，隐性成本会收窄。

* Q3: 美国费率下降靠监管还是市场？
  *结论*: 靠市场——买方投顾兴起+竞争加剧推动费率自发下降，监管没有强制。
  *形式化*: 美国费率↓ = 市场竞争(拼客户) + 买方投顾兴起 ≠ 监管强制
  *怎么想到的*:
  - 美国主动权益基金管理费从1.06%降至0.68%
  - 债券基金从0.77%降至0.46%
  - 指数基金降至0.06%
  - 两大因素：市场竞争加剧+买方投顾兴起
  *边界*: 若市场集中度提高、竞争减弱，费率下降动力会消退。

* Q4: 买方投顾如何实现三赢？
  *结论*: 投顾从客户需求出发做资产配置，客户赚钱→投顾赚钱→基金公司也赚钱。
  *形式化*: 买方投顾 = 客户需求导向 → 客户赚钱 → 投顾赚钱 → 基金公司赚钱
  *怎么想到的*:
  - 投顾以客户为中心做资产配置
  - 不支付销售佣金的基金公司通过投顾销售
  - 经历多次危机仍创造可观收益
  - 投资者主动认购，不愁销售
  *边界*: 若投顾机构短期考核压力过大，可能回到销售导向。

* Q5: 投顾机构如何证明客户体验好？
  *结论*: 两个关键问题——客户是否愿意推荐给亲友？是否已向大部分亲友推荐？
  *形式化*: 投顾体验好 = 愿意推荐(是) + 已推荐多数(是)
  *怎么想到的*:
  - 陈鹏提出两个衡量标准
  - 客户是否愿意推荐给亲朋好友
  - 是否已经向大部分朋友亲人推介
  - 两个"是"直接证明体验好
  *边界*: 若客户推荐是出于奖励机制而非真实体验，指标会失真。

* Q6: 中国投顾业务发展需要什么条件？
  *结论*: 长期主义考核+监管扶持+科技赋能+合规意识，缺一不可。
  *形式化*: 投顾成功 = 长期考核 + 监管扶持 + 科技赋能 + 合规意识
  *怎么想到的*:
  - 做好买方投顾是长期工程
  - 短期考核无法落实长期战略
  - 欧美监管扶持推动投顾发展
  - 欧洲强制基金销售转型投顾
  - 需要科技赋能优化运营效率
  *边界*: 若监管不扶持、市场不配合，投顾业务可能长期停滞。

* 收口
买方投顾不是新业务，而是商业模式革命——从"卖产品"到"管账户"，谁先完成这个转型，谁就能赢得下一代投资者的信任。
