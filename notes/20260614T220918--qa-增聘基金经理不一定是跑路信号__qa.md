招商产业债券基金经理马龙卸任，刘万锋接手——这是"跑路"吗？晨星数据显示，国内近四分之一基金由两位以上基金经理共同管理。增聘基金经理有四种常见原因，不是所有都是坏信号。

* Q1: 增聘基金经理有哪四种常见原因？

  *结论*：以老带新、优势互补、分担工作负荷、老经理离职信号。

  *形式化*: 增聘原因 = {培养新人, 能力互补, 减负, 离职信号}

  *怎么想到的*：
  - 以老带新：兴全合宜历史上多次增聘，新人合管1-2年后卸任
  - 优势互补：建信纯债2019年增聘彭紫云，黎颖芳管利率债、彭紫云管信用债
  - 分担负荷：工银双利欧阳凯升任固收总经理后，2021和2022年分别增聘徐博文和李昱
  - 离职信号：丘栋荣2025年5月密集增聘，7月宣布卸任

  *边界*：四种原因可能同时存在——比如增聘既是为了培养新人，也是为老经理减负。

* Q2: 如何判断增聘是"以老带新"还是"跑路信号"？

  *结论*：看投资团队稳定性、新经理经验、以及是否所有基金同时增聘。

  *形式化*: 判断矩阵: 团队稳定 + 新经理经验浅 = 以老带新； 所有基金密集增聘 + 新经理风格相似 = 离职信号

  *怎么想到的*：
  - 以老带新：原经理任职稳定，新人此前是研究员或基金经理助理
  - 以老带新时决策权在原经理手里，新经理分仓不足以大幅影响业绩
  - 离职信号：所有或大部分基金短期内密集增聘，且新经理风格与原经理相似

  *边界*：初次合作的基金经理需要磨合期——即使不是离职信号，也要密切观察。

* Q3: 优势互补型增聘的核心逻辑是什么？

  *结论*：让两位基金经理各管擅长的领域，实现1+1>2。

  *形式化*: 优势互补 = 经理A专长 × 经理B专长 > 单独管理

  *怎么想到的*：
  - 建信纯债：黎颖芳（宏观/利率债） + 彭紫云（信用债） = 各司其职
  - 两位经理此前在其他产品上有过类似合作，是加分项
  - 如果初次合作，可能存在磨合问题

  *边界*：分工明确是前提——如果两位经理投资理念冲突，反而会拖累业绩。

* Q4: 面对基金经理变动，投资者应该怎么做？

  *结论*：重新做功课——评估继任者的投资能力、投资流程是否稳定、是否符合自己的投资目标。

  *形式化*: 变动后评估 = 继任者经验 + 投资流程稳定性 + 与自身目标匹配度

  *怎么想到的*：
  - 基金未来的投资动作、风格、业绩都可能随新经理改变
  - 继任者可能是经验丰富的老将，也可能是新人
  - 投资者需要重新判断基金是否仍符合自己的风险偏好和投资目标

  *边界*：如果新经理能力出色且流程稳定，变动反而是好事。

* 收口

增聘基金经理是公募行业的常态——别急着跑，先搞清楚为什么增聘、接班的人能不能hold住。
