* 引子
2025年上半年公募基金规模达到29.6万亿，但资金流入节奏在放缓。最核心的变化是：被动基金在持续吸金，主动基金（尤其混合型）连续四年净流出。资金的选择已经用脚投票。

* Q1: 为什么混合型基金连续四年净流出？
  *结论*: 因为混合型都是主动基金，业绩差+投资者失望=持续赎回。
  *形式化*: 主动偏股基金超额能力↓ + 净值下跌 → 投资者赎回 → 连续四年净流出
  *怎么想到的*:
  - 混合型基金目前全部是主动型产品
  - 2022年以来A股系统性调整，主动基金超额收益难度加大
  - 长时间亏损导致大面积赎回，2025上半年流出1679亿
  *边界*: 2025年随着股市回暖，流出速度已在放缓，如果业绩改善可能逆转。

* Q2: 被动基金为什么能持续吸金？
  *结论*: 低费率+透明度高+债券和商品型被动产品持续净流入。
  *形式化*: 被动基金 = 低费率 + 透明 + 不依赖基金经理 → 投资者偏好 → 持续净流入
  *怎么想到的*:
  - 2022年以来非货基净流入核心由被动型驱动
  - 债券型被动和商品型被动净流入还在逐年增加
  - 即使2023-2024年股市下跌，股票型被动仍大幅净流入
  *边界*: 如果市场波动加剧、被动基金跟踪误差扩大，资金流入可能放缓。

* Q3: 为什么2025年QDII基金出现了资金净流出？
  *结论*: 因为A股行情反转，资金从海外回流国内。
  *形式化*: 2024年9月政策刺激 → A股大涨 → 资金从QDII回流A股 → 2025上半年QDII净流出117.5亿
  *怎么想到的*:
  - 2021-2024年A股持续走低时QDII快速增长
  - 2024年9月三部委政策后A股反转，QDII资金流入放缓甚至流出
  - 但得益于美股强劲，QDII规模仍增长11%（资本增值）
  *边界*: 如果A股行情再次走弱或美股大幅回调，QDII资金流可能再次转向。

* Q4: 为什么债券型ETF在2025年爆发式增长？
  *结论*: 低利率环境下信用债ETF新产品集中发行，吸引了大量资金。
  *形式化*: 低利率 + 8只信用债ETF发行 + 债牛余温 → 债券ETF净流入2000亿+ → 规模翻倍
  *怎么想到的*:
  - 2025年Q1发行了8只基准做市信用债ETF，上市后规模均破百亿
  - 债券型ETF资金流首次超过股票型ETF，占整个ETF资金流一半以上
  - 利率债分类相比2023年底增长1.4倍
  *边界*: 如果利率反转上行，债券ETF可能面临资金流出和净值下跌。

* Q5: 基金公司竞争格局有什么变化？
  *结论*: 头部效应增强，前10大基金公司占非货基规模44%，被动规模占比在头部公司中快速上升。
  *形式化*: 前10大占44% + 前20大占66% → 头部集中；华夏71%被动 + 华泰柏瑞89%被动 → 被动主导头部
  *怎么想到的*:
  - 易方达和华夏是仅有的两家非货基规模破万亿的公司
  - 前7大基金公司中4家被动规模占比超过主动
  - 8-20名仍以主动为主，中欧和兴证全球被动占比不足一成
  *边界*: 中小基金公司如果既没有主动超额能力也缺乏被动产品资源，生存空间会越来越小。

* Q6: 商品基金为什么增长这么猛？
  *结论*: 黄金价格持续创新高，避险和资产配置需求推动资金涌入。
  *形式化*: 黄金价格↑↑ + 避险需求 + 资产配置 → 商品基金净流入643亿 → 规模4倍增长
  *怎么想到的*:
  - 18只商品基金中14只投黄金
  - 2023年起黄金进入明显上涨阶段，不断创历史新高
  - 2025年上半年净流入是2024全年的近2倍
  *边界*: 如果黄金价格进入调整期，商品基金的资金流入会快速降温。

* 收口
晨星这篇报告的核心信号是：基金行业的"主动vs被动"格局正在发生结构性转变——被动产品凭借低成本和政策支持快速扩张，主动产品必须用真实的超额能力才能留住资金，过去"发什么都行"的时代已经结束。
