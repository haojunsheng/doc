* 引子
特朗普对加拿大墨西哥加征25%关税、对中国加征10%关税。晨星测算显示整体冲击有限，大部分企业受影响不超过总营收5%。家电行业因提前海外布局缓解冲击，新能源车海外扩张受阻，跨境电商反而可能因订单减少改善亏损。

* Q1: 特朗普对中国加征10%关税整体影响有多大？
  *结论*: 晨星测算大部分企业受影响不超过总营收5%，整体可控。
  *形式化*: 关税影响 ≤ 5%总营收 → 整体冲击有限 → 行业分化明显
  *怎么想到的*:
  - 晨星基于消费者完全不考虑受关税影响商品的假设估算
  - 实际影响可能更小（企业对策+消费者价格敏感度低）
  - 但市场情绪波动可能放大短期震荡
  *边界*: 若关税税率进一步升级或范围扩大，影响会非线性放大。

* Q2: 家电行业为什么能缓解关税冲击？
  *结论*: 经历2018年贸易战后，中国家电企业已通过海外建厂和转口贸易提前应对。
  *形式化*: 海外建厂(产能转移) + 转口贸易 → 绕过关税 → 冲击缓解
  *怎么想到的*:
  - 海尔30%销售来自美国但60%在美国本地生产
  - 美的7%-8%营收来自美国但仅5%本地生产，影响更大
  - 关键变量：美国本地产能占比
  *边界*: 若美国对海外组装也加征关税（如原产地规则收紧），转口贸易优势会减弱。

* Q3: 为什么海尔受关税影响比美的小？
  *结论*: 海尔美国销售60%在本地生产，美的仅5%在本地生产，海尔受关税冲击远小于美的。
  *形式化*: 海尔(60%本地生产) >> 美的(5%本地生产) → 海尔受冲击 << 美的受冲击
  *怎么想到的*:
  - 海尔约30%销售额来自美国，其中60%本地生产
  - 美的7%-8%营收来自美国，仅5%本地生产
  - 本地生产比例是决定关税影响的核心变量
  *边界*: 若美的加速美国建厂，差距会缩小。

* Q4: 新能源车行业为什么受关税影响更大？
  *结论*: 比亚迪北美营收占比5%-10%，关税上调会拖慢海外扩张进度甚至影响盈利增长。
  *形式化*: 比亚迪北美占比5-10% + 关税上调 → 海外扩张受阻 → 盈利增速承压
  *怎么想到的*:
  - 中国新能源车全球渗透率提升，美国是重要增量市场
  - 电池龙头宁德时代和国轩高科出口市场更多元，可调整结构
  - 上游锂矿企业因需回国内加工，潜在冲击更大
  *边界*: 若中国车企加速在墨西哥建厂出口美国，可规避部分关税。

* Q5: 跨境电商Temu为何受关税冲击反而可能有利？
  *结论*: Temu在美国"烧钱补贴抢市场"阶段，关税导致订单减少反而可能改善亏损。
  *形式化*: 订单减少 → 补贴减少 → 亏损收窄 → 净利润反而改善
  *怎么想到的*:
  - Temu目前以抢占市场份额为首要目标
  - 关税导致订单减少意味着补贴支出也减少
  - 同时Temu已拓展美国以外市场分散风险
  *边界*: 若Temu已进入盈利阶段，订单减少就是纯负面了。

* Q6: 为什么关税直接影响小但市场波动可能大？
  *结论*: 市场不是完全理性的，情绪波动可能导致短期震荡，但短期波动往往是机会。
  *形式化*: 基本面影响小 ≠ 市场波动小 → 情绪放大波动 → 冷静者获机会
  *怎么想到的*:
  - 晨星明确说"市场先生大多数时候都不是完全理性的"
  - 短期波动不等于基本面恶化
  - 保持冷静、做好分散的投资者反而能从中获益
  *边界*: 若关税升级引发全球系统性风险，分散配置也无法完全避险。

* Q7: 投资者面对关税政策应该怎么做？
  *结论*: 理性分析基本面影响，做好分散配置，短期波动中寻找被错杀的优质公司。
  *形式化*: 理性分析(基本面) + 分散配置(降低风险) + 逆向布局(情绪低点买入)
  *怎么想到的*:
  - 晨星建议"理性看待风险，做好长期投资规划"
  - 短期波动往往是机会而非危机
  - 关键是区分情绪波动和基本面恶化
  *边界*: 若关税政策持续升级超出预期，需要重新评估整体配置。

* 收口
晨星用关税2.0的分析证明：中国企业的海外布局和多元化能力比2018年大幅提升，这次冲击整体可控——真正危险的不是关税本身，而是恐慌。
