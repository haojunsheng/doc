* 引子
被动型债券基金一年内从253只飙升到348只，规模从7042亿翻倍到1.5万亿，债券ETF半年翻倍到3844亿。中国的固收被动投资时代正式到来，但不同类型债券的被动化进度差异极大——利率债领先、信用债滞后、纯债几乎空白。

* Q1: 为什么债券被动投资突然爆发？
  *结论*: 利率下行压缩主动超额空间+低费率+T+0交易+政策支持四重驱动。
  *形式化*: 利率↓ → 主动超额难 + 被动低费率 + ETF T+0 + 政策推动 → 被动债基爆发
  *怎么想到的*:
  - 利率持续下行，基金经理主动操作空间越来越小
  - 被动产品费率低、持仓透明，在"赚不到超额"时优势更明显
  - 债券ETF的T+0机制大幅提升交易灵活性
  - 监管推动ETF纳入质押回购、互联互通、快速审批
  *边界*: 如果利率反转上行，主动基金经理的久期操作空间扩大，被动优势会减弱。

* Q2: 为什么利率债被动化程度远高于信用债？
  *结论*: 利率债标准化程度高容易复制，信用债差异大跟踪难度高。
  *形式化*: 利率债 = 国债/政金债 + 发行主体集中 + 标准化 → 被动占比49%；信用债 = 主体分散 + 信用差异大 + 流动性差 → 被动占比<20%
  *怎么想到的*:
  - 利率债集中在政府/政策性银行，券种少、流动性好
  - 信用债涵盖企业债、中票、城投债，信用资质差异极大
  - 信用债估值不连续、流动性差，指数复制成本高、跟踪误差大
  *边界*: 如果信用债市场流动性改善、评级体系完善，被动化比例会提升。

* Q3: 为什么纯债基金被动占比只有2%？
  *结论*: 纯债基金主动管理空间大，投资者愿意为潜在超额付管理费。
  *形式化*: 纯债 = 信用债为主 + 主动管理空间大（信用下沉+杠杆+久期）→ 投资者愿付1.66%管理费 → 被动仅2%
  *怎么想到的*:
  - 纯债基金主要通过信用下沉、杠杆和久期调节获取超额
  - 主动转债基金管理费中位数1.66%，两只ETF费率仅0.15%-0.24%
  - 但纯债基金经理确实能通过主动操作创造超额，所以投资者愿意付溢价
  *边界*: 如果信用债市场有效性提升、超额空间压缩，纯债被动化也会跟进。

* Q4: 可转债ETF为什么规模占比高达42%？
  *结论*: 可转债产品集中在少数ETF，低费率+T+0交易吸引大量资金。
  *形式化*: 两只转债ETF = 0.15%/0.24%费率 + T+0 → 规模占可转债基金42%
  *怎么想到的*:
  - 目前被动可转债基金只有海富通和博时两只ETF
  - 费率远低于主动转债基金的1.66%中位数
  - T+0交易机制是主动基金做不到的（主动普遍T+1/T+3）
  *边界*: 如果更多基金公司进入转债ETF领域，现有产品的吸金效应可能减弱。

* Q5: 固收+和QDII环球债券为什么没有被动产品？
  *结论*: 跨资产/跨市场投资操作复杂度太高，被动管理难以同步跟踪。
  *形式化*: 固收+ = 股+债+转债跨资产 → 需同时跟踪多个市场 → 操作复杂 → 暂无被动产品
  *怎么想到的*:
  - 固收+涉及不同资产类别，波动性和流动性差异大
  - QDII环球债券涉及多个国家的利率、信用、汇率因素
  - 被动管理需要实时跟踪所有资产市值变化并调仓，技术上极其复杂
  *边界*: 如果技术发展和指数编制进步，未来这些领域也可能出现被动产品。

* Q6: 债券被动投资浪潮下投资者怎么选？
  *结论*: 利率债选被动、信用债选主动，看主动基金经理的超额能否覆盖费用。
  *形式化*: 利率债/短债 → 被动（低费率+透明）；信用债/纯债 → 主动（超额空间大）
  *怎么想到的*:
  - 利率债领域被动投资"卓有成效"，因为同质性高、难赚超额
  - 信用债领域主动基金经理有"超越市场表现的机会"
  - 核心权衡：被动确定赚市场平均 vs 主动可能跑赢也可能跑输
  *边界*: 如果利率债市场出现大幅波动，主动基金经理的择时能力也会发挥作用。

* 收口
晨星这篇文章的核心贡献是：用数据证明了中国债券被动投资已经到来（规模和增速都是证据），但也指出不同类型债券的被动化进度会分化——标准化程度高的先行、差异化的仍需要主动管理。
