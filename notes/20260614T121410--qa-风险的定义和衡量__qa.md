沪指从3000点出发又回到3000点，提醒我们投资伴随着风险。但"风险"到底是什么？文章从概率角度重新定义了风险，并介绍了标准差、索提诺比率、晨星风险系数、最大回撤等指标，告诉你如何更全面地衡量风险。

* Q1: 风险到底是什么？

  *结论*：风险是不确定性，更准确地说，是损失的可能性。

  *形式化*：风险 = 不确定性 = 损失可能性；不是 = 波动

  *怎么想到的*：
  - 通俗定义：没人能预测明天涨跌
  - 概率角度：不好的事情发生的概率有多大
  - 霍华德·马克思：风险是损失的可能性
  - 波动只是风险的一种表现，不是风险本身

  *边界*：风险无法完全消除，但可以通过资产配置和分散来管理。

* Q2: 为什么标准差不是完美的风险指标？

  *结论*：因为标准差把上行风险和下行风险一视同仁，但投资者只关心下行风险。

  *形式化*：标准差 = 好风险 + 坏风险；投资者只关心 = 坏风险

  *怎么想到的*：
  - 标准差衡量回报围绕平均水平的波动幅度
  - 跌得很猛的基金标准差高，涨得很猛的也高
  - 但投资者只关心下跌风险
  - 需要区分"好"波动和"坏"波动

  *边界*：标准差是简单、广为接受的指标，但需要结合其他指标来全面评估风险。

* Q3: 索提诺比率和夏普比率有什么区别？

  *结论*：夏普比率用标准差（好风险+坏风险），索提诺比率只用下行标准差（只有坏风险）。

  *形式化*：夏普 = 超额收益 / 标准差；索提诺 = 超额收益 / 下行标准差

  *怎么想到的*：
  - 两者都衡量每单位波动带来的超额收益
  - 夏普把上涨和下跌都算作波动
  - 索提诺只考虑下跌风险
  - 更精准展示冒着"赔钱"风险获得的回报

  *边界*：索提诺比率只考虑下行风险，但上行波动也是机会成本的体现。

* Q4: 为什么最大回撤很重要？

  *结论*：因为最大回撤衡量了极端情况下的表现，帮你做好"最坏打算"。

  *形式化*：最大回撤 = 从最高点到最低点的跌幅；价值 = 极端风险认知

  *怎么想到的*：
  - 标准差和索提诺比率无法刻画极端情况
  - 最大回撤衡量历史上最坏的时候到最差的时候的亏损
  - 帮你了解可能需要经历多大的痛苦
  - 做好心理准备

  *边界*：最大回撤是历史数据，未来可能出现更大的回撤。

* Q5: 为什么"真正的风险在数字之外"？

  *结论*：因为风险是极具个性化的东西，取决于你如何应对市场起伏。

  *形式化*：真正风险 = 你在错误时间做出错误决策；不是 = 量化指标

  *怎么想到的*：
  - 风险源于对未来的不确定性和未知
  - 真正的风险在于你如何应对
  - 每个人对风险的感知和应对方法不同
  - 取决于个性、经验、财务状况、生命周期

  *边界*：虽然风险难以完全量化，但量化指标仍然是重要的参考工具。

* 收口

风险不是波动，是损失的可能性。标准差、索提诺比率、最大回撤都是衡量风险的工具，但真正的风险在于你如何应对市场起伏。管理风险，而不是恐惧它——找到最舒适的资产配置，了解投资产品，考虑自己的投资行为。
