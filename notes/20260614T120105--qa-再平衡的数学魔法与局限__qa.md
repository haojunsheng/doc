* 引子

再平衡是投资组合管理中的经典策略——定期调整资产配置以维持目标比例。理论上它能"低买高卖"，但实践中再平衡的效果取决于交易成本、市场环境和执行纪律。

* Q1: 再平衡的核心逻辑是什么？

  *结论*：通过定期调整资产配置，实现"低买高卖"的纪律性操作。

  *形式化*: 再平衡 = 定期调整 → 卖出涨多的资产 + 买入跌多的资产 → 维持目标配置

  *怎么想到的*：
  - 投资组合随市场波动偏离目标配置
  - 再平衡通过纪律性操作实现低买高卖
  - 核心是"不贪多、不冒进"的纪律

  *边界*：再平衡不等于频繁操作——过度再平衡会增加交易成本。

* Q2: 再平衡的理论基础是什么？

  *结论*：基于"均值回归"假设——资产价格长期会回归均值。

  *形式化*: 理论基础: 均值回归 → 涨多的会跌，跌多的会涨 → 再平衡能捕捉这种回归

  *怎么想到的*：
  - 资产价格长期会回归历史均值
  - 再平衡利用这种均值回归特性
  - 卖出涨多的资产，买入跌多的资产

  *边界*：均值回归不是必然——在趋势性市场中，再平衡可能失效。

* Q3: 为什么再平衡在单边行情中效果不佳？

  *结论*：在单边行情中，再平衡会降低资金利用效率。

  *形式化*: 单边行情: 再平衡 → 过早卖出涨势资产 → 资金利用效率↓

  *怎么想到的*：
  - 在单边上涨行情中，再平衡会过早卖出涨势资产
  - 在单边下跌行情中，再平衡会过早买入跌势资产
  - 交易成本会不断侵蚀收益

  *边界*：在震荡行情中，再平衡效果最好。

* Q4: 再平衡的交易成本有多大？

  *结论*：交易成本会不断侵蚀收益——每次再平衡都要付手续费。

  *形式化*: 交易成本: 手续费 + 冲击成本 + 税收 → 再平衡净收益↓

  *怎么想到的*：
  - 每次再平衡都涉及买卖操作
  - 手续费、冲击成本、税收都会侵蚀收益
  - 有效进行仓位管理对择时能力要求极高

  *边界*：如果交易成本极低（如ETF内部再平衡），再平衡效果会更接近理论。

* Q5: 再平衡最根本的意义是什么？

  *结论*：不是提升回报，而是提供"纠错机制"——让组合不至于随市场波动失控。

  *形式化*: 再平衡 = 纠错机制；目标 = 保持配置在预设轨道上

  *怎么想到的*：
  - 再平衡最根本的意义不是提升回报，而是提供纠错机制
  - 帮助保持平稳投资心态，避免在市场涨跌中乱了阵脚
  - 锚定合理配置区间，只在必要时再平衡

  *边界*：不追求频繁操作——过度再平衡反而有害。

* 收口

再平衡是"纪律"而非"魔法"——它的价值在于帮助投资者保持配置在预设轨道上，而非追求超额回报。
