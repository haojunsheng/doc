- **x**：为什么中国政府不只是"市场失灵时的纠偏者"，而是经济运行的核心参与者？
- **f**：1994年分税制改变了地方政府的财力结构，但发展经济的政治激励未变，二者结合催生了"土地财政+土地金融+招商引资"的独特模式。
- **f(x)**：看中国经济的政策和现象时，不是问"政府该不该干预"，而是先问"激励结构是什么"，再追问资源配置会流向哪里。

# x：作者在讨论什么问题

主流经济学教材里的政府角色是清晰的：市场失灵时介入，提供公共物品、纠正外部性、反垄断。这套框架用来分析中国时却处处失灵——比如为什么地方政府能拿钱搞工业园、为什么房价上涨的同时政府还在压低工业地价招商引资、为什么地方债规模这么大却没有出现系统性崩溃。

兰小欢的问题是：如果把政府放回中国经济的核心位置，它为什么会这样运转？书中反复出现的疑问不是"政府该不该管"，而是"既然分了这么多权，为什么地方政府的钱袋子这么紧，还要搞这么多事"。

一个具体锚点：广东相当于世界第13大经济体，江苏是世界第14大经济体。但它们的财政收入并不像经济体量那么庞大。中国的"地方"不是加拿大的省份，更像独立的主权国家——经济体量够大，但财权有限，且发展经济的考核压力不变。这就是书的起点。

# f：作者怎样回答

书的核心框架是一条因果链：**财政制度 → 地方政府激励 → 土地财政与招商引资 → 宏观现象**。这条链的转折点是1994年分税制改革。

改革前，财政包干制让地方留成比例高，地方政府有动力发展乡镇企业，但中央财政越来越穷，宏观调控能力严重不足。分税制把增值税这一最大税种的75%划归中央，同时设立国税局垂直管理，从根本上扭转了"两个比重"（财政收入占GDP比重、中央收入占全国财政比重）不断下滑的局面。

但分税制的副作用同样深刻：地方预算内财力大幅缩水，而发展经济的任务没变，甚至更强了。地方政府必须另找财源。两条路并行：

**第一条路：土地财政。** 城市土地归国家所有，国有土地使用权可以有偿出让。1998年住房制度改革开启商品房时代，2002年"招拍挂"制度全面实施后，地方政府通过垄断土地一级市场，以高价出让住宅用地获取巨额土地出让收入。2010年土地出让收入占地方公共预算收入的比重达到68%。

**第二条路：土地金融。** 光靠卖地还不够搞基础设施建设。地方政府于是通过城投公司（土地融资平台），以土地为抵押向银行借贷，再用借来的钱搞园区开发、道路桥梁，提升土地价值，进而以更高价卖地——形成一个自我强化的循环。

这两条路与招商引资形成闭环：地方政府压低工业用地价格吸引制造业落地，制造业带来就业、GDP和增值税；同时抬高住宅用地价格套现；再用地价收入和土地抵押融资搞基础设施，进一步提升城市吸引力。这是一个"以地谋发展"的完整模式。

这个模式解释了书中的多条线索：

- 为什么各地竞相建工业园、给企业税收优惠和补贴——因为工业税源是地方政府的核心利益。
- 为什么房价越涨地方越有动力——土地财政的基石是住宅用地高价出让。
- 为什么地方债越来越大——城投平台债务本质是土地金融的杠杆化。
- 为什么京东方这样的项目政府敢重仓投入——地方政府的角色不只是"守夜人"，而是"投资人"和"开发商"。

事权划分的三大原则（外部性与规模经济、信息复杂性、激励相容）是理解这个体系的底层逻辑：地方政府为什么有权力也有动力这么做？因为信息优势让它知道本地有什么资源，因为激励机制让它必须对经济增长负责，因为事务的外溢性有限所以它可以自主决定本地资源如何配置。

```
分税制上收财权
       │
       ▼

       │
       ├──────────────────────┐
       ▼                      ▼
  土地财政（卖地）    土地金融（抵押融资）

```

# f(x)：怎样回应这个世界

接受 f 之后，面对中国的经济政策和新闻，观察顺序会改变。

以前看到"地方政府举债搞建设"，第一反应可能是"财政纪律松弛"。现在会先问：这笔债从哪来？抵押物是什么？还本付息靠什么？城投债的偿还来源是不是未来土地增值？这个问题一旦拆开，就知道不能简单用"地方财政失控"概括——它是一套以土地为信用基础的融资体系，有其内在逻辑。

以前看到"某个城市房价暴涨"，可能归咎于炒房客或投机。现在会追问：地价是怎么定的？地方政府在土地供给中扮演了什么角色？住宅用地和工业用地的价格差异反映了什么样的财政激励？这让人意识到房价不只是供需问题，更是地方财政模式的产物。

以前看产业扶持政策，容易陷入"政府扭曲市场"还是"政府弥补市场"的争论。现在会先问：谁是决策主体？它的激励是什么？它的资源从哪里来？京东方合肥案例告诉我们，政府投资不是因为经济学家说应该这样做，而是因为地方政府本身就是投资者，它在用自己的资源和风险承担能力参与产业升级。

最深层的变化：不再把"政府"当成一个外生变量放进模型里，而是去理解它作为一个有自身激励结构的行动者，是如何嵌入经济运行之中的。
