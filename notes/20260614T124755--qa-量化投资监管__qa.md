* 引子

沪指八连阳,但市场里最热闹的新闻不是反弹,而是很多买了私募量化巨亏的人找管理人要说法。春节前两周,大批私募量化产品多米诺式下跌,有的甚至一周跌了20%。监管也随之而来,重点整治高频交易等问题。量化投资到底是什么?为什么它也不是稳赚的?

* Q1: 量化投资和传统投资有什么区别?

  *结论*: 量化依靠数据和模型,传统依靠人的判断,但两者都是投资方式。

  *形式化*: 量化 = 数据模型 + 自动执行; 传统 = 人的判断 + 主观决策

  *怎么想到的*:
  - 传统投资:基金经理和研究员发掘机会,做基本面分析
  - 量化投资:用海量数据寻找规律,输入模型自动决策
  - 两者的区别在于决策方式,不在于投资本质

  *边界*: 很多传统基金也会用量化工具辅助决策,两者的界限越来越模糊。

* Q2: 为什么量化交易被称为"莫得感情的投资机器"?

  *结论*: 因为算法没有情绪,严格执行模型设置的条件。

  *形式化*: 量化 = 无情感 + 严格执行 → 避免人为错误

  *怎么想到的*:
  - 人类投资者容易追涨杀跌
  - 量化可以设置自动交易程序:涨10%卖出,跌10%买入
  - 算法只要触发条件就出手,比人为判断果断百倍

  *边界*: 算法的"纪律性"是优点也是缺点。在市场极端情况下,机械执行可能放大损失。

* Q3: 量化真正的含金量在哪里?

  *结论*: 在于数据挖掘,在过往市场规律中找到可以赚钱的法则。

  *形式化*: 量化价值 = 数据挖掘 + 有效法则 + 自动执行

  *怎么想到的*:
  - 量化团队每天处理海量历史数据
  - 寻找可以预测未来走势的变量
  - 把规律输入模型,利用计算机自动交易

  *边界*: 过去有效的规律,未来不一定有效。市场在不断变化,模型需要持续迭代。

* Q4: 为什么高频交易被称为"全自动韭菜收割机"?

  *结论*: 因为它在极短时间内频繁交易,利用微小价差获利,被认为不公平。

  *形式化*: 高频交易 = 极短期 + 频繁交易 + 微小价差 → 获利

  *怎么想到的*:
  - 基于对未来短期股价走势的判断
  - 低位买入,高位卖出,日内完成
  - 这种策略招致"不公平交易"等质疑

  *边界*: 高频交易也有风险,在市场剧烈波动时可能遭受重大损失。2024年春节前的量化危机就是例证。

* Q5: 量化投资和高频交易是一回事吗?

  *结论*: 不是,高频交易只是量化的一种策略,国内公募量化主要是基本面量化。

  *形式化*: 量化 ⊃ 高频交易; 国内公募量化 ≈ 基本面量化

  *怎么想到的*:
  - 高频量化是一些私募基金采用的策略
  - 国内公募量化大多采用基本面量化策略
  - 基本面量化类似传统价值投资,但用量化手段

  *边界*: 公募和私募的量化策略差异很大,投资者应该区分对待。

* Q6: 什么是"拥挤交易"?

  *结论*: 当多个机构发现相似的规律,同时买入相似资产,导致踩踏和崩盘。

  *形式化*: 拥挤交易 = 多机构 + 相似规律 + 同时买入 → 踩踏崩盘

  *怎么想到的*:
  - 量化机构用机器学习发现小盘股存在超额收益
  - 大家前后脚买入,结果智慧高度雷同
  - 一有风吹草动就出现踩踏

  *边界*: 拥挤交易不仅发生在量化领域,传统基金也会出现抱团现象。但量化机构反应更快,踩踏更剧烈。

* Q7: 量化投资面临哪两个核心挑战?

  *结论*: 一是预测能力的局限性,二是拥挤交易的威胁。

  *形式化*: 量化挑战 = 预测局限 + 拥挤交易

  *怎么想到的*:
  - 预测需要对过去重复,但未来不一定重复
  - 每年都有大量高材生进入量化行业
  - 花哨模型和代码难以拉开差距,信息和认知优势才是关键

  *边界*: 人工智能的发展可能提升量化能力,但不能改变市场本质。只要信息在变化,就无法完全预测市场。

* Q8: 为什么人工智能可能无法改变投资圈?

  *结论*: 因为投资不是一板一眼的棋牌游戏,市场和游戏有本质区别。

  *形式化*: AI > 棋牌; AI < 投资; 原因 = 市场变化 + 信息不对称

  *怎么想到的*:
  - AI已经在棋牌游戏中击败顶级人类玩家
  - 但市场和游戏不同,信息在不断变化
  - 只要知识进步,就无法完全预测市场

  *边界*: AI可以提升量化模型的效率和复杂度,但不能消除投资的不确定性。信息和认知仍然是核心优势。

* 收口

量化投资不是"游戏外挂",它只是另一种投资方式。理解量化的优势和局限,才能理性看待它的表现,无论是巅峰还是低谷。
