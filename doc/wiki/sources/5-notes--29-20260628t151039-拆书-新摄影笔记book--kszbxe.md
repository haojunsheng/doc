# 拆书：《新摄影笔记》

> "一张好照片 = 有感而拍的主题 + 取景曝光虚实构图的系统执行"
>
> 宁思潇潇 · 摄影笔记公众号创始人

## 核心论点

### 一、摄影技术可穷举为四个维度

**取景、曝光、虚实、构图**四个方面构成摄影技术的全景图，再无其他。这是宁思潇潇十年教学反复验证的第一条公理——无论学生犯什么错误，都可以归入这四个抽屉之一。

```
触动 → 主题
  |
  +--> 取景：画面里放什么
  +--> 曝光：画面亮成什么情绪
  +--> 虚实：哪里清楚，哪里模糊
  +--> 构图：元素怎么站位，视线怎么走
  |
  v
表达：让观者也感到那一下触动
```

### 二、五条公理

1. **摄影技术可以被穷举**——取景、曝光、虚实、构图，四个方面就是全部，分清分净，再无其他
2. **器材不是摄影的决定因素**——同样的手机、同样的相机，决定照片好坏的是内容选择，不是像素和镜头价格
3. **散点教学必然失败**——知识若无框架，背下参数仍拍不好
4. **"有感而拍"是摄影的起点**——没有值得记录的主题，一切技术都是空转
5. **先搭框架再填细节**——先理解"好照片由什么构成"，再学"每个参数具体怎么调"

### 三、"主题是目的，四项是手段"

贯穿全书的逻辑线：任何一张照片，判断顺序是**先看主题是否值得拍，再看四项技术是否协同表达了主题**。技术是载体，主题是灵魂。

## 技术展开：四维度全景

### 取景

**焦距体系与题材匹配：**

| 焦距 | 范围 | 典型题材 |
|------|------|---------|
| 超广角 | ≤24mm | 建筑、风光、室内 |
| 标准广角 | 24-28mm | 人文纪实、风光 |
| 人文眼 | 35mm | 街头、人文 |
| 标准镜 | 50mm | 通用 |
| 人像镜 | 85mm | 人像 |
| 长焦 | 200-300mm | 运动、野生动物 |
| 超长焦 | ≥300mm | 专业体育、鸟类 |

**变焦分类：** 超广角变焦 / 标准变焦 / 中长焦变焦 / 超长焦变焦

**取景四要素：** 取景内容（放什么）、取景范围（多大）、取景时机（何时）、取景角度（从哪看）

### 曝光

**影调三分类：** 高调 / 低调 / 中间调，以18%灰为分界

**测光模式二分：** 评价测光 vs 点测光

**曝光补偿 EV 量化：** EV 数值体系，"白加黑减"口诀

### 虚实

**景深四要素：** 光圈 / 焦距 / 拍摄距离 / 前景深后景深关系

**对焦三模式：** MF / AF-S / AF-C

**实操工具：** 超焦距、安全快门、前后帘闪光同步、陷阱对焦

### 构图

**居中法：** 主体大或对称时使用居中构图

**三分法：** 九宫格、视觉中心（4个交点）、**主体朝向空旷面**；本质是不居中

## 核心方法："先看主题后看技术"

评估一张照片的判断流程：
1. 主题是否值得拍？（有无触动）
2. 取景是否做了正确排除？
3. 曝光是否服务了意图？
4. 虚实是否分配了正确的注意力？
5. 构图是否管理了正确的视线流动？

## 关键区分

- **器材 ≠ 摄影**：蜂鸟网二手交易板块里大量"买了几年基本没用过"的帖子，证明器材不是决定性因素
- **三分法 ≠ 放交点**：三分法的底层逻辑是"避开居中"，放交点是工具而非本质
- **18%灰 ≠ 正确曝光**：相机的默认世界观是把一切拉回18%灰，"白加黑减"是反抗这个中庸

## 全书收口

> "摄影就是记录下您到达并发现的、触动您内心的场景及瞬间。"

这句话放在前言最先说，作为整本书的地基。十年后忘了焦距分类、忘了曝光补偿，但记得这句话，就还在摄影的正道上。
