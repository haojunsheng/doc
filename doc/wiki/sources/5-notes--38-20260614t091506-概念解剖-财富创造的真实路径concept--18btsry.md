# 财富创造的真实路径

> 来源：晨星文章《普通人能靠炒股发家致富吗？》
> 日期：2026-06-14

## 核心论断

对普通人而言，**炒股致富是低概率事件**，更现实的路径有三条：**创业、持有企业股权、长期投资指数基金**。每条路径都有风险-收益-门槛的 trade-off。

本质观点：追求"财富最大化"不如追求"生活富足"——**"富"的定义权在自己手中**。

## 关键数据

### 高净值标准（多方口径）

| 机构 | 标准 | 类型 |
|------|------|------|
| 普华永道 | 净资产 > 100万美元（约700万人民币） | 高净值 |
| 中国私人银行 | 可投资资产 > 1000万人民币 | 高净值；> 1亿 = 超高净值 |
| 胡润研究院 | 资产 > 600万 = 富裕家庭；> 1000万 = 高净值家庭 | 家庭层面 |

### A股收益数据

- 过去20年年化约 **9%**——这是**贝塔收益**，不是 alpha
- 每年投5万，年化9%，20年后≈256万——**不够"富"**
- 每年投5万，年化20%（顶级水平），20年后≈687万——**接近高净值，但保持20%是神话**

### 房地产数据

- 百城住宅租金回报率：2.2-2.3%
- 一线城市租金回报率：1.5-2%
- 2016年：15%高净值人群靠房地产达到标准
- 2024年：降至 **5%**——**房产造富时代已终结**
- 中国居民负债较20年前增长40%+

## 三条真实财富路径

### 1. 创业
- 高上限，极高失败率
- 需要资本、人脉、运气——非人人可得
- 幸存者偏差让成功者看起来更容易

### 2. 持有企业股权
- 需要早期识别能力
- 流动性差
- 早期介入才能获得超额收益

### 3. 长期指数基金
- 门槛低，流动性好
- 依赖时间和纪律
- 晨星作为销售平台，天然倾向推广此路径

## 四步财富规划流程

1. **设定目标**：需要多少钱？多少钱够我想要的生活？
2. **测算收益率**：需要多少年达成？年化回报多少？
3. **资产配置**：股票/债券比例如何分配？
4. **筛选标的**：买什么基金/股票？

## 核心方法论：以目标为导向的投资（Goal-Based Investing）

不追求"赚最多"，而追求"够用就好"——用目标倒推所需收益率和持有期。

核心转换：不是"买什么最好"，而是"买什么能帮我实现目标"。

## 批判性反思（元反思）

1. **作者立场**：晨星作为基金销售平台，天然倾向推广"指数基金+长期持有"
2. **"普通人"定义模糊**：每年能攒5万已是中高收入群体
3. **创业门槛被低估**：文章说"创业是最现实路径"，但同时承认需要资本/人脉/运气
4. **"以目标为导向"的局限**：目标本身不切实际时，再好的流程也无法阻止失败
