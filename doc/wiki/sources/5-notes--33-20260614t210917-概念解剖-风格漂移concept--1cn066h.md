# 概念解剖 — 风格漂移

来源：`notes/20260614T210917--概念解剖-风格漂移__concept.md`

## 核心论点

当基金经理偏离其宣称的投资风格时，就产生了"风格漂移"——投资者买的是"盲盒"，承担了不可预期的风险。**风格稳定的价值不在于"收益最大化"，而在于"预期可管理"**。

## 八刀分析框架摘要

| 刀 | 要点 |
|----|------|
| 定锚 | 风格漂移 = 基金经理偏离宣称投资风格；投资者买的是"盲盒" |
| 历史 | 晨星投资风格箱（Style Box）自 1992 年推出，大/中/小盘 × 价值/平衡/成长九宫格；晨星研究发现风格切换错误率高的基金长期收益率远落后于风格稳定的基金 |
| 辩证 | 正题：基金经理应坚守风格；反题：坚守一种风格可能错失机会；合题：风格稳定不是"永远正确"，而是"让投资者知道自己买的是什么" |
| 现象 | "新金融股票基金"重仓新能源，"养老产业股票基金"投资 TMT；晨星风格箱反映"当前"，基金分类反映"过去三年平均"，两者不一致即漂移信号 |
| 语言 | "漂移"（drift）是物理学隐喻——缓慢、不易察觉的偏离；"盲盒"是现代消费隐喻——无法预知内容 |
| 形式 | 定义 → 分析原因 → 论证重要性 → 预告后续（识别方法 + 应对策略） |
| 存在 | 触及深层焦虑："我买的到底是什么？"风格漂移让投资者失去对投资组合的控制感，指向投资中的信任危机 |
| 美感 | 诊断学之美：用简洁的九宫格几何结构，将抽象的投资风格变化可视化 |
| 元反思 | 有些基金经理（如彼得·林奇）在不同风格间灵活切换并取得超额收益，漂移与进化的边界在哪？指数基金因成分股调整发生"被动漂移"是否同样有害？ |

## 关键洞见

**风格稳定 vs 风格正确**：即使风格切换错误率很高，风格稳定仍然优于风格漂移——因为它让投资者能做出知情决策，实现预期可管理。这是本文的核心规范性论点。

## 行动准则

- 通过晨星风格箱（当前持仓）与晨星基金分类（过去三年平均）的对比识别漂移信号
- 警惕"盲盒效应"：不要买一个不知道里面是什么的东西
- 风格稳定是组合有效配置的前提：若风格漂移，分散化大打折扣
