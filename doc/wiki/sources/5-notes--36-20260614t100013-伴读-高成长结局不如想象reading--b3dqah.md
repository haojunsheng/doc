# 伴读：为什么大多"高成长"的结局不如想象中美好？

> 晨星中国 · 2025-08-15

## 一句话摘要

高成长赛道之所以让大多数投资者失望，不是因为"增长"本身有问题，而是因为**资本追逐成长→竞争加剧→供过于求→估值崩塌**的循环几乎不可避免——投资成功的关键不是选增长最快的，而是选**有"经济护城河"保护利润的**。

## 核心论点

### 高成长的投资悖论

投资者瞄准"高景气度、长坡厚雪"赛道，但结果往往不尽如人意。问题本质：**行业增长 ≠ 投资者赚钱**。行业在增长，但如果竞争太激烈、利润被侵蚀，投资者可能还是赚不到钱。

### 经济护城河——比增长更重要的东西

资本主义的本质是促进竞争，行业增长越快，竞争往往越激烈。晨星用"经济护城河"来衡量企业可持续竞争优势，主要来自五个方面：

1. **转换成本**：客户更换产品的成本高 → 维持现有选择
2. **无形资产**：专利、品牌、政府许可 → 抵御对手冲击
3. **网络效应**：用户越多价值越大 → 赢者通吃
4. **成本优势**：低成本生产 → 抢占市场/提升利润率
5. **有效规模**：规模有限的市场被少数企业高效占领 → 新进入者难以立足

**关键洞见**：护城河保护的是"利润"，不是"收入"。一家公司可以有很高的收入增长，但如果它的利润被竞争侵蚀了，股东并没有从中受益。

### 失控的增长（Out of Control Growth）

资本追逐成长的因果链：

- 高成长领域 → 企业举债扩张 + 风投/PE争相注入资本
- 为维持高增长 → 降价抢市场、砸钱做营销、扩招员工
- 供过于求成为不可避免的结果
- 员工要饭碗、投资者要短期回报、媒体要热点 → 增长不能停
- 泡沫终究会破

### 光伏案例

晨星全球光伏行业研究显示：
- 2020年到2023年，光伏供应链产能增长了 **3.4到4.1倍**
- 同期全球年度光伏装机量增幅仅 **2.6倍**
- 2022年Q4光伏产品价格开始大幅下跌，2024年跌到历史低点
- 晨星预计2025年全球装机量将进入停滞期

### 警惕"失控的增长"

最核心的教训：当增长基于**"简单且人人认可的事实"+"对社会有益"**的共识期待时，要加倍警惕。

- "绿色发展是趋势"、"AI会改变世界"——这些判断本身没错，但增长从来不是线性的
- 动听的故事不代表长期挣钱
- 看看过去几年新发行的主题ETF，就是最好的警示

## 行动建议

1. 用"经济护城河"框架分析持仓中的成长股，判断它们的竞争优势来源
2. 研究光伏行业的最新数据，验证晨星预测
3. 在阅读年报时，关注竞争格局而非增长速度
