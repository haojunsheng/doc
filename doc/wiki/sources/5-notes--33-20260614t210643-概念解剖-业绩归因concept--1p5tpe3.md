# 概念解剖 — 业绩归因

> 来源：晨星文章《复杂市场环境下，投资者该如何理解基金业绩？》

## 概念定义

**业绩归因（Performance Attribution）**是将基金的总回报拆解为不同来源——资产配置、行业配置、个股选择、市场风格、择时贡献——的过程。回答的核心问题是：**这个基金的收益到底是怎么赚出来的？**

## 核心主张

### 1. 业绩归因的本质：把"结果"还原为"原因链条"

词素拆解：
- **业（绩）** = 最终结果，可观测的数字
- **归** = 返回归属
- **因** = 导致缘由

整体含义：**把"结果"还原为"原因链条"**。

### 2. 归因是后视镜，不是挡风玻璃

历史归因无法预测未来可持续性。举例：景顺长城鼎益在 2021 年前表现优异，之后因价值风格逆风大幅落后——这并非基金经理能力消失，而是收益来源本身不可持续。

### 3. 归因方法本身的失效场景

- **市场风格剧烈切换** → 配置效应可能被误读为选择效应
- **基金经理频繁调仓** → 静态归因窗口严重失真
- 有些收益来自随机或无法量化的因素（如基金经理直觉、运气），不能被归因完全覆盖

### 4. 归因 = 考古（而非解剖）

传统隐喻"归因 = 解剖"预设过去可以完全被拆解和解释。更新后的隐喻"归因 = 考古"保留了谦逊：我们能逼近真相，但永远不能穷尽它。

## 形式化核心

### Brinson 模型简化式

```
总超额收益 = 资产配置效应 + 选择效应 + 交互效应

Rp - Rb = Σ(wp,i - wb,i)·Rb,i  +  Σwb,i·(Rp,i - Rb,i)  +  Σ(wp,i - wb,i)·(Rp,i - Rb,i)
```

其中：
- `Rp` = 组合收益率
- `Rb` = 基准收益率
- `wp,i` / `wb,i` = 组合/基准在第 i 类资产上的权重
- `Rp,i` / `Rb,i` = 组合/基准在第 i 类资产上的收益率

### 美感意象：三棱镜

白光进入，七色光谱出来。一个冰冷的收益率数字被拆成一条条清晰可辨的因果链。

## 哲学反思：可解释性执念

业绩归因暴露了一个深层结构性张力：**人类对"可解释性"的执念**与**"不可解释之物"的永恒共存**。

归因最怕的用法：被人当神谕使用。投资者在业绩最差、最急需解释的时刻，往往最依赖归因——但那时他们最需要的不只是解释，而是承认"有些事无法解释"。
