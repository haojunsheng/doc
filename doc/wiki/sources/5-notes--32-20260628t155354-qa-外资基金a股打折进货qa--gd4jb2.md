# QA — 外资基金A股打折进货

> 681只规模超10亿美元、A股配比超10%的外资基金，合计约9000亿人民币。2022-2023年中仓位下行后，2023年中以来开始逆势加仓。规模变化与美联储利率高度负相关，加息结束意味着资金流向将逆转。

## Q1：外资A股仓位2018年以来经历了哪四个阶段？

**结论**：2018下行 → 2019-2021上升 → 2022-2023中下行 → 2023中以来上升，当前处于第四阶段。

**形式化**：
```
外资仓位 = 2018↓ → 2019-21↑ → 2022-23中↓ → 2023中↑
```

**关键观察**：总体仓位相对稳定，没有大起大落。

**边界条件**：若中美关系急剧恶化或A股出现系统性风险，外资可能快速撤离。

## Q2：外资基金规模为何呈倒V字形？

**结论**：规模变化主要受美联储利率驱动，而非A股表现——降息扩规模，加息缩规模。

**形式化**：
```
基金规模 ↑↓ = f(美联储利率 ↓↑)
```

**数据支撑**：
- 2018-2021年规模翻倍
- 2021年后缩水约45%
- 2019降息 + 2020快速降息推高规模
- 2022加息后2年期美债从0飙升至5%+，规模快速下降

**边界条件**：若A股独立行情强劲到足以抵消加息压力，外资可能逆势加仓。

## Q3：美联储利率如何影响外资对A股配置？

**结论**：美国利率高 → 资金追逐美债无风险收益 → 新兴市场失血；利率低 → 资金外溢 → 新兴市场受益。

**形式化**：
```
美债利率↑(5%+) → 资金回流美国 → 新兴市场基金↓ → A股配置↓
```

**机制说明**：2年期美债从0升至5%以上，资金从新兴市场撤出追逐无风险收益，基金规模变化与美联储利率高度负相关。

**边界条件**：若A股自身回报远高于美债利差，外资可能不理会利率继续配置。

## Q4：外资仓位稳定说明什么？

**结论**：外资对A股没有极度乐观也没有极度悲观，是长期结构性配置而非短期博弈。

**形式化**：
```
外资仓位稳定(无大起大落) → 长期配置而非短期交易
```

**证据**：
- 681只基金合计9000亿规模
- 注册地集中在卢森堡、美国、爱尔兰
- 仓位未出现大起大落

**边界条件**：若A股纳入MSCI权重进一步提升，外资仓位可能系统性上升。

## Q5：加息结束后外资会大规模回流A股吗？

**结论**：方向确定但节奏不确定——还取决于A股自身表现和中美关系。

**形式化**：
```
加息结束 → 资金外溢方向确定 → 节奏 = f(A股表现 + 中美关系)
```

**判断依据**：市场倾向加息已结束，通胀降温强化降息预期，过去两年资金流向可能逆转。

**边界条件**：
- 若美国经济硬着陆导致全球衰退，外资可能同时撤离所有风险资产
- 若中美关系急剧恶化或A股系统性风险，外资可能快速撤离

## 收口

外资对A股的态度是"**结构性配置 + 利率驱动**"——2023年中开始的逆势加仓说明聪明钱在抄底，但真正的趋势性流入要等美联储降息确认。
