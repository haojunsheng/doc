# QA — 凯利公式仓位管理

> 晨星中国，2026-06-28

## 核心主题

凯利公式从数学上解决"在胜率不足100%的条件下，如何确定最优仓位以实现长期复利最大化，同时永不归零"的问题。其真正价值不在于公式本身，而在于推导出的三条方向性投资原则。

## 形式化表达

```
f = (p × b - q) / b

f = 最优仓位比例
p = 胜率
b = 净赔率
q = 败率 = 1 - p
```

## 关键结论摘要

### Q1：凯利公式解决什么问题？

在"永远不输完"的前提下，让长期复利增长最大化。它算的是**仓位**，不是方向。

**边界**：资本市场中胜率与赔率难以精确计算——输入垃圾，输出垃圾。公式的价值在于方向性指导，而非直接计算。

### Q2：为什么拉长持有期能提高胜率？

历史数据（沪深300，2006-2025）：
- 持有1个月：正收益概率 ≈ 55%
- 持有10年：正收益概率 ≈ 95%

**逻辑**：时间越长，市场正收益概率越高，且收益离散程度降低（极端亏损减少）。

**边界**：前提是市场长期向上。日本"失落的三十年"即反例。

### Q3：为什么孤注一掷在数学上是错的？

凯利公式的核心推论：**高赔率（高波动）投资的最优仓位反而更低**。

```
高收益 = 高波动
高波动 + 高仓位 = 一次大亏抹掉累积收益
凯利公式：赔率↑ → 最优仓位↓
```

只要胜率 < 100%，全仓（f = 100%）就是数学错误。牛市中主题投资、杠杆操作下行风险最致命。

### Q4：麦道夫骗局的凯利视角

爱德华·索普当年评估麦道夫基金时发现的危险信号：**收益高且波动极低**——表现"稳定得反常"。17年后证实为庞氏骗局。

**原理**：真实有效策略应有与收益匹配的波动。高收益 + 零波动 = 骗局或未暴露风险。

**边界**：套利策略确实可低波动，但规模有限，不对个人大额资金开放。

### Q5：凯利三原则（无需计算即可应用）

1. **提高胜率 → 拉长持有期**
2. **体系 > 运气 → 纪律执行**
3. **拒绝孤注一掷 → 仓位 < 100%**

### Q6：为什么体系化策略比运气更重要？

香农和索普在赌场成功靠的是两年理论准备 + 严格执行，而非某次幸运判断。索普后来将这套理念带入华尔街，开创量化投资。

**长期结果 = 体系 × 时间**
