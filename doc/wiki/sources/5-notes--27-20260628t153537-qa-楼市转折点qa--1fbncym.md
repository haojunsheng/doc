# 楼市转折点——2027年中国楼市或迎转折点

> 原文：《新信号出现！2027年中国楼市或迎转折点》（晨星中国，2026年6月）

## 核心论点

房地产经历四年深度调整后，晨星判断**2027年新房价格有望企稳回升**——但与2016年那轮反转**截然不同**：这是**供给收缩推动的出清收尾**，而非需求驱动的大牛市。理解这次"底"长什么样，是投资地产股的前提。

## 五问五答摘要

### Q1：为什么说库存已经见顶了？

**结论**：2025年Q4库存增幅从19%收窄到5%，竣工量超过新开工量，供给端主动收缩已见成效。

**形式化逻辑链**：

```
库存增幅 19% → 5%
+ 新开工↓25% > 竣工↓23%
→ 竣工 > 新开工
→ 未来供给自然减少
→ 库存见顶
```

**关键证据**：
- 2025年Q4住宅库存同比仅升5%，远低于2024年同期19%
- 新开工降25%、竣工降23%，房企主动收缩开工竣工节奏
- 竣工量超过新开工量意味着未来新增供给将自然减少

**边界条件**：若销售进一步大幅下滑（同比跌幅超30%），库存可能重新累积。

### Q2：购房压力为什么有所缓解？

**结论**：全国平均房价与年化可支配收入比从11降到9.6，买房门槛确实在降低。

**形式化逻辑链**：

```
房价收入比 11 → 9.6
⊃ 购房压力↓
⊃ 负担能力修复中
```

**关键证据**：
- 晨星测算2025年Q4房价收入比为9.6，明显低于上年同期的11
- 房贷利率与5年期LPR保持一致，融资成本未增加
- 2026年货币政策仍有放松空间，利率可能继续下行

**边界条件**：若收入预期持续恶化或失业率上升，房价收入比下降也不足以刺激购房。

### Q3：为什么2027年才可能企稳而不是更晚？

**结论**：供给收缩+库存去化推进，预计2030年库存销售比从3.3降到2.6，2027年是均价筑底窗口。

**形式化逻辑链**：

```
库存销售比 3.3 → 2.6（2030年）
+ 2026-2030年新房销量 > 新开工量 40%-70%
→ 2027年均价企稳
```

**关键证据**：
- 2026-2030年新房销量预计高出新开工量40%-70%
- 库存销售比持续下降对房价形成支撑
- 政策去库存+供给收缩双管齐下，2027是供需再平衡的交叉点

**边界条件**：若去库存政策执行不力或房企资金链断裂导致抛售，企稳时间可能延后。

### Q4：为什么二手房比新房更难复苏？

**结论**：新房品质提升缩小与二手房差距+增值税下调增加二手供给，二手价格修复可能等到2028年后。

**形式化逻辑链**：

```
新房品质↑ → 新房↔二手差距↓
+ 增值税↓ → 二手供给↑
→ 二手价格修复延后至2028年+
```

**关键证据**：
- 核心地段土地供应增加，新房品质提升
- 2025年增值税下调阶段性增加二手市场供给
- 北京、广州等在高基数背景下回调更明显

**边界条件**：若核心区新房供应减少或二手交易税费进一步下调，二手价格可能提前企稳。

### Q5：为什么区域分化会持续？

**结论**：东部及南部核心城市去化效率高，北方多数城市库存压力更大，城市分化不可逆。

**形式化逻辑链**：

```
上海/杭州/成都 → 去化效率高
北方多数城市 → 库存压力大
→ 分化持续
```

**关键证据**：
- 晨星明确指出东部南部经济发达城市去化效率更高
- 北京被点名库存压力相对较大
- 人口流动和产业分布不均衡是根本原因

**边界条件**：若北方城市出台更强力的产业和人口政策，分化可能收窄但不会消失。

## 核心贡献：断代判断

作者的核心贡献是用供需数据证明：**楼市"转折点"的本质是供给收缩推动的出清收尾，而非新一轮上涨周期的开始**。这与2016年政策刺激后暴涨的经验框架有本质区别。时间线为：

| 时间节点 | 事件 |
|---------|------|
| 2025年Q4 | 库存增幅大幅收窄，竣工超过新开工 |
| 2027年 | 新房均价筑底企稳 |
| 2028年+ | 二手房价格才可能实质性修复 |
