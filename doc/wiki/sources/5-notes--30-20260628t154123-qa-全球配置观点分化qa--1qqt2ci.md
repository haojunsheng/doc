# 全球配置观点分化——晨星2026Q2宏观视角

## 概述

晨星多资产团队2026Q2季度配置观点，核心问题是：**当利率预期从降息切到加息，哪些资产能撑住、哪些会分化？** 全文以"风险溢价是否已被收益率充分定价"为判断标准，给出四档配置观点：A股有韧性、英债中短端上调为"有吸引力"、日债下调至"中性"、信用债仍消化冲击中。

## Q1：为什么美股跑输全球，A股反而有韧性？

**结论**：美股（尤其成长股）对利率最敏感，油价推升利率预期后首当其先；A股已提前调整且估值偏低，跌幅有限。

```
利率预期↑ → 美股估值↓↓（成长股重）
A股已调整 + 估值低 → 跌幅有限 = 相对韧性
```

**驱动逻辑**：
- 美股一季度创2022年来最大季度跌幅，大幅跑输全球
- A股展现出相对韧性——中概股偏弱但不代表A股本身
- 成长型板块撤出 + 商品防御资产增配 = 风格轮动利好已调整的市场

**边界条件**：如果油价继续推高利率且A股估值不再便宜，A股的"韧性"会消失——相对优势是暂时的。

## Q2：英国国债为什么从"中性"上调为"有吸引力"？

**结论**：中东紧张让英债收益率曲线剧烈波动，中短端品种已具备性价比——不确定性溢价被定价进去了。

```
中东紧张 → 英债收益率曲线波动↑ → 中短端品种性价比↑ → 配置观点上调
```

**驱动逻辑**：
- 英国央行政策预期大幅修正，短端反应尤其敏感
- 中短端收益率上行幅度足够大，覆盖了风险溢价
- 长债虽有财政赤字和供给压力，但随不确定性缓和，溢价有望回落

**边界条件**：如果英国通胀数据持续超预期或财政恶化，中短端的"性价比"会被侵蚀——不是无风险机会。

## Q3：日本国债为什么从"有吸引力"下调到"中性"？

**结论**：油价上涨加剧日本输入性通胀，财政扩张预期加重债务负担，央行短期偏紧——三重压力让日债不再便宜。

```
油价↑ + 财政扩张 + 输入性通胀 → 10Y日债收益率数十年高位 + 央行偏紧 → 配置观点下调
```

**驱动逻辑**：
- 日本是能源进口国，油价上涨直接推升其通胀
- 大规模财政刺激加剧债务负担，信用风险溢价上升
- 央行短期维持偏紧政策立场，降息无望
- 10年期国债收益率升至数十年高位，但收益率上升的幅度还不足以补偿风险

**边界条件**：如果油价回落或日本央行意外转向宽松，日债的配置价值会重新上升。

## Q4：为什么信用债在Q1遭遇大幅回调？

**结论**：2025年信用债靠利差收窄赚钱，Q1地缘冲击改变了"叙事"——市场从追逐收益转向规避风险。

```
2025年：利差收窄 → 信用债正回报
2026Q1：地缘冲击 → 叙事切换 → 信用债大幅回调
```

**驱动逻辑**：
- 信用债本质是"承担信用风险换取收益"，当不确定性上升时，风险溢价要求提高
- 油价上涨推升利率预期，信用债同时承受利率风险和信用风险
- "叙事"切换意味着市场定价逻辑发生了变化，不只是基本面

**边界条件**：信用债回调幅度取决于油价冲击持续时间——如果快速逆转，信用利差会重新收窄。

## Q5：晨星这份报告的核心配置逻辑是什么？

**结论**：利率上行期，向"收益率已反映不确定性"的品种倾斜，同时回避"还在消化冲击"的市场。

```
利率上行期 → 选：收益率已反映风险（英债中短端）
避：还在消化冲击（日债、美股成长、信用债）
```

**统摄框架**：

| 资产类别 | 配置观点 | 核心逻辑 |
|---------|---------|---------|
| 英债中短端 | ↑ 有吸引力 | 不确定性溢价已被定价 |
| 日债 | ↓ 中性 | 三重压力未充分补偿 |
| 美股成长 | 回避 | 对利率最敏感 |
| A股 | 相对韧性 | 已调整+估值低 |
| 信用债 | 回避 | 叙事切换中，仍在消化冲击 |

**边界条件**：整套逻辑建立在"油价冲击短暂"的假设上——如果油价持续高位，所有利率敏感资产都会承压，英债也不能幸免。

## 收口

晨星这份配置观点的核心动作是**"根据利率预期重新定价风险溢价"**——英债中短端是目前最被市场过度惩罚的品种，而日债和信用债还在消化冲击中。
