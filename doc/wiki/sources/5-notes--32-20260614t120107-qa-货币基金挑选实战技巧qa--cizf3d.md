# QA — 货币基金挑选实战技巧

> 来源：Morningstar 晨星，春节闲钱理财攻略系列

## 核心论点

货币基金是少数可以「看历史业绩」来选基金的品类，但仍需结合规模、机构占比、收益指标稳定性综合判断。

## Q1：货币基金的历史业绩能用来选基金吗？

**结论**：能——与股票基金不同，货币基金的业绩有持续性，前一年排名靠前的下一年大概率继续靠前。

**形式化**：
```
货币基金：前 25% → 下年仍前 25% 概率 ≈ 20%
股票基金：同样操作概率 < 10%
连续五年维持前 1/4 的货币基金概率 ≈ 30%
```

**数据来源**：晨星统计了过去十年各类基金「买前一年排名前 1/4 的产品，下一年继续前 1/4 的概率」。股票、混合、债券基金几乎没有能连续五年维持前 1/4 的，而货币基金有此特征。

**边界**：这是统计规律，不代表具体某只基金一定延续。且货币基金收益率差距本身就很小。

## Q2：为什么货币基金的业绩比股票基金更有持续性？

**结论**：因为货币基金主要靠吃利息，收益可预期且稳定，基金经理发挥空间小。

**形式化**：
```
货币基金收益 = 利息为主 + 杠杆/久期受限 → 收益差距小 → 业绩持续
```

**机制拆解**：
1. 货币基金最主要的收益来源是持有到期吃利息，每日收益可预期且相对固定
2. 监管对货币基金投资操作（杠杆、久期）有严格限制，投资范围狭窄
3. 基金经理能玩的花样少，投资组合差异不大
4. 晨星因此不对货币基金评级——收益率差异太小，评价意义不大

**边界**：若市场利率环境发生剧变（如快速加息），货币基金收益也会受影响，但相对排名可能仍然稳定。

## Q3：七日年化收益率和万份收益看哪个？

**结论**：一般看七日年化收益率，但要小心「短期虚高」——可能是集中卖出高收益资产造成的假象。

**指标对比**：

| 指标 | 定义 | 特点 | 适用场景 |
|---|---|---|---|
| 七日年化收益率 | 按过去 7 天收益估算的年度水平 | 更稳定，适合横向对比 | 长期持有评估 |
| 万份收益 | 当天 1 万元可获的每日收益 | 波动大，反映当日真实收益 | 短期收益关注 |

**短期收益尖峰陷阱**：有些基金短期七日收益率「鹤立鸡群」，可能是集中卖出高收益资产变现所致，不可持续。见 [[concepts/短期收益尖峰陷阱]]。

**边界**：若只关心短期收益（如春节几天），万份收益可能更直观；但长期持有还是看七日年化的稳定性。

## Q4：货币基金规模越大越好吗？

**结论**：不是——规模过大会拉低收益，因为基金经理必须采取更保守的策略。

**形式化**：
```
规模 ↑ → 话语权 ↑ 但 → 流动性要求 ↑ → 策略保守 → 收益 ↓
```

**逻辑拆解**：
1. 理论上规模越大越有优势：投资债券、票据时话语权强，能争取更高利率
2. 但规模过大也有问题：基金经理为确保资金安全和流动性，必须采取更保守策略
3. 典型案例：天弘余额宝规模太大，整体收益率不太具备吸引力

**边界**：若市场利率高、流动性充裕，规模对收益的影响可能较小；但在钱紧的时候，规模劣势会更明显。见 [[concepts/规模困境]]。

## Q5：为什么要避开机构占比高的货币基金？

**结论**：因为机构大额赎回会导致基金被迫贱卖资产，损害散户持有人的收益和流动性。

**形式化**：
```
机构占比高 → 大额赎回风险 → 被迫卖资产 → 收益损失 + 流动性风险
```

**机制拆解**：
1. 机构持有比例高，意味着基金可能面临突然的大额赎回
2. 如果机构集中赎回，基金没有足够现金，就得不计市价卖出底层资产
3. 多家机构同时赎回还可能引发流动性风险
4. 应尽量选择散户持有人多的产品

**边界**：若机构是长期持有的（如企业短期闲置资金），赎回风险可能较低。但散户占比高仍然更稳定。见 [[concepts/机构持有人风险]]。

## 收口

货币基金不是「随便买就行」——看业绩持续性、看七日年化稳定性、选规模适中、避开机构扎堆。但也没必要为 0.5% 的差距过度纠结，毕竟货币基金的核心是低风险和高流动性，不是高收益。
