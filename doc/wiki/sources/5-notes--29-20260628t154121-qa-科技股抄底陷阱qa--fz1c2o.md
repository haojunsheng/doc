# QA — 科技股抄底陷阱

来源：[[晨星中国]] · [Morningstar.cn](https://www.morningstar.cn/articles/2624ea28435303e0ecf47623d7b578a3.html) · 2026-06-28

## 核心结论

美股 Q1 下跌主因是大型科技股自身估值泡沫破裂后的自我修正，而非关税冲击。AI 概念股在 DeepSeek 出现前就已经见顶。当前环境中价值股优于成长股，应转向有护城河的价值股而非抄底高估值成长股。

## Q&A 摘要

| 问题 | 结论 |
|------|------|
| 科技股下跌真因是关税吗？ | 不是，10只权重股的负回报超过指数整体跌幅，说明是内部估值泡沫破裂 |
| DeepSeek 是 AI 股转折点吗？ | 不是，多数 AI 概念股估值在其出现前已见顶，DeepSeek 只是加速器 |
| 价值股为何逆势上涨？ | 估值低位 + 基本面改善，成长股估值溢价从 24% 收缩至 3% |
| 小盘股现在能买吗？ | 不能，宽松周期、利率下行、经济复苏三条件尚未共振 |
| 宽护城河企业值得买吗？ | 是，大部分估值已降至区间底部，经济放缓期更具稳定性 |
| 公用事业板块需要警惕吗？ | 是，当前唯一估值泡沫加剧的板块，AI 电力需求预期已被过度定价 |

## 关键数据点

- 成长股估值溢价：年初 24% → Q1 末 3%
- 价值股 Q1 涨幅：+4.59%
- 10 只权重股负回报 > 指数整体跌幅（科技股权重集中）
- 美联储预计今年降息三次，但长期利率下半年才下行
- 美国经济增长率逐季放缓
