# QA — 大宗商品配置价值

## 来源信息

- **原始链接**：https://www.morningstar.cn/articles/84860d7e1062900aa2798b36131f2457.html
- **来源方**：晨星（Morningstar）

## 核心命题

商品的配置价值远超其投资价值，它在组合中扮演的是"保险"角色而非赚钱工具。

## Q&A 摘要

### Q1：期货投资最大的隐性成本是什么？

**结论**：负展期收益——当新合约价格高于旧合约时，每次展期都在无声地侵蚀回报。

**形式化表达**：新合约价 > 旧合约价 → 展期收益为负 → 跑输现货涨幅

**边界条件**：在 backwardation（现货溢价）市场，展期收益为正，此结论反转。

### Q2：为什么普通投资者不适合直接炒商品期货？

**结论**：因为期货有负展期收益、高杠杆、操纵风险三重门槛，历史上因炒期货巨亏的案例屡见不鲜。

**形式化表达**：期货 = 负展期 + 高杠杆 + 操纵风险 → 技术活

**案例**：亨特兄弟白银操纵事件、住友商社铜期货巨额亏损事件、安然扰乱加州能源供应事件、伦敦金属交易所（LME）镍危机。

**边界条件**：专业机构投资者有风控能力和信息优势，不受此限。

### Q3：为什么上游企业股票比期货更适合间接投资商品？

**结论**：上游企业从事开采环节，对商品价格变动最敏感；下游企业是价格被动接受者。

**形式化表达**：上游：价格敏感 → 受益于涨价 | 下游：价格接受 → 不受益

**边界条件**：上游企业有经营风险（矿难、环保事故），不等于纯商品暴露。晨星全球上游自然资源指数作为筛选参照。

### Q4：商品在组合中的核心价值是什么？

**结论**：在股债双杀的市场环境中提供保护，因商品价格与通胀正相关，而股债在通胀上升时往往下跌。

**形式化表达**：通胀↑ → 股↓ + 债↓ + 商品↑ → 商品对冲价值显现

**实证**：2022年美联储加息周期，股债双跌超17%，同期商品涨幅超15%。

**边界条件**：通缩环境中商品价格亦下跌，对冲失效。

### Q5：为什么说商品是"保险"而非"投资"？

**结论**：商品不产生现金流、走势难以预测、需要长期持有——这些特征与保险相似：付出成本换取极端情况下的保护。

**形式化表达**：商品 = 无现金流 + 难预测 + 长期持有 → 保险属性

**边界条件**：具备极强择时能力和风险承受力的投资者，可将商品作为交易工具。

# 负展期收益

## 定义

**负展期收益**（Negative Roll Yield）是期货投资中最容易被普通投资者忽视的隐性成本。当期货市场的期限结构呈现 contango（近月价格 < 远月价格）时，每次将到期合约展期至下一合约，都需要以更高的价格卖出旧合约、买入新合约，从而在不知不觉中侵蚀投资收益。

## 形式化表达

```
新合约价 > 旧合约价 → 展期收益为负 → 期货回报 < 现货涨幅
```

## 机制解释

期货合约具有到期日，持仓者必须在到期前平仓并建立新合约仓位，这一过程称为"展期"（Roll）。

- **理想情况**：新合约价格低于旧合约（backwardation），展期获得正收益。
- **常见情况**：新合约价格高于旧合约（contango），展期产生负收益。
- **结果**：即使商品现货价格上涨，期货投资者的实际回报也可能因持续的负展期收益而低于现货涨幅，甚至出现亏损。

## 边界条件

| 市场状态 | 展期收益方向 | 说明 |
|---------|------------|------|
| Contango（远期溢价） | 负 | 新合约更贵，每次展期侵蚀回报 |
| Backwardation（现货溢价） | 正 | 新合约更便宜，展期带来额外收益 |

在供应短缺的 backwardation 市场中，负展期收益可能逆转为正展期收益，此时该结论反转。

## 实践含义

1. **期货投资的技术门槛**：负展期收益是期货交易员的日常工作之一，普通投资者缺乏持续监控和优化的能力。
2. **替代方案**：通过持有上游企业股票间接暴露于商品价格变动，规避展期机制带来的隐性成本（参见 [[上游企业股票替代商品期货]]）。
3. **方法学呼应**：[[现货加密货币ETF vs 期货加密货币ETF]] 一文中同样涉及期货 vs 现货的对比逻辑，两类资产的展期机制分析方法论上相通。

# backwardation 与 contango

## 定义

**backwardation（现货溢价）** 和 **contango（远期溢价）** 是描述期货期限结构（Futures Term Structure）的两种基本状态，直接影响展期收益的方向和大小。

## 两种状态

### Contango（远期溢价）

- **定义**：近月合约价格 < 远月合约价格
- **期限结构形态**：向上倾斜
- **展期收益**：负（卖低买高）
- **典型场景**：持有成本低、供应充裕、市场预期未来涨价

### Backwardation（现货溢价）

- **定义**：近月合约价格 > 远月合约价格
- **期限结构形态**：向下倾斜
- **展期收益**：正（卖高买低）
- **典型场景**：供应短缺、现货紧缺、突发需求激增

## 对投资决策的影响

| 维度 | Contango 环境下 | Backwardation 环境下 |
|------|----------------|---------------------|
| 期货 vs 现货回报 | 期货明显跑输现货 | 期货可能跑赢现货 |
| 普通投资者参与风险 | 高（持续负展期侵蚀） | 相对较低 |
| 配置建议 | 避免直接持有商品期货 | 可考虑期货，但仍需警惕其他风险 |

## 与商品配置价值的关系

[[负展期收益]] 概念的核心边界条件即由这两种期限结构状态决定。在常规 contango 环境下，商品期货的天然劣势使其不适合作为普通投资者的主要配置工具；而在 backwardation 环境下，负展期收益可能转为正，此时"保险"定位需要重新评估（参见 [[商品组合保险定位]]）。

# 商品组合保险定位

## 核心命题

商品在投资组合中的核心价值不是"赚钱"，而是"保险"——在股债双杀的特殊市场环境中提供对冲保护。这一认知重构是理解商品配置价值的关键。

## 形式化表达

```
商品 = 无现金流 + 难预测 + 长期持有 → 保险属性
```

## 为什么是"保险"而非"投资"

| 维度 | 投资视角 | 保险视角 |
|------|---------|---------|
| 收益预期 | 追求正alpha | 接受常态损耗，只为极端情况付费 |
| 持有目的 | 赚取资本利得 | 降低组合整体波动 |
| 成本结构 | 手续费/管理费 | 展期损耗 + 无息持有成本 |
| 失效场景 | 系统性熊市 | 通缩环境（商品价格亦下跌） |

## 实证支撑

2022年美联储加息周期中：
- 股债双跌超过 17%
- 同期商品涨幅超过 15%
- 商品在此极端环境下发挥了显著的对冲价值

## 边界条件

| 场景 | 商品表现 | 对冲有效性 |
|------|---------|-----------|
| 通胀上升 + 股债双杀 | 商品上涨 | 有效 |
| 通缩环境 | 商品下跌 | 失效 |
| 正常增长环境 | 商品波动 | 贡献有限，可能拖累组合 |

## 与 [[债券稳定器]] 的对称关系

债券和商品是两类性质不同的防守型资产，形成对称框架：

| 维度 | 债券（稳定器） | 商品（保险） |
|------|--------------|------------|
| 常态表现 | 提供票息收益 | 持续损耗（负展期 + 无息） |
| 极端场景 | 可能失效（股债双杀） | 发挥作用（对冲通胀） |
| 低利率环境 | 双重收缩（票息↓+资本利得↓） | 不受直接影响 |
| 核心功能 | 收益稳定器 | 尾部风险对冲 |

**关键区分**：债券在正常状态下也提供正向收益，商品在正常状态下是净成本——两者不可混为一谈，投资者应根据组合的实际风险敞口分别配置。

## 实践建议

1. **定位清晰**：将商品视为组合的"保险单"，设定合理的配置比例（如 5%–10%），不期待其成为主要收益来源。
2. **规避期货**：普通投资者应优先通过上游企业股票（参见 [[上游企业股票替代商品期货]]）间接暴露于商品价格，避免直接承担负展期收益和操纵风险。
3. **关注期限结构**：定期观察 backwardation/contango 状态，判断当前展期收益方向是否有利于持有期货。

# 上游企业股票替代商品期货

## 核心命题

对于普通投资者，通过持有上游开采类企业股票来间接暴露于商品价格变动，比直接交易商品期货更具可行性——前者规避了负展期收益、高杠杆和操纵风险三重门槛。

## 形式化表达

```
上游企业：价格敏感 → 受益于涨价
下游企业：价格接受 → 不受益
```

## 产业链利润分布逻辑

在商品产业链中，利润分布呈非对称性：

| 环节 | 代表企业 | 价格敏感度 | 涨价时表现 |
|------|---------|-----------|-----------|
| 上游（开采） | 矿山、油田、油气田 | 高 | 直接受益，利润弹性大 |
| 中游（加工/精炼） | 炼油厂、冶炼厂 | 中 | 传导定价，利润空间被压缩 |
| 下游（制造/零售） | 消费品、制造业 | 低 | 价格被动接受者，成本上升侵蚀利润 |

## 与期货的对比

| 维度 | 商品期货 | 上游企业股票 |
|------|---------|------------|
| 展期成本 | 负展期侵蚀回报 | 无 |
| 杠杆风险 | 高杠杆，放大亏损 | 无（除非融资） |
| 操纵风险 | 历史案例频发 | 极低 |
| 公司经营风险 | 无 | 有（矿难、环保事故等） |
| 流动性 | 依赖合约 | 依赖股票流动性 |
| 商品价格β | 直接 | 间接（需筛选高β上游股） |

## 边界条件

1. **经营风险不可忽略**：上游企业并非纯商品暴露，还面临矿难、环保事故、政策监管等企业特有风险，不等于持有商品本身。
2. **筛选标准**：需区分真正具有商品价格β的上游企业与受公司经营因素主导的企业。晨星全球上游自然资源指数提供了可作为参照的筛选框架。
3. **不能完全替代期货**：对于需要精准商品价格暴露的专业投资者，期货仍是不可替代的工具。
