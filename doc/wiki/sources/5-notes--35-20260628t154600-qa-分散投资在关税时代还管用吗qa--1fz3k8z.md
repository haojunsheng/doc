# QA — 分散投资在关税时代还管用吗

> "不要将鸡蛋放在一个篮子里"还管用吗？晨星通过15年相关性数据证明：分散化未失效，失效的是对它的简单理解。

## 来源信息

- **原始来源**：[Morningstar.cn](https://www.morningstar.cn/articles/5715428853e77db058cccaceaa2eb45d.html)
- **发布时间**：2026-06-28
- **分析类型**：Q&A 格式研究报告

## 核心论点

分散化依然是应对不确定性的最佳工具，但"买不同标签"（如买了美股、买了港股）的时代已经过去。真正有效的分散需要理解资产之间的实际联动关系，并随环境变化动态调整。

## Q1: 为什么"配置海外市场"不等于真正的分散？

**结论**：不同海外市场的相关性不同——发达国家与A股相关性下降，新兴市场与A股相关性上升，港股已与A股高度联动。

| 市场分类 | 与A股相关性趋势 | 时间节点 |
|---------|--------------|---------|
| 发达国家（美日等） | 下降 | 自2021年起逐步下降 |
| 新兴市场 | 上升 | 自2017年起持续上升 |
| 港股 | 高度联动 | 近年来持续趋强 |

**边界条件**：相关性是历史统计，未来可能发生结构性变化。

## Q2: 为什么极端行情下分散会失效？

**结论**：危机时刻所有风险资产短暂趋同——2008、2018、2020、2025均出现"股债商品齐跌"。

```
正常时期: 资产间低相关 → 分散有效
极端时期: 恐慌→同卖→相关性→1 → 分散失效
```

流动性危机时，风险平价等策略可能同时崩溃。分散化假设了相关性稳定，但极端情况会打破假设。

**边界条件**：极端趋同通常是短期的，长期看分散效果会恢复。

## Q3: 债券作为"避风港"的角色为什么也在变？

**结论**：2015年前中国债券与A股负相关，近年来相关性上升，分散效果减弱。

| 时期 | 债券↔A股相关性 | 对冲效果 |
|------|--------------|---------|
| 2015年前 | 负相关 | 有效 |
| 2015年后 | 相关性↑ | 减弱 |

可能原因：机构行为趋同（如银行理财赎回机制）。

**边界条件**：国债的避险属性仍强于信用债，极端情况下国债仍能提供对冲。

## Q4: 大宗商品为什么比债券更能分散风险？

**结论**：大宗商品与A股相关性总体较低，且在风险资产表现不佳时仍能提供对冲。

```
商品价格由供需决定（逻辑独立于股市）
通胀环境中商品受益
风险资产↓时：商品常↑ → 提供对冲
```

**边界条件**：在通缩环境中，大宗商品可能和股市一起下跌，失去对冲作用。

## Q5: 怎样才算"反脆弱"的组合？

**结论**：跨资产类别、能穿越不同经济周期、且持续跟踪相关性的动态防御网络。

```
反脆弱组合 = 跨资产(股票+债券+商品+现金) × 跨市场(境内+海外) × 动态调整
```

单一分散维度（如只配海外）不够，需要多维度分散形成"防御网络"。

**边界条件**：维度越多管理成本越高，普通人可能难以维护过于复杂的多维分散。

## Q6: "分散未失效，失效的是简单理解"怎么理解？

**结论**：分散化原则依然正确，但执行必须从"买多个标签"升级为"理解真实相关性"。

```
简单理解: 买多个市场 = 分散
真实分散: 理解相关性结构 + 动态调整
```

很多人以为买了港股、买了美股就分散了，但港股已与A股高度联动。真正的分散效果取决于实际相关性，不是标签。

**边界条件**：完全理解并跟踪所有资产的相关性需要专业能力，普通人可以用少数低相关资产做简化版。

## 收口

作者用15年相关性数据证明：分散化依然是应对不确定性的最佳工具，但"买不同标签"的时代已经过去。真正有效的分散需要理解资产之间的实际联动关系，并随环境变化动态调整。
