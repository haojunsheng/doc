# QA — 90%基金用错基准，超额收益假象

> 晨星发现一个令人震惊的现象：90%的基金用错了基准，导致所谓的"超额收益"可能只是假象。

## 来源信息

- **原文日期**：2026-06-14
- **来源**：晨星中国

## Q&A 要点

### Q1: 为什么90%的基金用错了基准？

基金合同约定的基准往往与基金实际投资策略不匹配。基金合同通常约定一个标准化基准，但基金经理的实际投资策略可能与基准差异很大，导致超额收益数据失真。

### Q2: 基准不匹配会导致什么后果？

基准失真 → 超额收益假象 → 投资者误判基金经理能力。如果基准偏低，基金容易跑赢但可能只是市场风格匹配；如果基准偏高，基金难以跑赢但经理能力可能优秀。

### Q3: 如何判断一只基金的基准是否合适？

基准合适 = 实际投资组合风格 ≈ 基准风格 AND 行业配置 ≈ 基准行业配置。例如，若基金主要投资成长股但基准是价值指数，则基准不合适。

### Q4: 为什么基金公司不主动修正不合适的基准？

因为修正基准可能导致基金业绩看起来变差，影响销售。基金公司有动力维持好看的业绩数据，修正基准可能导致排名下降。

### Q5: 投资者如何避免被错误基准误导？

自行选择与基金实际策略匹配的基准进行比较，不要只看基金公告的超额收益，需分析基金实际投资组合并选择合适的基准重新计算超额收益。

### Q6: 晨星如何评估基金的基准是否合适？

通过风格匹配度 + 行业配置匹配度进行基准合适性判断，分析基金实际投资组合与基准的匹配程度。

### Q7: 基准不匹配对基金排名有什么影响？

基准失真导致超额收益失真，基金排名失真——有些基金排名虚高，有些基金排名虚低。

### Q8: 为什么投资者容易忽视基准问题？

基准问题涉及风格分析、行业配置等专业知识，普通投资者更关注简单的业绩排名，且基金公司也不会主动揭示基准问题。

## 核心逻辑链

```
合同约定基准 ≠ 实际投资策略
    ↓
基准失真
    ↓
超额收益假象
    ↓
投资者误判基金经理能力
```

## 基准合适性检验公式

```
基准合适 = 实际投资组合风格 ≈ 基准风格
         AND 行业配置 ≈ 基准行业配置
```

## 关键结论

晨星揭示了基金评价体系的重大缺陷：90%的基金用错了基准，导致超额收益数据失真，提醒投资者不要盲目相信基金排名。
