# 11月股债双杀，价值风格占优 QA

> 晨星基金月报 QA，分析2026年11月A股先涨后跌的脉冲结构，以及股债双杀环境下的风格表现与资产配置启示。

## 数据来源

- **发布方**：[[entities/晨星-morningstar]]
- **原文链接**：https://www.morningstar.cn/articles/ae232a1913b2af9c0f4c359bfe0533cd.html
- **收录日期**：2026-06-14

## 核心论点

11月的A股呈现典型的"政策利好脉冲→预期兑现→外部冲击回调"结构。上半月在十五五规划和中长期资金入市政策推动下创十年新高，下半月受科技股调整、美股波动和地缘紧张影响大幅回调。在权益回调中，价值风格（-0.72%）显著跑赢成长风格（-3.41%），而可转债基金因同时暴露于股债双杀，在固收类中表现最差（-1.35%）。商品基金（+2.25%）因黄金避险属性受益。

## 分项问答

### Q1：为什么A股上半月能创十年新高，下半月却大幅回调？

**数据**：上证从盘中4030点（十年新高）回落至-1.67%；深证成指-2.95%。

**逻辑链**：
```
上半月：政策利好（十五五规划、中长期资金入市） → 风险偏好↑ → A股↑ → 十年新高
下半月：科技股调整 + 美股波动 + 地缘紧张 → 风险偏好↓ → A股↓
```

**关键事件**：
- 政策催化：十五五规划确立科技自立自强主线，中长期资金入市方案发布
- 外部冲击：海内外科技股进入调整、美股波动引发全球股市共振、中日地缘关系紧张
- 时间节点：13日盘中最高触及4030点，中下旬开始回调

**边界条件**：若没有外部冲击，政策利好可能支撑A股继续上行；若外部冲击加剧，A股可能进一步下跌。

### Q2：PMI连续8个月在收缩区间，为什么市场还在上半月涨？

**数据**：制造业PMI录得49.2%，连续8个月位于收缩区间，但景气水平呈现弱修复态势（49.0%→49.2%）。

**核心机制**：市场交易的是**预期差**而非**绝对值**。

**逻辑链**：
```
PMI 49.2%（仍在收缩）但边际改善 + 政策利好 → 市场交易"预期差" → 上半月上涨
```

**行为逻辑**：
- 市场不是看PMI的绝对值，而是看PMI的变化方向和边际改善幅度
- 十五五规划、中长期资金入市等政策利好放大了PMI边际改善的正面效应

**边界条件**：若PMI后续再次回落，市场可能重新下跌；若PMI持续改善并突破50%，市场可能进一步上涨。此机制详见 [[concepts/预期差交易]]。

### Q3：为什么债市对通胀和宏观经济数据的修复反应钝化？

**数据**：10月CPI同比上涨0.2%（前值-0.3%），PPI同比下降2.1%（前值-2.3%），数据呈现修复态势。

**核心机制**：市场已提前定价经济修复预期，数据落地只是"符合预期"而非"超预期"。

**逻辑链**：
```
CPI/PPI数据修复 = 市场已预期 → 无超预期增量 → 债市反应钝化
```

**债市逻辑**：债市交易的是"预期差"，符合预期的数据不会引发大的价格波动。

**边界条件**：若数据超预期（如CPI大幅上升），债市会重新反应；若数据不及预期，债市可能反向上涨。

### Q4：为什么价值风格在11月跑赢成长风格？

**数据对比**：
| 风格类别 | 涨跌幅 |
|---------|-------|
| 大盘价值股票型基金 | -0.72% |
| 大盘成长股票型基金 | -3.41% |

**行业表现**：
| 板块 | 表现 |
|------|------|
| 综合、银行、纺织服饰 | +2%以上 |
| 电子、汽车、计算机 | -5%以上 |

**逻辑链**：
```
市场回调 × 价值股（低估值 + 高股息） → 防御属性凸显 → 跑赢
成长股（高估值 + 盈利不确定性） → 承压
```

**行为机制**：风险偏好下降时，资金从高估值成长股流向低估值价值股。

**边界条件**：若市场重新上涨，成长风格可能重新占优；若经济数据持续恶化，价值股的防御属性也会减弱。此数据强化了 [[concepts/成长-vs-价值风格的驱动因素]] 中"风险偏好下降 → 价值占优"的因果链。

### Q5：为什么科技、传媒及通讯基金11月跌得最惨？

**数据**：中证信息技术指数拖累行业混合—科技、传媒及通讯基金录得4.02%和4.57%月平均跌幅。

**逻辑链**：
```
科技股 = 前期涨幅大 + 估值高 + 盈利不确定性↑ → 市场回调时跌幅最大
```

**原因分析**：
- 估值压力：科技股前期涨幅大，估值偏高，在市场回调时容易遭遇"杀估值"
- 宏观环境：PMI连续8个月在收缩区间，科技股的盈利增长不确定性上升

**边界条件**：若科技股业绩超预期（如AI商业化加速），可能重新领涨；若市场继续回调，科技股可能进一步下跌。

### Q6：为什么可转债基金在固收类中表现最差（-1.35%）？

**数据**：中证转债指数11月录得-0.69%月平均跌幅，是所有细分券种中表现最差的。

**逻辑链**：
```
可转债 = 债券属性 + 股票属性 → A股↓ → 转股价值↓ → 跌幅超过纯债
```

**机制解释**：
- 转股价值缩水：A股下跌拖累可转债转股价值
- 债底保护有限：在股债双杀环境中，纯债部分也承压，债底保护减弱
- 综合结果：可转债基金在"股债双杀"环境中同时承受股债两方面的压力

**边界条件**：若A股企稳反弹，可转债的转股价值会重新上升；若债市继续下跌，可转债的债底保护也会减弱。此案例是 [[concepts/可转债双重属性]] 中"股债双杀 → 最弱"预测的实证实例。

### Q7：为什么商品基金在QDII中表现最好（+2.25%）？

**数据**：伦敦黄金价格11月上涨+5.41%。

**逻辑链**：
```
黄金 = 地缘风险↑ + 美联储降息预期↑ → 避险需求↑ → 金价↑ → 商品基金↑
```

**驱动因素**：
- 地缘风险：中美元首通话释放地缘政治冲突缓和信号，但万科寻求债券展期这一信用风险事件冲击市场
- 降息预期：美联储降息预期升温，实际利率下降利好黄金

**边界条件**：若地缘风险进一步缓解或美联储暂停降息，黄金价格可能回调；若通胀超预期上升，黄金的实际收益率会下降。

## 收口规律

当市场从"政策利好驱动"转向"基本面验证"时，价值风格（低估值+高股息）会跑赢成长风格（高估值+高预期），而可转债基金在"股债双杀"环境中表现最差——投资者需要根据市场周期的不同阶段，动态调整风格配置。
