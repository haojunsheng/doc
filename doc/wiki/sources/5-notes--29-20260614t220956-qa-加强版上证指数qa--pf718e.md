# 加强版上证指数

来源：晨星（Morningstar）文章，以 QA 形式解读上交所发布的"上证收益"指数。

## 核心内容

### 上证收益指数是什么？

上交所于2025年7月29日宣布发布"上证收益"指数，基点为3320.89点。该指数与上证指数的**编制方法完全相同**，唯一区别在于收益计算口径：上证收益指数是**全收益指数**，包含分红再投资；上证指数是**价格指数**，仅反映股价变动。

### 为什么要发布全收益指数？

全收益指数的设计目的是更准确地反映一笔投资的真实表现。股票投资收益由资本利得和股息两部分组成，过去十年沪深300全收益指数显著跑赢其价格指数版本，这说明分红再投资对长期回报的贡献不可忽视。

### 业绩基准的偏差问题

文章指出一个被广泛忽视的问题：**用价格指数作为基金业绩基准存在系统性偏差**。基金的回报按全收益口径计算，但若以价格指数作为基准，分母被低估，使得基金的"超额收益"看起来更明显。作者直言这在某种意义上构成"作弊"——即主动基金的管理费 justified 可能被夸大了。

对于被动指数基金，用价格指数作基准是合理的（因为基金本身不追求分红再投资），但对于主动管理型基金，应使用全收益指数作为基准。

### 投资者启示

投资者在评估基金真实表现时，应用全收益指数作为基准，才能看清费率损耗等真实成本，而非被虚高的超额收益所误导。

# 全收益指数

全收益指数（Total Return Index）是一种将成分股分红假设再投资后计算回报的指数，用于更准确地衡量一笔投资的真实表现。与之相对的是价格指数（Price Index），后者仅反映股价变动，不含股息。

## 核心定义

全收益 = 资本利得 + 股息（再投资）

价格指数仅计入资本利得，忽略股息部分。

## 编制要点

- 编制方法与对应价格指数完全相同（选股规则、加权方式等）。
- 唯一区别：对分红假设以"除息日后第一时间再投资"的方式处理。
- 因此全收益指数的长期回报通常显著高于价格指数，尤其在股息率较高的市场或板块。

## 经验证据

过去十年沪深300全收益指数显著跑赢其价格指数版本，证明分红再投资对长期回报的贡献不可忽视。

## 应用场景

- **主动基金的业绩基准**：基金的净值计算口径是全收益，应以全收益指数作为比较基准，否则超额收益会被系统性高估。
- **长期投资者评估真实回报**：使用全收益视角，避免被"指数还在3000点"的叙事误导。
- **指数基金的绩效披露**：被动基金若追求跟踪价格指数，则用价格指数作为基准仍属合理。

## 波动性差异

全收益指数的波动性可能略高于对应价格指数，因为分红再投资引入了额外的买卖价格路径。

## 常见误区

- 误以为全收益指数会取代价格指数——二者定位不同，全收益指数是补充而非替代。
- 用价格指数作为主动基金的基准来"证明"管理人的能力——这会人为放大超额收益的观感。

# 业绩基准选择与偏差

用错误的基准衡量基金业绩，会导致系统性偏差，使超额收益（Alpha）被人为夸大。这是投资者最容易忽视、也最容易被利用的认知盲区之一。

## 核心机制

当基金回报按全收益口径计算（含股息），而业绩基准使用价格指数（不含股息）时：

```
超额收益 = 基金回报（全收益） − 基准回报（价格指数）
```

由于价格指数未计入股息再投资，基准回报被系统性低估，导致"超额收益"被高估。文章作者将这种行为直接定性为"作弊"——因为这会让基金管理者看起来比实际更出色，从而更容易募集和管理更大规模。

## 适用边界

| 基金类型 | 合理基准 | 说明 |
|----------|----------|------|
| 主动管理型股票基金 | 全收益指数 | 基金净值含股息，应与全收益口径对比 |
| 被动指数基金（跟踪价格指数） | 对应价格指数 | 基金策略即为跟踪价格，基准口径一致 |
| 分红再投资型指数基金 | 全收益指数 | 基金策略即再投资，基准口径一致 |

## 与其他偏差叠加

[[费率复利效应]] 会进一步压低投资者的真实回报，而 [[业绩基准选择与偏差]] 则在"账面"上夸大管理人的能力。两者叠加后，投资者看到的"超额"与真实体验之间的差距更大。

## 投资者应对

- 评估主动基金时，优先查看其相对于全收益指数的超额收益，而非价格指数的超额。
- 关注基金管理人在招募说明书中的业绩基准口径。
- 警惕那些以价格指数为基准宣称"超额"的主动产品。

# 上证指数 vs 上证收益指数

| 维度 | 上证指数 | 上证收益指数 |
|------|----------|--------------|
| 类型 | 价格指数 | 全收益指数 |
| 收益口径 | 仅资本利得 | 资本利得 + 股息再投资 |
| 基点 | 100点（历史起始） | 3320.89点（2025年7月29日） |
| 编制方法 | 与上证收益指数相同 | 与上证指数相同 |
| 主要用途 | 市场晴雨表、行情参考 | 基金业绩基准、真实回报衡量 |
| 波动性 | 较低 | 略高（分红再投资引入额外价格路径） |
| 是否替代关系 | — | 补充，不替代 |

## 关键差异说明

两者的选股规则、加权方式和成分股调整逻辑完全一致，唯一的差异在于**收益率计算是否包含分红再投资**。

上证指数以100点为基点，自发布以来长期在2800–3500点区间波动，成为投资者感知"3000点保卫战"的背景。上证收益指数以3320.89点为起始，在发布时已超过上证指数的点位，因此引发"加强版上证指数强行突破3000点"的网络调侃。

## 投资者启示

- 上证指数作为行情风向标，其历史意义和传播度不可替代。
- 上证收益指数更适合作为基金业绩比较的基准，因为它反映了投资者实际获得的全部回报。
- 用上证指数（价格指数）作为主动基金的业绩基准，会导致基金"超额"被系统性高估。
