# QA — 自我服务偏见与基金经理行为

**原始来源：** Morningstar 中国（2023-11-15）  
**链接：** https://www.morningstar.cn/articles/bc37587adf0734c127e59606a5efbcde.html  
**副标题：** 胜则为己，败则为命：基金经理的自我归因偏见

## 核心论点

基金经理业绩好时归因于自身能力，业绩差时甩锅给市场——这种"自我服务偏见"（Self-serving bias）普遍存在且有害。优秀经理能在顺境中保持谦逊、在逆境中保持纪律，这种品质比经验年限更稀缺。

## 关键数据

- 美国研究分析 15,000 份基金报告，用 AI 语言模型识别归因方式
- 成功时 59% 强调内部因素（选股、配置），41% 提外部因素
- 失败时 83% 甩锅外部因素（市场、风格），17% 承认内部因素
- 有偏见的经理后续更愿承担风险、交易更频繁，但业绩反而更差、波动更大

## 三大发现

### 1. 自我服务偏见的行为链条

```
偏见 → 高估能力 → 过度交易 + 高风险 → 业绩↓ + 波动↑
```

有偏见的基金经理在取得出色绩效后偏见更强，倾向于进行更多组合调整和交易，这些操作对业绩产生负面影响并增加波动性。关键洞察：这些经理并非天生风险偏好更高，而是**偏见放大了他们对自身能力的判断**，导致风险敞口超出理性水平。

### 2. 牛市是"照妖镜"，熊市才是试金石

牛市期间行情和能力的信号混合，难以区分；熊市才是检验风控能力的试金石。2020 年很多基金经理把行情当能力，忽视风险；2021-2023 年熊市中，忽视风控的经理跌幅远超指数，而保持清醒的经理"守住了钱"。

### 3. 季报语言是性格识别窗口

| 归因语言 | 示例 | 风险解读 |
|---------|------|---------|
| 成功归己 | "战胜基准因消费配置" | 高估自身能力，风险敞口可能偏高 |
| 失败甩锅 | "业绩受逆风影响" | 缺乏反思，同类错误可能重复 |
| 谦逊归因 | "市场赏的，不可期望年年如此" | [[敬畏市场]] 的表现，长期更稳健 |

**边界：** 季报可能有"报喜不报忧"倾向，需结合长期表现判断；单一季报可能不代表整体风格。

## 敬畏市场 = 长期复利的基础

```
敬畏市场 = 谦逊 + 纪律 → 控制回撤 → 长期复利
```

敬畏市场不等于保守，而是在进攻和防守之间找到平衡。优秀经理表现为：承认市场赏赐、经历教训后完善投资流程、识别和控制组合风险。

- 量化数据：基于 AI 语言模型分析 15,000 份美国基金报告的单一研究
- A 股案例：以 2020-2023 年市场为背景的经验性叙述
- 原始研究的具体年份/期刊未给出，属于开放问题
