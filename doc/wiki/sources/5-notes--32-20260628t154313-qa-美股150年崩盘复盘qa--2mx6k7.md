# 美股150年崩盘复盘

来源：[[entities/晨星中国]] 美国团队分析。

## 核心论点

美国"对等关税"政策引发全球贸易战恐慌，投资者集体担忧"史诗级危机"。晨星回溯1871—2025年共150年的美股数据，用19次跌幅超过20%的崩盘史实告诉投资者：崩盘是常态而非例外，历史不会简单重复但规律相似，关键不在于预测方向而是做好应对。

## 历史数据摘要

| 指标 | 数值 |
|------|------|
| 统计跨度 | 1871—2025（150年） |
| 崩盘次数（跌幅>20%） | 19次 |
| 平均间隔 | 约7.9年一次 |
| 1871年1美元 → 2025年 | 约31,255美元 |
| 近10年幻觉 | "美股稳赚"；实则每9-10年一次崩盘 |

## 三次代表性崩盘对比

### 1929年大崩盘 — 痛苦基准（100%）

- 1929年8月投100美元 → 1932年5月剩21美元，市值蒸发89%
- 4年多才重回崩盘前水平
- 成因：十年牛市催生过度自信 + 生产过剩 + 通胀 + 黑色星期四
- 边界：现代央行工具（QE）可能减轻类似痛苦

### 2000年互联网泡沫 — 叠加崩盘导致"失落十年"

- 纳斯达克半年腰斩
- 2000年8月投100美元 → 2002年10月剩52.76美元
- 2008年次贷危机再砸至46美元
- 买入持有策略**12年才回本**
- 成因：第一次崩盘后尚未回本就遭遇第二次崩盘（叠加效应）
- 边界：若在2008年低点加仓可大幅缩短回本时间

### 2020年熔断 — 历史上"最不痛苦"的崩盘之一

- 10天4次熔断，当时感觉天塌了
- 1个月跌19.6%，但仅4个月重回前期高点
- 以1929年为痛苦基准（100%），2020年痛苦指数极低
- 边界：若无快速政策干预，修复时间可能大幅延长

## 核心主张

1. **崩盘常态化**：150年19次，约每7.9年一次，崩盘是常态而非例外
2. **"这次不一样"谬误**：每次崩盘时投资者都认为前所未有，但历史证明宏观政策引发的波动曾多次上演（一战+大流感、二战、石油危机等秩序颠覆事件后市场均复苏）
3. **应对优于预测**：不预测方向，基于风险承受能力 + 资金期限 + 多元化组合构建应对策略

## 应对框架

引用**托马斯·索威尔**和**霍华德·马克斯**的观点：

> 索威尔："预测经济需要先预测政治人物"
> 霍华德·马克斯："理性应对波动能带来回报"

```
理性应对 = 风险承受能力 + 资金期限 + 多元化组合
```

不赌方向，依靠资产配置的纪律性抵御不可预测的事件冲击。

## 边界条件

- 若全球化彻底逆转，经济结构发生根本性变化，历史参照系可能失效
- 当投资者面临短期流动性需求（1年内要用钱）时，多元化组合不能避免短期账面亏损
- 现代央行工具（QE等）已改变崩盘后的修复路径，历史痛苦程度的参照意义需打折扣
