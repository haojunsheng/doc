# QA — 2026年2月基金市场：政策利好推动股债双收，中小盘风格占优

**原文**：[晨星中国](https://www.morningstar.cn/articles/c974c237d7cbb5e08481f2b0be205d6a.html)  
**发布日期**：2026年2月基金月报（收录于 2026-06-14）

## 一句话摘要

2026年2月是中国资本市场的"政策催化月"：政治局会议稳增长信号+两会产业政策，推动A股中小盘涨3.71%、沪深300仅涨0.17%，债市在央行呵护下涨0.17%，收益序列风险与风格轮动特征显著。

## 核心发现

### Q1：中小盘风格为何跑赢？

**结论**：政策利好集中在科技成长和顺周期板块，这些板块以中小盘股为主。

```
政策利好（AI、新能源、基建）→ 科技成长+顺周期↑ → 中小盘↑ → 中证1000涨3.71%
```

**数据**：
| 指数 | 涨跌幅 |
|------|--------|
| 中证1000 | +3.71% |
| 中证500 | +3.46% |
| 沪深300 | +0.17% |

**行业表现**：综合、钢铁、建筑材料涨超8%；银行、非银金融跌超3%

**边界**：若政策转向或经济数据走弱，中小盘优势会消失

### Q2：PMI收缩但股市上涨？

**结论**：股市反映预期而非当下，政策利好让投资者相信未来经济好转。

```
PMI=49.0%（收缩）+ 稳增长信号 → 预期改善 → 股市↑
```

**核心机制**：股市是"预期的折现"，而非当前经济的镜子

**边界**：若PMI跌破48%，预期逆转

### Q3：收益率曲线为何陡峭化？

**结论**：短端受春节资金面扰动上行，长端受政策预期和避险情绪支撑下行。

```
短端（1年期）：春节资金紧张 → 收益率↑ +2bp
长端（5/10年期）：政策预期 + 地缘避险 → 收益率↓ -3~4bp
→ 收益率曲线陡峭化
```

**边界**：若春节后资金面超预期宽松，短端利率也会下行

### Q4：钢铁板块为何强势？

**结论**：《钢铁行业稳增长工作方案（2025-2026年）》推动供给侧控制预期。

```
政策（钢铁稳增长方案）→ 供给侧控制 + 落后产能退出 → 行业集中度↑ → 钢铁股↑
```

**边界**：若政策执行力度不足或需求端（房地产）持续走弱，钢铁股会回调

### Q5：固收+为何表现亮眼？

**结论**：A股和可转债在2月表现良好，权益敞口分享了上涨红利。

```
固收+ = 纯债 + 股票/可转债
2月A股↑ + 可转债↑0.89% → 固收+净值↑
纯债仅涨0.17%，说明"+"贡献了主要收益
```

**边界**：若股市下跌，可转债跟跌，固收+跑输纯债

### Q6：QDII全球新兴市场基金为何涨6.62%？

**结论**：日股、韩股在2月大幅上涨，这类基金重仓这些市场。

```
日经225涨10.31%（日元贬值+企业治理改革）
韩股受益半导体+AI主题
→ QDII全球新兴市场基金涨6.62%
```

**边界**：若日元大幅升值或地缘冲突再起，日韩股市可能回调

### Q7：银行、非银金融下跌意味着什么？

**结论**：市场主线是"科技成长+顺周期"，传统金融板块被资金抛弃。

```
资金从传统金融（银行、非银）→ 流向科技成长+顺周期（钢铁、建材）
```

**边界**：若市场风格转向价值/大盘，银行和非银金融会补涨

## 收口

晨星2月基金月报揭示的核心规律：**政策利好是市场上涨的"第一推动力"**——政治局会议释放的稳增长信号、两会推出的产业政策，直接决定了2月的市场风格（中小盘+科技成长+顺周期）。投资者要理解政策，才能理解市场在交易什么。
