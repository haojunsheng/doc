# 伴读：市场急涨急跌，操作上如何应对？

## 一句话摘要

从"为什么需要投资策略"到"如何制定策略"的四步框架：定目标 → 找认知优势 → 选工具 → 定交易纪律。核心观点：投资成功的关键不是了解别人怎么成功，而是更好地了解自己。

## 结构地图

- 开篇：市场急涨急跌，你需要自己的投资策略
  - 01 你为什么需要自己的投资策略？
    - "致富"不是目标，是空话
    - 没有目标的投资就像没有目的地的旅程
    - 霍华德・马克斯金句
  - 02 找到可以帮你实现目标的大方向
    - 用目标反推所需收益率
    - 不同股债配置的预期收益与波动
    - 年化收益的定义
  - 03 找到你的认知优势
    - 四种优势：信息、分析、行为、结构性
  - 04 找到你的认知优势（续）
    - 没有信息/分析优势 → 买宽基指数
    - 有信息/分析优势 → 可考虑主动基金或股票
  - 05 什么时候买卖？
    - 三种需要调整的情况：买入逻辑不再成立、再平衡、目标变化

## 核心论点

### 1. "致富"不是目标

"致富"是最常见的投资目标，但作者明确指出它太模糊，无法指导任何具体决策。以"致富"为目标的投资就像一场没有目的地的旅程——你永远不知道什么时候该停下来，也不知道是否已经到达。

> 霍华德・马克斯："你不能指望在与其他人采取相同行动的情况下，还能够超越常人实现卓越。"

### 2. 目标必须可量化、可反推

文章用具体数学展示了目标反推的过程：

- 目标：10 年后攒够 100 万
- 每月定投 5000 元 → 需要年化 8%
- 每月只能投 3000 元 → 需要年化 18%
- 每月只能投 500 元 → 需要年化 50%（不切实际）

这段用数学把"目标"和"可行性"连接起来——如果你的储蓄能力和目标不匹配，你要么调整目标，要么接受更高的风险。

### 3. 四种认知优势

| 优势类型 | 含义 | 散户通常状况 |
|----------|------|-------------|
| 信息优势 | 比别人更了解某项投资 | 没有 |
| 分析优势 | 更好地利用相同信息 | 没有 |
| 行为优势 | 更好地控制情绪和行为 | 每个人都有潜力 |
| 结构性优势 | 不受外部压力影响（无考核周期、无赎回压力） | 有优势 |

核心结论：散户在信息和分析上处于劣势，但在行为和结构性上有优势。这意味着散户应该扬长避短，而不是和机构比拼信息和分析。

### 4. 根据认知优势选择工具

- 没有信息/分析优势 → 买宽基指数（低成本获得市场平均回报）
- 有信息优势 → 可考虑买股票
- 有分析优势 → 可考虑主动基金
- 非专业投资者 → 保持简单

**原则：投资你最熟悉和擅长的东西。**

### 5. 三种正当的买卖情形

1. **买入的逻辑不再成立** — 当初买入的理由消失了
2. **再平衡** — 按配置比例调整，纪律性地"低买高卖"
3. **投资目标发生变化** — 个人情况或财务目标变了

**市场波动本身不是买卖理由。**

## 理解轨迹

现象引入 → 为什么需要策略 → 从目标反推配置 → 找认知优势 → 选工具 → 定交易纪律。整篇文章的论证路径是从"为什么"到"怎么做"，先建立策略意识，再给出具体框架。

## 术语表

- **投资策略**：基于投资目标和个人情况制定的行为指南
- **年化回报**：将一段时间的回报换算成一年期的回报，考虑了复利效应
- **再平衡**：将组合调整回原始资产配置比例，纪律性地实现"低买高卖"
- **信息优势**：比大多数投资者更了解某项投资的信息
- **行为优势**：更好地控制情绪和行为的能力
