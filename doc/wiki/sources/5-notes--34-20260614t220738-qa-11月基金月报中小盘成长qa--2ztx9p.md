# 11月基金月报——中小盘成长延续强势

> 数据来源：晨星11月基金月报（2024年）

## 核心发现

2024年11月，A股主要股指整体上涨，**中小盘风格继续跑赢大盘**，**成长风格延续强势**，同时**债市走强**，可转债基金以2.24%的月涨幅领涨固收类基金。这种"股债双收+中小盘成长占优"的组合，反映了政策预期升温与经济企稳复苏的双重驱动。

| 指标 | 涨跌幅 |
|------|--------|
| 上证 | +1.42% |
| 深证成指 | +0.19% |
| 中证1000 | +1.18% |
| 沪深300 | +0.66% |
| 中盘成长风格 | +2.72% |
| 大盘平衡风格 | -0.04% |
| 中证全债 | +1.01% |
| 可转债基金 | +2.24% |
| 中证转债指数 | +2.43% |
| 美国股票基金（QDII） | +5.53% |
| 标普500 | +5.73% |
| 恒生指数 | -4.40% |

## 关键问题与结论

### 中小盘为何继续跑赢大盘？

特朗普当选后市场预期即将召开的[[中央经济工作会议]]将释放更多政策利好，叠加国内经济数据持续回暖，资金从大盘防御板块流向中小盘成长板块。11月制造业PMI录得50.3，连续3个月上升趋势，连续2个月处于扩张区间。商贸零售、综合、纺织服饰、传媒、轻工制造涨幅超6%，这些行业中小盘股占比高。

### 成长风格为何延续强势？

中证信息技术指数和中证医药卫生指数表现良好。行业股票—科技传媒通讯基金+2.91%，行业混合—医药基金+2.27%，说明科技和医药是成长风格的核心驱动力。政策预期继续支持科技创新和消费升级。

### 可转债基金为何领涨固收类？

中证转债指数上涨2.43%，是所有细分券种中表现最佳的。11月股市上涨+债市上涨形成"股债双收"环境，可转债兼具股债特性，同时受益。利率债+0.71%、普通债+0.68%、信用债+0.61%，对比验证可转债弹性最大。

### 美国股票基金为何在QDII中表现最好？

美股表现强劲（标普500+5.73%），美国Markit制造业PMI 48.8，环比上升1.0，基本面边际改善。亚洲股债混合-2.72%、大中华区股票-2.91%，主要受港股拖累（恒生-4.40%）。

## 配置框架

**"中小盘成长+可转债底仓+美股分散"**

- 进攻端：中小盘成长（中证1000+1.18%）
- 平衡端：可转债底仓（中证转债+2.43%）
- 分散端：美股配置（标普500+5.73%）

## 与10月报告对照

| 月份 | 中证1000涨幅 | 沪深300涨幅 | 风格特征 |
|------|-------------|------------|---------|
| 10月 | +7.14% | -3.16% | 爆发式领涨 |
| 11月 | +1.18% | +0.66% | 延续性占优 |

结论：中小盘成长从"爆发式领涨"转向"延续性占优"，是行情降温而非趋势反转的信号。

## 边界条件

- 若政策不及预期，中小盘会回调
- 若股市下跌，可转债期权价值缩水
- 若美股回调（如美联储推迟降息），海外配置会拖累
- "股债双收"仅限A股+境内债市，QDII中的亚洲部分不参与

# 中证1000指数

中证1000指数是反映中国A股市场中小市值公司股价走势的重要指数，覆盖沪深两市剔除沪深300和中证500成分股后的第301-1300名公司规模，代表中小盘风格。

## 在基金投资中的作用

中证1000指数常被用作**中小盘风格基金**的业绩基准或参照指数。[[股债双收]]分析框架中，11月中证1000+1.18% vs 沪深300+0.66%，中小盘继续跑赢大盘，反映政策预期升温驱动资金从大盘防御板块流向中小盘成长板块。

## 历史表现参考

| 时间 | 表现 |
|------|------|
| 2024年10月 | +7.14%，爆发式领涨 |
| 2024年11月 | +1.18%，延续性占优 |

# 沪深300指数

沪深300指数是反映中国A股市场大盘蓝筹公司股价走势的核心指数，覆盖沪深两市规模最大的300家公司，代表大盘风格和稳健投资取向。

## 与中证1000的风格对比

| 时间 | 沪深300 | 中证1000 | 特征 |
|------|---------|---------|------|
| 2024年10月 | -3.16% | +7.14% | 中小盘爆发式领涨 |
| 2024年11月 | +0.66% | +1.18% | 中小盘延续性占优 |

沪深300在大盘平衡风格下通常受益于政策托底预期，但在政策预期升温环境下资金更倾向流向中小盘成长板块，形成风格轮动。

# 中央经济工作会议

中央经济工作会议是每年年底由中共中央召开的确定次年经济工作方向和政策基调的重要会议，是市场解读政策预期升温的核心事件节点。

## 对基金投资的影响机制

当外部地缘事件（如美国大选）引发市场对国内政策加码的预期时，[[政策预期升温]]会驱动资金从防御板块流向成长/中小盘板块。2024年11月，特朗普当选后市场预期中央经济工作会议将释放更多刺激政策，成为中小盘成长风格延续强势的核心驱动因素。

## 与"宽松预期抢跑"的关系

[[宽松预期抢跑]]侧重货币政策预期，而中央经济工作会议更多涉及财政政策方向（如产业支持、消费刺激等），两者共同构成政策预期升温的完整框架。

# 政策预期升温

外部地缘事件（如美国大选）触发市场对国内政策加码的预期，驱动资金从防御板块流向成长/中小盘板块，是风格轮动的重要驱动因素。

## 定义

当国际政治经济环境发生变化（如特朗普当选），市场预期国内决策层将推出更多刺激政策以对冲外部不确定性，这种预期本身就会改变资金的风险偏好和配置方向，形成"政策预期升温"效应。

## 传导机制

```
外部事件触发 → 政策加码预期升温 → 风险偏好提升 → 资金从大盘防御→中小盘成长
```

## 实证案例（2024年11月）

| 指标 | 表现 |
|------|------|
| 中证1000 | +1.18% |
| 沪深300 | +0.66% |
| 中盘成长 | +2.72% |
| 大盘平衡 | -0.04% |

制造业PMI连续3个月上升趋势，连续2个月处于扩张区间（11月50.3），为政策预期提供数据支撑。

## 与"宽松预期抢跑"的区别

- [[宽松预期抢跑]]：侧重货币政策预期（如降准降息），驱动利率敏感型资产
- [[政策预期升温]]：侧重财政政策预期（如产业支持、消费刺激），驱动成长/中小盘风格

## 边界条件

- 若政策不及预期，中小盘会回调
- 若政策重点转向传统行业，成长风格承压
- 若经济数据恶化，中小盘跌幅会更大

# 恒生指数

恒生指数是香港股市最具代表性的基准指数，反映香港主板市场上市公司整体表现，是QDII亚洲股债混合基金和大中华区股票基金的主要追踪标的之一。

## 在QDII配置中的角色

2024年11月，恒生指数-4.40%，拖累亚洲股债混合基金-2.72%、大中华区股票-2.91%，与美股（标普500+5.73%）形成强烈反差，是[[QDII两极分化]]现象的典型案例。

## 与A股的联动与背离

港股作为离岸市场，受流动性环境和地缘政治影响更大，与A股常出现背离。在"股债双收"的A股市场环境下，港股仍可能独自走弱，投资者需关注离岸与在岸资金分流的影响。

# 标普500指数

标普500指数是美国股票市场最具代表性的基准指数，覆盖美国股市规模最大的500家上市公司，是QDII美国股票基金的主要追踪标的。

## 在2024年11月QDII配置中的表现

2024年11月，标普500指数+5.73%，美国股票基金+5.53%，领跑所有QDII类别。同期美国Markit制造业PMI 48.8，环比上升1.0，显示经济虽在收缩区间但边际改善。

## 配置意义

标普500与A股相关性较低，在[[股债双收]]框架中提供有效的海外分散功能，是"中小盘成长+可转债底仓+美股分散"三环节中的分散端。
