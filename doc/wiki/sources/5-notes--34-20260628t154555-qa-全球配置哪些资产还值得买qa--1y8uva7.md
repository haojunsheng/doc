# 全球配置哪些资产还值得买

晨星2025Q3全球资产配置观点报告，面对的背景是：AI热潮让美股偏贵、债券在经历两年下跌后重新展现分散价值、新兴市场创多年最佳表现。报告的核心方法是复盘过去季度表现，结合公允价值分析，找出相对机会和风险。文章很短，但给出了三个明确的观点调整：日本股票从"中性"降为"吸引力较低"，英国股票从"吸引力较高"降为"中性"，美国投资级信用债从"中性"降为"吸引力较低"。

## Q1: 为什么债券重新成为"优质分散工具"？

**结论**：经历2021-2022年连续下跌后，2025年全球债市迎来近五年最佳表现，信用利差降至近十年低位。

**形式化**：
```
2021-2022: 债券连跌两年 → 质疑配置价值
2025:      债市反弹 + 信用利差近十年低位 → 重拾分散价值
```

**要点**：
- 2025年全球大部分债市创近五年最佳表现
- 几乎所有信用资产类别利差降至近十年低位
- 信用债表现整体好于国债

**边界**：如果利率反转上行，债券分散效果会再次失效。

## Q2: 日本股票为什么从"中性"降为"吸引力较低"？

**结论**：新首相当选短期利好被通胀政策不确定性、估值压力、汇率风险三重重压抵消。

**形式化**：
```
日本: 新首相当选 → 短期利好
     但: 通胀政策不确定 + 估值压力 + 汇率风险 → 长期吸引力下降
```

**边界**：如果日本通胀回升且政策明确，吸引力可能重新上升。

## Q3: 英国股票为什么从"吸引力较高"降为"中性"？

**结论**：前三季度上涨后估值已无显著优势，通胀高于欧元区其他国家，相对吸引力消退。

**形式化**：
```
英国: 前三季度涨 → 估值优势消失 + 通胀高于欧元区 → 从"有吸引力"降为"中性"
```

**边界**：如果英国通胀快速回落或企业盈利超预期，可能重新获得吸引力。

## Q4: 美国投资级信用债为什么降为"吸引力较低"？

**结论**：信用利差已逼近历史低位，后续收窄空间有限，当前收益难以覆盖潜在信用风险。

**形式化**：
```
美国投资级信用债: 利差逼近历史低位 → 收窄空间有限 → 收益 < 潜在风险 → 吸引力下降
```

**边界**：如果经济持续强劲不发生违约，低利差可以维持，但风险收益比不佳。

## Q5: 为什么新兴市场在三季度表现最强？

**结论**：新兴市场三季度涨近9%，创多年最佳，全年收益有望创2017年以来最佳水平。

**形式化**：
```
新兴市场Q3: +9% → 多年最强（发达市场同期 +7%）
新兴市场全年: 或创2017年来最佳
```

**边界**：新兴市场波动大，强劲表现不一定能持续。

## Q6: 面对"AI太火、美股太贵"的局面，配置思路应该转向哪里？

**结论**：转向仍有估值优势的市场（新兴市场）、重拾债券分散价值、警惕利差过窄的信用债。

**形式化**：
```
应对: 新兴市场(估值优势) + 债券(分散工具)
回避: 日本/英国/美国信用债(吸引力下降)
```

**边界**：如果美股继续跑赢、AI热潮不退，转向过早会拖累短期回报。

## 收口：季度再平衡框架

作者贡献了一个"季度再平衡"的配置框架：不追热点、关注估值和利差变化、在贵的地方减配、在便宜的地方增配——核心是"从撤出来的地方找去处"。这一框架与[[全球配置范式转变]]形成互补：范式卡给出长期（10年）预期回报率框架，本文给出短期（季度）观点调整逻辑。
