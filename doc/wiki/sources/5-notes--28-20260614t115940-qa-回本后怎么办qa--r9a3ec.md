# QA — 回本后怎么办

> 绿了三年，终于红了！回本之后怎么办？

## 核心论断

**回本是复盘时机，不是跑路信号。**

投资者在亏损多年后终于回本时，往往面临"卖不卖"的焦虑——卖了怕踏空，不卖怕再套。本文的核心洞见是将这一问题框架从"要不要卖"转向"配置是否合理"，把回本作为重新审视投资目标、风险偏好和持仓水平的契机。

## 关键问题与结论

### Q1：为什么"预测市场短期走势"是伪命题？

没有人能持续精准买低卖高。卖出后面临新问题：钱怎么处置？何时再入场？投资什么？预测市场的成本远高于不确定收益。替代方案是定期再平衡，而非择时。

**边界**：如果投资者有明确的长期目标和资产配置计划，就不需要预测市场。

### Q2：为什么回本时最该问的不是"要不要卖"？

回本焦虑暴露了股票/偏股基金仓位可能超出心理承受水平。正确的问题是"我的配置合理吗"，行动的起点是"我该拿多少钱投资"，而非单品持有层面的决策。

**边界**：如果已有明确的资产配置计划且当前配置合理，回本后不需要大幅调整。

### Q3：为什么"用闲钱投资"这么重要？

只有用不着急的钱做不着急的投资，才能在市场波动时保持从容。未来5年内要用的刚需资金（买房、教育等）不应投入股票类资产。回本时应先赎回这部分资金，让自己回到舒适配置水平。

**边界**：有稳定收入来源和充足应急资金的投资者，"闲钱"门槛可相对降低。

### Q4：为什么有些基金回本就该撤？

主动基金的及格线是指数，可用3年/5年业绩对比评估。业绩归因可拆分收益来源：押对赛道 vs 选对股票。若行业和选股带来的收益贡献均为负值，基金经理能力存疑。

**边界**：需区分"短期风格逆风"与"能力不足"——前者不一定是赎回理由。

### Q5：回本后如何评估基金该不该留？

三维度评估框架：

1. **业绩**：过去3/5年是否战胜指数和同类？
2. **收益来源**：钱是怎么赚的——押对赛道还是选对股票？
3. **能力圈**：是否真正理解这只基金，愿意投入多少时间精力？

**边界**：评估需要一定专业知识，不具备能力的投资者可借助晨星基金小程序等工具辅助判断。

## 方法论框架

### 三维度评估公式

```
评估 = 业绩（vs 指数 + 同行）+ 收益来源（能力 vs 运气）+ 能力圈（懂不懂）
```

### 收益来源拆分的操作路径

- 主动基金及格线：指数
- 对比周期：3年 / 5年
- 收益来源归因：赛道选择贡献 vs 选股能力贡献
- 两者均为负 → 基金经理能力存疑
- 主题/行业基金波动大 → 不懂就清仓

## 开放问题

- 5年"闲钱"门槛是否有实证依据？不同收入稳定性人群的阈值是否应动态调整？
- "风格逆风"和"能力不足"的量化区分标准是什么？

## 证据强度

中等。基于晨星机构的专业投资视角，逻辑链完整但缺乏数据支撑，更多是方法论指导而非实证研究。
