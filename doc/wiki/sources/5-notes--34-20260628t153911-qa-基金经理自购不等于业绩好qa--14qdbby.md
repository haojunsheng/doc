# QA — 基金经理自购不等于业绩好

来源：晨星中国（Morningstar.cn）

---

## 核心结论

自购是正面信号，但**信号正在贬值**。强制自购政策普及后，全员自购趋势会让自购从"信心的证明"变成"合规的要求"，区分度归零。

---

## Q1：多少基金经理在自购？

**结论**：超过半数基金经理没有自购，持有100万份以上的仅7%，自购仍是少数行为。

**形式化数据**（2024年年报，12,131只基金）：

| 自购档位 | 占比 |
|---------|------|
| 零自购 | 54% |
| ≤10万份 | 19% |
| 10-50万份 | 15% |
| 50-100万份 | 5% |
| >100万份 | 7% |

**制度背景**：监管要求基金经理将不少于30%绩效薪酬自购权益类基金，但执行差距显著——54%的基金经理零持有。

**边界**：当监管进一步强制自购比例或加大处罚时，零自购现象会减少，但信号价值同步稀释。

---

## Q2：为什么混合型基金自购率最高？

**结论**：年轻基金经理风险承受力强 + 主动管理超额收益潜力，使混合型基金成为自购首选。

```
混合型(主动管理+高风险高收益) > 股票型(2/3被动指数) > 债券型(低收益)
```

**原因拆解**：
- 年轻基金经理处于财富积累初期，风险承受力强，愿意用真金白银表达信心
- 主动权益基金长期有超额收益空间，自购回报潜力大
- 股票型基金2/3是被动指数基金，基金经理无主动决策空间，自购意义不大
- 债券型基金收益有限，难以满足快速财富积累需求

**边界**：当主动管理不再能稳定获取超额收益时，混合型基金自购率会下降。

---

## Q3：自购的基金业绩真的更好吗？

**结论**：三年期数据显示有自购的基金平均回报更高、胜率更高，但品类差异显著。

**实证数据**（锁定2021年底成立→2024年底表现）：

| 基金品类 | 自购胜率 |
|---------|---------|
| 大盘成长股票 | ≥60% |
| 中小盘 | ≥60% |
| 普通债券型基金 | ≥60% |
| 大盘平衡型 | **<50%**（反例） |

**核心发现**：有自购基金平均回报均值超越同类平均，但大盘平衡型是自购胜率的反例——自购并非万能。

**边界**：大盘平衡型基金胜率不足50%，说明自购的优势在低风险/低分化风格中不明显。

---

## Q4：为什么自购对成长股和中小盘影响更明显？

**结论**：高风险高分化基金中，自购促使基金经理同时把握机会和风控，优势更突出。

**机制**：

```
高风险基金 × 自购约束 → 基金经理更重视风控 → 长期胜率更高
```

- 成长/中小盘基金集中配置高增长高风险领域，基金经理容易"纯追收益"
- 自购带来"切肤之痛"，迫使基金经理在追求收益的同时注重风险控制
- 价值平衡风格本身较稳健，自购的边际约束效果小
- 纯债基金风险低，自购的约束作用也有限

**边界**：当市场风格从成长切向价值时，成长股基金的自购优势可能消失。

---

## Q5：自购信号未来会失效吗？

**结论**：随着强制自购政策落地，自购率普遍提升，自购对业绩的区分度会下降，**信号贬值**。

**核心类比**（晨星）：

> 就像"所有厨师都必须吃自己做的菜"——当全员自购成为常态，自购就不再是信心的证明，而只是合规的要求。

**信号贬值的逻辑链**：

```
强制自购普及 → 全员自购 → 自购不再是区分因素 → 信号区分度归零
```

**当前窗口**：
- 目前还能用自购做筛选，但随着强制政策推进，窗口在收窄
- 数据披露粒度不足（仅区间），也限制了判断精度

**边界**：如果披露从区间升级为精确金额，自购信号仍可判断"诚意"——大额 vs 小额自购仍有区分度。

---

## Q6：自购应该作为选基金的唯一标准吗？

**结论**：不应该，投研团队、投资流程、基金公司、费率等因素同样重要。

**多因素框架**：

```
基金潜力 = 自购信号 + 投研团队 + 投资流程 + 基金公司 + 费率
```

**各因素作用**：
- **自购信号**：信心代理变量，正向但不充分
- **投研团队稳定性**：直接影响策略执行连续性
- **投资流程制度化**：决定基金是否依赖个人，能否跨经理传承
- **费率**：直接侵蚀投资者到手收益

**边界**：当基金经理大额自购（如500万以上）时，信心信号的权重会相应提高。

---

## 收口

晨星的核心发现：自购是正信号但正在贬值——当制度让所有人都"不得不买"时，自购就从"信心的证明"变成了"合规的要求"。

投资者仍可在当前窗口用自购率做辅助筛选，但需结合投研团队、费率等维度综合判断，且应意识到这一信号的区分度正在收窄。
