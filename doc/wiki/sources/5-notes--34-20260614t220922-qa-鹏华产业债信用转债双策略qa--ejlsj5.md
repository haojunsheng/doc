# QA — 鹏华产业债信用转债双策略

来源文章：晨星焦点基金系列——鹏华产业债债券

## 基本信息

- 基金名称：鹏华产业债债券（206018）
- 基金经理：祝松
- 数据区间：2014年3月至2025年2月
- 年化回报：6.42%
- 同类排名：普通债券基金前14%
- 年度综合费率：1.30%（同类均值1.10%）

## 核心结论

鹏华产业债是一只典型的"固收+"基金——以AAA级信用债为底仓获取稳健收益，通过可转债增强弹性，考验的是基金经理对权益市场趋势的判断力。

## 关键问答

### Q1: 核心投资策略是什么？

**结论**：综合运用信用策略、久期策略和可转债策略，以信用债为核心配置。

**组合配置公式**：
```
组合 = 信用债（80-120%，AAA > 50%）
     + 利率债（0-20%）
     + 可转债（0-20%，均值15%）
```

- 自上而下从宏观出发确定久期和转债仓位
- 信用债为核心，重点配置中高等级（AAA占比长期>50%）
- 利率债以5-10年期政金债为主，久期1-5年灵活调整
- 可转债以自上而下的仓位配置和行业选择为主

**边界**：可转债仓位偏高（均15% vs 同类6%），在权益牛市表现突出，熊市可能拖累。

### Q2: 如何做到"前瞻性调整可转债仓位"？

**结论**：根据权益市场趋势预判，在牛市提高转债仓位、在熊市降低仓位。

**仓位调节模式**：
- 权益牛市 → 仓位↑（如2014Q4、2019Q1）
- 权益熊市 → 仓位↓（如2015H2、2016Q1、2020H1）

这种调节能力是可转债策略的核心竞争力，但高度依赖基金经理对权益趋势的判断——判断失误会放大损失。

### Q3: 为什么费率比同类高0.20个百分点？

**结论**：管理费和托管费率处于同类较高水平，导致年度综合费率偏高。

**费率结构**：
```
费率差异 = 该基金1.30% - 同类1.10% = 0.20%
         （主要来自管理费 + 托管费）
```

高费率是竞争劣势——如果同类基金提供类似回报，低费率产品更有优势。

### Q4: 投研团队有什么特点？

**结论**：团队资源丰富，为策略执行提供支撑。

```
投研团队 = 信用研究（20+人，经验>4年）
         + 利率/转债研究（10+人）
         + 权益策略小组
```

祝松担任债券投资一部总经理，带领8名平均经验>8年的投研人员。信用研究按行业和区域分工，实现全面覆盖。

**边界**：团队资源是必要条件，最终还是要看基金经理如何利用这些资源。

## 关键张力

| 张力 | 说明 |
|------|------|
| 费率高 vs 业绩好 | 费率高于同类0.20个百分点但排前14%，扣除费率后是否仍显著优于同类存疑 |
| 转债仓位偏高 | 均15% vs 同类6%，双刃剑：牛市增强、熊市拖累 |
| 团队丰富 vs 个人依赖 | 团队支撑充足，但最终依赖祝松个人判断，存在单点依赖风险 |

## 待确认事项

- 文档时间区间截至2025年2月，需确认祝松当前是否仍在管理该基金
- 转债仓位调节的择时能力是否有独立数据验证，排除运气成分
- 高费率劣势未来是否会影响基金竞争力，是否需要进一步降费
