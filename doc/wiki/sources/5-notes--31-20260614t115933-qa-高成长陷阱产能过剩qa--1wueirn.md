### Main Arguments & Findings

**核心论点**（按 Q 序）：

**Q1** — 高景气度赛道反而亏钱的因果链：
```
高景气 → 资本涌入 → 产能扩张 → 供过于求 → 价格崩塌 → 投资者亏损
```
边界条件：有强进入壁垒（专利/网络效应）或需求真正无限时例外。

**Q2** — 光伏案例数据：
- 2020-2023：供应链产能增长 3.4-4.1×，装机量仅增 2.6×
- 2022年Q4起价格大跌，2024年跌至历史低点

**Q3** — 正确趋势 ≠ 线性增长：
- 资本会把好故事变成泡沫
- "简单且人人认可的事实 + 对社会有益"是最危险的组合

**Q4** — 护城河优先于增速：
- 高增长公司往往护城河最弱（高利润本身是竞争磁石）
- 护城河五大来源：转换成本、无形资产、网络效应、成本优势、有效规模

**Q5** — 识别"注定崩塌"的主题ETF：
```
好 ETF = 宽基 + 分散 + 长期持有
坏 ETF = 窄行业 + 集中 + 短线交易
```
