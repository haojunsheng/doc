# 11月香港互认基金：资金流向分化，求稳→逐险切换

> 晨星中国 QA —— 2025年11月香港互认基金资金流向月报的Q&A结构化解读。

## 核心论点

2025年11月香港互认基金市场出现明显的资金流向分化：高收益债和全球债券持续"失血"，权益类和亚洲债券资金净流入；市场从"求稳"转向"逐险"。瑞士百达策略收益基金以12亿元净流入继续霸榜，摩根亚洲股息基金在股票类中领跑。

|------|------|---------|

## 七问七答

### Q1: 为什么瑞士百达策略收益基金能连续霸榜？

**结论**：全球灵活配置策略在分化市场中具有独特优势——东方不亮西方亮。

**形式化**：
```
瑞士百达 = 全球股债灵活配置（股20-70%、债15-60%）
         → 适应分化市场
         → 连续霸榜
```

**分析**：
- 策略优势：灵活配置于环球股票和固定收益，可根据市场环境动态调整
- 市场环境：2025年全球市场分化，单一资产难以持续领先，灵活配置反而更稳健
- 业绩支撑：年内累计净流入 99.33 亿（行业第一），形成正反馈循环

**边界条件**：
- 若全球市场齐涨或齐跌，灵活配置的超额收益会减弱
- 若基金经理判断失误，仓位调整可能适得其反

→ 详见 [[全球灵活配置策略]]

### Q2: 为什么摩根亚洲股息基金能在股票类中领跑？

**结论**：在"逐险"与"求稳"之间找到平衡——既有资本增长潜力，又有股息收益缓冲。

**形式化**：
```
摩根亚洲股息 = 资本增长（股票）+ 股息收益（债券属性）
             → 风险偏好修复期最佳配置
```

**分析**：
- 产品设计：兼顾资本增长与收益，目标是超越 MSCI 亚太除日本指数 30 个百分点
- 市场环境：投资者风险偏好从"极度避险"修复到"适度逐险"，股息策略正好承接这部分需求
- 业绩验证：2025年回报领先同类，受到投资者大量关注

**边界条件**：
- 若市场进入"极度风险厌恶"，高股息策略会跑输成长股
- 若亚太股市整体下跌，股息收益也难以弥补资本损失

### Q3: 为什么高收益债券和全球债券在"失血"？

**结论**：高收益债对信用风险敏感，全球债对利率敏感，在风险偏好回升时，资金会从避险资产流向逐险资产。

**形式化**：
```
风险偏好 ↑ → 资金从高收益债（信用风险）和全球债（利率风险）
           → 流向权益和亚洲债券
```

**分析**：
- 资金流向：汇丰亚洲高收益债净流出 1.90 亿，摩根国际债券净流出 4.11 亿，排名倒数前三
- 市场逻辑：PMI 回升、政策利好，投资者从"避险"转向"逐险"，高收益债的票息吸引力下降
- 产品特征：高收益债波动大，全球债受海外利率压制，在"股暖债冷"环境中承压

**边界条件**：
- 若经济数据再次恶化或地缘风险上升，资金会重新回流高收益债和全球债
- 若利率大幅下降，全球债会重新受青睐

→ 详见 [[风险偏好抬升]]

### Q4: 为什么中银香港和东亚联丰的亚洲债券基金暂停内地申购，还能吸引资金？

**结论**：离岸投资者的需求依然强劲，说明亚洲债券的票息优势对全球资金仍有吸引力。

**形式化**：
```
内地投资者暂停申购 ≠ 资金停止流入
离岸投资者继续买入 → 亚洲债券需求稳定
```

**分析**：
- 额度限制：两只基金自 10 月底起暂停对内地投资者的申购（内地销售额度耗尽）
- 离岸资金：大量离岸投资者资金继续流入，分别位列流入榜第二和第七
- 产品优势：亚洲债券的票息在全球低利率环境中仍有吸引力

**边界条件**：
- 若离岸投资者也撤资（如美元大幅升值），基金会面临更大的赎回压力
- 若亚洲债券违约率上升，需求会下降

→ 详见 [[离岸与在岸资金分流]]

### Q5: 为什么汇丰 10 月刚转正，11 月又陷入净流出？

**结论**：汇丰的"新基金"在吸金，但"老基金"在失血，整体仍在净流出。

**形式化**：
```
汇丰 = 新基金吸金（汇丰亚洲多元资产高入息基金，9月起销售）
     - 老基金失血（额度耗尽）
     → 整体净流出
```

**分析**：
- 新基金：汇丰亚洲多元资产高入息基金自 9 月面向内地投资者开放，持续吸引新资金
- 老基金：其他互认基金在内地的销售仍受限制（额度耗尽），呈现资金净流出
- 整体效果：新基金吸金不足以弥补老基金失血

**边界条件**：
- 若新基金持续放量销售，可能扭转整体净流出
- 若老基金额度持续受限，净流出可能延续

### Q6: 摩根和汇丰合计占香港互认基金市场 60%，这种"双寡头"格局对投资者意味着什么？

**结论**：头部效应明显，投资者更容易买到"明星基金"，但也可能错过"小而美"的产品。

**形式化**：
```
摩根（806亿）+ 汇丰（341亿）= 60%市场份额
→ 头部集中 + 中小基金公司生存空间被挤压
```

**分析**：
- 规模数据：截至 2025 年 11 月 30 日，两家公司旗下互认基金规模分别达 806 亿和 341 亿
- 市场效应：规模越大，品牌越强，资金越愿意涌入，形成正循环
- 投资者影响：头部公司产品线全、明星基金多，但中小基金公司可能更有创新和灵活性

**边界条件**：
- 若头部公司业绩大幅下滑，投资者可能转向中小基金公司
- 若监管限制头部公司扩张，市场格局可能改变

→ 详见 [[头部稳固-腰部竞争激烈]]

### Q7: 东方汇理新增两只混合型基金，为什么市场反响平淡？

**结论**：新基金需要时间建立业绩记录和品牌信任，在"老基金"已经占据市场注意力时，新基金难以快速吸引资金。

**形式化**：
```
新基金 = 缺乏业绩记录 + 缺乏品牌认知
       → 市场反响平淡

老基金 = 业绩亮眼 + 品牌信任
       → 资金持续流入
```

**分析**：
- 市场环境：2025 年 11 月新增两只混合型互认基金（东方汇理灵活配置均衡/平稳基金）
- 投资者心理：在"明星基金"已经占据市场注意力时，新基金需要时间证明自己
- 历史规律：新基金通常需要 1-3 年的业绩记录才能获得投资者信任

**边界条件**：
- 若新基金在 2026 年做出亮眼业绩，可能快速吸引资金
- 若业绩平平，可能持续边缘化

→ 详见 [[新基金冷启动周期]]

## 收口

资金流向是市场情绪的"晴雨表"——当风险偏好回升时，资金从高收益债和全球债（避险）流向权益和亚洲债券（逐险），而"全球灵活配置"策略在分化市场中展现出独特优势，能同时捕捉股债机会。
