# 概念解剖 — 分类比较的方法论

**来源笔记**：概念解剖 — 分类比较的方法论
**来源文章**：年末基金"大考"即将放榜！一招教你看懂晨星基金排行榜
**分析日期**：2026-06-14

## 核心主张

基金评价的关键不是"绝对收益"，而是"在正确的比较组中表现如何"。晨星通过资产类别、投资风格、市值规模三个维度的细致分类，为基金提供了一个"公平竞技场"，使同类基金之间的比较才有意义。

## 三层分类逻辑

```
第一层：资产类别分组（股票 / 债券 / 货币 / 商品）
第二层：投资风格分组（大 / 中 / 小盘 × 价值 / 平衡 / 成长 = 九宫格）
第三层：同类内排名（星级评价）
```

## 关键论点

### 1. 冠军魔咒的机制

当年霸榜基金的优异表现往往源于"押中某一风格"，而非持续选股能力。市场风格轮动后，曾经的顺风必然变成逆风，导致次年大幅回落。晨星分类的价值在于帮助投资者识别：收益来自"能力"还是"运气"（即风格带来的 β 收益）。

### 2. 隐喻框架

文章使用"大考"和"放榜"的教育隐喻，将基金业绩排名比作学校考试。核心信息：**不要只看总分，要看哪个科目得了多少分**。全市场排名是"总分"，分类比较是"分科得分"。

### 3. 分类的局限

分类只能"部分过滤"风格影响。同一分类内在行业配置、集中度、换手率等方面仍有很大差异。九宫格的简洁秩序与现实基金的灰色地带之间存在张力——有些基金横跨多个分类，风格会漂移，分类边界不是绝对的。

### 4. 存在性意义

分类比较帮助投资者对抗"从众本能"。当某只基金登上排行榜榜首时，买入一只"风格冠军"本质上是在买入一种市场趋势——而趋势终会逆转。

### 5. 权力结构与元反思

基金评价本质上是一种权力结构——它决定了哪些基金被关注、哪些基金被忽视。排行榜本身会改变投资者的行为，从而改变资金流向，进而影响基金表现。晨星分类试图通过"细化分类"减少这种扭曲，但基金经理也可能为了"符合分类"而放弃灵活性。
