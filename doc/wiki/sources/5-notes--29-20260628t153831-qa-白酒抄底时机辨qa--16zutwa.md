# 白酒抄底时机辨 — QA

来源：[[晨星中国]]，晨星文章《白酒抄底时机辨》，2026-06-28。

核心判断：**白酒抄底为时尚早，高端化是最后支撑。**

## 核心结论

白酒板块从 2021 年高点至今已跌近四年，股价几乎腰斩，但基本面未见底。供需格局决定行业底部尚未到来。

### 需求端：结构性恶化，非周期性波动

- 2017 年起生育率下降，饮酒人群萎缩，年轻人饮酒率持续走低
- 人口结构变化是**长期不可逆因素**，不是短期波动

### 供给端：仍在扩张，供需失衡加剧

- 前 20 大酒企计划十年内产能增加 ≥50%
- 行业收入 CAGR 仅 3.5%，远低于扩产速度
- 供需失衡将持续压制估值

### 唯一支撑：高端化提价

- 高端三家（茅台、五粮液、泸州老窖）占行业 95% 份额
- 以价格增长对冲销量下滑，维持收入增长
- 但提价**能保利润，保不住估值**

### 茅台的例外性

- 出厂价 1169 元仍"一瓶难求"，渠道利润巨大
- 供需格局与其他白酒本质不同：茅台供不应求 ⊥ 其他白酒产能过剩+竞争定价
- **不能将茅台的稀缺性泛化为行业整体机会**

## Q&A 要点

### Q1：白酒过去为什么涨那么猛？

核心逻辑是供不应求：窖池和陈酿周期限制产能 + 品牌溢价 + 政务/商务需求驱动。

```
产能受限 × 品牌护城河 × 需求旺盛 → 供不应求 → 价格↑ → 利润↑
```

前十大企业占 54% 份额，高端三家占 95%——集中度极高。

### Q2：白酒的护城河有多宽？

来源于无形资产：**品牌积累 + 工艺/窖池独特性**，转化为定价权。

晨星将护城河分为宽（20年以上）和窄（10年以上），茅台、五粮液、泸州老窖堪拓宽护城河。

边界：健康意识提升或社交文化变迁可能侵蚀品牌溢价。

### Q3：这轮周期为何不同？

旧周期：量价齐升；新周期：量跌价升（提价补量）。

```
旧周期：量↑ 价↑ → 新周期：量↓ 价↑（提价补量）
```

### Q4：为什么酒企还在扩产？

两个逻辑：满足升级需求（少喝但喝好）+ 抢占市场份额。

```
扩产（供应 +50%）≫ 需求增速（3.5%）→ 供需失衡加剧
```

### Q5：未来增速有多少？

晨星预计未来十年收入 CAGR 3.5%，低于过去十年的 4.2%。

```
销量增长↓ + 价格增长↑ → 行业收入 CAGR = 3.5%（从 4.2% 下降）
```

### Q6：现在能抄底吗？

不能。股价腰斩 ≠ 见底，需求端压力未出清，扩产周期刚起步，供需再平衡需要时间。

### Q7：茅台与其他的本质区别？

```
茅台：供不应求 + 超强定价权 ⊥ 其他白酒：产能过剩 + 竞争定价
```

茅台出厂价 1169 元，终端渠道加价空间巨大，是"一瓶难求"的稀缺品。

## 收口

跌了四年不等于便宜，基本面还没见底。人口结构+年轻人饮酒率下降是长期逆风，扩产还在路上，唯一的希望是高端化提价能否跑赢量缩。
