# QA — 基金翻倍业绩不可持续的底层原因

来源：[Morningstar China](https://www.morningstar.cn/articles/2557de1abe723b94b8ccb8f4cc51f2a2.html)
Date：2026-06-14

## 核心论点

2025年有85只基金收益率翻倍，但历史数据揭示了一个残酷真相：基金的短期业绩接近随机游走，翻倍业绩更多是"押中行业"的运气而非基金经理的能力。

### Q1：一年翻倍的基金，到底做对了什么？

**不是能力，是押注**——把90%以上的仓位集中在当年表现最好的两个行业上。

形式化：`翻倍基金 = 90%仓位 × 当年最佳行业（如通讯80%+涨幅） → 业绩翻倍`

实证案例：永赢科技智选90%+仓位在通讯和电子，前十大集中度90%，业绩翻两倍。2025年沪深300涨20%，但通讯和有色金属涨超80%，全仓这两个行业即可翻倍。

**边界**：若当年没有极端行业分化，或者押错了行业，这种策略会亏得很惨。

### Q2：为什么前一年排前四分位的基金，下一年大概率排不回去？

**行业轮动是常态，能年年押中下一年最强行业的人几乎不存在**。"行业找到了基金"而非"基金找到了行业"。

形式化：`今年前25% → 明年继续前25%的概率 = 28-30% ≈ 随机概率25% → 业绩持续性≈0`

2011-2025年15年数据，主动基金和被动基金均呈现同等随机性。

**边界**：若基金经理具备真正的行业轮动能力（极罕见），可能打破这个规律。

### Q3：为什么"连胜"三年后概率暴跌到3%？

**三年时间足以覆盖完整的行业轮动周期**，押中一次容易，连续押中三次的概率接近零。

形式化：`单年前25%概率 = 30% × 连续三年 = 30%³ ≈ 3% → 概率暴跌`

### Q4：为什么糟糕的业绩反而有持续性？

**好业绩靠运气（押中行业），差业绩靠实力（能力不足或风格严重错配）**，所以输家更容易持续输。

形式化：`前25%基金 → 下一年各四分位概率均等（随机） vs 后25%基金 → 下一年继续后25%或被清盘概率更高（非随机）`

投资策略启示：**避开输家比追逐赢家更有确定性**。

**边界**：若差业绩是暂时的市场风格错配（如价值基金在成长牛市中），可能反转。

### Q5：行业基金也逃不出"业绩随机性"

即使投资范围限定在单一行业，细分板块的轮动同样难以持续预测。

形式化：`行业基金 = 行业β + 选股α → 行业β随轮动变化，选股α不稳定 → 业绩随机`

### Q6：投资者为什么容易被"翻倍基"伤害？

**买入时预期过高，业绩波动时心态崩溃，追涨杀跌导致实际收益远低于基金净值涨幅**。

形式化：`看到翻倍业绩 → 高预期买入 → 业绩回归均值 → 心态崩溃赎回 → 实际收益 << 基金净值涨幅`

与 [[近因效应]] 和 [[前景理论]] 高度呼应。

### Q7：怎么正确使用历史业绩来选基金？

**看完整周期（至少3-5年），看业绩归因（钱是怎么赚的），看基金经理经验（是否经历过多轮牛熊）**。

形式化：`选基金 = 完整周期表现（3-5年）∩ 业绩归因清晰（不是纯行业押注）∩ 基金经理经验（多轮牛熊）`

## 关键数据摘要

| 指标 | 数值 | 含义 |
|------|------|------|
| P(前25% → 继续前25%) | 28-30% | 与随机25%相近，非能力 |
| P(连续3年前25%) | ≈3% | 30%³，行业轮动周期不可预测 |
| 翻倍基金行业集中度 | 90%+ | 本质是行业押注 |
| 输家持续性 | 更高概率继续垫底/清盘 | 能力问题的真实反映 |
