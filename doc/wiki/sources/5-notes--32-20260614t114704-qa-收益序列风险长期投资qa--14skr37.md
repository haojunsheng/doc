## Main Arguments & Findings

**核心主张**：长期投资的真正敌人不是"涨了跌回来"，而是**收益出现的顺序本身**——在有持续资金进出的场景下，基金净值的 TWR 与投资者的实际 IRR 可以截然不同。

### 证据与形式化表达

**Q1 的数值证据（形式化）**：
```
三年回报 +10%、+10%、-10%，基金 TWR 年化 = 2.88%

先涨后跌：IRR = -0.35%（亏损）
先跌后涨：IRR = +6.4%（盈利）

差距：6.75 个百分点
```

**Q2/Q3 的生命阶段非对称性**：
```
同样 -60% 跌幅：
  40 岁账户 2-3 万 → 绝对亏损小 → 可修复
  临近退休账户 30 万 → 绝对亏损大 → 永久性损伤

原因：下跌 × 账户规模 = 真实伤害
```

**Q5 水桶策略机制**：
```
无缓冲：市场跌 → 生活费不够 → 被迫卖跌中股票 → 永久本金损失
有缓冲：市场跌 → 生活费从现金桶出 → 股票仓不动 → 等反弹
```

**Q6 的核心论断**（最重要的一条）：
> "投资理财的终极风险，是你一生在支出上的不确定性。"
> 序列风险 = 市场波动 × 取款时点——两者均不完全可控，因此投资管理只能缓解，无法消除。

### 证据强度评估

- **数值示例**：基于假设数据的数学推演，逻辑自洽，但缺乏跨市场实证引用
- **2008 年案例**：单一历史事件的外推，方向可信但幅度不可直接复制
- **Q6 的开放性结论**：诚实且深刻，承认了投资科学的边界，这是本文最有价值的一处认知升级

## Contradictions & Tensions

1. **与损失厌恶直觉的冲突**：Q3 表明"年轻时遇到下跌是好事"——这与普遍的风险厌恶直觉相反，但与数学一致。wiki 中已有对此的标注，无需额外处理。

2. **与"长期投资=买入持有不动"的冲突**：本文击穿了这个幻觉——在有资金进出的场景下，"躺平"不是最优策略。这与 wiki 中 `time-weighted-return-vs-money-weighted-return` 的概念一致，但本文将其推向更深的结论：长期投资需要主动管理资金流顺序。

3. **Q6 的自我限制**：文章承认水桶策略只能缓解 1–2 年，无法覆盖更长熊市。这一诚实的边界声明与 wiki 中水桶策略页面的局限部分一致，但 Q6 进一步将问题上升到"人生支出不确定性"层面，超越了单纯的投资管理范畴。
