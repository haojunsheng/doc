# 新发基金五维度筛选法 QA

来源：晨星文章《新发基金五维度筛选：别让热度遮住眼睛》

## 核心框架

晨星提出用五个维度筛选新发基金，帮助投资者在缺乏历史业绩的情况下，基于公开信息做出判断：

1. **竞争优势（独特性）**：策略是否有实质差异化，而非仅贴标签
2. **投资本质**：区分结构性主题与短期炒作主题
3. **基金经理经验**：看相关经验而非总从业年限
4. **组合逻辑**：从招募说明书推断风格
5. **持基成本**：费率是筛选硬指标

## 关键结论

### Q1 新基金的"独特性"检验
- 仅宣称 GARP 策略的基金与存量基金无实质差异
- 叠加估值考量 + 宏观中观判断融入自下而上选股，才形成真正差异化
- 边界：若某分类存量基金极少（如首批 REITs），"独特性"来自赛道覆盖而非策略创新

### Q2 主题基金清盘率
- 晨星全球研究：多数主题基金未跑赢宽基指数
- 15 年内超 60% 主题基金已清盘
- 2021-2022 元宇宙主题基金靠炒作维持热度后商业化路径不清晰
- 边界：长期结构性主题（碳中和、人口老龄化）逻辑不同于短期炒作

### Q3 基金经理相关经验原则
- 15 年证券从业但可转债投管经验仅 2 年 → 经验可信度低
- 应查其在管组合长期业绩、回撤、波动及言行一致性
- 边界：跨资产类别转换时，过往业绩不构成新类别能力证据

### Q4 招募说明书风格推断
- "长期价值买入持有" → 稳健风格
- "灵活战术配置" → 灵活风格
- 边界：说明书是承诺而非保证，基金经理可能漂移

### Q5 费率作为硬指标
- 晨星《费率解码》研究显示：低费率基金存活概率和跑赢同类概率均更高
- 高费率必须证明创造了相应价值
- 边界：若高费率基金经理确实长期稳定跑赢基准，高费率可被容忍

### Q6 浮动费率的双刃剑
- 证监会《推动公募基金高质量发展行动方案》鼓励浮动费率
- 可变部分与业绩和持有期限挂钩，强化利益绑定
- 边界：若挂钩基准设置过低，基金公司仍可轻松获取超额报酬

### Q7 新基金避坑方法
- 用公开信息做尽职调查：策略、经理、组合逻辑、费率、独特性
- 五个维度彼此独立又互补
- 摒弃短期投机心理，以长期视角评估

## 内在张力

1. 说明书可推断风格，但说明书本身不可完全信赖——与 [[风格漂移识别]] 的核心担忧一致
2. 费率越低越好，但高费率可被容忍——削弱了"硬指标"的绝对性
3. 60% 主题基金清盘，但结构性主题例外——缺乏区分两者的操作标准

晨星是一家国际知名的独立投资研究公司，在公募基金评级、费率研究和投资组合分析领域具有广泛影响力。

# 新基金五维度筛选法

晨星提出的新发基金评估框架，帮助投资者在缺乏历史业绩的情况下，用公开信息做出判断。

## 五维度框架

| 维度 | 核心问题 | 评估方法 |
|------|---------|---------|
| 竞争优势（独特性） | 策略是否有实质差异化？ | 检视是否仅贴标签，还是叠加了估值+宏观中观融合 |
| 投资本质 | 是结构性主题还是短期炒作？ | 区分长期趋势（碳中和、人口老龄化）与热点概念（元宇宙） |
| 基金经理经验 | 经验是否相关？ | 看与所投资产类别直接相关的投管经验，而非总从业年限 |
| 组合逻辑 | 风格是稳健还是灵活？ | 从招募说明书措辞推断，核对投资范围与宣称目标一致性 |
| 持基成本 | 费率是否合理？ | 低费率基金存活和跑赢概率更高；高费率需证明阿尔法 |

## 形式化表达

```
GARP策略 = 同质 ‖ GARP + 估值 + 宏观中观融合 = 差异
热门概念炒作 → 热度消退后业绩↓ → 60%清盘
15年从业 ⊥ 年仅2年可转债经验 → 经验可信度低
"长期价值买入持有" → 稳健 ‖ "灵活战术配置" → 灵活
费率↓ → 存活概率↑ + 跑赢概率↑
```

## 边界条件

1. **独特性边界**：若某分类存量基金极少（如首批 REITs），"独特性"来自赛道覆盖而非策略创新
2. **主题边界**：长期结构性主题（碳中和、人口老龄化）逻辑不同于短期炒作，不应归入"60%清盘"结论
3. **跨资产边界**：基金经理跨资产类别转换时，过往业绩不构成新类别能力证据
4. **说明书局限**：招募说明书是承诺而非保证，基金经理可能在实际操作中漂移
5. **费率容忍**：若高费率基金经理确实长期稳定跑赢基准并创造阿尔法，高费率可被容忍

## 内在张力

1. 说明书可推断风格，但说明书本身不可完全信赖——与 [[风格漂移识别]] 的核心担忧一致
2. 费率越低越好，但高费率可被容忍——削弱了"硬指标"的绝对性
3. 60% 主题基金清盘，但结构性主题例外——缺乏区分两者的操作标准

## 与其他概念的关系

- [[费率复利效应]]：Q5 低费率论证与此互补，共同支持费率作为筛选硬指标
- [[主题基金存活率模型]]：Q2 主题基金清盘数据可直接补充该页
- [[GARP均衡派]]：Q1 策略差异化讨论可与此页互链
- [[基金经理换手率评级]]：Q3 基金经理经验评估可与该页并列为选基维度

# 浮动费率

浮动费率是指管理费与基金业绩和持有期限挂钩的收费模式，是证监会鼓励的改革方向。

## 政策背景

证监会《推动公募基金高质量发展行动方案》明确鼓励浮动费率模式，旨在强化基金公司与投资者的利益绑定。

## 机制设计

```
浮动费率 = 固定费 + 业绩挂钩浮动部分
         → 激励基金公司追求长期业绩
         → 引导投资者关注基准合理性
```

可变部分通常与以下两个维度挂钩：
1. **业绩表现**：基金相对基准的超额收益
2. **持有期限**：持有时间越长，浮动部分可能越低或结构越优

## 优势

- 理论上激励基金公司追求长期业绩，而非规模扩张
- 强化基金公司与投资者的利益绑定
- 引导投资者关注持有期限，减少短期交易行为

## 风险与边界

- **基准设置风险**：若浮动费率挂钩的基准不合理（如过低），基金公司可能轻松获取超额报酬
- **计算透明度**：投资者需清楚了解收取方式和时点
- **双刃剑效应**：浮动费率对投资者是好事还是坏事，取决于基准合理性和计算方式透明度

## 与新基金筛选的关系

浮动费率是新基金五维度筛选法中"持基成本"维度的政策延伸。[[新基金五维度筛选法]] Q6 对此有详细讨论。

## 开放问题

1. 浮动费率的挂钩基准如何设定才算合理？是否有量化参考线？
2. 实际落地中，基准设置是否存在系统性偏低倾向？
