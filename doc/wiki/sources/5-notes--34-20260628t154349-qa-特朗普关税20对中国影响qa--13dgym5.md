# QA — 特朗普关税2.0对中国影响：关税战2.0整体可控，家电电车跨境电商分化

晨星中国对特朗普对华加征10%关税的整体影响进行分析，结论：**整体冲击可控，大部分企业受影响不超过总营收5%，但行业间分化显著**，海外布局早的家电冲击弱，出海初期的新能源车冲击强，烧钱模式的跨境电商反而可能受益。

## 核心结论

- **Q1 整体评估**：晨星测算大部分中国企业受影响 ≤ 总营收5%，但市场情绪波动可能放大短期震荡，真正危险的是恐慌而非关税本身。
- **Q2/Q3 家电分化**：美国本地产能占比是核心变量。海尔（美国销售30%、其中60%本地生产）冲击极小；美的（美国营收7-8%、仅5%本地生产）相对受冲击更大。
- **Q4 新能源车**：比亚迪北美营收占比5-10%，关税上调拖慢海外扩张；电池龙头（[[宁德时代]]、国轩高科）出口市场更多元，可调整结构；上游锂矿因需回国内加工，潜在冲击更大。
- **Q5 跨境电商Temu**：处于"烧钱补贴抢市场"阶段，关税导致订单减少 = 补贴减少 = 亏损收窄，反而是利好（边界：若已进入盈利阶段则纯属负面）。
- **Q6/Q7 应对策略**：区分情绪波动与基本面恶化；做好分散配置；短期波动中寻找被错杀的优质公司。

## 形式化推理链

```
关税影响程度 = f(美国本地产能占比, 营收依赖度, 商业模式阶段)

家电行业（海外建厂+转口贸易）: 冲击 ≈ 0
新能源车（北美依赖+扩张期）:    冲击 > 0，盈利增速承压
烧钱电商（补贴抢份额阶段）:    冲击 < 0（反向利好）
```

## 关键数据

| 公司 | 美国营收占比 | 美国本地产能占比 | 关税冲击评估 |
|------|------------|---------------|------------|
| 海尔 | ~30% | 60% | 极小 |
| 美的 | 7-8% | 5% | 中等 |
| 比亚迪 | 5-10%（北美） | 极低 | 较大 |

## 边界条件

- 若关税税率进一步升级或范围扩大，影响非线性放大
- 若美国收紧原产地规则，家电转口贸易优势减弱
- 若Temu进入盈利阶段，订单减少即为纯负面
- 若关税引发全球系统性风险，分散配置也无法完全避险
