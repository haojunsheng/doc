# QA — 止盈与收益序列风险

> 长期投资的"止盈"不是猜市场，而是理解收益序列风险，根据人生阶段做出战略调整。

## 核心论断

短期止盈本质是择时，具有高风险；长期"止盈"应理解为基于人生阶段的资产配置调整，是必要的风险管理工具。两者的关键区别在于驱动因素——情绪预测 vs 纪律规划。

## Q1: 为什么短期止盈是危险的？

**结论**：无法判断卖点 + 再入场成本高 + 可能错过上涨。

```
短期止盈 = 难以卖在高点 + 不确定何时再入场 + 可能错过上涨
```

**边界**：有明确短期资金需求（如买房）除外，但这属于资金规划而非投资策略。

## Q2: 什么是收益序列风险？

**结论**：同样的平均收益率，收益发生的顺序不同，最终结果差异巨大。

```
收益序列风险 = f(市场回报 × 时间 × 资金流)
```

**数值示例**：三年回报均为 +10%、+10%、-10%，基金年化 TWR = 2.88%，但：
- 先涨后跌 → IRR = -0.35%
- 先跌后涨 → IRR = +6.4%
- 差距 6.75 个百分点

**边界**：收益序列风险对一次性投入影响最大；定投可部分平滑，但不能完全消除。

## Q3: 为什么临近退休的人最怕收益序列风险？

**结论**：退休后既要支取生活费，又遇市场下跌，账户修复极其困难。

```
退休 + 市场下跌 + 持续支取 = 永久性损失
```

退休者账户规模大、持续支取，早期下跌迫使以低净值赎回更多份额，后续上涨的本金基础已大幅缩水。

**边界**：有其他收入来源（如养老金）可降低对投资组合的依赖，从而降低收益序列风险影响。

## Q4: 为什么年轻人反而不太怕收益序列风险？

**结论**：账户规模小 + 持续定投 = 前期亏损对长期结果影响有限。

```
年轻 + 账户规模小 + 下跌 = 损失有限 + 定投成本摊低
```

示例：2008 年大跌时开始定投，坚持到 2025 年退休，账户可达 32 万元；同样金额若大跌发生在临近退休，仅 14 万元。

**边界**：年轻人在市场高点一次性投入大量资金时，仍会面临较大的收益序列风险。定投不是万能护盾，资金来源方式（一次性 vs 分期）是关键变量。

## Q5: 怎么管理收益序列风险？

**结论**：在退休前逐步调整资产配置，增加稳健资产比例。

```
管理收益序列风险 = 临近退休 + 降低风险资产比例 + 增加债券/现金
```

这不是择时，而是基于人生阶段的战略调整。债券波动比股票小，可在股市下跌时起到缓冲作用。

**边界**：全部转为保守资产可能无法抵御通胀；关键是找到适合自己的平衡点。

## Q6: "水桶策略"怎么应对收益序列风险？

**结论**：将未来 1-2 年生活费单独存放现金桶，避免被迫在低点卖出投资资产。

```
水桶策略 = 短期现金（1-2 年生活费）+ 长期投资（继续增值）
```

市场下跌时，从现金桶支出生活费，无需卖出风险资产，给投资组合更多时间等待回升。

**边界**：现金有通胀侵蚀成本，需在安全与收益间平衡。

## 与止盈陷阱的关系

[[止盈陷阱]] 描述了机械止盈的结构性亏损：赢时赚得少，输时亏得多。本文进一步指出，机械止盈不仅造成盈亏不对称，还可能**恰好卖在收益序列最不利的位置**——在早期上涨后卖出，陷入"先涨后跌"的不利序列，使收益序列风险与止盈陷阱双重叠加。

本文的核心贡献在于重新定义"止盈"：短期止盈是择时（有风险），长期止盈是资产配置调整（有必要）。[[规则对抗本能]] 提供了执行层面的方法论——用预设规则对抗止盈冲动。
