# 基金经理布局 QA

## 核心论点

2026年A股没有统一答案，选股比追风格更重要。

五位不同风格基金经理的共识：A股大幅下行风险小，但上涨节奏取决于政策和资金，选股能力比风格判断更重要。

## 2025年风格回顾

中盘成长（有色/通信/电子/电力设备）平均收益41.99%，大盘价值（食品饮料/地产/煤炭）仅8.75%。中证500（中盘）全收益显著跑赢沪深300（大盘）。

形式化：
```
中盘成长（有色/通信/电子/电力设备）↑ ⊃ 大盘价值（食品饮料/地产/煤炭）↓ ⊃ 41.99% vs 8.75%
```

## 各基金经理观点

### 徐荔蓉：长牛慢牛基础已建立

四大因素支撑慢牛：国家队/险资占比↑ + 外资低配↑ + 回购分红↑ + 经济结构多元 → 慢牛长牛

边界条件：若政策定位发生逆转或外资大规模撤离，慢牛基础可能被削弱。

### 周蔚文：年中经济才可能企稳

工业产能利用率↓ + 地产销售↓ + 消费就业↓ + 新兴产业基数小 → 经济企稳需待年中

边界条件：若政策超预期发力或外部环境改善，经济企稳可能提前。

### 綦缚鹏：风格从两端向中间切换

低利率 → 债/地产吸引力↓ → 股票性价比↑ → 居民: 利息→股息 → 风格: 两端→中间

边界条件：若利率大幅上行或股市波动过于剧烈，资金可能重新回流固收。

### 桑磊：极致分化是最大风险

少数行业领涨 × 赚钱效应不扩散 → 极致分化 → 市场情绪↓ → 风险积累↑

看好方向：内需板块（食品饮料/旅游/酒店/航空/地产）——估值低+政策敏感

边界条件：若政策未达预期或内需持续低迷，这些板块可能继续承压。
