# 五月股债分化下的基金选择 QA

> 晨星 2025年5月基金月报 QA，聚焦"股强债弱"分化格局下各类基金的表现与选择逻辑。

## 核心结论

5月出现典型的**股强债弱**分化格局：A股主要指数涨 1-2%，中证全债指数微跌 0.06%。可转债基金表现最佳（+1.75%），利率债基金微跌（-0.19%）。

## Q1：5月股债分化的直接触发因素

- **A股驱动**：中美关税缓和（外部） + 央行降准降息（内部） → 主要股指涨 1-2%
- **债市压制**：关税缓和→资金从债市流向股市（利空） + LPR 降息已充分定价（利多有限）
- **结果**：国债收益率短端↓5bp，长端↑5bp，形成**收益率曲线陡峭化**

> 边界：若中美摩擦重新升级或央行收紧流动性，股债分化格局可能逆转。

## Q2：为什么信用债表现远好于利率债？

| 指标 | 变动 |
|------|------|
| 1年期AAA收益率 | ↓9bp |
| 1年期AA收益率 | ↓10bp |
| 中证企业债指数 | +0.43% |
| 中证中票指数 | +0.43% |
| 中证短融指数 | +0.17% |
| 中证国债指数 | -0.19% |

机制：资金面宽松 + **信用利差收窄**，信用债收益率下行幅度远大于利率债。

> 边界：若经济超预期恶化导致信用风险上升，信用利差可能走阔，此时利率债反而更抗跌。

## Q3：行业基金内部为何分化？

| 行业 | 涨幅 | 驱动因素 |
|------|------|---------|
| 环保 | +6% | — |
| 医药生物 | +6% | 创新药政策 |
| 国防军工 | +6% | — |
| 银行 | +6% | 公募新规 |
| 纺织服饰 | +6% | — |
| 电子 | -2% | 行业周期下行 |

形式化表达：**行业分化 = f(产业政策, 行业周期)**。

> 边界：若政策转向或行业周期切换，行业分化格局可能逆转。

## Q4：全球市场为什么集体收涨？

- 标普 +6.15%：美国 PMI 53.0%（荣枯线之上），经济强劲
- 日经 +5.53%：风险偏好提升
- 恒生 +5.29%：港股跟随A股回暖
- 布伦特原油 +2.57%：中东冲突推动能源价格，但欧股仍涨（其他因素更强）
- 黄金 +0.51%：部分资金从欧股流向避险资产

> 边界：若中东冲突升级或美联储推迟降息，全球收涨格局可能逆转。

## Q5：可转债基金为什么又是表现最好的？

**可转债双重属性**在分化市中发挥优势：

- **股性**：A股涨 1-2% → 转股价值上升 → 转债价格上涨
- **债性**：短端利率↓5bp → 债底稳固，提供下行保护

结果：中证转债指数 +1.75%，所有券种中表现最佳。

与历史序列对比：
- 4月：可转债延续强势
- 5月：股强债弱分化，转债 +1.75%
- 6月：股债双收，转债 +3.34%
- 11月：股债双杀，转债 -0.69%

> 边界：若 A 股回调但债市继续下跌，可转债基金的股性和债性都会承压。

## Q6：固收+产品投资者应如何理解5月数据？

在"股强债弱"格局中：

| 产品类别 | 5月表现 |
|---------|--------|
| 偏股基金 | +5-6% |
| 可转债基金 | +1.75% |
| 固收+ | 居中 |
| 利率债基金 | -0.19% |

核心结论：**固收+产品需要更高的权益暴露才能跑赢纯债基金，但也要承担更高的波动。**

形式化：
- 股强债弱时 → 权益暴露越高越好
- 股弱债长时 → 权益暴露越低越好

> 边界：若后续股债分化加剧（如6月"股债双收"或7月"股涨债跌"），固收+表现将取决于权益暴露度。需追踪验证此判断。

## Q7：短端与长端利率债为何分化？

| 品种 | 变动 | 驱动 |
|------|------|------|
| 1年期国债 | ↓5bp | 资金面宽松（降准降息） |
| 5/10年期国债 | ↑5bp | 风险偏好提升（关税缓和） |

机制：**收益率曲线陡峭化** = 短端↓ + 长端↑。与2月平坦化形成对比，5月是典型的"政策宽松 + 风险偏好提升"同时作用的案例。

> 边界：若央行进一步降准降息，长端利率也可能下行；若风险偏好下降，长端利率反而会下行。

## 价值要点

晨星5月月报的核心价值：用"股强债弱"分化格局展示不同基金类别的表现差异，提醒投资者关注后续分化风险——**权益暴露越高，股强时弹性越大，股弱时回撤也越大**。
