# 伴读：06 | 感光度 (ISO) 与其他相机参数

**来源**：极客时间《摄影入门课》第 6 讲  
**作者**：小麥  
**日期**：2026-07-26

## 一句话摘要

ISO 是传感器对光的敏感程度——调高它可以在不改变光圈/快门的情况下提亮画面，但代价是噪点；白平衡解决"白色是不是真的白"，宽容度解决"明暗差距大的场景能不能都拍清楚"，HDR 是对宽容度的软件补偿。

## 核心论点

### 曝光三角正式闭环

光圈（空间维度/进光量）+ 快门（时间维度/曝光时长）+ ISO（信号维度/传感器灵敏度），三者共同决定画面明暗与视觉效果。这是全文的结构核心——前三课（光圈、焦段、快门）在此交汇。

```
光圈：控制进光量（空间维度）
快门：控制曝光时间（时间维度）
ISO：控制传感器灵敏度（信号维度）

三者共同决定：画面有多亮 + 画面是什么效果
```

### ISO 是最后的逃生通道，而非首选方案

当光圈和快门都被场景锁定（街拍时既需小光圈保景深、又需快快门防糊片），ISO 是唯一还能动的变量，但代价是噪点。文中明确建议熟悉自己相机的高感上限。

### "准确曝光"≠"正确曝光"

相机的测光以 18% 灰为数学基准（准确），但美学上"正确"的曝光可能是故意过曝或欠曝——这取决于摄影师想传达什么。这与白平衡段落中"绝对的'颜色正确'是个假命题"是同一个认识论立场。

### RAW 是宽容度的载体

宽容度是传感器硬件属性，但 JPEG 会"杀掉"宽容度——只有 RAW 才能体现传感器真实宽容度。大光比场景（日落、室内窗口）必须用 RAW。

## 关键区分：曝光补偿 vs ISO

| | 曝光补偿 | ISO |
|---|---|---|
| 是什么 | 指令（目标偏移） | 物理参数（传感器灵敏度） |
| 副作用 | 无直接（由实现方式决定） | 直接带来噪点 |
| 实现 | 相机自动选（改快门/光圈/ISO） | 你直接改 |
| 使用场景 | "相机测的不对我想要更亮" | "光圈快门都锁死了必须提亮" |

**核心区别**：曝光补偿是"我要亮一档"（甩锅给相机）；ISO 是"传感器调亮一档"（你亲自下场）。

- 大多数情况用曝光补偿：相机选快门通常比提高 ISO 更安全
- 快门被锁死时调 ISO：快门必须 1/500s、光圈已最大 → 曝光补偿没用 → 只能调 ISO

## 历史背景：DIN → ASA → ISO

- **DIN**（Deutsches Institut für Normung）：德国对数感光度制，如 21°
- **ASA**（American Standards Association）：美国线性感光度制，如 400
- **ISO**（International Organization for Standardization）：国际标准化组织，把两者捏合

ISO 400/27° 里的"400"是 ASA，"27°"是 DIN。现代相机只显示 ASA 整数，因为更直观。

## 其他附录知识点

- **白平衡**：让白色在任何光源下都是白色，用 K 值（开尔文）表示色温，K 越大越暖（黄），K 越小越蓝（冷）
- **RAW vs JPEG**：RAW = 传感器原始数据（未渲染）；JPEG = 相机算法渲染后输出（颜色艳丽但后期空间小）
- **宽容度（Dynamic Range）**：传感器能容纳的亮度反差范围，硬件属性，与 ISO 无关
- **HDR**：多帧合成（欠曝+正常+过曝）补偿传感器宽容度不足的软件方案

## 认识论洞见

> 相机永远在"计算"现实，不是"记录"现实。理解这一点，你就不会再纠结"RAW 才是真实"——RAW 也是经过传感器色彩滤镜、模数转换、去马赛克算法"计算"出来的。

真正的诚实不是追求"绝对真实"，而是**知道自己的工具在做什么，然后主动选择**。
