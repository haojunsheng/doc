# QA — 定投真能熨平波动吗：一次性买入碾压定投

来源：晨星中国（https://www.morningstar.cn/articles/79e530dc1a159ade0280727840b0f56a.html）

## 核心命题

定投被包装成"普通人最好的投资方式"——熨平波动、提高收益、降低风险。但晨星用2005-2026年的历史数据回测发现：**在超过一半的时间里，分批定投跑输一次性买入，且定投时间越长，跑输概率越高。**

## 形式化结论

### Q1：为什么分批定投在大多数时候跑输一次性买入？

```
趋势向上市场：早投入 = 多收益
分批投入 = 部分资金迟到 → 整体收益↓

证据：2005-2026年任意月份投资沪深300，正收益概率55%-95%
      5年期定投有72%概率跑输一次性买入
      10年期上升到83%跑输
```

### Q2：定投在什么市场环境下才能跑赢？

```
定投赢的场景：持续下跌熊市 或 先跌后反弹但整体≤0
难点：这种行情恰恰最难坚持定投
```

### Q3：定投能降低波动风险吗？

```
一次性买入 = 全部资金暴露于波动
分批定投 = 部分资金暴露 + 部分现金 → 波动↓
代价：牺牲账户收益换取更低波动
```

### Q4：为什么定投和一次性买入在"已投入资金"赚钱效率上没有显著差异？

```
定投 ≈ 每月一次一次性买入
IRR（已投入资金效率）≈ 买入持有
日常定投是每月从工资中拿出一部分投入，等于每月做一次"及时投资"
```

### Q5：定投真正的价值是什么？

```
定投价值 ≠ 收益提升
定投价值 = 强制纪律 + 持续在场 + 尽早投入
真正降低亏损风险的是"时间"而非"定投"——持有期限越长，亏损概率越低
```

### Q6：决定投资收益和风险的真正因素是什么？

```
投资收益 = 资产选择 × 仓位 × 持有时间
定投方式 × 收益 ≈ 无影响
```

### Q7：面对一次性买入的犹豫，真正该问的问题是什么？

```
犹豫 ≠ 买入方式问题
犹豫 = 风险错配 或 仓位过高
```

## 边界条件

1. 结论依赖"市场长期向上"假设——若市场长期横盘或下跌，结论反转
2. 若考虑闲置资金收益（货币基金等），一次性买入与定投差异缩小
3. 定投的价值在"每月有稳定现金流"场景下更高——此时定投本质是及时投资的纪律化
