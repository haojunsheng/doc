# QA — 六月股债双收下的基金选择

> 原文：[晨星中国](https://www.morningstar.cn/articles/973dde2ba645e44271ea6acec0f39626.html)  
> 发布日期：2025-06-30（ID：20260614T213808）

## 一句话摘要

2025年6月，A股主要指数上涨2-5%，中证全债指数上涨0.59%，权益基金和固收基金普遍收涨——这一罕见的"股债双收"格局由外交、货币、产业政策三重共振驱动，对固收+投资者构成窗口期，但也预示着后续分化风险。

## Q1: 6月股债双收的驱动因素是什么？

**结论**：A股受外部（中美元首通电）+ 内部（陆家嘴论坛+金融支持消费19条）双轮驱动；债市受央行买断式逆回购1万亿 + 资金面呵护驱动。

**形式化**：
```
A股驱动 = 外部（中美元首通电） + 内部（陆家嘴论坛 + 金融支持消费19条） → 主要股指涨 2-5%
债市驱动 = 央行买断式逆回购（1万亿） + 资金面呵护 → 国债收益率下行 2-12bp
股债同向：政策利好同时提振风险偏好和资金面
```

**时间线**：
- 6月5日：中美元首首次通电 → 提振风险偏好
- 陆家嘴论坛：宣布深化科创板政策 → 增强市场信心
- 央行：月初预告1万亿买断式逆回购 → 资金面企稳
- LPR降息落地 → 债市收益率下行

**边界条件**：若中美摩擦重新升级或央行收紧流动性，股债双收格局可能转为分化。

## Q2: 为什么信用债表现好于利率债？

**结论**：信用债收益率下行幅度更大（5年期AAA/AA均↓7bp），信用利差收窄。

**形式化**：
```
信用债表现 > 利率债 ← 信用债收益率↓（5年期AAA/AA均↓7bp） + 信用利差↓
```

**数据**：
| 指标 | 变动 |
|------|------|
| 1年期AAA信用债收益率 | ↓3bp |
| 1年期AA信用债收益率 | ↓5bp |
| 5年期AAA信用债收益率 | ↓7bp |
| 5年期AA信用债收益率 | ↓7bp |

**边界条件**：若经济超预期恶化导致信用风险上升，信用债利差可能走阔，此时利率债反而更抗跌。

## Q3: 行业基金内部为什么出现分化？

**结论**：通信/国防军工/有色金属涨超9%，食品饮料/美容护理/家电跌超3%，差异来自产业政策（算力网络）vs 内需疲软（CPI同比-0.1%）。

**形式化**：
```
行业分化 = f(产业政策, 内需) → 通信（算力行动计划）+9% ≠ 食品饮料（内需疲软）-3%
```

**数据**：
| 行业 | 涨跌幅 | 驱动因素 |
|------|--------|---------|
| 通信 | +9%以上 | 工信部《算力互联互通行动计划》 |
| 国防军工 | +9%以上 | 政策催化 |
| 有色金属 | +9%以上 | 商品价格上涨 |
| 食品饮料 | -3%以上 | CPI同比-0.1%，内需疲软 |
| 美容护理 | -3%以上 | 消费疲软 |
| 家电 | -3%以上 | 内需不足 |

**边界条件**：若消费刺激政策超预期或算力建设进度不及预期，行业分化格局可能逆转。

## Q4: 全球市场为什么涨跌互现？

**结论**：美股/港股/日经涨（标普+4.96%，日经+6.64%，恒生+3.36%），欧股跌（富时-0.13%，DAX-0.37%，CAC-1.11%），差异来自地缘风险（中东冲突）和美联储政策预期。

**形式化**：
```
全球分化 = f(地缘风险, 美联储) → 美股/亚太（风险偏好提升）≠ 欧股（地缘风险+能源冲击）
```

**数据**：
| 市场 | 涨跌幅 | 驱动因素 |
|------|--------|---------|
| 标普500 | +4.96% | 美国PMI 52.9%，经济强劲 |
| 日经225 | +6.64% | 风险偏好提升 |
| 恒生指数 | +3.36% | A股联动+政策利好 |
| 富时100 | -0.13% | 地缘风险 |
| DAX | -0.37% | 欧洲能源成本上升 |
| CAC40 | -1.11% | 能源冲击 |
| 布伦特原油 | +6.42% | 中东冲突升级 |
| 黄金 | +0.70% | 避险需求 |

**边界条件**：若中东冲突缓和或美联储提前降息，欧股可能反弹；若冲突升级，全球股市都可能承压。

## Q5: 可转债基金为什么又是表现最好的？

**结论**：可转债兼具股性（跟随正股）和债性（债底保护），在"股债双收"格局中双重受益。

**形式化**：
```
可转债收益 = 股性（A股涨 → 转股价值↑ → 转债价格↑） + 债性（债市稳 → 债底保护）
中证转债指数 +3.34%（所有券种中最好）
```

**数据**：
| 基金类型 | 月均涨幅 |
|---------|---------|
| 偏股型基金 | +5-6% |
| 可转债基金 | +3.19% |
| 纯债型基金 | +0.22% |
| 中证转债指数 | +3.34% |

**边界条件**：若A股回调但债市继续涨，可转债基金的股性部分会拖累业绩；若股债同跌，可转债基金也会亏损。

## Q6: 从6月数据看，成长风格和价值风格的表现如何？

**结论**：成长风格优于价值风格，主要受益于通信/国防军工等成长板块的强势表现。

**形式化**：
```
成长 > 价值 ← 通信/国防军工/有色金属涨超9% → 成长风格弹性更大
```

**注**：本文未给出明确的风格指数对比数据（如中证1000 vs 沪深300），结论主要基于行业涨跌推断。

**边界条件**：若市场从"成长"切换到"价值"风格（如经济复苏超预期），价值风格可能跑赢。

## Q7: 对于持有"固收+"产品的投资者，6月数据说明了什么？

**结论**：在"股债双收"格局中，固收+产品能同时享受股债两边的收益，但需要关注后续股债分化风险。

**形式化**：
```
固收+收益 = 纯债收益（+0.59%） + 权益增强收益（+2-5%）
股债双收时：双重受益，表现居中
股债分化时：取决于权益暴露度
```

**数据**：
| 类别 | 月涨幅 |
|------|--------|
| 纯债基金 | +0.22% |
| 可转债基金 | +3.19% |
| 偏股型基金 | +5-6% |

**边界条件**：若后续股债分化（如7月的"股涨债跌"），固收+的表现将取决于权益暴露度。

## 收口

晨星6月基金月报的核心价值在于：用"股债双收"这个罕见现象，展示政策驱动如何同时影响股债两类资产，并提醒投资者关注后续分化风险。

**关键洞察**：股债双收是政策共振的结果（外交+货币+产业），而非市场自发均衡，因此可持续性弱，分化是常态。
