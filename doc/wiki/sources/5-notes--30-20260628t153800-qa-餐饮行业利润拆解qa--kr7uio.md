# 餐饮行业利润拆解 QA

来源：[[entities/晨星中国]] Morningstar 股票分析团队
原文：https://www.morningstar.cn/articles/f53e3fe8a7ccd44c4eb609770a3de6af.html
日期：2026-06-28

## 核心结论

2025年餐饮行业利润率有望小幅提升，驱动力来自成本端三项（食材降、租金降、人工稳），但需求端个位数增长限制了利润弹性。

## Q&A 要点

### 食材成本：占比40%，波动决定利润好坏
- 2022年大宗涨价 → 行业承压；2023Q2后回落 → 毛利率改善
- 每降1%食材成本 → 释放约0.4%利润率
- 边界：2026年降幅收窄，红利消退

### 人工成本：占比30%，温和表象下的棘手
- 全国平均薪资增速7%，餐饮仅4% → 说明行业在压缩人力开支
- 高端中餐/传统中餐依赖人工，自动化空间小
- 边界：若经济回暖薪资回升至7%，压力骤增

### 商铺租金：占比15%，实质性利好
- 2024H2百街租金24.25元/㎡/天；一线61%、二线83%区域下滑
- 外卖业态兴起 + 自动化设备压缩厨房面积 → 对空间需求下降
- 边界：地产企稳反弹则租金利好可能反转

### 新开店增速：从疫情前高位降至2%
- 新进入者用价格战抢市场 → 存量品牌竞争环境改善
- 连锁品牌凭供应链与采购优势碾压单体店
- 边界：利润率提升可能重新吸引新玩家涌入

### 连锁品牌胜出逻辑
- 集中采购降本 + 标准化出品 + 性价比定位
- 消费理性化趋势下更获信任
- 边界：过度扩张导致供过于求 → 单店利润下降

### 2025展望：成本三管齐下，但需求是最大变量
- 预计2025年餐饮销售额增长4.8%（疫情前约10%）
- 节假日脉冲式增长后迅速回落 → 消费意愿未真正恢复
- 宏观复苏将显著放大利润弹性
