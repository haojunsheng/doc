# 巴菲特2024致股东信QA — 手握现金等待"大象"，继续加仓日本

> 晨星中国 Morningstar 研究团队
> 原文：https://www.morningstar.cn/articles/4daea790624a39476aa9b0be7a8ddb50.html
> 日期：2026-06-28

## 核心结论

巴菲特2024年致股东信透露：伯克希尔减持超1340亿美元股票（含苹果和美国银行），现金仓位创纪录。但巴菲特强调不会偏好现金，仍会重仓股票。日本五大商社是"虽小但重要的例外"，将继续加仓。60年伯克希尔市值增长234700%，年化18.92%。

## Q&A 要点

### Q1：巴菲特2024年减持了多少股票？
- **结论**：减持价值超1340亿美元，包括持有近10年的苹果和持有超10年的美国银行。
- **形式化**：减持1340亿 = 苹果(减持) + 美国银行(减持) + 其他 → 现金仓位创新高
- **边界**：减持不等于看淡公司本身，可能是估值过高或需要资金配置其他机会。

### Q2：巴菲特手握创纪录现金为什么还说不偏好现金？
- **结论**：价值投资者持有现金不是因为怕波动，而是因为没找到更有吸引力的资产。
- **形式化**：持有现金 ≠ 保守策略 → 理由仅一条：找不到更有吸引力的资产
- **边界**：若市场整体估值过高，巴菲特可能继续维持高现金仓位。

### Q3：巴菲特为什么持续加仓日本五大商社？
- **结论**：低估值+管理层克制+运营模式像伯克希尔，五家公司同意放松10%持股上限。
- **形式化**：日本商社低估值 ⊕ 管理层克制 ⊕ 类似伯克希尔模式 → 持续增持
- **边界**：若日本经济持续疲软或日元大幅贬值，日本商社投资价值可能下降。

### Q4：巴菲特60年投资业绩有多惊人？
- **结论**：年化18.92%，市值增长234700%，是标普500同期增长的14.6倍。
- **形式化**：伯克希尔年化18.92% >> 标普500年化12% → 60年复利差距 = 14.6倍
- **边界**：这是历史业绩，未来规模越大越难维持高收益，已接近"规模诅咒"。

### Q5：巴菲特投资的本质逻辑是什么？
- **结论**：专注有竞争优势、长期内在价值、安全边际的企业，用纪律和耐心长期执行。
- **形式化**：竞争优势 ⊕ 内在价值 ⊕ 安全边际 × 纪律 × 耐心 → 超凡收益
- **边界**：巴菲特的原则适用于有长期视角的价值投资者，短线操作者照搬会适得其反。

### Q6：伯克希尔从亏损纺织企业变成支付最多所得税的公司说明什么？
- **结论**：复利再投资的威力——1965年不缴一分税，60年后缴税超过所有美国科技巨头。
- **形式化**：不缴税(1965) → 缴税超科技巨头(2024) = 再投资复利 × 60年
- **边界**：这个成功建立在巴菲特个人能力上，后巴菲特时代能否延续是核心风险。

### Q7：普通投资者从巴菲特2024年致股东信能学到什么？
- **结论**：持有现金不是保守而是等待机会，重仓优质企业长期持有，别频繁操作。
- **形式化**：现金等待(不是避险) + 优质企业(长期持有) - 频繁操作 → 复利增长
- **边界**：普通人资金规模和伯克希尔完全不同，不能简单复制仓位操作。

## 形式化总结

```
巴菲特投资本质 = 竞争优势 ⊕ 内在价值 ⊕ 安全边际 × 纪律 × 耐心
持有现金逻辑 = 找不到更有吸引力的资产（而非避险）
日本商社投资 = 低估值 ⊕ 管理层克制 ⊕ 类似伯克希尔运营模式
60年复利效果 = 年化18.92% vs 标普500年化12% → 差距14.6倍
```
