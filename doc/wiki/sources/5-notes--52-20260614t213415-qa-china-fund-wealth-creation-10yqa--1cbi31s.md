# 十年财富创造6.27万亿：宽基指数是最大的功臣

> 过去十年，哪些基金为中国投资者创造了最多财富？晨星中国发布十年财富创造数据，揭示了一个残酷真相。

## 核心论点

长期创造财富的不是"最聪明的主动选股"，而是"最朴素的宽基指数"。

**量化框架：财富创造 = 基金规模 × 收益率**

只有规模足够大，收益率的提升才能真正转化为投资者口袋里的真金白银。一只年收益50%但规模仅1亿的基金，创造的财富（5000万）远不如一只年收益10%但规模1000亿的基金（100亿）。

## Q1: 为什么用"规模×收益率"而非单纯收益率衡量财富创造？

**结论**：因为只有规模足够大，收益率的提升才能真正转化为投资者口袋里的真金白银。

**形式化**：`财富创造 = 基金规模 × 业绩增长率 → 规模大 + 收益高 = 创造财富多`

**边界条件**：若基金规模是"短期冲高"来的（如2021年冠军基金），后续回吐会减少财富创造。

## Q2: 为什么宽基指数基金能创造最多财富？

**结论**：宽基指数分散配置、费率低、长期稳健，适合长期持有，规模容易做大。

**形式化**：`宽基指数 = 分散配置 + 低费率 + 长期稳健 → 规模大 + 持有时间长 → 财富创造多`

**边界条件**：如果市场长期熊市（如日本"失去的三十年"），宽基指数也会长期不赚钱。

## Q3: 为什么主题行业指数基金反而让投资者亏钱？

**结论**：主题基金在短期行情中涨幅吸引大量资金，但随后回调让追高的投资者被套牢。

**形式化**：`主题基金 = 极致风格 + 短期高收益 → 资金追高涌入 → 市场回调 → 投资者亏损`

**边界条件**：如果投资者能在低点买入、长期持有，主题基金也能赚钱；关键是"买入时点"。

## Q4: 前海开源新经济为什么让投资者亏钱？

**结论**：2021年接近100%的涨幅吸引大量追高资金，但2022-2023年40%的跌幅让这些资金被套牢。

**形式化**：`2021年涨幅100% → 规模从1.3亿暴增至143亿 → 2022-2023年跌40% → 投资者亏损`

**关键数据**：
- 规模：2020年底1.3亿 → 2021年底143亿（增长100倍）
- 回撤：2022-2023年累计跌近40%

**边界条件**：如果投资者在2022年底部买入，2024-2025年反弹后可能已回本甚至盈利。

## Q5: 为什么易方达、华夏能创造最多财富？

**结论**：因为它们的核心资产集中在"规模大+业绩稳健"的指数基金产品上。

**形式化**：`易方达/华夏 = 核心产品规模大 + 业绩稳健 → 财富创造4369亿/3308亿`

**边界条件**：如果核心产品业绩下滑或规模萎缩，财富创造能力会下降。

## Q6: 为什么华泰柏瑞能跻身财富创造前十？

**结论**：以被动指数产品为特色，旗下有规模庞大的沪深300ETF等产品。

**形式化**：`华泰柏瑞 = 被动指数产品特色 + 规模大 → 财富创造前十`

**边界条件**：如果被动指数产品规模被其他公司超越，排名会下降。

## Q7: 从消费和医药基金亏钱能推断出什么？

**结论**：即使"好赛道"（如消费、医药），如果买入时点不对（高点追高），也会亏钱。

**形式化**：`好赛道（消费、医药）+ 买入时点错误（高点追高）→ 实际收益为负`

**边界条件**：如果投资者在2022年底部买入消费或医药基金，2024-2025年反弹后可能已经回本。

## 收口

晨星通过十年财富创造数据揭示了一个核心洞见：**长期创造财富的不是"最聪明的主动选股"或"最热门的赛道"，而是"最朴素的宽基指数+长期持有"**——因为宽基指数分散配置、费率低、规模大，适合长期持有；而极致风格的主题基金虽然短期涨幅惊人，但追高的投资者往往在高点买入、低点割肉，最终反而亏钱。
