# QA — 行业研究的系统方法论

作者：肖璟 | 原笔记日期：2026-07-12

---

## 一句话总结

> 行业研究不是天赋，是一套可按图索骥的操作系统。

---

## 来源背景

肖璟在麦肯锡 12 年被反复指派到全新领域，靠的不是天赋，是可复用的方法论。本书《如何快速了解一个行业》将其研究成果系统化输出。本次 QA 聚焦方法论的核心推理链，将全书浓缩为 9 个"为什么—怎么—边界"的问答。

## Q1：分析师两周内摸透行业的本质是什么？

**结论**：不是天赋，是"生命周期阶段→分析重点"的映射系统。

**形式化表达**：
```
传统: 一个模板套所有 → 肖璟: 生命周期阶段 → 分析重点映射
```

**关键洞察**：
- 导入期看可行性，成长期看规模性，成熟期看防守性→盈利性→估值
- 同一把尺子量不同东西，问题随阶段变

**边界**：适用于制造业、消费品、科技行业。对政策驱动型（军工）和创意驱动型（纯内容创作），生命周期阶段边界模糊。

**与 wiki 关联**：[[五维分析框架-肖璟]] 已有完整框架，本 QA 以面馆故事简化呈现因果链。

## Q2：渗透率为什么是生命周期划分的最靠谱指标？

**结论**：渗透率反映用户接受程度，天然对应创新扩散的五阶段。

**形式化表达**：
```
渗透率 15-20% → 成长期信号 / 35-40% → 成熟期信号
```

**理论源头**：罗杰斯创新扩散理论——五种用户类型依次入场：
```
创新者(2.5%) → 早期采用者(13.5%) → 早期大众(34%) → 后期大众(34%) → 落后者(16%)
```

**实证锚点**：智能手机 2010 年渗透率突破 20% 后一路高歌猛进，2014 年超 65% 进入成熟期。

**边界**：存量渗透率 vs 新车渗透率口径差异可造成结论天差地别（新能源汽车例子：7% vs 40%）。替代品类复杂时渗透率难以统计。

**与 wiki 关联**：[[渗透率口径敏感性]] 已有口径问题的讨论，本 QA 补充了 15-20%/35-40% 量化阈值。

## Q3：护城河二元框架为什么比巴菲特的版本更好用？

**结论**：把"成本优势是不是护城河"的伪问题解决——成本优势是护城河带来的结果。

**形式化表达**：
```
护城河 = 资源垄断(独占生产要素) + 网络效应(独占生产关系)
成本优势 = f(护城河)
```

**核心区分**：
- 资源垄断：独占劳动力、土地、资本、技术、数据
- 网络效应：独占生产关系（用户越多，产品价值越大）
- 成本优势：是上述两者的衍生结果——沃尔玛成本低是因为门店网络密

**边界**：混合护城河（如苹果：品牌+生态）需看主导维度；平台型企业框架不完全适用。

**与 wiki 关联**：[[护城河二元构建]] 已有核心论点，本 QA 首次以形式化公式呈现。

## Q4：产能周期如何解释集中度 U 形曲线？

**结论**：行业集中度"先降后升"，本质是产能从稀缺到过剩再到出清的物理循环。

**形式化表达**：
```
供不应求 → 产能激增 → 产能出清 → 格局改善 = 行业集中度U形曲线
```

**面馆故事**：生意好(Stage1满负荷) → 扩张+跟风涌入(Stage2价格战) → 弱者关张(Stage3出清) → 幸存者提价(Stage4格局改善)。

**A股四行业实证**：白酒/空调/挖掘机/智能手机的 CR3 走出不同路径，但都在这个框架内。

**边界**：政策强力干预（供给侧改革）可能压缩或逆转周期；技术颠覆性迭代可能让"格局改善"前就重新洗牌。

**与 wiki 关联**：[[产能周期四阶段]] 已有完整因果链，本 QA 补充了 A 股四行业 CR3 实证案例。

## Q5：普通人最该建立哪种信息差？

**结论**：深度差——在有限几个行业里比市场平均理解更深。

**三分法**：
| 类型 | 难度 | 适合谁 |
|------|------|--------|
| 时间差 | 极难（机构门槛） | 机构 |
| 广度差 | 中等，但导致FOMO陷阱 | 多行业从业者 |
| 深度差 | 靠方法论 | ✅ 普通人 |

**案例：肖璟投资腾讯**：不玩游戏的人发现好友在玩 + 环游中国发现到处在玩 → 270 港元买入 → 500-600 港元卖出。

**边界**：深度差需要放弃"什么都懂"的幻觉，适合集中持股型，不适合量化/指数化投资者。

**与 wiki 关联**：[[深度差-普通人最容易建立的护城河]] 已有完整内容，本 QA 补充了肖璟本人腾讯投资案例。

## Q6：DIKW模型为什么能诊断研究停滞在哪一层？

**结论**：多数人收集了数据、整理了信息，却缺少"So what?"这一步。

**四层结构**：
```
数据(原始) → 信息(加过逻辑) → 知识(Know-how) → 智慧(Know-why)
```

**案例**：上班迟到——记录时间(数据) → 平均迟到15分钟(信息) → 要早起床(知识) → 我不够自律(智慧)。

**财经对应**：营收数字(数据) → 同比加速环比放缓(信息) → 市场份额提升但季节波动大(知识) → 建议买入/卖出(智慧)。

**边界**：高频交易有时只需信息层；长期价值投资必须到知识/智慧层。

**与 wiki 关联**：[[DIKW模型-研究方法论]] 已有完整覆盖，本 QA 以具体例子强化理解。

## Q7：假设驱动为什么比"先读完所有资料"更高效？

**结论**：把研究的起点从"阅读"变成"猜测+验证"，把无限信息海洋压缩成一条可证伪路径。

**麦肯锡心法**："Don't try to boil the ocean"（不要尝试把大海煮沸）

**三步法**：提出假设 → MECE拆解 → 找指标验证。

**消费降级 MECE 拆解示例**：
- 假设1：钱不够花 → 验证：收入变少（城镇调查失业率）、被动收入变少（沪深300涨幅）、应付本息变多（居民杠杆率）
- 假设2：意愿改变 → 验证：主动消费降级（可选消费品下降）vs 被动消费降级（必需品占比上升）

**边界**：假设质量取决于行业积累。新手建议先访谈业内人士 + 搜索高质量综述。快速变化行业（如 AI）假设有效期很短。

**与 wiki 关联**：[[假设驱动研究]] 已有完整内容，本 QA 提供了消费降级具体拆解示例。

## Q8：为什么专家访谈的性价比在于"挖非公开信息"？

**结论**：公开的科普知识搜索引擎+研报都能给，专家的真正价值是"你不知道自己不知道"的部分。

**公开信息可替代性判据**：能上网搜到的 → 不值得问专家。

**专家不可替代的部分**：
- 产业层面的真实瓶颈定性判断（如"14nm堆叠能不能打到7nm性能"）
- 关键数据的经验估算（如"CXO外包渗透率实际到多少"）
- 行业共识的盲点（如2015年新能源汽车专家全行业悲观）

**访谈技巧**：
- 变换问法："如果让您来设计，您会怎么设计？"
- 启发式追问："3家加一起70%？→ 估计80% → 推算各自份额"

**专家盲区案例**：2015年新能源汽车专家全行业悲观——他们看到了当时的泡沫，但没看到宏观趋势（政策支持+基础设施完善+消费者接受度三重共振）。

## Q9：为什么要从不同渠道交叉验证数据？

**结论**：每个数据源都有定义偏差和立场倾向，单一资讯源是所有系统性错误的入口。

**实证案例**：
1. 社会融资规模 vs 央行月度报的"人民币贷款增加量"口径不同，数值相异
2. 某调研机构受企业委托出"全行业报告"——原材料实为企业自身用户数据+"合理加工"
3. 布隆伯格数据库也有错得离谱的数据
4. 国家统计局 2023 年启动统计造假治理

**心法**：投研追求的不是"标准答案"，而是一个合理的区间值。

## 全书收口

肖璟真正贡献的东西只有一件：**一套让普通人也能建立深度差的操作系统**——按生命周期选维度，按维度选工具，用假设驱动搜索，用交叉验证确认，最后用 DIKW 模型把思考压到知识或智慧层。框架是骨，工具是翼，骨不变翼可以升级。
