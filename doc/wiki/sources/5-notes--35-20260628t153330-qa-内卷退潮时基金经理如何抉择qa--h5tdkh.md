# 内卷退潮时，基金经理如何抉择

晨星网 QA 文章，聚焦汽车、新能源、外卖三大行业同时陷入价格战内卷时，四位基金经理给出的不同应对方案。

## 背景

汽车、新能源、外卖三条线同时开打价格战：

```
汽车: 均价↓11.4% → 新能源: 产能1100GW > 需求600GW → 外卖: 免佣金+百亿补贴
```

监管层于7月24日发布《价格法修正草案》征求意见，完善低价倾销认定标准，信号明确。

## 四位基金经理的不同应对

### 程琨（景顺长城）：坚守汽车零部件，出海对冲

- 偏好高质量 + 成长 + 安全边际
- 判断零部件行业有技术/成本/服务三重壁垒
- 海内外市场扩张对冲国内价格战侵蚀
- 2季度重仓股中汽车零部件比例无明显变化
- **边界条件**：若欧美对中国零部件反倾销大幅加严，出海逻辑被打破

### 陈俊华：减持美团，避烧钱战

- 原本基于美团竞争力认同参与投资
- 京东、抖音新入局，市场份额争夺白热化
- 美团海外投资可能分散国内资源投入
- 2季度重仓股已相应减持美团
- **边界条件**：若外卖格局快速出清（京东/抖音退出），减持逻辑失效

### 蒋璆：押注周期类资产，赌反内卷盈利修复

- 2024年中期注意到政治局会议提"反内卷"，当时政策未落地故减持新能源
- 2025年政策信号更强，各部委已着手行动
- 受益最大的是中上游偏周期类资产（煤炭/化工/钢铁/电池）
- 光伏短期有修复机会，但更大亮点需看需求端新增量
- **边界条件**：若政策落地慢于预期，或全球经济衰退压制周期品价格

### 周云（东方红）：定存利率+ROE双支撑，攻防兼备

- 一年期定存利率跌破1%，居民财富有搬向股权的内在动力（分母端效应）
- 反内卷若成功，GDP增速可能放缓但ROE回报系统性上升（分子端效应）
- 核心仓位放低估值稳健资产，卫星仓位放高弹性成长股
- **边界条件**：若就业/房价预期恶化，储蓄→股权搬家节奏放缓

## 核心结论：跟框架，不跟人

> 不跟个人，跟框架——先建自己的投资框架，再选与之匹配的基金。

四位基金经理策略各异，没有唯一正确答案。个人投资者信息处理处于劣势，应先构建自身框架，选择投资能力较强、流程清晰、能穿越周期的基金。
