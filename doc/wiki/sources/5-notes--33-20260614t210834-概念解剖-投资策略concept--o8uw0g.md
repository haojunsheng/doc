# 投资策略

投资策略是一套服务于个人投资目标的、系统化的行为指南。它回答三个核心问题：**买什么、为什么买、什么时候卖**。本质是**用规则对抗情绪，用纪律替代直觉**。

## 构成框架

投资策略由四个要素依次构成：

1. **目标** — 明确投资要解决的具体问题（非抽象的"致富"）
2. **资产配置** — 将资金分配到不同资产类别的比例
3. **买卖规则** — 触发买入和卖出操作的具体条件
4. **再平衡机制** — 纪律性地调整持仓比例以维持目标配置

## 四种优势来源

| 类型 | 说明 | 适用主体 |
|------|------|----------|
| 信息优势 | 获取并处理信息的能力 | 机构 |
| 分析优势 | 基于信息做出判断的能力 | 机构 |
| 行为优势 | 在市场恐慌时保持逆向操作 | 散户 |
| 结构性优势 | 无季度业绩压力，可长期持有 | 散户 |

散户的核心优势在于行为和结构性优势，而非信息和analyze优势。

## 辩证关系

- **优势**：提供行为锚点，避免情绪化决策
- **风险**：策略可能僵化，无法适应市场结构变化
- **矛盾**：策略需要稳定性，但市场永远在变——与 [[concepts/适应性市场假说]] 形成潜在对话

## 与相关概念的关联

- [[concepts/无聊的投资]]：本概念直接呼应"最好的策略往往是最无聊的策略"这一命题
- [[concepts/资产配置]]：资产配置是策略的核心构成要素
- [[concepts/投资指南针模型]]：对"致富目标"的批判与此高度一致
- [[concepts/风格错配]]：策略僵化风险与风格错配存在间接关联
- [[concepts/业绩归因]] / [[concepts/归因的边界]]：涉及"知道≠做到"的执行困境

## 元反思

以下开放问题值得持续跟踪：

- 策略是否只是"事后诸葛亮"的合理化工具？
- 散户的"行为优势"是否只是"没有季度业绩压力"的另一种说法？
- 当策略失效时，是策略错了还是执行错了？
