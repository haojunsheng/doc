# 伴读：饼画得越大，投资陷阱越大

**来源**：[Morningstar.cn 文章](https://www.morningstar.cn/articles/fdfe8f34b1c6d70a874c5f33a80d162f.html)
**发布时间**：2026-06-14（周日）10:30

## 一句话摘要

GMO 联合创始人、逆向投资传奇格兰特姆用亲身经历和历史复盘揭示：市场最狂热时恰恰最危险，宏大叙事是泡沫的温床，真正的赢家是能识别泡沫并逆向布局的理性投资者。

## 核心论点

### 一、狂热乐观主义与泡沫

- 格兰特姆回顾自身经历：商学院毕业后从事管理咨询，同事在微盘股炒作中格外开心，最终血本无归。
- 核心结论：**泡沫与狂热密不可分**。市场最狂热时恰恰最危险。

### 二、市盈率的历史悖论

传统金融学认为高市盈率预示长期成长好，但历史复盘显示四个"高市盈率繁荣期"最终都对应大萧条/衰退/泡沫破裂/金融海啸：

| 繁荣期 | 特征 | 最终结果 |
|--------|------|----------|
| 1920年代 | 高市盈率繁荣 | 大萧条 |
| 1970年代 | 高市盈率繁荣 | 经济衰退 |
| 1990年代 | 高市盈率繁荣 | 互联网泡沫破裂 |
| 2000年代初 | 高市盈率繁荣 | 金融海啸 |

> 市场表现与传统金融学完全相反——高市盈率反而预示长期低回报。

### 三、宏大叙事催生泡沫

投资故事越宏大，泡沫概率越高。机制链条：

```
跨时代创新 → 过度资本涌入 → 产能过剩 → 泡沫破裂
```

- 历史案例：铁路、无线电、电话、汽车等创新，均经历过类似路径。
- 互联网案例：亚马逊股价下跌 **92%**，**80%** 的互联网公司消失。
- 结论：即使最具潜力的赛道也难以避免泡沫。

### 四、创新的三阶段模型

```
短期：过度炒作
中期：走向崩溃
长期：从废墟中重生，改变世界
```

格兰特姆并不否定创新的长期价值，但强调短期和中期的毁灭性。

### 五、垄断护城河与政府角色

- 高稳定回报的唯一方法是消灭竞争。
- 晨星美国市场指数前十大成分股集中度已达 **30%**，且十年翻倍。
- 政府角色转变：过去 30-40 年偏袒大公司，当前各国政府开始打击垄断企业。

## 格兰特姆的历史战绩

| 预警事件 | 结果 |
|----------|------|
| 日本泡沫 | 成功预警 |
| 互联网泡沫 | 成功预警 |
| 2008年金融危机 | 成功预警 |

> **选择性叙述提示**：来源仅提及三次成功预警，未提及其预测失败的案例（如 2008 年后美股长达十年的大牛市）。新建实体页时应补充完整记录以保持平衡。

## 关键金句

> "每当有创新出现的时候，它们都会在短期内被过度炒作，继而在中期走向崩溃，然后它们会从'废墟'中重生，最终在长期改变世界。"
