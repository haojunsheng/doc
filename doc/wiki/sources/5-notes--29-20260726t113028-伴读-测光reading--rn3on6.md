# 伴读：07 | 测光——什么才是正确曝光？

## 全局摘要

没有"绝对正确的曝光"——相机的测光系统把一切还原成 18% 中性灰，但"正确曝光"取决于你想让观者看见什么；点测光、全局测光等工具只是手段，最终参数由你的创作意图决定。

## 核心论点

1. **没有绝对正确的曝光，只有正确的曝光意图。** 相机的测光系统把一切还原成 18% 中性灰，这不是"测量现实"而是"把现实转换成灰"。摄影师的价值在于知道机器的计算偏差在哪里，然后决定要不要纠正、朝哪个方向纠正。

2. **同一场景，相反策略，都是"正确"的。** Alex Webb（对高光测光 → 阴影死黑 → 高对比）和滨田英明（对阴影测光 → 高光过曝 → 日系小清新）的策略完全相反，但都是大师级作品。

3. **测光是建议，曝光是决策。** 测光表给出的是参考值，曝光补偿是你对其的纠正。两者是修正关系而非并列关系。

## 术语表

| 英文 | 中文 | 本文含义 |
|---|---|---|
| Light Ratio | 光比 | 暗面与亮面的受光比例 |
| Metering | 测光 | 测量场景亮度以确定曝光 |
| Middle Gray / 18% Gray | 中性灰 / 18度灰 | 反光率 18% 的灰色，测光基准 |
| Spot Metering | 点测光 | 只测画面很小区域的亮度 |
| High-key | 高调 | 明亮、过曝的风格（滨田英明） |
| Low-key | 低调 | 暗沉、高对比的风格（Alex Webb） |
| Overexposure | 过曝 | 画面比"正确"更亮 |
| Underexposure | 欠曝 | 画面比"正确"更暗 |
| Exposure Compensation | 曝光补偿 | 在测光基础上手动+/-亮度 |

## 测光与曝光补偿的关系

```
测光（相机做的事）→ 基于"把一切变成 18% 灰"给出曝光参数
   ↓
你判断：这个读数是我想要的吗？
   ↓
不是 → 曝光补偿（你做的事）→ 告诉相机"亮一点/暗一点"
```

**一句话**：测光是相机的建议，曝光补偿是你的纠正。
