# 拆书《指数基金投资指南》— 银行螺丝钉

## 基本信息

- **作者**：银行螺丝钉
- **核心问题**：普通上班族怎样用一套简单规则，把投资从折磨变成习惯？
- **不满的对象**：把投资当玄学（追消息、追牛人）；把指数基金当无脑买入（不看贵不贵）

## 核心主张

普通人不用赢过市场里的所有聪明人，只要长期买入低估、低成本、可持续的指数基金。

指数基金负责分散和低成本，估值负责不买贵，定投负责长期执行。

## 三大工具层

### 1. 选工具：指数基金
- **宽基指数**：上证红利、中证红利、上证50、基本面50
- **行业指数**：按行业分类选择
- **策略加权指数**：按策略规则加权
- 选择原则：低费率、低误差

### 2. 看价格：估值方法
- **盈利收益率法**：用盈利收益率（E/P）判断指数估值
- **博格公式法**：用股息率+盈利增长估算合理估值
- **博格公式变种**：博格公式的变形应用
- **市盈率、市净率、股息率**：辅助指标

### 3. 定动作：三态操作纪律
- 盈利收益率 > 10% → 分批买入
- 6.4% < 盈利收益率 ≤ 10% → 持有
- 盈利收益率 ≤ 6.4% → 分批卖出
- 高速增长或高波动指数另用博格公式看初始股息率和PE变化

## 方法论命名

- **懒人定投法**：将定投从固定扣款升级为估值驱动的流水线
- **定期不定额**：便宜时多买，贵时少买或卖出
- **指数估值表**：查表执行的简化操作工具

## 三类具体计划

| 计划名称 | 目标 | 特点 |
|---------|------|------|
| 养老定投计划 | 养老积累 | 超长周期，自动执行 |
| 上班族加薪计划 | 资产加速 | 随工资增长动态提升定投额度 |
| 子女教育定投计划 | 教育储备 | 有明确时间截点 |

## 关键论据

- **80/20收益时间分布**：股票市场80%的收益集中在20%的时间里，因此"不择时"不等于"不看价格"
- **工资现金流是武器**：定投将稳定现金流转化为资产积累

## 局限与开放问题

1. 盈利收益率阈值（10% / 6.4%）缺乏严格的学术基础，更像经验法则，未解释数字来源
2. 未涵盖中国投资者当前面临的 QDII 额度稀缺、场内溢价等现实约束
3. 不同指数（宽基 vs 行业）是否适用不同阈值，未明确回答
