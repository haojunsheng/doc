# 概念解剖：阿尔法的本质与幻象（Alpha）

> 来源：晨星文章《消失的阿尔法回来了？》  
> 时间：2026-06-14

## 定锚

**阿尔法（Alpha）** —— 基金业绩中**无法被市场因子解释的超额收益**，通常被视为**基金经理主动管理能力的量化体现**。但阿尔法的"真相"是：**它可能来自能力，也可能来自运气、因子暴露或市场风格**。

本质：**阿尔法是"解释剩余"——所有模型都解释不了的，都被扔进这个黑箱**。

## 核心主张

1. **Alpha是"解释剩余"，不是固定的能力指标**
   - 证据：从1967年詹森阿尔法到1992年Fama-French三因子再到2010年代多因子模型，每一次模型扩展都"吃掉"了之前被认为是Alpha的部分。
   - 强度：强——有明确历史脉络支撑，逻辑链清晰。

2. **2025年初主动基金战胜率回升至28%主要是风格顺风，不是能力回归**
   - 证据：A股主动基金70%以上是成长风格，2025年初成长风格回归自然推高了这些基金的业绩。
   - 强度：中等——提供了方向性解释，但无法完全排除部分基金经理确实有改善的可能。

3. **晨星的定义使Alpha成为一个永远动态收缩的概念**
   - 证据：引用晨星重新定义Alpha为"当前任何因子模型都无法解释的决策"。
   - 强度：强——这个定义本身就内嵌了自我消解的逻辑。

4. **实践推论：普通投资者应承认无法识别真Alpha，转而追求低成本贝塔**
   - 证据：因子暴露被包装成Alpha收费的普遍现象；历史数据表明主动基金持续性存疑。
   - 强度：合理——是前述论据的自然推论，但属于规范性判断而非实证结论。

## 历史脉络

| 年份 | 事件 | 对Alpha的影响 |
|------|------|-------------|
| 1967 | Michael Jensen提出詹森阿尔法 | Alpha定义为基金收益对市场收益线性回归的截距 |
| 1992 | Fama-French三因子模型 | 引入市值因子(SMB)和价值因子(HML)，许多"Alpha"被发现是因子暴露 |
| 2010年代 | 动量、质量、低波动等因子被发现 | Alpha边界不断被重新定义，解释剩余持续缩小 |
| 2025年初 | 晨星统计主动权益基金1年期战胜率从14%回升至28% | 可能是风格顺风而非能力回归 |

## 詹森阿尔法公式

```
α = Rp - [Rf + β(Rm - Rf)]
```

其中：
- α：詹森阿尔法（超额收益）
- Rp：投资组合收益率
- Rf：无风险利率
- β：投资组合对市场的贝塔系数
- Rm：市场收益率

## Fama-French三因子模型

```
Rp = α + β1(Rm) + β2(SMB) + β3(HML) + ε
```

其中：
- SMB：规模因子（Small Minus Big）
- HML：价值因子（High Minus Low）
- α：在三因子框架下的残差收益（真正的Alpha）

**关键洞见**：每增加一个解释变量，α的估计值往往会缩小——"Alpha"被重新归类为因子收益。

## 晨星的动态定义

晨星将Alpha重新定义为：

> **"当前任何因子模型都无法解释的决策"**

这是一个**永远向后看的概念**——今天的Alpha可能是明天的Beta。一旦新的因子模型被开发出来，曾经被认为是Alpha的部分就会被纳入Beta范畴。

## 核心张力

- **能力 vs 运气**：Alpha高可能是因为基金经理能力强，也可能是运气好——短期无法区分。
- **因子暴露 vs 主动管理**：很多"Alpha"只是基金经理无意中暴露于某个风格因子（如小盘、成长），不是能力，是风格。
- **Alpha的周期性与"顺风"属性**：当市场风格与基金经理风格匹配时，Alpha"回归"；不匹配时，Alpha"消失"——Alpha是"顺风"的产物。

## 讽刺之美

越是追求Alpha，Alpha越难找到——它是投资的"圣杯"，但圣杯可能不存在。很多基金把"因子暴露"包装成"Alpha"，用小盘、成长风格跑赢大盘，然后收"Alpha"的管理费。

## 实践启示

与其追求"Alpha基金经理"，不如买指数基金（贝塔）+ 低成本——承认自己无法识别"真Alpha"。

# 阿尔法是解释剩余

阿尔法的本质不是"基金经理的能力"，而是**所有因子模型都解释不了的收益残差**——一个动态收缩的"解释剩余"。

## 核心定义

**Alpha = 总收益 - 所有可解释的因子收益**

它不是固定的能力指标，而是随着因子模型的扩展不断被"侵蚀"的残差项。每一次新的因子被发现，曾经被认为是Alpha的部分就会被重新归类为Beta。

## 历史演变

1. **1967年：詹森阿尔法**
   - 定义：基金收益对市场收益线性回归的截距
   - 此时Alpha = 总收益 - 市场贝塔收益
   - 几乎所有超额收益都被视为Alpha

2. **1992年：Fama-French三因子模型**
   - 引入市值因子(SMB)和价值因子(HML)
   - 大量之前被认为是Alpha的收益被重新解释为风格暴露
   - Alpha的边界大幅收缩

3. **2010年代：多因子模型扩展**
   - 动量、质量、低波动等因子被发现
   - Alpha继续被蚕食，解释剩余越来越小

4. **晨星的动态定义**
   - Alpha = "当前任何因子模型都无法解释的决策"
   - 定义本身就内嵌了自我消解的逻辑：今天的Alpha是明天的Beta

## 关键洞见

- **Alpha是后视镜概念**：过去的Alpha不代表未来的能力
- **Alpha随模型扩展而消失**：不是基金经理变差了，而是我们的理解更深了
- **因子暴露常被包装成Alpha**：小盘、成长等风格押注被当作"主动管理能力"收费

## 实践含义

承认Alpha可能是解释剩余的动态概念，意味着：
1. 不要过度解读历史Alpha数据
2. 警惕将因子暴露包装为Alpha的产品
3. 普通投资者应优先追求低成本贝塔，而非高费率的主动Alpha

# Michael Jensen

哈佛商学院金融学教授，1967年提出詹森阿尔法，开创了测量基金经理主动管理能力的学术传统。

## 核心贡献

**詹森阿尔法（Jensen's Alpha）** —— 在《1945-1964年共同基金的表现》一文中首次提出，定义为基金收益对市场收益线性回归的截距：

```
α = Rp - [Rf + β(Rm - Rf)]
```

这一公式成为后续几十年评估基金经理能力的标准工具，也是所有因子模型扩展的起点。

## 历史地位

Jensen的工作奠定了现代投资组合理论中"主动管理 vs 被动管理"争论的量化基础。他的阿尔法概念后来被Fama、French等学者不断扩展和修正，催生了多因子模型体系。

# Fama & French

**Eugene Fama**（芝加哥大学）与**Kenneth French**（达特茅斯学院）于1992年提出三因子模型，重新定义了Alpha的边界。

## 核心贡献

**Fama-French三因子模型**在CAPM市场因子的基础上，增加了两个系统性风险因子：

```
Rp = α + β1(Rm) + β2(SMB) + β3(HML) + ε
```

- **SMB（Small Minus Big）**：规模因子，衡量小盘股相对于大盘股的超额收益
- **HML（High Minus Low）**：价值因子，衡量价值股相对于成长股的超额收益

## 对Alpha概念的冲击

三因子模型揭示了大量此前被认为是Alpha的收益，实际上是基金经理对规模因子或价值因子的隐性暴露。这一发现大幅收缩了Alpha的定义边界，推动了从"主动管理能力"向"因子暴露分析"的范式转变。

## 后续发展

2010年代，Fama-French进一步扩展到五因子模型，加入盈利因子(RMW)和投资因子(CMA)，但Alpha作为"解释剩余"的本质未变。

# Fama-French三因子模型

1992年由Eugene Fama和Kenneth French提出的资产定价模型，在CAPM单一市场因子的基础上增加了规模因子和价值因子，重新定义了Alpha的测量边界。

## 模型公式

```
Rp = α + β1(Rm) + β2(SMB) + β3(HML) + ε
```

## 因子说明

| 因子 | 全称 | 含义 |
|------|------|------|
| Rm | 市场因子 | 市场组合收益率超过无风险利率的部分 |
| SMB | Small Minus Big | 小盘股收益减去大盘股收益，捕捉规模溢价 |
| HML | High Minus Low | 高账面市值比股票减去低账面市值比股票，捕捉价值溢价 |

## 对Alpha概念的影响

三因子模型的核心洞见是：**大量此前被认为是Alpha的超额收益，实际上是基金经理对规模因子或价值因子的隐性暴露。**

- 当模型从单因子扩展到三因子，Alpha的估计值显著缩小
- 这推动了从"主动管理能力"评价向"因子暴露分析"的范式转变
- Alpha从此被理解为三因子模型后的残差项（解释剩余）

## 与詹森阿尔法的关系

詹森阿尔法（1967）是CAPM框架下的Alpha定义，仅控制市场风险。Fama-French三因子模型扩展了风险控制的维度，使Alpha的估计更加精确——但也更"贫瘠"。

## 后续发展

- 2010年代：五因子模型（加入RMW盈利因子和CMA投资因子）
- 2015年：Q因子模型（加入质量因子）
- 每个新因子都进一步蚕食Alpha的边界

# SMB（规模因子）

**SMB（Small Minus Big）** 是Fama-French三因子模型中的规模因子，衡量小盘股相对于大盘股的超额收益。

## 定义

SMB = 小盘股组合收益 - 大盘股组合收益

## 经济学含义

规模溢价的存在意味着小盘股长期而言风险更高、预期收益更高。基金经理如果在持仓中隐含地偏向小盘股，其超额收益可能来自SMB因子暴露而非真正的选股能力。

## 与Alpha的关系

当三因子模型纳入SMB后，大量此前被认为是Alpha的收益被重新解释为规模因子收益。这是Alpha从"能力指标"向"解释剩余"演变的关键一步。

# HML（价值因子）

**HML（High Minus Low）** 是Fama-French三因子模型中的价值因子，衡量高账面市值比（价值股）相对于低账面市值比（成长股）的超额收益。

## 定义

HML = 高账面市值比股票组合收益 - 低账面市值比股票组合收益

## 经济学含义

价值溢价反映了价值股相对更高的风险补偿。基金经理如果在持仓中隐含地偏向价值股，其超额收益可能来自HML因子暴露而非真正的选股能力。

## 与Alpha的关系

HML因子的纳入使大量"成长风格"或"价值风格"的主动收益被重新归类为因子收益，进一步压缩了Alpha的边界。A股主动基金70%以上为成长风格，当成长风格回归时，这些基金的Alpha自然"回升"——但这正是因子暴露而非能力改善。

# 因子暴露

**因子暴露（Factor Exposure）** 指基金在某个系统性风险因子上的隐性赌注——基金经理可能自己都没有意识到。

## 核心定义

因子暴露 = 基金在某个风格因子（如规模、价值、成长、动量等）上的净敞口

当基金收益可以被某个因子解释时，这部分收益应归类为因子收益（Beta），而非主动管理Alpha。

## 常见因子暴露类型

| 因子 | 表现 | 风险特征 |
|------|------|---------|
| 规模因子（SMB） | 小盘股偏好 | 小盘股流动性差、波动大 |
| 价值因子（HML） | 价值股偏好 | 价值股可能有价值陷阱 |
| 成长因子 | 成长股偏好 | 成长股估值敏感、回撤大 |
| 动量因子 | 追涨杀跌 | 趋势反转时损失大 |
| 低波动因子 | 防御型持仓 | 牛市时跑输大盘 |

## 与Alpha的区分

**关键判准**：如果某部分超额收益可以用因子模型解释，它就是因子暴露（Beta），不是Alpha。

- 因子暴露 ≠ 主动管理能力
- 很多"Alpha"只是基金经理无意中押注了某个风格因子
- 当市场风格与基金因子暴露匹配时，Alpha"回归"；不匹配时，Alpha"消失"

## 实践警示

- **因子暴露被包装成Alpha收费**：这是行业普遍现象
- **风格顺风 ≠ 能力回归**：2025年初A股主动基金战胜率从14%回升至28%，主要原因是成长风格回归，而非基金经理能力改善
- **A股主动基金70%以上是成长风格**：这意味着大部分主动基金的业绩高度依赖成长因子的表现
