# QA — 新手投资避坑指南

> 投资路上所有的坑，"小韭"都替你踩过了。

## 元信息

- **来源**：[晨星中国 (Morningstar.cn)](https://www.morningstar.cn/)
- **日期**：2026-06-14
- **内容形式**：QA 访谈式投资教育文章（延续"小韭"叙事角色）

## 一句话摘要

以新手"小韭"为主角，提炼五个最常见的投资错误——追涨杀跌、听消息炒股、频繁换仓、不设止损、过度集中——及其背后的逻辑机制和边界条件，构成新手投资纪律的五道防线。

## 五条核心规则

### Q1 · 追涨杀跌
- **结论**：在别人恐慌时买入，在别人乐观时卖出；新手往往做反。
- **形式化**：新手行为：涨 → 买，跌 → 卖；正确行为：跌 → 买，涨 → 卖
- **引用**：乔治·索罗斯（George Soros）"在别人恐惧时贪婪，在别人贪婪时恐惧"
- **边界**：趋势跟踪/动量策略在强势趋势下追涨可能有效，但对普通投资者不适用。

### Q2 · 听消息买股票
- **结论**：听到消息时价格已经反映了信息，二手消息无法带来超额收益。
- **形式化**：消息传播链：内幕 → 机构 → 散户；你进场时已是尾声。
- **理论基础**：半强式有效市场中，公开信息已反映在价格里（见 [[有效市场假说]]）。
- **边界**：极度无效市场（小盘股、新兴市场）仍存在信息不对称机会。

### Q3 · 频繁换仓
- **结论**：每次交易都有成本，长期复利累积下来严重侵蚀收益。
- **形式化**：频繁交易 → 交易成本 ↑ → 净收益 ↓；持有不动 → 成本最低 → 复利最大。
- **深层逻辑**：频繁换仓本质是择时，而择时大多数人做错了（见 [[择时的心理陷阱]]）。
- **边界**：市场发生根本性变化（行业长期衰退）时，不换仓损失更大；关键在区分"短期波动"与"长期趋势"。

### Q4 · 止损纪律
- **结论**：止损不是"跌了就卖"，而是"跌破了预设的关键位置再卖"——纪律比情绪重要。
- **形式化**：止损 = 预设规则触发 → 执行；情绪 = 恐惧驱动 → 乱卖。
- **关键洞察**：没有止损的人往往在最低点割肉，因为恐惧让他们无法承受更大损失。
- **边界**：止损前提是买入逻辑被证伪，短期波动不应触发（详见 [[止损纪律与触发条件]]）。

### Q5 · 分散投资
- **结论**：分散避免"一把亏光"——单只股票跌 50%，分散组合仅跌 5%。
- **形式化**：集中投资：1 只股票跌 50% → 组合跌 50%；分散：1 只跌 50% → 组合跌 5%。
- **机制**：指数基金是分散投资的极致形式——持有整个市场，消除非系统性风险。
- **边界**：过度分散稀释收益；有能力研究个股时适度集中可能更优；但对新手，分散更安全（详见 [[分散化-起源与原理]]）。
