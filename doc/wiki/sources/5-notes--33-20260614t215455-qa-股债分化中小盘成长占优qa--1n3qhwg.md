# QA — 股债分化中小盘成长占优

**原文**：[晨星中国](https://www.morningstar.cn/articles/2e22f9b2d21055b68192fd4eadf446a0.html)  
**发布日期**：2025年1月基金月报（收录于 2026-06-14）

## 一句话摘要

2025年1月A股市场延续下跌（上证-3.02%，深证-2.48%），但债市走出"开门红"（中证全债+0.54%）。在股债分化背景下，中小盘成长风格跑赢大盘价值，可转债基金成为固收类中表现最优品种（+1.64%），黄金和美股QDII也表现亮眼。核心驱动是经济承压+宽松预期抢跑+地缘风险三重叠加。

## 核心发现

### Q1：为什么1月A股下跌，但中小盘跌幅反而小于大盘？

**结论**：中小盘跌幅较小（中证1000跌1.87% vs 沪深300跌2.99%）是因为前两年中小盘已经历估值修复，安全边际更高，且政策利好（以旧换新、人形机器人）精准提振了中小盘占优的机械设备、汽车等板块。

```
市场下跌 → 资金从高估值大盘股撤出 → 中小盘因前期估值修复+政策刺激获得相对支撑 → 中证1000跌幅 < 沪深300跌幅
```

**关键数据**：

| 指数 | 涨跌幅 | 说明 |
|------|--------|------|
| 沪深300 | -2.99% | 大盘价值代表 |
| 中证500 | -2.38% | 中盘代表 |
| 中证1000 | -1.87% | 中小盘代表，跌幅最小 |
| 机械设备 | 逆势上涨 | 人形机器人政策驱动 |
| 汽车 | 逆势上涨 | 以旧换新政策驱动 |
| 大盘价值基金 | -2.53%（平均） | 最差风格 |

**边界**：若政策利好未能落地或超预期利空出现，中小盘防御优势会消失；流动性大幅收紧时，中小盘因流动性差反而跌幅更大。

**来源**：[[sources/5-notes--55-20260614t215455-qa-股债分化中小盘成长占优-qa]]

### Q2：既然市场下跌，为什么成长风格反而跑赢了价值？

**结论**：成长风格跑赢（中盘成长-0.28% vs 大盘价值-2.53%）是因为成长股集中在科技行业，而科技板块受益于AI算力快速发展，且央行宽松预期抢跑推高了成长股估值。

```
成长风格 ≈ 科技权重高 → AI算力需求爆发 + 宽松预期抢跑 → 科技行业逆势上涨 → 成长风格跑赢价值
```

**关键数据**：

| 风格类别 | 涨跌幅 | 说明 |
|---------|--------|------|
| 中盘成长 | -0.28% | 表现最好 |
| 大盘价值 | -2.53% | 表现最差 |
| 科技传媒通讯（行业混合） | +1.95% | 远好于其他 |
| 消费/医药/金融地产 | -3%以上 | 传统价值板块重挫 |

**机制**：央行例会提出"择机降准降息" → 市场提前定价宽松 → 成长股对利率敏感（久期长）→ 受益更大

**边界**：若宽松政策落空（如1月10日央行暂停国债买入导致收益率走高），成长股会因估值回调而跑输。

---

### Q3：为什么债市能在股市下跌时走出"开门红"？

**结论**：债市上涨（中证全债+0.54%）是因为央行宽松预期抢跑——市场提前定价降准降息，推动国债收益率下行，债券价格上涨。

```
央行例会提出"择机降准降息" → 市场预期未来利率下降 → 债券价格与利率负相关 → 债券价格上涨
```

**关键数据**：

| 指标 | 涨跌幅 | 说明 |
|------|--------|------|
| 中证全债指数 | +0.54% | 债市"开门红" |
| 中证转债指数 | +1.34% | 所有细分券种最好 |
| 5年期国债收益率 | -0.3bp | 下行 |
| 10年期国债收益率 | -5bp | 下行 |
| 1年期国债收益率 | +22bp | 短端反而上行，市场对短期流动性有担忧 |

**机制**：央行2024年四季度货币政策例会延续"适度宽松"基调并提出"择机降准降息" → 机构提前抢跑定价宽松预期。

**边界**：若通胀超预期上升或经济数据大幅好转，宽松预期会逆转；1月10日央行暂停国债买入导致收益率反弹，说明预期与现实存在博弈。

---

### Q4：为什么可转债基金能成为固收类基金中表现最好的（+1.64%）？

**结论**：可转债基金领涨（+1.64% vs 普通债券+0.21%）是因为可转债兼具股债特性，在股市下跌时债底保护、在预期好转时享受估值抬升，且中证转债指数上涨1.34%是所有细分券种中最好的。

```
可转债 = 债券底 + 股票期权 → 股市下跌时债底支撑 + 预期好转时估值抬升 → 中证转债指数+1.34% → 可转债基金+1.64%
```

**关键数据**：

| 券种 | 涨幅 | 说明 |
|------|------|------|
| 可转债基金 | +1.64% | 固收类最优 |
| 中证转债指数 | +1.34% | 所有细分券种最好 |
| 普通债券基金 | +0.21% | 远低于可转债 |
| 中证国债政金债 | +0.35% | 利率下行贡献 |
| 中证企业债 | +0.22% | 信用利差收窄贡献有限 |

**机制**：1月A股下跌但预期企稳（政策利好+经济数据平稳），可转债的"进可攻退可守"特性完美匹配这种环境。

**边界**：若股市继续大幅下跌，可转债的期权价值会归零，仅剩债底保护，收益会低于纯债基金。

---

### Q5：为什么QDII基金中商品基金（+5.01%）和美国股票基金（+3.10%）表现最好？

**结论**：商品基金领涨是因为黄金上涨6.57%（特朗普加征关税加剧通胀担忧+地缘冲突），美国股票基金受益于标普500上涨2.70%（美国制造业PMI时隔6个月重回扩张区间）。

```
特朗普加征关税 → 通胀预期↑ + 地缘冲突↑ → 黄金避险需求↑ → 伦敦黄金+6.57% → 商品基金+5.01%
美国PMI重回扩张 → 美股上涨 → 标普500+2.70% → 美国股票基金+3.10%
```

**关键数据**：

| 资产/指数 | 涨跌幅 | 驱动因素 |
|----------|--------|---------|
| 伦敦黄金 | +6.57% | 关税+地缘冲突 |
| 商品基金（QDII） | +5.01% | 黄金主导 |
| 标普500 | +2.70% | 美国制造业PMI扩张 |
| 美国股票基金（QDII） | +3.10% | 标普500带动 |
| 布伦特原油 | +2.23% | 拜登制裁俄罗斯引发供应担忧 |

**边界**：若关税政策缓和或地缘冲突降温，黄金避险需求下降；若美国PMI再次跌破荣枯线，美股会拖累美国股票基金表现。

---

### Q6：从1月的市场分化中，能提炼出什么配置框架？

**结论**：核心框架是"政策驱动+风格轮动"：经济承压期配置中小盘成长风格（政策受益+弹性大），同时用固收类基金（尤其是可转债）做底仓对冲，海外配置聚焦黄金（避险）和美股（基本面支撑）。

```
经济承压 → 政策宽松预期 → 中小盘成长受益 + 债市上涨 + 黄金避险
组合 = 中小盘成长（进攻）+ 可转债（平衡）+ 黄金（防守）+ 美股（分散）
```

| 组合要素 | 配置工具 | 功能定位 |
|---------|---------|---------|
| 进攻端 | 中小盘成长基金 | 政策受益+弹性大 |
| 平衡端 | 可转债基金（+1.64%） | 股债分化中双向受益 |
| 防守端 | 黄金（+6.57%） | 极端风险对冲 |
| 分散端 | 美股QDII（+3.10%） | 低相关性分散 |

**边界**：若经济复苏确认，应切换到大盘价值风格；若宽松政策超预期，应增加利率债配置；若地缘冲突缓和，应减仓黄金。

## 收口

晨星1月基金月报揭示了一个关键规律：在政策驱动的市场中，风格轮动比资产配置更重要——中小盘成长+可转债底仓+黄金防守的组合，完美匹配了"经济承压+宽松预期+地缘风险"的三重环境。可转债的优异表现验证了其"进可攻退可守"的双重属性，在股弱债强分化格局中，可转债是固收类基金的最优选择。
