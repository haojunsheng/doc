# 中国资产为什么是新兴核心

## 来源信息

- **原始来源**: https://www.morningstar.cn/articles/b6ea07c51a3949ba343c7557fb9549d4.html
- **研究方**: 晨星（Morningstar）
- **日期**: 2026-06-28

## 核心结论

晨星最新研究将中国股票列为"未来十年新兴市场最具吸引力的资产"，年化预期收益率 **6.36%**，超过印度、泰国、墨西哥等其它主要新兴市场。

吸引力来自三个维度的叠加：
1. **估值便宜** — 当前估值已充分计入悲观预期
2. **增长仍强** — 中高收入阶段3.6%的含金量不同于追赶期9%
3. **全球配置稀缺性** — 中国是新兴市场中唯一具备足够规模、流动性和行业覆盖度的单一国家标的

## 关键问答摘要

### Q1: GDP增速从9%降到3.6%，中国股票反而更有吸引力了？

增速放缓是转型结果而非崩溃。基数扩大后绝对增量依然可观，且当前估值已把悲观预期计入。形式化逻辑：`9%增速 + 高杠杆风险 → 3.6%增速 + 估值便宜 = 更高隐含回报`。

**边界条件**：若实际增速持续低于3%，6.36%的预期回报将无法兑现。

### Q2: 中国股票6.36% vs 其他新兴市场，优势来自哪？

优势来自 **低估值 × 稳健增长 × 市场规模** 三者的综合。印度、泰国、墨西哥等国估值已偏高，而中国股票池的广度和深度无可替代。

**边界条件**：若中国被剔除全球指数（极端制裁情形），国际资金被迫撤离会压低估值。

### Q3: 51%的平均关税税率对中国经济影响有多大？

市场普遍预计会使中国潜在GDP增速下降约 **1个百分点**。形式化：`51%关税 → 出口竞争力↓ → 潜在GDP增速 -1%`。

**边界条件**：若中美贸易磋商取得突破、关税大幅回落，负面影响将显著降低。

### Q4: 房地产拖累还没结束，为什么还说"开始企稳"？

"企稳"是止跌，不是复苏。房价走势阶段：`急跌 → 跌幅收窄 → 企稳(进行中) → 复苏(未至)`。住宅市场接近企稳，但负财富效应仍在抑制总需求。

**边界条件**：若居民收入预期持续恶化，"企稳"可能只是下跌中继。

### Q5: 从全球配置角度看，中国股票的不可替代性在哪？

中国是新兴市场中唯一有足够规模、流动性和多样性的单一国家市场。全球机构配置新兴市场时绕不开中国，即使增速放缓，绝对体量仍在增长。

**边界条件**：若地缘冲突升级到金融制裁（如冻结资产），全球资金被迫减持中国股票。

## 结构定位

本文是 `[[全球配置范式转变]]` 中11.7%十年预期的新兴市场横向比较版本，提供了更具体的相对回报数据。同时以宏观视角补充了 `[[关税行业冲击分化框架]]` 的GDP总量影响（-1pp），以及 `[[估值隐含回报VIR框架]]` 在中国股票上的实证应用。

# 新兴核心市场定位框架

## 核心命题

在全球新兴市场配置中，存在一个**不可替代的核心市场**——中国。它不是"可选之一"，而是"必要之锚"。

## 形式化表述

```
新兴市场配置 = 中国(核心) + 印度/其他(卫星)

中国核心地位 = f(体量, 流动性, 行业覆盖度)
其中：中国同时最大化这三个维度
```

## 三要素论证

| 要素 | 中国表现 | 其他新兴市场对比 |
|------|---------|---------------|
| **体量** | 新兴市场最大单一国家市场 | 印度虽增长快但体量不足 |
| **流动性** | A股+港股日均成交额远超其他单一市场 | 泰国、墨西哥流动性有限 |
| **行业覆盖度** | 覆盖制造业、科技、消费、金融全链条 | 单一市场行业结构偏窄 |

## 与 `[[全球配置范式转变]]` 的关系

`[[全球配置范式转变]]` 给出中国股票10年预期回报11.7%，本文则从新兴市场内部横向比较角度补充：**6.36%的年化预期回报在新兴市场同类资产中最高**。两者不矛盾，前者是绝对回报预期，后者是相对排序。

## 边界条件

- **地缘冲突触发条件**：若中美关系升级到金融制裁（如冻结海外资产），全球资金被迫减持中国股票，核心地位假设失效
- **时间窗口**：印度完成工业化后是否构成挑战，取决于其资本市场开放度和流动性改善速度

## 投资决策含义

1. 新兴市场配置不应"跳过中国"，即使对中国短期增长悲观
2. 中国仓位应视为"核心仓位"，印度等增长更快市场作为"卫星仓位"补充
3. 极端制裁情景是尾部风险，不应作为日常配置决策的主要依据

# 增速-估值倒挂现象

## 定义

经济增长速度放缓，但股票市场投资价值反而提升的现象。表面矛盾，实则遵循估值隐含回报的基本逻辑。

## 形式化表达

```
传统直觉: 增速↑ → 回报↑
真实逻辑: 增速↓ → 估值↓ → 隐含回报↑

示例（中国股票）:
1980-2024: 9%增速 + 高杠杆风险溢价 → 估值贵 → 隐含回报低
2026-2029: 3.6%增速 + 估值便宜 → 隐含回报6.36%（新兴市场最高）
```

## 作用机制

1. **增速放缓压低估值**：悲观预期充分定价，PE/PB跌至历史低位
2. **基数效应维持绝对增量**：3.6%增速的绝对量 > 9%增速的绝对量（GDP基数已扩大）
3. **中段含金量上升**：中高收入阶段的3.6% ≠ 追赶期的9%，结构转型后增长质量更高

## 边界条件

- **有效前提**：实际增速不低于隐含回报所需的最低门槛（中国约为3%）
- **失效条件**：若增速持续低于门槛，估值无法进一步压缩，隐含回报假设崩塌
- **时滞风险**：估值修复需要催化剂，悲观定价可能延续数年

## 与 `[[估值隐含回报VIR框架]]` 的关系

本概念是VIR框架在中国股票上的具体应用案例：增速放缓通过压低估值起点，反而提升了未来十天的预期回报。6.36%的数字来自晨星大类资产模型，体现了VIR的核心思想——**买入价格决定回报上限，增长速度决定回报下限**。

# 房地产企稳与复苏区分

## 核心区分

"企稳"和"复苏"是两个截然不同的阶段，混淆二者会导致对宏观经济判断的系统性偏差。

## 房价四阶段模型

```
阶段1: 急跌（房价快速下挫，市场恐慌）
阶段2: 跌幅收窄（下跌动能衰减，但未止跌）
阶段3: 企稳（价格不再下跌，但也不涨）← 中国当前所处
阶段4: 复苏（房价回升，正财富效应启动）
```

## 中国当前状态判定

- **观测指标**：2025年房价跌幅已收窄，住宅市场接近企稳
- **但**：负财富效应仍在抑制总需求
- **结论**：处于阶段3（企稳中），距阶段4（复苏）仍有距离

## 投资含义

1. **"企稳"不等于买入信号**：止跌只是避免了进一步恶化，不代表经济开始好转
2. **负财富效应滞后性**：即使房价企稳，居民因资产缩水减少消费的效应仍需时间消化
3. **下行风险**：若居民收入预期持续恶化，"企稳"可能退化为"下跌中继"，而非向复苏过渡

## 与宏观经济判断的关系

在判断中国整体经济吸引力时，房地产仍处于"拖后腿"状态——企稳减少了负面贡献，但尚未转为正向贡献。这解释了为何6.36%的预期回报包含了对房地产风险的折价。
