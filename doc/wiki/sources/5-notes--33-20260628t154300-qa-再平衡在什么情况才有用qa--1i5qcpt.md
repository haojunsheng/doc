# 再平衡在什么情况才有用

> 本文用五组实测数据检验再平衡的真实效果，核心结论：再平衡的真正价值是管风险，不是赚更多。

## 核心论点

再平衡并非万能神器——它只在特定条件下创造正收益，在其他条件下反而拖累回报。关键区分不在于操作本身，而在于所选的资产对。

## Q1: 再平衡创造收益的数学条件是什么？

**结论**：两类资产长期收益接近 + 期间波动差距大 = 再平衡效果最好。

**形式化公式**：
```
再平衡收益 ≈ (波动差距) × 频率 / (长期收益差距 + 1)
```

**逻辑**：再平衡本质是"低买高卖"的机械化执行，收益来自高卖低买的价差。价差越大收益越大；如果长期收益差距大，强势资产不操作反而赚更多。

**边界条件**：两类资产完全同涨同跌（如成长&价值），再平衡几乎零收益。

## Q2: 为什么 A股+债券/现金 效果最好？

**结论**：三者年化收益差距不超 3%，但 A 股波动远大于债券和现金，造成巨大价差空间。

**实证数据**（基于过去十年）：
- 年多赚约 0.5%
- 十年累积收益差约 +5%~6%

**逻辑**：收益相近 → 没有"踏空"成本；波动差异大 → 每次再平衡都能捡到便宜；十年复利累积后差异显著。

**边界**：结论依赖过去十年数据，若未来 A 股收益大幅下降则效果减弱。

## Q3: 为什么 A股+黄金、A股+全球股票做再平衡反而亏？

**结论**：长期收益差距大时，再平衡等于强制减仓表现最好的资产。

**形式化**：
```
再平衡操作: 强势资产权重 ← 人为压低
不操作策略: 强势资产权重 ← 自然升高
```

**逻辑**：黄金/全球股票长期跑赢 A 股，再平衡要求卖掉涨得多的、补到涨得少的，相当于自动减仓赢家。

**边界**：若黄金/全球股票未来长期跑输 A 股，结论反转。

## Q4: 谁也无法预测未来，那再平衡意义何在？

**结论**：意义从"提升收益"切换到"控制风险"——没人能预判，所以需要纪律。

**形式化价值判断**：
```
再平衡价值 = 收益增量大? (×) → 风险可控性 (✓)
```

**逻辑**：拉长到 20 年看，中国股票跑赢债券现金，再平衡效果显著；但站在任一时点，你不知道未来谁会赢。不再平衡会让组合仓位随涨跌漂移，风险逐渐失控。

**边界**：如果你确实能稳定预测资产表现（几乎没人能），那不需要再平衡。

## Q5: 再平衡最大的隐性收益是什么？

**结论**：不是多赚，是让组合风险始终留在你能承受的舒适区间。

**风险漂移机制**：
```
股票+现金组合:
  不操作 → 股票上涨 → 股票占比飙升 → 风险超承受力 → 被迫低点割肉
  操作   → 占比回归目标比例   → 风险可控        → 避免恐慌性卖出
```

**边界**：固定比例再平衡在极端单边牛市会牺牲部分收益。

## Q6: 再平衡发挥作用的根本前提是什么？

**结论**：必须先有一个明确的"初始配置"比例，否则再平衡无从谈起。

**形式化**：
```
再平衡 = 拉回目标比例
没有目标比例 = 操作无依据 = 随机交易
```

**逻辑**：再平衡是相对于某个基准的操作，基准来自你的投资目标和风险承受能力。

**边界**：目标本身可以随人生阶段变化，但每个时点必须有明确配置。

## 收口

作者用五组实测数据戳破了"再平衡万能"的幻觉：它不是收益机器，而是风险纪律。真正决定长期回报的，是你敢不敢在不确定性中保持一个多元结构。
