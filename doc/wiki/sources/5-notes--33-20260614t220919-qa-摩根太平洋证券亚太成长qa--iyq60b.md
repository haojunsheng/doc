# QA — 摩根太平洋证券亚太成长

摩根太平洋证券基金（968011）是一只香港互认基金，主要投资日本、澳大利亚和新西兰等亚太区股票。本文从投资方法论、风格稳定性、基金经理团队和费率四个维度分析该基金。

## 核心结论

自下而上精选高质量成长公司，风格稳定不漂移，适合有亚太配置需求且能接受成长风格波动的长期投资者。

## 关键数据

| 指标 | 数值 |
|------|------|
| 代码 | 968011 |
| 类型 | 香港互认基金 |
| 投资区域 | 日本、澳大利亚、新西兰等亚太区 |
| 年化回报（2015.06–2025.03） | 7.14% |
| 相对基准超额 | +98基点（跑赢晨星亚太市场股票TME指数） |
| 同类排名 | 第9个百分位 |
| 年化综合费率 | 1.62%（与同类中位数持平） |

## 形式化要点

**选股标准**：
```
选股标准 = 强大市场竞争优势 + 持续稳定盈利能力 + 稳健股本回报率 → 高质量成长
```

**风格暴露与业绩关系**：
```
风格暴露: 成长风格 > 价值风格
→ 成长行情: 跑赢；价值行情: 跑输
```

**基金经理团队**：
```
管理团队 = Asia Ogoshi（25年经验，管理该策略12年）
         + Robert Lloyd（近25年经验，与Ogoshi合作超10年）
         + Julian Wong（10年经验，候补）
```

**费率**：
```
年化综合费率 = 1.62% = 同类中位数
```

## 投资方法论

研究员按盈利增长、竞争优势可持续性、公司治理评估公司，将公司从高到低分四档，大多数个股来自前两档：

- **第一档**：资产负债表强劲 + 执行出色的管理团队
- **第二档**：运营良好 + 股东回报稳定

## 风格稳定性

基金组合风格稳定，不随市场风格漂移——这是长期超额收益的来源，也是阶段性跑输的根源：

- 2017、2019、2020年成长股占优时表现亮眼
- 2022–2023年价值股占优时表现偏弱
- 长期来看，质量成长风格在多数亚太市场环境中能创造超额收益

## 基金经理稳定性

- 主基金经理 Asia Ogoshi 管理该投资策略已超过12年
- 该基金与卢森堡注册的摩根太平洋股票基金持仓重合度99%
- EMAP股票投研团队超过100人，资源充沛
- Lloyd和Ogoshi合作超过10年，默契度高
- **边界条件**：远程合作可能存在沟通效率问题

## 费率评估

年化综合费率1.62%，与同类中位数持平。考虑到百人投研团队规模，费率合理。对费率敏感的投资者可以对比同类产品。
