# 伴读：曝光三角四课总结（光圈/焦段/快门/ISO）

**来源**：《摄影入门课》P3-P6 深度总结（伴读笔记，2026-07-26）

## 核心内容

本笔记是对《摄影入门课》前三课内容的整合性总结，以"曝光三角"为骨架，将光圈、快门、ISO、焦段四个参数统合在一个统一的决策框架下。

## 四个参数的本质

| 参数 | 控制什么 | 副作用 | 比喻 |
|---|---|---|---|
| **光圈** | 单位时间进光量（孔的大小） | 景深（清晰范围） | 水龙头开多大 |
| **快门** | 光照时间长短 | 运动模糊/凝固 | 水龙头开多久 |
| **ISO** | 传感器对光的敏感度 | 噪点 | 信号放大器增益 |
| **焦段** | 取景范围（视角） | 透视关系、空间压缩 | 你站到哪里 |

## 曝光三角的核心公式

```
总曝光量 ∝ (1 / F²) × 快门时间 × ISO
```

三个参数可以在**总曝光量不变**的前提下互相补偿——这就是**互易律**（Reciprocity Law）。

补偿的本质：你牺牲一个参数的"副作用"，换取另一个参数的自由。

| 操作 | 获得 | 代价 |
|---|---|---|
| 开大光圈换更快快门 | 运动凝固 | 景深变浅（背景糊） |
| 放慢快门换更小光圈 | 全景深 | 运动模糊、手震风险 |
| 提高 ISO 换更快快门/更小光圈 | 曝光充足 | 噪点增多 |

## 焦段的特殊地位

焦段**不在**曝光三角内。F 值已经把焦段"约掉"了——F8 在 28mm 和 200mm 上的曝光量一样。

但焦段间接决定透视：
- 广角 → 必须走近 → 近摄 → 距离比大 → 透视夸张
- 长焦 → 必须走远 → 远摄 → 距离比小 → 透视压缩

> **焦段不改变透视；焦段决定的拍摄距离才改变透视。**

这是对摄影教学中常见迷思的重要澄清——很多教材错误地说"长焦压缩空间"，实际上是拍摄距离在起作用。

## "正确"的终极标准

> **"正确曝光"是数学概念（18% 灰），"正确摄影"是美学概念（让特定的人在特定情境下得到他想要的感受）。**

四个参数没有"正确值"，只有**适合特定目的的值**。

## 哲学核心：机器视觉 vs 人眼视觉

这是全文最核心的洞见：

| | 人眼 | 相机 |
|---|---|---|
| 时间感知 | 连续、实时 | 可凝固（高速快门）或累积（慢门） |
| 清晰范围 | 固定（眼球对焦） | 可选择（光圈控制景深） |
| 感光能力 | 有限、不能积累 | 可积累（ISO + 长时间曝光） |
| 色彩感知 | 大脑自动白平衡 | 需要手动/算法校正 |

> **摄影不是复制现实，而是用机器的方式重新编码现实。**

杉本博司《剧院》系列（2-3 小时曝光）作为典型案例：整部电影的光被压缩成一块纯白画面——人眼永远看不到这样的画面，这是机器视觉的极致表达。

## 关键纠正

本文澄清了一个广泛存在的摄影教学误区：**长焦不压缩空间，拍摄距离才压缩空间。** 焦段通过决定拍摄距离间接影响透视，但直接改变透视的是距离本身。
