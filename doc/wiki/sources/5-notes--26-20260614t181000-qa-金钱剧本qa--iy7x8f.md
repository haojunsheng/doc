### Main Arguments & Findings

**核心论点**：财务决策的真正驱动力不是知识，而是童年塑造的"金钱剧本"——一套没有意识到、却自动运行的底层信念系统。知识只在"剧本允许"时才生效。

形式化表达（源文档给出）：
```
财务行为 = f(金钱剧本 × 情境触发)
金钱剧本 = 童年家庭金钱经历 × 关键情绪事件 × 认知简化
知识生效边界 = 金钱剧本允许的范围
```

**四种剧本的核心逻辑链：**

1. **金钱回避型**："钱 → 贪婪/堕落/危险"的内隐联结 → 财富增长触发焦虑 → 无意识财务自残（大额消费、借出不靠谱的人） → 财富无法积累

2. **金钱崇拜型**："钱 → 万能药"的内隐联结 → 任何情绪/关系问题 → 花钱作为第一响应 → 钱花完问题还在 → 更焦虑 → 循环强化

3. **金钱地位型**：自我价值 ∝ 可见消费水平 → 消费降级触发身份焦虑 → 被迫维持消费水平 → 储蓄率持续为负 → 财务脆弱性上升

4. **金钱警觉型**："灾难随时会来"的底层恐惧 → 储蓄目标 = f(焦虑水平) 而非实际需求 → 焦虑不随储蓄增加而下降 → 储蓄目标无限上移 → 生活质量持续被压缩

**改变路径**：知道剧本 ≠ 改变剧本（Q7）。旧神经通路易强，需大量"故意做不一样的事"建立新通路。核心机制是"觉察间隙"（Q8）：

```
旧模式：刺激 → 剧本自动运行 → 行为 → 后悔
新模式：刺激 → 觉察（"我的剧本在说话"）→ 选择 → 行为 → 对齐感
```

**边界条件**（源文档明确标注）：
- 童年家庭金钱关系健康、无极端事件者，剧本影响可能很弱——知识真正管用
- 极端政治动荡中，金钱回避可能反而是理性策略
- 时间压力极大时（限时抢购、突发紧急支出），觉察间隙无法激活——提前设好的规则才是保险
- 严重到影响正常生活时，自助改写不够，需心理咨询介入

### Contradictions & Tensions

**内部张力**：
- 源文档强调"知识无效论"（懂理财原则也管不住手），但又给出具体行动建议（48小时等待、预算上限、自动定投）。这两者之间需要解释：在时间压力下，预设规则确实比"临时觉察"更可靠——但这是否意味着金钱剧本在规则面前可以被绕过？源文档提到"提前设好的规则才是真正的保险"，但未深入讨论规则的来源（规则本身也可能来自金钱剧本）。

**与已有 wiki 内容的潜在张力**：
- [[concepts/投资计划优于市场预测]] 强调计划和规则的重要性，金钱剧本则提示"计划可能也是旧剧本的产物"——若没有觉察，即使制定了计划也可能在执行中偏离。两者不矛盾，但金钱剧本给"计划执行难"提供了更深解释。
