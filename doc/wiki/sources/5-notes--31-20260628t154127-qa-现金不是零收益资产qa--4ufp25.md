# QA — 现金不是零收益资产

来源：[[晨星中国]] · [Morningstar.cn](https://www.morningstar.cn/articles/2f0845259ce27a5b4fd403c9a87a639d.html) · 2026-06-28

## 核心结论

晨星的核心贡献是：将现金从"无收益的默认选项"重新定义为"有战略意义的战术配置"，并给出三层刚需框架帮助普通人决定现金仓位。

## Q&A 摘要

| 问题 | 结论 | 形式化 |
|------|------|--------|
| 现金的长期收益到底怎样？ | 30年维度刚好跑赢通胀；利率持续下降趋势下，未来现金实际回报可能为负 | 现金30年收益 ≈ 通胀率，利率↓ → 未来实际收益 < 0 |
| 为什么"现金为王"不是在市场下跌时说的？ | 市场下跌时持有现金往往是损失厌恶和近因偏差导致的情绪反应，而非理性决策 | 市场下跌 ≠ 持有现金信号 \| 估值过高 = 持有现金信号 |
| 什么时候该持有现金？ | 市场估值过高、缺乏有长期价值的投资机会时，现金是等待部署的弹药 | 持有现金时机 = 高估值 + 无长期机会，非 = 市场下跌 |
| 调整现金仓位是不是一种择时？ | 是的，本质上就是市场择时，普通人很难做好，应谨慎评估自身能力 | 调整现金仓位 = 市场择时 → 难度高 → 适得其反风险 |
| 普通人应该留多少现金？ | 应急金 + 短期支出（1-2年） + 退休支出（1-2年生活费），超出部分才考虑投资 | 现金刚需 = 应急金 + 短期支出 + 退休支出 |

## 关键论点

### 论点1：现金有收益，不是零资产

- 以短期定存利率作为现金收益参考
- 拉长到30年刚好跑赢通胀
- 2000年初利率较高时现金确实不错
- 近年利率水平不断下降，低利率环境中现金收益越来越低
- **边界**：若全球进入高利率周期，现金吸引力会重新上升

### 论点2："现金为王"的正确使用时机

- 容易受损失厌恶（亏1元的痛苦需涨2元才能弥补）和近因偏差影响
- 市场低迷时恐惧性持有现金是情绪驱动，不是理性决策
- 应基于**估值比较**而非恐惧做决策
- 高估值意味着未来下行风险大，此时保留现金是正确的
- **边界**：若市场从高位快速下跌到极端低估，此时持有现金观望可能合理
- 判断估值高低本身需要能力，错误判断可能导致"高买低卖"

### 论点3：调整现金仓位 = 择时

这是本文最重要的认知纠偏：**主动增减现金仓位本质上就是在做市场择时。**

```
调整现金仓位 = 市场择时
市场择时 → 难度高 → 普通人适得其反风险
```

普通人应谨慎评估自己是否具备这种能力。坚持长期投资计划往往比频繁调整现金仓位更可靠。

**例外**：机械化的再平衡策略（如股债固定比例）是规则化操作，不属于择时。

### 论点4：三层刚需框架

普通人现金仓位的**刚性下限**由三个层次决定，超出部分才考虑投资：

```
现金刚需 = 应急金 + 短期支出 + 退休支出
```

| 层级 | 用途 | 建议覆盖时长 |
|------|------|------------|
| 应急金 | 应对突发支出（失业、疾病等） | 3-6个月必要开销 |
| 短期支出 | 1-2年内可预见的大额消费（购车、装修等） | 1-2年相关支出 |
| 退休支出 | 退休后1-2年生活费储备 | 1-2年退休生活费 |

**原则**：不因利率低就减少必要的现金储备。现金在投资组合中的角色首先是**流动性保险**，其次才是战术弹药。
