# 概念解剖 — 经济周期

**来源文件**：`notes/20260614T210625--概念解剖-经济周期__concept.md`
**核心命题**：经济周期与市场周期天然错位——股市是预言家而非反映者，预测未来现金流；经济指标是后视镜，反映已发生的状况。两者脱钩是常态，而非例外。

## 八刀结构

### 历史刀
- **技术性衰退定义**：连续两个季度GDP负增长，由经济学家提出。
- **NBER标准**：更严格——经济活动显著下降、扩散至整个经济体、持续数月以上。
- **关键案例**：2021年2月至2024年，沪深300下跌近40%，但中国经济并未连续两季度负增长——股市与经济脱钩。

### 辩证刀
- **经济周期看"当下"**：失业率、PMI、CPI都是滞后指标。
- **市场周期看"未来"**：股市估值基于未来现金流预测，是前瞻性指标。
- **核心隐喻**：经济是后视镜，市场是前照灯。两者经常不同步。

### 现象刀
- [[entities/保罗-萨缪尔森-paul-samuelson|保罗·萨缪尔森]]经典嘲讽："在美国过去的五次经济衰退中，美股'成功地'预测到了九次。"
- 市场比经济学家更容易受惊吓，对坏消息的提前定价常常超出后续实际经济下滑的程度。

### 语言刀
- "熊市"定义：从近期高点下跌20%或更多——纯粹的数学定义，与经济基本面无关。
- 熊/牛是市场情绪的动物化投射。
- **核心洞见**：周期不是客观规律，是集体心理的投射。

### 形式刀
经济衰退的触发器（因果链）：
1. 信心下降 → 消费减少 → 企业裁员 → 消费更少（恶性循环）
2. 高利率 → 债务负担加重 → 破产增加 → 连锁反应
3. 通胀飙升 → 购买力下降 → 消费萎缩
4. 通缩 → 消费推迟 → 需求坍塌

熊市的触发器：经济疲软、对未来预期悲观、投资者信心危机。

### 存在刀
- **经济靠预期运转**：当所有人相信经济会好，消费和投资就会增加，经济果然变好（自我实现的乐观）；当所有人相信经济会差，消费和投资就会减少，经济果然变差（自我实现的悲观）。
- **核心论断**：周期不是自然规律，是集体预期的共振。

### 美感刀
- 经济周期的美感在于**不可预测的韵律**——你知道有潮起潮落，但不知道下一次潮汐的精确时间。
- 这种不确定性既是风险也是机会。

### 元反思刀
- **核心警告**：如果你等"确认经济复苏"再入场，可能已经错过了大部分涨幅；如果你等"确认经济衰退"再离场，可能已经亏损了大部分本金。
- **周期的价值**：不在于预测，而在于理解市场永远在"定价预期"而非"定价现实"。

## 深层结构：预期的自我实现

辩证刀、现象刀、存在刀、元反思刀共同指向同一个深层结构——**预期的自我实现**：

```
市场预测经济 → 预测改变行为 → 行为改变经济 → 经济又改变预期
                ↑________________________________________________↓
                              永恒的反馈循环
```

## 压缩公式

`经济周期 = GDP波动 × 就业变化 × 政策响应 × 集体预期共振`

**一句话**：经济周期不是自然潮汐，是集体预期的自我实现——市场永远在定价未来，而非当下。
