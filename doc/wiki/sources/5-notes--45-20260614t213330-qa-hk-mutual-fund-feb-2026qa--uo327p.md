# QA — 2月香港互认基金：高股息策略吸金，债基受额度限制

> 晨星中国 Q&A —— 2026年2月香港互认基金资金流向分化格局分析。

## 核心现象：股债冰火两重天

2026年2月香港互认基金市场延续"股债冰火两重天"格局：混合型基金瑞士百达策略收益单月吸金32.7亿，股票型摩根亚洲股息基金净流入25.39亿；但债券型基金因客地销售额度限制普遍净流出，摩根国际债券基金流出规模居首。

**核心矛盾**：投资者需求旺盛，但政策额度成为瓶颈。

## Q1: 为什么高股息策略在2月受追捧？

*结论*：因为利率下行预期+市场波动加剧，高股息策略的"稳定现金流+低波动"特征正好匹配投资者需求。

*形式化*：利率↓ + 市场波动↑ → 投资者风险偏好↓ → 高股息策略（低波动 + 稳定现金流）→ 资金流入

*证据*：摩根亚洲股息基金2月净流入25.39亿，排名第二。

*边界*：如果利率大幅上行（如通胀失控），高股息策略的吸引力会下降。

*关联*：与 [[高股息陷阱风险]] 形成对照——当前资金大量涌入高股息策略，本身可能就是拥挤度上升的信号。

## Q2: 为什么"客地销售比例限制"会让债券基金暂停申购？

*结论*：因为监管要求香港互认基金在内地销售不能超过一定比例，额度用完就必须暂停申购。

*形式化*：客地销售比例限制 → 内地销售额度上限 → 额度用完 → 暂停申购 → 资金流入渠道切断

*证据*：中银香港全天候亚洲债券基金1月27日恢复申购→2月5日暂停→3月11日恢复，额度是"动态管理"的。

*边界*：如果监管放宽客地销售比例，债券基金可能迎来资金回流。

*关联*：这是对 [[客地销售比例限制]] 概念的实时实证补充，展示了额度恢复→暂停→再恢复的完整周期。

## Q3: 为什么瑞士百达策略收益基金能"延续领跑态势"？

*结论*：因为其灵活配置策略在过去一年业绩显著优于同类，形成了"业绩→资金流入→规模增长"的正循环。

*形式化*：灵活配置全球股债 + 过去一年业绩领先 → 资金持续流入 → 2月净流入32.7亿，今年以来累计80.24亿

*边界*：如果业绩领先优势消失（如市场风格转变），资金流入速度会放缓。

*关联*：这是 [[规模激增与业绩反转]] 概念的典型前置案例——当前规模正循环的可持续性需持续关注。

## Q4: 为什么摩根"股票与债券产品资金流向分化明显"？

*结论*：因为摩根的股票基金（高股息策略）受追捧，但债券基金（国际债券）遭赎回，两者方向相反。

*形式化*：摩根股票型（高股息）→ 净流入；摩根债券型（国际债券）→ 净流出 → 整体分化

*证据*：股票型摩根亚洲股息基金2月净流入25.39亿；债券型摩根国际债券基金当月净流出规模居首。

*关联*：这是对 [[策略选择优于大类选择]] 概念的强实证支撑——同样是摩根系，股票"吃肉"，债券"喝汤"。

## Q5: 为什么"汇丰受债券产品持续失血拖累"？

*结论*：因为汇丰旗下的多只债券基金都持续净流出。

*证据*：汇丰亚洲债券、汇丰亚洲高收益债券、汇丰亚洲高入息债券等产品均持续出现不同程度资金流出。

## Q6: 为什么"中银香港全天候亚洲债券基金"能"逆势净流入6.91亿"？

*结论*：因为该基金在1月底恢复了内地申购，资金集中涌入，虽然后来暂停过，但3月再次恢复。

*形式化*：恢复申购（1月27日）→ 资金集中流入6.91亿 → 暂停（2月5日）→ 再恢复（3月11日）

*关键洞察*：这个净流入是"恢复申购窗口"驱动的，不是业绩驱动；一旦额度再次用完，流入会停止。

## Q7: 从"摩根互认基金产品资产规模达867.6亿元，市场份额超40%"能推断出什么？

*结论*：说明摩根在互认基金市场具有"先发优势+全面产品布局"，即使短期资金流出，规模优势仍难以撼动。

*证据*：摩根规模867.6亿、份额超40%；汇丰、惠理分别位列第二、第三，但规模差距明显（200亿 vs 867亿）。

## 收口：结构重于总量

晨星2月互认基金报告揭示了一个核心规律：**资金流向的"结构"比"总量"更重要**。

| 同样是净流入 | 同样是净流出 |
|------------|------------|
| 高股息策略"吃肉" | 纯债基金"喝汤" |
| 同公司不同品类流向相反 | 规模第一也挡不住策略失血 |

投资者需要看清结构，才能理解自己的钱在经历什么。
