# 基金业绩归因——基金赚钱≠你赚钱，中间差了什么

**原文**：[晨星中国](https://www.morningstar.cn)  
**发布日期**：2026-06-14  
**标识符**：20260614T115908

## 一句话摘要

基金业绩不是黑箱，而是**市场风格β + 行业配置α + 个股选择α + 运气ε**四层叠加的结果；看懂这四层，才能分清基金经理是真本事还是踩了风口。

## 核心框架

### 基金业绩归因等式

```
基金业绩 = 市场风格β + 行业配置α + 个股选择α + 运气ε
```

| 层级 | 含义 | 可控性 |
|------|------|--------|
| 市场风格β | 基金经理的风格（价值/成长）与当期市场偏好的匹配程度 | 不可控，外生因素 |
| 行业配置α | 超配/低配某行业的判断 | 部分可控 |
| 个股选择α | 行业内选到优质个股的能力 | 真正可控制的 alpha |
| 运气ε | 无法归因的随机冲击项 | 不可控 |

### 好基金的定义

```
好基金 ≠ 某一年排名第一
好基金 = 每个完整周期（牛熊都经历过）都排前 1/3
```

## 关键案例

### 大成高新技术产业（000628）— Q3 选股能力验证

- 风格：成长风格逆风期
- 关键动作：靠通信、家电、石油石化选股贡献超额收益
- 结论：真本事 = 风格逆风时靠选股少亏甚至赚钱

### 工银创新动力（000893）— Q3 顺风期甄别

- 风格：价值风格顺风期
- 关键事实：同类价值基金中排名前列
- 结论：顺风期人人都是"明星"，需在同风格内部比较才能识别真选股能力

### 广发睿毅领先（005233）— Q4 行业集中风险

- 重仓：航空 + 商贸零售
- 行业表现：航空/零售基本面持续恶化
- 结果：基金业绩落后
- 核心教训：行业选择不是"选好的"，是"选对的时候选对的"

### 景顺长城鼎益（162605）— Q5 完整周期评价

- 2017–2020：连续四年跑赢中证 800
- 2021 后：风格逆转，大盘成长逆风，业绩落后
- 结论：历史业绩≠未来能力，方法论稳定性比短期排名更重要

### 广发创新升级（002939）— Q5 风格逆转风险

- 2019–2020：成长风格顺风期大赚
- 2021 后：重仓新能源，风格逆转大幅亏损
- 结论：风格逆转可以瞬间抹去多年积累的超额

## 市场数据支撑

### 2023 年上半年风格分化

- 中证 800 价值指数：+3.35%
- 中证 800 成长指数：-6.16%
- 说明：同样能力的基金经理，风格站对方向已赢第一步

### 2023 年行业极端分化

- TMT 板块：通信 +50%、传媒 +42%
- 房地产：-14%
- 商贸零售：-23%

## 边界条件

1. **风格不显著的单边行情**（普涨或普跌）：风格因子的解释力下降
2. **短期（1 年内）业绩**：可能完全由风格驱动，看不出选股能力——至少要看 3–5 年
3. **行业分散不是万能药**：过度分散会稀释收益，关键是理解自己在赌什么
4. **历史不代表未来**：基金经理换人、策略漂移、市场结构变化都可能打破过往规律

## 对投资者的启示

1. 不要因短期业绩差就否定基金经理——先判断是风格逆风还是能力问题
2. 不要用短期业绩好就追捧基金经理——顺风期人人都是"明星"
3. 用完整周期评价——至少跨 3–5 年，看牛熊两轮
4. 关注基金经理的方法论是否稳定、是否知行合一
