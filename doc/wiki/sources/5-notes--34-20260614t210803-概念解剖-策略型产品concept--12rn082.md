# 策略型产品

## 定义

以债券投资为主策略获取稳定收益打底，小部分仓位配置风险资产（股票/可转债）增强收益的投资策略统称。典型代表为[[concepts/固收+]]，晨星分类下包括积极债券型和保守混合型两类。

本质是**用固定收益作盾，用风险资产作矛**的组合拳。

## 结构框架

```
策略型产品 = 主策略（固定收益，作盾） + 增强策略（风险资产，作矛）
```

常见动态调整策略包括 [[concepts/CPPI]]（固定比例投资组合保险）和 [[concepts/OBPI]]（期权型投资组合保险）。

## "+"号的修辞陷阱

"+"在名称中暗示增益，但隐藏了风险。投资者因名称中的"固收"二字产生信任锚定，"+"激发收益想象，却忽略了"+"变成"-"的可能性。这与[[concepts/保本幻觉]]构成同一认知机制的不同变体——[[concepts/保本幻觉]]侧重对本金安全的错觉，策略型产品的修辞陷阱侧重对增益的想象。

当债券和股票同时下跌时（股债双杀），策略型产品失去保护，变成亏损产品。

## 评估准则

穿透持仓看真实风险暴露。评价"+"部分的质量应使用风险调整收益指标，而非绝对收益率：

- **夏普比率**：单位总风险的超额收益
- **卡玛比率**：年化收益与最大回撤之比
- **最大回撤**：历史最坏情况下的损失幅度

[[sources/5-notes--29-20260614t124755-qa-固收加产品选择qa--1cu68us]]提供了基金经理和投资流程的定性评价框架，与本文的量化准则互补。

## 存在的悖论

若市场有效，"+"的超额收益从何而来？这是策略型产品存在的根本张力：一方面，单一资产无法满足所有投资者需求，策略型产品填补了这一空白；另一方面，其增强部分的超额收益来源需要解释——通常来自承担更高风险、承担信用下沉风险，或承担风格漂移风险。

## 内观

- 我是否理解"+"背后的真实风险？
- 我是否把"固收+"当成了"稳赚不赔"的代名词？
- 我是否穿透了持仓，看到真正的资产配置比例？

常见盲区：过度关注"+"的收益潜力，忽视"-"的下跌风险；把策略型产品当成无脑持有的"懒人投资"。
