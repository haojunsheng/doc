# 概念解剖 — 赛道投资（主题投资）

来源：`notes/20260614T210908--概念解剖-赛道投资__concept.md`

## 核心论点

赛道投资的真正风险不在赛道本身，而在于投资者总是在共识形成后才进场。

> "赚钱最锋利的矛，也会成为让你亏钱的毒药。"

## 概念定义

**赛道投资（Thematic Investing）**：选定一个特定的投资主题，筛选出为该主题提供产品/服务支持的企业构建组合。本质是用增长叙事包装集中押注——选对赛道躺赚，选错赛道亏惨。

## 三条核心论据

1. **时间窗口悖论**：A股板块轮动使赛道热度短暂，真正的超额收益窗口极短。2020-2021年"茅赛""宁赛"、2023-2024年AI vs 消费的分化均为明证。
2. **产品供给侧扭曲**：基金公司在赛道热门后才集中发行相关基金，供给侧响应滞后于市场信号，进一步压缩普通投资者的入场窗口。
3. **同赛道业绩分化超30%**：即便选对赛道，最好与最差基金年化差距超30%，说明"选对赛道"本身不足以获利。

## 八刀分析框架摘要

| 刀 | 要点 |
|----|------|
| 历史 | 2020-2021"茅赛""宁赛"、2023-2024 AI vs 消费分化，A股板块轮动明显 |
| 辩证 | 选对早期弹性极高 vs 集中度高、波动大、买在高点；基金总收益远高于投资者实际收益 |
| 现象 | "老登资产"vs"小登资产"标签更替即赛道轮动；基金热点追发；同赛道最好与最差基金年化差距超30% |
| 语言 | "赛道"暗示速度与竞争；"锋利的矛"vs"毒药"揭示两面性；"躺赢"低估难度 |
| 形式 | 载体为主题基金（主动/被动ETF），窄基、高集中度、高波动 |
| 存在 | 市场对增长故事永远有需求；赛道一旦成为共识，超额收益消失；散户无信息优势却偏好信息密集型投资 |
| 美感 | 叙事之美、弹性之美、刀尖跳舞的危险之美 |
| 元反思 | 赛道投资是否只是后见之明的幸存者偏差？我们是在投资赛道还是投资自己的乐观偏见？ |

## 行动准则

- 赛道基金只作卫星仓位（<20%），核心仓位留给宽基
- 自我检验：买入时是否已涨很多？能否在回撤50%时坚持？持仓是否过于集中？
