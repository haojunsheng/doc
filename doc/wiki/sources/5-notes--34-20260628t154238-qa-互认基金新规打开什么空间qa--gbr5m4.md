### Main Arguments & Findings

**核心论点：2026年6月互认基金新规是两个质变，不是小修小补**

| 论点 | 证据 | 强度 |
|------|------|------|
| 销售空间放大60% | 客地比例从50%→80%，原暂停申购基金可重新开放；上半年互认基金获104亿净申购创历史新高 | 强（政策明确+数据验证） |
| 投资范围突破亚洲限制 | 允许管理职能转授权，162只基金出现全球/美/欧/日等非亚洲方向产品 | 强（符合新规名单已验证） |
| 现存基金以债券型为主（规模74%） | 39只中债券17只（规模74%）、股票18只（20%）、混合4只（6%） | 强（精确数据） |
| 2020年互认基金净流出源于A股领涨 | 2020年A股涨幅领先，北上基金净流出18亿 | 强（因果链条清晰） |

**形式化关键数据：**

```
2023年以来表现对比：
  A股年化收益率：-2.65%
  标普500年化收益率：+31.69%
  纳指年化收益率：+47.56%

2026年上半年：
  互认基金净申购：104亿元（历史新高）

新规框架：
  旧规：内地销售 ≤ 50% 总资产 → 暂停申购
  新规：内地销售 ≤ 80% 总资产 → 空间↑60%
  管理职能：香港本地团队 → 可转授权海外团队

现存39只基金结构：
  债券型：17只，规模占比74%
  股票型：18只，规模占比20%
  混合型：4只， 规模占比6%

符合新规的162只基金池：
  区域覆盖：全球、美、欧、日、印、韩、泰
  新增类型：健康护理、消费、基建行业股票型
  晨星铜牌及以上：11只（覆盖16只新规基金）
```
