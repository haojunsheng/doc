# 高主动持股比例不等于高业绩

> Morningstar 晨星中国 — 通过主动持股比例数据，揭示"主动≠好业绩"的反直觉结论。

## 核心论断

主动持股比例高的基金，并不等于业绩更好。2024年数据显示，主动持股比例三个区间（0–80%、80–90%、90–100%）的基金战胜率没有显著差异。真正的关键不是"有多主动"，而是基金经理的能力是否匹配其偏离度。

## 六个关键问题

### Q1：为什么高主动持股比例不等于高业绩？

**形式化**：`主动持股比例↑ ≠ 战胜率↑`

主动持股比例只是"描述性工具"（告诉你基金有多主动），不是"预测性工具"（不能预测未来业绩）。高主动可能是"盲目的主动"——偏离增加风险但不增加收益。

**边界**：若基金经理能力出众，适度偏离可创造超额收益；若能力不足，高偏离只会加大波动。

### Q2：为什么主动持股比例骤降需要警惕？

**形式化**：`主动持股比例骤降 = 规模↑导致选股困难 ∨ 策略变更`

典型案例：[[中欧均衡成长混合]] 2024年将策略改为对标沪深300的指数增强，主动持股比例从90%降至不足60%。可能原因：
- 规模膨胀导致选股困难（无法保持过去的高偏离度）
- 基金经理主动更改策略（如改为指数增强）

**边界**：若策略变更合理且适应市场环境，未必是坏事；若为规模失控所致，需重新评估。

### Q3：为什么主动持股比例骤升也需要警惕？

**形式化**：`主动持股比例骤升 = 押注单一行业 → 组合风险高度集中`

典型案例：[[前海开源沪港深龙头精选]] 主动持股比例从60%升至近100%，84%持仓集中于医药一个行业，一旦行业风险事件发生，净值大幅下滑。

**边界**：若基金经理对单一行业有深入研究且风险可控，集中配置可能带来超额收益；若只是追热点，风险极大。

### Q4：什么是"伪主动"基金？

**形式化**：`伪主动 = 主动持股比例<60% + 高费率（1.2%） → 持仓与基准高度重合 → 扣除费用后几乎不可能跑赢基准`

晨星以60%为阈值划分"真主动"与"伪主动"。2025年6月底，1749只主动偏股型基金中有20只主动持股比例低于60%，但仍收取1.2%行业通行管理费率。

### Q5：为什么"伪主动"基金损害投资者利益？

**形式化**：`投资者支付：高费率（1.2%） 获得：接近指数的回报 → 不如买低费率（0.15%）的指数基金`

"伪主动"基金收着高昂的主动管理费，做的却是复制指数的工作，扣除费用后几乎不可能跑赢基准，对投资者不利。

### Q6：新规下如何平衡"主动风险"与"偏离超额"？

**形式化**：`新规下主动管理 = 基准为锚 ∩ 能力圈 ∩ 偏离度 ∩ 风险控制`

以基准为锚，在能力圈内权衡偏离度与风险控制，避免两个极端：
- **盲目主动**：高偏离 + 低能力 → 增加风险不增加收益
- **伪主动**：低偏离 + 高费率 → 收取高额费用却不创造阿尔法
