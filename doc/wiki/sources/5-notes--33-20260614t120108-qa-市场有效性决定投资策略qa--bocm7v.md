# 市场有效性决定投资策略

**来源**：晨星（Morningstar）
**日期**：2026-06-14
**标识符**：20260614T120108

## 核心命题

> 市场是否有效不决定你该不该主动投资——**你的能力才是**。在低效市场里，没能力的散户参与主动游戏，只会成为有能力者的猎物。被动投资不是"放弃赚钱"，是"避免亏钱"。

## 形式化推理链

```
有效市场 → 无人能战胜市场 → 被动最优
无效市场 → 超额收益流向有能力者 → 无能力者参与 = 被收割 → 被动避险
∴ 无论市场是否有效，被动投资都是普通人的理性选择
```

## 核心问题

### Q1: 什么是"有效市场"？分哪几类？

有效市场是指价格已经反映了所有可获得信息的市场，分三类：

| 效率层级 | 定义 | 含义 |
|---------|------|------|
| 弱式有效 | 价格反映所有历史交易信息 | 技术分析无法获得超额回报 |
| 半强式有效 | 价格反映所有公开信息（财报、经济数据等） | 基本面分析也徒劳 |
| 强式有效 | 价格反映所有信息（含内幕） | 即使内部人也无法获得超额回报 |

现实中大多数市场处于弱式到半强式之间。

### Q2: 为什么"低效市场更适合主动投资"是错的？

传统观点：市场越无效，主动投资机会越多。

修正观点：
- 低效市场里，超额收益属于"有能力的投资者"
- 没能力的散户反而更容易被收割
- **市场无效 ≠ 你能从中获利**

三类参与者：
1. 有能力的主动投资者（能识别错误定价）
2. 无能力的主动投资者（试图但无法识别错误定价）
3. 被动投资者（不参与主动博弈）

### Q3: 被动投资为何在两种市场都适合普通人？

| 市场状态 | 逻辑 | 策略含义 |
|---------|------|---------|
| 完全有效市场 | 无人能战胜市场，成本决定回报 | 被动最优（控制成本） |
| 不完全有效市场 | 无能力者参与=被收割 | 被动避险（避免沦为对手方） |

被动投资的核心是**拥有整个市场**——不赌任何个股或行业，只依赖市场长期向上。

### Q4: 谁应该参与主动投资？

只有两类人：
1. **真正有能力的人**（持续跑赢指数 + 清晰投资框架）
2. **愿意为刺激买单的人**（主动游戏本身就是体验）

前者赚钱，后者买体验。没有第三种正当类型。

### Q5: 普通人如何判断自己有没有投资能力？

两个检验标准：
- 过去三年选股收益是否持续跑赢基准指数（如沪深300）
- 能否清晰解释每笔买入的逻辑

若无法做到，大概率没有主动管理能力，应转向被动投资。
