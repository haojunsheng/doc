# QA — 市场预测为什么靠不住

来源：晨星（Morningstar）行为金融研究团队
创作时间：2026-06-14

## 核心论点

市场预测远比天气预报困难，因为市场参与者的行为会改变被预测的对象。连顶级机构的预测准确率也低于随机（0% < 50%），行业持续生产预测是因为结构性需求——客户要确定性，机构要营销。

## 五问结构

### Q1: 专业机构的市场预测，准确率到底有多低？

**结论**：低得离谱。中金公司2023年十大预言全错，比抛硬币还差。

**形式化**：

```
中金2023年预测: 10条 → 0条正确
抛硬币预期:     10条 → 约5条正确
预测准确率:     0% < 50%（随机）
```

**证据**：中金2022年10条错9条，2023年继续观察，10条全错。

**边界**：这是单家机构数据，不代表所有机构都这么差，但整体来看预测准确率普遍不高。

---

### Q2: 为什么市场这么难预测？

**结论**：因为市场不是天气——预测行为本身会改变市场走势。

**形式化对比**：

| 维度 | 天气 | 市场 |
|------|------|------|
| 预测是否影响结果 | 否 → 可预测 | 是 → 预测失效 |
| 研究对象 | 物理系统 | 人的博弈 |
| 规律被套利 | 无此机制 | 聪明人发现规律 → 套利 → 规律消失 |

**机制**：

```
预测 → 影响投资者行为 → 改变市场走势 → 预测失效
```

**边界**：并不意味着市场完全不可预测，而是说长期稳定的预测非常困难。

---

### Q3: 既然预测不准，为什么机构还年年开策略会？

**结论**：因为投资者需要"确定性幻觉"，而金融机构需要营销。

**结构性矛盾**：

```
投资者心理: 出钱 → 想要确定性 → 更信"笃定"的顾问
金融从业者: 自信 → 混得更好 → 被迫表演确定感
机构层面:   策略会 = 营销行为（非研究行为）
```

**关键引用**：

- 达里奥（Ray Dalio）1987年论文："预测的价值并不很高，大多数做预测的人并没有在市场上赚钱。"
- 研究显示：自信的人在金融行业更成功。
- 极少有客户愿意听"我不知道"。

**边界**：不是所有机构都纯粹为了营销，有些确实在做严肃研究，但营销动机确实存在。

---

### Q4: 预测不准是 A 股特有的吗？

**结论**：不是，全球金融行业的预测准确率都不高。

**跨市场证据**：

- **A股**：预测打脸常见
- **美股**：预测打脸同样常见
- **霍华德·马克斯**："未来在多大程度上能预测是个哲学问题"
- 晨星行为金融团队研究：金融预测准确率低于"丢硬币"

**边界**：不同市场的有效性不同，但预测困难是普遍现象。

---

### Q5: 普通投资者应该怎么看待年终策略会？

**结论**：看逻辑，不看结论——策略会的价值在于理解市场分歧，而非抄作业。

**两种策略对比**：

```
错误策略: 策略会结论 → 直接买入
正确策略: 策略会逻辑 → 理解市场分歧 → 形成自己的判断
```

**根本逻辑**：

- 市场里只有一件事确定：什么都不确定
- 如果预测真的准确，预测者自己早就发财了，不需要靠写策略报告变现
- 反例：2019-2020年按"常理"抱团核心资产的人被反噬

**边界**：完全不看策略会也不对，关键是带着批判性思维看，而不是盲目相信。

---

## 收口

预测的价值不在于准确，而在于帮你理解市场在想什么——然后做好他们猜错的准备。
