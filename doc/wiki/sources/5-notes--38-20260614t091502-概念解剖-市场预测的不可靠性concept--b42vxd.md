# 概念解剖：市场预测的不可靠性

来源：晨星文章《又到年终策略会！满天飞的预言哪条最靠谱？》
创作时间：2026-06-14

## 核心论点

金融市场的极端复杂性和反身性，使得专业投资者的预测准确率长期低于随机，远低于"有用"的阈值。

本质：**预测者 vs 被预测系统的博弈困境**——预测本身会改变被预测的对象，预测者成为系统的一部分。

## 主要论据

### 实证案例

- **中金公司10条预言**：2022年错了9条，2023年10条全错
  - 预测美国衰退 → 美国经济数据良好
  - 预测A股正收益 → 沪深300原地踏步
  - 预测通胀压力 → CPI转负
  - 预测地产复苏 → 暴雷不断
- **达里奥（Ray Dalio）1987年论文**《赚钱还是做预测》："大多数做预测的人并没有在市场上赚钱……原因是没有什么是确定的。"
- **晨星行为金融团队研究**：金融预测准确率甚至低于"丢硬币"（50%胜率）

### 类比论证

市场比天气复杂得多：
- 天气有物理规律，可以精确建模
- 市场有人博弈，预测本身会改变结果

### 行为金融观察

**自信偏差**：自信的金融从业者在行业中更成功，即使预测不准——自信是职业需求，不是能力证明。

## 行业结构分析

### 策略会的本质

年终策略会是**营销行为**，不是投资指导。结构性矛盾在于：

- 客户要求确定性
- 机构只能卖幻觉
- 打脸本身也是流量密码

### 反身性机制（索罗斯概念）

预测影响行为 → 行为改变结果 → 结果推翻预测 → **预测者成为系统的一部分**

一旦某个预测被广泛相信，套利者会迅速消除它试图预测的模式——"天机"一旦公开就不再是天机。

## 语言批判

| 词汇 | 暗示 | 现实 |
|------|------|------|
| "预言" | 确定性 | 市场没有预言家 |
| "策略会" | 投资指导 | 营销行为 |
| "打脸" | 自嘲 | 行业对预测失败的习以为常 |
| "确定性" | 客户想要听的词 | 霍华德·马克斯说"未来在多大程度上能预测是个哲学问题" |

## 实用建议：情景推演 > 单点预测

预测的正确打开方式不是"市场会怎样"，而是**"如果市场怎样，我该怎么办"**。

形式化表达：

```
情景推演 = 列出多种可能路径 → 为每种路径预设应对方案 → 不赌单一结果
```

与 [[concepts/核心假设-退出信号框架]] 高度一致：核心假设是"如果怎样"的表达，退出信号是"怎么办"的操作化。

## 局限与自指悖论

1. **幸存者偏差**：文章只打脸了中金，其他机构的正确预测不被记载
2. **自指悖论**：声称"市场不可预测"的文章本身是一个关于市场的预测
3. **建构不足**：拆了预测的台，但没给出"如果不预测，该怎么投资"的具体路径
