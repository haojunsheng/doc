# 伴读 — 基金经理换手率段位

来源：晨星文章《想知道基金经理什么段位？两个指标告诉你》

## 一句话摘要

用**换手率**和**晨星星级**两个维度给基金经理分成四档，帮投资者识别谁是真大师、谁是"机构韭菜"。

## 核心论点

> 基金经理的嘴可能是骗人的鬼，但是他的组合不会骗人的。

文章从质疑市场上"长期持有"口号的真实落地出发，提出换手率可作为"言行一致性检验工具"，并给出四象限分类框架作为行动指南。

## 换手率定义与计算

基金主要投资于一篮子的股票或债券。假设年初组合为 A、B、C，年中全部卖出买入 D、E、F，换手率 = 100%；若临近年底再次全部换为 G、H、I，则年化换手率 = 200%（一年两次换血）。

计算公式：

```
换手率 = min(买入金额, 卖出金额) / 年内基金平均净资产
```

数据来源：基金年报中披露的股票买卖成本。

## 换手率三大影响因素

### 1. 投资策略

| 策略类型 | 描述 | 换手率特征 |
|---------|------|-----------|
| 买入持有 | 赚取上市公司长期业绩增长的钱 | 低，通常 <100% |
| 自下而上选股 + 行业景气判断 | 在行业轮动与个股精选间寻求最优解 | 中等 |
| 见风使舵型 | 靠择时和交易挣钱，做波段 | 高，常 >300% |

### 2. 投资期限与眼光精准度

理论上看，能做到以 **3-5 年时间维度**投资且看得准、拿得住的基金经理，换手率通常在 100% 以下。文章的关键追问是：**"长期"到底多长？** 戳破了"长期投资"话语的模糊性。

### 3. 市场环境

- 熊市：交易和套利机会偏少，换手率通常偏低
- 牛市：交易活跃，估值快速达到目标价，换手率偏高

## 核心实证发现

对中长期基金换手率与基金业绩进行相关性分析，**未发现显著相关性**。策略本身不存在优劣——白猫黑猫，抓到耗子才是好猫。

关键在于基金经理要找到最能发挥自身能力的策略，才能做出好业绩。

## 四象限分类框架

| | 晨星星级 ≥ 4星 | 晨星星级 ≤ 3星 |
|--|--------------|---------------|
| **低换手率** | 投资大师：以极少交易实现长期"躺赢"，选股眼光独到且命中率高，比肩巴菲特 | 破产版巴菲特：想做长期投资实践者，但没有发掘长期潜力股的眼光，东施效颦 |
| **高换手率** | 辛勤的炒股大神：通过勤劳翻石头、判断短期走势创造好收益；但命中率不稳定，**规模是天敌** | 机构韭菜：来回折腾挣不到钱，是典型的韭菜，运气还差 |

## 终局问题

当一只基金的换手率从 80% 突然跳到 300%，如何区分基金经理在"进化"还是在"漂移"？投资者该如何判断？
