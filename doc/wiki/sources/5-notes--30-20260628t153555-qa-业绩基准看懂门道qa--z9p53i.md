# 业绩基准看懂门道——从基准读出基金的本质

**来源**：晨星中国（Morningstar CN）
**URL**：https://www.morningstar.cn/articles/575a851779c72309e687c6f113d494be.html
**原始笔记**：`notes/20260628T153555--qa-业绩基准看懂门道__qa.md`

## 核心论点

业绩比较基准是基金的第一张解剖图，而非合同里的摆设。看懂基准比看收益率更重要——基准传达了基金的投资方向、风格和策略，是识别基金经理真实能力的第一道标尺。

## 六个关键问题

### Q1：看基准为什么比看收益率更重要？

**结论**：收益率只告诉你结果，基准才能帮你判断基金经理靠什么赚钱。

**形式化表达**：
```
绝对收益 = 市场水涨 + 基金经理能力
基准过滤 → 超额收益 ≈ 基金经理真实能力
```

**量化案例**：
- 2025年大盘成长指数涨 24.85%，某基金只涨 20%——看似赚钱，实际跑输基准 5%
- 2023年大盘成长跌 16.96%，某基金只跌 10%——看似亏钱，实际跑赢基准 7%

不看基准会被绝对收益骗：牛市赚钱可能是市场带的，熊市少亏才是本事。参见 [[基准不匹配]]。

### Q2：怎么从基准判断基金的投什么？

**结论**：基准的指数构成直接暴露基金的投资方向、区域和主题。

| 基准含成分 | 暴露的投资方向 |
|-----------|-------------|
| 沪深 300 | 大盘蓝筹稳健 |
| 中证 500 | 大中盘偏弹性 |
| 恒生指数 / 标普 500 | 跨市场配置 |
| 半导体 / 创新药指数 | 单一赛道，高弹性高回撤 |
| 中债成分 | 有债底仓 |

**边界**：基准只反映基金合同约定的方向，如果基金经理实际漂移，基准就失效了。参见 [[风格漂移]]。

### Q3：合成基准到底在说什么？

**结论**：合成基准揭示基金的资产配置策略——股债比例、市场分布、货币敞口。

**解读示例**：
```
沪深300×50% + 中证全债×50%  →  股债均衡型
沪深300×60% + 恒生×30% + 中债×10%  →  A股为主港股为辅债打底
```

- 股债比例直接反映基金的进攻性
- 多个市场指数叠加说明基金在跨市场配置
- 加入活期利率说明基金保留现金应对申赎

**边界**：合成基准越复杂（4-6 因子），投资者越难一眼看懂基金在做什么。参见 [[基准重构]]。

### Q4：为什么指数基金比主动基金更依赖基准？

**结论**：指数基金的核心目标就是跟踪基准，基准等于它的"产品说明书"。

```
指数基金目标 = 精准跟踪基准
评估标准 = 跟踪误差 + 跟踪偏离
→ 偏离基准 = 失误，偏离越大越差

主动基金目标 = 适度偏离基准赚超额
```

选指数基金本质上就是选一个你看好的基准。增强型指数基金介于主动和被动之间，需看它允许多少偏离。

### Q5：为什么价格指数和全收益指数的差异很重要？

**结论**：用价格指数做基准会降低超额收益的实现难度，误导投资者。

**核心机制**：
- 价格指数（不含分红）≠ 全收益指数（含分红再投）
- 沪深 300 十年股息占比 70.65%
- 用价格指数做基准更容易跑赢——所谓超额收益可能只来自没算分红
- 投资者据此高估了基金经理的真实能力

**边界**：短期看分红影响不大，但长期（5 年以上）累积差异会非常显著。参见 [[红利全收益指数与价格指数的口径差异]]。

### Q6：基准调整后投资者该做什么？

**结论**：看调整方向是否改变了基金的战略定位，不匹配就考虑赎回。

**三步决策框架**：
1. **看调整方向**：更聚焦 / 更分散 / 跨市场？
2. **评估匹配度**：是否符合自身需求？
3. **留或走**：不匹配则赎回

**案例**：某基金港股通权重从 55% 升至 80%，基金更聚焦港股。如果投资者本来想要均衡配置，这个变化就偏离了初衷。

**边界**：基准调整有时只是精细化和贴合实际，不一定意味着策略大变。参见 [[基准重构]]。

## 文章的真正贡献

把业绩比较基准从"合同里的摆设"变成"投资者决策的第一道工具"——教普通人用基准过滤市场噪音、识别真实能力、避免风格错配。
