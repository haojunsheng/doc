# 行业基金主动跑赢被动吗

晨星中国"基金主动/被动晴雨表"第二章，系统性对比消费、医药、科技传媒通讯三个行业的主动基金与被动基金表现，揭示"主动战胜率"数字背后的参照系偏差陷阱。

## 核心结论

主动基金的超额能力高度依赖行业结构——消费行业主动战胜率大幅提升、科技行业大幅下滑、医药长期领先，并非主动管理能力发生根本变化，而是被动参照系本身存在偏差。

## 三行业对比

### 消费行业：主动战胜率虚高

2024 年消费行业主动基金战胜被动基金的概率为 69.9%，看似主动管理大获全胜。但关键机制是：**被动基金被白酒指数严重拖累**。

| 指标 | 数值 |
|------|------|
| 中证白酒指数基金规模占消费被动组合比例 | 40.9% |
| 2024 年白酒指数涨跌幅 | -17.1% |
| 含白酒的主动战胜率 | 69.9% |
| 剔除白酒后的主动战胜率 | 43.4% |

消费行业真实敞口中，家电、汽车、商贸零售占更大权重且当年表现更好，但跟踪这些子行业的被动基金规模很小。被动基金高度集中于白酒主题，不代表消费行业整体。

**边界**：若白酒指数未来反弹，消费主动基金战胜率将回落。

### 科技行业：主动大幅跑输

2024 年科技传媒通讯行业主动基金战胜率仅 19.8%。原因不是主动能力全面崩塌，而是被动基金押中了当年强势赛道。

| 机制 | 说明 |
|------|------|
| 主动基金配置 | 试图分散配置各行业，错过集中爆发的半导体/科创板 |
| 被动基金配置 | 专注于半导体、科创板主题，精准吃到强势赛道 |
| 结果 | 科技行业主动战胜率仅 19.8% |

科技行业细分领域表现差异极大，踩中半导体和科创板的主动基金属少数。

**边界**：若 2025 年科技行情从半导体切向其他细分，主动基金可能重新跑赢。

### 医药行业：主动长期领先

2024 年医药整体低迷，但主动基金三年/五年战胜率仍居三行业之首。

| 主动基金经理策略 | 效果 |
|----------------|------|
| 超配化学制药、中药 | 受政策利好，相对抗跌 |
| 低配生物制品、医疗器械 | 持续疲软，规避损失 |
| 被动基金配置 | 跟踪宽基医药指数，无法区分子行业好坏 |

主动基金经理通过主动区分子行业好坏，创造了被动宽基指数无法提供的超额收益。

**边界**：若政策转向利好生物制品和医疗器械，主动基金的超额可能被削弱。

## 关键发现

### 发现一：被动基金未必代表行业真实敞口

被动基金可能高度集中于某一细分方向，不代表行业真实持仓分布。用这样的被动组合作为基准评价主动基金，本身就不公平。

```
行业被动基金组合 ≠ 行业真实持仓分布

消费行业：
  行业真实权重：家电 + 汽车 + 商贸零售 > 白酒
  被动基金实际暴露：白酒 40.9% >> 其他

科技行业：
  被动基金实际暴露：半导体/科创板主题集中
```

**边界**：行业 ETF 越多、覆盖越均匀，被动基金的代表性越强。

### 发现二：等权平均收益率 > 资产加权平均收益率

三个行业均呈现同一规律：等权平均收益率高于资产加权平均收益率。

| 指标 | 含义 |
|------|------|
| 等权平均收益率 | 所有基金收益率算术平均 |
| 资产加权平均收益率 | 投资者真金白银实际获得的平均回报 |
| 两者差距 | 反映投资者择时/择基行为损耗 |

**机制**：投资者倾向买入近期表现好的基金 → 买在高点 → 实际回报低于基金平均。

**边界**：若投资者长期持有不追涨，两者差距缩小。

### 发现三：费率改革对主动/被动对比的影响

管理费下调让主动基金的成本劣势收窄，但费率区分度降低。第三阶段还将降低销售费率，对主动基金更有利。

```
主动基金成本：1.2% → 降费后缩小
被动基金成本：0.1% → 跟进降费
成本差距缩小 → 费率不再是决定性因素
```

## 方法学贡献

本文最重要的方法论贡献是揭示**行业参照系偏差**：评价主动基金能否跑赢被动，不能只看基金经理能力，还要看被动参照系本身是否合理。当被动基金集中在少数细分赛道时，以被动为基准评价主动从开始就是不公平的。
