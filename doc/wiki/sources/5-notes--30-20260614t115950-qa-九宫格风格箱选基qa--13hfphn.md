# QA — 九宫格风格箱选基：选基先看持仓不看宣传

> 原文来源：[[entities/晨星中国-morningstarcn]]（Morningstar 中国）
> 核心叙事主线：用九宫格看清基金的真实风格，而非被基金名称和营销标签误导

## 核心论断

基金名称和宣传标签可能是"人设"——只有看实际持仓，才能知道基金经理真正在买什么。九宫格（晨星投资风格箱）的价值在于让你看清自己买了什么，而不是告诉你哪个格子最好。

## 五问主线

### Q1：价值型基金和成长型基金，谁更赚钱？

**结论**：长期来看两者收益趋向一致，没有优劣之分。

```
短期: 价值 ≠ 成长（风格切换）
长期: 价值 ≈ 成长（均值回归）
```

**怎么想到的**：用沪深300相对成长指数和沪深300相对价值指数的累计收益曲线做实证观察——短期会有明显差异，拉长时间看差异逐渐缩小甚至趋向一致。

**边界条件**：这是统计结论，不代表特定时间段内的表现。在风格切换剧烈的年份，差异可能持续较长时间。

→ 参见 [[价值成长长期趋同]]

### Q2：既然长期差不多，为什么还要区分投资风格？

**结论**：因为市场风格会轮动，不同阶段适合不同的风格配置。

```
牛市 → 成长风格占优
熊市 → 价值风格更抗跌
投资者 → 根据阶段特征 + 风险偏好 → 选择适配风格
```

**怎么想到的**：价值股和成长股在不同经济周期表现不同；如果只押一种风格，可能在逆风期承受较大回撤。

**边界条件**：风格轮动的时间点很难精准判断，试图通过择时切换风格往往适得其反。

→ 参见 [[风格轮动-a股语境]]、[[风格顺风与逆风]]

### Q3：怎么快速知道一只基金到底是什么风格？

**结论**：看它的实际持仓，而不是听它自己说——用晨星投资风格箱。

```
基金持仓 → 分析每只股票的风格 → 加权平均 → 定位九宫格
纵轴: 大盘 / 中盘 / 小盘（按市值）
横轴: 价值 / 平衡 / 成长（按估值和增长特征）
```

**怎么想到的**：基金的名称和宣传可能误导投资者，只有看实际持仓才能知道基金经理真正在买什么。晨星从1992年就开始用这个工具，基于持仓分析而非基金自述。

**边界条件**：风格箱反映的是历史持仓，如果基金经理近期调仓，风格箱可能滞后于实际变化。

→ 参见 [[晨星投资风格箱]]、[[风格漂移]]

### Q4：九宫格的九个格子分别代表什么？

**结论**：三个维度交叉产生九种组合，每种组合对应不同的风险收益特征。

```
市值维度: 大盘(稳定) ←→ 小盘(弹性)
风格维度: 价值(低估值) ←→ 成长(高增长)
九宫格 = 3(市值) × 3(风格) = 9种组合
```

**各格子的典型风险收益特征**：

| 格子 | 典型特征 |
|------|---------|
| 大盘价值 | 蓝筹股，波动小，分红高 |
| 大盘成长 | 白马股，业绩稳定增长 |
| 中盘价值 | 介于大盘和小盘之间，估值合理 |
| 中盘成长 | 成长性较好，弹性适中 |
| 小盘价值 | 被低估的小公司，弹性大风险也大 |
| 小盘成长 | 高成长潜力的小公司，波动最大 |
| 平衡类三格 | 价值与成长均衡配置，风格中性 |

**边界条件**：九宫格是静态分类，现实中很多基金的风格会漂移，不会一直待在某个格子里。

→ 参见 [[晨星投资风格箱]]

### Q5：普通投资者怎么用这个工具？

**结论**：在晨星官网的基金筛选工具里查看基金的风格箱定位，辅助组合配置。

```
选基流程: 确定投资目标 → 筛选风格 → 看风格箱定位 → 构建组合
组合构建: 不同风格的基金搭配 → 降低整体波动
```

**怎么想到的**：投资者需要知道自己组合的真实风格暴露，避免全买同一风格的基金导致集中风险；风格箱让抽象的"风格"变得可视化。

**边界条件**：风格箱只是选基的一个维度，还需要结合费率、基金经理、业绩稳定性等指标综合判断。

## 收口

> 九宫格的价值不在于告诉你哪个格子最好，而在于让你看清自己到底买的是什么——看持仓，不听宣传。
