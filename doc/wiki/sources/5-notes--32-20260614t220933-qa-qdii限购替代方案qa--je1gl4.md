# QA — QDII 限购后香港互认基金与跨境理财通是替代方案

来源：[[晨星中国-morningstarcn]]，2026-06-14

## 背景

截至 2025 年 1 月，600 多只 QDII 基金中近六成已关闭申购，核心原因是 QDII 额度紧张。投资者需要寻找替代通道出海。

## Q1: 为什么 QDII 基金会限购？

**结论**：QDII 额度是"紧俏物质"——基金公司只能在额度内运作，额度耗尽只能暂停申购。

**形式化表达**：
```
QDII 额度 = 外汇局审批的海外投资总额度
→ 额度耗尽 → 暂停申购
```

**关键数据**：
- 截至 2024 年末，所有证券和基金公司累计获批额度仅 920 多亿美元
- 最近一次额度审批在 2024 年 5 月，申请需等待数月

**边界**：如果外汇局批准新的额度，限购可能放松。

## Q2: 香港互认基金作为替代方案有什么局限性？

**结论**：数量少（40 多只）、投资范围窄（主要在亚太）、也有额度限制。

**形式化表达**：
```
互认基金局限: 数量少（40+ 只） + 范围窄（亚太为主） + 额度限制（销售规模≤总资产 80%）
```

**具体约束**：
- 2015 年推出，允许符合条件的香港基金在内地销售
- 产品数量少，缺乏多元化
- 主要投向中概股、亚洲和大中华地区
- 以主动管理型为主，被动管理型几乎没有
- **最新规定**：每只互认基金在内地销售规模不超过总资产 80%

**边界**：如果投资者需要配置欧美市场，互认基金选择有限。

## Q3: 跨境理财通相比 QDII 和互认基金有什么优势？

**结论**：额度充足（300 万/人）、产品丰富（2000+ 只）、可投欧美市场。

**形式化表达**：
```
跨境理财通优势: 额度充足（300 万/人） + 产品丰富（2000+ 只） + 市场覆盖广（北美、欧洲、亚洲）
```

**核心优势**：
- 每人 300 万人民币额度（**不占用外汇额度**）
- 可投产品包括：存款、债券、基金
- 基金主要投资大中华区、北美、欧洲
- 主动和被动产品都有

**边界**：仅限大湾区居民参与，且有投资经验和资产门槛。

## Q4: 投资者选择海外投资方式时应该考虑什么？

**结论**：看投资目标（市场、品种）、看自身条件（居住地、额度）、看产品特性（费率、风险）。

**形式化表达**：
```
选择 = f(投资目标, 自身条件, 产品特性)
```

**三条通道对比**：

| 通道 | 覆盖范围 | 核心约束 |
|------|---------|---------|
| QDII | 全球市场 | 额度紧张，近六成产品关闭申购 |
| 香港互认基金 | 亚太为主 | 40+ 只产品，以主动管理为主 |
| 跨境理财通 | 北美、欧洲、亚洲 | 仅限大湾区居民 |

**关键洞察**：看基金实际投向，而非注册地。这与 [[穿透持仓]] 原则一致。

## 收口

QDII 限购暴露了海外投资的结构性约束——但香港互认基金和跨境理财通提供了替代路径，投资者应根据自身条件和配置需求选择。
