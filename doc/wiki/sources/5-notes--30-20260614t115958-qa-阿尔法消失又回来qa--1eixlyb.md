# QA — 阿尔法消失又回来

> 来源：晨星（Morningstar）文章《阿尔法没消失，只是换了个马甲变成贝塔》
> 时间：2026-06-14

## 核心命题

阿尔法没有消失，只是随着因子模型不断扩展，曾经被认为是超额收益的部分被重新归类为贝塔。当你的"独家观点"变成市场共识，阿尔法就变成了贝塔。

## 阿尔法的本质：解释剩余

阿尔法是基金收益中无法通过现有因子模型解释的部分——它不是基金经理能力的固定指标，而是**所有模型都解释不了的收益残差**。

```
詹森阿尔法：α = Rp - [Rf + β(Rm - Rf)]
Fama-French 三因子：Rp = α + β1(Rm) + β2(SMB) + β3(HML) + ε
```

每一次因子模型扩展，α 的估计值就缩小——这是历史实证事实。

## 关键问答

### Q1：阿尔法到底是什么？

1967 年迈克尔·詹森首次提出阿尔法概念，通过对基金收益和市场收益做线性回归得到。回归线的斜率是贝塔（对市场风险的暴露），y 轴截距是阿尔法（超额收益）。但阿尔法只是统计结果，无法区分"能力"和"运气"。

### Q2：为什么有人说阿尔法消失了？

因为很多所谓的"阿尔法"其实是特定市场风格的隐性暴露——顺风时赚钱，逆风时亏钱。A 股主动基金 70% 以上是成长风格配置，2023-2024 年初成长风格回归自然推高这些基金的业绩，这不是阿尔法回来了，是风格轮动。

### Q3：阿尔法是怎么变成贝塔的？

当某种投资观点广为人知时，它就不再是阿尔法，而成了贝塔的一部分。最初只有市场因子，后来扩展到三因子（市场、市值、价值），再后来发现股息、低波动等因子也能解释业绩。晨星的定义："当前任何因子模型都无法解释的决策"——这个定义内嵌自我消解逻辑：今天 α 是明天 β。

### Q4：怎么判断一个基金经理的阿尔法是能力还是运气？

很难。单从阿尔法数字无法区分这三种来源：真实能力 / 运气 / 风格暴露。需要结合投资逻辑、市场环境、长期业绩综合判断。晨星等机构更多把阿尔法当作风险收益评估指标，而非"能力分数"。

### Q5：投资者应该怎么看待阿尔法？

把阿尔法当作理解基金风险回报的工具，而不是选基金的唯一标准。错误用法：阿尔法高 → 买入。正确用法：阿尔法 + 贝塔 → 理解基金的风险收益特征，再结合投资逻辑、费率、经理经验综合判断。

## 历史脉络

| 年份 | 事件 | 对 Alpha 的影响 |
|------|------|----------------|
| 1967 | Michael Jensen 提出詹森阿尔法 | Alpha 定义为基金收益对市场收益线性回归的截距 |
| 1992 | Fama-French 三因子模型 | 引入 SMB（规模）和 HML（价值），大量"Alpha"被发现是因子暴露 |
| 2010 年代 | 动量、质量、低波动等因子被发现 | Alpha 边界不断被重新定义，解释剩余持续缩小 |
| 2025 年初 | 晨星统计主动权益基金 1 年期战胜率从 14% 回升至 28% | 可能是成长风格顺风而非能力回归 |

## 实践启示

1. **警惕"阿尔法"包装**：很多基金将因子暴露（如小盘、成长风格）包装为主动管理能力收取 alpha 费用
2. **不要追涨顺风**：2025 年初主动基金战胜率回升是成长风格回归的产物，不宜据此判断基金经理能力改善
3. **追求低成本贝塔**：承认无法识别真阿尔法，普通投资者应优先追求低成本指数基金
4. **阿尔法是后视镜**：过去的 Alpha 不代表未来的能力
