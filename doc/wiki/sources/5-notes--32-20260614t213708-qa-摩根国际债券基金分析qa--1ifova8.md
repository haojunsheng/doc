# QA — 摩根国际债券基金分析

**原始来源：** `notes/20260614T213708--qa-摩根国际债券基金分析__qa.md`

## 摘要

晨星焦点基金系列文章，系统分析香港互认基金"摩根国际债券基金（968052）"成为焦点基金的底层逻辑：多元化收益来源结构 + 全球资源与本地专注结合的团队优势。

## 核心内容

### Q1 — 收益来源结构
超额收益 = 行业选择 + 发行主体选择 + 久期操作 + 外汇操作。行业和发行主体选择是主要来源；久期和外汇也有贡献。边界条件：全球债券市场相关性大幅上升时，行业和个券选择的超额收益收窄。

### Q2 — 团队优势
"全球资源 + 本地专注"：摩根全球综合投资团队（8位资深基金经理支持）+ 主基金经理常驻香港专注亚洲市场。边界条件：核心基金经理离职将影响投资管理能力。

### Q3 — 投资流程
"自上而下宏观研判 + 自下而上个券精选"双层架构：季度会议定方向，周度策略会调配置，专业团队做个券精选。边界条件：宏观研判失误会拖累业绩。

### Q4 — 历史表现规律
- 2021年：低配久期 + 超配投资级和高收益公司债 → 超额收益
- 2022年：低配久期 → 抗跌
- 2023年Q1：低配久期失误 → 表现较弱
- 2024年：多维度共同贡献 → 良好收益

### Q5 — 多元化收益来源是优势
不依赖单一策略，某维度失误时其他维度可弥补。边界条件：全球债券市场全面下跌时，多元化也无法避免亏损。

### Q6 — 适合投资者
有全球债券配置需求、能承受0.89%费率、认可摩根品牌的中长期投资者。

### Q7 — 互认基金 vs QDII
- 互认基金 = 香港基金 → 内地销售（侧重专业产品）
- QDII = 内地基金 → 海外投资（侧重额度管理）
- 两者是互补关系，非替代关系。
