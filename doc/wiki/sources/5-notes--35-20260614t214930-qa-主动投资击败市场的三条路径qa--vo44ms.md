# 主动投资击败市场的三条路径

> 都去买指数了，主动投资还有好日子吗？

## 核心论点

当市场上越来越多"聪明钱"涌入被动投资时，主动投资的三条可行路径按难度递减、可行性递增排序为：

1. **击败"愚蠢资金"**（高天赋门槛）→ 巴菲特/斯文森是特例，普通人无法复制，建议买指数
2. **寻找"不同的资金"**（承担别人不愿承担的风险）→ 执行难度中等，门槛是纪律而非天赋
3. **管理投资行为**（控制自身情绪）→ 难度最低，回报最高，决定胜负的是自己而非对手

## 三条路径详解

### 路径一：击败"愚蠢资金"

- 市场不完全有效：大量缺乏投资技能的参与者（"愚蠢资金"）给"聪明投资者"提供机会
- 扑克牌桌比喻：如果你在五分钟内还没弄清楚谁是"冤大头"，那么这个人很可能就是你自己
- 矛盾现象：巴菲特和斯文森（耶鲁捐赠基金前CIO）用这条路径成功了，却建议普通人买指数，说明此路径只适合极少数人
- 边界：若市场有效性持续提升，此路径会越来越难；若投资者确实有天赋，仍可行

### 路径二：寻找"不同的资金"

- 不同投资者对风险的认知差异、投资期限差异，会导致对同一只股票的估值不同，但这些差异基于"理性判断"而非"愚蠢决策"
- **自愿的输家（Voluntary Loser）**：机构投资者因业绩考核压力，可能"理性地"卖出给长期投资者，失去长期高回报机会——这不是零和博弈
- 超额收益 = 承担额外风险（流动性/期限/波动）× 风险溢价
- 边界：若市场参与者都是完全理性的，此路径超额收益会减少；若承担的风险过大（如流动性枯竭），可能亏损

### 路径三：管理投资行为（最易执行）

- CFA协会假设案例：假设市场全是指数投资者（年化5%），三类主动投资者表现对比：

| 投资者类型 | 年化收益 |
|-----------|---------|
| 定投者 | 5.4% |
| 追涨杀跌者 | -5% |
| 行为管理型主动投资者（折价10%买入/溢价10%卖出） | 28.3% |

- 核心逻辑：影响成败的因素是"自己的行为"而非"对手的能力"，相对可控——不需要寄希望于对手的"愚蠢"，也不需要承担额外的风险
- 边界：若无法控制情绪（如恐慌性卖出），此路径会失效；若市场长期单边上涨，行为管理的优势不明显

## 竞争终局推论

- 随着被动投资者比例上升，超额收益变得更加稀缺
- 剩余的主动基金经理陷入"相互交易"的局面，**相对技能水平比绝对技能水平更重要**
- 引用：拉里·斯韦德罗（Larry Sweeds）和安德鲁·伯金（Andrew Birkin）《不断缩小的超额收益》

## 收口

当市场上充斥着"聪明钱"时，靠"击败对手"越来越难，但靠"管理自己"仍然可行——决定投资胜负的，不再是"对手的愚蠢"，而是"自己的纪律"。

# 主动投资三条路径

## 定义

在被动投资热度持续攀升的背景下，主动投资仍可通过三条路径获取超额收益，按难度从高到低排列：

```
难度排序：击败愚蠢资金 > 寻找不同资金 > 管理投资行为
可行性排序：管理行为 > 寻找不同资金 > 击败愚蠢资金
```

## 路径一：击败"愚蠢资金"

- 依赖市场非理性行为产生的错误定价来获取超额收益
- 适合极少数天赋异禀的投资者（如巴菲特、斯文森），普通人无法复制
- 与[[投资是输家的游戏]]一脉相承：扑克牌桌比喻——若不知谁是"冤大头"，那人就是你自己
- 边界：市场有效性持续提升时，此路径空间不断收窄

## 路径二：寻找"不同的资金"

- 通过承担别人不愿承担的风险（流动性、期限、波动）获取风险溢价
- 基于理性判断而非对手愚蠢——不同投资者因风险认知或期限差异做出不同估值
- [[自愿的输家]]机制：机构投资者因考核压力"理性地"卖出，长期投资者获得超额收益来源
- 门槛是纪律而非天赋
- 本质是[[风险溢价]]的另类表述

## 路径三：管理投资行为

- 通过纪律控制情绪（低买高卖），不依赖对手愚蠢也不承担额外风险
- [[CFA协会]]假设案例：市场全为指数投资者（年化5%）时，行为管理型主动投资者可获得28.3%，而追涨杀跌者收益-5%
- 决定胜负的是"自己"而非"对手"——相对可控
- 是三条中最易执行、回报最高的路径
- 与[[无为投资]]表面看似冲突实则互补：无为针对资产配置层面，行为管理针对择时执行层面

## 竞争终局公式

```
被动投资者↑ → 主动基金经理相互交易 → 相对技能决定胜负
```

参见[[相对技能水平 vs 绝对技能水平]]。

## 开放问题

- 行为管理策略存在拥挤效应风险：若所有投资者都采纳"别人恐惧我贪婪"原则，该策略是否仍有效？本文未讨论。
- 路径二（承担别人不愿承担的风险）与路径三（管理自身行为避免恐慌性卖出）在实操中如何区分，尚需进一步澄清。

# 自愿的输家（Voluntary Loser）

## 定义

因风险认知差异或投资期限差异而"理性地"卖出资产，使另一方获得超额收益来源的交易机制。卖出方并非因判断错误而亏损，而是基于自身约束条件（如考核周期、风险承受力）做出的理性决策。

## 核心机制

- **风险认知差异**：一位投资者对某风险免疫，另一位高度敏感，两人对同一只股票的估值自然不同
- **投资期限差异**：机构投资者按年度考核，长期投资者按十年考核，短期操作可能截然不同
- 结果：机构投资者"理性地"卖出给长期投资者，失去长期高回报机会——但这是其基于自身约束的最优选择，而非错误

## 与相关概念的关系

- 丰富了[[赢家补贴输家]]的微观基础：输家的"输"并非来自愚蠢，而是来自自愿退出
- 是[[主动投资三条路径]]中"寻找不同的资金"路径的机制性支撑
- 使交易关系从"零和博弈"转化为非零和：双方基于各自约束做出理性决策，各自获得符合自身偏好的回报结构

## 边界条件

- 若市场参与者都是完全理性的（且约束条件相同），此机制将不复存在
- 若市场存在大量非理性行为，此路径的机会更多，但同时也伴随着[[无效市场的收割风险]]

## 简介

投资作家，与安德鲁·伯金（Andrew Birkin）合著《不断缩小的超额收益》（*The Shrinking Alpha*）。

## 在来源中的角色

在[[晨星中国]]文章"主动投资击败市场的三条路径"中被引用，用于支持"相对技能水平比绝对技能水平更重要"这一论点：随着被动投资者比例上升，剩余的主动基金经理陷入相互交易，相对优势决定胜负。

## 主要观点

- 随着市场被动化加深，主动管理的超额收益空间不断收窄
- 剩余主动基金经理之间的竞争，本质上是相对技能水平的较量，而非绝对能力的比拼
