# 银行理财不保本，底层资产决定风险

> 原文来源：[[entities/晨星中国-morningstarcn]]

## 核心论点

银行理财的"低风险"源于其底层资产主要是债券等固定收益类工具，而非银行信用背书。资管新规后刚性兑付已打破，所有资管产品均回归"投资者风险自担"的本质。

## Q1 — 刚性兑付的运作机制

**结论**：刚性兑付本质是用新投资者的钱给老投资者兜底，不是投资真的不会亏。

**形式化表达**：

```
刚性兑付 = 新产品资金 → 兑付老产品本息
本质 = 庞氏结构，不是无风险
```

只要不断有新投资者加入，前面的人就能拿到钱；一旦后续资金续不上，系统性风险爆发。在资管新规前的特殊历史阶段，这种模式确实维持了较长时间，但风险持续积累，最终监管出手打破。

## Q2 — 为什么要打破刚性兑付

**结论**：刚性兑付制造不公平收益分配和系统性风险，违背"投资者风险自担"的资管本质。

**形式化表达**：

```
刚性兑付 = 有人亏损 → 用别人钱补 → 不公平 + 风险积累
打破刚兑 = 回归资管本质
```

资管行业本质是"受人之托、代客理财、投资者风险自担"，管理人只拿管理费，赚的钱给客户，赔的钱也该客户自己承担。

## Q3 — 银行理财"低风险"的真正来源

**结论**：银行理财的"低风险"不是因为银行机构安全，而是因为它主要投资债券、存单等固定收益类资产。

**形式化表达**：

```
银行理财 ≈ 债券基金 ≈ 固定收益类资产
风险来源 = 底层资产，不是发行机构
```

关键数据：
- 银行理财 95% 是固定收益类产品
- 近 70% 投向债券、存单、现金

但"低风险"不等于"无风险"，债券也有波动和亏损可能。若银行理财配置了可转债、高收益债或加了杠杆，风险会上升。

## Q4 — 为什么买银行理财不如买债券基金

**结论**：两者底层资产相似，但公募基金信息更透明、费用更清晰、业绩可比较。

**形式化表达**：

```
银行理财 ≈ 债券基金（底层资产相似）
银行理财 = 黑箱（不透明）
公募基金 = 玻璃箱（透明）
```

关键数据：
- 银行理财整体 3.2% 资产直接投公募基金
- 其中 75% 是债券型基金

公募基金每日净值、季报半年报、持仓、基金经理履历全部公开；银行理财像"黑箱"，历史表现难查，业绩无法横向比较。

## Q5 — 银行理财间接购买公募基金意味着什么

**结论**：基金是更基础、更透明的投资工具；通过银行理财买基金，投资者被双重收费。

**形式化表达**：

```
银行理财 → 3.2% 资产 → 公募基金（75% 债基）
投资者被双重收费
```

银行理财配置基金可能是为了弥补自身投研能力不足，或者满足特定配置需求，但并非所有银行理财都这样做。

## 收口洞见

不要看产品形式，要看底层资产。在资管新规后，所有资管产品都是"风险自担"，投资者应该关注底层投向，而不是发行机构的名气。
