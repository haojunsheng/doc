# 固收加本质与陷阱 QA

> 原文核心：固收+基金不是稳赚不赔，熊市中"+"会变成"-"，10年维度跑赢纯债但3年维度可能跑输。

## Q1: 固收+到底分哪几类？

按权益仓位分为三类，晨星以 10% 和 20% 为分界线：

| 类型 | 权益仓位 | "+"资产构成 |
|------|---------|-------------|
| 普通债券基金 | <10% | 可转债为主（约6%） |
| 积极债券基金 | 10%–20% | 股票（10%–15%）+ 可转债（10%–20%）均衡配置 |
| 保守混合基金 | <30% | 股票为主（15%–25%），可转债 <5% |

关系：普通债券 ⊂ 积极债券 ⊂ 保守混合（按权益仓位递增）

**边界**：基金合同对仓位约束不严格时，实际仓位可能突破分类边界。

## Q2: 固收+为什么经历了两波爆发？

触发机制：利率↓ → 纯债收益↓ → 固收+吸引力↑ → 规模爆发

- 第一波（2015–2016）：央行多次降息，纯债收益率失去吸引力，年末规模接近万亿
- 第二波（2019–2021）：利率下行叠加股市牛市，固收+同时享受债牛和股牛，2021年末规模超2万亿

**边界**：利率进入上行周期时，纯债收益回升，固收+增强动力减弱。

## Q3: 熊市为何变成"固收-"？

公式：固收+ = 债底（正贡献） + 权益（负贡献） → 熊市时权益部分抵消债底收益

近3年数据（2019–2022熊市区间）：
- 积极债券基金年化：-1.0%
- 保守混合基金年化：-1.2%
- 纯债基金年化：+3.3%

**边界**：若股市温和上涨或震荡，"+"资产仍能提供正增强，不会变成"固收-"。

## Q4: 底层资产质量偏好

- 多数固收+基金偏好 AAA 以上高质量信用债，AAA 以下评级占比与纯债基金相当
- 杠杆率低于纯债基金（开放式上限140%，通常用不满）
- 信用债票息高于利率债，是底仓收益主要来源

**边界**：信用利差大幅走阔或违约频发时，底仓"稳定器"作用减弱。

## Q5: "+"策略差异形式化

```
普通债券 ≈ 纯债 + 6% 转债
⊂ 积极债券 ≈ 纯债 + 10–15% 股票 + 10–20% 转债
⊂ 保守混合 ≈ 纯债 + 15–25% 股票
```

**边界**：可转债市场扩容或股市风格切换时，各类型实际配置比例动态调整。

## Q6: 持有期限依赖性——时间尺度决定结论

- 短期（3年熊市）：固收+ ≺ 纯债（积极债券 -1.0%，保守混合 -1.2%，纯债 +3.3%）
- 长期（10年）：固收+ ≻ 纯债（风险资产增厚效应累积释放）

**边界**：若未来10年股市持续低迷，固收+长期优势也会缩小——这是条件性命题而非必然结论。

## Q7: 什么人不适合固收+？

```
不能接受任何回撤 → 纯债/利率债
能接受小幅回撤但想多赚 → 固收+
```

固收+在熊市也会亏，只是亏得比股票少。追求绝对保本者应选纯债。

**边界**：投资者若对回撤容忍度随市场波动而变化，可能在低点赎回反而锁定亏损。
