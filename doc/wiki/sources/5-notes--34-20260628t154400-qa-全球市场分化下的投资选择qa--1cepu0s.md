# 全球市场分化下的投资选择 — 估值是锚，不是预测未来的水晶球

**来源**：晨星中国  
**日期**：2026-06-28  
**URL**：https://www.morningstar.cn/articles/9b58f019036a183e5e5d48a4cc3121a0.html

## 核心论点

晨星使用「估值隐含回报」（Valuation Implied Return，VIR）作为统一标尺，将美股、新兴市场、债券、现金放到同一维度横向比较，在关税风暴中给出全球资产配置参考。

## VIR（估值隐含回报）方法论

```
VIR = 增长 + 总收益 + 汇率 + 通胀调整 + 估值回归
```

VIR 的核心价值在于将不同资产类别的收益来源翻译为统一的预期收益率百分比，使跨类别比较成为可能。

### 关键发现

| 资产/市场 | VIR | 含义 |
|-----------|-----|------|
| 新兴市场 | 10% | 最贵，但预期修复空间最大 |
| 美股 | 2.9% | 短期贵，长期基本面扎实 |
| 债券 | 较低 | 稳定器角色 |
| 现金 | 低 | 防御配置选项 |

**差距拆解**：新兴市场高VIR主要来自估值预期变化和汇率回归，而非企业盈利能力差异。

## 核心结论

### 美股
- 过去两年VIR持续下降（价格变贵），但盈利增长和回购仍在贡献正回报
- 短期回调压力存在，长期基本面仍扎实
- **边界**：若美国经济陷入深度衰退，长期向好前提不成立

### 医疗保健 / 能源 / 房地产
- 因关税波动导致市场过度抛售，处于低估区间
- 存在修复赔率，但低估可能持续很久
- **对比**：公用事业、金融、工业反而估值偏高

### 英伟达与指数集中度
- 英伟达市值超过英国、加拿大、德国三国股市总和
- 1999年上市至今回报超大盘500多倍（2022年末生成式AI爆发为驱动）
- 单只股票权重过大意味着被动指数基金持有者实质上在"单押AI"

### 关税→滞胀传导
- 晨星下调美国GDP增长0.7个百分点、上调通胀1.6个百分点
- 关税升至近百年来最高水平
- 关税同时推升通胀（进口价格↑）和压制增长（贸易↓）

### 投资哲学
- 估值告诉你"现在买贵了没有"，热点只告诉你"别人在买什么"
- 理性研判+耐心持有是穿越周期的方式
- **边界**：极端牛市中"以估值为锚"可能过早下车
