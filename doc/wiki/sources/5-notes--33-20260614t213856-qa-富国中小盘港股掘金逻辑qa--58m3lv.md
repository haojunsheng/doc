# QA — 富国中小盘港股掘金逻辑

> 晨星焦点基金系列：掘金港股中小盘机会，以张峰管理的富国中国中小盘混合（QDII）为案例。

## 核心论断

富国中国中小盘混合（QDII）在张峰管理的 13 年间年化回报 12.06%，跑赢基准 7.56 个百分点。超额收益主要来自**选股能力而非行业押注**，策略纪律（PEG 估值筛选 + 分散持股）是核心护城河。

## 关键数据

| 指标 | 数值 |
|------|------|
| 管理年限 | 13 年 |
| 年化回报 | 12.06% |
| 年化超额收益 | 7.56% |
| 综合费率 | 2.33%（同类平均 2.71%） |
| 管理规模 | 38.85 亿元 |
| 持股数量 | 70–100 只 |
| 前十大集中度 | 25–35% |

## 策略框架

**合理估值成长策略**的核心逻辑：

```
行业增长确定性↑ ∩ PEG（估值/盈利增长）≤ 合理区间 ∩ 分散持股 → 持续超额收益
```

操作路径：
1. 自下而上选股，通过行业分析、实地调研、上下游交流判断企业成长性和管理层素质
2. 用 PEG 指标衡量成长和估值的匹配度，不追高估值标的
3. 分散持股（70–100 只），单只股票风险有限

## 归因分析

**正选股超额来源**（多行业均贡献）：
- 可选消费、必选消费、医药、通信、工业、金融、房地产

**配置拖累**：
- 低配信息技术行业 −4.81%（该行业在某些年份大涨）

**年度表现对照**：
- 2020 年赚 52% 但排 60%（低配高估值科技，错失成长狂热）
- 2022 年亏 10% 却排 26%（低配信息技术 + 必选消费/金融/通信选股超额）

## 关键发现

### 阶段性防御调整 ≠ 风格漂移

2024 年增配中国太保、中信银行等价值股，组合风格箱移至大盘价值区间——这是对宏观下行环境下成长股盈利不确定性的**阶段性防御**，非策略根本变化。

→ [[风格漂移]] 补充判据：防御性调整与策略漂移的边界

### 不投 A 股的逆向优势

同类基金平均配置 21% 在 A 股（主要是食品饮料大盘白马股），2019–2020 年涨势良好，2021–2025 年因投资者转向价值和科技股而持续下跌。该基金不配反而避开"坑"，成为配置正贡献。

**但依赖市场路径**：若消费复苏，不配 A 股将变成拖累。

### 不配台湾股票的劣势

2019–2025 年台湾股票表现良好，同类基金通过配置获得额外收益，该基金完全错失——受限于投资范围契约。

### 中小盘风格的周期性

| 年份 | 市场风格 | 基金排名 | 结果 |
|------|---------|---------|------|
| 2019 | 大盘股行情 | 70% | 跑输 |
| 2021 | 中小盘行情 | 10% | 跑赢 |
| 2022 | 中小盘行情 | 26% | 跑赢 |
| 2024 | 大盘股行情 | 52% | 跑输 |
| 2025 | 中小盘行情 | 33% | 跑赢 |

→ [[中小盘风格周期性]] — 中小盘需要 3–5 年持有周期平滑风格波动

### 费率复利效应

```
费率差：2.71% − 2.33% = 0.38%/年
13 年复利累积差距 ≈ 8% 累计收益
```

## 边界条件与开放问题

**策略边界**：
- 若市场进入"唯成长论"狂热期，策略会持续跑输
- 若企业盈利增长普遍放缓，选股难度加大
- 策略"优势"（不配 A 股）高度依赖市场路径，非稳定结构特征

**开放问题**：
1. "实地调研 + 上下游交流"定性方法是否有可量化的跟踪指标？
2. 2024 年风格箱移至大盘价值区间的调整频率和幅度边界在哪里？
3. 不配台湾股票的契约限制是否可能在未来调整？对策略容量有何影响？
