# 概念解剖：总回报率

> 来源：这个指标比基金净值更重要
> 晨星文章 | 核心概念提取

## 核心内容

总回报率（Total Return）是衡量投资真实收益的指标，包含两部分：**资本增值**（净值/价格的变化）和**分红收入**（基金/股票派发的现金）。公式为：

```
总回报率 = (期末价值 - 期初价值 + 期间分红) / 期初价值 × 100%

若分红再投资：
总回报率 = (期末累计份额 × 期末净值 - 期初价值) / 期初价值 × 100%
```

## 关键论点

- **历史背景**：20世纪60年代ICI推动基金披露总回报率，晨星1984年成立即把总回报率作为评级核心。
- **常见误解**：以为净值增长率就是总回报；以为总回报率只适用于基金；以为总回报率可以预测未来。
- **必要但不充分**：总回报率假设分红可以再投资，但现实中很多投资者选择现金分红；它无法反映资金的时间价值。
- **失效场景**：高频小额分红的基金可能因再投资摩擦成本而被高估；基金经理可能通过分红前抬高净值来操纵印象。
- **隐喻转换**：总回报率 = 体检报告——展示当前状态，但不能预测未来疾病。
