# QA — QDII出海：额度松绑后怎么构建组合

来源：[[晨星中国-morningstarcn]]，2025-07-18

## 背景

2025年7月，外汇局向82家机构新发30.8亿美元QDII额度，基金公司集体松绑限购。但676只QDII份额中，仍有超一半限购，194只限购1万元以内，96只限购1千元以内，35只完全暂停认购。"出海"需求旺盛与额度供给不足的矛盾依然尖锐。

## Q1: 为什么现在释放QDII额度？

**结论**：释放额度是"政策信号+市场条件+监管表态"三重因素叠加——经济复苏带来多元化配置需求、外汇市场平稳提供环境、陆家嘴论坛监管明确表态。

**形式化表达**：
```
额度释放 = 经济复苏（居民财富积累）
         + 外汇市场平稳（汇率稳定）
         + 监管表态（朱鹤新陆家嘴论坛承诺）
         → 30.8亿美元新额度
```

**怎么想到的**：
- 看宏观：国内经济稳步复苏 → 居民财富积累 → 全球配置需求强烈
- 看外汇：人民币汇率中间价平稳向好 → 适宜的环境
- 看政策：2025年6月朱鹤新明确表示"新发放一批QDII额度" → 7月落地

**边界**：若外汇市场大幅波动（如人民币急贬），额度发放可能收紧；若国内经济复苏不及预期，需求端也会萎缩。

## Q2: 为什么说"额度虽放，但远未满足需求"？

**结论**：因为676只QDII份额中，超一半仍限购，且额度分配不均衡——优先给二级市场溢价高的基金，剩余才给其他产品。

**形式化表达**：
```
供给缺口 = 总需求 - 有效供给
→ 676只QDII中 > 50%限购
→ 194只限购<1万，96只限购<1千，35只暂停
```

**怎么想到的**：
- 看数据：676只QDII份额中，超一半限购，说明供给仍紧张
- 看分配逻辑：监管优先给"二级市场溢价过高"的基金 → 额度分配不均衡
- 看基金公司：即使获得新额度，旗下产品众多 → 分摊到每只依然有限

**边界**：若后续额度继续扩容或基金公司优化分配逻辑，限购情况会改善；若需求继续增长，供需矛盾可能持续。

## Q3: 除了QDII基金，还有哪些"出海通道"？

**结论**：还有两个——[[北向互认基金]]（香港优质基金来内地卖）和[[跨境理财通]]（大湾区居民专属，通过银行/券商买港澳基金）。

**形式化表达**：
```
出海工具箱 = QDII基金 + 北向互认基金 + 跨境理财通
互补：QDII（覆盖广） ≠ 互认（港股专业） ≠ 理财通（风控严）
```

**怎么想到的**：
- 北向互认基金：香港基金经批准来内地销售，直接投港股/海外债券
- 跨境理财通：大湾区居民专属，通过本地银行/券商买港澳公募基金
- 三者覆盖不同目标市场和风险偏好，形成互补

**边界**：北向互认基金仅限香港市场，跨境理财通仅限大湾区居民，QDII基金覆盖最广但额度受限。

## Q4: 为什么说"全球化布局是刚需"而不是"可选项"？

**结论**：因为A股与发达市场（如美股）的低相关性在长期内存在，多元化配置能改善组合的风险调整后收益（夏普比率）。

**形式化表达**：
```
全球化配置价值 = f(相关性)
→ ρ(A股, 美股) < 1
→ 组合风险↓ + 夏普比率↑
→ 沪深300+标普500组合夏普比率 > 纯沪深300
```

**怎么想到的**：
- 看相关性：发达市场与中国股市低相关性在较长时期内存在
- 看实证：2017年以来滚动10年，沪深300+标普500和沪深300+MSCI全球的夏普比率明显优于纯沪深300
- 看反例：沪深300+MSCI金龙指数在2022年前表现好，但近年因金龙指数高波动低收益而下降

**边界**：
- 在市场波动期间（如2008年金融危机），相关性会大幅上升，多元化效果减弱
- 在A股单边牛市（如2015年），全球化配置可能跑输纯A股组合

## Q5: 晨星建议的QDII筛选框架是什么？

**结论**：核心是"三步走"——评估基金经理及团队能力边界→解析投资策略底层逻辑→匹配自身风险偏好，再叠加分散配置。

**形式化表达**：
```
筛选框架 = 评估（基金经理 + 团队 + 策略）
         + 匹配（风险偏好）
         + 配置（分散化）
```

**怎么想到的**：
- 第一步看人：基金经理及投研团队的能力边界、稳定性、协作效率
- 第二步看策略：投资策略的底层逻辑和实际执行效果
- 第三步看自己：风险偏好是否匹配，避免风险错配
- 最后分散：不同风险收益特征的产品科学组合

**边界**：如果基金经理更换或团队不稳定，历史评估结论可能失效；如果市场环境剧变，策略底层逻辑可能不再适用。

## Q6: 为什么"长期持有"对QDII投资更重要？

**结论**：因为跨境投资的短期波动更大（汇率+市场双重波动），追涨杀跌的代价更高，长期持有才能兑现全球化配置的长期价值。

**形式化表达**：
```
QDII长期持有 = 克服（汇率波动 + 市场波动）
             → 避免"追涨杀跌"
             → 兑现全球化配置的长期价值
```

**怎么想到的**：
- QDII基金净值受汇率和海外市场双重影响，短期波动更大
- 全球化配置的长期价值（如低相关性改善夏普比率）需要时间兑现
- 短期择时在跨境投资中难度更大，胜率更低

**边界**：如果海外市场进入长期熊市（如2000-2002年美股），长期持有反而会持续亏损，此时需要重新评估是否继续持有。

## Q7: 从QDII额度的历史发展看，监管对QDII的态度经历了怎样的变化？

**结论**：经历了"高风险试点→规则修补→常态化扩容"三阶段，当前处于"审慎开放+动态平衡"状态。

**形式化表达**：
```
监管态度演变 = 2006-2008（试点+危机冲击）
             → 2009-2014（规则修补+结构优化）
             → 2015至今（常态化扩容+动态平衡）
             → 当前：1700亿美元总额度，超40%产品限购
```

**怎么想到的**：
- 第一阶段：2006年试点 → 2007年南方基金首发 → 2008年金融危机净值腰斩 → 监管收紧
- 第二阶段：2010年纳入债券/REITs → 2012年纳指ETF发行 → 总额度冻结在900亿
- 第三阶段：2018年重启审批 → 2020年突破1400亿 → 2025年达1700亿，但仍超40%限购

**边界**：若跨境资金流动出现异常（如大规模资本外逃），监管可能再次收紧；若人民币国际化进程加速，QDII额度可能进一步放开。

## 收口

这篇文章的核心价值在于：用"QDII额度松绑"这个新闻事件，串起"出海通道→全球配置必要性→筛选框架→长期持有"的完整逻辑链，帮投资者在额度稀缺时代构建一个靠谱的出海组合。
