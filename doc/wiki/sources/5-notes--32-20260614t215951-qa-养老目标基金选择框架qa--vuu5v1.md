# QA — 养老目标基金选择框架

> 原文来源：Morningstar 中国（2023-06-15）

核心论点：**养老目标基金不是选业绩最好的，而是选最适合的。**

## 原文问答结构

### Q1：目标日期基金和目标风险基金的核心区别？

**结论**：目标日期基金随退休日期临近自动降风险，目标风险基金保持固定风险水平。

```
目标日期 = 下滑路径（年轻时权益多 → 退休时固收多）
目标风险 = 固定风险等级（稳健/平衡/积极）
```

- 目标日期基金名字带年份（如 2035），为特定退休人群设计
- 年轻时可承受更多权益波动，退休前自动降低权益仓位
- 边界：目标日期假设所有人退休后需求相同，个体差异被忽略

### Q2：为什么养老 FOF 的基金经理需要不同的能力圈？

**结论**：养老 FOF 需要资产配置能力（选择基金）+ 底层资产理解（股票/债券），两者缺一不可。

```
养老 FOF 经理 = 资产配置经验 + 底层资产认知 → 两者缺一不可
```

| 经理 | 背景 | 能力侧重 |
|------|------|---------|
| 桑磊（中欧） | 16 年，保险组合背景 | 基金研究 + 底层资产 |
| 蒋华安（工银） | 15 年，社保基金理事会背景 | 大类资产配置 |

### Q3：如何评估养老 FOF 的"风险调整后收益"而非单纯业绩？

**结论**：看夏普比率，而非单纯排名。

```
夏普比率 = (基金收益 - 无风险利率) / 波动率 → 越高越好
```

- 万家鑫璟 2020 年前 2% 但波动高；工银纯债短期排名靠后但中长期稳健
- 两只基金夏普比率均位于同类前 10%——风险调整后收益出色
- 边界：夏普比率假设正态分布，对极端事件（黑天鹅）风险评估有限；过去夏普比率高不保证未来

### Q4：养老基金的费率结构有何特殊之处？

**结论**：养老 FOF 费率通常较低，且持有期越长费率优惠越大。

```
养老 FOF 费率 = 管理费 + 托管费 + 底层基金费率 → 双重收费问题
```

- 监管要求养老 FOF 费率优惠以鼓励长期投资
- 持有期越长，费率优惠越大（如 5 年以上免申购费）
- 边界：费率不是唯一考量，过度追求低费率可能错过优秀基金

### Q5：个人选择养老基金时需要评估哪些因素？

**结论**：退休年龄、风险偏好、已有资产、预期寿命、收入稳定性，因人而异。

```
养老规划 = f(退休年龄, 风险偏好, 资产状况, 收入预期) → 个性化配置
```

| 因素 | 影响 |
|------|------|
| 退休年龄 | 决定目标日期（如 2035 对应 75 后） |
| 风险偏好 | 决定选择目标日期还是目标风险、选择哪一风险等级 |
| 已有资产 | 决定补充缴费力度（已有企业年金可少缴，无则多缴） |
| 收入稳定性 | 决定缴费上限（最高 12000 元/年） |
| 预期寿命 | 影响资金规划期限 |

## 证据强度

中等。以两只基金为例对比，缺乏大样本数据支撑；夏普比率结论基于具体案例，普遍性有待验证。
