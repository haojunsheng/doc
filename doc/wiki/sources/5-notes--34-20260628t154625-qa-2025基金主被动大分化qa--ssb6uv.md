# 2025 基金主被动大分化

> 2025年全年非货基全景数据：被动基金贡献 125% 净流入，主动基金净流出 2509 亿，被动化从"加速"变为"确认"。

## 核心结论

2025 年中国非货基规模达 17.7 万亿，全年资金流入 1.02 万亿。但这"万亿"背后是主动基金净流出 2509 亿、被动基金净流入 12749 亿的极端分化。**被动贡献了 125% 的净流入——没有被动接盘，行业资金流入为负。**

被动基金规模占比从 2023 年初不到 20% 飙升到 40.7%，8 家基金公司被动规模已超过主动（2023 年底仅 3 家）。前 10 大基金公司市占率从 44% 升至 47%。

## 数据全貌

### 主动 vs 被动分流

| 指标 | 数值 |
|------|------|
| 行业总净流入 | +1.02 万亿 |
| 主动基金净流入 | -2509 亿 |
| 被动基金净流入 | +12749 亿 |
| 被动贡献率 | 12749 / 10200 ≈ **125%** |
| 被动规模占比（2025年底） | 40.7% |
| 被动规模占比（2023年初） | <20% |
| 主动基金流出主力 | 混合型基金净流出 3761 亿 |

### 债券资金流翻转

| 类别 | 2025 年流向 |
|------|------------|
| 纯债类（利率债/纯债/短债） | 大幅流出 |
| 积极债券（含权） | +9039 亿 |
| 基准做市信用债 ETF + 科创债 ETF | 全年吸金 4814 亿 |

### QDII 资金流：与 A 股行情非简单负相关

| 分类 | 全年净流入 |
|------|-----------|
| QDII 行业股票分类 | +1128 亿 |
| 香港股票型分类 | +2644 亿（股票型中最大） |
| 恒生科技 ETF 单品类 | >1100 亿 |
| QDII 整体（被动为主） | 8 成以上是被动管理产品 |

> **注意**：上半年 QDII 曾净流出 117.5 亿（因 A 股反弹资金回流），下半年港股强势逆转全年流向。需季度维度解读，不可用全年数字简单推断因果。

### 头部基金公司"失血但规模涨"假象

| 指标 | 数值 |
|------|------|
| 资金流下降的头部公司数 | 11 家 |
| 全年有机增长率 | 7% |
| 全年资本增值率 | 13% |
| 规模增长来源 | 主要靠股市上涨带来的资本增值，不是钱进来 |

## 关键机制

### 混合型基金连续三年净流出的深层原因

市场有效性提升 + 量化占比提升 + 风格轮动加速 → 主动超额收益压缩。

- 大盘成长股票分类净流出 1271 亿（高位获利了结）
- 积极配置-大盘成长分类净流出 2632 亿（最大流出分类）

### 资金迁移路径

主动股基/混合型/纯债/大盘宽基 → 被动指数/积极债/行业主题/港股 QDII/黄金商品

| 具体流向 | 金额 |
|---------|------|
| 主动股基净流出 | 708 亿 |
| 被动股基净流入 | 6424 亿 |
| 含权债基净流入 | +9039 亿 |
| 商品基金净流入 | 1273 亿 |
| 恒生科技 ETF | >1100 亿 |

## 边界条件

1. 若 2026 年市场风格从极致分化回归均衡，主动基金可能阶段性恢复净流入
2. 若 2026 年股市走弱、债市走牛，资金可能从含权债基回流纯债
3. 若港股表现走弱或外汇管制收紧，QDII 资金流入可能放缓
4. 若头部公司凭借品牌渠道优势重新发力主动业务，被动化趋势可能放缓
5. 若 2026 年延续牛市，资金流下降公司的规模仍会"靠天吃饭"式增长，但不可持续
