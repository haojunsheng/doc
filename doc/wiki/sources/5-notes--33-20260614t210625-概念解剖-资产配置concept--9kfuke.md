# 概念解剖 — 资产配置

来源：优化投资回报的四个必备步骤
作者团队：屈辰晨（晨星中国市场团队），编辑：陈昱融
核心提取：资产配置是投资回报的最大决定因素——它通过分散化降低波动、通过再平衡锁定收益、通过长期持有穿越周期，是普通投资者最可控的变量。

## 来源原文

原文以「八刀」方法解剖「资产配置」概念：定锚、历史刀、辩证刀、现象刀、语言刀、形式刀、存在刀、美感刀、元反思刀、内观、压缩。

### 核心数据

晨星研究显示，2016-2022 年间：

- 100% 股票组合：最坏一年亏损超 20%
- 50% 股票 + 50% 债券组合：最坏一年亏损约 11.48%
- 长期看，**90% 以上投资回报差异来自资产配置**，而非选股或择时（归因引用自 Brinson 经典研究）

### 四步框架

```
第1层：制定理财目标和计划 → 为什么投资？
    ↓
第2层：大类资产配置 → 股票、债券、现金的比例
    ↓
第3层：挑选优质基金 → 选什么产品？
    ↓
第4层：长期持有 + 成本控制 → 持多久？费用多少？
```

四步递进，没有前三步，第四步是空中楼阁。

### 压缩公式

```
资产配置 = 目标设定 × 股债比例 × 再平衡 × 长期持有
```

### 一句话

资产配置不是找最好的资产，是找最适合你的组合——认识自己，比认识市场更重要。

## 关键论断

1. **资产配置核心不是最大化收益，而是让波动处于心理承受范围内**（辩证刀）。能让你在熊市中安稳睡觉的组合，才是好组合。
2. **配置是起点，再平衡是过程**（语言刀）。「配置」一词带有工程学的精确感，但资产配置不是静态的，需要定期检视、调整、纠偏；更准确的表述是「资产动态管理」或「组合风险管理」。
3. **资产配置是反人性的自动化策略**（现象刀）：设定目标比例→定期再平衡，让组合自动执行高卖低买，对抗追涨杀跌冲动。
4. **资产配置是"认识你自己"在财务领域的实践**（存在刀）：知道自己能承受多少波动，比知道哪个基金会涨更重要。
5. **普通投资者存在注意力错配**（元反思刀）：把精力放在第三步（选基金），却忽视第一步和第二步（目标和配置）。
