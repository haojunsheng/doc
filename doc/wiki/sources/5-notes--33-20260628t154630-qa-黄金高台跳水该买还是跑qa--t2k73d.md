# 黄金高台跳水该买还是跑

**来源**：[Morningstar.cn 原文](https://www.morningstar.cn/articles/37492b21a806df92eb43595080ed6e41.html)
**日期**：2026-06-28

## 核心命题

黄金的正确标签是**低相关对冲工具**，而非"避险资产"。金价暴涨的四大推手为避险需求、通胀对冲、央行购金、ETF正反馈；长期配置有价值，短期梭哈是赌博。

## 主要问答

### Q1：为什么"避险资产"这个称呼具有误导性？

黄金被称为"避险"不是因为只涨不跌，而是因为与其他资产相关性低。单日跌幅可超过5%，其真正价值在于组合层面的分散效果。边界条件：极端系统性危机（全球金融体系崩溃）时，黄金仍可能成为最终避险手段。

### Q2：金价暴涨的"正反馈"效应是什么？

`金价↑ → ETF资金流入 → 买入实物 → 需求↑ → 金价↑↑`

2026年2月中旬以来黄金ETF持续大量净流入，底层持有实物黄金现货合约，规模越大对实物需求越高。**关键边界**：正反馈在下跌时同样反向运作——4%暴跌即反向正反馈的结果。

### Q3：央行购金对金价的影响有多大？

全球黄金需求结构：珠宝(50%) + 投资(20-30%) + 央行(20-30%)。包括中国在内的全球央行持续增持，动机为外汇储备多元化与控制通胀，构成重要底部支撑。边界：若央行突然停止购金或转净卖出，金价失去关键支撑。

### Q4：为什么说黄金长期会回归均值？

短期看避险+央行+ETF支撑高位震荡；长期看供应↑+需求↓的三重压力：
- 2020年疫情导致的矿山产量下滑已恢复
- 高金价刺激矿商最大化产量
- 央行购金无固定规律，终将回归常态

边界：若出现持续性新需求（如全球去美元化），均值回归时间大幅延长。

### Q5：黄金的正确打开方式是什么？

正确：组合配置(10-15%) + 长期持有 + 低相关性利用
错误：判断形势 + 短线交易

边界：若组合中黄金比例过高，其高波动性反而增加组合整体风险。

### Q6：暴跌4%说明了什么？

特朗普4月暂停加税90天 → 情绪突变 → 正反馈反向运作。与4月10日类似大跌机制相同，单次大跌不一定是趋势反转，需结合宏观环境判断。
