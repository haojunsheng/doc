# QA — 理财计划净资产快照：先算净资产再记账

> 理财计划的第一步不是记账，而是算清楚你现在有多少钱。这个"多少钱"不是月收入、不是存款余额，而是「净资产」——总资产减总负债。

## 核心论点

净资产是「家底照片」，记账是「日常流水」，先有照片才知道流水该往哪流。

```
理财计划步骤 = ① 算净资产 → ② 记账 → ③ 分析调整
```

## 公式体系

| 公式 | 表达式 | 含义 |
|------|--------|------|
| 净资产 | 总资产 − 总负债 | 静态"家底照片" |
| 总资产 | 流动资产 + 非流动资产 | 全部财富的加总 |
| 资产集中度 | 某类资产 / 总资产 | > 60–70% 时风险偏高 |
| 现金垫 | 流动资产中可随时支取的部分 | 失业缓冲期，目标 3–6 个月生活费 |

## 五个核心问答

### Q1：为什么理财计划的第一步是算净资产而不是记账？

**结论**：净资产告诉你「此刻你有多少钱」，是静态快照；记账告诉你「过去一段时间钱怎么动」，是动态过程。没有净资产，你不知道结余该拿去还债、投资还是消费。

**边界条件**：
- 净资产为负但未来收入增长可期（如刚毕业负债创业者），当前负值不代表长期财务健康
- 净资产为正但全是无法变现的资产（如偏远房产），数字好看但流动性差

### Q2：为什么要按流动性把资产分成流动和非流动？

**结论**：只看总资产不看流动性，会高估自己的抗风险能力。

**形式化**：
```
总资产 = 流动资产（现金/存款/股票/基金）+ 非流动资产（房产/汽车/收藏品）
```

**风险机制**：「我有 200 万资产」但其中 190 万是房子，手里只有 10 万现金，遇到急事一样抓瞎。

**边界条件**：如果非流动资产是核心城市优质房产，虽然流动性差但可以通过抵押贷款快速变现，实际流动性比表面高。

### Q3：为什么要检查「某类资产过度集中」？

**结论**：资产集中 = 风险集中，一旦该类资产大跌，净资产会跟着跳水。

**风险阈值**：某类资产占比 > 60–70% → 风险偏高

**中国家庭特有风险**：很多家庭净资产中房产占比超过 70%，房价一跌，纸面财富瞬间蒸发。

**边界条件**：
- 如果集中的是国债、存款等低风险资产，集中度高不等于危险
- 如果集中的是单一股票或加密货币，哪怕占比 30% 也危险

### Q4：现金垫为什么要 3–6 个月生活费？

**结论**：3–6 个月是「失业缓冲期」，够你找到下一份工作而不被迫卖资产或借高利贷。

```
现金垫下限 = 月必要开销 × 3（保守底线）
现金垫上限 = 月必要开销 × 6（宽裕保障）
```

**边界条件**：
- 收入来源多元（多份兼职、租金收入）→ 现金垫可低于 3 个月
- 收入单一且行业波动大 → 6 个月也不够

### Q5：净资产为负或勉强为正意味着什么？

**结论**：说明当前财务状况脆弱，需要立即制定理财计划止血，而非投资计划。

**财务健康分层**：
| 状态 | 含义 | 应对 |
|------|------|------|
| 净资产 < 0 | 资不抵债 | 立即止血计划 |
| 0 < 净资产 < 6个月支出 | 财务脆弱 | 止血计划优先 |
| 净资产 ≥ 6个月支出 | 有缓冲空间 | 可开始长期规划 |

**边界条件**：
- 净资产为负但负债是长期低息房贷，且收入稳定 → 不一定需要紧急处理
- 净资产为正但全是借来的（如信用卡套现买房）→ 实际风险比负值还高

## 财务体检三步法（收口）

| 检查项 | 类比 | 回答的问题 |
|--------|------|-----------|
| 净资产 | 体重秤 | 你此刻多重（有多少家底） |
| 流动/非流动拆分 | 体脂率 | 结构是否健康 |
| 现金垫厚度 | 血压 | 抗风险能力有多强 |

## 与中国市场的相关性

本文强调的中国家庭普遍风险——房产占比常超 70%——在 A 股语境下尤为突出，是理解 [[中产脆弱性]] 和 [[现金流断裂风险]] 的关键实证基础。
