# 伴读：基金界"最神奇"的九宫格

> 晨星中国文章，2026-06-22。以问答体（小Z / Momo）形式介绍晨星投资风格箱，核心论点是价值与成长长期收益趋同，风格箱是识别和选择基金风格的直观工具。

## 核心论点

价值与成长两种投资风格在长期来看收益趋同，不存在绝对的优劣之分。晨星投资风格箱是基于实际持仓的九宫格工具，帮助投资者识别基金的投资风格，构建分散化的投资组合。

## 关键证据

- 使用沪深300相对成长指数和沪深300相对价值指数的长期数据对比
- 短期因风格切换会产生业绩差异，但长期来看这种差异会变小，两者的收益水平甚至会趋向一致

**证据强度**：中等偏弱。来源是晨星的通俗科普文章，未给出具体数据图表或回测期数，仅以"会很直观"带过数据。

## 晨星投资风格箱关键事实

| 维度 | 内容 |
|------|------|
| 推出时间 | 1992年 |
| 纵轴 | 市值规模（大盘 / 中盘 / 小盘） |
| 横轴 | 价值-成长风格（价值 / 平衡 / 成长） |
| 分类依据 | 基金**实际持仓**（非名称/契约） |
| 九种组合 | 两个维度合并 → 9格 = 九宫格 |
| 查看路径 | 晨星官网 → "工具" → 基金筛选 |

## 核心结论

**"看持仓，不听宣传"**——风格箱的核心价值是用实际持仓而非基金名称来定位风格，避免"名不副实"的误判。投资者应根据市场特征和风险承受能力选择适合的格子，而非盲目追求某一风格。

## 终局问题

如果晨星投资风格箱是基于"实际持仓"的分类，那么当基金经理发生风格漂移（比如从价值转向成长）时，投资者该如何及时发现并应对？风格箱的"滞后性"会带来什么风险？
