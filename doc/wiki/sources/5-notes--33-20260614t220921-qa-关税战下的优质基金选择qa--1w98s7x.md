# QA — 关税战下的优质基金选择

**来源：** [[晨星morningstar]]（Morningstar）
**日期：** 2026-06-14
**URL：** https://www.morningstar.cn/articles/3b59d43074dfdaf5da49c6a68284d52f.html

## 核心论点

关税战是压力测试——它暴露了哪些基金在顺风时隐藏了风险，哪些基金在逆风时展现了韧性。选基金，看的是能不能穿越周期。

精准预测短期市场走势的概率极低，坚守长期目标才能避免冲动决策。投资决策质量 = f(长期目标清晰度) >> f(短期预测准确度)。

有完善投资流程和风控的基金管理人更能应对市场动荡。应对冲击能力 = f(投资能力, 投资流程稳定性, 风控管理)。

## Q&A 摘要

### Q1: 为什么关税战期间"关注长期目标"比"预测短期走势"更重要？

**结论：** 精准预测短期市场走势的概率极低，坚守长期目标才能避免冲动决策。

**边界：** 如果投资者的资金期限确实很短（<1年），短期规避风险是合理的。

### Q2: 为什么在关税冲击下要关注"基金管理者的投资能力和风控"？

**结论：** 有完善投资流程和风控的基金管理人更能应对市场动荡，甚至利用波动发掘机会。

**边界：** 投资能力和风控是长期因素——不能保证在每一次危机中都跑赢。

### Q3: 中泰星元价值优选的核心选股逻辑是什么？

**结论：** 自下而上，以较低价格买入有竞争优势的企业，偏好成本优势。

**形式化：** 选股 = 低估值 × 竞争优势（成本优势 > 产品差异化）

**证据：**
- 姜诚认为成本优势比产品差异化更容易把握
- 组合集中在化工、家电、交通、建材、银行等成熟行业的龙头企业
- 敢于重仓（持股约20只，前十大权重50-75%）
- 历史波动和下行风险始终低于同类

**边界：** 集中投资策略在选股正确时收益高，选股错误时损失也大。

### Q4: 大成高鑫（刘旭）如何在成长和价值之间灵活切换？

**结论：** 基于估值判断，在高估时减持成长股、低估时增持价值股。

**形式化：** 风格切换信号: 估值过高 → 减持成长 + 增持价值； 估值合理 → 均衡配置

**证据：**
- 用企业"现在的能力能否应对行业未来10年的需求"判断长期价值
- 用长期自由现金流折现与买入价格对比判断估值
- 2021年开始减持食品饮料、电子、电力设备，增持通信、石油石化、家电
- 9个完整年度均跑赢同类和沪深300

**边界：** 风格切换依赖基金经理的估值判断——判断错误会导致错失机会。

### Q5: 建信纯债（黎颖芳+彭紫云）的固收+策略有什么特点？

**结论：** 以信用债为主，灵活调节利率债比例和久期，控制AAA以下品种占比。

**形式化：** 组合 = 信用债（基准100%） + 利率债（灵活调节0-50%） + 久期（1-3.5年）

**量化约束：**
- AAA以下品种控制在25%以内
- 银行二级资本债控制在30%以内（波动性高）

**边界：** 久期调节依赖对利率走势的判断——判断错误会放大波动。

## 三类抗冲击路径

| 基金 | 基金经理 | 抗冲击路径 | 核心特征 |
|------|---------|----------|---------|
| 中泰星元价值优选 | 姜诚 | 自下而上低估值选股 + 集中持股 + 成本优势偏好 | 历史波动与下行风险低于同类 |
| 大成高鑫股票 | 刘旭 | 估值驱动风格中性 + DCF长期折现框架 | 9年连续跑赢同类和沪深300 |
| 建信纯债债券 | 黎颖芳 + 彭紫云 | 信用债打底 + 久期灵活调节 + 硬风控约束 | 债市避险环境中的稳健配置 |

## 证据强度评估

- **中泰星元：** 定性描述（"历史波动和下行风险始终低于同类"），无具体数值证据，证据强度中等
- **大成高鑫：** 有量化陈述（"9个完整年度均跑赢同类和沪深300"），证据强度较高
- **建信纯债：** 策略描述具体（百分比约束），但无业绩实证数据，证据强度中等
