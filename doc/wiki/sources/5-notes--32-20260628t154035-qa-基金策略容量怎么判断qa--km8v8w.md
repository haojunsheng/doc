# 基金策略容量怎么判断

来源：[晨星中国](https://www.morningstar.cn/articles/c9f7468d634e5b38ca82ffcd95c6f274.html)

## 核心主题

基金规模增长超出策略容量会导致交易冲击成本上升、持股被迫偏大盘、换手率下降、流动性恶化。晨星以广发创新升级基金为例，展示了规模从13亿涨到146亿过程中，基金经理被迫放弃中盘股、换手率从372%降到103%、流动性显著恶化，最终在小盘股行情中排名垫底。

## 关键问答摘要

### Q1: 什么是基金的策略容量？

基金经理在不损害超额收益的前提下能管理的最大资金规模，超出后被迫偏离策略。

**形式化：**
```
策略容量 = 超额收益可持续的最大规模 → 超出 → 策略变形 → 超额消失
```

**边界：** 策略容量不是固定值，会随市场流动性变化而演变。

### Q2: 规模增长对基金有哪三大冲击？

1. 交易冲击成本上升
2. 投资流程效率下降
3. 小市值公司买不到理想仓位

**形式化：**
```
规模↑ → 交易冲击成本↑ + 流程效率↓ + 小票买不够 → 超额收益↓
```

**边界：** 在流动性极度宽松的市场中，冲击成本会暂时降低。

### Q3: 广发创新升级基金规模从13亿涨到146亿发生了什么变化？

**实证数据：**
- 2019-2020年：年化回报 93.31%，吸引大量申购
- 规模：13亿 → 146亿（×11.2）
- 换手率：372% → 103%
- 中盘股占比：35% → 12%
- 平均流通市值：313亿 → 1056亿
- 2021-2023年排名跌至 95% 分位

**形式化：**
```
规模13亿→146亿 → 换手率372%→103% + 中盘股35%→12% + 市值313→1056亿
```

### Q4: 为什么规模大了就买不了中盘股？

中盘股流动性有限，大资金买卖冲击成本高，基金经理被迫转向超大盘股。

**形式化：**
```
中盘股流动性 ⊂ 规模冲击 → 买不够目标仓位 → 被迫买超大盘
```

**具体操作：**
- 增持隆基绿能、药明康德等超大盘股替代中盘
- 超大盘占比从19%升到29%

**边界：** 若中盘股流动性整体改善（如市场活跃度提升），限制会减弱。

### Q5: 基金限购了为什么规模还在涨？

限购分1万/10万/100万三档，2020年Q1仍吸纳35亿净现金流，叠加净值增长规模涨了73%。

**形式化：**
```
限购 ≠ 暂停申购 → 35亿净申购 + 净值增长 → 规模仍涨73%
```

**边界：** 若基金公司完全暂停申购，规模增长只来自净值增长。

### Q6: 怎么判断一只基金是否超出了策略容量？

综合看平均流通市值、换手率、组合流动性在规模增长时是否发生异常变化。

**形式化：**
```
规模增长时 → 观察{平均流通市值, 换手率, 流动性}是否异常偏离 → 判断是否超限
```

### Q7: 基金公司控制规模有哪些手段？

限购（分档限制申购金额）和暂停申购是最直接的手段，晨星更青睐严格规模监控的基金公司。

**形式化：**
```
规模监控 → 限购(分档) → 暂停申购 → 保护策略容量
```

**边界：** 基金公司有做大规模的商业动机，不是所有公司都会主动限购。

## 收口

晨星用广发创新升级的完整案例揭示了一条因果链：业绩好→资金涌入→规模超限→策略变形→超额消失——这就是"规模诅咒"。
