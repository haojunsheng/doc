# 伴读：回报率比净值更重要

**来源：** [晨星中国 Morningstar.cn](https://www.morningstar.cn/articles/1f4b3923f49f547de3d3f65646266033.html)  
**日期：** 2023-08-20

## 一句话摘要

基金净值只是时点价格快照，不能反映真实收益——**回报率**才是衡量基金业绩的正确指标，但比较回报率必须满足同类、同期、同风险三个前提，且应关注长期和逐年表现，而非短期排名。

## 核心结构

- **问题指出**：净值≠收益，净值高不等于赚得多
- **概念定义**：总回报率 =（资本增值 + 期间分红）/ 初始投资 × 100%
- **比较前提**：同类、同期、同风险——缺一不可
- **实践建议**：关注长期和逐年表现，确认基金经理仍在职

## 关键公式

```
总回报率 = (资本增值 + 期间分红) / 初始投资 × 100%
```

## 三个指数对比

| 指数类型 | 是否含分红再投资 | 是否扣红利税 | 说明 |
|---------|----------------|-------------|------|
| 价格指数 | 否 | — | 只反映股价变动 |
| 全收益指数 | 是 | 否 | 假设分红再投资 |
| 净收益指数 | 是 | 是 | 分红再投资 + 扣除红利税 |

长期来看，三者差距随复利效应扩大。

## 回报率比较的三个前提

1. **买入时点与持有周期相同**：同一只基金，高点买入 vs 低点买入、持有三年 vs 持有五年，收益天差地别。
2. **必须是同一类型基金**：股票型 vs 债券型不可比，风险与投资目标完全不同。
3. **同类中还需注意风险特征**：保守混合型 vs 积极配置型虽同属混合型，但股票仓位差异大，直接比较无意义。

## 实践检查清单

- [ ] 能算出过去三年的总回报率（含分红）吗？
- [ ] 能找到同类基金在同一时间段内做对比吗？
- [ ] 能确认创造良好业绩的基金经理是否仍在职吗？

# 净值与回报率的区别

基金净值是某一时点的每份价值快照，反映的是**当前价格**；回报率则是某段时间内的**实际收益水平**，两者有本质区别。

## 核心区别

| 维度 | 基金净值 | 回报率 |
|------|---------|--------|
| 性质 | 时点价格快照 | 期间收益比例 |
| 能否反映业绩 | 不能 | 能 |
| 受分红影响 | 分红后净值下降 | 分红计入回报 |
| 可比性 | 不同时间点不可比 | 满足前提后可比 |

## 常见误区

> "净值2.0的基金比净值1.0的基金好。"

这是错误认知。净值2.0的基金若从1.0起步，涨幅为100%；净值1.0的基金若从0.5起步，涨幅为100%——两者实际收益相同，只是起点不同。

> "净值越高，上涨空间越小。"

净值高低与未来上涨空间无关，取决于基金经理的投资能力和市场环境。

## 正确计算方式

```
总回报率 = (资本增值 + 期间分红) / 初始投资 × 100%
```

其中：
- **资本增值** = 期末净值 - 期初净值
- **期间分红** = 持有期间获得的现金分红或红利再投资金额

## 为什么净值会误导投资者

净值是"价格标签"，回报率是"成绩单"。用净值判断业绩，就像用身高判断能力——数据有，但意义无。

# 全收益指数与净收益指数

市场指数按是否包含分红再投资及红利税，分为三类：**价格指数**、**全收益指数**、**净收益指数**。三者的长期差距源于复利效应。

## 三个指数的定义

| 指数类型 | 分红处理 | 红利税 | 适用场景 |
|---------|---------|--------|---------|
| 价格指数 | 不含 | — | 单纯反映股价变动 |
| 全收益指数 | 假设分红再投资 | 不含 | 理论上的最大回报 |
| 净收益指数 | 假设分红再投资 | 扣除 | 更接近投资者实际所得 |

## 以沪深300为例

沪深300的**价格指数**仅反映成分股价格涨跌，不体现分红；**全收益指数**假设分红全部用于再投资，长期收益率显著高于价格指数；**净收益指数**在全收益基础上扣除红利税，是投资者实际可得的近似水平。

## 长期差距的来源

分红再投资产生**复利效应**：
- 分红 → 买入更多份额 → 更多分红 → 再买入……
- 每年分红金额的差异随时间呈指数级放大
- 税后净收益与实际到手收益的差距逐年扩大

## 对投资者的启示

1. 看指数历史走势时，区分用的是哪种指数——价格指数的涨幅被严重低估了长期回报
2. 计算基金回报率时，需明确是否假设了分红再投资
3. 实际到手收益通常介于全收益指数与净收益指数之间，取决于分红方式选择

# 基金回报比较三前提

比较两只基金的回报率时，必须同时满足三个前提条件，否则比较结果毫无意义。

## 三个前提

### 1. 买入时点与持有周期相同

同一只基金，在不同时点买入、持有不同期限，回报率差异巨大：
- 牛市高点买入 vs 熊市低点买入
- 持有3年 vs 持有5年

**原则**：不同买入时点和持有期的回报率不可直接比较。

### 2. 必须是同一类型基金

股票型基金年化20% vs 债券型基金年化5%——前者更高，但风险和投资目标完全不同，比较没有意义。

**原则**：不同类型基金的回报率不可比，就像苹果和橘子不能比甜度。

### 3. 同类中需注意风险特征

同属"混合型基金"大类，但风险收益特征差异巨大：
- **保守混合型**：股票仓位较低，波动较小
- **积极配置型**：股票仓位较高，波动较大

两者直接比较回报率，如同让举重运动员和长跑运动员比体重——数字有，但意义无。

**原则**：同一类型内还需进一步细分风险特征，才能进行有意义的比较。

## 一句话总结

**苹果只能和苹果比**——同类、同期、同风险，缺一个前提，比较都是数字游戏。

## 实践应用

晨星星级评价（[[晨星星级评价]]）正是基于这三前提来构建：在同类型基金中、按相同期限、用风险调整后回报率排序。

投资者自查时可用以下问题检验：
- 我和朋友比的是同类型基金吗？
- 我们持有的时间一样长吗？
- 两只基金的风险特征接近吗？
