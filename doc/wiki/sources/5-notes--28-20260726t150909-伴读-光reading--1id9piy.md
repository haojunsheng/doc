## Main Arguments & Findings

**核心主张 1：光是摄影的第四维（与曝光三角并立）**
- 证据：全文结构以"光"为独立章节，拆解为质量/方向/强度/颜色四要素
- 强度：强。这是"摄影入门课"课程的内在逻辑转折点，从"相机怎么控光"转向"光本身怎么控"

**核心主张 2：光的方向比软硬更能决定照片观感**
- 证据：P12 用正午硬光 vs 黄金半小时硬光对比说明，同为硬光，方向不同观感迥异
- 强度：中等。经验性判断，有实例支撑但缺乏量化证据

**核心主张 3：闪光灯用途是"塑造"而非"照亮"**
- 证据：三个具体用途（特效/压暗背景分离主体/逆光补光）+ 平方反比定律的物理原理
- 强度：强。有物理定律（平方反比）支撑，且与常见误区形成张力

**核心主张 4：硬光/软光不是绝对的，取决于表达意图**
- 证据：Frank Ockenfels 和 Bruce Gilden 都是硬光大师，硬光拍人照样成立
- 强度：中等。用案例反驳二元对立，说服力强

**结构性洞察（旁逸部分）：光要素与曝光三角的对应关系**
```
光的质量（软硬）     →  影响你对光圈的选择
光的方向            →  影响你对测光模式和曝光补偿的调整
光的强度            →  影响你对快门和 ISO 的组合
光的颜色            →  影响你对白平衡的设置
人为光（闪光灯）     →  同时影响全部三个参数
```
