# QA — 行业基金是组合必需品吗

作者用十年行业表现数据和相关系数图说明了一个反直觉的事实：行业基金不是组合的必需品，反而可能是波动的放大器。真正的分散靠的是跨资产，不是同资产内的行业轮动。

## 核心结论

- **行业基金不是组合必需品，而是波动的放大器。**
- 前一年领涨的行业，次年往往大幅回撤（"滑铁卢"），追涨即接盘。
- 消费、医药等热门行业与沪深 300 相关系数 > 0.7，本质是"影子大盘"，多付管理费买入同一篮鸡蛋。
- 高波动行业里，基金收益 +60%、投资者实际收益 -20%，波动扭曲了行为。
- 真正的风险降低靠跨资产类别分散（股/债/商品/海外），而非同一资产内的行业轮动。
- "完美的预测会自我毁灭"：预测被广泛采用后，行动本身消灭预测成立的前提。

## 十年行业轮替实证（年度领涨行业）

| 年份 | 领涨行业 |
|------|---------|
| 2020 | 白酒、互联网 |
| 2021 | 新能源 |
| 2022 | 煤炭 |
| 2023 | 通讯 |
| 2024 | 金融地产 |
| 2025 | 创新药 |

没有行业能连续三年领先。

## 投资者回报差案例

- 创新药板块 2025 年涨幅 +60%，30 亿资金跑步入场
- 高波动行业基金：基金收益 +60%，投资者收益 -20%
- 差距来源：择时失误 + 情绪驱动

## 核心机制

```
行业轮动追涨: 前一年领涨 → 次年大幅回撤（"滑铁卢"效应）
行业≠分散: 相关系数>0.7 → 行业≈大盘 → 分散效果≈0
跨资产分散: 股/债/商品/海外相关性低 → 真正降低波动
完美预测的自我毁灭: 预测正确→所有人照做→价格已反映→预测失效
```

## 边界条件

- 极少数长期结构性增长赛道（识别难度极高）可能连续多年跑赢
- 若行业与大盘相关性结构改变，分散效果会变化
- 跨资产分散在单一资产长期大牛市中会拖累收益
- 投资者若具备行业极深研究，可例外使用行业基金
