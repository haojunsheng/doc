# QA — 美大选左右不了股市长期走势

晨星中国分析特朗普与哈里斯经济政策差异及其对美股影响，核心结论：**历届总统任期内美股均经历繁荣与低迷，总统不是市场走势的决定因素；基于选举结果做投资决策是危险的。**

## 核心结论

- **Q1 税收政策**：哈里斯向富人加税（增公司税、提高个税最高税率、对未实现资本利得征税），特朗普全面减税（企业减税、取消小费税和社会保障税）——但两人都未将削减政府赤字作为优先目标。
- **Q2 关税与制造业回流**：2018-2019 年关税实验（NBER 研究）未推动制造业就业增长，反而伤害经济；特朗普提议对所有进口加 10%、对中国加 60%，经济学家普遍持负面态度。
- **Q3 通胀对策**：两党均缺乏有效的通胀工具——哈里斯的食品限价实施难度大，特朗普的关税反而推高物价，加剧通胀。
- **Q4 美联储独立性**：特朗普一贯支持低利率和货币宽松，即使在经济扩张期也倾向宽松；削弱美联储独立性是其政策主张之一，若实施则可能引发通胀失控或长期利率上行风险。
- **Q5 总统与市场走势无关**：小布什任期内经历互联网泡沫、9/11 和 2007 年危机；奥巴马任内股市表现出色；特朗普上次任期内股市也好——无论谁执政，美股都有牛市和熊市。
- **Q6 选举议题漂移**：2012 年候选人聚焦就业承诺，2024 年聚焦通胀；候选人主要回应当前民众最关心的问题，选举焦点随时间变化，不能作为长期配置依据。
- **Q7 投资者应对**：保持理性冷静，不要因为选举结果随意调整组合；政策不确定期市场波动加剧，情绪和观点会破坏理性决策。

## 形式化推理

```
总统 ≠ 股市决定因素
历史证据：历任总统任期均有牛市与熊市并存

关税 → 物价↑ + 制造业回流有限 → 就业无明显增长 → 经济负面影响（NBER 实证）

哈里斯 = 加税 + 限价（难实施）
特朗普 = 减税 + 关税（推通胀）
→ 两人均无有效通胀对策

政策不确定性↑ → 市场波动↑ → 择时风险↑
```

## 边界条件

- 若总统政策导致极端后果（经济危机或战争），市场反应可能比以往更剧烈
- 若美国债务问题恶化，两党可能被迫转向财政紧缩
- 若通胀问题缓解或就业问题重新成为焦点，候选人政策主张可能调整
- 若美联储独立性被实质性削弱且市场信心下降，长期利率可能上行
