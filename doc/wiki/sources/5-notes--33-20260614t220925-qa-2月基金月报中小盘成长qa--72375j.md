# QA — 2025年2月基金月报：中小盘成长风格占优，固收分化

**来源**：[[晨星morningstar]] — 2025年2月基金月报  
**URL**：https://www.morningstar.cn/articles/aa239cd87a0f874bfda8598f054fc4d4.html

## 一句话摘要

2025年2月，A股因1月CPI转正和经济数据超预期而回暖，中小盘成长和风格基金表现最佳；同时债市因降息预期减弱、国债收益率上行而调整，固收基金内部出现明显分化，再次验证"没有只涨不跌的资产"。

## 核心发现

### Q1：为什么2月中小盘成长风格表现最好？

**结论**：经济数据超预期 + 政策利好推动风险偏好回升，中小盘成长股弹性更大。

**形式化**：
```
2月风格排序：中小盘成长 > 大盘成长 > 大盘价值 > 中小盘价值
```

**驱动路径**：
```
1月CPI转正（+0.5%）+ PPI降幅收窄
  → 经济数据超预期
  → 降准降息预期↓ + 科技创新政策支持
  → 风险偏好↑
  → 中小盘成长弹性更大 → 跑赢大盘价值
```

**边界条件**：若经济数据低于预期或政策利好低于预期，中小盘成长的反弹会受阻。

### Q2：2月债市为什么出现调整？

**结论**：经济数据超预期 + 降准降息预期减弱，推动国债收益率上行。

**形式化**：
```
经济超预期 → 降息预期↓ → 国债收益率↑ → 债券价格↓
```

**驱动机制**：
- 1月CPI同比 +0.5%（前值 -0.7%），PPI降幅收窄
- 经济数据超预期降低了降息的紧迫性
- 国债收益率上行 → 利率债基金承压

**边界条件**：若经济数据重新走弱，降息预期会重新升温，债市可能反转。

### Q3：2月固收基金内部表现分化的核心原因？

**结论**：利率债受国债收益率上行直接冲击，信用债有票息缓冲且信用利差收窄，走出独立行情。

**形式化**：
```
2月固收分化排序：
信用债基金 > 纯债基金 > 短债基金 > 利率债基金 > 可转债基金
```

**机制拆解**：
| 子类 | 2月表现 | 核心机制 |
|------|---------|---------|
| 信用债基金 | 最优 | 票息缓冲 + 信用利差收窄 |
| 纯债基金 | 次优 | 组合久期中等，受利率上行影响有限 |
| 短债基金 | 居中 | 久期短，利率敏感性低 |
| 利率债基金 | 较差 | 直接受国债收益率上行冲击 |
| 可转债基金 | 最差 | 股性拖累超过债底保护 |

**边界条件**：若利率环境反转（开始降息），利率债基金可能反而表现更好。

## 收口：历史循环模式

2月的市场再次证明：**没有只涨不跌的资产**。

- 1月表现最好的利率债 → 2月回调
- 1月表现较差的信用债 → 2月补涨
- 可转债基金垫底，但"跟随A股上涨"的说法与绝对收益排名存在口径差异（见开放问题）

这一循环模式与[[频繁交易是收益隐形杀手]]中强调的长期规律一致：任何单一资产/风格的强势都会因均值回归而被修正。
