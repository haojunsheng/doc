# QA — 量化投资的真相与陷阱

来源：[[entities/morningstar]] · 类型：QA

## 核心论点

量化投资是一种用数据和模型做决策的工具，它不是"稳赚的游戏外挂"，也不是恶魔。它的成功取决于策略是否有效、执行是否纪律、信息是否独特。

## 关键问答摘要

### 量化投资 ≠ 高频交易

量化投资包含多种策略形态。高频交易只是其中一个子集——基于短期股价判断、日内买卖赚价差。国内公募量化主要采用**基本面量化**策略：收集企业公开信息，持仓周期短则数月，长则几年，与高频交易完全不同。参见 [[concepts/量化投资]] 和 [[concepts/高频交易]]。

### 量化不是"稳赚"的原因：拥挤交易

每当一个新因子被发掘，所有量化机构都觉得自己找到了独门武功，蜂拥而入。结果就是：

```
新因子被发现 → 所有人涌入 → 拥挤交易 → 踩踏 → 均值回归
```

典型案例是 2024 年春节前，大批私募量化产品多米诺式下跌，有的单周跌 20%，抹掉过去两三年收益。原因是很多量化机构不约而同发现小盘股超额策略，前后脚买入，最后集体踩踏。参见 [[concepts/拥挤交易]]。

### 量化的两大根本挑战

1. **未来不完全是过去的重复**：量化交易通过历史数据预测未来，但这个假设经常不成立。预测模型会失效。
2. **信息优势越来越难获得**：每年大量数学、计算机、金融工程高材生涌入行业，花哨的模型和代码很难拉开差距。互联网时代信息扩散极快，AI 也不能改变这一点——市场不是国际象棋，信息是变化的。参见 [[concepts/认知优势与信息迷雾]]。

### 监管逻辑

2024 年 2 月，沪深交易所表示将重点整治高频交易、过度运用信息优势等问题。监管的核心目标是防范信息不对称导致的市场不公平，而非禁止量化本身。合规的基本面量化投资仍然可以正常运作。

## 结论

对普通投资者而言，理解量化的内在逻辑（策略有效性决定成败，因子会拥挤、模型会失效）比盲目崇拜或恐惧更重要。这与 [[concepts/投资是输家的游戏]] 的精神一脉相承。
