# 基金经理经验不等于业绩，性格才是关键

来源：晨星中国（Morningstar CN），2024-06-27
链接：https://www.morningstar.cn/articles/f5a4ed4185f142273d5d98582cec5de0.html

## 核心论点

投资者常把"资深"等同于"优秀"，但晨星研究显示，基金经理的经验年限与业绩并无显著正相关。真正决定长期业绩的是基金经理的性格特质——能否在牛市保持清醒、在熊市保持纪律、在市场狂热时拒绝跟风。

### 论点一：经验 ≠ 业绩

```
经验 = 时间 × 反思深度
```

有经验但无反思 = 用1年经验重复操作10年。晨星研究发现经验年限与业绩无显著正相关。

**反例**：王宗合，管理鹏华匠心精选10年以上，但该基金3年跌38%。

### 论点二：牛市考验的是拒绝诱惑的纪律

```
牛市考验 = 风险识别能力 + 自律能力 → 拒绝追高 → 控制回撤
```

2020年多数基金经理将行情当能力，忽视高集中度与高估值风险，导致2021-2023年大幅回撤。相比之下，有经理在2020年明确说"这么高收益是市场赏的，不能指望年年如此"，后续三年跌幅可控。

### 论点三：自我服务偏见是可识别的危险信号

```
自我服务偏见 = 成功归己 + 失败归因市场 → 缺乏反思 → 重复犯错
```

美国研究显示：59%的成功归因于内部因素，83%的失败归因于外部因素。有该偏见的基金经理更愿承担风险、交易更频繁，但业绩反而更差。

**识别方法**：读季报语言分析——"战胜基准因为消费配置"=归己；"业绩受逆风影响"=甩锅。

### 论点四：敬畏市场是超额收益来源

```
敬畏市场 = 承认无知 + 建立纪律 → 控制回撤 → 长期复利
```

谦逊的经理承认市场不可预测，建立风控流程；自负的经理高估自己，忽视运气成分。

## 投资者实践框架

```
性格识别 = 归因风格 + 风控记录 + 牛市行为 → 选择谦逊+纪律型
```

可操作的三条信号：
1. 读季报"小作文"，看成功/失败时如何归因
2. 看牛市中是否主动限购（2020年少有经理限购）
3. 看最大回撤是否可控（对比同类基金）

## 边界条件

- 在特定市场环境下（如单边牛市），经验丰富的经理可能更有优势，但长期看性格 > 经验
- 性格判断需要时间，不宜频繁更换基金
- 历史表现不保证未来，但行为模式有一定延续性
