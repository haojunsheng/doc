# QA — 股债跷跷板下的基金选择

> 晨星2025年7月基金月报，揭示股债分化市场中不同基金类别的表现差异及选择逻辑。

## 来源概述

2025年7月，A股主要指数普涨3-5%（受"反内卷"政策+创新药/AI行情+中美缓和三重利好驱动），中证全债指数下跌0.11%（受监管指导农商行政策扰动+股债跷跷板资金分流双重打击）。偏股基金普涨近6%，固收类基金涨跌互现——可转债基金+3.19%，利率债基金-0.23%。本文用"股债跷跷板"框架串联各基金类别表现差异。

## Q1: 7月股债分化的直接触发因素

**结论**：A股受政策+产业+外部三重利好驱动；债市受监管扰动+资金分流双重打击。

**形式化**：
```
A股驱动 = 政策（反内卷）+ 产业（创新药/AI）+ 外部（中美缓和）→ 主要股指涨3-5%
≠ 债市驱动 = 监管扰动（农商行指导）+ 资金分流（股债跷跷板）→ 国债收益率上行4-6bp
```

**边界**：若政策方向逆转，股债分化收窄；在"股债同涨"的宽松周期中，跷跷板效应消失。

## Q2: 为什么信用债好于利率债，但固收基金整体仍分化

**结论**：信用债受益于收益率下行+利差收窄；利率债受国债收益率上行拖累；不同基金的久期和信用暴露决定分化方向。

**形式化**：
```
信用债表现 > 利率债 ← 信用债收益率下行（1年期AAA↓1bp） + 中证企业债指数+0.02% > 中证国债-0.14%
≠ 利率债基金-0.23% ← 国债收益率全面上行（1/5/10年分别↑4/6/6bp）
```

**基金分类排序**：可转债基金+3.19% > 积极债券+0.93% > 普通债券+0.21% > 利率债-0.23%

**边界**：若经济超预期复苏推动利率大幅上行，信用债利差可能走阔，信用债基金也会转跌。

## Q3: 行业基金为何冰火两重天

**结论**：医药行业基金平均回报18%，消费仅1.5%，差异来自产业政策+出海逻辑 vs 内需疲软。

**形式化**：
```
行业基金回报差异 = f(产业政策, 出海逻辑, 内需)
→ 医药（创新药政策+出海）→ +18.07% ≠ 消费（内需疲软）→ +1.68%
```

**边界**：若创新药政策收紧或出海受阻，医药基金会回落。

## Q4: 固收+基金在股债分化市中的核心矛盾

**结论**：核心矛盾是"权益暴露度"的权衡——暴露高则在牛市弹性大但熊市回撤大，暴露低则在牛市弹性不足但熊市更抗跌。

**形式化**：
```
固收+收益 = 纯债底仓收益 + 权益增强收益
权益暴露↑ → 牛市弹性↑ + 熊市回撤↑
权益暴露↓ → 牛市弹性↓ + 熊市回撤↓
```

**边界**：若A股继续上涨且债市企稳，高权益暴露更优；若A股回调或债市下跌，低权益暴露更稳健。

## Q5: QDII基金的配置价值

**结论**：QDII配置价值上升——海外主要股指普涨，大中华区+6.84%，环球+6.41%。

**形式化**：
```
QDII配置价值 = f(海外股市涨幅, 汇率, 额度)
→ 海外股市普涨（富时100+4.24%，恒生+2.91%，标普+2.17%）
+ QDII额度新发30.8亿美元 → 大中华区+6.84%，环球+6.41%
```

**边界**：若美元走强或海外市场回调，QDII承压；若人民币贬值，汇率收益增厚。

## Q6: 持有固收+的投资者应该怎么做

**结论**：固收+业绩差异主要来自"+"的部分——是加可转债、加股票还是加其他资产。

**形式化**：
```
固收+差异 = "+"资产类别 → 可转债增强（+3.19%）> 股票增强（+2.28%）> 纯债（+0.22%）≠ 利率债增强（-0.23%）
```

**边界**：若A股回调但债市企稳，纯债增强型可能跑赢可转债增强型。

## Q7: 成长风格优于价值风格的原因

**结论**：受益于创新药和AI行情驱动的大盘成长股表现，以及市场风险偏好提升。

**形式化**：
```
成长 > 价值 ← 创新药/AI行情 + 风险偏好提升
→ 大盘成长+6.36% > 大盘价值+2.75%
```

**边界**：若市场风险偏好下降，价值可能跑赢成长。

## 核心洞见

1. **股债跷跷板是7月分化总框架**：政策→产业→风格→基金选择，形成一条完整逻辑链
2. **权益暴露度是固收+分化的第一解释变量**：选固收+产品时应先问"你的+'部分是什么"
3. **行业基金分化源于产业政策**：医药（政策+出海）vs 消费（内需疲软），非随机波动
4. **QDII在7月价值凸显**：海外普涨+额度扩容双驱动
