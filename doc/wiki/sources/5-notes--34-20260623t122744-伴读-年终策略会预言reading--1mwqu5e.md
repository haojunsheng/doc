# 伴读 — 年终策略会预言：满天飞的预言哪条最靠谱？

本文论证年终策略会的预测对投资决策几乎无价值，投资者应将策略会视为营销行为而非投资指导。

## 核心论点

金融市场比天气复杂得多，且预测本身会影响投资者行为，导致"聪明人"无法按常理出牌。最终结论：**策略会 = 营销行为**。

## 实证：中金公司10大预言全错

中金公司每年末发布对未来一年的10大预言，今年是第8个年头。2023年的预测目前来看全部错误（命中率 0/10），低于抛硬币的 50% 基准：

| 预言 | 实际结果 |
|------|---------|
| 美国衰退、中国率先复苏 | 美国数据良好，国内 CPI 转负 |
| A股港股明显正收益，港股跑赢A股 | A股仍在约 3000 点，恒指从 20000 跌至 18000 |
| 疫后通胀面临阶段性压力 | CPI 走低，年内第二次转负 |
| 货币宽松势减，股强于债 | 两度降准降息，利率走低 |
| 地产销售面积回升 | 地产暴雷，各线城市房价环比下降 |
| 出口仍有压力 | 前三季度出口保持较好势头 |
| 泛消费行业有超额收益 | 消费未起 |
| 互联网和医药行业反转 | AI 行情已跌回，医药离回本尚早 |
| 海外资金逐步回流 | 北上资金净流入为 2016 年以来最少 |
| 美元拐点，人民币走强 | 年内多次汇率保卫战 |

"全错也是一种能力"。反着买，今年已经别墅靠大海了。

## 为什么预测市场比预测天气难

晨星行为金融研究团队的类比指出两个关键差异：

1. **反馈周期**：气象预测可在相对短的周期内验证，金融市场无此规律。
2. **预测影响行为**：市场里有很多人并不希望自己的行为能被别人预测。任何可被预测的趋势都会被"聪明人"提前反应并消化，公开预测反而扭曲结果。

典型案例：2019-2020 年核心资产抱团。机构价值投资者按"好公司、好行业"逻辑选出同一批股票，认为可以稳坐长坡厚雪慢慢赚钱，结果被冲高回落的价格波动反噬——当所有人都做出相同选择时，定价已提前透支。

## 为什么金融行业仍持续生产预测

投资者需要"确定性"。研究显示自信的人在金融行业混得更好，因为投资者更倾向于把钱交给笃定告诉他们未来一年能保证翻倍的人，而不是警示风险、说"不知道"的人。

金融机构做预测本质上是一种**营销需求驱动的行为**。

> 达利奥（1987）："预测的价值并不是很高，而且大多数做预测的人并没有在市场上赚钱……原因是没有什么是确定的。"

> 霍华德·马克斯（《投资最重要的事》）："市场上只有一件事是确定的，就是什么都不确定。"
