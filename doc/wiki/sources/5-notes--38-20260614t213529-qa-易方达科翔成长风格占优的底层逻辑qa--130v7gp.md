## 主要论点与发现

**核心论点：** 易方达科翔11年年化超额12.48个百分点，源于"中观行业判断+自下而上选股"的双轮驱动框架，但该风格暴露（中小盘+成长）是双刃剑——2025年回报72.25%（超基准39pp），2024年却跑输基准6.48%，说明风格适应性决定业绩波动。

**形式化支撑：**

```
超额收益 = 中观行业比较（自上而下）∩ 个股精选（自下而上） → 12.48%年化超额
成长风格 × 科技股牛市 → 72%回报
成长风格 × 价值股牛市 → -0.47%回报
规模↑（299亿）→ 中小盘流动性不足 → 能力圈拓展到大盘股 → 策略容量↑
高换手（400-500%）= 交易驱动 → 低换手（<200%）= 研究驱动 → 成本↓ + 胜率↑
行业集中度↑（40%→50%）∩ 单一行业≤30% → 超额收益潜力↑ 但 风险可控
费率差（2.27%-1.76%=0.51%）× 11年复利 → 累计多赚约10%
```

**证据强度评估：**
- 2025年 vs 2024年业绩对比数据具体（72.25% vs -0.47%，基准对比39pp vs -6.48pp）→ 强证据
- 费率复利计算为估算（"约10%"），非精确审计数据 → 中等强度
- 11年维度的长期业绩归因存在幸存者偏差风险 → 需保留

**关键边界条件（文章明确承认）：**
1. 若市场风格从"行业轮动"转向"个股分化"，行业配置的超额会下降
2. 大盘股行情中可能跑输基准
3. 能力圈拓展需要时间验证，存在"两头落空"风险
4. 若研究深度不够，低换手只是"被动持有"

## 矛盾与张力

1. **风格一致性与规模扩张的张力**：风格越鲜明（中小盘+成长），风格集中度高时超额收益越大，但规模一旦超过中小盘流动性承载上限，就必须被迫拓展能力圈，导致风格纯度下降。
2. **低换手的双重解释**：低换手可以解读为"研究驱动成熟"，也可以解读为"研究深度不够、被动持有"——两种解释在结果上不可区分，取决于投资者信任。
3. **行业集中度提升的风险**：前三大行业从40%升到50%，但单一行业上限仍为30%，这两个数字之间的空间较窄，意味着配置灵活性受限。
