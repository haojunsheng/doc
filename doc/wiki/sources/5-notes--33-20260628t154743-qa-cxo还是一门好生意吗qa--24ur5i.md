# CXO还是一门好生意吗

来源：晨星中国（Morningstar）

> 药明生物下调业绩预期，单日暴跌23.79%，CXO板块全线飘绿。322只基金持有药明生物，43只持仓超5%。CXO被称为"旱涝保收"的医药外包生意，但美联储加息+新冠红利消退让短期增速承压。

## 核心问题与结论

文章围绕6个核心问题展开，形成从"商业模式本质→短期困境→宏观传导→长期逻辑→增量来源→板块联动机制"的完整论证链。

| 问题 | 结论 |
|------|------|
| CXO凭什么"旱涝保收"？ | 服务费模式，不承担药品研发成败风险；但行业层面仍受药企研发活跃度影响 |
| 药明生物为何"业绩变脸"？ | 新冠收入快速下降 + 全球药企融资困难导致项目延迟，双重打击 |
| 美联储加息如何传导到CXO？ | 利率↑→药企融资成本↑→削减研发管线→CXO订单↓，传导有滞后性 |
| CXO长期增长逻辑是什么？ | 外包渗透率提升 + 生物制剂占比增加 + 全球药品需求增长，三重驱动 |
| DCT为何是新增量？ | 远程智能临床试验降低成本、加速上市，监管接纳是关键变量 |
| 药明生物跌23%为何带崩全板块？ | 龙头预期下修→整个赛道估值重估→市场情绪逆转 |

## 关键数据

- 临床试验外包渗透率：27.3% → 51.2% → 目标60%（2032年）
- 生物制剂占FDA批准药物：50%，生产难度大，更依赖外包
- 全球药品使用量年均增长：3%
- 全球药品支出年均增长：6%
- 药明生物持有数据：322只基金持有，43只持仓超5%
- 新冠相关收入：2023年快速消退

## 形式化框架

```
CXO基本盘 = 服务费模式 → 药企无论研发成败都要付钱 → 单个层面"旱涝保收"

业绩变脸 = 新冠收入↓ + 药企融资↓ → 项目延迟

加息传导链 = 美联储加息 → 药企融资成本↑ → 研发管线削减 → CXO订单↓
            （存在滞后性，恢复也需要时间）

长期增长 = 渗透率↑ + 生物制剂占比↑ + 药品需求↑

DCT增量 = 远程试验 → 成本↓ + 速度↑ → 药企采用↑ → CXO收入增量

板块联动 = 龙头(322只基金持有) → 下调预期 → 板块估值重估 → 全线飘绿
```

## 边界条件与风险提示

- "旱涝保收"只在单个药企层面成立；行业层面受系统性因素（融资环境、利率周期）影响
- 去库存周期持续时间取决于美联储降息节奏，不确定性高
- AI可能替代部分外包需求（长期逻辑的潜在削弱因素）
- 若其他CXO公司业绩超预期，板块可能出现分化而非联动
