# QA — 大类资产预期回报收窄：高收益资产正变稀缺

## 核心命题

2025年全球普涨之后，各大类资产的长期预期回报都在收窄，高收益资产正在变得越来越稀缺。投资者应降低预期、多元配置、与时间同行——而不是在越来越贵的资产里找高回报。

## 关键发现

### Q1：为什么几乎所有机构都在下调美股长期回报预期？

**结论**：因为2025年全球股市上涨后估值抬高了——同样的盈利和股息水平，更高的价格意味着更低的预期回报。

```
股价↑ + 基本面不变 → 股息率↓ + 估值↑ → 预期回报↓
```

除先锋领航外，几乎所有机构都下调了美股长期回报预期。发达市场和新兴市场股票回报预期也普遍下调。2025年全球股市两位数涨幅是下调的直接原因。

**边界条件**：如果美国企业盈利增长超预期或估值继续扩张，实际回报可能高于机构预测——但这是"看多"的假设，不是机构的基准假设。

### Q2：为什么晨星最看好新兴市场（尤其是中国）？

**结论**：因为新兴市场估值相对更低、增长潜力更大。

```
新兴市场：估值低 + 增长潜力大 → 长期预期回报 > 美股
中国市场：新兴市场中最被看好的部分
```

晨星自2024年起多次表示相较于美股更看好新兴市场，尤其是中国市场。即便经历了2025年上涨后适度下调，仍然是最看好的方向。

**边界条件**：新兴市场"看好"的前提是估值优势和增长潜力能够兑现——如果地缘风险或治理问题恶化，理论上的高回报可能无法实现。

### Q3：为什么美债和美股的预期回报正在"趋同"？

**结论**：美股预期回报被下调（估值高了），而美债收益率处于高位——两者的收益预期差正在收窄。

```
美股预期回报：3.1% - 6.7%（下调中）
美债收益率：高位 → 预期回报↑
结果：美股 ≈ 美债（收益接近）
```

先锋领航和锐联认为未来十年美债整体表现会优于美股。债券波动低于股票，在收益接近时性价比更高。

**边界条件**：如果美联储大幅降息，美债收益率会下行，收益预期差可能重新扩大。

### Q4：为什么"历史回报"不能直接用来做配置决策？

**结论**：因为当前环境已经变化——用过去高利率时期的债券收益率来预测未来，会过于乐观。

```
历史回报 ≠ 未来回报
环境变了 → 历史参考失效
```

预期回报是基于当前已知信息的概率性预测，而非历史统计的简单复制。历史回报不是完全没用——它提供了长期参考区间，但不能作为精确预测的依据。

### Q5：预期回报的测算为什么值得信赖？

**结论**：因为它依托稳定的模型和框架，不会出现大幅波动。

```
短期预测 = 波动大、不可靠
长期预期回报 = 稳定模型 + 动态参数 → 相对稳定
```

不同机构围绕股息率、估值水平、盈利增长预期等因素搭建模型，定期结合市场变化调整参数，动态修正预测。与预测短期涨跌不同，长期预期回报依托稳定框架。

**边界条件**：模型假设可能出错——如果全球经济结构发生根本性变化（如去全球化加速），历史模型的适用性会下降。

### Q6：面对"高收益资产变稀缺"的现实，投资者应该怎么做？

**结论**：降低收益预期，通过多元配置管理风险，与时间站在同一边。

```
高收益稀缺 → 不追单一资产 → 多元配置 + 长期持有
```

**边界条件**：如果投资者有明确的短期资金需求，"与时间站在同一边"就不适用——短期资金应该放在低波动资产里。

### Q7：为什么"美债替代美股"在当前环境下是合理的？

**结论**：因为两者预期回报接近，但债券波动更低。

```
美股 ≈ 美债（预期回报接近）
美债波动 < 美股波动
→ 低风险偏好：美债替代部分美股
```

对近期有资金支出需求的投资者，降低波动比追求更高回报更重要。

**边界条件**：如果美股预期回报重新上升（如企业盈利增长超预期），"美债替代"的逻辑就不成立了——需要持续跟踪和动态调整。
