# 拆书：《如何快速了解一个行业》（2026-07-12 版）

## 来源概述

本书以**渗透率**为锚，将产业生命周期（导入→成长→成熟→衰退）与四维分析权重（可行性/规模性/防守性/盈利性）绑定，把 PEST、波特五力、商业模式画布、护城河等碎片模型整合为"**按阶段分配注意力**"的决策系统。

> **互链关系**：本拆书为 2026-07-12 新版，与 2026-07-05 精读版 `[[sources/5-notes--34-20260705t165047-拆书-如何快速了解一个行业book--1a1mc17]]` 同源但结构不同——本次采用 x-f-f(x) 叙事框架，五维矩阵由表格呈现转为阶段动态权重的文字表述，方法论实质一致，建议合并阅读。另有关联泛读版 `[[sources/5-notes--34-20260531t215135-拆书-如何快速了解一个行业book--ffnop4]]`。

## x：问题定义

即使掌握 PEST、波特五力、商业模式画布、护城河等模型，面对一个新行业仍答不出"市场规模30亿、增速20%，然后呢？"病灶在两点：
1. **理论与产业脱节**：商学院课本模型与真实企业之间存在鸿沟，985/常春藤实习生仍会眉毛胡子一把抓。
2. **模型彼此割裂**：知识点是散点而非系统，人们套模板却找不到模型之间的接口。

## f：分析框架

### 部件一：用渗透率替代斜率定阶段

教科书按营收 S 曲线斜率划分生命周期，但现实中曲线不光滑（如口罩业疫情年脉冲不能算成长期穿透）。作者回到 **Rogers 创新扩散理论**，用渗透率（存量用户÷潜在客户群）作判据：

| 渗透率 | 阶段 |
|--------|------|
| < 15% | 导入期 |
| 15%–35% | 成长期 |
| 35%–40%+ | 成熟期 |

**锚定案例**：智能手机，2010年破20%后从 iPhone 4 开始加速，2014年破65%后进入"挤牙膏"阶段。

> 详见：[[concepts/渗透率定阶段阈值]]

### 部件二：四维分析按阶段分配权重

| 阶段 | 重点维度 |
|------|----------|
| 导入期 | 可行性↑（时间对标 + 空间对标 + UE 模型） |
| 成长期 | 规模性↑（TAM/SAM/SOM 天花板判断） |
| 成熟期 | 防守性↑ + 盈利性↑（护城河二元 + CRn 集中度） |
| 衰退期 | 替代品威胁 |

> 详见：[[concepts/五维分析框架-肖璟]]（补充动态权重视角）；[[concepts/护城河二元构建]]

### 部件三：景气度高频追踪

PEST 宏观 + 高频行业指标做纵向验证，防止长期趋势被短期波动欺骗。

```
渗透率判行业阶段
  导入 → 可行性权重↑
  成长 → 规模性权重↑
  成熟 → 防守性↑ 盈利性↑
  衰退 → 替代品威胁
        ↓
    匹配估值方式（PE/PEG/PS）
        ↓
  判定：赛道 vs 赛手 → 胜率 × 赔率
```

> 详见：[[concepts/景气度指标体系]]；[[concepts/稳定市场周期化]]

### 部件四：三种信息差

研究目的从"知道很多"变为"比他人更快、更广、更深"：

| 信息差类型 | 对应动作层 | DIKW 映射 |
|------------|-----------|-----------|
| 时间差（Data→Information） | 交易层 | Data → Information |
| 广度差（Information→Knowledge） | 配置层 | Information → Knowledge |
| 深度差（Knowledge→Wisdom） | 选股层 | Knowledge → Wisdom |

> 详见：[[concepts/三种信息差]]；[[concepts/DIKW模型-研究方法论]]

## f(x)：行动指引

### 第一：先看渗透率再选维度顺序

不再抱起模板从头填，而是先定位渗透率指标，据此决定哪个维度花最大力气。

### 第二：报告末尾必答"然后呢"

行业在哪个阶段 → 何种估值方式 → 属于"赛道投资"还是"赛手投资"。

> 详见：[[concepts/赛道与赛手二分法]]

### 第三：每次研究都是投资机会的预演

把三类信息差作为检验研究成果的标尺，不再以"报告厚实"为完成标准。

## 全书结构

- **第一部分**：行研框架（核心方法论）
- **第二部分**：新能源汽车实战案例（用新车渗透率判断行业处于"向成长期过渡"）
- **第三部分**：研究方法论（三类信息差 × DIKW）
- **第四部分**：AI 研究工具

## 核心案例

- **智能手机**：2010年渗透率破20%→加速；2014年破65%→成熟期挤牙膏
- **新能源汽车**：应用框架判为"向成长期过渡"
- **O2O破产/共享篮球**：导入期可行性判断失败的案例
- **红杉"赛道 vs 赛手"**：投资决策落地的经典分类
