# QA — 低利率时代的债券布局

> 【晨星焦点基金系列】低利率时代下应如何布局？聪明的投资者都在关注这个方向
> 发布日期：2025-07-30

## 核心论点

本文以[[entities/东方红汇利债券基金]]（002651）为案例，展示低利率时代债券投资的完整框架：纯债打底保安全，转债增强控波动，绝对收益导向守底线。核心结论是——"收益性"与"安全性"的权衡是低利率时代债券投资的核心矛盾，而可转债提供了"中间路线"。

形式化表达：

```
低利率时代
→ 纯债收益↓
→ 需通过"+"部分增厚收益
→ 转债增强：收益 > 纯债，波动 < 股票
→ 适合追求绝对收益、低波动的中长期投资者
```

## Q1: 东方红汇利的产品定位是什么？

**结论**：追求绝对收益的低波动债基，以纯债打底、可转债增强，不直接参与股票投资。

**形式化**：`产品定位 = 绝对收益 + 低波动 → 纯债打底 + 转债增强 ≠ 相对收益导向`

**证据**：
- 基金类型：积极债券（可投转债，不直接投股票）
- 业绩基准：中国积极债券基准指数（含转债的债券指数）
- 持仓：纯债+可转债，无股票持仓

**边界条件**：若市场进入大牛市，绝对收益导向的基金可能跑输相对收益导向的基金；若市场进入大熊市，绝对收益导向的基金更抗跌。参见 [[concepts/跑赢基准vs绝对收益]]。

## Q2: 基金经理的投资策略有什么特点？

**结论**：采用"自上而下宏观研判+自下而上个券精选"相结合的方法，转债仓位中枢25%，偏好低价高等级转债。

**形式化**：`投资策略 = 自上而下（宏观研判） + 自下而上（个券精选） → 转债仓位25% + 低价高等级偏好`

**证据**：
- 自上而下：从货币和财政政策出发研判宏观经济→确定类属券种配置
- 自下而上：结合错误定价捕捉、下修博弈、正股波动率等策略精选个券
- 转债偏好：低价高等级+偏债型为主，下跌保护更强

**边界条件**：若宏观经济研判失误（如误判利率方向），自上而下的配置决策可能拖累业绩；若转债市场大幅扩容，低价高等级转债的稀缺性可能下降。参见 [[concepts/转债选券偏好：低价高等级vs高弹性]]。

## Q3: 基金的纯债配置思路是什么？

**结论**：信用债配置比例45%-85%（平均54%），偏好高评级国央企信用债和二永债；利率债仓位<30%（平均21%），以波段操作为主。

**形式化**：
```
纯债配置 = 信用债（45%-85%，偏好AAA国央企） + 利率债（<30%，波段操作）
→ 久期1-3年 + 杠杆<120%（看好时可升至132%）
```

**参数详情**：
| 维度 | 区间 | 均值 | 偏好 |
|------|------|------|------|
| 信用债 | 45%-85% | 54% | AAA国央企+四大行二永债，AAA以下<15% |
| 利率债 | <30% | 21% | 波段操作为主 |
| 久期 | 1-3年 | — | — |
| 杠杆 | <120% | — | 看好时可升至132% |

**边界条件**：若信用风险上升（如国企信用事件），高评级信用债也会承压；若利率大幅上行，短久期策略更抗跌。

## Q4: 为什么说这只基金适合"低利率时代"？

**结论**：在低利率环境下，纯债收益下降，需要通过可转债等"+"部分增厚收益，同时控制波动。

**形式化**：
```
低利率时代 → 纯债收益↓ → 需要"+"部分增厚收益
→ 转债增强：弹性 > 纯债，下跌保护强于股票
```

**边界条件**：若利率大幅上升（如经济过热），纯债部分会承压，此时"低利率时代"的布局逻辑不再适用。参见 [[concepts/固收加的权益暴露度权衡]]。

## Q5: 基金的费用结构如何？

**结论**：综合费率低于同类平均水平，管理费、托管费、销售服务费均处于行业中低水平。

**形式化**：`费率优势 = 管理费低 + 托管费低 + 销售服务费低 → 综合费率 < 同类平均`

**边界条件**：在低利率时代，费率是"确定的成本"，费率越低，投资者实际到手收益越高。但如果基金经理更换或策略调整导致费率上升，费率优势可能消失。参见 [[concepts/费率复利效应]]。

## Q6: 这只基金适合什么样的投资者？

**结论**：适合有固收配置需求、追求绝对收益、能承受低波动的中长期投资者。

**形式化**：`适合投资者 = 固收配置需求 + 绝对收益偏好 + 低波动容忍 + 中长期持有`

**边界条件**：如果投资者需要更高的权益暴露（如20%以上），这只基金的权益暴露不足。

## Q7: 从东方红汇利的策略看，"低利率时代"的债券投资核心矛盾是什么？

**结论**：核心矛盾是"收益性"和"安全性"的权衡——纯债收益下降需要增厚，但增厚手段（如转债、股票）会增加波动。

**形式化**：
```
核心矛盾 = 收益性（纯债收益↓） vs 安全性（波动↑）
→ 转债增强是"中间路线"（收益>纯债，波动<股票）
```

**边界条件**：如果可转债市场出现系统性下跌（如2022年），"中间路线"也会失效，此时需要重新评估资产配置。参见 [[concepts/策略适用场景边界]]。

## 收口

本文的核心价值在于：用东方红汇利这个案例，展示"低利率时代"债券投资的完整思路——纯债打底保安全，转债增强控波动，绝对收益导向守底线。这一框架可推广至其他同类积极债券基金的选基判断。
