# 投资分析：美团

**标的：** 美团-W（03690.HK）  
**生成时间：** 2026-05-30 17:46  
**信息口径：** 截至 2026-05-30，最新完整财务口径为 2025 年报与 2025 全年业绩公告；美团已公告将于 2026-06-01 披露 2026 年一季度业绩。

## 赛道定义

中国城市生活需求的实时调度系统：把"人想要什么、附近谁能供给、谁能在半小时内送到"压成一次可成交的请求。

## 阶段判定

国内核心本地商业成熟但进入利润重估期；即时零售、前置仓、海外 Keeta、AI 助手仍在二次生长期。

## 融资情况

已上市公司。2026 年 5 月下旬港股市值约 HK$5000-5115 亿；股价公开报价区间约 HK$73.7-82.5。

```

```

```
Q4 核心本地商业经营利润率: -15.5%（Q3 为 -21.0%，环比收窄）
```

## 竞争侧数据

```
阿里+JD+美团半年直接用户补贴: RMB 800-1000 亿量级
抖音生活服务 2025 年支付 GMV: > RMB 8500 亿（同比 +59%）
抖音核销率: ~50%（美团约 80%-90%）
叮咚买菜收购对价: US$7.17 亿（2026 年 2 月公告，仍需交割条件）
```

## 核心论断

1. **美团是秩序创造机器，但 2025 年处于反脆弱验证期。** 机器未停，利润表被打穿，验证点在 2026 年二、三季度。
2. **秩序创造能力 > 利润捕获能力。** 这是美团当前最核心的结构性约束。
3. **2025 年价格战是压力测试，不是需求坍塌。** GTV、交易量、交易频次、ARPU 均创新高，证明用户行为未变，变的是货币化率。
4. **三组竞争冲击不同维度：** JD/阿里攻击履约密度（资本补贴），抖音攻击到店利润池（内容流量）。
5. **收购叮咚买菜是补供应链短板的防御动作，而非扩张叙事。**

## 飞轮结构

```
用户高频下单
  → 骑手和商家获得密度
    → 履约成本下降和确定性提高
      → 平台能扩展到更多本地品类
        → 更多场景反过来提高打开频率和会员黏性
```

## 创生公式

```
高频生活需求
  → 骑手和商家密度
    → 履约确定性
      → 更多本地品类接入
        → 用户频次和商家依赖提升
          → 更高密度和更低单位履约成本
```

## 成本坍缩三类

| 类型 | 含义 | 美团案例 |
|------|------|---------|
| 行动成本坍缩 | 过去需要多个店铺、电话、路线、等待和不确定性，现压成一个 App 内请求 | 买药、买酒、买水果、订餐、找本地服务，半小时达 |
| 理解成本坍缩 | 用户不再需要理解商家、菜品、距离、满减、配送费、评价体系，只要提出目标 | AI 助手小美/小团替用户完成判断 |
| 协作成本坍缩 | 商家、骑手、平台、用户之间的复杂协作被订单系统自动编排 | 美团越深入供给侧，越像本地商业的协作协议 |

## 核心假设与退出信号

| # | 假设 | 退出信号 |
|---|------|---------|
| 一 | 2025 年价格战是阶段性资本冲击，不是长期利润率新常态 | 2026 年 Q2 以后核心本地商业仍维持高个位数以上经营亏损率，或销售及营销费用率无法回落到 25% 以下 |
| 二 | 美团的履约密度仍能防御阿里和 JD 的入口/供应链攻击 | 公司披露或第三方数据显示美团外卖/即时零售 GTV 份额持续下滑，且不是主动放弃低质量订单导致 |
| 三 | 美团到店业务能守住高核销、高复购、高商家 ROI 的确定性需求，不被抖音内容流量持续抽走利润池 | 抖音在多个核心城市的餐饮到店核销 GMV 持续超过美团，且美团被迫用更高补贴维持份额；或美团到店广告/佣金货币化率明显下滑但交易规模没有对应加速 |
| 四 | 即时零售能提高全天候履约密度，而不是变成另一个重资产低毛利零售业务 | 新业务收入增长但经营亏损率扩大，或小象/闪电仓扩张带来持续资本消耗而没有效率改善 |
| 五 | 海外 Keeta 至少能复制一部分美团履约操作系统 | 香港以外市场订单增长依赖补贴，进入 18-24 个月后仍看不到单位经济改善 |
| 六 | AI 助手能增强本地服务入口，而不是只增加研发开支 | R&D 继续高增，但没有任何关于 AI 带来转化率、复购、商家效率或客服成本改善的量化披露 |

## 买入条件

1. 2026 年 Q1 或 Q2 核心本地商业经营亏损明显收窄，最好接近盈亏平衡。
2. 销售及营销费用率从 2025 年 Q4 的 34.4% 继续下降，而交易量/GTV 不明显失速。
3. 经营现金流从 2025 年净流出 RMB138 亿恢复为接近持平或正流入。
4. 管理层明确披露即时零售和海外投资纪律，而不是继续用模糊"长期价值"覆盖亏损。

## 建议仓位

高风险成长仓内的小到中等仓位。初始仓位不宜超过 2%-3%；只有在核心本地商业恢复经营利润、即时零售亏损没有扩大、Keeta 出现第二个正单位经济市场后，才考虑提高到 5% 以上。

## 未解问题

1. 2026 年 Q1 核心本地商业亏损到底收窄到什么程度？
2. 抖音团购的核销 GMV 是否会在核心城市持续逼近或超过美团？
3. 阿里淘宝即时零售和 JD 秒送在补贴退潮后是否还能保留订单密度？
4. 美团即时零售中，非餐订单的履约单位经济是否接近或优于外卖？
5. 叮咚买菜交易交割后，小象超市和前置仓体系是否能形成供应链优势？
6. 小美和小团是否会改变入口形态，还是只是主 App 的功能增强？

## 最后一句

美团的本质，是把一座城市的零散欲望和零散供给编译成实时可履约秩序；它仍在创造新秩序，但 2026 年必须证明这套秩序还能为股东留下租金。
