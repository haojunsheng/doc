# 基金经理AI分歧

> 整理者：晨星中国
> 原文链接：<https://www.morningstar.cn/articles/d99d5b067464e16b0b41785b8ad274ce.html>

## 核心命题

AI产业趋势确定，但当前哪些环节值得买、什么价格值得买——不同投资风格给出了完全不同的答案。没有对错，只有匹配。

## 关键数据

| 指标 | 数值 |
|------|------|
| 中证AI指数（三年涨幅） | +123% |
| 新易盛（三年涨幅） | +3582% |
| 中际旭创（三年涨幅） | +2877% |
| 寒武纪（三年涨幅） | +1702% |
| 新易盛PE变化 | 15倍 → 60倍 |

## 四位基金经理观点

### 毕天宇（成长风格）
- AI发展路径：模型竞赛（早期）→ 场景深耕（当下）→ 工业智能/AI for Science（未来方向）
- 更看好AI与实体经济深度融合的下游应用领域
- 投资机会从硬件（光模块/PCB）延伸至下游应用（制造、医疗）
- 边界条件：若AI应用落地缓慢、场景变现不及预期，下游标的的估值支撑会减弱

### 董辰（价值/平衡风格）
- AI产业链整体PE不高，但从PB看已明显偏贵
- 光模块商业模式壁垒远低于AI芯片
- 海外算力标的有关税、制裁等外部扰动风险
- 边界条件：若光模块需求持续超预期、或技术壁垒被低估，当前PB可能并不贵

### 田瑀（平衡风格）
- AI"不是泡沫但有过剩"
- 产业发展初期的阶段性过度投资是正常周期现象
- 必然伴随周期波动，但这正是产业成熟的催化剂
- 边界条件：若AI资本开支的回报周期远超预期（如10年以上），"阶段性过剩"可能变为"长期过剩"

### 王健（价值风格）
- 对高估值龙头保持谨慎
- 强调估值安全边际

## 风格分歧本质

成长风格：趋势确定 → 空间大 → 可以承受高估值
价值风格：壁垒+估值 → 等合理价格再出手

两者判断标准不同，而非对AI前景的判断不同。

## 配置建议

- AI赛道具备高成长、高波动、高不确定性特征
- 避免单一赛道过度集中
- 通过风格均衡的基金产品分散配置
- 不同风格互补：成长风格赚趋势，价值风格控风险

# 毕天宇

晨星中国旗下基金经理，成长风格。

## 投资框架

毕天宇认为AI发展遵循三段路径：**模型竞赛（早期）→ 场景深耕（当下）→ 工业智能/AI for Science（未来方向）**。

其核心判断是数字经济正由"模型竞赛"迈向"场景深耕"，更看好AI与实体经济深度融合的下游应用领域，包括制造、医疗等。投资机会从硬件（光模块/PCB）向应用端延伸。

## 对AI行业判断

- 全押AI产业趋势
- 认为AI与实体经济深度融合是下一阶段主线
- 边界条件：若AI应用落地缓慢、场景变现不及预期，下游标的的估值支撑会减弱

## 风格特征

典型成长风格：看产业趋势空间，愿意为确定性趋势承受高估值。

晨星中国旗下基金经理，价值/平衡风格。

董辰的核心判断是：**AI产业链整体PE不高，但从PB角度看已明显偏贵**。他同时指出光模块的商业模式壁垒远低于AI芯片，这是价值派不追光模块的根本逻辑。

# 戴维斯双击

## 定义

**戴维斯双击**（Davis Double Play）指盈利增长与估值提升同时发生，推动股价加速上涨的现象。反向情形称为**戴维斯双杀**。

## 形式化表达

```
行业景气↑ → 营收/利润↑(基本面) + PE倍数↑(估值) → 股价↑↑（双击）
行业景气↓ + PE倍数↓ → 股价↓↓（双杀）
```

## AI行业案例

新易盛是典型案例：PE从15倍升至60倍，叠加营收利润跨越式增长，三年涨幅达3582%，远超中证AI指数的123%。同样适用于中际旭创（+2877%）和寒武纪（+1702%）。

## 边界条件

- 若行业需求放缓、或估值已充分反映未来增长，双击变为双杀
- 高估值叠加业绩不及预期时，杀伤力极大
- 成长风格倾向于在双击初期介入，价值风格等待双击完成后的回调

# 光模块vsAI芯片壁垒差异

## 核心论断

光模块的商业模式壁垒显著低于AI芯片，这是价值派基金经理不追高AI概念股的根本原因。

## 分析框架

| 维度 | 光模块 | AI芯片 |
|------|--------|--------|
| 技术壁垒 | 中等（制造工艺为主） | 极高（设计+生态+软件栈） |
| 护城河 | 较弱，可替代性强 | CUDA生态锁定等强壁垒 |
| 定价权 | 相对较低 | 较强（英伟达等） |
| 商业模式 | 制造业逻辑（PB估值更合适） | 平台/生态逻辑（PE估值更合适） |

## 投资含义

董辰指出：AI产业链整体PE不高，但从PB角度看光模块已明显偏贵——这一判断本身就建立在"光模块是制造业、适用PB估值"的前提上。AI芯片则因高壁垒可承受更高估值溢价。

## 来源

此分析来自[[董辰]]的观点，是其价值派立场的核心论据。

# PB与PE估值法分歧

## 核心现象

同一AI产业链，不同基金经理因估值方法选择不同得出相反结论：
- **PE视角**：AI产业链整体估值不贵
- **PB视角**：光模块等环节已明显偏贵

## 方法论差异

| 估值方法 | 适用场景 | AI产业链适用性 |
|----------|----------|----------------|
| PE（市盈率） | 盈利稳定、轻资产行业 | 适合AI芯片（高壁垒、平台逻辑） |
| PB（市净率） | 重资产、制造业 | 适合光模块（制造业逻辑） |

## 投资含义

将PB标准应用于整个AI产业链可能造成评价不一致——这是估值框架分歧的根源，而非信息不对称。成长风格倾向于PE视角（看盈利增长潜力），价值风格倾向于PB视角（看资产重置成本和壁垒）。

# 阶段性过度投资

## 定义

田瑀提出的概念：产业发展初期的资本开支往往处于阶段性超前水平，这种"过度投资"是产业成熟的催化剂，但必然伴随周期波动。

## 核心判断

- AI对生产生活的改造才刚刚起步
- 技术发展初期的阶段性过度投资难以避免
- 当前AI资本开支处于阶段性超前水平
- "不是泡沫但有过剩"——过剩是周期现象，不是长期判断

## 边界条件

若AI资本开支的回报周期远超预期（如10年以上），"阶段性过剩"可能变为"长期过剩"。

## 与产能出清周期的关系

[[产能出清周期]]描述的是行业供给端产能过剩后自然出清的过程；[[阶段性过度投资]]则从需求端（产业早期投资冲动）解释资本开支超前的合理性，二者角度互补。
