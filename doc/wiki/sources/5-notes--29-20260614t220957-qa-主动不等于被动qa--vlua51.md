# 主动不等于被动 QA

来源：[Morningstar 投资者教育文章](https://www.morningstar.cn/articles/11821570ae67d513ab81d1da174f6336.html)

## 核心论点

指数投资和主动投资并非非此即彼——**指数投资可以是主动的（选择指数、择时），被动投资可以是指数的（跟踪指数），但主动不等于被动**。

## 关键 Q&A

### Q1: 为什么说"指数投资可被动，主动投资可指数"？

**结论**：投资方式 ≠ 工具类型。指数投资（工具）× 主动/被动（方式）= 四种组合。

- 指数投资可以是主动的：选择哪个指数、什么时候买入
- 主动投资可以是指数的：用指数作为基准，进行主动管理
- 投资方式和工具类型是两个独立维度

### Q2: 主动投资和被动投资的核心区别是什么？

**结论**：核心区别在于是否试图跑赢市场。

```
主动投资 = 试图通过择时、选股获取超额收益（高成本）
被动投资 = 接受市场平均收益（低成本）
```

**边界**：主动投资不一定能跑赢市场——大多数主动基金长期跑不赢指数。

### Q3: 为什么说"主动不等于被动"？

**结论**：主动投资和被动投资在投资理念、策略、成本上存在本质差异。

| 维度 | 主动投资 | 被动投资 |
|------|---------|---------|
| 依赖 | 基金经理主观判断 | 规则跟踪指数 |
| 目标 | 跑赢市场 | 接受市场平均 |
| 成本 | 较高管理费 | 较低费率 |
| 风险收益特征 | 不同 | 跟随指数 |

### Q4: 投资者应该选择主动投资还是被动投资？

**结论**：根据投资目标、风险偏好、市场环境综合选择。

```
选择 = f(投资目标, 风险偏好, 市场环境)
```

- 相信市场有效 → 被动投资
- 相信基金经理能力 → 主动投资
- 也可以两者结合
