# 固收+策略的核心——纯债打底，转债和股票增厚收益

## 来源概述

晨星基金系列文章，以东方红策略精选为案例，拆解固收+策略的实操框架，涵盖仓位纪律、转债择时、估值比较、纯债参数、个股筛选、费率影响及基金经理精力管理等内容。

## 核心论断

固收+的本质不是简单混合，而是"用债券的稳定性打底，用权益的弹性增厚"，成功关键在于在正确时机、以正确比例、选择正确工具进行配置。

## Q1：权益仓位 10%-30% 的区间纪律

**结论**：超过30%的权益仓位会让基金风险超出"保守混合"定位，低于10%则无法有效增厚收益。

**形式化**：
```
权益仓位 ∈ [10%, 30%]，中枢 ≈ 20%
→ 风险可控 + 收益增厚 → 保守混合基金定位
```

**边界条件**：如果基金经理判断失误，在市场大涨时仓位过低（如10%）会跑输同类；大跌时仓位过高（如30%）会承受更大回撤。

## Q2：转债择时——2025年下半年清仓可转债

**结论**：可转债估值持续高企，性价比不如普通信用债和二永债。

**形式化**：
```
可转债估值高企 → 转股溢价率高 → 性价比下降
→ 清仓转债、转向普通信用债 / 二永债
```

**边界条件**：如果市场突然大跌导致转债估值快速下降，基金经理可能错失低价加仓的机会。

## Q3：转债 vs 股票的决策框架——估值历史分位法

**结论**：通过比较转债估值（转股溢价率）和对应正股估值在历史中的位置，谁低估买谁。

**形式化**：
```
转债估值（历史分位） < 正股估值（历史分位） → 优先买转债
转债估值（历史分位） > 正股估值（历史分位） → 直接买股票
```

**逻辑**：转债有"债底保护"，如果转债估值比正股更便宜，相当于"打折买股票+免费保险"。如果转债估值处于历史低位，说明市场过度悲观，此时买转债性价比更高。

**边界条件**：在极端行情下（如股债双杀），转债的债底保护可能失效，这个框架会失灵。

## Q4：纯债打底的参数约束

**结论**：中短久期 + 高等级（AAA以下占比<5%），目标是提供稳定收益和流动性。

**形式化**：
```
纯债 = 中短久期 + 高等级（AAA以下占比 < 5%）
→ 低波动 + 高流动性 → 打底功能
```

**边界条件**：在利率下行周期中，中短久期债券的再投资收益会低于长久期债券，会跑输同类。

## Q5：个股筛选方法——DCF估值 + 行业差异化

**结论**：先用现金流贴现模型找"价格低于内在价值"的安全边际，再结合行业特点差异化配置。

**形式化**：
```
DCF估值 → 安全边际筛选（价格 < 内在价值）
→ 行业差异化配置：
    传统行业 → 选龙头（成本优势）
    新兴行业 → 分散配置（方向不确定）
```

**边界条件**：DCF模型依赖对未来现金流的预测，对于盈利不稳定或亏损的公司（如初创企业）不适用。

## Q6：策略边界——成长牛市末端表现欠佳

**结论**：2020年是成长股牛市末端、股市泡沫期，低权益仓位+价值风格跑不赢高仓位+成长风格。

**形式化**：
```
成长牛市末端 + 股市泡沫 → 低仓位（10-30%）+ 价值风格 → 跑输高仓位 + 成长风格
```

**案例**：2020年该基金表现欠佳，但在2022、2024年等波动加剧的行情中反而表现更好，说明策略适合震荡市而非单边牛市。

## Q7：费率复利影响的量化论证

**结论**：0.79%的年费率比同类1.47%低46%，10年复利差异约7%总收益。

**形式化**：
```
费率差 = 1.47% - 0.79% = 0.68%
10年复利影响：(1 + 0.0068)^10 ≈ 1.07
→ 10年多赚约 7% 总收益
```

**边界条件**：费率优势的前提是业绩不落后；如果因为低费率导致投研投入不足、业绩跑输，得不偿失。

## Q8：基金经理精力分散风险

**结论**：晨星认为"精力占用可控"，因为策略相似且有研究团队支持。

**形式化**：
```
8只基金策略相似 + 研究团队支持
+ 担任部门总经理但精力聚焦投研
→ 规模（282亿）可控
```

**边界条件**：如果规模继续快速膨胀（如突破500亿），或市场复杂度上升（如新策略），精力分散的风险会增加。此结论为晨星立场判断，缺乏独立验证数据。
