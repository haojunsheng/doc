# QA — 景顺长城成长之星 vs 汇添富外延增长主题股票

来源为晨星基金擂台赛系列，对比两只晨星分类同为"大盘成长股票型"的基金，揭示同分类下不同选股策略、费率结构与风险调整后收益的差异。

## 核心对比框架

两只基金均经晨星归类为大盘成长股票型，但选股路径截然不同：

- **景顺长城成长之星**（周寒颖管理）：中观行业 + 分散配置
- **汇添富外延增长主题股票**（蔡志文管理）：自下而上选股 + 适度集中

## 基金经理经验对比

| 维度 | 周寒颖 | 蔡志文 |
|------|--------|--------|
| 证券从业经验 | 18年 | 11年 |
| 公募投资经验 | 8年（早期管理QDII，后期接管A股） | 4年（直接从A股起步） |
| A股经验 | 约4年 | 4年 |

研究覆盖差异：
- 周寒颖：零售、服装、轻工、TMT；选股能力圈覆盖工业、信息技术、医药、原材料、金融（5个行业）
- 蔡志文：零售、农业、家电、轻工；选股能力圈覆盖信息技术、工业、可选消费、金融（4个行业）

## 费率结构差异

### 景顺长城成长之星

综合费率高于同类平均，原因：
- 固定费率高于同类
- 换手率较高 → 交易成本偏高

```
综合费率 = 固定费率（高于同类） + 高换手率驱动的交易成本 → 高于同类平均
```

### 汇添富外延增长

综合费率略低于同类平均，原因：
- 固定费率高于同类（劣势）
- 但低换手率带来较低交易成本（抵消优势）

```
综合费率 = 固定费率（高于同类） - 低换手率带来的低交易成本 → 略低于同类
```

## 风险调整后收益

两只基金截至2024年10月末最近三年和五年业绩均战胜基准和同类平均。

优于同类的共同原因：
1. **分散配置**：标准差和下行标准差均低于晨星同类基金平均水平
2. **多行业选股能力**：周寒颖在5个行业、蔡志文在4个行业展现选股能力，降低单一行业风险

## 选基逻辑框架

```
选基可行性 = 选股能力圈匹配 × 费率敏感 × 策略稳定性
```

- **选股能力圈匹配**：基金经理擅长行业与市场风格是否吻合
- **费率敏感**：优先选择低综合费率产品，长期持有下费率复利效应显著
- **策略稳定性**：关注换手率是否可持续，决定综合费率能否维持低位

## 边界条件

- 市场风格切换到两人都不擅长的行业时，业绩可能承压
- 基金经理离职将影响策略连续性
- 汇添富外延增长未来能否保持低交易成本，取决于投资策略的稳定性
- 如果基金策略调整导致换手率上升，综合费率将提高

## 宏观背景

2024年9月24日新政策出台后，成长股表现彻底翻盘，凸显成长股基金在资产配置中的不可或缺地位。
