# QA — 政策放宽引爆香港互认基金申购潮

> 香港互认基金资金流向2025年回顾：销售上限放宽引爆年初申购热潮，全年呈现"固收先行→权益跟进"的风险偏好轮动结构。

## 核心命题

政策闸门一开，资金会先涌向最安全的资产（固收），等风险偏好修复后再转向高收益资产（权益）；产品线的广度和深度决定了基金公司能否在这场资金迁徙中胜出。

## 六问六答

### Q1: 销售上限从50%提至80%，为何能引爆年初抢购？

**结论**：压抑的多元化需求集中释放。

```
销售上限 50% → 80% = 内地投资者可申购额度↑60% + 海外配置需求释放 → 一季度抢购潮
```

- 政策直接效应：每只基金能卖给内地投资者的量增加60%
- 需求侧动力：内地低利率环境，急需海外高收益资产填补收益缺口
- 时机叠加：年初配置需求旺盛，与政策放开形成共振

**边界**：若海外市场同时大幅下跌，或A股强劲反弹，资金可能不涌入。

---

### Q2: 固收基金先扬后抑，说明了什么？

**结论**：投资者从"求稳"转向"逐险"，A股企稳后风险偏好修复。

```
A股↓ → 固收↑（避险） → A股企稳↑ → 固收↓ + 权益↑（逐险）
```

- Q1：A股低迷，资金涌入海外固收
- Q2-Q3：A股和亚洲股市企稳回升，风险偏好修复
- 部分固收资金赎回，转向权益类资产

**边界**：若A股反弹力度不足，或海外利率大幅上行，固收吸引力会重新上升。

---

### Q3: 为什么摩根国际债券全年吸金130亿，而汇丰高收益债净流出？

**结论**："大而全"胜过"窄而锐"，额度耗尽是流出的主因而非业绩差。

```
环球债 = 全球分散 + 低相关 → 持续吸金
vs
亚洲高收益 = 集中度高 + 额度耗尽 → 净流出
```

- 产品差异：摩根国际债券是唯一环球债券型互认基金；汇丰两只产品聚焦亚洲高收益
- **额度限制（关键机制）**：汇丰两只产品内地销售额度耗尽，想买也买不到，导致被动净流出统计假象
- 市场环境：高收益债对信用风险敏感，波动大

**边界**：若全球利率大幅下降，高收益债的票息优势会重新显现。

---

### Q4: 摩根凭什么全年净流入226亿，稳坐基金公司头把交椅？

**结论**：产品线全+明星基金多+品牌信任深，形成双重护城河。

```
摩根 = 环球债（130亿）+ 亚洲总收益债（80亿）+ 亚洲股息（前三季吸金榜） → 226亿
```

- 全能选手：固收有摩根国际债券、摩根亚洲总收益，权益有摩根亚洲股息
- 规模正循环：规模越大→品牌越强→资金越愿意涌入
- **产品线广度优势**：多资产类别覆盖形成正循环，抗单一品类波动风险

---

### Q5: 权益基金上半年净流出、全年却净流入，中间发生了什么？

**结论**：市场情绪从"极度悲观"修复到"重新乐观"。

```
上半年A股低迷 → 权益净流出 → 三季度亚洲股票率先转正 → 四季度环球股票跟进 → 全年净流入
```

- 时间节点：上半年市场调整，投资者恐慌性赎回权益类互认基金
- 转折动力：A股企稳回升，亚洲股市反弹，风险偏好修复
- 资金回流：从固收和现金类回流权益

---

### Q6: 瑞士百达吸金、施罗德净流出，差距在哪？

**结论**：全球配置的灵活性战胜区域聚焦的局限性。

```
瑞士百达 = 全球灵活配置（股债20-70%可调） vs 施罗德 = 亚洲市场聚焦 → 吸金王 vs 净流出王
```

- 配置范围：瑞士百达可投资全球各类资产，施罗德聚焦亚洲市场
- 市场环境：2025年亚洲市场波动大，全球分散更能平滑波动
- 策略优势：灵活配置在震荡市中更容易做出超额收益

---

## 核心规律总结

1. **政策闸门效应**：销售上限50%→80%在Q1引爆固收类互认基金抢购潮，但此效应在Q2后衰减，资金随A股企稳转向权益
2. **风险偏好的S型曲线**：全年资金流向呈"固收先行→权益跟进"的时序结构，内地投资者对海外资产的配置是渐进式的
3. **"大而全"胜过"窄而锐"**：摩根凭借多产品矩阵拿下基金公司第一；汇丰因聚焦单一品类且额度耗尽，反而成为净流出
4. **额度机制的双刃剑效应**：额度放开利好资金流入，但**额度耗尽同样会切断后续流入通道**，形成"买不进→净流出"的统计假象——这是本文最反直觉的发现
5. **全球分散在震荡市的超额价值**：瑞士百达灵活配置在2025年亚洲市场高波动环境下胜出

## 投资决策启示

1. **穿透额度限制识别真实流向**：债基净流出数据需先做政策剔除，再做行为解读
2. **关注产品线的广度与深度**：单品类极致聚焦的风险在于额度耗尽时的被动流出
3. **理解风险偏好的时序结构**：固收先行、权益跟进是典型模式，不要将固收流入误读为对权益的看空
