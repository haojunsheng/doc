# 估值两门派——周期派 vs 价值派

> 来源：晨星（Morningstar）

## 一句话摘要

为什么投资者对"股票贵还是便宜"争论不休？因为存在两个估值门派：周期投资派看短期盈利和景气度，内生价值投资派看长期现金流折现。两者关注的时间维度和估值逻辑完全不同，同一只股票会得出不同结论。

## Q&A 核心内容

### Q1：周期投资派怎么判断股票贵不贵？

**结论**：周期派认为股票价值取决于中短期盈利，而盈利又取决于经济周期，所以估值要看景气度。

**形式化**：

```
周期派：
  股票价值 = f(短期盈利)
  短期盈利 = f(经济周期)
  景气度高 → 估值合理
```

**依据**：
- Barry Ritholtz："估值涉及价格和利润，价格已知，利润未知，经济因素决定利润"
- 景气度投资是周期派的典型代表：寻找"中短期业绩增速超预期"的公司
- 宁德时代 2021 年 PE 超 100 倍仍被追捧，反映的是对电动车行业景气的期待

**边界**：周期派依赖对经济周期和行业景气的准确判断。如果判断错误，可能在周期顶部买入被套牢。

→ [[周期投资派]]

### Q2：内生价值投资派怎么判断股票贵不贵？

**结论**：价值派认为股票价值等于未来现金流的折现值，关注企业长期盈利能力而非短期波动。

**形式化**：

```
价值派：
  内在价值 = 未来现金流折现值
  DCF模型：估值 = Σ(未来现金流 / (1+r)^t)
```

**依据**：
- 巴菲特定义内在价值为"企业生命周期内能给投资者带来的所有现金流的折现值"
- 通常看未来十年或更长时间的现金流总量
- 不同价值投资者对同一只股票可能得出完全不同的估值（DCF 假设无定式）

**边界**：DCF 模型的核心假设（现金流和贴现率）没有定式，最考验技术和眼光。

→ [[内生价值投资派]]

### Q3：为什么同一只股票，两派得出不同结论？

**结论**：两者关注的时间维度和估值逻辑完全不同——一个看短期景气，一个看长期价值。

**形式化**：

```
周期派 = 短期盈利 × 景气溢价
价值派 = 长期现金流 × 折现
两者视角不同 → 结论不同
```

**关键洞见**：
- 凯恩斯比喻：股票投资像选美比赛，猜中冠军不是选自己认为最美的，而是选能获得最多选票的
- 没有最好的投资方法，只有最适合的投资方法

→ [[凯恩斯-股票选美比喻]]、[[股价作为集体认知]]

### Q4：为什么价值投资这么难坚持？

**结论**：价值投资违反人性——我们很难不在意其他投资者的看法，市场可能长期处于低估或高估状态。

**形式化**：

```
价值投资 = 长期持有 + 忽视短期波动
人性 = 从众 + 短期偏好
两者冲突 → 难以坚持
```

**证据**：
- 巴顿·比格斯形容 1990 年代末互联网泡沫参与者："虽然满仓 all in，但实际上怕得要死"
- 罗伯特·希勒研究显示，市场可能长期处于低估或高估状态
- 1970 年买入成长股的价值投资者，可能要忍受 10 年熊市

### Q5：投资者应该选哪个门派？

**结论**：没有最好的投资方法，只有最适合的——取决于性格、能力、投资目标和风险偏好。

```
价值投资适合：有耐心、能承受长期波动的人
周期投资适合：对市场敏感、能快速反应的人
```

**关键洞察**：很多成功投资者结合两种方法——用价值投资选股，用周期判断择时。但这需要更高的能力。

## 收口

估值不是一门科学，而是一门艺术。周期派和价值派各有逻辑，没有绝对的对错。投资者应该理解两种方法的底层逻辑，然后根据自身特点选择适合自己的方法。

## 与中国市场的关联

- 宁德时代 2021 年案例：A 股周期投资思维的典型体现，PE 超 100 倍仍被追捧反映的是对产业景气的预期
- A 股市场短期博弈氛围浓厚，周期派思维更容易被验证（但也更容易追高）
