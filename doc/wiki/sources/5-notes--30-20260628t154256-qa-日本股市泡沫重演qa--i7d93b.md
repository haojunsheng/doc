# 日本股市是牛市修复非泡沫重演

## 来源信息

- **作者/机构**：晨星中国
- **发布日期**：2026-06-28
- **原文链接**：https://www.morningstar.cn/articles/33342626372e297f91902af6377d0ef2.html

## 核心结论

日本股市在日经225逼近1989年历史高点38957点之际，被市场争论是否重演泡沫。晨星中国通过六个维度拆解，结论是：**当前上涨本质是"盈利改善+估值修复+治理改革"三重驱动的修复行情，而非1989年式的杠杆投机泡沫**。但QDII额度限制导致的ETF溢价，是当前投资者面临的最直接、最务实的风险。

## 1989年泡沫 vs 2024年修复：核心对比

| 对比维度 | 1989年泡沫 | 2024年修复 |
|---------|-----------|-----------|
| 企业税前利润率 | <1% | ~7% |
| 估值水平 | 远超合理 | PE约14倍（美股20倍） |
| 上涨驱动力 | 纯杠杆+资金推升 | 盈利增长11.5% + 治理改革 |
| 资本效率 | 低下 | 东交所强制要求改善 |

## Q&A 结构

### Q1: 1989年泡沫和2024年上涨本质区别在哪？

- **结论**：1989年靠杠杆和投机推上来的，2024年靠盈利改善和估值修复支撑。
- **形式化**：1989: 盈利率<1% + 杠杆↑↑ → 泡沫；2024: 盈利率7% + 估值14倍 → 修复
- **关键差异**：
  - 1989年企业税前利润率不到1%，纯靠资金推
  - 2023年利润率飙升至近7%，盈利增长11.5%
  - 1989年估值远超合理水平，2024年14倍仍低于美股20倍
  - 当前上涨有基本面支撑而非纯资金驱动
- **边界条件**：若日元大幅升值或全球衰退打击出口，盈利改善会中断。

### Q2: 日元贬值为何反而利好日本股市？

- **结论**：日本企业重度依赖出口，日元贬值等于变相提价和增厚利润。
- **形式化**：日元贬值(103→151) → 出口价格↓ → 竞争力↑ → 企业利润↑ → 股市↑
- **关键数据**：日元兑美元从103贬至151，达几十年最低。
- **边界条件**：若日本央行突然收紧货币政策或美联储快速降息，日元贬值趋势会逆转。

### Q3: 东交所为何逼上市公司回购？

- **结论**：市净率低于1的公司被强制要求改善资本效率，否则2026年退市。
- **形式化**：东交所: PB<1 → 必须提交改善计划 → 不改善 → 2026年退市
- **关键机制**：
  - 2023年东交所要求上市公司自愿提出提高资本效率计划
  - PB<1的公司是重点监视对象
  - 需通过回购、调整战略等方式改善
- **边界条件**：若回购只是为达标而非真正改善效率，长期效果有限。

### Q4: 巴菲特为何加仓日本商社？

- **结论**：日本商社像伯克希尔——股东友好、现金流充沛、估值便宜。
- **形式化**：日本商社 = 回购↑ + 分红↑ + 现金储备↑ + 估值↓ → 巴菲特加仓
- **关键数据**：
  - 53.5%日本企业账上有正现金流（美国仅39.4%）
  - 巴菲特加仓伊藤忠、丸红、三菱、三井、住友
  - 这些公司通过回购提高股东回报，高管薪资合理，为业务预留充沛现金流
- **边界条件**：若日本股市流动性持续低迷，外资可能获利后撤离。

### Q5: ETF溢价为何是最大的坑？

- **结论**：溢价买入等于提前亏钱，20%溢价意味着指数需再涨20%才能回本。
- **形式化**：溢价买入 → 价格>净值 → 即便指数涨也回不了本 → 溢价终归零
- **传导链条**：
  - ETF价格由供需决定，净值由指数决定
  - QDII额度限制导致限购+抢购，价格偏离净值
  - 以20%溢价买入 = 当场亏20%
  - 历史上溢价无法长期维持，最终会被抹平
- **边界条件**：若QDII额度持续紧张、溢价长期存在，投资者需等溢价消化后再入场。

### Q6: 日本股市离1989年高点一步之遥意味着什么？

- **结论**：接近高点不等于泡沫，关键看盈利能否支撑——目前可以，但需警惕情绪过热。
- **形式化**：36546点 vs 38957点 → 差6% → 但有盈利支撑 vs 1989无支撑
- **关键事实**：
  - 日经225截至2024年1月22日站上了36546点，距1989年高点38957点仅差约6%
  - 当前有盈利增长、估值合理、治理改善三重支撑
  - 但散户疯狂买入和ETF溢价说明情绪过热
- **边界条件**：若全球流动性收紧或日本央行转向，估值修复可能中断。

## 收口判断

> 日本股市30年后的复苏不是泡沫重演，而是"盈利改善+估值修复+治理改革"三重驱动的修复行情——但投资者需警惕的是，QDII额度限制导致的ETF溢价才是真正的陷阱。
