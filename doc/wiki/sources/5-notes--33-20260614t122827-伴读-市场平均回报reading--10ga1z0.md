# 伴读：只拿市场平均回报，长期业绩能行吗？

晨星（Morningstar）投资理念系列文章。核心论点是：市场平均回报（指数投资）并非退而求其次的选择，而是大多数投资者在扣除费用和犯错成本后难以达到的基准——承认这一点是从"我要打败市场"到"我要打败自己"的认知升级。

## 核心论点

### 一、投资成功不可复制——巴菲特案例

马克·塞勒斯（Mark Cockerell）2007 年对哈佛 MBA 的演讲中提出：**几乎没人能成为巴菲特，概率不超过 2%**。

支撑这一判断的是七个关键特质，多数在青少年时期已定型，后天难以习得：

| 特质 | 说明 |
|------|------|
| 逆势操作 | 在市场恐慌时保持买入意愿 |
| 极度痴迷 | 对投资的热情超过家庭和朋友关系（巴菲特自称"投资是我唯一真正喜欢的事"） |
| 从错误中学习 | 快速纠错、复盘的能力 |
| 常识和风险敏感 | 对基本面的直觉判断 |
| 绝对信心 | 逆大众时的心理韧性 |
| 左右脑并用 | 兼顾数据分析与商业直觉 |
| 市场波动中保持冷静 | 情绪稳定性 |

**关键洞察**："读巴菲特的书、学财务分析、积累经验"——这些只是基本条件，不构成相对优势。真正的壁垒是性格与认知方式，而非知识。

→ [[entities/沃伦巴菲特warren-buffett]]

### 二、只要做到刚刚好就足够——约翰·内夫案例

约翰·内夫（John Neff）1965–1995 年管理温莎基金，31 年年化跑赢标普 500 指数 **3.2%**，1 万美元最终增长至 **56.4 万美元**。

选股标准：市盈率有 40–50% 折价、经营稳定、财务状况良好的公司。不追逐热点，风格始终如一。

这一数据验证了：微小的持续优势 × 长时间 = 巨大的复利效果，主动管理不需要成为巴菲特式传奇。

→ [[entities/约翰-内夫]]

### 三、输家的游戏——控制卖出比买入更重要

查尔斯·艾利斯（Charles Ellis）提出"赢得输家的游戏"框架：

- 买入手通常在冷静、理性状态下做出（研究、分析、计划）
- 卖出手通常在高情绪压力下做出（恐慌、贪婪、短期业绩焦虑）
- 大多数投资者的错误不是"买错了"，而是"卖错了"——该卖时不卖，不该卖时乱卖

因此，在输家的游戏中，**控制卖出决策比买入决策更重要**。这一论点是对[[投资是输家的游戏]]概念的重要补充维度。

## 结论

> 市场平均回报不是"退而求其次"的选择，而是大多数投资者（包括专业基金经理）在扣除费用和犯错成本后实际达不到的基准——承认这一点，不是认输，是从"我要打败市场"的幻想中醒来，进入"我要打败自己"的现实中。
