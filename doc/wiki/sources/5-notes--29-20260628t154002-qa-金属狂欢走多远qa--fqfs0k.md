# 金属狂欢走多远 QA

来源：[[晨星中国]] · [Morningstar.cn](https://www.morningstar.cn/articles/ff53abc1207b8a3d54c7bf6c7d7a6160.html) · 2026

## 核心论点

这轮金属狂欢（黄金、白银、铜同一年首次集体突破历史峰值）背后每个金属的供需逻辑完全不同。用一个大逻辑覆盖所有金属是常见谬误。

## 七种金属的独立剧本

### 黄金
- **短期边际驱动力**：ETF资金流（欧美黄金ETF资金流入节奏）
- **不是**：珠宝消费（稳定，非波动主因）或央行购金
- **边界**：若央行购金规模超预期，可能取代ETF成为边际驱动力

### 铁矿石
- **核心依赖**：中国经济转型 + 废钢使用比例提升
- **结论**：长期需求必然下行

### 铜
- **当前状态**：供应紧张
- **性质**：阶段性而非结构性
- **原因**：新矿山投产 + 扩产 + 新技术推进中
- **关键**：刚果（金）已成为全球第二大铜矿供应国

### 锂
- **当前状态**：价格远低于成本支撑位
- **趋势**：正在经历产能出清
- **前景**：价格有望修复

### 镍、铝、锌
- 本文提及但未详细展开，各自有独立供需逻辑
