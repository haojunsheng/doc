# QA — 低费吸金：全球基民偏好

## 核心结论

2024年全球基金市场迎来 **1.4万亿美元** 资金净流入，扭转了连续两年净流出的趋势，全球基金资产规模突破 **50万亿美元**。资金流向呈现三大特征：债券基金、被动基金、低费率产品。

## Q1: 2024年全球基金资金流向的最大赢家是谁？

**结论**：债券基金和ETF获得超1万亿美元净流入，是股票基金的两倍。

过去十年债券基金吸引 **4.7万亿美元**（仅2022年出现净流出），同期股票基金仅 **2.7万亿美元** 净流入。值得注意的是，2015-2024年全球股票年化收益 **7.04%** 远超债券的 **-0.21%**，但资金仍偏爱债券。

**边界条件**：债券基金持续吸金不等于债券表现好——投资者可能更看重确定性而非收益率。

## Q2: 为什么被动基金能持续扩张？

**结论**：低费率是被动基金持续扩张的核心推力。

| 指标 | 数据 |
|------|------|
| 2024年全球被动基金规模增长 | +3.2% |
| 占非货币基金份额 | 43.5% |
| 美国被动基金占比 | 53%（首次超过主动管理） |
| 安硕+先锋2024年吸金 | 6730亿美元（占全球近半） |
| 过去十年最低20%费率基金 | 持续获得更多资金流入 |

**边界条件**：美国之外被动基金份额仅 **29%**，银行渠道偏好主动基金、某些市场主动管理仍受欢迎。

## Q3: 为什么债券基金在表现不如股票的情况下仍持续吸金？

**结论**：投资者更看重确定性和风险调整后收益，而非单纯的收益率。

机构投资者（保险、养老金）需要匹配负债，天然偏好债券。在2022年股市大跌时债券基金表现相对稳健。

**边界条件**：如果利率环境反转（持续加息），债券基金可能失去吸引力。

## Q4: 全球基金市场的集中度说明了什么？

**结论**：前10大基金公司管理全球 **51%** 的资产——强者恒强。

- 安硕（iShares）+ 先锋领航（Vanguard）合计管理全球 **28.6%** 的资产
- 美洲基金（Ameriprise）、普信（T. Rowe Price）、富兰克林邓普顿（Franklin Templeton）2024年均出现资金净流出
- 被动投资的崛起正在挤压传统主动基金的市场份额

## 收口

全球基民的选择很明确：低费率、被动投资、债券打底——这三板斧是2024年资金流向的最大公约数。
