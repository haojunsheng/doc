# 固收+的典范——易方达稳健收益13年年化7.99%

> 【晨星焦点基金系列】稳中求胜的固收+基金
> 发布日期：2026-06-14

## 来源概述

以易方达稳健收益债券（110008）为案例，展示固收+基金如何通过"稳定的框架+严格的风险控制"实现13年年化7.99%的回报，在积极债券基金中排名前3%。核心论点是：长期成功不靠某年暴利，靠稳定框架。

## Q1：为什么股票仓位"围绕15%的战略配置比重，调整范围10%-20%"？

**结论**：超过20%的股票仓位会让基金风险超出"积极债券"定位，低于10%则无法有效增厚收益。

**形式化**：
```
股票仓位 = 10%-20%（中枢15%）
→ 风险可控 + 收益增厚 → 积极债券基金定位
```

**边界条件**：如果基金经理判断失误，在市场大涨时仓位过低（10%），会跑输同类。

## Q2：为什么可转债仓位"在0-30%之间灵活调整"？

**结论**：可转债在不同估值水平的性价比不同，基金经理通过仓位调整捕捉系统性机会。

**形式化**：
```
可转债仓位 ∈ [0%, 30%]，= f(估值分位数)
估值低位（如2014上半年、2018Q4）→ 加仓至20%以上
估值高位（如2015年中、2021Q3）→ 减仓至10%以下
```

**边界条件**：如果估值判断失误（在低位减仓、高位加仓），会跑输同类。

## Q3：为什么"信用债为底仓，仓位在60%-100%之间，以AAA债券为主"？

**结论**：信用债是固收+基金的"压舱石"，目标是提供稳定票息收入，不是追求高风险收益。

**形式化**：
```
信用债底仓 = 60%-100%仓位 + AAA评级
→ 高票息 + 低违约风险 → 稳定收益
```

**边界条件**：如果信用风险上升（如经济衰退导致违约增加），AAA债券也会受影响。

## Q4：为什么"股票投资侧重低估值、盈利稳定的大盘蓝筹股"？

**结论**：大盘蓝筹股盈利稳定、流动性好，适合固收+基金的"稳健增值"定位。

**形式化**：
```
大盘蓝筹 = 低估值 + 盈利稳定 + 流动性好
→ 适合固收+基金的稳健定位
```

**边界条件**：如果市场风格持续偏向中小盘成长，基金会跑输同类。

## Q5：为什么"2022-2023年表现更出色，而2020年和2025年表现相对偏弱"？

**结论**：2022-2023年是价值风格主导的市场，2020年和2025年是成长风格领涨的市场，基金的价值风格在后者中吃亏。

**形式化**：
```
2022-2023年：价值风格主导（银行、煤炭、建材）→ 基金价值风格占优 → 表现好
2020/2025年：成长风格主导（科技、医药、AI算力）→ 基金价值风格吃亏 → 表现偏弱
```

**边界条件**：如果未来市场风格继续偏向成长，基金可能持续跑输同类。

## Q6：为什么"组合自2021年以来逐步提高金融债的配置比重"？

**结论**：银行二级资本债、证券公司债等金融债的利差水平相对较高，能提供更高的票息收入。

**形式化**：
```
金融债 = 利差水平高 + 信用风险可控 → 票息收入↑ → 组合收益↑
```

**边界条件**：如果金融债信用风险上升（如银行坏账增加），利差会扩大，债券价格会下跌。

## Q7：基金经理胡剑"管理7只基金，合计规模超800亿"，会不会精力分散？

**结论**：晨星认为"仍在能力范畴内"，因为易方达固收团队实力雄厚，且胡剑是"固定收益投资总监"。

**形式化**：
```
胡剑 = 固定收益投资总监 + 7只基金 + 800亿规模
+ 固收信用研究部超20名研究员 + 权益研究部近50名研究员
→ 团队化运作降低个人依赖
```

**边界条件**：如果规模继续快速膨胀（如突破1000亿），或市场复杂度上升，精力分散的风险会增加。

## 收口

晨星通过易方达稳健收益的案例，展示了一个核心洞见：固收+基金的长期成功不靠"某年暴利"，靠"稳定的框架+严格的风险控制"——股票仓位10-20%、可转债0-30%、信用债60-100%的资产配置框架，加上"低估值大盘蓝筹"的选股策略，让这只基金在13年里实现了7.99%的年化回报，且波动率低于同类平均。
