# 好基金经理不在性别在体系

> 值得信任的优秀女性基金经理——晨星三八节专题。

## 核心论点

三位女基金经理的成功路径几乎没有"性别特质"差异——17年内部培养、GARP策略、赔率优先、交易增强，全是专业主义的硬功夫。文章真正要表达的是：**好基金经理是体系产物，不是天赋或性别产物**。

## 三位案例

### 乔迁（景顺长城）

| 维度 | 内容 |
|------|------|
| 管理产品 | [[景顺长城成长之星]]（景顺长城量化平衡灵活配置混合型证券投资基金） |
| 年化回报 | 17.5%（2018.7–2026.1，约7.5年） |
| 目标回报 | 年化10–15% |
| 策略 | GARP均衡派：用合理价格买合适回报率的股票，估值明显高估时卖出 |
| 特征 | 不追热点、不盲从趋势；持仓不完全集中于大盘股，也挖掘中小市值标的（如思源电气） |

形式化表达：

```
估值合理性 ∩ 成长确定性 → 买入
估值明显高估 → 卖出
⇒ 年化17.5%（2018.7–2026.1）
```

边界条件：若市场持续高估（如牛市末期），GARP策略可能因过早卖出而跑输。

### 黄珺（富国基金）

| 维度 | 内容 |
|------|------|
| 从业年限 | 17年，其中组合管理11年 |
| 策略 | 中观行业比较 + 自下而上选股，从景气度向上行业中挑赔率和预期收益率双高的公司 |
| 典型案例 | 2022年下半年左侧布局传媒/机器人；恺英网络涨245%，环旭电子翻倍 |
| 特征 | 坚持独立思考，不盲目追逐明星个股；中小盘长期占比高于同类 |

形式化表达：

```
产业政策判断 + 财务数据验证 → 左侧布局传媒/机器人
⇒ 恺英网络 +245% + 环旭电子翻倍
```

边界条件：若行业判断失误或左侧过早，可能承受较长时间浮亏。

### 宋倩倩（景顺长城，固收）

| 维度 | 内容 |
|------|------|
| 从业年限 | 14年 |
| 年化回报 | 4.04%（固收类产品） |
| 超额收益 | 超基准0.71% |
| 策略框架 | 三层增强固收策略 |

三层增强框架：

```
底层（90–100%）：高等级信用债（3年以内），城投/产业/金融均衡配置
中层（10–30%）：信用利差交易，主抓银行二级资本债3–5年期
顶层（0–20%）：利率交易，近两年从地方债获取超额收益
```

形式化表达：

```
90–100% 高等级信用债底仓 + 10–30% 信用交易 + 0–20% 利率交易
⇒ 年化4.04%，超基准0.71%
```

边界条件：若信用利差持续压缩或利率大幅波动，交易策略的超额收益可能消失。

## 三位共同特征

| 共同点 | 具体内容 |
|--------|---------|
| 内部培养路径 | 均从研究员/交易员起步，在公司内部成长14–17年后独立管产品 |
| 渐进式成长 | 经历助理/专户→公募的渐进过程 |
| 体系成熟后才独立管产品 | 非外部跳槽型，非天才型选手 |
| 策略一致性强 | 任期波动和下行风险均低于同类平均 |

形式化表达：

```
内部培养（14–17年） × 多轮牛熊 → 体系成熟 → 长期超额收益
⊃ 非外部跳槽型
```

边界条件：内部培养路径依赖公司平台投研体系质量，若平台体系薄弱则个人难以脱颖而出。

## 为什么"不追热点"反而成为超额收益来源

```
追热点 → 高位接盘
不追热点 → 估值合理时买入、高估时卖出 → 下行风险↓ + 长期超额↑
```

[[乔迁]]明确不追逐市场热点、不盲从趋势；[[黄珺]]坚持独立思考，不盲目追逐"明星个股"。两人任期内波动和下行风险均低于同类平均。

边界条件：在纯题材驱动的A股市场中，不追热点可能短期跑输，需要极强耐心和持有人理解。

## 来源局限与开放问题

- 样本量小（n=3），缺少统计检验
- 未涉及"外部跳槽型"经理，存在选择偏差
- 未提及三位经理管理规模对策略执行的影响

开放问题：
1. 内部培养14–17年的时间成本是否值得？与外部雇募相比成功率是否有统计学差异？
2. "不追热点"在A股纯题材驱动环境中的短期跑输忍耐度，如何量化评估？
