# QA — FOF配置方向：从稳打底转向攻守兼备

来源：[晨星中国](https://www.morningstar.cn/articles/ab3e2dd39c9e4aef7b70e4595c9fd13a.html)

## 核心论点

2025年Q3，FOF资产配置从"稳打底"全面转向"攻守兼备"。四大转向同时发生：短债打底、黄金入基准、权益偏好成长、海外债博票息。FOF规模突破2001亿创历史新高，但比规模更重要的变化是配置结构的结构性迁移。

## Q1: 为什么FOF三季度大幅提升短债配置？

**结论**：利率显著上行环境中降低组合久期 + 短债提供流动性缓冲，[[entities/海富通]] 中证短融ETF成FOF第一重仓。

```
利率↑ → 组合久期↓需求↑ + 短债=流动性工具 → 海富通短融ETF：18亿→33亿（FOF持仓第一）
```

**证据**：
- 海富通中证短融ETF被67只FOF重仓，持仓从18亿升至33亿
- 17只FOF持有该基金比重在10-20%之间
- 利率上行环境中降低久期是核心驱动

**边界**：若利率转为下行，FOF可能减持短债重新拉长久期。

## Q2: 为什么FOF将债券配置从场外转向场内？

**结论**：监管规定场外债基持有不满6个月需支付50bps以上赎回费，FOF转向场内ETF避免费用摩擦。

```
场外债基<6个月赎回费≥0.5% → FOF转向场内债券ETF
```

**证据**：
- 2025年9月5日销售费用规定征求意见稿出台
- 场外债基持有期不满6个月需支付至少0.5%赎回费
- FOF重仓前十债券型基金基本均为场内ETF

**边界**：若最终规定豁免FOF的赎回费或降低费率，场外配置可能回流。

## Q3: 为什么超80%的FOF在基准中引入了黄金？

**结论**：新规鼓励多元化基准 + 黄金在低利率环境下具备配置价值，FOF将黄金从可选项变为必选项。

```
新规后 → 80%+ FOF基准加入黄金（Au99.99）⊃ 持仓28亿 ⊃ [[entities/华安易富黄金ETF]] 持仓17.3亿
```

**证据**：
- 2025年5月行动方案以来部分FOF变更基准
- 超80%引入黄金，部分还加入商品期货指数
- FOF实际持有黄金基金总市值达28亿元

**边界**：若金价持续回调或FOF业绩基准不再考核黄金配置，持仓可能下降。

> 此现象与[[concepts/黄金保险定位框架]]将黄金定位为"保险"存在定位差异——专业投资者（FOF）实际将其 as 配置品种纳入基准。

## Q4: 为什么FOF权益持仓从价值切向成长？

**结论**：成长风格基金（科技/新能源）持仓提升，价值平衡风格基金被大幅减持。

```
成长风格（易方达科融/智造/兴全合润）持仓↑ ⊥ 价值风格（大成高鑫：169只→14只，国富中小盘：35只→0只）
```

**证据**：
- [[entities/大成高鑫股票]] 从被169只FOF持有（8.96亿）降至14只（0.88亿）
- [[entities/国富中小盘]] 从被35只FOF持有降至无FOF重仓
- 被减持基金最近两年投资风格均偏价值

**边界**：若市场风格从成长切回价值，FOF可能重新增配价值基金。

## Q5: 为什么FOF持有香港互认基金？

**结论**：国内利率持续下行环境中，香港互认债基提供获取较高票息收益的机会。

```
国内利率↓ → 境内债息↓ ⊃ 香港互认债基（票息↑）→ FOF持有33.76亿 ⊃ [[entities/摩根国际债券基金]] 最受欢迎
```

**证据**：
- FOF持有香港互认基金总市值33.76亿
- [[entities/摩根国际债券基金]] 被23只FOF重仓，持仓4.08亿
- 低利率环境下互认债基提供较高票息

**边界**：若国内利率上行或香港市场风险上升，FOF可能减持互认基金。

## Q6: FOF规模为什么能创历史新高？

**结论**：新发FOF募集火爆（富国60亿/东方红65亿）+ 存量FOF持营爆发，市场热度传导。

```
新发火爆（10天60亿/7天65亿） + 存量持营（中欧+68亿/华安+60亿/博时+59亿）→ 规模2001亿创新高
```

**证据**：
- 2025年FOF新成立50只，总规模达2001亿
- 存量FOF前三季度增长654亿，突破2021年高点
- 多只FOF首发即宣布提前结束募集

**边界**：若市场持续震荡或FOF业绩不达预期，规模增长可能放缓。

## 收口

作者的核心贡献：用FOF三季度持仓数据画出"专业买手"的配置图谱——短债打底 + 黄金进基准 + 权益偏成长 + 海外互认债博票息，核心是从稳打底转向攻守兼备。
