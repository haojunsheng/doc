# QA — 赛道基金陷阱：把双刃剑

**原文**：[Morningstar 晨星](https://www.morningstar.cn/文章/赚钱最锋利的矛也会成为让你亏钱的毒药)

## 核心命题

赛道基金是把双刃剑——用得好是锋利的矛，用不好是让你血亏的毒药。窄范围+高聚焦放大了行业波动，而 A 股板块轮动特征使择时极其困难。

```
窄聚焦 = 高弹性(涨得狠) + 高波动(跌得狠) + 轮动难测
```

## Q1：为什么赛道基金涨得狠，跌得也狠？

**结论**：因为赛道基金投资范围更窄更聚焦，放大了行业波动。

**形式化**：`赛道基金 = 窄范围 + 高聚焦 = 高波动`

- 普通行业基金已经比全市场基金波动大
- 赛道基金比普通行业基金更窄，波动更大
- A 股板块轮动特点使赛道基金更容易暴涨暴跌

**边界**：如果投资者能准确判断行业周期，高波动反而能带来更高收益——但这需要极强的择时能力。

## Q2：为什么"老登资产"和"小登资产"之争是伪命题？

**结论**：每个赛道都曾是"小登"，也会变成"老登"，关键不在赛道本身。

**形式化**：`赛道轮动: 小登(新赛道) → 热门(资金涌入) → 老登(资金撤离)`

- 现在被调侃的"老登资产"（如白酒），曾是上一轮牛市最锋利的"矛"
- 上一轮买科技基金的"小登"，也是最近才刚从坑里爬出来
- **没有永恒的热门赛道，只有不断轮动的市场风格**

**边界**：有些赛道确实有长期增长潜力（如科技、医药），但估值过高时买入仍然会亏钱。

→ 详见 [[赛道生命周期轮动]]

## Q3：为什么行业基金投资者实际拿到的收益远低于基金总回报？

**结论**：因为投资者往往在高点买入、低点卖出，错失了大部分收益。

**形式化**：`投资者回报 < 基金总回报; 原因 = 追涨杀跌 + 时机不当`

- 晨星研究显示，中国行业基金投资者实际收益远低于基金净值回报
- 资金流向数据显示，投资者通常在行业表现好后才扎堆买入
- 行业出现波动时又匆忙卖出，错过了后续反弹

**边界**：如果投资者能长期持有，或者采用定投策略，可以减少择时错误的影响。

→ 详见 [[追涨杀跌损益侵蚀]]、[[近因效应]]

## Q4：主题投资成功需要哪三个前提？

**结论**：长期跑赢的主题 + 能抓住风口的基金 + 在市场低估时上车。

**形式化**：
```
主题投资成功 = 好主题 ∩ 好基金 ∩ 好时机
```

| 前提 | 要点 |
|------|------|
| 好主题 | 有扎实长期逻辑支撑，不是概念炒作 |
| 好基金 | 不同基金的选股逻辑、配置比例差别很大 |
| 好时机 | 在市场低估时买入，而不是热度最高时追高 |

三个前提同时满足非常困难，这是大多数主题基金投资者不赚钱的根本原因。此公式与 [[主题基金存活率模型]] 的"三件事同时做对模型"（主题正确 ∩ 基金坚持 ∩ 入场时机对）实质相同，互为印证。

## Q5：为什么同一行业基金业绩差距能超过 30%？

**结论**：因为不同基金的选股逻辑、行业配置、跟踪指数差异很大。

**形式化**：`同赛道基金差异 = 选股逻辑不同 + 行业配置不同 + 指数编制不同`

- 晨星数据显示，同一行业类别中最好和最差基金年化收益差距超 **30%**
- 主动基金的选股、择时能力差异大
- 被动基金的指数编制方式不同，收益也会差很多

**边界**：历史业绩差距不代表未来。投资者应该关注基金的投资逻辑，而不是只看历史业绩。

→ 详见 [[买入逻辑检验]]

## Q6：基金公司为什么在主题热度起来后才发行相关基金？

**结论**：因为基金公司也是逐热的，热度起来后更容易募集资金。

**形式化**：`基金公司行为 = 追热度 + 发产品 + 高位接盘`

- 基金公司有业绩压力，需要规模增长
- 热度起来后，投资者更容易接受，基金更好卖
- 但这时往往已经错过了最佳买入时机

**边界**：有些基金公司会前瞻性布局，在热度起来前就发行产品。但这类产品往往规模较小，难以做大。

## Q7：行业主题基金在组合中应该扮演什么角色？

**结论**：适合作为"卫星持仓"，而非"核心配置"，且需严格控制仓位比例。

**形式化**：
```
组合 = 核心(宽基/债券) + 卫星(行业主题, ≤20%)
```

**关键量化证据**：
- 过去 10 年，大多数行业主题基金与大盘指数的三年期相关性保持在 **0.6 以上**
- 已持有大盘指数基金时，再添加主题基金起不到太多分散风险效果
- 债券、海外股票、黄金等与大盘相关性更低，对组合分散风险更有价值

> **注意**：原文未明确该 0.6 相关性的统计口径（样本覆盖范围、时间窗口），建议在后续研究中补充验证。

**边界**：如果投资者对某个行业有深入研究，可以适当增加配置比例，但一般不建议超过组合的 20%。

→ 详见 [[核心-卫星策略]]、[[赛道估值透支]]

## 收口

赛道基金不是不能买，而是要清醒认识它的风险。严格控制仓位，避免追高，才能让这把"锋利的矛"为你所用，而不是伤到自己。
