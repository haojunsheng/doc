# 概念解剖 — 投资目标

> 晨星文章：投资中的旷野求生
> 作者：屈辰晨
> 日期：2026-06-14

## 核心论点

投资目标不是"赚多少钱"的数字，而是"我想要什么样的生活"的清晰蓝图。致富不应是目标本身，而是追求理想生活的**副产品**。

## 形式化定义

**投资目标 = 具体金额 × 时间框架 × 可行性验证**

三要素缺一不可，否则只是白日梦。

## 主要内容

### 为什么"致富"不是目标

引用卡尼曼（Daniel Kahneman）前景理论：幸福感取决于参照点的对比，而非绝对金额。

- 100万在人均收入100万的年代不算富
- "享乐跑步机"效应：参照系永远向上移动
- 西西弗斯式循环：无终点目标 = 永恒徒劳

### 欧洲旅行类比

时间约束 × 预算约束 = 交通工具选择

投资同理：时间框架 × 资金需求 → 决定投资策略。没有约束的投资目标如同没有目的地和预算的旅行计划。

### 指南针 vs 地图隐喻

| 地图 | 指南针 |
|------|--------|
| 知道每一步怎么走（幻觉） | 知道朝哪走（清醒） |
| 精确路线 | 方向感 |
| 投资中的"预测"幻觉 | 投资中的"规划"现实 |

### 结尾五连问（行动框架）

1. 我想要什么样的生活？
2. 需要多少钱？
3. 多久实现？
4. 现实吗？
5. 需要调整吗？

## 理论来源

- **前景理论**（Daniel Kahneman, Amos Tversky）：参照点依赖
- **目标设定理论**（Locke & Latham）：目标需具体、有挑战性、可衡量、有时限
- **享乐适应**（Russell Swanburg, later Kahneman）：财富增长带来的幸福感随时间衰减

## 与已有知识库的关联

- 与 [[富有是副产品]] 高度一致，是对同一命题的方法论细化
- 与 [[投资指南针模型]] 互为补充——本文提供哲学基础，模型提供操作步骤
- 与 [[跑步机效应]] 同构：均以卡尼曼参照点理论为底层支撑
- 与 [[摩根·豪泽尔对话补充]] 共同指向"理财没有统一答案"的核心命题

## 元反思要点

- "人生是旷野"被过度引用为"毒鸡汤"，本文用"指南针"概念弥补其方法论缺口
- 隐含价值判断：理想主义优于物质主义——这是立场，非事实
- 机构张力：投资机构需要客户的具体数字目标来销售产品，与本文解构数字目标的立场存在利益冲突
- 未讨论：人生动态变化下的目标重新校准问题

## 盲区提醒

- 假设投资者有稳定的生活愿景——但很多人从未认真思考过这个问题
- 未讨论多重目标（退休+教育+购房）的复杂性，需要不同时间框架
- 目标本身的动态性与静态设定的张力未解决
