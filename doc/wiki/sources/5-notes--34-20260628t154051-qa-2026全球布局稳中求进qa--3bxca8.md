# 2026全球布局稳中求进——晨星全球策略师圆桌

## 概述

晨星CEO Kunal Kapoor 主持的圆桌对话，邀请三位区域策略师（美洲 Preston、欧洲 Michael、亚洲 Kai Wang）共同研判2026年全球投资布局。核心主题是"不确定性是主旋律"，但每个人开出的药方不同。整篇文章围绕八个问题展开，涉及AI估值可持续性、关税传导风险、被动投资者困境、行为偏差警惕等关键议题。

## 核心结论摘要

### 晨星方法论的价值边界

晨星不做单年预测，而是用10年视角评估公司持续增长能力。短期爆发的公司隐含的长期增长率往往不可持续。

```
跟风: 涨 → 推荐 → 不可持续
晨星: 退后10年 → 评估护城河 → 过滤噪音
```

### AI投资热度与估值可持续性

关键不是AI支出多少，而是能否推动更广泛经济领域的效率提升。只有当AI真正推动实体经济效率提升时，当前估值才站得住——"现在还不到时候"。

```
AI支出计划 + 股价上涨 ≠ 估值成立
AI提升实体效率 → 估值成立
```

### 2026年最大潜在波动源：关税-通胀连锁反应

关税传导到消费价格是最大风险，可能触发"关税→消费价格→通胀→降息泡汤→信贷违约上升"的完整传导链。

```
关税 → 消费价格传导 → 通胀上升 → 降息泡汤 → 消费回调 + 违约上升
```

### 被动投资者的集中度困境

英伟达占美国指数约8%、全球指数约6%，被动投资者已经"被动"重仓AI。如果再在个股层面加仓英伟达，集中度风险过高。建议：避免在个股和行业层面进一步加仓AI。

```
英伟达占指数8% + 主动加仓 → 过度集中 → 需要减配或至少不加
```

### FOMO是最需警惕的行为偏差

FOMO驱动的决策往往在高点买入，推高估值后必然大幅回落。这不是个案，是各市场的普遍现象。

```
FOMO: 看到涨 → 追高 → 估值极高 → 大幅回落
```

案例：泡泡玛特 Labubu 火爆 → 投资者追母公司股票 → 估值极高 → 股价大幅回落。

### 区域分化判断

**欧洲**：宏观从低位回升+利率下行空间，但消费恢复和国防股风险存疑。

**亚洲**：科技龙头（阿里、腾讯）+ 产能过剩行业龙头有机会，但房地产拖累财富效应。

```
欧洲: 宏观顺风 + 利率下行空间 | 但: 消费能否恢复？国防股风险？
亚洲: 科技强 + 产能过剩行业龙头机会 | 但: 房地产拖累财富效应
```

### 三位策略师的个人调整

- **Michael**：承认现金仓位太低，正在减持明显高估的标的
- **Kai**：也在看减持空间，并用比特币走势观察市场情绪
- **Preston**：思考"人力资本"对冲——白领职业可能被AI冲击，所以配置AI股

共同点：都承认需要留有余地应对波动。

## 收口框架

作者贡献的行动框架：**不预测、留现金、控集中度、看长期**——稳中求进的核心是"进"有纪律、"稳"有缓冲。
