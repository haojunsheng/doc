# QA — 基金经理的高光与遗憾

来源：晨星中国（https://www.morningstar.cn/articles/98d6507206f7145f0cf615263662d1f4.html）

## 核心命题

评估基金经理看什么？不是看他有没有犯过错，而是看他犯错后有没有把遗憾变成改进的燃料——这种**自我迭代能力**，比任何一次高光都更值钱。

## Q1: 赵晓东为什么敢在2020年减持食品饮料和生物医药？

- **结论**：他看到白酒平均PE超60倍、医药估值95倍，远超业绩增速预期，属于估值泡沫。
- **形式化**：白酒PE>60 + 医药PE95 >> 盈利增速预期 → 泡沫 → 系统性减持
- **操作**：食品饮料持仓从18.53%骤降至5.98%，生物医药从11.20%降至5.68%
- **边界**：若流动性持续宽松（如2021年），高估值可能维持更久，减持会错过一段涨幅

## Q2: 赵晓东为什么同时加仓银行？

- **结论**：银行兼具估值优势+长期增长逻辑+抗周期属性，行业估值修复是大概率事件。
- **形式化**：银行: 估值↓ + 中间业务↑ + 抗周期 → 配置从16.34%→27.31%
- **逻辑**：
  - 银行板块被低估，安全边际显著
  - 人民币国际化进程中银行中间业务有增长潜力
  - 头部银行（宁波银行、招商银行）具备超额收益空间
  - 银行相对沪深300五年累计超额收益31.8%
- **边界**：若经济下行导致银行资产质量恶化（如坏账率飙升），估值修复逻辑会被推迟

## Q3: 赵晓东投资爱美客犯了什么错？

- **结论**：过度依赖历史高增速数据，忽视了医美行业的周期性和竞争敏感度。
- **形式化**：历史增速100% + 估值回落至70-80倍 → 建仓 → 基本面恶化 → 跌50.76%
- **经过**：
  - 2022年爱美客营收净利均超100%增长，全年平均估值198倍
  - 赵晓东观察到估值回落至七八十倍后认为可以"消化"
  - 2023年新产品商业化不及预期+行业竞争加剧+宏观消费复苏乏力
  - 股价从424.26元跌至208.91元，跌幅50.76%
- **反思**：低估了医美行业周期性和竞争敏感度
- **边界**：若爱美客新产品成功商业化且竞争格局稳定，估值消化逻辑会被验证

## Q4: 杨嘉文为什么2023年低配了红利股？

- **结论**：他把红利当防御工具，认为无大跌预期时质量成长收益弹性更优。
- **形式化**：无大跌预期 → 红利(防御/低弹性) < 质量成长(高弹性) → 低配红利
- **逻辑**：质量成长股可通过"业绩增长×估值提升"的[[戴维斯双击]]实现更高回报
- **边界**：若2024年经济复苏强劲而非放缓，成长股跑赢，低配红利的判断就是对的

## Q5: 杨嘉文从红利误判中学到了什么？

- **结论**：市场对长期稳定现金流的定价逻辑已变，[[资产久期特征]]需纳入框架。
- **形式化**：经济寻底+利率↓ → 资金追逐长期稳定现金流 → 定价逻辑变 → 框架需更新
- **纠偏措施**：
  - 增配高股息资产
  - 引入[[股息率-无风险利率比价模型]]
  - 方法论从"以成长为主要导向"进阶为"成长与价值动态平衡"
- **边界**：若利率环境突然逆转（如通胀飙升），高股息资产的防御价值会下降

## Q6: 谷衡2020年债市V型震荡犯了什么错？

- **结论**：他逆势加仓利率债+提升久期，低估了货币政策从"总量宽松"转向"结构性调节"的速度。
- **形式化**：疫情恐慌→利率↓→经济恢复→央行边际收紧→利率↑ → 谷衡逆势加仓→净值↓
- **经过**：
  - 2020年前四个月利率下行至历史低点（十年期国债2.49%）
  - 疫情控制后央行边际收紧，利率快速攀升至3.34%
  - 谷衡早期反而增加利率债比重、提升组合久期
- **失误根源**：过度依赖传统指标，忽视央行防风险、金融稳定等新目标

## Q7: 三位基金经理的遗憾有什么共同启示？

- **结论**：犯错不可怕，可怕的是不复盘——[[基金经理自我迭代框架]]是基金经理真正的护城河。
- **形式化**：犯错 + 复盘反思 + 框架迭代 → 能力↑ ‖ 犯错 + 不反思 → 重复犯错
- **三位反思方向**：
  - 赵晓东：估值分析、行业研究、行业认知三个维度
  - 杨嘉文：久期特征和定价逻辑认知盲区
  - 谷衡：货币政策分析框架局限性
- **边界**：若反思停留在口头（如"下次注意"）而不落实到投资流程中，复盘无实质意义
