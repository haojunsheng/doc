# QA — 4000点牛市基金回本难题

晨星（Morningstar）分析揭示：2015年牛市高点买入的基金，即使上证指数回到4000点，大量基金净值仍低于买入价。核心原因是基金回撤深度远超指数，而回本难度随回撤深度呈非对称性上升。

## 核心问题与结论

### Q1: 为什么指数回到4000点，很多基金还没回本？

因为基金的回撤深度远超指数，指数涨回去不代表基金净值涨回去。2015年牛市高点成立的基金，即使指数回到4000点，很多基金净值仍低于买入价。基金在高点成立后经历了大幅回撤（如-50%），需要涨100%才能回本。这说明基金的回撤控制能力比上涨能力更重要。

### Q2: 基金回撤50%需要涨多少才能回本？

回撤50%需要涨100%才回本——回撤越深，回本难度呈指数级上升。

```
回撤d% → 需要上涨百分比 = d/(1-d) × 100%
回撤30% → 需涨42.9%
回撤50% → 需涨100%
回撤70% → 需涨233%
```

这就是为什么控制回撤比追求高收益更重要。如果基金持续分红，回本所需的净值涨幅会降低。

### Q3: 上个牛市基金"扎堆发行"在5000点附近，这说明什么？

基金公司倾向于在市场高点发行基金，导致投资者买在山顶。2015年5000点附近大量基金发行，募集了天量资金。这些基金建仓成本高，随后遭遇股灾大幅回撤。这说明基金公司的发行节奏往往与投资者利益不一致。

### Q4: 为什么有些基金从高点回撤后能快速回本，有些不能？

取决于基金经理的回撤控制能力、投资策略和市场风格匹配度：
- 回撤浅的基金更容易回本（如回撤30% vs 回撤60%）
- 反弹力度大的基金能快速填坑（如医药基金在医药行情中反弹）
- 如果市场风格变了（如从成长转向价值），某些基金可能永远回不了本

如果基金经理换人，历史回撤数据不再有参考价值。

### Q5: 投资者应该如何判断自己持有的牛市基金能否回本？

看三点：回撤深度、基金经理是否变更、当前市场风格是否匹配。

```
回本可能性 = f(回撤深度 < 50%, 经理未变更, 风格与市场匹配)
```

- 回撤<50%的基金，反弹50%就能回本，相对容易
- 如果基金经理换人，新经理的能力和风格未知，回本不确定
- 如果市场风格与基金策略不匹配，回本困难

如果市场整体继续上涨，即使风格不匹配，基金也可能回本。

### Q6: 文章的核心教训对当前4000点的投资有什么启示？

不要在市场高点扎扎堆买入热门基金——回本风险远大于想象。上一个牛市的教训表明，高点买入的基金回本难度极大。当前4000点虽然比5000点低，但仍是相对高位。应该采用定投、分散买入等方式，而不是一把梭。如果投资者有3-5年持有期，短期高点的影响会被时间平滑。

### Q7: 基金公司扎堆发行的行为反映了什么问题？

基金公司追求规模（管理费），而非投资者利益最大化。高点发行能募集更多资金（投资者追涨），但高点发行的基金业绩往往最差。这说明基金公司的销售节奏与投资者利益存在冲突。部分基金公司会在高点限购，保护投资者利益。

### Q8: 如果已经持有未回本的牛市基金，应该怎么办？

评估基金经理能力和市场风格，如果都不考虑，果断换仓。

决策框架：
- 经理优秀 + 风格匹配 → 持有等待
- 经理换人或风格不匹配 → 考虑换仓

如果基金经理能力经过验证（如周蔚文），可以继续持有。但换仓也有风险——新基金可能表现更差。如果基金有赎回费，换仓成本也需要考虑。

### Q9: 如何用这篇文章的教训指导未来的基金投资？

建立"逆向投资"思维——在市场低点买入，在高点谨慎。上一个牛市的教训表明，高点买入是最大的风险。如果能在市场低迷时买入，回本和盈利的概率更高。可以采用定投方式，自动实现"低点多买、高点少买"。但判断市场高低点很难，定投虽然平滑成本，但不保证盈利。

### Q10: 为什么"回本"这个概念对投资者心理影响这么大？

"回本"是投资者心理账户的锚点，回到买入价才有安全感。买入价成为心理账户的参考点，低于买入价时，投资者感到焦虑和后悔。即使基金相对基准表现好，只要没回本，投资者仍不满意。理性的投资者应该看相对基准的绝对收益，而非是否回本。

## 收口

晨星用数据揭示了一个残酷现实：上个牛市高点买入的大量基金至今未回本，核心教训是——回撤深度决定回本难度，高点买入是最大的风险。
