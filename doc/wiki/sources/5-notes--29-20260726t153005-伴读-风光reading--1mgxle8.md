# 伴读：16 | 风光——你不想让别人看见什么？

**课程来源**：《摄影入门课》第16讲，作者小麥

## 核心论点

拍风光的核心不是"你想让别人看见什么"，而是**"你不想让别人看见什么"**。风光摄影的本质是做减法：通过选择焦段、机位和构图，把无关元素排除在外，只保留打动你的部分。

## 内容结构

### 焦段选择：广角不是万能的

- 只有一种风光适合广角——本身巨好看的风光
- 大部分场景有边且杂乱，广角无法裁切，手持广角只能"干瞪眼"
- **中长焦更好**：视角窄 → 选择余地大 → 能做取舍
- 超广角仅适合银河/星轨等特殊题材

### 取景核心：简洁

- 取景 = 放大打动你的元素 + 屏蔽不必要元素 = 简洁
- **先观察，后按快门**：不知道重点是什么，就别掏相机
- "不拍这张照片死不了人"

### 机位选择：比"拍"更重要

- 类比链：静物 → "摆"比"拍"重要；人物 → "聊"比"拍"重要；风光 → **"找机位"比"拍"重要**
- 需要提前规划：地图软件勘察、徒步路线、天文气象预判
- 路径：模仿 → 熟练 → 创作

### 接片技术（实操）

- 长焦竖构图多张合成，获得宽幅+高像素
- 注意事项：重合 > 30%、手动白平衡、手动模式
- 花果园案例：70mm 竖构图 6 张合成，1小时拍摄 + 2小时后期，上亿像素

### 总结：风光 = 做减法

- 终局目标：让照片看起来像一幅画——"完整性，不多不少"
- 画框的作用就是隔掉不想让别人看见的东西
- 风光靠天吃饭，需要"认命"的心态

## 术语表

| Wide Angle | 广角 | 短焦段、视角宽的镜头 |
| Medium Telephoto | 中长焦 | 中等焦距的镜头 |
| Ultra Wide Angle | 超广角 | 极短焦段、极宽视角 |
| Panorama Stitching | 接片 | 多张照片合成宽幅 |
| Photomerge | 合成功能 | Photoshop 的接片功能 |

## 全文复盘

- **最大反直觉点**：拍风光不一定要用广角，中长焦反而更好（大众常识"大场景=广角"）
- **最深收获**：标题那句话——"你不想让别人看见什么"，适用于所有创作（写作/设计/演讲）
- **最实用收获**：接片技术——长焦竖构图多张合成

## 终局问题

如果场景本身就很杂乱（比如城市街头），做减法几乎不可能，这时候风光摄影的方法论还适用吗？还是说，风光摄影只适用于"本身就很简洁"的场景？

# 中长焦风光优先

> 拍风光不一定要用广角，中长焦反而更好。

## 核心观点

大众常识认为"大场景=广角"，但这篇课程提出了反直觉的论断：**中长焦更适合大部分风光场景**。

## 逻辑链

1. 只有"本身巨好看"的风光才适合广角
2. 大部分场景有边、杂乱，广角无法裁切无关元素
3. 手持广角面对杂乱场景只能"干瞪眼"
4. 中长焦视角窄，迫使你做取舍
5. 做取舍的能力 → 更容易拍出简洁、与众不同的画面

## 广角 vs 中长焦对比

| | 广角 | 中长焦 |
|---|---|---|
| 视角 | 宽 | 窄 |
| 能否裁切无关元素 | 不能 | 能（通过选择） |
| 适用场景 | 本身巨好看的风光、银河/星轨 | 大部分有边的杂乱场景 |
| 决策压力 | 低（什么都收进来） | 高（必须取舍） |
| 最终效果 | 容易杂乱 | 容易简洁 |

## 边界条件

- 超广角仅适合银河、星轨等特殊题材
- 长焦接片可弥补视角过窄的问题（多张合成获得宽幅+高像素）

# 机位优先原则

> "你站在哪儿"比"你怎么拍"更重要。

## 核心观点

风光摄影的独特性在于：**机位选择比拍摄动作本身更重要**。这不是一个关于参数设置的问题，而是一个关于位置选择的问题。

## 类比链

- 静物摄影 → "摆"比"拍"重要
- 人物摄影 → "聊"比"拍"重要
- 风光摄影 → **"找机位"比"拍"重要**

三者共享同一方法论结构：拍摄动作是最后的执行环节，前置准备才是决定性因素。

## 实操方法

- 提前规划：地图软件勘察、徒步路线规划
- 预判场景：天文气象判断
- 学习路径：模仿 → 熟练 → 创作

## 深层含义

在拍风光这件事里，"拍"这个动作反而是最不重要的一环。这与其他摄影类型形成对照：人物摄影侧重人际互动，静物摄影侧重布置，风光摄影侧重位置选择。

## 与关联概念的关系

- [[风光摄影做减法]]：机位选择是实现减法的手段之一
- [[摄影减法论]]：本原则是减法论在风光场景的方法论延伸

# 风光摄影做减法

> 风光摄影的本质是做减法：不是你想让别人看见什么，而是你不想让别人看见什么。

## 核心论点

风光摄影不是"把好的东西放进画面"，而是**"把不好的东西从画面中排除"**。画框的作用就是隔掉不想让别人看见的东西。

## 方法论结构

1. **焦段选择**：用中长焦代替广角，迫使自己在取景时做取舍
2. **先观察后按快门**：搞清楚什么打动了你，再决定拍不拍
3. **机位选择**：你站在哪儿比你怎么拍更重要
4. **接片技术**：在需要覆盖广阔场景时，用长焦多张合成代替广角单张

## 终局目标

让照片看起来像一幅画——**完整性，不多不少**。

## 心态层面

风光靠天吃饭，拼技术也拼命，需要"认命"的心态。这是风光摄影与其他摄影类型的本质区别：其他类型可通过摆布或互动控制变量，风光受天气/光线等不可控因素制约极大。

## 与关联概念的关系

- [[摄影减法论]]：本概念是减法论在风光场景的具体展开
- [[中长焦风光优先]]：减法的工具层面落实
- [[机位优先原则]]：减法的方法论层面落实
