# 四只固收基金深度拆解——选团队比选经理更重要

晨星潜力基金系列：盘点四只值得关注的固收基金——天弘永利（五周期择时模型）、安信目标收益（可转债为主）、西部利得汇享（严控回撤）、鹏华丰禄（规模纪律+多策略协同）。每只都有独门武器。

## Q1：天弘永利的"五周期模型"有什么用？

五周期（宏观+货币+机构+仓位+情绪）共振点识别 → 重仓布局。久期在1-4年波动，杠杆在0-140%调整。边界：若五周期同时指向同一方向但判断错误，集中出击会放大亏损。

## Q2：安信目标收益为什么从信用债切到可转债为主？

2021年起可转债市场大幅扩容+流动性提升，转债能提供更高超额收益弹性。转债配置比例可在0%-100%间灵活调整，2024Q4-2025Q1阶段性降低至30%以下以应对波动率。边界：若可转债市场流动性枯竭，高转债仓位面临变现困难。

## Q3：安信目标收益如何给可转债定价？

基本面研究刻画未来股价概率分布 → 为期权定价 → 筛选低估值、低信用风险个券。将转债分为纯债替代型、权益替代型和平衡型三类。边界：若股价概率分布估计偏差大（黑天鹅事件），期权定价会失效。

## Q4：西部利得汇享如何把最大回撤控制在-2%以内？

高等级信用债（80%-100%）打底 + 可转债≤20%且分散投资 + 杠杆纪律（100%-135%）。AAA以下信用债占比控制在20%-30%以内。边界：系统性违约事件（如国企信仰打破）时底仓也会受伤。

## Q5：鹏华丰禄的"规模纪律"为什么重要？

严格设置规模上限确保策略灵活执行，实现快速调仓、精准把握市场机遇。边界：规模上限过小可能导致清盘风险。

## Q6：鹏华丰禄的多策略协同指什么？

久期策略（核心，久期0.5-4年）+ 信用利差 + 收益率曲线 + 利差套利 + 息差优化。信用债仓位80%-110%，利率债0-25%，杠杆100%-135%。边界：多策略信号矛盾时需做取舍判断。

## Q7：选固收基金最该看什么？

**团队分工 + 策略清晰 + 风控纪律 + 规模管理 → 好的固收基金。**

| 基金 | 团队特点 | 策略清晰度 | 风控纪律 | 规模管理 |
|------|---------|-----------|---------|---------|
| 天弘永利 | 主经理+专业基金经理协同 | 五周期模型 | 久期/杠杆双约束 | 有 |
| 安信目标收益 | 两位经理互补（转债+纯债） | 可转债为核心 | 仓位动态调整 | 有 |
| 西部利得汇享 | 股债兼修+研究员支持 | 高等级信用债打底 | 回撤<-2%硬约束 | 有 |
| 鹏华丰禄 | 刘涛领衔 | 多策略协同 | 规模上限+信用底线 | 严格 |

# 五周期择时模型

天弘永利独创的市场周期共振识别框架，从五个维度寻找集中布局时机。

## 五周期构成

1. **宏观**：经济基本面周期
2. **货币**：流动性松紧周期
3. **机构**：资金行为周期
4. **仓位**：持仓集中度周期
5. **情绪**：市场心理周期

## 运作逻辑

五周期(宏观+货币+机构+仓位+情绪) → 共振点识别 → 重仓出击

- 赋予不同市场周期相应不同时长
- 寻找周期共振点并重仓布局
- 依据各周期时间尺度合理确定投资交易周期
- 久期在1-4年波动，杠杆在0-140%调整

## 边界风险

若五周期同时指向同一方向但判断错误（如共振看多但实际利空），集中出击会放大亏损。模型的公开可验证度仍有待考察。

```
# 可转债定价框架

基于基本面研究的转债定价与筛选方法，核心链条：

## 定价逻辑链

基本面研究 → 股价概率分布 → 转债期权定价 → 筛选低估值+低风险个券

## 关键步骤

1. **基本面研究**：对标的公司深入分析
2. **股价概率分布**：刻画未来股价的概率分布
3. **期权定价**：在股价分布基础上为期权定价
4. **筛选**：选取低估值、低信用风险的转债个券

## 转债三型分类

将可转债分为三类进行差异化配置：
- **纯债替代型**：债性强于股性，作为债券替代配置
- **权益替代型**：股性强于债性，作为权益替代配置
- **平衡型**：股债特性均衡

## 边界风险

若股价概率分布估计偏差大（如黑天鹅事件），期权定价会失效。安信目标收益在2024Q4-2025Q1降低转债仓位至30%以下即是对此边界的管理。
```

```
# 规模纪律

通过严格设置基金规模上限，确保投资策略灵活执行，避免"规模红利"变"管理负担"。

## 核心逻辑

规模有上限 → 策略灵活 → 快速调仓 → 精准把握机会

## 实践案例

鹏华丰禄在规模管控方面表现突出，通过严格设置规模上限确保多元策略（久期/信用利差/曲线/套利/息差）能够灵活执行，实现快速调仓和精准把握市场机遇。

## 边界风险

规模上限过小可能导致清盘风险（如持有人赎回过多），反而损害投资者利益。规模纪律本质上是在"规模过大拖累策略"和"规模过小触发清盘"之间寻找最优区间。
```

```
# 固收选基四维度框架

选固收基金的核心公式：**团队分工 + 策略清晰 + 风控纪律 + 规模管理 → 好的固收基金。**

## 四维度详解

### 1. 团队分工
- 晨星强调投研团队和投资流程的分析
- 天弘：主经理+专业基金经理协同
- 安信：两位经理互补（转债+纯债）
- 西部利得：股债兼修+研究员支持
- 鹏华：刘涛领衔+多元策略团队

### 2. 策略清晰
- 五周期模型（天弘）/ 可转债为主（安信）/ 高等级信用债打底（西部利得）/ 多策略协同（鹏华）
- 每种策略都有明确的适用边界和参数范围

### 3. 风控纪律
- 天弘：久期1-4年、杠杆0-140%双约束
- 安信：转债仓位0-100%动态调整，波动率高的阶段降至30%以下
- 西部利得：最大回撤<-2%硬约束，AAA以下≤20-30%
- 鹏华：规模上限+信用评级底线

### 4. 规模管理
- 四只基金均表现突出，通过规模上限确保策略灵活执行
- 与[[迷你基金三重困境]]形成对照：规模过大有管理负担，规模过小有清盘风险

## 核心结论

固收基金的差异化不在收益率高低，而在收益来源的多元化和风险控制的纪律性。选固收基金，选的是"不亏钱"的能力。

## 边界风险

若团队核心人员离职（如主基金经理跳槽），过往团队分工优势可能消失。
```

四只基金的共同点：策略清晰、团队稳定、风控严格。差异不在收益率高低，而在收益来源的多元化和风险控制的纪律性。
