# 2024年基金行业五大变局 — 晨星报告

## 来源概述

晨星于2024年6月发布报告，梳理了影响中国公募基金行业的五大结构性趋势，指出市场正从"增量扩容"进入"存量竞争"时代，投资策略需相应调整。

## 五大趋势

### 趋势一：基金清盘常态化

截至2024年12月20日，年内已有233只基金清盘或转型。原因是市场成熟导致同质化竞争加剧，业绩差、规模小、费率高的基金被淘汰，这是市场优胜劣汰的自然表现。

逻辑链：市场成熟 + 同质化竞争 → 业绩差/规模小/费率高 → 投资者赎回 → 清盘

边界条件：如果市场整体向好，清盘数量会减少；如果基金公司盲目推出同质化产品，清盘风险会上升。

### 趋势二：主动基金战胜率暴跌

主动基金1年期战胜率从2020年的90%暴跌至2024年11月的14%，三年期首次跌破50%，五年期降至57%。

原因：市场风格快速轮动、量化策略普及、信息透明度提高，导致主动基金经理难以持续获取超额收益。

边界条件：如果市场有效性下降（如新兴市场），主动基金可能重新获得超额收益；如果经济出现结构性变化，新的投资机会可能出现。

### 趋势三：指数基金规模爆发

2024年三季度，指数基金规模突破5万亿元，较10年前增长10倍。ETF获1.1万亿元资金流入，创近20年新高。

驱动因素：主动基金难以战胜指数 → 资金流向被动 + ETF成为热门工具 + 公募基金"工具化"属性加强。

### 趋势四：无风险利率集体下降

- 1年期定期存款利率降至1.1%（四大行2024年7月和10月两次下调）
- 10年期国债收益率首次跌破2%，1年期国债2009年以来首次跌破1%
- 货币基金7日年化降至约1.5%，近40只货基跌破1%

原因：经济下行压力导致央行持续降息，且市场预期未来利率将进一步下行。

### 趋势五：策略转向

核心框架为"被动为主 + 费率敏感 + 资产配置"：

- **被动为主**：优先选择低成本的指数基金和ETF
- **费率敏感**：无风险利率下降，费率对净收益影响更大
- **资产配置**：单一资产波动加剧，需分散配置（股债混合）

## 核心结论

在"低利率 + 高有效性 + 严监管"的新时代，投资者必须从"追求超额收益"转向"控制成本 + 分散风险"，指数基金 + ETF + 资产配置的组合，将成为未来十年的主流策略。
