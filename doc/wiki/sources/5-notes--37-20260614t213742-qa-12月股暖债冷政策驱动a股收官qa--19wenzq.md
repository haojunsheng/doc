# 12月股暖债冷政策驱动A股收官 QA

> 晨星基金月报 QA，分析2026年12月A股与债市在政策驱动下的分化表现。

## 数据来源

- **发布方**：[[entities/晨星-morningstar]]
- **原文链接**：https://www.morningstar.cn/articles/baabdbdf226b947ead4b608a37116a8d.html
- **收录日期**：2026-06-14

## 核心论点

政策面暖风频吹时，A股率先反应（尤其成长风格），而债市在"利好兑现"和"股债跷跷板"双重压力下承压——这是**政策驱动型**股债分化的典型案例。

## 分项问答

### Q1：PMI重回扩张区间，为什么债市反而跌了？

**数据**：制造业PMI 49.2% → 50.1%（时隔8个月重回扩张）；中证全债指数 -0.07%

**逻辑链**：
```
PMI回升（经济企稳信号↑）→ 稳增长政策预期↓ → 债市避险需求↓ → 债市承压
```

**边界条件**：若PMI回升是短期扰动、后续再次回落，债市可能重新走强；若通胀超预期上行，债市跌幅会更大。

### Q2：政治局会议和中央经济工作会议的"利好"为什么没能撑起债市？

**结论**：政策面"稳中求进"的定调已被市场充分定价，真正的利好需要"超预期"，而这次只是"符合预期"。

**逻辑链**：
```
政策定调"稳中求进" = 市场已预期 → 无超预期增量 → 债市反应钝化
```

**边界条件**：若政策力度超预期（如大幅降准降息），债市可能重新走强；若政策执行不及预期，债市会进一步下跌。此机制详见 [[concepts/利好兑现效应]]。

### Q3：为什么信用债表现优于利率债？

**数据对比**：
| 指数 | 12月表现 |
|------|----------|
| 中证国债及政金债指数 | -0.25% |
| 中证企业债/中票/短融指数 | 均为正收益 |

**逻辑**：利率债对政策预期敏感（利好兑现=卖出信号），信用债有票息缓冲。此机制详见 [[concepts/票息优势]]。

**边界条件**：若经济超预期复苏，信用利差可能走阔，信用债表现会差于利率债；若政策超预期宽松，利率债会重新领涨。

### Q4：权益基金中成长风格优于价值风格，背后的逻辑是什么？

**驱动因素**：
- 政策主线："稳市场、强创新"，科技自立自强是核心
- 行业表现：国防军工、有色金属、通信板块涨幅超10%，AI算力需求推动通信板块大涨
- 风格映射：成长风格重仓科技、通信；价值风格重仓金融、地产

**边界条件**：若政策重心从"科技创新"转向"消费复苏"，价值风格可能重新占优。

### Q5：为什么QDII基金中"全球新兴市场"和"商品"表现好，而"大中华区"和"环球债券"表现差？

| 类别 | 表现 | 原因 |
|------|------|------|
| 全球新兴市场 | +1.53% | 日股上涨（日经225 +0.84%）+ 金银铜走强 |
| 大中华区 | -2%+ | 恒生指数 -0.61% 拖累 |
| 环球债券 | 77只仅1只正收益 | 美联储降息25bp但点阵图隐含进一步降息空间，海外利率上行压制 |

### Q6：可转债基金在固收类中表现最好（+2.84%），为什么？

**数据**：中证转债指数12月录得+2.13%，为所有细分券种最高。

**逻辑**：可转债兼具股债双重属性——A股回暖时分享权益上涨收益，债市下跌时有债底保护。

**边界条件**：若A股大幅下跌，可转债的转股价值会缩水，跌幅可能超过纯债。

### Q7：为什么医药基金12月跌得最惨（行业股票-5.97%，行业混合-7.06%）？

**归因**：
- 政策环境：12月政策主线是"科技创新"和"商业航天"，医药不在核心催化范围内
- 市场风格：成长风格占优，医药作为传统防御板块被资金减持
- 估值压力：前期医药板块估值偏高，缺乏新催化剂时容易遭遇"杀估值"

> ⚠️ **待验证**：此归因偏宏观逻辑，缺乏医药板块具体持仓的微观数据支撑。

## 收口规律

政策主线驱动下，投资者应动态配置（关注政策催化方向），而非简单追涨杀跌。

# 利好兑现效应

预期内的政策或利好落地后，市场不涨反跌的现象。

## 核心机制

当市场已经充分预期某项政策或利好时，该事件的落地不会带来增量信息，反而触发"买预期、卖事实"的获利了结行为。

**形式化表达**：
```
政策定调"符合预期" = 市场已定价 → 无超预期增量 → 反向卖出 → 价格下跌
```

## 典型案例：2026年12月中国债市

政治局会议和中央经济工作会议延续"稳中求进"定调，市场早已预期"适度宽松货币政策"和"更加积极有为财政政策"，政策落地后债市未能持续走强，反而短暂修复后回落。

**关键判断标准**：只有"超预期"的利好才能推动债市上涨，符合预期的利好等同于没有利好。

## 边界条件

- 若政策力度**超预期**（如大幅降准降息），债市可能重新走强
- 若政策执行**不及预期**，债市会进一步下跌
- 该效应在债券市场尤为显著，因为债市对政策预期高度敏感

## 与相关概念的关系

- [[concepts/近因效应]]：利好兑现后投资者可能因近期下跌而过度悲观
- [[concepts/预期可管理性]]：理解此效应有助于管理对政策预期的锚定
- [[concepts/政策驱动型产业分化]]：政策主线驱动风格切换，利好兑现效应解释为何同一政策对股债影响相反

# 票息优势

信用债因票面利率高于利率债，在震荡市或政策利好兑现环境中表现更优的特性。

## 核心逻辑

| 类型 | 票息水平 | 对政策敏感度 | 震荡市表现 |
|------|----------|-------------|-----------|
| 利率债（国债、政金债） | 低 | 高 | 易受利好兑现冲击 |
| 信用债（企业债、中票、短融） | 高 | 低 | 票息提供缓冲 |

**形式化表达**：
```
信用债优势 = 高票息（提供下行缓冲）+ 低政策敏感度（不易因利好兑现而抛售）
利率债劣势 = 低票息（无缓冲）+ 高政策敏感度（利好兑现=卖出信号）
```

## 实证：2026年12月

- 中证国债及政金债指数：**-0.25%**
- 中证企业债/中票/短融指数：**均录得正收益**

PMI回升利好信用风险预期，信用利差收窄，信用债同时受益于票息保护和利差收窄。

## 边界条件

- 若经济**超预期复苏**，信用利差可能走阔，信用债表现会差于利率债
- 若政策**超预期宽松**，利率债会重新领涨
- 此优势在"股暖债冷"的震荡环境中最为显著

## 与相关概念的关系

- [[concepts/固收加的权益暴露度权衡]]：股暖债冷环境下，纯债与可转债分化，票息优势解释了信用债在其中的角色
- [[concepts/转债选券偏好：低价高等级vs高弹性]]：转债选券中低价高等级策略本质上也是追求票息保护
- [[concepts/信用利差分层]]：票息优势与信用利差变化方向密切相关
