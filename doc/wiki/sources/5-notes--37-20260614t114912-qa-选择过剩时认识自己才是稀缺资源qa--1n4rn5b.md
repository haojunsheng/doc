# 选择过剩时认识自己才是稀缺资源

> 又添 2400 只！基金多到眼花缭乱，究竟该怎么选？
> Morningstar.cn，2026-06-14

## 核心论断

选择过剩时，真正稀缺的不是好产品，而是你认识自己的能力。这篇 QA 从行为心理学的选择过载出发，经过最大化者/满足者的性格解剖，最终完成一个视角翻转：*努力研究所有选项，本身就是问题的一部分*。

## Q1：基金多了，为什么反而更难选了？

**形式化表达：**

```
选择收益 = 潜在最优解价值 − 比较成本 − 后悔焦虑
选项↑ → 比较成本↑↑ → 收益↓
```

果酱实验（Sheena Iyengar）：24 种口味购买率 3%，6 种口味购买率 30%。卡尼曼进一步指出，选项多会放大"后悔厌恶"——没选到最好的股票带来的不甘，远超选对带来的满足。

**边界：** 此效应在结果高度不确定的长期决策中尤其显著；可量化比较的简单决策（如手机参数）中不一定成立。

## Q2：为什么"选最好的"本身就是陷阱？

**形式化表达：**

```
电子产品选购: 研究 → 找到最优 → 满意
投资: 研究 → 仍无法覆盖未来 → 焦虑
```

投资是"未知信息"决策，未来不可预测。市场上超过一半主动基金的业绩比较基准都是沪深 300，产品高度同质化。

**边界：** 短期套利或确定性较高的策略（如打新、定投指数）中，充分研究的收益可能超过心理成本。

## Q3：为什么投资行业天然吸引"最大化者"？

投资行业每个环节都在奖励"更深入的研究"，把"不断比较"包装成"专业精神"，形成自选择与自强化循环。这种环境让"满足者"的选择显得像在偷懒，但事实上满足者的长期表现未必更差。

**边界：** 专业投资者（如量化基金）确实需要最大化策略来获取微小超额收益，但这套方法论对个人投资者的性价比极低。

## Q4：制定筛选标准为什么能治选择恐惧？

**形式化表达：**

```
无限集 → 标准 → 有限集(200只) → 选择性研究
无限集 → 逐一研究 → 决策瘫痪
```

作者自己的五维示例：

| 标准 | 目的 |
|------|------|
| 五年未换基金经理 | 确保历史业绩由现任经理创造 |
| 晨星四星以上评级 | 确保历史业绩质量 |
| 换手率 < 400% | 筛掉高成本、高波动策略 |
| 前十大持股 < 50% | 避免过度集中 |
| 费率低于同类 | 控制成本侵蚀 |

这些标准不追求"最优"，追求"不犯大错"——快速筛掉不符合的，留下少量值得深入研究的。

## Q5："接纳自己的选择"为什么是最难也最有效的一步？

**形式化表达：**

```
无计划: 市场波动 → 焦虑 → 频繁调仓 → 交易成本侵蚀收益
有计划: 市场波动 → 对照目标 → 确认仍匹配 → 不动
```

市场永远在给你"应该做点什么"的信号，但计划是唯一能让你锚定目标、抵抗噪音的东西。任何时点你都无法保证持有的是表现最好的——这是结构性不可能。

**边界：** 市场环境发生结构性变化（如利率长期走高、地缘政治剧变）时，原计划可能需要调整；"接纳"不等于"僵化执行"。

## Q6：基金公司为什么不断发新基金？

**形式化表达：**

```
基金公司目标: 管理费收入 → 牛市发股基、熊市发债基 ≠ 投资者需求: 找到最优配置
```

历史规律：股市好时股票/混合型扎堆发行，市场低迷时债券基金成主流——这是"追涨"不是"补缺"。很多新主题像快消品的"潮流新品"，相当一部分终将被时间淘汰。你需要的"基础款"大概率早就存在了。

**边界：** 部分创新产品（如 REITs、Smart Beta 早期）确实填补了市场空白，不能一概而论。

## Q7：选择过剩的尽头，真正稀缺的是什么？

**形式化表达：**

```
稀缺性翻转: 稀缺从"好产品" → "自我认知"
选基金 = 选自己
```

当你足够了解自己，许多看似复杂的选择会自然变清晰。这串 Q 链的底层逻辑是从"外部比较"转向"内部校准"，从"选最好的产品"转向"选最适合自己的产品"。

## 收口

作者的真正贡献不是教你"怎么选基金"，而是完成一个视角翻转：当选择过剩时，你的竞争对手不是其他投资者，是你自己认识自己的能力。
