# QA — 迷你基金陷阱

来源：[[晨星]]，原文见 Morningstar 中国网站。
原文件：`notes/20260628T154334--qa-迷你基金陷阱__qa.md`

## 核心结论

迷你基金（规模<5000万）占了市场12%的数量却只有0.12%的规模，呈现极端的小规模集中现象。投资者踩坑的根源在于两个认知误区——把净值当股价认为"便宜"、被短期暴涨吸引追高。远离迷你基金是最优解。

## 三重困境闭环

迷你基金陷入流动性、收益、费率三重困境，形成负向闭环：

```
规模小 → 持仓集中（小市值/低评级债）
  → 流动性差 + 变现难 + 赎回延迟
  → 波动大 + 投研资源不足 + 无法参与高门槛优质资产
  → 收益率低
  → 固定成本分摊上升（信披费、审计费等）
  → 单位费率侵蚀更严重
  → 进一步拖累收益率 → 规模继续萎缩
```

## 认知误区

| 误区 | 真相 |
|------|------|
| "净值便宜=有上涨空间" | 净值高低与未来涨幅无关联；净值3元的基金可能长期业绩优良 |
| "短期暴涨可追" | 迷你基金的短期暴涨往往是反弹而非趋势反转 |

## 机构占比风险

机构占比高的基金更容易变迷你。机构资金量大且行为一致性强，一旦触发赎回（基金经理变动、策略不如预期），规模缩水速度远超散户为主的产品。晨星建议避开单一机构占比极高的基金。

## 已持有迷你基金的处理策略

- **可观察条件**：业绩稳定 + 规模回升迹象 + 经理未变更
- **果断赎回条件**：规模持续缩水 + 业绩低迷 + 风格漂移
- 赎回费通常低于清盘带来的损失

## 边界条件

- 若迷你基金持仓以大盘蓝筹为主，流动性问题可能没那么严重
- 若基金经理主动管理能力极强，小规模反而灵活，可能跑赢大基金
- 若基金公司自担固定费用，费率侵蚀有所缓解但不会消失
- 若基金通过拆分或分红刻意压低净值吸引投资者，这种"便宜"是营销手段
