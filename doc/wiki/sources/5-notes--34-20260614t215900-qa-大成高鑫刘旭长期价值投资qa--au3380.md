# QA — 大成高鑫刘旭长期价值投资

**来源日期：** 2024-06-27
**来源类型：** 晨星焦点基金系列 QA
**评级：** ⭐⭐⭐（量化数据可靠，持仓切换描述具体，但"深度研究"主张缺乏可验证的微观证据）

## 核心论点

大成高鑫年化 17.26%（前 1%）的超额收益，本质来自"深度研究+知行合一"的复利，而非风格押注或主题红利。

## 关键数据

| 指标 | 数值 |
|------|------|
| 管理起始 | 2015年7月 |
| 年化回报 | 17.26% |
| 超越基准 | 16.92%（沪深300） |
| 同类排名 | 大盘平衡股票型基金前 1% |
| 管理规模 | 216亿元（来源时点） |
| 前十大持仓占比 | 50%–80% |
| 完整超基准年度数 | 9个 |

## Q1：如何判断"好公司"？

**形式化框架：**

```
好公司 = ROA/自由现金流初筛
        + 商业模式差异化（能提供不一样的产品/服务）
        + 经营能力强
        + 发展空间大
        + 安全边际高
        → 预期收益率 ≥ 10%
```

- 财务初筛：用ROA、自由现金流等排除基本面差的公司，快速缩小范围
- 商业模式：要求企业能提供差异化产品和服务
- 安全边际：从资本周期和估值角度衡量，要求行业惨淡、盈利能力低位、估值便宜
- 预期收益率：结合成长性和分红收益率，要求 10% 以上

**边界条件：** 新兴行业（如早期互联网）财务指标可能不适用；市场持续高估时严格执行安全边际会错过机会。

## Q2：为何对成长股和价值股无特别偏好？

**决策逻辑：**

```
成长股 vs 价值股
→ 同一维度比较（预期收益率 + 确定性）
→ 性价比更高者配置更多
→ 风格随市场变化灵活调整
```

- 2021年前：偏成长（家电、电子、电力设备）
- 2022年底后：偏价值（通信、石油石化、家电）
- 业绩归因：在成长股和价值股投资上均展现超额收益，说明不是押注单一风格

**边界条件：** 极端风格分化时不偏好成长会错失机会；判断错误会拖累业绩。

## Q3：为何持股集中度能长期维持 50%–80%？

**逻辑链：**

```
集中持股（50%–80%）
← 风险控制依赖个股安全边际（非行业分散）
→ 深度研究 + 高确定性
→ 敢于重仓
```

- 前十大重仓股权重长期维持在 50% 以上，最高达 80%
- 风险控制方式：通过对个股安全边际的把握控制组合风险，而非传统行业分散
- 对研究深入的个股给予高权重，对不确定的个股给予低权重

**边界条件：** 重仓股基本面恶化时集中持股放大风险；流动性不足时调仓成本高。

## Q4：为何从主题基金转型为全市场基金？

**制度演进：**

```
主题基金（仅限高新技术产业）
→ 选股范围受限
→ 转型全市场基金（2017年）
→ 选股能力最大化发挥
→ 年化 17.26%（前 1%）
```

- 原为"大成高新技术产业股票"，刘旭的选股能力不限于制造业
- 在通信、石油石化、家电等行业也展现超额收益
- 主题基金在行业表现不佳时只能被动持有，全市场基金可以主动规避
- 转型后（2017年以来）投资策略保持稳定，业绩持续优秀

**边界条件：** 极端行业分化时全市场基金会稀释收益；能力圈拓展不及预期反而降低胜率。

## Q5：为何能做到知行合一且框架稳定？

**形式化表达：**

```
知行合一 = 基本面研究导向
         + 独立判断（不完全依赖团队）
         + 深度跟踪个股
         + 稳定的投资方法（2017年至今）
```

- 刘旭是制造业研究员出身，对个股有深刻理解
- 相对依赖自己而非投研团队，有独立思考能力
- 2017年以来投资方法保持相对稳定，框架成熟
- 9个完整年度均超越同类平均和基准，框架有效

**边界条件：** 管理规模过大（216亿元）可能限制独立研究能力；核心研究员离职会影响研究支持。

## 反直觉结论

集中持股 + 长期持有 + 独立判断，比分散投资 + 频繁交易更有效——刘旭的 17.26% 年化回报，本质是"深度研究+知行合一"的复利。

## 关键张力

1. **"深度研究+独立判断" vs "216亿规模"**：大规模下个人深度研究的可扩展性存疑，这是来源自身也承认的边界条件。
2. **风格中性 vs 集中持股**：风格中性要求广泛覆盖，集中持股要求高度聚焦——来源暗示通过"个股确定性"桥接，但未展开论证。
