# 降息环境怎么选基金 — QA

晨星中国分析，全球降息周期下中国利率持续下行：LPR从4.15%降至3.1%，7天逆回购从2.5%降至1.5%，货币基金收益从2.7%降至1.5%。2024年12月货币政策从"稳健"转向"适度宽松"。在低利率环境下，纯债收益被压缩，固收+和高质量权益基金的弹性溢价更具价值。

## 核心结论

**利率越低，纯债越薄，固收+和高质量权益的"弹性溢价"越值钱。**

## 七大问题总结

### Q1: 降息为什么让货币基金收益下降？

央行降息直接拉低短端利率，货币市场基金主要投资于短期利率工具，收益率随政策利率同步下行。

```
央行降息 → 市场利率下行 → 短债收益率下降 → 货币基金收益缩窄
```

2024年货币基金平均7日年化从2.7%降至约1.5%，部分产品跌破0.8%。边界条件：若央行转向加息，货币基金收益会迅速回升。

### Q2: 货币基金收益下降为何规模反而增长？

权益市场波动加剧，低风险偏好驱动资金涌入货基避险，2024年净流入超2.1万亿，逼近14万亿规模。这是典型的**避险效应**——资金追求的不是收益而是安全。

```
收益下降 ≠ 规模萎缩 → 波动环境中安全性溢价 → 规模逆势增长
```

资管新规后银行理财波动加大，货币基金的低波动高流动性优势凸显。边界条件：若权益市场走牛或货币基金收益跌破0.5%，资金可能大幅流出。

### Q3: 固收+基金为何在低利率环境有优势？

纯债基金在利率下行初期有资本利得，但进入低位后空间收窄；固收+以债券打底赚票息、少量股票或可转债增厚收益，提供更有竞争力的回报弹性。

```
纯债(票息↓) ⊂ 固收+(票息+权益↑) → 固收+收益 > 纯债收益
```

边界条件：若股市大跌，固收+的回撤也会大于纯债，不是无风险替代。

### Q4: 易方达稳健收益债券基金的核心优势？

该基金利率债配置可达50%、久期调整范围1-6年，比同类上限4年更灵活，在降息周期能更充分把握资本利得。

| 维度 | 易方达稳健收益 | 同类平均 |
|------|--------------|---------|
| 久期调整范围 | 1-6年 | ≤4年 |
| 利率债配置上限 | 50% | 较低 |
| 股票仓位上限 | 20% | 类似 |
| 可转债上限 | 30% | 类似 |

边界条件：若利率反转上行，长久期会变成拖累，资本利得变资本损失。

### Q5: 工银创新动力股票基金为何适合降息环境？

大盘价值风格，低估值+高质量选股，在波动市场中防御性强。2022年熊市仅跌-2.79%（同类基准-15.46%）。

```
低估值 × 高质量 × 管理层诚信 → 下行保护 > 同类平均
```

大盘价值风格在紧缩后期和复苏初期表现更稳。边界条件：若市场风格切向成长或高估值占优，大盘价值会跑输。

### Q6: 国投瑞银瑞利灵活配置的核心策略？

基于**性价比择时框架**：通过估值×景气度×确定性三维度判断股票仓位，极端行情可降仓至50%以下，控制回撤。

```
性价比(估值×景气度×确定性) → 正常70-80%仓位 → 极端降至50%+ → 回撤可控
```

2021年底和2022年初均前瞻降仓控制回撤。边界条件：若判断失误提前降仓，可能踏空上涨行情。

### Q7: 低利率环境下投资者应怎么配置？

**分层配置公式**：

```
短钱(货币基金流动性) + 中钱(固收+弹性) + 长钱(质量成长/灵活配置) → 分层配置
```

| 资金期限 | 配置工具 | 核心功能 |
|---------|---------|---------|
| 短钱（随时可用） | 货币基金 | 流动性管理 |
| 中钱（半年-2年） | 固收+ | 票息+权益弹性 |
| 长钱（2年以上） | 质量成长/灵活配置 | 长期增值 |

配置比例因人而异：年轻人可偏向长钱，老年人偏向短钱和中钱。
