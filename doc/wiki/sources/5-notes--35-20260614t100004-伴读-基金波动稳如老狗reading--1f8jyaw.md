# 伴读：如何在基金波动时内心"稳如老狗"？

**原文**：[晨星中国](https://www.morningstar.cn/articles/0a1d1638d54f542b2e7d62adb0c66d52.html)
**发布日期**：2023-09-15

## 一句话摘要

克服投资恐惧的关键不是"心态好"，而是**提前理解你持有的基金有多少风险、在最坏情况下会亏多少**——风险可知，恐惧可控。

## 核心论点

恐惧来源于不了解，而非心理素质差。把基金风险了解透彻，提前做好风险管理，就算基金波动，内心也能少些波澜。

## 三个维度评估持仓风险

### 1. 投资风格风险

使用[[晨星投资风格箱]]快速判断基金风格：大盘比中小盘稳健，价值风格比成长风格波动低。风格没有好坏，但波动有大小。

> **关键提醒**：保守型投资者买中小盘成长基金，波动时恐惧是"合理的"——因为你买了不适合你的东西。

### 2. 行业风险

行业基金波动高于全市场基金，A股结构性行情下行业冷暖交替频繁。投资者应避免多只基金配置相同行业。

> **参照系注意**：行业基金应与同类行业指数对比，不应与市场宽基指数（如[[沪深300指数]]）比较。

### 3. 个股集中度风险

持仓集中投资于较少公司的基金风险更高，取决于基金经理的投资理念和对选股的信心程度。

## 三个指标衡量业绩风险

| 指标 | 回答的问题 | 递进关系 |
|------|-----------|---------|
| **标准差** | 波动大不大？ | 总波动率，最基础 |
| **下行风险** | 向下波动大不大？ | 只考虑亏损，与[[索提诺比率]]相关 |
| **最大回撤** | 最惨能惨到哪？ | 心理预期建立，最实用 |

对普通投资者，**最大回撤**是最实用的指标——直接告诉你最差情况下会亏多少，帮助建立心理预期，避免底部恐慌性卖出。

> 这些指标应与同类平均或市场基准相比才有意义。

## 风险调整后收益：风险不一定是坏的

风险本身不可怕，可怕的是承担了风险却没得到补偿。判断"性价比"的两个指标：

- **夏普比率**（Sharpe Ratio）：每单位风险获得的超额收益，越高越好
- **晨星风险调整后收益**：晨星自创指标，对下行波动惩罚更重，更贴近投资者真实体验

[[晨星星级评价]]即基于风险调整后收益对基金进行排名。

## 星级评价的三个注意事项

1. **星级是定量的**，反映过往业绩，不预测未来
2. **评级针对基金产品，未反映基金经理变化**——五星基金换了基金经理后，五星评级可能不再适用，这是高频认知盲区
3. **只适用于同类基金间比较**，跨类别星级比较是常见误用

参见 [[晨星星级评价]]。

## 全文逻辑链

```
恐惧 → 不了解风险（认知问题）
  ↓
三个维度评估持仓风险（风格→行业→个股集中度）
  ↓
三个指标衡量业绩风险（标准差→下行风险→最大回撤）
  ↓
风险调整收益判断"性价比"（夏普比率/晨星风险调整后收益）
  ↓
星级评价辅助选择（注意三项局限）
```

## 终局问题

你目前持有的基金，你知道它的最大回撤是多少吗？这个数字和你对它的"恐惧程度"是否匹配？
