## 主要论点与发现

**核心论点：建议观察，不建议追高。** 底层纳指100值得长期配置，但当前纳斯达克QDII入口拥挤、限购严重、场内溢价高。

**分层论证结构：**

1. **两层价格框架**：QDII有两层价格——底层纳指100贵不贵 + 通道税（限购、溢价、费用、汇率摩擦）。最危险的误解是把"纳指100是好资产"推成"所有纳指QDII都值得买"。

2. **秩序创造机器判定**：
   - 底层纳指100是成熟的秩序筛选机器（飞轮在转、冲击后变强、资源被引力拉来）
   - QDII通道是秩序搬运器（无飞轮、冲击时缩窄而非变强、供给受额度刚性约束）
   - 关键洞见：**通道在拥挤时会把好资产变成坏交易**

3. **闸门经济的形成机制**（链条式推理）：
   ```
   居民海外配置需求上升 → QDII额度供给刚性 → 场外限购/暂停申购
   → 资金转向场内ETF → 场内溢价上升 → 套利因额度限制失效 → 溢价继续维持或扩大
   ```
   这是"闸门经济，不是资产便宜"。

4. **两条不同步的S曲线**：
   - 纳指100：成熟平台上的AI再加速期，滚动PE 35-38倍 vs 长期中位数24-25倍
   - QDII通道：从"可用工具"进入"稀缺入口"期
   - 买QDII等于同时买两件东西：不便宜的指数 + 拥挤的入口

5. **认知差定位**：普通人以为在买美国科技，实际同时在买美国科技、人民币汇率、QDII额度稀缺、二级市场情绪四样东西。

6. **可操作的决策规则**：
   - 溢价纪律：>3%谨慎，>5%回避，>10%不碰
   - 仓位纪律：初始5%-10%，已有科技敞口则不重复堆仓
   - 场外纪律：每日10/100/200元限额当作微型定投，不是建仓工具
   - 时间纪律：不用短期钱买，接受30%-50%回撤

7. **五组核心假设-退出信号对**（已在源中以表格呈现，保留原文结构）：

| 核心假设 | 退出或降仓信号 |
|---|---|
| AI资本开支会转化为头部科技公司的收入和自由现金流 | 云厂商和AI公司资本开支继续上升，但收入增速、利润率、自由现金流连续不达预期 |
| 纳指100指数机制能持续筛出赢家 | 指数高度集中于旧赢家，新技术赢家无法进入或权重长期不足 |
| QDII仍是可用的配置通道 | 限购长期停留在10元/100元级别，或者申购长期暂停，导致再平衡失效 |
| 场内价格能围绕净值运行 | 溢价持续超过5%-10%，套利机制迟迟不能恢复 |
| 个人组合需要美元科技暴露 | 已有美股、港股科技、中概互联网、AI主题基金合计占比过高 |

**证据强度**：中等偏强。使用了公开市场数据（PE估值、额度数据）、产品事实（限购状态、费率）、逻辑推理（闸门经济链条）。缺少的是独立的第三方验证和回测数据。
