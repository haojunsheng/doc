### Main Arguments & Findings

**核心论点：阿尔法是一个自我毁灭的概念——一旦某种超额收益被广泛认知，它就变成贝塔的一部分。**

1. **现象引入**：A股主动权益基金近期战胜率回升至 28%（相对沪深300），引发"阿尔法回来了"的疑问。但作者先质疑：阿尔法到底是什么意思？

2. **历史演化链**（有强证据支持）：
   - 1967 年：詹森提出阿尔法 = 基金收益对市场的回归截距
   - 1992 年：Fama-French 三因子模型，引入 SMB（规模）和 HML（价值），大量"阿尔法"被重新归类为因子暴露
   - 2010 年代：动量、股息、低波动等因子被发现，阿尔法边界持续收缩
   - 今天：晨星的定义 → 阿尔法 = "当前任何因子模型都无法解释的决策"

3. **2025年初主动基金跑赢指数 ≠ 能力回归**（中等强度证据）：
   - A股主动基金 70% 以上是成长风格配置
   - 2025年初成长风格回归 → 自然推高这些基金的业绩
   - 这更像是"顺风收益"而非"主动管理能力提升"

4. **关键公式**：
```
詹森阿尔法：α = Rp - [Rf + β(Rm - Rf)]
Fama-French 三因子：Rp = α + β1(Rm) + β2(SMB) + β3(HML) + ε
```

**证据强度评估**：论点 1 和 3 有强证据（历史脉络清晰、逻辑自洽）；论点 2 中等（方向性解释合理，但无法完全排除部分基金经理能力改善的可能性）。
