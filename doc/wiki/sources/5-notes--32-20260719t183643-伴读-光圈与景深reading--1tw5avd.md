# 伴读：03 | 光圈与景深——拍照片可以不对焦？

> 来源课程：极客时间《摄影入门课》第 3 讲「光圈与景深：拍照片可以不对焦？」

## 一句话摘要

光圈不只是控制明暗的光孔大小，更是控制画面叙事范围（景深）的工具；掌握**景深陷阱**就能让对焦从"障碍"变成"预设"，在决定性瞬间手起刀落。

## 核心论点

### 一、光圈的双重功能

光圈同时控制两个变量——进光量（F 值↔亮度，负相关）和景深（F 值↔景深，正相关）。读者普遍不知道这两件事是同源的。

### 二、F 值是反直觉的比值标签

"F 值小 = 大光圈"是全文第一道硬门槛。认知模式提炼：当一个比值被当作标签使用时，分母越大数值越小，但"实际效果"方向跟数值方向相反。

### 三、虚化不是"删除背景"而是"构造色块"

虚化区域不是无用信息的垃圾桶，而是画面的构图材料；川内伦子的作品是这一立场的最佳反例。

### 四、景深陷阱 = 对焦动作的取消

"再快的自动对焦，也没有不对焦快"——零是最高速度。景深陷阱的本质是提前把容差配置好，在拍摄时跳过对焦步骤，把注意力从操作层解放到观察层。

### 五、技术选择背后是美学/伦理立场

小光圈用于纪实（"该拍到的东西一定要都拍到"是伦理责任）；大光圈用于人像/广告（叙事需要聚焦主体）。

## 关键数据点

- **50mm / F4 / 1.5m 拍摄距离** → 清晰范围 1.4m–1.6m（20cm，一支铅笔长度）
- **前景深 : 后景深 ≈ 1 : 2**，后方清晰距离约为前方两倍，偏前对焦是实用推论
- **28mm / F16 / 对焦点 1.5m** → 景深范围 0.8m–15m，覆盖超过 14 米
- **SONY α7R IV**：567 个相位对焦点，用作自动对焦速度的参照
