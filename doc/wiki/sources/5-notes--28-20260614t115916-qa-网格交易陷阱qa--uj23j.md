# QA：网格交易——赚小钱亏大钱的陷阱

**原文**：[晨星中国](https://www.morningstar.cn)
**标识符**：20260614T115916
**发布日期**：2026-06-14

## 一句话摘要

网格交易在震荡市里看似"省心神器"，但在单边上涨行情中系统性卖飞踏空——沪深300实测，10年收益仅为买入持有的一半。核心矛盾在于：网格的前提是"价格不涨"，而长期投资的前提是"资产向上"。

## 五个 Q&A 全览

### Q1：网格交易为什么在震荡市里能赚钱？

**结论**：利用价格来回波动——跌了就买，涨了就卖，反复赚差价。

**形式化**：

```
网格利润 = 每次低买高卖的差价 × 交易次数
```

机制：设定价格区间（如5-15元），每跌1元买入，每涨1元卖出。只要价格持续在区间内波动，就能反复收割差价，且规则自动执行，不受情绪干扰。

**边界**：策略前提是"价格在固定区间内波动"——一旦突破区间，策略失效。

### Q2：为什么网格交易在牛市里会"卖飞"？

**结论**：因为网格是"涨一格卖一格"，单边上涨行情里仓位越卖越少，最终空仓踏空。

**形式化**：

```
网格交易 + 单边上涨 = 仓位持续下降 → 踏空
```

**实证数据**（2019-2025年，沪深300ETF，10万元本金）：

| 策略 | 收益率 |
|------|--------|
| 网格交易（扣除成本后） | 41.89% |
| 买入持有 | 84.47% |

- 2021年 ETF 净值涨到5元以上（设定区间上限），按规则卖光所有仓位
- 之后市场继续上涨，但已空仓，复利节奏被打断

**边界**：若能准确判断"这是牛市"并暂停网格，可避免踏空——但判断牛市本身就需要择时能力。

### Q3：为什么网格交易的资金利用率低？

**结论**：需要预留资金"随时准备补仓"，这部分钱在上涨趋势中错失增值机会。

**形式化**：

```
网格资金 = 初始仓位 + 预留补仓资金
预留资金在牛市里 = 机会成本
```

举例：10万本金，5万建仓，5万留作补仓。若市场一直不跌，这5万完全闲置——它本可跟着上涨。

**边界**：如果市场持续下跌，预留资金有用武之地；但长期来看，市场螺旋向上。

### Q4：为什么"震荡市做网格，趋势市做长线"很难实现？

**结论**：震荡和趋势只能事后确认，事前判断 ≈ 猜。

**形式化**：

```
震荡 → 趋势转换点 = 事后可识别
事前判断 ≈ 猜
```

论证：
- 大多数时候，当你确认进入上涨趋势时，价格已涨了很多
- 判断错误的话（把震荡误判为趋势），暂停网格后价格下跌——又错失低吸机会
- 表面"无须择时"，实则需要判断震荡/趋势状态，对择时能力要求更高

**边界**：若有明确估值指标（如 PE 分位）辅助判断，可以降低不确定性——但这已不是"无脑网格"。

### Q5：网格交易的适用边界是什么？

**结论**：只适合短期震荡市套利；长期财富增值与网格前提存在根本矛盾。

**形式化**：

```
网格交易 = 短期套利工具
长期增值 = 买入持有优质资产
两者长期维度上互斥
```

**历史支撑数据**：沪深300全收益指数2005-2025年累计上涨581.15%，年化9.69%——买入持有远胜网格。

**边界**：若明确知道某资产会在固定区间波动（如某些 ETF、商品），网格可能有效——但这种确定性极少见。

## 收口

> 网格交易赚的是波动的钱，亏的是趋势的钱——而长期来看，趋势比波动更重要。
