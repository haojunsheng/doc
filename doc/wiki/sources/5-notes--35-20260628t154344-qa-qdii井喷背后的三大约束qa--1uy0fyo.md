# QA — QDII井喷背后的三大约束

**来源**：[[晨星中国]] 2025年Q1投资年度回顾——QDII篇

> **核心论点**：QDII井喷不是单纯的市场选择，而是"A股弱+海外强+额度卡脖子"三重约束下的被动结果——基金公司有产品发不出去，投资者有钱买不到份额，场内溢价成了常态。

## Q1 为什么QDII基金从2015年转正后，到2021年才真正爆发？

**结论**：2021年前A股收益不差，资金没有出海动力；2021年后A股转跌而海外暴涨，收益差才催生了配置需求。

**形式化**：2015-2020: A股还行 → QDII增长慢 | 2021+: 沪深300跌33.6% vs 标普500涨44.2% → QDII爆发

**数据**：
- 2015年QDII转正（此前连续7年净赎回）
- 2020年底：175只、1758亿规模
- 2024年中：298只、4977亿规模
- 2021-2024上半年资金净流入超3600亿
- 沪深300 2021年后跌幅：-33.6%
- 标普500同期涨幅：+44.2%

**边界条件**：如果A股重新走牛而海外转弱，QDII的资金流入会放缓甚至逆转。

## Q2 为什么行业股票基金是QDII中吸金最多的类别？

**结论**：2020年恒生科技和中概互联网指数暴涨50%+，投资者追涨买入，行业基金2021年来吸金2233亿。

**形式化**：2020: 恒生科技涨57% + 中概互联网涨50% → 2021: 资金涌入496亿 + 223亿

**数据**：
- 2021年两只追踪中概互联网指数的QDII合计吸引496亿
- 华夏恒生互联网科技业ETF(QDII) 2021年吸引223亿
- 2022年行业股票基金继续净流入641亿，尽管恒生科技指数已在下降

**边界条件**：行业主题投资的短期机会难把握，"时机不当的买入往往导致负的投资者回报"——追高者已被2022年后的回调惩罚。参见 [[择时的心理陷阱]]。

## Q3 为什么QDII额度卡住了基金公司的手脚？

**结论**：外汇额度审批自2020年后大幅放缓，基金公司想发产品、想接资金但没有额度。

**形式化**：QDII规模↑↑↑ + 额度↑缓慢 → 额度接近用尽 → 限购潮

**数据**：
- 截至2024年中累计批准1677.89亿美元（约1.2万亿人民币）
- 超过1/3的QDII基金处于限购状态
- "近年人民币汇率相对弱势，国家希望维持较强外汇管制，额度增幅缓慢"

**边界条件**：如果外管局大幅批QDII额度（如2020年那样），限购会缓解但汇率压力会增加。

## Q4 QDII限购为什么会导致场内溢价？

**结论**：场外申购暂停后，投资者只能场内买入，供需失衡推高交易价格相对净值的溢价。

**形式化**：额度用尽 → 场外申购暂停 → 只能场内买 → 供需失衡 → 溢价率↑

**机制**：
1. 外汇额度用尽，基金公司暂停场外申购
2. 投资者只能场内交易
3. 供需不平衡推高溢价
4. 多家基金公司和券商发布溢价风险提示

**边界条件**：若QDII基金折价而非溢价（如海外市场恐慌性抛售），场内持有者会面临"净值跌+折价扩大"的双重损失。参见 [[ETF溢价陷阱]]。

## Q5 为什么QDII市场指数基金占压倒性多数？

**结论**：发达市场主动基金难以战胜指数，加上基金公司海外投研资源有限，指数基金是性价比最高的出海方式。

**形式化**：发达市场: 主动基金难赢指数 + 海外投研资源有限 → 指数基金占优

**数据**：
- 2021-2024上半年发行的146只QDII中126只是股票型
- 其中113只被动指数基金，占比89.7%
- "对于投资区域为发达市场的产品，主动管理基金通常难以战胜相应指数"
- 发行指数基金"可以减轻在海外投研的资源投入"

**边界条件**：在新兴市场或特定行业（如港股主动选股），主动基金可能有超额收益，指数基金不一定是最优选择。

## 核心框架：QDII三重约束

| 约束维度 | 表现 | 后果 |
|---------|------|------|
| 额度约束 | 1677.89亿美元总额度接近用尽，1/3+基金限购 | 基金公司手脚被卡 |
| 收益差驱动 | 沪深300跌33.6% vs 标普500涨44.2% | 被动出海需求爆发 |
| 场内溢价传导 | 场外暂停→场内供需失衡 | 投资者溢价买入，侵蚀回报 |

**收口**：QDII爆发式增长，但额度卡住了脖子。这不是主动出海的理性配置，而是A股弱、海外强、额度卡脖子三重约束下的被动结果。
