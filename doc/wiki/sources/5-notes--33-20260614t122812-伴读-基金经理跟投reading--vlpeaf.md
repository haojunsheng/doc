# 伴读：那些基金经理自掏腰包买入的基金，长期业绩会更好吗？

**原文**：[晨星中国](https://www.morningstar.cn/articles/b6ec14fe774c6b08bdb0d30840a9a1d3.html)
**伴读日期**：2026-06-14 Sun 12:28

## 一句话摘要

基金经理跟投自己管理的基金确实与持有人利益更绑定，历史数据也显示跟投金额越大中长期跑赢概率越高——但这个指标不是"闭眼买入"的理由，因为动机强不等于能力强，而且基金适合基金经理不等于适合你。

## 历史趋势数据

| 维度 | 2016年 | 2025年 |
|------|--------|--------|
| 全市场自持比例 | <5% | 46% |
| 货币型基金自持比例 | 12% | — |
| 股票型基金自持比例 | 0.98% | >30% |
| 混合型基金自持比例 | 1.74% | >60% |
| 大额自持（>100万份） | 极少 | 超800只 |

自持比例从十年前约5%升至如今46%，大规模自持（100万份以上）在混合型基金中尤为突出。

## 核心数据：跟投金额与业绩关系

晨星2016-2025年非货币基金统计：

| 自持档位 | 3年跑赢同类概率 | 5年跑赢概率 |
|---------|-------------|-----------|
| 无自持 | 45.36% | 43.25% |
| 持有>10万份 | 47%-54% | ~50% |

**关键解读**：
- 跟投金额越大，中长期跑赢概率越高，数据结论清晰
- 但50%左右的胜率仅比随机略高，信号强度有限，属于"微弱优势"而非"压倒性优势"
- 晨星分类已扣除风格和市场因素影响，超额来自同一赛道内的更好操作

→ [[基金经理自持]] · [[投资者回报差距]]

## 两个常见误解的破解

### 反驳一：动机强 ≠ 做得好

基金经理希望做好业绩、获得市场认可，这是其职业激励的主要来源——即使没有自持，他们也有很强的动力。基金经理财富增值主要来自职业成长（成为明星基金经理），而非跟投收益本身。"越想赚钱就越能赚钱"没有必然逻辑。

自持的真正价值不在于"让基金经理更有动力"（他本来就有动力），而在于**让基金经理在亏损时和你一样痛**。这被称为"共痛效应"——改变的不是基金经理的上限（他本来就想做好），而是下限（他不能太随便）。

→ [[共痛效应]]

### 反驳二：没自持 ≠ 基金不好

基金经理未自持，可能出于个人财务阶段、风险偏好不匹配等理性原因。例如：
- 30岁的债券基金经理可能不适合把大笔钱放进短期债基
- 保守型基金经理可能不适合重仓行业基金

基金是标准化产品，与基金经理个人的资产配置需求无关。一个优秀的基金经理可能管理着不适合他自己的产品——就像一个优秀的外科医生，不一定能给自己做手术。

对投资者同样适用：**基金经理重仓 ≠ 适合你**。

→ [[策略适配性]]

## 正确使用框架

```
选基 = 基本面（投资范围/风格/持仓/风控/市场表现/组合角色） + 自持（加分项）
```

| 情形 | 处理 |
|------|------|
| 自持缺失 | 需警惕，进一步审视 |
| 有自持 | 仍需验证其他维度 |
| 自持金额变化 | 值得关注（增持为正信号，减持为负信号） |

**核心原则**：自持是加分项而非决策项。选基核心仍是匹配自身风险承受能力和财务目标，并在组合中明确该基金应发挥的作用。

## 终局问题：因果歧义

如果跟投金额越大业绩越好的因果关系成立，那这个超额到底来自：

1. **绑定效应**：利益绑定带来更审慎的操作
2. **信心信号**：只有对自己策略最有信心的基金经理才敢大笔跟投

后者其实是"信心信号"而非"绑定效应"，对投资决策的含义完全不同——如果是信心信号，那么**跟投金额的变化（增持/减持）可能比自持状态本身更有预测力**。

→ [[自持超额来自绑定效应还是信心筛选]]

## 信号稀释悖论

自持比例从5%上升到46%，意味着利益绑定机制在强化，但信号稀缺性在衰减。当近乎全员自持时，该信号的边际信息价值显著下降，仅能作为辅助参考而非决策依据。

## 作者注疏总结

本文提供了一套平衡的基金经理自持评估框架：

1. **确认信号存在**：跟投金额越大，中长期跑赢概率越高——数据支持
2. **破除迷信**：动机强≠能力强，没自持≠基金差
3. **回到根本**：选基核心是基本面分析 + 个人适配性判断
4. **信任建立**：跟投只是信任的一个信号，不是信任本身

全文核心洞见：**自持是参考指标，而非决策依据——真金白银大于口头承诺，但仍需综合判断。**
