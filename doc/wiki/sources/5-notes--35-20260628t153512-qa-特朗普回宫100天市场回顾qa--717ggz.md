# 特朗普回宫100天市场回顾——十张图复盘"预期全错"的时期

> 原文：[晨星中国](https://www.morningstar.cn/articles/04012ffffb201465618e96f25a7d1738.html)
> 作者：屈辰晨
> QA日期：2026-06-28

## 核心叙事

特朗普2025年1月20日宣誓就职第二个任期，华尔街满怀期待牛市，结果100天内美股差点跌入熊市，美债不涨反跌，黄金飙升突破3400美元。文章用十张图复盘这段"预期全错"的时期，揭示关税政策如何重塑全球资产配置逻辑。

**元结论**：亲商的总统不等于利好的市场——当政策本身成了不确定性来源时，市场会给负分。

## 十大问题与结论

### Q1: 美股为什么差点跌入熊市？

- 2月中创历史新高，4月关税宣布后急转直下
- 标普最大回撤19.4%，距熊市（20%）仅0.6个百分点
- 68个交易日中10天涨跌幅≥2%，占比15%（2024年仅3%）
- 科技股调整叠加关税冲击是双重驱动

### Q2: 美债为什么不涨反跌？

- 正常逻辑：股市跌→买国债→收益率降
- 实际：关税推高通胀预期，晨星上调通胀预期0.6个百分点
- 30年期美债收益率4天飙升45bp，1990年以来仅出现3次
- 机构为应对赎回加速抛售，形成负反馈循环
- **关键机制**：关税→通胀预期↑→美债从避险资产变成抛售对象

### Q3: 黄金为什么能突破历史新高？

- 黄金同时对冲衰退、地缘政治和高通胀三重担忧
- 特朗普上任后这三类担忧同时上升
- 价格路径：2755美元 → 突破3400美元（+23%）
- **边界条件**：关税落地且衰退概率下降时，黄金避险溢价会收窄

### Q4: 比特币为什么也跌了？

- 特朗普自称"加密货币总统"，市场预期放松监管
- 但比特币与科技股风险属性高度相关
- 关税恐慌→风险资产抛售→比特币跟着跌（100天累计跌9%）
- 停战消息刺激反弹，但整体仍下跌
- **边界条件**：监管政策真正落地放松时，比特币会脱钩科技股走独立行情

### Q5: 关税能缩小美国贸易逆差吗？

- 不能。贸易逆差的根源是储蓄投资失衡，关税解决不了结构性问题
- 美国经常账户逆差自2020年起再度扩大
- 进口占GDP从1930年代的3.7%升至2024年的14%
- 关税只能改变进口来源，不增加国内储蓄
- **边界条件**：若关税配合大规模产业政策重塑制造业，长期逆差可能收窄

### Q6: 美股为什么在特朗普任内表现历届最差？

- 标普每日回报率分布为历任总统中最差
- 美股2025年开局在全球主要资产中表现垫底
- 其他发达国家股指普遍小涨，黄金大涨
- 投资者预期的"振兴经济"完全没兑现

### Q7: 经济衰退概率有多大？

- 晨星宏观团队预测未来12个月衰退概率40%
- 关税引发的供需双重冲击是主因：
  - 高关税推高物价 → 消费需求下降
  - 出口受阻 → 供给端产出下降
- GDP增长预测下调1.6个百分点
- 美联储2%通胀目标更难实现，滞胀风险上升

## 关键形式化框架

### 股债跷跷板脱钩

```
传统逻辑：股市跌 → 美债买盘↑ → 收益率↓（股债负相关）
关税冲击：关税 → 通胀预期↑ → 美债价格↓ → 收益率↑（跷跷板失效）
```

### 贸易逆差本质

```
贸易逆差根源 = 储蓄投资失衡 ⊃ 关税能解决的范围
→ 关税 ≠ 解药
```

### 衰退概率推导

```
关税 → 需求侧（物价↑消费↓）+ 供给侧（出口受阻产出↓）
→ GDP增长预测下调1.6个百分点 → 衰退概率40%
→ 滞胀风险上升
```

### 黄金三重对冲

```
衰退风险 + 地缘风险 + 通胀风险 → 黄金 2755→3400+美元 (+23%)
```
