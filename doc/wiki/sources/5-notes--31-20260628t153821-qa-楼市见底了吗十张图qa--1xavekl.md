# 楼市见底了吗——十张图

来源：晨星中国，2024年。

通过七张图（QA）回答"2024年楼市是否见底"的问题，核心结论是：**2024年是"需求见底、供应见顶"的底部区间，但见底≠马上涨**——信心修复和库存去化仍需时间。

## 核心论点

```
需求端 2024 见底 + 供应端 2024 见顶 → 底部区间
    ↓
"见底" ≠ "反转"，信心修复与库存去化仍需时间
```

## QA 链

### Q1: 需求端三个指标为何同时向下？
- **结论**：房价下跌→信心崩塌→观望加重，形成需求萎缩的负反馈。
- **形式化**：`房价↓ → 信心↓ → 观望↑ → 需求↓ → 房价↓↓`
- 一季度新房销售同比降 33%；仅 13% 受访者看好房价回升，18% 计划半年内买房。
- **边界**：若政策力度超预期（如大规模收储、一线城市全面松绑），信心修复可能加速。

### Q2: 房贷利率降了为何仍救不了需求？
- **结论**：利率降的是月供，收入预期不恢复，购房决策不会启动。
- **形式化**：`购房决策 = 月供负担 × 收入预期 → 利率↓ 但 收入预期↓↓ → 决策仍↓`
- 五年期 LPR 从 4.20% 降至 3.95%（25bp），取消首套二套利率下限，但 70%+ 仍观望。
- **边界**：若经济企稳、就业改善，利率杠杆才会生效。

### Q3: 期房为何被现房挤出？
- **结论**：交付不确定性打破"买期房等交楼"传统模式。
- **形式化**：`期房占比 78.9% → 69.3%，现房增速 >> 期房增速`
- **边界**：若政府强化预售资金监管、恢复交付信用，期房偏好可能回升。

### Q4: 三线城市为何成房价跌幅重灾区？
- **结论**：三线人口净流出+库存高+产业弱，供需失衡最严重。
- **形式化**：`三线 = 人口流出 + 库存高 + 就业弱 → 房价跌幅 >> 一二线`
- **边界**：若核心城市带动周边三线协同发展，跌幅可能收敛。

### Q5: 二手房为何"量涨价跌"？
- **结论**：挂牌量持续增加压制价格，政策利好只带动成交不带动定价权。
- **形式化**：`挂牌量↑↑ → 供过于求 → 价格↓，政策↑ → 成交↑ 但 挂牌量仍↑`
- **边界**：若挂牌量开始下降（房东惜售或退出），价格才有支撑。

### Q6: 住宅库存四万亿何时消化？
- **结论**：需求回暖+收储+以旧换新三管齐下，2024年去库存压力见顶。
- **形式化**：`待售住宅 4 万亿 → 去化手段(收储+以旧换新+租赁) → 2024年见顶`
- **边界**：若新房开工不能有效控制，新增供应会抵消去库存成果。

### Q7: 新房供应为何主动收缩？
- **结论**：土地储备缩减+销售回款慢，开发商无力也无意扩大开工。
- **形式化**：`销售↓ → 回款↓ → 拿地↓ → 新开工↓ → 供应收缩`
- **边界**：若政府大规模收储存量房、限制新增供地，供需关系改善可能加速。
