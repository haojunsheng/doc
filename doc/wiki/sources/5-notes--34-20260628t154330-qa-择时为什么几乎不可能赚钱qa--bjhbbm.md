# QA — 择时为什么几乎不可能赚钱

来源：[晨星中国](https://www.morningstar.cn/articles/55e0089b944d81101a8c6869f6d6c292.html)

## 核心结论

择时在绝大多数情况下无法为投资者创造正期望收益。完美择时与不择时的年化收益差距极小，而持有成本会完全吞噬微弱超额。真正决定长期回报的是建立能让投资者"长期在场"的资产配置结构。

## 林奇经典实验（美股 1965-1995，30 年）

```
三位投资者每年各投 1000 美元，连续 30 年：
  投资者 A（每年买最高点）:   10.6% 年化
  投资者 B（每年买最低点）:   11.7% 年化
  投资者 C（每年第一天买/定投）: 11.0% 年化

完美择时 vs 不择时定投：仅多赚 0.7%/年
完美择时 vs 最差择时：仅多赚 1.1%/年
```

## A 股回测数据（沪深300，2005-2024）

```
完美择时:  7.82%
定投（每年第一天）: 6.19%
择时超额: +1.64%

主动基金年均持有成本: ~2.2%
净效果: 择时亏损 -0.56%（被成本完全覆盖）
```

边界：指数基金持有成本远低于 2.2%，此时择时微弱超额可以覆盖成本。

## 择时四维成本分解

```
择时成本 = 交易费用 + 踏空风险 + 心理消耗 + 生活质量下降
```

其中最大成本不是亏损，而是"错过"——可能错过一整轮反弹的复利。

## 冯柳测算案例

```
胜率 70%，做对 4 次抵 3 次错
扣成本后实际只做对 3 次
最终仅回避 1-2 个百分点回撤
代价：可能错过牛市主升段
```

边界：极端高波动市场中，一次大踏空可能需要多年才能回本。

## Brinson 90% 归因的常见误解

Brinson 研究的原意是：投资收益 90% 来自长期资产配置（5-10 年以上），而非"在不同资产间高抛低吸"的短期择时操作。战略配置是建一个结构，不是做波段。

```
真实配置:  长期(5-10年+) + 比例稳定
误解的"配置": 短期 + 频繁切换
```

## 闪电理论（查尔斯·艾里斯比喻）

市场回报集中在极少数交易日。"闪电劈下来的时候你最好在场"——不在场就拿不到回报。资产配置帮你长期在场。巴菲特也表达过类似观点。

```
长期在场 → 不错过关键日 → 复利完整
频繁择时 → 可能缺席 → 收益残缺
```

边界：长期在场不等于全仓不动的单资产，而是分散后能扛住波动的结构。

## 战术配置的合理边界

在 3-5 年周期中出现极端情绪时，围绕战略中枢做小范围调整是有纪律的微调，而非有害择时。

```
战术配置 = 战略中枢 ± 小调整
触发条件: 极端高估/低估
事先规定触发条件和幅度
```

边界：如果"战术调整"已变成频繁交易，就退化为择时了。
