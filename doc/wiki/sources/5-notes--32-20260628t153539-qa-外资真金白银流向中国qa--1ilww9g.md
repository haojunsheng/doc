# QA — 外资真金白银流向中国

> 核心论点：外资舆论上"看好中国"，但2023-2024两年实际流出164亿美元，2024年Q4出现边际回暖——真实情况比简单"加仓/减仓"叙事更复杂。

## Q1: "中国资产"在外资语境下到底指什么？

**结论**：外资说的"中国资产"不只是A股，还包括美股、港股上市的中国企业，MSCI China指数A股仅占20%。

**形式化**：
```
中国资产 = A股(20%) + 中概股(80%) ⊂ MSCI China指数
```

**关键认知**：
- 外资用MSCI China做基准，该指数A股占比极低
- 历史上中国资本市场不开放，外资只能买境外上市的中国公司
- 这些公司营收主要来自中国，基本面与中国经济同频
- 若A股在MSCI权重持续提升，"中国资产"会更多指向A股

**边界条件**：A股在MSCI China的权重是动态演变的，当前20%为参考值。

## Q2: 外资2023-2024从中国主题基金撤了多少钱？

**结论**：两年累计净流出164亿美元，总规模从2532亿高点降至1765亿，缩水近30%。

**形式化**：
```
2532亿(高点) → 1765亿(2024底) = -164亿净流出 ≈ -30%缩量
```

**资金流数据**：
| 时间节点 | 规模 |
|---------|------|
| 高点（约2021年） | 2532亿美元 |
| 2024年末 | 1765亿美元 |
| 净流出 | -164亿美元 |

**驱动因素**：
- 2020-2021年中国资产表现好时资金持续流入
- 2022年还有逆势加仓，但2023-2024转为持续流出
- 被动基金主导了四季度的资金流向

**边界条件**：这是存量数据，不代表2025年继续流出，实际上Q4已有回流迹象。

## Q3: 外资2024年四季度为什么又"跑步入场"？

**结论**：中国股市大幅反弹，外资借道指数基金抄底，但高位又减持，同样追涨杀跌。

**形式化**：
```
市场反弹 → 被动基金抄底(10月流入) → 高位减持(11月流出) → 散户行为
```

**行为特征**：
- 10月和11月出现大幅资金流入和流出
- 被动基金是这两个月主导资金流向的主力
- 说明外资也并非长期价值投资者，同样会择时交易

**边界条件**：若反弹持续性不够快，外资可能再次快速撤离。

## Q4: 外资主动基金对中国股票态度有变化吗？

**结论**：2021年起大幅低配中国，但2023年9月起低配幅度收窄，态度边际回暖。

**形式化**：
```
低配扩大(2021→2023.9) → 低配收窄(2023.9→2024) → 态度边际改善
```

**数据要点**：
- 晨星环球股票基金相对MSCI ACWI基准持续低配中国
- 2023年9月是拐点，低配幅度开始减小
- 新兴市场基金也出现同样趋势

**边界条件**：低配收窄不等于高配，只是没之前那么不看好。

## Q5: 外资选什么工具投中国？

**结论**：被动指数取代主动基金成为首选，全球前五中国主题基金清一色是ETF。

**形式化**：
```
主动基金(2020主导) → 被动基金(现在主导) → 前5全是指数产品
```

**驱动逻辑**：
- 被动基金逐渐取代主动基金成为外资配置中国的主要通道
- 全球规模前五中国主题基金都是指数产品
- 与国内被动投资崛起趋势一致

**边界条件**：若A股有效性下降或出现持续超额收益机会，主动基金可能重新受宠。

## Q6: 外资持有中国股票最多的是哪三家？

**结论**：先锋864亿、贝莱德iShares 436亿、富达259亿美元，三家合计占大头。

**形式化**：
```
先锋(864亿) > 贝莱德(436亿) > 富达(259亿) ≈ 外资中国持仓主力
```

**数据明细**：
| 机构 | 规模 |
|------|------|
| 先锋 (Vanguard) | 864亿美元 |
| 贝莱德 (iShares) | 436亿美元 |
| 富达 (Fidelity) | 259亿美元 |

**统计边界**：仅统计了基金渠道，主权财富基金和直投未包含在内。

## 收口

外资嘴上看好中国，手上2023-2024净流出164亿，但2024年Q4出现回暖拐点——真金白银正在试探性回流。

---
**证据强度**：中等。数据来源为晨星文章，提供了清晰的资金流数据；但文章未提供主动基金低配的具体百分比、2023年9月拐点的量化幅度，亦未披露具体基金名称。属于描述性分析，而非学术研究。
