# QA — 东方红新动力选股策略：知行合一的复利

> 晨星焦点基金系列：东方红新动力灵活配置混合（000480），基金经理周云自2015年9月管理以来获得11.11%年化回报，超越基准沪深300（9.7%），同类排名前14%。

## 核心论点

东方红新动力的超额收益本质是"知行合一的复利"——清晰的框架 + 严格的纪律 + 持续的执行，而非追逐短期热点。

## 形式化框架

```
好公司 = 产品满足真实需求 + 商业模式好 + 竞争格局优
安全边际 = 估值低 + 周期底部买入
选股 = 好公司 ∩ 安全边际

知行合一 = 清晰框架（自下而上+安全边际+分散）
         + 持续反思（不断学习新机会）
         + 团队支持（投研文化好）
         + 策略稳定（2015-2025年核心策略未变）
```

## 业绩表现

| 指标 | 数值 |
|------|------|
| 年化回报 | 11.11% |
| 基准（沪深300）年化 | 9.7% |
| 同类排名 | 前14% |
| 管理规模 | 约137亿元（截至2024年6月） |

## Q1: 如何平衡"公司质地"和"安全边际"？

**结论**：两者缺一不可——质地决定长期价值，安全边际决定买入时机。

- **公司质地**：从产品需求稳定性、商业模式、竞争格局三个维度评估
- **安全边际**：要求估值相对较低，倾向在周期底部买入（左侧交易）
- **估值方法灵活**：不同行业采用不同策略（市值、PE+分红率、PB-ROE等）
- **边界条件**：新兴行业（如早期互联网）周期判断可能失效；牛市后期严格执行安全边际会错过机会

## Q2: 为什么组合从"大盘平衡"调整为"中盘平衡"？

**结论**：2022年优化了组合风险控制，通过增加持股数量、降低集中度来实现更好的分散。

### 风险控制参数调整（2022年前后对比）

| 指标 | 2022年前 | 2022年后 |
|------|---------|---------|
| 单一行业占比上限 | 20% | 15% |
| 前十大重仓股占比 | 45%+ | 30-40% |
| 持股数量 | ~30只 | ~40只 |
| 风格定位 | 大盘平衡 | 中盘平衡 |

- **逻辑链条**：中小盘估值修复行情（2021-2023）→ 中小盘相对收益更好 → 提升中小盘配置 → 组合风格自然下移
- **性价比比较决策**：将所有股票放在同一维度比较长期预期收益率、胜率、赔率，中小盘性价比更高
- **边界条件**：大盘占优行情（如2019-2020年）会拖累业绩；中小盘流动性不足时调仓成本增加

## Q3: "自下而上选股"如何体现在组合构建中？

**结论**：全市场范围内选取潜在回报率相对较高的好公司，对行业和个股保持相对均衡配置，不押注单一行业或主题。

- **选股方法**：从研究员覆盖范围出发，筛选潜在回报率高的公司，而非先选行业再选个股
- **组合特征**：单一行业占比降至15%以内，持股约40只，分散化是主动选择
- **业绩归因**：在科技、工业、原材料、医药、房地产、金融等行业均展现选股能力
- **边界条件**：极端行业分化行情中，均衡配置会稀释收益

## Q4: 为什么换手率能长期维持在100%左右？

**结论**：换手率100%说明每年将组合全部换仓一次，与"基于性价比比较"的动态调整逻辑一致。

- **卖出触发**：基本面发生较大变化 / 估值太高
- **买入触发**：基于长期预期收益率和胜率、赔率比较，发现更优标的时买入
- **稳定性**：换手率长期维持100%左右，说明策略稳定，不是随机交易
- **边界条件**：市场波动加剧导致频繁调仓时，换手率会上升，交易成本增加

## Q5: 投资框架为什么能做到"知行合一"？

**结论**：不断反思总结、研究团队支持到位、且策略具备可复制性——2015年9月以来核心策略保持稳定，仅在2022年优化风险控制。

- **策略稳定性**：近10年核心框架未变，仅2022年微调风险控制参数
- **反思特质**：周云勤奋且擅于反思总结，对组合持仓有清晰思路
- **团队支持**：东方红投研文化和制度安排为个股挖掘提供支持
- **边界条件**：管理规模137亿元下策略容量可能受限；核心团队成员离职会导致研究支持减弱

## 局限与注意事项

- **规模约束**：137亿元规模下，中盘股策略alpha生成能力可能受限
- **归因偏差**：将超额收益归因于"知行合一"可能忽略运气成分；A股近10年包含多次风格剧烈轮动，持续跑赢基准可能有部分运气因素
- **无风险调整后收益数据**：源文档缺少与同类基金的夏普比率等横向对比数据

# 性价比比较决策

## 定义

将所有候选股票放在同一维度，比较其长期预期收益率、胜率、赔率，从而在不同行业、不同市值之间做出跨标的的最优选择。这是连接选股与组合构建的核心决策机制。

## 形式化表达

```
性价比 = f(长期预期收益率, 胜率, 赔率)

选股决策 = argmax_{股票i} [性价比(股票i)]

买入触发 = 发现某股票性价比 > 当前持仓中最低性价比的股票
卖出触发 = 基本面发生重大变化 OR 估值显著高于历史分位
```

## 关键特征

- **跨行业可比性**：不同行业的企业在相同维度上比较，避免行业偏见
- **三维度框架**：
  - 长期预期收益率：企业未来现金流的折现价值估算
  - 胜率：该预期实现的概率（基本面确定性）
  - 赔率：预期收益与潜在亏损的比率
- **动态调整**：不长期持有不动，定期根据性价比变化调仓

## 实践案例：周云与东方红新动力

[[周云]]管理的[[东方红新动力]]（000480）采用性价比比较决策机制，将其与[[自下而上选股]]和[[安全边际]]相结合：

- 选股双维度：`好公司 ∩ 安全边际`
- 在所有候选股票中，基于长期预期收益率、胜率、赔率进行横向比较
- 2021-2023年中小盘相对收益更好，性价比比较结果驱动组合向中小盘倾斜
- 风格从中盘平衡自然形成，而非预设的行业配置

## 边界条件

- 如果市场出现极端行业分化（如某行业暴涨），均衡配置会稀释收益
- 如果选股能力下降，分散化反而会放大错误
- 小盘股流动性不足时，调仓成本可能侵蚀性价比优势

# 组合风险控制参数调整

## 定义

在保持核心投资策略不变的前提下，通过调整持股数量、集中度、行业占比等组合层面的参数来优化风险收益特征。这种调整是渐进式的，反映基金经理对策略容量和市场环境的理性响应。

## 核心参数

| 参数 | 描述 | 典型范围 |
|------|------|---------|
| 持股数量 | 组合中持有股票的只数 | 30-50只 |
| 集中度 | 前十大重仓股占总资产的比例 | 30%-50% |
| 单行业占比上限 | 单一行业的最大权重 | 15%-20% |

## 实践案例：东方红新动力的2022年调整

[[周云]]管理的[[东方红新动力]]（000480）在2022年进行了风险控制参数优化，是知行合一的典型体现——核心策略不变，仅在风险控制层面做渐进式调整：

### 参数变化对比

| 指标 | 2022年前 | 2022年后 | 变化方向 |
|------|---------|---------|---------|
| 单一行业占比上限 | 20% | 15% | 降低 |
| 前十大重仓股占比 | 45%+ | 30-40% | 降低 |
| 持股数量 | ~30只 | ~40只 | 增加 |
| 风格定位 | 大盘平衡 | 中盘平衡 | 风格下移 |

### 调整逻辑

- 增加持股数量 → 降低单一个股风险
- 降低集中度 → 减少黑天鹅事件冲击
- 降低行业占比上限 → 避免行业过度集中
- 风格下移 → 响应中小盘性价比更高的市场机会

## 渐进式调整 vs 策略漂移

| 维度 | 渐进式参数调整 | 策略漂移 |
|------|-------------|---------|
| 核心框架 | 保持不变 | 发生变化 |
| 调整动机 | 风险控制优化 | 追逐市场热点 |
| 可解释性 | 高（有明确参数记录） | 低（事后解释） |
| 持续时间 | 长期有效 | 短期效应 |

## 边界条件

- 参数调整需要在战略稳定性和战术灵活性之间取得平衡
- 过于频繁的参数调整可能被误读为策略漂移
- 调整后的参数需要持续监控有效性
