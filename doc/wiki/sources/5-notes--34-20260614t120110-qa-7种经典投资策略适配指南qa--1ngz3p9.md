## Main Arguments & Findings

### 核心论断

> **策略没有优劣之分，只有适合不适合。** 最适合的策略取决于投资者的资源、背景、经验、投资优势和风险承受能力。"你只能赚到你认知范围内的钱。"

### 七种策略层级结构（来源中的核心贡献）

```
| 层级   | 策略           | 核心公式                          | 适合人群                  |
|--------|---------------|----------------------------------|--------------------------|
| 入门   | 宽基指数投资   | 覆盖广 + 费率低 + 不择时 → 市场平均回报 | 新手、无时间盯盘者        |
| 进阶   | GARP           | 合理价格 × 持续增长                 | 有一定研究能力的投资者     |
| 进阶   | 护城河         | 持续竞争优势 × 低估值买入           | 愿意深入研究行业和个股者   |
| 进阶   | 低市盈率       | 买低估值等待价值回归               | 有逆向承受力的投资者       |
| 进阶   | 道狗           | 买入道指最差10只，逆向均值回归      | 有纪律性的逆向投资者       |
| 高阶   | 因子投资       | 量化知识 + 数据 + 工具             | 专业投资者/机构           |
| 高阶   | 套利策略       | 高速系统 + 低成本 + 高杠杆         | 专业机构                  |
```

### 适配公式

```
适配 = 策略 × 认知 × 能力
不适配 = 复杂策略 → 执行失败
```

### 证据强度评估

- 整体偏**科普性质**，适合建立全景认知地图
- 各策略均**无实证数据**支撑，无历史回测结果
- 引用权威背书（巴菲特、博格尔、晨星）但未展开论证
