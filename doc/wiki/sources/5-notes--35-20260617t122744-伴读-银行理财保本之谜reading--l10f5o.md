# 伴读：银行理财保本之谜

> 原文来源：[晨星中国](https://www.morningstar.cn/articles/3a4322a0ae16e66617960e46f34aee8c.html)

## 一句话摘要

银行理财的"安全感"来自底层资产（债券、现金）而非机构信用，资管新规打破刚兑后，银行理财与公募债基本质趋同，而后者在信息透明度上更胜一筹。

## 核心论点

### 1. 刚性兑付的本质

银行理财"保本保息"的专业叫法是**刚性兑付**。运作机制是：新产品募集的资金用来兑付老产品的本息，不是投资本身不亏，而是用后来者的钱给先来者兜底。

```
刚性兑付 = 新产品资金 → 兑付老产品本息
         = 庞氏结构，不是无风险
```

只要不断有新投资者加入，前面的人就能拿到钱；一旦后续资金续不上，系统性风险爆发。此外，刚兑本质上也制造了不公平的收益分配——同样把钱放一起投资，凭什么有人亏了可以拿别人的钱来补。

### 2. 资管新规打破刚兑

2018年《资管新规》颁布，要求金融机构不得承诺保本保收益，产品出现兑付困难时不得以任何形式垫资兑付。此后，"预期收益率"被"业绩比较基准"取代，银行理财"保本保息"成为历史。

### 3. 银行理财"低风险"的真正来源

银行理财的"低风险"不是因为银行机构安全，而是因为它主要投资债券、存单等固定收益类资产。

| 指标 | 数值 |
|------|------|
| 固定收益类产品占比 | 95% |
| 投向债券、存单、现金的比例 | 近 70% |

关键数据：
- 银行理财整体 3.2% 资产直接投公募基金
- 其中 75% 是债券型基金

这揭示了一个关键事实：银行理财与公募债基的底层资产高度重叠，风险来源相同——都是底层资产，而非发行机构的信用。

### 4. 为什么买银行理财不如买债基

两者底层资产相似，但公募基金的信息更透明、费用更清晰、业绩可比较。

```
银行理财 ≈ 债券基金（底层资产相似）
银行理财 = 黑箱（不透明）
公募基金 = 玻璃箱（透明）
```

公募基金的优势：
- 每日净值披露
- 定期季报、半年报
- 基金经理、持仓全公开
- 历史表现可追溯，业绩可横向比较

银行理财像"黑箱"，历史表现难查，业绩无法横向比较，投资者难以判断真实风险。

## 收口洞见

不要看产品形式，要看底层资产。在资管新规后，所有资管产品都是"风险自担"，投资者应该关注底层投向，而不是发行机构的名气。
