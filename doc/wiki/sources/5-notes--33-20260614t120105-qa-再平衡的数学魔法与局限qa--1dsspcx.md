# 再平衡的数学魔法与局限

> 来源：[[sources/5-notes--32-20260614t120105-qa-再平衡的数学魔法与局限qa--1dsspcx]]

## 核心论点

再平衡是"纪律"而非"魔法"——它的价值在于帮助投资者保持配置在预设轨道上，而非追求超额回报。

## Q1：再平衡的核心逻辑是什么？

**结论**：通过定期调整资产配置，实现"低买高卖"的纪律性操作。

再平衡 = 定期调整 → 卖出涨多的资产 + 买入跌多的资产 → 维持目标配置

核心是"不贪多、不冒进"的纪律。

**边界**：再平衡不等于频繁操作——过度再平衡会增加交易成本。

## Q2：再平衡的理论基础是什么？

**结论**：基于"均值回归"假设——资产价格长期会回归均值。

理论基础：均值回归 → 涨多的会跌，跌多的会涨 → 再平衡能捕捉这种回归

**边界**：均值回归不是必然——在趋势性市场中，再平衡可能失效。

## Q3：为什么再平衡在单边行情中效果不佳？

**结论**：在单边行情中，再平衡会降低资金利用效率。

单边行情逻辑：再平衡 → 过早卖出涨势资产 → 资金利用效率↓

- 在单边上涨行情中，再平衡会过早卖出涨势资产
- 在单边下跌行情中，再平衡会过早买入跌势资产
- 交易成本会不断侵蚀收益

**边界**：在震荡行情中，再平衡效果最好。

## Q4：再平衡的交易成本有多大？

**结论**：交易成本会不断侵蚀收益——每次再平衡都要付手续费。

交易成本构成：手续费 + 冲击成本 + 税收 → 再平衡净收益↓

**边界**：如果交易成本极低（如 ETF 内部再平衡），再平衡效果会更接近理论。

## Q5：再平衡最根本的意义是什么？

**结论**：不是提升回报，而是提供"纠错机制"——让组合不至于随市场波动失控。

再平衡 = 纠错机制；目标 = 保持配置在预设轨道上

帮助保持平稳投资心态，避免在市场涨跌中乱了阵脚。锚定合理配置区间，只在必要时再平衡。

**边界**：不追求频繁操作——过度再平衡反而有害。
