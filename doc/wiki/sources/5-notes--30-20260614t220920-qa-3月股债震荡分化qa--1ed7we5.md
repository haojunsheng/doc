# 2025年3月基金月报——股债震荡分化

> 2025年3月基金月报 | 晨星中国

## 核心结论

2025年3月，两会提出"稳住楼市股市"，但特朗普关税政策落地压制风险偏好。A股主要股指涨跌互现——上证指数涨0.45%，深证成指跌1.01%。债市受降准降息预期影响波动，中证全债指数跌0.50%，但信用债表现好于利率债。

**核心规律**：没有只涨不跌的资产，也没有只跌不涨的资产——分散配置才是应对分化的最好策略。

## 股市：大盘蓝筹占优，中小盘承压

两会首次将"稳住楼市股市"写入总体要求和政策取向，利好大盘蓝筹。同时特朗普关税政策临近落地，中小盘成长股对风险偏好更敏感。

**形式化表达**：
```
大盘（沪深300 -0.07%）> 中盘（中证500 -0.04%）> 小盘（中证1000 -0.70%）
```

- 31个行业中17个上涨、14个下跌
- 有色金属、家电、煤炭领涨（周期价值风格）
- 大盘蓝筹受益于政策对冲，中小盘受关税不确定性压制

**边界条件**：3月的政策驱动特征明显，不代表长期风格轮动方向。

## 债市：信用债独立行情，利率债承压

1年期AAA级信用债收益率下行15bp，AA级下行18bp；5年期AAA下行16bp，AA级下行62bp。同期利率债收益率整体上行（1年期+8bp，5年期+5bp，10年期+10bp）。央行4500亿元MLF操作呵护流动性，但市场担忧资金空转。

**形式化表达**：
```
信用债收益率下行 > 利率债收益率上行 → 信用债涨、利率债跌
```

- AA级5年期信用债收益率下行62bp（信用分层极端案例）
- 利率债基金整体承压（-0.08%）
- 信用债基金受益（+0.21%）

**边界条件**：信用债表现好于利率债的前提是信用风险不爆发——如果违约事件增加，信用债会跑输。

## 固收内部：久期与信用暴露决定分化方向

```
固收分化排序：
  信用债基金（+0.21%）> 短债（+0.20%）> 纯债（+0.11%）> 利率债（-0.08%）> 可转债（-0.73%）
```

- 利率债基金受国债收益率上行拖累
- 信用债基金受益于收益率下行+票息收入
- 可转债跟随A股下跌，表现最差
