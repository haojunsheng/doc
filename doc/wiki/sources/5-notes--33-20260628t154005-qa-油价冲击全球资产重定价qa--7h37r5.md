# 油价冲击全球资产重定价 QA

> 来源：[Morningstar 中国](https://www.morningstar.cn/articles/cc9c318b98dd90d84456615972c7d59e.html)

## 引子

伊朗冲突让油价一季度几乎翻倍，全球资产经历了一轮"预期修正"。但4月反弹让人产生幻觉——波动好像过去了。晨星季度报告提醒：如果地缘风险持续，一季度的剧本完全可能重演。核心问题：油价冲击对经济和资产定价的实际影响到底有多大？

## Q1：油价如何成为全球资产重定价的触发器？

**结论**：油价翻倍 → 通胀预期升温 → 利率将在更久保持高位 → 所有资产按新利率重新折现 → 杀估值。

**形式化传导链**：

```
油价翻倍 → 通胀↑ → 利率高位更久 → 折现率↑ → 资产价格↓
```

**实证锚点**：2月28日伊朗冲突爆发后全球股市普遍下跌，印证了这条传导链。

**边界条件**：前提是把油价上涨认定为"持续性的"——如果油价快速回落，传导链会中断。

## Q2：为什么是"杀估值"而不是"杀盈利"？

**结论**：冲击来自利率预期变化而非经济衰退，企业盈利未受直接影响，但未来现金流的折现率上升了。

**形式化**：

```
盈利不变 + 折现率↑ → 估值↓
对比：衰退 = 盈利↓ + 折现率↓（可能）
```

**证据**：全球GDP增长预计从3.3%放缓至2.8%，幅度温和；美国金融和信息技术行业受冲击最明显——这些行业估值对利率最敏感。

**边界条件**：如果油价持续高位导致企业融资成本大幅上升、投资萎缩，就会从"杀估值"转向"杀盈利"。

## Q3：黄金为什么没起到避险作用？

**结论**：黄金的避险叙事被趋势交易覆盖——动量资金主导了金价，当利率上行时，同一批资金反身卖出。

**机制对比**：

```
正常避险：恐慌 → 买黄金 → 金价↑
实际发生：利率↑ + 美元强 → 资金流出 → 金价↓
```

**背景**：2025年黄金创1979年以来最大涨幅，大量趋势交易和动量资金涌入，形成自我强化机制（涨→资金流入→更涨→更多资金）。3月10年期美债收益率上行+美元走强后，资金机制反向运转。

**边界条件**：黄金避险功能在地缘恐慌初期仍然有效——只有当金价完全被趋势交易主导时，避险属性才被覆盖。

## Q4：油价对经济的实际影响有多大？

**结论**：比想象中温和——但资产价格反应远比经济数据剧烈，定价驱动力是"预期"而非"实际数据"。

**IMF预测假设（布油均价）**：

| 布油价格 | GDP 影响 | 通胀影响 |
|---------|---------|---------|
| 85美元/桶 | -0.5个百分点 | +0.5个百分点 |
| 100美元/桶 | -1.0个百分点 | +1.5个百分点 |

**关键区分**：真正影响资产价格的不是经济影响本身，而是对货币政策的预期改变。

**边界条件**：IMF预测基于"油价不持续恶化"的假设——如果霍尔木兹海峡完全中断，影响会远超模型。

## Q5：为什么市场从"降息预期"变成了"加息预期"？

**结论**：油价推升通胀 → 央行需要更长时间维持高利率 → 甚至可能加息来锚定通胀预期。

**市场定价变化**：

| 时间 | 市场定价 |
|------|---------|
| 2025年12月 | 美联储降息0.5个百分点 |
| 2026年4月 | 不降息 / 加息 |

对英格兰银行和欧洲央行，市场甚至开始定价2026年加息。

**边界条件**：如果油价快速回落或经济出现衰退迹象，加息预期会迅速逆转——市场定价本身也是动态的。

## Q6：晨星与市场的利率路径判断有何分歧？

**结论**：晨星认为美联储2026年维持利率不变，2027-2028年累计降息1.25个百分点——比市场预期更乐观。

**形式化**：

```
市场：2026年不降息
晨星：2026年不动 → 2027-2028降息1.25% → 2029年10Y=3.25%
```

**晨星逻辑**：油价冲击是暂时的，通胀影响消退后降息会启动；中长期低利率仍是支持经济增长的重要条件。

**边界条件（关键）**：如果油价持续高位演变为能源驱动型通胀，晨星的降息路径就不会实现——久期会成为负担。

## Q7：三种情景下投资组合应如何应对？

**结论**：短暂冲击可控；中期中断要区分赢家和输家；持续高位则需减久期、警惕新兴市场主权债。

```
短暂冲击   → 持有不动
中期中断   → 分化：赢家 vs 输家（需选股）
持续高位   → 减久期 + 信用利差扩大 + 新兴市场两位数损失
```

**边界条件**：三种情景的划分依赖对地缘政治的判断——而地缘政治本身就是最难预测的变量。

## 收口

作者用一条清晰的传导链（油价→通胀→利率→资产价格）解释了全球市场一季度的重定价，并指出真正的风险不是经济影响本身，而是市场对此的预期已经发生根本性转变。

> ⚠️ 警惕：4月反弹让人产生幻觉——波动好像过去了。如果地缘风险持续，一季度的剧本完全可能重演。
