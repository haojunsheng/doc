# 美股9月回调是结束还是开始

来源：[[entities/晨星中国]] 美国团队分析，原发布于 Morningstar CN。

## 核心判断

2024年9月美股回调是**牛市中的板块轮动**，而非趋势反转的开端。四大宏观因素中仅增长放缓为逆风，其余三向均已反转。

## 四因素对比（2022 vs 2024）

| 维度 | 2022年 | 2024年 |
|------|--------|--------|
| 通胀 | 上升 | 下降，预计2025年回到2%目标 |
| 利率 | 上升（美联储加息7次，1.5%→4%+） | 即将进入下行通道（降息共识） |
| 经济增速 | 放缓 | 温和放缓（唯一逆风） |
| 政策方向 | 紧缩 | 转向宽松 |

**结论**：2022年全线利空 vs 2024年三利好一利空。

## 九月回调归因

- 2022.10→2024.7：科技板块涨幅54%，是大盘两倍多，贡献标普总收益的25.3%
- 2024年7月以来：科技股跌8.5%，整体市场仅跌1.6%
- 8月房地产指数涨5.37%（先涨7.5%），显示资金转向防御板块
- **性质**：科技股涨幅消化式主动轮动，非基本面恶化驱动

## 估值分布

| 类型 | 状态 | 评估 |
|------|------|------|
| 大盘股 | 溢价约4% | 吸引力偏弱 |
| 小盘股 | 折价最明显 | 最具估值吸引力 |
| 成长股整体 | 溢价约8% | 略高 |
| 价值股 | 低估 | 有吸引力 |

## 软着陆逻辑链

```
软着陆: 通胀↓ + 经济温和放缓
  → 央行停止加息、转向宽松预期形成
  → 缓解性反弹（股市）
  → 若后续经济数据验证软着陆，反弹演变为趋势性行情
```

晨星判断软着陆概率大于衰退。

## 边界条件

- 若通胀反弹 → 三利好框架瞬间坍塌
- 若科技股盈利大幅不及预期 → 轮动变全面下跌
- 若小盘股盈利波动放大 → 低估值变价值陷阱
- 若软着陆变硬着陆 → 缓解性反弹变恐慌抛售
