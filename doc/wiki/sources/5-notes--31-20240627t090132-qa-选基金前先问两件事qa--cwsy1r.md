# 选基金前先问两件事

> 出处：晨星中国，2024-06-27

## 核心论点

投资决策的先决问题是**时间维度**（钱能闲置多久）和**比例维度**（该投多少），而非标的选择本身。资产配置决定90%以上的风险收益特征。

## Q1 — 为什么投资决策要先问"钱能闲置多久"？

**结论：** 时间决定了你能承受多大波动，从而决定了该买什么。

**形式化：**
- 时间短 → 波动承受力低 → 买低风险资产
- 时间长 → 波动承受力高 → 买高收益资产

**依据：**
- "不可能三角"：高收益、低风险、高流动性最多满足两个
- 3-5年内要用的钱，优先考虑流动性和安全性
- 5年以上的钱可以牺牲安全性换更高收益

**边界条件：** 即使钱能闲置很久，如果你心理上扛不住波动，还是该选稳健的。

## Q2 — 股票持有多久亏钱的概率会大幅下降？

**结论：** 持有1年亏损概率约50%，持有5年降到25%，10年只有11%。

**形式化：**
| 持有期 | 亏损概率 |
|--------|---------|
| 1年    | ~50%    |
| 5年    | ~25%    |
| 10年   | ~11%    |

**依据：** 2005-2023年中国市场数据，亏损概率随投资周期拉长递减。时间越长，市场经历完整周期的概率越高，即使短期遭遇下行也有足够时间回本。

**边界条件：** 这是历史统计，如果经济陷入长期停滞（如日本），10年可能仍然亏损。

## Q3 — "种田"和"打猎"资产有什么区别？

**结论：** 种田资产求稳（核心持仓60%+），打猎资产博惊喜（卫星持仓小比例）。

**形式化：**
- 种田（核心60%+）：宽基指数 / 均衡基金 → 稳健长期收益
- 打猎（卫星）：行业 / 主题基金 → 高波动高预期回报

**边界条件：** 如果"打猎"仓位太高，组合整体风险会急剧上升，失去分散意义。

## Q4 — 为什么3-5只基金就够了？

**结论：** 分散效果来自资产类别多样化，不是数量堆砌。

**形式化：** 3-5只不同类基金 ≈ 充分分散 >> 20只同类基金

**具体建议：**
- 1只宽基 + 1只纯债 + 1只短债/货币基金
- 可选加1-2只行业基金

**边界条件：** 资金量很大（百万级以上）时，可适当增加产品数量以细化配置，但本文未给出具体阈值。

## Q5 — 为什么"选择大于努力"在投资里成立？

**结论：** 资产配置决定了90%以上的风险收益特征，选具体基金只是锦上添花。

**形式化：** 组合风险收益 ≈ f(资产配置) >> f(具体基金选择)

**边界条件：** 在相同配置框架内，优秀基金确实能创造超额收益，但差距远小于配置决策的影响。

## 收口

不是"买什么"，而是"这笔钱能放多久"和"该用多大比例去下注"——这两个问题想对了，后面的选择自然就清楚了。
