# 施罗德亚洲高息股债：股债混合博收益

晨星焦点基金系列 QA，分析施罗德亚洲高息股债基金的核心策略与投资逻辑。

## 核心策略

股债混合配置，以高收益债券打底获取票息收益，以股票增强收益弹性。

```
组合 = 高收益债券（票息收益） + 股票（资本增值） → 股债平衡
```

## 亚洲收益优势

亚洲高股息股票和高收益债券的票息率普遍高于发达市场，且亚洲经济增长前景更好。

```
亚洲收益优势 = 高股息率（股票） + 高票息率（债券） > 发达市场
```

## 风险提示

高收益伴随高风险——亚洲市场的波动性和信用风险也高于发达市场。股债混合需要精准的大类资产配置能力，配置错误时两边都可能亏钱。

## 适用人群

适合有亚洲配置需求、追求稳健收益的投资者。
