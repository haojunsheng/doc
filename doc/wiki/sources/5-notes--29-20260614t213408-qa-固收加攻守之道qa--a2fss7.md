# 固收+攻守之道：华泰保兴尊合 vs 光大保德信增利

> 【基金擂台赛】震荡市下固收+基金的攻守之道：华泰保兴尊合债券 VS 光大保德信增利收益债券
> 发布日期：2025-07-31

## 核心论点

同一策略大类（固收+）内，两只基金都以纯债打底、可转债增强，但因**产品定位**不同——一个追求绝对收益（低波动），一个追求相对收益（跑赢中证全债指数）——导致转债仓位、选券标准、久期杠杆均呈现系统性分化，在极端市场中被放大为完全不同的持有体验。

形式化表达：

```
华泰保兴 = 绝对收益导向 → 低波动 ≠ 光大保德信 = 相对收益导向 → 跑赢基准
```

## Q1: 最本质的策略分歧在哪里？

**结论**：产品定位——华泰保兴追求绝对收益（低波动），光大保德信追求相对收益（跑赢中证全债指数）。

**形式化**：`华泰保兴 = 绝对收益导向 → 低波动 ≠ 光大保德信 = 相对收益导向 → 跑赢基准`

**证据**：
- 2023年（权益熊市）华泰保兴更抗跌
- 2021年（牛市）光大保德信更亮眼

**边界条件**：单边牛市 → 相对收益导向弹性更大；单边熊市 → 绝对收益导向更抗跌。

## Q2: 为什么华泰保兴转债仓位更低且偏好低价高等级？

**结论**：低价高等级转债债底保护强、熊市抗跌，符合绝对收益定位。

**形式化**：

```
低价高等级转债 → 转股溢价率高 + 债底保护强 → 熊市回撤小
高价低等级转债 → 转股溢价率低 + 股性强      → 熊市回撤大
```

**实证对比**：

| 维度 | 华泰保兴尊合债券 | 光大保德信增利收益债券 |
|------|-----------------|---------------------|
| 产品定位 | 绝对收益（低波动） | 相对收益（跑赢中证全债） |
| 转债仓位中枢 | 25% | 30% |
| 选券偏好 | 低价高等级，偏债型为主 | 转股溢价率分位数择时 |
| 久期 | 1-3年（更短） | 1-3年 |
| 杠杆 | 灵活，最高132% | 稳定，平均约107% |
| 交易费用 | 0.39% | 0.31% |

**边界条件**：A股大牛市时，低价高等级转债弹性不足，华泰保兴会跑输光大保德信。

## Q3: 光大保德信的"转股溢价率分位数"策略怎么用？

**结论**：将转债按转股价值分为高/中/低三类，比较每类当前转股溢价率的历史分位数，大幅低于50%则超配，高于50%则低配。

**形式化**：

```
转债分类（高/中/低转股价值） × 转股溢价率历史分位数
→ 分位数 << 50%  → 超配（低估，均值回归预期）
→ 分位数 >> 50%  → 低配（高估，均值回归预期）
```

**逻辑**：核心思路是均值回归——某类转债溢价率远低于历史中位数，说明被市场过度悲观定价，未来有修复空间。

**边界条件**：转债市场大幅扩容导致历史分位参考意义下降；极端行情下"低估"可能持续很久。

## Q4: 纯债部分久期和杠杆有什么差异？

**结论**：华泰保兴短久期（1-3年）+ 杠杆灵活（最高132%），光大保德信久期稍长 + 杠杆稳定（107%）。

**形式化**：`华泰保兴 = 短久期 + 灵活杠杆（最高132%） ≠ 光大保德信 = 稍长久期 + 稳定杠杆（~107%）`

**边界条件**：利率大幅上行 → 短久期华泰保兴更抗跌；利率持续下行 → 长久期光大保德信弹性更大。

## Q5: 为什么两只基金波动性都低于同类平均？

**结论**：均未直接参与股票投资，仅通过可转债间接暴露权益风险，而可转债波动性低于股票。

**形式化**：`权益暴露（可转债间接） ≠ 权益暴露（股票直接） → 波动性（可转债） < 波动性（股票）`

**边界条件**：可转债市场系统性下跌（如2022年）时，转债增强型基金波动性也会大幅上升，"低波动"特性消失。

## Q6: 光大保德信费率为什么更低？

**结论**：交易费用 0.31%（光大）vs 0.39%（华泰），反映更长的持有周期和更低的换手率。

**形式化**：`光大保德信费率 < 华泰保兴费率 ← 交易费用（0.31% < 0.39%） → 换手率低 → 持有周期长`

## Q7: 选择框架：如何在这两类基金中做决策？

**结论**：决策框架是"市场环境 × 产品定位"。

**形式化**：`选择 = f(市场环境, 产品定位) → 熊市→华泰保兴（低波动+抗跌） ≠ 牛市→光大保德信（高弹性+亮眼）`

**选择矩阵**：

| 市场环境 | 更优选择 | 原因 |
|---------|---------|------|
| 熊市 | 华泰保兴尊合 | 绝对收益导向 + 低价高等级转债 → 回撤更小 |
| 牛市 | 光大保德信增利 | 相对收益导向 + 分位数择时 → 弹性更大 |
| 震荡市 | 两者差异微小 | 综合费率/夏普/回撤等指标辅助决策 |

**核心收口**：没有永远更好的基金，只有更适合当前市场的基金。
