# 美团投资跟踪工具总结

生成时间：2026-05-31 10:32

## 核心思路

美团不能只等财报。财报是滞后结果，前置信号分布在四类地方：

- 用户是否还在用美团；
- 抖音是否继续攻击到店；
- 闪购供给是否变厚；
- 机构是否上调或下调盈利预期。

最现实的组合是：

> QuestMobile 看人，蝉妈妈看抖音，博晓通看闪购，久谦看机构结论。

## 1. 用户心智 / App 流量

看美团、京东、淘宝、抖省省谁在抢用户时间。

| 工具 | 看什么 | 用途 |
|---|---|---|
| QuestMobile | MAU、DAU、使用频次、用户重叠、App 迁移 | 判断美团主站心智是否被淘宝闪购、京东、抖省省侵蚀 |
| 极光 | App 活跃、用户画像、行业报告 | 作为 QuestMobile 的辅助验证 |
| data.ai / Sensor Tower | App 下载、排名、海外数据 | 看 Keeta、抖省省、海外 App 趋势 |

最重要：QuestMobile。

对应问题：

- 美团主站用户有没有流失？
- 淘宝闪购和京东是否提高主站打开频次？
- 抖省省是否真正起量？
- 即时零售是否让用户从单一外卖迁移到综合消费入口？

## 2. 抖音到店 / 团购攻势

看抖音有没有继续"偷家"。

| 工具 | 看什么 | 用途 |
|---|---|---|
| 蝉妈妈 | 抖音本地生活团购、门店榜、达人榜、同城热力图、竞品门店 | 判断抖音在到店餐饮、酒旅、休闲娱乐的投入强度 |
| 灰豚数据 | 抖音直播、达人、短视频带货、品牌投放 | 观察本地生活达人探店和直播投放热度 |
| 飞瓜数据 | 抖音/快手内容、达人、直播数据 | 辅助看达人和内容投放 |

最重要：蝉妈妈。

对应问题：

- 抖音团购券是否仍明显比美团便宜？
- 同城商家是否继续找达人探店？
- 哪些城市和品类是抖音重点进攻方向？
- 抖音是追 GMV，还是开始追利润和商家变现？

## 3. 闪购 / 即时零售

看美团闪购是不是第二曲线。

| 工具 | 看什么 | 用途 |
|---|---|---|
| 博晓通 / BXTData | SKU、铺货、价格、缺货、前置仓、O2O 渠道 | 判断美团闪购供给是否变厚、价格是否有竞争力 |
| 品牌渠道监测工具 | 商品上架、价格秩序、区域覆盖 | 看品牌是否把即时零售当正式渠道 |
| 行业报告 / 商务部数据 | 即时零售市场规模、渗透率 | 判断行业是否仍高增长 |

最重要：博晓通 / BXTData。

对应问题：

- 美团闪购 SKU 是否变厚？
- 夜间药品、酒水、生鲜、便利店、3C 覆盖是否增强？
- 闪电仓/前置仓是否继续扩张？
- 美团闪购和淘宝闪购、京东秒送的价格差是否收敛？
- 闪购是否从烧钱 GMV 变成正单位经济？

## 4. 机构调研 / 专家纪要

看市场怎么提前修正预期。

| 工具 | 看什么 | 用途 |
|---|---|---|
| 久谦中台 | 专家电话会、渠道调研、纪要 | 最接近一站式机构跟踪 |
| 萝卜投研 | 券商研报聚合、纪要 | 看分析师怎么改盈利预测 |
| 慧博 | 研报库 | 查本地生活、即时零售、平台竞争专题 |
| Wind / Choice / Bloomberg | 财务、估值、一致预期、研报 | 看市场是否上调/下调预期 |

最重要：久谦中台。

对应问题：

- 核心本地商业亏损预期是否下修？
- 到店利润率是否守住？
- 闪购单均亏损是否收窄？
- 抖音、阿里、京东是否减少非理性投入？
- 分析师是否上调 2026/2027 调整净利润？

## 5. 免费 / 半免费资讯源

看战略动作和组织变化。

| 来源 | 看什么 |
|---|---|
| 36氪 | 抖音、美团、阿里、京东组织调整和业务动作 |
| 晚点 LatePost | 平台战略、人事、组织、补贴方向 |
| 界面 / 钛媒体 | 行业评论、商家侧反馈 |
| 网经社 / 100EC | 电商、本地生活平台资讯 |
| TechBuzz China | 中概互联网深度分析 |
| Momentum Works / The Low Down | 外卖、即时零售、平台战争英文分析 |

这些不是严格数据源，但对提前感知变化有用，尤其是组织调整、补贴方向、业务负责人变化。

## 最小跟踪组合

如果只想搭一个轻量系统：

1. QuestMobile：看用户心智。
2. 蝉妈妈：看抖音到店。
3. 博晓通 / BXTData：看美团闪购。
4. 久谦中台：看专家和券商怎么解读。

## 对应美团三根轴

| 美团变量 | 最该看的工具 |
|---|---|
| 外卖是否稳住 | QuestMobile + 久谦 + 券商纪要 |
| 到店是否被抖音打穿 | 蝉妈妈 + 灰豚 + 36氪/晚点 |
| 闪购是否跑通 | 博晓通/BXTData + QuestMobile + 研报 |
| 市场预期是否变化 | 久谦 + Wind/Choice/Bloomberg + 萝卜投研 |

## 使用方法：每周五问

每周只问五个问题：

1. 美团主站活跃和频次有没有继续承压？
2. 抖音团购券和达人投放有没有降温？
3. 美团闪购 SKU、价格和前置仓覆盖有没有增强？
4. 骑手和补贴成本是否有下降迹象？
5. 券商是否开始上调核心本地商业利润和年度调整净利润？

如果这五个问题多数转好，美团可能从修复交易进入估值重估；如果只有外卖亏损收窄，但到店和闪购没有证据，那仍只是 HK$90-110 的修复逻辑。

## 最后判断

没有真正的一站式原始数据工具。

最实际的办法是四屏组合：

- QuestMobile 看人；
- 蝉妈妈看抖音；
- 博晓通看闪购；
- 久谦看机构结论。

这四类信息拼起来，才接近财报前的美团观察仪表盘。
