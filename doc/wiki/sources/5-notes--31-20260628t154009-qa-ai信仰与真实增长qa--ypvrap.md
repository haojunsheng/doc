# AI信仰与真实增长

> AI技术进步是共识，但对经济影响的判断分歧巨大。信仰能推高股价，但能把GDP拉到多高？——晨星中国，2026-06-28

## 核心论断

AI技术进步是市场共识，但晨星引用《预测人工智能对经济影响》研究（覆盖560名经济学家、AI从业者、超级预测者）显示：**即便最乐观情景下，GDP增长预测也仅5.3%，无条件预测中位数仅2.5%**。技术为真 ≠ 投资为真。

## Q1: 为什么经济学家对AI的经济影响这么谨慎？

**结论**：他们认为技术扩散存在滞后性——电气化用了几十年才体现在生产率数据中，PC也花了近20年。

**形式化推导**：
```
技术突破(即时) → 经济体现(滞后数十年)
电气化(几十年) + PC(20年) + AI(?)
```

**关键证据**：
- 无条件预测下，2030年美国GDP增长中位数仅**2.5%**，与历史相当
- 经济学家对中度/快速AI进展概率判断高达**61%**，但GDP预测没有明显提高
- 地缘政治风险、能源约束不会因AI进步自动解决

**边界条件**：若AI的应用扩散速度远超历史任何技术（如软件复制边际成本为零），滞后性可能大幅缩短。

---

## Q2: AI从业者和经济学家的判断有什么关键差异？

**结论**：同一最乐观情景下，从业者预测GDP增长**5.3%** vs 经济学家**3.5%**，且经济学家预测劳动力参与率将降至**55%**。

**形式化推导**：
```
同一情景(GDP增长)：从业者(5.3%) >> 经济学家(3.5%)
劳动力参与率：经济学家预测↓至55%（隐含大规模失业）
```

**关键证据**：
- 从业者身处行业内部，看到的是技术应用的可能性
- 经济学家看到的是历史规律和结构性约束
- 经济学家更关注负面效应：劳动力参与率降至55%、最富10%家庭持有财富占比升至80%

**边界条件**：若AI替代就业的速度慢于预期（如新岗位创造抵消旧岗位消失），经济学家的悲观预测可能过于保守。

---

## Q3: 为什么公众对就业保障的支持率是经济学家的4倍？

**结论**：经济学家偏好有针对性的渐进式干预（技能培训、失业保险），公众偏好广泛干预（就业保障、全民基本收入），支持率差异达4倍。

**形式化推导**：
```
经济学家：技能培训+失业保险(渐进) vs 公众：就业保障+全民基本收入(广泛) → 分歧4倍
```

**关键证据**：
- 仅13.7%经济学家支持就业保障，公众支持率57.1%
- 两者对GDP和劳动力参与率的预测差异很小，但政策偏好差异巨大
- 说明：即便认识到同样的事实，不同群体的风险感受和诉求完全不同

**边界条件**：若AI导致大规模失业实际发生，经济学家可能转向支持更广泛干预措施。

---

## Q4: 生产力红利的滞后性对投资意味着什么？

**结论**：深度应用AI改善效率的非AI产业链公司，可能处于"市场未充分定价"阶段。

**形式化推导**：
```
直接AI产业链(光模块/算力) → 定价已满
间接应用AI提效的公司 → 可能未充分定价
```

**关键证据**：
- 通用技术的价值通常不会立刻反映到宏观数据
- 市场把注意力给了AI上游（光模块、算力租赁），但忽略了下游应用
- 深度应用AI改善商业模式的公司可能被低估

**边界条件**：若AI应用落地缓慢、或企业数字化基础薄弱，"未充分定价"可能长期无法兑现。

---

## Q5: "一致预期"为什么本身就是风险？

**结论**：当一个板块承载过多乐观预期，边际变化的影响会被放大——超预期空间小、低于预期空间大，形成不对称风险结构。

**形式化推导**：
```
预期打满 → 超预期空间↓ + 低于预期空间↑ → 不对称风险
```

**关键证据**：
- 通信行业指数年内涨近40%，已计入大量乐观预期
- 几年前的消费和医药故事也经历过"预期打满→问题随之而来"
- 越是一致看好的地方，边际负面变化的杀伤力越大

**边界条件**：若AI的实际进展持续超预期（如通用AI提前出现），一致乐观预期仍可能被验证。

---

## Q6: 投资者应该怎么做？

**结论**：可以相信AI，但不要all in信仰——保持配置、控制仓位、对波动留有余量。

**形式化推导**：
```
all in信仰(高风险) vs 控制仓位 + 保持配置 + 留余量(与认知匹配的策略)
```

**关键证据**：
- 即使是最乐观的从业者，最乐观情景下GDP也只预测5.3%
- 当前股价可能已充分反映甚至透支了乐观预期
- 极端押注可能让你承担与自身认知不匹配的风险

**边界条件**：若投资者对AI技术有深度认知且风险承受力强，集中配置可能是合理的。

## 收口

晨星的核心提醒不是"AI不行"，而是**"信仰和收益是两回事"**——你可以相信技术的长期潜力，但股价已经price in了太多信仰，留有余地的人才能等到生产力红利真正兑现的那一天。
