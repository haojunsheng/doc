# QA — 10月股债分化，价值风格占优

> 10月基金月报 | 股市震荡债市向好，权益基金涨跌互现，固收基金多数录涨

**原文**：[晨星中国](https://www.morningstar.cn/articles/1618d98c384d79b35ad159616255136a.html)
**发布日期**：2026-06-14

## 核心论点

10月A股先抑后扬再回落，上证指数盘中突破4000点（十年新高）最终涨1.85%，深证成指跌1.10%；债市在"经济偏弱+央行重启国债买卖"支撑下全线向好，中证全债指数涨0.73%。权益基金涨跌互现，固收基金多数录涨，价值风格优于成长风格，可转债在"股弱债强"环境中表现最差。

## Q1: 为什么A股月初调整、月中反弹、月末再回落？

*结论*：月初受中美贸易摩擦升温、经济数据不及预期影响，月中受中美贸易磋商进展顺利、四中全会影响，月末受经济数据不及预期影响。

*形式化*：
```
月初：贸易摩擦↑ + 经济数据↓ → 股市调整
月中：贸易缓和 + 四中全会 → 风险偏好↑ → 股市反弹
月末：经济数据↓ → 小幅利空
```

*边界*：若贸易摩擦进一步升级，股市可能继续调整；若经济数据超预期，股市可能继续上涨

## Q2: PMI连续7个月在收缩区间，为什么债市反而涨了？

*结论*：PMI低于50%是经济收缩信号，市场预期央行会加大宽松力度（如降准降息），债券价格因此上涨。

*形式化*：
```
PMI 49.0%（连续7个月<50%）= 经济收缩信号↑ → 宽松预期↑ → 债券需求↑ → 债市↑
```

*数据验证*：
- 中证全债指数10月上涨0.73%
- 5年期国债收益率下行4bp，10年期下行7bp

*边界*：若央行未如预期宽松（如通胀上升），债市可能回调；若经济超预期复苏，债市会进一步下跌

## Q3: 为什么价值风格在10月跑赢成长风格？

*结论*：煤炭、钢铁、有色金属等周期股（价值风格）受益于政策利好（煤矿超产核查、钢铁行业稳增长方案），而电子、汽车等成长股承压。

*形式化*：
```
价值风格 × 政策利好（周期股） → 表现好
成长风格 × 政策压力（科技自立自强方向） → 表现差
```

*数据*：
- 煤炭、钢铁、有色金属板块涨幅均超过5%
- 电子、汽车、美容护理和传媒板块跌幅均超过3%
- 政策催化：煤矿超产核查利好煤炭，钢铁行业稳增长方案利好钢铁，十五五规划利好矿业、冶金
- 成长风格承压：科技自立自强方向在政策博弈中短期承压

*边界*：若政策重心从"传统周期"转向"科技自立"，成长风格可能重新占优；若经济复苏超预期，周期股可能进一步上涨

## Q4: 为什么医药基金10月跌得最惨（行业股票-4.86%，行业混合-5.23%）？

*结论*：医药板块缺乏政策催化剂，且前期估值偏高，在市场风格从"防御"转向"周期"时被资金抛弃。

*形式化*：
```
医药 = 缺乏政策催化 + 前期估值偏高 + 市场风格从防御→周期 → 资金流出 → 跌幅最大
```

*边界*：若政策重心转向"民生保障"或"医疗基建"，医药可能重新走强；若市场风格从周期回归防御，医药会重新受青睐

## Q5: 为什么固收类基金多数录涨，唯独可转债基金下跌？

*结论*：可转债兼具股债双重属性，在A股下跌时转股价值缩水，跌幅超过纯债基金。

*形式化*：
```
可转债 = 债券属性 + 股票属性 → A股↓ → 转股价值↓ → 跌幅超过纯债
```

*数据对比*：
| 指标 | 10月表现 |
|------|---------|
| 中证全债指数 | +0.73% |
| 中证转债指数 | 月平均-0.11%（最差） |
| 深证成指 | -1.10% |
| 中证500 | -1.10% |
| 中证1000 | -0.90% |

*边界*：若A股企稳反弹，可转债的转股价值会重新上升；若债市继续走强，可转债的债底保护会增强

## Q6: 为什么QDII基金中"全球新兴市场"和"美国股票"表现好，而"大中华区"表现差？

*结论*：全球新兴市场受益于美股、韩股和台股的强劲表现，大中华区受制于港股拖累。

*形式化*：
```
全球新兴市场 = 美股↑ + 韩股↑ + 台股↑ → 表现好（+7.60%）
大中华区 = 港股↓ → 表现差（-7.18%）
```

*数据*：
- 全球新兴市场：得益于美股、韩股和台海股的良好表现，录得7.60%月平均涨幅
- 大中华区：恒生指数下跌3.53%，拖累大中华区股票基金和股债混合基金录得2.04%和7.18%月平均跌幅

*边界*：若港股企稳反弹，大中华区基金可能重新走强；若美股继续上涨，全球新兴市场会进一步受益

## Q7: 为什么10月短端国债收益率上行，中长端国债收益率下行？

*结论*：短端受资金面紧张影响（央行未如预期宽松），中长端受经济偏弱预期影响（市场定价"降息预期"）。

*形式化*：
```
短端（1年期）= 资金面紧张 → 收益率↑（+2bp）
中长端（5/10年期）= 经济偏弱预期 → 收益率↓（-4bp/-7bp）
```

*机制*：
- 短端定价"资金面"：央行重启国债买卖释放宽松信号，但1年期国债收益率小幅上行2bp，说明资金面仍偏紧
- 中长端定价"经济预期"：经济基本面偏弱和关税博弈升级支撑债市走强，5年期和10年期国债收益率分别下行4bp和7bp

*边界*：若央行加大宽松力度（如降准），短端收益率也会下行；若经济超预期复苏，中长端收益率会上行

## 收口

作者通过10月的基金月报揭示了一个核心规律：当经济偏弱、政策宽松预期升温时，债市（尤其是中长端利率债）会率先受益，而权益市场则呈现"结构分化"——价值风格（周期股）受益于政策催化，成长风格（电子、汽车）承压，可转债在"股弱债强"环境中表现最差——投资者需要根据经济周期和政策方向，动态调整股债和风格配置。
