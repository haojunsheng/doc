# 9月基金月报——权益涨跌互现，债市承压

**原文**：[晨星中国](https://www.morningstar.cn/articles/518e57d993ce94e62be48dfe1bf62f5e.html)  
**发布日期**：2025-10-01（对应 9 月月报）

## 一句话摘要

2025年9月，A股整体向好但行业结构分化明显，权益基金涨跌互现；债市因经济预期改善、利率上行压力而承压，固收基金多数收跌。这提醒投资者：行业配置能力与动态资产配置纪律比市场整体涨跌更重要。

## 核心论点

### 1. 股市向好 ≠ 所有基金盈利

9月A股整体上涨，但行业表现差异巨大——部分行业大涨，部分行业下跌。重仓上涨行业的基金表现好，重仓下跌行业的基金表现差。**基金业绩取决于行业配置方向**，而非市场整体涨跌。

形式化：
```
股市整体向好 ≠ 所有行业向好
           → 行业分化
           → 基金业绩取决于行业配置
```

**边界**：如果市场进入普涨行情（全面牛市），权益基金可能集体上涨，结构分化效应收敛。

### 2. 债市承压的逻辑链

经济预期改善 → 利率上行压力 → 债券价格下跌 → 债市承压

这是利率与债券价格反向关系的典型例证。债券价格与利率负相关，当股市向好反映经济预期改善时，市场预期利率上行，债券价格随之下跌。

**边界**：如果央行降息（宽松货币政策对冲），债券价格可能逆势上涨。

### 3. 固收基金 ≠ 无风险资产

这是本文最具认知纠偏价值的论点：**利率上行时，债券基金也会亏损**。普通投资者常误将固收基金视为"安全资产"，忽视了利率风险这一固有风险来源。

**边界**：如果持有至到期且基金未提前赎回，债券基金可以收回本金，不受利率波动影响。

### 4. 行业配置贡献约 60% 基金业绩

晨星月报指出，基金业绩的主要来源是行业配置（约 60%），而非个股选股（约 40%）。**优秀的行业配置能创造显著超额收益**，这也是为什么选基金首先要关注基金经理的行业配置能力。

> ⚠️ 该比例为晨星的概括性估算，并非严格实证结论。不同风格（成长/价值/行业主题/固收+）的基金配置贡献占比差异很大。

形式化：
```
基金业绩 ≈ 行业配置（~60%）+ 选股能力（~40%）
```

### 5. 根据经济周期动态调整权益/固收比例

经济复苏期企业盈利改善，股市上涨 → 配置权益基金  
经济衰退期企业盈利下滑，债券相对安全 → 配置固收基金

**关键约束**：判断经济周期是困难的，可能需要专业分析。

## 投资决策启示

1. **选基金看行业配置能力**——在结构分化市场中，行业配置比选股能力影响更大
2. **固收基金需关注利率环境**——利率上行期不宜重仓纯债基金
3. **避免过度集中热门行业**——警惕结构性风险，分散配置降低单一行业暴露
4. **动态调整权益/固收比例**——依据经济周期判断进行大类资产配置
