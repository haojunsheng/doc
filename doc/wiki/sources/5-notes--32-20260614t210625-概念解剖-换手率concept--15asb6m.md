# 概念解剖 — 换手率

**来源文件**：`notes/20260614T210625--概念解剖-换手率__concept.md`

## 核心主张

换手率是基金经理投资行为的"测谎仪"——它揭示真实的投资期限、策略类型和能力段位，穿透"长期持有"口号。

## 关键论点

1. **换手率公式**（通行定义）：

   ```
   换手率 = min(买入金额, 卖出金额) / 年内基金平均净资产
   ```

2. **2018–2022 年中国主动权益基金数据**：大部分基金经理平均每年对组合进行 2–6 次大换血。换手率分布从 <50%（买入持有型）到 >400%（短线交易型）不等。长期来看，换手率与业绩无显著相关性——策略本身无优劣，关键是策略与能力匹配。

3. **换手率+星级四象限**：低高×低高分出四类基金经理（投资大师/辛勤炒股大神/破产版巴菲特/机构韭菜），该框架与 [[基金经理换手率评级]] 内容一致。

4. **知行合一的验证器**：换手率的价值不在于高低，而在于一致性——基金经理的换手率是否与他的策略声明一致、与他的能力圈一致、与市场环境一致。

5. **时间观隐喻**：高换手意味着基金经理活在"当下"——不断对最新信息做出反应；低换手意味着基金经理活在"未来"——基于长期判断布局，然后等待。

## 三层解读框架

- **策略层**：买入持有（低）vs 行业轮动（中）vs 短线交易（高）
- **能力层**：看得准+拿得住（低换手高收益）vs 看错频繁调整（高换手低收益）
- **环境层**：熊市换手低（机会少）、牛市换手高（目标价快速达到）

## 压缩公式

```
换手率 = 交易频率 × 策略类型 × 能力信号 × 知行合一度
```
