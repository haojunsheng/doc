# 晨星2026年3月基金市场报告：地缘冲击下的股债分化与风格轮动

晨星（Morningstar）发布于2026年6月的3月基金市场月报，以中东地缘冲突推高油价41%为背景，分析了全球及A股市场的结构性反应。

## 核心数据

| 指标 | 数值 |
|------|------|
| 布伦特原油 | +41.42% |
| 日经225 | -13.62% |
| 上证指数 | -6.51%（跌至3800点附近） |
| 深证成指 | -7.01% |
| PMI | 50.4%（重返扩张区间） |
| 1年期国债收益率 | 1.22%（下行10bp） |
| 10年期国债收益率 | 1.82%（上行4bp） |

## 基金分类表现

| 基金类型 | 3月表现 | 说明 |
|---------|---------|------|
| 大盘价值基金 | -2.85% | 表现最佳权益风格 |
| 中盘成长基金 | -11.79% | 差距近9个百分点 |
| 可转债基金 | -8.35% | 最大亏损品类之一 |
| 积极债券基金 | -1.70% | 受权益敞口拖累 |
| 普通债券基金 | -0.39% | — |
| 纯债基金 | +0.27% | 唯一正收益债券品类 |
| QDII商品基金 | +8.44% | 受益于油价暴涨 |
| 黄金基金 | -11.54% | 美联储偏鹰压制金价 |
| 行业混合-医药 | -0.91% | 跌幅最小行业基金 |
| 科技基金 | -10%+ | — |
| 传媒基金 | -15%+ | — |

## 核心结论

地缘冲击下的市场反应是"有结构的"，而非无差别恐慌。资金按特定逻辑迁移：成长→价值、中小盘→大盘、股市→短债。这种"避险迁移"不是恐慌，而是投资者在重新定价风险。

理解这个结构，才能理解自己的钱在经历什么。

# 避险迁移

避险迁移是指在地缘政治冲击、宏观经济恐慌或其他系统性风险事件发生时，资金并非无差别逃离风险资产，而是沿着特定结构路径从高风险资产向相对安全资产迁移的现象。

## 典型迁移路径

1. **成长股 → 价值股**：资金从估值高、波动大的成长风格撤出，流向盈利稳定、估值低的大盘价值风格。2026年3月，大盘价值基金跌2.85%，而中盘成长基金跌11.79%，差距近9个百分点。

2. **中小盘 → 大盘**：大盘股流动性更好，在恐慌时有更强的抗跌性。

3. **股市 → 短债**：避险资金涌入短端债券，推动短端利率下行。2026年3月，1年期国债收益率下行10bp至1.22%。

4. **权益资产 → 商品（能源类）**：在地缘冲突直接推升特定商品（如原油）价格时，商品基金成为另类避险通道。

## 关键特征

- **有结构的恐慌**：不是所有资产同跌，而是按风险暴露程度分层下跌。
- **可预测的迁移方向**：基于历史规律，可以预判资金可能流向哪些资产类别。
- **逆转条件明确**：当冲击消退或风险偏好回升，迁移过程会反向进行。

## 与股债跷跷板的区别

[[股债跷跷板效应]]描述的是股债之间的资金流动，而避险迁移是一个更宽泛的概念，涵盖了股票内部风格轮动、跨资产类别迁移等多个维度。

## 投资启示

理解避险迁移的结构，可以帮助投资者：
- 判断当前持仓的地缘风险敞口
- 提前布局可能受益于迁移方向的资产
- 避免在地缘冲击时将"固收+"误认为无风险资产（其权益敞口同样会遭受损失）

# 收益率曲线陡峭化

收益率曲线陡峭化是指短期利率下行、长期利率上行，导致收益率曲线斜率增大的现象。在地缘冲击等风险事件中，这是债券市场最常见的结构性反应之一。

## 形成机制

| 端点 | 方向 | 驱动因素 |
|------|------|---------|
| 短端（1年期） | 下行 | 避险资金涌入短债 → 需求增加 → 价格↑ → 收益率↓；同时央行通过流动性投放呵护短端 |
| 长端（10年期） | 上行 | 通胀预期上升 → 市场预期未来加息 → 长债被抛售 → 价格↓ → 收益率↑ |

## 2026年3月实例

- 1年期国债收益率：下行10bp至1.22%
- 10年期国债收益率：上行4bp至1.82%
- 结果：收益率曲线整体陡峭化

## 经济含义

- **短端下行**反映市场对当前经济不确定性的避险情绪，以及货币政策的宽松导向。
- **长端上行**反映市场对未来的通胀担忧和加息预期。
- 陡峭化通常发生在经济前景不明朗但通胀压力初现的阶段。

## 与政策的关系

若央行明确释放宽松信号（如降准），长端利率也可能跟随下行，此时曲线可能平行下移而非单纯陡峭化。

# QA — 2026年3月基金市场：地缘冲击下的股债分化与风格轮动

本文基于晨星2026年3月基金月报，以问答形式解析地缘冲突对各类基金的差异化影响。

## 问题与结论摘要

**Q1：油价暴涨41%为何导致全球股市下跌？**

通胀预期上升 → 企业成本上升 + 央行加息预期 → 盈利和估值双杀。数据：布伦特原油涨41.42%，日经225跌13.62%。

**Q2：为何"大盘价值风格"表现最好？**

价值股盈利来自当前业务（银行贷款、电力销售），不依赖未来增长预期；成长股依赖未来增长，在地缘冲击下不确定性增加被抛售。大盘价值基金-2.85% vs 中盘成长-11.79%。

**Q3：为何"固收+"反而下跌？**

固收+含股票和可转债敞口，中证转债指数跌7.41%拖累净值。纯债基金+0.27%说明债券部分没问题，问题在权益敞口。

**Q4：为何"短端利率下行，长端利率上行"？**

短端：避险资金涌入+央行流动性呵护；长端：通胀预期压制。1年期-10bp至1.22%，10年期+4bp至1.82%，收益率曲线陡峭化。

**Q5：为何"医药基金"跌幅最小？**

医药属防御性行业，需求刚性，与油价弱相关。行业混合-医药仅跌0.91%，科技跌10%+，传媒跌15%+。

**Q6：为何"QDII商品基金"逆势涨8.44%**？

油价暴涨直接推升商品基金净值。但黄金跌11.54%（美联储偏鹰），说明商品基金内部收益结构复杂，不能简单等同"避险资产都涨"。

**Q7：沪指跌至3800点意味着什么？**

PMI 50.4%重返扩张，两会稳增长信号，基本面未恶化。下跌主要来自地缘冲击和情绪面，定性为"短期情绪冲击"而非趋势反转。边界：若霍尔木兹海峡封锁，3800点支撑可能失效。
