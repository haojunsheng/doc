# QA — 回报率比净值重要

**来源：** 晨星中国（Morningstar.cn）  
**日期：** 2026-06-14  
**格式：** Q&A 问答拆解

## 一句话摘要

基金净值只是时点的价格快照，真正反映收益的是回报率；但比较回报率必须满足同类、同期、同风险三个前提，且基金经理更换会大幅降低历史业绩的参考价值。

## 五项核心问答

### Q1：为什么净值高不代表赚得多？

净值是"价格"，不是"收益"——你赚多少取决于买入价和卖出价的差，不是净值本身。

**形式化：** 净值 = 某时点价格；收益 = (卖出价 - 买入价) / 买入价

- 净值从1块涨到2块（涨幅100%），若在1.5块买入，实际只赚33%
- 净值高可能意味着"涨了很多"，也可能意味着"跌得少"
- 净值本身不能告诉你"还能不能买"，只能告诉你"现在值多少"

**边界：** 定投场景下净值高确实意味着之前的投入赚了，但这不是"现在该买"的理由。

→ [[净值与回报率的区别]], [[净值恐高症]]

### Q2：回报率由哪两部分组成？

总回报 = 资本增值 + 分红——只看净值会漏掉分红这部分收益。

**形式化：**
```
总回报率 = (资本增值 + 期间分红) / 初始投资 × 100%
```

- **资本增值**：净值从1块涨到2块
- **分红**：基金定期或不定期发给你的利润
- 未选红利再投资时，实际收益可能低于基金公司公布的总回报率

**边界（重要）：** 分红不是"白赚的钱"——它来自基金净值，分红后净值会相应下降（**除权**）。

→ [[分红除权机制]], [[总回报优先原则]]

### Q3：为什么不能直接比较两只基金的回报率？

不同基金的风险、投资目标、买入时间完全不同——没有比较基础的数字没有意义。

**形式化：** 回报率可比性 = 同类型 + 同时间段 + 同风险水平

- 股票型基金年化20% vs 债券型基金年化5%，看似前者好但风险完全不同
- 同一只基金，买5年和买3年的收益率可能天差地别
- 在高点买入 vs 低点买入，持有同样的时间，收益也会差很多

**边界：** 如果两只基金类型完全相同、买入时间相同，回报率可以直接比较——但理想情况很少见。

→ [[基金回报比较三前提]]

### Q4：为什么长期业绩比短期业绩重要？

短期高回报可能是运气，长期持续跑赢才是基金经理的真本事。

**形式化：**
```
短期高回报 = 运气 + 能力
长期高回报 = 能力 + 风控
```

- 牛市里短期收益率突出很难具有持续性——可能只是押对了热点
- 经历了牛熊市轮换后还能获得高回报，说明经得起考验
- 逐年回报稳定优于基准，比某一年暴利更有参考价值

**边界：** 长期业绩不代表未来——基金经理换人、策略漂移、市场结构变化都可能改变未来表现。

→ [[三层业绩归因框架]], [[投资是性格测试]]

### Q5：基金经理换人了，历史业绩还参考吗？

大打折扣——历史业绩是"那个人"的，不是"这个基金"的。

**形式化：** 基金业绩 = 基金经理能力 + 策略 + 团队；换人 → 业绩参考性大幅降低

- 基金经理变更会使基金历史回报的参考性大打折扣
- 新基金经理可能有不同的投资风格、风险偏好、选股逻辑
- 需重新评估这只基金是否还符合你的投资目标

**边界：** 若基金公司有强大的投研团队和策略体系，换人影响可能小一些——但个人能力仍然重要。

→ [[基金经理变更风险]]

## 收口

净值是表象，回报率是实质——真正的判断标准是：在完整周期里，基金经理能不能持续跑赢同类。
