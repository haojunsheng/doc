# QDII不等于海外分散，要看穿透持仓

**原文**：[晨星公众号](https://www.morningstar.cn)
**日期**：2026-06-14

## 一句话摘要

QDII 基金是普通人投资海外的门槛最低渠道，但"名字带 QDII"不等于"真能分散 A 股风险"——中概股 QDII 穿透后的"中国含量"可接近 100%，同时持有中概股 QDII 与 A 股基金等于加倍押注中国。

## 核心形式化表达

```
QDII = 国内基金公司 × 外汇额度 × 海外投资
```

> QDII 只是渠道（通道），不是分散化本身。能不能分散，取决于具体投了什么。

```
真分散 = 持仓公司营收来源 × 与A股低相关
```

## Q1：QDII 的本质是什么？

**结论**：QDII 是投资代购——基金公司用额度帮你投海外，你不用自己换汇。

- 外汇管制下普通人很难直接投资海外
- 基金公司申请 QDII 额度，代替投资者操作
- 只要用了 QDII 额度，基金名必须带"QDII"字样

**边界**：QDII 只是渠道，不等于分散化效果。纳指 100 QDII 等以美国本土公司为主的基金，其分散效果仍然成立。

## Q2：为什么"上市地"不等于"公司归属地"？

**结论**：公司在哪里上市跟它赚哪里的钱是两回事。

- 瑞幸咖啡美股上市，但营收主要来自中国消费者
- 它的股价跟中国经济相关，跟美国咖啡市场无关
- 上市地决定监管环境，营收来源地决定基本面

**边界**：有些公司确实跨国经营，营收来源复杂，不能简单按总部所在地划分。

## Q3：港股能对冲 A 股风险吗？

**结论**：效果有限，因为港股上市的公司大部分是中国企业。

- 恒生指数 60% 以上公司是中国企业
- 这些企业的业务受中国经济影响大
- 上市地不同，但基本面驱动因素相似

**边界**：如果你投的是港股里没在 A 股上市的中国企业（如某些互联网龙头），有一定差异化价值。

## Q4：中概股基金的"海外浓度"有多高？

**结论**：名字带 QDII，实际"中国含量"可能接近 100%。

```
中概股QDII = QDII额度 × 100%中国公司持仓
```

**关键数据**：
- 中证海外中国互联网指数与沪深 300 相关系数达 **0.71**
- 与标普 500 的相关性反而更低

**边界**：中概股基金适合看好中国新经济、想避开 A 股估值体系的投资者，但不适合"分散地域风险"。

## Q5：怎么判断 QDII 是否真的能分散风险？

**结论**：穿透持仓看营收来源地，而不是看上市地或基金名字。

**三步法**：
1. 获取基金季度报告中的完整持仓清单
2. 查询每只持仓公司的营收来源地分布（晨星等机构提供此数据）
3. 按营收来源地汇总，得到基金的真实国家敞口

**边界**：即使穿透持仓，也要看基金经理是否会因为市场变化调整持仓——动态跟踪比静态穿透更重要。

## 收口

QDII 是工具，不是目的。买了 QDII 不等于做了海外配置——穿透持仓、看营收来源、算相关性，三步走才能知道你的"海外浓度"到底够不够。
