# QA — 富国产业债信用债投资

> 原文：[晨星中国](https://www.morningstar.cn/articles/47bb7c269da56609bf3d59d035c1bea2.html)
> 发布日期：2024-06-27

## 核心论点

富国产业债债券（100058）自2017年3月由武磊管理以来，以"低波动+票息收益"为核心策略：通过投资中高等级产业债获取稳定票息，控制回撤在2%以内，实现年化4.50%回报、排名前18%的业绩，且波动性显著低于同类中位数。

## Q1: 为什么富国产业债要将回撤控制在2%以内？

**结论**：低波动定位是策略基石——回撤目标 <2% → 降低投资者恐慌赎回概率 → 确保长期持有 → 票息收益得以积累。

**形式化**：
```
低波动定位 → 回撤控制目标<2% → 降低投资者恐慌赎回概率 → 长期持有 → 票息收益积累
```

- 风控目标：基金经理希望将回撤控制在2%以内，对风险极度敏感
- 历史验证：自武磊管理以来组合最大回撤仅为0.93%，远低于2%目标
- 策略匹配：低波动产品适合风险厌恶型投资者，避免因波动而频繁交易

**边界**：如果市场出现极端波动（如股灾），回撤可能突破2%；如果过度追求低波动，可能牺牲收益。

## Q2: 为什么基金主要投资中高等级产业债？

**结论**：中高等级产业债违约风险低、票息稳定，符合"低波动+票息收益"策略定位；产业债占固收资产85%-90%，AAA以下债券占比<20%。

**形式化**：
```
中高等级产业债 = 违约风险低 + 票息稳定 → 符合低波动策略 → 基金持仓85%-90%为产业债
```

- 契约规定：产业债占固收资产比重须达80%以上，过往一般在85%-90%
- 信用等级：AAA等级以下债券占比通常在20%以内
- 业绩归因：票息收益是超额收益的主要来源，其次为久期策略、杠杆策略、转债投资

**边界**：如果信用风险蔓延（如行业危机），中高等级债券也会受波及。

## Q3: 为什么基金对转债的配置力度相对较低（5%以内）？

**结论**：转债与股市相关性强，会增加组合波动性，不符合"低波动"定位；仅选债性转债（到期收益率 ≥2%）。

**形式化**：
```
转债配置低 = 转债与股市相关性强 → 增加波动性 → 不符合低波动定位 → 仅配置债性转债（到期收益率≥2%）
```

- 仓位控制：大部分时间转债仓位<5%，在同类基金中相对保守
- 标的选择：仅投资偏债性的低价可转债，到期收益率或回售收益率须在2%以上
- 历史验证：2020年股市上涨时表现弱于同类（未充分分享权益收益），但2022年以来股市波动时更稳定

**边界**：如果股市持续上涨，低转债配置会错失收益；如果股市大幅下跌，低转债配置反而减少损失。

## Q4: 武磊的投资方法如何体现"自上而下和自下而上相结合"？

**结论**：自上而下（利率趋势+信用利差→确定久期/杠杆）+ 自下而上（个券基本面+定价+流动性→确定个券）→ 组合构建。

**形式化**：
```
自上而下（利率趋势+信用利差→确定久期/杠杆）+ 自下而上（个券基本面+定价+流动性→确定个券）→ 组合构建
```

- 宏观判断：基于利率趋势和信用利差走势研判，确定久期和杠杆水平
- 中观配置：分析不同类型券种的估值比价和供求关系，确定类属配置比例
- 微观选择：综合个券信用基本面、定价合理性和流动性确定个券配置

**边界**：如果宏观判断失误（如利率走势判断错误），组合会承压；如果个券选择失误（如踩雷），会拖累业绩。

## Q5: 从富国产业债的策略中能学到什么？

**结论**：成功 = 低波动定位（回撤<2%）+ 票息收益（中高等级产业债为主）+ 严格风控（分散投资+久期控制+杠杆管理）→ 年化4.50%（前18%）。

**形式化**：
```
成功 = 低波动定位（回撤<2%）+ 票息收益（中高等级产业债为主）+ 严格风控 → 年化4.50%（前18%）
```

- 业绩归因：票息收益是超额收益主要来源，其次久期策略、杠杆策略、转债投资也有正贡献
- 风控措施：稳健风格、多元化策略、前瞻性预判、分散投资控制风险
- 长期验证：自2017年以来投资策略保持稳定，组合特征与策略相互印证

**边界**：如果利率环境逆转（进入加息周期），债券价格会下跌；如果信用风险蔓延，中高等级债券也会受波及。

## 收口

富国产业债的成功证明了一个朴素道理：在债券投资中，"低波动+票息收益+严格风控"的组合能穿越股市和债市的波动——4.50%的年化回报，本质是"稳健+纪律"的复利。
