# 被动权益首超主动，ETF费率战刚打到中局

## 来源信息

- **作者/机构**：晨星中国
- **发布日期**：2026-06-28
- **原文链接**：https://www.morningstar.cn/articles/77a78ff8dd6ea56c13020c54c26bb5fb.html

## 核心结论

2024年末，中国公募基金迎来历史性时刻：被动权益基金规模（3.61万亿）首次超越主动权益基金（3.46万亿）。ETF在被动权益中占比从2015年的38%攀升至90%，开放式被动基金从62%萎缩至10%。与此同时，ETF费率战愈演愈烈，头部产品从0.6%降至0.2%，但中国净费率0.42%仍为美国0.12%的3.5倍，费率战"刚打到中局"。

宽基指数ETF持续创造价值，而行业主题ETF则普遍毁灭价值，二者天差地别。

## Q&A 结构

### Q1: 被动权益凭什么超越主动权益？

- **结论**：主动基金跑赢难度增大 + 投资者风险偏好转向多元化，被动基金凭透明度和低成本迅速崛起。
- **形式化**：主动基金超额收益↓ + 投资者风险偏好调整 → 被动权益3.61万亿 > 主动权益3.46万亿
- **边界条件**：若A股进入长期结构性牛市且主动基金超额收益回升，被动优势可能收窄。

### Q2: ETF在被动权益中占比为什么从38%涨到90%？

- **结论**：ETF凭交易便捷和成本优势，十年间彻底碾压被动开放式基金。
- **形式化**：2015: ETF(38%) + 开放式(62%) → 2024: ETF(90%) + 开放式(10%)
- **边界条件**：若交易所交易机制发生重大变化（如T+0限制），ETF的交易优势可能被削弱。

### Q3: 中国ETF费率降到什么水平了？

- **结论**：2024年明显下降，头部ETF从0.6%砍到0.2%，但仍高于美国的0.12%。
- **形式化**：中国ETF净费率: 0.42% ‖ 美国ETF净费率: 0.12% → 中国还有↓空间
- **关键事实**：
  - 2024年下半年集体降费：华泰柏瑞沪深300、华夏上证50等从0.5%+0.1%降至0.15%+0.05%
  - 中证A500ETF首发直接打最低费率0.15%，拉低行业整体水平
  - 2023年公募基金费率改革是政策推手
- **边界条件**：若基金公司费率已逼近运营成本线，进一步降费空间有限。

### Q4: 为什么美国费率能比中国低这么多？

- **结论**：美国ETF市场更成熟、更早开始价格竞争，Vanguard等巨头以极低费率抢占市场。
- **形式化**：美国: 成熟市场+巨头价格战 → 0.12% ‖ 中国: 成长期+刚开始价格战 → 0.42%
- **关键事实**：
  - 美国ETF自1980年代起步，中国起步晚
  - 美国2018-2024年费率累计下降12%，2022年后重新回到下行区间
  - 美国股票型ETF费率仅0.11%，债券型0.09%
  - **统计口径注意**：Vanguard部分ETF下挂在共同基金下，未纳入统计，实际市场费率可能更低——中美差距可能被低估
- **边界条件**：若中国ETF市场集中度快速提升（类似美国前五占60%），费率下降速度可能加快。

### Q5: 谁在创造价值？谁在毁灭价值？

- **结论**：价值创造靠宽基指数ETF（前10中有8只被动宽基），价值损失集中在行业主题ETF。
- **形式化**：宽基指数ETF → 价值创造 ‖ 行业主题ETF → 价值损失
- **关键事实**：
  - 国内价值创造前10的ETF中，8只为追踪广泛市场指数的被动型产品
  - 国内价值损失前10全部是行业主题ETF
  - 美国类似：价值创造前15中有9只低成本大盘指数基金
- **边界条件**：若某行业进入长期景气周期（如AI），相关主题ETF可能从价值损失转为价值创造。

### Q6: 行业主题ETF为什么会毁灭价值？

- **结论**：投资范围窄 + 轮动难把握 + 投机客频繁买卖放大波动，三重叠加侵蚀收益。
- **形式化**：窄行业绑定 + 轮动难把握 + 投机客频繁交易 → 价格波动↑ → 价值损失
- **机制拆解**：
  1. 聚焦特定细分行业，缺乏宽基分散风险特性
  2. 普通投资者把握行业轮动难度极高
  3. 行业遭遇政策/技术/供需冲击时净值大幅波动
  4. 吸引短期投机者频繁买卖，进一步放大价格波动
- **边界条件**：若投资者具备行业研究能力且长期持有，行业主题ETF不一定毁灭价值。

### Q7: ETF投资决策应考虑哪些维度？

- **结论**：费用优先 + 选对基金公司 + 验证跟踪精度，三者缺一不可。
- **形式化**：费率↓ + 公司受托责任 + 跟踪精度↑ → 好的ETF投资
- **实践框架**：
  1. **费用优先**：持有成本包括管理费、托管费、换手率和抽样偏差等，应优先选择低费率产品
  2. **公司受托责任**：基金公司的受托利益文化至关重要——把投资者利益放首位
  3. **跟踪精度验证**：被动基金需验证指数跟踪表现（对比同类平均和跟踪指数）
- **边界条件**：若基金公司文化和投研团队发生变动（如核心人员离职），过往评估可能失效。

## 收口判断

> 被动超越主动不是风格轮动，而是成本透明度和投资者觉醒的里程碑——但ETF的价值创造和损失天差地别，选宽基还是选主题，决定了你是站在创造价值还是毁灭价值的一边。
