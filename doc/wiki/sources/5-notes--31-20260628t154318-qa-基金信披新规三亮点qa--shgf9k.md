# 基金信披新规三亮点

晨星中国解读证监会基金定期报告新规，指出三个强制披露要求分别精准对应基金行业三大顽疾。

## 核心论点

**信息披露不是形式主义，而是塑造行业行为的指挥棒——你披露什么指标，基金经理就会在什么指标上努力。**

## 三大亮点

### 1. 拉长业绩展示周期（7年/10年）

- 旧模板强调1个月业绩，导致基金经理为季度排名博弈
- 新规取消1个月业绩展示，强制展示7年/10年长期业绩
- 边界：若投资者仍只看近3个月收益做决策，效果打折扣

### 2. 强制披露股票换手率

- 换手率 = min(买入成本, 卖出收入) / 日均持仓市值
- 高换手率暴露风格漂移与交易成本问题
- 晨星2023年已将换手率带来的隐形交易成本纳入综合费率计算
- 边界：高频量化策略天然高换手，不能一概而论

### 3. 首创盈利投资者数量占比

- 盈利投资者占比 = 净收益≥0的投资者数 / 投资者总数（剔除持有<7天）
- 直接回答"基金净值涨≠基民赚钱"的问题
- 晨星2005年开创投资者回报研究，2024年引入中国
- 边界：统计期内规模大幅变动时需结合规模变动解读

## 制度逻辑

```
披露什么指标 → 基金经理在什么指标上努力 → 行业行为模式被改变
```

三套准则合并（年报+半年报+季报→统一体系）是背景而非亮点，真正价值在于三个强制披露指标的制度设计。

## 投资者使用框架

| 新指标 | 判断维度 |
|--------|---------|
| 7年/10年业绩 | 长期能力 |
| 股票换手率 | 风格稳定性 |
| 盈利投资者占比 | 与持有人利益一致性 |

三个指标组合使用比单一指标更有判断力。
