# 超长期国债值不值 — Q&A

## 来源信息

- **原始来源**：[[晨星中国-morningstarcn]]（Morningstar.cn）
- **原始链接**：https://www.morningstar.cn/articles/1ed26db7a8d6a890f642409a62b76bd1.html
- **日期**：2024-06-27
- **背景**：财政部发行万亿超长期特别国债（20/30/50年期），社交媒体大V鼓吹"闭眼冲"

## 核心论点

文章拆解"超长期特别国债"三个关键词，戳破两个流行误解：

1. **国债 ≠ 无风险**：信用风险低，但利率风险和流动性风险依然显著
2. **锁定收益是误导**：固定票面利率 ≠ 锁定实际回报（扣除通胀后），50年维度的利率走势无法预测

## Q&A 要点

### Q1: 国债为什么不是真正的"无风险"？

- 国债只有信用风险低，违约概率极低
- 利率和债券价格反向变动：利率升 → 债券价格跌
- 期限越长，利率风险越大，50年期波动极为剧烈
- 形式化：`国债风险 = 信用风险(低) + 利率风险(高) + 流动性风险(中)`
- 边界：持有至到期且不提前卖出，价格波动不影响最终收益——但50年期限很难做到

### Q2: 为什么"锁定收益"这个说法有陷阱？

- 30-50年维度无法预测利率走势
- 若未来通胀高于票面利率，实际购买力在缩水
- 机构可通过波段交易和加杠杆获利，个人不行
- 形式化：`锁定收益 = 固定票面利率 ≠ 锁定实际回报(扣除通胀后)`
- 边界：利率持续下行（如日本）时提前锁定确实有效——但这是事后才知道的

### Q3: 国债和存款的流动性有什么关键差异？

形式化对比：

```
存款:   随时取 → 损失定期利息
储蓄国债: 有最低持有期 → 提前兑取交手续费+折收益
记账式国债: 可交易 → 但按市场价卖，可能亏本
```

- 本次发行的是记账式国债，可交易但承担市场风险
- 中途急需用钱时可能被迫在低价卖出

### Q4: 为什么大V推荐的超长期国债对普通人未必合适？

- 机构做长债投资的核心策略不只是吃利息，还包括波段交易+杠杆
- 普通人只能买入持有，无法利用波动获利
- 50年可能超过很多人的投资生涯甚至寿命
- 形式化：`机构: 波段交易+杠杆 → 从波动中获利` / `普通人: 买入持有 → 只能承受波动，无法利用波动`
- 边界：只投一小部分（组合10-20%）且能持有到期，风险可控

### Q5: 普通人应该怎么看待超长期国债？

- 当组合里的"压舱石"小比例配置，不要当"传家宝"全仓押注
- 超长期国债适合有长期负债匹配需求的机构（如保险）
- 关键自测问题：能否接受买入后账面浮亏20%不卖？
- 形式化：`超长期国债角色 = 组合稳定器(小比例) ≠ 主力收益来源`
- 边界：极度厌恶风险且资金长期闲置，超长期国债比存款利率高，可以配置
