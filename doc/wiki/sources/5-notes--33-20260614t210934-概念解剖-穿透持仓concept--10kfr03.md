# 概念解剖 — 穿透持仓（QDII海外浓度）

> 原文ID：a46149a869291035428bf7f309645a04

## 核心论点

穿透持仓（Look-through Holdings）是识破QDII"海外伪装"的分析工具，核心在于**按营收来源地而非上市地判断真实风险暴露**。名字带QDII不等于真正海外分散。

## 关键数据与案例

| 指标 | 数据 |
|------|------|
| 中证海外中国互联网指数 vs 沪深300 相关性 | 0.71 |
| 中证海外中国互联网指数 vs 标普500 相关性 | 几乎无关 |
| 恒生指数中中国企业占比 | 60%以上 |

**瑞幸咖啡案例**：在美股上市，但营收来自中国——上市地≠公司属性。

## 现象描述

- 2020年代"中概股基金"热潮：投中国公司却用QDII额度包装
- 很多QDII基金的"中国含量"接近100%，分散效果存疑
- QDII额度稀缺性与投资者海外配置需求的矛盾，催生了"伪QDII"产品动机

## 分析框架：穿透持仓工具

- **工具**：晨星"穿透持仓"功能
- **指标**：持仓地域分布、行业分布、前十大集中度
- **对比维度**：QDII额度使用情况 vs 实际海外资产占比

## 行动准则

用穿透持仓检查所有QDII基金，确保海外配置名副其实。真正的分散不在名字，在持仓；不在上市地，在营收来源。
