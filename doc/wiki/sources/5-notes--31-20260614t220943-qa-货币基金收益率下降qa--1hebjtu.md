# QA — 货币基金收益率下降：躺赚时代已经过去

来源：[[晨星中国]] 文章，整理于 2026-06-14。

## 核心结论

货币基金收益率从4-5%持续下滑至约2%，"躺赚"时代已经过去。这是资金面宽松与监管收紧双重作用的结果，投资者应放弃固收幻想，按风险偏好重新配置资产。

## Q1：货币基金为什么收益率越来越低？

**机制：** 收益率↓ = 资金面充足（借钱利率↓） + 监管限制（投资范围↓）

- 银行不缺钱，同业拆借利率持续走低，货币基金资产配置收益随之下降
- 2017年监管限制货币基金投资者集中度，防止单一持有人大额赎回引发流动性风险
- 2023年新规强调流动性管理，限制久期和杠杆比例，压缩收益空间
- 天弘余额宝采用比普通货币基金更严格的风控标准，收益率承压更明显

**边界：** 若资金面收紧（如经济过热），货币基金收益率可能回升。

## Q2：美国货币基金的高收益为什么是"幻觉"？

**机制：** 名义高收益（14%） - 高通胀（>10%） = 实际低收益（<4%）

- 美国Q条例限制银行存款利率仅2.5%
- 国债、大宗协议存款利率"高高在上"，吸引资金流入货币市场基金
- 应税型货币基金平均年化收益一度高达14%
- 但同期通胀率超过10%——名义高收益被通胀侵蚀殆尽

**边界：** 若通胀率下降，名义收益率即使不高，实际收益率也可能不错。

## Q3：货币基金收益率下降，还有买的价值吗？

**结论：** 有——相对优势依然存在。

| 资产 | 收益率（参考） |
|------|--------------|
| 货币基金 | ~2% |
| 活期存款 | 0.2% |
| 一年期定期 | 1.55% |
| 四大行三年/五年期定期 | 跌破2.5% |

货币基金可随时提取，兼具流动性和相对收益，对风险厌恶型投资者仍是天然避风港。

**边界：** 追求长期增值的投资者，货币基金并非好资产，股债基金长期增值效果更好。

## Q4：投资者应该如何应对货币基金收益率下降？

**框架：** 活钱 → 货币基金（安全+流动）；长期增值 → 股债基金（风险+收益）

- 货币基金是现金管理工具，不是长期投资工具
- 追求高收益必须承受更高风险
- "既要安全又要高收益"是不现实的预期
- 树立合理的收益和风险预期才是正确的应对方式

**边界：** 完全不能承受风险的投资者，只能接受低收益——这是风险与收益的必然权衡。

## 关键实体

- **天弘余额宝**：案例中的主要参照物，以更严格风控管理，收益率下行幅度较大
- **美国Q条例（Regulation Q）**：历史上限制银行存款利率的监管规定，是理解高通胀时期货币市场基金兴起的背景
- **四大行**：工商银行、农业银行、中国银行、建设银行，其存款利率作为市场基准参照
