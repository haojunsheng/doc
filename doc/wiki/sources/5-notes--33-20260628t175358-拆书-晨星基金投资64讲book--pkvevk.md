# 拆书：《晨星基金投资64讲》

## 核心问题

晨星这 64 篇文章真正在回答的是：**为什么基民总是赚不到基金的钱，以及他们该怎么做才能赚到。**

这不是一个"如何选出好基金"的技术问题——64 篇中有大量篇幅在讲"你选了好基金也赚不到钱"。

**晨星的核心判断：基民不赚钱的根本原因是行为偏差，而非选基能力。**

## 证据链

| 数据 | 来源 |
|------|------|
| 2023 年价值风格基金普遍优于成长风格，但追涨杀跌的投资者收益不如买入持有 | 晨星中国 |
| 2024 年中国基金投资者买卖决策产生的收益比不上简单买入并长期持有 | 晨星中国 |
| 主动基金平均持有成本 2.55% vs 被动基金 1.03% | 晨星中国 |
| 1% 费率占 7% 回报的 15% | 晨星中国 |
| 主动基金战胜同类被动基金比例长期低于 50% | 晨星中国 |
| 主动基金年均换手率 350–400% | 晨星中国 |

> ⚠️ 数据来源为晨星自身统计，属于行业视角，非独立第三方审计。关键数据点（如战胜率、成本差）与[[sources/5-notes--30-20260628t160126-qa-主动基金vs被动基金qa--18qr6go]]、[[sources/5-notes--33-20260628t155829-qa-买方投顾解决基民不赚钱qa--1eb9tzy]]相互呼应，构成一致性证据群。

## 五条基础假设

1. **市场至少是半强式有效的**：股价已反映所有公开信息，依靠公开信息持续跑赢市场极其困难
2. **历史业绩不预测未来**：法马的随机漫步理论、塞勒的输者赢者效应、杰加迪和蒂特曼的动量效应——三个诺贝尔奖得主的结论互相矛盾，说明历史业绩信号价值有限
3. **成本是回报的最大侵蚀项**：主动基金平均持有成本 2.55%，被动基金 1.03%
4. **大多数散户不具备信息优势和研究优势**：机构投资者之间的竞争让定价越来越有效，散户参与主动选股游戏是危险的
5. **投资者的行为偏差是回报的最大杀手**：追涨杀跌、频繁交易、锚定效应、损失厌恶、FOMO——这些不是例外，是常态

动摇任何一条，整本书就塌。

## 晨星基金评价三维定位系统

晨星的取景框是**基金评价 + 行为纠偏**——用定量工具给基金画像，同时用行为金融学问投资者为什么反复犯蠢。

| 维度 | 工具 | 作用 |
|------|------|------|
| 维度一 | [[晨星投资风格箱]]（九宫格） | 按市值×风格将基金定位到九格之一 |
| 维度二 | [[晨星基金分类]]（12个子类） | 建立"苹果比苹果"的比较基准 |
| 维度三 | [[晨星星级评价]]（风险调整回报） | 同风格区内比较基金经理真实投管能力 |

> 这套三维系统让"选基金"从主观判断变成可验证的定位——不是"推荐哪只"，而是"怎么给任何一只基金定位"。

## 散户行为金融学四偏差框架

晨星将散户面临的劣势分为四个层面：

| 偏差类型 | 描述 | 散户能否反超 |
|---------|------|-------------|
| 信息劣势 | 获取公开信息的速度和质量落后于机构 | 否 |
| 研究劣势 | 深度分析和基本面研究能力弱于机构 | 否 |
| 行为劣势 | 追涨杀跌、频繁交易、情绪驱动决策 | **可以**——需行为纪律 |
| 自主性劣势 | 资金有用途约束、流动性需求迫在眉睫 | **可以**——闲钱投资是优势 |

## 本书立场：主动 vs 被动

**最强结论**：在有效性低的市场（如中国），散户参与主动选股游戏更危险。被动投资不仅是有效市场的最优解，也是不完全有效市场里普通人的**风险最低的制胜策略**。

建议行动：低成本指数基金 + 分散配置 + 长期持有 + 控制成本。

## 书中重点引述

> "投资作为一个过程，最有趣的一点就是，它是完全关于每个人自己的，是我们与外界噪音以及自己内心欲望对抗的过程。"
>
> 潜台词：**你的对手不是市场，是你自己。你打败了自己，就打败了市场。**
