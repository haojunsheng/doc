# 不确定市场找可持续回报——晨星2026展望

晨星2026全球展望报告的核心主张是"不做预测只谈应对"。2025年证明了华尔街的预测反复打脸，晨星选择不提供具体点位，而是帮投资者识别长期结构性机会和潜在风险。

## 核心论点

### Q1：为什么"不做预测只谈应对"

2025年地缘政治一夜改变市场走向，华尔街头部机构对美股预测多次变脸。晨星的结论：即便是规模最大的机构也预测不准，应对框架比点位在2026年更有价值。

形式化表达：
```
华尔街2025: 多次预测 → 多次打脸
晨星: 放弃预测 → 构建应对框架
```

边界条件：如果市场进入高度可预测的单边市，应对框架的价值会下降。

### Q2：2026年两种主要不确定性

- **贸易摩擦**：美国尚未消化已实施关税的影响，明年可能进一步提高；若对中国加征新关税，可能引发更大范围动荡
- **货币政策分化**：美联储已重启降息，其他央行倾向于按兵不动或小幅下降；央行政策差异是市场波动的重要来源

形式化表达：
```
不确定性 = 贸易摩擦(关税加码) + 货币政策(央行步调不一)
```

### Q3：AI是2026年影响最深的技术变革，但泡沫风险存在

超大型科技公司数据中心资本支出每年数千亿美元，2026年预计达美国上市能源行业总支出的四倍以上。算力需求带来巨大能源和环境压力，GPU和服务器实际寿命可能低于预期，无法实现计划回报。类比90年代互联网泡沫：资本支出巨大但商业模式未明。

形式化表达：
```
AI: 年支出数千亿 + 数据中心疯狂扩建 → 商业模式不明 + 能源限制 + 成本超支风险 → 类似互联网泡沫
```

边界条件：如果AI加速落地并产生真实盈利，当前担忧会被证明过度。

### Q4：持有宽基美股指数的投资者，已经被动重仓了AI

晨星美国指数与晨星AI指数重叠超过30%。投资者即使不主动买AI主题基金，也已经通过指数大量暴露于AI。AI指数价格/公允价值比自2023年起在74%-114%之间波动，超过100%即为高估。

形式化表达：
```
买美股指数 = 30%被动配在AI → 无需主动追就已经大量暴露
```

### Q5：弱美元是全球配置的转折点

2025年美元大幅下跌标志着美元长期强势周期结束。美国投资者可增加非美配置以分散风险并获得货币升值收益；非美投资者需要管理美元敞口，货币对冲可将分散收益转化为潜在回报，关键在于平衡对冲成本与分散收益。

形式化表达：
```
美元强势周期结束 → 
  美国投资者: 增配非美(估值+货币升值)
  非美投资者: 管理美元敞口(对冲或分散)
```

边界条件：美元如果反转走强，非美配置的汇兑收益会变成亏损。

### Q6：中国"反内卷"政策的机会只适合长期投资者

化解产能过剩需要限产、调结构、削补贴，产能向龙头集中带来盈利改善，但这一过程需数年兑现。电动汽车和电池行业是典型案例，有明确龙头；钢铁、光伏等行业缺乏明确龙头，效果不确定。

形式化表达：
```
反内卷: 限产调结构削补贴 → 产能向龙头集中 → 盈利改善 → 数年兑现 → 只适合长期投资者
```

边界条件：政策执行力度如果不及预期，时间窗口会进一步拉长。

### Q7：三条"不变"建议

1. **独立视角**：最优质机会藏在暂时失宠的资产中（买失宠资产）
2. **理解周期**：繁荣孕育萧条，抵制从众行为（狂热时冷静）
3. **贴合自身需求**：组合核心意义是满足实际需求，不只是追回报（分散抗冲击）

三条都指向同一个底层逻辑：不跟风、不冲动。

形式化表达：
```
三条建议: 独立视角(买失宠资产) + 理解周期(狂热时冷静) + 贴合需求(分散抗冲击)
```

边界条件：逆势布局可能面临阶段性亏损，需要心理承受力支撑。
