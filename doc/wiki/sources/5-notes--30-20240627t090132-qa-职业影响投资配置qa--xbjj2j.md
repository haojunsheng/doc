# 职业影响投资配置 — Q&A

## 概述

本文是一篇面向普通投资者的 Q&A 形式科普文章，介绍了晨星旗下 Ibbotson 的研究框架：将人力资本纳入资产配置决策。核心观点是，人的总财富由金融资本和人力资本共同构成，忽视人力资本会导致风险敞口重叠，从而做出错误的资产配置决策。

## 核心内容

文章包含五个问答，逐层展开：

1. **为什么要把人力资本纳入资产配置？** 总财富 = 金融资本 + 人力资本（未来收入折现），只看金融资产会忽略风险敞口重叠，导致配置偏差。人力资本随年龄增长而减少，金融资本随年龄增长而增加。
2. **为什么教授可以比基金经理更激进？** 教授的收入稳定如国债（隐性债券），金融资产可以更激进（多配股票）；基金经理的收入随市场波动（隐性股票），金融资产需偏保守。
3. **硅谷银行员工犯了什么经典错误？** 工资来自银行，退休金又投了银行股票，18%的资产集中在同一家公司。银行倒闭后失业+投资双杀，是人力资本与金融资产相关性最高的极端案例。
4. **互联网大厂员工为什么资产大缩水？** 工资（互联网）+ 期权（互联网）+ 投资（中概股），三个收入来源都依赖同一行业景气度，形成三重打击。
5. **普通人怎么把人力资本框架用起来？** 先判断职业收入像债券还是股票，在金融资产中做反向配置。行业判断比职业判断更重要——一个"稳定职业"如果所在行业在衰退，人力资本也不安全。

## 关键框架

```
总资产 = 金融资产 + 人力资本(未来收入折现)

职业像债券(收入稳定) → 金融资产多配股票
职业像股票(收入波动) → 金融资产多配债券/现金
```

## 边界条件与限制

- 人力资本难以精确量化（未来收入不确定），只能做粗略估计。
- 教授类比在"非升即走" tenure 制度下失效。
- 如果投资完全分散（如全球指数+债券），行业集中风险可大幅降低。
- 文章同时指出"看清全貌很重要"又承认"看清后若无调整能力，焦虑反而增加"——诊断意义与实际可操作性之间存在张力。
- 行业判断比职业判断更重要，但未展开如何操作化。

## 证据强度评估

中等。核心框架逻辑严密（Ibbotson 方法论基础），但案例推理为主，缺乏量化回测。人类资本的分类（债券型 vs 股票型）依赖定性判断，不同职业分类可能存在主观差异。
