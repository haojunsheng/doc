# 中国基民择时回报差研究 QA

晨星首份中国公募基金投资者回报差研究。核心发现：所有五年期年化投资者回报差均为负值，行业基金亏最多（-3.59%），宽基指数唯一为正（+3%）。差距来自交易行为而非产品本身。

## 核心数据

| 基金类型 | 五年期年化投资者回报差 |
|---------|---------------------|
| 行业基金 | -3.59% |
| 主动股票基金 | -2.65% |
| 积极配置基金 | -2.17% |
| 固收基金 | -0.62% |
| 宽基指数 | +3.00%（唯一正值） |

## 关键结论

- 行业基金投资者实际只拿到基金回报的 4.69%
- 宽基指数正回报差反证产品本身并非问题根源
- 中国市场特殊性：赛道轮动快 + 波动大 → 回报差更剧烈
- 2020年疫情后流动性充裕是高位追入的历史背景

## 建议路径

减少择时操作、分散买入时间、选低波动产品，定投是最简单的改善方式。
