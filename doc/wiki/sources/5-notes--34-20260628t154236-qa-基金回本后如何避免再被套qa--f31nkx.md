# QA — 基金回本后如何避免再被套

> 基金终于回本！但松口气的同时，一个更尖锐的问题浮现：现在该怎么办？继续拿着会不会再次被套？

## 核心论点

**回本不是终点，是重新审视的起点。**

文章将投资决策从"选产品"重新框定为"管理期限错配"——用晨星中国基金分类矩阵揭示一个刺眼结论：大多数基金只适合做组合里的配角，短期和重仓位持有都是错配。

## 关键问题与结论

### Q1: 投资真正的风险是什么？

**结论**：真正的风险不是波动，而是需要用钱时账户还在亏。

```
旧风险: 波动大小 → 新风险: 用钱时点 ∩ 账户状态
```

每个人投资目标不同（养老/买房/旅行），用钱时间不同。波动是通用指标，但"期限错配"才是个人化的致命伤。

**边界**：长期不用钱的人（如 20 岁存养老）确实可以忽略短期波动，此时传统波动衡量仍有效。

### Q2: 为什么"买多久"比"买什么"更优先？

**结论**：持错时间比选错产品更致命——高仓位基金最短回撤恢复期可达 7-10 年。

```
买什么 → 买多久 → 买多少（优先级递减）
```

历史数据显示权益基金最大回撤持续期 7-10 年，消费、医药、科技等行业基金至今未从历史回撤中爬出。用 2-3 年要用的钱买高仓位基金 = 注定焦虑。

**边界**：货币基金/短债基金回撤极小，这类产品不需要考虑持有期问题。

### Q3: "买多少"的核心判断标准是什么？

**结论**：看分散度和复杂度——越分散、越易懂的越适合重仓（核心持仓 40-80%）。

```
核心持仓(40-80%) = 高分散 + 易懂
卫星持仓(0-15%)  = 细分行业 + 复杂策略
```

分散度：资产配置/行业配置/国家配置越分散，风险越小。复杂度：难理解的基金在波动中更容易引发恐慌性操作。

**边界**：行业老手对特定行业有深度认知时，可以放宽复杂度限制。

### Q4: 为什么大多数基金只适合当配角？

**结论**：晨星中国基金分类图中，大量基金只适合长期限+小比例持有，短持或重仓都是错配。

```
基金角色矩阵: 短期×重仓 = 空 | 长期×小比例 = 密集区
```

右下角（长期+小比例）聚集了大量基金类别，这解释了为什么按收益率选基金很难赚钱。

**边界**：少数大盘混合/宽基指数确实可以短期持有，不能一刀切。

### Q5: 普通人投资不犯错的三条底线是什么？

**结论**：选低成本产品 + 持有期匹配 + 高风险仓位不过重。

```
低成本 × 期限匹配 × 仓位克制 → 接近长期成功
```

三条叠加已超越大多数投资者。

**边界**：市场极端黑天鹅（如全球金融危机）时，三条底线仍可能全部失效。

## 持有期四档分类

| 档期 | 持有期 | 匹配目标 |
|------|--------|---------|
| 短期 | 1-2 年 | 旅行/装修 |
| 中短期 | 2-6 年 | 首付/婚礼 |
| 中长期 | 6-10 年 | 子女教育 |
| 长期 | >10 年 | 养老/遗产 |

每档对应不同回撤特征的基金类别，时间越长容错率越高，可承受更大回撤。
