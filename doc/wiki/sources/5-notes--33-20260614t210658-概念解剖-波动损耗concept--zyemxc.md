# 概念解剖：波动损耗（Volatility Drag）

> 晨星文章：为什么A股创十年新高，你却在自选股里"躲牛市"？
> 作者：屈辰晨
> 日期：2026-06-14

## 核心论点

**波动损耗**（volatility drag）解释了"多数个股跑输指数"的数学根源：正收益资产因价格波动，几何平均收益率严格低于算术平均，导致长期实际回报被侵蚀。指数靠少数赢家"补贴"输家而上涨——它不反映平均体验，只呈现赢家贡献后的结果。

## 关键数据

```
硬币游戏期望收益: +5%/次（正面+50%，反面-40%）
A股10年跑赢沪深300的个股比例: 16%
美股10年跑赢大盘的个股比例: <20%
模拟1万人×100次，最幸运者盈利: 1.17亿元（拿走70%+筹码）
半数以上玩家本金: 不到1元
```

## 思想实验：抛硬币游戏

| 轮次 | 结果组合 | 期望值 | 实际结果 |
|------|---------|--------|---------|
| 1次 | +50% 或 -40% | +5% | 随机 |
| 50次 | 25次正 × 25次负 | +5% | 本金持续被侵蚀 |
| 100次（1万人） | 同分布 | +5% | 最幸运者1.17亿，过半归零 |

**核心洞见**：即使每只股票的期望收益为正，波动通过几何平均机制使大多数个体最终亏损。这是数学问题，不是能力问题。

## 指数为何能上涨

指数的上涨来自极少数暴利股票的贡献，覆盖了多数输家的亏损：

1. **成分股权重集中**：头部股票贡献大部分涨幅
2. **汰弱留强机制**：输家被剔除，赢家权重增加
3. **幸存者偏差**：指数永远只保留幸存者

指数 ≠ 市场平均个股表现。它是"赢家补贴输家之后"的结果呈现。

## 与波动拖累的关系

本文从**个股 vs 指数**的应用场景重新论证波动拖累效应：

- [[波动拖累]]页面侧重再平衡和组合层面
- 本文补充了**个股层面**的具体论证：个股有寿命（退市），指数没有（成分轮换）
- 与[[算术收益率vs几何收益率]]直接互证：几何平均 ≤ 算术平均，差距随波动增大而扩大

## 行动指令

计算你过去3年个股组合的年化收益率，与沪深300对比。如果跑输，把至少50%的资金移到指数基金。

## 元反思

- 文章用概率论证"应该投指数"，但16%这个历史数据是否可外推至未来10年未讨论
- 未讨论指数选择（沪深300 vs 中证500 vs 全球指数）和择时问题
- 隐含立场：被动投资优于主动投资——这是晨星的一贯视角
- 未讨论悖论：如果所有人都只投指数，谁做价格发现？指数的有效性是否会自我消解？
