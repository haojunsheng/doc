# QA — 主动基金 vs 被动基金

> 主动基金与被动基金，孰强孰弱？

## 核心数据

晨星中国基金主动被动晴雨表覆盖 **2555只基金、3.5万亿规模**，2022年核心发现：
- **63%** 主动偏股基金跑赢同组被动，中长期超额显著
- 中小盘主动战胜率从 **73%（2021）暴跌至43%（2022）**
- 大盘成长：**66%**；大盘平衡：**63%**，仍保持高胜率
- 消费行业主动一年/三年/五年战胜率仅 **28%-52%**，全行业最差
- 医药/TMT中长期战胜率超 **60%**

## 关键问题与结论

### Q1：为何美国主动跑不赢被动而中国能跑赢？

**结论**：市场有效性不同——美国市场有效性高难寻错误定价，中国市场结构性机会多。

```
美国: 有效性高 → 主动难赢 → 低费被动胜出
中国: 有效性低 → 主动能赢
```

**边界条件**：若A股有效性持续提升（机构化+信息透明），主动超额会收窄。

### Q2：用被动基金而非指数做基准有何意义？

**结论**：投资者买的是有成本的指数基金而非无成本指数，用被动基金做基准更贴近现实。

```
可投资基准 = 被动基金(有成本) ≠ 指数(无成本) → 更贴近实际
```

**边界条件**：若某被动基金费率极高或跟踪误差大，作为基准会有偏差。

### Q3：中小盘主动战胜率为何从73%暴跌至43%？

**结论**：2022年中小盘风格剧烈切换+市场环境严峻，主动经理难以应对快速轮动。

```
中小盘主动: 73% → 43% → 风格轮动↑ + 环境严峻 → 主动失效
```

**边界条件**：若2023年中小盘风格回归稳定，中小盘主动战胜率可能回升。

### Q4：消费行业主动为何难以获取超额？

**结论**：消费行业研究透明度高、定价有效，主动经理难以找到错误定价机会。

```
消费行业 = 研究透明 + 定价有效 → 错误定价↓ → 主动超额↓(28%-52%)
```

**边界条件**：若消费行业出现结构性变化（如新消费趋势），主动经理可能找到机会。

### Q5：医药和科技传媒通讯行业为何主动能持续超额？

**结论**：行业复杂度高、研究壁垒强，主动经理的专业知识能创造信息优势。

```
医药/TMT = 高复杂度 + 高壁垒 → 信息不对称 → 主动超额(>60%)
```

**边界条件**：若AI辅助研究普及、信息不对称降低，这些行业的主动超额可能收窄。

### Q6：投资者该选主动还是被动？

**结论**：取决于个人能力——能选到绩优主动经理选主动，否则选低费被动更稳妥。

```
选基金 = 能选绩优主动(选主动) vs 不能(选低费被动)
```

**边界条件**：若未来主动基金整体超额收窄，被动基金会成为更优默认选项。

## 收口

中国主动基金能跑赢被动，不是因为中国市场无效，而是因为"机构化程度不够+信息不对称"给了主动经理超额空间——但这个空间正在缩小。
