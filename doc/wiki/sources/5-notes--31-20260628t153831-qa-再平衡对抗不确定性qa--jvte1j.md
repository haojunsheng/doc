# 再平衡对抗不确定性 QA

晨星首席投资官吴刚撰文，以 Q&A 形式阐述再平衡如何以规则替代择时。

## 核心论点

文章给出 7 个问答，层层递进：

1. **择时 vs 再平衡**：择时依赖少数关键交易日的判断，错一次就出局；再平衡把决策从"市场往哪走"变成"组合偏离没有"，问题可答可控。
2. **再平衡的核心动作**：设目标比例 → 检查偏离 → 卖超买欠 → 回到目标，全程机械可执行。
3. **情绪根源**：很多人"涨了不敢拿、跌了不敢守"的根源是投资开始时跳过了设定目标配置的步骤，没有锚就没有纪律。
4. **牛市四方向变形**：股债比例失衡、行业过度集中、风格偏向成长、资产集中于国内——四个方向都因上涨而被动超配。
5. **卖飞不是缺陷**：再平衡卖的是"超出计划"的部分，不是清仓；少赚不等于亏，防止的是组合承担超出承受力的波动。
6. **触发阈值**：偏离 5-10 个百分点时动手，微小偏离是正常波动，频繁交易反而损耗收益。
7. **终极价值**：把无解的"市场往谁走"变成可控的"组合在不在计划内"，拉开长期收益差距的是这种简单纪律。

## 关键边界

- 极强单边趋势中再平衡会少赚，但"永远在场"优于择时出局
- 目标配置本身需要个人风险测评，一旦设定不能随意变
- 四方向变形是 2024-2026 牛市特定产物，不同市场环境变形方向不同
- 阈值非铁律，极端行情（短期暴涨 30%）可提前关注

# 组合变形——牛市四方向

牛市中，组合因强势资产上涨而被动偏离目标配置，呈现四个典型变形方向。

## 四个方向

| 方向 | 机制 | 表现 |
|------|------|------|
| 股债比例失衡 | 股市上涨 → 股票仓位自然超出目标 | 股票占比远高于预设比例 |
| 行业过度集中 | 持有 3-5 只基金但全押同一批赛道（如半导体/AI） | 表面分散、实质集中 |
| 风格偏向成长 | 成长风格跑赢价值 → 组合"成长化"而不自知 | 风格敞口偏离目标 |
| 资产集中于国内 | A 股强势 → 国内仓位被动提高 | 海外配比低于目标 |

## 形式化

```
牛市 → 强势资产涨得多 → 组合自动偏向强势资产 → 偏离目标
```

## 边界

- 这四个方向是 2024-2026 牛市的特定产物，不同市场环境下变形方向不同
- 熊市时债券可能超配，变形方向相反
- 再平衡是纠正组合变形的核心手段

## 与再平衡的关系

再平衡的本质就是对抗组合变形：定期把涨多的卖掉、跌多的买回来，让组合回到目标配置。偏离 5-10 个百分点时触发操作。
