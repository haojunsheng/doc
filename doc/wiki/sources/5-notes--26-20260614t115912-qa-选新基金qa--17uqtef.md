# 新基金筛选五维度框架

从五个维度判断一只新基金是否值得买。

## 一、填补空白或策略创新

**结论**：只有两种情况值得买——要么它填补了市场空白（从0到1），要么它在策略上有真正创新。

**正面案例**：2021年首批REITs基金，新增基础设施资产配置选项，填补市场空白。

**反面案例**：同类GARP基金已经泛滥，新基金只是"又一个GARP策略"，没有差异化价值。

**形式化**：`新基金价值 = 填补空白 + 策略创新`；跟风 ≠ 价值

**边界**：市场空白会随时间被填补——今天的差异化，明天可能就成了同质化。

## 二、不追热点基金

**结论**：热点消退后，主题基金几乎必然跑输宽基指数，且超过60%的主题基金最终清盘。

**形式化**：`热点基金 = 短期炒作 + 长期跑输 + 高概率清盘`

**数据**：晨星全球研究——过去15年，超过60%的主题基金已清盘；多数主题基金未能跑赢宽基指数。

**边界**：如果主题背后有长期结构性趋势（如人口老龄化、技术创新），可能例外——但需要严格甄别。

## 三、看基金经理的"相关经验"

**结论**：评估新基金的基金经理，要看他在**其他产品上**的**相关**经验，不是总从业年限。

**形式化**：`基金经理能力 = 相关资产经验 + 历史业绩 + 知行合一`

**核心判断**：
- 15年从业经验，但和这只基金相关的投管经验只有2年——信心要打折扣
- 晨星官网和基金公司网站可查：历史业绩、风险收益特征、持仓等

**边界**：历史业绩不代表未来——但它是唯一可参考的客观数据。

## 四、招募说明书信号

**结论**：从招募说明书的三个关键词可判断组合逻辑的稳健/激进倾向。

| 关键词 | 信号 |
|--------|------|
| "长期价值投资""买入并持有" | 偏稳健 |
| "灵活把握短期机会""战术性配置" | 偏激进 |
| "权益比例上限20%"（债券基金） | 风险比纯债高，波动更大 |

**形式化**：`招募说明书信号：长期持有 = 稳健；灵活操作 = 激进；权益上限 = 风险上限`

**边界**：招募说明书是"承诺"，不是"保证"——基金经理可能实际操作偏离说明书。

## 五、费率决定长期存活与跑赢概率

**结论**：费率是确定性成本，低费率基金长期存活并跑赢同类平均的概率更高。

**形式化**：`费率 = 确定性成本；低费率 → 高存活率 + 高跑赢概率`

**晨星研究结论**：在风格、行业配置、市值风格相同的情况下，优先选费率低的。高费率必须证明创造了相应价值——否则就是给基金公司打工。

**边界**：如果高费率能带来显著超额收益（如顶级基金经理），可以接受——但这种案例极少。

## 收口

选新基金不是选"看起来好的"，是选"适合你的"——先搞清楚你要什么，再找能满足的。

# 热点基金陷阱

主题基金追涨的陷阱：热点消退后几乎必然跑输宽基指数，且清盘率极高。

## 核心论点

投资者在热点爆发时追入主题基金，但热点消退后：

1. **跑输宽基指数**：晨星全球研究显示，多数主题基金未能跑赢宽基指数。
2. **清盘率高**：过去15年，超过60%的主题基金已清盘。
3. **投资者实际收益更差**：投资者往往在高点买入、低点卖出——实际收益比基金业绩更差。

## 形式化

`热点基金 = 短期炒作 + 长期跑输 + 高概率清盘`

## 认知机制

与 [[宏大叙事]] 共享同一认知偏差：投资者被宏大叙事吸引，忽略历史数据中主题基金的高清盘率和低持续性。

## 边界条件

如果主题背后有**长期结构性趋势**（如人口老龄化、技术创新），可能例外——但需要严格甄别，避免将短期热点误判为长期趋势。

## 与泡沫识别的关系

[[泡沫-投资语境]] 中的"这次不一样"叙事陷阱，在主题基金追涨中反复上演。

# 招募说明书信号

从招募说明书的关键词判断基金经理的策略倾向与风险上限。

## 三个关键信号

| 关键词 | 判断 |
|--------|------|
| "长期价值投资""买入并持有" | 策略偏稳健 |
| "灵活把握短期机会""战术性配置" | 策略偏激进 |
| "权益比例上限" | 风险上限指标（如债基可投20%股票，风险高于纯债） |

## 形式化

`招募说明书信号：长期持有 = 稳健；灵活操作 = 激进；权益上限 = 风险上限`

## 性质

这是**启发式**方法，不是严谨的分析工具。招募说明书是"承诺"，不是"保证"——基金经理可能实际操作偏离说明书。

## 适用场景

主要用于新基金筛选（[[新基金筛选五维度框架]] Q4），帮助在没有历史业绩的情况下建立初步判断。

# 费率侵蚀效应

费率是基金投资的确定性成本，它会直接侵蚀收益，且低费率基金长期存活并跑赢的概率更高。

## 核心论点

- 费率 = 确定性成本（区别于不确定的管理费回报）
- 低费率 → 高存活率 + 高跑赢概率
- 晨星研究支持：在风格、行业配置、市值风格相同的情况下，费率是区分基金未来表现的显著因素

## 形式化

`费率 = 确定性成本；低费率 → 高存活率 + 高跑赢概率`

## 边界

高费率可以接受，但必须证明它创造了相应价值——否则就是给基金公司打工。顶级基金经理带来的显著超额收益是少数例外。

## 与综合费率的关系

[[综合费率]] 从成本构成角度描述费率结构；本文从长期结果角度描述费率的侵蚀效应，两者互补。
