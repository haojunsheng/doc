# 失败者游戏在中国市场是否适用

## 问题陈述

查尔斯·艾利斯（Charles Ellis）的"失败者游戏"理论建立在美股高度有效的背景下。但在中国市场，散户占比高、定价效率低，文章的元反思明确指出这一张力：**"中国可能更适合主动投资"**，但同时引用了艾利斯。这个矛盾未被解决。

## 核心张力

| 论点 | 依据 |
|------|------|
| 失败者游戏适用于中国 | 机构占比持续提升，市场有效性逐年增强 |
| 失败者游戏在中国不适用 | 散户占比高、信息不对称严重、定价效率低 |
| 中间立场：市场不完全有效，但普通人参与主动投资反而更危险 | 超额收益属于有能力的玩家，普通人更可能被收割 |
