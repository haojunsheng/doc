# 风格漂移还是风格进化如何区分

## 问题背景

晨星分类体系通过"风格箱 vs 风格分类"的时间差来监测风格漂移：当期风格箱与基金分类不一致 = 风格漂移信号。但这一信号存在解释上的模糊性——基金经理的调整是"漂移"还是"进化"？

## 核心张力

- **风格漂移**：基金经理偏离原有投资风格，追求短期收益或盲目追逐热点
- **风格进化**：基金经理在市场环境变化时主动调整策略，是适应能力的体现

两者的边界在哪里？同样是风格调整，什么情况下是坏事，什么情况下是好事？

## 开放问题

1. 如何区分主动的风格进化与被动跟随的市场噪音？
2. 风格调整的频率与幅度是否构成判断标准？
3. 投资者应该容忍多少风格调整？还是必须严格执行原有分类？
4. 基金经理的"进化"是否应该被奖励，还是其初衷（为持有人利益调整 vs 为业绩排名追热点）更重要？
