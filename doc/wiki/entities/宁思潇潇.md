# 宁思潇潇

## 简介

《新摄影笔记》作者，摄影笔记公众号创始人，摄影教育者。花了十年看同一批人犯同一个错误，并以此作为写书的直接动因。

## 教学观察来源

蜂鸟网二手交易板块里大量"买了几年基本没用过，不太会用也拍不好还是卖了吧"的帖子——这些啼笑皆非的案例是他挠痒处。他看到的现象：摄影教育最大的问题不是没人教，是教得零散、教得混乱、教得让学生越学越怕。

## 核心定义

他把摄影定义为：

> "摄影就是记录下您到达并发现的、触动您内心的场景及瞬间。"

这句话放在前言最先说，作为整本书的地基。十年后忘了焦距分类、忘了曝光补偿，但记得这句话，就还在摄影的正道上。

## 五条公理

1. **摄影技术可以被穷举**——取景、曝光、虚实、构图，四个方面就是全部，分清分净，再无其他
2. **器材不是摄影的决定因素**——同样的手机、同样的相机，决定照片好坏的是内容选择，不是像素和镜头价格
3. **散点教学必然失败**——摄影知识如果不被纳入一个逻辑框架，学生背下所有技术参数依然拍不出好照片
4. **"有感而拍"是摄影的起点**——没有值得记录的主题，一切技术都是空转，这一点放在前言最先说
5. **先搭框架再填细节**——先理解"一张好照片是由什么构成的"，再学"每个参数具体怎么调"

这五条任塌一条，整本书就散了。

## 核心逻辑线

**"主题是目的，四项是手段"**——贯穿全书的逻辑主线。他看任何一张照片，第一反应不是"这张用了什么镜头"，而是"主题是什么，取景怎么做的，曝光怎么控的，虚实怎么处理的，构图怎么排的"。

## 摄影四件事框架

他将摄影拆解为四个可练习的控制面，构成技术全景图：

| 控制面 | 对应 wiki 条目 | 核心含义 |
|--------|--------------|---------|
| 取景 | [[取景作为排除]] | 决定画面纳入什么、排除什么 |
| 曝光 | [[曝光作为情绪控制]] | 画面亮成什么情绪，对抗 18% 灰默认世界观 |
| 虚实 | [[虚实作为注意力阀门]] | 清楚与模糊的组织，分配注意力 |
| 构图 | [[构图是视线管理]] | 元素怎么站位，视线怎么走 |

```
触动 → 主题
  |
  +--> 取景：画面里放什么
  +--> 曝光：画面亮成什么情绪
  +--> 虚实：哪里清楚，哪里模糊
  +--> 构图：元素怎么站位，视线怎么走
  |
  v
表达：让观者也感到那一下触动
```

## 技术体系贡献

### 取景

- [[焦距与题材匹配]]：超广角≤24mm / 标准广角24-28mm / 人文眼35mm / 标准50mm / 人像85mm / 长焦200-300mm / 超长焦≥300mm
- [[取景四要素]]：内容（放什么）、范围（多大）、时机（何时）、角度（从哪看）
- [[测光模式二分]]：评价测光 / 点测光
- [[曝光补偿 EV 量化]]：EV 数值体系及"白加黑减"口诀
- [[安全快门]]：手持拍摄不糊片的经验法则
- [[陷阱对焦]]：预先对焦在固定位置等待主体进入焦平面的手动策略

### 曝光

- [[影调三分类]]：高调 / 低调 / 中间调，以 18% 灰为分界
- [[18%灰]]：相机默认测光想拉回的中间亮度，"白加黑减"是反抗这个中庸

### 虚实

- [[景深四要素]]：光圈 / 焦距 / 拍摄距离 / 前景深后景深关系
- [[对焦三模式]]：MF / AF-S / AF-C
- [[超焦距]]：利用前景深最大化清晰范围的对焦策略
- [[前后帘闪光同步]]：闪光与快门配合的两种模式

### 构图

- [[居中法构图]]：主体大或对称时使用
- [[三分法本质是不居中]]：三分法的底层逻辑是避开居中，而非放交点
- [[三分法]]：九宫格、视觉中心（4 个交点）
- [[主体朝向空旷面]]：三分法应用中主体朝向应留有空旷空间
