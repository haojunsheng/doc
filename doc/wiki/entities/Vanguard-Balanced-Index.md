# Vanguard Balanced Index

美国最大的多资产指数基金，由 Vanguard 管理，1992 年成立以来规模达 623 亿美元。

## 市场定位

- 属于美国混合型被动基金品类
- 该类基金在美国被动基金总量中仅占 0.36%（38 只/764 亿美元）
- 即使在美国这个被动投资最成熟的市场，多资产指数基金也仍属小众品类

## 意义

作为多资产指数品类的标杆案例，说明该策略在美国经过三十余年验证，但渗透率仍然很低，折射出编制复杂度和投资者认知两方面的障碍。
