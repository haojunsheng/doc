# 美国最高法院

美国最高司法机关，2026年春节期间裁定特朗普依据《紧急经济权力法》（IEEPA）加征的关税无效，这一裁决直接触发后续关税法律路径的升级。

## 关键裁决

- **裁决内容**：特朗普依据 IEEPA 加征关税超越总统紧急权力范围，属越权行为，判决无效
- **裁决时间**：2026年春节期间（约2月）
- **直接影响**：IEEPA 依据下的关税失去法律效力，全球市场一度预期关税将取消

## 裁决后的连锁反应

裁决公布后数小时内，特朗普政府宣布依据《贸易法》第122条加征10-15%新关税，并将第301条款调查提速。法律升级路径：

```
IEEPA关税被推翻
  → 第122条（150天临时，10-15%）
  → 第301条（无限期，可能更高）
```
