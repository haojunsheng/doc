# 胡润（Hurun Report）

《胡润财富报告》（Hurun Rich List）是中国最具影响力的高净值人群财富调研报告之一，由胡润研究院发布。

## 高净值定义（中国）

| 层级 | 可投资资产门槛 |
|------|--------------|
| 富裕家庭 | 600万人民币 |
| 高净值家庭 | 1000万人民币 |
| 超高净值家庭 | 1亿人民币+ |

> 注："可投资资产"指扣除自住房产后的金融资产，包括股票、基金、银行理财、现金等。

## 主要发现（与本文相关）

- 中国高净值人群中，企业主和金领占比超过70%
- 靠房地产和投资（股票、基金）致富的比例在下降
- 新房销售和二手房价格承压，租金回报率低（约2.2%–2.3%）

## 与其他机构的对比

- 私人银行标准通常更高：高净值门槛为1000万可投资资产
- 普华永道（PwC）全球标准：100万美元（约700万人民币）为高净值门槛
