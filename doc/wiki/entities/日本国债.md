# 日本国债

日本主权债券，晨星2026Q2全球配置观点中重点提及的资产类别，从"有吸引力"下调至"中性"。

## 基本特征

- **货币**：日元（JPY）
- **定价基准**：10年期日本国债收益率（JGB 10Y）
- **风险特征**：日本是能源净进口国，油价对输入性通胀和财政路径有双重冲击

## 2026Q2晨星配置观点

| 指标 | 现状 |
|------|------|
| 配置观点 | ↓ 从"有吸引力"下调至"中性" |
| 核心驱动 | 油价上涨叠加财政扩张与央行偏紧，三重压力尚未被收益率充分补偿 |
| 价格位置 | 10Y收益率升至数十年高位，但风险补偿仍不足 |

## 三重压力框架

```
输入性通胀 + 财政扩张 + 央行偏紧 → 三重压力 → 日债配置价值下降
```

| 压力来源 | 机制 |
|---------|------|
| 油价上涨 | 日本是能源进口国，油价↑直接推升国内通胀 |
| 财政扩张 | 大规模财政刺激加剧债务负担，信用风险溢价上升 |
| 央行偏紧 | 日本央行短期维持偏紧政策立场，降息无望 |

## 与英债对比

| 维度 | 日本国债 | 英国国债 |
|------|---------|---------|
| 2026Q2配置观点 | ↓ 中性 | ↑ 有吸引力 |
| 收益率位置 | 10Y达数十年高位 | 中短端收益率上行已覆盖风险 |
| 核心压力来源 | 输入性通胀 + 财政扩张 + 央行偏紧 | 中东地缘冲突导致收益率曲线波动 |
| 风险定价状态 | 还在消化冲击 | 不确定性溢价已被定价 |

## 边界条件

如果油价回落或日本央行意外转向宽松，日债的配置价值会重新上升。
