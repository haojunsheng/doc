# 彭珂

易方达基金管理有限公司基金经理，2026年接任易方达行业领先混合，是冯波的继任者。

## 基本信息

| 项目 | 内容 |
|------|------|
| 从业年限 | 11年（研究员背景） |
| 投管经验 | 1年（接管易方达行业领先混合时仅6天） |
| 当前管理 | 易方达行业领先混合（新任）、易方达科益混合 |
| 管理风格 | 从研究员转型，与冯波风格不同 |

## 业绩表现

彭珂管理的另一只基金**易方达科益混合**，一年多业绩落后同类平均。这一业绩记录是评估其能力的参考依据，但样本量有限。

## 能力评估

晨星的判断是：**目前无法判断彭珂能否接好易方达行业领先混合**。理由：

1. 投管经验极短（接管旗舰基金时仅6天经验）
2. 历史业绩落后同类
3. 未经历完整市场周期考验
4. 研究员出身，风格与冯波差异明显

晨星明确建议"需要经过完整市场周期（3-5年）考验"才能做出可靠判断。
