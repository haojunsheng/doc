# 刘万锋

中国公募基金行业基金经理，2026年接棒马龙成为招商产业债券基金经理。

## 案例角色

在马龙卸任案例中，刘万锋作为继任者出现。晨星文章将其作为"增聘不一定等于跑路"的引子案例——投资者需要评估的是继任者的能力与投资流程的稳定性，而非情绪化恐慌赎回。
