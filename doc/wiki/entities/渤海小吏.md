# 渤海小吏

中国当代历史写作者，以《楚汉双雄》闻名，擅长从底层机制角度分析历史事件，不满意标签化答案，追问「故事背后的底层逻辑」。

## 写作风格

- 用 x → f → f(x) 的分析框架组织全书：问题→机制→行动指引
- 核心方法：拒绝「项羽刚愎自用」「刘邦善于用人」等标签式解释，追问结构性机制
- 强调「算术」而非「暴政」来解释秦朝崩溃
- 用具体数据支撑论点（运粮成本、人口估算、役夫数量）

## 代表作

- 《楚汉双雄》：以「系统厚度」为框架，重新解读秦亡、项羽败、刘邦胜的共同底层逻辑
- 《南北归一》：以「北人南下为六朝盛衰总纲」为核心论断，系统分析南朝五朝更替与北朝统一的历史机制
- 《两汉风云》《大唐气象》等作品构成其历史分析谱系
