# 泡泡玛特

潮玩龙头公司，年内暴涨后单周跌12%，成为新消费板块基金经理分歧的核心案例。

## 行情表现

- 年内涨幅显著（具体点位未披露）
- 单周最大跌幅12%
- 与老铺黄金同期大跌（跌13%）
- 基金经理分歧焦点：成长机会 vs 泡沫定价

## 基金经理分歧全景

| 基金经理 | 投资框架 | 操作 | 核心理由 |
|---------|---------|------|---------|
| 熊潇雅 | 成长框架 | 2023年Q1买入 | 海外门店盈利模型验证，低估+业绩低谷布局 |
| 萧楠 | 成长框架 | 2021年重仓→2022年减持→2025年继续减持 | 低估时代潮流力量；后判断第一曲线走完 |
| 戴军 | 泡沫定价框架 | 不碰 | 认为属泡沫定价，低价非竞争壁垒 |

## 关键分析框架

### 熊潇雅的成长框架

**形式化链条**：
```
低估值+业绩低谷买入 → 海外扩张验证 → 估值↑+业绩↑ → 超额收益
```

**调研发现**：海外门店能迅速盈利，海外市场对潮文化IP接受度高，产品能卖高价。

### 萧楠的认知迭代

**2022年反思**：低估了一家年轻公司的可能性、独特性和时代潮流力量。

**2025年减持逻辑**：
- 新消费公司上市时第一成长曲线基本走完
- 第二曲线：海外扩张，但不明朗
- 判断：竞争者蜂拥而入，继续减持

**形式化链条**：
```
估值↑ → 第一成长曲线走完 + 第二曲线不明朗 + 竞争者蜂拥 → 减持
```

### 戴军的泡沫定价框架

**判断**：泡泡玛特属于"泡沫定价"——将偶然性因素（潮流风口）过度资本化。

**核心观点**：低价不是竞争壁垒，市场默认利润可持续很久是荒谬的。

## 股价过度波动案例

泡泡玛特是[[股价过度波动之谜]]的典型个案：

- Labubu爆红（短期事件）→ 市场将其放大为长期IP商业化逻辑 → 目标价越喊越高 → 股价狂飙
- [[预期外推偏差]] 在此案例中清晰可见：分析师将短期销量暴涨、IP出海成功线性外推为长期增长
- [[FOMO行为偏差]] 驱动追高买入，形成情绪溢价
- 最终增长不可持续，股价回调——符合"预期超前→修正"的经典剧本

**边界条件**：若泡泡玛特成功将IP拓展到主题乐园/影视衍生领域（参考[[迪士尼]]、[[三丽鸥-sanrio]]模式），"护城河未建成"的判断可能被推翻，波动剧本也可能改变。
