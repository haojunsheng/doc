# 小米（小米集团-W）

**股票代码**：1810.HK / 81810.HK  
**创始人**：雷军  
**赛道定义**：以手机为入口、AIoT 为触手、汽车为最大终端的"人车家"消费硬件操作系统  
**定位**：秩序创造机器（正在验证中，尚未完全证明）

## 基本信息

| 项目 | 内容 |
|------|------|
| 2026 年 5 月股价 | 约 HK$28-30 |
| 市值 | 约 HK$7200-8000 亿 |
| TTM PE | 约 15.6 倍 |
| 现金储备 | RMB2326 亿（净现金状态） |
| 52 周高点 | HK$61.45 |

## 三根轴映射

| 轴 | 对应业务 | 作用 |
|---|---|---|
| 地板业务 | 手机 + AIoT | 决定下限，提供用户规模和硬件入口 |
| 利润锚 | 互联网服务 + 手机高端化 + AIoT 毛利 | 决定当前合理估值 |
| 天花板业务 | 智能汽车 + 人车家生态 + AI | 决定能否重新拿成长平台估值 |

**分析提示（现有版本）**：
- 地板业务（手机/IoT）决定下限，是现金流基础
- 利润锚（高端化/IoT/互联网服务）决定当前合理 PE 区间
- 天花板业务（汽车）是当前估值争议的主要来源——市场是否愿意给汽车业务成长溢价，决定了股价能否进入成长价/乐观价区间

## 飞轮结构

```
手机用户规模 → AIoT 设备连接 → 家庭场景密度
    → 用户习惯和品牌信任 → 汽车成为最大智能终端
        → 人车家系统协同 → 更高客单价和更强用户黏性
```

飞轮在转，但尚未完全闭合。

## 护城河资产清单

1. 全球手机出货前三（第 5 年）及渠道网络
2. 超 11 亿台 AIoT 连接设备
3. 米家 App、HyperOS、AI 助手等软件入口
4. 小米之家和全球新零售网络（490 家智能 EV 销售中心）
5. 高性价比供应链能力
6. 雷军个人品牌与小米用户社区
7. 汽车带来的新高客单价终端

**关键判断（新增版本）**：单一资产可复制，但组合起来很难。手机厂商做车难，车企做手机和智能家居更难。

## 两条 S 曲线状态

- **手机+AIoT**：已进入成熟期，正在主动做产品结构优化（ASP 创新高、出货量下降）
- **汽车**：处于高速爬坡期，"产品周期+产能爬坡+成本波动"的拐点区

## 关键问题（合并两处版本）

现有版本指出：

> 小米的核心问题不是"手机卖不卖得出去"，而是：汽车能否从叙事变成可持续利润池。

新增版本列出五条核心跟踪问题：
1. 2026 年 55 万辆交付目标的现实性（前四个月仅完成约 19.8%）
2. Q1 亏损是一次性扰动还是结构性压力（需等到中报确认）
3. YU7 和新一代 SU7 是否依赖补贴换量
4. 车主手机/IoT/服务复购率是否显著提高
5. AI 投入能否形成系统级体验

## 与美团、腾讯的对比

| 公司 | 本质 | 利润锚状态 | 风险特征 |
|------|------|----------|------|
| 美团 | 物理履约网络 | 被竞争打穿后等待修复 | 利润锚不稳定 |
| 腾讯 | 数字秩序现金牛 | 已固化，用现金流买 AI 期权 | 低波动、高确定性 |
| 小米 | 硬件生态公司 | 正在从手机/互联网服务向汽车转移 | 高成长但高波动 |
