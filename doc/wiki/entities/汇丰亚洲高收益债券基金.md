# 汇丰亚洲高收益债券基金

## 简介

汇丰亚洲高收益债券基金是一只专注于亚洲地区高收益债券的基金产品，由[[entities/汇丰投资-hsbc-investment]]管理，属于晨星焦点基金系列分析对象之一。

## 投资策略

基金主要投资于亚洲地区信用评级低于投资级（BBB-）的高收益债券，通过信用下沉策略获取比投资级债券更高的票息收益。

## 持仓特征

亚洲高收益债市场以中国房地产债和东南亚企业债为主：
- 中国房地产企业在亚洲高收益债中占比较高
- 东南亚国家（印尼、印度等）企业债构成另一重要组成部分

## 风险收益特征

| 维度 | 说明 |
|------|------|
| 收益来源 | 无风险利率 + 信用利差 |
| 主要风险 | 信用风险（违约）> 利率风险 > 流动性风险 |
| 市场环境 | 低利率环境下吸引力提升，但需承担相应风险 |
