# Ray Dalio

Ray Dalio，桥水基金创始人。1987 年发表文章"赚钱还是做预测"，提出核心观点：

> "预测的价值并不是很高，而且大多数做预测的人并没有在市场上赚钱……原因是没有什么是确定的。"

该观点被晨星中文用于佐证年终策略会预测的低价值。
