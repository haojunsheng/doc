# 华泰柏瑞基金

华泰柏瑞基金管理有限公司，国内公募基金管理公司之一，在红利指数产品线上有较强的品牌心智和产品积累。

## 主要产品线

### 红利指数系列

华泰柏瑞在红利ETF赛道布局完整，被称为"红利全家桶"：

- **华泰柏瑞中证红利低波动ETF（512890）**：跟踪中证红利低波动指数（H30269），规模约311.87亿元（2026-03-31），是国内规模最大的红利低波ETF之一
- **华泰柏瑞中证港股通高股息投资ETF（QDII）（513530）**：跟踪中证港股通高股息投资指数，采用QDII模式，净资产约33.16亿元（2026-03-31）
- **华泰柏瑞港股通红利低波ETF（520890）**：港股高股息+低波过滤组合

### 联接基金

华泰柏瑞针对上述ETF均设有场外联接基金，其中：
- 红利低波ETF联接A（007466）：A类份额规模约64.12亿元（2026-03-31）
- 港股通高股息ETF联接C（018388）：C类份额约4.946亿元（2026-03-31），跟踪误差低（日均偏离0.020%）

## 在红利赛道的位置

华泰柏瑞是红利指数ETF赛道的核心玩家，其512890是国内规模最大的红利低波ETF。但在港股高股息方向，其产品（513530）竞争尚不充分，仍存认知差；而A股红利低波已被充分讨论，进入加速期后段。

与南方基金、广发基金、嘉实基金、华夏基金等同赛道管理人相比，华泰柏瑞的差异化优势在于：
- 产品线完整度高（A股红利低波 + 港股高股息 + 港股高股息低波）
- 指数规则纪律性强（连续分红、支付率过滤、低波筛选）
- QDII模式在港股红利税处理上可能具有相对优势（需实际数据验证）
