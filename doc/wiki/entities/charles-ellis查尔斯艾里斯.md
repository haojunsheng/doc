# Charles Ellis（查尔斯·艾里斯）

投资管理公司 Greenwich Associates 创始人，指数投资理论的重要阐述者。

## 核心贡献

### "无聊是指数投资者的美德"

这句格言被[[Q7: 投资这个游戏真正的对手是谁？]]引用，作为晨星 64 讲收口论断的核心支撑。含义是：投资者最大的敌人是追涨杀跌的冲动，无聊意味着纪律，而纪律是指数投资成功的核心。

## 在晨星 64 讲中的作用

[[Q7]] 中作为格言来源被引用，与格雷厄姆的"正确思考 + 独立思考"并列，共同支撑"投资对手是自己"的收口论断。
