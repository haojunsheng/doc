# 东京证券交易所

东京证券交易所（Tokyo Stock Exchange，TSE）是日本最大的证券交易所，也是推动日本企业治理改革的核心制度力量。

## 核心制度：PB<1强制改善规则

2023年，东京证券交易所发布要求，强制市净率（PB）低于1的上市公司提交资本效率改善计划，否则将在2026年面临退市风险。

### 规则要点

| 要素 | 内容 |
|------|------|
| 触发条件 | 市净率（PB）< 1 |
| 义务 | 必须向交易所提交改善资本效率的具体计划 |
| 改善手段 | 股份回购、股息提升、战略调整等 |
| 不合规后果 | 2026年起面临退市风险 |
| 政策目标 | 提升日本企业资本效率，扭转长期低ROE困局 |

### 改革逻辑

```
PB<1 → 市场认为资本利用效率低 → 强制改善计划 → 回购/分红↑ → 资本效率↑ → 股价修复
```

## 对日本股市的影响

- **推动回购潮**：大量PB<1公司开始大规模股份回购，直接支撑股价
- **倒逼治理改革**：管理层从"规模扩张"转向"资本效率优先"
- **与巴菲特加仓逻辑呼应**：[[entities/日本五大商社]]中提到的"管理层克制、股东友好"特征，正是东交所改革意图的制度性成果

## 边界条件

- 若日本经济持续疲软、企业盈利无法实质性改善，强制回购可能流于形式
- 退市执行的严格程度仍有待观察，2026年时间节点的 Enforcement 力度是关键变量
