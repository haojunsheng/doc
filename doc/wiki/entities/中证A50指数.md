# 中证A50指数

**中证A50指数**（CSI A50 Index）是2024年与中证A500指数同年推出的兄弟指数，由中证指数公司编制，代表A股市场超大盘股。

## 基本信息

- **成分股数量**：50只
- **推出时间**：2024年
- **编制主体**：中证指数公司
- **定位**：超大盘股基准，与A500形成风格互补

## 核心特征

- 嵌入ESG理念，与A500同源
- 强调行业均衡和分散持股
- 要求各中证二级行业入选股票不少于1只
- 市值规模大于A500，代表超大盘风格

## 与中证A500的关系

两者为"兄弟指数"关系，非竞争关系：

| 维度 | 中证A50 | 中证A500 |
|------|---------|----------|
| 成分股数量 | 50只 | 500只 |
| 代表风格 | 超大盘 | 大盘 |
| 集中度 | 更高 | 较低 |
| ESG筛选 | 是 | 是 |
| 行业均衡 | 是（二级行业≥1只） | 是（一级行业自由流通市值分布） |

**形式化：** `A500 = 大盘（500只） ⊥ A50 = 超大盘（50只）`

## 边界条件

若市场风格明确偏向大盘或超大盘，两只指数中总有一只更占优；两者适合不同风险偏好的投资者进行组合配置。
