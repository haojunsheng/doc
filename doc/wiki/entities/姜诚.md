# 姜诚

## 基本信息

- **身份：** 基金经理
- **现管理基金：** [[中泰星元价值优选]]
- **所在机构：** 中泰资产（上海）基金管理有限责任公司
- **投资风格：** 价值型，自下而上，集中持股，风格中性
- **核心贡献：** 提出"成本优势优先于产品差异化"的选股原则

## 投资框架

### 选股逻辑

```
选股 = 低估值 × 竞争优势
      其中：成本优势 > 产品差异化
```

姜诚认为成本优势比产品差异化更容易把握和验证。这是其与[[刘旭]]投资框架的共性——两者均强调估值判断，但切入角度不同：姜诚从成本结构出发，刘旭从DCF折现出发。

### 行业偏好

组合集中在化工、家电、交通、建材、银行等成熟行业的龙头企业。这些行业具有：
- 商业模式清晰、易于理解
- 成本结构稳定，竞争优势可量化
- 估值水平相对保守，提供安全边际

### 持仓特征

- 持股数量约20只（高度集中）
- 前十大权重50-75%
- 敢于重仓 conviction 高的标的

## 关税战压力测试表现

在2025年4月美国对华加征34%关税的冲击下，[[中泰星元价值优选]]的历史波动和下行风险始终低于同类，体现了自下而上低估值选股策略在外部冲击环境中的韧性。

这一表现在[[sources/5-notes--33-20260614t220921-qa-关税战下的优质基金选择qa--1w98s7x]]中被作为关税战冲击框架的核心实证案例之一。

## 与刘旭的比较

| 维度 | 姜诚 | 刘旭 |
|------|------|------|
| 估值方法 | 成本优势优先级 | DCF折现 + 长期需求判断 |
| 行业侧重 | 化工、家电、交通、建材、银行 | 家电、电子、通信、石油石化 |
| 风格定位 | 自下而上低估值选股 | 估值驱动风格中性 |
| 集中度 | 前十大50-75% | 前十大50-80% |
| 共同点 | 均偏好成本优势型标的，估值纪律严格 | |

详见[[sources/5-notes--33-20260614t220921-qa-关税战下的优质基金选择qa--1w98s7x]]。

## 边界条件与风险

1. **集中持股的双刃剑**：选股正确时收益高，选股错误时损失也大
2. **成本优势的时效性**：行业技术变革可能削弱既有成本优势
3. **估值判断依赖个人判断**：与[[刘旭]]类似，判断错误会错失机会
