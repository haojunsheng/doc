# ARK Innovation（ARKK）

ARK Innovation ETF（代码：ARKK）是主动ETF的典型失败案例——无法暂停申购导致规模膨胀、风格漂移、业绩反转。

## 基本信息

- **基金管理公司**：ARK Investment Management（凯瑟琳·伍德创立）
- **成立年份**：2014年10月
- **投资策略**：聚焦颠覆性创新主题的中盘成长股
- **关键特征**：高换手率、高集中度、高透明度（日度持仓披露）

## 成功阶段（2019-2020）

- 2019-2020年业绩亮眼，成为"网红基金"
- 规模快速膨胀，资金持续流入
- 持仓以中盘成长股为主（特斯拉、Zoom、Shopify等）

## 失败机制

### 第一层：规模失控

```
无法暂停申购 + 资金持续流入 → 规模膨胀 → 超出策略容量
```

- ARK Innovation无法像传统主动基金那样暂停申购
- 规模快速增长后，中盘股流动性不足以容纳新增资金
- 被迫增加大盘股持仓来缓解流动性压力

### 第二层：风格漂移

```
中盘成长 → 大盘成长 → 偏离原定策略 → 投资者失望
```

- 投资风格从"中盘成长"漂移到"大盘成长"
- 为容纳资金，被迫买入更大市值的股票
- 策略纯度丧失，超额收益来源模糊

### 第三层：透明度反噬

```
日度持仓披露 → 市场监控 → 跟风买入 → 股价↑ → 基金被迫高位加仓
```

- ARK买入的股票次日股价平均上涨3.5%（无基本面原因）
- 市场提前跟风买入，推高股价
- 基金只能在其已推高的价格上建仓，稀释超额收益

## 业绩反转（2021）

- 2021年ARK Innovation大幅跑输标普500
- 风格漂移后既失去中盘成长的高弹性，又未获得大盘成长的安全感
- 投资者遭受显著损失

## 教训与启示

### 对主动ETF的警示

```
主动策略有规模容量限制
ETF形式无法通过暂停申购控制规模
规模失控 → 被迫漂移 → 业绩反转
```

### 适用边界

- 如果策略本身容量大（如大盘宽基策略），此问题影响较小
- 备兑开仓、缓冲ETF等规则化策略不受此困境影响（规模容量大）
- 精选个股、中小盘策略在ETF形式下面临结构性约束

## 与中国市场的关联

- 中国尚未大规模推出主动ETF，ARK案例可作为预警信号
- 如果未来推出中小盘主动ETF，需警惕相同困境
- 定制化篮子申赎可能是缓解方案之一
