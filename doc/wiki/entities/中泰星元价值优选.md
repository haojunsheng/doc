# 中泰星元价值优选

## 基本信息

- **基金经理：** [[姜诚]]
- **基金类型：** 大盘平衡股票型（价值取向）
- **评级：** 晨星相关分析标的

## 投资特征

### 选股方法论

```
选股 = 低估值 × 竞争优势
      其中：竞争优势 = 成本优势 > 产品差异化
```

核心逻辑：以较低价格买入有竞争优势的企业，偏好成本优势型标的。

### 行业配置

集中在化工、家电、交通、建材、银行等成熟行业的龙头企业。这些行业特征：
- 商业模式清晰、易于理解
- 成本结构稳定，竞争优势可量化
- 估值水平相对保守

### 持仓集中度

| 指标 | 数值 |
|------|------|
| 持股总数 | 约20只 |
| 前十大权重 | 50%-75% |
| 策略特征 | 敢于重仓 conviction 高的标的 |

### 风险收益特征

- **历史波动**：始终低于同类
- **下行风险**：始终低于同类
- **关税战表现**：2025年4月美国对华加征34%关税冲击下，展现韧性

## 关税战压力测试案例

[[sources/5-notes--33-20260614t220921-qa-关税战下的优质基金选择qa--1w98s7x]]将[[中泰星元价值优选]]列为三种抗冲击路径之一，代表"自下而上低估值选股 + 集中持股 + 成本优势偏好"路径。

关键结论：在关税战等外部冲击环境下，选股能力比行业配置更重要，自下而上的低估值选股策略能在恐慌中发掘错杀机会。

## 边界条件与风险

1. **集中持股的双刃剑**：选股正确时收益高，选股错误时损失也大
2. **成本优势的可持续性**：行业技术变革可能削弱既有成本优势
3. **定性证据为主**：目前缺乏具体回撤数值数据支撑"始终低于同类"的陈述

## 与[[大成高鑫股票]]的比较

两者均代表价值取向、集中持股的基金，但方法论切入角度不同：

| 维度 | 中泰星元价值优选 | 大成高鑫股票 |
|------|----------------|-------------|
| 基金经理 | [[姜诚]] | [[刘旭]] |
| 估值方法 | 成本优势优先级 | DCF折现 + 长期需求判断 |
| 风格定位 | 自下而上低估值选股 | 估值驱动风格中性 |
| 行业侧重 | 化工、家电、交通、建材、银行 | 家电、电子、通信、石油石化 |
| 实证强度 | 定性描述（波动低于同类） | 量化数据（9年连续跑赢） |
