# 鹏华产业债债券

鹏华产业债债券（代码：206018），一只典型的"固收+"混合策略债券基金。

## 基本信息

| 项目 | 内容 |
|------|------|
| 基金代码 | 206018 |
| 基金经理 | 祝松 |
| 管理区间 | 2014年3月 – 2025年2月 |
| 年化回报 | 6.42% |
| 同类排名 | 普通债券基金前14% |
| 年度综合费率 | 1.30%（同类均值1.10%） |

## 投资策略

组合配置公式：

```
信用债：80-120%，其中 AAA 级占比长期 > 50%
利率债：0-20%，以 5-10 年期政金债为主，久期 1-5 年灵活调整
可转债：0-20%，均值 15%（同类均值约 6%）
```

- 以信用债为核心底仓，重点配置中高等级信用债
- 可转债仓位进行自上而下的前瞻性调整，根据权益牛熊预判增减
- 利率债作为久期调整工具

## 核心差异化能力

**可转债仓位择时**：在权益牛市（2014Q4、2019Q1）维持高转债仓位获取增强收益；在权益调整期（2015H2、2016Q1、2020H1）提前大幅降仓规避风险。这是该基金的超额收益来源，但也构成主要风险点。

## 费率劣势

年度综合费率1.30%，高于同类均值1.10%，主要源于管理费和托管费率偏高。在同类回报相近的情况下，高费率构成竞争劣势。

## 团队支撑

鹏华固收团队研究实力雄厚：
- 信用研究团队20+人（平均经验>4年），按行业和区域分工
- 宏观利率和可转债研究10+人
- 祝松任债券投资一部总经理，带领8名平均经验>8年的投研人员

## 待确认事项

- 祝松卸任时间：文档数据截至2025年2月，需确认当前管理状态
- 转债择时能力的独立性验证：是否有数据证明其择时能力而非运气
- 高费率的长期影响：是否需要进一步降费以保持竞争力
