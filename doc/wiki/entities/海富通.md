# 海富通

**海富通**是一家公募基金管理公司，其发行的中证短融ETF成为2025年Q3 FOF配置转向的核心标的。

## FOF持仓数据（2025年Q3）

| 指标 | 数值 |
|------|------|
| 被FOF持有数量 | 67只 |
| 持仓规模 | 18亿 → 33亿 |
| 持仓占比 | FOF第一重仓债基 |
| 10-20%区间持有FOF | 17只 |

## 产品特征

海富通中证短融ETF跟踪中证证券交易所短期融资券指数，主要投资于短期融资券，具有流动性好、久期短的特征，是利率上行环境下的典型防御性配置工具。

## 配置意义

在[[concepts/FOF配置转向框架]]中，海富通中证短融ETF是"短债打底"转向的核心载体，反映了FOF在利率上行环境中降低组合久期的系统性行为。
