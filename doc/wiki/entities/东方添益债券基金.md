# 东方添益债券基金

## 基本信息

- **类型**：信用债债券型基金
- **基金经理**：吴萍萍
- **规模**：203.61亿元
- **费率**：1.36%（运作费0.90% + 交易及其他费用0.46%）
- **同类平均费率**：0.86%
- **晨星评级**：晨星焦点基金系列案例

## 业绩表现

| 指标 | 数值 |
|------|------|
| 管理年限 | 6年 |
| 年化回报 | 4.97% |
| 同类排名 | 前2% |
| 夏普比率 | 同类第8个百分位 |

## 核心策略：票息打底+交易增强

**票息打底**：以中短久期、中高等级信用债（城投债和产业债）为主，获取稳健票息收益。

**交易增强**：以高等级信用债、利率债和地方债为主要交易品种，积极捕捉信用利差交易机会和利率波段操作增厚收益。

**决策框架**：自上而下决定久期 → 结合信用环境决定券种比例 → 自下而上精选个券。

## 年度业绩与市场分析

| 年份 | 市场环境 | 策略效果 |
|------|---------|---------|
| 2020年 | 利率波动较大 | 利率波段操作空间大，业绩优异 |
| 2023年 | 信用利差显著下行 | 捕捉信用利差交易机会，表现突出 |
| 2024年 | 利率波动较大 | 波段操作空间大，跻身同类前10% |
| 2025年 | 利率/利差波动收窄 | 交易受限，仍凭综合能力跑赢平均 |

## 策略特点

- 波动性高于同类平均（交易增强放大波动）
- 但超额收益补偿风险，风险调整后收益优秀
- 近两年动态调整：降低城投债配置、提升产业债配置（基于利差相对价值判断）
- 持仓以中高等级信用债为主，适配203亿规模的高流动性需求

## 与同类基金对比

| 基金 | 策略风格 | 权益/转债仓位 | 特点 |
|------|---------|-------------|------|
| 东方添益债券 | 交易增强型 | 较少 | 信用利差+利率波段主动交易 |
| 易方达稳健收益 | 纯债打底型 | 60-100%纯债 | 保守型固收+，转债为辅 |
| 东方红聚利 | 转债策略型 | 转债为主 | 可转债双重属性利用 |

## 关键洞察

投资者支付1.36%的高费率，换取年化4.97%的回报（同类前2%），属于典型的"能力溢价"逻辑——超额收益足以覆盖成本。
