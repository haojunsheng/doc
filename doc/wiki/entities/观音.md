# 观音

《西游记》中的关键关系节点。取经路上遇到无法解决的困难时，悟空首先求助的对象之一。

## 角色定位：关系网络中的关键枢纽

在[[concepts/识节点vs硬打]]中，观音代表一种成事技能——**识别权力网络中的关键人物**。取经路上的每一难，破解方式不是硬打，而是找到正确的"关系节点"：找观音、找太上老君、找这个精那个怪的"主人"。

这不是走后门，这是识别权力网络的基本能力。你不会找人，不是因为你正直，是因为你没看懂谁在管什么事。
