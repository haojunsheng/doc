# 沃伦·巴菲特（Warren Buffett）

美国著名投资家，伯克希尔·哈撒韦公司董事长兼 CEO，被誉为"奥马哈先知"。

## 在本 wiki 中的角色

巴菲特在本 wiki 的知识脉络中被多重引用：

1. **指数投资推荐者**：公开推荐普通投资者采用宽基指数基金，作为最简单有效的投资方式。这一立场与他在伯克希尔·哈撒韦年度股东信中多次表达的观点一致。
2. **护城河策略创始人**：提出"经济护城河"概念，主张买入拥有持续竞争优势（网络效应、无形资产、成本优势）的公司，是其价值投资体系的核心选股维度。
3. **内生价值投资派核心代表**：定义内在价值为"企业生命周期内能给投资者带来的所有现金流的折现值"，是 DCF 估值方法论在实践中的最成功践行者。
4. **能力圈实践典范**：通过"错过微软44000%仍大幅跑赢标普500"的著名案例，证明专注能力圈才是超额回报的真正来源。

## 核心投资理念

- **长期持有**：时间是优秀企业的朋友
- **护城河思维**：关注企业能否持续抵御竞争
- **能力圈边界**：不投自己不理解的东西
- **简单即有效**：对普通投资者，宽基指数是最优选择
- **内在价值=现金流折现**：股票价值等于其生命周期内自由现金流的折现总和
- **战略性拒绝**：投资成功不在于抓住所有机会，而在于拒绝能力圈外的诱惑

## 能力圈实践：错过微软的案例

巴菲特在1991年就认识比尔·盖茨，当时微软市值仅100亿美元。截至2026年，微软市值约3万亿美元，涨幅超44000%。但巴菲特并未因此影响其业绩表现，仍大幅跑赢标普500。

原因有两个层面：

1. **护城河判断**：微软经历了从软件→游戏→云计算的多次战略转型，巴菲特认为其护城河"不够明显"——竞争优势的可辨识度和可持续性不足。
2. **机会成本约束**：研究微软会分散注意力，使巴菲特无法深入跟踪后来大赚的Geico、美国运通、可口可乐等能力圈内公司。

形式化表达：
```
研究微软 → 注意力分散 → 错过Geico/运通/可乐 → 总回报↓
```

关键认知：**投资的护城河不在于你能看多少机会，而在于你能拒绝多少机会。**

## 均值回归预测框架

2014年基于"股价偏高+滞胀"预测美股未来十年回报7-8%，与[[杰克-博格]]持类似观点。实际结果：标普500十年回报超过最乐观派预期（10-12%），巴菲特预测框架被实证打破。

核心遗漏：股票回购对EPS的机械推升作用（[[股票回购对EPS的机械效应]]）。这不否定价值投资整体框架，但提示**机械应用均值回归**的风险。

## 对黄金的评述

引用巴菲特名言："黄金只会静静待在那里，什么也不创造。"指向[[黄金非生息资产]]的核心特征——黄金不产生现金流，价值完全由供需关系决定。巴菲特认为黄金适合保值但不适合追求增值，这一观点与[[黄金配置双面框架]]的风险面相呼应。

**语境补充**：巴菲特的黄金批评应理解为针对"追求增值"的角度，而非否定黄金在组合中的配置价值（低相关性分散风险）。

## 与 [[concepts/内生价值投资派]] 的关系

巴菲特是内生价值投资派的标杆人物。他提出的内在价值定义构成了 DCF 估值方法论的实践基础，其投资生涯本身就是对"市场可能长期偏离价值，但长期必然回归"这一命题的最佳实证。

## 与 [[concepts/护城河策略]] 的关系

巴菲特的护城河理论是本 wiki 中"护城河策略"概念的直接来源，二者共享同一套核心思想：企业的可持续竞争优势是长期回报的根本保障。
