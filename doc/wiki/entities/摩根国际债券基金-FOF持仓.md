# 摩根国际债券基金（FOF持仓视角）

**摩根国际债券基金**（基金代码：968052）是一只香港互认债券型基金，在2025年Q3成为FOF最受青睐的互认债基标的。

## FOF持仓数据（2025年Q3）

| 指标 | 数值 |
|------|------|
| FOF持有数量 | 23只 |
| FOF持仓规模 | 4.08亿 |
| 互认债基总持仓 | 33.76亿 |
| 配置地位 | FOF最重仓互认债基 |

## 产品特征

- **类型**：环球债券型基金（香港互认）
- **主要投资标的**：全球发达与新兴市场投资级债券
- **高收益债券敞口**：过去5年在0-7.5%区间
- **综合费率**：0.89%（略高于同类中位数0.87%）

## 配置意义

在[[concepts/FOF配置转向框架]]中，该基金是"香港互认债基配置"转向的核心载体，反映了FOF在国内低利率环境下通过互认渠道获取票息增厚的配置行为。
