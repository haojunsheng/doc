# 祁广东

易方达基金国际固收团队核心成员，美元债投资专家。

## 基本信息

| 属性 | 内容 |
|------|------|
| 所属公司 | 易方达基金 |
| 团队 | 易方达国际固收团队 |
| 美元债经验 | 10年 |
| 管理年限 | 6年以上 |
| 研究方向 | 美元信用债、美债波段操作 |

## 投资方法

根据[[concepts/海外投研能力框架]]，祁广东的管理体现以下特点：
- 平台优势：易方达国际固收团队人数和经验处于行业前列
- 久期控制：以中短久期美元信用债为主，控制利率风险
- 风险分散：强调分散配置，避免单一发行人风险

## 代表产品

[[entities/易方达稳健收益]]的QDII美元债产品线是其管理领域的延伸，核心价值是获取海外债券收益 + 汇率分散，适合做资产配置的底仓。

## 边界条件

QDII美元债基金的风险主要来自汇率波动：美元升值时人民币份额受益，美元贬值时侵蚀收益。
