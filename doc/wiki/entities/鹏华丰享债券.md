# 鹏华丰享债券

鹏华丰享债券是一只纯债基金，由鹏华基金管理，晨星在2024年7月将其列为焦点基金推荐之一。

## 基本信息

| 项目 | 信息 |
|------|------|
| 基金类型 | 纯债基金（不投资股票） |
| 管理公司 | 鹏华基金 |
| 推荐方 | 晨星（2024年7月焦点基金） |
| 投资范围 | 债券市场 |
| 基金经理 | 来源未标注 |
| 基金代码 | 来源未标注 |
| 基金规模 | 来源未标注 |

## 核心定位

作为纯债基金，鹏华丰享债券的核心价值在于：
- **低波动**：不投资股票，避免权益市场大幅波动
- **低回撤**：专注于债券票息收益，回撤可控
- **资产配置角色**：作为投资组合中的"稳定器"，降低整体组合波动

## 投资策略

来源所述策略包括：
- **久期管理**：根据利率走势调整债券期限结构
- **信用评级控制**：投资高评级债券，降低违约风险
- **信用下沉**：适度投资低评级高收益债券，获取信用利差
- **分散投资**：避免单一债券违约造成重大损失

**策略张力**：Q2 强调"信用评级控制"（保守），Q3 又提到"信用下沉"（进取），两种说法存在表面矛盾。可能解释为在整体信用风险可控前提下适度下沉，或来源描述前后不一致。

## 与同类基金的对比

| 维度 | 纯债基金（鹏华丰享） | 混合债券基金 |
|------|---------------------|-------------|
| 股票投资 | 不投 | 允许（通常≤20%） |
| 波动性 | 较低 | 较高 |
| 回撤 | 较小 | 较大 |
| 牛市表现 | 无法分享股市收益 | 可能跑赢纯债基金 |
| 熊市表现 | 相对稳定 | 可能受损 |

## 适用场景

- 风险承受能力较低的投资者
- 追求稳健收益、不需要短期流动性的投资者
- 需要降低组合整体波动的资产配置需求

## 边界条件与风险

- 股市大涨时，纯债基金无法分享收益，可能跑输混合债券基金
- 利率大幅上升时，债券价格下跌，纯债基金也受影响
- [[股债双杀]] 环境下，稳定器作用减弱
- 信用下沉策略下，低评级债券存在违约风险
- 历史业绩不代表未来表现
- 投资者若无法承受波动，可能提前割肉，导致实际亏损
