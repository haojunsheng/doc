# TikTok

字节跳动的海外版短视频产品。存在**生产要素绑定**脆弱性。

## 核心风险

TikTok的增长依赖中国母公司资源，在美国等市场的政治环境中处于不利地位。这与微信在中国的政治保护形成对比。

详见 [[生产要素绑定]]。
