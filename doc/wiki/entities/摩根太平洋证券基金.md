# 摩根太平洋证券基金

摩根太平洋证券基金（代码：968011）是一只香港互认基金，主要投资日本、澳大利亚和新西兰等亚太区股票。由摩根资产管理旗下EMAP股票投研团队管理，风格稳定的高质量成长策略是其核心特征。

## 投资方法论

采用自下而上的选股框架，核心看公司竞争地位、盈利能力和股本回报率：

```
选股标准 = 强大市场竞争优势 + 持续稳定盈利能力 + 稳健股本回报率 → 高质量成长
```

研究员按盈利增长、竞争优势可持续性、公司治理评估公司，将公司分四档，大多数个股来自前两档：

- **第一档**：资产负债表强劲 + 执行出色的管理团队
- **第二档**：运营良好 + 股东回报稳定

## 风格特征

基金组合风格稳定，始终偏好高质量成长风格，市盈率、盈利增长率、净利润率、ROE均高于基准：

- 成长行情（2017、2019、2020年）：表现亮眼
- 价值行情（2022–2023年）：表现偏弱
- 长期超额收益来源：坚持选股能力而非风格择时
- 阶段性跑输根源：风格不在优势期但拒绝漂移
