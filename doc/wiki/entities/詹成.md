# 詹成

景顺长城基金管理有限公司基金经理，管理景顺长城品质投资混合（000020）等4只基金。

## 基本信息

- **所属公司**：景顺长城基金
- **管理基金**：景顺长城品质投资混合（000020）等4只基金
- **职务**：股票研究部副总经理
- **投资风格**：大盘成长风格，自下而上选股

## 投资方法论

**选股标准**：
- 较强竞争力
- 优秀管理团队
- 良好盈利能力
- 可持续成长性

**持仓纪律**：
- 单一行业占比通常低于20%
- 前十大持股占比约30%-40%
- 换手率200%-300%/年（长期持有核心仓位 + 短期调整行业景气度暴露）

**估值特征**：整体估值水平略高于晨星同类基金平均

## 业绩表现

| 时期 | 年化回报 | 表现 |
|------|---------|------|
| 2015年底-至今 | 9.90% | 长期年化 |
| 2016-2020年 | 19.15% | 成长股牛市，四度跑赢同类 |
| 2021-2024年 | -7.67% | 价值股牛市，两度跑输同类 |

## 晨星评价要点

1. **选股能力**：在成长股领域具备扎实的研究能力，但受风格轮动影响，业绩呈现极端分化
2. **行业配置**：医药行业高配遭遇政策黑天鹅（2021-2024）；低配新能源（2021）和AI（2024），反映行业轮动盲点
3. **管理职责**：担任股票研究部副总经理，占用约10%时间，晨星判定不影响投资管理工作
4. **精力分散**：同时管理4只基金，策略高度重合，存在潜在精力分散风险（文中未明确量化）
