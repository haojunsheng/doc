# 外汇管理局（SAFE）

国家外汇管理局（State Administration of Foreign Exchange，简称SAFE）是中国QDII额度的审批和发放主体，负责管理跨境资本流动的宏观审慎框架。

## 基本信息

- **全称**：国家外汇管理局
- **英文缩写**：SAFE
- **职能**：管理中国国家外汇储备、审批QDII/QFII等跨境投资额度、监控跨境资本流动
- **隶属**：中国人民银行

## QDII额度管理

SAFE是QDII额度的唯一审批和发放机构，其核心权力包括：

1. **额度审批**：向符合条件的金融机构（基金公司、银行、券商等）发放QDII额度
2. **额度分配**：决定各机构获得多少额度，以及额度在机构内部如何分配给具体产品
3. **动态调整**：根据宏观经济形势和跨境资金流动情况，动态调整总额度和发放节奏

## 监管逻辑

SAFE对QDII的监管遵循"审慎开放+动态平衡"原则：

- **优先保障流动性安全**：在跨境资本流动压力较大时收紧额度
- **结构性分配**：优先给二级市场溢价过高的产品发放额度，缓解套利压力
- **动态调整**：根据宏观经济形势灵活调整发放节奏

## 与市场的关系

SAFE的额度政策直接影响QDII产品的申购体验和投资者的出海成本：
- 额度紧张 → 产品限购 → 二级市场溢价 → 投资者追高买入
- 额度释放 → 限购松动 → 溢价收敛 → 但供需缺口仍存
