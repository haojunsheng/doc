# 富国中国中小盘混合（QDII）

富国基金旗下专注于港股中小盘的价值成长型 QDII 基金，张峰管理超过 13 年。

## 基本信息

| 项目 | 内容 |
|------|------|
| 基金类型 | 混合型基金（QDII） |
| 投资范围 | 港股中小盘为主，不投 A 股 |
| 基金经理 | [[张峰]] |
| 管理规模 | 38.85 亿元 |
| 综合费率 | 2.33%（同类平均 2.71%） |

## 费率结构

- 年度运作费用：1.40%
- 交易及其他费用：0.93%
- 不收销售服务费
- 规模效应有效摊平运营费用

## 持仓特征

- 持股数量：70–100 只
- 前十大集中度：25–35%
- 单只股票风险有限

## 业绩表现

| 指标 | 数值 |
|------|------|
| 管理年限 | 13 年 |
| 年化回报 | 12.06% |
| 年化超额收益 | 7.56%（相对基准） |

## 归因分析

**正选股超额来源**（多行业）：
- 可选消费、必选消费、医药、通信、工业、金融、房地产

**配置拖累**：
- 低配信息技术行业（−4.81%）

**风格表现**：
- 2020 年赚 52% 但排 60%（低配高估值科技）
- 2022 年亏 10% 却排 26%（低配信息技术 + 选股超额）

## 与同类基金的差异

| 维度 | 该基金 | 同类平均 |
|------|--------|---------|
| A 股配置 | 0% | 21%（主要是食品饮料大盘白马） |
| 台湾股票配置 | 0% | 有配置 |
| 综合费率 | 2.33% | 2.71% |

- 不配 A 股：避开 2021–2025 年食品饮料大盘白马的持续下跌，但也错失消费复苏时的配置机会
- 不配台湾股票：错失 2019–2025 年台湾科技股上涨的红利
