# 摩根亚洲股息基金

## 基本信息

| 维度 | 内容 |
|------|------|
| 类型 | 亚洲股票型互认基金（高股息策略） |
| 管理公司 | 摩根（Morgan） |
| 业绩基准 | MSCI 亚太除日本指数 + 30 个百分点 |
| 核心特征 | 兼顾资本增长与股息收益 |

## 2025年资金流向表现

| 时期 | 表现 |
|------|------|
| 2025年10月 | 股票类净流入亚军（9.27亿），紧随瑞士百达策略收益基金 |
| 2025年11月 | 股票类互认基金净流入冠军 |
| 2025年前三季 | 持续吸金榜前列 |
| 2025年全年 | 回报领先同类 |

## 策略定位

摩根亚洲股息基金的核心定位是"在'逐险'与'求稳'之间找到平衡"：
- **资本增长**：通过股票持仓获取资本增值潜力
- **股息收益**：通过高股息策略提供现金流缓冲
- **目标受众**：风险偏好从"极度避险"修复到"适度逐险"的投资者

## 与母公司的关系

摩根亚洲股息基金是 [[摩根互认基金业务]] 的重要组成部分。2025年摩根全年净流入 226 亿元居首，其中亚洲股息基金是股票类产品的核心代表。

## 边界条件

- 若市场进入"极度风险厌恶"，高股息策略会跑输成长股
- 若亚太股市整体下跌，股息收益也难以弥补资本损失
- 若投资者风险偏好继续上升，资金可能从高股息转向成长股

## 汇丰（互认基金业务）

> 以下内容为独立实体，来源：notes/20260614T214636--qa-10月香港互认基金股债全面吸金__qa.md

汇丰在香港互认基金市场中位列第二，截至2025年10月末资产规模约349亿元，与摩根合计占据超60%市场份额，形成"2+1"格局中的第二位。

### 核心特征：新基金与老基金的双轨制

汇丰的互认基金业务呈现独特的"双轨制"——新基金与老基金的资金流向相反：

| 产品线 | 代表产品 | 资金流向 | 关键事件 |
|--------|---------|---------|---------|
| 新基金 | 汇丰亚洲多元资产高入息基金 | 净流入（5.78亿，10月） | 2025年9月开放内地申购，10月跃入净流入前十 |
| 老基金 | 汇丰亚洲债券基金 | 净流入（重启开放驱动） | 向内地个人投资者重启开放 |
| 其他老基金 | 汇丰亚洲高收益债基金 | 净流出（11月） | 额度耗尽，内地申购受限 |

#### 10月转折点

2025年10月，汇丰在经历数月净流出后实现月度净现金流**由负转正**，核心驱动力来自两条线的合力：
1. 新基金汇丰亚洲多元资产高入息基金自9月开放，10月即贡献5.78亿净流入并跃入前十
2. 汇丰亚洲债券基金向内地个人投资者重启开放，带来额外申购

#### 11月回落

2025年11月，汇丰新基金的吸金不足以弥补老基金的失血（额度耗尽导致），公司整体再度陷入净流出。这一对比揭示了汇丰"双轨制"结构的脆弱性——新基金的成功难以完全抵消老基金的结构性约束。

### 市场定位

在"2+1"格局中，汇丰是规模第二的成员：
- 摩根：810亿，规模第一
- 汇丰：349亿，规模第二
- 惠理：>10%，第三极

汇丰的核心竞争力在于产品线广度与渠道优势，但其面临的额度约束问题比摩根更为突出。

### 边界条件

- 若新基金持续放量销售，汇丰可能摆脱对老基金额度的依赖
- 若监管放宽互认基金额度限制，汇丰的老基金产品线有望恢复增长
- 若市场环境恶化，新基金同样面临赎回压力
