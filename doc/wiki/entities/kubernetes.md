# Kubernetes

2017 年容器战争中登基的容器编排平台。在《凤凰架构》中被视作关键里程碑：首次让基础设施跟上软件的灵活性，使分布式问题（注册发现、负载均衡、容错等）从应用代码层下沉到基础设施层的工程实践成为可能。是「后微服务时代」分布式问题下沉的核心载体。
