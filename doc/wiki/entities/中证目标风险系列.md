# 中证目标风险系列

中证指数公司编制的多资产目标风险指数系列，是国内目前最成熟的目标风险指数框架。

## 四档分层

| 档位 | 目标年化波动率 |
|------|--------------|
| 保守 | 3% |
| 稳健 | 5% |
| 平衡 | 10% |
| 积极 | 15% |

## 编制特点

- 通过调整股债比例维持目标波动率
- 细分资产内部采用[[风险平价]]模型计算权重
- 目标风险管整体组合波动率，风险平价管内部风险贡献结构，两者嵌套使用

## 现状

虽已有指数编制储备，但国内尚无直接跟踪中证目标风险系列的公募产品，多资产指数仍属小众品类。
