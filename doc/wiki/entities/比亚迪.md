# 比亚迪

比亚迪是中国新能源汽车的龙头企业，也是关税2.0冲击下受影响较大的行业代表。

## 关税影响评估

- 北美营收占比5-10%
- 关税上调将拖慢海外扩张进度，影响盈利增长
- 相比家电行业，新能源车出海时间更短，海外产能布局尚未成型

## 投资启示

比亚迪属于[[关税行业冲击分化框架]]中"出海初期+单一目标市场依赖→冲击较大"的类别。电池上游的[[宁德时代]]和国轩高科出口市场更多元，可调整结构，受影响相对可控；但上游锂矿企业因需回国内加工，潜在冲击更大。

## 规避路径

若中国车企加速在墨西哥建厂以出口美国，可规避部分关税——这是当前行业正在探索的方向，但尚未大规模落地。
