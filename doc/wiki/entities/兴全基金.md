# 兴全基金

全称：兴证全球基金管理有限公司，业内常简称为"兴全基金"。

## 基本信息

| 项目 | 内容 |
|------|------|
| 管理规模 | 约 7772.9 亿元 |
| 旗下基金数量 | 163 只 |
| 市场定位 | 以主动管理口碑著称 |
| 核心优势 | 内部基金库丰富，尤其主动权益和固收产品历史口碑较好 |

## 与 FOF 的关系

兴全基金是 [[concepts/FOF]] 领域的重要参与者，旗下拥有多只内部 FOF 产品，形成了较为完整的内部产品矩阵。兴全优选稳健6个月A（015377）的前五大持仓全部为兴全系产品，内部产品依赖度较高（合计 37.97%）。

内部基金优势：
- FOF 团队对内部基金经理风格、容量、风险暴露有深度理解
- 风格一致性更强，研究协作更高效
- 但也存在透明度风险：内部产品占比过高可能被解读为利益输送
