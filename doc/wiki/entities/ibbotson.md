# Ibbotson

## 简介

Ibbotson 是晨星（Morningstar）旗下的研究机构，在资产配置领域具有开创性贡献。其核心贡献是将**人力资本**纳入资产配置框架，提出人的总财富由金融资本和人力资本共同构成，投资决策应考虑两者的风险敞口关系。

## 核心方法论

Ibbotson 框架的关键洞见：
- 人力资本 = 未来收入的折现值
- 人力资本属性因职业而异：收入稳定者（如教授）≈ 隐性债券；收入波动者（如基金经理）≈ 隐性股票
- 金融资产应与人力资本做反向配置，以实现整体风险均衡
