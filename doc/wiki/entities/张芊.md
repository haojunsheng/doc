# 张芊

广发基金管理有限公司固定收益投资总监，兼任广发增强债券A（013997）基金经理。

## 基本信息

| 属性 | 内容 |
|---|---|
| 职务 | 广发基金固定收益投资总监 |
| 管理产品 | 广发增强债券A（013997）等 |
| 背景 | 银行和基金固收管理经验 |

## 管理能力评价

张芊在广发固收平台负责债券组合管理，策略包括利率预测、收益曲线预测、债券类属配置、信用策略、套利机会挖掘和新股申购策略。其管理能力是广发增强债券A的加分项，但分析认为这种能力并非不可替代——固收增强赛道可选产品众多，投资者可通过同类基金收益、回撤、规模稳定性直接比较替代。

参见 [[wiki/concepts/秩序搬运]] 关于"能力不等于不可替代"的论述。
