# 鹏华匠心精选

晨星研究文章中引用的反面案例基金。基金经理王宗合管理年限超过10年，但该基金在3年内下跌38%。该案例用来说明长期管理经验并不必然转化为优异的长期业绩，性格与反思能力同样关键。
