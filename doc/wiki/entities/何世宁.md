# 何世宁（He Shining）

摩根亚洲股息基金（968048）新任基金经理，拥有19年投资经验。2014年起担任协管基金经理，全程参与投资决策。2024年2月正式接任，投资流程与前任 Jeffrey Roskell 保持一致。研究员出身，后转为基金经理。
