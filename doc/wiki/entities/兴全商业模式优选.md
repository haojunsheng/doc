# 兴全商业模式优选混合基金

**基金代码：** 163415

## 基本信息

- **类型：** 积极配置-大盘成长
- **晨星分类：** 积极配置-大盘成长（晨星焦点基金系列）
- **业绩比较基准：** 沪深300相对成长

## 策略定位

兴全商业模式优选是晨星焦点基金分析中用于阐释"中间策略"的代表性案例。其核心特征为：

- 不纯粹押注价值或成长
- 以"商业模式优秀"为筛选前提
- 寻找合理价格的优质成长公司
- 采用自下而上选股方法

## 晨星分类与策略主张之间的张力

晨星将兴全商业模式优选归类为"积极配置-大盘成长"，但基金本身在策略上强调"不纠结于成长/价值标签"。这产生了一个分类层面的矛盾：

- 晨星的分类体系强制将基金贴上"成长"标签
- 所谓"中间策略"在分类视角下可能被误读为纯成长
- 与 [[风格漂移]] 的概念形成张力：如何区分"策略定位清晰"与"风格漂移"，需要从晨星分类标签的盲区入手理解

## 评估要点（来源）

1. 商业模式判断的准确性：能否持续找到商业模式优秀且估值合理的公司
2. 历史超额收益来源：来自商业模式判断还是市场风格
3. 跨周期稳定性：不同市场环境下是否能创造 alpha
4. 风险可控性：回撤与投资者风险偏好的匹配度
