# 乔治·索罗斯 (George Soros)

乔治·索罗斯，匈牙利裔美国投资家、哲学家，量子基金创始人。最广为人知的身份是1992年"狙击英镑"事件中的获利者，以及**反身性理论**的提出者。

## 在本 Wiki 中的角色

索罗斯是 [[concepts/反身性]] 概念的原创者。本文引用其概念来解释为何市场预测本质上不可靠：预测本身改变被预测对象，预测者成为系统的一部分。

## 反身性概念

索罗斯的反身性理论认为，参与者的认知与市场现实之间存在双向反馈：

```
认知 → 影响行为 → 改变市场现实 → 反馈修正认知 → 再次影响行为
```

这与自然科学中的观察者效应有本质区别：市场参与者的信念本身就是改变客观现实的变量。

## 投资实践中的体现

- 1992年狙击英镑：基于对英国政府政策不可持续性的判断（认知），大规模做空（行为），迫使英镑退出欧洲汇率机制（结果），验证了判断（反馈）
- 反身性与 [[concepts/市场预测的不可靠性]] 高度一致：一旦判断被广泛预期，套利行为会改变结果路径
