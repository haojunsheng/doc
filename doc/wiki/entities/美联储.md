# 美联储

## 基本信息

**全称**：美国联邦储备系统（Federal Reserve System）

**职能**：美国的中央银行，负责制定和执行货币政策、维护金融稳定。

## 决策机制

- 联邦公开市场委员会（FOMC）负责制定利率决策。
- [[点阵图解读|点阵图]]是FOMC每季度发布的利率路径预测分布，反映委员们对未来利率的匿名预期。
- 点阵图中位数代表官方共识预测，但个体委员立场可能存在显著差异。

## 2022年加息周期

- 2022年美联储加息7次，利率从1.5%涨到4%以上，形成全线紧缩环境。（来源：`notes/20260628T153852--qa-美联储降息周期研判__qa.md`、`notes/20260628T154138--qa-美股9月回调是结束还是开始__qa.md`）
- 2022年四因素（通胀↑、利率↑、经济放缓、紧缩）全部压顶，美股熊市。（来源：`notes/20260628T154138--qa-美股9月回调是结束还是开始__qa.md`）
- 上述四因素分析框架亦用于横向对比2024年宏观环境，见下方对照表。（来源：`notes/20260628T154138--qa-美股9月回调是结束还是开始__qa.md`）

| 维度 | 2022年 | 2024年 |
|------|--------|--------|
| 通胀 | 上升 | 下降，预计2025年回到2%目标 |
| 利率 | 上升（美联储加息7次，1.5%→4%+） | 即将进入下行通道（降息共识） |
| 经济增速 | 放缓 | 温和放缓（唯一逆风） |
| 政策方向 | 紧缩 | 转向宽松 |

**结论（2022 vs 2024）**：2022年全线利空 vs 2024年三利好一利空。（来源：`notes/20260628T154138--qa-美股9月回调是结束还是开始__qa.md`）

## 2024–2025年降息周期中的角色

- 2024年12月以来首次降息25个基点，利率目标区间降至4%–4.25%。（来源：`notes/20260628T153852--qa-美联储降息周期研判__qa.md`）
- [[点阵图解读|点阵图]]显示内部对未来路径分歧严重：中位数预测2025年底利率3.50%–3.75%。
- 米兰（Michelle Bowman）是唯一主张降50bp的鸽派委员，曾担任特朗普政府前经济顾问。

## 政策框架的两难

美联储面临[[滞胀两难]]的经典困境：需要在通胀控制和就业支持之间走钢丝。[[预防式降息-vs-衰退式降息|预防式降息]]与[[衰退式降息]]的区别，决定了资产表现是否符合历史规律。（来源：`notes/20260628T153852--qa-美联储降息周期研判__qa.md`）

## 相关市场分析：美股9月回调归因

以下内容来自 [[entities/晨星中国]] 美国团队分析（原发布于 Morningstar CN），用于说明美联储政策转向背景下的市场反应，不直接构成关于美联储本身的陈述。（来源：`notes/20260628T154138--qa-美股9月回调是结束还是开始__qa.md`）

### 核心判断

2024年9月美股回调是**牛市中的板块轮动**，而非趋势反转的开端。四大宏观因素中仅增长放缓为逆风，其余三向均已反转。

### 九月回调归因

- 2022.10→2024.7：科技板块涨幅54%，是大盘两倍多，贡献标普总收益的25.3%
- 2024年7月以来：科技股跌8.5%，整体市场仅跌1.6%
- 8月房地产指数涨5.37%（先涨7.5%），显示资金转向防御板块
- **性质**：科技股涨幅消化式主动轮动，非基本面恶化驱动

### 估值分布

| 类型 | 状态 | 评估 |
|------|------|------|
| 大盘股 | 溢价约4% | 吸引力偏弱 |
| 小盘股 | 折价最明显 | 最具估值吸引力 |
| 成长股整体 | 溢价约8% | 略高 |
| 价值股 | 低估 | 有吸引力 |

### 软着陆逻辑链

```
软着陆: 通胀↓ + 经济温和放缓
  → 央行停止加息、转向宽松预期形成
  → 缓解性反弹（股市）
  → 若后续经济数据验证软着陆，反弹演变为趋势性行情
```

晨星判断软着陆概率大于衰退。

### 边界条件

- 若通胀反弹 → 三利好框架瞬间坍塌
- 若科技股盈利大幅不及预期 → 轮动变全面下跌
- 若小盘股盈利波动放大 → 低估值变价值陷阱
- 若软着陆变硬着陆 → 缓解性反弹变恐慌抛售

引用本杰明·格雷厄姆比喻：市场每日报价情绪化波动 ≠ 企业真实价值。忽视短期波动、专注长期内在价值是应对此类回调的行为准则。详见 [[市场先生]]。
