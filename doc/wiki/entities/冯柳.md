# 冯柳

中国知名基金经理，以独特的投资理念和风险控制方法著称。

## 择时成本测算

冯柳用个人测算量化了择时的真实代价：

```
胜率 70%（已属较高水平）
做对 4 次 = 抵 3 次错
扣交易成本后实际只做对 3 次
最终仅回避 1-2 个百分点回撤
```

核心结论：即使拥有 70% 的择时胜率，扣除成本后收益也极为有限，且代价是可能错过牛市主升段的复利增长。
