# 陆家嘴论坛

## 定义

陆家嘴论坛是中国上海举办的国际性金融论坛，由国务院批准设立，是中国金融对外开放的重要窗口。论坛通常在每年6月举办，聚焦金融市场改革、开放与创新等议题。

## 在本文中的角色

2025年6月的陆家嘴论坛宣布深化科创板政策，成为当月A股市场上涨的三大驱动因素之一（另两项为中美元首通电和央行买断式逆回购）。论坛释放的政策信号提振了市场风险偏好，直接推动了科技成长板块的上涨。

## 市场影响机制

```
陆家嘴论坛政策信号
    → 科创板深化政策 announced
    → 市场风险偏好提升
    → 科技/成长板块领涨
    → A股主要指数涨 2-5%
```

## 边界条件

- 陆家嘴论坛的政策信号效力取决于后续政策落地情况
- 若中美摩擦升级，论坛释放的积极信号可能被抵消
- 论坛效果具有时效性，通常在政策宣布后短期内最为明显
