# 兰小欢

兰小欢，经济学家，《置身事内：中国政府与经济发展》作者。

以"地方政府投融资"为主线，还原政府如何既生产蛋糕又制造失衡，将"事权划分—分税制—土地财政—土地金融—招商引资—地区竞争"这套微观机制与宏观现象相连。

核心主张：主流新古典经济学抽象掉政治与历史的盲区，主张"置身事内"理解中国政府行为背后的制度约束与激励机制。
