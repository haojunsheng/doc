# 尤金·法玛（Eugene Fama）

美国经济学家，芝加哥大学布斯商学院教授，2013 年诺贝尔经济学奖获得者，**有效市场假说（EMH）**的主要创立者。

## 主要贡献

1970 年提出有效市场假说（Efficient Market Hypothesis, EMH），将市场效率分为三个层次：

| 层次 | 定义 |
|------|------|
| 弱式效率 | 价格反映所有历史信息 |
| 半强式效率 | 价格反映所有公开信息 |
| 强式效率 | 价格反映所有信息，包括内幕信息 |

## 核心主张

市场价格能充分反映所有可用信息，因此没有人能持续获得超额收益（跑赢市场）。

## 理论贡献与边界

- **强主张**：大多数时候市场是有效的，被动投资（持有市场组合）是最理性选择
- **被批评点**：行为经济学家认为 EMH "不完整"而非"错误"——它无法解释泡沫、恐慌等市场失效时期
- **实践后果**：为 [[约翰博格尔john-bogle]] 的指数基金革命提供了理论基础

## 与 wiki 的关联

- 其理论构成 [[市场有效悖论]] 的逻辑基础。EMH 传统推论是"市场越有效，主动投资越困难"，而市场有效悖论在此基础上提出了反向推论——低效市场中普通人更应被动投资。
- 法玛的 EMH 是连接 Q2/Q3 理论探索与 Q6 实践落地的关键一环——它回答了"如果市场大部分时间有效，那普通人应该怎么做"这个实际问题。
