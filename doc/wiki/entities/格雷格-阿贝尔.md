# 格雷格·阿贝尔（Greg Abel）

伯克希尔·哈撒韦现任副董事长，巴菲特指定的接班人，负责非保险业务。

## 职业轨迹

| 时间 | 事件 |
|------|------|
| 1992年 | 加入CalEnergy（加州能源公司） |
| 之后 | 通过收购将CalEnergy发展为大型公用事业公司 |
| 2018年 | 升任伯克希尔副董事长，负责非保险业务 |
| 2026年 | 被巴菲特宣布为接班人，计划年底正式接棒 |

## 能力画像

| 维度 | 评估 | 说明 |
|------|------|------|
| 运营管理 | 强 | 在公用事业领域有成功运营经验 |
| 能源管理 | 强 | 深谙能源行业运作逻辑 |
| 独立投资记录 | 弱 | 没有独立管理大规模投资组合的历史记录 |
| 资本配置总指挥 | 定位中 | 巴菲特的角色定位是"总指挥"而非一线投资执行者 |

## 角色定位

阿贝尔大概率扮演资本配置"总指挥"角色，具体投资执行由库姆斯（Todd Combs）和韦施勒（Ted Weschler）负责。巴菲特时代10亿美元以下投资已由两人直接拍板，阿贝尔自认更擅长运营管理，角色定位类似现在的巴菲特——把控大方向。

> 巴菲特公开表示："阿贝尔比我有效得多。"

## 与巴菲特的关系

阿贝尔是伯克希尔"去中心化运营"制度的核心产物——巴菲特长达25年的接班布局将其培养为制度验证者，而非"第二个巴菲特"。他的使命是证明伯克希尔的制度体系能够独立运转并穿越周期。

## 关键边界

- 当伯克希尔遇到需要大规模资本配置决策时，缺少投资经验的短板可能暴露
- 当库姆斯和韦施勒离职或能力下滑时，阿贝尔能否亲自下场做投资决策是真正的考验
- 面临短期业绩压力时，是否仍能坚守长期原则存疑
