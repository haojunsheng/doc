# 贵州茅台

中国高端白酒代表，"一瓶难求"的稀缺品，拥有行业内最强的定价权和护城河。

## 核心特征

- **供需格局**：出厂价 1169 元仍供不应求，渠道利润巨大，与其他白酒的产能过剩格局形成鲜明对比
- **护城河**：晨星评定为宽阔护城河，来源为无形资产（品牌历史+独特工艺/窖池）
- **定位**：高端白酒三家（茅台、五粮液、泸州老窖）中最为极端，代表品类稀缺性

## 与其他白酒的本质差异

| 维度 | 茅台 | 其他白酒 |
|------|------|----------|
| 供需状态 | 供不应求 | 产能过剩 |
| 定价模式 | 超强定价权 | 竞争定价 |
| 价格弹性 | 出厂价1169元仍短缺 | 提价能力受限 |
| 渠道利润 | 巨大 | 微薄或亏损 |

```
茅台：供不应求 + 超强定价权 ⊥ 其他白酒：产能过剩 + 竞争定价
```

## 风险边界

- 若反腐政策升级或商务消费持续萎缩，茅台也会受影响，只是程度小于其他白酒
- 健康意识提升或社交文化变迁可能侵蚀品牌溢价
