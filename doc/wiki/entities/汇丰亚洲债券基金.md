# 汇丰亚洲债券基金

## 简介

汇丰亚洲债券基金是一只香港互认基金，由[[entities/汇丰投资-hsbc-investment]]管理，属于晨星焦点基金系列分析对象之一。基金主要投资于亚洲地区的投资级债券，以稳健收益为目标。

## 投资策略

```
组合 = 亚洲投资级债券（高权重） + 少量其他固收工具
```

- 核心持仓为亚洲投资级债券，信用评级 BBB- 及以上
- 收益来源主要是债券票息，而非资本利得或信用下沉
- 亚洲债券市场提供比发达市场更高的票息收益

## 风险收益特征

| 维度 | 说明 |
|------|------|
| 收益来源 | 债券票息（高权重）+ 少量其他固收工具 |
| 主要风险 | 利率风险 > 信用风险（低于高收益债）> 流动性风险 |
| 风险等级 | 保守型 |
| 适用投资者 | 低风险偏好 + 稳健收益目标 + 亚洲配置需求 |

## 与汇丰亚洲高收益债券基金的区别

⚠️ **重要区分**：本基金的底层资产为投资级债券，与[[entities/汇丰亚洲高收益债券基金]]（投资高收益债/垃圾债）风险收益结构截然不同。

| 维度 | 汇丰亚洲债券基金（本页） | [[entities/汇丰亚洲高收益债券基金]] |
|------|------------------------|----------------------------------|
| 投资标的 | 投资级债券（BBB-及以上） | 高收益债（低于 BBB-） |
| 核心收益来源 | 票息收益 | 无风险利率 + 信用利差 |
| 主要风险 | 利率风险 | 信用风险（违约） |
| 风险等级 | 保守型 | 高风险 |
| 适用投资者 | 风险厌恶型 | 追求高收益、能承受高波动 |
