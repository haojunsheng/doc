# 大成高鑫股票（FOF持仓视角）

**大成高鑫股票**（基金代码：000628）是一只价值风格公募基金，在2025年Q3 FOF配置转向中被大规模减持，成为"权益风格从价值切向成长"的典型样本。

## FOF持仓变化

| 指标 | 转型前 | 转型后 |
|------|--------|--------|
| FOF持有数量 | 169只 | 14只 |
| FOF持仓规模 | 8.96亿 | 0.88亿 |
| 配置地位 | 被广泛持有 | 基本被清仓 |

## 产品特征

- **基金经理**：[[entities/刘旭]]（2015年7月起管理）
- **基金类型**：大盘平衡股票型
- **投资风格**：价值平衡风格，深度研究驱动
- **持仓集中度**：前十大重仓股权重长期维持50%-80%

## 配置意义

在[[concepts/FOF配置转向框架]]中，大成高鑫的减持是"权益风格切换-价值到成长"转向的核心证据。与[[entities/国富中小盘]]一同构成了FOF减持价值风格的实证数据。

两只被减持基金的共同特征是最近两年投资风格均偏价值，而FOF增持的则是科技/新能源成长风格基金。

## 边界

若市场风格从成长切回价值，FOF可能重新增配此类价值风格基金。
