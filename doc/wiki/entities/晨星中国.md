# 晨星中国

Morningstar 在中国的研究分支，发布多篇公募基金投资者行为与产品分析研究。

## 代表性研究

- 首份中国公募基金投资者回报差研究（2026），覆盖五年期年化回报差，揭示基民普遍"高买低卖"
- 多资产指数选型研究
- 内卷退潮时基金经理抉择研究

## 方法论特点

以量化数据驱动，注重行为金融视角，覆盖欧美亚太跨市场验证。
