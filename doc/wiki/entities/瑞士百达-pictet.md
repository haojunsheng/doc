# 瑞士百达（Pictet）

瑞士百达是全球资产管理公司，在香港互认基金市场表现突出，是 [[策略选择优于大类选择]] 框架的实证案例。

## 核心业绩（2026年Q1 + 2025年10月更新）

### 2026年Q1数据
- **Q1混合型基金净流入**：94.3亿元，领跑互认基金市场
- **年内累计净流入**：99.33亿元，行业第一
- **1个月 + 3个月净流入**：均排名榜首

### 2025年10月数据
- **瑞士百达策略收益基金单月净流入**：9.57亿元，延续霸榜
- 该数据进一步巩固了瑞士百达在全球灵活配置领域的市场领先地位

## 代表产品

### 瑞士百达策略收益基金

- **策略**：全球灵活配置（股债比例灵活调整，无固定比例约束）
- **业绩特点**：过去一年业绩显著优于同类美元灵活配置型产品
- **资金来源**：业绩驱动型飞轮——业绩好 → 资金流入 → 规模效应 → 品牌认知提升

## 与现有概念的关系

- 是 [[配置飞轮]] 中"业绩驱动型飞轮"的典型实证案例
- 其资金流入模式印证了 [[近因效应]]：投资者追逐近期业绩
- 证明了 [[策略选择优于大类选择]] 的核心命题：灵活配置策略在动荡市场中胜出

## 市场定位

瑞士百达在香港互认基金市场属于"策略型赢家"——不是规模最大的公司（摩根、汇丰规模更大），但凭借灵活配置策略在特定时期获得了最强的资金流入。这提示投资者和从业者：互认基金市场的赢家由策略适应性决定，而非单纯由公司品牌或规模决定。
