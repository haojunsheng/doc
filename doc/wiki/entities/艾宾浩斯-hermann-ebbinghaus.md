# 艾宾浩斯（Hermann Ebbinghaus）

德国心理学家，系列位置效应的提出者，近因效应和首因效应的心理学奠基人。

## 关键贡献

**1885 年《记忆》（*Über das Gedächtnis*）**：通过系列位置实验证明，记忆材料中开头和结尾的内容更容易被记住，中间部分容易被遗忘。

这一发现构成了近因效应和首因效应的共同心理学基础。

## 在投资语境中的意义

- 解释了为什么基金销售人员喜欢展示"最近一年业绩"（利用近因效应）
- 解释了为什么投资者对基金经理的评价往往基于最近 3 个月而非最近 3 年
- 解释了为什么"第一次接触"某只基金的印象（首因效应）和"最近一次接触"的印象（近因效应）都会影响投资决策
