# Temu

Temu是拼多多旗下的跨境电商平台，在美国以"烧钱补贴抢市场"为主要战略，是关税冲击下出现反直觉效应的典型案例。

## 商业模式与关税关系

- 当前处于补贴抢份额阶段，订单量是核心KPI
- 关税导致订单减少 → 补贴支出减少 → 亏损收窄 → 净利润反而改善
- 已拓展美国以外市场分散风险

## 投资启示

[[Temu]]属于[[关税行业冲击分化框架]]中"烧钱阶段企业→关税反而利好"的特殊类别，体现了[[烧钱模式逆向关税效应]]的核心逻辑。这一结论高度依赖边界条件：若[[Temu]]已进入盈利阶段，订单减少即为纯负面冲击。
