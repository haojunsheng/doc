# 中欧新趋势混合

中欧新趋势混合基金，晨星焦点基金案例，以基金经理周蔚文14年长期任职为核心特征，是"基金经理任职稳定性"论点的代表性实证载体。

## 基本信息

- **基金类型**：混合型基金（偏股型）
- **基金经理**：周蔚文（2011年至今，14年，唯一基金经理）
- **晨星评级**：焦点基金
- **投资策略**：中观行业景气度分析 + 自下而上精选个股

## 业绩表现

| 指标 | 数值 |
|------|------|
| 任职以来年化收益 | 12.76% |
| 13年完整年度中排名前50%的次数 | 9年 |
| 2021年业绩（行政事务拖累期） | 1.08%，排名后移73% |

## 持仓特征

- 前十大重仓股占比：30-45%
- 行业分散度：单行业不超过20%
- 换手率：100-200%，偏低
- 风格定位：成长股为主 + 少量价值股

## 费率结构

- **基金费率**：1.70%（1.4%年度运作费 + 0.30%交易费）
- **同类平均费率**：2.26%
- **费率优势**：每年节省0.56%，10年复利累积约6%累计收益差距

## 历史考验记录

- 2015年股灾：经受住考验
- 2018年熊市：经受住考验
- 2021年：新能源/电子配置不足，错失上涨机会（与行政事务分散精力有关）
- 2022年大跌：经受住考验

## 在本 Wiki 中的角色

作为"基金经理任职稳定性"概念的核心实证案例，该基金的价值不在于业绩绝对值，而在于其14年同一基金经理的长期任职提供了跨多轮牛熊周期的充分判断样本，使得业绩归因具备了统计学意义上的可信度。
