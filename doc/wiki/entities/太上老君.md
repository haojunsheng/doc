# 太上老君

《西游记》中的重要关系节点。青牛精（金刚琢）的主人，悟空多次求助的对象。

## 角色定位：关系网络中的关键枢纽

在[[concepts/识节点vs硬打]]中，太上老君代表另一种成事技能——**识别并调动关系网络中的上级资源**。青牛精下界为妖，悟空打不过，最终找太上老君收回坐骑。这不是简单的"找人办事"，而是理解整个权力网络的层级结构，知道谁管谁、该找谁。
