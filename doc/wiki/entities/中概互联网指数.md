# 中概互联网指数

中概互联网指数跟踪在中国大陆以外上市的中国互联网公司股价表现，是QDII行业主题基金的重点配置标的之一。

## 在QDII井喷中的作用

2020年中概互联网指数暴涨50%+，与恒生科技指数一起成为QDII资金涌入港股科技板块的主要驱动力。两只追踪中概互联网指数的QDII产品在2021年合计吸引资金496亿，成为当年行业基金吸金的绝对主力。

## 典型案例：华夏恒生互联网科技业ETF(QDII)

该基金追踪中概互联网指数，2021年全年吸引资金223亿，是单只QDII基金的标志性吸金案例。但投资者在2022年指数回调时承受了显著亏损，印证了 [[择时的心理陷阱]] 中关于"时机不当的买入往往导致负的投资者回报"的判断。
