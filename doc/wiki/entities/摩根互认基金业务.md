# 摩根互认基金业务

摩根（Morgan）是2025年香港互认基金市场中规模最大的基金公司，全年净流入226亿人民币，截至2025年10月末资产规模达810亿元，稳居基金公司头把交椅。

## 2025年资金流向数据

| 产品 | 类型 | 全年/阶段性净流入 |
|------|------|------------------|
| 摩根国际债券基金 | 环球债 | 130亿 |
| 摩根亚洲总收益债基金 | 亚洲债 | 80亿 |
| 摩根亚洲股息基金 | 亚洲股（高股息） | 前三季吸金榜前列 |
| 摩根太平洋科技基金 | 科技板块 | 2025年Q2后逆转，10月跻身净流入前十 |
| **合计** | — | **226亿** |

## 竞争优势来源

1. **产品线广度**：覆盖环球债、亚洲债、亚洲股、科技股多个资产类别，多产品矩阵形成正循环
2. **环球分散策略**：摩根国际债券是唯一环球债券型互认基金，低相关度分散风险能力强
3. **业绩支撑**：多只产品回报领先同类，形成赚钱效应
4. **品牌信任**：规模越大→品牌越强→资金越愿意涌入，形成 [[规模正循环]]

## 与竞争对手的对比

| 维度 | 摩根 | 汇丰 |
|------|------|------|
| 产品线 | 多品类覆盖（债+股+科技） | 聚焦亚洲高收益债+灵活配置 |
| 地域策略 | 全球分散 | 区域聚焦 |
| 2025年10月规模 | 810亿（第一） | 349亿（第二） |
| 2025年全年净流入 | 226亿（冠军） | 净流出（10月由负转正） |
| 核心原因 | 额度充裕+产品矩阵 | 新基金+老基金重启 |

## 关键结论

- "大而全"胜过"窄而锐"——产品线广度是基金公司在互认市场胜出的核心因素
- 摩根案例是 [[规模正循环]] 的经典样本：产品线广→规模大→品牌强→资金继续涌入
- 摩根太平洋科技基金12个月净流出逆转事件（[[摩根太平洋科技基金]]），验证了科技板块反弹驱动资金回流机制
