# 财新

中国财经媒体，以深度报道著称。

## 定位

财新的报道方法可概括为：把异常事件翻成制度结构。不追热点，追踪"大家都知道不对劲但说不清"的制度摩擦点。

## 报道哲学（"markdown"）

财新的"markdown"不是一本书，是一台新闻机器留下的切片集合。其本质是一套**制度诊断机器**：

- 先抓一个可验证的异动（投资转负、终止评级、版权降价等）
- 再问谁在里面得利，谁在承担成本，谁有权不说话，谁被迫浮出水面
- 第一反应不是喊口号，而是找结构

## 栏目体系

| 栏目 | 功能 |
|------|------|
| 最新封面报道 | 把大议题放进时代坐标 |
| 深度 | 拆机制 |
| 特稿 | 把人和链条拉长 |
| 独家 | 放出市场或监管信号 |
| 火线评论 | 给事件定公共问题 |
| 数字说 | 用数字让情绪落地 |

## 方法论核心

财新的分析取景框是：**异常信号 → 利益结构 → 制度后果**，详见 [[异常信号-利益结构-制度后果]]。

每篇稿子都是一次小型 [[制度压力测试]]，将数据、公告、采访、历史背景压在制度上，看哪块先变形。

## 商业模式前提

财新的报道假设读者愿意为长链条付费（7000–8500字的深度报道），而非摘要碎片。这与当前中文互联网的碎片化消费趋势存在内在张力。
