# 易方达稳健收益

晨星中国选基案例中的固收+基金，由[[entities/胡剑]]管理。

## 产品特征

| 要素 | 数值/说明 |
|------|---------|
| 基金类型 | 固收+ |
| 股票占比 | 10%-20% |
| 权益持仓偏好 | 蓝筹价值股 |
| 利率债比例 | 最高50% |
| 久期 | 1-6年，灵活调整 |
| 上行捕获比 | 50.75%（超越78%同类） |

## 定位

- 适合风险偏好中等的投资者
- 债券打底保安全，权益增强追收益
- 在股市向好时仍具配置价值

## 边界

- 如果股市大幅回调，权益部分仍会拖累净值

## 关联

- [[entities/胡剑]]管理的产品，可作为[[concepts/固收+结构]]的实证案例
- 与纯权益基金（如[[entities/毕天宇]]管理的成长基金）形成风险偏好光谱的两端
