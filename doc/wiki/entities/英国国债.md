# 英国国债

英国主权债券，晨星2026Q2全球配置观点中重点提及的资产类别，从中性上调为"有吸引力"。

## 基本特征

- **货币**：英镑（GBP）
- **定价基准**：英国国债收益率曲线，短端对央行政策预期高度敏感
- **风险特征**：受英国通胀、财政赤字、央行政策立场三重驱动

## 2026Q2晨星配置观点

| 指标 | 现状 |
|------|------|
| 配置观点 | ↑ 从"中性"上调至"有吸引力" |
| 核心驱动 | 中东地缘冲突推升收益率曲线波动，中短端品种性价比显现 |
| 关键机制 | 不确定性溢价已被定价 |

## 英债中短端性价比逻辑

```
中东紧张 → 英债收益率曲线波动↑ → 中短端品种性价比↑
```

**触发条件**：
- 英国央行政策预期大幅修正，短端反应尤其敏感
- 中短端收益率上行幅度足够大，覆盖了风险溢价
- 长债虽有财政赤字和供给压力，但随不确定性缓和，溢价有望回落

**边界条件**：若英国通胀数据持续超预期或财政恶化，中短端的"性价比"会被侵蚀——不是无风险机会。

## 与日债对比

| 维度 | 英国国债 | 日本国债 |
|------|---------|---------|
| 2026Q2配置观点 | ↑ 有吸引力 | ↓ 中性 |
| 收益率变动 | 上行幅度足够覆盖风险 | 10Y达数十年高位但补偿不足 |
| 核心压力来源 | 中东地缘冲突 | 油价输入性通胀 + 财政扩张 + 央行偏紧 |
| 价格位置 | 不确定性溢价已被定价 | 风险仍在恶化中 |

晨星对英债与日债的判断具有对称性——两者均受油价冲击影响，但**风险定价程度不同**是观点分化的关键。
