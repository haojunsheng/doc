# 财政部

## 简介

中华人民共和国财政部，是超长期特别国债的发行主体。2024年发行万亿规模超长期特别国债，期限为20年、30年、50年。

## 相关背景

- 2024年发行超长期特别国债引发社交媒体大V鼓吹"闭眼冲"，被解读为"无风险理财天花板"
- 本次发行类型为记账式国债，可上市交易，但也意味着承担市场价格波动风险
