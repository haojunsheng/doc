# 摩根亚洲增长基金

**基金代码**：968073
**管理机构**：摩根资产管理（Morgan Asset Management）
**管理人数**：2人（双基金经理制）
**成立时间**：较早（具体年份未披露）

## 双基金经理

- **Mark Davids**：负责宏观方向判断，管理新兴市场及亚太股票团队，擅长战略层决策
- **郭为熹**：负责个股深挖，在大盘股和小盘股均有不俗实力，专注战术层选股

两人共事近10年，磨合成本低，沟通效率高。

## 投资策略特征

| 维度 | 描述 |
|------|------|
| 选股方式 | 自下而上选取高质量成长型公司 |
| 组合规模 | 40-60只个股 |
| 换手率 | 30%-60%（较低水平） |
| 持有周期 | 每只经五年预期收益评估后长期持有 |
| 研究框架 | 137名研究员按盈利、增长、竞争优势、治理四维度打分分层 |

## 业绩表现

- 年化回报率：6.65%
- 年化超额收益：+50基点 vs 基准
- 夏普比率：0.23（基准0.21）
- 上行捕获率：优于同类
- 下行捕获率：较差，但上行覆盖下行

## 费用结构

- 基金费用率：1.63%
- 同类中位数：1.74%
- 费用优势：11个基点，在50基点年化超额中占比约22%

## 风格暴露

明确的成长偏好，风格稳定：
- 2017/2019/2020年成长股行情中大幅跑赢基准
- 2021-2023年价值股行情中落后

## 已知问题

- 团队对中国市场盈利预测存在持续乐观偏差
- 2023年底新任命大中华区研究主管，任务为纠正此偏差
