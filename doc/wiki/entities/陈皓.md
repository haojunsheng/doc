# 陈皓

中国工程师、技术作家，以技术博客和专栏《左耳听风》闻名。2018 年前后活跃于国内工程师社区， writings 涉及分布式系统、编程范式、技术成长等多个领域。

## 核心观点

- 大多数技术问题本质上是管理问题
- 学习的核心方法：吃一手资料、重基础原理、建立知识地图
- 分布式系统设计的本质是"对故障的妥协方案集"
- 编程范式的本质是"组合方式之争"

## 《左耳听风》专栏

共 117 篇，是陈皓多年工程实践的结晶，按模块分为：
- 分布式系统总纲（21-29）
- 弹力设计（41-51）
- 管理设计（52-57）
- 性能设计（58-62）
- 编程范式（30-40、107-115）
- 工程基础（11-12、17-18、20）
- 区块链（63-68）
- 成长与方法（1-2、5-10、15-16、69-106、加餐）
