# 瑞·达里欧 (Ray Dalio)

## 简介

瑞·达里欧（Ray Dalio），桥水基金（Bridgewater Associates）创始人，全天候策略（All Weather Strategy）的提出者。他是宏观对冲基金领域的标志性人物，以其基于经济变量的资产配置框架闻名。

## 全天候策略

达里欧的全天候策略核心逻辑是**经济四象限模型**：将经济按通胀/通缩和增长加速/减速两个维度划分为四个象限，每个象限配置在该环境下最受益的资产类别。典型配置为股票30% + 债券55% + 黄金15% + 商品等其他资产。

该策略风险资产占比约50%，历史最大回撤约12-16%，适合求稳的投资者。与哈里·布朗的永久组合相比，达里欧虽然也声称被动投资，但其55%的债券比例透露了保守偏好，且他会根据经济环境调整各资产比例，而布朗坚持等权永不调仓。

## 边界与争议

- 达里欧策略在滞胀环境（经济差+通胀高）时可能所有资产同时下跌。
- 其声称的"不预测"具有内在张力：资产配置比例的选择本身就是一种隐性预测。
- 有研究（如 AQR 的报告）指出其实际历史回测表现与宣称的"任何环境都赚钱"存在差距，2022年股债双杀时回撤明显大于文章所述的12-16%。
