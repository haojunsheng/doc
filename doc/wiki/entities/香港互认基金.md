# 香港互认基金

香港互认基金是指在香港注册的公募基金，经中国证监会批准后可在内地公开销售的产品。是内地投资者配置海外市场的重要工具之一。

## 产品定义

- **注册地**：香港
- **监管方**：香港证监会（SFC）+ 中国证监会（CSRC）
- **销售对象**：内地合格投资者
- **币种**：人民币计价（互认份额）
- **投资范围**：全球市场（以港股为主，也可投资美股、欧股等）

## 与 QDII 的区别

| 维度 | 香港互认基金 | QDII 基金 |
|------|------------|----------|
| 注册地 | 香港 | 内地 |
| 监管架构 | 香港证监会 + 中国证监会 | 中国证监会 |
| 销售渠道 | 内地银行、券商、第三方平台 | 内地银行、券商、第三方平台 |
| 额度管理 | 受客地销售比例限制 | 受 QDII 外汇额度限制 |
| 税收待遇 | 香港免税，内地代扣 | 内地税收政策 |

## 政策约束

### 客地销售比例限制

- 规定香港互认基金向内地投资者销售的比例上限
- 超出额度的基金暂停内地申购，或仅向特定投资者开放
- 主要影响债券类互认基金（因利率敏感度高）
- 是资金流向数据失真的重要政策因素

### 与 [[通道摩擦与额度稀缺]] 的关系

香港互认基金的额度限制与 QDII 的额度限制类似，都属于"政策造成的通道摩擦"，但互认基金的限制更针对"客地销售比例"而非整体额度。

## 主要管理人

| 管理人 | 特点 | 代表产品 |
|--------|------|---------|
| 摩根（Morgan） | 规模最大，但受债基流出拖累 | 摩根亚洲股票高息基金、摩根国际债券 |
| 施罗德（Schroders） | 高息策略吸金代表 | 施罗德亚洲高息股债基金 |
| 瑞士百达（Pictet） | 年内累计净流入行业第一 | 瑞士百达全球灵活配置策略 |
| 高腾（Gao Teng） | 差异化债基代表 | 高腾亚洲收益债券 |
| 汇丰（HSBC） | 年内累计净流出较大 | 汇丰亚洲债券基金等 |

## 投资策略特征

1. **高股息策略占比高**：多数互认基金聚焦港股高股息，收益率吸引力强
2. **期权备兑开仓常见**：部分基金通过卖出看涨期权增厚收益
3. **灵活配置产品多**：股债混合策略适应不同市场环境
4. **策略分化明显**：同品类不同策略的资金流向可能完全相反

## 投资风险提示

1. **政策风险**：客地销售比例限制可能随时调整，影响申购可行性
2. **汇率风险**：人民币计价，底层资产以外币计价，存在汇率波动风险
3. **策略拥挤风险**：高股息策略持续吸金可能导致未来收益压缩
4. **流动性风险**：互认基金申购赎回周期较长，流动性管理需提前规划
