# 滨田英明

## 简介

滨田英明是日本当代摄影师，以**低对比度、日系小清新**风格闻名。

## 核心风格特征

**对阴影测光 → 高光过曝 → 日系小清新**。滨田英明的策略与[[Alex Webb]]完全相反：他对画面中的阴影部分和暗部进行测光，有意追求画面略微过曝，让高光区域失去细节，同时保持暗部有内容、不沉入纯黑。

过曝 + 浅景深 = 典型的日系小清新美学效果。

## 与 Alex Webb 的对立关系

两人面对同一类大光比场景时采取完全相反的曝光策略，但都是大师级作品。这一对比共同证明了：**"正确曝光"不是客观参数，而是主观表达意图**。
