# 冯波

易方达基金管理有限公司基金经理，管理旗舰产品易方达行业领先混合长达15年，2026年卸任该基金。

## 基本信息

| 项目 | 内容 |
|------|------|
| 管理年限 | 15年 |
| 代表作 | 易方达行业领先混合（已卸任基金经理） |
| 长周期排名 | 同类前26%（15年维度） |
| 近5年表现 | 偏低，质量成长风格遭遇逆风 |
| 当前状态 | 仍管理研究精选和竞争优势企业 |

## 业绩特征

冯波的业绩呈现明显的**业绩时间窗口偏差**：
- 15年维度：排名前26%，属于优秀水平
- 近5年维度：排名偏低，风格与市场不匹配

这说明冯波具备投资能力，但其擅长的质量成长风格在近5年遭遇逆风，存在**风格漂移或市场错配**的可能。

## 卸任背景

冯波2026年卸任易方达行业领先混合，新任基金经理为彭珂。卸任背景包括：
- 近5年业绩逆风
- 公司内部调整（冯波仍管理其他基金，非全面离职）
- 15年老将为新人让路属于行业常见安排

## 投资风格

冯波以质量成长风格著称，持仓偏向基本面扎实、成长确定性高的企业。风格与市场的匹配度直接影响其业绩表现。
