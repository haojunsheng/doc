# 乔迁

景顺长城基金经理，GARP均衡派代表人物之一，管理景顺长城量化平衡灵活配置混合型证券投资基金（景顺长城成长之星）。

## 基本情况

| 维度 | 内容 |
|------|------|
| 任职机构 | 景顺长城基金 |
| 管理产品 | 景顺长城成长之星（景顺长城量化平衡灵活配置混合型证券投资基金） |
| 从业年限 | 17年（内部培养路径） |
| 年化回报 | 17.5%（2018.7–2026.1，约7.5年管理期） |
| 投资风格 | GARP均衡派（合理价格买入成长） |

## 投资体系

核心策略为GARP（Growth at a Reasonable Price）：用合理价格买合适回报率的股票，目标年化回报10–15%，估值明显高估时卖出。

- 不追热点、不盲从趋势
- 持仓不完全集中于大盘股，也挖掘中小市值标的（如思源电气）
- 明确追求估值与成长的匹配度

形式化表达：

```
估值合理性 ∩ 成长确定性 → 买入
估值明显高估 → 卖出
⇒ 年化17.5%（2018.7–2026.1）
```

## 关键特征

- 任期波动和下行风险均低于同类平均
- 非外部跳槽型，从研究岗起步内部成长17年后独立管产品
- 策略一致性强，与 [[synthesis/五大流派框架]] 中GARP均衡派高度吻合

## 与现有框架的关联

[[synthesis/五大流派框架]]将乔迁归入GARP均衡派，代表人物除[[刘旭]]、[[周云]]外，乔迁是补充案例。

## 边界条件

- 若市场持续高估（牛市末期），GARP策略可能因过早卖出而跑输
- 内部培养路径依赖公司投研体系质量
