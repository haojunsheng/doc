# 乔迁

景顺长城基金经理，GARP（Growth at a Reasonable Price，合理价格买入成长）均衡派代表人物之一，管理景顺长城量化平衡灵活配置混合型证券投资基金（景顺长城成长之星）。晨星中国选基案例中的GARP策略代表基金经理。

## 基本情况

| 维度 | 内容 |
|------|------|
| 任职机构 | 景顺长城基金 |
| 管理产品 | 景顺长城成长之星（景顺长城量化平衡灵活配置混合型证券投资基金） |
| 从业年限 | 17年（内部培养路径，从研究岗起步） |
| 年化回报 | 17.5%（2018.7–2026.1，约7.5年管理期） |
| 投资风格 | GARP均衡派（合理价格买入成长） |
| 上行捕获比 | 97.59% |

## 投资体系

核心策略为GARP：用合理价格买合适回报率的股票，目标年化回报10–15%，估值明显高估时卖出。

- 选股框架：竞争格局 + 优势 + 管理层 + 估值匹配
- 不追热点、不盲从趋势，以此作为超额来源
- 持仓不完全集中于大盘股，也挖掘中小市值标的（如思源电气）
- 适度均衡，明确追求估值与成长的匹配度

形式化表达：

```
估值合理性 ∩ 成长确定性 → 买入
估值明显高估 → 卖出
⇒ 年化17.5%（2018.7–2026.1），上行捕获比97.59%
```

## 关键特征

- 任期波动和下行风险均低于同类平均
- 非外部跳槽型，从研究岗起步内部成长17年后独立管产品
- 策略一致性强，与 [[synthesis/五大流派框架]] 中GARP均衡派高度吻合

## 在成长风格中的定位

与[[entities/毕天宇]]（集中型成长，成长行业集中）、[[entities/詹成]]（行业精选型成长，聚焦成长行业）形成成长风格内部的三种子类型对比：

| 基金经理 | 风格类型 | 组合特点 |
|---------|---------|---------|
| [[entities/毕天宇]] | 集中型成长 | 成长行业集中 |
| [[entities/詹成]] | 行业精选型成长 | 聚焦成长行业 |
| [[entities/乔迁]] | GARP均衡 | 适度均衡，兼顾估值 |

## 与市场环境的适配

- 在成长占优但估值风险积累的市场中，GARP攻守平衡
- 上行捕获比97.59%说明在上涨市中几乎完全参与
- 可作为[[concepts/GARP策略]]的实证案例

## 边界条件

- 若市场持续高估（牛市末期），GARP策略可能因过早卖出而跑输
- 若市场进入纯概念炒作阶段，估值约束会拖累表现
- 内部培养路径依赖公司投研体系质量

## 与现有框架的关联

[[synthesis/五大流派框架]]将乔迁归入GARP均衡派，代表人物除[[刘旭]]、[[周云]]外，乔迁是补充案例。
