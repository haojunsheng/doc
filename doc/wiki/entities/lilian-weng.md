# Lilian Weng

AI 研究者、工程师，博客作者。其撰写的 Agent 综述文章是该领域最广为流传的入门框架之一。

## 核心贡献

- 撰写 [LLM Powered Autonomous Agents](https://lilianweng.github.io/posts/2023-06-23-agent/)，系统梳理 Agent 的组成模块（规划、工具调用、记忆），成为 AI Agent 领域引用最高的综述之一。

## 在 wiki 中的位置
