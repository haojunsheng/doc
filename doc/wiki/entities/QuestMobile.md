# QuestMobile

QuestMobile 是国内领先的移动互联数据监测平台，提供 App 活跃度、用户心智及迁移行为的一手数据。

## 在美团投资跟踪中的角色

是美团投资跟踪的首要数据源，用于监测用户对美团主站的真实粘性变化，以及来自淘宝闪购、京东、抖省省等竞品的用户心智侵蚀风险。

### 监测指标

- **MAU / DAU**：衡量主站规模趋势
- **使用频次**：用户打开 App 的频率变化
- **用户重叠**：美团用户同时使用哪些竞品
- **App 迁移**：用户从美团流向哪个平台

### 对应关键问题

- 美团主站用户有没有流失？
- 淘宝闪购和京东是否提高主站打开频次？
- 抖省省是否真正起量？
- 即时零售是否让用户从单一外卖迁移到综合消费入口？

## 辅助工具

- **极光**：App 活跃、用户画像、行业报告，作为 QuestMobile 的辅助验证。
- **data.ai / Sensor Tower**：App 下载、排名、海外数据，主要用于观察 Keeta、抖省省等海外/新产品趋势。

## 数据局限性

QuestMobile 本质是流量数据，无法直接反映交易质量（如 GMV、核销率），需与蝉妈妈、久谦等工具交叉验证。
