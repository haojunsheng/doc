# 卢琴斯（Luchins）

美国心理学家，1957 年研究证明：后续新出现的刺激物是印象形成的决定因素——这一发现为近因效应提供了重要的实验证据。

## 关键贡献

**1957 年研究**：在印象形成实验中，被试者阅读的关于某人的描述信息中，后续出现的新信息比早期信息对整体印象的影响更大。这直接支持了近因效应在社会认知中的作用。

## 在投资语境中的意义

- 解释了为什么基金经理更换后，投资者对基金的评价会迅速转向（新信息覆盖旧印象）
- 解释了为什么基金短期业绩的负面新闻会迅速摧毁长期建立的信任
- 与艾宾浩斯的系列位置效应研究相互印证：近因效应是社会认知和投资判断中的普遍机制
