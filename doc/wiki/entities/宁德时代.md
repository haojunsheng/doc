# 宁德时代

宁德时代（CATL）是全球动力电池龙头，2021年前后作为"高成长叙事"的标志性案例出现在新能源牛市中。

## 投资案例中的角色

在[[失控的增长]]和[[成长的叙事陷阱]]的案例分析中，宁德时代2021年的估值巅峰被用作说明"高成长叙事如何导致估值崩塌"的典型样本：

- **2021年**：新能源牛市峰值，市盈率突破100倍，"高成长"叙事让估值失去锚点
- **2021年后三年**：赛道竞争加剧、产能过剩，股价腰斩甚至脚踝斩
- **叙事与现实的落差**：行业增长确实存在，但投资者收益与行业增长脱钩——这是[[失控的增长]]核心论断的实证

## 案例警示

宁德时代的案例凸显了[[成长的叙事陷阱]]的运作机制：当"高成长"标签被广泛接受，投资者停止追问竞争格局和护城河，直至估值泡沫破裂。该案例同时说明了[[增长率陷阱]]的核心命题——为增长支付过高价格，最终回报为负。
