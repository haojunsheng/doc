# 谢治宇

## 基本信息

- **身份：** 基金经理
- **投资流派：** 硬核成长派
- **核心特征：** 产业萌芽期布局，赚取产业趋势的钱
- **换手率变化：** 早期换手率约300%，后降至约100%（框架进化，非风格漂移）

## 投资风格

```
硬核成长派 = 行业萌芽期布局 → 业绩驱动股价
```

与长期价值派的本质区别：
- 成长派赚的是**产业趋势**的钱
- 价值派赚的是**估值修复**的钱
- 两者都看公司质地，但一个重增速、一个重安全边际

## 框架进化案例

[[谢治宇]]换手率从300%降至100%，是其投资框架进化的表现——从交易型转向陪伴企业成长，体现了[[知行合一（框架稳定性）]]中的"框架稳定性"原则：表面行为变化，底层逻辑一致。

详见 [[基金经理换手率评级]]。

## 边界条件

- **产业趋势误判风险**：判断错误或介入太早，可能承受巨大回撤
