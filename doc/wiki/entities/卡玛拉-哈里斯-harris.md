# 卡玛拉·哈里斯（Kamala Harris）

美国第 49 任副总统，2024 年美国总统选举民主党候选人。

## 经济政策立场

| 领域 | 政策主张 |
|------|---------|
| 税收 | 向富人加税：提高个税最高税率、增企业税、对未实现资本利得征税 |
| 通胀 | 主张整治企业哄抬食品物价（限价政策） |
| 贸易 | 支持多边自由贸易体系 |
| 监管 | 倾向加强监管 |

## 与投资的关联

晨星研究指出，哈里斯与特朗普在经济议题上立场几乎完全相反，但两党均缺乏有效的通胀对策——哈里斯的限价政策实施难度大，特朗普的关税政策反而推高物价。投资决策不应基于"哈里斯赢 vs 特朗普赢"的二元预测。
