# 广发内需增长混合

广发内需增长混合是晨星 2024 年 8 月推荐的焦点基金之一，聚焦内需增长主题，重点投资消费、医药、服务等内需相关行业。

## 基本信息

| 属性 | 内容 |
|------|------|
| 基金名称 | 广发内需增长混合 |
| 基金类型 | 混合型基金（内需增长主题） |
| 推荐机构 | 晨星中国（Morningstar） |
| 推荐时间 | 2024 年 8 月 |
| 投资主题 | 内需增长 |

**注**：本来源未提供基金代码、基金经理姓名、最新规模及费率结构等具体信息，需查阅基金定期报告获取完整数据。

## 投资定位

该基金定义"内需增长"为以下多行业覆盖：

```
内需增长 = 消费 + 医药 + 服务 + 受益内需扩张的制造业
```

与单一行业主题基金不同，该基金横跨消费、医药、服务及制造业四个方向，属于宽内需主题配置。

## 选股方法论

基金经理采用自下而上的选股方法，三要素公式：

```
选股 = 品牌力 × 盈利能力 × 估值水平 → 高确信度标的
```

| 要素 | 权重/含义 |
|------|-----------|
| 品牌力 | 消费企业的核心竞争力 |
| 盈利能力 | 反映企业质地 |
| 估值水平 | 决定安全边际 |

## 风险评估

| 风险类型 | 风险描述 |
|---------|---------|
| 消费降级 | 可能影响企业盈利 |
| 政策变化 | 可能影响行业格局 |
| 高估值 | 面临回调压力 |
| 定义过宽 | 若内需定义过于宽泛，基金定位不清晰 |

## 策略稳定性

- 策略框架明确：品牌力 × 盈利能力 × 估值水平
- 选股方法自下而上，不依赖行业择时
- 需持续跟踪基金经理是否坚守能力圈
