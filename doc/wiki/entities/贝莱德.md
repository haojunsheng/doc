# 贝莱德（BlackRock）

全球最大资产管理公司，通过比特币信托ETF（IBIT）成为加密货币ETF领域的头号玩家。

## 在本Wiki中的角色

贝莱德是"新资产被传统金融收编"叙事的核心执行者——通过ETF产品将比特币这一边缘资产纳入主流合规投资渠道，单只产品规模在短时间内超越全行业早期总和。

## IBIT：比特币信托ETF

| 指标 | 数值 |
|------|------|
| 成立时间 | 2024年1月 |
| 2024年11月单月净流入 | 16亿美元（占当月全市场20亿的80%） |
| 规模 | 约390亿美元 |
| 市场占比 | 超过2023年底全类别53只ETF总和（380亿） |

**核心优势**：品牌溢价 + 低费率 + 高流动性，形成三重护城河。
