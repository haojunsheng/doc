# 叮咚买菜

美股上市公司（NASDAQ: DDL），自营前置仓模式的即时零售代表企业。

## 公司概况

- **模式**：自营前置仓（重资产：自建前置仓 + 自采自销 + 即时配送）
- **覆盖范围**：长三角 17 城（江苏、浙江、上海为主），非扩张型盈利模式
- **定位**：生鲜为主，自有品牌占比 20%+

## 关键财务数据（2022-2024）

| 指标 | 2022（亏损年） | 2023（减亏） | 2024（盈利年） |
|:---|:---|:---|:---|
| 营收 | ~200 亿 | ~210 亿 | **≈ 230.7 亿** |
| 毛利率 | ~28% | ~29% | **≈ 30%+** |
| 履约费率 | ~27% | ~25% | **≈ 22-23%** |
| 营销费率 | ~5% | ~4% | ≈ 3-4% |
| 净利率 | 亏损 | 微利转正 | **非 GAAP 利润持续为正** |
| 覆盖城市 | 收缩后 ≈ 17 城 | 稳定 | 稳定（长三角深耕） |

> 数据来源：SEC 20-F / 纳斯达克披露。GAAP 净利率含股权激励/资产减值，非 GAAP 净利润持续为正。

## 竞争地位

- **市占率**：约 3-4%（2024-2025 估算，即时零售整体 GMV 口径）
- **战略转型**：从大规模扩张转向"收缩+深耕"——退出无优势城市，聚焦长三角
- **盈利路径**：收缩战线 + 自有品牌（20%+ 销售占比拉动毛利率）+ 供应链直采降低履约费率

## 行业意义

叮咚买菜证明了**前置仓模式在 UE 模型上成立**——通过控制城市数量和规模效应，可以实现非 GAAP 盈利。但天花板受限于覆盖范围，跨区域扩张重启需依赖 UE 进一步改善。
