# 伯克希尔·哈撒韦（Berkshire Hathaway）

美国跨国 conglomerate 控股公司，由沃伦·巴菲特（Warren Buffett）自 1965 年接管以来，实现了年化收益率超过 20% 的传奇业绩。

## 核心商业模式

伯克希尔的业务版图主要由两部分组成：

1. **收购优秀公司并持续经营**（全资子公司）
2. **投资少数优秀公司的股权**（股票投资组合）

晨星中国从基金角度分析时提出：如果将伯克希尔视为一只"基金"，其零费率结构和保险浮存金杠杆使其成为一种特殊的投资载体。

## 资产配置三支柱

| 支柱 | 说明 |
|------|------|
| 股票投资 | 提供资本增值，包括苹果、可口可乐等核心持仓 |
| 全资子公司 | 提供稳定现金流，如 GEICO 保险、BNSF 铁路等 |
| 现金及等价物 | 用于应对危机和捕捉投资机会的流动性储备 |

## 零费率结构

与公募基金不同，伯克希尔作为公司实体不收取管理费。投资者购买伯克希尔股票后，无需每年支付管理费或托管费，所有投资收益归股东所有——仅需支付交易费用。这一结构使其被晨星称为"一只零费率基金"。

**边界**：公司运营成本仍会体现在利润中，并非真正"零成本"。

## 保险浮存金杠杆

伯克希尔的核心差异化因素在于其保险业务产生的**保险浮存金**（Insurance Float）：

- 保险公司收取保费后、赔付前的资金沉淀
- 低成本甚至零成本的资金来源
- 巴菲特将这些资金投入投资组合，实现收益放大

**边界**：赔付压力增大时浮存金减少，杠杆效应削弱。

## 投资哲学

- **集中投资**：巴菲特认为"分散投资是对无知的保护"，主张高确信度深度研究后集中持有
- **长期持有**：减少交易成本，让复利发挥作用
- **能力圈原则**：聚焦自己理解并确信的投资标的

## 自认的"最大错误"

巴菲特公开表示，收购伯克希尔（当时是一家纺织公司）是他最大的错误。原因是：

```
机会成本 = 本可用于更高回报机会的资金被沉淀在纺织业务中
```

这揭示了机会成本与事后结果的不对称性——当时看来是一次错误，但经过转型后的结果是传奇的。

## 长期业绩与规模约束

- 1965 年至今，年化收益率超过 20%
- 股价增长数万倍
- **关键约束**：随着规模增大，获取超额收益的难度持续上升

这与 [[concepts/基金业绩的短期随机性]] 形成对照：伯克希尔的"不可持续"风险来自规模而非运气。

## 对普通投资者的启示

- **可学习**：长期投资、深度研究、耐心持有的理念
- **难复制**：保险浮存金的资金优势和交易对手地位不可复制
