# 工银瑞信信用添利

工银瑞信信用添利债券是一只专注于信用债投资的基金，属于 [[产业债基金]] 范畴，由 [[工银瑞信]] 管理，入选晨星焦点基金系列。

## 基本信息

- **基金类型**：债券型基金（信用债为主）
- **管理人**：[[工银瑞信]]
- **归类**：[[晨星morningstar]] 焦点基金系列
- **策略定位**：通过独立信用评级能力，力求为投资者创造稳健收益

## 投资策略

```
信用债收益 = 无风险利率 + 信用利差
超额收益来源 = 信用利差变动
```

核心是通过深入的信用研究和利差分析，承担信用风险以获取票息收益，并通过利差变动捕捉交易机会：

- 信用利差收窄 → 债券价格上涨（资本利得）
- 信用利差扩大 → 债券价格下跌（资本损失）

## 核心竞争力：独立信用评级能力

工银瑞信依托自有信用研究团队，具备独立的信用评级能力，不完全依赖外部评级机构。这是该基金区别于一般信用债基金的关键特征：

```
信用研究能力 = f(研究团队规模, 评级模型, 风控体系)
```

**边界条件**：研究团队的判断也可能出错——如果信用事件超出预期，仍然可能造成损失。
