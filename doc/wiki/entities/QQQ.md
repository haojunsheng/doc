# QQQ

QQQ（Invesco QQQ Trust）是美国追踪纳斯达克100指数的交易所交易基金（ETF），由Invesco（景顺）发行和管理。

## 基本信息

| 属性 | 内容 |
|---|---|
| 全称 | Invesco QQQ Trust |
| ticker | QQQ（NASDAQ） |
| 发行方 | Invesco（景顺） |
| 跟踪标的 | 纳斯达克100指数（NASDAQ-100） |
| 上市地 | 美国NASDAQ交易所 |
| 费用水平 | 管理费约0.20%/年，显著低于境内QDII产品 |

## 与境内QDII的关系

QQQ是境内人民币投资者获取纳指100敞口的**境外替代工具**：

- **优势**：费用低（约0.20% vs 境内QDII约1.00%）、流动性极佳、无QDII额度限制、无场内溢价风险
- **约束**：需要境外证券账户、涉及换汇和跨境合规条件，对大多数境内普通投资者不构成可直接使用的通道

## 在闸门经济框架中的定位

QQQ代表了纳斯达克QDII品类分析中的"更直接、更低费率、更少摩擦的合法替代通道"。对于已具备境外投资条件的投资者，QQQ是绕过闸门经济成本的最优解；对于仅能通过境内渠道投资的投资者，需在QDII产品溢价率纪律约束下做出选择。
