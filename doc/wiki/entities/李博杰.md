# 李博杰

## 身份

Pine AI 首席科学家，OpenClaw 作者。撰写了《深入理解 AI Agent：设计原理与工程实践》（v1.4，2026 年 8 月，10 章约 304 页）。

> **注意**：已存 wiki 描述其为「《AI Agent 实战》作者」，新源描述其为「OpenClaw 作者」并著《深入理解 AI Agent：设计原理与工程实践》。两本书名不同，需核实是否为同一人两部著作，或身份标签存在差异。

## 主要著作

- **《深入理解 AI Agent：设计原理与工程实践》**（v1.4，2026 年 8 月，10 章约 304 页）：从上下文工程到多 Agent 协作，覆盖 Agent 构建全流程；核心论点为 Harness 工程是生产级 Agent 竞争力的关键。
- **配套 OpenClaw 框架**：书中案例与实验背景均源于此，包括消融实验（52.8% → 66.5%）和 Pass@k vs Pass^k 评估区分。

## 核心观点

- Agent 核心公式：**Agent = LLM + 上下文 + 工具**
- Harness 工程是生产级 Agent 稳定性的核心来源（上下文管理、工具编排、评估体系、安全护栏、错误恢复）
- 模型-Harness 共同进化飞轮：Harness 补上模型此刻做不好的事，补救经验沉淀为训练信号，模型内化后对应 Harness 层可删
- Pass@k（试 k 次有一次成功）≠ Pass^k（连续 k 次都成功）——这是选型评估时最常忽略的语义鸿沟
- 隔离优于压缩：与其让单 Agent 记住一切，不如把任务分给多个子 Agent
