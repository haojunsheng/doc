# 约翰·凯利（John L. Kelly Jr.）

贝尔实验室科学家，1956年提出凯利公式。

## 背景

- 任职于贝尔实验室（信息论重要诞生地）
- 师从或同属于香农所在的团队环境

## 贡献

1956年发表论文，从信息论角度推导出最优投注仓位公式，后被称为凯利公式（Kelly Criterion）。公式形式：

```
f* = (p × b - q) / b
```

## 影响

香农和索普后续将其应用于赌场实践并验证，索普进一步将这一思想引入华尔街，开启了量化投资的新方向。
