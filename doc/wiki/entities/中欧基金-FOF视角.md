# 中欧基金（FOF视角）

**中欧基金**在2025年Q3存量FOF持营中表现突出，其FOF产品前三季度增长68亿，是FOF规模创新高的核心驱动力。

| 指标 | 数值 |
|------|------|
| 前三季度FOF规模增长 | +68亿 |
| FOF总规模趋势 | 突破2001亿创新高 |
| 增长来源 | 存量持营爆发 |

## 配置意义

在[[concepts/FOF配置转向框架]]中，中欧FOF的持营增长是"FOF规模创新高"转向的存量驱动力。同期华安FOF增长60亿、博时FOF增长59亿，显示存量FOF持营是规模增长的主要来源，而非新资金追高权益。

这一特征解释了为什么权益持仓从价值大幅撤出但规模仍在增长——规模增长主要来自存量持营，而非新资金流入权益。
