# 刘邦

名邦，字季，汉朝开国皇帝（汉高祖）。书中定位为「多轴系统」的典型样本——单挑从未赢过项羽，但通过构建多轴协同系统最终获胜。

## 五轴系统

刘邦构建了一个五轴协同系统：

| 轴 | 代表人物 | 核心职能 |
|----|---------|---------|
| 后勤轴 | 萧何 | 关中大后方，源源不断为前线输血 |
| 战略轴 | 张良 | 「下邑画策」，点出英布、彭越、韩信三枚关键棋子 |
| 侧翼军事轴 | 韩信 | 十个月平定北方四国 |
| 敌后袭扰轴 | 彭越 | 持续袭扰楚军后方，像「怎么也轰不走的苍蝇」 |
| 正面牵制轴 | 刘邦本人 | 正面与项羽主力对峙 |

## 关键转折

- **彭城大败后**：刘邦被项羽三万骑打得全军覆没，但这次惨败反而启动了最有效的调整——下邑画策、争取英布、启用韩信
- **反思窗口**：刘邦在劣势时打开反思窗口，调整系统；项羽在连胜时从未换过打法

## 书中定位

刘邦是「系统厚度碾压单点天才」的胜利者。他个人能力不如项羽，但系统韧性远超项羽。书中强调：不是刘邦更聪明，而是他的系统有多双眼睛同时盯着不同方向。

## 开放问题

书中称刘邦「无意中」构建多轴系统，但张良「下邑画策」说明有明确战略规划——「无意」与「有意」之间存在叙述张力。
