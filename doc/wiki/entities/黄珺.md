# 黄珺

富国基金基金经理，硬核成长派变体实践者，擅长从产业趋势早期识别赔率与预期收益率双高的标的。

## 基本情况

| 维度 | 内容 |
|------|------|
| 任职机构 | 富国基金 |
| 从业年限 | 17年（其中组合管理11年） |
| 投资风格 | 硬核成长派变体 |

## 投资体系

采用**中观行业比较 + 自下而上选股**的框架：从景气度向上的行业中挑选赔率和预期收益率双高的公司。

典型操作：
- 2022年下半年判断传媒和机器人产业趋势明确，左侧布局
- 从性价比角度减持医药、食品饮料、交运
- 中小盘长期占比高于同类，擅长挖被忽略的标的
- 结果：恺英网络涨245%，环旭电子翻倍

形式化表达：

```
产业政策判断 + 财务数据验证 → 左侧布局传媒/机器人
⇒ 恺英网络 +245% + 环旭电子翻倍
```

## 关键特征

- 坚持独立思考，不盲目追逐"明星个股"
- 任期波动和下行风险均低于同类平均
- 非外部跳槽型，从研究岗起步内部成长17年后独立管产品

## 与现有框架的关联

[[synthesis/五大流派框架]]中，黄珺属于硬核成长派变体。其与[[谢治宇]]的区别在于：谢治宇偏产业趋势确认后的右侧跟踪，黄珺更强调左侧介入（赔率优先）。

## 边界条件

- 若行业判断失误或左侧过早，可能承受较长时间浮亏
- 内部培养路径依赖公司投研体系质量
