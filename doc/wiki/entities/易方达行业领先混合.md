# 易方达行业领先混合

易方达基金管理有限公司旗下混合型基金，冯波管理的旗舰产品，2026年更换基金经理。

## 基本信息

| 项目 | 内容 |
|------|------|
| 类型 | 混合型基金 |
| 基金公司 | 易方达基金 |
| 前任基金经理 | 冯波（管理15年） |
| 现任基金经理 | 彭珂（2026年接任） |
| 基金特点 | 深度绑定冯波个人风格 |

## 历史业绩

- **15年维度**：同类排名前26%，属于优秀水平
- **近5年维度**：排名偏低，质量成长风格遭遇逆风

## 换帅事件

2026年，冯波卸任该基金基金经理，由彭珂接任。换帅原因综合了业绩压力与内部人才梯队调整：
- 冯波仍管理研究精选和竞争优势企业，属于局部交接而非全面离职
- 彭珂从研究员出身，1年投管经验，接管时仅6天管理经验在此基金
- 基金风格深度绑定冯波个人，换帅带来策略断裂风险

## 持有人应对

该案例是分析**单一基金经理依赖风险**的教科书级案例——基金打上了冯波的风格烙印，换帅意味着持有人买到的可能不再是"冯波式的易方达行业领先"。
