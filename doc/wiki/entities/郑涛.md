# 郑涛

中银基金基金经理，海外债券投资专家。

## 基本信息

| 属性 | 内容 |
|------|------|
| 所属公司 | 中银基金 |
| 海外债经验 | 20年 |
| 研究方向 | 中资美元债、信用债风险判断 |
| 团队支持 | 中银有专门的海外宏观策略研究员 |

## 核心能力：风险判断的动态调整

郑涛是[[concepts/海外投研能力框架]]中"风险判断能力"的典型案例：

**2020年前**：
- 中资美元地产债违约率低
- 策略：配置高收益地产债
- 结果：超额收益高

**2020年后**：
- 地产债违约率上升，风险格局逆转
- 策略：主动降低地产债仓位，转向投资级债券
- 结果：成功规避地产债违约风险，体现风险识别能力

**核心纪律**：严格分散配置、不碰无评级品种，体现长期稳健风格。

## 与晨星的关系

[[entities/晨星morningstar]]在QDII基金推荐中将郑涛作为中资美元债方向的代表，认为其风险判断能力是真正的差异化能力，而非单纯追逐收益。
