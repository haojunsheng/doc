# 兴全合宜混合

兴全基金管理公司旗下的灵活配置混合型基金，以"以老带新型增聘"模式著称。

## 增聘历史

兴全合宜历史上多次增聘新基金经理，形成典型的"以老带新"培养模式：
- 原基金经理继续掌舵，新经理合管1-2年后独立
- 决策权始终保留在原经理手中
- 新人来自内部培养（研究员/基金经理助理出身）

## 案例意义

兴全合宜是"以老带新"型增聘的代表性案例，展示了公募基金公司如何通过组织安排实现人才梯队建设，而非被动应对离职风险。

## 投资者启示

评估以老带新型增聘时，投资者应关注：
1. 原经理是否继续掌舵（决策权归属）
2. 新经理是否为内部培养（非外部空降）
3. 新经理合管周期（通常1-2年）
