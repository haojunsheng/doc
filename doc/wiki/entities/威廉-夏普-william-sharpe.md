# 威廉·夏普（William Sharpe）

美国经济学家，1960 年代首次将投资收益拆分为**阿尔法（Alpha）**和**贝塔（Beta）**两部分，奠定了现代投资组合理论的量化基础。后发展出**CAPM（资本资产定价模型）**，获 1990 年诺贝尔经济学奖。

## 核心贡献

**收益分解框架**：任何投资的总收益都可以拆解为两部分：

```
总收益 = 贝塔收益（市场风险补偿）+ 阿尔法收益（超额管理能力）
```

- **贝塔收益**：来自承担系统性风险（市场波动）所获得的补偿，可被动获得
- **阿尔法收益**：来自基金经理的选股/择时能力，是主动管理的产物
