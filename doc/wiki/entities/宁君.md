# 宁君

富国基金港股投资部负责人，拥有9年港股投资经验。

## 基本信息

| 属性 | 内容 |
|------|------|
| 所属公司 | 富国基金 |
| 职位 | 港股投资部负责人 |
| 海外经验 | 9年港股 |
| 投资风格 | 成长 + 高股息（2023年后扩展） |
| 平台支持 | 富国海外权益投研团队 |

## 投资框架

- 核心选股逻辑始终：竞争壁垒 + 成长空间 + 估值
- 2023年从纯成长策略扩展至成长 + 高股息，目的是增加组合防御性，而非风格漂移
- 属于[[concepts/风格适配]]的实际案例，体现[[concepts/海外投研能力框架]]中的平台支持效应

## 代表性投资

### 泡泡玛特（2024年上半年买入）

- 宁君对新兴消费业态保持敏锐，2024年上半年建仓泡泡玛特
- 体现其"竞争壁垒 + 成长空间 + 估值"框架对跨行业机会的适用性
- 详见[[entities/泡泡玛特]]

## 与平台的关系

根据[[concepts/海外投研能力框架]]，宁君的成功不仅依赖个人9年港股经验，也得益于富国海外权益投研团队的支持。在[[entities/晨星morningstar]]的四只QDII推荐中，宁君是唯一被点名的港股方向基金经理。
