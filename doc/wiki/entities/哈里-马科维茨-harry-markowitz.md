# 哈里·马科维茨（Harry Markowitz）

美国经济学家，1990 年诺贝尔经济学奖获得者，现代投资组合理论（Modern Portfolio Theory, MPT）的奠基人。

## 核心贡献

### 均值-方差模型

马科维茨第一次用严格的数学方法证明：**组合的整体属性比单个资产的属性更重要**。核心洞见是——资产之间的**相关性**才是决定组合风险的关键因素，而非单个资产的风险大小。

形式化转变：

```
旧范式: 投资 = 选最佳个股（单品视角）
新范式: 投资 = 选相关性低的资产组合（组合视角）
```

这一转变直接催生了 [[concepts/组合视角]] 的认知框架。

## 理论边界

马科维茨均值-方差模型有一个重要假设局限：**投资者只关心风险和收益两个维度**，忽略了流动性、税收、社会影响等其他现实约束。在实际应用中需要引入修正。

## 在本 wiki 中的角色

马科维茨是现代投资组合理论的起点。[[威廉-夏普-william-sharpe]] 将其纯数学理论转化为实用的 CAPM 模型；[[约翰博格尔john-bogle]] 则进一步将其落地为万亿美元规模的指数基金产品。三者的贡献构成了一条从理论到实践的完整链条。
