# 国证自由现金流指数

国证自由现金流指数是由国证指数公司编制的、以自由现金流为核心筛选标准的A股指数，是市场上首只自由现金流主题指数的跟踪标的。

## 编制规则要点

- **核心筛选**：以自由现金流（经营现金流 − 资本开支）为核心排序指标
- **行业排除**：刻意排除金融、地产等高负债、高账面利润行业（这些行业往往是传统红利策略的价值陷阱重灾区）
- **质量导向**：优先选择自由现金流稳定且充裕的公司

## 历史业绩

| 指标 | 数据 |
|------|------|
| 年化收益 | 12%（自2015年起） |
| 正收益年份 | 2019-2024连续6年 |
| 对比沪深300 | 大幅跑赢（同期0.9%） |
| 对比中证红利 | 大幅跑赢（同期4.6%） |

## 关联ETF产品

- **华夏国证自由现金流ETF**：首批产品，规模从6.94亿增至37亿（2025年6月数据），管理费降至0.15%
- 另有其他基金公司发行的跟踪产品
