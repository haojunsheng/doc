# 东方红汇利债券基金

## 基本信息

| 项目 | 内容 |
|------|------|
| 基金代码 | 002651 |
| 基金类型 | 积极债券基金 |
| 基金公司 | 东方证券资产管理 |
| 晨星定位 | 晨星焦点基金 |
| 业绩基准 | 中国积极债券基准指数（含转债的债券指数） |

## 产品定位

追求**绝对收益**的低波动债基，以纯债打底、可转债增强，不直接参与股票投资。与[[entities/东方红聚利]]同属东方红系，但定位不同——东方红聚利为准可转债策略基金（仓位0%-140%灵活调整），东方红汇利更偏向"固收+"框架。

参见 [[concepts/跑赢基准vs绝对收益]] 了解绝对收益与相对收益在产品定位上的系统性差异。

## 纯债配置参数

| 维度 | 区间 | 均值 | 偏好 |
|------|------|------|------|
| 信用债 | 45%-85% | 54% | AAA国央企+四大行二永债，AAA以下<15% |
| 利率债 | <30% | 21% | 波段操作为主 |
| 久期 | 1-3年 | — | — |
| 杠杆 | <120% | — | 看好时可升至132% |

## 转债策略参数

| 维度 | 参数 |
|------|------|
| 仓位中枢 | 25% |
| 选券偏好 | 低价高等级，偏债型为主 |
| 个券精选方法 | 错误定价捕捉、下修博弈、正股波动率 |
| 下跌保护 | 低价高等级转债债底保护强 |

## 费用结构

综合费率低于同类平均水平，管理费、托管费、销售服务费均处于行业中低水平。在低利率环境下，费率优势更凸显（参见 [[concepts/费率复利效应]]）。

## 适用场景与边界

**适合**：
- 低利率环境
- 追求绝对收益、低波动的中长期投资者
- 震荡市场

**不适合**：
- 需要更高权益暴露（如20%以上）的投资者
- 单边大牛市（绝对收益导向基金可能跑输相对收益导向基金）

**边界条件**：
- 若转债市场出现系统性下跌（如2022年），"中间路线"也会失效
- 若利率大幅上升，纯债部分会承压

## 核心策略公式

```
东方红汇利策略 = 纯债打底（信用债54%均值+利率债波段）
               + 转债增强（仓位25%中枢+低价高等级偏好）
               + 绝对收益导向
               → 低波动，追求"中间路线"
```

参见 [[concepts/固收加的权益暴露度权衡]] 了解同类产品在不同市场环境下的表现差异。
