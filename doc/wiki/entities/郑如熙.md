# 郑如熙

固收基金经理，2026年固收投资策略代表性观点持有者之一。

## 核心观点

- 中短端信用利差压缩空间已**极其有限**，长端和超长端债券反而可能成为债市投资的胜负手
- 地产失速将拖累GDP并蔓延信用风险
- 关注长端利率债的交易机会（若资金面转松引发宽松预期）
