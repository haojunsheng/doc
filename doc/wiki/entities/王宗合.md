# 王宗合

晨星研究文章中引用的反面案例：管理经验长达10年以上，但管理鹏华匠心精选期间该基金3年下跌38%。该案例用于说明"经验年限 ≠ 业绩质量"的核心论点——即使拥有长期从业经历，若缺乏对运气的反思和风险控制纪律，业绩仍可能显著跑输同类。
