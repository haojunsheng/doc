# 李世民

唐太宗，唐朝实际奠基者。渤海小吏在《大唐气象》中将其视为唐朝「初始动量」的注入者。

## 核心成就

| 事件 | 意义 |
|------|------|
| 虎牢关一战灭双王 | 展示军事天赋，奠定天下威望 |
| 玄武门之变 | 夺取权力，完成从 0 到 1 的政权转移 |
| 天可汗体系 | 收服草原，建立东亚秩序 |
| 贞观之治 | 制度奠基（三省六部、府兵制） |

## 成功公式拆解

书中所用公式：成就 = 成功率 × 事业量级 × 效率 × 时间长度 × 时代的机遇

- **成功率**：虎牢关一战定乾坤，几乎无败绩
- **事业量级**：奠定唐朝三百年基业，影响整个东亚
- **效率**：年轻有为，28 岁登基，快速完成制度奠基
- **时间长度**：贞观之治成为后世标杆
- **时代机遇**：隋末大乱，群雄并起

## 与惯性定律的关系

李世民为唐朝注入了巨大的初始惯性。这个惯性大到连武韦之乱都刹不住车——武则天篡唐、韦后乱政、太平公主政变，唐朝政治中枢换了三轮血，但太宗打下的框架仍能自我运转，给了李隆基半个世纪的红利时代。
