# 黄莹洁

固收基金经理，2026年固收投资策略代表性观点持有者之一。

## 核心观点

- 固收投资主线更多在于对**票息机会**的把握
- 2024年Q4利率下行已提前透支利好，若地产继续下行将对收益率形成明显下行压力
- 强调票息优先于资本利得的策略取向
