# 比特币

比特币（Bitcoin, BTC）是2009年诞生的去中心化加密货币，被视为"数字黄金"——一种价值存储型数字资产。2024年现货比特币ETF获批后，比特币正式进入传统金融体系的合规投资渠道。

## 基本信息

| 属性 | 内容 |
|------|------|
| 诞生时间 | 2009年 |
| 定位 | 去中心化加密货币 / 数字黄金 |
| 历史长度 | 十余年（截至2024年） |
| 波动特征 | 月度波动率约±30%+，高风险属性 |
