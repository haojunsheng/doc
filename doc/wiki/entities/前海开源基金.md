# 前海开源基金

前海开源基金管理有限公司是一家公募基金管理公司，旗下"前海开源新经济混合"基金是过去十年公募基金市场中"冠军魔咒"与"规模激增与业绩反转"的经典案例。

## 前海开源新经济：2021年冠军的反面教材

**2021年**：前海开源新经济混合以接近100%的年度涨幅成为当年冠军基金，吸引大量追高资金涌入。

**规模变化**：
- 2020年底：规模约1.3亿元
- 2021年底：规模暴增至约143亿元（增长约100倍）

**后续表现**：
- 2022-2023年：累计下跌约40%
- 追高投资者被套牢，即使2024-2025年有所反弹，仍难以弥补此前回撤

## 案例意义

该案例完整展示了[[冠军魔咒]]的机制：
1. 当年踩中风格顺风→成为冠军
2. 近因效应+线性外推→资金高位涌入
3. 规模激增触及策略容量瓶颈→超额收益反转
4. 风格轮动→曾经的顺风变成逆风
5. 追高投资者实际收益远低于基金净值增长率

参见[[规模激增与业绩反转]]、[[投资者回报差距]]。

## 边界条件

如果投资者在2022年底部买入并持有至2024-2025年反弹，则可能已经回本甚至盈利——关键是买入时点，而非基金本身的质量。
