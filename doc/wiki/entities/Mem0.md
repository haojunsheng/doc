# Mem0

Mem0 是一个用户记忆管理框架，其 v2 到 v3 的设计演进揭示了"错误代价决定存储策略"的原则。

## v2：选择式更新

写入时由 LLM 决定 ADD / UPDATE / DELETE / NOOP。记忆库简洁，但**错误更新不可逆**——一旦错删，历史丢失。

## v3：仅追加 + 排序

只 ADD，冲突记忆并存；检索时通过多路排序（语义 + BM25 + 实体 + 时间）决定哪条记忆优先呈现。

在 **LoCoMo**（长期对话记忆基准，约 300 轮/35 会话）上，v3 相比 v2 从 71.4 提升到 92.5。

## 设计取舍

| 维度 | v2（选择式） | v3（全追加） |
|------|-------------|-------------|
| 存储 | 简洁 | 可能爆炸 |
| 错误代价 | 错删不可逆 | 错排可重试 |
| 检索复杂度 | 低 | 高（多路排序） |

深层原则：**错排可重试（低风险），错删不可逆（高风险）**，故 append-only + 检索时排序更优。
