# 冯·诺依曼

计算机体系结构奠基人。在《凤凰架构》中被引用为「不可靠部件构造可靠系统」的理论先驱——花约两年时间研究自复制自动机，给出了肯定答案：关键在于承认部件会出错、会崩溃消亡，但后代一定会出现，重新代替它。这一理论为凤凰架构的「个体可死、整体不死」提供了思想源头。
