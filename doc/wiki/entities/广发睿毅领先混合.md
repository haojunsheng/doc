# 广发睿毅领先混合

广发睿毅领先混合是广发基金旗下的一只混合基金，偏深度价值投资风格。

## 投资风格

偏深度价值风格，核心策略公式为：

```
睿毅领先 = 深度价值 × 逆向投资 × 长期持有
```

## 策略特点

- **深度价值**：注重公司质地和安全边际
- **逆向投资**：在市场恐慌时买入被错杀的优质标的
- **长期持有**：不频繁交易，持有周期较长

## 与同类基金对比

与同公司的 [[广发优企精选灵活配置混合]] 相比，睿毅领先风格更偏深度价值，换手率较低，行业配置相对稳定。

## 边界条件

逆向投资需要耐心，短期内可能跑输市场。适合看好长期价值、能承受短期压力的投资者。
