# 小麥

极客时间专栏《摄影入门课》主讲人。

## 背景

自称"拍了十三年照片，还是个小白"，以此诊断市场上普遍存在的"自我感动式拍摄"困境。

## 核心贡献

提出**摄影四层递进框架**（技术语法 → 视觉表达 → 判断标准 → 照片里的"我"），强调每层依赖前一层，不可跨级绕过。

引入**"可复现概率"**作为判断好照片的硬指标，区别于文案、地点、器材等外在因素。

主张"技术的终点是忘了技术"，照片的上限取决于摄影师本身——**你拍不出你没感受过的东西**。

- **去哥**：负责后期部分讲解
