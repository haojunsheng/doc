# 周云

## 基本信息

东方证券资产管理基金经理，自2015年9月起管理东方红新动力灵活配置混合（000480）。

## 投资框架

周云的核心投资框架可概括为"自下而上选股 + 安全边际 + 分散配置"，其关键特征：

- **选股双维度**：好公司（产品满足真实需求 + 商业模式好 + 竞争格局优）与买入时机（估值低 + 周期底部）缺一不可
- **性价比比较决策**：将所有股票放在同一维度比较长期预期收益率、胜率、赔率
- **组合风险控制**：2022年后增加持股数（30→40）、降低集中度（45%→30-40%）、行业占比降至15%以内，风格从中盘平衡体现
- **换手率纪律**：长期维持约100%（年均全仓换一次），卖出触发为基本面变化或估值过高，买入基于跨标的性价比比较

## 知行合一的证据

- 2015年9月以来核心策略框架保持稳定，仅2022年优化风险控制参数
- 勤奋且擅于反思总结，对持仓有清晰思路
- 东方红投研文化和制度安排为其策略执行提供支持

## 管理挑战

- **规模约束**：137亿元规模下，中盘股选股能力可能受限
- **风格迁移风险**：2022年从中盘平衡调整是否有先例，需持续跟踪
