# 王晓晨

## 基本信息

- **身份：** 基金经理
- **投资流派：** 固收+增强派
- **核心特征：** 高度分散的股票、可转债、债券配置，不依赖集中押注做增强

## 投资风格

```
固收+增强派 = 纯债底仓（70%–90%）+ 权益增强（10%–30%）→ 债稳股增
```

[[王晓晨]]的风格特点：
- 股票、转债、债券均高度分散
- 不靠集中押注单一方向增强收益
- 在低利率环境下通过适度权益敞口提升组合收益

与[[祝松]]的差异化：[[祝松]]更强调转债仓位择时（权益牛市时维持高转债仓位，熊市时提前降仓），[[王晓晨]]则偏分散配置思路。

## 边界条件

- **股债双杀风险**：债券和股票同时下跌时，固收+增强派两头承压，增强变亏损
