# 宋倩倩

景顺长城基金固收基金经理，三层增强固收策略的实践者。

## 基本情况

| 维度 | 内容 |
|------|------|
| 任职机构 | 景顺长城基金 |
| 从业年限 | 14年 |
| 年化回报 | 4.04%（固收类） |
| 超额收益 | 超基准0.71% |
| 投资风格 | 固收+增强派 |

## 三层增强策略框架

```
第一层（底层，90–100%）：高等级信用债
  - 久期：3年以内
  - 类型：城投/产业/金融均衡配置

第二层（中层，10–30%）：信用利差交易
  - 标的：银行二级资本债3–5年期
  - 来源：捕捉信用利差收窄/扩大

第三层（顶层，0–20%）：利率交易
  - 标的：地方债
  - 来源：近两年从利率波动获取超额收益
```

形式化表达：

```
90–100% 高等级信用债底仓 + 10–30% 信用交易 + 0–20% 利率交易
⇒ 年化4.04%，超基准0.71%（宋倩倩，景顺长城）
```

## 关键特征

- 严控风险前提下捕捉结构性机会
- 非外部跳槽型，从交易岗起步内部成长14年后独立管产品
- 与[[乔迁]]同在景顺长城，体现平台体系的内部培养能力

## 与现有框架的关联

[[synthesis/五大流派框架]]中宋倩倩归入固收+增强派，与[[王晓晨]]、[[祝松]]同流。其策略细节（三层增强）为该类流派提供了更精细的操作框架补充。

## 边界条件

- 若信用利差持续压缩或利率大幅波动，交易策略的超额收益可能消失
- 内部培养路径依赖公司投研体系质量
