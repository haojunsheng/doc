# Hartford（哈特福德基金）

**Hartford**（哈特福德基金）是美国资产管理公司，其研究数据常被用于投资行为分析。

## 关键统计

标普500过去数据显示：**78%的最高日收益**发生在熊市或牛市的前2个月。

这一数据与 A 股[[收益集中规律]]的实证结论相互印证——关键交易日往往集中在市场极端情绪时期（熊市末尾恐慌抛售期、牛市初期暴涨期），而非投资者最容易留在场上的平稳时段。
