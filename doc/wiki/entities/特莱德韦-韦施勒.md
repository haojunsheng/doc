# 特莱德韦·韦施勒（Ted Weschler）

伯克希尔·哈撒韦投资执行层干将之一，与阿吉特·贾恩（Ajit Jain）和托德·库姆斯（Todd Combs）共同负责投资决策执行。

## 角色定位

在巴菲特时代，韦施勒与库姆斯是直接拍板10亿美元以下投资的两人组。阿贝尔作为资本配置"总指挥"把控方向，具体执行由韦施勒和库姆斯完成。他是巴菲特制度延续的关键变量之一。

## 关键信息

- 参与日本五大商社投资谈判
- 与库姆斯共同构成伯克希尔日常投资决策的执行层
- 其角色是制度延续而非个人英雄主义的投资

## 边界

当韦施勒和库姆斯离职或能力下滑时，阿贝尔能否亲自下场做投资决策是真正的考验，也是伯克希尔制度韧性的关键节点。
