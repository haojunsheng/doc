# 广发优企精选灵活配置混合

广发优企精选灵活配置混合是广发基金旗下的一只灵活配置型混合基金。

## 投资风格

偏灵活轮动风格，核心策略公式为：

```
优企精选 = 灵活配置 × 优质企业 × 行业轮动
```

## 策略特点

- **灵活配置**：可根据市场环境调整仓位比例
- **行业轮动**：注重把握不同阶段的行业投资机会
- **优质企业**：精选基本面良好的企业

## 与同类基金对比

与同公司的 [[广发睿毅领先混合]] 相比，优企精选风格更偏灵活轮动，换手率相对较高，行业配置随市场变化而调整。

## 边界条件

行业轮动策略依赖对市场节奏的判断能力，判断错误会拖累业绩。适合看好行业轮动、能接受较高波动的投资者。
