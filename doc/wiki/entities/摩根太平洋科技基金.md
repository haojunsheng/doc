# 摩根太平洋科技基金

摩根太平洋科技基金是香港互认基金市场中少数专注科技板块的主动管理产品，2025年10月以风格周期反转的案例进入市场视野。

## 基本信息

| 维度 | 内容 |
|------|------|
| 类型 | 科技板块股票型互认基金 |
| 管理公司 | 摩根（Morgan） |
| 市场特征 | 互认基金市场中唯一专注科技板块的主动产品 |

## 关键事件：终结连续12个月净流出

| 时间 | 事件 |
|------|------|
| 2024年10月-2025年8月 | 连续12个月资金净流出 |
| 2025年9月 | 首次终结净流出（资金转向） |
| 2025年10月 | 跻身资金净流入前十 |

## 触发机制

```
科技板块反弹（2025年Q2启动）
    ↓
基金净值表现强劲
    ↓
资金重新流入（9月终结连续12个月净流出）
    ↓
10月跻身净流入前十
```

核心驱动因素：2025年二季度启动的科技板块反弹，是资金流向反转的根本原因。这一案例清晰地展示了**板块风格周期如何直接传导至资金流向**。

## 作为风格周期反转案例的意义

摩根太平洋科技基金的12个月逆转具有典型意义：
- **高惯性**：连续12个月净流出说明趋势一旦形成，逆转需要等待足够强的基本面信号
- **高反转风险**：若科技板块反弹终结，资金可能再次快速流出（反向惯性）
- **验证了 [[科技板块反弹驱动资金回流]] 机制**：单一风格反弹可以在短期内逆转长期资金流出趋势

## 边界条件

- 若科技板块反弹终结，资金可能再次流出——12个月的逆转并不意味着反转可持续
- 若科技股估值过高，回调风险加大，可能加速资金流出
- 作为互认基金市场中唯一的科技板块产品，其资金流向本身也会影响该板块的市场情绪
