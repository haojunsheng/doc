# 特斯拉（Tesla）

特斯拉是全球领先的电动汽车制造商，同时也是 AI/自动驾驶技术的积极探索者。在中国市场，特斯拉同样是双积分政策下新能源积分的主要卖方。

## 基本信息

| 属性 | 内容 |
|------|------|
| 全称 | Tesla, Inc. |
| 成立时间 | 2003 年 |
| 总部 | 美国德州奥斯汀 |
| 核心业务 | 电动汽车、储能、AI/自动驾驶（FSD）、太阳能 |
| 市场地位 | 全球 EV 龙头，曾多次登顶全球市值最高车企 |

## 中国市场：双积分政策下的积分卖方

与比亚迪类似，特斯拉凭借纯电动车型的积分盈余，在向不达标车企出售积分方面获得收益。

- 中国不达标车企需向特斯拉、比亚迪等积分盈余企业购买新能源积分
- 积分销售构成特斯拉中国业务的重要收入来源之一
- 相关框架参见 [[concepts/双积分政策框架]] 和 [[concepts/电动车渗透率趋势]]

## 作为参照系的 2023 年暴跌

2023 年前三季度，特斯拉股价经历了大幅下跌。晨星分析将此作为参照系，用于理解高估值+增长预期降温时的市场反应模式：

```
特斯拉暴跌 = 增长预期↓ + 估值泡沫 → 大幅回调
```

### 与英伟达的对比

| 维度 | 特斯拉（2023） | 英伟达（2026） |
|------|---------------|---------------|
| 增长故事 | EV + 自动驾驶叙事降温 | AI 需求真实存在，未降温 |
| 估值水平 | 已从高位回落 | 仍隐含多年增长预期 |
| 需求基本面 | 实际交付增速放缓 | AI 训练/推理需求持续扩张 |
| 市场敏感度 | 高（叙事依赖型） | 高（估值依赖型） |

### 关键差异

晨星明确指出：**不会简单重演特斯拉式暴跌**。核心区别在于 AI 需求是真实存在的产业趋势，而非纯叙事驱动。但两者都面临"高估值+高敏感度"的结构特征——任何不及预期都可能触发大幅回调。

## 投资启示

特斯拉案例说明：**护城河宽 ≠ 估值合理**。即便是一家拥有强大品牌和技术的公司，当股价已透支多年增长预期时，任何增长放缓的信号都会引发剧烈价格调整。这一逻辑同样适用于英伟达。
