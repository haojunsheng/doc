# 尼康 Z30

## 定位

尼康 Z 系列 APS-C 画幅无反相机，面向摄影入门和进阶用户。无机身防抖（IBIS）、无电子取景器（EVF）是其与 Z50/Zfc 的主要差异，定位为轻量化、高性价比的影像学习机。

---

| 参数 | 数值 |
|------|------|
| 画幅 | APS-C（DX 格式，等效焦距裁切系数 ×1.5）|
| 有效像素 | 20.9 MP |
| 传感器类型 | CMOS，支持 14bit RAW |
| 机身防抖（IBIS） | 无 |
| 电子取景器（EVF） | 无，仅 LCD 实时取景 |

| 人脸/人眼识别 | 支持（静态 + 动态）|
| 动物/鸟类识别 | 支持 |
| 续航（EN-EL25） | 约 330 张/充满 |
| 视频 | 4K UHD 30p / Full HD 120p |

## 主要设计特征

### 无 IBIS（机身防抖）

手持拍摄时安全快门为硬约束。与有 IBIS 的机型（如 Z50）相比，Z30 在低光环境下的手持成功率更低，需要在快门速度和 ISO 之间做更明确的取舍。

安全快门公式需乘 APS-C 裁切系数：

> 安全快门 = 1 / (镜头焦距 × 1.5)

例如 50mm 镜头在 Z30 上的安全快门为 1/75s，而非全画幅的 1/50s。

### 无 EVF（电子取景器）

全程 LCD 取景，强光下屏幕可见性受限。建议配置遮光罩或磨砂膜辅助户外拍摄。LCD 取景同时有一个优势：视野边界完整可见，构图时更容易感知画面边缘。

### 209 点复合对焦系统

209 点对焦覆盖画面大部分区域，支持人眼/动物眼识别和连续追踪对焦。这是 Z30 被低估的能力之一——大量用户长期停留在"全域自动"模式，只使用了约 10% 的对焦能力。

## 镜头生态

### 原生 Z 卡口

- **Z DX 16-50mm f/3.5-6.3**（套头，等效 24-75mm）：覆盖日常最常用焦段，适合 W1-W3 基础训练
- 原生 Z 卡口镜头群逐步丰富中，但入门阶段套头已足够

### F→Z 转接

使用 F→Z 转接环可将尼康单反镜头（F 卡口）用于 Z30，且支持自动对焦。二手 AI-S 定焦镜头（如 50mm f/1.8、85mm f/1.4）在 Z30 上表现优秀且性价比高。

## 适用场景判断

Z30 适合以下场景：
- 初学者建立摄影思维框架（W1-W5 六周学习计划）
- 街拍/人文摄影（轻便机身 + LCD 取景的低调性）
- 日常记录（套头 24-75mm 等效覆盖足够）

Z30 不适合的场景：
- 低光手持摄影（无 IBIS，需依赖高 ISO 或三脚架）
- 专业体育/野生动物拍摄（11fps 连拍尚可，但无 IBIS 影响追拍成片率）
- 蓝调时刻手持拍摄（需三脚架配合）
