# 萧楠

嘉实基金基金经理，成长框架代表，泡泡玛特投资经历完整记录了成长投资者的认知迭代过程。

## 基本信息

- **所属公司**：嘉实基金
- **投资风格**：成长框架，自下而上选股
- **核心特征**：对年轻公司可能性识别存在反思性偏差

## 泡泡玛特投资历程

### 第一阶段：底部买入（2021年下半年）

- 重仓泡泡玛特，持仓占比达到4.48%
- 买入时看好泡泡玛特的成长性和独特性

### 第二阶段：恐慌减持（2022年）

- 2021-2022年股价大幅波动给组合带来损失
- 基于基本面考量大幅减持至0.75%
- **反思**：低估了一家年轻公司的可能性、独特性和时代潮流力量
- **边界条件**：若2022年宏观冲击更严重（如长期封控），减持可能是正确的风控决策

### 第三阶段：持续减持（2025年）

- 泡泡玛特估值持续提升
- 判断新消费公司上市时第一成长曲线基本走完
- 后续面临第二曲线不明朗、竞争者蜂拥而入
- 这是基于成长策略框架的理性决策，而非短期情绪
- **边界条件**：若成功开拓出第二曲线（海外大规模扩张超预期），减持逻辑失效

## 形式化决策逻辑

```
2022年：底部买入 → 疫情波动恐慌减持 → 股价大涨 → 遗憾少赚
        ↓
2025年：估值↑ → 第一曲线走完 + 第二曲线不明朗 + 竞争者蜂拥 → 减持
```

## 关键教训

1. **波动率与交易冲动**：2022年疫情波动触发恐慌减持，是波动率对交易冲动的典型案例（参见 [[波动率对交易冲动的影响]]）
2. **持仓占比约束**：底部减持后无法快速回补，存在公募持仓占比约束的技术原因
3. **成长曲线的动态判断**：对"第一成长曲线"的判断需要随时间更新，萧楠2025年减持是基于成长框架的理性决策

参见 [[泡泡玛特]]、[[成长曲线两阶段模型]]。
