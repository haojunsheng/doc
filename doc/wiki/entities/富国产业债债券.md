# 富国产业债债券

## 基本信息

- 基金代码：100058
- 基金类型：普通债券型基金（产业债型）
- 基金经理：[[武磊]]
- 管理起始：2017年3月
- 所属公司：富国基金

## 业绩表现

- 年化回报率：4.50%（自2017年3月以来）
- 同类排名：前18%
- 波动性：显著低于同类中位数
- 历史最大回撤：0.93%

## 投资策略

富国产业债采用"低波动+票息收益"策略，核心特征：

1. **产业债为主**：产业债占固收资产85%-90%（契约规定≥80%）
2. **中高等级**：AAA等级以下债券占比通常<20%
3. **低转债配置**：维持<5%仓位，仅选债性转债（到期收益率≥2%）
4. **回撤控制**：将最大回撤严格控制在2%以内
5. **双层决策**：自上而下（久期/杠杆）+ 自下而上（个券选择）

## 业绩归因

超额收益来源（按贡献度排序）：
1. 票息收益（主要来源）
2. 久期策略
3. 杠杆策略
4. 转债投资

## 策略定位

富国产业债属于[[产业债基金]]典型代表，区别于以利率债为主的[[纯债基金]]（如[[工银纯债债券]]、[[万家鑫璟纯债债券]]）。其票息打底策略与[[东方添益债券基金]]（吴萍萍管理）形成同策略范式下的两个实践案例。
