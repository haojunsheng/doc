# Carl Richards

美国理财顾问、作家，"找到你的足够"理念的主要推广者。

## 核心贡献

提出通过亲身体验替代抽象比较来发现"足够"的实验方法：

```
找到"足够" = 实验 → 体验 → 反馈 → 调整 → 再体验（循环）
```

## 主要观点

1. **相对收益是零和博弈**——以他人为参照的目标永远无法达成满足
2. **理财顾问的核心价值是定义"去哪里"**，而非帮客户"怎么走最快"
3. **知足≠不思进取**——知足是主动选择（目标清晰+达到+停止），不思进取是被动放弃

## 思想渊源

与 [[entities/摩根-豪泽尔-morgan-housel]] 的《金钱心理学》思想同源，均强调"足够"的主观性和内在定义。
