# 国富深化价值混合

国富深化价值混合（基金代码：450004）是一只成立于2008年7月的老牌混合型基金，采用"深化价值"策略。

## 基本信息

- **基金代码**：450004
- **成立日期**：2008年7月
- **管理人**：国富基金
- **策略标签**：深化价值

## 策略框架

该基金采用晨星分类中的"深化价值"策略，在传统价值投资（低PE/PB）基础上叠加成长因子（可持续盈利增长、竞争优势），目标是在低估值企业中寻找兼具成长潜力的标的，实现戴维斯双击，规避纯粹低估值带来的价值陷阱。

## 经理信息

- **基金经理**：王晓宁

## 历史周期

基金自2008年成立以来，经历了以下关键市场周期：

1. **2008年金融危机**：成立即逢市场底部区域
2. **2015年A股异常波动**：考验策略抗跌性
3. **2018年熊市**：中美贸易摩擦，价值股承压
4. **2020年疫情冲击**：市场风格剧烈切换

## 策略张力三要素

根据晨星分析，影响该基金策略执行质量的三个操作性变量及其内在张力：

| 变量 | 适中状态 | 过度状态的风险 |
|------|---------|---------------|
| 规模 | 适中 → 选股灵活、交易成本低 | 过大 → 流动性约束、选股范围受限 |
| 持仓集中度 | 20-30只 → 高确信度+风险分散 | <15只 → 高波动、高回撤 |
| 换手率 | <100% → 长期持有 | >300% → 短期交易、风格漂移 |

## 与同类基金的关系

- **[[entities/国富策略回报混合基金]]**：同属国富基金旗下，策略框架不同（三要素选股 vs 深化价值）
- **[[entities/王晓宁]]**：兼任两只基金基金经理，需核实管理边界与精力分配
