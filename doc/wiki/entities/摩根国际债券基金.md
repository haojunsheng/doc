# 摩根国际债券基金

基金代码：968052

晨星焦点基金，香港互认基金，由 [[摩根互认基金业务]] 管理。

## 基金概况

- **类型：** 环球债券型基金（香港互认）
- **主要投资标的：** 全球发达与新兴市场投资级债券
- **高收益债券敞口：** 过去5年在 0-7.5% 区间
- **综合费率：** 0.89%（略高于同类中位数 0.87%）
- **2025年净流入：** 约130亿人民币（互认基金中规模最大产品）

## 基金经理团队

- **主基金经理（2017年起）：** [[Arjun-Vij]]
- **联合主基金经理：** [[彭逸升]]，亚洲利率及外汇业务负责人，19年经验

团队背景：[[Arjun-Vij]] 同时管理亚洲机构客户多元债券组合；[[彭逸升]] 负责亚洲利率及外汇业务。两人背靠摩根全球综合投资团队（8位资深基金经理）提供跨资产类别支持。

## 收益来源结构

超额收益拆解框架（适用于债券基金的 [[业绩归因]]）：

```
超额收益 = 行业选择 + 发行主体选择 + 久期操作 + 外汇操作
```

- **行业选择：** 国家和行业配置决策（自上而下）
- **发行主体选择：** 个券精选（自下而上）
- **久期操作：** 对不同市场债券的平均久期主动调整
- **外汇操作：** 汇率敞口管理

该基金的核心优势是多元化收益来源，不依赖单一策略维度。详见 [[收益来源结构分解]]。

## 历史表现规律

| 年份/时期 | 主要操作 | 结果 |
|-----------|---------|------|
| 2021年 | 低配久期 + 超配投资级和高收益公司债 | 超额收益 |
| 2022年 | 低配久期 | 在美债利率上行时抗跌 |
| 2023年Q1 | 久期低配失误（日本市场久期低配） | 表现较弱 |
| 2024年 | 低配美国久期 + 超配欧洲久期 + 超配机构MBS和投资级公司债 | 良好收益 |

## 投资流程

"自上而下宏观研判 + 自下而上个券精选"双层架构：

1. **季度会议：** 基金经理与各细分领域团队负责人研判宏观经济 → 制定国家和行业配置策略
2. **周度策略会：** 结合各行业预期回报和信心 → 动态调整资产配置
3. **个券精选：** 各专业团队基于全球利率、投资级债券、高收益债券等细分领域研究完成

详见 [[久期操作]]。

## 适合投资者画像

- 有全球债券配置需求
- 能接受 0.89% 综合费率
- 认可摩根品牌
- 中长期持有

边界：若只需配置单一市场债券（纯美债或纯中债），选择专注该市场的基金可能更合适；若不能接受该费率，可考虑费率更低的被动指数基金。
