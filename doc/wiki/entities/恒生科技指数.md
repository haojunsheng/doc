# 恒生科技指数

恒生科技指数（Hang Seng TECH Index）是香港证券市场的重要科技股指数，由恒生指数公司编制，反映在香港上市的科技公司股票表现。

## 在QDII井喷中的作用

2020年恒生科技指数暴涨57%，成为QDII资金涌入港股科技板块的关键催化剂。这一暴涨直接推动了2021年QDII行业的爆发式增长——行业股票基金当年吸金2233亿，其中追踪中概互联网指数的QDII产品就吸引了496亿。

## 投资教训

恒生科技指数在2021年见顶后持续下跌，追高的投资者在2022年承受了巨大亏损。这一案例印证了 [[择时的心理陷阱]] 的核心论点：时机不当的买入往往导致负的投资者回报。
