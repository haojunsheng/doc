# 国泰基金

国泰基金是中国大陆公募基金管理人之一，管理多只QDII指数基金产品。

## ETF市场份额

根据晨星中国2026年6月数据，国泰基金ETF管理费份额从2018年的约1%跃升至2024年的5%，是腰部超车典型案例。策略特点：**新发产品抓住宽基/行业/QDII机遇 + 老产品把握货币ETF/黄金ETF需求**，新老协同拉动规模增长。

## 纳指100产品线

国泰基金旗下持有**国泰纳斯达克100指数证券投资基金（160213）**，是中国市场上最早一批成立的纳指100 QDII产品之一（成立于2010-04-29），基金经理为朱丹。

## 产品特征

- 结构类型：直投复制型QDII，不通过境内ETF中转，路径比联接基金更直接。
- 费用水平：管理费0.80%/年 + 托管费0.20%/年，年化运作费约1.00%，在同类型产品中偏高。
- 规模变化：净资产从2025年末约18.55亿元下降至2026年一季度末约16.36亿元，反映一定赎回压力。

## 当前约束

2026年5月，国泰纳指100曾短暂开放申购（5月20日每日300元限额），随后5月26日迅速收紧至每日100元，体现QDII额度持续紧张。

## 定位判断

国泰基金自身不创造阿尔法，其管理的纳指QDII产品本质上是**秩序搬运者**——将纳指100指数的收益、波动、汇率风险原样转移给人民币投资者。产品价值在于通道可达性和费用透明度，而非主动管理能力。
