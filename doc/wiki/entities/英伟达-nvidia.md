# 英伟达（NVIDIA）

NVIDIA（英伟达）是全球领先的 GPU（图形处理器）制造商，也是当前 AI 算力基础设施的核心供应商。2026 年市值位居美股前三，超过俄罗斯全国 GDP。

## 基本信息

| 属性 | 内容 |
|------|------|
| 全称 | NVIDIA Corporation |
| 成立时间 | 1993 年 |
| 总部 | 美国加州圣克拉拉 |
| 核心产品 | GPU（GeForce / RTX / A100 / H100 等系列）、CUDA 软件平台 |
| AI 市场地位 | GPU 市占率约 80%，AI 训练首选硬件 |
| 估值特征 | 晨星评级：宽护城河公司，但当前估值已偏高 |

## 护城河结构

英伟达的护城河并非单纯来自 GPU 硬件本身，而是 **"GPU 硬件 + CUDA 生态"的双重锁定**：

```
护城河 = 硬件(80%市占) × CUDA生态(转换成本↑↑)
```

### 硬件层面
- GPU 市占率约 80%，均价是 AMD 的两倍
- AI 训练需要海量并行计算，GPU 架构天然适配
- 2006 年推出 CUDA，比 AI 浪潮早十余年布局

### 软件生态层面（真正的护城河）
- CUDA 平台已被几乎所有主流 AI 模型训练采用
- 客户切换平台需要重写算法、重训模型，转换成本极高
- 单看 GPU 设计，AMD 也能做，但 CUDA 没有替代品

参见 [[concepts/CUDA生态锁定]]。

## 竞争对手

| 对手 | 类型 | 威胁评估 |
|------|------|---------|
| **AMD** | GPU 厂商 | 能设计 GPU，但无 CUDA 替代品；均价仅为英伟达一半 |
| **英特尔** | CPU/GPU 厂商 | 加速研发中，短期技术差距仍在 |
| **亚马逊/微软/谷歌** | 云厂商自研芯片 | 自研芯片只服务内部需求，不构成对英伟达通用市场的直接威胁 |

参见 [[entities/AMD]]、[[entities/英特尔]]。

## 核心风险

### 1. 估值风险
当前股价已透支多年增长预期，"护城河宽不等于估值合理"。任何业绩不及预期都可能触发大幅回调。参考 [[concepts/估值隐含过度乐观预期]]。

### 2. 出口管制风险（最大下行风险）
2023 年美国对中国半导体和超算行业实施出口限制，直接压缩中国市场空间。"特供芯片"能否满足中国客户需求存疑，且管制可能扩展至其他国家。若管制放松，该风险可缓解。参见 [[concepts/美国出口管制政策-半导体与超算]]。

### 3. 自研芯片风险（中期风险）
科技巨头自研芯片主要服务内部需求，短期不构成威胁；但若云厂商从"自研自用"转向"对外销售"，英伟达将面临直接竞争。参见 [[concepts/自研芯片vs通用市场]]。

## 与特斯拉暴跌的类比

2023 年前三季度特斯拉因增长故事降温而暴跌。英伟达当前处境有相似之处（高估值+高敏感度），但存在关键差异：AI 需求真实存在，而非纯叙事驱动。不会简单重演特斯拉式暴跌，但市场敏感度极高（如某周五单日跌 5.55%）。参见 [[entities/特斯拉]]。

## 集中度风险（2026 Q2补充）

晨星2026年全球展望指出，英伟达市值已超过英国、加拿大、德国三国股市总和。1999年上市至今回报超大盘500多倍（2022年末生成式AI爆发为核心驱动力）。这一极端集中度使纳指100等被动指数基金持有者实质上"单押AI"，[[纳指七雄集中度风险]]在此得到最典型印证。
