# 毕天宇

晨星中国选基案例中的成长风格基金经理代表，集中型成长风格。

## 投资风格

- **策略类型**：集中型成长
- **方法**：中观行业分析 + 自下而上选股
- **聚焦**：成长行业

## 关键指标

| 指标 | 数值 |
|------|------|
| 5年上行捕获比 | 92.51% |
| 同类排名 | 前24% |

## 评价

- 在成长行情中，上行捕获比高说明在上涨市能充分参与
- 2025年成长股（21.26%）远超价值股（9.86%），深耕成长的基金经理有优势
- **边界**：如果市场风格从成长切向价值，会跑输

## 关联

- 与[[entities/詹成]]同为成长风格代表，方法相近
- 与[[entities/乔迁]]形成对比：毕天宇集中 vs 乔迁均衡
- 可作为[[concepts/上行捕获比]]的实证案例
