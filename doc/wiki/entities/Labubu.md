# Labubu

泡泡玛特旗下潮玩IP，代表潮玩文化投资热潮的引子符号。

## 背景

Labubu等潮玩IP的走红，推动了泡泡玛特股价暴涨，也引发了基金经理对"泡沫定价"vs"成长机会"的分歧讨论。
