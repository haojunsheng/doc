# Bruce Gilden

## 基本信息

| 项目 | 内容 |
|---|---|
| 身份 | 摄影师 |
| 专长 | 街头摄影、硬光人像 |

## 在摄影入门课中的角色

[[宁思潇潇]] 在讲解"硬光也能拍人"时引用 Gilden 作为典型案例，与 [[Frank Ockenfels]] 并列，用于破除"软光才能拍人"的二元偏见。

## 艺术风格

- 以近距离直闪（on-camera flash direct）著称
- 闪光灯直接打在 subject 脸上，产生强烈的硬光效果
- 作品充满侵略性和即时感，常见于街头、派对、肖像等场景
- 代表作包括纽约街头系列、名人肖像系列等

## 与 Frank Ockenfels 的对比

| | Frank Ockenfels | Bruce Gilden |
|---|---|---|
| 工作方式 | 工作室为主 | 街头抓拍 |
| 光线控制 | 精确布光 | 直闪光，不可控 |
| 风格感受 | 粗粝但精致 | 粗粝且即时 |
| 共同点 | 都证明硬光是美学选择，非光线缺陷 |
