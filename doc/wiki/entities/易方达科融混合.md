# 易方达科融混合（FOF持仓视角）

**易方达科融混合**是一只成长风格公募基金，在2025年Q3 FOF配置转向中被增持，成为"权益风格从价值切向成长"转向的代表性成长基金。

## FOF持仓变化

- **增持状态**：FOF持仓提升
- **风格标签**：成长风格（科技/新能源方向）
- **配置地位**：FOF成长风格代表基金之一

## 配置意义

在[[concepts/FOF配置转向框架]]中，易方达科融的增持是"权益风格切换-价值到成长"转向的核心证据。与[[entities/兴全合润混合-FOF持仓]]一同构成了FOF增持成长风格的实证数据，与[[entities/大成高鑫股票-FOF持仓]]、[[entities/国富中小盘]]的价值风格减持形成对照。

## 边界

若市场风格从成长切回价值，FOF可能重新增配价值风格基金。
