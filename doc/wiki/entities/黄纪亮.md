# 黄纪亮

## 基本信息

- **身份：** 基金经理
- **投资流派：** 纯债稳健派
- **核心特征：** 严格信用筛选 + 灵活久期管理，追求绝对收益和极低回撤

## 投资风格

```
纯债稳健派 = 高等级债券 + 低久期 + 低杠杆 → 回撤极小 → 高夏普比率
```

[[黄纪亮]]的风控标准（量化体现）：
- AAA以下评级债券占比控制在20%以下
- 低评级个券持仓不超过0.5%

与[[黎颖芳]]的共同点：两家纯债基金均不碰高风险品种，赚确定的钱。

## 边界条件

- 利率单边下行时，低久期策略会跑输长久期基金
