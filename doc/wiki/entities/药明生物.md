# 药明生物（WuXi Biologics）

国内乃至全球领先的CDMO（合同研发生产组织）企业，以 biologics（生物药）CRO/CDMO服务为核心业务。

## 基本信息

- 业务定位：生物药研发与生产外包服务
- 市场地位：国内及全球CDMO龙头
- 基金关注度：322只基金持有，43只持仓超5%

## 2023年业绩事件

2023年，药明生物下调业绩增长目标，触发当日股价暴跌23.79%，并带动CXO板块全线飘绿。

### 业绩变脸原因（双重打击）

1. **新冠收入快速消退**：疫情期间积累的新冠相关业务收入大幅收缩
2. **全球药企融资困难**：美联储加息推高药企融资成本，导致研发管线调整、项目延迟

### 事件解读

药明生物的业绩变脸并非公司个体经营恶化，而是宏观利率环境传导至下游药企研发支出后，再传导至上游CXO订单的结果。这一事件将"旱涝保收"的CXO标签打破——系统性因素（融资寒冬）出现时，CXO的贝塔并不低。

## 与板块的关系

作为CXO板块龙头，药明生物的预期下修具有板块级联效应：

```
龙头(药明生物)下调预期
  → 市场重估整个赛道增速
  → 板块估值整体压缩
  → 情绪从"旱涝保收"转向"也会变脸"
```

322只基金持有、43只重仓5%以上的集中度，放大了这种联动效应。
