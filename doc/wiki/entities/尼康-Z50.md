# 尼康 Z50

## 概述

尼康 Z 系列 APS-C 画幅无反相机，与 Z30 定位接近但关键差异在于**拥有电子取景器（EVF）**和机身防抖（IBIS）。

---

## 与 Z30 的关键差异

| 特性 | Z30 | Z50 |
|------|-----|-----|
| EVF | 无 | 有 |
| IBIS | 无 | 有 |
| 说明书章节顺序 | 与 Z30 几乎同构 | 与 Z30 几乎同构 |

说明书章节同构说明：[[相机决策栈]] 的四层决策框架可能对 Z50 同样适用，但 Z50 多了 EVF 取景层，翻转屏不再是唯一取景方式。
