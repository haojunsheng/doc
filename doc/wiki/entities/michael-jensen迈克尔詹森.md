# Michael Jensen（迈克尔·詹森）

哈佛商学院金融学教授，1967 年提出**詹森阿尔法**，开创了量化测量基金经理主动管理能力的学术传统。

## 核心贡献

**詹森阿尔法（Jensen's Alpha）** —— 在论文《1945-1964 年共同基金的表现》（The Performance of Mutual Funds in the Period 1945–1964）中首次提出，定义为基金收益对市场收益线性回归的截距：

```
α = Rp - [Rf + β(Rm - Rf)]
```

这一公式成为后续几十年评估基金经理能力的标准工具，也是所有因子模型扩展的起点。

## 历史地位

Jensen 的工作奠定了现代投资组合理论中"主动管理 vs 被动管理"争论的量化基础。他的阿尔法概念后来被 Eugene Fama、Kenneth French 等学者不断扩展和修正，催生了多因子模型体系。

## 在本 Wiki 中的角色

作为詹森阿尔法的提出者，是理解"阿尔法消失"现象的历史起点——当因子模型扩展时，原先由 Jensen 定义的 Alpha 被逐步重新归类为 Beta。
