# DoorDash

美国最大的即时配送平台，全球即时零售赛道的**最核心对标企业**。

## 公司概况

- **美股代码**：NASDAQ: DASH
- **主要市场**：美国（本土）+ 全球（通过收购 Wolt 进入欧洲市场）
- **业务形态**：餐饮外卖 + 即时零售（商超、便利店、医药等非餐品类）
- **美国市占率**：~67%（准垄断地位）

## 关键财务数据（FY2024）

| 指标 | 数值 |
|:---|:---|
| Revenue | ≈ **US$10.7B**（+24% YoY） |
| GAAP Net Income | ≈ **US$1.0B+** |
| GAAP 净利率 | ~9-10% |
| Market Cap（2025 年初） | ~US$70-85B |

## 对中国的对标价值

1. **最高市占率 + 已盈利**：美国准垄断 vs 中国四强争霸，竞争烈度对比鲜明
2. **非餐品类扩张**：DoorDash 已从纯餐饮外卖扩展到即时零售（商超、便利店、医药），与中国美团闪购路径相似
3. **广告货币化**：DoorDash Ads 收入增速 30%+，中国品牌广告化也已在布局
4. **UE 模型差距**：中国市场 UE 更薄（骑手成本低但竞争激烈吃掉利润），DoorDash 净利率 9-10% 难以直接复制
