# 反向思考-Jacobi框架

## 定义

源自数学家卡尔·古斯塔夫·雅可比（Carl Gustav Jacobi）的名言"永远要反向思考"，芒格将其转化为投资决策的方法论工具：**在列出所有买入理由之后，必须反过来列出所有不买的理由，以确保研究完整。**

## 形式化

```
买入理由(N条) + 不买理由(N条) → 完整视角 → 更优决策
```

## 核心规则

**芒格判定标准：** 如果一个人不能说服对立面，说明他对这个标的的了解还不够透彻。

反向思考的执行路径：
1. 列出所有支持买入的理由（N条）
2. 站在对立面上，列出所有不支持买入的理由（至少 N 条）
3. 对比两组理由，判断自己的倾向是否坚定
   - 若反向思考后仍坚定买入 → 决策质量高
   - 若反向思考后犹豫 → 研究深度不足

## 与[[反向信号检验]]的关系

| 维度 | [[反向信号检验]] | [[反向思考-Jacobi框架]] |
|------|------------------|--------------------------|
| 关注点 | 信息源的可信度（分享本身就是反向信号） | 研究过程的完整性（双向论证） |
| 应用场景 | 评估外部推荐、专家观点 | 评估自身投资决策 |
| 核心问题 | "谁在告诉你这件事？他为什么告诉你？" | "我有足够理由拒绝这个投资吗？" |

两者互补：反向信号检验过滤信息来源，Jacobi 框架完善研究过程。

## 边界条件

- 反向思考后若仍倾向买入，说明决策更坚定；若犹豫则说明研究不够
- 当市场环境发生重大变化时，过去的"不买理由"可能已失效，需要重新评估
- 反向思考不是自我否定，而是为了增强决策的韧性

## 适用场景

- 个股深度研究前的自我审查
- 投资组合调整前的理由对照
- 重大投资决策前的"魔鬼代言人"练习
