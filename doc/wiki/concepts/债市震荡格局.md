# 债市震荡格局

2026年债市的核心判断：趋势性行情缺失，利率在窄幅区间内波动。

## 形成机制

```
央行宽松方向确定但空间有限
× 积极财政托底但不刺激
→ 利率↑动力↓ + 利率↓空间↓
⊃ 震荡格局
```

## 关键驱动因素

| 因素 | 方向 | 来源 |
|------|------|------|
| 货币政策 | 宽松方向确定，但降息降准"可用但不多" | 宏观共识 |
| 财政政策 | 托底但不走老路大刺激 | 政策取向 |
| 经济基本面 | 出口韧性+新质生产力对冲地产下行 | 基本面 |
| 地产 | 继续下行→拖累GDP+信用风险→利率承压 | [[郑如熙]] |

## 边界条件

- 若地产超预期失速或外部冲击剧烈，央行可能超预期宽松，利率突破震荡区间下行
