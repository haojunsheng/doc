# 标准化程度决定被动化可行性

**标准化程度决定被动化可行性**是指债券市场被动投资（ETF/指数基金）的渗透速度取决于底层资产的标准化程度——标准化越高，指数复制越容易，被动化越快；标准化越低，跟踪误差越大，主动管理越难被替代。

## 核心机制

```
标准化程度高（利率债）
  → 发行主体集中（政府/政策性银行）
  → 券种少、流动性好
  → 指数复制成本低、跟踪误差小
  → 被动占比高（49%）

标准化程度低（信用债/纯债）
  → 主体分散、信用资质差异大
  → 估值不连续、流动性差
  → 指数复制成本高、跟踪误差大
  → 主动超额空间存在 → 被动占比低（<20%/2%）
```

## 量化证据

| 债券类型 | 标准化特征 | 被动占比 |
|---------|-----------|---------|
| 利率债 | 发行主体<10家（央行+财政部+几大政策性银行），券种有限 | **49%** |
| 信用债 | 发行主体数千家，资质跨度极大（AAA~违约级），估值频率低 | **<20%** |
| 纯债 | 以信用债为主，主动可通过信用下沉+杠杆+久期创造超额 | **2%** |
| 可转债 | 标准化程度中等，但产品仅两只ETF极端集中 | **42%** |

## 边界条件

- 若信用债市场流动性改善（如做市商制度扩大），被动化比例将提升
- 若信用评级体系完善、违约定价更透明，信用债被动化加速
- 若技术发展和指数编制进步，固收+和QDII等跨资产品类可能出现被动产品
