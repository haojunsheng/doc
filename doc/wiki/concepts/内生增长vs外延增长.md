# 内生增长 vs 外延增长

两种根本不同的企业增长驱动方式，也是成长型基金之间最核心的结构性差异。

## 形式化定义

```
内生增长 = 企业自身竞争力 × 管理层质量 × 时间复利
外延增长 = 并购增长 × 重组增长 × 主题投资
```

## 内生增长（Internal Growth）

企业依靠自身盈利能力、研发投入、管理优化等方式实现增长，不依赖外部并购或资本运作。

**特征**：
- 增长来自企业内在竞争力的持续提升
- 依赖对管理层质量和长期商业趋势的判断
- 更稳定，但弹性相对较小
- 适合风险厌恶型投资者

**代表基金**：[[景顺长城成长之星]]（周寒颖管理）

**适用环境**：市场平稳期、企业盈利稳定增长期

## 外延增长（External Growth）

企业通过并购、重组、股权投资等外部方式实现规模扩张和业绩增长。

**特征**：
- 增长来自并购、重组等资本运作
- 受并购市场活跃度影响大
- 弹性更大，波动性更高
- 适合风险承受能力较强的投资者

**代表基金**：[[汇添富外延增长主题股票]]（蔡志文管理）

**适用环境**：并购活跃期、政策支持重组市场

## 对比框架

| 维度 | 内生增长 | 外延增长 |
|------|---------|---------|
| 驱动源 | 企业自身竞争力 | 并购/重组 |
| 稳定性 | 更高 | 较低 |
| 弹性 | 较小 | 较大 |
| 依赖条件 | 管理层质量 | 并购市场活跃度 |
| 风险类型 | 判断风险 | 执行风险 + 市场风险 |

## 配置建议

两种增长方式在不同市场环境下表现各异，可组合配置以实现增长方式互补：
- 内生增长基金作为"稳定器"
- 外延增长基金作为"弹性来源"
- 注意行业重叠风险，避免重复暴露
