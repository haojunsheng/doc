# 指数许可壁垒

指数许可壁垒是指特定指数（如中证红利、上证红利）由中证指数公司、上海证券交易所等独家编制和授权，其他基金公司不可发行跟踪同一指数的同类产品，从而形成的**独占性准入壁垒**。

## 在红利基金中的作用

在[[被动红利飞轮]]的护城河构建中，指数许可是最关键的非规模要素：

| 要素 | 可独占？ | 说明 |
|:---|:---|:---|
| 劳动力 | ❌ | 基金经理可被挖走 |
| **指数许可** | ✅ | 中证红利、上证红利等由中证/上证独家授权，他人不可发行同类产品的直接跟踪者 |
| 先发 AUM / 流动性 | ✅ | 先发即成事实标准 |
| 资本 | ✅ | 头部公司可"战略亏损"养规模 |
| 技术 | 🟡 | 跟踪技术同质化 |
| 数据 | 🟡 | 复合因子需要多模型协同，有一定壁垒 |

## 与指数内卷的张力

[[指数内卷]]的核心矛盾是：费率战导致产品高度同质化，而指数许可壁垒恰好是"打破同质化"的制度性手段——谁拿到指数授权，谁就拥有不可替代的产品定义权。华泰柏瑞（红利低波）、易方达（中证红利）、华夏（央企红利）各自持有不同指数的独家授权，形成了当前格局的基础。

## 挑战者的路径

当主流指数授权已被锁定，挑战者只能通过以下路径突破：
1. **开新因子 SKU**：红利+央企、红利+低波、红利+ESG、红利+港股通，在维度上包抄
2. **创新策略**：主动增强、期权策略（如 PutWrite）、Smart Beta 复合因子

## 风险提示

指数许可壁垒并非永恒。随着中证指数公司对指数授权策略的调整（如引入多家管理人竞争），原有授权方的独占优势可能被削弱。
