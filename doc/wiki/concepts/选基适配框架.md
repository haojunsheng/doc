# 选基适配框架

晨星三维度选基金经理框架：选基金经理不是选明星，是选"适配"。三个维度相互依赖，缺一不可。

## 核心公式

$$\text{胜任力可持续性} = \text{能力圈可信度} \times \text{工作负荷合理} \times \text{团队支持适配}$$

任何一项为零，整体胜任力即为零。

---

## 维度一：能力圈可信度（过往投研经验）

经验不等于能力——需要同时满足三个条件：

| 条件 | 说明 |
|------|------|
| 类似策略经验 | 管过同类型策略，而非跨策略盲目扩张 |
| 跨周期验证 | 在不同市场环境下表现与风格契合 |
| 环境可比性 | 当前组合规模与团队支持跟历史高度相似 |

**边界：** 策略发生漂移时，历史经验参考价值大幅下降。

---

## 维度二：工作负荷（组合数量 × 组合相似度）

核心认知纠偏：**管越多基金 ≠ 越差。**

```
多只基金 × 高相似度 ≈ 管 1 只（负荷不重）
多只基金 × 低相似度 ≈ 管很多只（负荷很重）
```

晨星区分"数量负荷"和"相似度减负"两个子维度。高度相似的组合同时管理，策略复用度高，实际工作量接近单只基金。

**边界：** 若兼任总经理等行政职务且分工不明确，即使组合相似度高也可能是精力分散的警告信号。

---

## 维度三：研究团队支持（架构适配 + 人员稳定 + 激励机制）

适配度 > 规模。好团队由三个要素共同决定：

| 要素 | 说明 |
|------|------|
| 架构适配 | 研究团队组织形式是否与基金经理投研流程匹配 |
| 人员稳定 | 研究员司龄长、流动性低，策略执行更连续 |
| 激励机制 | 是否有首推奖、实盘贡献考核等研究转化机制 |

**关键机制：研究转化通道**
- 鼓励研究员质疑基金经理观点
- 考核含实盘贡献、模拟组合业绩、研究报告质量
- 设"首推奖"激励研究员推荐优秀标的

**边界：** 人数再多，若研究员司龄短或激励不足，难以转化为投资贡献。

---

## 与直觉的张力

| 直觉判断 | 框架修正 |
|---------|---------|
| 从业年限长 = 能力强 | 需满足类似策略 + 跨周期 + 环境可比三个条件 |
| 管越多基金 = 业绩越差 | 高度相似的组合多管≠负荷加重 |
| 大公司 = 团队更强 | 适配度 > 规模，小公司激励机制有效也可产出 |
| 行政职务 = 减分项 | 分工明确则不拖累，分工不清才扣分 |

---

## 收口概念：可复制的胜任力

选基金经理不是选短期业绩冠军，而是筛选**可复制的胜任力**——能力圈、工作负荷、团队支持能否让基金经理在未来持续交出与策略相符的成绩。
