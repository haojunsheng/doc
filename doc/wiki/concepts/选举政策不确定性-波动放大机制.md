# 选举政策不确定性-波动放大机制

选举周期带来政策不确定性上升，政策不确定性通过改变投资者预期和行为，放大市场短期波动——但这一波动不等于长期趋势变化。

## 核心机制

```
选举临近 → 政策不确定性↑ → 投资者预期分歧↑ → 交易行为短期化↑
→ 市场波动↑ → 情绪化决策↑ → 择时风险↑
```

## 双重效应

| 维度 | 短期（数周至数月） | 长期（数年） |
|------|------------------|-------------|
| 波动 | 放大 | 无显著影响 |
| 方向 | 取决于候选人民意领先 | 由经济基本面决定 |
| 投资者行为 | 情绪驱动、交易频繁 | 理性回归 |
| 政策落地 | 悬而未决 | 已定价，影响有限 |

## 与[[择时的心理陷阱]]的关系

选举猜测是择时的一个典型子类型：
- 猜"谁赢→政策什么→市场涨跌"，本质是三层预测叠加
- 每层预测胜率均不高于 55%，三层叠加后整体胜率极低
- 错误预测的成本远高于正确预测的收益（参考[[择时的心理陷阱]]中的"双重损失"机制）

## 形式化表达

```
选举年波动 = 基础波动 × (1 + 政策不确定性系数)
政策不确定性系数 = f(选举悬念程度, 政策分歧幅度, 历史先例)
```

## 边界条件

- 若选举结果明确（民调大幅领先），不确定性效应减弱
- 若出现极端政策主张（如关税 60%、央行独立性被实质性削弱），不确定性效应急剧放大
- 若市场已提前 price in 选举结果，落地后可能出现"买预期卖事实"的反转

## 投资启示

政策不确定期保持纪律，不因选举结果随意调整组合。波动本身不是风险，因波动而做出非理性决策才是。
