# 产能出清周期

**产能出清周期**是理解商品底部反转的核心框架：当价格跌破成本支撑位时，低价促使生产商暂停投资，供应增长放缓，最终推动价格修复。

## 核心机制

```
价格跌破成本 → 投资暂停 → 供应增长↓ + 需求↑ → 产能出清 → 价格修复
```

## 关键节点

| 阶段 | 特征 | 信号 |
|------|------|------|
| 价格跌破成本 | 生产商亏损 | 出现产能出清前提 |
| 投资暂停 | 新项目搁置 | 未来供应受限 |
| 供应收缩 | 产能退出 | 供需重新平衡 |
| 价格修复 | 供需紧张 | 投资机会出现 |

## 应用案例

- **锂**：当前正处于"价格跌破成本→投资暂停"阶段，价格有望修复
- **房地产**：需求见底供应见顶，去库存压力见顶

## 边界条件

1. 出清时滞：从"低价→投资暂停"到"供应下降→价格修复"存在显著时滞
2. 若需求持续超预期增长，可能抵消供应收缩影响
3. 若新产能快速投产，出清进程被推迟
