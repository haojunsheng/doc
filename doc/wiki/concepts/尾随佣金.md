# 尾随佣金

尾随佣金（客户维护费，Trailing Commission）是基金公司从管理费中按一定比例支付给代销渠道（银行、券商、互联网平台）的费用，用于补偿渠道持续为基金客户提供服务。**尾佣是基金行业利益冲突的核心机制之一。**

## 机制

```
尾佣 = 基金管理费 × 尾佣比例
→ 渠道收入与基金推荐绑定
→ 渠道有动机推荐尾佣比例更高的产品
```

## 利益冲突来源

当投顾或代销渠道既收投顾费（向投资者收费），又在基金层面收尾佣（从基金公司收费），就形成"双重收费"——投顾的收入部分来自投资者，部分来自被推荐基金的基金公司。这导致：

- 推荐行为被尾佣比例扭曲
- 投资者买到的可能是"最会营销的产品"而非"最适合的产品"
- 类似超市货架：最显眼的位置放给超市最多钱的商品，而非最好的商品

## 制度应对

| 制度 | 措施 | 效果 |
|------|------|------|
| 英国RDR（2013） | 禁止基金公司向投顾支付尾佣 | 催生"清洁份额" |
| 美国受托人规则（2017） | 投顾不能因尾佣高低推荐基金 | 推动清洁份额普及 |
| 中国投顾份额（征求意见稿，2025） | 投顾渠道不得收取客户维护费 | 投顾收入只来自基于账户规模的投顾费 |

## 与 [[基金公司利益冲突]] 的关系

[[基金公司利益冲突]]描述的是规模导向 vs 投资者利益的结构性偏差；尾随佣金是这一偏差在销售渠道层面的具体运作机制。消除尾佣（投顾份额、清洁份额）是切除此机制的制度路径。

## 边界与未解问题

- 若尾佣比例统一（所有产品相同），利益冲突减弱但不消失
- 中国投顾份额尚在征求意见阶段，实际落地时间和执行力度有待观察
- 免尾佣后投顾的商业模式可持续性——基于账户规模的投顾费在低费率环境下能否覆盖成本
