# 交易成本-指数调仓冲击

指数基金除了费用率之外，还有一种隐性成本：**指数调仓时产生的市场冲击成本**。这种成本不会出现在费用账单上，但会真实地侵蚀回报。

## 机制

```
指数调整成分股（如标普 500 每年 6/12 月）
    ↓
所有跟踪该指数的基金同一天买卖
    ↓
集中买卖 → 推高买入价、压低卖出价
    ↓
市场冲击成本由所有基金持有人共同承担
```

## 成本构成

| 成本类型 | 说明 |
|---------|------|
| 佣金 | 直接交易费用 |
| 买卖价差 | 买入价高于卖出的差价 |
| 市场冲击 | 集中买卖导致的 price impact |

## 量化估算

- 大盘股指数（标普 500）：冲击成本小，总交易成本约 0.1%
- 小盘股/新兴市场指数：冲击成本高，交易成本可达 0.5% 或更高

## 与跟踪误差的关系

交易冲击成本是跟踪误差的来源之一。两者密切相关但不同：

- 跟踪误差：结果指标（回报偏离指数的程度）
- 交易冲击成本：成因之一（调仓时的额外成本）

→ [[concepts/跟踪误差]]

## 与中国市场的关联

A 股市场：

- 沪深 300 等主流指数调仓频率低（半年一次），冲击成本可控
- 中证 500、中证 1000 等小盘指数调仓更频繁，冲击成本更大
- 中国基金的佣金费率较低（万分之一左右），但买卖价差和冲击成本仍需关注

## 与通道摩擦的类比

[[concepts/通道摩擦与额度稀缺]] 描述的 QDII 额度约束是跨境层面的摩擦，而指数调仓冲击是指数规则层面的摩擦。两者都属于"指数投资摩擦谱系"，但作用机制不同：

```
摩擦谱系：
  通道摩擦（额度/流动性）← 跨境维度
  编制摩擦（规则缺陷）   ← 指数规则维度
  调仓摩擦（冲击成本）   ← 执行维度
  跟踪摩擦（误差）       ← 结果维度
```
