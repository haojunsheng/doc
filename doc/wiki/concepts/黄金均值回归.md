# 黄金均值回归

长期来看，黄金价格面临三重均值回归压力：**矿山产量恢复**、**央行购金常态化**、**ETF资金流平稳化**。

## 三重回归压力

| 压力来源 | 短期状态 | 长期趋势 |
|---------|---------|---------|
| 矿山供应 | 2020年疫情导致产量下滑 | 已恢复，高金价刺激最大化产量 |
| 央行购金 | 持续增持，构成底部支撑 | 无固定规律，终将回归常态 |
| ETF资金流 | 2026年2月起持续净流入 | 情绪逆转时平稳或流出 |

## 形式化表达

```
短期: 避险需求 + 央行购金 + ETF正反馈 → 高位震荡
长期: 供应↑ + 需求↓ → 均值回归
```

## 边界条件

若出现持续性新需求（如全球去美元化进程加速），均值回归的时间跨度将大幅延长，短期内难以用供需框架预判。

## 与配置策略的关系

[[concepts/黄金保险定位框架]]主张的黄金配置比例（10-15%）正是基于对均值回归的认知：不预测短期方向，利用低相关性做长期对冲，而非在均值回归过程中做短线博弈。
