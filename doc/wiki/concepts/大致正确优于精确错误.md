# 大致正确优于精确错误

对普通投资者而言，**简单、低成本、易执行的策略，远比复杂、高成本、难执行的"精确"策略更有价值**。

## 核心命题

```
精确错误 = 复杂模型 + 高成本 + 难执行 → 执行不了 = 零收益
大致正确 = 简单策略 + 低成本 + 易坚持 → 长期坚持 = 复利胜利
```

## 为什么这对普通人更重要

学者和机构可以承受复杂模型的失败——他们有资源、有团队、有时间试错。但普通投资者的约束条件完全不同：

- **执行难度**：复杂的再平衡规则、多因子择时模型，普通人很难坚持
- **成本侵蚀**：复杂策略通常伴随更高的管理费和交易成本，长期复利效应下差距巨大
- **心理可持续性**：一个"精确但难执行"的策略，一旦在压力时刻被放弃，所有理论收益归零

## 博格尔的实践

[[约翰博格尔john-bogle]] 的贡献正是把马科维茨的复杂理论变成简单的指数基金——让普通人以最低成本获得市场平均回报。这完美诠释了"大致正确 > 精确错误"。

## 边界条件

这个原则**不适用于**：
- 企业级风险管理（如制药公司的气候风险对冲）
- 需要精确对冲的专业机构
- 有足够资源和专业团队的大投资者

但对绝大多数个人投资者，简单持久远比精确短暂更有价值。

## 与相关概念的关系

- [[无聊的投资]]：同向——查尔斯·艾里斯指出，主动投资的"无聊失败者"往往是最终的赢家
- [[简单可坚持原则]]：是同一理念的另一种表述
- [[完美组合的动态性]]：既然没有完美组合，追求"大致正确且能坚持"就是最优策略
