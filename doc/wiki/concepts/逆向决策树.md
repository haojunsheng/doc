# 逆向决策树

逆向决策树是一套用于判断「越跌越买」是否有效的流程化工具，核心结论是：**逆向操作有效的前提是资产本身优质，否则只是接飞刀。**

## 决策流程

```
看到下跌
    │
    ├─ 资产基本面是否仍然良好？
    │       │
    │       ├─ 是 → 检查估值
    │       │           │
    │       │           ├─ 估值处于历史低位？→ 可考虑加仓
    │       │           │
    │       │           └─ 估值仍偏高？→ 观望，等待
    │       │
    │       └─ 否 → 停止！这是基本面恶化，不是机会
    │                   （接飞刀陷阱）
    │
    └─ 我的资金期限是否匹配？
                │
                ├─ 是（长期资金）→ 继续评估
                │
                └─ 否（短期要用）→ 不动，甚至减仓
```

## 晨星原文支撑

[[越跌越买？赚钱的关键不在于你有多叛逆]] 一文的核心论点：

> 越跌越买的前提是资产本身优质，否则只是接飞刀。

该文区分了两类下跌：
- **价格下跌 + 基本面未变** → 机会
- **价格下跌 + 基本面恶化** → 陷阱

## 与[[产能周期四阶段]]和[[稳定市场周期化]]的联动

逆向决策树中的「基本面是否良好」判断，可以借助[[产能周期四阶段]]分析供给端是否仍在扩张，以及[[稳定市场周期化]]理解当前所处的周期位置。三者结合，可以区分「周期性底部」和「结构性衰退」。

## 与[[越跌越买]]行为偏差的关系

逆向操作容易陷入的认知偏差：
1. **沉没成本谬误**：「已经跌了这么多，再等等总会回来」
2. **确认偏差**：只找支持加仓的信息，忽略反面证据
3. **从众心理的反面**：别人恐慌时故意反向操作，而不是基于基本面判断

逆向决策树通过结构化流程强制检查基本面，避免上述偏差。
