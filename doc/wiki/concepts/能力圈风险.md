# 能力圈风险

对某类资产一无所知就进行配置，是"踏出能力圈的风险"。

## 核心论点

组合复杂度与犯错概率正相关：

**复杂度↑ → 认知要求↑ → 犯错概率↑**

- 组合越复杂，维护时间和精力成本越高
- 对不理解的投资品种配置，本质是在赌博
- 3~5 只不同类型的基金已足够实现分散

## 形式化表达

犯错概率 = f(组合复杂度, 认知盲区数量)

## 边界条件

- 金融知识丰富且有时间研究的投资者，可以适当增加组合复杂度
- 普通人应优先考虑 [[concepts/宽基指数]] 等自带分散属性的工具，避免踏出能力圈

## 与 [[concepts/资产相关性分散]] 的关系

试图通过持有大量基金来实现分散，往往是因为不理解相关性的本质——这是能力圈风险的一种典型表现。
