# SFT 记忆、RL 泛化

## 定义

后训练的两条主线：SFT（监督微调）教格式和记忆，RL（强化学习）教能力和泛化。

## 两条主线的分工

| 维度 | SFT | RL |
|------|-----|----|
| 目标 | 让模型记住特定格式、知识、行为模式 | 让模型学会在不确定环境中做出好决策 |
| 数据 | 高质量标注数据（pair/suite） | 环境交互轨迹 + 奖励信号 |
| 适用场景 | 固定格式输出、知识注入、风格模仿 | 多步推理、工具调用策略、探索性任务 |
| 典型失败 | 过拟合、灾难性遗忘 | reward hacking、训练不稳定 |

## 预训练/SFT/RL 三阶段各司其职

- **预训练**：学通用语言和世界知识
- **SFT**：学任务格式和特定行为
- **RL**：学泛化和策略优化

一个行为该用 SFT 还是 RL 训出来，判断标准是：**如果答案固定且可标注，用 SFT；如果需要在环境中试错学习，用 RL**。

## 验证方式

用一个例子说清"这个行为该用 SFT 还是 RL 训出来"。例如：让 Agent 调用特定 API 的格式 → SFT；让 Agent 决定何时调用哪个 API → RL。
