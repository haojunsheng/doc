# 叙事切换与信用债定价

信用债定价不仅取决于基本面利差，还深受市场"叙事"（narrative）驱动。当宏观事件改变市场定价逻辑时，信用债价格会出现非基本面驱动的剧烈调整。

## 核心逻辑

```
2025年：叙事 = "追逐收益"（利差收窄 → 信用债正回报）
    ↓
2026Q1：地缘冲击 → 叙事切换 = "规避风险"（利差走阔 → 信用债大幅回调）
```

## 叙事切换的触发机制

| 阶段 | 市场叙事 | 信用利差 | 定价逻辑 |
|------|---------|---------|---------|
| 平稳期 | "追逐收益" | 收窄 | 承担信用风险换取收益 |
| 冲击期 | "规避风险" | 走阔 | 风险溢价要求大幅提高 |
| 恢复期 | "风险定价回归" | 重新收窄 | 回到基本面定价 |

## 为什么叙事切换对信用债影响显著

信用债的本质是"承担信用风险换取收益"。当市场不确定性上升时：

1. **风险溢价要求提高**：投资者不再愿意承担同样的信用风险
2. **利率风险叠加**：油价推升利率预期，信用债同时承受利率风险和信用风险
3. **流动性折价**：风险偏好下降时，信用债流动性首先受损

## 与叙事的早期信号

| 信号类型 | 含义 |
|---------|------|
| 地缘冲突升级 | 市场从"收益追逐"转向"风险规避" |
| 油价剧烈波动 | 通胀预期变化，利率风险上升 |
| 央行立场变化 | 流动性环境改变，定价基准重置 |

**识别难点**："叙事切换"往往只能事后确认，早期信号识别困难。这是该框架的应用边界。

## 与英债/日债框架的关联

[[英债性价比框架]] 和 [[日债三重压力框架]] 同样受叙事切换影响，但债券品种因流动性好、定价更透明，叙事切换的影响相对较慢。信用债因定价复杂度高、信息不对称，叙事切换的影响更剧烈。

## 边界条件

- 若油价冲击快速逆转 → 叙事切换可能是短暂的 → 信用利差会重新收窄
- 若地缘冲突持续升级 → 叙事切换固化 → 信用债定价逻辑长期重塑
