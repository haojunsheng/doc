# 期望管理（Expectation Management）

期望管理是投资中被忽视的核心技能——它决定了你能否从"拥有更多"中获得真正的幸福。

## 定义

期望管理是指对投资收益和财富增长的合理预期进行主动调节的过程。其核心不等式为：

```
幸福感 = f(实际收益 - 期望)
当 期望增长速度 > 实际收益增长速度 → 幸福感下降
即使实际收益绝对值在增长
```

## 核心命题

**命题一**：投资的终极难题不是"赚多少"，而是"期望多少"。如果期望超过实际收益，无论赚了多少都不会满足。这是摩根·豪泽尔在《金钱心理学》中提出的"金融铁律"。

**命题二**：金融行业几乎把所有努力都放在增加你的钱上，但几乎完全忽视了等式的另一部分——告诉你什么是合理的预期。这是金融行业的结构性缺陷。

**命题三**："足够"不是一个客观数字，而是一种主观状态，取决于期望水平。如果你没有"足够"的概念，无论你赚多少钱都不会感到满意。

## 人性基础：享乐适应

人类是适应性极强的生物，会迅速适应新状态后产生更高的期望。两个经典案例：

- **盲人复明**：女孩恢复视力后并不快乐，因为她从未为"能看见"后的生活做好准备。
- **彩票中奖**：中奖者在实现梦想后往往不比中奖前更快乐，期望迅速上调至新的参照点。

这与[[concepts/享乐适应]]概念直接呼应，跑步机效应（[[concepts/跑步机效应]]）是其在财务场景中的具体表现。

## 操作框架

### 辩证结构

| 层次 | 内容 |
|------|------|
| 正题 | 金融行业的核心任务是帮助人们增加财富 |
| 反题 | 如果期望增长快于财富增长，增加财富不会带来幸福 |
| 合题 | 真正的理财应双管齐下：既增加财富，也管理期望 |

### 三个操作要点

1. **设定参照系**：避免以市场最高回报或他人收益为参照，选择与自身风险承受能力匹配的基准。
2. **定期校准期望**：当财富增长时，主动审查期望是否同步上调，防止跑步机效应。
3. **理解行业叙事**：意识到基金公司和金融媒体的商业动机与其建议的"合理性"之间存在结构性矛盾，保持独立思考。

## 与相关概念的关系

- **[[concepts/控制期望]]**：期望管理是更系统的框架，控制期望是其操作层策略之一。本文的精化在于强调期望增速与收入增速的**相对速度**而非绝对水平的比较。
- **[[concepts/享乐适应]]**：期望管理的人性基础——人类会适应新状态并不断抬高期望。
- **[[concepts/足够-t-动态校准]]**：期望管理使"足够"成为一个可操作的动态校准过程，而非静态目标。
- **[[concepts/理财焦虑避坑指南-忽略简单自动化]]**：期望管理是缓解理财焦虑的底层机制，忽略、简单、自动化三把刀都建立在合理期望之上。

## 限制与开放问题

- "期望增速"如何量化？缺乏可操作的指标（如参照系选择、基准设定方法）。
- 在低利率环境下，收入增速天然受限，期望管理是否应成为更优先的策略？
- 本文对金融行业的批判缺乏数据支撑，不宜作为攻击行业的主要论据。
