# 被动AI暴露

## 定义

持有宽基美股指数（如晨星美国指数）的投资者，即使不主动买入AI主题基金，也已经被动地将其投资组合的30%以上配置在了AI相关公司上。这是由于宽基指数天然重仓科技巨头（Mag 7等），而这些公司正是AI军备竞赛的主要玩家。

## 核心机制

```
宽基美股指数成分 → 科技巨头高权重 → 被动覆盖AI龙头 → 30%+被动AI暴露
```

晨星美国指数与晨星AI指数重叠超过30%（来源：[[sources/5-notes--33-20260628t154319-qa-不确定市场找可持续回报qa--1owcxwz]] Q4）。

## 投资含义

- 普通投资者无需主动追逐AI主题基金即可参与AI红利
- AI指数的价格/公允价值比自2023年起在74%-114%区间波动，超过100%即为高估——这意味着被动投资者已在不知情的情况下承担了相当比例的估值风险
- 试图通过主动配置增加AI敞口可能导致过度集中
