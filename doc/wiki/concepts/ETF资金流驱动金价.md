# ETF资金流驱动金价

**ETF资金流驱动金价**是指短期金价波动的主要边际驱动力是欧美黄金ETF的资金流入节奏，而非珠宝消费或央行购金。

## 核心命题

> 珠宝消费是最大来源但相对稳定，短期金价波动主要由ETF资金流决定。

## 形式化表达

```
珠宝消费（稳定）≠ 金价波动主因
ETF资金流（灵活）= 短期金价边际驱动力
```

## 驱动机制

```
实际利率↓ → 持有黄金机会成本↓ → ETF资金流入↑ → 金价↑
```

## 边界条件

若全球央行购金规模超预期增加，央行行为可能取代ETF成为边际驱动力。
