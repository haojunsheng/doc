# 资产荒

**资产荒**指资金充裕但优质资产稀缺的宏观状态——储蓄资金无处可去，被迫追逐有限的高收益标的，推高资产价格、压缩预期回报。

## 形成机制

```
低利率环境 → 票息躺赚时代终结 → 储蓄资金寻找替代品 → 涌入红利/债券等"类固收"资产 → 估值抬升、股息率压缩 → 资产荒加剧
```

资产荒的本质是**供需失衡**：资金端（居民储蓄、机构资金）供给充足，资产端（合格的高股息股票、优质债券）供给有限。

## 与红利投资的关系

[[红利资产拥挤度]] 上升的直接推手是资产荒——大量资金涌入红利板块，导致：
- 红利股估值被推高
- 股息率被动压缩
- 超额收益空间收窄

这是"红利成为主流"过程的宏观背景，也是红利策略自我消解悖论的催化剂。

## 行为金融学视角

资产荒放大了 [[线性外推]] 偏差：投资者在低利率环境中形成"债券收益应持续低位"的认知，转而追逐风险更高的资产，试图复制过去的票息躺赚体验，反而承担了超出自身风险承受能力的风险。

## 政策含义

资产荒期间，监管层面临的权衡是：鼓励资金流入权益市场以支持实体经济，但同时需要防范资产价格过度泡沫化带来的金融风险。
