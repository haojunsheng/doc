# QDII制度三阶段演化

QDII（合格境内机构投资者）制度自2006年试点以来，经历了三个特征鲜明的历史阶段，每个阶段的政策重心不同，塑造了当前额度稀缺与全球配置需求的格局。

## 第一阶段：高风险试点（2006-2008）

- **2006年8月**：QDII制度正式推出，首批机构获批额度
- **2007年**：首批QDII产品发行，募集规模超300亿元人民币，市场热情高涨
- **2008年**：全球金融危机冲击，QDII净值普遍腰斩，暴露高风险敞口，监管紧急收紧

这一阶段的特征是"激进试点-遭遇危机-快速退潮"，制度在极端市场压力下暴露出风险管理能力的不足。

## 第二阶段：规则修补（2009-2014）

- **2010年**：QDII投资范围突破股票限制，纳入债券和REITs，降低组合风险
- **2012年**：首只跨境ETF发行，被动产品开始布局；同时QDII总额度冻结在900亿美元
- 特征：监管从"放开"转向"修补漏洞"，试图在控制风险的前提下丰富产品形态

## 第三阶段：常态化扩容（2015至今）

- **2018年**：审批重启，额度开始阶梯式增长
- **2020年**：累计额度突破1400亿美元
- **2025年6月**：外汇管理局表态"新发放一批QDII额度"
- **2025年7月**：新发30.8亿美元，累计达1708.69亿美元
- 特征：额度供给稳步增长，但需求增速更快，40%的QDII产品仍存在限购

## 形式化表达

```
QDII额度(t) = f(阶段_t, 监管态度, 跨境资本流动压力)

阶段_t = 高风险试点 → 规则修补 → 常态化扩容
额度供给↑ ≠ 供需均衡 → 40%产品限购证明结构性短缺
```

## 边界条件

- 若再次出现全球系统性危机（如2020年式冲击），扩容节奏可能再次放缓
- A股持续走牛可能导致海外配置需求边际下降，缓解额度压力
