# 主动不等于被动

将"主动/被动"与"指数/非指数"拆解为两个独立维度，破除常见概念混淆。

## 二维框架

```
投资方式（主动/被动） × 工具类型（指数/非指数） = 四种组合

                指数工具          非指数工具
主动方式    选择指数+择时        主观选股
被动方式    跟踪指数             固定策略
```

### 四种组合详解

| 组合 | 说明 | 示例 |
|------|------|------|
| 主动 × 指数 | 选择指数、择时入场 | 手动选指数基金+定投/一次性买入时机 |
| 主动 × 非指数 | 主观判断、主动选股 | 主动管理股票基金 |
| 被动 × 指数 | 规则跟踪指数 | 普通 ETF 跟踪沪深 300 |
| 被动 × 非指数 | 固定规则、非指数工具 | 某些固守规则的量化策略 |

## 核心命题

> **主动投资 ≠ 被动投资**

两者在以下方面存在本质差异：

```
主动投资（试图跑赢市场） vs 被动投资（接受市场平均）
    理念: 主观判断 vs 规则跟踪
    策略: 择时+选股 vs 跟踪指数
    成本: 高费率 vs 低费率
```

## 常见误区

| 误区 | 真相 |
|------|------|
| "指数投资 = 完全被动" | 选择哪个指数、何时买入本身是主动决策 |
| "主动投资 ≠ 指数" | 主动管理可以以指数为基准进行偏离 |
| "被动 = 无脑躺平" | 选择被动工具本身也是主动行为 |

## 与已有概念的区分

- [[concepts/主动-被动-结构性困境]] 关注**实证结论**（费用/规模/效率导致大多数主动基金跑不赢指数）
- 本页面关注**概念辨析**（厘清"主动/被动"与"指数/非指数"不是同一维度）
- 二者互补，不冲突

## 扩展应用

此框架对理解以下产品有分类学价值：

- **主动 ETF**：属于"主动 × 指数"组合，兼具主动策略与指数工具特性
- **Smart Beta**：规则化主动策略，可归入"被动 × 非指数"或"主动 × 指数"边界
- **定投策略**：时间维度的"被动"纪律，但资产选择仍可主动

## 边界条件

- 此框架澄清概念，**不推翻**"大多数主动基金长期跑不赢指数"的实证结论
- 选择主动还是被动，取决于投资目标、风险偏好和市场环境
- 没有绝对优劣
