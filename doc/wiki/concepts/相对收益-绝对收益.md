# 相对收益与绝对收益

区分两种财富目标设定方式：以他人为参照的"相对收益"和以自身需求为参照的"绝对收益"。

## 核心框架

| 维度 | 相对收益 | 绝对收益 |
|------|----------|----------|
| 参照系 | 他人财富 | 自身生活需求 |
| 目标性质 | 永远移动 | 有明确终点 |
| 满足感 | 暂时性 | 持久性 |
| 储蓄率 | 系统性受压 | 可持续积累 |
| 心理状态 | 焦虑驱动 | 目标驱动 |

## 形式化表达

**相对收益：**
```
相对收益目标 = 我的财富 > 参照群体的财富
参照群体随财富增长而上移 → 目标本身在移动 → 满足感永远是暂时的
```

**绝对收益：**
```
绝对收益目标 = 我的财富 ≥ 我的生活需求
需求由自己定义 → 有明确终点 → 达到后满足感持久
```

## 相对收益的陷阱机制

相对收益将消费转化为地位信号，形成"赚得多花得多"的循环：

```
相对收益 → 消费 = 地位信号
消费水平 ∝ 参照群体消费水平
收入↑ → 参照群体消费↑ → 我的消费↑ → 储蓄率维持低位
```

## 切换方法

**开关 = 具体化"我想要的生活" → 量化"需要多少钱" → 对比"我现在有多少钱" → 行动有方向**

越具体地知道你想要什么，越不容易被"别人有什么"带偏。

## 边界条件

- **相对收益有用的场景：** 律师、金融、娱乐圈等职业，消费水平直接影响职业机会——此时"地位消费"是投资而非开销
- **绝对收益不适用的场景：** 基本需求未满足时，应优先保障生存，再谈"定义足够"
