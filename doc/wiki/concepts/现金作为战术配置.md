# 现金作为战术配置

现金不是"无收益的默认选项"或"不投资"，而是一种有战略意义的主动投资选择。关键是区分**刚性底层现金**（刚需）与**弹性战术现金**（择时工具）。

## 核心命题

```
投机者持有现金 = 规避波动风险（被动防御，情绪驱动）
价值投资者持有现金 = 等待更有吸引力的资产（主动等待，基于估值判断）
普通人持有现金 = 满足三层刚需 + 必要时作为战术弹药
```

## 现金的收益属性

| 维度 | 结论 |
|------|------|
| 长期（30年） | 现金收益刚好跑赢通胀 |
| 利率下行趋势 | 未来现金实际回报可能为负 |
| 利率上行趋势 | 现金吸引力重新上升 |

**形式化**：现金30年收益 ≈ 通胀率；利率↓ → 未来实际收益 < 0

## "现金为王"的正确使用时机

"现金为王"被大众误用的典型场景：市场下跌后，因**损失厌恶**（亏1元的痛苦需涨2元才能弥补）和**近因偏差**恐惧性持有现金。

正确的使用时机：

- **高估值 + 缺乏长期价值机会** → 持有现金保留弹药
- **市场下跌 ≠ 持有现金信号**（恐惧驱动的决策往往是错的）
- 应通过**估值比较**全面评估各类资产后再做决策

> 边界：若市场从高位快速下跌到极端低估，此时持有现金观望可能合理。但判断估值高低本身需要能力，错误判断可能导致"高买低卖"。

## 调整现金仓位 = 市场择时

这是本文最重要的认知纠偏：**主动增减现金仓位本质上就是在做市场择时。**

```
调整现金仓位 = 市场择时
市场择时 → 难度高 → 普通人适得其反风险
```

普通人应谨慎评估自己是否具备这种能力。坚持长期投资计划往往比频繁调整现金仓位更可靠。

**例外**：机械化的再平衡策略（如股债固定比例）是规则化操作，不属于择时。

## 三层刚需框架

普通人现金仓位的**刚性下限**由三个层次决定，超出部分才考虑投资：

```
现金刚需 = 应急金 + 短期支出 + 退休支出
```

| 层级 | 用途 | 建议覆盖时长 |
|------|------|------------|
| 应急金 | 应对突发支出（失业、疾病等） | 3-6个月必要开销 |
| 短期支出 | 1-2年内可预见的大额消费（购车、装修等） | 1-2年相关支出 |
| 退休支出 | 退休后1-2年生活费储备 | 1-2年退休生活费 |

**原则**：不因利率低就减少必要的现金储备。现金在投资组合中的角色首先是**流动性保险**，其次才是战术弹药。

## 边界条件

- 如果个人收入稳定且保险充足，应急金比例可以适当降低
- 若全球进入高利率周期，现金的吸引力会重新上升
- 高现金仓位在牛市中存在机会成本（踏空风险），需要承受心理压力
- 现金仓位本身不是目标，而是资本配置的中间状态
