# 波动率不是风险

波动率是风险的**代理变量**，但不等于风险本身。真正风险是**永久性亏损**——本金永远无法恢复。

## 核心区分

| | 波动 | 永久亏损 |
|---|---|---|
| 本质 | 价格围绕价值的摆动 | 价值本身消失 |
| 可恢复 | 是（时间可平滑） | 否 |
| 典型场景 | 好公司短期大跌 | 退市、公司破产 |

## 形式化

```
波动率 = 价格上下波动的幅度
高波动 ≠ 一定亏钱

永久性亏损 = 本金永远回不来
```

## 边界

- 波动率对**短期投资者**（1-3 年）很重要，因为可能需要在低点卖出
- 波动率对**长期投资者**（10 年以上）的影响会被时间平滑

> 参见 [[最大回撤与恢复时间]] —— 比波动率更直观的风险度量。
