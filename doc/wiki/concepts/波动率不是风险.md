# 波动率不是风险

波动率是风险的**代理变量**，但不等于风险本身。真正风险是**永久性亏损**——本金永远无法恢复。

## 核心区分

| | 波动 | 永久亏损 |
|---|---|---|
| 本质 | 价格围绕价值的摆动 | 价值本身消失 |
| 可恢复 | 是（时间可平滑） | 否 |
| 典型场景 | 好公司短期大跌 | 退市、公司破产 |

## 形式化

```
波动率 = 价格上下波动的幅度
高波动 ≠ 一定亏钱

永久性亏损 = 本金永远回不来
```

## 边界

- 波动率对**短期投资者**（1-3 年）很重要，因为可能需要在低点卖出
- 波动率对**长期投资者**（10 年以上）的影响会被时间平滑

> 参见 [[最大回撤与恢复时间]] —— 比波动率更直观的风险度量。

## 好风险与坏风险

[[波动率不是风险]] 指出波动本身不是风险，真正的风险是永久性亏损。但波动本身也有性质之分：

- **好风险**（上涨波动）：代表收益机会，不应被惩罚
- **坏风险**（下跌波动）：代表本金损失可能，是需要管理的核心风险

[[索提诺比率]] 和 [[晨星风险系数]] 正是在尝试量化这一区分——前者只看下行波动，后者给坏风险更大权重。详见 [[好风险与坏风险]]。

## 与三层模型的关系

[[投资风险]] 提出了"数字层 × 人性层 × 工具层"的三层模型，本文主要对应数字层的起点——指出标准差/夏普比率无法区分好波动和坏波动，是三层模型第一层的核心批判对象。
