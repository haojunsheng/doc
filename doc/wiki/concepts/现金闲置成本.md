# 现金闲置成本

分批投入过程中，未投入资金停留在现金状态所损失的机会收益——这是定投跑输一次性买入的根本原因。

## 核心结论

- 定投的本质是"延迟部分资金投入市场"
- 延迟意味着错失期间涨幅，损失的机会收益即"现金闲置成本"
- 定投期限越长，闲置成本越大，跑输概率越高

## 形式化

```
一次性买入：全部资金立即暴露 → 无闲置成本
分批定投：每月投入一部分 → 闲置成本 = Σ(未投入资金 × 期间涨幅)

跑输原因：
  不是定投"买贵了"，而是"买晚了"
  更多资金被推迟入市 → 整体收益↓
```

## 量化关系

| 定投期限 | 跑输概率 | 闲置成本程度 |
|---------|---------|------------|
| 短期 | 较低 | 较小 |
| 5年 | 72% | 中等 |
| 10年 | 83% | 较大 |

（数据来源：晨星中国，沪深300，2005-2026）

## 缓解因素

1. **闲置资金有收益**：若未投入资金投向货币基金，闲置成本降低
2. **市场短期下跌**：延迟投入反而规避了下跌损失
3. **投资者有现金流约束**：每月工资逐步投入是唯一可行方式，此时定投是"及时投资"的纪律化

## 边界

- 结论依赖"市场长期向上"假设——若市场横盘或下跌，闲置成本可能转为收益
- 在"每月有稳定现金流"场景下，定投是必要的纪律工具，闲置成本是 unavoidable 的
