# 投资者自身投资框架

个人投资者应先建立独立的判断框架，再据此选择与之匹配的基金，而非盲从基金经理的个人观点或历史业绩。

## 核心命题

```
投资者框架 × 基金经理框架 → 匹配则投 ‖ 不匹配则不盲从
```

## 来源论证

来源同时呈现四位基金经理对同一现象（内卷退潮）的四种截然不同的应对方案：

- 程琨坚守汽车零部件
- 陈俊华减持美团
- 蒋璆押注周期资产
- 周云攻守兼备

既然四位专业基金经理都没有共识答案，个人投资者更不应把某位经理的观点当作权威。

## 与[[主动基金去留评估框架]]的关系

[[主动基金去留评估框架]]聚焦"持有期间如何评估一只主动基金是否还应持有"，本文补充的是更早一步的问题——"在选择基金之前，我是否有自己的判断框架"。两者是先后关系：先有框架，再评估。

## 操作要点

1. **建立自己的核心假设**：你相信什么宏观逻辑？（如周云的定存利率<1%→储蓄搬家，或蒋璆的反内卷→周期盈利修复）
2. **明确框架的时间跨度**：你的投资周期是多长？不同框架适用不同时间尺度
3. **寻找框架匹配的基金**：而非找"最牛"的基金——每位经理擅长不同框架
4. **避免纯历史业绩导向**：历史业绩好≠未来框架正确，尤其当市场环境已变

## 边界条件

若投资者完全没有能力圈认知，仅凭历史业绩选基金，仍是在盲从——此时最简单的选择是低费率宽基 ETF，而非主动基金。
