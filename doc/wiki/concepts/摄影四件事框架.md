# 摄影四件事框架

## 定义

把摄影拆解为四个可练习的控制面：**取景、曝光、虚实、构图**。这四个面合成一个系统，把内心触动变成别人也能看见的照片。

## 四件事的逻辑结构

```
触动 → 主题
  |
  +--> 取景：画面里放什么
  +--> 曝光：画面亮成什么情绪
  +--> 虚实：哪里清楚，哪里模糊
  +--> 构图：元素怎么站位，视线怎么走
  |
  v
表达：让观者也感到那一下触动
```

## 与原子化思考的关系

将摄影这一复杂能力拆解为四个原子化控制面，每个面可以单独练习。这与[[原子化思考]]方法论同构——把大问题拆成最小可操作单元。

## 使用方式

每次按快门前问四个问题：取什么？亮成什么？哪里清楚？怎么站位？
