# 全球机构减持美国配置

全球机构正集体重估"美国例外论"：约 40% 的机构正在考虑或已经减少美国资产配置，减持动因因地而异，资金去向并非简单本土替代，而是私募资产 + 多元化配置。

## 核心形式化

```
减持美国 = 美元波动 + 关税扩大 + 监管不确定性 | 地区权重不同
亚太: 监管不确定性(58%) > 欧洲: 关税担忧(48%) > 北美: 估值吸引力下降
```

## 调查证据

晨星第四次年度全球机构投资者调查（500 余家机构、11 个国家）显示：

| 地区 | 减持意愿强度 | 主因 |
|------|------------|------|
| 加拿大 | 62% | 估值吸引力↓ |
| 英国 | 55% | 估值吸引力↓ |
| 亚太 | — | 监管不确定性(58%) |
| 欧洲 | — | 关税担忧(48%) |
| 北美 | — | 估值吸引力↓ |

全球约 40% 机构已减少或计划减少美国资产配置。

## 资金去向：不是本土回归，而是私募 + 多元

仅 9%（欧洲）~11%（亚太）将"聚焦本国资产"列为减持原因，说明去美元化不等于本土化。

```
减持美国 → 私募资产(占比20%) + 非美公开市场
私募占比: 全球20% | 欧洲21.4% | 亚太20.3% | 北美19.0%
```

## 边界条件

1. 若美国政策转向或美元企稳，减持趋势可能放缓
2. 机构自报数据≠实际资金流；500 家机构体量 vs 全球数万亿美元，代表性有限
3. 私募资产流动性差、估值不透明，追求多元化的同时进入更低透明度的市场
