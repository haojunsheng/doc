# 市场预测的不可靠性

金融市场的极端复杂性和反身性，使得专业投资者的预测准确率长期低于随机，远低于"有用"的阈值。

## 核心机制

**预测者 vs 被预测系统的博弈困境**：预测本身会改变被预测的对象，预测者成为系统的一部分。

### 反身性效应

索罗斯提出的反身性概念在此生效：

```
预测 → 影响行为 → 改变结果 → 推翻预测 → 预测者重新调整
```

一旦某个预测被广泛相信，套利者会迅速消除它试图预测的模式——"天机"一旦公开就不再是天机。

### 与天气预测的本质区别

| 维度 | 天气预测 | 市场预测 |
|------|---------|---------|
| 研究对象 | 物理系统 | 人的博弈 |
| 预测是否改变结果 | 否 | 是 |
| 准确率趋势 | 随技术进步持续提升 | 因反身性难以持续提升 |

## 证据

- **中金公司10条预言**：2022年错9条，2023年全错
- **达里奥（Ray Dalio）1987年论文**：预测价值不高，大多数做预测的人并未在市场上赚钱
- **晨星行为金融团队研究**：金融预测准确率低于"丢硬币"（<50%胜率）

## 结构性原因

行业存在结构性矛盾：客户要确定性，机构只能卖幻觉。策略会是营销行为，不是投资指导。打脸本身也是流量密码。

**自信偏差**：自信的金融从业者在行业中更成功，即使预测不准——自信是职业需求，不是能力证明。

## 正确打开方式

不做单点预测，做情景推演：

```
正确问题 ≠ "市场会怎样"
正确问题 = "如果市场怎样，我该怎么办"
```

参见 [[concepts/核心假设-退出信号框架]] 作为操作化落地方案。

## 边界条件

- 本文仅证伪了"单点预测"的可靠性，并未否定方向性判断的全部价值
- 估值分析（如 [[concepts/盈利收益率法]], [[concepts/博格公式法]]）的有效性边界与此相关但尚未明确——方向可以猜，路径不能，还是连方向也不可预测？
- 存在自指悖论：声称"市场不可预测"本身是一个元预测
