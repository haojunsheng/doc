# 詹森阿尔法（Jensen's Alpha）

基金收益对市场收益做线性回归后，回归线的 **y 轴截距**——代表投资组合在控制市场风险后获得的超额收益。

## 核心公式

```
α = Rp - [Rf + β(Rm - Rf)]
```

其中：
- α：詹森阿尔法（超额收益）
- Rp：投资组合收益率
- Rf：无风险利率
- β：投资组合对市场的贝塔系数
- Rm：市场收益率

## 历史起源

1967 年，哈佛商学院教授 Michael Jensen 在论文《1945-1964 年共同基金的表现》中首次提出。这是第一个将基金经理主动管理能力量化的学术指标。

## 局限与演变

詹森阿尔法有一个根本性缺陷：它只控制了市场风险（单因子 CAPM），没有控制其他系统性风险因子（规模、价值、动量等）。因此，许多被认为具有正阿尔法的基金，实际上只是对某些风格因子有隐性暴露。

Fama-French 三因子模型将 Alpha 定义为三因子回归后的残差，进一步收窄了"真正的阿尔法"的范围。这一演变过程正是"阿尔法消失"现象的学术基础。

## 关键洞见

- 詹森阿尔法 > 0：基金跑赢了与其风险水平相匹配的预期收益
- 詹森阿尔法 = 0：基金表现恰好符合 CAPM 预期（被动等价）
- 詹森阿尔法 < 0：基金表现不如与其风险水平相匹配的预期收益
- **但 Alpha > 0 不等于"有能力"**——可能是因子暴露、运气，或模型遗漏

## 实践含义

在因子模型充分发展的今天，单纯看詹森阿尔法数字已经不够。需要结合 Fama-French 三因子或多因子模型，才能更准确地区分真正的主动管理能力和风格暴露。
