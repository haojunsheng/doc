# 额度耗尽反噬

**额度耗尽反噬**是指跨境投资产品中，因销售额度被完全消耗，导致后续申购需求无法承接，从而在资金流向数据上呈现"净流出"的统计假象——实际上投资者并未看空，而是"想买却买不进"。

## 核心机制

```
额度放开 → 资金涌入 → 额度耗尽 → 后续需求受阻 → 净流出统计（非真实看空）
```

这是 [[QDII额度机制]] 的反向表现：额度机制通常被理解为"供给约束"（限制了能买多少），但在额度耗尽后，它会变成一种"需求约束的统计幻觉"——资金流出数据掩盖了真实的购买意愿。

## 实证案例

| 产品 | 现象 | 真实原因 |
|------|------|---------|
| 汇丰亚洲高收益债 | 净流出 | 内地销售额度耗尽，想买的人买不到 |
| 摩根国际债券 | 全年吸金130亿 | 环球分散策略，额度充裕，持续承接新需求 |

## 与"净流出=看空"朴素解读的区别

| 维度 | 朴素解读 | 额度耗尽反噬 |
|------|---------|------------|
| 净流出含义 | 资金看空，主动撤离 | 资金想买但买不进，统计假象 |
| 后续反应 | 预期继续流出 | 一旦额度恢复，资金可能回流 |
| 政策关联 | 无 | 直接受客地销售比例限制约束 |

## 识别方法

1. **查额度状态**：基金是否处于限购/暂停申购状态
2. **看产品结构**：是否为单一市场/单一策略的高度集中产品
3. **对比同行**：同品类其他产品是否在持续净流入（如摩根环球债 vs 汇丰亚洲高收益债）
4. **观察政策变化**：客地销售比例是否有放宽/收紧的动态

## 边界条件

- 若产品本身业绩持续恶化，净流出则可能是真实看空，需与额度耗尽区分
- 若额度长期受限无法恢复，资金可能逐渐形成替代渠道习惯（如通过港股通或QDII）

## 与现有概念的关系

- 扩展 [[QDII额度机制]]：补充了"额度耗尽导致净流出统计假象"这一反向机制
- 强化 [[股债冰火两重天]]：债基流出需先做额度限制剔除，再做行为解读
- 关联 [[客地销售比例限制]]：本机制的制度根源
