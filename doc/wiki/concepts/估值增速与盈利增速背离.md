# 估值增速与盈利增速背离

泡沫的本质信号：**估值增速远超盈利增速**，而非绝对估值水平高。

## 核心形式化

```
正常上涨 = 盈利 ↑ + 估值 ↑（合理）
泡沫     = 盈利 → + 估值 ↑↑（不合理）
```

## 案例对比

| 时期 | P/E 变化 | 盈利增速 | 判断 |
|------|---------|---------|------|
| 2000 年互联网泡沫 | 20 → 45（+125%） | +10% | 泡沫：估值增速远超盈利增速 |
| 2020–2021 年疫情后 | 20 → 30（+50%） | +30% | 非泡沫：估值与盈利增速基本匹配 |

## 边界

- **高估值 ≠ 泡沫**：亚马逊长期高 P/E，但持续盈利增长消化估值。
- **关键不是 P/E 绝对值，而是 P/E 增速与盈利增速的匹配度**。
- 周期性行业：盈利低谷时 P/E 自然偏高，属于"盈利 → + P/E ↑"，非泡沫信号，需单独判断。
