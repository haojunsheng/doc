# 高股息陷阱风险

高股息陷阱风险指：高股息收益率并非来自公司盈利提升或分红质量改善，而是来自股价下跌导致的分母效应——股息率被动升高。此时高股息是"假象"，本质是价值陷阱。

## 形成机制

股息率 = 每股分红 / 股价

当股价下跌而分红金额不变时，股息率被动升高。投资者看到的高股息可能只是股价崩盘的镜像，而非分红能力的真实体现。

## 港股高股息的特殊风险

港股市场的高股息陷阱风险尤其突出，原因：

1. **长期折价结构**：港股长期被低估，很多公司的低估值反映的是结构性不信任（如内地投资者对港股公司治理、披露质量的折扣）
2. **缺乏低波过滤**：多数港股高股息指数（如中证港股通高股息投资指数）无波动率筛选层，无法排除股价剧烈下跌的标的
3. **行业集中**：港股高股息成分股高度集中在金融、能源、电信、公用事业，这些行业的周期性波动直接冲击股价
4. **汇率叠加**：人民币计价的港股红利收益还叠加汇率风险

## 识别信号

| 信号 | 含义 |
|------|------|
| 股息率持续走高但盈利下滑 | 股价下跌驱动的被动升高，典型的陷阱信号 |
| 支付率异常上升 | 分红不可持续，靠透支现金流维持高股息 |
| 行业过度集中 | 周期性行业集中度高，行业下行期陷阱风险放大 |
| 低波因子缺失 | 无波动率筛选的指数更易陷入高股息陷阱 |

## 与相关概念的关联

- [[秩序搬运]]：高股息指数属于秩序搬运机器，其陷阱风险与搬运的底层资产质量直接相关
- [[集中度风险]]：行业集中是陷阱风险的放大器——金融、能源等周期性行业集中度高时，整体陷阱概率上升
- [[红利资产拥挤度]]：拥挤度上升时，后来资金推高股价、压低股息率，但陷阱已潜伏在前期下跌的标的中

## 应对思路

1. 使用带低波过滤的指数（如华泰柏瑞港股通红利低波ETF 520890）
2. 跟踪成分股盈利趋势，而非只看当期股息率
3. 关注股利支付率是否在合理区间（0-1），支付率>1意味着不可持续
4. 将股息率利差（[[股息率利差纪律]]）作为动态监控指标，利差异常收窄时警惕陷阱风险暴露
