# 总回报率

**总回报率（Total Return）**是衡量投资真实收益的完整指标，包含资本增值和分红收入两部分，除以初始投资得出百分比。

## 定义与公式

```
总回报率 = (期末价值 - 期初价值 + 期间分红) / 期初价值 × 100%

其中：
- 期末价值 = 期末净值 × 期末份额
- 期初价值 = 期初净值 × 期初份额
- 期间分红 = Σ每份分红 × 持有份额

若分红再投资：
总回报率 = (期末累计份额 × 期末净值 - 期初价值) / 期初价值 × 100%
```

## 核心要点

总回报率改变投资者看待"收益"的方式：从"价格上涨了多少"到"我真正赚了多少"。分红不是"额外的施舍"，而是"我的钱生出的钱"。它是一种**完整性原则**——在计算收益时，不遗漏任何来源。

**本质：总回报率 = 投资的完整成绩单。**

## 历史背景

20世纪60年代，美国投资公司 Institute（ICI）开始要求基金公司披露"总回报率"而非仅披露净值增长率，因为许多基金通过分红来回馈投资者，只看净值会系统性低估真实收益。晨星从1984年成立之初就把总回报率作为基金评级的核心指标。

关键转折：从"价格回报"到"全要素回报"——投资者开始意识到，分红不是"额外的"，而是回报的一部分。

## 必要但不充分

总回报率并非完美指标，具有两重局限：

1. **分红再投资假设**：总回报率假设分红可以再投资，但现实中很多投资者选择现金分红，不再投入。
2. **忽略时间价值**：同样10%的回报，在一年实现和三年实现完全不同。总回报率无法反映资金的时间价值。

它是理解投资回报的起点，不是终点。

## 失效场景

- **高频小额分红基金**：再投资的摩擦成本（手续费）可能导致总回报率被高估。
- **分红操纵**：基金经理可能在分红前抬高净值，通过"分红"制造虚假的高回报率印象。

## 元反思：体检报告隐喻

总回报率 = **体检报告**。它告诉你身体目前的各项指标，但不能预测你明年会不会生病。你需要看体检报告，但你不能只看体检报告来决定未来的生活方式。

**更深层的警示**：总回报率是后视镜，不是挡风玻璃。过度依赖历史总回报率，可能导致"追涨杀跌"——买过去回报最高的基金。见[[净值恐高症]]。

```
│   │         │         │ │

│   │         │         │ │

│             ▼           │
│   ┌─────────────────┐  │
│   │   总收益         │  │
│   │    ÷            │  │

│   └────────┬────────┘  │

净值 ≠ 总回报
净值 + 分红 = 总回报
```
