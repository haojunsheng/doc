# 净资产快照

**核心论点**：理财计划的第一步是算净资产，不是记账。净资产是静态快照，记账是动态流水；没有快照，流水无方向。

## 定义

```
净资产 = 总资产 − 总负债
```

净资产是个人财务的「家底照片」，回答「你此刻站在哪条起跑线上」。

## 与记账的关系

| 维度 | 净资产快照 | 记账 |
|------|-----------|------|
| 性质 | 静态 | 动态 |
| 回答 | 此刻有多少钱 | 过去一段时间钱怎么动 |
| 作用 | 定位起点 | 发现流向 |
| 优先级 | 第一步 | 第二步 |

```
理财计划步骤 = ① 算净资产 → ② 记账 → ③ 分析调整
```

## 财务健康分层

基于净资产与支出关系划分：

```
净资产 < 0                         → 资不抵债，立即制定止血计划
0 < 净资产 < 6个月必要支出         → 财务脆弱，止血优先
净资产 ≥ 6个月必要支出             → 有缓冲空间，可启动长期规划
```

## 边界条件

- **净资产为负但负债是长期低息房贷 + 收入稳定**：不需紧急处理
- **净资产为正但全是借来的（如信用卡套现买房）**：实际风险比负值更高
- **非流动资产是核心城市优质房产**：可通过抵押贷款快速变现，流动性比表面高
- **收入来源多元**：现金垫可低于 3 个月；单一高波动行业收入：6 个月也不够
