# 浮动费率行业集中度风险

浮动费率制度在推动行业从规模驱动转向能力驱动的同时，也带来了行业集中度上升的结构性风险。

## 核心机制

浮动费率系统要求每笔份额独立核算、按持有期和收益率动态匹配费率，这对后台系统提出了极高要求：

```
浮动费率系统 = 每笔份额独立核算 × 持有期 × 收益率匹配
```

中小基金公司面临双重壁垒：
1. **系统改造成本高**：需要投入大量资金升级后台系统
2. **投研能力门槛高**：必须持续跑赢基准才能维持合理费率收入

## 市场现状

浮动费率基金从2023年8只试水到2025年30只规模330亿，占主动偏股基金募集的24%。参与者多为头部基金公司。

## 潜在风险

如果头部基金公司形成垄断，浮动费率产品可能缺乏竞争，反而损害投资者利益。这与被设计用来促进竞争的制度目标之间存在张力。
