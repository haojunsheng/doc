# 股票回购对EPS的机械效应

股票回购通过减少流通股数量，在总盈利不变的情况下机械性地提升每股盈利（EPS）。这一机制是2014-2024年美股专家预测模型系统性遗漏的关键变量。

## 核心机制

```
回购效应：流通股↓ → EPS = 总盈利 ÷ 流通股 → EPS↑↑
```

- 总盈利（净利润）不变
- 流通股数量因回购而减少
- 分母变小 → EPS机械性上升
- 这一提升无需企业实际业绩增长

## 为何被专家模型遗漏

1. **传统模型假设**：盈利增长来自业务扩张，而非财务操作
2. **忽略资本配置决策**：回购是企业资本配置选择，不同于经营决策
3. **持续性盲点**：2010年代回购规模持续扩大，模型未及时调整权重

## 与回报分解的关联

在[[美股十年估值扩张实证]]的四因素分解中：
- 预测股息率3%，实际1.87%（预测偏高）
- 但回购使EPS增长超预期，部分抵消股息率偏低的负面影响
- 两项相加≈5.25%，与实际5.69%大致吻合
- **剩余超额收益全部来自估值扩张**

## 与资本增值vs资金流入驱动的区分

[[资本增值vs资金流入驱动]]讨论外部资金流入对估值的推动。回购是另一种机制：
- 外部资金流入 → 推高股价 → 估值扩张
- 回购 → 减少流通股 → EPS提升 → 支撑股价
- 两者可叠加：回购释放的"财务空间"让公司更有能力维持高估值

## 纳指七雄的回购实践

[[纳指七雄集中度风险]]中的科技巨头（苹果、微软、亚马逊等）是回购主力：
- 巨额现金储备 + 稳定现金流 → 大规模回购能力
- 回购进一步推高EPS → 支撑高估值
- 形成正反馈循环

## 边界条件

- **可持续性质疑**：如果未来回购节奏放缓或停止，EPS增长的机械加分消失
- **会计操纵风险**：过度依赖回购推升EPS可能掩盖基本面疲弱
- **监管关注**：多国监管机构已开始审视大额回购对实体经济的影响
