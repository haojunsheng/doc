# 易得性直觉驱动目标

人容易把"身边常见的事"误认为"自己应该追求的目标"——朋友圈晒房 → "我也该买房"，财务自由叙事 → "我也要存百万"。这些可能是别人的剧本，不是你的目标。

## 定义

**形式化**：
> 易得性直觉驱动目标 = 社会环境中高频出现的行为/目标 → 误认为个人真实目标

**来源**：Kahneman & Tversky 的"易得性启发式"（Availability Heuristic）在个人目标设定中的应用。

## 机制

```
社会环境高频叙事（朋友圈晒房、财务自由传播）
    ↓
大脑误判：常见 = 重要 = 我应该追求
    ↓
目标来源外源性 → 与真实价值观错位 → 存钱动力不足或方向错误
```

## 与相关概念的区别

| 概念 | 关注点 | 机制 |
|------|--------|------|
| **易得性直觉驱动目标** | 目标来源 | 把常见当应该追求 |
| **地位消费** | 消费行为 | 用消费证明社会地位 |
| **跑步机效应** | 满足感 | 比较对象随财富上移 |
| **目的焦虑** | 焦虑状态 | 社会大目标绑架人生意义 |

易得性直觉是**认知偏差**，地位消费是**行为表现**，跑步机效应是**心理机制**，目的焦虑是**结果状态**。

## 与投资/储蓄的关系

- **存钱方向错误**：为"别人的目标"存钱（如买房），而非为"自己的价值观"存钱
- **动力不足**：目标来源外源，缺乏内在驱动力
- **解法**：通过"回想最快乐的旅行体验"等内向探索，区分"社会目标"与"真实目标"

## 边界条件

- 如果目标本身是社会共同认可的（如养老储备），易得性偏差的影响较小
- 如果已经按"别人的目标"存了很多钱但不开心，需要停下来重新评估
