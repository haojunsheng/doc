# 赛道轮动

资金在不同行业赛道间快速切换的行为模式，是中国市场特有风险，加剧追涨杀跌效应。

## 特征

- 2020年疫情后：成长股（创业板+65%）→ 医药（+50%）→ 消费（+65%）
- 2021年起：新能源、半导体、AI 等高景气赛道轮动
- 轮动速度快，资金集中涌入 → 高位追入 → 业绩反转 → 低位割肉

## 与投资者回报差的关系

赛道轮动是中国市场投资者回报差比欧美亚太更剧烈的核心原因。

## 与主题基金发行的传导链条

[[sources/5-notes--35-20260628t153730-qa-主题基金热潮中的冷思考qa--1f24gn3]]（晨星中国，2026-06-28）补充了赛道轮动向主题基金发行端的传导机制：

```
赛道轮动→主题基金发行增加→行业集中度上升→投资者回报差加剧
```

**具体机制**：
1. 赛道A上涨→资金涌入→基金公司发行赛道A主题基金
2. 赛道B上涨→资金切换→基金公司发行赛道B主题基金
3. 同一时期多只主题基金竞争资金→行业集中度上升
4. 投资者在赛道高潮期申购→热潮退却后亏损→回报差扩大

**2024年数据**：140只主题基金中，新兴行业76只、国企17只、医药14只、黄金6只——发行高度集中在当时热点赛道。
