# 关税自我抵消机制

## 核心定义

关税无法从根本上解决贸易逆差，因为存在自我抵消的汇率传导机制：进口减少→美元升值→出口受阻→逆差不变。

## 形式化表达

```
关税↑ → 进口↓ → 美元↑ → 出口↓ → 逆差≈不变（自我抵消环）
```

## 传导逻辑

1. **经常账户恒等式**：经常账户赤字 = 资本净流入
2. 关税提高→进口商品变贵→进口减少→美元支出降低
3. 美元支出降低→美元需求相对上升→美元升值
4. 美元升值→美国商品在海外变贵→出口下降
5. 进口减少带来的改善被出口减少完全抵消
6. 资本净流入没变，经常账户赤字也没变

## 历史反证：页岩气革命案例

2010年代美国页岩气革命使能源从进口转为出口：

```
页岩气革命 → 能源出口↑ → 美元↑20% → 其他行业出口↓ → 整体逆差没变
```

- 美国从能源第一大进口国变成出口国
- 按理说贸易逆差应该缩小
- 但美元升值20%让其他行业出口变难
- 逆差被其他商品的进口增加对冲了

**关键启示**：单一部门的出口竞争力提升，会被汇率渠道完全抵消。

## 边界条件

| 条件 | 逆差是否收窄 | 说明 |
|------|------------|------|
| 仅加征关税（单政策） | 否 | 自我抵消机制成立 |
| 关税 + 资本管制 | 可能 | 阻断资本流动，打破恒等式 |
| 关税 + 财政赤字削减 | 可能 | 减少资本净流入 |
| 关税维持时间短 | 影响有限 | 未及形成完整传导链 |

**核心约束**：自我抵消机制的前提是资本自由流动且财政赤字不变。一旦政策组合变化，抵消效应可能被打破。

## 与现有框架的关系

- **[[关税通胀传导链]]**：同一关税政策的另一条传导路径（物价路径 vs 汇率路径），两者并存但作用机制不同
- **[[经常账户-资本流入恒等式]]**：自我抵消机制的理论基础
- **[[关税行业冲击分化框架]]**：宏观层面的逆差不变≠行业层面无影响，行业冲击是第二层面的问题
