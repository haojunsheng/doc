# 烧钱抢份额

多平台资本投入争夺市场份额，短期牺牲利润换取用户规模与渠道占有的竞争策略，典型出现在互联网平台经济的价格战阶段。

## 核心特征

```
烧钱抢份额 = 多平台入场 + 补贴争夺用户 + 短期利润承压 + 格局未出清
```

## 典型案例：外卖价格战

- 京东入局，免佣金冲击美团主业
- 饿了么"饿补超百亿"
- 阿里砸约 RMB500 亿补贴投入
- 美团海外 Keeta 同步扩张，分散国内资源

2025 年上半年美团核心本地商业经营利润从 RMB524 亿骤降至 RMB-69 亿，是烧钱战的直接财务体现。

## 投资判断框架

烧钱抢份额是否构成卖出信号，取决于三个问题：

1. **格局可出清吗？** 若新入局者因亏损持续而退出，原有龙头竞争力恢复，则短期烧钱是阵痛；若格局长期僵持，则利润被永久压低。
2. **现金储备够吗？** 烧钱战中拥有最强资产负债表的企业才可能笑到最后。
3. **单位经济能跑通吗？** 补贴退潮后，核心业务的单位经济能否独立盈利？

## 与[[单位经济]]的关系

[[单位经济]]正数是烧钱抢份额可持续的前提——若单笔订单长期亏损，烧钱只是延缓死亡而非创造价值。

## 在陈俊华决策中的应用

陈俊华减持美团的核心依据即：多平台烧钱抢份额格局恶化 + 美团海外资源分散导致国内价格战可能处于下风。
