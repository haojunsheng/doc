# 高点买入风险

在市场高点买入基金，不仅面临估值回归风险，还因[[回撤与回本的非对称性]]而承受不成比例的恢复难度。

## 风险机制

```
牛市高点 → 基金扎堆发行 → 投资者追涨买入 → 建仓成本高 → 遭遇大幅回撤 → 回本困难
```

2015年5000点附近大量基金发行，募集了天量资金。这些基金建仓成本高，随后遭遇股灾大幅回撤。即使上证指数后来回到4000点，大量基金净值仍低于买入价。

## 行为金融驱动因素

- **[[近因效应]]**：近期上涨被视为趋势延续的信号，驱动投资者在高点追入
- **[[共识入场陷阱]]**：当市场共识一致看好时，往往是阶段性顶部
- **[[期望管理]]盲区**：基金公司将销售节奏与市场高点对齐，而非与投资者利益对齐

## 应对策略

- 避免在市场高点一把梭买入
- 采用定投方式平滑成本，自动实现"低点多买、高点少买"
- 关注基金的回撤控制能力，而非仅看收益率
- 建立逆向投资思维：别人恐惧时买入，别人贪婪时谨慎

## 与 [[回撤与回本的非对称性]] 的关联

高点买入的最大风险不仅在于买入价格高，更在于一旦遭遇深度回撤，回本所需的涨幅呈非对称性放大——这是普通投资者最容易忽视的数学陷阱。
