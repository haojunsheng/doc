# 最小知识地图

## 定义

合上所有材料后，仅凭记忆在一张纸上画出的领域结构图。用于验证 MECE 完整性——如果你画不出来，说明学习尚未完成。

## 用途

[[假设驱动研究]] 阶段零（建立最小领域认知）的验收工具。不是精美图表，而是个人理解的快照：把领域摊开成一张拓扑图，看各层之间的关系是否清晰、覆盖是否完整。

## 画法要求

以 AI Agent 领域为例，一张合格的最小知识地图应包含：

```
AI Agent
  ├─→ 认知层（LLM 做什么？）
  ├─→ 工具层（调用什么外部能力？）
  ├─→ 记忆层（短期？长期？）
  ├─→ 评估层（怎么知道 Agent 做对了？）
  └─→ 应用层（落地在哪些场景？）

每层 → 列出 3-5 个关键技术/产品/论文
```

## 判断标准

- **能画出来** → 阶段零通过，进入阶段一的逐层深入
- **画不出来或严重缺漏** → 回去补材料，不急于推进

## 与相关概念的关系

- [[假设驱动研究]]：最小知识地图是假设驱动阶段零的产物；地图的质量决定了后续假设的质量
- [[DIKW模型-研究方法论]]：地图构建是从 Data（散点信息）向 Knowledge（结构化理解）的跃迁
- [[五维分析框架-肖璟]]：地图的层间关系体现了产业分析的结构化思维
