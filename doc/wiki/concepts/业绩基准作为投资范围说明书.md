# 业绩基准作为投资范围说明书

业绩基准是判断QDII基金实际投资区域和投资比例的最快、最有效的工具。基金名称和分类标签可能产生严重误导，但业绩基准直接写明了基金契约规定的配置目标，是不可绕过的信息锚点。

## 核心逻辑

基金产品的招募说明书中设有"业绩比较基准"章节，该章节直接规定了：
- 基金投资于哪些市场/指数
- 各市场/指数的权重比例
- 是否包含对冲策略

**解析示例**：
- `60% MSCI全球 + 40%恒生` → 真正的全球配置 + 港股敞口
- `100% 日经225` → 单国日本暴露，却可能归类在"环球股票"下

## 实操方法

### 步骤一：找到业绩基准

在基金详情页或招募说明书中查找"业绩比较基准"字段，而非依赖基金名称或产品分类标签。

### 步骤二：解析基准构成

将基准中的指数/市场翻译成实际投资区域：

| 基准构成 | 实际投资区域 |
|---------|------------|
| MSCI全球 | 全球发达+新兴市场 |
| MSCI新兴市场 | 印度、巴西、台湾、韩国等 |
| 恒生指数 / 恒生科技 | 港股 |
| 标普500 | 美股大盘 |
| CAC 40 | 法国 |
| 日经225 | 日本 |
| 富时100 | 英国 |

### 步骤三：判断是否符合投资意图

- 想全球分散 → 找基准含MSCI全球或类似宽基的基金
- 想配置港股 → 找基准含恒生的基金
- 不想单国集中 → 避开基准为单一国家指数的基金

## 边界条件与局限

1. **风格漂移**：基金实际持仓可能偏离业绩基准，需结合定期报告交叉验证
2. **基准不透明**：部分基金使用自定义基准或复合基准，需查阅招募说明书全文
3. **基准变更**：基金可能在存续期内调整业绩基准，需关注最新公告
