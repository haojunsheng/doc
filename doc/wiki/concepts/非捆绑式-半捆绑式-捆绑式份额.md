# 非捆绑式-半捆绑式-捆绑式份额

三类份额按**利益冲突程度**和**费率透明度**分层，构成理解基金收费结构的核心分析框架。

## 形式化定义

```
非捆绑式 = 管理费 + 运营费
          （无申购费、无尾佣、无其他利益关联费用）

半捆绑式 = 管理费 + 运营费 + 其他费用
          （无申购费、无尾佣，但含过户代理服务费、平台使用费等）

捆绑式   = 管理费 + 运营费 + 申购费 + 尾佣 + 其他费用
          （含一系列潜在利益冲突费用）
```

## 对比表

| 维度 | 非捆绑式 | 半捆绑式 | 捆绑式 |
|------|---------|---------|--------|
| 透明度 | 最高 | 中等 | 最低 |
| 利益冲突程度 | 最小 | 中等 | 最大 |
| 成本构成 | 仅管理费和运营费 | 管理费+运营费+其他费用 | 含申购费、尾佣等多重费用 |
| 典型形态 | 海外清洁份额、中国投顾份额 | 含过户代理服务费等的份额 | 国内A类、C类、Y类份额 |
| 资金流向趋势 | 持续净流入 | 稳定/流入 | 持续净流出 |

## 关键洞见

**费率透明度梯度直接对应利益冲突程度梯度**：捆绑式份额中，尾随佣金使渠道有动机推荐高分成产品而非最适合产品；非捆绑式通过消除这一机制，实现投顾收入与投资者利益的真正对齐。

## 与 [[投顾份额]] 的关系

中国投顾份额在费率结构上属于**非捆绑式**——免尾佣、免申购费，仅收管理费和基于账户规模的投顾费。投顾份额是中国语境下非捆绑式的制度实现。

## 边界条件

- 非捆绑式通常只能通过投顾渠道购买，普通直销渠道难以触及
- 半捆绑式虽无尾佣和申购费，但其他费用可能隐含利益关联
- 捆绑式份额在中国市场仍占主流，但资金正在向非捆绑式迁移
