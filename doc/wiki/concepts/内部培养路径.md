# 内部培养路径

指基金经理从研究岗（研究员/交易员）起步，在基金公司内部经过14–17年渐进式成长后独立管理产品的人才培养路径。与外部跳槽型经理相对。

## 核心论点

**内部培养路径是长期超额收益的可靠前置指标**，因为：

1. 时间长：14–17年经历多轮牛熊，体系在实践中反复打磨
2. 平台依赖：公司内部投研体系为其提供研究支持、风控约束和渐进式授权
3. 纪律性强：非天才型选手，靠体系成熟而非短期运气

## 形式化表达

```
内部培养（14–17年） × 多轮牛熊 → 体系成熟 → 长期超额收益
⊃ 非外部跳槽型
```

## 典型案例

[[乔迁]]（17年）、[[黄珺]]（17年从业/11年组合管理）、[[宋倩倩]]（14年）三位晨星专题案例均走内部培养路径，且三人任期波动和下行风险均低于同类平均。

## 边界条件

- 依赖公司平台投研体系质量，若平台体系薄弱则难以复制
- 样本量小（晨星专题n=3），缺少统计检验
- 未涉及外部跳槽型经理的表现对比，存在选择偏差
