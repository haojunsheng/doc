# ETF费率内卷

**ETF费率内卷**是指当ETF管理费率已逼近成本红线（0.15%地板价）时，基金公司在产品高度同质化的背景下，只能通过继续降价来争夺市场份额的零和竞争状态。这是指数内卷在费率维度的集中体现。

## 典型样本：中证A500ETF费率战

- 2024年9月23日中证A500指数成立，几天内首批10只ETF相继成立
- 后续又发行22只，总计32只A500ETF
- 32只产品首发费率全部为0.15%，直接卷到行业地板价
- 2024Q4规模达1756亿，占所有ETF规模的5%

## 形成机制

```
产品同质化（同一指数多只产品）
    ↓
投资者以费率为主要决策依据
    ↓
基金公司竞相降价抢规模
    ↓
费率逼近成本线 → 无法再降 → 内卷陷入僵局
    ↓
倒逼方向：靠产品创新和差异化突围
```

## 边界条件

- 若A500指数持续跑赢沪深300，规模增长可能支撑低费率走薄利路线
- 若基金公司能开发出真正差异化的策略指数（非简单因子叠加），可跳出费率战
- 若监管限制头部市场份额（反垄断），费率内卷程度可能有所缓解
- 费率持续下降会反噬管理费收入，长期不可持续

## 核心判断

费率内卷是阶段性现象，终将被产品创新突破。当费率逼近成本线，真正的竞争才开始：谁先找到差异化锚点，谁就占位。
