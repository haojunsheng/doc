# 热力学第二定律——王朝能量收支模型

借用克劳修斯的热力学第二定律与老子「天之道/人之道」，政权天然散功（熵增），要维持高能量状态需持续输入燃料。逆天而行终有极限。

## 定义

- **天之道**：能量自然从高温流向低温——任何政权天然在散功（熵增）
- **人之道**：逆天而行，用燃烧低能量者来加热高能量者——高能量者需持续输入燃料

## 核心公式

```
王朝续航 = 初始惯性 + ∫(燃料输入 - 燃料消耗) dt
```

燃料包括：税收、人口、兵源、土地。

## 唐朝案例：燃料链的断裂过程

| 阶段 | 能量状态 | 关键事件 |
|------|---------|---------|
| 贞观→开元 | 燃料输入 > 消耗，惯性正向增长 | 府兵制运转良好，均田制稳定 |
| 天宝年间 | 燃料输入 ≈ 消耗，收支接近平衡 | 节度使掌握地方财政，中央依赖上贡 |
| 安史之乱 | 燃料输入 < 消耗，系统性漏油 | 「出将入相」通道封闭，河北断裂 |
| 藩镇割据 | 燃料输入 << 消耗，持续净流出 | 藩镇截留赋税，中央失去造血能力 |

## 「人之道」的极限

书里反复强调：高能量者想要永远沸腾，需要源源不断的燃料献祭。但当「大量做功是无效的，是与抓取燃料所无关的」，就是下坡之路的开始。

杨广的案例：开运河、征高句丽，做功巨大但都与「抓取燃料」无关——这是在逆天而行的无效做功，加速了熵增。

## 跨领域迁移

- **企业**：收入（燃料输入）需大于运营支出（熵增），否则规模越大崩溃越快
- **个人**：精力管理——高能量状态需要持续输入（休息、学习、关系），否则必然耗散
- **投资**：账面浮盈不等于现金流为正，需区分「惯性维持」与「基本面健康」

## 局限与说明

- 类比限于启发，不适用于严格数学推导
- 「燃料」的定义需根据具体系统调整（王朝=税收+人口+兵源；企业=现金+客户）
- 与[[惯性定律-王朝续航力框架]]配对使用：前者解释为何停，后者解释为何久
