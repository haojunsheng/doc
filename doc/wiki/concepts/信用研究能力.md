# 信用研究能力

信用研究能力是信用债基金的核心竞争力，指基金管理人通过自建研究团队对债券发行人进行独立信用风险评估的能力。

## 核心命题

> **选择信用债基金，本质上是在选研究团队的"排雷"能力。**

与股票基金选基金经理个人能力不同，信用债基金的选择焦点应从"谁管理"转向"团队能力结构"——是否有独立的信用评级能力。

## 形式化表达

```
信用研究能力 = f(研究团队规模, 评级模型, 风控体系)
```

三个维度：
- **研究团队规模**：人员数量与行业覆盖深度
- **评级模型**：内部评级方法论的科学性与迭代能力
- **风控体系**：信用风险的预警、跟踪与处置机制

## 核心价值

独立信用评级能力使基金能够：

1. **不依赖外部评级**：外部评级存在滞后性和利益冲突，独立评级更贴近实际风险
2. **提前识别风险**：通过深度调研发现外部评级未能反映的隐患（"排雷"）
3. **把握交易机会**：在利差变动中精准判断信用恶化与修复的时机

## 边界条件

- **研究团队判断也可能出错**——如果信用事件超出预期，仍然可能造成损失
- 独立评级并非护身符，只是比完全依赖外部评级略胜一筹
- 与 [[信用下沉]] 形成对照：信用下沉是降低信用质量以博取高收益，而信用研究能力强调通过研究避免踩雷

## 典型实践

- [[工银瑞信信用添利]]：依托工银瑞信信用研究团队，强调独立信用评级作为核心优势
- [[富国产业债债券]]（武磊管理）：同样具有独立信用研究团队，可作为横向参照
