# 顺手哲学

## 核心命题

**最好的相机 = 最顺手的相机 = 最能满足你需求的相机。**

不是比出来的，是用出来的。

## 两层含义

### 第一层：顺手 = 愿意带出门

一台相机再先进，如果不愿意带出门，它的实际价值为零。体积重量差异每次出门都能感知，画质差异需要放大才能看出——两者的使用频率严重不对称。

### 第二层：顺手 = 与你的技能水平匹配

"顺手"是一个会随技能提升而变化的动态概念。你现在的"顺手"可能不是三年后的"顺手"。这带来一个终局问题：**选购时应该买"现在顺手的"还是"未来可能顺手的"？**

作者没有给出明确答案，但这个张力本身是值得持续反思的。

## 与 [[摄影减法论]] 的同构关系

两篇都指向同一个结论：少即是多。

- [[摄影减法论]]：好照片是删出来的（删冗余构图、删拍摄执念）
- 顺手哲学：好相机是选出来的，不是参数堆出来的（删过剩参数、删高科技功能）

工具的价值在于**被使用**，不在于**被拥有**。

## 与 [[审美判断力≠软件操作]] 的关系

高级功能不等于审美能力。[[审美判断力≠软件操作]] 关注的是技术能力与审美能力的错位，顺手哲学关注的是工具复杂度与实际使用价值之间的错位。两者互相佐证。

## 实践检验

判断一台相机是否"顺手"的最简单标准：**第三次出门后，你还会愿意带它出门吗？** 如果答案是否定的，这台相机可能不是你的最佳选择。
