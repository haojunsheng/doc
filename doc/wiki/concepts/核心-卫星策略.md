# 核心-卫星策略

用低成本宽基指数做核心（60-80%），用少量卫星仓位（20-40%）做主动或主题投资——保证不死的骨架设计。

## 形式化表达

```
核心仓位（60-80%）：宽基指数基金、债券基金
  → 锚定防死，获取市场平均回报
  
卫星仓位（20-40%）：行业基金、主题基金、主动管理基金
  → 超额可能性，承担更高风险
```

## 设计逻辑

1. **核心 = 保证不死**：市场跌时不太怕，市场涨时不太踏空
2. **卫星 = 给你赌注**：押行业、押主题、押基金经理，错了也不伤筋动骨
3. **无核心则赌博**：全是卫星 = 与赌博无别
4. **无卫星则存定期**：全是核心 = 与存定期无别

## 边界条件

- **前提**：必须真正区分核心与卫星——很多人把卫星也买成宽基指数，形同虚设
- **管理成本**：卫星仓位管理成本更高，没时间研究则全仓核心更省心
- **比例非定律**：60-80%/20-40% 是经验值，非定律，可根据个人情况调整
