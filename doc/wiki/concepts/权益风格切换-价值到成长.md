# 权益风格切换-价值到成长

**权益风格切换-价值到成长**指2025年Q3 FOF在权益持仓上从价值风格基金向成长风格基金的系统性迁移，是[[concepts/FOF配置转向框架]]五大转向之一。

## 核心机制

```
成长风格（易方达科融/智造/兴全合润）持仓↑ ⊥ 价值风格（大成高鑫、国富中小盘）大幅减持
```

## 实证数据

| 基金 | FOF持有数量变化 | 持仓规模变化 |
|------|----------------|-------------|
| [[entities/大成高鑫股票]] | 169只 → 14只 | 8.96亿 → 0.88亿 |
| [[entities/国富中小盘]] | 35只 → 0只 | 无重仓 |
| 成长风格基金（科技/新能源） | 持仓提升 | — |

## 共同特征

被减持基金（大成高鑫、国富中小盘）最近两年投资风格均偏价值。

## 边界条件

若市场风格从成长切回价值，FOF可能重新增配价值基金。
