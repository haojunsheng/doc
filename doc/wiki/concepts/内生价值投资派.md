# 内生价值投资派

内生价值投资派（Endogenous Value Investing School）是一种以长期现金流折现（DCF）为核心判断股票内在价值的投资方法，与 [[周期投资派]] 形成对照。

## 核心框架

```
内在价值 = 未来现金流折现值
DCF模型：估值 = Σ(未来现金流 / (1+r)^t)
```

## 核心主张

- 股票价值等于企业生命周期内能给投资者带来的所有现金流的折现值
- 关注**十年以上**的现金流总量，而非短期盈利波动
- 如果估值高于当前市值，说明有投资价值

## 方法论要点

- 常用自由现金流贴现法（DCF）估值
- DCF 模型的核心假设（现金流和贴现率）没有定式，最考验技术和眼光
- 不同价值投资者对同一只股票可能得出完全不同的估值——这是价值投资的内在不确定性

## 代表人物

[[沃伦巴菲特warren-buffett]] 定义内在价值为"企业生命周期内能给投资者带来的所有现金流的折现值"，是其价值投资体系的核心基石。

## 认识论要点

[[伴读：股票估值两门派]] 强调：知道用什么框架估值，比知道真实估值更重要。DCF 的输入参数（现金流、贴现率）高度主观，不同投资者结论可以截然相反——这正是估值"艺术性"的本质。

## 边界条件与风险

- DCF 假设的高度主观性：不同投资者对增长率、贴现率的设定差异巨大，导致估值结果可能完全相反
- 长期视角要求投资者具备极强的耐心和财务安全垫——否则在市场长期偏离内在价值时难以坚持
- 与 [[低市盈率策略]] 的关系：价值派认为低 PE 是机会，但需排除基本面恶化的"价值陷阱"

## 难以坚持的根源

[[巴顿-比格斯-barton-biggs]] 描述了互联网泡沫期间投资者的心理状态："虽然满仓 all in，但实际上怕得要死"。[[罗伯特-希勒-robert-shiller]] 的研究进一步表明，市场可能长期处于高估或低估状态，1970 年买入成长股的价值投资者可能要忍受 10 年熊市——在熬过这 10 年前，投资者很可能就已对自己的判断失去信心。

## 与其他概念的关联
