# 分散化有效性条件

**分散化有效性条件**是指分散投资要真正发挥降低组合风险的作用，必须满足的核心前提：分散效果取决于资产间的真实相关性结构，而非简单的市场标签或基金数量。

## 核心命题

> 分散化未失效，失效的是对它的简单理解。

传统观念认为"买多个市场/多只基金"就是分散，但晨星15年相关性数据表明，这种标签式分散在关税时代已不再可靠。

## 形式化条件

```
有效分散的条件：
1. 资产间相关性 < 1（越低越好）
2. 相关性结构相对稳定（或可预测/可跟踪）
3. 极端情形下有备用的非风险资产
```

不满足以上条件时，分散化效果显著下降甚至失效。

## 标签式分散为何失效

| 标签 | 实际相关性 | 结果 |
|------|----------|------|
| 港股 | 与A股高度联动 | 伪分散 |
| 发达国家市场 | 与A股相关性自2021年起下降 | 分散效果尚可，但需择时选择 |
| 新兴市场 | 与A股相关性自2017年起上升 | 分散效果恶化 |

## 普涨后情境：分散化的升级应用

当所有资产普涨时，分散化从"降低风险的工具体"升级为"最优策略"：

```
普涨后：各资产估值接近合理 → 难以找到明显低估 → 分散化最优
```

这一情境由 [[普涨后分散化最优框架]] 详细阐述，补充了分散化在"安全边际普遍压缩"时的额外有效性理由。

## 边界条件

- 相关性是历史统计，未来可能发生结构性变化（如关税政策的持续影响）
- 极端行情下所有风险资产相关性趋近于1，分散短期失效
- 管理维度越多，维护成本越高，需权衡复杂性与可操作性
- 普涨后分散化虽为最优，但仍需防范"相关性上升"导致的分散效果减弱

## 实践含义

1. 用穿透后的底层相关性判断分散效果，而非基金名称或上市地标签
2. 关注相关性结构的时间演变，定期重新评估配置
3. 在极端行情下，承认分散短期失效是正常现象，不必恐慌性调仓
4. 普涨后不要试图通过集中配置来"抓住下一个机会"，分散化仍是最优的事前策略
