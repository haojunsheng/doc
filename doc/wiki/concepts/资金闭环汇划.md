# 资金闭环汇划

> 南向通的核心操作机制，资金只能在指定账户间封闭流转。

## 定义

资金闭环汇划是指跨境理财通南向通中，内地汇款账户与香港投资账户之间专款专用的人民币跨境汇划机制。资金不能自由进出，只能在配对后的两个账户间闭环流动。

## 操作路径

```
内地银行汇款户 ←配对→ 香港银行投资户 → 购买港澳理财产品（人民币汇划）
```

## 关键约束

- **币种限定**：只能以人民币跨境汇划，不能直接用港币或其他外币
- **账户配对**：内地汇款账户必须与香港投资账户建立配对关系后才能使用
- **专款专用**：资金只能在汇款户和投资户之间流转，不能转入其他账户
- **额度控制**：在各自渠道（银行/券商）额度内自由换汇投资，但总额度受控

## 参与门槛

- 内地合格投资者身份：满 2 年社保/个税缴纳记录，或年均收入 40 万元人民币以上

## 意义

闭环汇划是跨境理财通风险控制的核心设计，确保资金流向可追溯，防止通过该通道进行套利或规避外汇管制。对投资者而言，理解闭环机制是参与南向通的前提。
