# 商铺租金下行周期

2020年以来持续的商铺租金下行趋势，是餐饮行业成本端的重要利好因素。

## 关键数据

- 2024H2 百街租金：24.25元/㎡/天
- 一线城市：61%区域租金下滑
- 二线城市：83%区域租金下滑
- 趋势：持续走低至2025年

## 驱动因素

1. **地产调整**：商业地产供大于求，空置率上升
2. **外卖业态兴起**：无需临街旺铺，可选更小更便宜的场地
3. **自动化设备普及**：压缩厨房面积，降低对空间的需求

## 对餐饮利润的影响路径

```
地产调整 → 商铺租金持续下降 → 餐饮拿铺成本降低 → 利润率提升（占成本15%）
```

## 边界与反转风险

- 若地产企稳反弹，租金利好可能反转
- 目前判断2025年仍会走低，但需持续跟踪商业地产空置率数据
