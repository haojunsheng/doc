# 烧钱模式逆向关税效应

## 核心定义

处于"烧钱补贴抢份额"阶段的企业，关税导致的订单减少反而可能改善其财务表现——因为补贴支出随订单量同步下降，亏损收窄。这一反直觉效应的本质是：烧钱模式的利润表结构与传统企业相反。

## 形式化逻辑

```
传统企业: 关税↑ → 订单↓ → 收入↓ → 利润↓（负面）
烧钱企业: 关税↑ → 订单↓ → 补贴↓ → 亏损↓ → 利润↑（逆向利好）

边界条件：该效应仅在"补贴驱动"阶段成立，一旦进入盈利阶段即失效。
```

## 典型案例：[[Temu]]

- 战略阶段：以抢占市场份额为首要目标，持续高补贴
- 关税影响：订单减少 → 补贴支出减少 → 亏损收窄
- 风险分散：已拓展美国以外市场降低单一市场依赖

## 投资启示

这一概念与[[市场先生]]的行为金融学框架相呼应：当市场因关税恐慌抛售时，逆向投资者可能发现被错杀的机会。但需严格区分企业所处阶段（烧钱期 vs 盈利期），否则可能误判方向。

## 边界条件

- 若企业已进入盈利阶段，订单减少即为纯负面
- 若关税导致不可逆的市场份额流失（如用户转向本地替代品），长期仍是负面
- 需持续跟踪企业财务状况变化以判断阶段转换时点
