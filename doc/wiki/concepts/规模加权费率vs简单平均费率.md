# 规模加权费率 vs 简单平均费率

通过资金分布与费率的交叉分析，识别投资者对费率的实际敏感度。

## 定义

- **简单平均费率**：所有基金费率的算术平均，不考虑规模
- **规模加权费率**：以各基金规模为权重计算的综合费率，反映"资金实际承担的成本"

二者关系揭示资金分布是否偏向高费率或低费率产品。

## 分析框架

```
规模加权费率 > 简单平均费率 → 资金集中在高费率产品（费率不敏感）
规模加权费率 < 简单平均费率 → 资金集中在低费率产品（费率敏感）
```

## 货基 vs 被动股基的对比

| 指标 | 货基 | 被动股基 |
|------|------|---------|
| 简单平均费率 | 0.49% | 0.52% |
| 规模加权费率 | 0.54% | 0.52% |
| 高费率40%产品中的资金占比 | 65% | 78% |
| 资金分布倾向 | 高费率 | 低费率 |
| 投资者敏感度 | 低 | 高 |

## 关键发现

**货基**：规模最大、最受欢迎的产品费率反而更高，形成反常的"规模溢价"现象。65%的资金集中在费率最高的40%产品中，规模加权费率(0.54%)高于简单平均(0.49%)。

**被动股基**：恰好相反，78%资金集中在低费率40%产品中，规模加权费率(0.52%)等于或低于简单平均，体现费率敏感性。

## 应用价值

该分析工具可复用至其他基金品类的费率敏感度评估：
1. 判断某品类投资者是否理性关注成本
2. 识别是否存在"规模溢价"（规模越大费率越高）的反常现象
3. 为费率改革提供实证依据

## 边界条件

- 该分析反映的是横截面数据，不直接预测动态变化
- 若低费率产品通过大规模营销改变投资者认知，资金分布可能反转
- 需结合持有期、流动性需求等因素综合判断费率敏感度
