# 叠加崩盘效应

指一次崩盘后市场尚未回本就遭遇第二次崩盘，导致回本时间显著延长的效应。这是解释"失落十年"现象的关键机制。

## 核心机制

```
第一次崩盘（高→低）
       ↓
      回暖中（部分回本）
       ↓
第二次崩盘（再次砸低，未触底反弹即重来）
       ↓
回本时间大幅延长（远超单次崩盘的预期）
```

关键：**回本路径不是线性的**。第一次崩盘后的回暖期本身就充满不确定性，若在此期间遭遇新的系统性冲击，投资者的痛苦会指数级放大。

## 典型案例：纳斯达克 2000—2012

| 时间节点 | 事件 | 100美元（2000年8月投入）价值 |
|----------|------|----------------------------|
| 2000年8月 | 投入100美元 | 100 |
| 2000年底 | 互联网泡沫破裂，纳指半年腰斩 | ~50 |
| 2002年10月 | 尚未回本 | 52.76 |
| 2008年 | 次贷危机再砸 | 46（新低） |
| 2012年 | 终于回本 | 100 |

**结论**：两次崩盘叠加 → 12年回本（单次崩盘通常2-4年即可回本）

## 投资启示

1. **叠加崩盘是最大风险**：单次崩盘虽痛但可预期修复；叠加崩盘的不确定性极高，投资者难以判断"这次是不是底"
2. **低位加仓的重要性**：若在2008年低点追加投入，回本时间会大幅缩短——但因叠加崩盘的恐慌属性，多数投资者在此时选择割肉而非加仓
3. **多元化是对抗叠加崩盘的唯一护城河**：单一资产暴露于叠加崩盘时毫无招架之力；跨资产、跨地域的多元化组合能显著降低叠加崩盘的实际伤害

## 边界条件

- 若在两次崩盘之间成功加仓（如2008年在纳指低点补仓），叠加崩盘效应可被缓解甚至逆转
- 现代央行"看跌期权"（Put Option）机制已部分降低叠加崩盘的概率——2020年熔断后的快速政策干预即是证明
- 若叠加崩盘由结构性变化（如全球化彻底逆转）驱动，历史参照系下的修复时间可能系统性延长

## 与其他概念的关系

- 是 [[concepts/痛苦指数]] 的核心解释机制：痛苦指数异常升高往往由叠加崩盘导致
- 与 [[concepts/崩盘常态化框架]] 一致：叠加崩盘并非异常，而是崩盘常态化框架下的高痛苦子情形
- 与 [[concepts/回本]] 交叉：叠加崩盘直接决定了回本时长这一痛苦指数维度
