# 五类工具划分

## 定义

将 Agent 的工具按交互方式划分为五类，覆盖 Agent 与世界交互的全部方式。

## 五类工具

| 类别 | 描述 | 典型例子 | 设计要点 |
|------|------|---------|---------|
| 感知类 | 获取外部环境信息 | 搜索引擎、API 查询、文件读取 | 输入结构化、输出可解析 |
| 执行类 | 改变外部环境 | 代码执行、数据库 CRUD、HTTP 请求 | 能力 vs 安全是核心矛盾 |
| 协作类 | 与其他 Agent/服务交互 | MCP 调用、函数调用、RPC | 互操作标准（如 MCP）的价值所在 |
| 事件触发类 | 被动响应外部事件 | 消息队列消费、webhook、定时器 | 异步架构、占位符机制 |
| 用户沟通类 | 与用户直接交互 | 聊天界面、语音播报、通知推送 | 交互模式（全双工/半双工）影响体验 |

## 执行工具的核心矛盾

执行工具的核心矛盾是**能力 vs 安全**：
- 能力：让 Agent 能做更多事
- 安全：沙箱、确认、越权防护

安全机制是 harness 的原型。Pine 敢让 Agent 替用户谈钱，靠的就是这套安全机制清单。

## MCP 的价值

MCP（Model Context Protocol）的价值是**互操作标准**而非新能力——出现前后给 Agent 加一个新工具的工程成本差在标准化接口的统一性上。

## 验证方式

- 跑 `chapter4/` 执行工具安全机制实验，故意让 Agent 做一次越权操作看拦截
- 画出同步 Agent 与事件驱动 Agent 在"打一通 2 小时电话"场景下的时序差异图
