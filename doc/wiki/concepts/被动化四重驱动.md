# 被动化四重驱动

**被动化四重驱动**是解释中国债券被动投资爆发原因的统一框架，包含四个互为强化的因素：利率下行、低费率、T+0交易机制和政策推动。

## 形式化链条

```
利率↓
  → 主动超额难（久期操作空间压缩）
  → 被动低费率优势凸显
  → ETF T+0交易机制吸引力提升
  → 政策推动（质押回购、互联互通、快速审批）
  → 被动债基爆发（一年内规模7042亿→1.5万亿，翻倍）
```

## 四重驱动详解

### 1. 利率下行压缩主动超额

利率持续下行环境下，债券价格整体上行，基金经理通过久期调节、信用下沉获取超额的空间被压缩。当"赚不到超额"时，被动产品的成本优势变得更具吸引力。

### 2. 低费率优势凸显

被动债券ETF管理费仅0.15%~0.24%，而主动转债基金管理费中位数为1.66%。在超额收益有限的固收领域，费率差距直接转化为费后净收益差距。

### 3. T+0交易机制

债券ETF支持T+0二级市场买卖，资金使用效率远高于普通债券基金的T+1/T+3申赎到账。对于需要灵活调仓的资金而言，这是关键竞争优势。

### 4. 政策推动

监管层推动债券ETF纳入质押回购、互联互通机制，并实施快速审批通道，降低了产品发行和交易的基础设施壁垒。

## 边界条件

- **若利率反转上行**：主动基金经理久期操作空间扩大，被动优势减弱，被动化进程可能放缓甚至逆转
- **若债券市场波动加剧**：被动产品跟踪误差可能扩大，投资者信心受挫
- **若更多公司进入被动债基领域**：费率竞争可能进一步压降，加速被动化进程
