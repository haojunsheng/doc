# 跑步机效应（Hedonic Treadmill）

满足感随财富增长而快速适应，目标参照系随之上移，导致"跑得越来越快，却始终还在原地"。

## 核心机制

```
赚100万 → 发现身边人都有200万 → 目标变为200万
赚200万 → 发现身边人都有500万 → 目标变为500万
→ 满足感永远是暂时的
→ 永远不满足
```

## 与享乐适应的关系

跑步机效应是享乐适应在财务领域的行为表现：
- **享乐适应**：心理层面，对新的财富水平快速适应
- **跑步机效应**：行为层面，比较对象随财富上移，导致持续追逐

## 与[[目的焦虑]]的关系

[[目的焦虑]]是跑步机效应在社会文化层面的延伸：
- **跑步机效应**：个人行为层面，比较对象不断上移
- **目的焦虑**：社会文化层面，"大目标"叙事不断重新定义"成功"

两者互为因果：社会用大目标绑架人生意义（目的焦虑），驱动个体不断追逐更高参照系（跑步机效应）。

## 与相对收益的关系

跑步机效应是相对收益思维的核心机制——比较对象永远在移动，所以永远无法抵达满足的终点。

## 与 PERMA-V 模型的对比

[[perma-v模型]] 提供了跑步机效应的意义侧解法：

| 维度 | 跑步机效应 | PERMA-V |
|------|-----------|---------|
| **问题侧** | 欲望永不停歇，参照系不断上移 | 人生意义单一，快感随财富适应消退 |
| **机制** | 行为层面：比较对象随财富上移 | 心理层面：六个维度覆盖幸福来源 |
| **解法** | 切换到绝对收益思维 | 建设多维人生目标，降低对单一财富参照的依赖 |

## 解决方案

切换到绝对收益思维：以自身需求为参照，而非以他人财富为参照。

## 与相关概念的关系

- **[[相对收益-绝对收益]]** — 跑步机效应解释了相对收益为何永远不满足
- **[[享乐适应]]** — 两者互为因果，跑步机效应是行为表现，享乐适应是心理机制
- **[[地位消费]]** — 跑步机效应在消费端的体现
- **[[目的焦虑]]** — 跑步机效应在社会文化层面的延伸（春节焦虑场景）
- **[[大目标与小目标框架]]** — 目的焦虑的机制性解释框架
- **[[perma-v模型]]** — 意义侧解法，通过多维目标建设对抗单一财富参照
