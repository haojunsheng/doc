# 行业分类——利润来源视角

## 核心观点

基金里的"行业"不要只看标签。消费、科技、医药、红利、周期这些词背后，对应的是不同的**利润来源、估值逻辑和宏观敏感点**。更好的分类方式是理解每个行业靠什么赚钱、吃什么宏观环境、怕什么风险。

## 七大行业本质速查

### 消费：收租的品牌
- 典型方向：白酒、食品饮料、家电、消费50
- 本质：买人的日常欲望和品牌定价权
- 适合：收入稳定、消费信心恢复
- 怕：估值太贵、消费降级、人口变化
- 关键逻辑：需求相对稳定，强品牌可提价转嫁成本

### 科技成长：买未来生产力
- 典型方向：半导体、AI、云计算、软件、信创、机器人
- 本质：买未来，而不是现在
- 适合：流动性宽松、风险偏好高
- 怕：估值高、周期强、兑现慢
- 关键逻辑：新技术提高生产力则利润可能大幅增长；市场情绪好时愿意为远期故事付钱，情绪差时杀估值

### 医药健康：长期刚需，但政策手很重
- 典型方向：创新药、医疗器械、CXO、中药、医疗服务
- 本质：买老龄化和生命需求
- 适合：政策稳定、创新周期向上
- 怕：集采、医保控费、监管、研发失败
- 关键逻辑：需求长期存在，但利润分配会被政策重塑——不是"稳稳的刚需"

### 金融地产链：经济的水管
- 典型方向：银行、保险、券商、地产
- 本质：买信用扩张和资产负债表
- 适合：经济修复、利率和信用改善
- 怕：坏账、地产拖累、利差压缩、政策压制
- 关键逻辑：和经济周期高度相关

### 周期资源：潮汐资产
- 典型方向：煤炭、有色、钢铁、化工、油气
- 本质：买商品价格和供需周期
- 适合：通胀、供给收缩、全球需求强
- 怕：周期反转、商品价格暴跌
- 关键逻辑：关键不是"公司好不好"，而是"价格周期站在哪一边"

### 高端制造：产业升级里的军备竞赛
- 典型方向：新能源车、光伏、军工、机械、电力设备
- 本质：买产业升级和资本开支
- 适合：技术迭代、订单高增、产业政策支持
- 怕：产能过剩、价格战、补贴退坡
- 关键逻辑：区分两个问题——行业有没有趋势，公司能不能把趋势变成利润

### 防御红利：现金流资产
- 典型方向：红利、低波、央企红利、公用事业、电力、电信
- 本质：买现金流、分红和低估值
- 适合：低利率、震荡市、风险偏好低
- 怕：成长性弱、拥挤交易、分红下滑
- 关键逻辑：不靠故事靠当下赚钱能力；全市场都去买红利时，红利也会变贵

## 使用方法

这个框架的价值在于：面对一个新行业基金时，不是记忆标签，而是问三个问题：
1. 它靠什么赚钱（利润来源）？
2. 它喜欢什么样的宏观环境？
3. 它最怕什么风险？

答案决定了它在什么情况下该买、什么情况下该卖。
