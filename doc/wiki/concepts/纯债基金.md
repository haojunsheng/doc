# 纯债基金

纯债基金是指仅投资于债券市场、不投资股票的基金类型。其核心价值在于提供稳健收益和较低回撤，适合作为资产配置中的"稳定器"。

## 定义与分类

```
纯债基金 = 仅投资债券（国债、金融债、信用债等）
         → 不投资股票
         → 波动↓ + 回撤↓
```

与混合债券基金的区别：

| 维度 | 纯债基金 | 混合债券基金 |
|------|---------|-------------|
| 股票投资 | 禁止 | 允许（通常≤20%） |
| 波动来源 | 利率风险、信用风险 | 利率风险、信用风险、股市风险 |
| 波动水平 | 较低 | 较高 |
| 牛市表现 | 无法分享股市收益 | 可能跑赢纯债基金 |
| 熊市表现 | 相对稳定 | 可能受损 |

## 收益来源

```
债券投资收益 = 票息收益 + 资本利得（久期操作） + 信用利差（信用下沉）
```

1. **票息收益**：持有债券至到期获得的利息收入，是主要收益来源
2. **久期操作**：根据利率预期调整组合久期，获取资本利得
3. **信用下沉**：适度投资低评级债券，获取信用利差

## 策略异质性：纯债基金内部差异

纯债基金并非"低风险=都一样"，不同策略会导致截然不同的风险收益特征：

### 两种主流策略范式

```
策略分化 = 信用债打底（票息导向） vs 利率债波段（交易增强导向）
```

| 维度 | 信用债打底策略 | 利率债波段策略 |
|------|--------------|---------------|
| 核心仓位 | 高评级信用债（约100%） | 利率债（0-40%）+ 信用债 |
| 久期管理 | 稳健（如2-4年） | 灵活（如1-5年） |
| 收益来源 | 票息为主 | 久期操作资本利得占比高 |
| 波动特征 | 相对稳健 | 高波动、高弹性 |
| 典型案例 | [[工银纯债债券]] | [[万家鑫璟纯债债券]] |

### 策略差异的业绩影响

- **高波动 ≠ 高风险**：利率债波段策略的基金波动性高于同类中位数，但夏普比率往往位于同类前10%，说明风险调整后收益出色
- **周期性特征**：利率波动大的年份（如2020年）表现优异，窄幅波动年份收益偏弱
- **费率优势**：纯债基金不涉及股票投研，管理复杂度低，费率天然低于权益基金。两只案例基金费率均为0.41%，处于同类最低五分位，与 [[费率复利效应]] 呼应

详见 [[利率债波段操作]]。

## 风险控制手段

| 手段 | 机制 | 风险 |
|------|------|------|
| 久期管理 | 根据利率走势调整债券期限 | 利率判断失误时拖累业绩 |
| 信用评级控制 | 投资高评级债券 | 限制收益空间 |
| 信用下沉 | 投资低评级高收益债券 | 违约风险上升 |
| 分散投资 | 避免单一债券违约 | 稀释超额收益 |

## 资产配置角色

纯债基金在资产配置中扮演"稳定器"角色：

```
资产配置 = 纯债基金（稳定器） + 股票基金（增长引擎） → 风险调整后收益↑
```

- 提供稳定票息收益，不受股市波动影响
- 在股市下跌时提供缓冲
- 投资者可在股债之间进行动态再平衡

详见 [[债券稳定器]]。

## 边界条件与风险

**适用场景**：
- 风险承受能力较低的投资者
- 追求稳健收益、不需要短期流动性的投资者
- 需要降低组合整体波动的资产配置需求

**边界条件**：
- 股市大涨时，纯债基金无法分享收益，可能跑输混合债券基金
- 利率大幅上升时，债券价格下跌，纯债基金也受影响
- [[股债双杀]] 环境下，稳定器作用减弱
- 信用下沉策略下，低评级债券存在违约风险
- 历史风险指标不代表未来表现
- 投资者若无法承受波动，可能提前割肉，导致实际亏损
- [[机构占比与赎回风险]]：机构持有人比例过高可能引发大额赎回冲击净值

## 费用影响

费用是确定性成本，长期持有下复利效应显著：

```
年费差异（1%） × 10年 ≈ 累计收益差距约10%
```

纯债基金费率通常更低（管理费0.3%+托管费0.1%=0.41%），是费率复利效应的典型场景。详见 [[费率复利效应]]。

## 选择指南

```
选择 = f(风险偏好, 收益预期, 持有期限)
→ 稳定型 → 信用债打底策略基金（如工银纯债债券）
→ 弹性型 → 利率债波段策略基金（如万家鑫璟纯债债券）
```

关键原则：理解底层策略，而非只看历史业绩排名。

## 与相关概念的区分

- **[[中等波动固收+]]**：在纯债基础上增加股票/可转债等增强收益，波动更高
- **[[持有期债基]]**：通过设置持有期限制流动性，但不改变基金投资范围
- **[[票息打底-交易增强策略]]**：一种主动管理策略框架，纯债基金可采用此框架
- **[[信用下沉]]**：适度投资低评级债券获取信用利差，与本文强调的"避免过度信用下沉"形成边界
