# 基金经理变更风险

基金经理变更后，基金历史业绩对未来的参考价值大幅降低——因为历史业绩反映的是"那个人"的能力，而非"这个基金"的固有能力。

## 核心命题

```
基金业绩 = 基金经理能力 + 策略 + 团队
```

换人后，"基金经理能力"这一项归零或发生根本变化，历史业绩的参考性随之打折。

## 为什么影响大

- 新基金经理可能有不同的投资风格、风险偏好、选股逻辑
- 投资者此前基于历史业绩做出的判断，建立在对前任基金经理的信任上
- 风格转换可能导致基金不再符合投资者原有的资产配置计划

## 边界条件

| 情形 | 影响程度 |
|------|---------|
| 基金经理独立决策型 | 影响极大，历史业绩基本归零参考 |
| 强投研团队支撑型 | 影响较小，历史业绩仍有一定参考价值 |
| 策略体系成熟公司 | 中等影响，团队能力部分弥补个人更替 |

**判断要点：** 需要了解该基金经理是"个人英雄"还是"团队产物"——这通常反映在基金公司的投研文化、决策流程透明度上。

## 实践操作

1. 在 [[晨星星级评价]] 等工具中关注基金经理任职期限字段
2. 发现换人公告后立即重新评估，而非继续沿用历史业绩判断
3. 结合 [[风格漂移]] 概念检查新经理是否维持原有风格定位
