# 三钱包分配法

## 定义

**三钱包分配法**：将收入按时间归属切分为三个独立"钱包"，每个钱包对应不同的时间维度和用途，防止资金混用导致短期目标被长期需求侵蚀。

## 核心框架

```
收入 → 三钱包：
  钱包一：过去（还债）→ 偿还历史债务
  钱包二：现在（生活费）→ 满足当期消费
  钱包三：未来（梦想基金）→ 短期刚性目标储蓄
```

## 为什么需要三个钱包？

**核心问题**：如果所有钱混在一个账户里，"未来的梦"会最先被"过去的债"和"现在的享乐"吃掉。

- 一笔混花的生活费 → 弹性支出无限扩张 → 储蓄为零
- 给每笔钱打上"时间标签" → 心理账户自然隔离 → 每个钱包独立核算

## 与分层水池策略的对比

| 维度 | 三钱包分配法 | 分层水池策略 |
|------|------------|------------|
| 分类依据 | 时间归属（过去/现在/未来） | 动用时间（1-3年/3-10年/10年+） |
| 核心机制 | 心理账户隔离 | 风险层级配置 |
| 适用场景 | 收入规划 | 资产配置 |
| 关系 | 收入端的"怎么分" | 投资端的"放哪里" |

两者互补：先用三钱包法在收入端隔离资金，再用分层水池策略在投资端配置。

## 边界条件

- **收入紧约束**：如果收入连"过去+现在"都覆盖不住，三钱包只是空架子——需先解决现金流问题
- **债务优先级**：高息债务（如信用卡）应优先偿还，低息债务可延后
- **心理账户的实际执行**：需要物理隔离（不同账户/子账户），仅靠 mental accounting 不够

## 形式化表达

```
收入 = I
I = P + N + F
  P = 过去钱包（还债）≥ 0
  N = 现在钱包（生活费）≥ 生活必需
  F = 未来钱包（梦想基金）≥ 目标倒推的月储蓄额

约束：P + N ≤ I - 月储蓄额(F)
      F = 目标总金额 ÷ 目标月数
```
