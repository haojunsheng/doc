# 行权审美

## 核心定义

行业基金不是互相独立的标签，而是一组**资金审美**的表达。不同风格的基金对应了市场对不同"价值形式"的偏好：

| 基金风格 | 买的是什么 |
|---------|-----------|
| 红利 | 现在的现金流 |
| 科技成长 | 未来的想象 |
| 周期资源 | 价格潮汐 |
| 消费 | 品牌定价权 |
| 医药 | 生命需求 |
| 债券 | 安全感 |

## 方法论价值

"行权审美"提供了一个统一框架，将分散的行业分析收束为同一个逻辑：资金在不同宏观环境和市场情绪下，会偏好不同形式的价值。

- 风险偏好低时，资金审美偏向"现在能兑现的"（红利、债券、消费）；
- 风险偏好高时，资金审美偏向"未来能想象的"（科技、成长、周期）。

## 与配置的关系

真正的配置不是选名字，而是理解这些力量之间的平衡。当组合过度偏向某一审美（如全部买入红利风格）时，就面临风格切换的风险——此时需要检视组合是否缺少对应的另一审美方向的资产。
