# 上行捕获率与下行捕获率

衡量基金在涨跌行情中收益捕捉能力的两个归因指标，用于判断超额收益来源是选股能力还是市场择时。

## 定义

- **上行捕获率**：市场上涨时，基金相对市场的收益捕捉比例
- **下行捕获率**：市场下跌时，基金相对市场的收益损失比例

## 解读方法

| 组合 | 解读 |
|------|------|
| 上行捕获高 + 下行捕获低 | 选股能力强，上涨能抓住、下跌能少亏 |
| 上行捕获高 + 下行捕获高 | 风格暴露偏向进攻型，涨跌都放大 |
| 上行捕获低 + 下行捕获低 | 风格保守，或持仓与基准高度重合 |
| 上行捕获低 + 下行捕获高 | 选股能力弱，上涨没抓住、下跌也没躲过 |

## 摩根亚洲增长基金案例

- 上行捕获率：优于同类
- 下行捕获率：较差
- 结论：超额收益主要来自选股α（成长股行情中积累），而非市场择时；上行覆盖了下行

## 与夏普比率的关系

夏普比率反映整体风险调整后收益，而上行/下行捕获率揭示收益分布的非对称性。两者结合使用可以更完整理解基金经理的真实能力。
