# H1/H2/H3 假设体系

## 定义

《AI Agent 实战》深度研究计划中的三个核心可证伪假设，贯穿全部十章学习路径。这是与晨星投资学习计划中 H1/H2/H3 不同的另一套假设体系，适用于 AI Agent 领域。

## H1：上下文工程是瓶颈

> Agent 的能力瓶颈不在模型智能，而在上下文工程——固定同一个模型，只改上下文设计（消息结构、压缩、状态栏、Skills 加载），就能拉开 Agent 表现的档次差距。

**复审节点**：W7 立场文——模型变强后上下文工程还重要吗？
**反向趋势**：Agentic RL 正在把工具调用能力训进模型参数，可能压缩上下文工程的生存空间。

## H2：新名词多为既有实践重命名

> 业界流行的 Agent 新名词（Skill、harness、loop engineering）绝大多数是既有工程实践的重新命名；近一年真正"新"的东西是评估与后训练方法。

**限定**（伴读修订）：重命名并非没有价值——名词是大多数人低成本继承实践的通道；但读名词时必须带着它背后的实践问题去读。

## H3：单强 Agent 多数情况下优于多 Agent 编排

> 在当前模型能力下，多数真实任务里"单个强 Agent + 良好工具设计"优于"多 Agent 编排"；多 Agent 的价值集中在少数天然分工的场景。

**裁决节点**：W9 结尾。

## 假设驱动方法论

本计划使用 [[假设驱动学习计划-H1H2H3可证伪框架]] 的方法论：
- 每个假设配子假设（1.1, 1.2, ...）
- 每条子假设配验证方式和失败判定
- 每周产出物是假设的推进证据，而非知识笔记

## 与旧计划的关系

旧计划（[[AI Agent 深度认知学习计划]]）使用 H1-H4 四假设体系，本计划精简为 H1-H3，并将"交互"章（原计划无此独立周）纳入 W5，W6-W9 章节号整体偏移。两套计划在结构上存在差异，但内容互补。
