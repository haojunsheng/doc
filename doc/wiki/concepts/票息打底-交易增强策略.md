# 票息打底-交易增强策略

## 定义

以中高等级信用债获取稳定票息为基础收益，同时通过主动交易（信用利差交易、利率波段）增厚收益的信用债投资策略框架。

## 策略结构

```
票息打底 = 中高等级信用债 × 稳健票息
交易增强 = 信用利差交易 + 利率波段操作
总收益 = 票息打底 + 交易增强
```

**决策层次**：
1. 自上而下决定久期
2. 结合信用环境决定券种比例
3. 自下而上精选个券

## 适用条件

| 条件 | 效果 |
|------|------|
| 利率波动大 | 利率波段操作空间大，超额收益显著 |
| 信用利差波动大 | 信用利差交易机会多，增厚效果明显 |
| 利率/利差窄幅波动 | 交易空间受限，依赖票息打底和综合能力 |

## 典型案例：东方添益债券基金

- 6年年化回报4.97%，同类前2%
- 波动性高于同类平均，但夏普比率位于同类第8个百分位
- 2023年信用利差下行年份表现突出，2025年波动收窄年份仍跑赢平均

## 策略边界

- 低等级信用债票息虽高，但流动性差、违约风险高，不适合大规模操作
- 城投债利差压缩至历史低位时，需动态调整至产业债
- 若市场环境恶化（信用风险爆发），高波动性会放大损失

## 与相关概念的关系

- 与[[易方达稳健收益]]的"纯债打底（60-100%仓位）"策略形成光谱两端：前者交易更积极，后者更保守
- [[能力溢价]]解释了为何投资者接受高费率（1.36% vs 0.86%）
- [[城投债-产业债配置权衡]]是该策略在券种选择维度的具体应用
