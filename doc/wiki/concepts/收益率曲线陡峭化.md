# 收益率曲线陡峭化

## 核心定义

收益率曲线陡峭化是指短期利率下行、长期利率上行，导致期限利差扩大的现象。曲线变陡意味着短端与长端利率的差距扩大。

## 形式化表达

```
收益率曲线陡峭化 = f(短端资金面, 长端风险偏好)
→ 短端↓（资金面宽松）+ 长端↑（风险偏好提升）→ 曲线变陡
```

## 2026年2月实证数据

| 期限 | 变动 | 驱动因素 |
|------|------|---------|
| 1年期 | +2bp | 春节前资金面紧张 |
| 5年期 | -3bp | 两会稳增长预期 |
| 10年期 | -4bp | 政策预期+美伊冲突避险 |

## 2025年5月实证数据

| 期限 | 变动 | 驱动因素 |
|------|------|---------|
| 1年期（短端） | ↓5bp | 央行降准降息 → 资金面宽松 |
| 5/10年期（长端） | ↑5bp | 中美关税缓和 → 风险偏好↑ → 资金流出债市 |

**与2月的关键区别**：5月短端因降准降息而下行的幅度（↓5bp）大于2月（-4bp），而长端在5月反而上行（↑5bp），反映了风险偏好提升对长端利率的上行压力。

## 机制解析

### 短端下行的原因

央行降准降息释放流动性，资金面宽松直接压低短端利率。

### 长端上行的原因

1. **风险偏好提升**：中美关税缓和 → 投资者将资金从债市转向股市 → 长端利率上行
2. **增长预期改善**：经济数据好转预期压低长端债券需求
3. **资产配置再平衡**：机构在股强债弱格局下调整债券久期

## 对基金投资者的含义

- **纯债基金**：短端下行利好短债基金，长端上行利空长债基金
- **固收+基金**：权益敞口（股票/可转债）的贡献通常大于纯债部分
- **债券型基金选择**：陡峭化环境中，短债基金表现优于长久期纯债基金（与平坦化环境相反）

## 边界条件

**陡峭化可持续的前提**：
- 央行维持宽松货币政策
- 风险偏好持续高于避险偏好
- 无重大地缘政治冲击

**陡峭化逆转的信号**：
- 央行释放收紧短端流动性信号
- 经济数据超预期恶化（长端利率下行）
- 地缘风险升级（避险需求推动长端利率下行）

## 压缩

**一句话**：收益率曲线陡峭化是"短端看资金、长端看预期"的典型场景，理解其驱动因素有助于判断债券基金的配置时机——陡峭化时短债优于长债。
