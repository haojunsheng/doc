# 能量感系统

## 定义

一套用"能量管理"替代"意志力消耗"的自我管理框架。核心主张：倦怠不是意志力不足，而是能量管理系统崩了。

## 框架组成

```
【坏循环】自我1 / 外生驱动
低能量感 → 高目标+自我苛责 → 完不成 → 更低能量感
              ↑______焦虑·手机·自我怀疑______

【好系统】自我2 / 内生驱动
高能量感 → 小步行动 → 闭合回路(完结点+仪式) → 更高能量感
              ↑____自主感·专精感·目标感·兴趣____
```

## 五大部件

1. **关小自我1**：减少不断评判的声音，放出自我2的执行力。
2. **指标替换**：从"我够不够自律"换成"我的能量感是高还是低"。
3. **系统替代自律**：设计一套几乎不耗意志力的方法，靠闭合任务回路维持运转。
4. **内生驱动优先**：走兴趣、自主、助人、专精、目标的路径，避开挤出效应。
5. **金刚罩防护**：识别并避开手机、焦虑、自我苛责等能量大盗。

## 与意志力模型的根本区别

| | 意志力模型 | 能量感系统 |
|---|---|---|
| 问题归因 | 不够自律 | 能量管理系统崩了 |
| 解决方案 | 更狠地逼自己 | 设计让能量自动回流的系统 |
| 失败后果 | 自我苛责，恶性循环 | 系统告警信号，需调整设计 |
| 驱动力来源 | 外生（奖惩/他人期待） | 内生（兴趣/自主/目标） |

## 适用边界

本书未对"能量感"给出统一的量化定义，该概念缺乏严格的操作化测量。在高度需要纪律的场景（如投资学习），需自行判断"系统替代自律"的适用范围。
