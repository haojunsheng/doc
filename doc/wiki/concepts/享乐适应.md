# 享乐适应（Hedonic Treadmill）

人们对新的快乐水平（无论好坏）会快速适应，导致"得到X就能更快乐"的承诺永不兑现——获得之后，你回到基准线，然后继续追求Y。

## 核心论点

**资产翻倍 ≠ 更快乐**。这不是因为赚得不够多，而是因为大脑会自动适应新的财富水平，然后继续追求更多。

## 心理学基础：适应水平理论

**形式化**：享乐适应 = 适应水平理论在财务领域的表现

人们对新的快乐水平会快速适应，无论是好的变化还是坏的变化。恢复视力的人会适应光明，中彩票的人会适应财富。所以"等我有了X就会快乐"这个等式永远不会成立——因为X到来后，你会适应它，然后想要Y。

## 三个案例

| 案例 | 结果 |
|------|------|
| 盲人女孩恢复视力 | 没有更快乐，反而希望回到从前（习惯了黑暗，突然光明带来太多新责任） |
| 40岁盲人恢复视力 | 世界太刺激，经常戴眼罩走路 |
| 中彩票的人 | 没有更快乐，甚至难以接受 |

## 与大目标/小目标框架的关联

[[大目标与小目标框架]]（源：[[notes/20260614T189000--qa-春节焦虑灵魂拷问__qa.md]]）对享乐适应机制的具体应用：

- **大目标场景**：买房/升职/买车后，快感峰值通常只持续数月，随后回落至基线，触发新一轮追逐
- **小目标场景**：日常嵌入的过程性目标（如"每天读书30分钟"）因持续产生体验而非单次达成，享乐适应影响较弱
- **健康/关系类持续性目标**：享乐适应的影响显著减弱

## 与投资的关系

这是"足够"问题的底层机制。如果享乐适应存在，那：

1. 赚更多不会让人更快乐（只是暂时）
2. 控制期望比增加收入更能提升长期幸福感
3. "足够"是一个需要主动定义的词，而不是自动实现的状态

## 与退休规划的关系

[[退休满意度-财务×意义]] 用乘法公式精确刻画了享乐适应的后果：如果只有财务安全而没有人生意义，满意度趋近于零——这正是享乐适应在退休场景的终极体现：钱够之后，快感迅速消退，留下意义真空。

→ [[perma-v模型]] 是对策：通过六个维度的持续建设，减缓单一财富目标的享乐适应效应。
