# 泡沫（投资语境）

## 定义

资产价格大幅偏离实际价值的现象，通常伴随市场狂热情绪与过度投机。

## 形成机制：宏大叙事驱动模型

格兰特姆提出的泡沫形成链条：

```
宏大叙事（跨时代创新故事）
    → 情绪狂热，投资者相信"这次不一样"
    → 过度资本涌入
    → 产能过剩
    → 泡沫破裂
    → 从废墟重生（部分标的）
```

### 关键变量：叙事规模

投资故事越宏大（跨时代、改变世界），泡沫概率越高。

| 历史案例 | 叙事规模 | 结局 |
|----------|----------|------|
| 铁路 | 改变物流与地域连接 | 1840s 英国铁路泡沫破裂 |
| 无线电/电话 | 改变通信方式 | 早期大量公司消失 |
| 互联网 | 改变信息传播与商业 | 亚马逊跌 92%，80% 公司消失 |
| 人工智能 | 正在发生 | 待验证 |
