# 公募基金高质量发展行动方案

证监会发布的《推动公募基金高质量发展行动方案》，以"基准约束+费率挂钩+透明度"三管齐下，系统性扭转公募基金行业"重规模轻回报"的旧生态。方案由晨星分析师屈辰晨提炼核心看点。

## 三大核心看点

### 1. 业绩比较基准的契约化

每只基金必须设定清晰的业绩比较基准，基金经理的考核与薪酬直接与基准表现挂钩，而非传统的同类排名竞争。

**背景数据**：
- 一半主动基金干不过同类指数
- 三年期考核中，16%的基金跑输基准超10%

这意味着过去基准形同虚设，基金经理只讲收益不讲风险，导致部分基金"比个股还跌得猛"。方案将基准从"参考指标"升级为"契约锚"，是整份政策最核心的制度创新。

### 2. 风格漂移治理

方案要求基金的投资行为、产品定位、业绩考核均围绕基准展开，不得随意偏离。此前基金公司常为追热点而偏离发行时的产品宣传，投资者买"稳健"产品却实际买到激进组合。

- 方案要求制定"设定基准的指引"，产品在设计阶段便需更审慎
- 未来投资者可直接通过对比基准快速筛选基金

*边界条件*：当市场风格剧烈切换时，严格绑死基准可能限制基金经理的灵活应对能力。

### 3. 费率与业绩挂钩

跑赢基准才正常收费，跑输则降费，直接绑定投资者与基金管理人的利益。此前两轮降费已降低主动权益基金费率，此次将浮动费率与基准直接挂钩，进一步收紧利益对齐。

**核心逻辑**：业绩 > 基准 → 正常/更高费率；业绩 < 基准 → 降低费率 → 利益绑定。

*边界条件*：即使跑输基准触发降费，投资者本金可能仍在亏损，降费只是"少亏"而非"回本"。

## 核心逻辑

```
用基准约束行为 → 用费率绑定利益 → 用透明度降低筛选门槛
→ 让基金公司从"替自己赚规模钱"变成"替投资者赚钱"
```

这是对 [[烧钱抢份额]] 旧模式的系统性纠正，将基金行业的激励机制从规模驱动彻底转向回报驱动。

## 潜在风险

- **低标准基准 loophole**：若基金公司故意设低基准，基准的约束作用将大幅削弱
- **考核窗口设计**：短期（1年）与长期（3年）考核并存时，基金经理可能在考核期末刻意调整风险敞口
- **对被动基金的影响**：若指数基金基准调整，跟踪误差计算基准随之变化，可能引发混乱
- **监管执行力**：方案要求制定基准设定指引，但具体由谁制定、标准为何、违规后果如何，尚待落实
