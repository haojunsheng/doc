# 跨境理财通

跨境理财通是粤港澳大湾区居民专属的港澳基金购买通道，作为 QDII 和香港互认基金的补充出海路径。

## 基本定义

跨境理财通允许大湾区内的居民投资者通过本地银行或券商，直接购买港澳地区的公募投资基金。它是继 QDII 和香港互认基金之后，中国内地居民配置海外资产的第三条合法通道。

## 核心特征

| 维度 | 特点 |
|------|------|
| 推出时间 | 2021 年 |
| 参与者 | 仅限大湾区居民（广州、深圳、珠海、东莞、佛山、惠州、江门、中山、肇庆） |
| 渠道 | 通过本地银行/券商购买港澳公募基金 |
| 个人额度 | **300 万人民币/人**（不占用外汇额度） |
| 风控 | 设有投资比例限制，风控严格 |
| 产品数量 | **2000+ 只** |
| 投资范围 | 大中华区、**北美、欧洲、亚洲** |
| 产品类型 | 主动管理和被动管理均有 |
| 参与门槛 | 有投资经验和资产要求 |

## 在三条出海通道中的位置

在 [[QDII额度稀缺与通道选择]] 中，跨境理财通与另外两条通道形成互补：

```
出海工具箱 = QDII基金 + 香港互认基金 + 跨境理财通
          （全球覆盖）    （亚太专业）    （额度充裕）
```

- **与 QDII 的差异**：QDII 覆盖全球市场但额度紧张；跨境理财通额度充裕但地理和参与人限制严格
- **与香港互认基金的差异**：互认基金面向全国但有产品数量和销售比例限制；跨境理财通仅限大湾区但产品丰富

## 核心优势

1. **额度充足**：每人 300 万额度，且**不占用外汇额度**，与 QDII 的 920 亿美元总额度形成鲜明对比
2. **产品丰富**：2000+ 只可选，远多于互认基金的 40+ 只
3. **市场覆盖广**：不仅限于亚太，可投北美、欧洲市场
4. **类型齐全**：主动和被动产品都有

## 局限

- 地理限制：仅限大湾区 9 个城市居民
- 参与门槛：有投资经验和资产要求
- 无法直接持有美股、欧股等标的（需通过港澳基金间接配置）
