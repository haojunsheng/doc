# 理财焦虑避坑指南——忽略、简单、自动化三把刀

晨星文章提出：理财焦虑的核心机制是**信息过载引发行为偏差**，解法是三条可操作的纪律。

## 问题框架：两种错误类型

信息过载导致投资者同时犯两种错：

- **过度反应**：看到什么都想反应，频繁操作
- **过度自信**：高估自己处理这些信息的能力

这两种错误共同驱动[[concepts/追涨杀跌损益侵蚀]]。

## 三把手术刀

### 第一刀：忽略法则

**定义**：主动忽略三类信息——看不懂的、与长期目标无关的、短期预测。

**形式化**：

```
信息 ∈ {个股新闻 ∪ 复杂工具 ∪ 短期预测} → 忽略
信息 ∈ {长期趋势 ∪ 自身目标 ∪ 持仓核心} → 关注
```

**机制**：短期预测准确率≈50%，但交易费率是真扣。忽略噪音，专注核心信号。

**边界**：如果信息直接关系持仓重大变化，或职业需要深度信息，不能忽略。

→ [[concepts/信息少是优势]]：本文提供操作性落地；前者强调结构性优势，本文强调纪律性选择，两者互补。

### 第二刀：简单经验法则

**定义**：可持续执行的简单规则，胜不可复制的高收益方案。

**形式化**：

```
简单法则 → 低认知负担 → 高执行率 → 长期复利
财富密码 → 高认知负担 → 低执行率 → 爆仓风险
```

**关键洞见**："定投指数"无聊但长期有效；"财富密码"幸存者偏差，失败案例你见不到。

**边界**：规则必须贴合个人风险偏好，否则执行走样。

→ [[concepts/投资是输家的游戏]]："无聊=不操作"与本文"简单法则"论点一致。

### 第三刀：自动化

**定义**：用预设规则替代每次手动决策，跳过情绪干扰。

**形式化**：

```
行为偏差 → 追涨杀跌
自动化 → 预设规则 → 跳过情绪 → 机械执行 → 减少偏差
```

**机制**：手动操作每次都需要克服贪婪/恐惧，意志力会耗竭；自动化把储蓄从"剩多少存多少"变"先存后花"。

**边界**：极端行情下，人可能忍不住手动暂停自动化，反而踏错节奏。

## 收口论点：最难战胜的是自己

```
总风险 = 市场风险（外）+ 行为风险（内）
```

行为风险可通过纪律和自动化降低，但无法消除。[[concepts/行为代价-mind-the-gap]] 补充量化数据：Morningstar 报告显示行为代价约 2%/年。

## 开放张力

"忽略短期预测"与"极端行情下不能盲目自动化"之间存在轻微张力：若完全忽略短期信号，如何识别极端行情？建议理解为——忽略"短期方向性预测"，而非忽略"持仓组合本身的极端状态"。
