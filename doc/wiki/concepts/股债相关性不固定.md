# 股债相关性不固定

传统投资组合理论假设股债长期负相关，但这不是恒定规律——相关性会随宏观环境变化。

## 正常环境（负相关）

经济放缓 → 央行降息 → 债券收益率下降（债券价格上涨），同时企业盈利预期改善支撑股票。股跌债涨，组合稳定。

## 极端环境（正相关）

通胀上升 → 央行激进加息 → 债券价格下跌，股票估值承压。股债同跌，相关性由负转正。

## 对组合管理的意义

如果只依赖股债组合分散风险，在极端环境下会同时失去两个缓冲器。这构成了配置 [[另类投资]] 的核心动因。
