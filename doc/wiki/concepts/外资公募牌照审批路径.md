# 外资公募牌照审批路径

外资进入中国公募基金市场的准入路径，经历了从"参股小股东"到"控股"再到"全资"的三阶段演进。

## 三阶段路径

```
阶段一：合资小股东（2018年前）
  └─ 外资持股上限：49%

阶段二：控股（2018-2020）
  └─ 2018年：持股上限从49%提至51%
  └─ 2019年：摩根资管控股上投摩根（里程碑案例）

阶段三：全资（2020年4月起）
  └─ 全面取消外资所有权限制
  └─ 外资可申请独资公募牌照
```

## 审批时间线

| 时间 | 事件 |
|------|------|
| 2018年 | 外资持股上限从49%提至51% |
| 2019年 | 摩根资管控股上投摩根 |
| 2020年4月 | 全面取消外资所有权限制 |
| 2021年6月 | 贝莱德首家获牌 |
| 2022年Q4 | 路博迈、富达获批 |
| 2022年11月 | 宏利获批 |

## 关键事实

- 十余家外资递交公募牌照申请，截至2022年末仅4家获批
- 审批严格，不是递交申请就能获批
- 若政策收紧，已获批牌照可能面临股权调整

## 边界条件

- 若监管加速审批，更多外资会入场，竞争加剧
- 已获批牌照的外资机构仍可能因政策变化而调整股权结构
