# 投资计划优于市场预测

## 定义

建立基于自身财务状况、风险承受能力和投资目标的纪律性投资计划，比试图预测市场短期走势更能带来良好的长期结果。

## 形式化表达

> 投资计划 > 市场预测 → 纪律性操作 → 更好的长期结果

## 核心论点

### 市场预测为何不可靠

1. **信息不对称**：专业机构拥有信息优势，普通投资者处于劣势
2. **复杂性**：市场受多重因素影响，非线性关系使预测极具挑战性
3. **自我否定性**：有效的预测一旦被广泛采用，会改变市场行为从而自我消解
4. **幸存者偏差**：成功的预测被放大，失败的预测被遗忘

### 投资计划为何更有效

1. **纪律性**：计划提供明确的买卖标准，减少情绪干扰
2. **适配性**：计划基于个人财务状况定制，而非统一的市场观点
3. **可验证性**：计划的执行过程可回顾、可修正
4. **长期导向**：计划聚焦长期目标，不被短期波动带偏

## 与已有知识的关联

- **[[市场预测的不可靠性]]**：从负向论证"为什么预测靠不住"，本页从正向论证"应该建什么"——两者互补
- **[[买入逻辑检验]]**：计划的组成部分——买入前明确持有理由和退出条件
- **[[投资指南针模型]]**：计划的具象化工具，帮助投资者在不确定的市场中找到方向
- **[[择时的心理陷阱]]**：试图预测市场往往导致择时错误，而纪律性计划可规避此陷阱
- **[[追涨杀跌损益侵蚀]]**：无计划的投资者更容易陷入追涨杀跌，有计划的投资者可通过纪律规避

## 边界条件与张力

- **适度预测的合理性**：如果投资者有明确的择时策略（如基于估值区间的宏观择时），适度预测也可以作为计划的补充
- **计划的可执行性**：过于复杂的计划难以执行，反而不如简单的纪律性规则
- **计划的动态调整**：计划不是僵化的——当基本面或财务状况发生根本变化时，应调整计划

## 实践框架

一个完整投资计划应包含：

1. **目标设定**：投资目标、时间 horizon、收益预期
2. **资产配置**：股债比例、行业/地区分散
3. **投资标的**：具体基金/ETF 选择标准
4. **买入条件**：何时买入、买多少
5. **卖出条件**：何时卖出、什么情况下止损
6. **再平衡规则**：多久检查一次、触发再平衡的条件
7. **记录机制**：每笔决策的记录与事后复盘
