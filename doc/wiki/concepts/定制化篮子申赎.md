# 定制化篮子申赎

定制化篮子申赎是主动ETF在中国市场落地的关键制度障碍——允许非标准组合进行ETF申赎，保护主动策略机密性、降低冲击成本。

## 形式化

```
定制化篮子申赎：
允许基金经理用非标准股票组合（不一定是指数权重）进行ETF申赎
→ 提升交易效率
→ 降低冲击成本
→ 保护策略机密性
```

## 当前中国制度约束

### 标准篮子申赎模式

- 国内ETF采用"严格对标指数权重的标准股票篮子"申赎
- 申购时必须按指数权重提供一篮子股票
- 赎回时获得按指数权重的一篮子股票

### 对主动ETF的限制

```
主动策略需要灵活调整持仓
但标准篮子要求严格对标指数权重
→ 基金经理无法自由调仓
→ 主动策略被"被动化"
```

**后果**：如果中国按现有模式推出主动ETF，主动管理将被制度约束削弱，沦为"伪主动"。

## 定制化篮子的优势

| 维度 | 标准篮子 | 定制化篮子 |
|------|---------|-----------|
| 持仓灵活性 | 低（必须对标指数权重） | 高（可按策略需求调整） |
| 交易效率 | 低（需凑齐标准篮子） | 高（直接按持仓申赎） |
| 冲击成本 | 高（集中买卖推高价格） | 低（分散申赎平滑成本） |
| 策略机密性 | 低（持仓完全透明） | 高（非标准篮子保护机密） |
| 监管复杂度 | 低（规则统一） | 高（需逐只审核） |

## 对主动ETF的意义

### 解决持仓透明度反噬

定制化篮子可保护主动策略机密性，减少市场监控和跟风效应：

```
标准篮子：持仓完全透明 → 市场监控 → 跟风交易 → 反噬业绩
定制化篮子：非标准组合 → 难以监控 → 减少跟风 → 保护超额
```

### 提升策略容量

降低冲击成本后，策略容量提升：

```
冲击成本↓ → 规模容量↑ → 更适合ETF形式
```

## 边界条件

- **监管难度**：定制化篮子增加审核复杂度，监管成本上升
- **操作风险**：非标准组合增加操作难度和错误风险
- **流动性要求**：定制化篮子需要更高的流动性支持

## 与中国市场主动ETF的关系

### 现状

- 中国尚未大规模推出主动ETF
- 现有ETF均为被动指数型，采用标准篮子申赎
- 如果推出主动ETF，需制度突破

### 政策建议方向

1. **试点定制化篮子**：选择少数机构试点，验证机制可行性
2. **分层披露**：核心持仓披露+策略细节保密的折中方案
3. **逐步放开**：先从大盘风格主动ETF开始，再扩展到中小盘

## 与 [[主动ETF的结构困境]] 的关联

定制化篮子申赎是解决主动ETF结构困境的关键制度创新——通过保护策略机密性，缓解持仓透明度反噬；通过降低冲击成本，提升策略容量。

## 关键洞见

> 中国推出主动ETF的最大障碍不是"有没有好策略"，而是"制度是否允许策略灵活执行"。定制化篮子申赎是打通这一阻塞的关键阀门。
