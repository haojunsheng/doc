# 重复持仓陷阱

## 定义

持有多个基金却跟踪同一指数或重仓同一批股票，导致**分散了精力，却没有分散风险**。

## 形式化示例

- **精简前**：5只基金，3只都是沪深300指数基金
- **精简后**：1只沪深300 + 1只债券 + 1只红利

表面上持有5只基金似乎很分散，实际上3只沪深300基金的持仓高度重合，等同于集中持有一只沪深300。

## 为什么重复持仓是陷阱

1. **假分散**：持有数量多 ≠ 风险分散；风险来自底层资产的多样性
2. **费用叠加**：每只基金都收取管理费，重复持仓放大了费用侵蚀
3. **监控困难**：持仓越多越难跟踪，风格漂移越难发现
4. **再平衡失准**：重复持仓导致实际权重偏离目标配置

## 识别方法

- 用 [[晨星投资风格箱]] 检查每只基金的真实风格，确认是否有重叠
- 查看基金季报的前十大持仓，识别重仓股重合度
- 检查指数跟踪类基金的基准是否相同

## 与精简组合的关系

[[精简组合]] 是应对重复持仓的操作方法：

1. 识别重复：用持仓穿透或风格箱归因，找出跟踪同一指数的基金
2. 合并同类：保留费率最低或跟踪误差最小的一只
3. 检查错配：短期目标不应买高波动产品，长期目标不应买低收益产品
4. 重新分配：释放的资金按 [[分层水池策略]] 重新配置

## 边界条件

精简不是"越少越好"。如果每只基金跟踪不同市场或不同因子（如A股 + 港股 + 债券 + 红利），3只比1只更合理。精简的前提是**每个持仓有明确的用途**，而非单纯追求数量少。

## 与伪分散风险的关系

[[伪分散风险]] 描述了"看着分散实则集中"的现象，重复持仓是其最常见形式之一。两者互补：伪分散风险提供理论框架，重复持仓提供具体诊断工具。
