# 风格轮动与业绩反转

风格轮动导致基金业绩在顺风和逆风之间切换，是"短跑冠军陷阱"的根本成因——投资者追逐历史业绩排名选中的基金，往往恰好在风格切换时遭遇业绩反转。

## 核心机制

```
基金经理形成能力圈 → 专注擅长领域提高决策质量
         ↓
风格顺风期 → 业绩突出 → 投资者追涨申购
         ↓
风格切换 → 逆风期 → 业绩反转 → 投资者赎回/追高被套
```

## A 股市场风格轮动时间线（2012–2022）

| 年份 | 主导风格 | 说明 |
|------|---------|------|
| 2012 | 大盘 | 蓝筹主导 |
| 2013 | 中小盘成长 | "美丽中国"行情 |
| 2014 | 大盘 | 牛市启动 |
| 2015 | 中小盘成长 | 杠杆牛 + 互联网+ |
| 2016–2018 | 大盘价值 | 供给侧改革 + 低估值修复 |
| 2019–2021 | 成长 | 核心资产抱团 |
| 2022 | 价值 | 价值风格抗跌 |

## 与相关概念的关系

### 短跑冠军陷阱

[[短跑冠军陷阱]] 的数据（2017 年前十大基金 5 年后半数落后）正是风格轮动的直接后果——冠军基金往往在特定风格顺风期积累业绩，风格切换后业绩反转。

### 能力圈风险

基金经理的能力圈既是优势也是局限。专注擅长领域可以提高决策质量（顺风期），但也意味着风格切换时缺乏跨领域的适应能力（逆风期）。本文的张力在于：既强调能力圈的价值，又承认其局限性，但未给出区分"有能力但遇逆风"与"纯粹运气"的判断标准。

### 基金逆向投资无效

[[基金逆向投资无效]] 和[[短跑冠军陷阱]] 共同揭示了"基于历史业绩选基金"的无效性——买冠军和买垫底，长期表现都只有中等水平。风格轮动是这一现象的底层机制。

## 边界条件

- 风格轮动并非完全随机，与经济周期、政策环境、流动性条件相关
- 部分基金经理具备跨风格适应能力，但难以持续验证
- 风格轮动的加速（如近年新能源/AI 快速崛起）使得传统能力圈更有效范围缩短

## 开放问题

- 短跑冠军陷阱的数据仅覆盖 2017 年一个时点的大盘成长类别，在其他类别（如价值、小盘）中是否同样显著？
- 如何识别"有能力但遇逆风"与"纯粹运气"之间的区别？
