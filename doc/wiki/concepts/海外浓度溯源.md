# 海外浓度溯源

海外浓度溯源是指通过查阅 QDII 基金的前十大持仓，计算其真实海外资产占比，而非依赖基金名称中的「全球」「纳斯达克」「美国」等营销词汇做判断。

## 核心论点

晨星[[QDII"打假"！你的基金海外浓度有多高？]]一文的核心发现：**基金名字 ≠ 基金持仓**。许多名字带有「全球」或「纳斯达克」字样的 QDII 基金，实际海外持仓比例远低于预期。

## 溯源方法

1. 打开基金定期报告（季报/年报）
2. 找到「前十大持仓」或「股票投资组合」章节
3. 统计境外标的（港股、美股、其他海外市场）的权重
4. 对比基金名称所暗示的海外暴露程度

## 常见误区

| 基金名字暗示 | 实际可能情况 |
|------------|------------|
| 「全球精选」 | 可能主要投 A 股 + 港股 |
| 「纳斯达克」 | 可能只持有一两只美股科技股 |
| 「美国成长」 | 可能重仓中概股（回归 A 股风险） |
| 「亚太」 | 可能 80% 集中在日本或韩国 |

## 与[[费率悖论]]的联动

QDII 基金的综合费率通常显著高于境内基金（管理 + 托管 + 外汇转换成本）。若海外浓度低，投资者实际上支付了更高的费用却未获得真正的海外分散——这是费率悖论在 QDII 领域的具体表现。
