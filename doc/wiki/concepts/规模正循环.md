# 规模正循环

**规模正循环**是指基金业绩领先吸引资金流入，规模增长进一步强化品牌效应和市场地位，形成自我强化的正向反馈回路。这是主动管理型基金在特定市场环境下追求的理想状态。

## 核心机制

```
业绩领先 → 资金流入 → 规模增长 → 品牌强化 → 更多资金流入 → 业绩（暂时）领先
```

关键特征：
- **时间维度**：通常需要至少一年的业绩表现才能启动正循环
- **持续性依赖**：正循环的持续性取决于业绩能否维持，一旦业绩下滑，可能迅速转为负循环
- **近因效应放大**：近期业绩优异会吸引更多资金，进一步强化近因效应

## 典型案例

瑞士百达策略收益基金（2026年2月）：

| 指标 | 数值 |
|------|------|
| 2月单月净流入 | 32.7亿 |
| 今年以来累计净流入 | 80.24亿 |
| 驱动因素 | 过去一年业绩显著优于同类美元灵活配置型基金 |
| 策略特点 | 灵活配置全球股债，无固定比例约束 |

## 与相关概念的关系

### 与 [[规模激增与业绩反转]] 的关系

规模正循环是业绩反转的前置阶段。当规模增长过快超过策略容量时，可能触发 [[规模有机增长率]] 的警戒阈值，导致业绩反转。

识别信号：
- 累计净流入超过某一阈值（如6个月累计>50亿）
- 规模增长率超过历史均值
- 策略容量开始受限（如限购）

### 与 [[近因效应]] 的关系

规模正循环的心理基础是近因效应——投资者倾向于追逐近期表现优异的基金。这既是正循环的驱动力，也是其脆弱性的来源：

- 正循环建立在近因效应上 → 一旦近期业绩反转，资金可能快速撤离
- 投资者在正循环后期入场时，面临的风险收益比已显著劣化

### 与 [[配置飞轮]] 的关系

两者都是自我强化的反馈机制，但作用层面不同：

| 维度 | 规模正循环 | 配置飞轮 |
|------|-----------|---------|
| 作用主体 | 单只基金 | 投资组合 |
| 驱动因素 | 单只产品业绩 | 资产配置再平衡 |
| 持续条件 | 持续业绩领先 | 严格纪律执行 |
| 反转机制 | 业绩下滑 → 资金撤离 | 纪律失效 → 飞轮停止 |

## 投资决策启示

1. **正循环是机会也是风险**——在正循环早期入场可获得超额收益，但在后期入场面临业绩反转风险
2. **关注规模增长与策略容量的匹配度**——规模有机增长率是重要的监测指标
3. **警惕近因效应驱动的跟风行为**——正循环的加速器往往是投资者行为，而非产品基本面

## 边界条件

- 规模正循环的持续性取决于业绩能否维持，没有永久性正循环
- 当规模增长超过策略容量时，正循环可能迅速转为负循环
- 政策环境变化（如客地销售比例限制）可能打断正循环的自然进程
