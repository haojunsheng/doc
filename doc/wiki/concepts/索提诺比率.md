# 索提诺比率（Sortino Ratio）

索提诺比率是一种风险调整收益指标，专门衡量"赔钱风险"——它只用**下行标准差**（向下波动的标准差）替代传统标准差，从而区分"好波动"和"坏波动"。

## 定义

```
索提诺比率 = (组合收益率 - 最低目标收益率) / 下行标准差
```

与传统夏普比率（用总标准差）相比，索提诺比率对上涨波动不予惩罚，只惩罚低于目标水平的波动。

## 与标准差的对比

| | 标准差（夏普比率分母） | 下行标准差（索提诺比率分母） |
|---|---|---|
| 上涨波动 | 计入（惩罚） | 不计入 |
| 下跌波动 | 计入（惩罚） | 计入（惩罚） |
| 投资者直觉匹配度 | 低 | 高 |

标准差将涨得猛的基金和跌得猛的基金视为同等风险，显然不符合投资者只关心下跌的真实偏好。索提诺比率修正了这一点。

## 适用场景

- 比较同一风险类别内基金的 downside protection 能力
- 评估追求绝对收益目标的策略（而非相对指数收益）
- 晨星风险系数在其基础上做了进一步折中，参见 [[晨星风险系数]]

## 局限

- 仍需选定"最低目标收益率"（通常取无风险利率），选择会影响结果
- 对短期数据敏感，建议至少3年滚动计算
- 不如夏普比率普及，部分平台不直接提供
