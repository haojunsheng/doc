# 索提诺比率（Sortino Ratio）

索提诺比率是一种风险调整收益指标，专门衡量"赔钱风险"——它只用**下行标准差**（向下波动的标准差）替代传统标准差，从而区分"好波动"和"坏波动"。

## 定义

```
索提诺比率 = (组合收益率 - 目标收益率) / 下行标准差
```

其中，**下行标准差**仅考虑低于目标收益（通常取无风险利率或零）的收益波动，忽略高于平均水平的上涨波动。索提诺比率对上涨波动不予惩罚，只惩罚低于目标水平的波动。

## 与标准差的对比

| | 标准差（夏普比率分母） | 下行标准差（索提诺比率分母） |
|---|---|---|
| 上涨波动 | 计入（惩罚） | 不计入 |
| 下跌波动 | 计入（惩罚） | 计入（惩罚） |
| 投资者直觉匹配度 | 低 | 高 |

标准差将涨得猛的基金和跌得猛的基金视为同等风险，显然不符合投资者只关心下跌的真实偏好。索提诺比率修正了这一点。

## 与夏普比率的对比

| 维度 | 夏普比率 | 索提诺比率 |
|------|---------|-----------|
| 分母 | 标准差（全波动） | 下行标准差（仅坏波动） |
| 对上涨的态度 | 视为风险的一部分 | 不视为风险 |
| 适用场景 | 一般风险调整收益评估 | 更关注下行保护的投资者 |

- 两者都衡量每单位波动带来的超额收益
- 夏普把上涨和下跌都算作波动
- 索提诺只考虑下跌风险
- 索提诺比率更精准展示冒着"赔钱"风险获得的回报

## 局限

- 仍需选定"目标收益率"（通常取无风险利率），选择会影响结果
- 对短期数据敏感，建议至少3年滚动计算
- 不如夏普比率普及，部分平台不直接提供
- 只考虑下行风险，但上行波动也是机会成本的体现
- 下行标准差对数据质量敏感，样本期不同可能产生显著差异
- 单一指标永远不够，需结合最大回撤等指标共同判断

## 适用场景

- 比较同一风险类别内基金的 downside protection 能力
- 评估追求绝对收益目标的策略（而非相对指数收益）
