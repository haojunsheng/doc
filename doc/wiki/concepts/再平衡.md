# 再平衡

按预设股债比例回调持仓，把情绪从决策中剔除。是资产配置比率得以维持的执行机制。

## 核心机制

```
初始配置：60% 股票 / 40% 债券
→ 市场大涨：股票变成 70% / 债券变成 30%
→ 再平衡操作：卖出部分股票，买入债券，恢复到 60/40
→ 市场大跌：股票变成 40% / 债券变成 60%
→ 再平衡操作：卖出债券，买入股票，恢复到 60/40
```

本质是"高卖低买"的纪律化执行，不依赖预测，只依赖规则。

## 为什么有效

1. **剔除情绪干扰**：不再需要判断"现在买还是卖"
2. **强制逆向操作**：涨时减仓锁定利润，跌时加仓摊低成本
3. **保持风险敞口稳定**：不因市场波动而被动加杠杆或缩仓
