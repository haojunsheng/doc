# 持有期基金

设有最短持有期限的开放式基金。申购后，每笔份额在持有期到期前不可赎回，到期后可自由赎回。

## 核心机制

```
开放式基金 + 最短持有期限限制 → 限制赎回 ≠ 保证收益
```

与普通开放式基金的区别仅在于赎回约束，而非投资策略或费率结构。

## 设计意图

持有期基金是行为产品的典型形态——其核心价值不是产生更高的绝对收益，而是通过限制赎回行为来改善投资者的实际回报。

```
持有期 = 强制持有 → 减少追涨杀跌 → 降低交易成本 + 提高长期收益
```

这一机制针对的是追涨杀跌中的结构性行为偏差。

## 常见持有期

| 持有期 | 典型产品类型 | 适用场景 |
|---|---|---|
| 6个月 | 固收+持有期基金 | 中期稳健配置 |
| 1年 | 偏股型持有期混合基金 | 中长期权益配置 |
| 3年 | 长期权益持有期基金 | 长期复利积累 |

## 与持有期债基的区分

持有期债基是持有期机制在债券品种上的应用，核心目的是"用流动性换票息"，基金经理可通过配置期限稍长的信用债获取票息溢价。

持有期基金（偏股型）与持有期债基的本质差异：
- 前者限制赎回以改善投资者行为，收益来源仍是市场β+经理α
- 后者限制赎回以获得负债端稳定性，收益来源主要是债券票息

## 持有期与流动性权衡

持有期基金是不可能三角在基金产品中的直接体现：牺牲流动性，换取行为纪律收益（减少非理性交易），而非直接换取更高收益。

## 适用边界

- **适合**：有长期投资规划、能承受市场波动、不需要短期流动性的投资者
- **不适合**：有明确资金使用计划、风险承受能力较低的投资者
- **不保证**：持有期不保证正收益，仅限制赎回时点
