# FOMO行为偏差

## 定义

FOMO（Fear Of Missing Out，害怕错过）是投资者看到某资产上涨后追高买入的行为偏差，推高估值后必然导致大幅回落。这是各市场的普遍现象，被晨星亚洲策略师Kai Wang明确标注为"当前投资者最该警惕的行为偏差"。

## 形式化表达

```
FOMO循环: 看到涨 → 追高 → 估值极高 → 大幅回落
```

## 与羊群效应的区分

| 维度 | 羊群效应 | FOMO行为偏差 |
|------|---------|-------------|
| 层次 | 宏观群体行为 | 微观心理机制 |
| 驱动 | 跟随群体决策 | 害怕错失收益的焦虑 |
| 焦点 | 资金流向 | 个体心理冲动 |
| 关系 | FOMO是羊群效应的心理动因之一 | 羊群效应是FOMO的集体表现 |

FOMO是羊群效应的微观心理机制，聚焦于"看到涨→追高→估值极高→大幅回落"的个体决策链条。

## 典型案例

**泡泡玛特/Labubu案例**：
- Labubu火爆 → 投资者追母公司股票 → 估值推极高 → 股价大幅回落
- 这不是个案，是各市场的普遍现象

## 与AI投资热潮的关系

当前AI热潮中，FOMO表现为：看到AI相关标的上涨 → 追高买入 → 估值推高 → 回调风险积累。Preston明确指出"只有当AI真正推动实体经济效率提升时，估值才站得住"，暗示当前存在FOMO驱动的估值泡沫。

## 对抗工具

- **长期视角过滤噪音**：用10年维度评估可持续性，而非跟风短期爆发
- **稳中求进框架**：不预测、留现金、控集中度、看长期
- **意识到FOMO的存在**：识别自己是否正在被FOMO驱动

## 边界条件

- 如果趋势持续，FOMO可能短期获利，但长期大概率亏钱
- FOMO本身是正反馈循环，越追越高、越涨越追
