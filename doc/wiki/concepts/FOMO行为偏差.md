# FOMO行为偏差

Fear Of Missing Out（错失恐惧症）是投资者在看到某资产上涨后产生的焦虑情绪，驱动非理性追高买入的行为偏差，推高估值后必然导致大幅回落。这是各市场的普遍现象。

晨星亚洲策略师 Kai Wang 明确标注其为"当前投资者最该警惕的行为偏差"。

## 核心表现

- 看到别人赚钱后急于入场
- 害怕"错过一波行情"导致恐慌性买入
- 在估值偏高时仍选择追涨
- 纠结于"上车还是不上车"的精确择时问题

"上车还是不上车"本身就是一个典型的FOMO体现——投资者纠结于择时，而非关注长期配置纪律。

## 形式化表达

```
FOMO循环: 看到涨 → 追高 → 估值极高 → 大幅回落
```

## 与羊群效应的区分

| 维度 | 羊群效应 | FOMO行为偏差 |
|------|---------|-------------|
| 层次 | 宏观群体行为 | 微观心理机制 |
| 驱动 | 跟随群体决策 | 害怕错失收益的焦虑 |
| 焦点 | 资金流向 | 个体心理冲动 |
| 关系 | FOMO是羊群效应的心理动因之一 | 羊群效应是FOMO的集体表现 |

FOMO是羊群效应的微观心理机制，聚焦于"看到涨→追高→估值极高→大幅回落"的个体决策链条。

## 典型案例

**泡泡玛特/Labubu案例**：
- Labubu火爆 → 投资者追母公司股票 → 估值推极高 → 股价大幅回落
- 这不是个案，是各市场的普遍现象

**AI投资热潮**：
- 看到AI相关标的上涨 → 追高买入 → 估值推高 → 回调风险积累
- Preston指出"只有当AI真正推动实体经济效率提升时，估值才站得住"，暗示当前存在FOMO驱动的估值泡沫

## 与择时思维的关联

[[美股现在上车还来得及吗]]（晨星中国）一文指出，"上车还是不上车"的问题本身就是一个典型的FOMO体现。

- [[择时的心理陷阱]]：FOMO是择时陷阱的一种具体形式
- [[应对优于预测]]：用纪律应对不确定性，而非预测市场
- [[择时成本四维分解]]：FOMO导致的追涨行为带来额外的择时成本

## 化解方式

- **配置思维替代择时思维**：确保随时在车上，而非猜测何时上车
- **长期视角过滤噪音**：用10年维度评估可持续性，而非跟风短期爆发
- **稳中求进框架**：不预测、留现金、控集中度、看长期
- **承认预测的不可能性**：2022年底最乐观机构也只预期个位数涨幅，结果纳指涨55%
- **建立投资纪律**：减少情绪驱动决策
- **意识到FOMO的存在**：识别自己是否正在被FOMO驱动

## 边界条件

- 如果趋势持续，FOMO可能短期获利，但长期大概率亏钱
- FOMO本身是正反馈循环，越追越高、越涨越追
