# 贝塔（Beta）

**贝塔（Beta）**是衡量投资组合相对于市场整体波动性的量化指标，代表"跟随市场波动获得的收益"，即可被被动获取的系统性风险补偿。

## 核心定义

贝塔由威廉·夏普在 1960 年代提出，作为收益分解框架的一部分：

```
总收益 = 贝塔收益（市场风险补偿）+ 阿尔法收益（超额能力）
```

贝塔收益的本质是"躺平"——只要承担市场风险，就能获得市场平均回报，无需选股或择时。

## 贝塔系数

贝塔系数（β）衡量基金相对于基准的波动性：

| β 值 | 含义 | 风险特征 |
|------|------|---------|
| β > 1 | 比基准更激进 | 波动大于市场，上涨时更猛，下跌时也更猛 |
| β = 1 | 与基准同涨同跌 | 波动与基准一致 |
| 0 < β < 1 | 比基准温和 | 波动小于市场，相对稳健 |
| β = 0 | 与市场无关 | 如国债等无相关性资产 |
| β < 0 | 反向波动 | 罕见，与基准走势相反 |

## 飞猪理论

雷军的名言"只要站在风口，猪也能飞"常被用来比喻贝塔——风（市场上涨）是贝塔，猪（基金/投资者）能否飞起来取决于是否站在风口上，而非自身能力。

> "只要在这个市场中，谁都无法规避贝塔，也就是我们说的系统性风险。"

## 实践含义

- 贝塔是**可低成本获得**的收益来源：通过宽基指数基金/ETF即可
- 追求高贝塔意味着接受高波动；追求低贝塔意味着接受低波动
- 不要买"高贝塔、负阿尔法"的基金——风险高且无超额收益
