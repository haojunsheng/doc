# 四种算法思想光谱

## 核心论点

四种算法思想（贪心 / 分治 / 回溯 / 动态规划）是一条光谱而非四个孤岛。

## 光谱定义

| 维度 | 贪心 | 分治 | 回溯 | 动态规划 |
|------|------|------|------|----------|
| **子问题重叠** | 无 | 无 | 可能有 | 有 |
| **需要全局最优证明** | 是 | 否 | 否（穷举） | 否（最优子结构） |
| **思考方式** | 每步局部最优 | 分解→合并 | 枚举+剪枝 | 状态转移 |
| **典型问题** | Huffman编码、跳跃游戏 | 归并排序、快速排序 | 八皇后、全排列 | 编辑距离、背包问题 |

## 关键区分

- **贪心 vs DP**：贪心每步局部最优且无需回头；DP 需要回头看历史状态。证明不了贪心正确性 → 换 DP
- **回溯 vs DP**：回溯是"穷举+剪枝"；DP 是"有重复子问题的回溯+状态表"
- **分治 vs 回溯**：分治子问题不重叠；回溯子问题可能有重叠（此时退化为 DP）

## DP 的三步路径

1. **回溯**：暴力枚举所有可能
2. **记忆化搜索**：记录已计算的子问题结果，避免重复计算
3. **递推**：从底向上填表，消除递归开销

禁止直接看题解，必须走通这三步才能真正理解 DP。

## DP 三要素

1. **最优子结构**：大问题的最优解包含子问题的最优解
2. **无后效性**：未来状态只与当前状态有关，与如何到达当前状态无关
3. **重复子问题**：存在重叠子问题，值得用状态表缓存

其中**状态定义**是唯一真正难的部分，没有机械流程，需要通过"回溯→记忆化→递推"的路径来推导。

## P7 面试标准

DP 能达到 Medium 稳定 AC、Hard 有思路，即满足 P7 面试要求（王争手册原话：掌握标志就是 LeetCode Medium）。
