# 生命周期基金

随年龄自动调整股债比例的基金——目标日期工具，用规则替代人工再平衡。

## 核心机制

生命周期基金（Target Date Fund）的核心设计：投资者在买入时选择目标年份（如"2040 retire"），基金随着目标日期临近，自动降低股票比例、提高债券比例。

```
年轻 → 目标日期远 → 高股票比例（进取）
中年 → 目标日期渐近 → 逐步降低股票比例
退休 → 目标日期到达 → 以债券为主（保守）
```

## 与手动配置的关系

- 手动配置：自己设定股债比，定期手动再平衡
- 生命周期基金：自动执行股债比调整，省去手动操作

本质相同，区别在于谁来做再平衡——人还是基金管理人。

## 适用场景

- 不确定自己能否坚持定期再平衡
- 希望"设置后不管"的懒人配置
- 有明确退休目标但缺乏时间管理组合

## 局限

- 每个人的风险承受力和财务状况不同，统一的目标日期曲线不一定适合所有人
- 基金管理团队的能力差异影响实际表现
- 不能完全替代对自身风险偏好的判断
