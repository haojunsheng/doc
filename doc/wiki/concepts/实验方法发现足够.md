# 实验方法发现足够

Carl Richards 提出的通过亲身体验替代抽象比较来发现"足够"的方法论。

## 形式化表达

```
找到"足够" = 实验 → 体验 → 反馈 → 调整 → 再体验（循环）
```

## 核心思想

- 很多人说"我想要更好的生活"，但说不清"更好"是什么——因为他们在比较，而不是在体验
- 关键是"亲身体验"——别人告诉你"钱买不来幸福"没用，你得自己试了才知道对你是不是真的

## 操作方法

- 花一个月过"只花3000元"的日子，看看自己会不会更开心
- 花10万去旅行，看看这种消费是否真的带来满足
- 用小额试错代替抽象比较

## 边界条件

- 实验需要时间和金钱成本
- 如果连基本生活都紧张，"实验"就是奢侈品
- 这时候优先级应该是先保证基本需求，再谈"定义足够"
