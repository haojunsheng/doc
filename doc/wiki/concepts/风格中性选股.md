# 风格中性选股

## 定义

一种选股策略：不在成长股和价值股之间做预先的风格偏好，而是将所有股票放在统一的评估维度（预期收益率 + 确定性）下比较性价比，根据比较结果决定配置权重。风格的"漂移"是结果而非预设。

## 形式化决策逻辑

```
候选股票池（全市场）
→ 统一维度评估：预期收益率 + 确定性
→ 性价比排序
→ 性价比更高者配置更多
→ 结果：风格随市场变化灵活调整（非预先设定）
```

## 与风格偏好的对比

| 维度 | 风格中性 | 风格偏好（成长/价值） |
|------|---------|-------------------|
| 仓位分配依据 | 预期收益率+确定性 | 风格标签（成长/价值） |
| 风格切换 | 结果导向（随性价比变化） | 主动或被动跟随 |
| 业绩归因 | 可归因为选股能力 | 易被误认为风格顺风 |
| 极端行情风险 | 分散（不押注单一风格） | 集中（风格逆风时回撤大） |

## 实证案例：刘旭与大成高鑫

[[刘旭]] 在 [[大成高鑫股票]] 的管理中体现了风格中性的实践：

- **2021年前：** 偏成长（家电、电子、电力设备），持仓包括贵州茅台、宏发股份等
- **2022年底后：** 偏价值（通信、石油石化、家电），持仓包括中国移动、中国海洋石油、格力电器等
- **关键证据：** 在成长股和价值股上均展现超额收益，归因到选股能力而非风格顺风
- **业绩验证：** 9个完整年度均超越同类平均和基准，年化回报 17.26%

这与 [[业绩归因]] 中的"能力归因的有效验证"相呼应——当一只基金在成长和价值双向均获超额收益时，风格顺风的替代解释被排除。

## 关键张力

**风格中性 ≠ 保持中性仓位**。刘旭的案例表明，"中性"的含义是**无先验偏好**，而非**仓位始终均衡**。实际上，基于估值判断，组合可以从大盘成长明显漂移到大盘价值——这是主动选择，而非中性状态的维持。

## 与"集中持股"的兼容性

风格中性要求广泛覆盖所有候选股，集中持股（前十大 50%–80%）要求高度聚焦。二者的兼容性通过"个股确定性"桥接：

```
风格中性 → 广泛评估所有候选股
           ↓
       只对确定性最高的个股重仓
           ↓
       集中持股成为结果而非风险来源
```

详见 [[集中持股]] 中的双面性分析。

## 边界条件

1. 极端风格分化时，不预先押注风格会错失机会
2. 判断错误时（如将成长股误判为价值股，或对估值的判断失误），拖累业绩
3. 需要广泛的行业覆盖能力，对基金经理的研究广度要求较高
4. 风格漂移被误读为"没有风格"，可能引发投资者赎回压力
