# 关税战冲击下的基金选择框架

## 核心定义

关税战等外部冲击构成一次市场压力测试，暴露了顺风时隐藏的风险和逆风时展现的韧性。选基金的本质是寻找能穿越周期的能力，而非预测短期走势。

## 形式化框架

### 论点一：长期目标优先于短期预测

```
投资决策质量 = f(长期目标清晰度) >> f(短期预测准确度)
```

关税走向、经济数据、政策变化均高度不确定，精准预测短期市场走势概率极低。投资者在恐慌中做出的决策往往是错误的。

**边界：** 资金期限 < 1年的投资者，短期规避风险是合理的。

### 论点二：选股能力 > 行业配置

宏观预测高度不确定，但优秀的自下而上选股能力可以在任何宏观环境下创造价值。有成功应对动荡经验的团队更能在危机中保持冷静，完善的风控措施能限制下行风险，优秀的选股能力能在恐慌时发掘错杀机会。

```
应对冲击能力 = f(投资能力, 投资流程稳定性, 风控管理)
```

**边界：** 投资能力和风控是长期因素，不能保证每次危机都跑赢。

## 三类抗冲击路径

### 路径一：自下而上低估值选股（中泰星元价值优选 · 姜诚）

```
选股 = 低估值 × 竞争优势
      竞争优势中：成本优势 > 产品差异化
```

- 持股约20只，前十大50-75%，敢于重仓
- 行业集中在化工、家电、交通、建材、银行等成熟龙头
- 历史波动和下行风险始终低于同类

### 路径二：估值驱动风格中性（大成高鑫 · 刘旭）

```
风格切换信号：估值过高 → 减持成长 + 增持价值
              估值合理 → 均衡配置
```

- 用DCF与买入价格对比判断估值
- 用"企业现在能力能否应对行业未来10年需求"判断长期价值
- 9个完整年度均跑赢同类和沪深300

### 路径三：信用债打底 + 久期灵活调节（建信纯债 · 黎颖芳+彭紫云）

```
组合 = 信用债（基准100%） + 利率债（灵活调节0-50%） + 久期（1-3.5年）
风控硬约束：AAA以下 ≤ 25%，银行二级资本债 ≤ 30%
```

- 利率债性价比低时仅持有短久期信用债
- 利率债性价比高时信用债持仓可降至50%以内
- 控制高波动品种敞口

## 关税战背景数据

2025年4月美国宣布"对等关税"，对中国额外加征34%：
- 4月3日起全球股市自由落体
- 上证指数一周跌7.17%，深证成指跌10.85%
- 债市成为避风港，10年期国债收益率下行19bp

## 边界条件

1. 投资能力和风控不能保证每次危机都跑赢
2. 集中持股在选股错误时损失也大
3. 风格切换依赖基金经理估值判断——判断错误会错失机会
4. 久期调节依赖利率判断——判断错误会放大波动
5. 短期资金期限（<1年）投资者应优先考虑流动性而非抗冲击能力
