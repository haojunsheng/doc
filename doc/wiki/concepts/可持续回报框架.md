# 可持续回报框架

## 定义

在不确定的宏观环境下，放弃点位预测，通过资产配置纪律和逆向思维获取长期可持续回报的投资哲学。由晨星2026全球展望报告提出，核心是"以不变应万变"。

## 三条"不变"建议

### 1. 独立视角——买失宠资产

> 最优质的投资机会往往隐藏在暂时失宠的资产中。

这对应[[概念/市场先生]]的逆向利用：当市场情绪极度悲观时买入，而非追高热门资产。与[[FOMO行为偏差]]直接对立。

### 2. 理解周期——狂热时冷静

> 繁荣孕育萧条，抵制从众行为。

认识到任何主题（如AI）都遵循生命周期，在狂热阶段保持冷静，避免在估值高点加大暴露。[[被动AI暴露]]概念表明，即使不加码，被动投资者也已承担了一定比例的AI周期风险。

### 3. 贴合自身需求——分散配置

> 投资组合的核心意义是满足实际需求，而不是单纯追逐最高回报。

分散配置的目的在于抗冲击，而非最大化收益。这与[[应对优于预测]]的方法论一脉相承：承认不可知，用结构而非预测来应对不确定性。

## 形式化表达

```
可持续回报 = 独立视角(买失宠资产) 
          + 理解周期(狂热时冷静) 
          + 贴合需求(分散抗冲击)
```

## 边界条件

- 逆势布局可能面临阶段性亏损，需要心理承受力支撑
- 适用于长期投资者，不适用于短期择时交易者
- 不适用于单边高确定性趋势市场
