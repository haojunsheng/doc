# 可转债双重属性

可转债（Convertible Bond）兼具债券属性和股票期权属性，是其核心特征。在股债双收或股强债弱格局中，这种双重属性使其成为表现最优的券种之一。

## 形式化表达

```
可转债价值 = 债底保护 + 转股期权价值

债底保护 = min(债券面值, 市场价格)  → 下行有底
转股期权 = f(正股价格, 转股溢价率, 剩余期限) → 上行弹性
```

## 不同市场情境下的表现

### 股债双收：2025年6月

| 指标 | 涨幅 | 驱动因素 |
|------|------|---------|
| 中证转债指数 | +3.34% | 股债双重受益 |
| 偏股型基金 | +5-6% | 纯权益暴露 |
| 纯债型基金 | +0.22% | 利率下行 |

**机制**：
- A股上涨（2-5%）→ 转股价值上升 → 转债价格上涨
- 债市企稳（收益率下行）→ 债底保护稳固 → 价格支撑

**数据来源**：[[sources/5-notes--34-20260614t213808-qa-六月股债双收下的基金选择qa--cstlca]]

### 股强债弱（分化）：2025年5月

2025年5月"股强债弱"分化格局中，可转债基金延续4月趋势，再次表现最优：

| 指标 | 涨幅 | 驱动因素 |
|------|------|---------|
| 中证转债指数 | +1.75% | 股性受益（A股涨1-2%）+ 债性保护（短端↓5bp） |
| 偏股型基金 | +5-6% | 纯权益暴露 |
| 利率债基金 | -0.19% | 长端利率↑压制 |
| 中证全债指数 | -0.06% | 微跌 |

**机制**：
- A股上涨（1-2%）→ 转股价值上升 → 转债价格上涨
- 短端国债收益率↓5bp → 债底保护稳固

**数据来源**：[[sources/5-notes--08-20260614t214508-qa-五月股债分化下的基金选择qa--g62a6z]]

### 股债双杀：2026年11月

2026年11月A股上半月创十年新高后大幅回调，可转债基金表现印证了"股债双杀 → 最弱"的预测：

| 指标 | 11月表现 | 说明 |
|------|----------|------|
| 中证转债指数 | -0.69% | 所有细分券种表现最差 |
| 可转债基金 | -1.35% | 固收类中表现最差 |
| 纯债基金 | 优于-1.35% | 债底保护相对稳固 |

**机制**：A股下跌拖累转股价值，同时债市震荡走弱压缩债底保护空间，可转债在股债双杀环境中同时承受双重压力。

**数据来源**：[[sources/5-notes--35-20260614t214227-qa-11月股债双杀价值风格占优-qa--12pmtwq]]

## 适用场景边界

| 市场状态 | 可转债表现 | 原因 |
|---------|-----------|------|
| 股债双收 | 最优（+3.34%） | 双重属性全面受益 |
| 股涨债跌（分化） | 次优（+1.75%） | 股性受益，债性承压但短端保护 |
| 股跌债涨 | 次优 | 债底保护但股性拖累 |
| 股债双杀 | 最弱 | 双重属性同时受损 |

## 投资决策启示

1. **股债双收窗口期**：可转债基金是参与权益上涨的低风险方式
2. **分化预警**：若股债开始分化，需关注转债的转股溢价率变化
3. **风格判断**：成长风格占优时，转债股性部分弹性更大
4. **双杀规避**：在股债双杀预判下，应降低可转债仓位或转向纯债
