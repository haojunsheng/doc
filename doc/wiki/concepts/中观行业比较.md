# 中观行业比较

中观行业比较是一种自上而下的行业筛选框架：站在2–3年维度，按**估值、景气度、确定性**三个维度对行业进行排序，选出性价比最高的行业进行集中配置。由[[綦缚鹏]]在管理[[国投瑞银瑞利混合]]（161222）时系统应用。

## 与中观行业配置策略的区别

[[中观行业配置策略]]更强调"先选赛道再选马"的一般性方法论；[[中观行业比较]]则是其具体操作框架，核心特征在于**三维排序**和**集中+分散的持仓结构**。

## 三维排序框架

| 维度 | 含义 |
|------|------|
| 估值 | 行业当前估值是否合理，不追高估值 |
| 景气度 | 行业未来2–3年的盈利增长预期 |
| 确定性 | 行业景气向上趋势的可验证性和可持续性 |

## 持仓结构

```
核心行业：前4–5个行业，合计占50%仓位，单一行业≤20%
卫星行业：剩余50%仓位，分散到10–15个行业
```

## 与极端市场降仓的结合

当流动性、企业盈利、宏观政策出现边际恶化信号时，通过中观行业比较框架判断是否进入极端行情，必要时将股票仓位降至50%–70%。

## 代表案例

[[綦缚鹏]]管理[[国投瑞银瑞利混合]]的实践：
- 2018年初、2021年底前瞻降仓，有效控制回撤
- 换手率从300%（2022年优化前）降至200%以内，降低交易成本
- 2019年成长占优、2021年价值占优时均跑赢同类

## 适用边界

- 行业比较依赖基金经理对中观趋势的判断，判断错误会导致配置偏差
- 牛市后期（估值驱动型上涨）环境下，安全边际策略可能跑输
