# 资产久期特征

市场对长期稳定现金流的定价逻辑随利率环境和经济周期变化，这是主动基金进行资产配置时必须纳入考量的核心特征。

## 核心定义

资产久期特征（Duration Character）指不同资产对利率变化的敏感性差异，以及市场在不同经济阶段对"稳定现金流"的定价偏好变化。

## 定价逻辑的两种情境

### 经济扩张期

```
经济向好 + 利率上行 → 资金追逐成长股（业绩增长×估值提升的戴维斯双击）
红利资产（低弹性防御）→ 相对弱势
```

### 经济寻底期

```
经济放缓 + 利率下行 → 资金追逐长期稳定现金流
高股息/价值资产（久期特征稳定）→ 相对强势
```

## 杨嘉文案例

杨嘉文2023年低配红利、2024年承认误判，核心原因在于：
- 未能理解市场对长期稳定现金流的定价逻辑已发生转变
- 缺乏对[[资产久期特征]]的系统性研究
- 误将红利视为纯防御工具，忽略了其在低利率环境下的久期价值

纠偏措施：引入[[股息率-无风险利率比价模型]]，将久期特征纳入框架。

## 与久期操作的关系

[[久期操作]]是从组合构建角度主动调整久期，而[[资产久期特征]]是从资产定价角度理解久期的经济含义。两者互为表里：
- 理解久期特征 → 判断何时应拉长久期
- 久期操作 → 实现久期特征的定价优势

## 边界条件

若利率环境突然逆转（如通胀飙升），高久期资产的定价优势会快速消失，此前的框架修正可能失效。
