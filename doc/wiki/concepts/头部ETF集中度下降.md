# 头部ETF集中度下降

**头部ETF集中度下降**是指在2025年ETF市场资金流结构均衡的背景下，头部基金公司市占率系统性下降、排名6-20的中腰部基金公司市占率上升的现象。

## 量化数据

| 指标 | 变化 |
|------|------|
| 前三基金公司市占率 | 48.4% → 42.1% |
| 前十基金公司市占率 | 81.1% → 76.7% |
| 排名6-20的公司 | 市占率上升（吃到增量） |

## 驱动机制

```
资金从宽基 → 分散到债/主题/跨境
     ↓
头部公司靠宽基吃饭 → 受到冲击
中腰部公司布局债券/主题/跨境 → 吃到增量
     ↓
集中度下降
```

**典型案例**：大成基金首次进入前20，靠跨境产品 + 新发信用债产品实现突破。

## 与相关概念的关系

- [[ETF资金流结构均衡]]：本概念是资金流结构均衡在供给侧的表现
- [[费率触底后的ETF竞争格局]]：集中度下降是费率触底后竞争格局变化的体现
- [[指数内卷]]：头部市占率下降可视为指数内卷加剧的表现之一——中小公司通过差异化产品争夺流量

## 边界条件

- 若头部公司同样在债券/主题/跨境全面布局，集中度未必持续下降
- 若市场回归宽基主导，头部可能重新集中
- 集中度下降可能是暂时性而非结构性，需持续跟踪
