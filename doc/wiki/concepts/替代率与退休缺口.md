# 替代率与退休缺口

**替代率**是指退休后月收入占退休前工资的比例，是退休规划的核心变量。本文整合了世界银行 70% 底线标准、中美对比、以及收入分层逻辑（高收入 60% vs 低收入 90%）。

## 世界银行标准

- **替代率 ≥ 70%**：世界银行建议的底线，防止退休后生活质量断崖式下跌
- **70% 不是体面线**：只是防止生活质量显著恶化的最低防线，不是舒适标准
- 美国建议更高：**75-80%**

## 中国现实

- **社保替代率 ≈ 40%**（典型估算，因地区、职业、缴费年限而异）
- **结构性缺口 = 70% - 40% = 30%**
- 社保定位：「广覆盖、低水平」，设计上不扛全部养老责任

## 收入分层逻辑

| 收入层 | 所需替代率 | 原因 |
|--------|----------|------|
| 低收入 | 90% | 几乎全靠工资替代，资产收益占比极低，边际消费倾向高 |
| 中等收入 | 70% | 接近世界银行底线 |
| 高收入 | 60% | 资产收益（利息/租金/股息）占比高，对工资替代依赖低 |

**形式化**：
```
总退休收入 = 工资替代 + 资产收益 + 其他转移支付
```
- 高收入者资产收益占比高 → 工资替代率可低
- 低收入者资产收益占比低 → 工资替代率必须高

**底层逻辑**：边际消费倾向递减——低收入者每一分钱都花在必需品上，没有缓冲空间。

## 量化示例

月薪 1 万的情况：

| 项目 | 金额 |
|------|------|
| 退休前月薪 | 10,000 元 |
| 社保替代率 | 40% |
| 社保月领取额 | 4,000 元 |
| 体面替代率 | 70% |
| 体面月需额 | 7,000 元 |
| 月缺口 | 3,000 元 |
| 20 年总缺口 | 72 万元（未计通胀和医疗增长） |

## 边界条件

- 高收入者若负债高（如房贷未还清），60% 可能瞬间不够
- 低收入者若有子女大额转移支付，90% 可下调
- 如果退休前工资远高于社保缴费基数，实际替代率可能不到 30%
- 如果退休前工资低于社保缴费基数，替代率可能高于 40%

## 与 [[安全提取率]] 的关系

[[安全提取率]] 计算的是「需要多少本金才能可持续提取」（支出端）。替代率计算的是「退休后需要多少收入」（收入端）。两者互为输入：

```
知道替代率 → 知道退休后需要多少收入 → 反推需要多少本金 → 用安全提取率验证可持续提取
```

替代率是安全提取率的**输入端**，两者共同构成退休规划的上下半场。

## 与 [[养老三支柱框架]] 的关系

三支柱是填补缺口的工具框架——替代率定义了缺口有多大，三支柱定义了用什么填。参见 [[养老三支柱框架]]。

## 与 [[12000限额定位]] 的关系

[[12000限额定位]] 提到 12000 元/年远不足以支撑退休，但缺乏判断「不够」的基准。世界银行 70% 底线提供了这个基准锚点：即使把 12000 元按最优假设复利到退休，其对替代率的贡献也极其有限。
