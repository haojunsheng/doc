# 个性化风险（Personalized Risk）

个性化风险指风险并非客观量化的指标，而是高度依赖投资者个人行为、心理特征和财务处境的独特属性。

## 核心论断

> 真正的风险在数字之外。风险是极具个性化的东西，取决于你如何应对市场起伏。

## 风险承受能力的两个来源

### 问卷式自评（假设）

- 基于当前财务状况和心理预期填写的风险测评问卷
- 在牛市中完成，没有真实亏损经历
- **局限性**：不知道自己不知道自己不知道什么

### 事实校准器（熊市经验）

熊市是风险承受能力的"事实校准器"：
- 牛市测评是假设，熊市后测评是事实
- 典型情况：认为能承受30%亏损 → 实际只能承受15%
- 真金白银亏过之后，你才知道自己的真实承受力
- **核心洞见**：风险承受能力不是静态属性，是被市场经历塑造的

如果在熊市里没亏钱（因为没投资），那风险测评还是"假设"——需要用小资金先试水，逐步校准。

## 影响因素

| 因素 | 说明 |
|------|------|
| 个性 | 不同人格对波动的容忍度不同 |
| 经验 | 经历过完整周期的投资者更能承受波动 |
| 财务状况 | 现金流需求、负债水平决定风险承受能力 |
| 生命周期 | 年龄、投资期限影响风险配置 |

## 与量化指标的关系

- 标准差、索提诺比率、最大回撤等都是有用的参考工具
- 但量化指标无法替代对个人行为和财务状况的判断
- 管理风险，而不是恐惧它——找到最舒适的资产配置

## 实践启示

投资者在选择基金时，不应只看风险评级（如晨星 R1–R4），还应审视：
1. 这个波动幅度我能否承受而不做出错误决策？
2. 我的资金使用期限是否匹配？
3. 我是否有足够的现金储备应对极端情况？
