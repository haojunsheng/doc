# 风格逆风与能力不足

这是赎回决策中最关键的区分点：基金表现不佳是因为基金经理正在经历短期风格逆风，还是因为真正的能力不足？前者不一定是赎回理由，后者则是。

## 风格逆风

- 基金经理的投资流程长期稳定，只是当前市场环境不匹配其策略风格
- 例如：价值风格基金经理在大盘成长股行情中表现落后
- 特征：历史业绩显示其在不同市场环境下均有正期望收益
- 决策：等待风格轮动，而非赎回

## 能力不足

- 基金经理的投资流程本身存在问题，或持续无法适应市场变化
- 特征：3年/5年业绩持续跑输指数和同类，收益来源归因显示依赖运气
- 决策：果断赎回

## 判断方法

通过 [[三层业绩归因框架]] 中的收益来源拆分：

```
收益 = 赛道选择贡献 + 选股能力贡献
```

- 两者均为负 → 能力不足 → 赎回
- 仅赛道贡献为负但选股贡献为正 → 可能是风格逆风 → 进一步观察
- 整体业绩好但收益来源不明 → 需要穿透评估

## 与[[风格漂移]]的关系

风格漂移是基金经理主动偏离其宣称风格的行为，既可能是应对风格逆风的尝试，也可能是能力不足的表现。识别风格漂移有助于判断是短期适应还是本质变化。
