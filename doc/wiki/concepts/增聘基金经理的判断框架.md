# 增聘基金经理的判断框架

增聘（appointing additional fund managers）是公募基金常见的组织调整手段，但投资者往往本能地将"增聘"等同于"跑路信号"。正确判断增聘意图需要建立四类原因的分类框架和三个维度的交叉判断矩阵。

## 核心命题

```
增聘 ≠ 跑路；增聘原因 = {培养新人, 能力互补, 减负, 离职信号}
```

晨星数据显示，国内近四分之一基金由两位以上基金经理共同管理。增聘是风控和管理工具，而非异常信号。

## 四种增聘原因

### 1. 以老带新模式

- **机制**：增聘新人（通常是研究员/基金经理助理），原经理继续掌舵，1-2年后新人独立
- **决策权**：决策权在原经理手里，新经理分仓不足以大幅影响业绩
- **典型案例**：兴全合宜历史上多次增聘，新人合管1-2年后卸任
- **投资者应对**：观察原经理是否继续掌舵、新人背景是否为内部培养

### 2. 优势互补型增聘

- **机制**：两位经理按各自专长分工（如利率债 vs 信用债），实现1+1>2
- **核心逻辑**：经理A专长 × 经理B专长 > 单独管理
- **典型案例**：建信纯债（黎颖芳管利率债 + 彭紫云管信用债）
- **关键前提**：分工必须明确——理念冲突的两位经理会互相拖累
- **加分项**：两位经理此前在其他产品上有过类似合作

### 3. 分担工作负荷型增聘

- **机制**：原经理晋升管理岗位后精力受限，增聘分担日常投资决策
- **典型案例**：工银双利（欧阳凯升任固收总经理后，2021和2022年分别增聘徐博文和李昱）
- **与任职稳定性关系**：这正是 [[基金经理任职稳定性]] 中"行政事务挤出投研精力"机制的制度化应对

### 4. 离职信号型增聘

- **机制**：在正式卸任前密集增聘，为平稳过渡做准备
- **典型案例**：丘栋荣2025年5月密集增聘，7月宣布卸任
- **投资者应对**：需立即启动重新评估流程

## 判断矩阵

| 维度 | 以老带新 | 离职信号 |
|------|---------|---------|
| 团队稳定性 | 团队整体稳定 | 全员动荡或大面积调整 |
| 新经理经验 | 研究员/助理出身，经验浅 | 经验丰富，风格与原经理高度相似 |
| 增聘范围 | 单只/少量基金 | 所有或大部分基金密集增聘 |
| 决策权 | 原经理继续掌舵 | 原经理即将离场 |

**操作公式**：
```
团队稳定 + 新经理经验浅 → 以老带新（持有观察）
全员动荡 + 所有基金密集增聘 + 风格相似 → 离职信号（启动重新评估）
```

## 边界条件

1. **四种原因可能同时存在**——例如增聘既为了培养新人，也为老经理减负，单一判断不可靠
2. **初次合作有磨合风险**——即使不是离职信号，也需要密切观察新经理首季持仓
3. **新经理风格与原经理相似**是离职信号的强指标——但需区分"相似"与"相近风格但不同方法"

## 变动后评估框架

无论哪种增聘类型，基金经理变动后投资者应重新做功课：

```
变动后评估 = 继任者经验 + 投资流程稳定性 + 与自身目标匹配度
```

- 继任者能力：是经验丰富的老将还是新人？
- 投资流程：基金公司的投研流程是否足以支撑风格延续？
- 目标匹配：新经理的风格是否符合自己的风险偏好和投资目标？
