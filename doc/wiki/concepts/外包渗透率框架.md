# 外包渗透率框架

CXO（医药外包）行业的长期增长逻辑建立在渗透率持续提升的结构性趋势之上。

## 临床外包渗透率趋势

| 阶段 | 渗透率 |
|------|--------|
| 早期（历史基准） | 27.3% |
| 当前（2023年前后） | 51.2% |
| 目标（2032年） | 60% |

渗透率持续提升的逻辑：药企倾向于将非核心环节外包，聚焦核心研发能力，以降低固定成本、加快上市速度。

## 生物制剂占比加成

生物制剂占FDA批准药物的50%，但生产难度远高于小分子化学药，对CDMO（合同研发生产组织）的外包依赖度更高。这意味着生物制剂占比提升进一步推高CXO渗透率。

## CXO长期增长的三驱动公式

```
CXO增长 = 渗透率↑ + 生物制剂占比↑ + 药品需求↑
```

同时叠加全球药品需求增长（使用量年均+3%，支出年均+6%），构成CXO行业长期增长的基本盘。

## 注意时效性

上述渗透率数字来自晨星中国2026年6月引用的数据，实际数字随时间推移可能已变化，需以最新行业报告为准。
