# 利率债波段操作

利率债波段操作是指以利率债为主要操作标的，通过久期调整捕捉利率波动收益的主动管理策略。

## 定义

```
利率债波段操作 = 以利率债（国债、金融债等）为主要仓位
               → 根据利率预期调整组合久期
               → 捕捉利率波动带来的资本利得
               → 波动↑ + 收益弹性↑
```

与"持有到期"策略的区别：

| 维度 | 利率债波段操作 | 持有到期策略 |
|------|--------------|-------------|
| 核心目标 | 资本利得（价差） | 票息收益 |
| 久期管理 | 灵活调整（如1-5年） | 相对稳定（如2-4年） |
| 波动特征 | 高波动、高弹性 | 低波动、稳健 |
| 收益来源 | 利率判断 + 交易增强 | 票息积累 |
| 适用场景 | 利率波动大年份 | 利率稳定或下行年份 |

## 2025年4月实证：股弱债强情境下的表现

2025年4月美国关税冲击下，A股主要股指下跌，10年期国债收益率下行19bp至1.62%，利率债基金表现领跑固收内部五档：

```
固收五档排序（2025年4月）：
  利率债基金（+0.90%）> 纯债基金（+0.61%）> 信用债基金（+0.49%）> 短债基金（+0.32%）> 可转债基金（-1.29%）
```

利率债基金以+0.90%的月度涨幅领跑，印证了"国债收益率下行 → 利率债价格上涨"的直接传导机制。

## 策略特征

**收益结构**：
```
总收益 = 票息收益 + 久期操作资本利得
       → 利率债波段策略中，久期操作资本利得占比更高
```

**波动来源**：
- 利率债对利率变化敏感，价格波动大
- 久期越长，对利率变化越敏感
- 操作灵活的基金在利率波动大年份收益高，窄幅波动年份收益弱

**夏普比率优势**：
- 虽然波动高于同类中位数，但风险调整后收益（夏普比率）往往位于前列
- 说明策略在捕捉利率波动机会方面具有超额能力

## 案例数据

| 指标 | 工银纯债债券 | 万家鑫璟纯债债券 |
|------|-------------|-----------------|
| 利率债仓位 | 20-25%，最高45% | 0-40% |
| 久期范围 | 2-4年 | 1-5年 |
| 波动性 | 高于同类中位数 | 高于同类中位数 |
| 夏普比率 | 同类前10% | 同类前10% |
| 2020年排名 | — | 前2% |

**关键观察**：两只基金波动性均高于同类中位数，但夏普比率均在同类前10%——高波动被高收益充分补偿。万家鑫璟在2020年利率大幅波动年份排名前2%，体现利率债波段策略在特定市场环境下的高弹性。

## 与纯债基金策略的关系

纯债基金内部策略分化显著，可归纳为两种范式：

```
策略分化 = 信用债打底（票息导向） vs 利率债波段（交易增强导向）
```

- **信用债打底策略**：以高评级信用债为主要仓位，获取稳定票息，久期稳健
- **利率债波段策略**：以利率债为主要操作标的，通过久期调整捕捉利率波动收益

两只典型案例基金（[[工银纯债债券]] vs [[万家鑫璟纯债债券]]）展示了这两种策略的差异。

## 与固收内部五档排序的关系

利率债波段操作策略在股弱债强情境下表现最优，其+0.90%的月度涨幅超过了纯债基金（+0.61%），原因是：
1. 利率债无信用风险，纯信用下沉带来的微弱票息优势在避险环境中不被市场定价
2. 波段策略通过主动久期管理放大了利率下行带来的资本利得

## 风险与边界

- 利率判断失误时，久期操作可能拖累业绩
- 高波动特征不适合风险承受能力较低的投资者
- 窄幅波动年份收益偏弱，存在周期性
- 历史表现不代表未来，利率周期变化会影响策略有效性

## 与相关概念的区分

- [[久期操作]]：更广义的概念，指通过调整组合久期管理利率风险；利率债波段操作是久期操作的一种主动应用形式
- [[票息打底-交易增强策略]]：利率债波段操作属于"交易增强"部分，与"票息打底"形成互补
- [[信用下沉]]：与利率债波段操作相对，信用下沉是通过承担信用风险获取收益，而非利率风险

## 投资者启示

1. 理解基金的底层策略（信用打底 vs 利率波段），而非只看历史排名
2. 高波动不等于高风险，需结合夏普比率评估风险调整后收益
3. 选择与自身风险偏好匹配的基金：稳健型选信用打底，弹性型选利率波段
4. 关注利率周期变化对策略有效性的影响
