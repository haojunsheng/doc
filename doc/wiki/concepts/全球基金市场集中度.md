# 全球基金市场集中度

## 定义

全球基金资产管理规模高度集中于少数头部公司，形成"强者恒强"的市场格局，其中被动投资的兴起进一步加速了集中度提升。

## 核心数据

| 指标 | 数值 |
|------|------|
| Top 10 基金公司 | 管理全球 **51%** 资产 |
| 4400+ 家其他基金公司 | 合计管理 **49%** 资产 |
| 安硕（iShares）+ 先锋领航（Vanguard） | 合计 **28.6%** 全球资产 |
| 2024年安硕+先锋单年吸金 | 6730亿美元 |
| 美洲基金（Ameriprise） | 2024年资金净流出 |
| 普信（T. Rowe Price） | 2024年资金净流出 |
| 富兰克林邓普顿（Franklin Templeton） | 2024年资金净流出 |

## 驱动因素

1. **被动投资崛起**：被动基金凭借低费率优势持续扩张，挤压主动管理份额
2. **规模效应**：大型基金公司摊薄运营成本，进一步强化费率优势
3. **客户锁定**：历史业绩和品牌认知形成正反馈循环

## 边界条件

- 集中度提高可能降低竞争效率，但被动基金的崛起正在改变这一格局
- 美国市场被动份额（53%）远高于全球其他地区（29%），渠道结构是关键差异因素
- 欧洲和亚洲市场银行渠道仍偏好主动管理，为中小基金公司提供生存空间
