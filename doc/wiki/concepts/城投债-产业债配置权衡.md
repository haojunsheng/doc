# 城投债-产业债配置权衡

## 定义

信用债基金经理在城投债与产业债之间进行动态配置调整的策略维度。调整依据是两种债券的相对利差水平和预期收益性价比。

## 决策逻辑

```
城投债利差压缩至历史低位 → 预期收益↓ → 配置比例↓
产业债相对价值↑ → 配置比例↑
```

## 典型案例：东方添益债券基金

近两年（截至2025年），东方添益债券基金适度降低城投债配置比例、提升产业债配置比例，原因是城投债利差已压缩至历史低位，继续持有性价比不高。

## 与风格漂移的区分

此配置调整是基于市场相对价值的主动策略调整，而非风格漂移。判断标准：
- **主动调整**：有明确的市场利差/价值判断依据，随市场环境变化而调整
- **风格漂移**：偏离既定投资目标，无合理逻辑支撑

## 风险与边界

- 若城投债利差重新走阔，减少配置会错失机会
- 若产业债信用风险上升，增加配置会加大损失
- 不过度依赖单一券种，分散配置是风险控制的基本手段
