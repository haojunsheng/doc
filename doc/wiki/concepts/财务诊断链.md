# 财务诊断链

**核心论点**：理财的正确路径是从净资产出发，经记账形成诊断链，最终以三条红线（10% / 28% / 36%）判断财务健康度——这套组合把"理财"从模糊感觉变为数字诊断。

## 公式

```
财务诊断链 = 净资产(起点快照) → 记账(过程流水) → 三条红线(健康度刻度)

其中：
  储蓄率 ≥ 10%   → 健康下限（复利启动阈值）
  住房成本 ≤ 28% × 税前收入  → 防"房奴"
  总债务还款 ≤ 36% × 税前收入 → 防多债叠加压垮现金流
```

## 三层结构

### 第一层：净资产（存量快照）

净资产 = 总资产 − 总负债，回答「你此刻站在哪里」。

- 不知道负债压力（房贷余额、信用卡欠款），就无法判断结余该还债、投资还是消费。
- 净资产决定结余用途，是理财计划的第一步。

### 第二层：记账（流量诊断）

六步记账法构成操作骨架（见 [[六步记账法]]）：① 记收入 → ② 记固定支出 → ③ 记可自由支配开支 → ④ 算每月结余 → ⑤ 分析记账表 → ⑥ 评估借贷水平。

- 记账的价值是发现问题（看清钱去哪了），预算 + 调整消费 + 增加收入才是治疗（见 [[记账是诊断仪而非治疗仪]]）。
- 多份兼职 / 现金收入会使第一步失真，全链路受影响。

### 第三层：三条红线（健康度刻度）

| 红线 | 公式 | 作用 | 来源 |
|------|------|------|------|
| 10% 储蓄率下限 | 储蓄率 = 月结余 / 月税前收入 ≥ 10% | 复利启动阈值，低于此长期财富停滞 | 经验法则 |
| 28% 房贷红线 | 住房成本 ≤ 税前收入 × 28% | 防单一住房支出压垮现金流 | 美国 HUD/FHA 贷款标准 |
| 36% 总债务上限 | 总债务还款 ≤ 税前收入 × 36% | 防多债叠加，含 8% 缓冲带 | 美国 HUD/FHA 贷款标准 |

**证据强度**：中低。三条红线均为经验法则，未引用实证研究；28%/36% 源自美国贷款标准，在中国语境下适用范围需本土化验证。

## 边界条件

- 月光族：10% 储蓄率无法执行，需先解决收入端问题
- 极高收入者：10% 远低于实际需要，应提高储蓄比例
- 收入波动大（提成制）：28%/36% 应按保守月收入计算，峰值收入会失效
- 中国语境：28%/36% 源自美国，需考虑国内房贷利率、公积金、首付比例等差异
