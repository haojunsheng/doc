# 固收+策略与权益增强

在2026年债市震荡格局下，[[固收+]]产品仍被认为有空间的核心逻辑。

## 形成机制

```
A股PB估值历史中低 + 居民存款比例高
→ 权益配置需求潜在上升
→ 固收打底 + 权益增强策略有性价比
```

## 边界条件

- 若A股持续下跌或波动过大超出散户承受力，固收+可能面临赎回压力
- 依赖"赚钱效应"能否真正激活居民资金入市

## 与相关概念的关系

- 依托 [[票息策略]] 提供底座收益
- 处于 [[债市震荡格局]] 框架下的资产配置选择
