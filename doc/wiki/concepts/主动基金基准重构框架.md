# 主动基金基准重构框架

## 核心观点

评估主动基金超额收益时，应使用**同组被动基金**而非**无成本指数**作为基准。

## 基准选择的演变

| 基准类型 | 优点 | 缺点 |
|----------|------|------|
| **无成本指数** | 理论清晰、易于理解 | 投资者无法直接获得、忽略基金成本 |
| **同组被动基金** | 贴近实际、包含成本 | 需匹配基金分类 |

## 形式化表达

```
传统基准: 指数(无成本) ← 投资者不可直接获得
现实基准: 被动基金(有成本) ← 投资者实际可购买的标的
```

## 为何更贴近现实

1. **投资者实际买的是指数基金/ETF**，而非指数本身
2. **指数基金有管理费和跟踪误差**，这些成本会侵蚀收益
3. **晨星美国主动被动晴雨表采用类似方法**，已有成熟实践
4. **反映真实投资收益对比**，避免用理想化基准造成偏差

## 与[[主动基金行业胜率分化框架]]的关系

本框架为行业胜率分化分析提供了方法论基础——只有在同组被动基金基准下，才能准确评估各行业主动基金的真实超额能力。

## 边界条件

- 若某被动基金费率极高或跟踪误差大，作为基准会有偏差
- 对于超低费率ETF，与指数的差异可以忽略
