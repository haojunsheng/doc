# 能力 vs 运气

区分超额收益来自真实选股能力还是运气/因子顺风，是基金经理评价的核心难题。单从 Alpha 数字无法区分，需要结合多种信号综合判断。

## 核心困境

Alpha 的来源可以分解为三部分：

```
Alpha = 能力 + 运气 + 风格暴露
```

- **能力**：真实的选股/择时能力，可持续
- **运气**：随机性带来的短期超额收益，不可持续
- **风格暴露**：基金隐含的因子敞口（如成长、小盘），在顺风期表现为"Alpha"

问题在于：这三者在数据上高度混叠，单凭历史业绩无法可靠区分。

## 贝叶斯后验概率（晨星2017年数据）

晨星2017年研究提供了关键的贝叶斯视角：即使观察到"连续跑输10年"这一强负面信号，选到真正有能力基金经理的后验概率仍有 **45%**。

| 后验状态 | 概率 |
|----------|------|
| 有能力 | 45% |
| 平庸 | 32% |
| 没能力 | 22% |

这意味着连续跑输10年不能"一票否决"基金经理——概率分布足够分散，难以做出确定性判断。参见 [[业绩信噪比]]。

## 判断框架

| 信号 | 能力的证据 | 运气/暴露的证据 |
|------|-----------|----------------|
| 长期业绩（10年+） | 持续正 Alpha | 短期高峰后回归 |
| 投资逻辑清晰度 | 可复述、可验证 | 事后合理化 |
| 风格稳定性 | 不同市场环境下一致 | 顺风期"神"，逆风期"鬼" |
| 规模约束 | 小规模可持续，大规模衰减 | 规模扩大后 Alpha 消失 |
| 因子归因 | 排除了 SMB/HML/动量等因子后仍有残差 | Alpha 可被因子完全解释 |

## 晨星的立场

晨星等机构更倾向于把 Alpha 当作**风险收益评估指标**，而非"能力分数"。这意味着：

- Alpha 高 ≠ 基金经理能力强
- Alpha 高 ≠ 应该买入
- Alpha 应与其他指标（费率、风格一致性、投资逻辑）结合使用

## 与"阿尔法是解释剩余"的关系

正是由于能力与运气难以区分，Alpha 才必须被理解为"解释剩余"——即使我们能构建最完善的因子模型，残差中仍包含能力与运气的混合体，无法完全剥离。
