# 周期投资派

周期投资派（Period/Cyclical Investing School）是一种以短期盈利和经济周期为核心判断股票贵贱的投资方法，与 [[内生价值投资派]] 形成对照。

## 核心框架

```
股票价值 = f(短期盈利)
短期盈利 = f(经济周期)
景气度高 → 估值合理（即使PE较高）
```

## 核心主张

- 股票贵贱取决于**中短期盈利**，而盈利由**经济周期**决定
- **景气度投资**是周期派的典型操作：寻找"中短期业绩增速超预期"的公司
- 在景气股框架下，即使市盈率处于高位，只要业绩增速仍在上升，股价仍可能继续上涨

## 经典案例：宁德时代（2021）

2021 年宁德时代 PE 超过 100 倍仍被市场追捧。从周期派视角看，这不是泡沫，而是对电动车行业景气持续延长的合理定价——投资者买的是"行业景气"，而非"当前盈利"。

## 关键引用

[[巴里-瑞泰兹-barry-ritholtz]]："估值涉及价格和利润，价格已知，利润未知，经济因素决定利润。"

## 边界条件与风险

- 依赖对经济周期和行业景气的准确判断——判断错误时可能在周期顶部买入被套牢
- 与 [[低市盈率策略]] 的对照：周期派认为低 PE 可能是景气上升信号（盈利低谷），而非价值陷阱；价值派则相反
- 需要较高的市场敏感度和快速反应能力
- 周期投资派与 [[内生价值投资派]] 没有高下之分，适合不同性格和能力的人；周期派更强调对经济周期的判断和反应速度，价值派更强调对企业内在价值的独立分析（来源：[[伴读：股票估值两门派]]）

## 与其他概念的关联

- [[股价作为集体认知]] — 周期派更关注集体认知的短期变化，而非长期内在价值
- [[护城河策略]] — 周期派对护城河评估持更短视态度，更关注景气位置而非竞争优势的持久性
- [[凯恩斯-股票选美比喻]] — 周期派思维与凯恩斯"选最多人投票的"逻辑存在同构性
