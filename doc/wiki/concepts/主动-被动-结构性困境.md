# 主动-被动-结构性困境

主动基金跑不赢指数不是个别基金经理的能力问题，而是**费用、规模、市场效率三者的结构性合力**，再加上普通散户作为对手方的收割风险。同时，**投资者的行为方式**决定了无论买主动还是被动，真正影响回报的是买完之后做什么。

## 形式化

```
失败率 = 清盘/合并（~25%）+ 存活但跑输指数（~50%） → 总失败率 ≈ 75%

失败原因 = f(费用, 规模, 市场效率, 对手方风险, 投资者行为)
其中：
  费用差距 = 1.2% - 0.1% = 1.1%/年（确定的负收益）
  规模效应 = 规模↑ → 只能买大盘股 → 市场效率↑ → 超额收益↓
  市场效率 = 价格反映公开信息的程度（大盘股 > 小盘股，成熟市场 > 新兴市场）
  对手方风险 = 无能力者参与主动游戏 → 成为有能力者的猎物
  投资者行为 = 无论主动还是被动，频繁交易都会侵蚀回报
```

## 五要素详解

### 1. 费用碾压效应

主动基金平均费用率 1.2%，指数基金 0.1%，相差 5-10 倍。10 年累计差距约 12%。

- 费用是「确定的损失」，回报是「不确定的」
- 主动基金需要每年多赚 1.1% 才能打平——大多数做不到

→ [[concepts/费用是复利的反面]]

### 2. 规模困境

Morningstar 发现：规模前 25% 的基金，5 年跑输指数的概率是后 25% 的两倍。

- 小基金（10亿）→ 可以买小盘股 → 找到错误定价 → 跑赢
- 大基金（500亿）→ 只能买大盘股（苹果、微软）→ 研究覆盖度高 → 难以跑赢

→ [[concepts/规模困境]]

### 3. 市场效率

- 美国大盘股：市场效率最高 → 主动基金失败率最高
- 新兴市场/小盘股：市场效率低 → 主动管理仍有机会

### 4. 对手方风险

[[无效市场的收割风险]] 补充了第四维度：

即使在无效市场（理论上存在超额收益机会），普通散户参与主动游戏时，由于缺乏专业能力、信息和时间优势，**更可能成为有能力者的猎物而非猎手**。超额收益来自对手方失误，散户=对手方。

这一维度解释了为什么"低效市场更适合主动投资"是片面论断——它对有能力者是机会，对无能力者是陷阱。

### 5. 投资者行为

[[QA — 主动被动选择关键不在产品在行为|主动被动选择关键不在产品在行为]] 补充了第五个维度：**投资者行为**。

| 误区 | 真相 |
|------|------|
| 买被动就等于被动 | 买 ETF 却频繁交易 = 主动投机 |
| 主动一定差 | 少数基金经理能跑赢，但难识别 |
| 被动一定好 | 没有耐心和清晰目标，被动也亏钱 |

核心公式：**投资成功 = 清晰目标 + 耐心 + 抗波动能力 > 选产品类型**

主动 = 基金经理做决策；被动 = 投资者自己做决策。两者的好坏都取决于"谁在真正做决策"以及"决策质量"。

## 边界条件

- 不同类别差异大：债券基金失败率 ~50%，小盘股 ~80%
- 即使在非有效市场，大多数主动基金仍然跑不赢
- 优质主动基金（低费+小规模+跟投+稳定）的优势会随规模膨胀而消失
- 少数真正有能力的人可以在无效市场中获利（但这不代表普通人就是）
- 2024 年 10 月数据：仅 20% 主动基金过去一年战胜同类被动基金，主动成本 2.55% vs 被动 1.03%
