# 耐心-投资语境

投资中的耐心不是死扛，而是在不该动的时候不动——这是最稀缺也是最难养成的投资品质。

## 核心定义

```
耐心 = 恐慌时不卖出 + 狂热时不追高 + 平淡时不焦虑
```

耐心是一种**克制型能力**：它的表现是「不做」，而非「做」。这恰恰是人类进化本能的反方向。

## 进化根源

人类祖先在原始部落中，不行动 ≈ 死亡。进化让我们天生厌恶「什么都不做」的状态，感到焦虑并驱动我们采取行动。

但在投资中：
- 「什么都不做」往往是最好的行动
- 行动冲动（追涨杀跌）才是亏损的主要来源
- 需要克服进化给的本能，而非利用它

> 关联：[[concepts/风险厌恶的进化根源]] 从同一机制解释为什么投资者倾向于过早卖出盈利资产。

## 耐心 ≠ 死扛

如果基本面恶化了（公司失去竞争优势），卖出是正确的——这不叫「没耐心」，叫「理性决策」。耐心的边界是：

| 情形 | 正确行动 | 本质 |
|------|---------|------|
| 市场恐慌、价格下跌，但基本面未变 | 持有不动 | 耐心 |
| 市场狂热、价格大涨，但估值已严重偏离 | 不追高 | 耐心 |
| 公司基本面持续恶化 | 卖出 | 理性决策 |
| 资产配置比例偏离目标太远 | 再平衡 | 规则执行 |

## 执行难点：两种独立能力

1. **承受短期波动** — 知道该持有，但心理扛不住账面浮亏
2. **控制「落袋为安」冲动** — 赚了钱就想卖出，怕利润跑掉

多数人具备第一种能力（能判断基本面没变），但缺乏第二种能力（控制不住冲动卖出）。

> 关联：[[concepts/止盈陷阱]] 是第二种能力不足的具体表现。

## 与规则的关系

耐心本身是一种品格，但品格不可靠。[[concepts/规则对抗本能]] 提供了替代方案：用预定的再平衡规则、定投规则，让「不动」变成系统行为，而非依赖意志力。

## 收口

耐心不是等待回报的被动状态，而是主动选择不被市场情绪驱动——理解这一点，才能把耐心从「美德」变为「方法」。
