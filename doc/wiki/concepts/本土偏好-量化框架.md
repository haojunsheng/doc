# 本土偏好-量化框架

本土偏好（Home Bias）是指投资者系统性超配本国市场资产的倾向。从中国投资者的实际情况看，这种偏好已严重到错失全球主要投资机会的程度。

## 核心数据

```
中国股票占全球股市: 约3%
中国投资者QDII配比（占非货公募）: 约4%
→ 本土偏好 → 错失>90%全球股票机会
```

## 形成机制

| 因素 | 说明 |
|------|------|
| 信息优势 | 熟悉的公司更容易判断，降低了研究门槛 |
| 汇率风险规避 | 海外投资面临汇率波动，本土投资天然对冲 |
| 制度障碍 | QDII 额度、港股通等渠道仍有容量限制 |
| 行为偏差 | 对本土市场的熟悉度带来心理舒适感 |

## 量化框架

本土偏好程度可以用以下指标衡量：

```
本土偏好系数 = 本国资产配置占比 / 本国市值全球占比
```

- 若系数 > 1：存在本土偏好（超配本国）
- 若系数 = 1：完全跟随市值加权（中性）
- 若系数 < 1：逆向配置（低配本国）

中国的情况：本国股票占全球3%，但投资者实际海外配置仅4%（QDII占比），意味着本土偏好系数极高，严重超配本国。

## 与行为因素的区分

[[内地投资海外热情降温]] 描述"本土偏好上升"是市场波动期间的**行为反应**；本概念从**结构性、长期**角度论述——两者角度不同，不矛盾但需区分时序。

## 边界条件

- 本土偏好并非完全不合理：信息优势确实存在
- 但如果本土偏好导致严重偏离市值加权，则可能错失大量全球机会
- QDII 渠道的扩容是缓解本土偏好的重要制度因素
