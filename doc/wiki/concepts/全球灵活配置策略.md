# 全球灵活配置策略

## 定义

全球灵活配置策略是一种股债比例无固定约束、可根据市场环境动态调整资产配置的基金策略。典型配置区间为：股票 20%-70%，债券 15%-60%，其余为现金或其他资产。

## 核心机制

```
全球灵活配置 = 股债比例动态调整
            + 地域分散（全球配置）
            + 基金经理主观判断
            → 适应分化市场
```

## 典型案例：瑞士百达策略收益基金

| 维度 | 数据 |
|------|------|
| 2025年11月净流入 | 12 亿元（行业第一） |
| 年内累计净流入 | 99.33 亿元（行业第一） |
| 策略特征 | 全球股债灵活配置，股20-70%、债15-60% |
| 核心优势 | "东方不亮西方亮"，能同时捕捉股债机会 |

## 适用边界

### 优势场景
- 全球市场分化（股债走势不一致）
- 风险偏好处于修复期（从避险→逐险的过渡）
- 基金经理具备较强的宏观判断能力

### 劣势场景
- 全球市场齐涨或齐跌（超额收益减弱）
- 基金经理判断失误（仓位调整适得其反）
- 极端单边行情（灵活配置的"灵活"无法发挥）

## 与相关概念的关系

### 与 [[风险偏好抬升]] 的关系
全球灵活配置策略在风险偏好抬升期间表现优异，因为基金经理可以同时增加股票仓位（捕捉上涨）和保留债券仓位（防守回撤）。

### 与 [[风格漂移]] 的关系
灵活配置策略本质上具有"风格漂移"的特征——股债比例的动态调整本身就是风格迁移。投资者需区分：这是策略设计的灵活性，还是基金经理的能力不足？

### 与 [[股债冰火两重天]] 的关系
全球灵活配置是应对股债分化的策略工具——当股债走势不一致时，灵活配置可以"两头赚"。

## 投资决策启示

1. **关注基金经理的宏观判断能力**——灵活配置的核心是"灵活"，而灵活依赖于判断
2. **警惕业绩归因的复杂性**——灵活配置的收益来源难以分解为单一的β或α
3. **长期持有优于短期择时**——频繁调仓的成本会侵蚀收益
