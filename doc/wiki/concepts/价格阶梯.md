# 价格阶梯

## 定义

**价格阶梯**是将股价拆成若干区间，每个区间对应一种隐含的业务假设，替代单一目标价的分析框架。

## 为什么不用单点目标价

单点目标价只告诉你"便宜"或"贵"，价格阶梯告诉你：

> 每个价格对应的是哪种预期。

## 通用价格阶梯区间

| 价格区间 | 隐含判断 |
|---|---|
| 熊市价 | 市场只相信地板业务 |
| 修复价 | 市场相信利润锚恢复 |
| 合理价 | 利润恢复，但不给新故事溢价 |
| 成长价 | 市场开始相信天花板业务 |
| 乐观价 | 多条新曲线同时兑现 |

## 美团案例

| 股价区间 | 隐含判断 |
|---|---|
| HK$50-70 | 外卖没稳，到店也被打，利润池永久受损定价 |
| HK$70-85 | 观察区，市场押亏损收窄，但证据不足 |
| HK$85-105 | 外卖修复区，核心亏损明显收窄 |
| HK$105-110 | 过渡区，外卖修复基本打满，等到店证据 |
| HK$110-130 | 到店稳住区，本地生活利润池被重新确认 |
| HK$130-160 | 闪购跑通区，开始有成长股味道 |
| HK$160+ | Keeta、AI、即时零售等新曲线兑现 |

[[股价区间-业务条件映射]] 是价格阶梯在美团案例上的具体实现；[[四重估触发器-美团]] 定义了每个区间需要哪些前置证据来确认；[[核心假设-退出信号框架]] 与之互补，负责制定进出场纪律。

## 关联概念

- [[利润锚]]：价格阶梯中"合理价"以上的上涨，需要利润锚的改善来支撑
- [[动态-PE]]：不同价格区间的隐含 PE 不同，取决于利润质量和确定性
- [[前置信号-财报滞后性]]：价格阶梯中的每个区间需要不同的前置证据来确认
- [[经济账户vs情绪账户]]：在价格阶梯的各个区间做买卖决策时，必须区分经济账户和情绪账户的判断
