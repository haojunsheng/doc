# 理财破刚兑溢出效应

**理财破刚兑溢出效应**是指银行理财产品打破刚性兑付后，原低风险偏好资金寻找替代品种，进而推动短债ETF规模快速增长的现象。

## 传导机制

```
理财打破刚兑 → 低风险资金需新避风港
      ↓
短债ETF（波动低于权益、收益高于货基、流动性好）
      ↓
海富通中证短融ETF单只贡献债券类一半以上流入
```

**形式化**：
```
短债ETF流入 = f(理财破刚兑程度, 权益市场波动, 货基收益率差距)
```

## 关键数据

- 债券型ETF仅17只，短债仅3只但规模居首
- 海富通中证短融ETF单只贡献债券类超过50%的资金流入
- 短债ETF定位：波动 < 权益ETF，收益 > 货币基金，流动性接近货基

## 与货基的关系

| 维度 | 货币基金 | 短债ETF |
|------|---------|---------|
| 波动 | 极低 | 低 |
| 收益 | 低 | 略高于货基 |
| 流动性 | T+0/T+1 | T+0 |
| 费率 | 极低 | 低 |

短债ETF填补了理财破刚兑后"低风险+略高收益"的空白地带，对货基形成部分替代。

## 边界条件

- 若利率大幅上行 → 短债价格下跌，低波动优势被侵蚀
- 若信用风险爆发 → 短债ETF净值受损，资金回流货基
- 若理财重新推出低风险产品 → 资金可能回流理财

## 与已有研究的关系

- 与 [[concepts/货基费率侵蚀效应]] 不同：后者强调货基本身费率下降对收益的侵蚀，前者强调外部产品（理财）打破刚兑后资金的溢出效应
- 两者共同解释了低风险资产的竞争格局变化
