# 评估三维度

## 定义

评估体系由三个独立维度构成：环境 × 数据集 × 评判方法。三者缺一不可，且各自可以独立变化。

## 三维度

| 维度 | 描述 | 可选值示例 |
|------|------|-----------|
| 环境 | Agent 运行的环境类型 | API 调用环境 / 浏览器环境 / 桌面环境 / 物理环境 |
| 数据集 | 测试用的任务集合 | 公开 benchmark / 自建数据集 / 真实用户日志 |
| 评判方法 | 如何判断任务是否完成 | 规则校验 / LLM-as-a-Judge / 人工审核 |

## 两种根本评估范式

| 范式 | 适用场景 | 评判依据 | 局限 |
|------|---------|---------|------|
| 工具调用型 | 结构化任务（API 调用、数据处理） | 工具返回结果是否符合预期 | 无法评估多步推理质量 |
| 人机交互型 | 开放式任务（客服、咨询、创作） | 用户满意度 / 任务完成度 | 主观性强，难以规模化 |

**关键原则**：两种范式混用会得出错误结论——工具调用型评测得分高不代表人机交互体验好。

## 验证方式

- 各找一个适用场景，说清为什么另一种范式在该场景失效
- 跑 `chapter7/` 评估实验，建小评估集 → 跑 → 出分 → 分析一个失败 case
