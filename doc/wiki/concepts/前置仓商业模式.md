# 前置仓商业模式

**前置仓**（Front Warehouse）是即时零售中自营模式的核心载体——在靠近消费者的城市区域设置小型仓储节点，实现 30-60 分钟送达。

## 商业模式结构

```
上游供应链（品牌商/产地直采）
       ↓
前置仓（城市区域小型仓储，100-300 ㎡）
       ↓  ← 订单密度驱动人效
骑手配送（30-60 分钟达）
       ↓
终端用户
```

## 经济特性：重资产 vs 平台模式

| 维度 | 自营前置仓（叮咚/朴朴） | 平台模式（美团闪购/京东到家） |
|:---|:---|:---|
| 资产轻重 | 重资产：自建仓 + 自采库存 | 轻资产：连接商家 + 配送网络 |
| 收入模式 | 商品差价（GMV - 采购成本） | 抽佣/广告/配送费 |
| 毛利率 | 20-30%（靠自有品牌和直采） | 3-8%（抽佣率） |
| 履约成本占比 | 20-25%（规模效应可优化） | 5-10%（依赖骑手密度） |
| 扩张速度 | 慢（每城需建仓+建仓+建团队） | 快（轻资产模式，快速复制到新城市） |
| 盈利路径 | 收缩战线 + 自有品牌 + 供应链直采 | 订单密度 + 规模效应 + 广告货币化 |
| 天花板 | 受限于区域深耕（17 城级） | 全国乃至全球扩展 |

## 盈利模型（UE）

```
单均利润 = 客单价 × 毛利率 − 履约成本 − 获客分摊 − 平台运营费

前置仓参考值（2024-2025）：
  - 客单价：~57 元（叮咚买菜）
  - 毛利率：≈ 30%+（自有品牌占比 20%+拉动）
  - 履约费率：≈ 22-23%（规模效应改善，从 27% 降至）
  - 营销费率：≈ 3-4%（品牌认知建立后自然回落）
```

## 成功案例：叮咚买菜的三重路径

叮咚买菜从亏损走向非 GAAP 盈利的三重路径：

1. **收缩战线**：从全国铺开收缩至长三角 17 城，集中资源提升订单密度
2. **自有品牌**：自有品牌销售占比达 20%+，直接拉动毛利率至 30%+
3. **供应链直采**：减少中间环节，降低采购成本

核心结论：前置仓模式在经济模型上**成立**，但天花板受限于覆盖范围——跨区域扩张需依赖 UE 进一步改善。

## 与平台模式的本质差异

前置仓模式的核心矛盾：**规模效应 vs 扩张速度的权衡**。

- 前置仓必须在足够订单密度的城市才能实现 UE 转正，这意味着必须**收缩城市数量**以集中资源
- 平台模式可以通过轻资产快速覆盖更多城市，但单均利润更薄，依赖流量变现（广告、增值服务）

两家路径都在跑通，但天花板各异：前置仓是"小而美"的区域深耕，平台模式是"大而全"的全国覆盖。
