# 费率逆袭良性循环

业绩优秀的高费率产品可以通过规模效应实现费率下降和费后净收益提升的正向循环，打破"起跑费率高就注定失败"的线性判断。

## 循环机制

```
高费率产品 → 回报亮眼 → 资金流入 → 规模扩大 → 费率下降 → 净收益提升
```

## 核心证据

晨星研究发现：**期末费率与跑赢同类比例呈负相关**。这意味着：
- 业绩好的产品即使起跑时费率高，也能在过程中实现费率下降
- 规模效应是良性循环的核心驱动力
- 最终费后的净收益可能优于起跑时就低费率但业绩一般的产品

## 启动门槛

良性循环的启动需要满足：
- 产品初期回报足够亮眼以吸引资金流入
- 资金流入规模需达到触发费率下调的阈值
- 规模扩大带来的费率下降幅度需超过因规模过大产生的冲击成本

## 边界条件

若产品业绩不够亮眼到吸引足够资金，或市场风格切换导致业绩下滑，费率下降的良性循环无法启动，产品仍可能因高费率被淘汰。
