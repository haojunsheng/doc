# 均值-方差模型（Markowitz）

由 [[哈里-马科维茨-harry-markowitz]] 创立的现代投资组合理论核心模型，第一次用严格的数学方法描述了如何通过资产配置实现"更高收益、更低风险"。

## 核心命题

**组合的整体属性 > 单个资产的属性。**

投资的关键不是"选哪只股票"，而是"选哪些相关性低的资产组成组合"。

形式化表达：

```
旧范式: 投资 = 选最佳个股
新范式: 投资 = 选相关性低的资产组合
```

## 关键洞见：相关性才是核心

均值-方差模型揭示了一个反直觉的事实：两只高风险资产，如果相关性很低甚至为负，组合后的整体风险可以远低于任一单只资产的风险。

这意味着：
- 资产选择的标准从"风险低"变为"与现有持仓相关性低"
- 分散化的本质是管理相关性，而非简单地"多买几只"

## 理论边界

均值-方差模型有一个重要前提假设：**投资者只关心风险和收益两个维度**。但在现实中，投资者还关心：
- 流动性需求
- 税收影响
- 社会/伦理偏好（ESG 等）
- 心理承受阈值

这些边界条件意味着：均值-方差模型是优秀的理论框架，但不是投资决策的全部。
