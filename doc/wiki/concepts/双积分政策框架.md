# 双积分政策框架

双积分政策是中国政府通过行政手段倒逼车企电动化的核心政策机制，由燃油乘用车平均燃料消耗量积分（CAFC积分）和新能源汽车积分（NEV积分）两部分组成。

## 运行机制

```
双积分 = 每年提高新能源比例 → 不达标 → 买积分(比亚迪/特斯拉)或受罚
```

- 车企每年必须提高新能源积分比例
- 不达标可向比亚迪、特斯拉等积分盈余企业购买
- 本质是用行政手段推动电动化

## 政策效果

- 混合动力被排除在积分奖励之外，纯电受偏爱
- 车企必须销售更多纯电车以满足积分要求
- 积分买卖机制为比亚迪、特斯拉等头部车企创造了额外收入

## 边界条件

- 若政策放松或积分价格下降，车企电动化动力可能减弱
- 考核收紧程度决定政策倒逼力度
