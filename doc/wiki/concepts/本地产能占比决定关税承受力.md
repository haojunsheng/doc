# 本地产能占比决定关税承受力

## 核心定义

衡量一家中国企业对美国关税冲击的脆弱程度，最直接的指标不是"美国营收占比"，而是"美国本地产能占比"。本地化生产比例越高，关税冲击越小。

## 形式化判断

```
关税承受力 ∝ 美国本地产能占比 / 美国营收依赖度

海尔: 60%本地产能 / 30%美国营收 → 承受力强
美的: 5%本地产能 / 7-8%美国营收 → 承受力弱
```

## 关键洞察

- 表面看[[海尔]]美国营收依赖度更高（30% vs 美的7-8%），但实际关税冲击更小
- 核心变量是本地化生产能力，而非营收地理分布
- 2018年贸易战教训促使家电行业提前完成海外产能转移

## 边界条件

- 若美国收紧原产地规则，对海外组装环节也加征关税，则本地产能占比的保护作用减弱
- 若关税税率进一步升级，原有比例阈值需要重新评估
