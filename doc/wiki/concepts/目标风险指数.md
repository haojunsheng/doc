# 目标风险指数

以目标波动率为约束，动态调整资产比例使组合实际波动率贴近目标值的被动指数。

## 设计逻辑

设定一个年化波动率目标（如 10%），根据实际波动率与目标的偏离方向反向调整股债比例：
- 实际波动率 > 目标波动率 → 降低股票仓位
- 实际波动率 < 目标波动率 → 提高股票仓位

细分资产内部再用风险平价模型计算权重。

## 国内代表：中证目标风险系列

| 档位 | 目标年化波动率 |
|------|--------------|
| 保守 | 3% |
| 稳健 | 5% |
| 平衡 | 10% |
| 积极 | 15% |

## 核心优势

目标风险指数直接约束组合整体风险水平，弥补了恒定比例指数在波动率 regime shift 期间风险漂移的缺陷。

## 边界条件

历史波动率 ≠ 未来波动率，极端行情下实际风险可能大幅偏离目标。目标风险管"总波动多大"（结果导向），与[[风险平价]]管"每类资产对风险的贡献相等"（结构导向）构成互补而非替代关系——中证目标风险系列在细分资产内部就采用了风险平价模型。
