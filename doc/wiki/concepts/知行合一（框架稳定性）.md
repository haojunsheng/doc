# 知行合一（框架稳定性）

## 定义

投资框架稳定性指基金经理在较长周期内保持一致的投资方法论和决策逻辑，不因市场短期波动或风格轮动而偏离核心策略。"知行合一"强调框架不仅清晰，而且被持续严格执行。

## 形式化表达

```
知行合一 = 清晰框架（选股标准 + 风险控制参数）
         + 持续反思（定期评估策略有效性）
         + 团队支持（投研文化与制度保障）
         + 时间沉淀（框架在多个市场周期中验证）
```

## 关键案例：周云与东方红新动力

周云自2015年9月管理东方红新动力以来，核心策略框架保持稳定，仅在2022年优化了风险控制参数（增加持股数、降低集中度），体现了知行合一的实践：

- **策略稳定性**：近10年核心框架未变，仅微调风险控制参数
- **纪律性执行**：换手率长期维持在100%左右，卖出和买入标准清晰且一致
- **团队支撑**：东方红投研文化为策略执行提供制度保障

## 知行合一 vs 策略漂移

| 维度 | 知行合一 | 策略漂移 |
|------|---------|---------|
| 框架清晰度 | 明确、可描述 | 模糊、事后解释 |
| 执行一致性 | 多周期验证 | 随市场风格切换 |
| 可预测性 | 高 | 低 |
| 超额收益来源 | 框架执行力 | 不可归因 |

## 局限与注意事项

- **过度稳定可能错失机会**：市场结构性变化时，僵化的框架可能导致系统性偏离
- **规模约束**：框架稳定性假设资金规模在策略容量范围内；规模膨胀后可能被迫偏离
- **归因偏差**：成功归因于"知行合一"可能忽略运气成分和系统性风险暴露
