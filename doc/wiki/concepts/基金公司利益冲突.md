# 基金公司利益冲突

基金公司的商业模式决定了其利益与投资者利益存在结构性偏差——这解释了为何基金发行往往与市场高点同步。

## 利益结构分析

```
基金公司利益 = 规模 × 管理费费率
投资者利益   = 净收益最大化
```

两者并不等价。基金公司通过管理费收入盈利，而管理费与规模正相关，与业绩相关性较弱。这导致：

- 高点发行能募集更多资金（投资者追涨）
- 但高点发行的基金业绩往往最差
- 基金公司的销售节奏与市场高点对齐，而非与投资者最佳买入时机对齐

## 表现形态

- **扎堆发行**：牛市高点频繁发行新基金，规模激增
- **业绩分化**：高点发行的基金长期表现普遍弱于低点发行的基金
- **限购保护**：部分基金公司在高点主动限购，以保护投资者利益（同时也保护了存量份额的净值）

## 与 [[尾随佣金]] 的关系

基金公司的利益冲突不仅体现在发行节奏上，还通过销售渠道的尾随佣金机制进一步放大。[[尾随佣金]]是渠道推荐行为的扭曲机制——渠道有动机推荐尾佣高的产品而非最适合的产品，使投资者买到"最会营销的产品"而非"最适合的产品"。

## 制度应对：投顾份额

[[投顾份额]]和[[清洁份额]]是针对尾佣机制的制度解法——通过免尾佣、透明收费，让投顾收入与投资者利益对齐。详见 [[投顾份额]] 和 [[清洁份额]] 页面。

## 投资者应对

- 警惕市场高点时的"爆款基金"热潮
- 关注基金公司的销售节奏是否理性
- 将基金公司利益冲突纳入投资决策框架，而非仅看历史业绩
- 优先选择费率透明、利益冲突少的份额类型（投顾份额/清洁份额）

## 与 [[期望管理]] 和 [[金融行业的结构性缺陷]] 的关系

[[期望管理]]强调的是投资者对自身收益预期的管理，而[[金融行业的结构性缺陷]]是从更宏观角度指出行业激励机制的系统性问题。[[基金公司利益冲突]]是这两者的具体体现——基金公司的激励机制本身就是结构性缺陷的一部分。
