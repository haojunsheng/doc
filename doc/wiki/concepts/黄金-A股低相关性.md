# 黄金-A股低相关性

**黄金-A股低相关性**指黄金与A股市场的价格变动关联性较弱（三年期相关系数约0.37），这一特性使黄金成为A股组合中有效的风险分散工具。

## 核心数据

| 资产对 | 三年期相关系数 | 解读 |
|--------|---------------|------|
| 黄金 ↔ A股 | ~0.37 | 低相关，有效分散风险 |
| 黄金 ↔ 债券 | 更低 | 所有主要资产类别中最低之一 |

## 配置意义

```
黄金↔A股: 相关系数0.37(低)
→ 将黄金加入A股组合 → 降低整体风险 + 改善风险调整后收益
```

这是资产配置逻辑的核心：通过将低相关性资产放入同一组合，可以在整个投资周期里降低组合整体波动，提高夏普比率。

## 边界条件

- **极端流动性危机时相关性可能上升**：当市场出现系统性恐慌时，所有资产类别可能同步下跌（流动性挤兑），此时黄金的低相关性优势暂时失效
- **相关性是历史统计量，不保证未来**：若美元信用体系发生根本性变化，黄金与A股的相关性结构可能重构
