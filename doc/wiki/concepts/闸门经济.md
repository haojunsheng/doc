# 闸门经济

闸门经济是指：当某种资产的需求集中涌向一个供给刚性的合规通道时，通道本身从服务工具变成稀缺商品，产生独立的定价层——即通道价格（限购、溢价）与资产价格（底层净值）同时存在且相互扭曲。

## 形成机制

```
居民海外配置需求上升
    ↓
QDII额度供给刚性（无法快速扩容）
    ↓
场外产品限购/暂停申购
    ↓
资金转向场内ETF
    ↓
场内溢价上升（一级市场套利失灵）
    ↓
溢价成为独立定价层，与底层资产净值脱钩
    ↓
通道本身具有了稀缺商品属性
```

## 核心命题

> 闸门经济 ≠ 资产便宜。通道拥挤说明需求旺盛，但不说明底层资产被低估。

普通人容易混淆两件事：

1. **底层资产的价值**：纳指100是好资产，历史表现强。
2. **通道的可得性**：通过QDII买到的难易程度和额外成本。

闸门经济的危险在于，第2件事会被误读为第1件事的信号——"限购=稀缺=好资产=值得抢"。

## 特征识别

| 信号 | 说明 |
|---|---|
| 多只同类产品同时限购至百元级 | 通道整体拥挤，非单一产品问题 |
| 场内ETF溢价持续>3% | 套利机制失灵，通道税已显性化 |
| 媒体报道集中讨论"抢额度" | 需求端集体行动形成正反馈 |
| 额度新增但迅速被瓜分 | 供给弹性为零，需求远超增量 |

## 与 [[concepts/秩序搬运]] 的关系

闸门经济是秩序搬运框架在通道层面的具体展开。秩序搬运说"QDII不创造阿尔法"，闸门经济解释"为什么QDII在拥挤时会变成坏交易"——因为通道税（溢价+限购成本）侵蚀了底层资产的实际收益。

## 与 [[concepts/S曲线阶段判定]] 的关系

闸门经济描述的是通道自身的S曲线位置：从"可用工具"进入"稀缺商品期"。底层资产可能同时处于完全不同的阶段（如纳指100在成熟再加速期），两条S曲线不同步是闸门经济的本质。

## 投资决策意义

1. 区分"通道税"和"资产价格"：溢价和限购是通道成本，不是估值信号
2. 不要在闸门经济高峰期买入：拥挤的入口意味着你正在为稀缺性付费
3. 关注替代通道：如果有更低摩擦的合法路径（如港股通中的中概互联网、境外账户直接买QQQ），优先选择
4. 小额纪律性配置：当通道受限时，把每日限额当作微型定投，而非建仓工具
