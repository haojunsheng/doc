# 黄金纳入FOF基准

**黄金纳入FOF基准**指2025年Q3超80%的FOF在业绩基准中引入黄金（Au99.99）的结构性变化，是[[concepts/FOF配置转向框架]]五大转向之一。

## 核心机制

```
新规鼓励多元化基准 → 80%+ FOF基准加入黄金（Au99.99）
```

## 实证数据

- FOF实际持有黄金基金总市值达28亿元
- [[entities/华安易富黄金ETF]] 持仓17.3亿
- 部分FOF还加入商品期货指数作为基准组成部分

## 与"黄金保险定位框架"的关系

[[concepts/黄金保险定位框架]]将黄金定位为"保险"，但FOF实际将其 as 配置品种纳入基准。这说明：
- 保险是功能定位（针对普通投资者）
- 配置是操作行为（针对专业投资者）

两者并不矛盾，而是互补视角。专业投资者同样认可黄金的保险价值，并通过纳入基准来制度化管理这一配置。

## 边界条件

若金价持续回调或FOF业绩基准不再考核黄金配置，持仓可能下降。
