# 地缘政治溢价

## 核心定义

地缘政治溢价是指因地缘政治风险上升，大宗商品（尤其是原油和黄金）价格被推高的额外溢价部分。这种溢价源于市场对供应中断和避险需求的预期。

## 形式化表达

```
地缘政治风险↑ → 大宗商品涨价预期↑ → 地缘政治溢价↑
```

## 2026年1月实证

| 资产 | 涨幅 | 驱动因素 |
|------|------|---------|
| 布伦特原油 | +14.64% | 美伊对峙升级、中东局势紧张 |
| 伦敦黄金 | +13.36% | 美联储降息预期 + 避险需求 |
| 有色金属板块 | >+15% | 地缘冲突 + AI算力需求双重驱动 |

## 传导路径

```
地缘政治风险（美伊对峙、中东局势）
    → 原油供应担忧 → 布伦特原油↑14.64%
    → 避险需求↑ → 伦敦黄金↑13.36%
    → AI算力需求↑（铜、铝等）→ 有色金属板块↑
    → QDII商品基金↑17.15%
```

## 双重驱动机制

1月有色金属板块的上涨有两条独立驱动链：

```
链1：地缘政治溢价 → 大宗商品涨价预期 → 有色板块↑
链2：AI算力扩张 → 铜/铝工业需求↑ → 有色板块↑
```

两条链叠加，形成"地缘+产业"双重驱动的领涨格局。

## 边界条件

- 若地缘冲突缓解，原油和黄金价格可能快速回调
- 若美联储降息预期逆转，黄金溢价可能被压缩
- AI算力需求对有色金属的实质需求量级仍需量化验证
