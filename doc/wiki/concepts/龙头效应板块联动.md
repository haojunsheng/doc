# 龙头效应板块联动

当行业龙头的业绩预期大幅下调时，市场会通过估值重估机制将悲观预期传导至整个板块，形成"龙头跌→板块跟跌"的联动效应。

## 传导机制

```
龙头下调预期
  → 市场重新评估赛道增速
  → 板块估值倍数压缩（杀估值）
  → 全板块同步下跌（全线飘绿）
  → 市场情绪逆转（"旱涝保收"→"也会变脸"）
```

## 药明生物案例（2023年）

- 药明生物：国内及全球CDMO龙头，322只基金持有，43只持仓超5%
- 事件：下调业绩目标，单日跌23.79%
- 结果：CXO板块全线飘绿
- 机制：龙头悲观预期重估整个赛道，基金持仓集中放大了联动幅度

## 与[[杀估值vs杀盈利]]的关系

药明生物事件同时涉及杀盈利预期（业绩目标下调）和杀估值（板块估值倍数压缩）。龙头事件触发的是"盈利预期下修→估值倍数收缩"的共振，比单一机制杀伤力更强。

## 反向情景

若龙头业绩超预期而非不及预期，同样会带动板块估值扩张——这是龙头效应的对称面。
