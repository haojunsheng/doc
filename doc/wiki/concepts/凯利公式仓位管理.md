# 凯利公式仓位管理

凯利公式（Kelly Criterion）是从赌场数学迁移到投资领域的仓位管理框架，其核心目标是：**在永不归零的前提下，实现长期复利增长最大化**。

## 公式

```
f* = (p × b - q) / b

f*  = 最优仓位比例
p   = 胜率（投资成功的概率）
b   = 净赔率（盈利时每单位风险获得的回报）
q   = 败率 = 1 - p
```

公式同时保证两个结果：永不输完 + 复利增长最快。

## 核心推论

### 推论一：高赔率需要更低仓位

凯利公式中，赔率 $b$ 在分母位置——赔率越高，最优仓位反而越低。高波动投资（主题投资、杠杆操作）看似收益诱人，但一次下行风险即可抹掉所有累积收益。

### 推论二：只要胜率 < 100%，全仓就是数学错误

唯一使 $f^* = 100\%$ 的情形是胜率 $p = 100\%$，这在现实中不存在。因此，任何"全仓押注"行为在数学上都是非最优的。

### 推论三：高收益必然伴随波动

真实有效的策略应有与收益水平相匹配的波动。"高收益 + 零波动"的组合要么是骗局（麦道夫案例），要么是未暴露的尾部风险。

## 凯利三原则（实践导向，无需计算）

1. **提高胜率 → 拉长持有期**：持有期越长，正收益概率越高。沪深300数据：月持有正收益概率约55%，10年持有约95%。
2. **体系 > 运气 → 纪律执行**：可复制的纪律长期胜过随机好运。
3. **拒绝孤注一掷 → 仓位 < 100%**：任何单一投资的仓位都应低于100%。

## 输入敏感性警告

资本市场的胜率 $p$ 和净赔率 $b$ 极难精确估计。垃圾输入导致垃圾输出（Garbage In, Garbage Out）。因此凯利公式的实际价值在于**方向性指导**，而非直接用于数值计算。实践中常用"半凯利"（half-Kelly，取 $f^*/2$）来降低输入误差的风险。

## 边界条件

- **"市场长期向上"假设**：拉长持有期提高胜率的结论依赖于此假设。长期下跌市场（如日本失落的三十年）下时间不提高胜率。
- **胜率/赔率估计困难**：对普通投资者而言，主观估计的胜率和赔率可靠性存疑。
- **套利策略例外**：某些策略（如市场套利）可低波动获取稳定收益，但规模受限，不对个人大额资金开放。

## 历史脉络

- **1956年**：约翰·凯利（John L. Kelly Jr.）在贝尔实验室发表论文，提出公式。
- **1960年代**：克劳德·香农（Claude Shannon）与爱德华·索普（Edward Thorp）将公式应用于赌场轮盘，实践验证。
- **1970年代后**：索普将凯利思想带入华尔街，开创量化投资先河。
- **麦道夫案例**：索普当年评估麦道夫基金时发现其收益"稳定得反常"，17年后证伪为庞氏骗局。
