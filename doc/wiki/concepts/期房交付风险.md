# 期房交付风险

## 定义

期房交付风险是指购房者购买尚未竣工的商品房时，面临**开发商无法按约交付、延迟交付或交付质量不达标**的可能性。2023 年以来，这一风险显著影响了购房者的产品选择偏好。

## 趋势数据

- 期房占新房销售比例从 **76% 降至不足 70%**
- 2023 年起，已竣工住宅销售面积增速持续超过期房
- 现房销售增速领先期房，分化趋势持续

## 形成机制

```
开发商资金紧张 → 交付能力不确定性↑ → 购房者风险规避 → 偏好现房
  → 期房市场份额↓ → 开发商加速推出现房/准现房项目
  → 政策端推出"白名单"和 4 万亿保交付贷款
```

## 政策应对

- **4 万亿保交付贷款**：专门用于支持已售罄但未竣工项目的交付
- **"白名单"机制**：政府筛选符合条件的房地产项目，协调银行提供融资支持
- 政策效果取决于资金落地速度和覆盖范围

## 对新房-二手房分化的影响

期房交付风险是推动**二手房跑赢新房**的核心机制之一——二手房（尤其是次新房）交付确定性远高于期房，即使价格略高，购房者也愿意承担溢价以获得确定性。

## 边界条件

- 若保交付资金落地快且覆盖广，期房信心可能提前恢复，分化收窄
- 若开发商资金链持续恶化，交付风险仍可能蔓延至已有"白名单"项目
- 现房占比下降是结构性趋势，短期内难以逆转
