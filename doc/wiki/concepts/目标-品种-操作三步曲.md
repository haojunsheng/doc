# 目标—品种—操作三步曲

把基金投资从"买哪只"拉回"我是谁"——先定目标，再选基金品种，最后定操作方法。这是《解读基金》的核心框架，指纹级方法论。

## 三步顺序

```
第一步：定投资目标
  → 我有多少钱？这笔钱能用多久？能亏多少？
  → 要理财还是想发财？
  → 我的风险承受力和睡眠质量能不能撑住？

第二步：选基金品种
  → 指数基金、债券基金、QDII、FOF、生命周期基金——各有位置，无神性
  → 晨星评级、优秀基金公司作为参考维度

第三步：定操作方法
  → 红利再投资还是现金分红？前端还是后端收费？一次性买还是定投？
  → 什么时候赎回？什么情况下再平衡？
```

## 核心洞察

市场涨到 6000 点时问"买还是卖"，市场跌下去时问"怎么办"，都已经晚了。正确问题应该在入场前就想清楚：这笔钱是不是闲钱？目标几年？股债比例多少？跌了还能不能按规则再平衡？

如果答案含糊，任何基金都会变成折磨。

> 基金投资不是向外找神基，而是向内建立一套能长期活下来的规则。
