# 信用债利差

## 定义

信用债利差是信用债收益率与同期限国债收益率的差额，反映市场对信用风险的定价。

## 形式化表达

```
信用债利差 = 信用债收益率 - 同期限国债收益率 → 反映信用风险溢价
```

## 核心含义

- 国债被视为无风险资产，其收益率为基准
- 信用债有违约风险，需要更高的收益率补偿
- 利差越大，说明市场认为信用风险越高
- 利差收窄，说明市场对信用风险的定价趋于乐观

## 边界条件

- 流动性紧张也会导致利差扩大，不一定代表信用风险增加
- 历史利差不一定能准确预测未来走势
- 需结合宏观经济、企业盈利、监管政策等综合判断
