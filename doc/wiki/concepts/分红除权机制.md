# 分红除权机制

基金分红不是"白赚的钱"，而是从基金净值中划出部分资产分配给持有人——分红后净值相应下降，这一过程称为除权。

## 核心公式

```
分红后净值 = 分红前净值 - 单位分红金额
```

## 为什么容易误解

投资者看到基金分红到账，往往误以为是额外收益。实际上：

- 分红资金来自基金已持有的资产（股票、债券等）
- 分红当天净值会同步下调，持有人总资产不变
- 只有将分红**再投资**（买入更多份额），才能真正增加整体收益

## 与普通投资者收益的关系

| 分红处理方式 | 对总回报的影响 |
|-------------|--------------|
| 现金分红（不选再投资） | 总回报不变，但现金流增加；净值除权后账面价值减少 |
| 红利再投资 | 总回报增加（多买入的份额继续参与涨跌），复利效应启动 |
| 未选任何方式（默认现金分红） | 多数基金默认此项，容易形成"到账即结束"的错觉 |

## 与回报率的关联

在计算 [[净值与回报率的区别]] 中的总回报率时，期间分红必须计入分子——但未选红利再投资的情况下，这笔钱停留在账上而非自动再买入，实际投资者的复利收益会低于基金公布的总回报率。

## 实践建议

- 长期持有型投资者应主动选择"红利再投资"选项
- 关注基金定期报告中的分红记录，确认为正常除权而非"额外派发"
- 将除权后的净值变动纳入 [[基金回报比较三前提]] 中的"同风险"考量
