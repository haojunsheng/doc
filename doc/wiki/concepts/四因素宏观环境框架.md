# 四因素宏观环境框架

## 定义

通过四个宏观维度同时判断当前市场所处环境的方法论：通胀方向 × 利率方向 × 经济增速方向 × 货币/财政政策方向。四维组合决定市场整体风险收益特征。

## 形式化表达

```
市场判断 = f(通胀方向, 利率方向, 经济增速方向, 政策方向)

2022年样本: 通胀↑ + 利率↑ + 增速↓ + 紧缩 = 全线利空（熊市）
2024年样本: 通胀↓ + 利率↓ + 增速↓ + 宽松 = 三利好一利空（结构性机会）
```

## 四个维度

| 维度 | 利好信号 | 利空信号 |
|------|---------|---------|
| 通胀 | 持续下降接近目标（2%） | 反弹或居高不下 |
| 利率 | 进入下行通道 | 维持高位或回升 |
| 经济增速 | 温和放缓（软着陆）或复苏 | 严重放缓（硬着陆/衰退） |
| 政策方向 | 宽松（降息/财政扩张） | 紧缩（加息/财政收紧） |

## 应用：区分牛市轮动与趋势反转

- **三利好一利空**：下跌多为结构性轮动，非系统性风险
- **两利空两利好**：震荡格局，需逐类资产判断
- **一利好三利空**：系统性风险期，防御优先
- **全利空**：熊市，等待政策转向信号

## 边界条件

- 若通胀反弹，三利好框架瞬间坍塌，需重新评估
- 若经济从"温和放缓"滑向"严重放缓"，软着陆变硬着陆，利好逻辑逆转
- 该框架为晨星美国团队提出，适用于美股宏观判断，跨市场移植需谨慎
