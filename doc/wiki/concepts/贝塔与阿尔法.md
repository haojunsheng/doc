# 贝塔与阿尔法

**贝塔（β）与阿尔法（α）**是收益拆解的两个基本维度，分别代表市场平均分与超额分。这个框架的核心洞见在于：**多数人以为自己赚的是阿尔法，其实只是贝塔**——认清这一点才能理性选择工具。

## 核心公式

```
总收益 = 贝塔收益 + 阿尔法收益
```

- **贝塔收益**：跟随市场大势获得的回报，可通过低成本指数基金被动获取
- **阿尔法收益**：超越市场的超额回报，需要主动管理能力，且极难持续

## 系数解读

### 贝塔系数（β）

| β 值 | 含义 | 特征 |
|------|------|------|
| β > 1 | 比基准更激进 | 涨跌都比基准猛，风险更高 |
| β = 1 | 与基准同步 | 同涨同跌，完全跟踪 |
| 0 < β < 1 | 比基准温和 | 波动小于市场，相对稳健 |
| β = 0 | 与市场无关 | 如国债等无相关性资产 |

### 阿尔法系数（α）

| α 值 | 含义 | 评价 |
|------|------|------|
| α > 0 | 超额收益 | 基金经理有真本事 |
| α = 0 | 与市场持平 | 没有超额贡献 |
| α < 0 | 拖累收益 | 扣除费率后反而跑输 |

## 认知陷阱

### 把贝塔当阿尔法

牛市中最常见的错误：把市场整体上涨带来的收益误认为自身选股或择时能力。当风停了，才发现自己是那只"掉下来的猪"。

### 为可能不存在的阿尔法支付高价

主动管理基金费率远高于指数基金，但多数主动基金长期无法产生正阿尔法。投资者实际是在为"可能存在的阿尔法"支付确定性的高额成本。

## 飞猪比喻

雷军的"飞猪理论"让贝塔概念大众化：

- **贝塔 = 风口**：只要站在风口上，猪也能飞
- **阿尔法 = 逆风飞翔**：风停了还能继续飞，或者至少不摔在地上

> 核心比喻：贝塔是"躺平"的收益，阿尔法是"冒险"的收益。

## 贝塔易得，阿尔法难求

这是本框架最重要的实践结论：

1. 贝塔通过指数基金可以低成本、稳定地获得
2. 阿尔法需要选股或择时能力，且多数情况下是"运气"的学术化表达
3. 历史阿尔法不能预测未来阿尔法——它只是一个归因结果

## 行动准则

1. **先拿贝塔**：通过低成本宽基指数基金/ETF确保获得市场平均回报
2. **再谈阿尔法**：如有意追求阿尔法，优先选择低费率、长周期表现可解释的策略
3. **自我检验**：定期问自己——我赚的是贝塔还是阿尔法？我是否为阿尔法支付了过高的费率？
