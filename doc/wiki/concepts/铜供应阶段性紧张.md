# 铜供应阶段性紧张

**铜供应阶段性紧张**是指当前铜价上涨源于需求强劲+矿企下调产量预期，但新矿山投产、现有矿山扩产、新技术应用都在推进，长期供应仍有增长空间。

## 核心命题

> 当前紧张是阶段性的，非结构性的。

## 形式化表达

```
新矿山投产 + 扩产 + 新技术 → 铜矿供应长期↑ ⊃ 当前紧张 = 阶段性非结构性
```

## 关键变量

| 变量 | 状态 | 影响 |
|------|------|------|
| 刚果（金）铜矿 | 全球第二大供应国 | 新增产能重要来源 |
| 新矿山投产 | 持续推进 | 长期供应增长 |
| 现有矿山扩产 | 进行中 | 缓解短期紧张 |
| 新能源需求 | 超预期可能 | 延长紧张周期 |

## 边界条件

若铜矿投产进度持续低于预期或新能源需求超预期，供应可能持续紧张。
