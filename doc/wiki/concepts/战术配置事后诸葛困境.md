# 战术配置事后诸葛困境

战术配置（Tactical Allocation）指基于对市场短期或中期判断进行的主动资产配置调整，但最优配置往往只有事后才能知道，导致多数战术配置基金跑输"什么都不做"的基础组合。

## 核心命题

```
理论: 阶段增强 → 更优风险调整收益
实际: 多数战术基金 < 60/40基础组合
```

## 机制

| 阶段 | 表现 | 原因 |
|------|------|------|
| 事前（现在） | 需要判断哪个资产即将上涨 | 信息不完整，预测困难 |
| 事中（持有期） | 择时错误概率高 | 行为偏差（追涨杀跌）、交易成本 |
| 事后（复盘） | 看起来显而易见 | 幸存者偏差，历史路径清晰 |

## 典型证据

- 1990年以来，阶段性增加比特币、REITs等另类资产能提升收益
- 但"最优配置"只有事后诸葛才能知道
- 晨星大量研究显示多数战术基金跑输基础60/40组合
- 说明择时和主动调仓对多数人来说是负期望游戏

## 与现金作为战术配置的关系

[[现金作为战术配置]] 从另一个角度讨论了同一问题：调整现金仓位本质上是市场择时，对普通人而言难度极高。两者共同指向一个结论——**坚持长期投资计划往往比频繁调整仓位更可靠**。

## 边界条件

- 极少数有持续择时能力的投资者可能例外
- 机械化的再平衡策略（如股债固定比例）不属于择时，是规则化操作
- 无法事先识别谁能持续择时成功

## 核心结论

战术配置是一个"听起来很美但实际很难"的领域。对大多数投资者而言，以市值加权为起点，减少主动调仓，反而能获得更优的风险调整后收益。
