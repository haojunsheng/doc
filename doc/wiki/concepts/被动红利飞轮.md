# 被动红利飞轮

被动红利飞轮是指先发规模带来的流动性优势所构建的**正反馈循环**：先发 AUM 越大 → 流动性越好 → 跟踪误差越低 → 套利者/配置盘越愿意买入 → 长钱（养老金、险资、FOF、投顾）将其纳入标准配置入口 → AUM 进一步扩张。

这是[[配置飞轮]]在红利被动基金领域的具体形态。

## 运转路径

```
先发 AUM 越大
    → 流动性越好（买卖价差最低、折溢价最小）
    → 跟踪误差越低（大额申赎对持仓影响小）
    → 套利者和机构配置盘更愿买入
    → 联接基金、FOF、投顾策略将其纳入标准配置入口
    → 长钱直接对接，AUM 再扩大
```

## 护城河实质

被动红利的墙**不在产品端，而在先发规模+指数许可分发**。

头部 CR5 市占率 60–70%+，已形成护城河正循环。挑战者能切入的唯一路径是**开新因子 SKU**（红利+央企、红利+低波、红利+ESG、红利+港股通），在维度上包抄，而非正面硬刚。

## 与经营飞轮的区别

| 维度 | 被动红利飞轮 | 经营飞轮 |
|:---|:---|:---|
| 驱动力 | 资金配置需求 | 用户/产品价值增长 |
| 规模变大的结果 | 流动性提升、默认路径强化 | 底层业务增长、护城河加深 |
| 上限 | 有明确上限（规模不改善底层盈利） | 理论上无上限 |

## 反身性风险

飞轮是可逆的：利率上行或强经济复苏期，资金弃红利拥成长 → 头部红利 ETF 赎回 → 流动性变差 → 赎回加剧 → 飞轮逆转。被动基金同样存在**负周期弹性**下的反身性风险。
