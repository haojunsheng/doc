# 资管黑箱

## 定义

**资管黑箱**是指银行理财等资管产品信息披露不透明，投资者难以了解产品实际持仓和风险状况的信息不对称现象。与之相对的是公募基金的"玻璃箱"——每日净值、季报持仓、基金经理履历全部公开。

## 形式化表达

```
银行理财 ≈ 黑箱（不透明）
公募基金 ≈ 玻璃箱（透明）
底层资产相似，但透明度差异显著
```

## 黑箱的具体表现

- 历史表现难查
- 业绩无法横向比较
- 持仓披露不充分
- 费用结构不清晰

## 与刚性兑付的关系

在刚性兑付时期，黑箱是风险积累的温床：

1. 投资者无法看清底层资产风险
2. 只看到银行信用背书，误认为无风险
3. 风险被掩盖而非被管理
4. 系统性风险持续积累

打破刚性兑付后，黑箱问题更加突出——投资者既没有刚性兑付兜底，又缺乏判断风险的必要信息。

## 穿透持仓是应对黑箱的工具

[[穿透持仓]] 建议投资者穿透产品形式，看清底层资产的实际投向。这是应对资管黑箱的核心方法。

## 透明度的价值

透明度是做出正确投资决策的前提：

- 公募基金每日净值可追踪真实收益
- 季报持仓可验证投资策略是否漂移
- 费用透明便于评估综合费率
- 业绩可比便于横向筛选
