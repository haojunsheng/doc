# 主题基金存活率模型

## 双重概率模型

主题基金投资的胜率由两个独立概率相乘得出：

```
胜率 = 活过10年 × 跑赢大盘 ≈ 50% × 40% ≈ 20%
```

### 概率分解

| 概率项 | 数值 | 含义 |
|--------|------|------|
| 活过10年 | ~50% | 全球一半以上主题基金10年内清盘 |
| 跑赢大盘 | ~40% | 活下来的基金中，能跑赢大盘的比例 |
| **总胜率** | **~20%** | 两个概率相乘，约等于赌马"三重彩" |

## 三件事同时做对模型

```
赚钱 = 主题正确 ∩ 基金坚持 ∩ 入场时机对
```

### 三个必要条件

1. **选主题**：判断这是长期趋势而非短期炒作
2. **选基金**：所选基金不因业绩压力偏离原定主题
3. **选时机**：在赛道尚未拥挤前买入

### 实操难度

- 专业投资者也可能三件事同时做对，但对普通人概率接近零
- 三个条件相互独立，需同时满足才能获利

## 边界条件

- 这是全球统计数据，A股主题基金历史更短，实际胜率可能更低
- 极少数长期主题（如科技）被归入宽基，不属于此模型适用范围
