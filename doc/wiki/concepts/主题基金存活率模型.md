# 主题基金存活率模型

## 双重概率模型

主题基金投资的胜率由两个独立概率相乘得出：

```
胜率 = 活过10年 × 跑赢大盘 ≈ 50% × 40% ≈ 20%
```

### 概率分解

| 概率项 | 数值 | 含义 |
|--------|------|------|
| 活过10年 | ~50% | 全球一半以上主题基金10年内清盘 |
| 跑赢大盘 | ~40% | 活下来的基金中，能跑赢大盘的比例 |
| **总胜率** | **~20%** | 两个概率相乘，约等于赌马"三重彩" |

## 三件事同时做对模型

```
赚钱 = 主题正确 ∩ 基金坚持 ∩ 入场时机对
```

### 三个必要条件

1. **选主题**：判断这是长期趋势而非短期炒作
2. **选基金**：所选基金不因业绩压力偏离原定主题
3. **选时机**：在赛道尚未拥挤前买入

### 实操难度

- 专业投资者也可能三件事同时做对，但对普通人概率接近零
- 三个条件相互独立，需同时满足才能获利

## 时序风险：热潮期申购机制

[[sources/5-notes--35-20260628t153730-qa-主题基金热潮中的冷思考qa--1f24gn3]]（晨星中国，2026-06-28）补充了时序风险维度：

```
主题上涨→申购↑→规模↑→热潮退→下跌→高位买家亏损
```

**关键机制**：
- 基金公司"趁热发行"：在主题热度上升期加速推出新产品
- 投资者"趁热买入"：在主题高潮期大量申购
- 两者形成合谋陷阱：高位申购者成为热潮退却的买单者

**与双重概率模型的互补**：
- 存活率模型强调"选主题+选基金+选时机"三件事同时做对的概率
- 热度循环机制解释了"选时机"为何最难——当投资者确定"这个主题能改变未来"时，赛道通常已经拥挤

## 边界条件

- 这是全球统计数据，A股主题基金历史更短，实际胜率可能更低
- 极少数长期主题（如科技）被归入宽基，不属于此模型适用范围
- 2024年数据显示60%主题基金为指数基金，改变了风险特征：从主动管理风险转向赛道估值透支风险

## 与AI浪潮QA的互证

[[sources/5-notes--28-20260628t153258-qa-ai浪潮投资qa--7irwzm]]（晨星中国，2026-06-28）以AI主题ETF为实证：前十大重仓≈50%资产，高集中度正是"主题正确"这一前提条件的苛刻体现——在AI终局未定时押注单一赛道，三件事同时做对的概率极低。文中"买草堆比找针靠谱"的结论，是双重概率模型的通俗表述。
