# 宽基指数

宽基指数基金是一次买入整个市场、自带分散属性的投资工具，是普通投资者的首选起点。

## 核心论点

**宽基指数 = 一次买入整个市场 → 自动分散 + 省心**

- 一只沪深 300 包含 300 家公司，天然分散个股风险
- 无需研究任何行业或个股
- 再配一只纯债基金或短债/货币基金，基础组合即告完成

## 形式化表达

宽基指数的核心价值：降低认知门槛，用工具替代选股能力。

## 边界条件

- 无法获得超额回报（贝塔收益，非阿尔法）
- 追求跑赢市场需叠加主动基金或行业基金
- 适合"从 0 到 1"的起步阶段，进阶后可考虑 [[concepts/全天候策略]]、[[concepts/永久组合]] 等策略框架

## 集中度风险边界

> [!warning]
> 并非所有宽基指数都真正分散——需单独评估集中度风险。

纳指100是一个典型反例：名义上100家公司，但前九大公司权重超过60%，实际波动由少数科技巨头决定。这挑战了"宽基指数=天然分散"的隐含假设。

参见 [[concepts/集中度风险]]。

## 与 [[concepts/能力圈风险]] 的关系

宽基指数是规避能力圈风险的直接工具——你不需要懂行业，只需要接受市场整体回报。但需注意：即使是宽基指数，也可能存在高度集中的风险，需额外评估。
