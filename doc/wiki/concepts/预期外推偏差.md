# 预期外推偏差

## 定义

投资者和分析师将近期短期表现线性外推为长期趋势的系统性认知偏差——高估短期信号的持久性，低估均值回归力量。

## 形式化表达

```
观察到短期高增长（或短期事件爆红）
    → 线性外推至长期盈利预期
    → 实际长期增长低于外推值
    → 预期误差 → 股价纠正
```

## 实证依据

**NBER 2023年研究**：
- 分析师长期盈利预期大部分源于当前短期表现
- 当长期增长预期高于历史平均时，未来实际盈利经常不如预期
- 这种乐观情绪预示未来1-2年盈利增长令人失望

**实体经济传导（约两年滞后）**：
- 某年长期增长预测比平常高一个标准差
- 下一年公司投资/资本比率明显提高
- 但投资热潮通常在两年后急剧降温
- 短期带来消费、就业、工资增长，长期回归均值

## 边界条件

- **缩小偏差的条件**：分析师具备穿越多个周期的长期预测能力；机构投资者占比高、成熟市场；投资者教育水平提升
- **放大偏差的条件**：短期事件冲击强烈（如爆款产品、政策利好）；散户主导市场；社交媒体放大情绪

## 案例

**泡泡玛特**：Labubu爆红（短期事件）→ 市场将其外推为长期IP授权帝国逻辑 → 目标价不断上调 → 实际IP生命周期仅5-8年 → 股价回调。
