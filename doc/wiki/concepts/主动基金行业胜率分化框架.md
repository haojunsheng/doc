# 主动基金行业胜率分化框架

主动基金的超额收益不是"有无"的问题，而是"在哪些行业、什么环境下有"的问题。**行业分化是主动胜率波动的核心变量**——选主动基金=选赛道+选风格，而非只看经理个人。同一时期，不同行业的主动基金胜率差异可达60个百分点以上。

## 核心命题

```
主动胜率 = f(行业属性, 市场环境, 基金经理配置能力)
```

形式化表达：

```
消费行业: 研究透明 + 定价有效 → 错误定价↓ → 主动超额↓
医药/TMT: 高复杂度 + 高壁垒 → 信息不对称 → 主动超额↑
```

## 晨星晴雨表数据（2022-2023）

晨星中国主动/被动晴雨表覆盖2790只基金，按行业和风格分类统计主动战胜被动基金的比例：

### 整体胜率趋势

| 风格分类 | 2022年胜率 | 2023年胜率 | 变化 |
|---------|-----------|-----------|------|
| 大盘成长 | 61%-82% | 61%-82% | 基本稳定 |
| 大盘平衡 | 63% | 49% | ↓14个百分点 |
| 整体主动偏股 | — | 58% | ↓5%（较2022年） |

### 行业胜率分层

| 行业类型 | 2022年胜率 | 2023年胜率 | 原因 |
|----------|-----------|-----------|------|
| 医药生物 | 67%-93% | 67%-93% | 行业研究门槛高、信息不对称性强、专业壁垒强 |
| 科技传媒（TMT） | 61% | 29% | 技术迭代快、信息不对称；但2023年配置失误导致暴跌 |
| 消费 | 27%-46% | 27%-46% | 研究透明度高、定价有效、信息对称，全行业最差 |

**数据解读**：
- 医药行业主动胜率稳定在67%-93%，是最稳定的超额来源。
- 科技传媒从61%暴跌至29%，显示行业选择错误可导致巨大损耗。
- 消费始终垫底（27%-46%），主动在消费行业战胜率不足一半。

## 分化机制分解

### 1. 医药行业：主动碾压的稳定性来源

- 医药行业研究门槛高、信息不对称性强
- 主动基金经理可以通过深度研究挖掘被低估标的
- 被动指数难以精准捕捉细分龙头，主动选股优势明显

### 2. 科技传媒：胜率暴跌的根因

2023年科技传媒行业主动基金胜率从61%暴跌至29%，核心机制：

```
基金经理配置失误 = 错失机会 + 错误超配
├─ 错失：消费电子、光学光电子、影视院线（高增长细分）
└─ 超配：半导体、软件开发（表现疲软）
```

反观被动基金专注于游戏、5G和人工智能等特定主题，反而表现出色。

**边界条件**：若半导体和软件开发反弹而游戏AI回调，主动经理可能重新跑赢。

### 3. 消费行业：长期垫底的结构性原因

消费行业2023年极分化（家电汽车涨、美容护理跌），主动经理在弱势行业配置过重：

- **配置错配**：申万美容护理行业指数表现垫底，部分主动基金经理因在该行业配置较重，业绩受拖累
- **偏好偏差**：许多主动基金经理偏好在医药生物和轻工制造领域高权重配置，对获取超额收益造成负面影响
- **被动主题胜出**：家用电器和汽车实现了正回报，专注这些主题的被动基金获得不俗回报

**边界条件**：若消费行业整体回暖且主动经理调整配置，胜率可能回升。

### 4. 大盘平衡组：市场分化时的脆弱性

2023年大盘平衡组胜率从63%暴跌至49%，原因：
- **战胜者**：超配机械设备、石油石化、纺织服饰等抗跌行业
- **跑输者**：在疲软行业中配置了较高权重
- **机制**：行业配置分化直接导致胜率下降

**边界条件**：若2024年市场从结构化回归普涨，平衡型基金的行业配置差异对业绩的影响会减小。

## 与相关概念的关系

### 与 [[战胜率]] 的区别

- [[战胜率]]：整体维度，衡量基金跑赢基准的比例
- [[主动基金行业胜率分化框架]]：行业维度，揭示同一时期不同行业胜率差异可达60个百分点

### 与 [[行业轮动策略]] 的关系

- [[行业轮动策略]]：主动管理策略，追求"选对行业"
- [[主动基金行业胜率分化框架]]：实证数据，证明"选对行业"比"选对经理"更重要

### 与 [[等权平均收益率-vs-资产加权平均收益率]] 的关系

- 后者衡量投资者择时行为损耗
- 前者揭示行业选择是胜率分化的核心变量
- 两者共同构成完整的"主动 vs 被动"评价框架

### 与 [[主动基金基准重构框架]] 的关系

本框架补充了[[主动基金基准重构框架]]的行业维度，说明不同行业的主动胜率存在显著分化，单一的整体胜率（如63%）不足以指导投资决策。

## 实践启示

| 优先级 | 关注点 | 说明 |
|-------|-------|------|
| 首要 | 行业赛道 | 主动基金胜率高度依赖行业，医药稳定超额（67%-93%），消费风险高（27%-46%），TMT波动大（61%→29%） |
| 次要 | 市场环境 | 普涨市场降低行业配置差异影响，分化市场放大行业配置重要性 |
| 补充 | 基金经理风格 | 在优势行业匹配对应风格的经理，而非只看历史业绩 |

**核心结论**：选主动基金不是选基金经理一个人，而是选他所在的赛道和风格。

**投资者决策参考**：
1. **选行业比选主动/被动更重要**——在消费行业，被动基金可能是更优选择；在医药/TMT行业，主动基金更可能获取超额
2. **行业研究深度决定超额空间**——研究越透明的行业，主动超额越难获取；研究壁垒越高的行业，主动经理的专业知识越有价值
3. **警惕行业选择错误**——在消费行业选主动基金，胜率不足一半；在医药/TMT选主动基金，胜率超60%

## 边界条件

- 数据仅覆盖2022-2023两年，时间跨度有限，不宜过度泛化
- 若2024年市场风格回归普涨，行业分化效应可能减弱
- 若主动基金费率改革后仍无法创造超额收益，各行业胜率可能整体下移
- 被动基金同质化加剧可能导致某些行业被动产品清盘，影响基准稳定性
- 若AI辅助研究普及、信息不对称降低，医药/TMT的主动超额可能收窄
- 若消费行业出现结构性变化（如新消费趋势），主动经理可能找到新机会
