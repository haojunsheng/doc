# 压舱石定位框架

"压舱石"是用于描述资产配置中稳健底仓角色的比喻——这类资产在经济波动时守底线，在复苏时贡献弹性收益，兼具防御性与成长性。自由现金流ETF是2025年新出现的压舱石型配置品种。

## 核心逻辑

```
压舱石 = 现金流安全垫 + 盈利成长性
         ↓
  震荡市守底线（高确定性+低波动）
  复苏期享红利（盈利增长带来弹性）
```

## 压舱石 vs 冲锋舟

| 维度 | 压舱石 | 冲锋舟 |
|------|--------|--------|
| 投资目标 | 稳健收益、防守 | 超额收益、进攻 |
| 持有周期 | 长期（数年） | 短期（数周到数月） |
| 风险承受 | 低波动优先 | 高波动可容忍 |
| 适合资产 | 自由现金流ETF、宽基ETF | 行业主题ETF、赛道基金 |

## 边界条件

- 持有周期过短（如几个月），低波动优势无法体现，交易成本反而侵蚀收益
- 若经济陷入深度调整，现金流的"安全垫"属性可能失效
- 压舱石不等于零波动——不应将"抗波动"误解为"无波动"

## 适用场景

自由现金流ETF作为压舱石配置的典型条件：
- 居民理财从"刚兑依赖"转向"风险适配"
- 追求稳健收益、不适合短期博弈的投资者
- 家庭资产配置中需要类固收替代品的部分
