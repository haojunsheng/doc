# 代码是元能力

## 定义

代码生成让 Agent 能内生生成新工具，是通用 Agent 的技术基座。这是 W4 的核心论点。

## 为什么是代码而不是别的？

| 候选方案 | 局限性 | 代码的优势 |
|---------|-------|-----------|
| 固定工具集 | 工具数量有限，无法覆盖未知场景 | 代码可以动态生成任意工具 |
| 自然语言接口 | 语义模糊，执行不可控 | 代码有明确语义和可执行性 |
| 图形界面操作 | 需要 GUI 环境，不稳定 | 代码可在无头环境中运行 |

## 代码生成的三种价值

1. **做新工具**：Agent 写代码生成新工具（自举能力）
2. **辅助思考**：用代码梳理逻辑、验证假设
3. **构建知识库**：用代码组织、索引、检索知识

## 与 Sutton "设计实体"的关系

Agent 自举（Agent 写 Agent）是 Richard Sutton 所说"设计实体"的工程实现——一个能够修改自身结构的系统，是通用智能的关键特征。

## Coding Agent 的工作流

Coding Agent = ReAct 循环 + 文件系统这个特殊工具的组合。与通用 ReAct 的差异点在于：
- 文件系统作为持久化工具，可以跨越多次调用保存状态
- 代码执行环境提供沙箱隔离
- 循环中可以包含"写代码→测试→调试"的子循环

## 新源补充：Coding Agent 成熟的真正原因

新源（李博杰，OpenClaw）强调：Coding Agent 成熟不是因为代码模型强，而是因为软件工程几十年攒下的测试套件、类型系统、版本控制天然构成了一套强大的 Harness。这进一步强化了"代码是元能力"的论点——代码不仅是输出物，更是 Harness 的基础设施。

## 验证方式

- 读 OpenClaw 架构剖析，画出它的循环结构，标出与第一章通用 ReAct 的差异点
- 选一个非编程用途实验跑通（如用代码生成整理一个知识库）
- 跑自举相关实验，或写 200 字说清它和"模板生成代码"的本质区别
