# 资产配置比率

选择基金的核心，不是选具体哪只基金，而是确定股债比例——用资产配置比率替代择时判断。

## 核心主张

不是猜涨跌，而是让股票和债券的比例把你从情绪里拽回来。资产配置比率是第一步"定目标"后落地的具体决策。

```
确定目标 → 决定股债比 → 选对应基金品种 → 定期再平衡
```

## 决策依据

- **投资时间框架**：钱能闲置多久决定波动承受力，从而决定股债比例（见 [[concepts/投资时间框架原则]]）
- **风险承受力**：不只是账户承受力，更是心理上扛得住
- **年龄与人力资本**：年轻时人力资本高，可承受更高权益比例；临近退休则相反（见 [[concepts/年龄-债券经验法则]]）

## 常见误区

| 误区 | 正确理解 |
|------|---------|
| 追涨杀跌，根据近期表现调整比例 | 比例应在入场前确定，期间通过再平衡执行 |
| 以为换基金能改变风险水平 | 换基金不换比例，风险敞口不变 |
| 只看收益率选基 | 配置比率决定整体风险，比单只基金更重要 |
