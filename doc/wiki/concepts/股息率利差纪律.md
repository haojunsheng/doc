# 股息率利差纪律

股息率利差纪律是一种基于跨市场收益率差的配置决策框架：以港股高息指数股息率与境内无风险利率（通常为10年期国债收益率）的利差作为持仓或加仓的核心判断依据。

## 核心逻辑

当港股高息指数股息率显著高于10年期国债收益率时，存在"股息率利差"，配置价值明确；当利差收窄时，未来收益空间被压缩，应考虑降配或退出。

## 实例：港股通高股息场景

截至2026年5月6日公开数据：
- 10年期国债收益率约 1.77%
- 中证港股通高股息投资指数（CNY）股息率约 4.77%
- 利差约 300bp（3个百分点），具有吸引力

## 作为退出信号

股息率利差纪律同时构成退出信号：

| 场景 | 操作 |
|------|------|
| 10年期国债收益率明显上行 | 利差收窄，考虑减仓 |
| 港股高息指数股息率下降 | 估值修复完成或资金涌入导致，利差收窄，考虑减仓 |
| 利差明显压缩至历史低位 | 配置价值已不大，等待再入场机会 |

## 与相关概念的关联

- [[溢价纪律]]：精神一致，均为收益率差作为纪律依据；前者关注跨市场利差，后者关注场内溢价率
- [[配置飞轮]]：股息率利差是飞轮运转的判断锚——利差存在则资金流入，利差消失则飞轮停转
- [[红利资产拥挤度]]：利差被资金涌入压缩是拥挤度的直接信号

## 局限性

- 股息率是静态指标，未反映分红可持续性
- 国债收益率上行可能是经济复苏信号，而非单纯利空
- 汇率波动会侵蚀利差收益
- 需结合基本面分析，不能仅凭利差做决策
