# 外延增长投资

外延增长投资是通过并购、重组等资本运作方式实现企业规模扩张和业绩增长的投资策略，属于外延增长型策略的典型实践。

## 形式化定义

```
外延增长 = 并购增长 × 重组增长 × 主题投资
```

## 核心特征

1. **事件驱动**：关注并购、重组、资产注入等事件带来的投资机会
2. **主题投资**：围绕特定主题（如并购重组、国企改革、产业整合）构建投资组合
3. **弹性优先**：追求比内生增长更高的业绩弹性，愿意承担更高的波动性
4. **周期敏感**：业绩与并购市场活跃度高度相关

## 与内生增长的区别

| 维度 | 内生增长 | 外延增长（本文） |
|------|---------|-----------------|
| 增长来源 | 企业自身盈利 | 并购/重组 |
| 业绩弹性 | 稳定但有限 | 高弹性 |
| 依赖条件 | 管理层能力 | 并购市场活跃度 |
| 风险类型 | 判断风险 | 执行风险 + 政策风险 |
| 适用环境 | 平稳期 | 并购活跃期 |

## 代表实践

[[汇添富外延增长主题股票]] 是外延增长投资的典型代表，由蔡志文管理，采用自下而上选股 + 适度集中的策略，围绕并购重组主题构建投资组合。

## 适用边界

- **优势环境**：并购政策宽松期、产业整合加速期、国企改革推进期
- **劣势环境**：并购监管收紧期、市场低迷期（并购活动减少）
- **核心风险**：并购失败风险、政策风险、整合不及预期风险

## 与主题投资的关系

外延增长投资通常以主题投资为主要操作手段，主题包括：
- 国企改革主题
- 产业整合主题
- 跨界并购主题
- 资产注入主题

详见 [[主题投资]]。
