# 现金流断裂风险

现金流断裂风险是指因收入中断而导致的固定支出无法继续覆盖，进而引发资产被迫变现、信用破产等**不可逆财务损害**的风险。

## 与账面亏损的本质区别

| | 投资风险（账面亏损） | 现金流风险（断裂） |
|---|---|---|
| 性质 | 账面波动 | 资产被迫变现 + 信用受损 |
| 可逆性 | 可逆（持有等待回本） | **不可逆**（法拍、信用破产） |
| 修复难度 | 低 | 极高（信用污点影响5-7年） |
| 典型案例 | 2008/2020年大跌后回本 | 断供导致房子被法拍 |

## 触发条件

现金流断裂通常由以下因素触发或加剧：
- **收入中断**：失业、降薪、行业衰退
- **固定支出刚性**：房贷月供占收入比过高
- **现金储备不足**：应急金低于3个月必要开销
- **单一收入来源**：无多元收入备份

## 与[[人力资本]]的关系

人力资本是中产最大的资产，失业风险即人力资本的骤然折损。现金流断裂风险本质上是对人力资本稳定性的风险定价——当人力资本突然贬值（失业），若缺乏现金储备缓冲，整个财务结构即刻崩塌。

## 与[[浮亏与真亏的区分]]的互补

[[浮亏与真亏的区分]]从投资心理角度区分账面亏损与实际亏损；本文概念从现金流角度补充：**现金流断裂才是真正意义上的"真亏"**，因为它不可逆且修复成本极高。
