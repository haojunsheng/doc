# 低贝塔策略

低贝塔策略是一种以持有 Beta < 1 的股票为核心的防御性投资方法，旨在降低组合整体波动。该策略通常与高股息策略结合使用，构成"三合一"配置框架中的一环。

## 核心特征

| 特征 | 说明 |
|------|------|
| 目标 | 降低组合波动，增强防御性 |
| 典型标的 | 地产、收费公路等公用事业类资产 |
| 组合角色 | 与价值股、质量成长股形成互补 |

## 在摩根亚洲股息基金中的应用

摩根亚洲股息基金将低贝塔股作为三类配置之一：
- **低贝塔股**（①）：地产、收费公路
- **价值股**（②）：银行、保险、能源
- **质量成长股**（③）：科技、消费（占比25%–45%）

该框架通过增加第三类股票的多样性，降低了"价值风格逆风"时的组合风险。

## 与其他概念的关系

- 与 [[高股息策略的正面框架]] 共同构成组合构建基础
- 在 [[成长-vs-价值风格的驱动因素]] 中，低贝塔股属于价值风格配置的一部分

## 边界条件

- 在成长股主导的行情中，低贝塔策略容易跑输
- 低贝塔股的长期资本增值潜力有限，主要收益来源为股息
