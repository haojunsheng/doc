# 费率复利效应

费率差经长期复利累积，对投资者最终收益产生显著影响。

## 核心命题

```
费率差 × 持有年限复利 = 累计收益差距
```

省下的费用就是赚到的收益。

## 量化案例（富国中国中小盘混合）

| 项目 | 数值 |
|------|------|
| 该基金综合费率 | 2.33% |
| 同类基金平均费率 | 2.71% |
| 费率差 | 0.38%/年 |
| 持有年限 | 13 年 |
| **累计收益差距** | **约 8%** |

## 费率的复利侵蚀机制

每年节省 0.38%，13 年复利累积：

```
(1 + r - 0.0038)^13 vs (1 + r)^13
≈ 8% 累计差距
```

这意味着：即使两只基金回报率完全相同，费率低的基金最终收益也可能高出 8 个百分点。

## 与 [[费用是复利的反面]] 的关系

本文献是对前概念的补充和实证强化：
- 前概念提供理论框架："费用是复利的反面"
- 本文献提供具体数据：0.38% 费率差 → 13 年 → 8% 差距

## 边界条件

- 费率优势需要持续保持，若业绩大幅下滑，低费率无法弥补损失
- 费率差异需结合费用透明度判断（综合费率含管理费、托管费、交易费等）
- 中国市场基金费率差异通常小于海外，但长期累积效应同样显著

## 投资者启示

1. 选基金时费率是重要考量，低费率长期累积效应显著
2. 规模效应（38.85 亿管理规模）可有效摊平运营费用
3. 不要只看短期费率数字，要看长期复利累积效果
