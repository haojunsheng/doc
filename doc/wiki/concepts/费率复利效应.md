# 费率复利效应

费率差经长期复利累积，对投资者最终收益产生显著影响。

## 核心命题

```
费率差 × 持有年限复利 = 累计收益差距
```

省下的费用就是赚到的收益。

## 费率的复利侵蚀机制

每年节省一定比例，多年复利累积产生可观差距：

```
(1 + r - 费率差)^n vs (1 + r)^n
```

这意味着：即使两只基金回报率完全相同，费率低的基金最终收益也可能高出相应百分点。

## 量化案例

### 案例一：富国中国中小盘混合（长期持有）

| 项目 | 数值 |
|------|------|
| 该基金综合费率 | 2.33% |
| 同类基金平均费率 | 2.71% |
| 费率差 | 0.38%/年 |
| 持有年限 | 13 年 |
| **累计收益差距** | **约 8%** |

每年节省 0.38%，13 年复利累积约 8% 差距。

### 案例二：2023 年降费改革的实际价值（10 年期）

| 场景 | 综合费率 | 实际年收益 | 10 年后金额（假设年收益 10%） |
|------|---------|-----------|--------------------------|
| 无成本 | 0% | 10% | 2.6 万元 |
| 降费前（2022） | 2.61% | 7.39% | 2.0 万元 |
| 降费后（2023） | 1.8% | 8.2% | 2.15 万元 |

费率下降 0.81%，1 万元投资 10 年多赚约 **1500 元**（本金的 15%）。

### 案例三：个人养老金账户场景（30 年期）

| 场景 | 综合费率 | 差异 |
|------|---------|------|
| 低费率指数基金 | ~0.5% | 基准 |
| 高费率指数基金 | ~1.0% | +0.5% |
| **30 年后收益差距** | — | **10%+** |

0.5% 的费率差在 30 年投资周期内可导致 10%+ 最终收益差距。这是养老金指数选择的核心筛选维度，详见 [[个人养老金指数选择框架]]。

### 案例四：货基场景（低收益下的费率侵蚀）

| 项目 | 数值 |
|------|------|
| 费前收益 | 1.5% |
| 综合费率 | 0.5% |
| 费后收益 | 1.0% |
| 持有期 | 10 年 |
| 本金 | 10 万 |
| **费率损耗金额** | **5500 元** |
| **损耗占比** | **36% 的潜在收益** |

**形式化**：
```
10万 × (1.5% - 0.5%) × 10年复利 = 原本1.6万回报只剩1万
其中5500元被费率损耗 → 36%的潜在收益被吃掉
```

这是低利率时代货基的典型困境：费率从"零头"变成"命脉"，0.5%在1.5%的收益面前不再是六分之一，而是三分之一。详见 [[货基费率侵蚀效应]]。

**边界**：若持有期很短（几天到几周），该效应可忽略；若市场利率回升至2.5%+，费率侵蚀率下降。

## 与 [[费用是复利的反面]] 的关系

本文献是对前概念的补充和实证强化：
- 前概念提供理论框架："费用是复利的反面"
- 本文献提供具体数据：0.38% 费率差 → 13 年 → 8% 差距；费率差 0.81% → 10 年 → 1500 元差距；费率差 0.5% → 30 年 → 10%+ 差距

## 与相关概念的关联

- [[基金费率三环节]]：三环节的综合费率通过复利累积产生显著收益差距，投资者需统筹三个环节的持有成本
- [[软美元机制]]：交易费中的软美元部分是基金隐性成本高于散户的重要原因，属于综合费率中常被忽视的组成部分
- [[养老目标基金]]：养老 FOF 存在双重收费问题（FOF 层管理费+底层基金费率），费率复利效应在超长持有期（20-30 年）内被进一步放大；监管要求持有期越长费率优惠越大，是制度层面的对冲机制
- [[个人养老金指数选择框架]]：本文在养老金场景下具体化了费率复利的时间尺度（30年）和量级（0.5%→10%+），并提供可操作的筛选框架
- [[货基费率侵蚀效应]]：低收益场景下的费率侵蚀是费率复利效应的极端表现——费率占比本身即构成收益的侵蚀源

## 边界条件

- 费率优势需要持续保持，若业绩大幅下滑，低费率无法弥补损失
- 费率差异需结合费用透明度判断（综合费率含管理费、托管费、交易费等）
- 中国市场基金费率差异通常小于海外，但长期累积效应同样显著
- 如果基金亏损，省费率只是"少亏"而非"多赚"；复利效应需要 5-10 年才能显现，短期投资者感受不明显
- 需警惕[[软美元机制]]带来的隐性成本差异，这部分常被忽视
- 养老 FOF 的双重收费使费率复利效应更为显著——20-30 年持有期内，每年 0.5% 的额外成本可导致终值差距超过 20%

## 投资者启示

1. 选基金时费率是重要考量，低费率长期累积效应显著
2. 规模效应（38.85 亿管理规模）可有效摊平运营费用
3. 不要只看短期费率数字，要看长期复利累积效果
4. 关注综合费率（含隐性成本），而非仅看管理费
5. 长期投资者更应关注持有环节的综合费率，因为这是最大头的持续性成本
6. 养老投资周期长达数十年，费率差异的复利影响极为可观，应优先选择费率优惠的养老 FOF 份额
