# 共识入场陷阱

共识入场陷阱是指：投资者在市场对某一投资主题达成共识（媒体热议、产品集中发行、价格已大幅上涨）后才进场，此时超额收益已基本消失，甚至已开始回调。

## 核心命题

> 赛道投资的真正风险不在赛道本身，而在于你总是在共识形成后才进场。

## 形成机制

```
赛道崛起 → 市场关注 → 媒体报道 → 产品集中发行 → 共识形成 → 投资者入场 → 超额收益消失/回撤
         ↑_________________________________________↓
                          （追涨杀跌闭环）
```

1. **时间窗口悖论**：A股板块轮动使赛道热度短暂，真正的超额收益窗口极短
2. **供给侧扭曲**：基金公司往往在赛道热度高后才集中发行相关基金，供给侧滞后进一步强化了入场时点的恶化
3. **同赛道分化巨大**：即便选对赛道，最好与最差基金年化差距超30%，说明入场时机与选择比方向更重要

## 认知心理基础

- [[近因效应]]：投资者将近期表现当作永久趋势，在热门阶段追高
- [[线性外推]]：从过去几月的强势外推未来将持续
- [[认知依赖]]：媒体和产品的密集曝光强化了"这个方向没错"的确定感

## 典型场景

- 2020-2021年新能源"宁赛"成为共识时，后续两年大幅回调
- 2023-2024年AI主题爆发后，共识期入场的投资者承受了显著的估值回调
- "茅赛"在2020年封神后，2021-2022年持续承压

## 与相关概念的区别

- vs [[赛道估值透支]]：后者关注估值层面的贵贱，前者关注入场时机层面的"共识后"
- vs [[线性外推]]：线性外推是认知偏差本身，共识入场是其行为后果
- vs [[赢家补贴输家]]：共识入场是输家的形成路径，赢家补贴输家是机制描述

## 应对策略

- 赛道基金只作卫星仓位（<20%），核心仓位留给宽基
- 警惕"人人都说好"的信号——当讨论一个赛道成为社交常态时，往往是共识形成的标志
- 区分"方向判断正确"和"入场时机正确"——前者容易，后者难得多
