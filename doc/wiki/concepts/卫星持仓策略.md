# 卫星持仓策略

## 核心思想

不因主题基金的高失败率而完全放弃，而是通过仓位控制将其风险限制在可承受范围内。

## 资产配置框架

```
核心持仓 (60%+) ：宽基指数 / 债券基金
                 ← 稳健收益主体

卫星持仓 (小比例)：主题基金
                 → 高风险高潜在回报的补充
```

## 策略逻辑

### 为什么不能完全放弃？
- 极少数主题确实代表长期结构性变化（如早期互联网）
- 完全放弃可能错过这类机会

### 为什么不能重仓？
- 主题基金胜率仅约20%，等同于赌博（参见 [[theme-fund-survival-rate]]）
- 主题基金编故事能力强，实际赚钱能力弱
- 买主题基金像赌马"三重彩"，太难

### 为什么控制小比例？
- 即使小比例全亏，也不影响整体组合
- 保留参与极少数真正有未来赛道的可能性
- 避免追高被套的心理压力

## 适用人群参考

| 投资者类型 | 建议卫星比例 |
|-----------|-------------|
| 普通投资者 | 5%-10% |
| 有极强行业判断能力 | 可适当提高，但需能承受全亏 |
| 保守型投资者 | 0%（完全不做主题基金） |

## 边界条件

- 此策略假设核心持仓（宽基/债券）本身能产生稳定回报
- 如果你有极强的行业判断能力且能承受全亏，比例可以高一些
