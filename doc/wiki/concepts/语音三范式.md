# 语音三范式

## 定义

语音交互的三种范式，演进主线是"摆脱轮流说话"——让 Agent 更像真人对话，而非一问一答的轮询系统。

## 三范式

| 范式 | 描述 | 延迟 | 体验 |
|------|------|------|------|
| 级联式 | STT → LLM → TTS，依次执行 | 最高 | 明显停顿，像机器 |
| Omni 式 | 端到端语音到语音，但仍是轮流 | 中等 | 流畅但仍有轮转感 |
| 全双工式 | 边听边说，可打断，可并行 | 最低 | 最接近真人对话 |

## 快慢思考分离

语音三范式的核心洞察：**快慢思考分离让交互能力与智能上限分别演进**。
- 快速通道：语音识别 + 语音合成（交互能力）
- 慢速通道：大模型推理（智能上限）

两者解耦后，交互体验可以提升而不必等待模型变强。

## Pine 的选择

Pine 语音 Agent 选择快慢分离架构，原因是：
1. 快速通道可以用专用小模型，延迟低、成本低
2. 慢速通道用大模型，保证智能上限
3. 两者独立迭代，互不阻塞
