# 经常账户-资本流入恒等式

## 核心定义

国际收支基本恒等式：经常账户赤字 = 资本净流入。这是一个会计恒等式，不受单边政策直接影响。

## 形式化表达

```
CA = -KA  （经常账户 = -资本账户）
或：CA赤字 = 资本净流入
```

其中：
- CA = 商品贸易余额 + 服务贸易余额 + 初次收入 + 二次收入
- KA = 外国资产购买 - 本国资产购买 = 资本净流出

## 政策含义

任何试图通过关税单独改变经常账户赤字的政策，都不改变资本净流入，因此无法改变经常账户赤字。

### 关税对恒等式的影响路径

```
关税↑ → 进口↓ → CA改善？
    ↓
进口↓ → 美元支出↓ → 美元↑ → 出口↓ → CA恶化
    ↓
净效果：CA ≈ 不变（恒等式约束）
```

## 突破恒等式的条件

只有改变资本净流入本身，才能改变经常账户赤字：

| 政策组合 | 资本净流入变化 | 经常账户效果 |
|---------|--------------|------------|
| 仅加征关税 | 不变 | 逆差不变 |
| 关税 + 资本管制 | 下降 | 逆差收窄 |
| 关税 + 财政赤字削减 | 下降 | 逆差收窄 |
| 增加国内储蓄 | 下降 | 逆差收窄 |

## 在关税分析中的应用

[[关税自我抵消机制]]正是基于这一恒等式推导而出。该恒等式是判断关税能否改变贸易逆差的理论基础，也是评估关税政策效果的基本前提。
