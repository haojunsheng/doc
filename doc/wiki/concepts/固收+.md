# 固收+

## 定义

以债券投资打底、用风险资产增强收益的投资策略，本质是"稳定收益 + 弹性收益"的组合。

[[sources/5-notes--34-20260614t120827-qa-固收加产品看基金经理流程qa--vvk7xr]] 提供形式化定义：

```
固收+ = 债券（主策略，稳定收益） + 风险资产（股票/可转债，增强收益）
```

## 分类框架

固收+根据"+"部分所配置的风险资产类型，可分为两大类：

### 积极债券型 / 保守混合型

"+"部分是股票（或股票 + 可转债），直接暴露于股票价格风险之下。在股市上涨时弹性较大，在股市下跌时回撤也可能较深。

### 普通债券型

"+"部分仅为可转债，不直接投资股票，通过可转债的转股期权参与权益市场。可转债兼具债券属性和转股期权，在牛市中能享受股票上涨带来的收益弹性，在熊市中又有债券底的保护。

## 定性评价框架（晨星，QA 来源）

[[sources/5-notes--34-20260614t120827-qa-固收加产品看基金经理流程qa--vvk7xr]] 补充晨星的定性评价方法论：

```
基金评价 = 基金经理（能力圈、经验） + 投资流程（策略、风控、决策流程）
```

两个维度都需在同类中具备竞争优势，才是好的"固收+"产品。这是定性评价，基于历史不代表未来持续。

## 风险评估维度缺失

很多产品介绍文章（包括 [[entities/晨星中国-morningstarcn]] 的分析）仅用"基金经理 + 投资流程"定性判断，缺乏量化指标支撑：

- 最大回撤
- 夏普比率
- 信息比率

读者无法自行验证结论，也无法在不同固收+产品之间进行横向比较。

## 极端市场的脆弱性

当债券和股票同时下跌时（如 2022 年），"固收+"可能变成"固收-"。这一风险在产品定位中常被弱化，投资者需要明确自己持有的固收+产品的"+"部分是什么——是股票、可转债，还是两者都有——以及在不同市场环境下的贡献度如何。

## 组合中的角色

建议将固收+作为"组合的核心配置"之一，用于降低 [[concepts/波动拖累]]，而非追求高收益。[[concepts/组合视角]] 强调应将固收+放在整体资产配置框架中理解，而非作为独立理财产品看待。

## 量化分析工具

可用 [[entities/brinson]] 归因框架分析固收+中债券部分与权益部分的贡献，区分择时（资产配置）与选股（个券选择）的贡献来源。
