# 规模导向与回报导向

基金行业的两种激励机制：**规模导向**下基金公司靠规模赚管理费，与投资者利益存在结构性偏差；**回报导向**下基金公司靠业绩吸引资金，与投资者利益绑定。

## 两种模式的利益结构

```
规模导向：
  基金公司收入 = 规模 × 管理费率
  → 动机：最大化规模 → 可能忽视投资者利益

回报导向：
  基金公司收入 = f(业绩) × 规模
  → 动机：做出业绩 → 利益与投资者绑定
```

### 规模导向的问题

- 基金公司在市场高点频繁发行新基金（追涨），规模激增但业绩往往最差。
- 管理费与业绩相关性弱，与规模正相关——"躺赚"模式激励基金公司追求规模而非回报。
- 与销售渠道的尾随佣金机制相互强化，形成系统性利益冲突。

### 回报导向的制度设计

降费改革的核心逻辑是压缩固定管理费空间，迫使基金公司从"规模驱动"转向"业绩驱动"：
- 管理费降低 → 基金公司利润收窄 → 必须靠业绩吸引资金
- 浮动费率机制：基础费率低 + 业绩提成，进一步将管理费与回报挂钩
- 投顾份额/清洁份额：切断尾佣链条，让顾问收入与投资者利益一致

## 降费改革的深层意义

晨星指出，2023 年启动的降费改革不仅是"少交钱"的技术性调整，更是基金行业生态向"更有利于投资者"方向变化的标志——通过制度设计实现**利益绑定**。

## 边界条件

- 如果降费导致基金公司利润大幅下降，可能引发行业人才流失，长期损害投资者利益。
- 从规模导向向回报导向的转变需要配套机制（浮动费率、投顾份额、长期考核）才能真正落地，单纯降费不足以解决问题。

## 与 [[显性费率与隐性费率]] 的关系

降费主要针对显性费率（尤其是管理费），但改革的深层逻辑是推动行业从规模导向转向回报导向——这不仅涉及费率结构变化，更涉及整个行业激励机制的重构。
