# 规模激增与业绩反转

短期规模暴涨预示未来超额收益回落——这是 20 多年数据验证的结构性规律，而非基金经理个人能力问题。

## 核心命题

**规模激增是业绩杀手，而非锦上添花。** 人气越高，离风险越近。

## 形式化

```
人气高 → 规模激增（有机增长率 > 200%） → 策略容量瓶颈 → 超额收益反转
```

**实证数据**：
- 70% 的爆款基金在激增前一年跑赢市场（平均超额 6.77%）
- 1/2 爆款基金一年内超额转负
- 2/3 爆款基金三年内跑输市场或清盘

## 机制拆解

### 1. 投资者行为层：近因效应 + 线性外推

```
前一年超额收益 > 0 → 吸引申购 → 规模激增 → 业绩反转
```

投资者根据近期业绩做决策——哪个基金涨得好就买哪个。但这恰恰意味着资金涌入的时机往往在市场高点附近。

### 2. 基金经理操作层：双重管理负担

开放式基金经理同时管理两件事：
- **选股**：寻找超额收益来源
- **现金流**：新资金怎么投？赎回时卖什么？

规模激增带来操作复杂度上升，超额收益被稀释。

### 3. 策略容量层：容量瓶颈

```
符合标准的标的有限 → 钱太多被迫注水 → 超额下滑
```

策略容量有限：符合标准的股票数量有限，钱太多会"注水"（买次优标的或持有现金）。

### 4. 指数基金的特殊路径

指数基金虽然不选股，但涌入时点往往是细分领域过热期，风格反转风险高。

## 边界条件

- **少数基金经理例外**：确实有管理大规模资金能力的基金经理，但数据看是少数
- **指数基金不适用**：指数基金的规模增长基本是被动的，"规模有机增长率"指标失真
- **平稳流入 vs 激增流入**：如果资金流入平缓且策略容量足够大，规模激增不必然导致业绩反转
- **规模 ≠ 危险**：这不是说所有大规模基金都不行，而是说"短期规模激增"这个特定现象是危险的

## 与中国市场的关联

- 本文基于 A 股公募基金 20 年历史数据，实证结论适用于中国市场
- 2019 年是投资者行为的分界线："业绩不足三年"的爆款基金占比显著下降，投资者开始关注长期业绩
- 具体转折原因（监管政策？市场周期？）值得进一步研究

## 投资启示

- **"人多的地方不要去"**：规模激增是风险信号，不是买入信号
- **买冷门基金 vs 买爆款**：冷门基金虽有问题但无规模激增的系统性反转压力
- **基金经理自持/历史经验**：可作参考但非决定因素
- **基金公司主动限购**：是专业能力的体现，说明清楚策略边界
