# 国债利率风险

## 核心定义

国债并非"无风险"资产，其风险结构为：

```
国债风险 = 信用风险(低) + 利率风险(高) + 流动性风险(中)
```

- **信用风险低**：国债违约概率极低，是国家信用背书
- **利率风险高**：利率与债券价格反向变动，期限越长，利率风险越大
- **流动性风险中**：取决于国债类型（储蓄式/记账式）

## 利率风险的机制

利率上升 → 债券价格下跌。超长期国债（如50年期）由于久期极长，利率小幅变动即可引发价格大幅波动，历史回测显示利率上行周期中50年期国债可能出现超过20%的账面浮亏。

## 与"锁定收益"的误区

固定票面利率 ≠ 锁定实际回报。如果未来通胀高于票面利率，实际购买力将持续缩水。30-50年维度的利率走势无法预测，所谓"提前锁定高收益"本质上是对未来利率路径的赌注。

## 与普通投资者的关系

普通投资者买入超长期国债后通常只能持有到期或被动承受波动，无法像机构那样通过波段交易和加杠杆对冲利率风险。因此超长期国债的利率风险对散户而言是被放大的。

## 与 [[年龄-债券经验法则]] 的关系

年龄法则建议"债券比例 ≈ 年龄"，但未区分债券期限结构。超长期国债的高利率风险意味着：债券比例的增加不等于安全比例的增加，超长期国债不应简单纳入"年龄=债券比例"的计算中。

## 自测问题

你是否能接受买入超长期国债后账面浮亏20%而坚持不卖？如果不能，超长期国债不适合你。
