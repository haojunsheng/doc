# 被动替代主动

**被动替代主动**是指主动管理基金的超额收益难度加大后，投资者资金从主动基金向被动ETF转移的结构性趋势。这一趋势由三个因素共同驱动：结构性行情压缩主动超额、ETF费率下降降低成本、宽基配置需求上升。

## 驱动机制

```
A股结构性行情 → 主动基金超额收益难度↑
      ↓
ETF降管理费（2023年起）→ 被动成本↓
      ↓
机构持续配置宽基ETF → 资金流入被动
      ↓
被动替代主动
```

**形式化**：
```
资金流入ETF = f(结构性行情强度, 费率差, 机构配置需求)
```

## 证据

| 年份 | ETF资金流入 | 变化 |
|------|------------|------|
| 2021年 | 1272亿 | 基准 |
| 2022年 | 3872亿 | +204% |
| 2023年 | 6043亿 | +56% |

2021-2023年资金流入增速远超历史平均水平，同期A股结构性行情突出，主动基金超额收益难度加大。

## 边界条件

- **全面牛市**：主动基金能轻松跑赢指数时，ETF吸引力下降
- **费率优势消失**：若主动基金费率进一步下降或被动费率上升，替代动力减弱
- **风格漂移**：若被动ETF出现跟踪误差扩大或风格漂移，投资者可能回流主动
