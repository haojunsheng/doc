# 近因效应

大脑天然给近期信息赋予更高权重，使人将最近发生的事误判为最重要或最具预测性的认知偏差。这是追涨杀跌行为的心理根源。

## 定义

**形式化**：近因效应 = 近期信息 > 历史信息；导致 = 过度乐观/悲观

**来源**：心理学中的"系列位置效应"——开头和结尾的内容更容易被记住。近因效应对应"最近印象"，与"首因效应"（第一印象）相对。

**投资语境**：
- 短期业绩好的基金让人忽略长期表现差的基金
- "一根阳线改变情绪，两根改变观念，三根改变信仰"
- 连续上涨让人觉得趋势永续，连续下跌让人绝望离场

## 心理学根基

### 系列位置效应（艾宾浩斯，1885）

艾宾浩斯经典实验证明：记忆材料中开头和结尾的内容更容易被记住，中间部分容易被遗忘。这一发现构成近因效应的心理学根基。[[系列位置效应]]

### 卢琴斯（Luchins）研究，1957

后续新出现的刺激物是印象形成的决定因素——这一研究进一步支持了近因效应在印象塑造中的关键作用。[[卢琴斯-luchins]]

### 首因效应 vs 近因效应

| 效应 | 定义 | 在投资中的表现 |
|------|------|--------------|
| 首因效应 | 第一印象主导印象形成 | 第一次看到某只基金的宣传、首次接触某基金经理 |
| 近因效应 | 最近印象覆盖原有印象 | 连续几天大涨后对基金的看法转变 |

近因效应通常影响更大，因为投资是一个持续过程——每天都有新的信息进来，不断覆盖旧的印象。

## 机制

```
市场快速轮动 / 信息爆炸
    ↓
近期事件在记忆中高度活跃
    ↓
大脑错误地赋予近期事件更高权重
    ↓
线性外推（把近期趋势当成长期规律）
    ↓
追涨杀跌行为
```

## 典型案例

- **2021 年核心资产团灭 + 周期股飞涨**：近因效应的集中体现。年轻投资者对核心资产上涨产生"认知依赖"，认为趋势会永久持续，结果遭遇大幅回撤。
- **硬币实验**：连续 4 次正面后，人们会觉得下一次还是正面——但概率仍是 50%。
- **A 股热点轮动（电风扇式）**：高股息 → AI算力 → 出海出口 → 低空经济 → 地产，鲜少热点持续超过一个月。每个热点都被宣称是"全年方向"，结果迅速消退。[[周期情绪]]

### 热手谬误的同构性

线性外推和"热手谬误"（hot hand fallacy）是同构的——篮球运动员连续进球后，观众觉得他"手感火热"下一球更可能进（实际上每次投篮独立）。投资者看到一只基金连续上涨，觉得它还会继续涨——这是同一个认知偏差。[[热手谬误]]

## 为什么难以克服

近因效应是人类进化出的认知捷径——快速反应比全面分析在生存上更有优势。因此它不是 bug，是 feature。

影响因素：
- **信息量越大，影响越强**：大脑处理不过来，只能依赖最近的信息
- **24小时财经信息**：不断刺激近因效应
- **利益相关方利用**：标题党、基金公司推热点主题基金，都在刻意放大近因效应
- **信息环境的结构性角色**：近因效应不仅是认知偏差，更是现代信息过载时代的产物——减少信息暴露比增加信息更有价值

## 边界条件

| 条件 | 近因效应强度 |
|------|-------------|
| 信息稳定（长期基本面投资） | 较弱 |
| 信息爆炸 + 市场快速轮动 | 极强 |
| 震荡市 / 轮动市 | 极强 |
| 强趋势牛市（如2006-2007） | 可能产生误判，但趋势本身有效 |

## 对抗方法

**对抗 = 信息过滤 × 目标清晰 × 纪律执行**

1. **减少信息暴露**：控制输入频率，不被24小时资讯流裹挟
2. **甄别信息**：有选择地过滤，不是所有新闻都有决策价值
3. **保持投资纪律**：不要因为短期波动改变策略
4. **建立长期视角**：关注长期规律，不被眼下事件绑架

关键：**过滤**而非**屏蔽**。你需要足够的信息做判断，但不要被信息淹没。
