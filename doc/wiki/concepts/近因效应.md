# 近因效应

大脑天然给近期信息赋予更高权重，使人将最近发生的事误判为最重要或最具预测性的认知偏差。这是追涨杀跌行为的心理根源。

## 定义

**形式化**：近因效应 = 近期信息 > 历史信息；导致 = 过度乐观/悲观

**来源**：心理学中的"系列位置效应"——开头和结尾的内容更容易被记住。近因效应对应"最近印象"，与"首因效应"（第一印象）相对。

**投资语境**：
- 短期业绩好的基金让人忽略长期表现差的基金
- "一根阳线改变情绪，两根改变观念，三根改变信仰"
- 连续上涨让人觉得趋势永续，连续下跌让人绝望离场

## 机制

```
市场快速轮动 / 信息爆炸
    ↓
近期事件在记忆中高度活跃
    ↓
大脑错误地赋予近期事件更高权重
    ↓
线性外推（把近期趋势当成长期规律）
    ↓
追涨杀跌行为
```

## 为什么难以克服

近因效应是人类进化出的认知捷径——快速反应比全面分析在生存上更有优势。因此它不是 bug，是 feature。

影响因素：
- **信息量越大，影响越强**：大脑处理不过来，只能依赖最近的信息
- **24小时财经信息**：不断刺激近因效应
- **利益相关方利用**：标题党、基金公司推热点主题基金，都在刻意放大近因效应

## 边界条件

| 条件 | 近因效应强度 |
|------|-------------|
| 信息稳定（长期基本面投资） | 较弱 |
| 信息爆炸 + 市场快速轮动 | 极强 |
| 震荡市 / 轮动市 | 极强 |
| 强趋势牛市（如2006-2007） | 可能产生误判，但趋势本身有效 |

## 对抗方法

**对抗 = 信息过滤 × 目标清晰 × 纪律执行**

- 有选择地甄别信息——不是所有新闻都重要
- 认清自己的投资目标——长期还是短期？
- 保持投资纪律——不要因为短期波动改变策略
- 不要忘记长期事物发展的规律——市场有周期，行业有轮动

关键：**过滤**而非**屏蔽**。你需要足够的信息做判断，但不要被信息淹没。
