# 知识库标签索引系统

> 关联来源：[[5-notes--4-标签索引--1bygpru]]

这是一个基于标签体系的知识库元索引，用于对 657 篇笔记进行多维度分类和快速定位。

## 标签维度

索引使用多个独立维度，每条笔记可归属于多个维度：

1. **type/** — 笔记内容类型（qa / reading / concept / book / invest-analysis / plan / invest-note）
2. **domain/** — 领域（invest / photo / industry / ai / media / social-media / tech）
3. **asset/** — 资产类别（fund / qdii / bond / equity / index-fund / dividend / gold / nasdaq / etf / hk-stock / money-fund）
4. **topic/** — 主题标签（risk / style-box / factor / active-passive / fund-selection / allocation / behavior / macro / timing / retirement / valuation 等 20+ 主题）
5. **entity/** — 实体关联（morningstar / buffett / meituan / nasdaq100 / nikon 等）
6. **自定义文件夹** — AI-Agent / DoorDash / product-philosophy / 软件架构

## 设计意图

- `type/qa` 占主导（69%），说明知识库以问题驱动方式积累知识
- `domain/invest` 占绝对多数（96%），投资是唯一主轴
- `topic/` 层支持细粒度检索，将跨资产、跨域的主题聚合在一起
- `entity/` 层将分散在多篇笔记中的实体知识汇聚成可导航的实体中心

## 与 Wiki 的关系

该索引是本笔记库的**原始目录**，Wiki 页面是从中抽出的结构化知识。两者存在系统性覆盖差：索引中有大量 entity（美团、腾讯、小米、纳斯达克100、北交所）在 `entities/` 中有页面，但部分概念和来源尚未同步到 Wiki。
