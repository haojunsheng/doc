# 诊断型知识 vs 鉴赏型知识

## 定义

摄影学习中两种不同性质的"知识层"认知：

- **诊断型知识**：知道一张照片为什么不好（收敛性，原因有限）
- **鉴赏型知识**：知道一张照片为什么好（发散性，原因无限）

## 核心差异

| | 诊断型知识 | 鉴赏型知识 |
|---|---------|---------|
| 对象 | 废片/问题照片 | 好照片/优秀照片 |
| 方向 | 为什么不好？ | 为什么好？ |
| 原因数量 | 有限（对焦错/快门慢/过曝等） | 无限（光线+构图+时机+情绪...） |
| 学习时间 | W2 阶段建立 | W3 阶段开始建立 |
| 难度 | 较低（原因收敛） | 较高（原因发散） |

## 与 DIKW 模型的关系

[[DIKW模型-研究方法论]]框架下，两者都属于 K 层（知识层），但处于不同深度：

- 诊断型知识：K 层浅处——能把规则和具体废片对应起来
- 鉴赏型知识：K 层深处——能提炼出好照片的构成因素，并迁移到新场景

## Z30 学习计划中的应用

| 周 | 知识类型 | 示例 |
|----|---------|------|
| W2 | 诊断型 | "这张不是快门问题，是对焦对到了栏杆上。下次切换单点对焦。" |
| W3 | 鉴赏型 | "这张好在哪？视线引导 + 留白 + 层次——我可以复用这个思路吗？" |
| W5 | 鉴赏型深化 | "这张照片三个标准：光线方向明确、视线有流动路径、主体与环境的对比关系强。" |

## 学习启示

1. 废片分析比好照片分析更容易入门——从诊断型知识开始建立学习信心
2. 鉴赏型知识需要大量输入——每周看 100 张高赞照片并逐张分析是最短路径
3. 事后反思比记录废片更有价值——"我为什么觉得这张好，后来再看就不好了"是鉴赏型知识成长的证据
