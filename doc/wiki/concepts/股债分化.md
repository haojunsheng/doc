# 股债分化

**股债分化**是指股票资产与债券资产在同一时期内呈现方向性背离的市场格局，是最基础的资产分化形态。与"股债双杀"（双跌）、"股债双收"（双涨）不同，股债分化的特征是某一类资产上涨而另一类下跌或持平，形成"此消彼长"的零和结构。

## 两种基本形态

### 股强债弱（风险偏好提升期）

典型驱动路径：
```
关税缓和/政策利好 → 风险偏好↑ → 资金从债市流向股市
            → A股涨 1-2%
            → 债市收益率：短端↓（资金面宽松）/ 长端↑（风险偏好↑）
            → 收益率曲线陡峭化
```

**5 月案例（2025 年 5 月）**：
- A 股主要指数涨 1-2%
- 中证全债指数微跌 -0.06%
- 可转债基金 +1.75%（双重受益）
- 利率债基金 -0.19%（受压制）

### 股弱债强（风险偏好下降期）

典型驱动路径：
```
关税冲击/地缘风险/经济数据疲软 → 风险偏好↓ → 资金从股市流向债市
    → 债市收益率下行 → 债券价格上涨
    → 权益市场承压
```

**2025 年 4 月案例**（[[sources/5-notes--51-20260614t220915-qa-4月股债分化大盘价值占优qa--y5oy58]]）：
- A 股：上证指数 -1.70%，深证成指 -5.75%
- 中证全债指数 +1.41%
- 10 年期国债收益率下行 19bp 至 1.62%
- 驱动机制：美国对中国额外加征 34% 关税 → 制造业 PMI 回落至 49.0% → 避险资金涌入债市

**2025 年 3 月案例**（[[sources/5-notes--40-20260614t220920-qa-3月股债震荡分化qa--1ed7we5]]）：
- A 股：上证指数 +0.45%，深证成指 -1.01%
- 中证全债指数 -0.50%
- 特征：两会利好大盘蓝筹，关税压制中小盘

**2025 年 1 月案例**（[[sources/5-notes--38-20260614t220928-qa-1月股债分化中小盘成长qa--1uf8kn8]]）：
- A 股：上证指数 -3.02%，深证成指 -2.48%
- 固收类基金全数收涨：可转债（+1.64%）> 普通债券（+0.21%）> 积极债券（+0.20%）> 利率债（+0.09%）> 纯债（+0.08%）
- 特征：中小盘成长风格逆势+0.77%，政策驱动是关键变量

## 特殊形态：股债跷跷板脱钩

**股债跷跷板脱钩**是指股票和债券在风险事件冲击下不再呈现传统的负相关关系——即股市下跌时，债券不涨反跌或表现异常，股债之间的"跷跷板"机制失效。这是股债分化的一种极端形态，通常出现在关税+通胀突变等结构性冲击场景中。

### 2025年1-4月特朗普关税冲击案例

**驱动路径**：
```
关税政策宣布 → 通胀预期↑ → 美债从避险资产变成抛售对象
              → 30年期收益率4天飙升45bp（1990年来仅3次）
              → 机构为应对赎回加速抛售 → 负反馈循环
```

**数据**：
- 标普最大回撤19.4%，距熊市仅0.6个百分点
- 68个交易日中10天涨跌幅≥2%，占比15%（2024年仅3%）
- 晨星上调美国通胀预期0.6个百分点

**边界条件**：当市场认为关税是短期冲击而非持续通胀压力时，美债避险属性会恢复；若政策明朗化且不再反复摇摆，波动率会显著下降。

## 固收内部的进一步分化

股弱债强情境下，固收内部同样存在结构性差异：

**2025 年 4 月**（关税冲击）：
```
固收五档排序：
  利率债基金（+0.90%）> 纯债基金（+0.61%）> 信用债基金（+0.49%）> 短债基金（+0.32%）> 可转债基金（-1.29%）
```

**2025 年 3 月**（政策利好+关税并存）：
```
固收五档排序：
  信用债基金（+0.21%）> 短债（+0.20%）> 纯债（+0.11%）> 利率债（-0.08%）> 可转债（-0.73%）
```

**2025 年 1 月**（宽松预期抢跑）：
```
固收五档排序：
  可转债（+1.64%）> 普通债券（+0.21%）> 积极债券（+0.20%）> 利率债（+0.09%）> 纯债（+0.08%）
```

## 形式化表达

```
股债分化程度 = f(风险偏好变化, 政策周期, 利差变动)

股强债弱时：
  固收+策略 = 纯债（微跌） + 权益增强（涨 1-2%）
  → 权益暴露越高，弹性越大，回撤也越大

股弱债强时：
  → 权益暴露越低越好
  → 利率债基金表现最优（+0.90%）或信用债最优（+0.21%），取决于信用风险状态
  → 宽松预期抢跑期可转债表现最优（+1.64%）
```

## 投资决策含义

1. **股强债弱时**：固收+产品需要更高权益暴露才能跑赢纯债，但承担更高风险
2. **股弱债强时**：降低权益暴露是优先选项，避免"固收-"
3. **可转债的特殊地位**：在宽松预期抢跑期因估值扩张表现最优（+1.64%），但在关税冲击等风险偏好下降期承受最大拖累（-1.29%）
4. **3月特殊提示**：政策利好与利空并存时，分化而非单边行情，需区分驱动源
5. **1月重要发现**：股市下跌≠所有基金亏钱，固收类基金可作为有效避风港
6. **跷跷板脱钩警示**：在关税+通胀双重冲击下，股债可能同跌，传统的60/40组合失效

## 边界条件

- 股债分化格局通常由外部冲击（关税、地缘）或内部政策（降准降息）驱动
- 若宏观驱动因素反转，分化格局可能迅速收敛
- 分化期间，固收+产品的权益暴露度是决定相对表现的关键变量
- 短期规律不代表长期优势，需结合月度数据验证
- **3月特殊性**：政策利好与利空并存导致分化而非单边行情
- **跷跷板脱钩条件**：当通胀预期上调幅度足够大时，美债避险属性可能失效，传统股债分化格局被打破
