# 中等波动固收+

在波动市场中，**中等波动固收+**是风险收益比最优的产品定位：权益仓位 20-30%，债券打底 70-80%。既不过于保守（收益接近纯债），也不过于激进（回撤接近股票）。

## 核心框架

**形式化表达**：
```
中等波动固收+ = 债券（70-80%）打底 + 股票（20-30%）增强 → 稳健 + 弹性
攻 = 股票配置 → 追求资本利得 + 股息收益
守 = 高等级债券 → 票息稳定 + 低违约风险 → 降低波动
```

| 波动档位 | 权益仓位 | 特征 | 适用场景 |
|---------|---------|------|---------|
| 低波动 | ≤10% | 收益接近纯债，无法满足收益需求 | 极度避险环境 |
| 中等波动 | 20-30% | 风险收益比最优，攻守兼备 | 波动市场（震荡市） |
| 高波动 | >30% | 回撤接近股票，偏离稳健目标 | 牛市预期强烈时 |

**边界条件**：最优波动水平因人而异，取决于投资者的风险承受能力。

## 进攻端：权益增强逻辑

- 精选**低估值+高股息**股票，追求长期资本利得和股息收益
- 低估值 = 安全边际高，下跌空间有限
- 高股息 = 稳定现金流，降低组合波动
- **边界条件**：市场风格不利于价值股时，进攻效果不佳

## 防守端：债券打底逻辑

- 配置**高等级债券**，获取稳定票息
- 票息收益不受股市波动影响
- 债券与股票相关性低，分散风险
- **边界条件**：利率大幅上升时，债券价格下跌，防守效果减弱

## 回撤控制三要素

回撤控制 = 股债比例限制 + 止损机制 + 分散投资

1. **股债比例限制**：股票仓位上限约 30%，避免过度暴露股市风险
2. **止损机制**：设置止损线，及时止损避免深度回撤
3. **分散投资**：行业分散 + 债券品种分散

**边界条件**：系统性风险（如 2022 年股债双杀）时，回撤控制可能失效。

## 筛选评估三标准

评估一只固收+基金：**基金经理经验 + 历史最大回撤 < 10% + 股债比例合理**

**边界条件**：历史回撤不代表未来，需结合市场环境判断。"最大回撤<10%"为参考性阈值，无统一量化来源。

## 最优市场环境

**最佳环境**：股市震荡（非单边熊市）+ 利率稳定（非大幅加息）

在此环境下，债券提供稳定收益，股票提供弹性收益，两者叠加效果最优。

**边界条件**：
- 单边牛市 → 固收+跑输纯股票
- 单边熊市 → 固收+受股票拖累
- 大幅加息 → 债券部分承压

## 费率影响

固收+基金费率通常 0.5-1.0%，长期复利效应显著，与 [[concepts/费率复利效应]] 直接呼应。

## 适合的投资者

- 风险承受能力中等
- 追求稳健收益
- 不想承受股市大幅波动
