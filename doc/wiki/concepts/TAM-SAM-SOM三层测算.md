# TAM / SAM / SOM 三层测算

将市场规模从宏观到微观逐层收敛的分析框架：**潜在市场（TAM）→ 可服务市场（SAM）→ 可获得市场（SOM）**。

## 三层结构

```
┌─────────────────────────────────────────┐
│  TAM：潜在市场总量                        │
│  ┌─────────────────────────────────┐    │
│  │  SAM：可服务市场（品类/地区筛选）  │    │
│  │  ┌───────────────────────┐      │    │
│  │  │  SOM：可获得市场       │      │    │
│  │  └───────────────────────┘      │    │
│  └─────────────────────────────────┘    │
└─────────────────────────────────────────┘
```

## 即时零售应用实例

| 层级 | 定义 | 数值 |
|:---|:---|:---|
| TAM | 本地零售全量（社零） | ≈ 40-45 万亿 CNY |
| SAM | 适合即时的品类（生鲜+日百+医药+快消） | ≈ 10-15 万亿 |
| SOM | 2025 实际 GMV | ≈ 1.0-1.2 万亿 CNY |

关键比率：
- SAM ÷ TAM ≈ 25-35%（品类可线上化率）
- SOM ÷ SAM ≈ 8-12%（渗透率）
- SOM ÷ TAM ≈ 2-4%（极小，代表巨大空间）

## 三种交叉验证方法

| 方法 | 逻辑 | 2025E GMV |
|:---|:---|:---|
| 需求导向 | 城镇家庭 4.9 亿户 × 渗透率 × 50 次/年 × 55 元 | ≈ 0.8-1.2 万亿 |
| 供给导向 | 主流平台加总 | ≈ 0.9-1.1 万亿 |
| 对标成熟市场 | 韩/日/美即时零售占社零 8-12%，中国若达 3-5% | ≈ 1.2-2.0 万亿 |

## 天花板推算

| 场景 | 假设 | GMV |
|:---|:---|:---|
| 乐观 | SAM/TAM 40% × SOM/SAM 30% | ≈ 5 万亿 |
| 中性 | SAM/TAM 30% × SOM/SAM 20% | ≈ 3 万亿 |
| 保守 | 品类瓶颈 | ≈ 1.5 万亿 |

## 使用要点

1. **口径一致性**：TAM/SAM/SOM 必须用同一统计口径（社零/网上零售/本地生活），否则比值无意义
2. **渗透率口径敏感性**：详见 [[渗透率口径敏感性]]
3. **动态修正**：SOM 随品类扩张（从生鲜→3C→万物）上移，SAM 也随之扩大
