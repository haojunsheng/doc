# 分散化对冲逆向风险

## 定义

逆向投资天然带有判断错误的高风险——你可能在"价值陷阱"中越跌越买。分散化是应对这一风险的结构性工具：通过持有足够多的逆向标的，用大数定律让少数正确判断覆盖多数错误。

## 核心机制

```
逆向投资 × 分散持仓 = 少数大赚覆盖多数小亏
```

邓普顿1939年的经典案例是这一机制的实证：他买入104只股价低于1美元的股票，其中100只盈利、4只亏损，整体大赚。如果他只买了3-5只，一旦某只继续下跌，损失将不可挽回。

## 适用边界

| 条件 | 说明 |
|------|------|
| 标的数量 | 逆向投资需要足够多的标的（通常20+）才能有效对冲单票判断错误的风险 |
| 时间耐心 | 分散化不能消除方向性判断错误的风险——如果整个市场继续下跌，所有标的都会亏 |
| 信息优势 | 邓普顿日本案例中的"隐藏价值"发现依赖于深度研究，普通投资者难以复制 |

## 与相关概念的区分

- [[分散化-起源与原理]]：分散化的普遍原理，不限定投资风格
- [[风格逆风与能力不足]]：分散化可以缓解"风格逆风"的单票冲击，但不能解决风格判断错误的问题
- [[虚假的逆向]]：虚假的逆向者往往用"集中押注一只标的"来证明自己"与众不同"，这与分散化对冲逆向风险的思路背道而驰

## 对普通投资者的启示

邓普顿的分散化逆向策略对个人投资者而言门槛较高——需要研究能力发现"隐藏价值"，需要纪律承受短期浮亏，需要资金量支持足够分散的持仓。

因此，[[逆向投资]] 对普通人的真正价值不在于执行"逆向交易"，而在于采用[[虚假的逆向]]所警示的"思考习惯"：主动寻找反面证据，避免单一叙事的群体盲从。
