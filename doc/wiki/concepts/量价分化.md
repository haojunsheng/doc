# 量价分化

旧周期量价同向，新周期量跌价升的分析框架。用于识别行业从景气上行转入结构性收缩阶段。

## 核心框架

```
旧周期：量↑ 价↑ → 新周期：量↓ 价↑（提价补量）
```

在行业景气上行期，销量和价格同向增长，企业轻松获得收入增长；进入结构性收缩期后，销量下滑成为常态，企业只能通过提价来维持收入，量价关系发生根本性反转。

## 白酒行业的量价分化

| 周期阶段 | 销量趋势 | 价格趋势 | 增长驱动 |
|----------|----------|----------|----------|
| 旧周期（2021年前） | 增长 | 上涨 | 量价齐升 |
| 新周期（2021年起） | 下滑/停滞 | 上涨 | 高端化提价 |

- 前十大企业占 54% 份额，高端三家占 95%——集中度提升使提价能力集中在头部
- 行业收入 CAGR 从 4.2% 降至 3.5%，量跌价升勉强维持正增长

## 应用价值

量价分化是判断行业是否进入"结构性收缩而非周期性波动"的关键信号：

1. 若量价持续背离（量跌价升），说明需求端已发生结构性变化
2. 此时靠"估值低"或"跌得多"来判断底部是无效的
3. 需等待供需再平衡（产能出清或需求恢复）才能确认底部
