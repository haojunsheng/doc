# 关税的税负归宿

关税的最终承担者是本国消费者，而非外国政府。这是理解关税政策经济影响的第一个核心框架。

## 核心定义

关税不是寄给外国政府的账单，而是进口企业向本国政府缴纳的税金。进口企业面临三种成本吸收路径：

1. **自担利润**：进口企业压缩自身利润率
2. **降薪裁员**：将成本转嫁给内部员工
3. **提价转嫁**：提高售价，由消费者买单

无论哪条路径，**最终负担都落在本国消费者身上**，因此关税实质上是一种"隐形消费税"。

## 形式化表达

```
关税
  → 进口企业缴纳
  → 三种吸收路径：自担利润↓ / 降薪裁员 / 提价转嫁
  → 消费者最终买单
```

## 实证案例

- **进口铝25%关税**：饮料罐、汽车零部件等全链条涨价
- **进口洗衣机**：进口型号 $500 → $650，本土品牌 $520 → $600 跟随涨价
- 本土品牌虽不受直接关税影响，但借机提价，进一步推高消费者负担

## 边界条件

- **需求弹性极大时**：若进口商品需求弹性极大（卖不出去），企业被迫自己吸收成本，税负归宿回流至企业自身
- **定价权差异**：拥有定价权的企业（[[定价权企业-保护主义环境下的投资选择]]）更能通过提价转嫁成本；缺乏定价权的企业只能压缩利润

## 投资意义

理解关税税负归宿，才能正确评估关税政策对企业盈利的真实影响——不能简单地将"关税取消"等同于"进口企业利润提升"，需具体分析企业的成本转嫁能力和估值水平（参见 [[估值>利好-宏观噪音与企业基本面]]）。
