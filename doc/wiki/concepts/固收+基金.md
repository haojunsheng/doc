# 固收+基金

"固收+"是一类以固定收益资产为底仓、通过配置权益或另类资产获取收益增强的混合策略基金。

## 基本结构

典型的固收+组合结构：

```
固收+ = 信用债/利率债底仓（70-90%）
      + 权益增强仓位（10-30%，如可转债、股票）
```

底层以债券票息收益为目标，上层通过权益仓位获取弹性。

## 常见增强手段

| 增强手段 | 风险特征 | 典型案例 |
|----------|----------|----------|
| 可转债仓位调节 | 与权益市场高度相关，牛熊影响大 | [[鹏华产业债债券]] |
| 信用下沉 | 提升票息但增加违约风险 | [[信用下沉]] |
| 利率债波段 | 依赖宏观利率判断能力 | [[利率债波段操作]] |
| 股票配置 | 直接暴露权益风险 | [[中等波动固收+]] |

## 核心能力要素

1. **信用研究能力**：识别和规避信用风险，是底仓安全的基础
2. **择时能力**：对权益市场的判断决定增强仓位的成败
3. **回撤控制**：股债跷跷板效应下，需要平衡收益与波动

## 与纯债基金的区别

| 维度 | 纯债基金 | 固收+基金 |
|------|----------|-----------|
| 权益仓位 | 0% | 10-30% |
| 收益来源 | 票息 + 利率价差 | 票息 + 权益增强 |
| 波动水平 | 较低 | 中等 |
| 信用风险 | 有 | 有，且可能更高 |
| 利率风险 | 主要风险 | 次要风险 |

## 已知风险

- **转债仓位偏高**：如[[鹏华产业债债券]]可转债均15% vs 同类6%，牛市增强明显，熊市拖累显著
- **择时失败放大损失**：对权益趋势判断失误会直接侵蚀底仓收益
- **费率劣势**：主动管理能力要求更高，费率往往高于纯债基金
