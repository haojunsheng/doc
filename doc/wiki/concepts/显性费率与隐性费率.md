# 显性费率与隐性费率

基金的持有成本分为两个层次：**显性费率**（明码标价）和**隐性费率**（藏在交易和运营里）。两者共同构成投资者的综合成本。

## 费率结构

```
综合费率 = 显性费率（~70%）+ 隐性费率（~30%）
```

### 显性费率

在买基金时即"明码标价"，主要包括：

| 费用项 | 说明 |
|--------|------|
| 管理费 | 基金公司收取，显性费率中占比最大 |
| 托管费 | 托管银行收取 |
| 销售服务费 | 销售渠道收取 |

显性费率是投资者最容易感知和比较的成本，也是 2023 年降费改革的主要目标。

### 隐性费率

基金年报/半年报的会计报表中才能看到，主要包括：

- **交易成本**：佣金 + 印花税 + 价差成本，约占隐性费率的近三成。与基金换手率正相关——换手率越高，交易成本越高。
- **其他运营费用**：审计、信息披露等日常支出。

隐性费率常被投资者忽略，导致低估真实持有成本。若市场波动加大导致换手率上升，隐性费率可能不降反升，抵消显性费率下降的效果。

## 关键洞察

**费率是确定的成本，收益是不确定的。** 投资者无法控制未来收益，但可以控制持有成本。在相同的预期收益下，费率越低，到手收益越高；长期复利下，费率差异的影响被显著放大。

降费改革的核心逻辑之一正是通过压缩显性费率，让基金公司的收入来源从"规模驱动"转向"业绩驱动"——只有做出好业绩，投资者才会留资或追投，从而实现利益绑定。

## 与 [[交易成本]] 的关系

交易成本是隐性费率中最主要的组成部分，由换手率驱动。详见 [[交易成本-指数调仓冲击]] 页面。

## 边界条件

- 1.41% 是 2022 年平均综合费率（规模加权，不含货币基金），不同类型基金费率差异很大。
- 隐性费率的变化方向不确定：降费改革压缩了显性费率，但若市场波动导致换手率上升，隐性费率可能回升。
