# 跌势不等于见底

股价下跌 ≠ 基本面见底，供需再平衡需要时间。抄底需看供需而非只看估值。

## 核心论点

白酒板块从 2021 年高点跌近四年、股价腰斩，但晨星的判断是**抄底为时尚早**。原因：

1. **需求端压力未出清**：人口红利消退、年轻人饮酒率下降是长期趋势
2. **供给端仍在扩张**：前 20 大酒企计划十年内产能增加 ≥50%，供需失衡加剧
3. **利润与估值分离**：高端化提价能保利润，但保不住估值

```
股价腰斩 ≠ 见底（需求压力未解 + 扩产周期未结束）
```

## 深层逻辑

估值便宜只是表象，真正决定底部的是**供需再平衡**：

- 旧思维：跌多了就是便宜 → 买入
- 新思维：供需没再平衡之前，便宜可以变得更便宜

## 与投资者回报差的关系

[[投资者回报差]] 揭示的"高买低卖"行为模式，在此得到又一次印证：投资者往往在跌势中因"估值便宜"而冲动入场，却忽视了需求端的结构性恶化尚未逆转。

## 判断底部的正确框架

| 错误做法 | 正确做法 |
|----------|----------|
| 看股价跌幅判断底部 | 看供需格局是否再平衡 |
| 看 PE/PB 估值判断便宜 | 看产能出清进度和需求拐点 |
| 被"跌了四年"叙事驱动 | 等待量价分化趋势逆转信号 |
