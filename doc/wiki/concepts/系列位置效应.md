# 系列位置效应

记忆材料中开头和结尾更容易被记住，中间部分容易被遗忘的心理现象。这是近因效应和首因效应的共同心理学根基。

## 定义

**提出者**：赫尔曼·艾宾浩斯（Hermann Ebbinghaus），1885 年《记忆》（*Memory*）一书中通过系列位置实验确立。

**形式化**：在一组序列材料中，回忆正确率呈 U 型曲线——开头项和结尾项的回忆率显著高于中间项。

- **首因效应**（primacy effect）：开头项回忆率最高，对应"第一印象"
- **近因效应**（recency effect）：结尾项回忆率最高，对应"最近印象"

## 在投资中的应用

| 场景 | 表现 |
|------|------|
| 基金评价 | 投资者对基金经理的评价往往基于最近 3 个月业绩，而非 3 年 |
| 基金销售 | 销售人员展示"最近一年业绩"——利用近因效应 |
| 交易决策 | 连续上涨后过度乐观，连续下跌后过度悲观 |

## 边界

- 首因效应在"初次接触"时作用最强（如第一次买某只基金）
- 近因效应在"持续过程"中作用更强（如每天看盘、持续跟踪基金）
- 投资是持续过程，因此近因效应通常影响更大
