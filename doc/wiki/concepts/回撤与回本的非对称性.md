# 回撤与回本的非对称性

净值下跌后恢复所需的涨幅，与下跌幅度呈非对称关系——这是理解基金回本难度的核心数学规律。

## 数学关系

回撤 d% 后，需要上涨的百分比为：

```
需要上涨百分比 = d / (1 - d) × 100%
```

| 回撤深度 | 回本所需涨幅 |
|---------|------------|
| 30%     | 42.9%      |
| 50%     | 100%       |
| 70%     | 233%       |
| 80%     | 400%       |

回撤越深，回本难度呈指数级上升。回撤50%意味着需要翻倍才能回本，这是大多数基金难以跨越的障碍。

## 与投资实践的关系

- **控制回撤比追求高收益更重要**：一次深度回撤可能需要数年甚至无法恢复
- **指数恢复 ≠ 基金回本**：上证指数回到高点，不代表持仓基金净值也回到高点
- **分红可降低回本门槛**：持续分红的基金，回本所需的净值涨幅会相应降低
- **基金经理的稳定性至关重要**：换人后历史回撤数据不再具有参考价值

## 与 [[波动拖累]] 的关系

[[波动拖累]]（Volatility Drag）描述的是波动本身对复合收益率的侵蚀效应，与本文的"回撤-回本非对称性"是两个层面的问题：前者关注波动率对长期复利的影响，后者关注单次回撤后恢复的难度。两者共同解释了为何高波动策略的长期表现往往不及预期。
