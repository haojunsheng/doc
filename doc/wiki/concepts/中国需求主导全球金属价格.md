# 中国需求主导全球金属价格

**中国需求主导全球金属价格**是理解工业金属定价的核心前提：中国贡献了全球铜和铁矿石需求增长的几乎全部。

## 形式化表达

```
中国→全球50%钢铁消费 + 70%贸易铁矿石 + >50%精炼铜需求 ⊃ 金属价格看中国
```

## 关键数据

| 指标 | 中国占比 | 说明 |
|------|---------|------|
| 钢铁消费 | >50% | 全球最大钢铁生产国和消费国 |
| 贸易铁矿石 | 70% | 国内储量有限且品位低，高度依赖进口 |
| 精炼铜需求 | >50% | 矿山铜供应占全球不足10% |

## 边界条件

1. 若中国加速向低大宗商品依赖转型，此逻辑弱化
2. 若印度等国的需求能替代中国，此逻辑弱化
3. 经济转型速度多快？目前无明确数据锚点
