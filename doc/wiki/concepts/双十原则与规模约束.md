# 双十原则与规模约束

"双十原则"是中国基金行业监管规则，构成中小盘基金的天然规模天花板。

## 规则定义

```
双十原则 = 
  (1) 单只股票持仓 ≤ 10% 基金净值
  (2) 同一股票全公司持仓 ≤ 10% 该股票总市值
```

## 对中小盘基金的约束机制

中小盘股票市值小，基金规模一旦增长，很快触及上述两个上限：

**场景推演**：
1. 基金规模从10亿增至50亿
2. 买入某只5亿市值的中小盘股，持仓已达10%净值上限
3. 无法继续加仓 → 只能寻找更多标的或买次优股票
4. 最终被迫配置大盘蓝筹股 → 投资风格"变味"

```
中小盘股市值小 → 容量上限低
    ↓
基金规模↑ → 单只股票快速达到10%净值上限
    ↓
被迫配置大盘股或次优标的
    ↓
风格漂移 / 业绩稀释
```

## 与策略容量的关系

[[策略容量瓶颈]] 从资金端视角解释规模与业绩的反向关系，双十原则则是这一机制的具体监管体现：

| 维度 | 策略容量瓶颈 | 双十原则 |
|------|------------|---------|
| 角度 | 资金流入 vs 标的数量 | 监管硬性约束 |
| 性质 | 描述性机制 | 规则性约束 |
| 结果 | 被迫持有现金或降低标准 | 被迫买大盘股或次优标的 |

## 案例

晨星文章引用案例：某中小盘基金规模暴增后，从"大盘成长"逐渐漂移向"超大盘成长"——双十原则迫使基金经理放弃原有策略能力圈。

## 边界条件

- **大盘蓝筹股**：市值大、流动性好，双十原则约束较弱，规模增长空间大
- **量化基金**：通过模型优化可分散持仓，双十原则约束相对弱化
- **债券基金**：不受双十原则约束（持仓上限规则不同）

## 与基金限购的关系

双十原则是中小盘基金限购的**技术性原因**：

```
规模增长 → 触及双十原则上限 → 无法有效配置 → 收益被稀释
    ↓
基金经理决策：限购（控规模保业绩）vs 扩规模（调策略）
    ↓
多数专业经理选择：限购
```
