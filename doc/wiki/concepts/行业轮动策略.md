# 行业轮动策略

行业轮动策略是指根据市场环境在不同行业间调整配置，以把握不同阶段的投资机会。

## 核心逻辑

```
行业轮动 = 判断市场节奏 + 调整行业配置
```

## 策略特点

- 主动管理型基金常用的策略之一
- 依赖基金经理对市场周期的判断能力
- 在不同经济阶段配置表现优异的行业

## 风险与边界

- **择时风险**：行业轮动高度依赖对市场节奏的判断，判断错误会显著拖累业绩
- **交易成本**：频繁调仓会带来较高的换手率和交易成本，需参考 [[换手率与交易成本]]
- **风格稳定性**：频繁的轮动可能影响 [[风格稳定性]]
- **追涨反身性**：过去十年领涨行业逐年切换（白酒→新能源→煤炭→通讯→金融地产→创新药），无一行业连续三年领先——追涨即接盘，[[预测的自我毁灭性]] 在此处显现

## 十年行业轮替实证

| 年份 | 领涨行业 |
|------|---------|
| 2020 | 白酒、互联网 |
| 2021 | 新能源 |
| 2022 | 煤炭 |
| 2023 | 通讯 |
| 2024 | 金融地产 |
| 2025 | 创新药 |

数据来源：[[sources/5-notes--35-20260628t154500-qa-行业基金是组合必需品吗qa--8xk2zm]]

## 行业分散的量化局限

消费、医药等热门行业与沪深 300 相关系数 > 0.7，行业基金本质是"影子大盘"，多付管理费买入同一篮鸡蛋，分散效果接近零。真正的风险降低靠跨资产类别分散，而非同一资产内的行业轮动。参见 [[资产配置优先原则]]。

## 典型应用

[[广发优企精选灵活配置混合]] 采用"灵活配置 × 优质企业 × 行业轮动"的策略公式，是行业轮动策略的典型应用。

## 与相关概念的对比

- 与 [[逆向投资]] 相比：行业轮动关注"何时换行业"，逆向投资关注"何时买被错杀的好公司"
- 与 [[大盘价值风格的防御性]] 相比：行业轮动追求进攻性收益，价值风格更注重防御性
- 与 [[赛道轮动]] 相比：两者高度重合，赛道轮动强调产业趋势维度，行业轮动更偏宏观周期维度
