# 被动与指数的语义陷阱

同一个投资策略，不同名称 → 选择率差异可达 50%。语义本身的正面/负面暗示直接影响投资决策。

## 核心命题

```
"被动投资" = 指数投资
  → "被动"在社会语境中是负面词（消极、懒惰、不积极）
  → 人们不愿被认为"被动"
  → 选择"被动投资"的人数较少

"指数投资" = 指数投资
  → "指数"是中性技术描述词，无情感负担
  → 选择"指数投资"的人数可能多 50%

→ 同一策略，不同名称，不同采纳率
```

## 行为金融学基础

投资决策不只由理性计算驱动，还受情感和语义框架影响。这与以下概念一脉相承：

- [[concepts/参考点依赖]] — 同一结果因表述方式不同而被不同评估
- [[concepts/后悔厌恶-投资语境]] — 人们为避免后悔而做出非理性决策
- [[concepts/选择过载]] — 选项命名方式影响选择倾向

## 启示

1. **语言即框架**：命名的选择本身就是投资决策的变量，不应忽视
2. **投资者教育**：用中性或正面词汇描述策略，可降低采纳阻力
3. **自我觉察**：意识到语义影响后，有意识地剥离名称做实质判断

## 边界条件

此效应在语义敏感人群中更明显。对已理解指数投资优势的投资者，名称影响不大。
