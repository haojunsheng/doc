# 债券被动化分化框架

**债券被动化分化框架**是指中国债券市场被动投资（ETF及指数基金）在不同债券类型之间呈现显著非均匀进度的分析框架——标准化程度高的债券先行被动化，差异化大的债券仍由主动管理主导。

## 被动化梯度

| 债券类型 | 被动占比 | 驱动原因 |
|---------|---------|---------|
| 利率债（国债/政金债） | **49%** | 发行主体集中、券种少、流动性好、指数复制成本低 |
| 可转债 | **42%** | 极端集中（仅两只ETF），T+0交易+低费率吸金效应强 |
| 信用债（企业债/中票/城投债） | **<20%** | 主体分散、信用差异大、估值不连续、跟踪误差高 |
| 纯债基金 | **2%** | 主动超额空间大，投资者愿付管理费获取超额 |
| 固收+ | 0% | 跨资产跟踪复杂度超出当前被动管理能力 |
| QDII环球债券 | 0% | 跨国利率/信用/汇率三重跟踪难度极高 |

## 核心解释变量

被动化进度的决定性因素是**标准化程度**：

- 标准化程度高 → 券种少、发行主体集中、流动性好 → 指数复制成本低、跟踪误差小 → 被动化快
- 标准化程度低 → 主体分散、信用资质差异大、估值不连续、流动性差 → 指数复制成本高、跟踪误差大 → 被动化慢

## 演进方向

若以下条件改善，被动化比例将提升：

1. 信用债市场流动性改善
2. 信用评级体系更加完善
3. 债券市场透明度提升
4. 被动管理技术（如跨资产跟踪）发展

若利率反转上行，主动基金经理久期操作空间扩大，被动优势可能减弱——这意味着债券被动化进展可能是**周期性的**而非永久性的趋势。
