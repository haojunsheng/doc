# PERMA-V 模型

Martin Seligman 提出的幸福六维度框架，用于拆解"人生目标"，避免将财富积累当作唯一追求。

## 定义

```
PERMA-V = P(正向情绪) + E(全心投入) + R(人际) + M(意义) + A(成就) + V(活力)
```

| 维度 | 含义 | 退休场景中的典型资金需求 |
|------|------|------------------------|
| **P - 正向情绪** | 日常积极情感体验 | 旅行、休闲、兴趣爱好 |
| **E - 全心投入** | 心流状态、沉浸体验 | 学习课程、创作设备、会员订阅 |
| **R - 人际** | 社交关系与归属感 | 家庭活动、社交支出、礼物 |
| **M - 意义** | 超越自我的目的感 | 公益捐赠、志愿活动、家族传承 |
| **A - 成就** | 目标达成与能力展现 | 技能认证、挑战型目标（如马拉松） |
| **V - 活力** | 身体健康与精力水平 | 健身、医疗、营养 |

## 在退休规划中的核心应用

传统退休规划只做一件事：算"需要多少钱"。PERMA-V 解决了另一个问题：**钱要花在哪里，才能换来真正的满足感？**

**形式化转换**：
```
传统问法：我退休需要多少钱？
PERMA-V 问法：我的 P/E/R/M/A/V 分别需要多少资金支撑？
```

**操作步骤**：
1. 评估当前六个维度的满意度
2. 为每个维度设定退休后目标水平
3. 量化实现每个目标所需的年度支出
4. 汇总得出总资金需求

## 边界条件

- **模型是框架，不是标准答案**：个人对六维度的权重不同，有人重视人际（R），有人重视意义（M）
- **定性为主**：目前框架停留在定性层面，六维的资金需求尚未有统一的量化方法
- **非普适性声明**：不同文化背景、不同人生阶段的人，六个维度的优先级不同

## 与相关概念的关系

- **[[退休满意度-财务×意义]]**：PERMA-V 提供了解构"人生意义"的具体框架，使满意度公式中的"人生意义"维度可操作化
- **[[享乐适应]]**：解释了为什么单一目标（如"攒够钱"）实现后快感迅速消退，PERMA-V 的多维覆盖有效对抗这种适应
- **[[人际关系幸福预测]]**：PERMA-V 中 R 维度的实证基础之一（哈佛 Grant Study 发现幸福≈f(关系质量)）
- **[[大目标与小目标框架]]**：PERMA-V 提供了"大目标"的细分维度，小目标可沿六个维度分别设定
