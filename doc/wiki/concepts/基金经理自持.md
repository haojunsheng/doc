# 基金经理自持

## 定义

基金经理用自己的钱买入自己管理的基金，锁定期至少6个月。这是一种将基金经理利益与持有人利益绑定的机制，中文语境下常被称为"吃自家狗粮"（dogfooding）。

---

## 为何重要

自持是衡量基金经理与持有人利益绑定程度的最直观信号。其逻辑链条：

```
真金白银买入 → 利益绑定 → 信任信号 → 降低信息不对称
```

但这一信号的有效性取决于三个前提条件：基金经理的财富主要配置在这只基金上（"痛感"足够强）、信号未被过度稀释、投资者不将信号等同于能力证明。

---

## 实证数据

### 历史数据（晨星2016-2025年非货币基金）

| 自持档位 | 3年跑赢同类概率 | 备注 |
|---------|-------------|------|
| 无自持 | 43-45% | 基准线 |
| 低档（0-10万份） | ~47% | 小幅提升 |
| 高档（>10万份） | 50-54% | 最大提升约9个百分点 |

5年期数据结论与3年期基本一致。

**历史趋势**：自持比例从十年前约5%升至如今的46%（混合型基金已超过60%）。

### 2024年最新年报数据（晨星中国）

2024年年报数据显示，12,131只基金中：
- **54%** 的基金经理持有份额为0
- **7%** 持有100万份以上

---

## 按基金品类的胜率差异

有自购的基金三年期年化回报均值和胜率高于同类平均，但**品类间差异显著**：

| 基金品类 | 自购胜率 | 备注 |
|---------|---------|------|
| 大盘成长股票 | ≥60% | 高风险+主动管理，自购效果最佳 |
| 积极配置-中小盘 | ≥60% | 同上 |
| 普通债券型基金 | ≥60% | 收益有限，但自购约束仍有效 |
| 积极配置-大盘平衡 | **<50%** | 反例：低风险/低分化风格中自购区分度弱 |

> **重要边界**：积极配置-大盘平衡基金自购胜率反而不足50%，说明"自购=更好"是一种过度泛化。不同策略类型的利益绑定效果存在系统性差异——高风险高分化基金中自购优势突出，低风险风格中效果有限。

---

## 信号贬值机制

晨星2024年研究提出核心判断：**自购信号正在贬值**。

**逻辑链**：
```
监管要求≥30%绩效薪酬自购 → 强制自购普及 → 全员自购趋势
    → 自购不再是区分因素 → 信号区分度归零
```

**类比**：晨星用"所有厨师必须吃自己做的菜"说明——当全员自购成为常态，自购就从"信心的证明"变成了"合规的要求"。

**当前窗口**：
- 54%仍零自购，信号仍有区分度
- 但随着强制自购政策推进，窗口在收窄
- 数据披露粒度不足（仅区间），也限制了判断精度

**未来情景**：
- 若披露从区间升级为精确金额 → 大额 vs 小额自购仍可判断"诚意"，信号部分保留
- 若全员强制自购 → 信号完全失效

---

## 三个边界条件

### 边界一：动机 ≠ 能力

自持证明了利益一致（动机强），但不证明投资水平（能力强）。大多数基金经理都想做好，明星基金经理的职业激励远超自持收益本身。自持只是增加了一层约束，不改变底层能力差异。

### 边界二：不买 ≠ 不好

基金经理未自持，可能出于个人财务阶段、风险偏好不匹配等理性原因。基金是标准化产品，与基金经理个人的资产配置需求无关。

### 边界三：买不买是两件事

基金经理自持是他的风险偏好匹配，你买是你的风险偏好匹配——两者独立。选基核心仍是匹配自身风险承受能力和财务目标。

---

## 正确使用方式

自持是**加分项而非决策项**。选基决策框架：

```
选基 = 基本面（投资范围/风格/持仓/风控/市场表现/组合角色） + 自持（加分项）
```

- 自持缺失 → 需警惕
- 有自持 → 仍需验证其他维度
- 自持金额变化 → 值得关注（增持为正信号，减持为负信号）

## 关联概念

- [[三层业绩归因框架]]：业绩归因解决"赚了是谁的功劳"，自持解决"这人有没有和你站在同一边"——互为补充
- [[共痛效应]]：自购让基金经理与持有人"同痛"，是共痛效应在基金领域的直接体现
- [[切肤之痛约束]]：自购的核心机制——让基金经理从"代客理财"变为"自投"，风险偏好更审慎
- [[信号贬值]]：强制自购普及后，自购从"信心的证明"变为"合规要求"，区分度归零
- [[浮动费率]]：同属"利益绑定机制"家族——自购是"真金白银投入"，浮动费率是"收入与业绩挂钩"
- [[基准-浮动费率挂钩机制]]：同样涉及激励相容问题，自购可视为另一种激励对齐工具
- [[投资者回报差]]：自购率是基金经理利益一致性的代理指标，有助于理解基民回报差的制度成因
- [[业绩归因]]：自购信号筛选的是动机（利益绑定），而非能力本身；能力与运气的区分仍不可替代
- [[能力-vs-运气]]：自购只能增加利益对齐，不能提升基金经理的真实能力或改变运气分布
- [[策略适配性]]：基金经理自持是基金经理自己的适配选择，不代表适合你
- [[后悔厌恶-投资语境]]：自持信号可能被用作"我跟着经理买了所以不后悔"的心理安慰
