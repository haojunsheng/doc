# 单一金属叙事谬误

**单一金属叙事谬误**是指用一个统一的大逻辑（如"央行购金"或"新能源需求"）覆盖所有金属品种，忽视各品种供需逻辑的根本差异。

## 核心命题

> 黄金、白银、铜同一年首次集体突破历史峰值，但这轮"金属狂欢"背后每个金属的供需逻辑完全不同。

## 谬误特征

| 错误认知 | 正确认知 |
|---------|---------|
| 所有金属都受同一因素驱动 | 每种金属有独立的供需剧本 |
| 黄金上涨 = 避险需求 | 黄金短期由ETF资金流驱动 |
| 铜价涨 = 新能源需求 | 铜供应短期紧张但长期不缺 |
| 锂价跌 = 需求萎缩 | 锂正在经历产能出清 |

## 正确框架

- 黄金：看ETF资金流
- 铁矿石：看中国转型
- 铜：看矿山投产
- 锂：看产能出清
