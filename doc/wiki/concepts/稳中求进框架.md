# 稳中求进框架

## 定义

在不确定性为主旋律的投资环境中，采取"不预测、留现金、控集中度、看长期"的四要素行动框架。这是晨星2026全球展望圆桌的收口方法论。

## 四要素详解

### 1. 不预测
- 不尝试预测关税何时落地、AI何时站住、消费何时恢复
- 承认"韧性最意外"——过去一年的市场韧性超出所有人预期
- 与[[长期视角过滤噪音]]方法论一致：不预测单年表现

### 2. 留现金
- 三位策略师都在减持高估标的、腾出现金
- Michael承认自己现金仓位太低
- 为[[关税通胀传导链]]等风险预留缓冲

### 3. 控集中度
- 被动投资者已"被动"重仓AI（英伟达占美国指数8%、全球指数6%）
- 避免在个股和行业层面进一步加仓AI
- 与[[被动投资者集中度困境]]直接相关

### 4. 看长期
- 用10年维度评估投资标的的可持续性
- 不被短期FOMO驱动（见[[FOMO行为偏差]]）
- 与[[AI估值可持续条件]]判断逻辑一致

## 形式化表达

```
稳中求进 = 不预测 + 留现金 + 控集中度 + 看长期
         = 进有纪律 + 稳有缓冲
```

## 适用场景

- 2026年全球投资布局
- 关税-通胀传导链风险评估
- AI投资热潮中的估值判断
- 被动投资者面对指数集中度的决策
