# 伪主动基金

## 定义

**伪主动基金**是指宣称采用主动管理、收取高额主动管理费（行业通行约1.2%），但实际持仓与业绩基准高度重合（主动持股比例低于60%）的基金。这类基金扣除费用后几乎不可能跑赢基准，对投资者构成实质损害。

## 形式化

```
伪主动基金 = min(主动持股比例, 60%) + 管理费率≈1.2% + 持仓高度跟随基准
                  ↓
       扣除费用后几乎不可能跑赢基准
                  ↓
       投资者应直接购买低费率指数基金
```

## 核心特征

| 特征 | 说明 |
|------|------|
| 主动持股比例 | < 60%（晨星阈值） |
| 管理费率 | 接近行业通行水平（约1.2%） |
| 持仓特征 | 与基准成分高度重合 |
| 实际超额 | 扣除费用后为负或接近零 |

## 数据背景

2025年6月底，1749只主动偏股型基金中，有20只主动持股比例低于60%，属于典型的"伪主动"基金。这些基金收取与"真主动"基金相近的费用，却提供接近指数的回报，形成隐性费用侵蚀。

## 投资者应对

1. **查看持仓偏离度**：不只看宣传文案，实际查看基金持仓与基准的偏离程度
2. **对比费率**：若主动持股低但费率不低，考虑转为低费率指数基金
3. **关注晨星分类**：晨星星级评价和风格箱可辅助判断基金的真实主动程度
4. **计算净超额**：扣除费用后的超额收益才是真实的基金经理能力体现

## 与 [[超额收益假象]] 的关系

"伪主动"是超额收益假象的一种具体形态——低偏离基金用高费率伪造阿尔法。参见 [[超额收益假象]]。

## 与 [[主动-被动-结构性困境]] 的关系

"伪主动"解释了结构性困境的一个微观表现：基金公司通过收取主动管理费而实际执行被动跟踪的策略，从中获取结构性利润。
