# 跟踪误差控制

进取型目标风险基金通过控制跟踪误差在约束范围内争取超额收益。

## 机制

```
战略配置基准 + 战术偏离(月度打分) → 跟踪误差 < 阈值
```

## 兴全安泰积极案例

- 基准：中证偏股型基金指数×70% + 中债综合指数×30%
- 跟踪误差：<6%
- 战术偏离：月度打分决定，权益比例区间60%-75%

## 边界条件

若基金经理风格偏离判断失误（如2021年错判成长股），可能显著跑输基准。
