# 能量大盗

## 定义

持续偷走能量感的外部因素和内部噪音。识别并规避它们，是能量感系统维护的必要手段。

## 典型能量大盗

| 类型 | 例子 |
|------|------|
| 技术产品 | 手机成瘾、社交媒体刷不停 |
| 情绪噪音 | 焦虑、反复的自我怀疑碎碎念 |
| 人际压力 | 总打击自己的人、打击型他人 |
| 自我苛责 | 内化的"应该"标准，达不到就骂自己 |

## 典型案例：小葵

小葵在图书馆学习，刷手机到饭点，一天报废，深夜陷入自我失望——典型的低能量循环：刷手机→时间流逝→完不成任务→自我苛责→更低能量→更想逃避→继续刷手机。

## 防护策略：金刚罩

戴上"金刚罩"避开能量大盗：
- 物理隔离手机（放包里、用番茄钟锁机）
- 缩小"影响圈"——只关注能控制的事，放下控制不了的人和事
- 识别焦虑碎碎念的模式，用仪式标记其结束

## 与能量感系统的关系

能量大盗识别是[[concepts/能量感系统]]五大部件之一（部件五），属于系统维护层面——设计好系统只是第一步，持续防护同样重要。
