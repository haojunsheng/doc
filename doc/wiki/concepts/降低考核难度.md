# 降低考核难度

**降低考核难度**指部分基金借基准调整之机，将业绩比较基准切换为更容易超越的组合，实质是在基准重构框架内进行的制度套利。这是基准重构政策的潜在负面效应。

在浮动费率机制下，基金公司有明确动机通过调整基准来降低"跑赢"门槛，从而获得更高管理费。

## 机制

基准重构本意是让基准贴合策略，但同一机制存在被逆向利用的空间：

```
表面：基准更精准 → 政策合规
实际：基准更容易跑赢 → 考核压力降低 → 触发高费率档位概率上升
```

典型操作：
- 将固定年化10%的绝对目标，转为股债组合基准——数字上更容易超越
- 选择与基金真实策略匹配度不足的基准，使基准偏离实际收益特征

## 价格指数陷阱案例

> **来源：** [[浮动费率]] 相关实证分析

沪深300十年年化全收益3.32%，价格收益仅1.08%，差2.24个百分点。用价格指数做基准，基金更容易"跑赢"，投资者却为此支付更高费率。

该案例说明：即使基金经理能力未变，仅通过基准从全收益指数切换为价格指数，即可显著降低"跑赢"门槛，产生费率套利空间。

## 与基准不匹配的关系

[[基准不匹配]]描述的是基金公司因制度惰性而"维持错误基准"的问题。[[降低考核难度]]是基准重构政策下的新变体——基金公司从"不改"变为"改但不改对"，利用政策窗口进行策略性基准选择。

二者共同指向核心矛盾：**基准选择具有实质性经济后果，但缺乏有效的审查标准**。

## 边界条件

- 晨星明确指出部分变更隐含降难度倾向，但未给出具体基金名单（来源：[[基准重构]] 实务QA）
- 若监管对基准调整设立审查标准，降难度空间将被压缩
- 当前阶段：警示性判断，证据强度较弱，需持续观察后续基金公告
- 如果基金通过降低基准难度而非真正提高能力来"跑赢"，浮动费率的激励对齐功能就失效（来源：[[浮动费率]] 实测QA）
- 基准选择审查标准尚未明确，监管层是否会对"降难度套利"进行干预仍存疑（来源：[[浮动费率]] 实测QA）

## 投资者应对

1. 不要仅看基准名称变更，应检查新基准与基金实际持仓的匹配度
2. 关注基准调整后浮动费率档位的实际触发情况
3. 对频繁调整基准的基金保持警惕
4. 警惕以价格指数替代全收益指数作为基准的操作——价差即套利空间
