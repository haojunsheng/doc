# 股债混合配置

同时持有股票与债券两类资产，在不同市场环境中切换收益来源，力求平衡风险与收益的投资策略。

## 核心框架

```
组合 = 债券（票息收益） + 股票（资本增值）
```

- **债券部分**：通常以高收益债券为主，提供基础票息收入，构成组合底仓
- **股票部分**：通常为高股息股票或成长股票，提供资本增值弹性

## 与固收+的区别

[[固收+基金]] 以债券为主要仓位，权益仓位较小（一般低于 20%），本质是"债为主、股为辅"。股债混合配置则允许股票仓位有更大弹性，根据市场环境双向调整股债比例，是真正意义上的双向配置。

## 关键能力要求

策略有效性高度依赖基金经理的大类资产配置能力。若股债配置方向判断错误，两类资产均可能产生亏损，不存在天然的"避险"属性。
