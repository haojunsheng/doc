# 短视性损失厌恶

## 定义

**短视性损失厌恶**（Myopic Loss Aversion）由 Benartzi 和 Thaler 于1995年提出，指投资者在进行长期投资时因频繁查看账户，导致心态退化为短期博弈，进而放大对波动的风险感知，要求更高的收益作为补偿的心理偏差。

## 核心机制

```
长期投资 × 频繁看账户 → 短线心态 → 放大风险感知 → 要求更高收益补偿
```

具体路径为：

1. **频繁看盘**：投资者频繁查看账户盈亏
2. **损失厌恶激活**：每次看到下跌都触发对损失的不适感
3. **痛苦不对称**：亏损100块带来的痛苦需要赚200-300块才能抹平（损失厌恶比例约2:1~2.5:1）
4. **冲动决策**：在连续下跌中被迫做出"割肉"等非理性操作
5. **账面亏损变实际亏损**：原本可回弹的浮亏变成了永久性损失

## 关键变量：看盘频率

短视性损失厌恶与普通损失厌恶的核心区别在于引入了**看盘频率**作为关键变量：

- 普通损失厌恶：损失和收益不对称（损失带来的痛苦约为同等收益快乐的2-3倍）
- 短视性损失厌恶：在损失厌恶基础上，**频繁查看**放大了损失的感知强度，使长期投资退化为短线心态

这解释了为何同样的投资组合，看盘频率不同的投资者会有截然不同的体验和行为。

## 对照案例：房价 vs 股价

| 维度 | 房价 | 股价 |
|------|------|------|
| 报价频率 | 无实时统一报价 | 每日实时报价 |
| 焦虑程度 | 低 | 高 |
| 波动感知 | 低（看不到就不感受） | 高（随时可见） |

房价没有全国统一实时报价系统，投资者查不到实时估值，因此波动不可见、焦虑感低。股票有每日报价，波动实时可见，焦虑被持续激活。

**边界条件**：若房产APP推出实时估价功能，房价焦虑可能变得和股票一样——说明"透明度效应"是更底层的机制。

## 银行理财净值化的启示

银行理财从"预期收益型"转向"净值化"后，投资者普遍感觉"理财变不稳了"。这一感知的真正来源并非风险上升，而是**透明度上升**：

```
理财"变不稳" ≠ 风险↑ → 而是 透明度↑ → 感知波动↑
```

净值化前，投资者看不到底层资产价格变化；净值化后，每天披露净值，价格波动立即反映到收益数字上。

## 解药：拔网线

短视性损失厌恶的行为解药是**减少信息输入**——即"拔掉网线"：

- 减少看盘频率，降低损失厌恶的激活次数
- 让时间熨平波动，而非通过频繁操作放大波动
- 最终目标：把波动交给配置，把收益交给时间

这一解药与[[把波动交给配置把收益交给时间]]的核心主张高度一致，两者互为印证。

## 边界与适用性

- 若投资者能真正做到"不看"，这一偏差就不再影响决策
- 专业训练或理性性格可降低损失厌恶程度
- 有明确止损纪律且能机械执行的投资者，看账户不一定会导致乱操作
- 对于已形成追涨杀跌习惯的投资者，"拔网线"的效果有限——需要额外的行为约束机制
