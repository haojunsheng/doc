# 净值便宜误区

投资者将基金净值与股票价格混淆，误认为净值低的基金"便宜"、上涨空间更大。这是迷你基金陷阱中两个主要认知误区之一。

## 核心谬误

```
净值1元 ≠ 便宜 ≠ 上涨空间大
净值3元 ≠ 贵  ≠ 上涨空间小
```

净值高低与未来涨幅无关联。净值3元的基金可能长期业绩优良、持续上涨；净值1元的基金可能长期低迷。

## 产生原因

迷你基金单位净值往往较低（因长期业绩不佳或经历多次分红/拆分），投资者观察到"低价"后产生买入冲动，忽视了净值本身只是已实现收益的累积结果。

## 相关误区：短期追高

迷你基金在短暂反弹后出现短期暴涨，吸引追高资金。但这类暴涨往往只是技术性反弹，而非趋势反转。

## 边界条件

若基金通过拆分或分红刻意压低净值吸引投资者，这种"便宜"确实是营销手段，本质仍是净值便宜误区的一种变体。

## 与预期外推偏差的区别

[[预期外推偏差]]是更广泛的预测偏差——人们倾向于从过去表现外推未来。净值便宜误区是其在基金投资领域的具体表现，特指对净值数字本身的价值判断错误，而非对收益趋势的错误外推。
