# 转股溢价率

## 定义

转股溢价率是可转债估值的核心指标，衡量转债价格相对于其转股价值的溢价程度。公式为：

```
转股溢价率 = (转债价格 − 转股价值) / 转股价值 × 100%
```

其中，转股价值 = 标的股票价格 × 转股比例。

## 含义解读

- **转股溢价率高**：转债定价偏贵，股性弱、债性强，"上不封顶"的弹性被削弱
- **转股溢价率低**：转债定价便宜，股性强，更接近正股表现

## 在固收+中的决策应用

[[sources/5-notes--54-20260614t213200-qa-china-fixed-income-plus-strategyqa--1y620o5]] 提供两个关键应用场景：

### 场景1：转债 vs 股票的择时

当转股溢价率的高企时，转债性价比下降，基金经理倾向于减仓转债、转向普通信用债或二永债。

### 场景2：转债 vs 正股的配置决策

通过比较转债转股溢价率的历史分位和正股PE的历史分位，判断谁更便宜：
- 转债估值历史分位 < 正股估值历史分位 → 优先买转债（相当于"打折买股票+免费保险"）
- 转债估值历史分位 > 正股估值历史分位 → 直接买股票

## 两种实战应用范式

[[sources/5-notes--08-20260614T213408--qa-固收加攻守之道-qa]] 用两只基金的实证对比，展示了转股溢价率在实战中的两种应用范式：

### 范式一：静态偏好（低价高等级）

华泰保兴尊合债券采取"低价高等级转债 + 偏债型为主"的静态偏好：
- 低价 → 转股溢价率高 → 债底保护强 → 熊市抗跌
- 高等级 → 违约风险低 → 信用风险可控
- 适合绝对收益导向的产品

### 范式二：动态择时（转股溢价率分位数）

光大保德信增利收益债券采取"转股溢价率分位数"的动态择时：
- 按转股价值将转债分高/中/低三类
- 计算每类当前溢价率的历史分位数
- 分位数 << 50% 超配，>> 50% 低配
- 适合相对收益导向、追求超额的产品

### 两种范式的对比

| 维度 | 静态偏好 | 动态择时 |
|------|---------|---------|
| 决策频率 | 低（策略确定） | 中（定期评估分位数） |
| 风险特征 | 债底保护优先 | 均值回归博弈 |
| 适用定位 | 绝对收益 | 相对收益 |
| 方法论基础 | 信用分析 | 估值历史分位法 |

两种范式无优劣之分，关键看是否与产品定位匹配。

## 边界条件

在极端行情下（如股债双杀），转债的债底保护可能失效，转股溢价率框架的判断可能失灵。
