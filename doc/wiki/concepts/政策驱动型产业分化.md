# 政策驱动型产业分化

## 核心定义

产业政策（如创新药政策、AI产业支持政策）在短期内对特定行业形成催化，导致行业基金表现出现显著分化——受益行业暴涨，非受益行业平淡或下跌。

## 形式化表达

```
行业基金回报差异 = f(产业政策, 出海逻辑, 内需)
→ 医药（创新药政策+出海）→ +18.07% ≠ 消费（内需疲软）→ +1.68%
```

## 政策传导链：政策→风格→行业→指数

晨星2026年1月月报揭示了一个关键规律：**政策驱动的产业趋势是市场上涨的"第一推动力"**——AI算力政策、商业航天扶持直接决定了1月的市场风格（中小盘+科技成长+顺周期）。投资者要理解政策，才能理解市场在交易什么。

完整的传导路径为：

```
政策利好（AI算力、商业航天）→ 科技成长板块↑ → 中小盘股↑ → 中证1000涨8.70%
```

## 与投资逻辑的三层归因

政策驱动型产业分化的归因层次：

| 层次 | 问题 | 示例 |
|------|------|------|
| 第一层 | 哪个行业涨了？ | 医药+18% / 钢铁+8% / 有色+15% |
| 第二层 | 为什么涨？ | 创新药政策利好 / 钢铁稳增长方案 / AI+地缘双重驱动 |
| 第三层 | 持续性如何？ | 若政策收紧，回落风险大 / 若需求未跟进，回调风险大 / 若政策转向或经济数据走弱，中小盘风格优势会消失 |

## 与[[共识入场陷阱]]的关系

- [[concepts/共识入场陷阱]] 指出当某个赛道成为共识时，往往已接近顶部
- 本文7月医药+18%的案例警示：创新药政策利好被广泛认知时，已计入价格

## 边界条件

**政策驱动型分化可持续的前提**：
- 产业政策具有长期性（而非短期刺激）
- 企业盈利真正兑现（而非概念炒作）
- 出海逻辑未被阻断（关税、监管风险可控）

**政策驱动型分化失效的信号**：
- 产业政策转向或收紧
- 企业财报不及预期
- 赛道估值过高（如市盈率分位数>80%）
- 政策转向或经济数据走弱（中小盘风格优势消失）
