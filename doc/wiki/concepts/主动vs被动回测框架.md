# 主动 vs 被动回测框架

> 阶段六核心验证方法：用样本基金做 ≥5 年对比，量化主动战胜率，验证 H1。

## 核心目标

验证 H1：长期低成本宽基/ETF（贝塔）对普通人的风险调整后收益 ≥ 主动基金。

## 样本选择标准

- 数量：至少 10 只样本基金（偏股混合型）
- 时间窗：≥5 年完整滚动周期
- 分组：
  - 主动组：晨星 funds 库中的主动偏股基金
  - 被动组：对应基准的宽基 ETF（如沪深 300ETF、中证 500ETF）

# 四象限投资知识结构

> 阶段零产出框架：把投资认知摊成一张可俯瞰的「四柱 + 一线」地图，作为后续 11 周学习的路由器。

## 结构定义

```
┌─────────────────────┬─────────────────────┐
│  认知与纪律         │   资产认知          │
│  （怎么想）         │   （有什么）        │
│  H2: 现金流优先于   │  H1: 贝塔为主，     │
│      收益率         │     阿尔法稀缺      │
├─────────────────────┼─────────────────────┤
│  市场研判           │   组合配置          │
│  （何时/贵贱）      │   （怎么配）        │
│  H3: 热点降噪       │  H4: 再平衡优先     │
│     估值周期框架    │     仓位管理        │
└─────────────────────┴─────────────────────┘
          一条贯穿线：对任何新信息的价值判断能力
```

## 四象限说明

### 象限一：认知与纪律（怎么想）
- 核心问题：我的钱怎么用？我为什么买？
- 对应阶段：阶段一（W1–W3）
- 关键假设：H2（现金流优先于收益率）

### 象限二：资产认知（有什么）
- 核心问题：有哪些工具？它们真实成本是多少？
- 对应阶段：阶段二（W4–W6）
- 关键假设：H1（贝塔为主）

### 象限三：市场研判（何时/贵贱）
- 核心问题：现在贵吗？这个热点是真的吗？
- 对应阶段：阶段三（W7–W9）
- 关键假设：H3（热点降噪）

### 象限四：组合配置（怎么配）
- 核心问题：如何分配权重？何时再平衡？
- 对应阶段：阶段三（W8–W9）+ 阶段四（W10–W11）
- 关键假设：H4（再平衡贡献 > 单基选择）

## 贯穿线：价值判断能力

四象限之外有一条贯穿线：无论新来什么信息（基金、策略、热点），都能在 10 分钟内完成四象限扫描，给出「该不该看 / 该不该买 / 该不该跑」的初步判断。
