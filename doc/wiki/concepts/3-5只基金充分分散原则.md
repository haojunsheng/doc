# 3-5只基金充分分散原则

分散效果来自资产类别多样化，而非基金数量的堆砌；3-5只不同类基金即可实现充分分散。

## 核心规则

```
3-5只不同类基金 ≈ 充分分散  >>  20只同类基金
```

## 推荐组合模板

- **基础版（3只）：** 1只宽基 + 1只纯债 + 1只短债/货币基金
- **进阶版（5只）：** 基础版 + 1-2只行业基金

## 理论支撑

与 [[concepts/资产相关性分散]] 高度一致：分散的本质是降低组合内资产间的相关性，而非增加数量。20只同类基金（如20只科技主题基金）的相关性极高，分散效果远不如3只完全不同资产类别的基金。

## 边界条件

1. **资金量大时可适度增加：** 百万级以上资金可考虑进一步细化配置，但本文未给出具体阈值标准。
2. **管理成本递增：** 基金数量过多会增加跟踪、再平衡的管理成本，且容易买重（同一行业多头持仓）。
3. **与时间框架配合：** 基础版适合短钱求稳，进阶版适合长钱博收益。参见 [[concepts/投资时间框架原则]]。

## 与相关概念的关系

- [[concepts/投资时间框架原则]]：时间框架决定资产类别选择，3-5只原则解决"选几只"的落地问题。
- [[concepts/种田打猎资产配置法]]：3只基础版偏种田，5只进阶版可在种田基础上加入打猎卫星仓位。
