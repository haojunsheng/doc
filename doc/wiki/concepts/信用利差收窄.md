# 信用利差收窄

## 核心定义

信用利差 = 企业债收益率 - 国债收益率。信用利差收窄意味着企业债相对国债的收益率优势缩小，反映信用环境改善或风险偏好提升。

## 形式化表达

```
信用利差 = 企业债收益率 - 国债收益率

信用利差收窄 ← 企业债收益率下行 > 国债收益率下行（或上行更少）
信用利差走阔 ← 企业债收益率上行 > 国债收益率上行（或下行更少）
```

## 2025年7月实证数据

| 指标 | 变动 | 解读 |
|------|------|------|
| 1年期AAA信用债收益率 | ↓1bp | 短端信用环境改善 |
| 1年期AA信用债收益率 | ↑3bp | 低等级信用利差走阔 |
| 5年期AAA信用债收益率 | ↑4bp | 长端信用利差走阔 |
| 5年期AA信用债收益率 | ↓1bp | 中等级信用利差收窄 |
| 中证企业债指数 | +0.02% | 整体略涨 |
| 中证国债指数 | -0.14% | 利率债下跌 |

## 与市场环境的关系

| 市场环境 | 信用利差方向 | 原因 |
|---------|------------|------|
| 经济复苏预期强 | 收窄 | 企业违约风险下降，风险偏好提升 |
| 流动性宽松 | 收窄 | 资金追逐收益，推高信用债价格 |
| 信用事件频发 | 走阔 | 风险厌恶上升，信用债遭抛售 |
| 利率上行周期 | 分化 | 久期长的信用债受冲击更大 |

## 对基金选择的影响

- **信用利差收窄** → 信用债基金表现优于利率债基金（如2025年7月）
- **信用利差走阔** → 信用债基金承压，利率债基金相对抗跌

## 与[[久期风险]]的关系

信用利差变化与久期风险相互叠加：
- 长端信用债（如5年期）同时面临利率风险和信用风险
- 短端信用债（如1年期）久期风险小，但信用利差变化对价格影响更直接
