# 子基金筛选定量定性框架

养老目标风险基金在筛选子基金时采用定量+定性双重评估机制，确保选基既基于历史数据也考虑前瞻因素。

## 定量筛选

考察周期：3年或5年

核心指标：
- 超额收益（alpha）
- 最大回撤
- 夏普比率
- 波动率
- 业绩排名（要求至少一个指标排名前1/3）

局限：仅依赖历史数据存在滞后性，市场剧变时可能失效。

## 定性尽调

尽调内容：
- 基金公司基本面
- 投研团队稳定性与经验
- 投资文化
- 投资流程规范性

目的：补足定量方法的滞后性，提前发现潜在风险。

## 双重收费豁免对选基的影响

FOF投自家基金免收管理费、托管费和申赎费，导致内部基金偏好。但内部质量参差，过度依赖可能拖累整体收益。

```
内部基金 = 费率优势 ⊥ 外部基金 = 范围更广
```

## 与基金公司评估框架的关系

本框架与[[基金公司三要素评估框架]]（管理、风控、投研）互补，前者聚焦子基金层面，后者评估基金公司整体能力。
