# 足够(t)动态校准

"足够"不是一个固定数字，而是随人生阶段、价值观、生活状态动态变化的。关键是定期重新校准。

## 形式化表达

```
足够(t) = f(人生阶段(t), 价值观(t), 生活状态(t))
t 变化 → 足够(t) 变化 → 需要定期重新定义
```

## 生命周期示例

| 人生阶段 | "足够"的可能含义 |
|----------|-----------------|
| 20岁 | 能去旅行、有基本自由 |
| 30岁 | 能买房、建立家庭 |
| 50岁 | 能退休、保障生活质量 |

## 操作建议

- 每3-5年重新问自己"对我来说够是什么"
- 这不是折腾，是适应变化
- 用旧阶段的"够"指导新阶段决策，要么过度储蓄（生活质量被压缩），要么储蓄不足（退休后不够花）

## 边界条件

如果连当前阶段"够"是什么都还没定义，先别急着做长期规划——先搞清楚眼前，再想以后。
