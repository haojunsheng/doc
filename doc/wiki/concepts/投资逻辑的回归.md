# 投资逻辑的回归

投资逻辑是连接过去与未来的桥梁——如果逻辑还在，亏损只是波动；如果逻辑不在了，继续持有才是最大的风险。

决策的依据不是"亏了多少"，而是"当初为什么买"。

## 核心命题

> 没有锚的船，任何方向的风都是逆风。

锚定的是"当初为什么买"，而非"现在亏了多少"。

## 认识论基础：可证伪性

引入卡尔·波普尔（Karl Popper）的认识论框架：

- **可证伪的逻辑**："看好新能源行业3年渗透率提升" → 渗透率停滞即证伪
- **不可证伪的"逻辑"**："好公司迟早会涨" → 无论涨跌都能自圆其说，只是信念而非逻辑

好的买入逻辑必须能被现实证伪。不可证伪的"逻辑" = 不是逻辑，只是信念。

## 两种决策路径

### 路径1：逻辑仍在 → 继续持有

市场波动是常态，短期亏损不代表长期失败。只要当初买入的理由还在（行业趋势仍在、基金经理仍在、风格未变），持有是理性选择。

### 路径2：逻辑已破 → 果断赎回

以下情况意味着投资逻辑可能被破坏：
- 基金经理变更（新经理理念差异大）
- 风格漂移（实际持仓与宣称风格不符）
- 行业逻辑改变（政策、竞争格局、景气度根本性逆转）
- 业绩持续跑输同类和市场

继续持有"错"的基金只会让亏损加深。

## 常见陷阱：没有逻辑的买入

牛市里"看着能赚钱就买了"的投资者，在熊市暴露双重困境：
- 没有持有的理由（因为没有逻辑）
- 也没有卖出的标准（因为没有预期）

只能被恐惧和焦虑驱动，要么硬抗，要么恐慌割肉——两种极端反应都源于逻辑缺失。

## 三段式决策框架

```
第一步：诊断
  → 亏损 ≠ 业绩差。与同类和市场比较，判断是市场原因还是基本面原因。

第二步：分析
  → 回归买入逻辑检验：当初为什么买？这个理由还在不在？

第三步：建议
  → 综合三维度决策：
    - 急不急着用钱（资金需求）
    - 有没有更好的标的（替代方案）
    - 心态还能不能扛（心理承受力）
```

## 实践检验

问自己：如果接下来发生 X 情况，我会承认自己错了并退出吗？

- 如果不能 → 你的逻辑不可证伪，需要重新思考
- 如果能 → 你的逻辑是可检验的，可以执行

"谋事在人，成事在天"——接受不确定性，但坚持用逻辑而非情绪做决策。
