# 自研芯片 vs 通用市场

## 定义

云厂商（亚马逊 AWS、微软 Azure、谷歌 Cloud）为降低算力成本而自研 AI 训练/推理芯片的现象，与其对英伟达通用 AI 算力市场的竞争关系。

## 核心逻辑

```
自研芯片 = 内部需求 ≠ 通用市场
→ 英伟达仍为行业默认选项
```

自研芯片的设计目标是服务云厂商自身业务，而非向外部客户提供通用算力。因此，自研不等于替代，而是两条并行路径：

| 维度 | 自研自用 | 通用市场 |
|------|---------|---------|
| 服务对象 | 云厂商内部 | 全行业客户 |
| 代表厂商 | Google TPU、Amazon Trainium | 英伟达、AMD |
| 竞争关系 | 不直接竞争 | 替代关系 |
| 规模边界 | 受内部算力需求限制 | 面向无限外部需求 |

## 关键事实

- 亚马逊、微软、谷歌均已开发 AI 训练芯片
- 这些芯片主要服务于自身云业务，未对外大规模销售
- 外部客户仍需通用方案，英伟达是目前唯一具备完整软硬件生态的玩家
- AMD 和英特尔在通用 GPU 市场加速研发，但短期技术差距仍在

## 边界条件

**短期不构成威胁**：自研芯片仅满足内部需求，不进入通用市场。

**中长期风险**：若云厂商从"自研自用"转向"对外销售"（例如将自研芯片通过云服务对外提供），则英伟达面临直接竞争。Google 将 TPU 以 API 形式在 Cloud 上开放，是观察这一转化的典型案例。

## 与 CUDA 生态锁定的关系

[[CUDA生态锁定]] 构成英伟达的护城河，但自研芯片路径绕开了通用市场逻辑——云厂商通过自研芯片降低对英伟达的采购依赖，同时仍可使用 CUDA 兼容方案。这构成了锁定效应的隐性侵蚀路径。
