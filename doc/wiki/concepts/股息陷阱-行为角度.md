# 股息陷阱（行为角度）

从行为金融学视角，股息陷阱的核心不是"股息率高所以便宜"，而是**投资者看到的高股息率是股价下跌的镜像，而非分红能力提升的信号**。

## 陷阱形成机制

```
股价下跌 → 股息率被动升高 → 投资者判断为"便宜" → 买入接盘 → 股价继续下跌
```

投资者被高股息率吸引，却忽略了股息率是公式 `股息率 = 每股分红 / 股价` 的分母效应。分母（股价）变小，分子（分红）不变，股息率被动升高——这不是价值被发现，而是价值在被毁灭。

## 与 [[concepts/高股息陷阱风险]] 的关系

[[concepts/高股息陷阱风险]] 从资产质量角度定义股息陷阱（港股结构性成因），本概念从**投资者行为动机**角度补充：投资者为何会落入陷阱——因为"高股息 = 便宜"是一种直觉性错误判断，本质上是 [[concepts/本土偏好-量化框架]] 中"追热点"行为的变种：这次追的是"高股息红利"。

## 与定投悖论的交集

[[concepts/定投悖论]] 指出定投的价值在于纪律性而非收益增强。若将定投纪律错误地应用于高股息标的，"越跌越买"会放大股息陷阱的损失。定投不应被滥用为无差别接盘的借口。

## 识别信号

- 股息率持续走高，但公司盈利同步下滑
- 行业处于下行周期（如周期性行业集中度高的港股红利指数）
- 无低波过滤的股息指数成分股频繁更替
