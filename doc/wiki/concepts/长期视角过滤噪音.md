# 长期视角过滤噪音

## 定义

用10年维度评估投资标的的可持续性，而非跟风短期爆发。这是晨星全球策略师圆桌中提出的方法论核心。

## 形式化表达

```
跟风模式: 涨 → 推荐 → 不可持续
晨星模式: 退后10年 → 评估护城河 → 过滤噪音
```

## 核心逻辑

1. **短期爆发不可持续**：短期爆发的公司隐含的长期增长率往往不可持续
2. **10年视角过滤噪音**：把时间拉长到10年，才能看清真正的护城河和增长可持续性
3. **方法论价值边界**：金融预测准确性太难验证，晨星选择"不预测单年表现"，转而评估长期可持续性

## 应用场景

- 评估AI投资热潮：不能只看当前的AI支出计划和股价上涨，要看AI是否能真正推动实体经济效率提升
- 评估主题基金热度：避免在热门主题高点跟风买入
- 与FOMO行为偏差对抗：FOMO的本质就是被短期噪音驱动

## 局限性

- 可能错过短期交易机会，对短线投资者无意义
- 长期视角的判断本身也存在不确定性（如AI估值何时能"站得住"未给出时间框架）
