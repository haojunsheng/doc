# 能力圈

投资者真正理解并能持续跟踪的标的范围。超出能力圈的投资依赖运气而非能力，长期来看不可持续。

## 巴菲特原教旨定义

能力圈概念源自[[沃伦-巴菲特]]的投资哲学，强调"知道自己的能力边界在哪里"比"拥有广泛知识"更重要。

巴菲特的核心论点：**错过能力圈外的巨大机会，不等于失败。**

### 经典案例：错过微软44000%

- 1991年巴菲特认识比尔·盖茨，当时微软市值100亿美元
- 2026年微软市值约3万亿美元，涨幅超44000%
- 巴菲特仍未大额投资微软，但其业绩仍大幅跑赢标普500
- 原因：在能力圈内（Geico、美国运通、可口可乐）赚得更多

**形式化**：
```
投资成功 = 看懂少数几件事 + 长期持有 ≠ 抓住所有机会
```

**关键洞察**：投资的护城河不在于你能看多少机会，而在于你能拒绝多少机会。

### 机会成本约束

```
研究微软 → 注意力分散 → 错过Geico/运通/可乐 → 总回报↓
```

注意力是有限资源，投在能力圈外意味着能力圈内投入不足。

**边界**：若投研团队足够大（如大型基金公司），分散研究未必影响其他标的的研究深度。

## 在基金评估中的应用

回本后的基金去留决策中，能力圈是第三评估维度（仅次于业绩和收益来源）：

1. 这只基金我是否真正理解？
2. 我愿意投入多少时间和精力跟踪它？
3. 超出能力圈 → 果断清仓

## 边界识别

- **主题和行业基金**：波动大，需要专业能力 → 不懂就清仓
- **基金经理变更**：新经理的投资风格可能超出原能力圈
- **风格漂移**：当基金的实际持仓偏离其宣称风格，能力圈边界模糊

## 能力圈的扩展性

能力圈并非绝对固定——巴菲特后期大举买入苹果，说明边界可以逐步扩展。但扩展的前提是：新领域符合原有判断框架（品牌护城河+消费属性）。

**边界条件**：
- 主动放弃 vs 能力不足：巴菲特是"有意识放弃"微软，而非"能力不足错过"
- 能力圈扩展需以原有框架为基础，而非盲目追逐热点

## 能力圈与风格逆风的区分

| 特征 | 风格逆风 | 超出能力圈 |
|-----|---------|----------|
| 定义 | 基金经理的投资风格短期不适用市场环境 | 投资者本身无法理解或跟踪该基金 |
| 赎回决策 | 不一定是最佳选择，可等待轮动 | 应果断赎回 |
| 判断依据 | 基金经理长期投资流程是否稳定 | 是否愿意投入跟踪精力 |
