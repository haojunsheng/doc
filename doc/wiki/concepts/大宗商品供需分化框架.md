# 大宗商品供需分化框架

**大宗商品供需分化框架**是指判断不同大宗商品价格走势时，不能用一个统一的大逻辑覆盖所有品种，而应根据各品种的供需基本面单独分析。

## 核心命题

> 黄金看ETF资金流、铁矿石看中国转型、铜看矿山投产、锂看产能出清——每种金属都有独立的剧本。

这是理解大宗商品投资的根本方法论：**单一金属叙事谬误**是投资者常犯的错误。

## 框架应用示例

| 商品 | 核心驱动因素 | 分析重点 |
|------|-------------|---------|
| 黄金 | ETF资金流 | 短期边际驱动力，而非珠宝消费或央行购金 |
| 铁矿石 | 中国需求转型 | 经济向低大宗商品依赖转型 + 废钢比例提升 |
| 铜 | 矿山供应 | 新矿山投产节奏、刚果（金）产能扩张 |
| 锂 | 产能出清 | 价格跌破成本 → 投资暂停 → 供应收缩 → 价格修复 |
| 白银 | 工业+货币双重属性 | 兼具黄金和工业金属特征 |

## 边界条件

1. 若中国加速向低大宗商品依赖转型，工业金属需求逻辑弱化
2. 若某品种出现超预期供需冲击（如地缘政治、自然灾害），框架需调整
3. 不同时间尺度下驱动因素可能变化（短期看资金流，长期看供需基本面）
