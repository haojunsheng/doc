# 离岸与在岸资金分流

## 定义

离岸与在岸资金分流是指同一只基金在内地销售额度耗尽后，内地投资者无法继续申购，但离岸投资者（非内地投资者，如香港、新加坡、欧洲等地的机构投资者和个人投资者）仍可继续买入，导致基金整体资金流并未停止的现象。

## 核心机制

```
内地销售额度耗尽
    → 内地投资者暂停申购
    → 但离岸投资者继续买入
    → 基金整体资金流仍为正
```

## 典型案例

### 案例 1：中银香港亚洲债券基金
- 状态：自 2025 年 10 月底起暂停对内地投资者的申购
- 结果：仍在资金流入榜位列第二
- 原因：离岸投资者需求强劲，填补了内地资金的真空

### 案例 2：东亚联丰亚洲策略债券基金
- 状态：同样暂停内地申购
- 结果：位列流入榜第七
- 原因：亚洲债券的票息优势对全球资金仍有吸引力

## 与 [[QDII额度机制]] 的关系

QDII 额度机制是内地投资者购买海外基金的通道限制。当额度耗尽时，内地资金无法继续流入，但离岸资金不受此限制。因此，"暂停内地申购"不等于"基金失去吸引力"。

## 投资决策启示

1. **穿透额度限制看真实流向**——债基净流出数据需先做政策剔除，再做行为解读
2. **关注离岸需求指标**——对于受额度限制的基金，离岸资金流是更重要的观测指标
3. **亚洲债券的票息优势**——在全球低利率环境中，亚洲债券的票息对离岸资金具有持续吸引力

## 边界条件

- 若离岸投资者撤资（如美元大幅升值），基金会面临更大的赎回压力
- 若亚洲债券违约率上升，离岸需求会下降
- 若内地额度重新放开，资金流格局可能快速逆转
