# 规模困境

基金规模越大，越难跑赢指数——因为大资金只能买大盘股，而大盘股是市场最有效的部分。

## 形式化

```
规模 ↑ → 持仓流动性约束 ↑ → 只能买大盘股 → 大盘股研究覆盖度 ↑ → 错误定价 ↓ → 跑输指数概率 ↑
```

## 实证数据

Morningstar：规模前 25% 的基金，5 年跑输指数的概率是后 25% 的 **两倍**。

## 机制拆解

1. **小基金（10亿）**：可以灵活配置小盘股，买到好股票就能大幅跑赢
2. **大基金（500亿）**：小盘股装不下，只能买苹果、微软等大盘蓝筹——这些股票已被无数分析师深度覆盖，价格接近有效

## 边界条件

- 该结论主要适用于**大盘股基金**
- 小盘股基金即使规模变大，影响也没那么大——因为小盘股市场效率本就低，大资金仍有犯错定价的机会
- 优质主动基金的特征是「小规模」，但规模扩大后优势会消失

## 与费用困境的联动

规模增长通常伴随费用结构变化：管理费可能下降（规模经济），但规模本身带来的「被迫配置大盘股」效应才是主导因素。
