# 应对优于预测

在不可预测的事件冲击面前，基于自身条件构建多元化组合的"应对"策略，远比试图预测方向的"预测"策略更有效。

## 核心公式

```
理性应对 = 风险承受能力 + 资金期限 + 多元化组合
```

## 理论支撑

- **托马斯·索威尔**："预测经济需要先预测政治人物"——承认世界本质上不可预测
- **霍华德·马克斯**："理性应对波动能带来回报"——不预测方向，只准备应对方案

## 为什么预测不可靠

1. 宏观政策引发的波动多次上演（一战+大流感、二战、石油危机等），每次都有人喊"这次不一样"
2. 历史证明所有"这次不一样"的叙事最终都被证伪
3. 即使是系统性秩序颠覆事件（全球化逆转等），市场最终也趋于复苏

## 为什么应对有效

1. 不依赖对未来方向的判断，而是基于当下可知的约束条件（风险承受力、资金期限）做决策
2. 多元化组合天然覆盖多种情景，不需要押注单一方向
3. 19次崩盘后，坚守多元化+长期持有的策略均被验证有效

## 边界条件

- 当投资者有短期流动性需求（1年内需用钱）时，多元化不能避免短期账面亏损
- 应对框架假设历史规律在未来至少部分成立；若全球化彻底逆转导致经济结构根本性变化，历史参照系可能失效
