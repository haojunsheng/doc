# 长牛慢牛

A股市场有望迈向长牛慢牛的结构性判断，由基金经理徐荔蓉提出，基于四大支撑因素。

## 四大支撑因素

| 因素 | 内容 |
|------|------|
| 长期资金占比↑ | 国家队、险资等长期资金占比提升 |
| 政策定位质变 | 股市政策定位从短期刺激转向长期机制化操作 |
| 生态优化 | 回购分红比例上升，市场生态持续改善 |
| 结构多元化 | 新经济与传统经济板块都有望获得青睐 |

形式化表达：
```
国家队/险资占比↑ + 外资低配↑ + 回购分红↑ + 经济结构多元 → 慢牛长牛
```

## 边界条件

若政策定位发生逆转或外资大规模撤离，慢牛基础可能被削弱。
