# 基金经理自我迭代框架

晨星的核心观点：基金经理的真正分水岭不是不犯错，而是犯错后怎么改。自我迭代能力是基金经理真正的护城河。

## 核心公式

```
犯错 + 复盘反思 + 框架迭代 → 能力提升
犯错 + 不反思 → 重复犯错
```

## 三个迭代维度

### 1. 估值分析维度（赵晓东案例）

赵晓东在爱美客失手后，系统性地从三个层面反思：
- **估值分析**：不再仅依赖历史增速外推，建立估值与盈利增速的对比锚
- **行业研究**：深入理解医美行业的周期性和竞争敏感度
- **行业认知**：区分高增速与可持续增长，避免线性外推

### 2. 久期定价维度（杨嘉文案例）

杨嘉文在红利误判后引入的纠偏工具：
- **框架升级**：从"以成长为主要导向"进阶为"成长与价值动态平衡"
- **量化工具**：引入[[股息率-无风险利率比价模型]]，将资产久期特征纳入定价框架
- **定价逻辑更新**：理解市场对长期稳定现金流的定价逻辑随利率环境变化

### 3. 宏观政策分析维度（谷衡案例）

谷衡在债市V型震荡后的反思：
- **指标局限**：过度依赖传统经济周期指标
- **政策目标演变**：央行从单一总量宽松转向防风险/金融稳定等多元目标
- **边际变化敏感度**：提升对政策转向信号（如公开市场操作微调）的捕捉能力

## 与择时心理陷阱的边界

[[择时的心理陷阱]]强调的是情绪化、随机性的择时行为，而自我迭代框架的核心区别在于：

| 维度 | 情绪化择时 | 自我迭代框架 |
|------|-----------|-------------|
| 触发条件 | 市场恐慌/贪婪 | 系统性复盘后发现框架漏洞 |
| 决策依据 | 感觉、从众 | 估值/久期/政策数据分析 |
| 结果可复现性 | 不可复现 | 可复现（同类型问题可提前规避） |

## 在选基中的应用

[[选基适配框架]]目前关注能力圈、工作负荷、团队支持三个维度。本框架补充第四维度：**自我迭代能力**——评估基金经理面对错误时的态度和改进机制，而非只看历史业绩。
