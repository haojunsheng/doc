# DCT去中心化临床试验

DCT（Decentralized Clinical Trial，去中心化临床试验）是一种远程智能临床试验模式，通过数字技术降低药物开发成本、加速新药上市进程。

## 核心机制

```
DCT = 远程试验（参与者足不出户）
      → 远程收集数据 + 监控效果
        → 成本↓ + 速度↑
          → 药企采用↑ → CXO增量
```

## 疫情对DCT的加速作用

新冠疫情加速了DCT模式的采纳——传统临床试验需要患者频繁到医院，疫情下这一模式不可持续，推动监管和药企对远程试验接受度提升。

## 关键变量：监管接纳

DCT能否成为可持续增量，取决于监管机构对远程数据质量的认可程度。美国FDA、欧洲EMA已在部分场景下接纳DCT数据，但推广速度因地区监管差异而不同。

## 与[[CXO服务费商业模式]]的关系

DCT降低了临床试验的整体成本、提高了效率，使更多药企有能力开展临床试验，间接扩大了CXO服务的总需求池。
