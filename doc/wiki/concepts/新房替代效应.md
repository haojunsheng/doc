# 新房替代效应

## 定义

新建商品房（尤其核心地段）对周边二手房形成竞争挤压，导致二手房市场需求分流、价格跌幅反而大于外围区域的反直觉现象。

## 机制

```
核心地段新房供应（品质新、贷款条件优、政策激励）
  → 改善型需求优先选择新房
  → 周边二手房竞争力下降
  → 一线城市核心区二手房跌幅 > 外围区域
```

## 经验证据

- 一线城市二手房跌幅甚至大于二三线城市
- 上海、杭州等需求强城市去化效率更高，新房对周边二手房的替代效应也更显著
- 北方城市库存压力重，新房供给收缩后，替代效应减弱，二手房去化更缓慢

## 与投资的关系

- 开发商股价重估的部分逻辑建立在"新房替代效应→新房价格先稳"的传导上
- 若政府加大保障性住房供应（包括收购存量房），新房替代效应可能向保障型需求扩展，进一步挤压低端二手房市场

## 边界

- 若核心地段开发商拿地减少、新房供应萎缩，替代效应减弱
- 若政策大量收购二手房转为保障房，可直接缓解周边二手房供给压力
