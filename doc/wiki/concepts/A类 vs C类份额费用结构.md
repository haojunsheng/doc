# A类 vs C类份额费用结构

同一只基金的不同份额类别，费用结构不同，适用场景也不同。在QDII基金中，这一选择直接影响净回报。

## 核心差异

| 费用项 | A类份额 | C类份额 |
|--------|---------|---------|
| 前端申购费 | 有（通常1.30%，平台常有折扣） | 无 |
| 销售服务费 | 无 | 有（通常0.10%-0.40%/年） |
| 管理费+托管费 | 相同 | 相同 |

## 费用对比示例（纳指100 QDII）

| 基金 | A类年化 | C类年化 | 差异 |
|------|---------|---------|------|
| 广发纳指100 | 1.00%（0.80%+0.20%） | — | 有前端申购费 |
| 南方纳指100 | — | 0.75%（0.50%+0.15%+0.10%） | 无申购费 |

## 决策规则

**持有期 > 3-5年 + 平台有申购费折扣 → 选A类**

前端申购费一次性支付，长期持有可摊薄；无销售服务费，长期成本更低。

**持有期 < 3年 或 不确定 → 选C类**

无前端申购费，虽然每年收销售服务费，但短期持有总成本更低。

## 常见陷阱

1. **忽略前端折扣**：标称1.30%的申购费，平台可能打1折至0.13%，大幅降低A类初始成本
2. **误用A类做短炒**：前端费+赎回费（持有<7天通常1.5%）会侵蚀短期收益
3. **只看费率不看限购**：A类限购100元/日时，C类限购200元/日，C类更适合定投建仓

## 与 [[concepts/秩序搬运]] 的关系

无论选A还是C，都是秩序搬运管道，费用差异只是通道成本差异，不影响底层资产回报。
