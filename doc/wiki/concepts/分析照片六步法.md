# 分析照片六步法

## 定义

分析一张照片的标准流程，从技术参数到创作背景，六步层层递进。既是评价他人照片的方法，也是拍摄时的反向决策链。

## 六步流程

```
1. 曝光参数    → 光圈、快门、ISO——决定画面基础质感
2. 镜头焦段    → 广角/标头/长焦——决定空间透视和视角
3. 拍摄距离和快门时机  → 最关键的步骤——决定"为什么只有这个时刻才能存在"
4. 构图        → 前景/中景/背景的元素安排
5. 后期        → 曝光调整、色彩风格、裁切
6. 创作背景    → 为什么拍、在哪里拍、当时的情况
```

## 核心判断：第3步最重要

> 参数可以后期猜，但拍摄距离和时机决定了这张照片为什么只有这个时刻才能存在。

这是[[可复现概率]]的判断核心：一张好照片之所以不可复现，不是因为参数或构图，而是因为**那个特定的距离和时机**。

## 反向操作：从创作到参数

评价照片时顺向走一遍（参数→背景），拍摄时反向思考：

```
创作意图 → 创作背景 → 构图 → 时机/距离 → 焦段 → 曝光参数
```

先想清楚为什么要拍这张照片，再反过来决定光圈、快门、ISO。

## 实操要点

- **靠近**：简化画面，减少干扰元素
- **等待**：让主体进入最佳位置，抓关键动作
- **退后**：复杂场景也要有主次，乱中有序

## 与[[可复现概率]]的关系

六步法中的第3步（时机）和第4步（构图）是判断的直接依据：
- 时机不可复现 → 好照片
- 构图可被他人轻易模仿 → 游客照水平

## 关联概念

- [[可复现概率]] — 六步法的最终判断标准
- [[捷径幻觉]] — 跳过六步法直接依赖预设/文案，是捷径幻觉的表现
