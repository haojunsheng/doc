# 行业集中度风险

当一只基金在单一行业或少数几个行业的配置比例显著偏高时，该基金就不再是真正的分散化投资，而是变成了一个该行业的"带包装的敞口"。这种结构性暴露称为**行业集中度风险**。

## 核心判断

分散化投资的核心逻辑是不同行业/资产之间的低相关性来降低整体组合波动。但当持仓高度集中于某一行业时，这一逻辑失效——所有持仓在同一产业周期内同涨同跌，相关性趋近于1。

## 典型案例：广发全球精选股票QDII

| 指标 | 数值 |
|------|------|
| 信息技术持仓占比 | 49.83%（2026Q1） |
| 前十大持仓 | ASML、Knowledge Atlas Technology、Alphabet、NVIDIA、Apple、Amazon、Lam Research、Sandisk、Broadcom、Micron |
| 行业指向 | 全部为AI算力链、半导体设备、存储、云平台 |
| 实际效果 | 本质上是一只"全球AI科技股"基金，而非"全球分散配置"基金 |

## 与"S曲线阶段判定"的叠加风险

参见 [[concepts/S曲线阶段判定]]。行业集中度风险 + S曲线加速期 = 双重风险放大：

1. 行业高度集中 → 波动来自单一产业周期
2. 处于S曲线加速期后段 → 估值已充分定价，容错率低
3. 两者叠加 → 下行时没有行业对冲，上涨时已无多少预期差

## 识别方法

1. 看季报行业分布：单行业是否超过30%？是否接近半仓？
2. 看前十大持仓：是否全部指向同一产业链？
3. 看产品名称与实际持仓是否一致："全球精选""多资产配置"等名称可能是误导标签
4. 看限购行为："限大额"往往暗示资金涌入导致管理人控制规模，是拥挤度信号

## 与[[concepts/集中度风险]]的区别

| 维度 | 集中度风险 | 行业集中度风险 |
|------|-----------|--------------|
| 范围 | 主题风险、单一资产过度集中 | 跨行业配置中某一行业占比过高 |
| 典型场景 | 单只股票占比过高、单一主题基金 | 科技行业占净值50%+、半导体主题基金 |
| 解决思路 | 分散持仓数量 | 检查行业分布、避免名称与实际不符的产品 |

两者在广发全球精选QDII案例中同时存在：前十大持仓集中 + 信息技术行业半仓，是双重集中风险的叠加。

## 投资启示

投资者在购买"全球""多配置"类产品时，应核查真实行业分布，不要被产品名称中的"全球分散"误导。真正分散的组合应该在行业、区域、风格三个维度都有明显差异化的敞口，而不是用"QDII"这个标签来掩盖高度集中的科技敞口。
