# 捷径幻觉

## 定义

构图法则、调色预设、营销文案等"速成技巧"让人产生"我在学"的错觉，实则绕开真正必须迈过去的那道坎（技术语法的内化），从而制造停滞的幻觉。

## 机制

```
捷径诱惑
  │
  ├─ 构图法则 → 看起来有章法，但没解决"为什么这样构图"
  ├─ 调色预设 → 画面好看了一时，但没有建立个人审美判断
  └─ 营销文案 → 用"故事感""氛围感"掩盖画面本身的不足
       │
       ▼
  自我感动式拍摄 → 拍了很多年，仍在爱好者水平
```

## 与四层递进的关系

[[摄影四层递进框架]]指出，捷径的本质是试图跨级跳过第一层（技术语法），直接进入第二层或第三层。结果是在每一层都"看起来会了"，但实际每层都不扎实，最终陷入长期停滞。

## 与"审美判断力≠软件操作"的关联

捷径幻觉的另一个表现是混淆 T 型（软件操作）和 W 型（审美判断）——以为学会 Lightroom 就是学会了摄影，实则是把技术执行层当成了审美决策层。

## 破除方法

1. 承认"拍了很久"不等于"会拍"，两者之间没有自动通道
2. 回到语法层，把基础练到不用过脑子
3. 用"可复现概率"检验照片，而非诉诸文案或滤镜

## 与"三类不靠谱摄影师"的关系

[[小麥]]在伴读中批评的三类摄影师（文案掩盖派、外因堆叠派、游客照冒充派）正是[[捷径幻觉]]的典型表现：试图绕过真正的技术修炼，通过文案、地点、器材堆叠来制造"好照片"的假象。参见[[三类不靠谱摄影师]]。
