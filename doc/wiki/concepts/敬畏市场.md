# 敬畏市场

**定义：** 敬畏市场是指基金经理承认市场不可预测、不将运气归为能力，并据此建立风控纪律和投资流程的性格特质。它是长期超额收益的来源之一，与[[自我服务偏见（基金经理归因偏差）]]形成对立。

## 核心机制

```
敬畏市场 = 承认无知 + 建立纪律 → 控制回撤 → 长期复利
```

## 行为表现

- 牛市高峰时主动限购，拒绝规模膨胀
- 业绩好时不将成功归因于个人能力，而是承认市场赏赐
- 经历教训后完善投资流程和风控措施
- 在进攻和防守之间寻找平衡，而非一味追求高收益

## 案例对比

| 行为 | 2020年表述 | 后续表现 |
|------|-----------|---------|
| 敬畏市场型 | "这么高收益是市场赏的，不能指望年年如此" | 2021-2023年熊市跌幅可控 |
| 自我服务偏见型 | 将业绩归功于自身选股能力 | 2021-2023年大幅回撤 |

## 实践意义

敬畏市场不等于保守，而是在进攻与防守之间找到平衡。这需要经验与反思的结合——单纯的经验不足以产生敬畏，必须有对自身运气成分的认知和反思能力。

## 与相关概念的关系

- [[自我服务偏见（基金经理归因偏差）]]：对立概念——前者承认外部因素影响，后者将所有成功归因内部
- [[最大回撤]]：敬畏市场的结果之一是控制回撤，二者构成事前性格指标→事后风控结果的逻辑链
- [[能力-vs-运气]]：敬畏市场的本质是正确区分能力与运气
