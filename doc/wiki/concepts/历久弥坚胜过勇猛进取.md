# 历久弥坚胜过勇猛进取 (Tried and True vs. Bold and New)

老牌成熟行业的长期回报，往往胜过高增长的新行业。这不是说增长没有价值，而是说**增长已经被买入价格定价了**。

## 核心论点

西格尔用历史数据展示了这一对比：

| 历久弥坚（老行业） | 勇猛进取（新行业） |
|---|---|
| 铁路 | 互联网 |
| 石油 | 生物科技 |
| 烟草 | 科技股 |
| 消费品 | 高速增长国家 |

老行业不性感，但市场给它们的起跑价低；新贵性感，但起跑价太高。当增长被高估值提前收走，剩下的就是账单，不是机会。

## 与增长率陷阱的关系

这是增长率陷阱的反面表述：

- 增长率陷阱：为增长付高价 → 亏损
- 历久弥坚：起点价格低 + 现金回流稳定 → 复利积累

两者描述的是同一机制的两面。

## 适用边界

这个框架适用于**估值敏感型**投资者——关注买入价格和现金回流，而非仅看行业增速。对于成长型投资者或短期交易者，这个结论需要配合其他框架使用。
