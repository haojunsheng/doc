# 排除法优于优选法

在低 alpha 空间的品类中，选基策略应聚焦于**"哪些不该买"**，而非"哪个是最好的"。

## 核心论点

- 短债基金的收益差异极小，主动管理能力对最终回报的影响远小于费用、结构等"排除项"。
- 在同类产品收益率高度趋同的前提下，找到"最优"的信息收益极低，而排除"最差"的收益极高。
- 五维过滤器（任职时长、星级、机构占比、费率排名、规模）本质上是一组**排除标准**，逐一过筛即可大幅缩小选择集。

## 适用边界

| 场景 | 适用性 |
|------|--------|
| 短债基金、货币替代型固收 | ✅ 高度适用，alpha 空间极小 |
| 宽基指数基金 | ✅ 适用，费率是主要区分因素 |
| 高 alpha 空间的主动权益基金 | ❌ 不适用，优选法更有价值 |
| 主题/行业基金 | ⚠️ 部分适用，需叠加主题逻辑判断 |

## 与"净值恐高症"的关系

[[净值恐高症]]描述投资者因过往高净值而拒绝购买"看起来贵"的基金的认知偏差。排除法提供了理性替代：不看净值高低，看五个硬指标是否全部通过。

## 注意事项

排除法框架本身也可能混合正选信号（如星级≥三星仍带有"优选"色彩），因此它并非纯粹排除，而是**以排除为主、正选为辅**的混合策略。
