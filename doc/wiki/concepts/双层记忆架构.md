# 双层记忆架构

本章汇合点：两条支线（用户记忆 + 知识库检索）的工程汇合方案。

## 架构组成

- **上层：Advanced JSON Cards 常驻** — 提供"概览"：backstory / person / relationship / 时间戳，支持部分更新和情境化消歧
- **下层：上下文感知检索按需取细节** — 提供"细节"：原始对话或文档的完整片段，解决分块切断上下文导致的指代丢失

## 设计动机

单一格式无法同时满足所有需求：

| 需求 | 对应层 | 载体 |
|------|--------|------|
| 稳定偏好、快速匹配 | 概览层 | Advanced JSON Cards |
| 完整上下文、精确溯源 | 细节层 | 上下文感知检索 |

## 与动态 Agent 公式的关系

双层记忆架构可视为"记忆"在 [[动态Agent公式]] 中的工程实现：JSON Cards 提供持久化的记忆状态，上下文感知检索提供按需调取的原始上下文。
