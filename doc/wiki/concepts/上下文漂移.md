# 上下文漂移

## 定义

在多步工具调用链中，中间步骤的返回结果逐渐淹没原始任务目标，导致 Agent 的行为偏离最初意图的现象。是 Agent 执行复杂任务时的核心失败模式之一。

## 核心机制

```
初始目标: "查询北京今天天气并推荐穿什么"
  │
  ▼
Step 1: 调用天气 API → 返回 "北京 25°C，晴"
  │
  ▼
Step 2: 调用穿衣建议 API → 返回详细穿搭指南（冗长）
  │
  ▼
Step 3: LLM 被 Step 2 的输出吸引，开始讨论时尚趋势
  │
  ▼
最终输出: 偏离了"推荐今天穿什么"的简洁目标
```

**触发条件**：
- 工具返回结果过长，挤占了后续推理的注意力
- 中间结果包含大量无关信息，稀释了对原始目标的聚焦
- 多步调用链超过某个临界步数后，"目标遗忘"概率指数上升

## 缓解策略

1. **结果截断**：对工具返回做摘要或截断，只保留与当前目标相关的部分
2. **目标锚定**：在每步推理中重新引用原始目标，防止偏移
3. **规划粒度**：减少不必要的中间步骤
4. **评估层拦截**：在关键节点加入检查点，验证当前状态仍对齐原始目标
