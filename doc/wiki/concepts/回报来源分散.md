# 回报来源分散

真正的分散化是「回报来源的分散」，而非「持有数量的分散」。

## 核心区分

| 误区 | 真相 |
|------|------|
| 买了 20 只股票 = 分散化 | 20 只科技股 = 同一回报因子，一荣俱荣一损俱损 |
| 持有数量越多越安全 | 边际分散化收益趋零，50 只以上效果接近于零 |
| 分散 = 广撒网 | 分散 = 不同回报因子的组合 |

## 形式化表达

```
分散化 = 不同回报因子的组合（价值/成长/规模/质量/地域）
      ≠ 同一因子内持有更多标的
```

## 实操示例

- **低分散**：50 只不同行业的股票（仍集中于单一资产类别）
- **高分散**：全球股票指数基金 + 债券基金 + 商品 ETF + REITs（跨类别、跨地域）

## 边界条件

过度分散也有问题：持有 50 只以上股票，边际分散化收益趋近于零，管理成本反而上升。一个全球股票指数基金即可包含上千只股票，实现有效分散。
