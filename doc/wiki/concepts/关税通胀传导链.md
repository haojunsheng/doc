# 关税通胀传导链

关税政策通过消费价格传导，引发通胀上升、降息落空、信贷违约率上升的完整连锁反应。这是2026年全球投资面临的"最大潜在波动源"。

## 形式化表达

```
关税 → 消费价格传导 → 通胀上升 → 降息泡汤 → 消费回调 + 违约上升
      ↘ 贸易 ↓ → GDP ↓ ──────────────→ 滞胀
```

## 传导机制详解

### 第一环：关税 → 消费价格传导
- 目前关税对消费价格的传导有限
- 但如果关税成本开始传导到消费端，将触发完整连锁反应
- Michael补充：消费者支出预期可能落空

### 第二环：通胀上升 → 降息泡汤
- 高通胀可能让美联储降息计划泡汤
- 预防式降息预期可能被打破

### 第三环：降息泡汤 → 违约上升
- 信用卡违约率已高于疫情前（Preston引用）
- 失业率已在小幅上升（Michael引用）
- 如果利率维持高位，违约率可能进一步恶化

## 滞胀维度（晨星2026Q2全球展望补充）

晨星对关税影响的量化评估：
- 下调美国GDP增长 **0.7个百分点**
- 上调通胀 **1.6个百分点**
- 关税升至**近百年来最高水平**
- 企业面临两难：吸收利润（股价跌）或转嫁消费者（通胀升）

这个滞胀分支对应形式化表达中的第二条传导路径：关税 → 贸易↓ → GDP↓ → 滞胀。当企业选择吸收关税成本而非转嫁时，短期通胀传导中断，但利润收缩拖累增长，仍可能触发滞胀风险。

## 与现有框架的关联

- 与[[油价冲击资产重定价传导链]]形成并列的两大宏观风险情景
- 是[[三情景油价冲击投资组合应对]]之外的重要风险来源
- 构成[[稳中求进框架]]中"留现金"的现实依据：为关税冲击预留缓冲
- 与[[错杀-修复框架]]的交叉：关税冲击下，部分板块（医疗保健、能源、房地产）因恐慌被**错杀**而低估，存在修复赔率；但传导链若持续恶化，这些板块也可能从"错杀"转为"真恶化"，需动态跟踪

## 边界条件

- 如果关税不再升级，传导链可能中断
- 如果企业自行吸收关税成本（而非转嫁消费者），传导链也会断裂——此时滞胀分支（GDP↓）可能单独成立
- 目前策略师们认为"韧性"已消化了部分关税冲击，但传导未完全结束
- 错杀-修复框架的适用前提是传导链尚未全面恶化；一旦违约率显著上行，错杀板块亦无法免疫
