# 迷你基金三重困境

迷你基金（规模<5000万元）同时面临流动性差、收益率低、费率侵蚀三重困境，三者形成负向闭环，使迷你基金成为投资者最应避免的一类基金。

## 困境一：流动性困境

规模小 → 持仓集中于小市值股票或低评级债券 → 变现时找不到交易对手 → 赎回延迟或部分赎回。

市场流动性紧张时尤为突出。例外：若持仓以大盘蓝筹为主，流动性问题有所缓解。

## 困境二：收益困境

三重因素压缩收益空间：

1. **持仓集中**：少数个股/个债导致净值大幅震荡
2. **投研资源不足**：基金公司核心投研力量向头部大基金倾斜
3. **无法参与高门槛资产**：资金体量受限，错过部分优质布局机会

例外：若基金经理主动管理能力极强，小规模反而灵活，可能跑赢大基金。

## 困境三：费率困境

固定成本（信息披露费、审计费等）分摊到小规模资产上，单位成本显著上升。同时，稍大的交易就影响标的价格，交易冲击成本更高。监管虽有信披费豁免规则，但管理费、托管费、交易成本仍高。

## 负向闭环

```
规模小 → 流动性差 → 净值波动大 → 业绩不佳 → 资金流出 → 规模更小
         ↑                                                        ↓
         ← 单位费率侵蚀更严重 ← 固定成本分摊基数小 ←———————
```

## 机构占比加剧效应

机构占比高的基金更容易滑入迷你困境。机构投资者行为一致性强，一旦触发赎回（基金经理变动、策略不如预期），规模缩水速度远超散户为主的产品，可能直接从大基金变为迷你基金。

晨星建议：**避开单一机构占比极高的基金**。

## 与规模诅咒的关系

[[规模诅咒]]主要描述规模过大的负面效应，本概念补充了规模过小的另一面——两者共同构成完整的"规模诅咒"谱系：

| 规模区间 | 主要风险 | 典型表现 |
|---------|---------|---------|
| 过小（<5000万）| [[迷你基金三重困境]] | 流动性危机、费率侵蚀、清盘风险 |
| 适中 | 无明显规模诅咒 | 策略执行效率高 |
| 过大 | 超额衰减 | 换手率下降、风格漂移、流动性恶化 |

## 已持有迷你基金的处理

- **可观察**：业绩稳定 + 规模回升迹象 + 经理未变更
- **果断赎回**：规模持续缩水 + 业绩低迷 + 风格漂移
- 赎回费通常低于清盘带来的损失

## 边界条件

- 持仓以大盘蓝筹为主的迷你基金，流动性问题相对较轻
- 基金经理能力极强时，小规模优势可抵消困境
- 基金公司自担固定费用时，费率侵蚀有所缓解但不会消失
