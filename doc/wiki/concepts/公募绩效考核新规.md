# 公募绩效考核新规

中国证券投资基金业协会2026版《基金管理公司绩效考核管理指引》，替代2022旧版。核心变化：薪酬不再与规模挂钩，改为与投资者真实盈利挂钩；高管强制跟投30%绩效薪酬买自家基金，基金经理40%买自己产品；递延支付不少于3年。整套制度瞄准"基金赚钱、基民不赚钱"的根源——管理人利益与持有人利益不一致。

## 六项核心制度

### 1. 中长期导向考核

三年以上中长期指标权重≥80%，薪酬不再与规模挂钩。

**旧规→新规转变**：
- 旧规：规模↑ → 管理费↑ → 薪酬↑
- 新规：持有人盈利↑ + 中长期业绩(≥80%) → 薪酬↑
- 新版删除"薪酬"字眼，用绩效考核统筹薪酬全链条

### 2. 强制跟投绑定

高管30%绩效薪酬买入自家基金（权益类≥60%），基金经理40%绩效薪酬买入自己管理的产品，持有期不少于1年。

**机制逻辑**：
```
高管薪酬 × 30% → 买自家基金(权益≥60%)
基金经理薪酬 × 40% → 买自己产品（持有≥1年）
```

与 [[基金经理自持]] 的区别：自持是基金经理个人行为信号，强制跟投是监管强制的制度安排，约束力远强于前者。

### 3. 薪酬递延机制

递延支付不少于3年，起付不早于T+2年，支付节奏不快于等分发放。董事长、高管、核心人员递延比例≥40%。3年内若出现风险事件，未发放部分可追索扣回。

**时间轴**：
```
当年绩效 → T+2年开始发放 → 至少3年等分发放 → 实际到手延后2-5年
```

### 4. 阶梯化薪酬调节

针对主动权益产品的不对称奖惩：三年跑输基准超10%且利润为负，基金经理绩效薪酬降幅不低于30%；反之可适度上调。

```
业绩 < 基准(-10%) + 利润率(-) → 薪酬↓≥30%
业绩 > 基准 + 利润率(+)       → 薪酬可↑
```

### 5. 投资者盈利纳入考核

把"盈利投资者占比"纳入基金公司考核指标，正式将 [[晨星中国]] 开创的学术指标上升为监管硬要求。

这是解决 [[投资者回报差]] 的制度级回应——基金净值收益≠投资者真实收益，追涨杀跌导致两者背离。

### 6. 股东分红约束

基金业绩不佳、投资者亏损较大时，降低股东分红频率和比例。打通持有人、公司、从业人员、股东四方利益链条，实现"业绩差的年份股东要多扛一段"。

## 制度设计的核心逻辑

```
管理人利益与持有人利益不一致
    ↓ 是一切短视行为的根源
用"强制跟投+递延支付+盈利考核"三把锁
    ↓
把管理人的利益周期拉长到与持有人对齐
```

## 与晨星评价体系的呼应

[[晨星中国]]评价体系与新规方向高度一致，从第三方视角佐证了改革逻辑：
- 晨星星级评级强调长期收益并包含风险衡量，反对只看短期排名的做法
- 晨星奖牌基金的定性评级把费率和信托责任纳入评价维度
- 晨星明确认为"规模扩张时多投研少营销才是对持有人负责"，与新规禁止规模崇拜的逻辑一致

晨星评价体系也提供了验证新规效果的指标体系——投资者可通过晨星官网查询基金经理跟投情况和投资者回报数据。详见 [[sources/5-notes--31-20260628t154108-qa-基金考核投资者本位__qa--7gknqp]]。

## 投资者验证新规效果的三个指标

| 指标 | 观察方向 | 含义 |
|------|---------|------|
| 投资者回报差 | 缩小 | 基金净值收益与基民真实收益差距减小 |
| 基金经理换手率 | 下降 | 不再为排名频繁交易 |
| 规模变化 | 健康增长（非暴增暴减） | 业绩驱动而非短期行为驱动 |

需至少3-5年充分验证，短期数据可能受市场环境影响而失真。

## 边界与风险

1. **短期极端行情下的约束困境**：80%中长期权重可能在暴涨后泡沫期让基金经理在短期考核中吃亏，与市场节奏脱节
2. **人才流失风险**：若基金业绩长期低迷，强制跟投导致基金经理薪酬因自购亏损而大幅下降
3. **一刀切问题**：若市场整体下行导致几乎所有基金跑输基准，阶梯化薪酬规则可能误伤优秀基金经理
4. **递延支付执行障碍**：若递延期间基金公司被并购或业务调整，追索扣回可能面临法律障碍
5. **能力 vs 动机的混淆**：新规假设"经理有能力但动机不足"，但若能力本身不足，强制跟投反而造成双输
6. **销售端盈亏考核归因难题**：客户盈亏数据统计周期长、归因困难，销售端考核在实际操作中可能流于形式，是新规尚未解决的落地盲区
