# 可转债仓位择时

在固收+基金中，根据权益市场趋势预判动态调节可转债仓位的操作策略。

## 策略逻辑

可转债兼具债性和股性，其价格与权益市场高度相关。通过前瞻性调整转债仓位：

```
权益牛市预期 → 提高转债仓位 → 获取权益上涨增强收益
权益熊市预期 → 降低转债仓位 → 规避权益下跌损失
```

## 典型案例：鹏华产业债债券

| 时期 | 市场状态 | 操作 | 结果 |
|------|----------|------|------|
| 2014Q4 | 权益牛市 | 维持高转债仓位 | 收益增强 |
| 2015H2 | 权益调整 | 提前大幅降仓 | 规避风险 |
| 2016Q1 | 权益低迷 | 提前大幅降仓 | 规避风险 |
| 2019Q1 | 权益牛市 | 维持高转债仓位 | 收益增强 |
| 2020H1 | 权益调整 | 提前大幅降仓 | 规避风险 |

## 核心能力要求

1. **宏观研判**：对经济周期和权益市场趋势的判断
2. **数据支撑**：可转债估值指标（溢价率、隐含波动率等）
3. **纪律执行**：判断正确时敢于维持高仓位，判断错误时及时止损

## 风险与挑战

- **单点依赖**：高度依赖基金经理个人判断，如[[鹏华产业债债券]]依赖祝松
- **择时失误放大损失**：判断错误时，高转债仓位会显著拖累收益
- **仓位偏高放大波动**：如鹏华产业债转债均15% vs 同类6%，双刃剑效应明显
- **验证困难**：择时能力的可复制性和持续性难以独立验证，存在运气成分可能
