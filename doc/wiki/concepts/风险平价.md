# 风险平价（Risk Parity）

**风险平价**是一种资产配置策略，核心思想是按各资产对组合总风险的贡献来分配权重，而非按资本金额分配。

## 核心逻辑

传统资产配置（如 60/40 股债组合）中，股票往往贡献了绝大部分风险（约 90%+），债券的风险贡献很小。风险平价试图让每类资产对组合风险的贡献趋于均衡。

```
传统配置: 资本均分 → 风险不均（股票主导风险）
风险平价: 风险均分 → 资本不均（债券加杠杆以平衡风险贡献）
```

## 历史背景与兴衰

风险平价在 2008 年金融危机后大受追捧，被视为"为下一次危机做准备"的经典策略——其代表产品桥水基金的 All Weather Fund 闻名遐迩。

然而，[[sources/5-notes--30-20260614t124755-qa-完美投资组合追寻qa--8k9hl5]] 中 Q9 明确指出：2022 年股债双杀证实了风险平价的局限——该策略针对的是上一次危机（2008 年金融危机的通缩/流动性冲击）设计的，但当危机形态变化时（通胀飙升导致股债同跌），策略失效。

> "为上一次危机做准备是危险的，因为明天的危机不会是今天的危机。"

## 关键教训

- 任何策略都是对过往市场特征的适应，**策略的有效性随市场环境变化而衰减**
- 风险平价并非万能，在股债同跌的环境中暴露出严重缺陷
- 完美组合需要**适应变化**，而非固化过去——组合框架应具备动态调整能力
