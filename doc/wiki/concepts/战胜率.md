# 战胜率

## 定义

**战胜率**是指基金跑赢业绩基准的比例。它是衡量基金经理超额能力（Alpha）的重要指标之一。

## 核心发现

**主动持股比例与战胜率无显著正相关。**

2024年数据显示，将主动偏股基金按主动持股比例分为三个区间：
- 0–80%：战胜率 X%
- 80–90%：战胜率 Y%
- 90–100%：战胜率 Z%

三者之间没有统计学意义上的显著差异，直接推翻"越主动越好"的朴素认知。

## 形式化表达

```
主动持股比例↑ ≠ 战胜率↑
```

主动持股比例是"描述性指标"，战胜率才是"结果性指标"。两者之间的关系远比直觉复杂——它取决于基金经理的真实能力、市场环境、费率和规模等因素。

## 与 [[业绩信噪比]] 的关系

高主动持股不一定提高业绩信噪比。偏离本身不产生信号——只有基金经理的能力才能产生超额收益信号。当主动持股比例高但能力不足时，偏离反而会放大噪音（波动），降低业绩信噪比。

## 晨星64讲补充数据

《晨星基金投资64讲》补充了更完整的成本-战胜率论据（数据来源为晨星自身统计，属行业视角，非独立第三方审计）：

| 指标 | 数值 |
|------|------|
| 主动基金战胜同类被动基金的长期比例 | **长期低于 50%** |
| 主动基金年均一年战胜率（2024） | **约 20%** |
| 主动基金三年战败率 | **超过 50%** |
| 主动基金平均持有成本 | **2.55%** |
| 被动基金平均持有成本 | **1.03%** |
| 主动基金年均换手率 | **350%–400%**（持仓每年更换 3–4 遍） |

核心逻辑：
```
主动基金总成本（2.55%） - 被动基金总成本（1.03%） ≈ 额外成本约 1.5%
额外成本侵蚀回报：若年化回报 7%，1% 费率占走约 15% 的回报
→ 仅 20% 的主动基金一年战胜被动，超一半三年战败
```

## 与 [[主动被动胜率基准方法论]] 的关系

[[主动被动胜率基准方法论]]强调用被动基金而非指数本身作为基准，战胜率正是建立在这个方法论之上——以被动基金为基准时，主动基金的胜率长期低于 50%，这个数据比用指数做基准时更有说服力。

## 与 [[主动基金行业胜率分化框架]] 的关系

[[主动基金行业胜率分化框架]]指出主动胜率在不同行业之间存在分化，某些行业（如细分行业）中主动基金有一定胜率优势。战胜率的整体数据（<50%）是加总结果，行业内分化意味着这个均值下隐藏着结构性差异。

## 边界条件

- 在无效市场（小盘股、新兴市场），较高主动持股更可能转化为高战胜率
- 在有效市场（大盘股、成熟市场），即使高主动持股也难以显著提升战胜率
- 费率是关键调节变量：高主动持股 + 高费率 → 净战胜率更低
- 战胜率是历史统计，不构成对未来表现的承诺
- 短期（1年内）战胜率波动较大，应关注长期（3-5年以上）数据
