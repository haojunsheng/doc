# 股东分红约束

《基金管理公司绩效考核管理指引》（2026版）首次将股东分红与投资者盈利挂钩的制度设计：基金业绩不佳、投资者亏损较大时，应适当降低分红频率和比例。

## 制度逻辑

**旧格局的问题**：
```
基金公司赚管理费 → 股东高分红 → 不管基民盈亏
```
形成典型的利益冲突：基民亏钱，股东照常分红。

**新规的修正**：
```
基民亏钱 → 股东分红↓
```

## 核心意义

打通持有人、公司、从业人员、股东四方利益链条，实现最后一环的对接——此前股东可以从管理费中持续分红，而不必承担投资者亏损的后果。

## 边界条件

- 若股东有短期财务需求（如补充资本金），降低分红可能遭到股东抵制
- 该约束的执行力取决于监管处罚力度和具体实施细则
