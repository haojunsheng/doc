# 人力资本-金融资产反向配置原则

## 核心原则

在做出资产配置决策时，应先判断自身人力资本的属性，然后在金融资产中做**反向配置**，以实现整体风险均衡。

**形式化表达：**
```
职业像债券(收入稳定) → 金融资产多配股票
职业像股票(收入波动大) → 金融资产多配债券/现金
```

## 原理

人的总财富由金融资本和人力资本共同构成。如果两者风险属性相同（都偏向股票或都偏向债券），则整体风险敞口高度集中；反之，如果两者风险属性互补，则整体组合更稳健。

## 操作框架

1. **判断职业收入属性**：
   - 稳定型（债券属性）：公务员、教师、医生（传统体制内）、大学教授（tenure 后）
   - 波动型（股票属性）：创业者、销售人员、自由职业者、基金经理、互联网从业者
   
2. **行业判断优先**：行业判断比职业判断更重要——一个"稳定职业"如果所在行业在衰退，人力资本也不安全。

3. **金融资产反向配置**：
   - 人力资本像债券 → 金融资产提高股票比例
   - 人力资本像股票 → 金融资产提高债券/现金比例

## 反面案例

- [[svb]]：硅谷银行员工工资来自银行，退休金又投了银行股票，100% 集中于单一公司，银行倒闭后失业+投资双杀。
- 互联网大厂员工：工资+期权+投资三重集中于互联网行业，行业下行时遭受三重打击。

## 边界条件

- 人力资本难以精确量化，只能做粗略估计。
- "看清全貌很重要"但"看清后若无调整能力，焦虑反而增加"——诊断意义与实际可操作性之间存在张力。
- 若投资完全分散（如全球指数+债券），行业集中风险可大幅降低。
