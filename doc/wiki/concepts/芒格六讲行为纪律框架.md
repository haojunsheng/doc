# 芒格六讲行为纪律框架

## 核心命题

> **投资是认知纪律的较量，不是智力的较量。**

六个原则各自独立，又互相印证同一命题：真正的投资敌人是自身的认知盲区与情绪弱点，而非外部市场。

---

## 六讲框架总览

### Q1 · 机会成本思维：比较而非孤立判断

**形式化：**

```
投资决策 = 新标的 vs 已有持仓
         → 认知不够或收益不够 → 放弃
```

**关键自问：**
1. 我对这个标的的认知是否高于已有持仓？
2. 风险调整后的收益是否高于已有持仓？

**边界：** 若已有持仓逻辑被证伪，即便新标的不够好也应切换。

---

### Q2 · 市场常识幻觉：独立判断而非追共识

**形式化：**

```
市场常识 = 集体情绪
         → 追常识 = 追高
         → 保持理性 = 独立判断
```

**关键区分：** 有些"常识"是对的（如均值回归），需区分常识与规律。

---

### Q3 · 嫉妒的心理代价：双重惩罚机制

**形式化：**

```
嫉妒 → 追涨 → 亏钱 + 不快乐 → 双重惩罚
```

**关键洞察：** 嫉妒让人同时亏钱且失去内心的平静，这是投资中少有的"双倍惩罚"情绪。

**边界：** 若别人的高回报来自真正研究发现而非泡沫，跟进不叫嫉妒叫学习。

---

### Q4 · 反向思考（Jacobi 原则）：完整视角

**形式化：**

```
买入理由(N条) + 不买理由(N条) → 完整视角 → 更优决策
```

**关键标准：** 芒格认为不能说服对立面，说明了解不够透彻。反向思考后仍倾向买入→决策更坚定；若犹豫→研究不够。

---

### Q5 · 双重错误墙：两种愚蠢都值得铭记

**形式化：**

```
错误墙 = 做错的 + 没做但能赚的 → 两种愚蠢 → 双重学习
```

**关键机制：** 人类大脑倾向于遗忘错过的机会，因为"没做的事"没有带来直接的痛苦体验。必须主动建立记忆系统。

**边界：** 若市场环境变了，过去的"错误"可能在新环境下是对的。

---

### Q6 · 不杠杆即风险控制：确保不被动

**形式化：**

```
不杠杆 → 危机时零压力 → 疯狂世界中被动位置↓
```

**关键案例：** 约翰·阿里亚加持有 1500 万平方英尺资产，其中 300 万空置，因无杠杆危机来时连眉头都不皱。

**边界：** 关键是"不被动"而非绝对不杠杆——若永远不杠杆，可能错过合理加杠杆机会。

---

## 六讲归一：投资敌人的统一画像

| 问题 | 内部陷阱 | 纪律解法 |
|------|----------|----------|
| 要不要买新标的？ | 孤立判断好坏 | 与已有持仓比较（Q1） |
| 市场共识怎么说？ | 追常识=追高 | 独立判断（Q2） |
| 别人赚钱怎么办？ | 嫉妒=追涨 | 克制嫉妒（Q3） |
| 买入理由够充分吗？ | 只看单边证据 | 反向思考（Q4） |
| 犯了错怎么办？ | 选择性遗忘 | 双重错误墙（Q5） |
| 如何控制风险？ | 追求高回报 | 确保不被动（Q6） |

---

## 与相邻框架的关系

- **与[[逆向投资]]的关系：** Q2 和 Q4 是逆向投资的行为前提——先戒除常识幻觉和单边思考，才能正确执行逆向操作
- **与[[安全边际]]的关系：** Q6 不杠杆逻辑与安全边际同源，都是"先确保不死"
- **与[[凯利公式仓位管理]]的张力：** 凯利公式提倡在优势下合理加杠杆最大化增长，Q6 强调不杠杆确保生存——前者追求增长最优，后者追求绝对生存
- **与[[行为代价-mind-the-gap]]的关系：** Q3 嫉妒是最典型的行为代价案例，亏钱+不快乐双重损失

---

## 适用场景

- 个人投资者进行资产配置决策
- 机构投资者评估新标的是否纳入组合
- 基金管理人检视自身决策流程是否存在认知偏差
- 行为金融学视角下的投资纪律训练
