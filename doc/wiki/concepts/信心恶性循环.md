# 信心恶性循环

经济衰退的自我强化机制，核心链条为信心下降引发的行为连锁反应。

## 机制

```
信心 ↓
  → 消费者节衣缩食，消费 ↓
    → 企业销售额下降
      → 企业缩减开支，裁员降薪
        → 就业和收入受损
          → 消费进一步 ↓
            → 信心进一步 ↓  （闭环）
```

## 与熊市的关系

熊市本质上是一场"投资者信心危机"，而信心恶性循环描述的是实体经济层面的类似机制。两者具有同构性：

- 实体层面：信心↓→消费↓→经济恶化→信心再↓
- 金融市场层面：信心↓→抛售→股价↓→财富缩水→信心再↓

[[股市与经济脱钩]] 框架解释了为何这两个循环并非完全同步——金融市场提前定价预期，而实体经济数据滞后确认。

## 三大诱因中的位置

[[source/5-notes--36-20260616t122744-伴读-熊市与经济周期关系reading--22es9r]] 中，信心减弱被列为经济衰退的三大诱因之一，高利率和通胀/通缩是另外两个。三者可相互强化：

- 高利率加剧债务负担，打击企业扩张意愿→信心↓
- 通胀侵蚀实际购买力→消费↓→企业盈利↓→信心↓
- 通缩反映需求不足→企业被迫降价→利润压缩→裁员→信心↓

## 与 [[恐慌性离场负反馈循环]] 的对比

| 维度 | 信心恶性循环 | 恐慌性离场负反馈循环 |
|------|------------|-------------------|
| 层面 | 实体经济 | 金融市场 |
| 触发 | 信心减弱 | 暴跌+恐慌 |
| 传导 | 消费→企业→就业 | 抛售→价格下跌→进一步悲观 |
| 可逆性 | 需政策干预打破 | 需信心恢复或外部冲击结束 |

两者在同构但不等价——信心循环是根因，恐慌离场是金融市场层面的放大和加速机制。
