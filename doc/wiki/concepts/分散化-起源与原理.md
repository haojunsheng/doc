# 分散化（起源与原理）

分散化是最古老也是最基本的风险管理思想：**不要把鸡蛋放在同一个篮子里**。通过持有相关性较低的资产，可以在不牺牲预期收益的前提下降低整体风险。

## 历史起源：日内瓦三十少女基金

分散化的最早实践可追溯至 18 世纪的日内瓦：

- 法国政府向公民出售终身年金债券，承诺每年支付固定金额直至受益人死亡
- 投资者发现：选择年轻受益人（如 30 名年轻女性）可以大幅延长年金给付期限，提高投资回报
- 瑞士银行家将多笔年金整合为一个组合，选择年轻女性作为受益人——这实质上就是最早的"分散化组合"

这个案例表明：**分散化的本质是通过降低结果的变动性来延长期限**，而不仅仅是"多买几只股票"。

## 现代原理

[[哈里-马科维茨-harry-markowitz]] 的均值-方差模型将分散化从经验上升为科学：

```
组合风险 ≠ 各资产风险的简单加权平均
组合风险 = f(各资产风险, 资产间相关性)
```

关键点：
- 资产间相关性越低，组合风险降低效果越强
- 相关性接近 -1 时，风险可大幅抵消；相关性接近 +1 时，分散化无效

## 常见误解

**"买了多只股票就等于分散化"**是错误的。如果多只股票属于同一行业或同一宏观因子，它们的相关性很高，分散化效果极有限。

参见 [[concepts/伪分散风险]] 了解这种典型误区。

## 实践意义

分散化是 [[组合视角]] 的核心操作手段之一——评估一只新资产是否值得加入组合，关键问题是"它与现有持仓的相关性有多低"，而非"它本身好不好"。
