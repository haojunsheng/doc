# 以地谋发展模式

以土地为核心信用基础和发展工具的整套地方政府行为模式，是理解当代中国经济运行的关键框架。

## 核心定义

**以地谋发展**：地方政府通过控制土地供应（双向定价）、以土地为抵押融资（土地金融）、低价工业用地招商引资，实现工业化与城市化的自我强化循环。

## 完整因果链

```
1994 年分税制改革
  │
  ├→ 增值税 75% 划归中央，设立国税局垂直管理
  │   → 地方预算内财力大幅缩水
  │
  ├→ 发展经济的政治激励未变（GDP 考核、官员晋升）
  │
  ▼
地方政府必须另找财源 → 以地谋发展模式成型
  │
  ├→ 土地财政：高价出让住宅用地（2010 年占地方预算外收入 68%）
  │
  ├→ 土地金融：城投公司以土地为抵押撬动银行信贷
  │
  └→ 双向定价：工业用地低价招商 + 商住用地高价套现
        │
        ▼
  招商引资竞争 → 工业园建设 → 制造业集聚 → 就业/GDP/税收
        │
        ▼
  基建投入提升城市吸引力 → 地价上涨 → 循环强化
        │
        ▼
  宏观后果：快速工业化 + 城市化 + 房价上涨 + 地方债务累积
```

## 与相关概念的关系

- **[[土地财政]]**：以地谋发展的收入端（卖地收入）。
- **[[土地金融]]**：以地谋发展的杠杆端（土地抵押融资）。
- **[[双向定价]]**：以地谋发展的操作工具（工业低价 + 商住高价）。
- **[[生产型政府]]**：以地谋发展的行为主体特征（政府直接参与投资和开发）。
- **[[分税制]]**：以地谋发展模式的制度起源。

## 关键洞察

这个模式解释了一组表面上矛盾的现象为何能并存：

1. 房价高企与大力招商引资并存——不是矛盾，而是同一激励结构的两面。
2. 地方债规模庞大但无系统性崩溃——债务有明确抵押物（土地）和偿还来源（未来土地增值），是理性融资而非盲目借贷。
3. 各地竞相建设工业园——工业税源是地方政府的核心利益，低价工业用地是有竞争力的招商工具。

## 转型方向

《置身事内》指出，以地谋发展模式在特定历史阶段有效，但不必然适用于未来。转型方向是**服务型政府 + 探索创新**：从"生产蛋糕"转向"提供公共服务"，从"招商引资竞争"转向"制度创新竞争"。

## 证据强度

- 描述性分析为主，逻辑自洽，缺乏严格因果识别。
- 案例支撑强：京东方合肥、光伏产业、各地工业园均有具体数据。
- 与学界已有研究（如周飞舟"土地财政"、陈斌开等关于分税制的研究）高度一致。
