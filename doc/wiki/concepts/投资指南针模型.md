# 投资指南针模型

## 模型概述

投资指南针模型是从"过想要的生活"出发推导投资策略的四步框架。与常见投资框架不同，它不以收益率或风险等级为起点，而是以个人生活愿景为起点。

## 四步框架

```
指南针 = 生活需求 × 所需金额 × 时间 × 现状评估
```

1. **我想要什么生活**（生活需求）
   - 定义理想生活的具体场景：住在哪里、做什么工作、什么样的日常节奏
   - 这是整个框架的起点，也是最难回答的一步

2. **需要多少钱**（所需金额）
   - 将生活需求转化为具体的财务数字
   - 包括日常开销、重大支出（买房、教育、医疗）、应急储备

3. **多久能实现**（时间）
   - 时间尺度决定实现方式：一年赚100万 vs 四十年赚100万，策略完全不同
   - 时间越长，可承受的风险越高，复利效应越显著

4. **现实吗**（现状评估）
   - 对照当前资产、收入、储蓄率，判断目标是否可实现
   - 如不现实，回到第1或第2步调整，而非硬撑

## 关键原则

- **诚实面对自我**：很多人不愿意承认目标不现实，或回避"我不知道我想要什么"
- **金钱是工具，不是目的**：所有财务计算都服务于生活愿景，而非反过来
- **目标可调整**：发现不现实时修改时间或金额，关键是保持"有目标"而非让目标永远不变

## 相关概念

### 与[[生活愿景倒推法]]的关系

[[生活愿景倒推法]]是[[投资指南针模型]]的哲学基础和操作补充——指南针模型提供结构化的四步框架，生活愿景倒推法则强调第一步（"写作描述理想生活"）的操作细节，并增加了"动态调整"作为显式步骤。

### 与[[富有是副产品]]的关系

[[富有是副产品]]是[[投资指南针模型]]的价值前提：如果富有是目标本身，指南针就会偏离到"收益率最大化"而非"生活质量最大化"。[[富有是副产品]]回答"为什么"，指南针模型回答"怎么做"。

## 开放问题

- "现实吗"这一步缺乏量化基准（如储蓄率、预期收益率假设）
