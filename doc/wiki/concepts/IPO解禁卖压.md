# IPO解禁卖压

IPO解禁卖压是指私募投资者和员工持股在锁定期结束后集中变现，对股价形成的下行压力。这是判断SpaceX等巨无霸IPO入场时机的关键机制。

## 机制

```
IPO热度↑ → 短期股价↑ → 180天锁定期到期 → 卖压↑ → 估值回归
```

核心逻辑：
- IPO时初始流通股比例小，流动性稀缺推高价格
- 投行推动+叙事热度进一步放大短期上涨
- 锁定期到期后，私募和员工持股集中解禁
- 大量抛售压力使价格回归内在价值

## SpaceX案例

- 市场估值：1.7-2万亿美元
- 晨星合理估值：约7800亿美元
- 180天锁定期到期后，私募和员工持股解禁
- 晨星建议：等待更高安全边际的时机

## 与行为偏差的关系

IPO解禁卖压是[[追涨杀跌损益侵蚀]]的典型场景之一：
- 散户在IPO热度中追高买入
- 锁定期后面临卖压下跌
- 恐慌性卖出进一步扩大损失

## 投资决策含义

- IPO不是最佳入场时机——历史数据显示锁定期后价格回归
- 等待解禁完成后再评估更安全边际
- 若未验证技术已验证成功，则等待成本可能很高（边界条件）
