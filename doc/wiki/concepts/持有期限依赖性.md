# 持有期限依赖性

## 定义

同一投资组合的表现随持有期限不同而得出相反结论的现象。在固收+语境中，短期可能跑输纯债，长期则跑赢——持有期限是评估固收+的隐藏变量。

## 核心发现

近3年熊市区间数据：
- 积极债券基金年化：-1.0%
- 保守混合基金年化：-1.2%
- 纯债基金年化：+3.3%

10年维度：固收+总体跑赢纯债，风险资产增厚效应累积释放。

## 形式化表达

```
短期（3年熊市）:  固收+ ≺ 纯债
长期（10年）:    固收+ ≻ 纯债

持有期限 T 决定 "+" 资产是增厚还是拖累
```

## 边界条件

若未来股市持续低迷，10年维度优势也会缩小——"长期必赢"是条件性命题而非必然结论。

## 投资者含义

投资者在配置固收+前，需明确自身资金的实际持有期限。若资金需在3年内使用，固收+在熊市中可能不如纯债；若资金可持有10年，固收+的长期增厚效应更可能兑现。

盲目追求"稳健+"的短期资金，可能在熊市中既承受了回撤，又错失了纯债的稳定回报。
