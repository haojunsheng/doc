# 基准做市信用债ETF

**基准做市信用债ETF**是指2024年底获批的8只跟踪做市信用债指数的交易所交易基金，成分券均为AAA级债券，由交易所做市商提供流动性支持。

这是国内信用债场内投资的关键突破——此前信用债ETF仅3只，产品布局严重薄弱。

## 背景与突破

2024年底之前，国内信用债ETF仅有3只产品，几乎空白。2024年底，监管批准8只新ETF分别跟踪：

- **上证做市公司债指数**：4只ETF
- **深证做市信用债指数**：4只ETF

加上原有的3只信用债ETF，信用债ETF总数增至11只。

## 核心机制

### AAA级筛选标准

- 成分券信用评级的**最低门槛为AAA级**（最高评级）
- 剔除低评级信用债，从源头控制信用风险
- 相比主动债基可能信用下沉的策略，本产品体系更为保守

### 做市商流动性支持

- 交易所指定做市商在成分券层面提供双边报价
- 当二级市场买卖价差扩大时，做市商自动补位
- 理论上流动性优于无做市支持的信用债ETF

**边界条件**：若做市商制度执行不到位（如做市商积极性不足、报价不及时），流动性优势可能打折扣，需持续跟踪实际成交数据。

## 与同类产品的对比

| 维度 | 基准做市信用债ETF | 传统信用债ETF（3只） | 主动信用债基金 |
|------|-----------------|-------------------|-------------|
| 信用质量 | AAA级（上限） | 参差不齐 | 依赖经理判断 |
| 流动性 | 做市商支持 | 一般 | 申购赎回制 |
| 费率 | 低（0.15%+0.05%） | 低 | 较高（0.2%-1.0%） |
| 策略透明度 | 高 | 高 | 低 |
| 信用下沉空间 | 无 | 有限 | 有（但风险高） |
| 超额收益潜力 | 无（被动） | 无（被动） | 有（主动管理） |

## 在债券ETF三分法中的定位

[[债券ETF三分法]]将国内债券ETF分为利率债ETF（16只）、信用债ETF（11只）、可转债ETF（2只）三大类。基准做市信用债ETF属于信用债ETF子集，填补了低评级信用债的场内投资空白——AAA级筛选使得这类产品风险特征更接近利率债，但收益率略高于利率债。

## 配置价值

对于追求**信用风险可控、费率低廉、交易灵活**的投资者，基准做市信用债ETF是配置信用债敞口的理想工具：

```
利率债ETF（无信用风险）+ 基准做市信用债ETF（AAA级信用风险）
→ 在利率债基础上获取少量信用利差，风险可控
```

适合放在组合中承担[[债券稳定器]]功能的信用部分，而非作为收益增强工具。
