# 适应性市场假说（Adaptive Markets Hypothesis, AMEH）

**适应性市场假说（AMEH）**由麻省理工学院金融学教授 [[罗闻全-andrew-lo]] 提出，是对传统 [[有效市场假说]] 的修正与补充。

## 核心观点

AMEH 认为金融市场不是物理系统（遵循恒定不变的定律），而是**生态系统**——参与者之间不断竞争、创新、适应、选择和进化。

```
EMH:  市场 = 物理系统（恒定定律）
AMEH: 市场 = 生态系统（生物竞争/适应）
```

关键区别：

| 维度 | EMH | AMEH |
|------|-----|------|
| 市场性质 | 物理系统，恒定定律 | 生态系统，动态演化 |
| 参与者 | 完全理性 | 有限理性，通过学习适应 |
| 有效性 | 普遍成立 | 条件性、阶段性 |
| 失效解释 | 异常（需修正模型） | 正常（生态变化的一部分） |

## 与市场有效性的关系

AMEH 并不否定 EMH，而是将其置于一个更大的框架内：

- **市场有效性是条件性的**：在某些条件下市场近似有效，在另一些条件下失效
- **有效性是动态变化的**：随着参与者数量、策略同质性、市场环境而变化
- **竞争驱动进化**：套利者发现错配→消除错配→策略失效→新策略涌现

当市场出现错配时，理解错配成因的投资者能抓住机会；但随着更多人学习并模仿，机会被填补，策略逐渐失效。

## 实践启示

- 市场有效性不是永恒真理，也不是彻底错误——它是**随条件变化的程度问题**
- 投资者不应盲目信奉"市场永远有效"或"市场永远无效"，而应判断当下所处阶段
- 策略的生命周期：发现→获利→同质化→失效→再发现

## 当前地位

AMEH 目前尚未被主流金融学广泛接受，更多被视为一种**启发式框架**而非可操作的定价模型。但它提供了一种比 EMH 更贴近现实的视角，帮助投资者理解市场失效期的规律。
