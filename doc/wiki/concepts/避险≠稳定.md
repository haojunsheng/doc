# 避险≠稳定

**避险≠稳定**是对黄金"避险资产"标签的纠偏认知：黄金的避险属性来自其与股债的低相关性（组合分散价值），而非自身价格表现稳健。历史上黄金多次出现暴涨暴跌，波动性极高。

## 核心命题

```
避险 ≠ 稳定
黄金的"避险" = 与股债低相关 → 组合分散工具
黄金的"自身" = 暴涨暴跌周期 → 波动性极高
```

这是一个常见的认知混淆：投资者往往把"避险资产"等同于"稳健资产"，但黄金恰恰相反——它的避险功能来自于它不跟随股债同涨同跌，而不是因为它自己波动小。

## 历史证据

| 时期 | 事件 | 表现 |
|------|------|------|
| 1980年10月-1985年2月 | 金价年均跌幅 | 超过17% |
| 1982-2000年 | 美国股市年化回报 | 近17% |
| 同期 | 黄金年化回报 | 近-2% |
| 2011年8月峰值后 | 2013-2015年 | 惨烈下跌 |

## 认知偏差机制

1. **可得性偏差**：记住2009-2011年的暴涨，忘记1980-2000年的十年低迷
2. **标签效应**："避险资产"标签让人误以为黄金天然安全
3. **线性外推**：看到近年金价持续上涨，推断未来也会如此

## 与[[concepts/均值回归陷阱]]的关联

[[concepts/均值回归陷阱]]描述的是投资者过度依赖均值回归假设的认知偏差。而[[concepts/黄金配置双面框架]]中的风险面则进一步指出：即使不考虑均值回归，黄金自身的波动性也远高于"避险"标签所暗示的水平。

## 配置启示

- 黄金适合做组合中的"保险"（[[concepts/黄金保险定位框架]]），不适合做短期博弈工具
- 配置黄金应基于其低相关性带来的分散价值，而非期待其单边上涨
- 控制配置比例，避免因误判"避险=稳定"而过度集中
