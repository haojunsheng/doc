# 核心+卫星策略在FOF中的应用

目标日期基金在下滑曲线确定的战略配置基础上，基金经理通过"核心+卫星"策略进行战术调整。

该策略同样适用于单只主动权益基金的内部持股设计，不局限于 FOF 层级。

## 策略结构（FOF 层级）

```
核心仓位（60-70%）：长期持有基本面好的基金，跟踪基准指数
卫星仓位（30-40%）：择机调整，捕捉风格或行业短期机会
```

## 策略结构（单只基金内部持仓层面）

核心+卫星结构同样适用于单只主动权益基金的内部持股设计：

```
核心仓位（约 70%）：大盘蓝筹股 → 保稳定，流动性好，市值大
卫星仓位（约 30%）：中小盘股     → 博超额，在市值或风格约束下追求 alpha
```

参见 [[持股集中度评估框架]] 中关于核心+卫星内部结构的论述。

## 运作机制

- **战略配置**：由下滑曲线决定大类资产比例（权益/固收）
- **战术调整**：基金经理可在 ±10% 范围内浮动权益仓位
- **核心仓位**：选基本面好的基金长期持有，与万得偏股型基金指数接近
- **卫星仓位**：通过指数基金或风格基金做行业和风格暴露调整

## 典型案例

- **平安基金**：核心配置约占权益仓位的 60%，卫星配置约占 40%
- **中欧基金**：核心仓位与万得偏股型基金指数接近，卫星仓位用于行业和风格调整
- **南方基金**：通过考察权益和长久期债券相对价值做战术配置

## 边界条件

- 卫星仓位的操作依赖基金经理判断，可复制性差
- 战术判断失误（如中欧 2023 年超配新能源）可能给组合带来较大负贡献
- 不一定能持续创造超额收益，投资者需审慎评估基金经理能力
- 若核心仓位选股失误，卫星仓位的超额收益可能不足以弥补核心的亏损

## 与 [[下滑曲线设计类型到点型与穿点型]] 的关系

下滑曲线提供战略配置的"骨架"，核心+卫星策略在此基础上添加战术灵活性。两者共同决定基金最终表现。
