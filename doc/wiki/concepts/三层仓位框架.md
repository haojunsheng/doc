# 三层仓位框架

三层仓位框架是固收+基金的经典资产配置结构，由信用债底仓、股票仓位和可转债仓位三层组成，每层承担不同的风险收益功能。

## 核心定义

```
固收+ = 信用债底仓（60%-100%）+ 股票仓位（10%-20%）+ 可转债仓位（0%-30%）
```

| 层级 | 仓位区间 | 核心目标 | 风险特征 |
|------|---------|---------|---------|
| 信用债底仓 | 60%-100% | 稳定票息收入（压舱石） | 低波动、低违约风险 |
| 股票仓位 | 10%-20%（中枢15%） | 权益风险增厚收益 | 中高波动、受股市影响 |
| 可转债仓位 | 0%-30%（灵活调整） | 捕捉系统性机会 | 中等波动、兼具股债属性 |

## 形式化表达

```
总仓位 = 信用债 + 股票 + 可转债 = 100%

信用债 = f(利差环境)，中枢 ≈ 70%-80%
股票   = f(估值环境)，区间 [10%, 20%]，中枢 ≈ 15%
可转债  = f(估值分位数)，区间 [0%, 30%]，灵活调整
```

## 各层策略逻辑

### 第一层：信用债底仓

- **功能**：提供稳定票息收入，为股票和可转债的波动提供缓冲
- **约束**：以AAA评级为主，确保违约风险极低
- **调整依据**：信用利差变化、利率环境
- **边界条件**：如果信用风险上升（如经济衰退），AAA债券也会受影响

### 第二层：股票仓位

- **功能**：在风险可控前提下增厚收益
- **约束**：10%-20%是"积极债券"分类的边界要求
  - 超过20%：风险超出积极债券定位
  - 低于10%：无法有效增厚收益
- **调整依据**：股市估值、宏观经济判断
- **边界条件**：如果判断失误，在市场大涨时仓位过低会跑输同类

### 第三层：可转债仓位

- **功能**：捕捉系统性机会，兼具债底保护和股性弹性
- **约束**：0%-30%区间内灵活调整
- **调整依据**：估值分位数（详见[[可转债择时-估值分位驱动]]）
- **边界条件**：如果估值判断失误，会跑输同类

## 实证案例：易方达稳健收益

[[entities/易方达稳健收益]] 是三层仓位框架的典范案例：
- 13年年化7.99%，在积极债券基金中排名前3%
- 波动率低于同类平均
- 核心成功因素：稳定的框架 + 严格的风险控制

## 边界条件

1. **风格匹配风险**：如果市场风格持续偏向与基金风格相反的方向，基金会跑输同类
2. **规模膨胀风险**：如果规模快速膨胀，框架的执行难度可能上升
3. **极端市场环境**：股债双杀时，三层框架可能同时承压
