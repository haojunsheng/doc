# 净值恐高症

害怕净值高的基金、偏好净值低的心理偏差——典型散户行为，作者点名批评的对象。

## 表现

- 看到净值 3.0 的基金不敢买，觉得"太贵了"
- 看到净值 1.1 的基金反而觉得"便宜"，更想买
- 混淆"净值高低"与"贵贱"——净值高说明历史表现好，净值低不代表估值低

## 为什么错误

基金的净值高低与"贵贱"无关：
- 净值 3.0 = 每份值 3 元，涨了 200%
- 净值 1.1 = 每份值 1.1 元，涨了 10%
- 买 1000 元两者得到的资产完全相同

真正的"贵贱"取决于持仓资产的估值（PE、PB 等），而非基金净值本身。

## 根源

净值恐高症的本质是**把基金当股票炒**——用"价格"思维理解净值，而非用"资产份额"思维理解。

## 克服方法

回到 [[concepts/目标-品种-操作三步曲]]：先问目标（我要多大比例的股票/债券暴露），再选对应比例的基金，净值数字不参与决策。
