# 系统性风险与非系统性风险（CAPM 框架）

[[威廉-夏普-william-sharpe]] 在 [[哈里-马科维茨-harry-markowitz]] 均值-方差模型基础上的关键区分：**风险分为两类，只有系统性风险需要补偿**。

## 两类风险的定义

| 类型 | 定义 | 能否通过分散化消除 | 是否需要补偿 |
|------|------|------------------|------------|
| 系统性风险 | 影响整个市场的风险（如利率变化、经济衰退） | 否 | 是——承担系统性风险应获得超额收益 |
| 非系统性风险 | 仅影响个别公司/行业的风险（如管理层变动、产品失败） | 是 | 否——分散化可免费消除 |

## 形式化转变

```
马科维茨: 风险 = 波动率（总风险）
夏普:     风险 = 无法通过分散化消除的波动率（系统性风险，用β衡量）
```

## 实践含义

1. 不要为可通过分散化消除的风险支付额外回报
2. 超额收益只能来自承担系统性风险（β）
3. β=1 与市场同步，β>1 更激进，β<1 更保守

## 边界：贝塔不完美

多因子模型（Fama-French 等）发现除市场贝塔外还有规模、价值等因子。CAPM 是基础框架而非终极答案。
