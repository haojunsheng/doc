# 系统性风险与非系统性风险

所有风险的构成：总风险 = 系统性风险 + 非系统性风险。

## 定义

| 类型 | 定义 | 能否通过分散化消除 |
|---|---|---|
| 系统性风险 | 市场整体风险，影响所有资产 | 否 |
| 非系统性风险 | 个股/行业特有风险 | 是 |

## 形式化

```
总风险 = 系统性风险（市场整体） + 非系统性风险（个股/行业）
分散化消除后者 → 保留前者
```

## 实证结论

- 持有 **20 只以上**不同行业股票，非系统性风险降至接近零
- 但系统性风险（市场涨跌）无法通过分散化消除

## 边界：分散化在极端恐慌时失效

2008 年等极端事件中，所有资产相关性趋近于 1，分散化暂时失效。解决方案：加入债券、黄金等**真正低相关**资产。
