# 基准-浮动费率挂钩机制

**基准-浮动费率挂钩机制**指《推动公募基金高质量发展行动方案》将基金业绩比较基准与浮动管理费档位绑定，使基准选择直接决定管理人的收入结构和投资者的实际费率成本。这一机制是驱动2026年57只基金集体基准重构的核心政策杠杆。

浮动费率制度的改革要点：从封闭转向开放、从单一品类扩展到主题基金、从不对称约束转向双向基准约束。但开放运作+系统改造门槛将中小公司排除在外。

参见 [[浮动费率]] 获取完整费率结构说明。

## 三档费率触发条件

```
管理费 = f(持有期业绩相对基准) {
  跑输 ≥ 3%:  0.6%   （低费率档）
  -3% ~ +6%:  1.2%   （普通费率档）
  跑赢 ≥ 6%:  1.5%   （高费率档）
}
```

关键规则：
- 持有 **1年以内** 统一按 1.2% 收取，浮动机制仅对长期投资者生效
- 判断标准是**相对基准**，不是绝对收益——亏钱但跑赢基准也不触发高费率
- 三档设计本质：**惩罚弱者、奖励强者、中间不动**

## 基准选择即成本选择

在挂钩机制下，基准不再是形式条款，而是直接决定管理人收入的核心变量：

1. **打破制度惰性**：过去基金公司缺乏修正错误基准的激励（因为基准失真反而让业绩更好看）。挂钩机制使管理人必须认真选择基准，否则浮动费率档位将不利。
2. **精确匹配需求**：管理人有意愿将基准切换到更贴合策略的细分指数，以建立合理的业绩评价基准，从而在浮动费率结构中获得公正的费率档位判定。
3. **互为因果**：基准重构政策与浮动费率挂钩机制互为因果，基准选择的调整直接影响浮动费率的实际成本效应。

## 负面效应：基准选择投机

同一机制可被逆向利用为降难度工具：

- 将固定年化10%的绝对目标转为股债组合基准——数字上更容易超越
- 选择更易跑赢的基准组合，降低触发高费率档的概率
- 用**价格指数（不含分红）**做基准，系统性降低"跑赢"门槛——详见 [[价格指数vs全收益指数基准]]
- 基准调整可能成为降难度套利的工具——详见 [[降低考核难度]]

具体数据：沪深300十年年化全收益 3.32% vs 价格收益 1.08%，差 2.24 个百分点。以价格指数为基准会使"跑赢"门槛显著降低，导致管理费档位更容易触发高费率档。

## 投资者关注点

1. **基准选择影响成本**：基准若被刻意调低，管理人更容易获得高费率档位，投资者实际支付更多管理费
2. **需验证基准合理性**：不应仅看基准名称变更，应检查新基准是否真正贴合基金策略
3. **关注持有期**：1年以内持有者不受浮动机制影响，与固定费率基金无异
4. **注意价格指数vs全收益指数的差异**：使用价格指数做基准会降低"跑赢"门槛，需核实基金实际采用的基准类型
