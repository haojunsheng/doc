# 基准-浮动费率挂钩机制

**基准-浮动费率挂钩机制**指《推动公募基金高质量发展行动方案》将基金业绩比较基准与浮动管理费档位绑定，使基准选择直接决定管理人的收入结构。这一机制是驱动2026年57只基金集体基准重构的核心政策杠杆。

## 制度设计

浮动费率基金的三档管理费结构与相对基准业绩挂钩：

```
管理费 = f(持有期业绩相对基准) {
  跑输 ≥ 3%:  0.6%   （低费率档）
  -3% ~ +6%:  1.2%   （普通费率档）
  跑赢 ≥ 6%:  1.5%   （高费率档）
}
```

关键规则：
- 持有 **1年以内** 统一按 1.2% 收取，浮动机制仅对长期投资者生效
- 判断标准是**相对基准**，不是绝对收益——亏钱但跑赢基准也不触发高费率
- 三档设计本质：**惩罚弱者、奖励强者、中间不动**

参见 [[浮动费率]] 获取完整费率结构说明。

## 对基准重构的驱动作用

在挂钩机制下，基准不再是形式条款，而是直接决定管理人收入的核心变量：

1. **打破制度惰性**：过去基金公司缺乏修正错误基准的激励（因为基准失真反而让业绩更好看）。挂钩机制使管理人必须认真选择基准，否则浮动费率档位将不利。
2. **精确匹配需求**：管理人有意愿将基准切换到更贴合策略的细分指数，以建立合理的业绩评价基准，从而在浮动费率结构中获得公正的费率档位判定。

## 负面效应：基准选择投机

同一机制可被逆向利用为降难度工具：

- 将固定年化10%的绝对目标转为股债组合基准——数字上更容易超越
- 选择更易跑赢的基准组合，降低触发高费率档的概率

参见 [[降低考核难度]]。

## 投资者关注点

1. **基准选择影响成本**：基准若被刻意调低，管理人更容易获得高费率档位，投资者实际支付更多管理费
2. **需验证基准合理性**：不应仅看基准名称变更，应检查新基准是否真正贴合基金策略
3. **关注持有期**：1年以内持有者不受浮动机制影响，与固定费率基金无异
