# 最大回撤

## 定义

最大回撤（Maximum Drawdown）是投资组合历史上从峰值到谷值的最大跌幅，是衡量投资风险的核心指标之一。它回答了"最坏情况下你会亏多少"这个问题，对投资者的心理承受力有直接意义。

```
最大回撤 = (最高点净值 - 后续最低点净值) / 最高点净值
```

## 核心价值

> — notes/20260614T121410--qa-风险的定义和衡量__qa.md

- 标准差和索提诺比率无法刻画极端情况
- 最大回撤衡量历史上最坏的时候到最差的时候的亏损
- 帮你了解可能需要经历多大的痛苦，做好心理准备

## 局限

> — notes/20260614T121410--qa-风险的定义和衡量__qa.md

- 最大回撤是历史数据，未来可能出现更大的回撤
- 不反映回撤持续时间，两个组合可能有相同最大回撤但恢复时间差异巨大
- 需与其他风险指标结合使用

## 决策意义

> — notes/20240627T090132--qa-全天候策略怎么选__qa.md

最大回撤是选择全天候策略的关键依据。文章指出，如果投资者连10%的回撤都无法承受，任何全天候策略都不适合，应该选择银行存款等无风险资产。

## 实践意义

> — notes/20260614T121410--qa-风险的定义和衡量__qa.md

最大回撤帮助投资者在做资产配置时进行**心理预设**：如果我的组合最大可能下跌 30%，我能否承受？这是量化指标之外的行为风险判断的重要依据。
