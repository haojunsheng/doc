# 外资低配与低配收窄

**外资低配与低配收窄**描述的是全球主动管理基金对中国股票持仓相对于MSCI ACWI基准的系统性偏离轨迹：2021年起大幅低配，2023年9月迎来拐点后低配幅度开始收窄，但截至2024年末仍未转为高配。

## 定义

- **低配（Underweight）**：基金组合对中国股票的配置比例低于MSCI ACWI基准权重的状态
- **低配收窄**：低配幅度（负偏离）逐步缩小的趋势性变化
- **拐点**：低配程度从扩大转为收窄的时间节点

## 轨迹形式化

```
阶段一：低配扩大期（2021 → 2023年9月）
  中国资产表现持续疲软 → 主动基金系统性减持 → 低配幅度扩大

阶段二：低配收窄期（2023年9月 → 2024年末）
  中国政策刺激预期升温 → 主动基金减仓速度放缓 → 低配幅度逐步收窄

状态：仍未转高配
  低配收窄 ≠ 高配，仅是"没那么不看好"的边际改善
```

## 量化数据

| 指标 | 数值 |
|------|------|
| 中国主题基金规模高点（约2021年） | 2532亿美元 |
| 2024年末规模 | 1765亿美元 |
| 两年净流出 | -164亿美元（≈-30%） |
| 拐点时间 | 2023年9月 |
| 驱动低配的主导类型 | 主动管理基金 |

> **注意**：主动基金低配的具体百分比未披露，仅能确认"持续低配"的方向性趋势。

## 与被动基金行为的对比

| 维度 | 主动基金 | 被动基金 |
|------|---------|---------|
| 低配幅度变化 | 2023.9起收窄 | 不受低配框架约束 |
| 2024年Q4行为 | 态度边际改善 | 先抄底（10月）后高位减持（11月） |
| 行为模式 | 倾向趋势判断 | 追涨杀跌，与散户趋同 |

被动基金的Q4行为模式表明，外资并非整体上的"长期价值投资者"，其在短期价格波动面前同样会追涨杀跌。

## 与[[风格轮动与业绩反转]]的关联

外资低配收窄与主动基金风格的均值回归逻辑相关——当某一资产被系统性低配后，估值压缩至极端水平，往往触发持仓再平衡。但需警惕的是，低配收窄的幅度是"边际改善"而非"实质性转向"，不足以作为重仓信号。

## 边界条件

- 低配收窄不等于高配，仅是负面预期的边际缓和
- 拐点（2023年9月）为描述性判断，具体量化阈值未披露
- 数据仅覆盖晨星统计的主动基金与主题基金渠道，主权财富基金、养老基金及直投未包含
- 2025年后的流向需持续跟踪晨星月度资金流数据验证趋势延续性
