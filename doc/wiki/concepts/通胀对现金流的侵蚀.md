# 通胀对现金流的侵蚀

**通胀对现金流的侵蚀**是指：在现金流思维框架下，固定支出随通货膨胀上涨，导致"可自由支配比例"被动压缩，财务自由条件需要动态调整的现象。

## 核心机制

现金流思维的核心公式：
```
可自由支配比例 = (现金流入 - 固定支出) / 现金流入

财务自由条件：被动现金流 ≥ 固定支出 + 期望自由支出
```

当通胀发生时：
- **固定支出膨胀**：租金、保险费、物业费等合同性支出随通胀上调
- **现金流入可能滞后**：工资、股息的调整速度慢于通胀，存在"时滞效应"
- **结果**：可自由支配比例被被动压缩，即使名义金额不变，实际自由度也在下降

## 失效场景

这是现金流思维的主要失效场景之一。现金流公式在静态条件下成立，但在通胀环境下需要动态调整：

1. **租金上调**：租房者的固定支出直接随 CPI 上涨
2. **保险费递增**：健康险、车险保费随年龄和通胀双重上涨
3. **税制因素**：部分税种（如房产税）可能与通胀或资产评估挂钩

## 应对策略

- 将通胀预期纳入现金流规划：公式中的固定支出应使用"通胀调整后"的估算值
- 配置具有抗通胀属性的资产：TIPS、房地产、大宗商品相关资产
- 关注现金流入的通胀弹性：选择股息增长型股票而非固定股息率债券
- 动态调整财务自由门槛：公式右侧的"期望自由支出"也应按通胀预期上调
