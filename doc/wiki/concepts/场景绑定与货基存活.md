# 场景绑定与货基存活

货币基金在低利率环境下，通过深度绑定用户交易账户/支付生态来获得持续性资金流入的机制。

## 核心命题

**谁离用户的交易账户越近，谁就能在低利率环境下守住阵地。**

## 定义

场景绑定指：货基与用户的日常交易场景（支付、证券账户、薪资发放）形成系统性连接，使资金在流入时自动沉淀于该货基，从而在收益率不具备竞争力时仍能维持规模。

## 机制拆解

### 日本MRF案例

```
传统MMF：理财收益驱动 → 负利率下收益为负 → 清盘
MRF：账户绑定驱动 → 证券交易账户自动归集闲置资金 → 豁免负利率 → 存续
```

- 2016年日本全面负利率后，传统MMF全线亏损，2017年基本清盘
- MRF（Money Market Mutual Funds - 豁免版）绑定证券交易账户，自动归集闲置资金
- MRF享有存款负利率豁免，在负利率环境中保持正收益

**关键变量**：MRF离证券交易账户的距离 = 资金自动归集的效率 = 存活概率

### 中国余额宝案例

```
支付宝支付生态绑定 → 消费/转账场景触发自动申购 → 资金沉淀 → 规模逆势增长
```

- 余额宝7日年化跌破1%，但规模逆势攀升至15.58万亿
- 核心原因：与支付宝支付生态深度绑定，消费结算时自动归集零钱
- "支取灵活"+"相对活期5倍优势"+"场景自动沉淀"三重叠加

## 场景类型与粘性层级

| 场景类型 | 绑定深度 | 资金留存率 | 典型代表 |
|---------|---------|-----------|---------|
| 支付结算 | 极高 | 高 | 余额宝/支付宝 |
| 证券交易 | 高 | 高 | 日本MRF |
| 薪资代发 | 中高 | 中高 | 工资卡关联货基 |
| 独立理财APP | 低 | 低 | 纯收益驱动的货基销售 |
| 银行柜台 | 中 | 中 | 银行自有货基 |

## 边界条件

- 若监管取消场景绑定的监管豁免（如日本MRF的负利率豁免），绑定逻辑失效
- 若支付/证券账户体系被颠覆（如央行数字货币全面铺开替代现有账户体系），现有绑定关系可能被重估
- 若出现更强的替代性现金管理工具，场景绑定深度可能被重新定义
