# 错杀-修复框架

关税等宏观冲击引发市场恐慌性抛售时，部分基本面未实质性受损的板块被"错杀"，随后存在估值修复机会。该框架帮助区分"真正恶化"和"被误杀"的资产。

## 核心逻辑

```
宏观冲击 → 恐慌抛售 → 低估（错杀） → 若基本面未恶化 → 修复机会
                                     ↘ 若基本面确实恶化 → 价值陷阱
```

## 当前案例：被错杀的三大板块

| 板块 | 错杀原因 | 修复条件 |
|------|---------|---------|
| 医疗保健 | 关税担忧引发抛售 | 关税影响未实质波及医疗需求 |
| 能源 | 关税不确定性 | 原油供需基本面未恶化 |
| 房地产 | 利率+关税双杀 | 租金收入端未受冲击 |

**对比**：公用事业、金融、工业反而估值偏高，不具同等修复赔率。

## 与净值便宜误区的关系

[[净值便宜误区]]提醒：便宜不等于值得买。错杀-修复框架在此基础上增加一步——**判断"便宜"是否由基本面恶化驱动**。若是情绪/恐慌导致（错杀），则有修复赔率；若是基本面实质恶化，则是价值陷阱。

## 边界条件

- 低估可能持续很久，"抄底"需要耐心和承受进一步下跌的能力
- 修复的前提是基本面未实质性受损，需独立验证
- 关税冲击方向不确定，部分板块可能从"错杀"转为"真恶化"
