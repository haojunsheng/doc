# 资产配置

资产配置（Asset Allocation）是将资金在不同资产类别（股票、债券、现金等）之间分配，并根据市场变化定期调整（再平衡）的过程。它是投资回报的最大决定因素，也是普通投资者最可控的变量。

## 定义与常见误解

**通行定义**：将投资资金在不同资产类别之间进行分配，并根据市场变化定期调整。

**常见误解**：
- 资产配置 = 选股（实际选股是第三步）
- 资产配置 = 一次性决定（实际需要定期再平衡）
- 资产配置只适合机构（实际上普通投资者更需要）

**核心词素**："资"=资金，"产"=资产，"配"=分配，"置"=放置。合成义：把资金分配到不同资产类别中。

## 四步框架

资产配置包含四个递进步骤，缺一不可：

```
第1层：理财目标和计划
  → 回答"我为什么要投资"
  ↓
第2层：大类资产配置
  → 确定股票、债券、现金的比例
  ↓
第3层：挑选优质基金
  → 选择能持续创造超额的基金产品
  ↓
第4层：长期持有 + 成本控制
  → 持多久？费用多少？
```

**关键认知**：没有前三步，第四步是空中楼阁。

## 核心命题

### 资产配置决定回报（历史证据）

晨星研究显示，2016-2022 年间：
- 100% 股票组合最坏一年亏损超 20%
- 50%/50% 股债组合最坏一年亏损约 11.48%
- 长期来看，**90% 以上回报差异来自资产配置**，而非选股或择时（归因引自 Brinson 经典研究）

### 让波动处于心理承受范围内（辩证命题）

资产配置的核心**不是最大化收益，而是让波动处于你的心理承受范围内**。能让你在熊市中安稳睡觉的组合，才是好的组合。分散化牺牲极端收益，避免极端亏损。

### 配置是起点，再平衡是过程（语言辨析）

「配置」一词带有工程学的精确感，但资产配置不是静态的。更准确的表述是「资产动态管理」或「组合风险管理」。配置是起点，再平衡是过程。

### 认识你自己（存在论命题）

投资的本质不是"找到最好的资产"，而是"找到最适合你的组合"。每个人的风险偏好、收入水平、投资期限都不同，最优配置也不同。资产配置是"认识你自己"在财务领域的实践——知道自己能承受多少波动，比知道哪个基金会涨更重要。

## 压缩表达

```
资产配置 = 目标设定 × 股债比例 × 再平衡 × 长期持有
```

**一句话**：资产配置不是找最好的资产，是找最适合你的组合。
