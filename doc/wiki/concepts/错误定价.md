# 错误定价

市场并非完全有效，资产价格可能偏离其内在价值，形成可以被研究与洞察力挖掘的定价偏差。这是主动管理的理论基石。

## 核心观点

- **市场非完全有效**：信息不对称、行为偏差、流动性约束等因素导致价格偏离价值
- **主动管理的价值来源**：通过深度研究识别并利用错误定价，获取超额收益（α）
- **指数基金的局限**：被动跟踪只能获得市场平均回报（β），无法利用错误定价

## 形式化表达

```
主动管理 = 深度研究 × 择时能力 → α（超额收益）
指数基金 = β（市场收益）
```

## 与有效市场假说的关系

错误定价的存在直接挑战强式有效市场假说。行为金融学为错误定价提供了更丰富的解释框架（过度自信、锚定效应、羊群效应等）。

## 实践中的边界

- 基金经理能力不足时，无法有效识别或利用错误定价
- 市场效率持续提升（如量化投资普及）压缩错误定价空间
- 错误定价的发现和利用之间存在时间差，需要耐心持有

[[xingquan-herun-mixed]] 的主动管理价值正建立在错误定价理论之上——基金经理通过自下而上的深度研究，寻找被低估的优质企业。
