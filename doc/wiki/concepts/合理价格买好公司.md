# 以合理价格买好公司

## 定义

一种选股框架：在确认公司基本面优秀的前提下，以足够低的价格买入，确保预期收益率达到可接受的下限（通常 ≥ 10%）。该框架将"好公司"和"好价格"两个维度结合，避免陷入纯价值陷阱（便宜但质量差）或纯成长溢价（质量好但价格过高）。

## 形式化框架

```
好公司 = ROA/自由现金流初筛
        + 商业模式差异化（能提供差异化产品/服务）
        + 经营能力强
        + 发展空间大
        + 安全边际高

预期收益率 = 成长性贡献 + 分红收益率
预期收益率 ≥ 10% → 买入
```

## 五个筛选维度

### 1. 财务初筛（ROA、自由现金流）

快速排除基本面差的公司，缩小研究范围。ROA 衡量资产盈利能力，自由现金流衡量企业真实赚钱能力。

**局限：** 新兴行业（如早期互联网）财务指标可能失真或不适用。

### 2. 商业模式差异化

企业能否提供不一样的产品和服务，满足客户差异化需求，从而形成护城河。

### 3. 经营能力

管理层是否具备持续运营和扩张的能力。

### 4. 发展空间

行业天花板和企业市场份额提升空间。

### 5. 安全边际

从资本周期和估值角度衡量：行业惨淡、盈利能力处于低位、估值便宜时买入，为判断错误留出缓冲。

与 [[安全边际]] 的关系：此处的安全边际更接近邓肯/格林布拉特式价值思路——强调"行业景气底部+估值便宜"的组合，而非单纯的低市盈率。

## 与相关概念的区别

| 概念 | 核心差异 |
|------|---------|
| [[安全边际]] | 安全边际侧重"买入价低于内在价值"的保护垫；本框架进一步要求公司是"好公司"，避免价值陷阱 |
| [[自下而上选股]] | 自下而上选股是方法论取向（从个股出发而非从行业出发）；"以合理价格买好公司"是自下而上框架下的具体选股标准 |
| 纯价值投资 | 纯价值侧重低估值；本框架同时要求商业模式优秀和发展空间 |

## 实证案例：刘旭与大成高鑫

[[刘旭]] 将这一框架应用于 [[大成高鑫股票]] 的管理，自 2015 年 7 月起年化回报 17.26%（前 1%），且在成长股和价值股投资上均获超额收益，证明该框架的有效性不依赖单一风格顺风。

## 边界条件

1. 新兴行业财务指标可能不适用，需要替代评估方法
2. 市场持续高估时严格执行安全边际会错过机会
3. 预期收益率 ≥ 10% 的门槛在不同市场环境下的适用性需动态评估
