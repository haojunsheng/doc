# 完整市场周期检验

评估一位新基金经理的真实能力，至少需要经历一个完整的牛熊周期（3-5年）。

## 定义

**完整市场周期检验**是指对基金经理的能力评估必须跨越至少一个完整的牛市和熊市周期（通常3-5年），才能判断其真实投资水平——短期业绩受运气和市场风格影响过大，不足以作为判断依据。

## 晨星的明确判断

晨星在分析[[entities/彭珂]]接任[[entities/易方达行业领先混合]]时明确指出："需要经过完整市场周期考验"。

理由：
- 一年以内的业绩波动很大
- 牛熊环境中基金经理的风控能力和风格一致性才能得到验证
- 短期排名不能说明问题

## 评估维度

完整市场周期检验应包含以下维度：

| 维度 | 说明 |
|------|------|
| 业绩 | 跨牛熊周期的绝对收益和相对收益 |
| 风控 | 极端市场中的回撤控制能力 |
| 风格一致性 | 是否坚持原风格，还是随市场漂移 |
| 下行保护 | 熊市中的防御能力 |

## 与短期业绩的关系

短期业绩（1年以内）可以作为参考，但不能作为决策依据。极端市场中表现优异（如大跌中回撤控制出色）可以提前加分，但不足以完全替代完整周期的验证。

## 形式化表达

```
评估新经理 = 完整周期(3-5年) + 多维度(业绩/风控/风格一致性) → 长期判断
```

## 边界条件

- 如果新经理有极强研究员背景且投资框架成熟，短期落后不说明问题
- 如果新经理在极端市场中展现出优秀风控能力，可提前加分
- 若新经理频繁大幅调仓偏离原策略，应重新评估
