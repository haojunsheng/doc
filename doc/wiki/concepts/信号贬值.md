# 信号贬值

## 定义

信号贬值（Signal Dilution / Signal Erosion）指某个原本具有区分度的信息信号，因被广泛使用或强制执行而导致其区分能力逐步衰减，最终趋近于零的过程。

---

## 核心机制

```
信号有效（稀缺） → 被广泛认知/采用 → 覆盖率提升 → 区分度下降 → 信号失效
```

信号的有效性依赖于其**稀缺性**。当所有人都拥有同一信号时，该信号不再能提供额外信息。

---

## 典型案例：基金经理自购

晨星中国2024年研究揭示了信号贬值的典型场景：

**现状**：
- 54%基金经理零自购，7%持有100万份以上
- 自购是正面信号：有自购的基金在大盘成长/中小盘/普通债券三类胜率≥60%
- 但大盘平衡型自购胜率<50%，说明自购并非万能

**贬值逻辑链**：

```
监管要求≥30%绩效薪酬自购 → 强制自购普及 → 全员自购趋势
    → 自购不再是区分因素 → 信号区分度归零
```

**晨星类比**：

> 就像"所有厨师都必须吃自己做的菜"——当全员自购成为常态，自购就从"信心的证明"变成了"合规的要求"。

**当前窗口**：54%仍零自购，信号仍有区分度；但随政策推进，窗口在收窄。

**未来情景**：
- 披露从区间升级为精确金额 → 大额 vs 小额自购仍可判断"诚意"，信号部分保留
- 全员强制自购 → 信号完全失效

---

## 与其他信号的对比

| 信号 | 当前状态 | 贬值风险 |
|------|---------|---------|
| 基金经理自购 | 54%零自购，窗口仍在 | 高（政策驱动） |
| 机构减持宽基ETF | 两周暴跌44%-50% | 中等（取决于解读一致性） |
| 基金限购 | 限购本身是信号 | 低（限购原因各异） |
| 爆款基金发行 | 逆周期信号 | 高（大众广泛使用） |

---

## 投资决策启示

1. **信号窗口期**：当前仍可用自购率做辅助筛选，但应意识到窗口在收窄
2. **多维度验证**：单一信号不应作为决策依据，需结合投研团队、费率、投资流程等
3. **逆向思维**：当信号开始贬值时，正是需要更新框架的时候
4. **披露粒度**：精确披露（金额）比区间披露更能保留信号区分度
