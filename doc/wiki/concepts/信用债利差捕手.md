# 信用债利差捕手

## 定义

通过判断信用债利差是否被市场错误定价，在低估时买入、高估时卖出，从而获取超额收益的主动管理策略。

## 形式化表达

```
信用债利差 = 信用债收益率 - 同期限国债收益率

利差捕手 = 利差被低估时买入 + 利差被高估时卖出 → 捕捉定价偏差
```

## 策略前提

市场对信用风险的定价并不总是准确的：
- **利差过大**（市场过度恐慌）→ 买入机会
- **利差过小**（市场过度乐观）→ 卖出机会
- **核心能力**：通过企业基本面分析、行业前景判断、历史利差比较识别定价偏差

## 利差变化驱动因素

```
利差变化 = f(宏观经济, 企业盈利, 流动性, 监管政策)
```

| 因素 | 对利差的影响 |
|------|------------|
| 宏观经济向好 | 企业违约风险↓ → 利差收窄 |
| 企业盈利改善 | 信用风险↓ → 利差收窄 |
| 市场流动性紧张 | 利差扩大（不一定代表信用风险增加） |
| 监管政策变化 | 结构性影响，需具体判断 |

**识别要点**：流动性驱动的利差扩大与信用风险驱动的利差扩大需要区分，但本文未提供明确识别方法，这是一个潜在的逻辑缺口。

## 典型案例：东方添益债券基金

[[entities/东方添益债券基金]]（吴萍萍管理）是利差捕手策略的典型实证：

- 近两年动态降低城投债配置比例、提升产业债配置比例
- 判断依据：城投债利差已压缩至历史低位，性价比不高；产业债相对价值凸显
- 这与 [[concepts/城投债-产业债配置权衡]] 框架完全一致

## 风险评估框架

投资者可从四个维度评估信用债基金风险：

```
风险评估 = 信用评级分布 + 行业集中度 + 久期 + 历史最大回撤
```

| 维度 | 考察重点 |
|------|---------|
| 信用评级分布 | 低评级占比越高，违约风险越大 |
| 行业集中度 | 集中度越高，行业风险暴露越大 |
| 久期 | 久期越长，利率风险越大 |
| 历史最大回撤 | 反映基金的风险控制能力 |

## 策略适用边界

- **最佳环境**：经济复苏期，信用风险下降，利差收窄带来资本利得
- **不利环境**：经济衰退期，信用风险上升，利差扩大导致策略可能失效
- **适合投资者**：风险承受能力中等，追求稳健收益
- **不适合投资者**：风险承受能力低（更适合纯债基金）

## 关键洞见

利差捕手策略的本质是对信用风险的主动定价能力博弈——不是"持有债券收利息"的静态逻辑，而是"判断市场是否把信用风险定价错了"的动态定价博弈。
