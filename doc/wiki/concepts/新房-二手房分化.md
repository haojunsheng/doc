# 新房-二手房分化

## 定义

同一城市中，新建商品房与存量二手房价格走势出现结构性背离的现象。其根因不在于需求侧，而在于**供给端的可控性差异**——新房供给可被开发商决策和政府土地出让节奏主动调控，二手房供给由无数业主个体分散决策，政策工具难以统一干预。

## 核心机制

```
新房：供给可控（开发商减少开工 + 政府收缩土地出让）
  → 库存增速趋零 → 供需再平衡 → 价格先企稳

二手房：供给不可控（业主挂牌决策分散）
  → 挂牌量持续增加 → 过剩需数年消化 → 价格滞后企稳
```

## 关键事实（2026年数据）

- 新开工面积同比降22%，土地购置面积同比降49%
- 全国住宅库存预计净下降2%
- 一线城市二手房跌幅甚至大于二三线（核心地段新房替代效应更强）
- 房价收入比9.3→8.5为被动改善，非真实购买力提升
- 租金回报率2.26%，仍低于无风险利率

## 城市分化规律

高线城市（上海、杭州）需求强、去化快，率先出清；北方城市库存压力重，企稳滞后。若人口与产业持续流出北方城市，分化可能加剧而非收敛。

## 与投资相关的延伸含义

- 开发商股价重估逻辑建立在"供给收缩→价格企稳→利润修复"的预期链上，2027年是关键验证窗口
- 专项债收购存量房转为保障房的政策范围扩大，可能改变二手房供给曲线
- 此分化框架可类比到其他"供给可控 vs 供给分散"的市场结构分析中

## 边界条件

- 若改善型需求大幅回暖或业主集体惜售，二手房去化可能加快
- 若开发商债务危机蔓延，供给收缩预期可能被证伪
- 若专项债收购范围扩大至二手房，供给不可控性将减弱
