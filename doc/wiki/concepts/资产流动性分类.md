# 资产流动性分类

**核心论点**：只看总资产不看流动性，会高估抗风险能力。中国家庭房产占比常超 70%，房价下跌时净资产瞬间缩水。

## 分类框架

```
总资产
├── 流动资产（可随时变现应对突发事件）
│   ├── 现金
│   ├── 银行存款
│   ├── 股票
│   └── 基金
└── 非流动资产（价值高但变现周期长、成本高）
    ├── 房产
    ├── 汽车
    └── 收藏品
```

## 关键洞察

流动性决定「你能不能马上用这笔钱」——非流动资产是财富，但不是现金。

> 「我有 200 万资产」但其中 190 万是房子，手里只有 10 万现金，遇到急事一样抓瞎。

## 流动性修正因素

某些非流动资产具有隐藏流动性：

| 非流动资产 | 表面流动性 | 修正后流动性 | 条件 |
|-----------|-----------|-------------|------|
| 核心城市优质房产 | 低 | 中高 | 可通过抵押贷款快速变现 |
| 偏远地区房产 | 低 | 低 | 无人接盘，折价出售 |
| 汽车 | 低 | 低 | 折旧快，变现即损失 |
| 收藏品 | 极低 | 极低 | 鉴定难、买家少 |

## 资产集中度风险

```
资产集中度 = 某类资产 / 总资产
集中度 > 60–70% → 风险偏高
```

中国家庭常见风险：房产占比超过 70%，房价一跌，纸面财富瞬间蒸发。

分散配置的核心逻辑是「不要把所有鸡蛋放一个篮子」——这里「篮子」不是指多只股票，而是指大类资产（房产、股票、现金、债券）。

## 边界条件

- 如果集中的是国债、存款等低风险资产，集中度高不等于危险
- 如果集中的是单一股票或加密货币，哪怕占比 30% 也危险
- 核心城市优质房产可通过抵押提升实际流动性
