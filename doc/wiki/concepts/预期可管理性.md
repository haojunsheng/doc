# 预期可管理性（Expectation Manageability）

风格稳定的价值不在于收益最大化，而在于让投资者能够管理自己的预期。

## 核心定义

**预期可管理性**：投资者根据基金宣称的风格做出配置决策，只有当基金的风格保持稳定，投资者的预期才能与实际持仓对齐，从而做出知情决策。风格漂移破坏了这种可管理性，使投资者陷入不确定性裸奔。

```
预期可管理性 = 基金风格稳定性 × 投资者知情程度
```

## 核心论点

风格稳定 vs 风格正确是本次分析的核心辩证维度：

- **风格正确**：基金经理在某一时点做出了"正确的"风格判断
- **风格稳定**：基金经理坚守宣称的投资风格，不随市场热点摇摆

合题：**风格稳定的价值不在于"永远正确"，而在于"让投资者知道自己买的是什么"**。即使风格切换错误率很高，风格稳定仍然优于风格漂移——因为前者让投资者能做出知情决策。

## 与风格漂移的关系

[[风格漂移]]直接破坏预期可管理性：
- 投资者基于"价值型"标签配置组合
- 基金实际漂移到"成长型"
- 投资者的组合风险敞口与预期严重偏离
- 预期可管理性归零

## 扩展应用

预期可管理性不仅适用于基金选择，也可推广到：

1. **资产配置层面**：各基金风格稳定，组合层面的风险预算才有意义
2. **再平衡决策**：风格漂移会导致再平衡失效，因为实际仓位已偏离目标
3. **业绩归因**：风格不稳定时，业绩好坏难以归因于能力还是运气

## 边界条件

- 风格稳定≠永远不调整：有框架地调整（基于投资逻辑的演进）与无原则地追热点是本质区别
- 部分基金经理（如彼得·林奇）确实具备跨风格获取超额收益的能力，但这属于特例而非规范
- 指数基金的"被动漂移"（成分股调整导致的风格微变）性质不同于主动漂移，需区分对待
