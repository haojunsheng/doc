# 自由现金流ETF

自由现金流ETF是以自由现金流（经营现金流 − 资本开支）为核心筛选标准构建的指数型ETF产品，2025年成为中国ETF市场新增热门品类，被视为低利率环境下"质量因子"投资的代表性品种。

## 定义与核心逻辑

自由现金流 = 经营现金流 − 资本开支。该指标比账面利润更难操纵，更能反映企业的真实盈利质量和分红能力。

```
自由现金流选股逻辑:
  筛选自由现金流稳定且充裕的公司 → 剔除账面利润造假的高股息陷阱
  ↓
国证自由现金流指数刻意排除金融/地产等高负债行业 → 强化质量因子暴露
  ↓
ETF产品化 → 成为低风险偏好的机构资金（险资、养老金）配置工具
```

## 与红利策略的本质区别

| 维度 | 传统红利策略 | 自由现金流策略 |
|------|------------|--------------|
| 筛选锚点 | 当前股息率高低 | 自由现金流质量 |
| 行业覆盖 | 不限（含金融/地产） | 刻意排除金融/地产等高分红陷阱行业 |
| 财务操纵风险 | 高（账面利润可操纵） | 低（现金流更难伪造） |
| 高股息陷阱风险 | 高（股价下跌→被动抬高股息率） | 低（以真实现金流为筛选标准） |

参见 [[高股息陷阱风险]]、[[高股息三种形态]]。

## 规模暴增的三重驱动

```
低利率环境: 10年期国债收益率 < 2%，与4%股息率形成约2%利差
       ↓
险资配置痛点: 传统保险/养老产品收益率下滑，需要类固收替代品
       ↓
政策暖风: 新"国九条"强调分红与市值管理，提升自由现金流策略的政策契合度
       ↓
结果: 规模四个月从数亿级飙升至数十亿级
```

参见 [[资产荒]]。

## "压舱石"定位框架

自由现金流ETF的核心配置角色是"压舱石"而非"冲锋舟"：

- **震荡市**：靠充沛现金流维持经营韧性和分红持续性，守住底线
- **复苏期**：持仓企业盈利增长带来弹性收益
- **不适合**：短期博弈（持有周期过短时，交易成本侵蚀收益，低波动优势无法体现）

## 规模膨胀的隐性风险

规模从6.94亿暴增至37亿（另一口径达86亿），引发流动性管理挑战：

- 极端行情下大额申赎可能放大净值波动
- "规模红利"可能演变为"管理负担"
- 需要动态优化成分股筛选与流动性匹配机制

参见 [[规模诅咒]]。

## 边界条件

- 若国债收益率大幅上行，4%股息率的相对吸引力快速消退
- 宏观经济持续低迷时，企业整体现金流承压，历史业绩未必可持续
- 费率战跌破成本线可能引发部分产品清盘
- 自由现金流因子的有效性随时间变化（参见 [[主动管理失效周期]]）
