# 内需增长

内需增长是中国宏观经济从出口/投资驱动向消费驱动转型的长期结构性主题，是权益市场重要的投资主线之一。

## 核心命题

中国经济增长模式正在经历结构性转型：

```
经济增长转型 = 出口/投资驱动 → 消费驱动
```

在这个转型过程中，内需增长是长期结构性趋势，而非短期波动现象。

## 定义边界

```
内需增长 = 消费 + 医药 + 服务 + 受益内需扩张的制造业
```

| 组成部分 | 驱动逻辑 |
|---------|---------|
| 消费 | 内需核心，受益消费升级 |
| 医药 | 与人口老龄化相关，需求刚性 |
| 服务 | 受益于消费升级及收入增长 |
| 内需制造 | 受益于国产替代及内需扩张 |

## 与外需驱动的对比

| 维度 | 内需增长 | 外需驱动 |
|------|---------|---------|
| 核心动力 | 居民消费 | 出口/投资 |
| 周期属性 | 长期结构性趋势 | 受全球周期影响大 |
| 风险特征 | 消费降级、政策变化 | 汇率波动、贸易摩擦 |
| 代表性主题 | 消费、医药、服务 | 制造业出口、航运 |

## 投资意义

- 内需增长主题的基金适合看好中国消费升级、能够承受市场波动、有长期投资规划的投资者
- 该主题的长期结构性逻辑在短期市场走弱时可能承压，但不改变长期趋势
- 选基时应关注基金经理的策略稳定性、长期业绩及费用水平

## 边界条件

1. **政策依赖**：如果经济政策重新偏向投资、出口，内需增长主题可能降温
2. **定义过宽风险**：若内需定义过于宽泛，基金定位可能不清晰
3. **行业颠覆**：如果行业发生颠覆性变化，基于历史基本面的分析可能失效
