# 六步记账法

**定义**：从收入出发，逐层剥离到结余，最后反推债务健康度的操作性记账框架，是财务诊断链的第二层（记账层）的实现方法。

## 六步流程

```
① 记收入 → ② 记固定支出 → ③ 记可自由支配开支 → ④ 算每月结余 → ⑤ 分析记账表 → ⑥ 评估借贷水平
```

| 步骤 | 内容 | 目的 |
|------|------|------|
| ① 记收入 | 工资、兼职、投资分红、现金流 | 确定起点：你有多少钱可以分配 |
| ② 记固定支出 | 房租/房贷、保险、水电、通勤 | 扣掉刚性支出，计算弹性空间 |
| ③ 记可自由支配开支 | 餐饮、娱乐、购物、社交 | 找到"漏点"，是砍支出的主战场 |
| ④ 算每月结余 | 收入 − 固定支出 − 可自由支配 | 判断是否有储蓄能力 |
| ⑤ 分析记账表 | 识别异常支出、趋势、可优化项 | 从数据到洞察 |
| ⑥ 评估借贷水平 | 对照 28%/36% 红线 | 判断债务健康度 |

## 与财务诊断链的关系

六步法是 [[财务诊断链]] 的操作化实现，将抽象的"记账"拆解为可执行的步骤序列：

```
财务诊断链
  ├─ 第 1 层：净资产（时点快照）← 六步法之前
  ├─ 第 2 层：记账（过程流水）   ← 六步法在此
  │     ├─ ①-③：数据采集
  │     ├─ ④：初步诊断
  │     └─ ⑤-⑥：深度分析
  └─ 第 3 层：三条红线（健康度刻度）← ⑥ 步的输出
```

## 边界条件

- 收入来源复杂（多份兼职、现金收入）会使第 ① 步失真，全链路受影响。
- 记账不分析不调整 = 自我感动（见 [[记账是诊断仪而非治疗仪]]）。

## 与相关方法的区分

- **[[三钱包分配法]]** — 三钱包是预算分配（治疗），六步法是记账诊断（诊断），两者是先后关系而非替代关系。
- **[[理财计划设立目标]]** — 设目标（步骤 1）→ 净资产（步骤 0）→ 六步记账（步骤 2），是同一流程的不同阶段。
