# 质量因子暴露

指投资组合对"质量因子"（Quality Factor）的系统性倾斜。质量因子通常以盈利能力、财务稳健性、现金流质量等指标衡量公司质量。

## 核心定义

自由现金流指数本质上是一种**质量因子暴露**策略：

```
自由现金流指数 ≈ 质量因子暴露↑ + 大市值泡沫风险↓
```

## 与市值加权的对比

传统市值加权指数的问题是"大不等于好"——大市值公司可能因市场情绪被高估，但基本面质量未必优秀。质量因子暴露通过基本面筛选，剥离规模因素，直接捕获高质量公司的超额收益。

## 边界条件

- 质量因子并非永远有效，存在因子周期
- 质量因子在熊市或市场恐慌期可能表现优异（防御性），但在风险偏好急剧上升的市场可能跑输成长因子
- 费率成本可能侵蚀超额收益
