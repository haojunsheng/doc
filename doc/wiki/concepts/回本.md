# 回本

投资账户从亏损状态恢复到初始本金水平的过程，是投资者心理上的一个重要"锚点"。回本不是终点，而是最佳的"组合体检"时机。

## 核心命题

**回本不是回到原点，而是带着三年经验站在新的起点。** 亏损经历本身具有认知价值——它揭示了你的真实风险承受能力，而不仅仅是数字上的得失。

## 常见误解

| 误解 | 澄清 |
|------|------|
| 回本 = 可以走了 | 忽视了组合是否合理 |
| 回本 = 投资成功 | 只是回到了起点 |
| 亏了三年才回本 = 白忙 | 这三年是宝贵的投资经验 |

## 组合体检框架（形式刀）

回本后的四步决策流程：

1. **风险承受能力重评**：过去几年的熊市体验让你认识到自己真正能承受多少波动
2. **资产配置检查**：股票仓位是否过高？是否用了"闲钱"投资？
3. **持仓质量评估**：业绩来源是能力还是运气？经理是否变更？策略是否稳定？
4. **去留决策**：不懂的、波动大的、需要精力维护的（如行业基金）可以清仓；宽基指数、优质主动基金可以继续持有

## 回本后的正确 vs 错误行为

| 错误行为 | 正确行为 |
|---------|---------|
| 立即赎回所有基金（怕再跌） | 盘点资产配置是否合理 |
| 追加投入"抄底"（怕踏空） | 评估持仓质量 |
| 频繁查看账户（焦虑驱动） | 调整仓位到安心水平 |
| | 不懂的就清仓 |

## 深度解读

### 辩证刀：解套焦虑 vs 财务规划

回本后的决策分化为两条路径：
- **解套焦虑**（情绪驱动）："终于不亏了，赶紧跑"
- **财务规划**（理性驱动）："我的组合是否合理？风险是否匹配？"

**回本的价值不在于"不亏了"，而在于提供了一个不带情绪审视组合的最佳时机**——因为人在亏损时容易恐慌，在盈利时容易贪婪，只有在"不亏不盈"时最理性。

### 存在刀：回本是自我认知的催化剂

回本揭示了投资的本质不是"赚钱"，而是"认识自己"。三年的亏损让你知道自己的真实风险承受能力——之前说"我能承受30%亏损"，但在真实亏损中你发现10%就让你夜不能寐。

### 元反思刀：问题的提出本身就是答案

"回本之后怎么办"这个问题本身就暴露了大多数投资者"把回本当终点"的思维模式。如果你只是在等"回本"然后卖出，说明你的投资从一开始就没有计划。

### 美感刀：凤凰涅槃

回本的美感是"凤凰涅槃"——不是简单地回到原点，而是经历了火焰（熊市）洗礼后的重生。你不是回到了原点，你是一个经历了完整牛熊周期的投资者。

## 与已有概念的关联

### 与 [[回本心理]] 的区分

- **[[回本心理]]** 聚焦"回本就跑"的行为偏差——将回本错误地当作退出信号
- **本文** 提供回本后的正向决策框架——将回本重构为财务规划重启的契机

两者互补：前者描述偏差，后者提供纠偏框架。回本心理是"回本→冲动卖出"的负面描述，本文是"回本→组合体检"的正面指引。

### 与 [[买入逻辑检验]] 的关系

[[买入逻辑检验]] 揭示了一个更深层的事实：很多人持有亏损基金不是因为买入逻辑还在，而是因为不愿意承认自己当初的逻辑从来就没存在过。回本后的组合体检，本质上就是对买入逻辑的二次检验——只不过这次是在"不亏不盈"的最理性时刻进行。

### 与 [[个性化风险]] 的关系

[[个性化风险]] 强调风险不是数字而是个人行为。本文的实践意义：回本帮你校准个性化风险承受力——你之前认为自己能承受的波动幅度，经过熊市洗礼后往往被修正。

## 公式

```
回本 = 本金恢复 × 风险重评 × 持仓体检 × 财务规划重启
```

## 行动原则

1. 用不着急的钱做不着急的投资
2. 回本是组合体检的时机，不是跑路信号
3. 真正的决策标准是买入逻辑是否仍然成立，而非账户盈亏是否回到零
