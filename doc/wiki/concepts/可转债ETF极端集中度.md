# 可转债ETF极端集中度

**可转债ETF极端集中度**是指全市场仅两只可转债ETF（海富通、博时），却占据可转债基金规模42%的极端马太效应现象。这是债券被动化领域中"集中度上升"的反例，与[[头部ETF集中度下降]]的整体趋势形成张力。

## 核心数据

| 指标 | 数值 |
|------|------|
| 可转债ETF数量 | **2只**（海富通、博时） |
| 两只ETF规模占可转债基金比重 | **42%** |
| 主动转债基金管理费中位数 | 1.66% |
| 海富通可转债ETF管理费 | 0.15% |
| 博时可转债ETF管理费 | 0.24% |
| 费率倍数差 | 7~11倍 |

## 驱动机制

```
极低费率（0.15%/0.24% vs 1.66%）
  + T+0交易机制（主动普遍T+1/T+3到账）
  + 两只产品已建立规模和流动性优势
  → 吸金效应极强 → 规模占比42%
```

费率差距是直接推手：在固收领域费率敏感放大器效应显著（参见[[固收类产品费率敏感放大器]]），0.15% vs 1.66%的差距意味着每年1.51个百分点的净收益差，复利效应下差异巨大。

T+0机制是另一关键优势：主动转债基金申赎普遍T+1/T+3到账，而ETF支持T+0二级市场买卖，对需要灵活调仓的资金（如机构、量化策略）极具吸引力。

## 与头部ETF集中度下降的张力

[[头部ETF集中度下降]]描述的是2025年ETF市场资金流结构均衡背景下，头部公司市占率系统性下降的趋势。但可转债ETF是一个反例：

- 整体趋势：头部集中度**下降**
- 可转债ETF细分：头部集中度**上升**（两只产品占据42%）

这一张力表明，集中度变化并非全局一致——在特定细分品类（如可转债ETF），低费率+先发优势仍可形成极强的马太效应。

## 边界条件

- 若更多基金公司进入转债ETF领域，现有产品的吸金效应可能减弱
- 若费率竞争继续压降，主动与被动之间的费率差缩小，吸金效应减弱
- 若监管限制ETF产品数量或设置准入门槛，集中度可能维持高位
