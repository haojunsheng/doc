# 需求见底供应见顶

**需求见底供应见顶**是指中国房地产市场在 2024 年进入的一个特殊底部区间：**需求端 2024 见底，供应端 2024 见顶**，但"见底≠马上涨"。该框架从供需双侧同时判断楼市位置，是对单端供给视角的补充。

## 核心命题

> "2024年中国楼市处于'需求见底、供应见顶'的底部区间，但见底不等于马上涨——信心修复和库存去化仍需时间。"

"见底"指边际恶化趋势终结，但并不意味着反转；"见顶"指新增供应的峰值已出现，去库存压力开始减轻。

## 七大机制

### 需求端收缩机制

**① 房价→信心→观望负反馈**

```
房价↓ → 信心↓ → 观望↑ → 需求↓ → 房价↓↓
```

- 仅 13% 受访者看好房价回升，18% 计划半年内买房
- 房价下跌是观望情绪的原因而非结果（因果方向关键）

**② 利率失效悖论**

```
购房决策 = 月供负担 × 收入预期
          → 利率↓ 但 收入预期↓↓ → 决策仍↓
```

- 五年期 LPR 从 4.20% 降至 3.95%（25bp），取消首套/二套利率下限
- 但 70%+ 购房者仍观望——问题不在利率，在收入预期

### 供给侧结构变化

**③ 期房被现房挤出**

```
期房占比：78.9%（2023Q1）→ 69.3%（2024Q1）
现房销售增速 >> 期房增速
```

- 购房者规避烂尾风险，愿意为确定性付溢价
- 与 [[期房交付风险]] 直接关联，为后者提供了最新量化证据

**④ 新房供应主动收缩**

```
销售↓ → 回款↓ → 拿地↓ → 新开工↓ → 供应收缩
```

- 2024Q1 新开工继续下滑，竣工同比负增长
- 土地储备缩减是硬约束，开发商有意无力争规模

**⑤ 三线城市跌幅重灾区**

```
三线 = 人口流出 + 库存高 + 产业弱 → 供需失衡最严重
```

- 一二线相对坚挺，三线跌幅最大
- 结构性分化意味着"全国平均"信号失真

### 二手房与库存机制

**⑥ 二手房"量涨价跌"**

```
挂牌量↑↑ → 供过于求 → 价格↓
政策↑   → 成交↑ 但 挂牌量仍↑
```

- 政策利好只带动成交不带动定价权
- 挂牌量下降（惜售或退出）才是价格支撑信号

**⑦ 四万亿库存何时消化**

```
待售住宅 4 万亿（2024Q1）
→ 去化手段：收储 + 以旧换新 + 租赁
→ 2024年去库存压力见顶
```

- 与 [[收储机制]] 衔接：央行已批准超 2.2 万亿收储贷款
- 若新房开工控制不力，新增供应会抵消去库存成果

## 与 [[楼市转折点-供给收缩驱动出清]] 的定位关系

| 维度 | 需求见底供应见顶 | 楼市转折点 |
|------|----------------|-----------|
| 视角 | **双端**（需求+供给） | **单端**（供给侧收缩） |
| 时间定位 | 2024年进入"底部区间" | 2027年新房价格企稳 |
| 本质区别 | 确认已进入底部区间 | 预测价格止跌时点 |
| 关系 | 前置判断 | 后续验证 |

两者不矛盾：本文确认"2024年已进入底部区间"，[[楼市转折点]] 解释"为何2027年才止跌"——中间是库存去化与信心修复的时间窗口。

## 边界条件

1. 若政策力度超预期（大规模收储、核心城市全面松绑），信心修复加速，底部区间缩短
2. 若收入预期持续恶化，利率杠杆完全失效，底部延长
3. 若期房交付信用恢复，现房/期房偏好逆转，供给侧结构重排
4. 若新房开工无法有效收缩，新增供应抵消去库存成果，"供应见顶"判断失效
