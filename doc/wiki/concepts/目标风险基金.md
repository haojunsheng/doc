# 目标风险基金

保持固定风险等级、不随时间自动调整的养老基金类型——投资者需自行判断风险偏好并进行动态调整。

## 核心机制

```
目标风险 = 固定风险等级（稳健/平衡/积极）
投资者自行判断：自身风险承受能力 → 选择对应等级
```

与[[目标日期基金]]的区别在于：目标风险基金的风险敞口不随时间自动变化，需要投资者根据自身情况主动管理。

## 三种风险等级

| 等级 | 权益仓位 | 适用人群 |
|------|---------|---------|
| 稳健型 | 低 | 风险厌恶、临近退休 |
| 平衡型 | 中等 | 风险中性、有一定风险承受力 |
| 积极型 | 高 | 风险偏好、年轻且有较长投资期限 |

## 与目标日期基金的对比

| 维度 | 目标日期基金 | 目标风险基金 |
|------|------------|------------|
| 风险策略 | 随时间自动降风险（下滑路径） | 保持固定风险等级 |
| 投资者主动度 | 低（设好不管） | 高（需自行调整） |
| 灵活性 | 低（统一曲线） | 高（可按个人情况选择） |
| 行为要求 | 无需操作 | 需定期评估并调整 |

## 边界条件

- 投资者需要具备风险判断能力，否则容易选错等级
- 市场环境变化时，固定风险等级可能不再适用
- 目标风险基金更灵活，但灵活性也意味着更高的行为要求

## 与相关概念的关系

- [[目标日期基金]]：对比参照，两者是养老 FOF 的两种主要类型
- [[风险调整后收益]]：选择目标风险基金时，应关注夏普比率等风险调整指标，而非单纯排名
- [[养老目标基金]]：目标风险基金是养老目标基金的两种类型之一
