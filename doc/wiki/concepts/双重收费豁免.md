# 双重收费豁免

FOF投资自家基金时免收管理费、托管费和申赎费，这是导致内部基金偏好的根本制度动因。

## 机制

```
FOF投内部基金 = 免管理费 + 免托管费 + 免申赎费
FOF投外部基金 = 正常收取上述费用
```

## 影响

- 交银安享稳健债券部分约70%配置内部产品
- 富国也倾向内部基金配置债券部分
- 但内部基金质量参差，过度依赖可能拖累收益

## 边界条件

若基金公司内部基金质量不高，双重收费豁免的费率优势可能被质量劣势抵消。
