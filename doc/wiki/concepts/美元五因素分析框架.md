# 美元五因素分析框架

系统性分析美元中长期走势的五个维度框架，由晨星多资产研究团队提出。

## 框架结构

| 因素 | 方向 | 核心逻辑 |
|------|------|---------|
| 财政赤字 | ↓ | 联邦债务与利息支出持续攀升，缺乏财政收紧计划，削弱财政可持续性信心 |
| 对外资本依赖 | ↓ | 经常账户赤字扩大+NIIP为负+外资持有25%美国资产，大规模减持触发负反馈循环 |
| 避险光环失效 | ↓ | 2025年4月股市抛售+美元同步大跌，打破历史规律，反映制度信任松动 |
| 央行独立性受威胁 | ↓ | 政治干预（施压降息+试图罢免理事），引发"财政主导"担忧 |
| 储备货币多元化 | ↓ | 各国央行增持黄金，多货币体系方向明确，过程缓慢但不可逆 |

**方向符号说明：** "↓"表示对该因素而言，趋势方向是美元走弱。

## 形式化表达

```
美元走势 = f(财政赤字, 外资依赖, 避险光环, 央行独立性, 储备多元化)
五因素全部指向贬值方向 → 温和贬值周期
短期约束: 储备货币地位稳固（外汇90%/贸易50%/储备60%）→ 不可替代
```

## 核心判断

> 美元十年涨势已终结，进入温和贬值周期；短期内储备货币地位不会被取代。

## 关键数据支撑

- **美元指数（DXY）**：2025年上半年暴跌11%，全年跌近10%；终结2010年以来近40%的涨势
- **美元估值**：33种货币中仅9种估值高于美元（相对高估）
- **外资持有规模**：约18万亿美元美股（占20%）+ 7万亿美债（占25%）= 合计约25%美国资产
- **储备货币份额**：外汇交易90% / 贸易结算50% / 官方储备60%

## 动态机制

### 减持—贬值—再减持负反馈循环

```
外资减持美国资产 → 美元贬值 → 资产以美元计价值下降
        ↓
更多外资因汇率损失而减持 → 美元进一步贬值 → 恶性循环
```

该机制使"对外资本依赖"成为美元结构性软肋——一旦触发，贬值压力自我强化。

## 边界条件

1. 若美国推出可信的财政整顿计划，美元下行压力可能缓解
2. 若全球出现非美市场危机，美元避险光环可能恢复
3. 若美联储保持独立性，"财政主导"担忧将回落
4. 五因素均为中长期判断，短期汇率波动受利率差异、风险情绪等影响
