# 买入时机对指数基金收益的影响

指数基金的收益完全来自指数涨跌，因此**买入价格即成本**。同一只指数基金，在不同点位买入，长期收益差异巨大。

## 核心机制

```
买入时机影响: 3000点买入 vs 5000点买入 → 收益差异巨大

收益 = (卖出点位 - 买入点位) / 买入点位 × 持有时间系数
买入点位越低，等幅上涨带来的收益率越高
```

### 形式化说明

假设沪深300从3000点涨到5000点（涨幅66.7%）：
- 3000点买入：收益 = (5000-3000)/3000 = 66.7%
- 5000点买入：收益 = (5000-5000)/5000 = 0%

即使在同一时间点卖出，买入时机的差异直接决定了收益的有无。

## 定期定额的平滑效应

定期定额投资（DCA）是一种针对买入时机风险的纪律性解决方案：

```
单次大额买入: 成本集中于某一时点，风险极高
定期定额:     成本分散于多个时点，波动平滑
```

DCA 的本质是用时间换空间——在不择时的前提下，通过多次分批买入来降低单一时点择时错误的风险。

与 [[定投]] 的关系：本文场景下 DCA 的标的为指数基金（或 ETF），与定投页面的一般性框架一致，但本文特别强调了"在低估值区域坚持定投"的效果优于"在高估值区域开始定投"。

## 边界条件

- 定期定额仅在长期持有了效，短期定投在下跌趋势中可能持续亏损
- 有明确择时策略者可适度交易，但需要独立判断能力，绝大多数散户不具备
- 在市场极端低估区域一次性建仓的收益远高于定期定额，但难以识别和执行
