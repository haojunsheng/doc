# 规模有机增长率

定义"爆款基金"的核心指标：剔除被动增值后的资金净流入比例。

## 形式化

```
规模有机增长率 = 资金净流入 / 期初规模
```

**爆款基金操作性定义**（晨星）：
- 规模有机增长率 > 200%
- 期初规模 > 5 亿元
- 确保至少 10 亿元真实净流入

## 计算逻辑

基金规模增长来自两个源头：
1. **被动增值**：持仓资产价格波动带来的规模变化（市场涨跌决定）
2. **主动申购**：投资者用真金白银买卖导致的规模变化（行为信号）

只有主动申购部分反映真实热度。规模有机增长率 = 剔除被动增值后的"主动规模增长"相对于期初规模的比率。

## 边界条件

- **指数基金不适用**：指数基金的规模增长基本是被动的（跟踪指数涨跌），用规模有机增长率会失真
- **小规模基金噪声大**：期初规模 < 5亿 的基金即使规模翻三倍，绝对金额可能只有几千万，不具备统计意义
- **门槛效应**：如果期初规模是10亿，200%增长意味着30亿规模——标准会随基数变大而提高

## 实证数据

- 70% 的爆款基金在规模激增前一年跑赢市场（平均超额 6.77%）
- 三分之二的爆款基金在三年内跑输市场或清盘
- 规模激增本身是业绩反转的领先指标
