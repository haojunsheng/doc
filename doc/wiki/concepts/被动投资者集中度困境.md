# 被动投资者集中度困境

## 定义

被动投资者因跟踪指数而天然重仓某些行业或个股，当这些标的占比过高时，面临"已被动重仓、不应主动加仓"的困境。这是被动投资策略在极端集中度情况下面临的核心风险。

## 核心数据

- 英伟达占美国主要指数约 **8%**
- 英伟达占全球主要指数约 **6%**
- 被动投资者实际上已经"被动"重仓了AI

## 困境逻辑

```
被动跟踪指数 → 英伟达已占8%/6% → 被动已重仓AI
                                      ↓
                    如果主动在个股层面加仓 → 过度集中
                                      ↓
                        需要减配或至少不加（而非追高）
```

## 与相关概念的区分

### 与[[指数权重集中风险]]的区别
- [[指数权重集中风险]]是更广义的概念，描述指数权重过度集中于少数标的的风险
- [[被动投资者集中度困境]]是其在被动投资策略中的具体体现，强调"被动已重仓、不应主动再加"的操作困境

### 与[[宽基指数正回报差悖论]]的关系
- 被动集中风险是导致宽基指数超额收益差的结构原因之一
- 指数集中度越高，被动持有者面临的非系统性风险越大

## 应对建议

1. **避免在个股层面加仓**：被动投资者已在指数层面重仓，不应再在个股层面追高
2. **避免在行业层面追逐主题**：行业层面追逐AI主题会加剧风险
3. **考虑减配**：如果集中度已达到危险水平，应适当减配

## 与AI估值的关系

如果[[AI估值可持续条件]]不满足（即AI未真正推动实体经济效率提升），被动投资者将面临双重损失：估值回归 + 指数权重集中风险。
