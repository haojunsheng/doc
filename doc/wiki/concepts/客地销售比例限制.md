# 客地销售比例限制

客地销售比例限制是指监管部门对香港互认基金向内地投资者销售设定的比例上限。这一政策限制会扭曲资金流向数据，导致部分债券基金的净流出不能真实反映其产品吸引力。

## 政策机制

- 规定香港互认基金向内地投资者销售的额度上限
- 超出额度的基金暂停内地申购，或仅向特定投资者开放
- 与基金本身的投资能力无关，是纯粹的监管政策约束

## 对数据的影响

当债券基金因客地销售比例限制而暂停内地申购时：
- 内地投资者的正常申购需求被切断
- 资金流入渠道受阻
- "净流出"数据被放大（本来可能有净流入）
- 不能简单归咎于产品表现差

## 识别方法

判断一只基金的净流出是否受政策扭曲：
1. 查看基金公告——是否标注"暂停内地申购"或"额度受限"
2. 对比同类型其他基金——若整体债基都在流出，需考虑政策因素
3. 等待政策变化——一旦放开，流向可能快速反转

## 与投资行为的关联

客地销售比例限制造成的数据失真，提醒投资者：
- 资金流向数据需先做政策剔除，再做行为解读
- 单一月份的数据可能受政策干扰，需跨期观察
- 与 [[风格漂移]] 形成对照——被动政策限制 ≠ 主动风格偏移

## 与现有概念的关联

- 与 [[香港互认基金]] 实体直接相关——这是互认基金特有的政策约束
- 与 [[通道摩擦与额度稀缺]] 同源——都是跨境投资中的政策摩擦
- 与 [[风格漂移]] 形成参照——被动政策限制 vs 主动风格偏移
