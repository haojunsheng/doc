# 基金逆向投资无效

在公募基金领域，基于排名的机械逆向操作（买去年垫底基金以"反着买"）无法获得超额收益，无论买冠军还是买垫底，长期业绩均回归中等水平。

## 核心命题

> 股票逆向投资有效，基金逆向投资无效。

这是两类的根本差异所在：股票价格受投资者情绪影响会产生"低估"→均值回归；而基金净值由底层资产决定，不受基金本身声誉/情绪影响，不存在"低估"概念。

## 形式化表达

```
股票逆向: 过度反应 → 低估 → 均值回归 → 有效（塞勒&德邦特 1985）
基金逆向: 业绩由底层资产决定 → 无"低估"概念 → 无效
```

```
买冠军 10 年后 → 中等水平（晨星 10 年数据）
买垫底 10 年后 → 中等水平（晨星 10 年数据）
```

## 双端失效机制

### 买冠军端

```
冠军基金 = 极致风格 × 单一板块
→ 风格匹配时暴涨
→ 风格切换后回落
→ 2019 年前 ten 名基金持有到 2024 年，五年期业绩仅处中等水平
```

参见 [[冠军魔咒]]。

### 买垫底端

```
垫底基金 = 风格错配 or 能力不足
→ 风格错配：可能反转，但概率不确定
→ 能力不足：继续恶化
→ 清盘风险：部分垫底基金没撑到反转就被清盘
→ 10 年数据：2019 年垫底基金多数长期表现不佳，部分在 5 年内被清盘
```

参见 [[基金清盘常态化]]。

## 股票与基金的定价机制差异

| 维度 | 股票 | 基金 |
|------|------|------|
| 定价驱动 | 投资者情绪 + 基本面 | 底层资产净值 + 基金经理操作 |
| 是否可"低估" | 是（情绪过度反应） | 否（净值由资产决定） |
| 均值回归 | 有实证支持（塞勒&德邦特） | 无（排名随机性强） |
| 可预测性 | 长期有一定可预测性 | 短期高度随机 |

**学术支撑**：1980 年代塞勒（Richard Thaler）与德邦特（Victor De Bondt）在《股市是否反应过度》（*Does the Stock Market Overreact?*）中验证了股票逆向投资的有效性——输者赢者效应。

## 基金特殊性的三个原因

1. **基金净值不受情绪影响**：基金净值由持仓资产市值决定，不会因投资者恐慌赎回而系统性"低估"。
2. **基金经理是可变的**：基金经理会调仓、会犯错、会变更——基金不是一个静态资产。
3. **历史业绩高度随机**：见 [[基金业绩的短期随机性]]——前一年表现优异的基金下一年继续优秀的概率接近随机水平。

## 实践含义

- 逆向思维应用于选股（如买入被市场恐慌抛售的优质股票）可能有效
- 但逆向思维应用于选基金（买去年垫底基金）无效——这是一种[[虚假的逆向]]
- 选基金的本质：独立思考 + 风险偏好匹配 + 收益预期匹配，而非榜单反向操作

## 边界条件

- 如果投资者能识别"真正有能力的基金经理"而非"风格受益者"，逆向可能有例外
- 如果投资者能识别"暂时遇到困难但能力不错的基金经理"，买垫底可能有效
- 普通投资者难以准确区分这两种情况，因此机械逆向操作整体无效
