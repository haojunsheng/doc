# 股价过度波动之谜

## 定义

实际股价波动远超未来股利贴现所决定的基本面价值波动——传统有效市场假说无法解释的现象。由诺贝尔经济学奖得主罗伯特·希勒于1981年首次提出并实证发现。

## 形式化框架

```
实际股价波动 >> 基本面(股利贴现)波动
```

理论上，价格波动应小于未来基本面变化的波动（因为价格是对未来现金流的折现，本质是平滑后的序列）。现实恰恰相反。

## 核心机制

**根源：预期外推偏差（Expectation Extrapolation Bias）**

```
短期业绩超预期 / 短期事件爆红
    → 长期盈利预期被过度外推
    → 情绪溢价累积（FOMO → 追高买入）
    → 股价大幅上涨
    → 实际业绩无法兑现预期
    → 股价回调（均值回归）
```

关键观察（NBER 2023年研究）：
- 分析师长期盈利预期大部分源于当前短期表现
- 当长期增长预期高于历史平均时，未来实际盈利经常不如预期
- 这种乐观情绪预示未来1-2年盈利增长令人失望

## 实体经济传导链（约两年滞后）

```
高预期 → 短期投资↑ + 消费↑ + 就业↑ + 工资↑
    → 两年后投资急剧降温
    → 一切回归均值
```

**边界条件**：若高预期恰好对应真实的技术革命（如互联网），投资热潮可能持续更久。

## 典型案例

**泡泡玛特**：Labubu爆红（短期事件）→ 市场放大为长期IP商业化逻辑 → 目标价越喊越高 → 股价狂飙 → 护城河未建成判断导致回调 → 预期反复超前与修正。
