# QDII两极分化

## 核心定义

QDII两极分化是指境内投资者通过QDII渠道配置海外市场时，因所投市场不同而产生巨大业绩差异的现象。这一现象在2023年首次凸显，并在后续月份持续出现区域分化特征。

## 2023年实证数据

| 市场 | 代表指数 | 涨跌幅 | 对应QDII表现 |
|------|---------|--------|-------------|
| 美股（纳斯达克） | 纳斯达克100 | +40%+ | 普遍涨40%以上 |
| 港股 | 恒生指数 | -20%+ | 多只港股ETF跌幅超20% |
| A股（对比） | 沪深300 | -13.8% | 国内权益基金整体承压 |

**形式化表达**：
```
纳斯达克涨40%+ vs 恒生指数跌20%+ → QDII业绩冰火两重天
```

## 月度案例：区域分化全景

### 2024年12月（新增案例）

| 市场/品类 | 驱动因素 | QDII表现 |
|----------|---------|---------|
| 黄金/商品 | 黄金价格上涨 | 商品基金上涨 |
| 港股 | 受A股带动 | 港股基金上涨 |
| 美股 | 美股下跌 | 拖累美国股票基金 |
| 全球新兴市场 | 受地缘风险影响 | 表现偏弱 |

**形式化**：`投资黄金/港股 > 投资美股/全球新兴市场`

### 2025年1月全球市场分化案例

| 市场 | 涨跌幅 | QDII对应表现 |
|------|--------|-------------|

| 法国CAC | +7.72% | — |

**QDII内部品类分化**：
```
商品基金（+5.01%）> 美国股票（+3.10%）>> 环球债券（-0.05%）
```

**驱动因子**：
- 黄金上涨6.57%（关税担忧+地缘冲突）→ 直接利好商品基金
- 标普500涨2.70%（美国Markit制造业PMI时隔6个月进入扩张区间）→ 利好美国股票基金
- 环球债券受全球利率环境拖累 → 表现垫底

## 成因分析

1. **全球市场分化**：2023年全球大部分市场有正收益，A股是"差等生"
2. **集中押注单一市场风险**：大中华区基金因重仓港股表现差，暴露了地域集中风险
3. **投资者情绪低谷**：市场对A股情绪低落，低估了海外配置的必要性
4. **通道摩擦加剧**：QDII额度限制导致部分投资者"想买买不到"
5. **底层资产决定论**：QDII表现完全取决于底层资产所在地区经济周期

## 与投资方法论的关系

- 与 [[concepts/跨市场分散]] 直接呼应：QDII两极分化是缺乏跨市场分散的典型反面案例
- 强化 [[concepts/内地投资海外热情降温]] 的观点：投资者在海外配置上的行为存在明显滞后
- 与 [[concepts/通道摩擦与额度稀缺]] 互为印证：额度限制使正确配置难以执行

## 边界条件

**QDII配置有效的条件**：
- 目标市场处于上涨或稳定趋势
- 汇率相对稳定或有利于本币投资者
- 额度充足，能够顺利申购

**QDII配置失效的风险**：
- 海外市场大幅回调（如美股大跌）
- 人民币大幅升值（汇率侵蚀收益）
- 额度紧张导致无法建仓或追加
- 3月教训：QDII表现完全取决于底层资产所在地区经济周期，区域分散比单一市场集中更安全
- 1月教训：商品基金因黄金上涨表现最优，美国股票基金次之，环球债券垫底——底层资产属性决定一切
