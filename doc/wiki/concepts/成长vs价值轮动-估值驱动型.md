# 成长vs价值轮动——估值驱动型

## 定义

当成长股因前期涨幅过大导致估值过高，而价值股/小盘股长期被忽视、估值接近公允甚至低估时，市场出现从成长向价值的系统性轮动。这一轮动的核心驱动力是**估值压力**，而非基本面恶化。

## 形式化表达

```
成长股领涨 → 估值过高（"被吹得过大的气球"）
价值/小盘长期被忽视 → 估值接近公允或低估 → 风险收益比更优

轮动触发条件: 利率下行 + 企业盈利增速放缓（或预期兑现）
```

## 核心逻辑

### 成长股："被吹得过大的气球"

- 过去一年大盘成长股领涨，但估值已处于历史高位
- 利率下行虽是利好，但不足以支撑当前估值
- 任何不及预期的信号都可能触发大幅回调
- 类比[[估值隐含过度乐观预期]]：护城河宽 ≠ 估值合理

### 价值/小盘："被遗忘的宝藏"

- 长期被市场忽视，资金持续流向成长股
- 估值接近公允水平，某些领域还低估
- 在利率下行周期中，价值股历史表现更优
- 提供比高估成长股更好的风险收益比

### 边界条件

| 条件 | 结果 |
|------|------|
| 企业盈利增长超预期 | 高估值可被消化，成长股继续强势 |
| 经济持续低迷 | 小盘股盈利稳定性弱于大盘股，轮动可能延迟 |
| 利率持续下行 | 价值股吸引力进一步增强 |

## 投资启示

1. 不要因成长股近期表现好就忽视估值风险
2. 关注"被忽视"的价值/小盘标的，寻找安全边际
3. 利率下行环境有利于价值股相对表现
4. 若企业盈利增速超预期，需重新评估成长股估值消化可能性
