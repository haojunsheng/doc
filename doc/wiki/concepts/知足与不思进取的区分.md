# 知足与不思进取的区分

Carl Richards 提出的重要区分：知足是主动选择，不思进取是被动放弃。

## 形式化区分

```
知足 = 目标清晰 + 达到目标 + 主动停止
不思进取 = 目标模糊 + 放弃追求 + 用"知足"合理化懒惰
```

## 核心洞察

- 真正的知足需要更大勇气——得先知道自己要什么，然后承认"够了"
- 不思进取的人其实并不知足，他们只是害怕失败，用"我不想要"来保护自己
- 真正的知足是：你曾经全力追求过，体验过了，然后发现"够了"——这是主动的，不是被动的

## 边界条件

如果连基本需求都没满足，"知足"就是自我欺骗——这时候应该先追求，再谈知足。
