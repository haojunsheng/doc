# 行为代价（Mind the Gap）

Morningstar 核心发现：投资者实际承担的风险，主要来自自身行为偏差，而非市场波动本身。

## 核心数据

Morningstar "Mind the Gap" 报告：2000-2020 年，标普 500 年化回报 **7%**，但投资者实际仅拿到 **5%**，差额 **2%/年** 来自行为代价。

[[sources/5-notes--37-20260614t091504-qa-为什么大多数基金经理跑不赢指数qa--yzydit]] 补充案例：基金年化 10% → 投资者实际拿到 7%，差 3% 来自行为代价；指数基金同样存在行为代价，但因波动较小，差距相对窄一些。

## 形式化

```
理论风险 = 市场波动
实际风险 = 市场波动 + 行为偏差
→ 后者往往更致命
```

## 具体机制

- 恐慌卖出：在市场底部卖出，错过后续反弹
- 追涨杀跌：在高点买入，在低点割肉
- 关键句：**市场跌 30% 不是风险，你在跌 30% 时卖出才是风险**

## 路径选择偏差

[[sources/5-notes--38-20260614t091506-概念解剖-财富创造的真实路径concept--18btsry]] 补充：行为代价不仅来自买卖时机的偏差，也来自**初始路径选择偏差**——很多人一开始就选错了财富创造路径（如幻想炒股致富），这种偏差同样造成巨大的机会成本。

## 边界

- 适用于有纪律的投资者；若无纪律，行为代价会持续侵蚀回报
- 降低风险资产比例是合理选择，但不是因为你不能承受波动，而是因为你不能承受"在低点卖出"的后果

## 与幸存者偏差的关系

[[concepts/幸存者偏差-基金数据库]] 是数据层面的认知偏差，与行为代价叠加，让人严重高估主动基金的真实表现。
