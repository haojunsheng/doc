# 策略选择优于大类选择

投资者做资金配置决策时，本质上是在不同策略之间做选择，而非简单地在"股票 vs 债券"的大类之间切换。资金流向反映的是策略偏好，而非大类资产配置偏好。

## 核心命题

> 资金流向的本质是"策略选择"而非"大类选择"

## 实证依据

以 2026 年 4 月香港互认基金市场为例：

| 类别 | 典型产品 | 流向 | 说明 |
|------|---------|------|------|
| 混合型 | 施罗德亚洲高息股债 | 净流入 5.36 亿 | 高股息 + 股债混合策略受追捧 |
| 混合型 | 瑞士百达灵活配置 | 净流入 4.96 亿/月 | 灵活配置策略业绩领先 |
| 股票型 | 摩根亚洲股票高息 | 净流入 12.35 亿 | 期权备兑开仓策略增强 |
| 股票型 | 环球/科技基金 | 净流出 >7 亿 | 纯股票风险暴露被减持 |
| 债券型 | 高腾亚洲收益债 | 净流入 4.93 亿 | 差异化策略仍有资金 |
| 债券型 | 摩根国际债券 | 净流出 10.48 亿 | 受政策限制 + 利率上行双重压力 |

**关键观察**：
- 不是"卖股票买债券"，而是"卖纯股票买混合型"
- 不是"逃债基"，而是"挑肥拣瘦"——高腾债基净流入，摩根债基净流出
- 策略差异比品类差异更重要

## 与相关概念的关系

### 与 [[赛道投资]] 的关系

两者都指向"细分策略"的重要性，但角度不同：
- 赛道投资关注的是行业/主题层面的集中风险
- 策略选择关注的是产品策略层面的适配性

### 与 [[资产配置]] 的关系

传统资产配置理论强调大类资产比例（股债配比），但本文提出的观点是：
- 大类选择是前提，但不是决策的全部
- 在同一品类内，策略选择同样重要（甚至更重要）
- 例如：同样是债券基金，不同策略的资金流向可以完全相反

### 与 [[业绩归因]] 的关系

归因颗粒度决定结论准确性：
- 粗颗粒度：看公司整体流向 → 摩根净流出 12.25 亿
- 细颗粒度：看策略流向 → 股票型净流入 12.35 亿，债券型净流出 22.72 亿
- 细颗粒度归因揭示更真实的资金逻辑

## 投资决策启示

1. **选基金先看策略，再看品类**——同品类内策略差异可能比品类差异更大
2. **关注策略适配性**——没有最好的策略，只有最适合当前市场环境的策略
3. **警惕单一策略拥挤**——高股息策略持续吸金是好事，但也可能是未来收益压缩的信号
4. **归因要分层**——公司层面、品类层面、策略层面，三层归因结论可能完全不同

## 边界条件

- 如果市场进入极端单边行情（如全面牛市），策略选择的差异会缩小
- 如果政策环境发生重大变化（如客地销售比例限制放开），策略选择逻辑可能重估
- 策略选择的适用前提是市场存在明显的策略分化，而非全面一致行情
