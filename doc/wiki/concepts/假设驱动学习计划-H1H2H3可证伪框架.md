# 假设驱动学习计划——H1/H2/H3 可证伪框架

本框架是一种将「假设驱动验证」引入个人学习路径的方法论，核心思想是：**在学习开始前写下可证伪的假设，并在每个阶段结束时用具体行动检验，让学习成果来自验证而非吸收。**

## 与普通学习计划的本质区别

| 维度 | 普通学习计划 | 假设驱动计划 |
|------|------------|------------|
| 起点 | 我要学什么 | 我相信什么，需要验证什么 |
| 结构 | 章节顺序 | 假设 → 子假设 → 验证方式 → 失败判定 |
| 终点 | 我读了多少 | 我的假设被推翻了多少 |
| 错误处理 | 避免犯错 | 记录失败日志，从错误中学习 |

## H1/H2/H3 示例（晨星投资学习计划）

### H1：阿尔法稀缺假设

> 长期稳定跑赢基准（阿尔法）的主动基金是极少数（<15%），普通投资者的合理目标应是拿住贝塔。

- **子假设**：
  - 1.1：阿尔法在 A 股主动基金中持续存在比例 <15% → 验证：回测近 5 年偏股基金跑赢沪深 300 的比例
  - 1.2：基准比收益排名更客观 → 验证：对比一只基金的「排名」与「相对基准超额」是否背离
  - 1.3：历史业绩对未来预测力弱 → 验证：统计「去年 Top10 基金」今年掉队比例
- **如果错了我会在**：阶段一末回测结果 >15% 时知道

### H2：分层配置假设

> 用「三个钱袋子」做分层配置，长期风险调整后收益 ≥ 单押高波动资产，且回撤更可控。

- **子假设**：
  - 2.1：钱应按期限 + 目标分三类 → 验证：读[[赚钱的铁律，不是高风险高收益]]
  - 2.2：高现金流比高收益率更幸福 → 验证：读[[财务自由的关键，不是你赚了多少钱]]
  - 2.3：散户有独特优势（时间、无排名压力）→ 验证：读[[散户优势]]
- **如果错了我会在**：阶段二用真实资金模拟 1 年，发现分层配置回撤反而大于单押时知道

### H3：溯源优先假设

> 选基金时先看「基准契合度 + 海外浓度/持仓溯源 + 费率」，比只看历史收益排名更能避开营销误导。

- **子假设**：
  - 3.1：先定「为什么买」再定「买什么」→ 验证：用[[ETF投资五问框架]]筛出 3 只符合目标的 ETF
  - 3.2：费率/跟踪误差显著影响长期收益 → 验证：对比同标的 2 只 ETF 费率和跟踪偏离
  - 3.3：基金名≠持仓，海外浓度需查 → 验证：查一只名字带「全球/纳斯达克」基金的前十大持仓
- **如果错了我会在**：阶段三末复盘「按溯源选的基金 vs 按排名选的基金」3 年表现时知道

## 方法论四支柱

```
假设驱动 → MECE 拆解 → 动手验证 → DIKW 自检 → 失败日志
    ↑___________________________________________↓
```

螺旋迭代，每周循环一次。

### 1. 假设驱动

在开始学习前先写下 2–3 条核心假设，每条假设必须包含明确的「如果错了我会在什么时候知道」。这是与普通学习计划最关键的区别。

### 2. MECE 拆解

每条主假设拆解为 2–3 条互相独立、完全穷尽的子假设。每条子假设对应一个具体验证动作。

### 3. 动手验证

每周至少一个 demo/验证实验（回测、配置表、溯源报告、体检单）。验证产出物不是笔记，而是可以提交的可复现成果。

### 4. DIKW 自检 + 失败日志

- 每周填入 DIKW 自检表，确认停留在哪一层、是否有证据
- 每周记录 ≥1 条失败日志（哪怕很小）

## 适用范围

本框架适用于任何需要「从知道到能用」的 P+M 型（实践手艺 + 心智判断）学习领域，不限于投资。关键信号：
- 该领域的知识容易以「正确的废话」形式被吸收
- 学习者容易陷入「读了很多但没有判断力」的状态
- 验证结果可以是客观的（数据回测）也可以是主观的（能否在 10 分钟内做出判断）
