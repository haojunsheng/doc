# 隐性成本-交易费占比

在销售导向的基金商业模式下，高换手率导致隐性成本（交易费）成为吞噬投资者收益的关键因素，其规模往往远超显性管理费。

## 核心判断

```
显性成本(管理费) < 隐性成本(交易费6.8%) → 隐性成本才是大头
```

投资者往往只关注管理费这一显性成本，而忽视了交易费用这一隐性成本。在高换手率的基金中，交易成本可达6.8%，远高于管理费水平。

## 形成机制

```
销售导向模式 → 高换手率 → 高频交易 → 交易成本高企(6.8%) → 收益被侵蚀
```

- 销售佣金来自产品规模而非客户收益，激励销售人员推动频繁交易
- 中国股市整体换手率高，加剧了交易成本
- 投资者缺乏对隐性成本的认知和敏感度

## 对比框架

| 成本类型 | 名称 | 典型水平 | 投资者感知度 |
|---------|------|---------|-------------|
| 显性成本 | 管理费 | 约1-1.5% | 高（明码标价） |
| 隐性成本 | 交易费 | 可达6.8% | 低（隐藏在内） |

## 边界条件

若市场换手率下降或交易费率降低，隐性成本会收窄。但在当前销售导向模式下，这一问题持续存在。

## 与买方投顾的关系

买方投顾模式通过降低换手率、坚持资产配置和长期持有，可以显著减少隐性成本。这是买方投顾创造价值的直接体现之一。
