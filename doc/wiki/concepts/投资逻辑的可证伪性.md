# 投资逻辑的可证伪性

好的买入逻辑必须能被现实证伪。如果一个"投资逻辑"无法被任何事实推翻，那它可能只是一个模糊的感觉，而非真正的投资判断。

## 核心命题

> 不可证伪的逻辑 = 不是逻辑，只是信念

可证伪性来源于科学哲学家卡尔·波普尔的认识论：一个命题如果无法被经验事实反驳，就不属于科学范畴。投资同理。

## 可证伪 vs 不可证伪的案例

| 类型 | 可证伪的逻辑 | 不可证伪的"逻辑" |
|------|-------------|----------------|
| 行业投资 | "看好新能源行业3年渗透率提升" → 渗透率停滞即证伪 | "这个赛道未来会涨" → 无论涨跌都能自圆其说 |
| 基金经理 | "看好经理A的逆向选股能力" → 连续3年风格漂移即证伪 | "好公司迟早会涨" → 永远正确但无法指导操作 |
| 宏观判断 | "利率下行支撑债券牛市" → 利率上行即证伪 | "大环境不好但基金能赚" → 任何结果都能解释 |

## 在买入逻辑检验中的应用

[[concepts/买入逻辑检验]] 框架本质上依赖可证伪性：
- 看好行业趋势 → 行业趋势破 = 卖出
- 看好基金经理 → 经理更换/操作变形 = 卖出

如果买入时没有明确的可证伪条件，那持有或卖出决策就沦为情绪驱动。

## 与能力圈的关联

[[concepts/能力圈]] 强调做自己懂的东西。可证伪性是能力圈的测试工具：如果你无法说出什么情况下会证明自己的判断是错的，那你可能并不真正"懂"这个投资。

## 与近因效应的关联

[[concepts/近因效应]] 描述的认知偏差会让投资者把最近的价格波动误认为逻辑变化的证据。可证伪性框架要求投资者明确列出证伪条件，避免被近因效应劫持。

## 实践检验

问自己：如果接下来发生 X 情况，我会承认自己错了并退出吗？

- 如果不能 → 你的逻辑不可证伪，需要重新思考
- 如果能 → 你的逻辑是可检验的，可以执行
