# 个人养老金税收套利

## 核心论点

个人养老金制度通过"缴费时省税 + 持有期降费 + 领取时低税率"三段式设计，为边际税率 > 3% 的高收入者创造净正收益；对边际税率 ≤ 3% 的低收入者则是负向套利。

## 三段式收益结构

### 第一段：缴费时省税

每年缴纳上限 12000 元可从应纳税所得额中扣除。

```
省税金额 = 边际税率 × 12000
```

| 边际税率 | 年省税额 |
|---------|---------|
| 3%（最低档） | 360 元 |
| 10% | 1200 元 |
| 20% | 2400 元 |
| 45%（最高档） | 5400 元 |

### 第二段：持有期降费

个人养老金专属 Y 份额管理费约为普通份额一半（约省 0.5%/年）。

```
省费 = 0.5% × 账户余额
```

经 30 年复利，0.5% 费率差约侵蚀终值 12.5%；1% vs 0.15% 差则侵蚀约 26% 累计收益。

### 第三段：领取时统一 3%

所有领取金额单独按 3% 税率计税，不再适用劳动所得累进税率。

## 边界条件：边际税率 < 3% 者不宜开户

月工资 5000 元以下者边际税率为 0%：
- 缴费时无省税收益
- 领取时额外缴纳 3% 税率
- **净亏损**

这是一个反直觉结论——个人养老金对低收入者并非优惠政策。

## 形式化判断框架

```
净收益 = 边际税率 × 12000 − 3% × 12000 + 费率节省（复利累积）
```

当边际税率 > 3% 时，税收套利为正；≤ 3% 时为负。

## 常见误区

1. **"个人养老金人人适合"**：边际税率 ≤ 3% 者开户即亏损
2. **"12000 够用"**：仅达到最优税收优惠的满额投入，不是养老储备的全部
3. **"只算省税不管费率"**：0.5% 费率差经 30 年复利可产生显著差异
