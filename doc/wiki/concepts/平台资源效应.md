# 平台资源效应

在QDII基金选择中，基金经理的个人海外经验有限，真正的差异化能力来自基金公司的平台投研支持。

## 核心论点

个人投资者的海外信息获取能力天然受限，基金经理同样如此。即使有多年海外经验，若缺乏持续的研究团队支持和外部券商信息通道，也难以持续获得超额收益。

## 形式化表达

```
QDII超额收益 = f(个人能力, 平台团队, 外部资源)
              个人能力是必要条件，平台资源是充分条件
```

## 三家基金公司对比

| 公司 | 平台支持模式 | 外部资源 |
|------|------------|---------|
| 广发基金 | 国际业务部 + 海外权益投研团队 | 高盛/摩根研究对接 |
| 易方达基金 | 国际固收团队（行业人数/经验前列） | — |
| 中银基金 | 海外宏观策略研究员专职配置 | — |

## 与能力圈拓展的关系

平台资源使基金经理能够：
- 在不熟悉的市场保持信息优势（李耀柱仅4年全球经验但可覆盖全球）
- 在原有专业领域外扩展策略（宁君从纯成长扩展至成长+高股息）
- 动态调整风险敞口（郑涛2020年后快速识别地产债风险并调整）

详见[[concepts/能力圈拓展]]。

## 边界条件

- 若基金公司战略调整、缩减海外研究投入，平台资源效应会衰减
- 若基金经理离职但平台和策略稳定，基金仍可延续；若核心人员离开且无接替，需警惕
