# 核心式投资组合

以指数/宽基为核心、卫星为补充的组合结构——用核心保证稳定性，用卫星捕捉超额收益机会。

## 核心-卫星结构

```
核心仓位（70-80%）：宽基指数基金、债券基金
  → 获取市场平均回报，低成本，低波动
  
卫星仓位（20-30%）：行业基金、主题基金、主动管理基金
  → 捕捉超额收益机会，承担更高风险
```

## 设计逻辑

1. **核心是基本盘**：保证组合在大多数情况下获得市场平均回报
2. **卫星是增强盘**：在核心稳定基础上，用小部分仓位尝试获取超额收益
3. **卫星亏损可控**：即使卫星仓位全部亏损，整体组合仍由核心支撑

## 与相关概念的关系

- [[concepts/资产配置比率]]：核心-卫星结构是资产配置比率的具体实现方式
- [[concepts/种田打猎资产配置法]]：类比关系——核心=种田（稳），卫星=打猎（博）
- [[concepts/3-5只基金充分分散原则]]：核心仓位通常用 1-2 只宽基基金，卫星仓位再用剩余名额分散
- [[concepts/集中度风险]]：核心仓位过度集中（如全部押一个行业指数）即构成集中度风险
- [[concepts/卫星持仓策略]]：卫星策略是该框架的延伸，强调卫星仓位的独立管理

## 操作要点

- 核心仓位确定后，长期持有，不因短期波动调整
- 卫星仓位可适度主动管理，但总规模不应超过预设上限
- 再平衡时优先调整核心仓位，卫星仓位可根据情况灵活处理
