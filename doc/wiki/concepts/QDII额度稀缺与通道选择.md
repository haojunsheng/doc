# QDII 额度稀缺与通道选择

QDII 额度稀缺是中国投资者配置海外资产的核心制度约束，催生了三条出海通道并存但各有短板的格局。

## 核心论断

**QDII 限购的根本原因是额度稀缺，而非基金公司主观意愿。**

- 截至 2024 年末，所有证券和基金公司累计获批额度仅 920 多亿美元
- 截至 2025 年 1 月，600 多只 QDII 基金中近六成已关闭申购
- 最近一次额度审批在 2024 年 5 月，申请需等待数月

## 三条出海通道及约束

### 1. QDII 基金

| 维度 | 特征 |
|------|------|
| 覆盖范围 | 全球市场 |
| 核心优势 | 投资范围最广 |
| 核心约束 | 额度紧张，近六成产品关闭申购 |

### 2. 香港互认基金

| 维度 | 特征 |
|------|------|
| 推出时间 | 2015 年 |
| 覆盖范围 | 亚太为主（中概股、亚洲、大中华） |
| 产品数量 | 40+ 只 |
| 核心约束 | 每只基金在内地销售规模 ≤ 总资产 80% |
| 产品类型 | 以主动管理为主，被动管理型稀缺 |

### 3. 跨境理财通

| 维度 | 特征 |
|------|------|
| 推出时间 | 2021 年 |
| 参与者 | 仅限大湾区居民（广州、深圳、珠海等 9 城） |
| 个人额度 | 300 万人民币/人（不占用外汇额度） |
| 产品数量 | 2000+ 只 |
| 投资范围 | 大中华区、北美、欧洲 |
| 产品类型 | 主动和被动均有 |
| 参与门槛 | 有投资经验和资产要求 |

## 选择框架

**形式化表达**：
```
选择 = f(投资目标, 自身条件, 产品特性)
```

**三条通道的匹配逻辑**：

| 投资者类型 | 推荐通道 | 原因 |
|-----------|---------|------|
| 大众投资者，可接受等待 | QDII | 覆盖最广，但需忍受限购 |
| 专注亚太配置 | 互认基金 | 专业度高，但选择有限 |
| 大湾区居民，追求额度充裕 | 跨境理财通 | 额度充足，产品丰富 |

**关键原则**：看基金实际投向，而非注册地。这与 [[穿透持仓]] 原则一致。

## 约束性质

三条通道的短板都是**制度性约束**，而非策略选择问题：
- QDII 的额度约束来自外汇局审批
- 互认基金的 80% 销售比例限制是监管规定
- 跨境理财通的地域限制是政策设计

这解释了"为什么我买不了 QDII"的根本原因——不是基金不好，而是通道稀缺。
