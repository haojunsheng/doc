# 左侧布局

在产业趋势确认但尚未被市场充分定价时提前介入的策略。与"右侧跟随"相对。

## 核心论点

左侧布局的本质是：**在赔率和预期收益率双高时介入，而非等市场共识形成后再追**。

## 形式化表达

```
产业政策判断 + 财务数据验证 → 左侧布局
⇒ 在产业趋势确认但未充分定价时介入
```

## 典型操作

[[黄珺]]的实践：
- 2022年下半年判断传媒和机器人产业趋势明确
- 从性价比角度减持医药、食品饮料、交运
- 左侧布局后：恺英网络涨245%，环旭电子翻倍

## 与相关概念的区分

| 概念 | 区别 |

| [[产业趋势误判风险]] | 左侧布局的核心风险：若产业判断错误则承受长时间浮亏 |

## 边界条件

- 若行业判断失误或左侧过早，可能承受较长时间浮亏
- 在纯题材驱动的A股市场中，左侧布局需要极强耐心和持有人理解
- 无法量化短期跑输的忍耐力阈值
