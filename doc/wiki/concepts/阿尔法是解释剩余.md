# 阿尔法是解释剩余

阿尔法的本质不是"基金经理的能力"，而是**所有因子模型都解释不了的收益残差**——一个动态收缩的"解释剩余"。

## 核心定义

**Alpha = 总收益 - 所有可解释的因子收益**

它不是固定的能力指标，而是随着因子模型的扩展不断被"侵蚀"的残差项。每一次新的因子被发现，曾经被认为是 Alpha 的部分就会被重新归类为 Beta。

## 历史演变

1. **1967 年：詹森阿尔法**
   - 定义：基金收益对市场收益线性回归的截距
   - 此时 Alpha = 总收益 - 市场贝塔收益
   - 几乎所有超额收益都被视为 Alpha

2. **1992 年：Fama-French 三因子模型**
   - 引入市值因子(SMB)和价值因子(HML)
   - 大量之前被认为是 Alpha 的收益被重新解释为风格暴露
   - Alpha 的边界大幅收缩

3. **2010 年代：多因子模型扩展**
   - 动量、质量、低波动等因子被发现
   - Alpha 继续被蚕食，解释剩余越来越小

4. **晨星的动态定义**
   - Alpha = "当前任何因子模型都无法解释的决策"
   - 定义本身就内嵌了自我消解的逻辑：今天的 Alpha 是明天的 Beta

## 关键洞见

- **Alpha 是后视镜概念**：过去的 Alpha 不代表未来的能力
- **Alpha 随模型扩展而消失**：不是基金经理变差了，而是我们的理解更深了
- **因子暴露常被包装成 Alpha**：小盘、成长等风格押注被当作"主动管理能力"收费
- **定义循环风险**：Alpha 越被追求，越难找到——它是投资的"圣杯"，但圣杯可能不存在

## 实践含义

承认 Alpha 可能是解释剩余的动态概念，意味着：
1. 不要过度解读历史 Alpha 数据
2. 警惕将因子暴露包装为 Alpha 的产品
3. 普通投资者应优先追求低成本贝塔，而非高费率的主动 Alpha
4. 2025 年初 A 股主动基金战胜率回升至 28%，本质是成长风格顺风而非能力回归
