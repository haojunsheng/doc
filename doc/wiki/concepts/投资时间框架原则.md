# 投资时间框架原则

投资决策应先于"买什么"回答"钱能闲置多久"——时间决定波动承受力，从而决定资产类别。

## 核心规则

**决策顺序：** 时间框架 → 配置比例 → 具体标的

```
时间短 → 波动承受力低 → 买低风险资产（纯债/短债/货币基金）
时间长 → 波动承受力高 → 买高收益资产（宽基指数/行业基金）
```

## 支撑数据：股票持有期-亏损概率递减规律

| 持有期 | 亏损概率（2005-2023 A 股） |
|--------|--------------------------|
| 1年    | ~50%                     |
| 5年    | ~25%                     |
| 10年   | ~11%                     |

逻辑：时间越长，市场经历完整周期的概率越高，即使短期遭遇下行也有足够时间回本。

## 理论基础：不可能三角

高收益、低风险、高流动性三者最多同时满足两个，任何投资决策都需在三者中做出取舍。时间框架是做出取舍的锚点。参见 [[concepts/不可能三角-收益风险流动性]]。

## 边界条件

1. **心理承受力优先：** 即使钱能闲置很久，若心理上扛不住波动，仍应选稳健资产。这一点与 [[concepts/能力圈风险]] 呼应——超出心理舒适区的配置，长期来看难以坚持。
2. **历史统计非因果：** 上述亏损概率数据来自2005-2023年中国 A 股市场，若推广到全球或其他市场需谨慎；长期经济停滞国家（如日本）不适用。
3. **阈值不明：** 资金量达到百万级别时"可适当增加产品数量"，但本文未给出具体阈值标准。
