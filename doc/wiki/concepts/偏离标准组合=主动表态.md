# 偏离标准组合=主动表态

任何对市值加权基准的偏离，本质上都是在主动表达投资观点——可能获得超额收益，也可能带来额外亏损。

## 核心命题

```
中性配置: 不表态
偏离基准: 主动表态 → 超额收益 or 额外亏损
```

## 理论基础

[[市值加权中性起点]] 指出，国际机构普遍以市值加权指数（如 MSCI 世界指数）作为基准，这对应的是威廉·夏普描述的"虚构全球投资者"——一个完全跟随全球市场权重、不做任何主动判断的理想化投资者。

现实中没有人是完全"平均"的。高配或低配某个市场、某种资产，本质上是在做主动决策。

## 判断框架

在决定偏离基准之前，投资者应该能够回答以下问题：

| 问题 | 如果答不出 | 含义 |
|------|-----------|------|
| 我为什么偏离？ | 说不清具体观点 | 可能是随波逐流，而非主动决策 |
| 我的偏离方向是什么？ | 不知道是高配还是低配 | 可能是随机行为 |
| 我有多少把握？ | 无法量化信心 | 偏离更多是赌博 |
| 如果错了，后果是什么？ | 没有预案 | 风险敞口不可控 |

## 与本土偏好的关系

[[本土偏好-量化框架]] 揭示了中国投资者系统性超配本国的现象——这本身就是一种大规模、持续性的主动偏离，但其决策过程往往缺乏上述框架的审视。

## 边界条件

- 如果对偏离的资产没有深入认知，偏离更多是赌博而非投资
- 市值加权本身可能被被动资金流入（ETF化）自我强化，导致偏离的边际成本越来越高
- 机械化的再平衡策略（如股债固定比例）不属于主动偏离，是规则化操作

## 核心结论

**标准模板是地图，不是目的地。** 偏离基准本身不是坏事，但偏离必须是有意识的主动表态，而非无意识的随波逐流。
