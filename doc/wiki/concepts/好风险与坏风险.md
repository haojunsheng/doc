# 好风险与坏风险

"好风险"与"坏风险"是日常语言对金融术语的改造——涨是"好"，跌是"坏"。这一区分是理解风险度量演进的核心线索。

## 核心区分

| | 好风险（上涨波动） | 坏风险（下跌波动） |
|---|---|---|
| 对投资者意味着 | 收益机会 | 本金损失 |
| 被标准差计入 | 是（惩罚） | 是（惩罚） |
| 被夏普比率计入 | 是（惩罚） | 是（惩罚） |
| 被索提诺比率计入 | 否 | 是（惩罚） |
| 被晨星风险系数计入 | 小权重 | 大权重 |

## 度量工具的演进逻辑

标准差和夏普比率把涨得猛的基金和跌得猛的基金视为同等风险，不符合投资者只关心下跌的真实偏好。索提诺比率修正了这一点——只用下行标准差。晨星风险系数进一步折中：不忽视好风险（给予较小权重），但给坏风险更大权重。

## 实践意义

晨星星级评级在同一收益下对"坏风险更少"的基金给予更高等级，说明评级机构在方法论上已经承认：好风险和坏风险不应对等对待。投资者在选基时，也应优先关注"坏风险"（下行保护）而非总波动。

## 与 [[波动率不是风险]] 的连接

[[波动率不是风险]] 指出波动本身不是风险，真正的风险是永久性亏损。好风险/坏风险的区分进一步完善了这一观点：即使是波动，也有性质之分——涨的波动不是敌人，跌的波动才是。
