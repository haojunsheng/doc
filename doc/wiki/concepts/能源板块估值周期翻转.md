# 能源板块估值周期翻转

## 定义

能源板块在较短时间内从"最被低估"翻转为"最被高估"的完整估值周期反转案例，由中东冲突引发油价飙升驱动。

## 翻转路径

```
2025年: 投资者对能源兴趣不高 → 能源板块最被低估 → 晨星建议超配
          ↓
      中东冲突升级 → 油价飙升
          ↓
      能源股年内+34% → 安全边际急剧收缩
          ↓
2026Q1: 能源板块变为最被高估 → 晨星建议部分止盈
```

## 作为杠铃策略的价值端止盈依据

能源板块从洼地到高估的完整翻转，验证了此前"超配能源"建议的正确性，同时也构成杠铃策略价值端的止盈信号——涨多了自然需要部分兑现。

## 与油价冲击的关系

该翻转正是[[油价冲击资产重定价传导链]]的一个实证案例，展示了外生冲击（地缘冲突→油价）如何快速重塑行业估值格局。

## 边界条件

若油价继续上涨，能源股可能仍有上涨空间；但"最被高估"意味着当前安全边际极低，新增配置风险较高。
