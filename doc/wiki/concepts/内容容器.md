# 内容容器

> 容器决定内容，形式大于内容。

来源：潘乱《乱翻书》。

## 核心命题

内容容器（产品形态）决定了内容的形态和质量。这不是修辞，是因果机制。

## 具体表现

- 单列容器 → 算法主导 → 内容为算法服务 → 创作者被动适应
- 双列容器 → 用户主导 → 内容为关系服务 → 创作者有可见度

## 与[[产品容器即世界观]]的关系

"内容容器"是"产品容器即世界观"的具体化——容器不只是UI，是价值观的物理表达。

## 与[[人就是最好的内容]]的关系

双列容器里，人是内容；单列容器里，算法是内容分发者。容器的选择决定了"谁是最有价值的节点"。
