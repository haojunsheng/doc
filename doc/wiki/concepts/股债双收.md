# 股债双收

股票与债券市场在同一时期内同时上涨的现象。表面看是"双赢"格局，但内部结构往往存在显著分化，且通常是政策共振驱动的罕见窗口，而非市场自发均衡。

## 核心特征

股债双收通常由以下组合驱动：
- **股市端**：风险偏好修复（地缘降温、政策利好、盈利预期改善）
- **债市端**：流动性宽松（央行操作稳健、资金面充裕、利率下行）

**关键区分**：股债双收 ≠ 股债跷跷板失效。它是特定政策组合下的暂时状态，边界条件清晰。

## 形式化表达

```
股债双收 = f(政策共振)
        = f(外部外交信号 + 内部货币政策 + 产业政策)
        → 风险偏好↑ + 流动性↑ → 股债同涨
```

## 实证案例

### 2025年6月：政策三重共振

| 驱动因素 | 类型 | 市场影响 |
|---------|------|---------|
| 中美元首通电（6月5日） | 外交 | 风险偏好提升 |
| 陆家嘴论坛（深化科创板） | 产业 | 科技成长领涨 |
| 央行买断式逆回购1万亿 | 货币 | 国债收益率下行2-12bp |

**结果**：A股主要指数涨2-5%，中证全债指数涨0.59%，可转债基金涨3.34%。

**数据来源**：[[sources/5-notes--34-20260614t213808-qa-六月股债双收下的基金选择qa--cstlca]]

### 2026年4月：地缘降温+政策利好

| 驱动因素 | 类型 | 市场影响 |
|---------|------|---------|
| 美伊停火协议 | 地缘 | 风险偏好修复 |
| 政治局会议释放积极信号 | 宏观 | 信心提振 |

**结果**：成长风格（+14.31%）碾压价值风格（+1.89%），固收+吃肉而纯债喝汤。

**数据来源**：[[sources/5-notes--50-20260614t213230-qa-china-fund-market-april-2026qa--ujoiyl]]

### 2024年11月：政策利好+经济企稳

| 驱动因素 | 类型 | 市场影响 |
|---------|------|---------|
| 10月CPI同比+0.2%（前值+0.1%） | 经济数据 | 企稳信号 |
| 降准降息预期 | 货币 | 债市受益 |
| 科技创新政策支持 | 产业 | 中小盘成长领涨 |

**结果**：A股主要股指整体上涨，固收基金集体收涨，中小盘成长风格领涨。

**数据来源**：[[sources/5-notes--29-20260614t220941-qa-11月股债双收qa--bb0mw7]]

## 与[[股债分化]]的关系

两者构成镜像关系：

| 维度 | 股债双收 | 股债分化 |
|------|---------|---------|
| 市场状态 | 罕见窗口 | 常态模式 |
| 驱动因素 | 政策共振 | 利率周期转换/外部冲击 |
| 投资者行为 | 普遍受益 | 策略分化 |
| 持续性 | 短期 | 中期 |

**核心洞见**：股债双收是例外，股债分化才是常态。投资者不应将双收窗口期误判为长期趋势。

## 结构差异警告

股债双收不等于"所有基金都赚钱"。以2025年6月为例：

| 类别 | 月涨幅 | 说明 |
|------|--------|------|
| 偏股型基金 | +5-6% | 成长风格占优 |
| 可转债基金 | +3.19% | 股债双重受益 |
| 纯债型基金 | +0.22% | 利率下行受益 |
| 通信板块 | +9%以上 | 算力政策催化 |
| 食品饮料 | -3%以上 | 内需疲软拖累 |

**风险提示**：投资者容易在"总量上涨"的幻觉中忽略持仓的实际风险敞口，这与[[信任危机-投资中的不知道自己拥有什么]]直接相关。

## 边界条件

股债双收格局在以下条件下会被打破：
1. 地缘冲突升级（如中美摩擦重新加剧）
2. 央行收紧流动性（买断式逆回购到期后不再续作）
3. 经济数据超预期恶化（信用利差走阔）
4. 政策低于预期（如降准降息落空）

**历史参照**：2026年3月（[[sources/5-notes--50-20260614t213315-qa-china-fund-market-march-2026qa--12lmc58]]）即呈现"地缘冲击下的股债分化"，与6月形成鲜明对比。2024年11月之后，市场也出现分化迹象，印证了"这种理想场景不会永远持续"的判断。

## 投资决策启示

1. **识别窗口期**：股债双收是短期机会，不应作为长期配置的基准假设
2. **关注结构**：双收期间的风格分化往往预示后续分化方向
3. **固收+策略**：双收时舒适，分化时痛苦，需提前关注[[固收加的权益暴露度权衡]]
4. **可转债优势**：在股债双收格局中，可转债基金因双重属性往往表现最优
