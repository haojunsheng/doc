# 债券稳定器

债券稳定器是指在资产配置中，以债券类资产（尤其是纯债基金）降低组合整体波动、提供稳定收益回报的角色定位。

## 核心命题

```
资产配置 = 纯债基金（稳定器） + 股票基金（增长引擎） → 风险调整后收益↑
```

纯债基金通过提供稳定的票息收入和较低的波动性，在组合中承担"稳定器"功能，抵消股票资产的剧烈波动。

## 工作机制

| 机制 | 说明 |
|------|------|
| 票息稳定器 | 债券票息提供持续现金流，不受股市波动影响 |
| 波动平滑器 | 股债低相关性（常态下）降低组合整体波动 |
| 再平衡素材 | 股跌债涨时，可卖出债券买入股票，实现低买高卖 |
| 心理稳定器 | 低波动组合减少投资者恐慌性赎回 |

## 与纯债基金的关系

[[纯债基金]] 是债券稳定器的主要载体，因其不投资股票，波动来源单一（主要是利率和信用风险），更符合稳定器的定位。

详见 [[纯债基金]]。

## 边界条件

**稳定器失效的场景**：

1. **股债双杀**：通胀+加息或政策脉冲+外部冲击等环境下，股债同跌，稳定器作用减弱
   - 详见 [[股债双杀]]

2. **利率大幅上升**：债券价格下跌，纯债基金也受影响
   - 与 [[久期操作]] 相关，久期管理可部分对冲但非万能

3. **信用危机**：信用下沉策略下，低评级债券违约造成损失
   - 与 [[信用下沉]] 相关

4. **投资者行为风险**：即使纯债基金波动小，若投资者无法承受任何回撤，仍可能提前割肉
   - 与 [[回撤控制机制]] 相关

## 资产配置中的应用

| 投资者类型 | 债券稳定器占比建议 | 说明 |
|-----------|------------------|------|
| 低风险承受 | 60%~80% | 以稳定为主 |
| 中等风险承受 | 40%~60% | 股债平衡 |
| 高风险承受 | 20%~40% | 以增长为主 |

实际配置需结合 [[资产配置比率]]、[[再平衡]] 纪律执行。
