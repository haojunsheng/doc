# 薪酬递延机制

《基金管理公司绩效考核管理指引》（2026版）规定的薪酬延迟支付制度，将绩效薪酬的实际到手时间延后2-5年，并与风险事件挂钩实现追索扣回。

## 制度设计

**基本规则**：
- 递延支付不少于3年
- 起付不早于T+2年（即至少延后2年）
- 支付节奏不快于等分发放
- 董事长、高管、核心人员递延比例≥40%

**时间轴**：
```
当年绩效 → T+2年开始发放 → 至少3年等分发放 → 实际到手延后2-5年
```

**追索扣回**：3年内若出现风险事件，未发放部分可被追索扣回。

## 设计意图

将风险与收益跨周期匹配，避免基金经理在短期内"赚快钱、拿高薪"而后留下风险敞口由投资者承担。

## 边界条件

- 若递延期间基金公司被并购或业务调整，递延支付的执行和追索可能面临法律障碍
- 递延机制无法区分"运气好"和"能力强"的经理——两者都在同一时间窗口内获取薪酬
