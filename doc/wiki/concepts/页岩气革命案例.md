# 页岩气革命案例

## 核心定义

2010年代美国页岩气革命使美国从能源第一大进口国变为出口国，但美元升值20%完全抵消了其他行业的出口竞争力提升，整体贸易逆差未变。这是[[关税自我抵消机制]]的历史反证案例。

## 传导路径

```
页岩气革命 → 能源出口↑ → 美元↑20% → 其他行业出口↓ → 整体逆差没变
```

## 关键事实

| 阶段 | 能源地位 | 汇率影响 |
|------|---------|---------|
| 革命前 | 能源第一大进口国 | — |
| 革命后 | 能源出口国 | 美元升值20% |
| 净效果 | 能源逆差改善 | 其他行业出口受损，逆差被对冲 |

## 理论意义

- 单一部门的出口竞争力提升，会被汇率渠道完全抵消
- 验证了[[经常账户-资本流入恒等式]]：资本净流入不变，经常账户赤字不变
- 支持"关税无法单独改变逆差"的命题

## 边界条件

如果那次美元升值幅度较小，或者美国制造业竞争力足够强，结果可能不同。
