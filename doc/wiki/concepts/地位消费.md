# 地位消费

消费作为维持社会位置的手段，导致"收入↑→支出↑→储蓄率难以上升"的系统性陷阱。

## 核心机制

```
相对收益 → 消费 = 地位信号
消费水平 ∝ 参照群体消费水平
收入↑ → 参照群体消费↑ → 我的消费↑ → 储蓄率维持低位
```

## 典型表现

- 升职加薪后换车——因为同事换了新车
- 换车后参与出国游——因为同事开始讨论旅行
- 消费不是为了满足需求，而是为了"不掉队"
- 掉队的标准由别人定义，而非自己

## 与储蓄率的关系

地位消费是解释"高收入者也是月光族"的关键机制：赚得多，但花得更多，因为维持地位的成本同步上涨。

## 边界条件

- **地位消费是投资的场景：** 律师、金融、娱乐圈等职业，消费水平直接影响职业机会
- **多数人高估了消费对职业的影响**

## 与相关概念的关系

- **[[相对收益-绝对收益]]** — 地位消费是相对收益思维在消费端的连锁机制
- **[[享乐适应]]** — 地位消费依赖的外部参照系随时间上移，形成消费层面的"跑步机效应"
- **[[足够-财务满足的临界点]]** — 定义自己的"足够"是打破地位消费循环的关键
