# 关税行业冲击分化框架

## 核心定义

关税等外部政策冲击对不同行业的冲击差异巨大，不可一概而论"关税冲击大"或"关税冲击可控"。冲击方向取决于三个维度：海外产能本地化程度、营收依赖度、企业所处商业模式阶段。

## 形式化框架

```
关税冲击程度 = f(美国本地产能占比, 美国营收依赖度, 商业模式阶段)

家电行业（海外建厂早）:   冲击 ≈ 0     ← 海尔(60%本地产能)
家电行业（海外建厂晚）:   冲击中等     ← 美的(5%本地产能)
新能源车（出海扩张期）:   冲击较大     ← 比亚迪(北美5-10%依赖)
烧钱电商（补贴抢份额）:   反向利好     ← Temu(订单减=补贴减=亏损缩)
```

## 三类行业表现

### 1. 海外布局成熟的行业（冲击弱）

家电行业经历2018年贸易战已提前完成海外建厂和转口贸易布局。[[海尔]]美国销售30%中60%本地生产，几乎无关税冲击。

### 2. 出海初期的行业（冲击较强）

新能源车行业整体海外渗透率仍低，[[比亚迪]]北美营收占5-10%，关税上调直接拖慢扩张进度。上游锂矿因需回国内加工，潜在冲击更大。

### 3. 特殊商业模式（逆向效应）

烧钱阶段的跨境电商（如[[Temu]]），关税导致订单减少反而减少补贴支出、收窄亏损。边界条件：进入盈利阶段后此效应消失。

## 核心命题

> 关税整体可控，行业分化明显，情绪比基本面更危险。
