# 汇率股市共振非因果

人民币汇率与A股走势呈现同步波动（同涨同跌），但**二者之间不存在直接因果关系**，而是受共同驱动因素影响的结果。这是一个典型的"相关≠因果"认知陷阱。

## 核心机制

```
共同因素(经济预期/政策/风险偏好)
    ├──→ 汇率（人民币）
    └──→ 股市（A股）
```

两者是"兄弟"关系而非"父子"关系——共同受到第三个因素的驱动，而非互相导致。

## 驱动共振的共同因素

| 因素 | 对汇率影响 | 对股市影响 |
|------|----------|----------|
| 经济预期向好 | 资本流入，人民币升值 | 企业盈利预期改善，股市上涨 |
| 宽松政策出台 | 流动性增加，本币走强 | 市场风险偏好提升，股市上涨 |
| 风险偏好上升 | 外资流入新兴市场，本币升值 | 权益资产受追捧，股市上涨 |
| 中美关系改善 | 地缘风险溢价下降，人民币升值 | 外资回流，股市上涨 |

## 常见认知偏差

**偏差**："人民币升值 → A股必然涨" 或 "人民币贬值 → A股必然跌"

**纠偏**：这种推论忽略了两者共享的第三变量。若仅因汇率变动就推断股市方向，会忽略真正的驱动因子（如国内政策、经济数据、全球风险偏好）。

**边界条件**：若资本管制加强或市场结构变化，汇率-股市相关性可能减弱。

## 操作含义

- 不要根据汇率走势直接推断股市方向
- 分析汇率-股市共振时，应追溯共同驱动因（经济预期、政策、风险偏好）
- 在人民币走强背景下投资A股，需验证内因（经济复苏）是否扎实，而非仅看汇率
