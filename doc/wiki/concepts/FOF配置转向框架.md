# FOF配置转向框架

**FOF配置转向框架**指2025年Q3以来，FOF（基金中基金）资产配置从"稳打底"向"攻守兼备"转型的五大结构性变化。该框架揭示了专业机构投资者在利率上行、低票息环境下的系统性配置迁移。

## 核心命题

> FOF在2025年Q3画出了一张"攻守兼备"的配置图谱：短债打底 + 债券场内外切换 + 黄金入基准 + 权益偏成长 + 海外互认债博票息。规模创历史新高背后，是底层配置的结构性转向而非简单的资金流入。

## 五大配置转向

### 1. 短债打底：利率上行期的久期防御

```
利率↑ → 组合久期↓需求↑ + 短债=流动性缓冲 → 短债基金被疯抢
```

- [[entities/海富通]] 中证短融ETF被67只FOF重仓，持仓从18亿升至33亿
- 17只FOF持有该基金比重在10-20%之间
- 短债同时提供流动性缓冲，应对赎回压力

**边界条件**：若利率转为下行，FOF可能减持短债重新拉长久期。

### 2. 债券配置：从场外转向场内

```
场外债基<6个月赎回费≥0.5% → FOF转向场内债券ETF
```

- 2025年9月5日销售费用规定征求意见稿出台
- 场外债基持有期不满6个月需支付至少0.5%赎回费
- FOF重仓前十债券型基金基本均为场内ETF
- 这是政策 unintended consequence：抑制短期交易的规则扭曲了机构配置行为

**边界条件**：若最终规定豁免FOF的赎回费或降低费率，场外配置可能回流。

### 3. 黄金纳入FOF基准：从保险到配置品种

```
新规鼓励多元化基准 → 80%+ FOF基准加入黄金（Au99.99）
```

- FOF实际持有黄金基金总市值达28亿元
- [[entities/华安易富黄金ETF]] 持仓17.3亿
- 部分FOF还加入商品期货指数作为基准组成部分

**与[[concepts/黄金保险定位框架]]的关系**：该框架将黄金定位为"保险"，但FOF实际将其 as 配置品种纳入基准（80%+）。这说明专业投资者对黄金的定位与普通投资者的认知存在差异——保险是功能定位，配置是操作行为。两者并不矛盾，而是互补视角。

**边界条件**：若金价持续回调或FOF业绩基准不再考核黄金配置，持仓可能下降。

### 4. 权益风格切换：从价值到成长

```
成长风格（易方达科融/智造/兴全合润）持仓↑ ⊥ 价值风格（大成高鑫、国富中小盘）大幅减持
```

- [[entities/大成高鑫股票]] 从被169只FOF持有（8.96亿）降至14只（0.88亿）
- [[entities/国富中小盘]] 从被35只FOF持有降至无FOF重仓
- 被减持基金最近两年投资风格均偏价值
- 成长风格基金持仓提升

**边界条件**：若市场风格从成长切回价值，FOF可能重新增配价值基金。

### 5. 海外债配置：香港互认债基博票息

```
国内利率↓ → 境内债息↓ ⊃ 香港互认债基（票息↑）→ FOF持有33.76亿
```

- [[entities/摩根国际债券基金]] 被23只FOF重仓，持仓4.08亿
- 低利率环境下互认债基提供较高票息
- 这是获取海外票息增厚的配置路径

**边界条件**：若国内利率上行或香港市场风险上升，FOF可能减持互认基金。

## 规模增长来源

```
新发FOF募集火爆（富国65亿/东方红60亿） + 存量FOF持营爆发（中欧+68亿/华安+60亿/博时+59亿） → 规模2001亿创新高
```

**关键观察**：规模创新高主要来源于存量持营（如中欧+68亿），而非新资金追高权益。这解释了为什么权益持仓从价值大幅撤出但规模仍在增长。

## 框架的开放问题

1. FOF规模创新高是否与政策推动（如个人养老金账户推广）有关？
2. 黄金纳入基准后，其"保险"定位与"配置"定位的张力如何演化？
3. 赎回费政策若最终豁免FOF，债券配置会回流场外吗？
4. 成长风格的集中是否意味着FOF在追踪市场共识而非独立判断？
