# 事前分类与事后分类

## 定义

**事前分类**（Ex-ante Classification）和**事后分类**（Ex-post Classification）是基金分类的两种方法论，其核心区别在于分类数据的来源与时间指向。

```
事前分类 = f(基金名称, 契约承诺)
事后分类 = f(实际持仓, 过去三年数据)
```

## 两种方法对比

| 维度 | 事前分类 | 事后分类 |
|------|---------|---------|
| 数据来源 | 基金名称、招募说明书、契约承诺 | 过去三年的实际持仓数据 |
| 时间指向 | 基金"宣称"做什么 | 基金"实际"做了什么 |
| 适用对象 | 所有基金，包括新基金 | 成立超过三年的基金 |
| 优点 | 操作简单，覆盖面广 | 反映真实投资行为，不受"包装"误导 |
| 缺点 | 容易被"风格漂移"误导 | 存在滞后性，对频繁换仓的基金可能误判 |
| 典型代表 | 市场通用做法 | 晨星基金分类体系 |

## 实证案例：沪港深基金

2025年6月晨星分类回顾的典型案例：
- 恒生指数年内涨 **24.8%**
- 650+ 只"沪港深基金"港股实际持仓极低，有的甚至为零
- 晨星将这些基金从"沪港深"类别调整回"积极配置"或"大盘股票"类别
- 调整率：**1920 / 13530 ≈ 14.2%**

这说明事前分类（看名称/契约）与事后分类（看持仓）之间存在显著背离。

## 债券基金的二级分类

事后分类还能识别债券基金的"隐性偏好"：
- 170 只表现出利率债或信用债明显偏好的债券基金被重新归入"利率债基"或"信用债基"
- 这是对现有分类体系的重要补充——仅看契约承诺无法识别这类偏好

## 适用边界

| 场景 | 推荐方法 | 原因 |
|------|---------|------|
| 新基金（成立不足三年） | 事前分类 | 无足够历史持仓数据 |
| 风格稳定的基金 | 两种方法均可 | 结果相近 |
| 风格可能漂移的基金 | 事后分类优先 | 能捕捉实际持仓偏离 |
| 组合构建时的风格检查 | 事后分类 | 避免"伪分散" |

## 与晨星投资风格箱的关系

[[晨星投资风格箱]] 反映的是**当前持仓**风格（更接近"现在"），而[[晨星基金分类]] 反映的是**过去三年平均**风格（更接近"事后分类"）。两者结合使用，可以更早发现风格漂移：

```
风格箱（现在）≠ 基金分类（过去三年平均） → 风格漂移信号
```

## 核心洞见

投资中最重要的不是"基金叫什么"，而是"基金在买什么"。事前分类回答"它承诺做什么"，事后分类回答"它实际上做了什么"——后者才是投资者应依赖的判断基础。

> **原则**：先看分类，再看星级；看分类看持仓，不看名字看契约。
