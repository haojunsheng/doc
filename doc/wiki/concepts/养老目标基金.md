# 养老目标基金

个人养老金制度下的重要配置工具，分为目标日期和目标风险两类，核心选择原则是"适合"而非"业绩最好"。

## 两种类型

| 类型 | 机制 | 适用人群 |
|------|------|---------|
| [[目标日期基金]] | 随退休日期临近自动降风险（下滑路径） | 希望省心、有明确退休日期 |
| [[目标风险基金]] | 保持固定风险等级 | 有风险判断能力、愿意主动管理 |

## 选择框架：五维评估

### 维度一：目标日期 vs 目标风险

根据退休日期和风险偏好选择类型，而非盲目追业绩排名。

### 维度二：基金经理能力圈

养老 FOF 经理需要双重能力圈：

```
养老 FOF 经理 = 资产配置经验 + 底层资产认知 → 两者缺一不可
```

| 经理 | 背景 | 能力侧重 |
|------|------|---------|
| 桑磊（中欧） | 16 年，保险组合 | 基金研究 + 底层资产 |
| 蒋华安（工银） | 15 年，社保基金理事会 | 大类资产配置 |

两种能力圈均有效，不存在唯一正确路径。

### 维度三：风险调整后收益（夏普比率）

用[[夏普比率]]替代单纯业绩排名：

```
夏普比率 = (基金收益 - 无风险利率) / 波动率 → 越高越好
```

- 万家鑫璟 2020 年前 2% 但波动高；工银纯债短期排名靠后但中长期稳健
- 两只基金夏普比率均位于同类前 10%——风险调整后收益出色
- 边界：夏普比率假设正态分布，对极端事件（黑天鹅）风险评估有限

### 维度四：费率结构

```
养老 FOF 费率 = 管理费 + 托管费 + 底层基金费率 → 双重收费问题
```

- 监管要求养老 FOF 费率优惠以鼓励长期投资
- 持有期越长，费率优惠越大（如 5 年以上免申购费）
- 边界：费率不是唯一考量，过度追求低费率可能错过优秀基金

### 维度五：个人因素评估

```
养老规划 = f(退休年龄, 风险偏好, 资产状况, 收入预期) → 个性化配置
```

| 因素 | 影响 |
|------|------|
| 退休年龄 | 决定目标日期（如 2035 对应 75 后） |
| 风险偏好 | 决定选择目标日期还是目标风险、选择哪一风险等级 |
| 已有资产 | 决定补充缴费力度（已有企业年金可少缴，无则多缴） |
| 收入稳定性 | 决定缴费上限（最高 12000 元/年） |
| 预期寿命 | 影响资金规划期限 |

## 核心主张

> 养老目标基金不是"选业绩最好的"，而是"选最适合自己的"——综合考虑退休年龄、风险偏好、费率、基金经理能力圈，以及最重要的：长期坚持定投，让复利发挥作用。

## 边界条件与警示

- 夏普比率不能替代完整业绩分析，仅作为辅助指标
- 目标日期基金的下滑路径假设（所有人退休后需求相同）存在简化
- 双重收费框架下需警惕[[基金公司利益冲突]]带来的销售导向问题
- 养老规划是长期过程，需定期评估和调整；年轻时更激进，临近退休应更保守
