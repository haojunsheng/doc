# Computer Use 五原语

## 定义

Computer Use（计算机使用）与机器人共享的五组原语，横跨多模态交互的同构结构。这五原语让 Agent 能在物理世界和数字世界中使用相同的控制抽象。

## 五原语

| 原语 | 描述 | Computer Use 示例 | 机器人示例 |
|------|------|------------------|-----------|
| 唤醒 | 从待机/空闲状态激活 | 点击桌面图标打开应用 | 唤醒机器人启动任务 |
| 安全点 | 在执行关键操作前确认安全 | 弹窗确认删除文件 | 急停按钮 |
| 取消 | 中断正在进行的动作 | ESC 键取消操作 | 停止机械臂 |
| 抢占 | 更高优先级任务抢占当前任务 | 来电打断正在编辑的文档 | 障碍物检测强制避让 |
| 快慢分离 | 快速反应通道 vs 慢速推理通道 | 快捷键即时响应 vs LLM 推理 | 反射弧 vs 规划 |

## 与 SoM（State of Machine）的关系

Computer Use 的瓶颈从"能不能完成任务"转向"动作后现实是否仍与计划一致"。SoM 定位是验证现实与计划一致性的机制。

## 同构结构的价值

五原语横跨多模态的意义在于：
1. 同一个 Agent 架构可以同时在软件和硬件上运行
2. 开发工具链可以复用
3. 用户交互模式统一（唤醒/取消/抢占的逻辑一致）

## 验证方式

对比 Computer Use 的 SoM 定位与机器人的 observe→pick→verify_state 工具契约，找出同一组原语的实现差异。
