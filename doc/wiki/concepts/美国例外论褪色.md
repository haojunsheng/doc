# 美国例外论褪色

"美国例外论"指美国经济增长、政策稳定性和制度可信度相对于其他发达经济体的独特优势。这一优势正在系统性消退，是美元十年涨势终结的根本原因，也是全球机构调整美国资产配置的核心叙事。

## 核心逻辑

```
美国例外论褪色 = 经济优势↓ + 政策稳定性↓ + 制度可信度↓
         ↓
   美元贬值压力 + 全球机构减持美国配置
```

"美国例外论"曾是美元长期走强的底层支撑叙事。当这一叙事褪色，美元从"默认首选"变为"普通选项之一"。

## 表现维度

### 1. 经济优势收敛

- 美国经济增长势头逐步放缓，美联储高利率对抗通胀效果不显著
- 联邦债务与利息支出持续攀升，财政可持续性存疑
- 经常账户赤字占GDP比重不断上升，结构性失衡持续

### 2. 政策不确定性上升

- 关税政策反复变调，市场难以形成稳定预期
- 美联储独立性受政治干预威胁（试图罢免理事、施压降息）
- 选举周期带来的政策摇摆风险

### 3. 制度信任松动

- 2025年4月美元避险光环失效——股市抛售时美元同步大跌
- 全球投资者开始基于汇率变化主动调整配置，而非被动持有
- "财政主导"担忧升温：财政政策压倒货币政策的格局出现苗头

## 边界条件

1. 美国例外论褪色是渐进过程，非断崖式变化——短期仍可能有反弹
2. "例外论"的对比对象是其他发达经济体；若欧洲或中国出现更大问题，美元例外论可能暂时回潮
3. 本概念是定性叙事框架，缺乏统一的量化指标——不同分析师对褪色程度可能有分歧
