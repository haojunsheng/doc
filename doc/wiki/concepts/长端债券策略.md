# 长端债券策略

在2026年债市中，长端和超长端债券被视为潜在的"胜负手"——因市场线性外推偏好中短端，导致长端定价可能存在错误机会。

## 形成机制

```
市场习惯性看好中短端
× 中短端信用利差≈0（已压缩到极致）
→ 长端/超长端反而有定价空间 = 胜负手
```

## 触发条件

- 资金面转松 → 引发宽松预期 → 超长期利率债出现交易机会

## 边界条件

- 若通胀超预期上行 → 长端利率可能不降反升
- 若政府大量发行超长端债券 → 供给冲击压制价格
