# 香港互认债基配置

**香港互认债基配置**指2025年Q3 FOF通过香港互认基金获取较高票息收益的配置行为，是[[concepts/FOF配置转向框架]]五大转向之一。

## 核心机制

```
国内利率↓ → 境内债息↓ ⊃ 香港互认债基（票息↑）→ FOF持有33.76亿
```

## 实证数据

- FOF持有香港互认基金总市值33.76亿
- [[entities/摩根国际债券基金]] 被23只FOF重仓，持仓4.08亿
- 低利率环境下互认债基提供较高票息

## 配置逻辑

在国内利率持续下行、境内债券票息压缩的背景下，香港互认债基成为FOF获取票息增厚的海外配置路径。

## 边界条件

若国内利率上行或香港市场风险上升，FOF可能减持互认基金。
