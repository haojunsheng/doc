# 楼市转折点——供给收缩驱动的出清收尾

**楼市转折点（供给收缩驱动的出清收尾）**是指中国房地产市场在经历四年深度调整后，由供给端主动收缩（新开工↓、拿地↓）推动供需重新平衡，而非需求端爆发驱动的新一轮上涨周期。晨星判断2027年新房价格将率先企稳，但本质是"止跌"而非"反转"。

## 核心机制

```
供给侧收缩（新开工↓25% + 拿地↓49%）
  → 库存增幅收窄（19%→5%）
  → 竣工 > 新开工（未来供给自然减少）
  → 供需再平衡
  → 价格企稳（2027年新房）
```

## 四大量化信号

| 信号 | 当前状态 | 含义 |
|------|---------|------|
| 库存增幅收窄 | 19% → 5%（2025Q4） | 库存增速趋零，见顶前置信号 |
| 竣工 > 新开工 | 竣工↓23% < 新开工↓25% | 未来新增供给自然减少 |
| 房价收入比下降 | 11 → 9.6 | 购房门槛实质性降低 |
| 库存销售比下降 | 3.3 → 2.6（2030年预测） | 供需再平衡推进中 |

## 与2016年的本质区别

| 维度 | 2016年 | 2027年（预测） |
|------|--------|--------------|
| 驱动因素 | 需求侧刺激（棚改货币化） | 供给侧收缩（主动去产能） |
| 市场表现 | 暴涨（新一轮大牛市） | 企稳（止跌，非反转） |
| 政策范式 | 需求端刺激主导 | 供给侧管控+需求端托底并存 |
| 后续空间 | 价格翻倍 | 回归理性区间 |

## 新房vs二手房时间线差异

- **新房**：2027年均价筑底（供给端可控，收缩效果直接）
- **二手房**：2028年后才可能跟上（受增值税下调增加供给、新房品质提升替代效应双重压制）

## 边界条件

1. 若销售同比跌幅超30%，库存可能重新累积，企稳时点延后
2. 若去库存政策执行不力或房企资金链断裂抛售，出清节奏被打乱
3. 若收入预期持续恶化，房价收入比改善不足以转化为实际需求
4. 若核心区新房供应减少或二手税费进一步下调，二手房可能提前企稳

## 与投资的关系

- 开发商股价重估逻辑建立在"供给收缩→价格企稳→利润修复"的预期链上
- 2027年是验证此逻辑的关键窗口
- 区分"企稳"与"反转"是判断地产股是否值得配置的核心前提
