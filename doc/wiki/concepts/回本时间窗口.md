# 回本时间窗口

从崩盘低点到市场重回前期高点所需的时长，是衡量一次崩盘严重程度的关键量化指标。

## 核心定义

```
回本时间窗口 = 市场低点日期 → 市场重回崩盘前高点日期
```

回本时间窗口与市值蒸发比例共同构成 [[concepts/痛苦指数]] 的两个维度。

## 历史数据

| 崩盘事件 | 市值蒸发 | 回本时间窗口 |
|----------|---------|-------------|
| 1929年大崩盘 | 89% | 4年+ |
| 2000年互联网泡沫（单次） | ~50% | ~2年（但被2008年叠加打断） |
| 2000—2008叠加崩盘（纳斯达克） | 累计至46（相对高点） | 12年 |
| 2020年熔断 | 19.6%（1个月） | 4个月 |

## 关键规律

1. **回本时间 ≠ 跌幅的线性函数**：2020年跌幅不小（19.6%）但仅4个月回本；1929年跌幅89%需4年+回本。真正决定回本时长的关键是**经济结构冲击的深度**而非单纯跌幅
2. **叠加崩盘使回本时间非线性放大**：2000—2008年纳斯达克从半年腰斩到12年回本，叠加效应使回本窗口延长了6倍以上
3. **政策干预显著缩短回本窗口**：2020年快速政策响应是4个月回本的关键因素

## 投资含义

- 回本时间窗口是判断"这次崩盘有多严重"的最直观标准
- 投资者应评估自身资金是否能在回本窗口内保持在场——若资金期限短于回本窗口，权益资产的波动会带来真实损失（而非账面浮亏）
- 叠加崩盘情境下，若投资者能在第一次崩盘后保持仓位并在低位加仓，可大幅缩短实际回本时间
