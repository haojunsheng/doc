# 秩序搬运

基金本身不创造阿尔法，只是把底层指数的收益、波动、汇率风险、额度约束原样转移给投资者的现象，称为"秩序搬运"。

## 核心定义

QDII联接基金本质上是多一层包装的通道：

```
投资者 → 联接基金（管理费+托管费）→ 目标ETF → 指数成分股 → 底层资产收益
```

每一层都只增加摩擦成本，不增加价值。真正的价值来源是底层指数及其成分股的经营质量。

## 判定方法

用"秩序创造机器"框架判断一只基金：

1. **飞轮在不在转？** — 基金自身有无自我强化的收益机制？
2. **冲击后变强还是变弱？** — 面对市场冲击，基金是收缩还是扩张？
3. **资源是被推过来的，还是自己来的？** — 资金是被产品吸引，还是被底层资产吸引？

对于QDII联接基金，答案通常是：基金本身没有飞轮，底层资产才有。

## 典型场景

- QDII联接基金：费率0.8%-1.0%/年，本质是跨境通道
- 指数基金联接产品：管理费叠加，但阿尔法为零
- 场内ETF vs 场外联接：前者少一层包装，后者多一层限额
- 主动债券增强基金：通过信用利差、久期调整、可转债增强等方式"搬运"债券市场既有收益源

## 债券增强基金的秩序搬运

广发增强债券A（013997）是秩序搬运在债券领域的典型案例。其循环是：基金经理判断宏观利率和信用利差 → 配置金融债、企业债、中票、国债、可转债等资产 → 赚取票息、利差收敛、久期变化和少量可转债弹性 → 用历史业绩吸引资金。

**判定：秩序搬运，不是秩序创造。** 它不创造新秩序，而是在旧秩序里做更细的搬运和定价——把债券市场的期限、信用、流动性和少量转债弹性重新组合，提供给普通投资者一个比纯债略活跃的固收载体。

### 判定理由

1. **没有飞轮**：强弱依赖基金经理判断，而非产品网络自增长。
2. **冲击后不会变强**：2023-2024连续跑输基准，说明主动策略并非每年稳定胜出。
3. **资源不是自己来的**：规模剧烈波动，机构资金进出主导（A类机构占比超90%），不是自然吸引形成的流量资产。

## 投资启示

买基金时，要清楚自己在买什么（底层资产机制或基金经理的真实阿尔法），而不是在哪里买（哪只基金）。基金名称和品牌往往是通道属性，真正的价值来源要么是底层指数的经营质量，要么是基金经理稀缺的能力。

秩序搬运不等于"没用"——对于无法直接持有海外资产的人民币投资者，联接基金是唯一合规通道；对于想要比普通现金管理稍高收益的投资者，主动债券增强产品可以承担一部分中低风险收益增厚功能。问题在于：费用是否合理、能力是否可持续、时机是否合适。
