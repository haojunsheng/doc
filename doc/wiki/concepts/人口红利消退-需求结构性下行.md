# 人口红利消退——需求结构性下行

人口结构变化作为长期需求逆风，适用于白酒、地产、养老等多个行业。

## 核心机制

```
人口↓ × 饮酒率↓ → 销量↓（长期不可逆）
```

2017 年起生育率持续下降，叠加年轻一代饮酒率走低，形成对白酒等依赖人口红利的行业的**双重挤压**。这不是短期周期性波动，而是结构性趋势。

## 白酒行业的具体表现

- 销量增长停滞甚至下降，企业转向提价维持收入增长
- 晨星预测行业收入 CAGR 仅 3.5%，低于过去十年的 4.2%
- 高端化提价是对冲量跌的主要手段，但提价能力有边界

## 跨行业适用性

| 行业 | 人口红利消退的影响 |
|------|-------------------|
| 白酒 | 饮酒人群萎缩，需求量持续下滑 |
| 房地产 | 购房需求人口基数收缩，长期需求见顶 |
| 养老产业 | 老龄化加速，需求端反而是结构性机会 |

## 投资启示

人口红利消退是**长期结构性因素**，不能用"周期性低点"来解释或对抗。判断行业底部时，必须将人口趋势纳入供需分析框架，而非仅看股价跌幅或短期估值。
