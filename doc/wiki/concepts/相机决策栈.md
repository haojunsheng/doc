# 相机决策栈

## 定义

将相机的操作抽象为四层自上而下的决策链，每层自带一个物理操作器：内容类型（模式转盘）→ 曝光（指令拨轮）→ 对焦（AF 子系统）→ 确认+输出（翻转屏取景）。从上往下走完一遍即完成一次拍摄，无需深潜菜单。

---

## 四层结构

```
内容类型（模式转盘：Auto / PASM / SCENE / 视频）
    │
    ▼
曝光（指令拨轮：光圈 + 快门 + ISO 按钮）
    │
    ▼
对焦（AF-M 按钮：AF-S / AF-C / MF + OK 锁焦 + 人眼/动物识别）
    │
    ▼
确认 + 输出（翻转屏取景 → 快门 / 红点录像）
```

---

## 核心原则：交给相机 vs 手动接管

每层之内二选一。普通场景信任 Auto，只在以下三类边界触发手动接管：

| 触发条件 | 说明 | 接管操作 |
|---------|------|---------|
| 弱光 | 主体暗/背景亮，Auto ISO 拉爆噪点 | 手动锁定 ISO + 曝光补偿 |
| 遮挡 | 主体被部分遮挡，全域 AF 对到前景 | 切换点 AF + OK 锁焦 |
| 杂乱背景 | 背景对比度高，抢走对焦点 | 点 AF 锁定主体 |

**设计哲学：不是永远 Auto，也不是永远 M，而是「相机读得准就交给它，读不准才接手」。**

---

## 适用场景

- 面向从手机升级上来的新用户，面对高功能密度相机（约 100+ 菜单项）时避免决策瘫痪
- 适用于功能密度远超工作记忆容量的任何操作工具（可迁移方法论）
- 与 [[尼康-z30]] 说明书章节顺序高度契合（P.6 拍摄流程 → P.14-17 拨轮 → P.18-19 AF）

## 局限

- 三类边界条件目前依赖主观判断，尚无量化触发标准（如 ISO 阈值、反差阈值）
- 材料证据主要来自说明书章节顺序，缺少对照实验验证其对失误率的实际改善效果
- 不同品牌/机型章节编排未必同构，决策栈的直接移植需验证
