# 白平衡与色温

## 白平衡

白平衡解决的是"色彩准确"问题——让白色在任何光源下看起来都是白色。

- 自动白平衡：相机自动判断
- 手动白平衡：根据场景选择预设或自定义 K 值

## 色温（Kelvin）

用 K 值（开尔文）表示光源颜色：

- K 值越大 → 越暖（黄/红）
- K 值越小 → 越冷（蓝）

常见参考值：蜡烛光约 1500K，日光约 5500K，阴天约 7000K。

## 认识论洞见："颜色正确是假命题"

> 绝对的"颜色正确"是个假命题。

这不是技术判断，是**认识论判断**：相机永远在"计算"现实，而不是"记录"现实。RAW 也经过传感器色彩滤镜阵列和去马赛克算法处理。

这与下节"准确曝光 ≠ 正确曝光"是同一个哲学立场—— photographer 的主动选择比追求"绝对准确"更重要。

## "舒服"是谁的舒服？

同一张照片，不同观者有不同的"正确"标准：

- 地质学家 → 要"准确的地貌颜色"
- HR 看证件照 → 要"这个人真实的样子"
- 观众看电影海报 → 要"这个世界的氛围感"
- 家属看遗照 → 要"他最好看的样子"

让观者舒服 = 让特定的人在特定的情境下得到他想要的感受。
