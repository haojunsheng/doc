# 自我服务偏见（基金经理归因偏差）

**定义：** 自我服务偏见（Self-serving bias）指个体倾向于将成功归因于自身内部因素（能力、努力），而将失败归因于外部因素（市场风格、运气、环境）的认知偏差。在基金经理评价中，这是识别危险投资经理的重要行为金融学信号。

## 核心机制

```
成功 → 归因内部（"我选股能力强"）
失败 → 归因外部（"市场风格逆风"）
       ↓
缺乏反思 → 重复犯错 → 长期业绩恶化
```

## 实证数据

美国研究显示：
- 59% 的成功被归因于内部因素
- 83% 的失败被归因于外部因素

有自我服务偏见的基金经理表现出：更愿意承担风险、交易频率更高，但长期业绩反而更差。

## 因果链条：偏见 → 过度自信 → 业绩恶化

```
偏见 → 高估能力 → 过度交易 + 高风险 → 业绩↓ + 波动↑
```

有偏见的基金经理在取得出色绩效后偏见更强，倾向于进行更多组合调整和交易，这些操作对业绩产生负面影响，增加波动性。关键洞察：这些经理并非天生风险偏好更高，而是**偏见放大了他们对自身能力的判断**，导致风险敞口超出理性水平。

**边界：** 适度的风险承担是必要的，但过度风险往往源于过度自信；关键是区分"有纪律的风险"和"冲动的风险"。

## 牛市照妖镜：能力与运气的分离机制

```
牛市 = 运气 + 能力 → 难以区分
熊市 = 风控能力 → 真金不怕火炼
```

牛市期间行情和能力的信号混合，难以区分谁真正有本事、谁只是运气好。2020 年很多基金经理把行情当能力，问他们"组合风险在哪"时回答"业绩这么好，不存在风险"。进入 2021-2023 年熊市后，忽视风控的经理跌幅远超指数，而保持清醒的经理"守住了钱"。

**边界：** 熊市表现好不代表牛市表现好，最佳经理是在两种市场中都能保持纪律的人。

## 识别方法：读季报语言

| 归因风格 | 示例表述 | 风险等级 |
|---------|---------|---------|
| 归己（成功时） | "战胜基准因为消费配置" | 警惕 |
| 甩锅（失败时） | "业绩受逆风影响" | 高度警惕 |
| 谦逊 | "市场赏的，不能指望年年如此" | 正向信号 |

**边界：** 偶尔甩锅可能是情绪宣泄，但持续甩锅说明缺乏反思能力，这类经理应回避。
