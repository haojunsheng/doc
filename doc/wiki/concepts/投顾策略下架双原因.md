# 投顾策略下架双原因

投顾策略下架分为两类原因：**投资端失败**和**顾端失败**，两者最终都导致客户体验不好，但性质截然不同。

## 分类框架

```
投顾策略下架
├── 投资端失败：研究不够扎实，未能实现投资目标和客户预期
└── 顾端失败：投资表现不错，但客户在市场下行区间拿不住
```

### 投资端失败

- 研究不够扎实，未能实现原有投资目标和客户的预期
- 与[[业绩信噪比]]和[[规模激增与业绩反转]]有关联——规模扩大后策略执行变形
- 根本原因：投研能力不足，本质是"投"的问题

### 顾端失败

- 投资表现虽然不错，但"顾"没做好
- 客户在市场下行区间很难跟随，最终提前赎回
- 根本原因：客户教育和行为干预缺失，本质是"顾"的问题

## 关键洞察

两类原因共同指向一个结论：**投顾最本质的问题不是投研能力，而是投资者教育**。

- "顾没做好"的问题在市场持续向好时会被掩盖——客户赚了钱不会在意是否拿得住
- 在市场下行期，"顾"的价值才会真正显现——能否让客户坚持持有是投顾服务的核心竞争力

## 与三分投七分顾的关系

[[三分投七分顾]]从价值分配比例角度提出投顾应以70%精力做"顾"，本框架从策略下架原因角度验证了这一判断的正确性——两类下架原因中，顾端失败占比同样不可忽视，甚至更为普遍。

## 边界

- 两类原因并非互斥，实际案例中可能同时存在
- 在大V投顾场景下，顾端失败的概率更高——信任积累者往往缺投研团队，导致策略本身也不够扎实
