# 核心仓位 vs 卫星仓位框架

基金在投资者组合中扮演的角色不同，面对基金经理变更等风险事件时的应对策略也不同。

## 定义

**核心仓位 vs 卫星仓位框架**是将基金在投资者组合中的角色分为两类：核心仓位（长期持有、权重较大、追求稳健）和卫星仓位（战术调整、权重较小、追求弹性），从而差异化地应对基金经理变更等风险事件。

## 决策框架

```
赎回决策 = 新经理信心 + 基金角色 + 替代选项
```

### 核心仓位的应对

- 基金在组合中权重较大
- 策略依赖度高（如深度绑定某经理）
- 换帅时应更谨慎
- 需要综合评估新经理能力、替代选项性价比
- 不宜盲目跟随赎回，也不宜盲目持有

### 卫星仓位的应对

- 基金在组合中权重较小
- 风险容忍度较高
- 换帅后可以观察一个完整年度
- 若新经理风格稳定且展现能力，可继续持有
- 若新经理大幅调仓偏离原策略，及时止损

## 在冯波案例中的应用

[[entities/易方达行业领先混合]]若为某投资者的核心仓位：
- 深度绑定冯波个人风格
- 换帅即意味着策略断裂
- 需重新评估是否换成制度化管理的同类型基金

若为卫星仓位：
- 可观察彭珂接管后的一个完整年度
- 关注风格一致性和风控表现
- 根据新数据再做决策

## 与[[降息环境基金配置分层]]的关系

两框架逻辑相似：都是根据基金在组合中的角色（核心/卫星、不同风险层级）制定差异化的管理策略，而非一刀切。

## 边界条件

- 若新经理上任后立刻大幅调仓偏离原策略，无论核心仓还是卫星仓都应重新评估
- 若存在明显更好的替代选项，核心仓位更应果断调整
