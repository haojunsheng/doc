# 债券配置场外转场内

**债券配置场外转场内**指2025年Q3 FOF因赎回费政策倒逼，将债券配置从场外基金转向场内ETF的结构性变化，是[[concepts/FOF配置转向框架]]五大转向之一。

## 核心机制

```
场外债基<6个月赎回费≥0.5% → FOF转向场内债券ETF
```

## 政策背景

- 2025年9月5日销售费用规定征求意见稿出台
- 场外债基持有期不满6个月需支付至少0.5%赎回费
- FOF作为机构投资者同样受该规定约束

## 配置结果

- FOF重仓前十债券型基金基本均为场内ETF
- 这是政策 unintended consequence：抑制短期交易的规则扭曲了机构配置行为

## 边界条件

若最终规定豁免FOF的赎回费或降低费率，场外配置可能回流。
