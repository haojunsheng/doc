# 现货加密货币ETF vs 期货加密货币ETF

现货加密货币ETF与期货加密货币ETF的核心区别在于底层资产持有方式：现货ETF直接持有加密货币本身，期货ETF则通过商品交易所（CME）期货合约间接追踪价格。

## 核心区分

| 维度 | 现货ETF | 期货ETF |
|------|---------|---------|
| 底层资产 | 直接持有加密货币（如比特币） | 持有CME期货合约 |
| 价格跟踪 | 实时反映真实价格 | 通过合约展期追踪 |
| 成本结构 | 无展期损耗 | 存在展期损耗 |
| 监管门槛 | 较高（需SEC批准） | 较低（早期已有） |
| 代表产品 | IBIT（贝莱德） | 早期期货ETF |

## 展期损耗

期货ETF的劣势源于合约换月产生的隐性成本——当近月合约到期时，基金需卖出近月、买入远月，若远月价格高于近月（Contango结构），则每次换月产生亏损。这一损耗在加密货币高波动环境下尤为显著。

```
期货ETF换月循环：
近月合约到期 → 卖出近月 → 买入远月（Contango溢价）
→ 每次换月产生隐性成本 → 长期累积损耗
```

## 2024年爆发的制度前提

- 2024年1月11日：SEC批准现货比特币ETF
- 此前仅有期货ETF，投资者被迫承受展期损耗
- 现货ETF类似黄金ETF（GLD）模式，直接持币，价格跟踪精准

## 边界条件

- 若期货市场流动性更好或费率更低，期货ETF仍有存在价值
- 现货ETF的高监管门槛意味着并非所有加密资产都能获得现货ETF资格
- 现货ETF的爆发依赖于SEC监管立场的明确转变
