# 估值修复框架

从资产被错杀形成估值洼地，到向公允价值回归的动态分析框架。区别于静态的估值历史分位法，该框架关注的是估值偏离的"过程"而非"位置"。

## 核心逻辑

**触发事件** → **估值洼地** → **修复回归** → **新的均衡**

以2025年欧股为例：
```
特朗普加征关税(2025.04) → 欧股被抛售 → 形成估值洼地
→ 市场逐步消化冲击 → 2026Q1修复至公允价值×0.99
```

## 关键判断维度

### 1. 整体估值水平
- 衡量指标：当前估值与公允价值的偏离度
- 修复完成的信号：折价收窄至接近零（如欧股仅折价1%）

### 2. 结构性分化
整体"合理"可能掩盖内部严重分化：
- **国家层面**：意大利/西班牙偏贵，荷兰/丹麦最便宜（权重股拖累）
- **行业层面**：金融服务从合理→最贵，通信服务从高估→最便宜

### 3. 宏观支撑与风险
- 支撑因素：GDP预期上调、降息空间、贸易改善、财政加码
- 风险因素：地缘政治、盈利预期下修

## "谨慎乐观"的判断锚点

| 谨慎 side | 乐观 side |
|-----------|-----------|
| 2025年已涨19.1%，涨幅门槛高 | 估值未失控，距泡沫尚有距离 |
| 地缘政治风险未消除 | GDP预期上调、降息空间打开 |
| 个别国家/行业估值已偏高 | 贸易协定落地、财政支出加码 |

## 典型案例：日本股市——盈利改善+估值修复+治理改革三重驱动

日本股市是估值修复框架的典型实证。日经225指数逼近1989年历史高点38957点，市场关于"泡沫重演"的担忧不断，但用估值修复框架审视，2024年上涨本质是三重驱动：

### 三重驱动模型

| 驱动层 | 1989年（泡沫） | 2024年（修复） |
|--------|---------------|---------------|
| 企业税前利润率 | <1% | ~7% |
| PE估值 | 远超合理水平 | 14倍（美股20倍） |
| 上涨驱动力 | 纯杠杆+资金推升 | 盈利增长11.5% + 治理改革 |
| 资本效率 | 低下 | 东交所强制要求改善 |

### 三驱动展开

**第一层：盈利改善**
- 日元兑美元从103贬至151，企业重度依赖出口，贬值直接增厚利润
- 2023年企业税前利润率飙升至近7%，盈利增长11.5%
- 53.5%日本企业账上有正现金流（美国仅39.4%）

**第二层：估值修复**
- 14倍PE仍显著低于美股20倍，存在向全球均值收敛的空间
- 日经225截至2024年1月22日为36546点，距历史高点38957点仅差约6%

**第三层：治理改革**
- 东交所2023年要求上市公司自愿提出提高资本效率计划
- PB<1的公司必须提交改善计划，否则2026年面临退市
- 回购潮和分红提升由制度倒逼而非单纯市场行为

### 与1989年泡沫的本质区别

1989年靠杠杆和投机推升，利润率不足1%，无基本面支撑；2024年上涨有盈利增长、估值合理、治理改善三重支撑。接近历史高点不等于泡沫，关键看盈利能否持续支撑——目前可以，但需警惕交易层面情绪过热（ETF溢价现象即为信号）。

### 投资者陷阱：ETF溢价

QDII额度限制 → 基金限购 → ETF二级市场抢购 → 价格远高于净值。以20%溢价买入意味着指数需再涨20%才能回本。历史上溢价无法长期维持，最终会被抹平——这是无论宏观判断对错都必然受损的结构性风险，与[[concepts/信号贬值]]不同：后者是信号本身的可靠性问题，前者是价格与净值背离的结构性风险。

## 与相关框架的区别

- **vs 估值历史分位法**：历史分位法是静态的"当前位置"判断；估值修复框架是动态的"偏离→回归"过程分析
- **vs 赛道拥挤度**：两者方向一致但维度不同——赛道拥挤关注资金行为，估值修复关注价格与内在价值的偏离
- **vs 泡沫定价四分类法**：估值修复框架关注的是向公允价值回归的过程，泡沫分类法关注的是当前定价属于哪种类型

## 边界与局限

1. **公允价值本身是模型估算**，盈利预期下修可能导致"折价"消失
2. **结构性分化具有脆弱性**：荷兰/丹麦的"便宜"标签高度依赖个别权重股表现，反转时迅速消失
3. **"便宜≠值得买"**：通信服务估值最低，但便宜反映的是基本面恶化而非投资机会
4. **跨境案例需考虑汇率风险**：日元若大幅升值或全球衰退打击出口，盈利改善会中断；日本央行若突然收紧货币政策，贬值逻辑逆转
5. **情绪过热与基本面稳健可并存**：日股案例显示，即使三重驱动模型成立，ETF溢价仍可能是短期最大陷阱
