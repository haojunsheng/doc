# 普涨后分散化最优框架

**普涨后分散化最优框架**是指在经历全面普涨行情后，大类资产估值普遍趋于合理、难以识别明显低估品种的情境下，分散化成为最优配置策略的分析框架。

## 核心命题

> 普涨之后，把波动交给配置，把收益交给时间。

当所有资产都在涨，"被遗忘的洼地"消失，试图押注单一资产或风格的命中率大幅下降，分散化成为风险调整后收益最高的选择。

## 形式化表达

```
普涨情境判定条件：
- 股票：整体两位数涨幅，分布均匀
- 债券：稳健上涨
- 信用利差：收窄至数十年低位
→ 结论：无大类资产明显低估 → 分散化为最优

适用边界：
- 仅适用于普涨后、无明显结构性低估的情境
- 若某资产出现极端低估，分散化可能跑输集中配置
- 但事前难以识别何时该集中，因此分散化仍是最优的"事前策略"
```

## 三种逻辑层次

### 1. 估值层面：安全边际普遍压缩
普涨后各资产价格上升，安全边际被系统性压缩。详见 [[安全边际压缩逻辑]]。

### 2. 认知层面：挖掘难度上升
大类资产层面的"超额收益来源"在普涨后变得难以识别。即使结构性机会存在，判断哪个品种最值得超配的概率接近抛硬币。分散化的价值不在于收益最高，而在于"不需要预测"。

### 3. 行为层面：避免择时陷阱
[[择时的心理陷阱]] 和 [[择时成本四维分解]] 指出，试图在普涨后捕捉"下一个机会"往往导致追高和频繁调仓，隐性成本通常超过分散化的机会成本。

## 与相关框架的关系

- **[[分散化有效性条件]]**：本文补充了分散化的适用情境——在普涨后（相关性趋同、安全边际压缩）的特定条件下，分散化从"有益"升级为"最优"
- **[[全球配置范式转变]]**：本文的"格局打破"（美股不再领跑）是该范式转变在 2025 年的具体实证案例
- **[[估值隐含回报VIR框架]]**：VIR 用于判断单个资产的相对吸引力；普涨后各资产 VIR 趋近，此时 VIR 的区分能力下降，分散化成为次优选择

## 实践含义

1. 普涨后不要试图"抄底"或"追高"某个单一资产类别
2. 接受"平均回报"是合理的目标——追求超额收益在普涨后往往适得其反
3. 定期再平衡（季度）是维持分散化策略纪律的关键机制
4. 仅在出现明确、持久的相对低估信号时，才考虑偏离分散化基准

## 边界条件

- 若某资产因突发事件出现极端低估，集中配置可跑赢分散化——但事前极难识别
- 若市场进入明确的单边牛市（非普涨），集中配置胜率更高
- 对专业投资者而言，适度主动偏离基准可能跑赢，但这是例外而非规则
