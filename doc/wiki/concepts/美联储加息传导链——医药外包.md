# 美联储加息传导链——医药外包

美联储利率政策通过融资成本渠道传导至药企研发支出，再传导至CXO（医药外包）订单，形成一条跨资产的宏观-行业传导链。

## 传导路径

```
美联储加息
  → 药企融资成本↑（全球药企倾向股票融资，利率上升增加股权融资稀释成本）
    → 药企调整/削减研发管线
      → CXO订单↓
```

### 关键特征

- **传导有滞后性**：药企从融资困难到削减管线再到取消CXO订单，存在数季度的时滞
- **恢复也需要时间**：即使美联储开始降息，药企重新恢复研发支出和下达新订单也需要过程
- **双向敏感**：不仅加息利空，降息利好也有滞后

## 与[[降息原因决定市场反应]]的关系

本文与[[降息原因决定市场反应]]形成镜像：

| 降息触发背景 | 对CXO的影响 |
|------------|-----------|
| 预防式降息（经济稳健） | 药企融资成本↓→研发重启→CXO订单恢复 |
| 应对式降息（经济危机） | 盈利下滑主导，CXO订单可能仍疲软 |

## 实证案例：2023年药明生物业绩变脸

2023年药明生物下调业绩目标、单日暴跌23.79%，直接原因是：
- 新冠相关收入快速消退（一次性收入贡献结束）
- 美联储加息周期下，全球药企融资困难，研发管线调整，项目延迟

这验证了加息→药企融资成本↑→研发管线↓→CXO订单↓的传导链。
