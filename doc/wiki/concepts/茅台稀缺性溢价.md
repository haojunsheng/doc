# 茅台稀缺性溢价

出厂价与终端价的巨大落差反映的供需极端不对称，是茅台独一档的核心标志。

## 核心事实

- 茅台出厂价 1169 元，终端渠道售价动辄数千元
- 供不应求，"一瓶难求"成为常态
- 渠道利润空间巨大，形成独特的价格双轨制

## 与其他白酒的本质差异

```
茅台：供不应求 + 超强定价权 ⊥ 其他白酒：产能过剩 + 竞争定价
```

| 维度 | 茅台 | 其他白酒 |
|------|------|----------|
| 供需状态 | 供不应求 | 产能过剩 |
| 定价模式 | 超强定价权 | 竞争定价 |
| 渠道利润 | 巨大 | 微薄 |
| 行业地位 | 品类稀缺性代表 | 陷入价格战 |

## 投资启示

茅台的稀缺性溢价使其在行业整体下行周期中独善其身，但这**不能泛化为整个白酒行业的投资机会**。恰恰相反，茅台与其他的分化恰恰说明：同一行业内部分化极大，抄底需逐个甄别供需格局，而非一概而论。
