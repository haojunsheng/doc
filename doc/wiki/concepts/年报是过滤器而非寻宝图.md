# 年报是过滤器而非寻宝图

年报阅读的根本目的：**不是为了找到好股票，而是为了排除坏公司。**

## 核心论断

```
年报 = 过滤器 → 排除有问题的公司 → 缩小选股范围 → 剩下的才值得进一步研究
```

这是 Morningstar 年报阅读指南的最终收口结论，也是对散户年报阅读习惯的根本性重构。

## 排除标准

哪些公司应该被年报排除：

| 排除条件 | 红旗信号 |
|---------|---------|
| 审计意见不是无保留 | 保留意见 / 无法表示意见 |
| MD&A 回避关键问题 | 竞争加剧、监管风险、客户流失等话题一笔带过 |
| 风险因素持续恶化 | 风险披露从模糊变具体、从少量变大量 |
| 财务数据与行业趋势不符 | 行业下滑而公司逆势增长，但缺乏合理理由 |

## 与排除法的关联

[[排除法优于优选法]]是同一思维范式在不同场景的应用：

| 场景 | 排除法应用 |
|------|-----------|
| 短债基金选基 | 五维过滤器：任职时长、星级、机构占比、费率排名、规模 |
| 年报阅读 | 红旗信号三件套：会计政策变更 + 回避话题 + 保留意见 |
| ETF 选基 | 综合费率、跟踪误差、规模三大排除项 |

## 与「寻宝逻辑」的对比

| 寻宝逻辑 | 过滤器逻辑 |
|---------|-----------|
| 目标：找到最好的公司 | 目标：排除有问题的公司 |
| 心态：兴奋、期待 | 心态：谨慎、怀疑 |
| 风险：过度关注 positives，忽视 negatives | 风险：过于保守，错过好公司 |
| 适合：深度研究已有候选 | 适合：初次筛选大量候选 |

## 边界

年报不是唯一的过滤器——你还需要结合行业分析、竞争分析、估值分析。但年报是**第一步**：如果年报都过不了关，后面的分析就没有意义。
