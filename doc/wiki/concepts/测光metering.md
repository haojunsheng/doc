# 测光 Metering

## 定义

测光是测量场景亮度以确定曝光参数的过程。它是曝光四要素（光圈、快门、ISO、测光）中的最后一环，也是将技术知识转化为创作意图的关键过渡。

## 核心原理：18% 中性灰

相机的测光系统将接收到的所有光线转换为反光率为 **18% 的中性灰**的读数。这意味着：

- 拍白雪 → 相机以为场景太亮 → 自动压暗 → **雪变灰**
- 拍黑猫 → 相机以为场景太暗 → 自动提亮 → **猫变灰**
- 拍任何颜色的物体 → 相机都试图把它还原成同一种灰色

**相机不是在"测量现实"，而是在"把现实转换成 18% 灰"。**

## 测光模式的常见类型

| 模式 | 说明 |
|---|---|
| 点测光（Spot Metering） | 只测量画面极小区域（通常 1-5%）的亮度 |
| 全局测光 / 评价测光 | 测量整个画面的平均亮度 |
| 中央重点测光 | 优先测量画面中心区域 |

> 本课未深入讨论现代智能测光模式（评价测光/矩阵测光）的实际可靠性，留有开放空间。

## 测光与曝光补偿的关系

两者是**修正关系**，非并列关系：

```
测光（相机的建议）→ 曝光补偿（你的纠正）
```

1. 先让相机给出测光读数
2. 判断这个读数是否符合创作意图
3. 不符合则用曝光补偿纠正：+EV 让画面更亮，-EV 让画面更暗

## 实战意义

现代相机在 80% 日常场景下测光靠谱。真正需要手动干预的主要是：

| 场景 | 触发原因 |
|---|---|
| 雪景 / 白墙背景 | 相机过度压暗，需 +EV |
| 大面积黑色背景 | 相机过度提亮，需 -EV |
| 逆光人像 | 人脸过暗，需 +EV 或点测光 |
| 舞台 / 演唱会 | 高反差极端场景 |
| 日出日落 | 需要保留色彩而非压制为灰 |

## 本课的核心命题

**测光是建议，曝光是决策。** 摄影师的价值不在于让相机测得"更准"，而在于知道相机在哪里会歪曲，然后主动纠正。
