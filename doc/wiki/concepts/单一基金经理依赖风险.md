# 单一基金经理依赖风险

当基金策略深度绑定某一位基金经理的个人风格与能力时，该经理的变动对持有人构成系统性风险。

## 定义

**单一基金经理依赖风险**是指基金的投资策略、选股逻辑和仓位管理高度依赖某一位基金经理的个人判断，而非制度化体系。一旦该经理离职，基金策略可能发生根本性转变，持有人的预期收益基准也随之改变。

## 核心公式

```
策略绑定个人 → 换帅 = 策略风险
策略绑定制度 → 换帅 = 运营风险
```

前者意味着持有人"买的是冯波，变成的是彭珂"，后者意味着换帅只是运营层面的调整，策略连续性得以保持。

## 典型案例

### 冯波→彭珂

[[entities/冯波]]管理[[entities/易方达行业领先混合]]15年，基金深度打上了其质量成长风格烙印。2026年换帅后，新经理[[entities/彭珂]]从研究员出身，风格与冯波截然不同——这正是单一依赖风险的具象化。

### 丘栋荣→刘晟/吴承根

[[entities/丘栋荣]]管理[[entities/中庚基金]]旗下多只产品，其低估值策略带有强烈个人烙印。2025年5月密集增聘[[entities/刘晟]]和[[entities/吴承根]]（两位内部培养的低估值风格经理），3个月后正式离职。规模在传闻期间缩水91亿，正式离任后再缩水51亿，合计缩水142亿。投资者买的不是基金而是基金经理——当策略绑定个人而非制度时，离职就是最大风险。

## 与制度优势的镜像关系

[[concepts/制度优势-个人能力转化]]描述的是伯克希尔·哈撒韦的正例：巴菲特用25年把个人能力转化为制度体系，使阿贝尔接棒后策略仍能延续。冯波案例和丘栋荣案例是其反面教材——策略随个人而走，制度未能吸收个人能力。

## 对持有人的启示

1. **换帅不是自动赎回信号**：应评估基金在组合中的角色（核心仓 vs 卫星仓）
2. **新经理能力需要时间验证**：至少一个完整市场周期（3-5年）
3. **关注基金是否绑定个人**：若基金风格高度依赖某经理，未来换帅风险更高
4. **替代选项比较**：同类基金中是否存在制度化管理、风格稳定的替代品

## 边界条件

- 若基金公司有成熟的投资委员会和风控体系，个人离职的影响会被制度缓冲
- 若新经理展现出与原经理相近的风格稳定性，依赖风险可降低
- 当行业普遍存在换帅时，换帅信号本身的信息价值也会稀释——参见[[信号贬值]]
