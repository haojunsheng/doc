# 自由现金流选股

以自由现金流（经营现金流 − 资本开支）为核心筛选标准，优先选择自由现金流稳定且充裕的公司，替代传统市值加权的选股方式。

## 核心逻辑

自由现金流选股将"质量"作为第一排序维度：

```
自由现金流稳定性↑ + 自由现金流充裕度↑ → 质量导向
```

与利润指标相比，自由现金流更难被财务操纵，更能反映公司的真实盈利质量。自由现金流充裕的公司具备更强的分红和股票回购能力，对股东更友好。

## 与传统市值加权的区别

| 维度 | 市值加权 | 自由现金流筛选 |
|------|---------|--------------|
| 权重依据 | 公司规模 | 基本面质量 |
| 风险点 | 大市值泡沫（"大而不好"） | 行业周期影响稳定性 |
| 财务操纵难度 | 利润可操纵 | 现金流更难操纵 |

## 边界条件

- 自由现金流是**历史数据**，不代表未来
- 行业周期可能影响自由现金流的稳定性，周期性行业的自由现金流波动较大
- 自由现金流指数费率通常高于传统指数
- 因子有效性随时间变化，任何因子都有周期
