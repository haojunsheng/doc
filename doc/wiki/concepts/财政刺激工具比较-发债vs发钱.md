# 财政刺激工具比较：发债 vs 发钱

比较两种主要财政刺激工具的效果、风险和适用场景。

## 发债（借钱）

**机制**：政府通过发行债券向市场借款，将社会闲置资金集中用于特定项目。

```
发债 → 借钱(不印钞) → 闲置资金再利用 → 基建投资 → 就业↑ → 消费↑
```

| 维度 | 特点 |
|------|------|
| 货币创造 | 中性（不增加货币总量） |
| 通胀风险 | 低 |
| 乘数效应 | 取决于产业链联动和就业带动 |
| 分配效应 | 资金定向使用，政府可选择项目 |
| 可持续性 | 创造就业提升收入，更可持续 |

## 直接发钱（印钞/转移支付）

**机制**：政府直接向居民或企业发放资金，刺激消费或投资。

```
发钱 → 印钞(或透支央行) → 居民获得资金 → 消费↑(?) 
```

| 维度 | 特点 |
|------|------|
| 货币创造 | 扩张性（可能增加货币总量） |
| 通胀风险 | 高（资金直接进入消费端） |
| 乘数效应 | 不确定（可能捂在口袋里不花） |
| 分配效应 | 普惠但效率低 |
| 可持续性 | 短期刺激强，长期可能加重债务负担 |

## 关键对比

| 比较维度 | 发债 | 发钱 |
|---------|------|------|
| 通胀风险 | 低 | 高 |
| 货币总量影响 | 中性 | 扩张 |
| 资金利用率 | 高（政府选择项目） | 低（居民自行决定） |
| 就业带动 | 强（基建产业链） | 弱（直接消费） |
| 适用场景 | 有明确项目需求、通缩压力不大 | 紧急救助、流动性陷阱、深度通缩 |

## 适用边界

### 发债更优的场景

- 经济有明确基建需求
- 金融体系有闲置资金
- 通胀压力可控

### 发钱更优的场景

- 经济处于深度通缩
- 居民资产负债表严重受损
- 信贷传导机制失效（流动性陷阱）

## 中国2026年特别国债的选择逻辑

2026年万亿特别国债选择"发债"而非"发钱"，反映了以下判断：

1. 经济尚未陷入深度通缩，信贷传导机制仍在运转
2. 有明确的防灾救灾基建项目需求
3. 希望避免直接发钱可能带来的通胀压力
4. 通过基建投资创造就业，形成更可持续的经济修复路径
