# 主动超额衰减与中小盘机会并存

主动基金超额收益整体呈衰减趋势，但中小盘股票因定价效率相对较低，仍保留结构性超额机会。

## 核心矛盾

同一篇文章同时指出两个看似矛盾的结论：
1. 主动基金超额收益在快速衰减
2. 中小盘领域主动基金仍有超额机会

实际这两者并不矛盾：大盘股定价效率已很高，超额空间被压缩；中小盘因研究覆盖不足，定价效率仍较低，超额窗口尚未关闭。

## 数据：主动战胜率断崖式下降

| 时间维度 | 过去战胜率 | 当前战胜率 | 降幅 |
|---------|----------|----------|------|
| 1年 | 49.6% | 38.2% | −11.4pp |
| 3年 | 58.7% | 37.6% | −21.1pp |

数据来源：晨星中国，主动中小盘基金样本。

## 传导机制

```
资金涌入被动产品
  → 市场定价效率提升（更多资金追踪同一基准）
  → 基准约束加强（2025年5月行动方案强化）
  → 主动基金超额收益空间缩小
```

## 中小盘例外机制

```
大盘股 → 机构覆盖密集 → 定价效率高 → 超额难
中小盘股 → 研究覆盖少 → 定价效率低 → 超额机会尚存
```

## 边界条件

- 若被动产品在中小盘领域持续扩张，定价效率将同步提升，主动超额空间也会收窄。
- 本判断针对A股市场；美股市场主动战胜率已长期低于30%，可作参考基准。

## 与投资实践的关联

- 对于宽基配置：优先选择ETF，避免为难以实现的主动超额支付管理费。
- 对于行业/主题配置：中小盘赛道中仍有筛选主动基金的结构性价值。
- 对于基金持有者：审视自身持有的主动基金是否处于定价效率较低的领域。
