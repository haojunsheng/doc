# 上香行情

> 机构信任崩塌后，散户用玄学投机填补信任真空的市场现象。

## 核心定义

**上香行情**是指机构投资者因信任崩塌（如抱团崩盘、宏大叙事破灭）而离场后，散户和游资用非基本面、玄学化的投机行为填补市场信仰真空的现象。

**词源隐喻**："上香"比喻散户在机构失灵后转向"拜神"——通过炒名字、炒代码等玄学逻辑来寻找确定性，而非基于企业价值。

**形式化**：

```
机构信任崩塌 → 信任真空 → 玄学投机(上香) → 短期热闹 → 长期亏损
```

## 典型特征

| 特征 | 表现 |
|------|------|
| **非基本面驱动** | 炒名字（"东西南北中发白"麻将概念股）、炒代码，而非业绩 |
| **反机构叙事** | "没机构啥都能炒"，将机构视为敌人而非参照系 |
| **共识投机** | 靠情绪共振而非估值锚定 |
| **生命周期极短** | 火不过两天，涨停砸跌停，内鬼抢跑 |

## 生成机制

```
机构无序规模扩张 → 抱团股崩盘 → 基金经理宏大叙事破灭 → 投资者用脚投票 → 机构信任崩塌 → 信任真空 → 散户反机构化投机(上香) → 短期热闹 → 长期亏损
```

**关键转折**：投资者从"追随机构"走向"反机构"，但并未建立真正的独立投资能力，只是用另一种非理性替代另一种非理性。

## 边界条件

- **终止条件**：若机构真正回归基本面投资、重建信任，上香行情可能缓和
- **土壤消失**：若市场真正成熟、散户比例下降，反机构化土壤会消失
- **误判风险**：若经济持续恶化导致企业盈利下滑，"3000点不贵"的判断可能错误

## 制度启示

- 经济增长红利能否转化为投资者回报，取决于市场治理结构
- 反机构化是信任崩塌的副产品，而非解决方案
- 真正需要的是制度重建（强制分红、减持限制），而非玄学投机
