# 反向信号检验

## 定义

当一个信息源主动分享所谓的"财富密码"或投资机会时，分享行为本⾝就是一种**反向信号**——真正知道机会的人不会分享，分享本身说明该机会价值有限。

## 形式化

```
知道金矿在哪 → 不会画地图送你 → 送你地图 = 不可信
```

## 来源

巴菲特姐姐贝蒂的朴素智慧：她虽是普通投资者，但深谙人性——第一条建议就是"不要轻信专家"。用画金矿地图给邻居挖矿的比喻，说明分享本身就是利益不一致的体现。

## 适用场景

- 各类"专家推荐"的股票/基金/投资机会
- 社交媒体上的"财富密码"分享
- 任何涉及竞争利益的信息传递场景

## 边界条件

若信息传递不涉及竞争利益（如学术交流、开源项目），可信度另论。此检验适用于**存在竞争关系的利益场景**。
