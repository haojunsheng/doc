# 高收益资产稀缺化

## 定义

指在全球大类资产层面，能够提供高长期预期回报的资产类别正在越来越少、越来越少的现象。这是[[资产荒]]概念的全球化扩展——不再局限于某一国家或市场，而是覆盖美股、美债、发达市场股票、新兴市场股票等主要资产类别。

## 核心逻辑

```
全球普涨（2025年）→ 估值普遍抬升 → 预期回报收窄 → 高收益资产稀缺
```

## 各资产类别表现

| 资产类别 | 预期回报变化 | 原因 |
|---------|------------|------|
| 美股 | 下调（3.1%-6.7%） | 估值抬升，除先锋领航外几乎所有机构下调 |
| 发达市场股票 | 下调 | 普涨后估值普遍偏高 |
| 新兴市场股票 | 下调但幅度较小 | 估值相对更低，仍是首选 |
| 美债 | 维持或小幅上调 | 收益率处于高位 |
| 中国资产 | 晨星最看好 | 估值优势 + 增长潜力 |

## 与[[资产荒]]的关系

| 维度 | [[资产荒]] | 高收益资产稀缺化 |
|------|-----------|----------------|
| 范围 | 中国国内市场为主 | 全球大类资产 |
| 触发因素 | 国内低利率环境 | 全球普涨后估值普遍抬升 |
| 核心表现 | 储蓄资金追逐有限红利资产 | 高收益资产在所有大类中变稀缺 |
| 结论方向 | 需拓展配置边界 | 需降低预期+多元配置 |

两者结论相近但背景不同，存在概念重叠，建议在[[资产荒]]页面补充全球化视角的延伸说明。

## 投资者应对

```
高收益稀缺 → 不追单一资产 → 多元配置 + 长期持有
```

具体行动：
1. **降低收益预期**：客观理性看待市场新变化
2. **多元配置**：不押注单一资产，分散持有
3. **与时间同行**：长期持有让复利发挥作用
4. **关注新兴市场**：晨星最看好中国等新兴市场，估值优势仍在

## 边界条件

- 若美国企业盈利超预期或美联储大幅降息，部分结论可能不成立
- 模型依赖历史关系，若全球经济结构发生根本变化（如去全球化加速），长期预期回报测算的适用性会下降
- "高收益稀缺"可能是周期性现象也可能是结构性趋势，目前尚无定论
