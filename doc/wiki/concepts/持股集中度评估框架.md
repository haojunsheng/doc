# 持股集中度评估框架

持股集中度是评估主动管理权益基金的重要维度，但不能仅看持股数目或前十大持仓占比，必须结合基金规模和基金经理能力综合判断。

## 核心原则：规模是必要校正因子

持股数目 ≠ 持股集中度。同样的持股数量，对于小盘基金可能是集中，对于大盘基金可能是分散。

```
小盘基金持股 30 只 ≠ 集中
大盘基金持股 200 只 ≠ 分散
规模决定持股下限，风格决定持股上限
```

基金规模越小，少量股票即可满足配置需求；规模越大，持股数目自然增加。中小盘风格基金达到规模瓶颈后，会选择关闭接受新资金以保护策略容量。

**边界**：若基金规模暴增但策略容量不够，基金经理被迫买入不熟悉的公司，业绩恶化。

## 前十大持仓占比维度

| 分组 | 占比 | 样本数量（1560只） |
|------|------|-------------------|
| 高度集中 | > 70% | 112 只 |
| 中度集中 | 40%–70% | 中间区间 |
| 轻度集中 | 20%–40% | 中间区间 |
| 高度分散 | < 20% | 156 只 |

与 [[主动持股比例]] 形成互补：主动持股比例衡量与基准的偏离程度，前十大持仓占比衡量组合内的集中程度。两者共同构成基金策略特征的完整画像。

## 核心+卫星的持股结构

大多数主动基金在内部持仓层面也采用"核心+卫星"结构，而不仅限于 FOF 层级的战术调整：

```
核心仓位（约 70%）：大盘蓝筹股 → 保稳定，流动性好，市值大
卫星仓位（约 30%）：中小盘股     → 博超额，在市值或风格约束下追求 alpha
```

核心部分选择长期基本面优秀的标的；卫星部分提供风格暴露和超额收益。

**边界**：若核心仓位选股失误，卫星仓位的超额收益可能不足以弥补核心的亏损。

参见 [[核心卫星策略在FOF中的应用]]，源文将其从 FOF 战术调整推广到单只基金的个股持仓结构层面。

## 集中与基金经理能力的关系

集中本身不是优点也不是缺点，它是基金经理选股能力和投资策略的外化表现：

```
有能力选股 → 集中持股 → 赚大钱
无能力选股 → 集中持股 → 亏大钱
认可贝塔   → 分散持股 → 老老实实赚贝塔
```

高集中度基金的业绩完全取决于少数核心持仓的选择正确性——大赢大输，没有中间地带。集中度高说明基金经理对所持个股有信心，但若决策失误也容易带来较大净值损失。

**边界**：若基金经理能力圈变化或市场风格与其不匹配，高集中度从优势变为致命伤。

## 量化基金的分散逻辑

量化基金通过量化模型捕捉市场"错误定价"机会获取统计优势，持仓分散是为了避免个股非系统性风险破坏模型预期收益。集中持有单一个股会破坏量化模型的统计逻辑，这是量化基金天然倾向分散的根本原因。

**边界**：若市场出现模型未覆盖的极端事件（黑天鹅），分散也无法避免系统性损失。

## 投资者选择框架

将持股集中度纳入 [[选基适配框架]] 的评估维度：

```
选集中基金：信任基金经理选股能力 + 能承受大波动
选分散基金：不想跑输指数 + 厌恶大波动
选量化分散：认可统计优势 + 接受模型覆盖之外的风险
```

持仓集中度不能作为单一参考，需结合自身投资目标和风险承受能力，结合基金经理投资能力、基金投资方法综合判断。

**边界**：若投资者选了高集中基金但又不愿承受短期大幅波动，可能在最低点赎回，把浮亏变成实亏。
