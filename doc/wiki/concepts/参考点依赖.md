# 参考点依赖

> 人们把「买入价」当作决策参考点——涨回买入价就卖出，而非看未来基本面。

## 定义

**参考点依赖**（Reference Point Dependence）：决策者以某个参考点（通常是买入价）为基准评估收益或损失，而非以绝对价值或未来预期为准。这是前景理论的核心机制之一。

## 形式化

```
买入价 = 参考点
→ 价格 > 买入价 → perceived as "盈利" → 倾向卖出
→ 价格 < 买入价 → perceived as "亏损" → 倾向持有（期待回本）
→ 忽略：未来基本面无变化时，参考点不应影响决策
```

## 典型案例：回本心态

场景推演：
1. 100 元买入一只股票
2. 跌到 80 元
3. 涨回 100 元——很多人卖出，因为「终于回本了」
4. 但基本面未变，股票可能涨到 200 元

错误：把「回到买入价」当作卖出信号，而非把「基本面变化」当作决策依据。

## 与锚定效应的关系

参考点依赖是锚定效应（Anchoring Effect）在投资中的具体表现：
- 锚：买入价
- 偏倚：以买入价为基准评估当前价格是否「合理」
- 正确做法：忽略买入价，问「如果我现在没有持有，我会以当前价格买入吗？」

## 投资中的表现

| 情境 | 参考点依赖导致的错误 | 正确决策依据 |
|------|---------------------|------------|
| 股票从 100 涨到 150 | 卖出锁定「50% 收益」 | 基本面是否支撑更高估值 |
| 股票从 100 跌到 80 | 持有等待「回本」 | 基本面是否恶化 |
| 股票从 100 跌到 60 | 加仓摊低成本 | 当前价格是否符合内在价值 |

## 边界条件

参考点依赖在以下情况可能合理：
- 基本面恶化时，买入价成为「成本沉没」的判断参照
- 止损纪律中，买入价作为初始风险边界的参考

但大多数时候，参考点是噪音而非信号。

## 对抗方法

[[concepts/假设有持仓决策测试]] 是直接的对抗工具：
- 问：「如果我现在没有持有，我会以当前价格买入吗？」
- 如果答案是肯定的，就不该卖出
- 如果答案是否定的，就该卖出

此方法消除了买入价锚定的干扰，回归基本面判断。

## 与相关概念的关系

- [[concepts/卖太早的陷阱]]：参考点依赖是「卖太早」的核心心理机制之一（Q2）
- [[concepts/净值恐高症]]：参考点依赖的反面——涨多了不敢买，因为参考点被拉高了
- [[entities/kahneman-tversky]]：前景理论提出者，参考点依赖是其核心假设
