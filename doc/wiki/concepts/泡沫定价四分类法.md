# 泡沫定价四分类法

由晨星中国访谈中基金经理戴军提出的股票定价分析框架。该框架将上市公司按其估值逻辑划分为四类：净资产定价、净现金流定价、成长定价、泡沫定价。每一类对应不同的投资纪律与风险边界，核心判断标准是"价格中所资本化的因素是否具备持续性"。

## 四分类定义

| 类别 | 定价依据 | 典型特征 | 代表案例 |
|------|---------|---------|---------|
| 净资产定价 | 资产重置成本或清算价值 | 价格贴近或低于净资产，安全边际高 | — |
| 净现金流定价 | 自由现金流折现 | 利润真实、可分配，股息或回购支撑估值 | — |
| 成长定价 | 未来盈利增长预期 | 当前业绩一般但增长确定性高，需持续验证 | 泡泡玛特（熊潇雅/萧楠框架） |
| 泡沫定价 | 偶然性因素过度资本化 | 短期政策红利、潮流风口等非持续性变量被计入长期估值 | 泡泡玛特、老铺黄金、蜜雪（戴军判断） |

## 核心判断标准

1. **偶然性因素不应被资本化**：泡泡玛特、老铺黄金、蜜雪的共同特征是，市场将"政策红利"和"潮流风口"等短期变量过度计入估值，隐含假设这些非持续性因素会长期存在。
2. **低价不是竞争壁垒**：市场默认利润可持续很久是一种荒谬假设；低价优势若缺乏结构性护城河（品牌、专利、网络效应），终将被竞争侵蚀。
3. **框架与标的的匹配度决定结果**：同一个标的，用不同框架得出不同结论，都可能是"合理"的——关键在于投资者是否清楚自己的框架边界。

## 形式化表达

```
输入：某股票P
判断流程：
  若 P ≈ f(净资产) → 净资产定价类 → 关注资产质量与清算价值
  若 P ≈ f(净现金流) → 净现金流定价类 → 关注自由现金流可持续性
  若 P ≈ f(成长预期) → 成长定价类 → 关注第二曲线验证进度
  若 P 将偶然性因素(政策红利+潮流风口)过度资本化 → 泡沫定价类 → 不碰

关键约束：
  偶然性因素 = {短期政策红利, 潮流风口, 审美偏好}
  这些因素的半衰期 ≠ 长期，将其永续化定价 = 泡沫
```

## 案例：泡泡玛特的两副面孔

同一只泡泡玛特，在两位基金经理眼中呈现出截然不同的定价类别：

- **熊潇雅（成长框架）**：2023年Q1在低估值+业绩低谷时买入，通过调研供应链和海外门店发现海外扩张盈利模型成立 → 海外业务快速增长验证 → 估值与业绩双升 → 超额收益。在她的框架里，泡泡玛特属于"成长定价"。
- **戴军（泡沫定价框架）**：泡泡玛特、老铺黄金、蜜雪都属于"泡沫定价"——价格将偶然性因素（潮文化热度、政策红利）过度资本化。在他的框架里，这些标的不碰。

两人判断差异的本质不是信息不对称，而是**框架不同**：成长框架关注"第二曲线是否存在"，泡沫定价框架关注"现有利润的持续性能否经得起竞争检验"。

## 萧楠的中间地带：成长曲线的两阶段判断

萧楠的经历为四分类法提供了重要补充——他并非简单地从"成长"转向"泡沫"，而是引入了时间维度：

- 2021年下半年：底部买入，持仓占比达4.48%，基于成长框架判断泡泡玛特独特性
- 2022年：疫情波动触发恐慌减持至0.75%，事后反思"低估了年轻公司的可能性"
- 2025年：重新审视并再次减持，理由是从成长曲线角度看，上市时第一曲线已基本走完，第二曲线不明朗、竞争者蜂拥而入

关键洞察：**同一公司，在不同时间点可以归属于不同定价类别**。成长定价类公司在第一曲线走完、第二曲线未明时，定价逻辑可能滑向泡沫定价。

## 边界条件

1. **海外热潮消退**：若潮文化IP在海外市场的接受度下降，熊潇雅的海外扩张盈利模型失效，成长定价转为泡沫定价。
2. **品牌护城河加深**：若新消费公司证明其利润具备持续性和可复制性（如品牌壁垒加固），戴军的泡沫定价判断可能过于保守。
3. **宏观冲击强度**：2022年萧楠的减持是否在逻辑上正确，取决于疫情封控的严重程度——若冲击更严重，风控逻辑成立；若属短期波动，则反思合理。
4. **量化标准缺失**：泡沫定价四分类法目前缺乏明确的量化阈值（如"多少倍PE算过度资本化"），依赖主观判断，可复用性存疑。

## 与其他概念的关联

- **[[concepts/主题基金热度循环]]**：泡泡玛特年内暴涨后单周跌12%正是热度循环的经典形态；戴军的框架提供了一个前置筛选机制，在热度峰值前识别泡沫定价标的。
- **[[concepts/波动率对交易冲动的影响]]**：萧楠2022年的减持是波动率触发交易的典型案例，与四分类法中"成长定价→恐慌→转向"的路径吻合。
- **[[concepts/信号贬值]]**：基金经理公开表态本身成为市场信号，当戴军说"不碰泡泡玛特"时，市场反而可能反向追捧。
- **[[concepts/赛道轮动]]**：新消费与创新药的同步震荡体现了赛道轮动中框架不匹配的风险。
- **[[concepts/成长-vs-价值风格的驱动因素]]**：四分类法可视为风格框架的具体操作化——成长定价对应成长风格，净资产/净现金流定价对应价值风格。
