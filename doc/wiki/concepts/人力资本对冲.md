# 人力资本对冲

## 定义

当投资者的职业人力资本（如白领工作）可能受到AI冲击时，在投资组合中配置AI相关标的作为对冲。这是晨星美洲策略师Preston提出的个人策略思考。

## 形式化表达

```
人力资本受AI冲击 → 配置AI股对冲 → 职业损失 ↔ 投资组合收益
```

## 核心逻辑

1. **白领职业风险**：Preston认为白领职业可能被AI冲击
2. **对冲机制**：配置AI股，当职业收入受冲击时，投资组合收益可以部分弥补
3. **非理性因素**：Preston承认这一配置行为含非理性因素（"考虑"配AI股对冲），但反映了真实的职业焦虑

## 与FOMO的区分

| 维度 | 理性的人力资本对冲 | FOMO驱动的配置 |
|------|-----------------|---------------|
| 动机 | 职业风险对冲 | 害怕错过收益 |
| 标的选择 | 基于职业暴露度 | 基于短期涨幅 |
| 时间维度 | 长期风险管理 | 短期投机 |
| 心理状态 | 冷静评估 | 焦虑驱动 |

Preston的困境在于：他知道自己配置AI股 partly 是因为FOMO式焦虑，但也 partly 是理性的对冲需求。

## 适用性边界

- **核心问题**：白领职业受AI冲击的程度因国家/地区而异
- **中国投资者适用性**：中国白领职业受AI冲击的程度与北美不同，直接套用需谨慎
- **职业类型差异**：并非所有白领职业都同等受AI影响
