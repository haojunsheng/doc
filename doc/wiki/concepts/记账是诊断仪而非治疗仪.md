# 记账是诊断仪而非治疗仪

**核心论点**：记账的价值是发现问题（看清钱去哪了），但记账本身不会自动改变行为；预算 + 调整消费结构 + 增加收入才是真正的治疗。

## 形式化

```
记账 = 诊断仪（发现问题）
治疗 = 预算 + 调整消费结构 + 增加收入

常见错误：记账后不分析 → 自我感动（记了等于没改）
正确路径：记账 → 分析 → 预算 → 执行 → 追踪
```

## 核心论证

### 诊断 vs 治疗的区分

| 维度 | 诊断仪（记账） | 治疗仪（预算+执行） |
|------|--------------|-------------------|
| 功能 | 发现问题、暴露漏点 | 解决问题、改变行为 |
| 输出 | "我每月奶茶花 600" | "下个月奶茶预算 200" |
| 是否自动生效 | 否 | 否（需主动执行） |
| 典型失败模式 | 记了三个月，然后没有然后 | 定了预算，但执行不下去 |

### 反例：记账 ≠ 省钱

很多人记账三个月，发现「原来我每月奶茶花 600」，然后呢？记账本身不会让你少喝一杯。

真正的改变需要：
1. 记账发现漏点（诊断）
2. 分析为什么会有这个漏点（认知）
3. 设定新预算或替代方案（治疗设计）
4. 执行并追踪（治疗实施）

### 与预算的关系

- 不记账的预算是拍脑袋，不知道钱去哪了，预算无从下手。
- 记账后的预算才是量体裁衣——基于真实数据，而非主观猜测。
- 但记账只是预算的前提，不是预算本身。

## 边界条件

- 记账后不分析 = 自我感动：这是最常见的失败模式
- 对部分人群，记账本身可能具有行为约束效应（如"记录即约束"心理），但这不是普遍规律
