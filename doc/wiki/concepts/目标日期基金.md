# 目标日期基金

随退休日期临近自动降低风险敞口的基金类型——名字带年份（如 2035），为特定退休人群设计。

## 核心机制：下滑路径

```
年轻时（距离退休远） → 高权益仓位（进取）
退休临近 → 逐步降低权益、提高固收
到达目标日期 → 以固收为主（保守）
```

这种自动调整股债比例的设计被称为**下滑路径（Glide Path）**，用规则替代人工再平衡，解决"人性难以坚持纪律"的行为问题。

## 与目标风险基金的结构性对比

| 维度 | 目标日期基金 | 目标风险基金 |
|------|------------|------------|
| 风险策略 | 随时间自动降风险 | 保持固定风险等级 |
| 命名 | 带年份（如 2035） | 稳健/平衡/积极 |
| 投资者主动度 | 低（设好不管） | 高（需自行调整） |
| 适用人群 | 希望省心、有明确退休日期 | 有风险判断能力、愿意主动管理 |

## 边界条件

- **假设所有人退休后需求相同**：个体差异（不同风险偏好、其他资产状况）被忽略
- **下滑路径的假设未必正确**：并非所有人退休前后风险偏好都线性下降
- 不能完全替代对自身风险偏好的独立判断

## 与相关概念的关系

- [[生命周期基金]]：目标日期基金是生命周期基金的典型形态，两者在核心机制上一致
- [[目标风险基金]]：对比参照，风险策略的根本差异
