# 短期刚性目标配置

## 定义

**短期刚性目标**：指≤1年内必须动用、容错空间几乎为零的资金用途（如旅游、年假、短期大额支出）。这类资金的风险容忍度接近于零，配置优先级是**保本 + 流动性**，而非收益最大化。

## 核心规则

```
短期刚性目标(≤1年) → 风险容忍度 ≈ 0
  → 资产必须保本优先
  → 股票等权益类资产不可接受（1年亏损概率≈50%）
  → 最优工具：货币基金 / 短债
```

## 形式化约束

```
目标时间 t ≤ 1年
要求集合 R = {高流动性, 保本, 收益 ≥ 存款利率}
工具选择 = argmin(风险)  s.t. 工具 ∈ R
→ 货币基金、短债满足 R，存款次之（收益较低）
→ 权益类资产 ∉ R（不满足保本）
```

## 与相关概念的关系

### 投资时间框架原则

[[concepts/投资时间框架原则]] 提出"时间短→买低风险资产"的通用规则。本文将其精确化为≤1年的硬性约束，并用"股票1年亏损概率≈50%"这一数据锚定决策。

### 分层水池策略

[[concepts/分层水池策略]] 的第一层定义为"1-3年"，本文的"≤1年刚性目标"比第一层更严格——它要求的是**零容错**而非低容错。两者互补：本文是分层水池最底层（最严格层）的具体操作规范。

### 目标倒推法

[[concepts/目标倒推法]] 解决"怎么存够"的问题，短期刚性目标配置解决"存够了放哪里"的问题，二者是同一流程的不同环节。

### 三钱包分配法

[[concepts/三钱包分配法]] 解决"怎么隔离"的问题，短期刚性目标配置解决"隔离后怎么配"的问题，前者是心理账户机制，后者是资产配置规则。

## 边界条件

- 如果目标时间从≤1年扩展到3-5年，风险容忍度提升，可配置部分权益类资产
- 如果收入连"过去+现在"都紧（入不敷出），三钱包框架本身不成立，需先解决现金流问题
- 极端流动性危机下，货币基金也可能赎回延迟（概率极低），此时现金是唯一完全保本的替代品

## 典型场景

| 场景 | 目标时间 | 风险容忍度 | 推荐工具 |
|------|---------|-----------|---------|
| 旅游基金 | 6个月-1年 | ≈0 | 货币基金 / 短债 |
| 年假预算 | 3个月 | ≈0 | 货币基金 |
| 紧急备用金 | 随时 | ≈0 | 货币基金 |
| 购房首付 | 1-3年 | 低 | 短债 / 固收+ |
| 子女教育金 | 5-10年 | 中 | 固收+ / 平衡基金 |
