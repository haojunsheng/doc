# Human-in-the-loop Agent

## 定义

在 Agent 执行流程中保留人工介入环节的设计模式。论证了 Agent 在可见未来不可能完全"自主"的核心论据。

## 为什么 Human-in-the-loop 不可或缺

| 原因 | 说明 |
|------|------|
| 价值判断 | Agent 可以优化指标，但"什么值得优化"需要人类设定 |
| 安全兜底 | 高 stakes 场景（医疗、金融）必须有人的最终否决权 |
| 未知场景 | 训练分布外的情况，Agent 可能产生危险行为 |
| 责任归属 | 出了事谁负责？人类必须在环中才能追责 |

## 介入方式

```
┌─────────────────────────────────────┐
│  Agent 自主执行                      │
│  ┌───┐  ┌───┐  ┌───┐  ┌───┐       │
│  │思考│→│行动│→│观察│→│思考│ ...   │
│  └───┘  └───┘  └───┘  └───┘       │
│       ↑               │             │
│       │    关键节点    │             │
│       └───[人工确认]──┘             │
└─────────────────────────────────────┘
```

- **执行前确认**：高危操作前要求人工批准
- **执行中干预**：Agent 遇到不确定时主动请求指导
- **执行后 review**：定期审查 Agent 的行为日志
