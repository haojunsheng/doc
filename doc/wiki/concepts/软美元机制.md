# 软美元机制（Soft Dollar）

软美元（Soft Dollar）是指基金以高于市场标准的交易佣金换取券商提供的研究、销售、软件数据等隐性服务，而非以现金形式直接支付这些服务的费用。这种机制导致投资者的隐性交易成本远高于散户个人投资者。

## 机制核心

```
基金交易佣金（万八，0.08%）
    ↓
超出散户标准佣金的部分（万六~万六，0.06%-0.06%）
    ↓
换取券商研究服务、销售支持、软件数据等隐性服务
    ↓
这些服务成本由基金投资者间接承担，而非基金公司独立支付
```

## 基金 vs 散户佣金对比

| 投资者类型 | 交易佣金 | 可购买的服务 |
|-----------|---------|------------|
| 散户个人 | 万二~万三（0.02%-0.03%） | 仅交易执行 |
| 主动基金 | 万八（0.08%） | 交易执行 + 券商研究 + 销售 + 软件数据 |
| 被动基金（ETF/指数） | 万二（0.02%） | 仅交易执行（软美元被禁止） |

基金佣金约为散户佣金的 **4 倍**，差额部分即用于支付软美元服务。

## 监管动态

- **欧洲**：2018 年禁止软美元，要求将研究服务与交易执行分开定价并单独披露
- **美国**：未禁止软美元，但监管设上限限制软美元的使用空间
- **中国**：2023 年降费改革将基金交易佣金纳入降费范围，但未明确禁止软美元机制

## 影响

- 软美元机制使基金的隐性交易成本成为投资者综合成本的组成部分
- 被动基金（ETF/指数）因禁止软美元，综合交易成本显著低于主动基金
- 这是[[显性费率与隐性费率]]中隐性费率的重要组成部分，解释了为何基金交易成本远高于散户

## 边界条件

- 软美元服务的价值难以量化，基金公司是否真的为这些服务支付了合理对价存在争议
- 若市场波动加大导致换手率上升，软美元带来的隐性成本会同步放大
- 降费改革后基金佣金有所下降，但软美元机制本身在中国尚未被明确禁止
