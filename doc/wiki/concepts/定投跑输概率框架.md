# 定投跑输概率框架

定投时间越长，跑输一次性买入的概率越高——这是一个反直觉但被数据验证的规律。

## 核心结论

- 在趋势向上市场中，分批定投有**超过一半时间跑输**一次性买入
- 定投期限越长，跑输概率越高：资金被推迟入市的程度越深
- 这一规律只在"市场长期向上"假设下成立

## 数据支撑

| 定投期限 | 跑输一次性买入的概率 |
|---------|-------------------|
| 5年 | 72% |
| 10年 | 83% |

数据来源：晨星中国，2005-2026年沪深300回测。

## 形式化

```
跑输概率 = f(定投期限, 市场趋势方向)

当市场趋势向上：
  跑输概率随期限单调递增
  原因：更多资金被推迟入市，错失期间涨幅

当市场长期横盘/下跌：
  跑输概率反转（定投可能跑赢）
  但此类行情下投资者最难坚持定投
```

## 边界

- 结论依赖"市场长期向上"假设
- 若考虑闲置资金收益（货币基金等），跑输概率可能降低
- 定投赢得的场景（先大跌后反弹、整体≤0）恰恰最难执行
