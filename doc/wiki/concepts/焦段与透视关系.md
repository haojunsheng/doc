# 焦段与透视关系

## 核心纠正

> **焦段不改变透视；焦段决定的拍摄距离才改变透视。**

这是一个广泛存在于摄影教学中的常见误区。很多教材说"长焦压缩空间"，这个说法是错误的——真正改变透视的是拍摄距离，焦段只是间接通过影响拍摄距离而产生效果。

## 为什么会有这个误区

- 使用广角镜头时，摄影师必须走近被摄体，此时近大远小的透视关系被放大
- 使用长焦镜头时，摄影师必须退后，此时透视被压缩

人们把"走近拍"和"走远拍"造成的透视变化，错误地归因于焦段本身。

## 正确的因果链

```
选择焦段 → 决定拍摄距离 → 决定透视效果
```

具体来说：
- **广角（28mm）**：为了填满画面，必须走近 → 距离比大 → 透视夸张
- **长焦（200mm）**：为了填满画面，必须走远 → 距离比小 → 透视压缩

如果保持拍摄距离不变，只换焦段，透视不会改变，只会改变取景范围。

## 焦段在曝光中的角色

焦段**不参与**曝光计算。F 值已经将焦段约掉：F8 在 28mm 和 200mm 上的曝光量完全相同。

焦段的唯一作用是控制取景范围（视角），以及通过决定拍摄距离间接影响透视。
