# 频繁交易成本复利侵蚀

个人投资者因频繁买卖股票或基金而产生的交易成本（佣金、印花税、买卖价差），通过复利机制在长期持有期内持续侵蚀投资收益的行为机制。

## 核心机制

```
频繁交易 → 每笔交易成本累计 → 净收益被逐步蚕食
持有不动 → 无交易成本 → 复利完整积累
长期差异：高频交易者 vs 低换手持有者的收益差距随时间指数扩大
```

## 成本构成

| 成本项目 | 说明 | 典型范围 |
|---------|------|---------|
| 佣金 | 券商收取的交易服务费 | 万分之几到千分之几/笔 |
| 印花税 | 卖出时征收（A 股） | 0.05%（单边） |
| 买卖价差 | 买入价与卖出价之间的Spread | 视流动性而定 |
| 冲击成本 | 大额订单对价格的短期影响 | 视规模而定 |

> 注：以上成本每次往返（买+卖）至少产生一次，若频繁换仓则累计效应显著。

## 形式化对比

**情景 A：每年换手 4 次**
- 假设年化收益率 10%
- 每次往返成本 0.5%（佣金+印花税+价差估算）
- 年化成本侵蚀：4 × 0.5% = 2%
- 净年化收益：8%

**情景 B：持有不动，5 年不换手**
- 年化收益 10%，复利累积
- 5 年后：(1.10)^5 = 1.611 倍
- 情景 A 5 年后：(1.08)^5 = 1.469 倍
- **差距：约 9.7% 的绝对收益差**

> 差距随持有期延长而指数扩大，正是"复利侵蚀"的含义。

## 深层逻辑

频繁换仓不仅仅是成本问题，其本质是**择时行为**——试图预测短期价格变动。[[择时的心理陷阱]] 指出大多数人的择时判断是错误的，因此高频换手同时面临：
1. 更高的交易成本
2. 更高的错误择时概率
3. 错过最佳交易日（[[80-20收益时间分布]]）的风险

三者叠加，使频繁交易成为新手收益率被侵蚀的最主要来源之一。

## 边界与限制

- **市场发生根本性变化时**（行业长期衰退、公司基本面恶化），频繁调整是必要的，此时成本代价低于不调整的亏损代价
- **低成本环境下差异缩小**：若交易成本极低（如零佣金券商），侵蚀幅度减小，但择时错误的风险依然存在
- **主动管理基金**的换手率本身较高，个人投资者在此基础上再频繁调仓，会产生双重成本

## 与相关概念的关系

- [[追涨杀跌损益侵蚀]]：方向错误（追涨杀跌）+ 频率过高（频繁换仓），两者常常同时发生，形成双重侵蚀
- [[综合费率]]：机构层面的综合费率讨论与个人交易成本属于同一类成本问题，视角不同
- [[基金经理换手率评级]]：将机构换手率概念扩展到个人行为层面，形成对称理解
- [[无聊的投资]]：本文与"无聊投资"理念一致——少动、低成本、长期持有才是最优策略

## 行动启示

1. 交易前先问：这笔交易的预期收益能否覆盖往返成本？
2. 将交易频率纳入收益评估：扣除全部成本后再评估策略是否真正有效
3. 若持仓逻辑未变，不因短期波动而更换标的
4. 使用指数基金等低换手工具，降低自身交易频率
