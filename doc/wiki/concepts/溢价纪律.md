# 溢价纪律

在境内QDII通道拥挤时，场内跨境ETF常出现显著溢价。溢价纪律是一套基于溢价率做决策的可操作规则，核心原则是：溢价越高，越不应该买入。

## 规则

| 溢价率 | 行动 |
|---|---|
| ≤ 1% | 正常考虑，关注底层资产估值和自身组合需求 |
| 1% - 3% | 谨慎，评估溢价来源和持续时间 |
| 3% - 5% | 回避，溢价已在为通道情绪付费 |
| > 5% | 不碰，高溢价买入等于给通道情绪交税 |
| > 10% | 绝对禁区，此时买的是情绪而非资产 |

## 逻辑

场内溢价本质上是通道摩擦的显性化：一级市场申购受限 → 套利机制失灵 → 二级市场买盘把价格推到净值之上。溢价不是阿尔法，是通道拥堵税。

溢价纪律的关键认知：**场内ETF溢价再高，也不意味着底层资产更值钱了，只意味着通道更拥挤了。**

## 与联接基金的关系

场外ETF联接基金看似绕开了场内溢价，但如果目标ETF本身溢价严重，联接基金在换购时也会承受更高的成本，间接传导给投资者。因此，溢价纪律同样适用于联接基金——只是传导路径更长、更难观察。

## 应用范围

溢价纪律最初来自纳斯达克QDII通道的分析，但其逻辑适用于所有存在套利失灵可能的跨境ETF：

- 纳斯达克100相关ETF（广发、华夏、嘉实、华安、招商等）
- 标普500相关ETF
- 其他因额度限制导致一级市场申购受限的跨境产品

## 与 [[concepts/不可能三角-收益风险流动性]] 的关系

高溢价买入本质上是用安全边际（价格）换流动性（立刻买到）。溢价纪律提醒：当流动性溢价超过一定阈值，这笔交易不再划算。
