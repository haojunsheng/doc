# 现金垫标准

**核心论点**：现金垫是流动资产中可随时支取的部分，3–6 个月生活费是「失业缓冲期」的标准——够你找到下一份工作而不被迫卖资产或借高利贷。

## 标准公式

```
现金垫下限 = 月必要开销 × 3（保守底线）
现金垫上限 = 月必要开销 × 6（宽裕保障）
```

## 为什么是 3–6 个月？

- 失业后找到新工作的平均周期是 1–3 个月，3 个月是「最坏情况」的保底线
- 如果行业不景气或经济下行，找工作可能需要更久，6 个月是安全边际
- 现金垫不足 → 失业时被迫卖股票（可能割肉）、借消费贷（高利息）、卖房（周期长且折价），都是「被迫贱卖资产」的财务灾难

## 收入结构调整规则

| 收入类型 | 现金垫建议 | 理由 |
|---------|-----------|------|
| 收入来源多元（多份兼职、租金收入） | 可低于 3 个月 | 失业风险分散 |
| 单一收入来源 | 3–6 个月 | 标准下限 |
| 单一高波动行业收入 | 需 > 6 个月 | 失业周期不可预测 |
| 自由职业者 | 建议 6 个月+ | 无稳定雇主保障 |

## 现金垫不足的风险链

```
现金垫 < 3个月 → 失业时被迫决策 → 贱卖资产 / 借高息债 → 财务危机恶化
```

这也解释了 [[现金流断裂风险]] 的触发机制：断裂往往不是因为收入减少，而是因为现金垫不足以支撑过渡期。
