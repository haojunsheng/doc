# 加密资产国家战略

加密资产国家战略是指将加密货币（尤其是比特币）纳入国家层面金融战略的政策框架，包括将其列为战略储备资产、放松监管、支持矿业发展等一揽子举措。这一概念的核心载体是特朗普政府时期的加密政策议程。

## 政策框架

| 政策主张 | 具体内容 | 象征意义 |
|---------|---------|---------|
| 战略储备资产 | 将比特币列为美国国家战略储备资产 | 赋予BTC制度层面的"国家信用背书" |
| 组建总统委员会 | 成立比特币总统委员会 | 顶层设计加密政策方向 |
| 解雇SEC主席 | 上任第一天解雇Gensler | 清除监管障碍，转向宽松 |
| 支持挖矿用电 | 保障加密货币挖矿的电力供应 | 产业支持政策 |

## 核心逻辑

```
加密资产国家战略 = 制度合法性 + 产业支持 + 监管松绑
    ↓
比特币从"边缘投机资产" → "国家战略储备资产"
    ↓
价格发现机制从纯市场 → 叠加国家信用溢价
```

## 特朗普的角色

- 2024年比特币大会上宣称比特币市值将超越黄金
- 自称"加密货币总统"
- 承诺上任后推动上述一揽子政策

## 边界条件

- **国会制约**：若国会反对，战略储备立法可能受阻，政策落地存疑
- **政策可持续性**：行政命令的效力有限，需立法确认才能持久
- **国际协调**：单一国家政策难以改变全球加密资产定价结构
