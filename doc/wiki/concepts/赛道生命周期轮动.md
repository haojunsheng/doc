# 赛道生命周期轮动

赛道生命周期轮动是指：任何一个投资主题（赛道）都会经历从冷门到热门再到过热的完整周期，不存在永恒的热门赛道，只有持续轮动的市场风格。

## 生命周期模型

```
小登(新赛道) → 热门(资金涌入) → 老登(资金撤离) → 下一轮小登
```

### 三个阶段

| 阶段 | 特征 | 投资者行为 | 风险 |
|------|------|-----------|------|
| 小登 | 新兴赛道，关注度低 | 早期发现者入场 | 流动性风险、验证风险 |
| 热门 | 资金蜂拥，估值推高 | 追高买入 | 估值透支风险 |
| 老登 | 热度消退，资金撤离 | 恐慌卖出 | 高买低卖亏损 |

## "老登资产/小登资产"是伪命题

市场上常有人争论"白酒是老登资产"还是"科技是小登资产"，但这种二分法是错误的：

- 白酒曾是上一轮牛市最锋利的"矛"，如今被嘲讽为"老登"
- 科技曾是"小登"，追高的投资者最近才从坑里爬出来
- **没有永恒的热门赛道，只有不断轮动的市场风格**

## 与已有概念的关联

- [[赛道估值透支]]：解释了"热门→过热→透支→回调"的传导机制，是生命周期模型的恶化版本
- [[近因效应]] + [[线性外推]]：投资者将近期表现当作永久趋势，在"热门"阶段追高，在"老登"阶段恐慌
- [[均值回归]]：赛道从热门回归平庸是概率性事件，而非异常
- [[宏大叙事]]：热门赛道的"未来可期"叙事正是生命周期热门阶段的典型特征
- [[拥挤交易]]：资金蜂拥进入热门赛道形成类拥挤交易，当风向转变时引发踩踏
- [[风格跷跷板]]：A 股风格切换加速了赛道的生命周期轮动

## 实操启示

1. 避免在赛道已成为市场共识、媒体大量报道时入场——此时通常处于"热门→过热"阶段
2. 区分"有长期增长潜力的赛道"与"纯概念炒作型赛道"——前者可能完成生命周期轮回，后者则不会
3. 理解赛道轮动是结构性特征，而非个体认知问题——即使看懂了方向，入场时机也至关重要
4. 控制仓位（≤20%）+ 严格止损纪律，是应对赛道不确定性的可行方案
