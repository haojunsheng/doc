# 美国出口管制政策（半导体与超算）

## 定义

2023 年起美国对中国实施的半导体及超算设备出口限制政策，是英伟达面临的最大下行风险来源。

## 核心逻辑

```
出口管制 → 中国市场↓ + 全球供应链多元化 → 英伟达市占↓
```

## 政策演进

- **2023 年**：美国对中国半导体和超算行业实施出口限制，禁止高性能 AI 芯片出口中国
- 英伟达被迫推出"特供芯片"（如 A800/H800 降规版）以满足中国市场需求
- "特供芯片"能否满足中国客户实际需求存疑

## 对英伟达的影响路径

| 影响路径 | 机制 |
|---------|------|
| 中国市场收入压缩 | 高端芯片禁售，特供版性能受限，客户流失 |
| 供应链多元化压力 | 中国客户被迫寻找非英伟达替代方案 |
| 长期锁定效应松动 | 客户转向其他生态，CUDA 锁定效应被削弱 |
| 管制扩展风险 | 管制范围可能从中国扩展至其他国家 |

## 与 CUDA 生态锁定的张力

[[CUDA生态锁定]] 构成英伟达的核心护城河，但出口管制从外部侵蚀了这一锁定效应：
- 政策迫使中国客户寻找替代方案
- 替代方案可能转向 AMD、华为等生态
- 一旦客户迁移到其它生态，锁定效应将难以恢复

## 风险缓解边界

- 若管制放松或英伟达成功游说政府放宽限制 → 风险缓解
- 若中国自主芯片（如华为昇腾）未能达到替代标准 → 风险部分缓解
- 若管制扩展至更多国家/地区 → 风险扩大

## 量化缺口

目前缺乏中国市场收入占比的具体数据，限制了出口管制风险的精确量化评估。
