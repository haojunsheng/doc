# 行业重叠风险

行业重叠风险是指多只基金在行业配置上高度重合，导致名义上的分散实际上并未实现风险分散的现象。

## 形式化定义

```
实际分散度 = f(基金数量) × (1 - 行业重叠率)
```

## 核心机制

当投资者同时持有两只"不同类型"的基金（如内生增长 vs 外延增长），但它们的行业配置高度相似时：
- 风险敞口并未真正分散
- 在行业性下跌中，两只基金会同步回撤
- 组合的整体波动性高于预期

## 识别方法

检查以下维度：
1. **前十大重仓股重合度**：两只基金前十大重仓股的重合比例
2. **行业配置相似度**：两只基金行业配置的前三行业是否一致
3. **基金经理能力圈重叠**：两人擅长研究的行业是否有显著重合

## 应对措施

1. **定期持仓穿透**：每季度检查前十大重仓股的重合度
2. **行业暴露控制**：单一行业暴露不超过组合的 20%
3. **风格互补验证**：确认不同类型基金确实提供不同的风险收益来源
