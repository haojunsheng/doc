# 年龄-债券经验法则

一条简单的资产配置经验法则：**债券比例 ≈ 个人年龄**。

## 核心论点

- 年轻人：投资期限长，可承受更多波动，多配股票
- 年长者：投资期限短，应多配债券，降低组合波动
- 债券比例 ≈ 年龄，是一个广为流传的起点规则

例如 30 岁投资者，债券比例约 30%，股票比例约 70%。

## 形式化表达

最优比例 = f(你的目标, 你的风险承受力, 你的投资期限)

年龄法则是上述函数在信息不足时的近似简化。

## 边界条件与局限

- 法则很粗糙，不考虑个人收入稳定性、家庭负担、具体财务目标
- 与 [[concepts/人力资本-金融资产反向配置原则]] 可能产生冲突：30 岁互联网工程师按年龄法则应持 70% 股票，但按人力资本框架（收入像股票）应多配债券——两者需结合使用，而非二选一

## 与 [[entities/马科维茨-markowitz]] 的关系

马科维茨为自己选择 50/50 股债配置，说明即使是理论奠基人也倾向于简单规则，而非执着于复杂模型的最优解。
