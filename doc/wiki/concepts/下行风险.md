# 下行风险

下行风险（Downside Risk）是只考虑负收益波动的风险指标，反映资产收益低于某一目标水平（通常为0或无风险利率）的可能性及幅度——投资者真正关心的是亏损的大小和频率，而非上涨的波动。

## 核心观点

- 标准差把上行风险和下行风险一视同仁
- 投资者只关心**坏波动**（损失），好波动（上涨）对投资者是机会
- 需要区分"好"波动和"坏"波动

## 与相关概念的关系

| 指标 | 是否只考虑下行风险 |
|------|------------------|
| 标准差 | 否（全波动） |
| 索提诺比率 | 是（下行标准差） |
| 下行捕获率 | 是 |

- **与[[标准差-基金波动率]]的区别**：标准差衡量总波动，上涨和下跌都计入；下行风险只计算亏损方向的波动
- **与[[索提诺比率]]的关系**：索提诺比率的分母即为下行风险，衡量单位下行风险带来的超额收益；[[晨星风险系数]]同样以"下行风险"为计算基础，对下行波动惩罚更明显
- **与[[最大回撤]]的关系**：下行风险是统计层面的概率描述，最大回撤是单段极端情况的幅度

## 在风险指标递进链中的位置

[[标准差-基金波动率]] → 下行风险 → [[最大回撤]]

1. 标准差回答"波动大不大"
2. 下行风险回答"向下波动大不大"
3. 最大回撤回答"最惨能惨到哪"

对普通投资者而言，最大回撤比下行风险更直观——它直接给出一个具体数字，帮助你建立心理预期。

## 延伸讨论

索提诺比率的分母使用下行标准差，体现了对下行风险的聚焦。但原文也指出：**上行波动也是机会成本的体现**——在牛市中过度规避波动可能意味着错过收益，这是单一风险指标永远不够的根本原因。

参见 [[最大回撤]]、[[索提诺比率]]。
