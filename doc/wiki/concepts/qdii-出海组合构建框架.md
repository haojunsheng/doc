# QDII出海组合构建框架

在QDII额度稀缺的时代，普通投资者需要系统性的"出海"方法来构建全球化投资组合。本框架整合了三条出海通道、全球化配置的必要性和一套可操作的筛选方法。

## 三条出海通道

投资者可通过三种互补通道配置海外资产：

| 通道 | 覆盖范围 | 目标市场 | 限制条件 |
|------|---------|---------|---------|
| QDII基金 | 最广 | 全球（美股、欧股、新兴市场等） | 额度受限，超50%产品限购 |
| 北向互认基金 | 有限 | 香港市场为主 | 仅限港股/海外债券 |
| 跨境理财通 | 最窄 | 港澳基金 | 仅限大湾区居民 |

- **QDII基金**：覆盖最广但额度紧张。2025年7月外汇局新发30.8亿美元额度后，676只QDII份额中仍有超一半限购，194只限购1万元以内，35只完全暂停认购。
- **北向互认基金**：香港优质基金经批准在内地销售，直接投资港股/海外债券，专业性强但覆盖范围有限。
- **跨境理财通**：大湾区居民专属，通过本地银行/券商购买港澳公募基金，风控严格。

三者互补：QDII（覆盖广）≠ 互认（港股专业）≠ 理财通（风控严）。

## 全球化配置是刚需而非可选项

**核心论点**：A股与发达市场（如美股）的低相关性在长期内存在，多元化配置能系统性改善组合的风险调整后收益。

**实证支撑**（晨星数据，2017年以来滚动10年）：
- 沪深300 + 标普500 组合的夏普比率明显优于纯沪深300
- 沪深300 + MSCI全球 组合同样表现优异
- 反例：沪深300 + MSCI金龙指数近年夏普比率下降（因金龙指数高波动低收益）

**形式化**：
```
全球化配置价值 = f(相关性)
ρ(A股, 美股) < 1 → 组合风险↓ + 夏普比率↑
```

**边界条件**：
- 危机期间（如2008年金融危机）：相关性大幅上升，分散效果弱化
- A股单边牛市（如2015年）：全球化配置可能跑输纯A股组合

## 晨星QDII筛选三步走

1. **评估（基金经理 + 团队 + 策略）**
   - 基金经理及投研团队的能力边界、稳定性、协作效率
   - 投资策略的底层逻辑和实际执行效果
   - 警惕：经理更换或团队不稳定时，历史评估结论可能失效

2. **匹配（风险偏好）**
   - 风险偏好是否匹配，避免风险错配
   - 跨境投资受汇率+市场双重波动，风险承受力评估更为关键

3. **配置（分散化）**
   - 不同风险收益特征的产品科学组合
   - 不同市场、不同策略的分散，而非仅在不同QDII产品间分散

## 长期持有原则

跨境投资的双重波动特性决定了短期择时胜率极低：
- **汇率波动**：人民币升值会侵蚀海外资产本币收益
- **市场波动**：海外市场波动节奏与A股不完全同步
- **长期价值兑现**：低相关性改善夏普比率的效应需要时间体现

**原则**：QDII长期持有 = 克服（汇率波动 + 市场波动）→ 避免追涨杀跌 → 兑现全球化配置的长期价值。

**边界**：若海外市场进入长期熊市（如2000-2002年美股），需重新评估是否继续持有，长期持有≠死拿。

## 额度分配的监管逻辑

额度分配遵循"优先解决溢价过高"原则：监管优先给二级市场溢价高的基金发放额度，剩余才分配给其他产品。这导致即使有新额度释放，部分热门产品仍限购，而冷门产品可能额度充裕但需求不足。
