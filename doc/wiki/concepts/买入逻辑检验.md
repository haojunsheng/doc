# 买入逻辑检验

卖出决策的核心标准是"当初为什么买"——买入逻辑是否还成立，而非"亏了多少"。这是区分理性投资决策与情绪化行为的分水岭。

## 核心原则

```
不该卖的理由：买入逻辑依然成立
该卖的理由：买入逻辑已被证伪
```

## 两种买入逻辑及检验清单

### 逻辑1：看好行业/赛道（趋势投资）

**证伪条件**：行业趋势出现根本性逆转

检查要点：
- 行业景气度是否仍在上升？
- 政策环境是否发生不利变化？
- 竞争格局是否恶化？

**检验原则**：只要趋势还在，不必因短期亏损而恐慌。

### 逻辑2：看好基金经理（基本面投资）

**证伪条件**：基金经理的能力或稳定性出现重大问题

检查清单：
| 检查项 | 合格信号 | 风险信号 |
|--------|---------|---------|
| 经理是否更换 | 无变动 | 换将，且新经理理念差异大 |
| 操作是否变形 | 风格稳定 | 追涨杀跌、风格漂移 |
| 业绩持续性 | 持续跑赢同类 | 单年度拖累 vs 持续落后 |

## 与纪律化止损的对照

[[止损纪律与触发条件]] 强调预设规则驱动的止损，适用于量化/规则驱动策略；买入逻辑检验适用于基本面/主观驱动策略。两者并非矛盾，而是适用场景不同：

- **纪律化止损**：价格触发 → 机械执行，适合规则型投资者
- **买入逻辑检验**：逻辑证伪 → 理性判断，适合基本面型投资者

共同底线：止损不应是恐慌驱动的情绪反应，而应有明确的触发条件。

## 与回本心理的关联

[[回本心理]] 揭示了更深层的心理动因：很多人持有亏损基金不是因为买入逻辑还在，而是因为不愿意承认逻辑从未存在过。买入逻辑检验提供了一种更理性的退出判断标准，帮助投资者跨越"不愿承认错误"的心理障碍。

## 实践步骤

1. 买入前写下：我为什么买这只基金？（具体到可检验的假设）
2. 定期回顾：这些假设是否仍然成立？
3. 触发退出：假设被证伪时，无论盈亏都应考虑退出
