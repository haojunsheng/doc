# 隐藏价值

## 定义

**隐藏价值**是指资产真实价值未在公开信息（如财报）中充分反映，因而被市场系统性低估的定价偏差。发现隐藏价值需要超越报表数字的深度研究能力。

## 邓普顿日本案例

1950年代，邓普顿几乎全仓日本股市。当时战后日本遍地废墟，市场极度悲观，但邓普顿发现：

- 日本公司财报不完整，没有充分披露子公司的真实资产状况
- 实际资产价值远超报表市值
- 劳动力市场有前途
- 低估值提供安全边际

这一案例是"隐藏价值"的典型应用：市场因悲观预期而低估了日本企业的真实资产价值，邓普顿通过深度研究发现了这一偏差。

## 价值发现路径

```
公开财报信息 → 表面市值（低估）
公开财报信息 + 深度研究 → 真实资产价值
→ 发现隐藏价值 → 逆向买入机会
```

## 边界与风险

- **信息不对称**：邓普顿的信息优势源于深度研究能力，普通投资者难以复制
- **持续性**：隐藏价值被发现后会被市场逐步修正，先发优势会随时间消失

## 与普通投资者的关系

对大多数人而言，识别"隐藏价值"所需的深度研究能力（如审计子公司账目、跨国调研）不可得。因此：

- [[逆向投资]] 对普通人的真正价值在于"思考习惯"层面（主动寻找反面证据），而非"交易策略"层面（发现隐藏价值）
- 普通投资者更适合通过[[分散化对冲逆向风险]]和低成本指数工具参与，而非尝试发掘隐藏价值
