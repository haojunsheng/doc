# 简单可坚持原则

简单组合更容易坚持，而「坚持」是投资成功最大的变量。

## 核心命题

```
复杂组合 → 需要更多时间和知识维护 → 容易在恐慌时乱操作 → 实际收益低于简单组合
简单组合 → 无需盯盘 → 可以完全不管 → 10 年后再打开
```

## 实证支撑

Vanguard 研究：简单三因子组合（股票+债券+现金）的长期回报，与复杂多因子策略差距 <1%。

## 边界条件

- **"简单"≠"粗糙"**：简单组合仍需考虑资产类别、地域分散、费用控制
- **执行率是关键变量**：再完美的组合若无法坚持，收益归零；简单组合执行率高，实际收益反而更高
- **与资产配置优先原则互补**：配置决定方向，简单保证执行
