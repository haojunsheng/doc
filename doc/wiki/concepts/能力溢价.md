# 能力溢价

## 定义

投资者支付高于市场平均的费率，换取足以覆盖成本的超额收益。高费率不是"成本劣势"，而是对投资管理能力的付费。

## 核心逻辑

```
能力溢价 = 高费率（支付） + 超额收益（回报） → 净收益仍优于市场平均
```

## 判断框架

| 维度 | 关键问题 |
|------|---------|
| 费率水平 | 是否显著高于同类平均？ |
| 超额收益 | 是否持续覆盖费率差异？ |
| 风险调整后收益 | 夏普比率等指标是否优秀？ |
| 持续性 | 超额收益是否可重复，还是偶发？ |

## 典型案例

**东方添益债券基金**
- 费率：1.36%（同类平均0.86%，高出0.5个百分点）
- 年化回报：4.97%（同类前2%）
- 夏普比率：同类第8个百分位
- 结论：高费率被超额收益完全覆盖，投资者支付的是能力溢价

## 与费率复利效应的关系

[[费率复利效应]]强调低费率在长期复利下的累积优势；[[能力溢价]]则是反向验证——当基金经理能力足够强时，高费率的复利效应仍为正。两者共同构成费率-收益关系的完整判断框架。

## 边界条件

- 若基金经理业绩下滑，高费率会成为负担
- 若同类基金费率持续下降，高费率会失去竞争力
- 能力溢价的前提是超额收益的可持续性，而非一次性运气
