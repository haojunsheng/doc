# 风险认知双路径

风险认知存在两条路径：**理性告知**与**体验学习**。前者效果有限，后者深刻持久——这是理解风险教育为何常常无效的核心框架。

## 路径一：理性告知

- **方式**：阅读风险提示、观看图表、听讲座、学习理论
- **机制**：激活决策效用层面
- **局限**：抽象数字无法转化为真实感受，"知道"不等于"相信"

## 路径二：体验学习

- **方式**：亲身经历市场波动、真实盈亏体验、叙事替代体验
- **机制**：激活体验效用层面
- **效力**：通过情绪记忆塑造长期行为倾向

## 辩证关系

| | 理性告知 | 体验学习 |
|--|---------|---------|
| 作用层面 | 决策效用 | 体验效用 |
| 效果速度 | 即时 | 渐进 |
| 持久性 | 短暂 | 深刻 |
| 适用场景 | 入门教育 | 深度内化 |

两条路径并非对立，而是互补。理性告知建立认知框架，体验学习填充情感记忆。最有效的风险教育应同时激活两条路径。
