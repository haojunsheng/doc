# 估值分歧：已验证价值 vs 未验证预期

市场估值与专业机构估值之间的差距，本质上是对"未验证技术"的定价分歧。这一框架解释了SpaceX万亿估值差的根源。

## 核心公式

```
市场估值 = 已验证价值 + 未验证预期溢价
专业估值（DCF） = 已验证价值
```

## 维度对比

| 维度 | 已验证价值 | 未验证预期 |
|------|-----------|-----------|
| 数据基础 | 历史现金流、财务数据 | 技术路线图、行业预测 |
| 验证程度 | 已实现或高度可能 | 新颖且未经验证 |
| 折现率 | 相对确定 | 高度不确定 |
| 时间维度 | 过去→现在 | 现在→未来 |
| 案例 | Starlink EBITDA增长86% | Starship完全可重复使用 |

## SpaceX案例分解

晨星7800亿美元估值 = 已验证价值（Starlink现金流 + 发射业务现金流）

市场1.7-2万亿美元估值 = 7800亿 + 约1万亿未验证预期溢价

未验证预期包含三项：
1. **Starship完全可重复使用** — 技术验证中，若成功将大幅降低成本
2. **轨道数据中心商业化** — 概念阶段，应用场景待验证
3. **AI业务正向贡献** — 2025年亏损63.5亿，距离正向贡献遥远

## 与投资判断的关系

这一框架是[[内生价值投资派]]估值方法论的核心工具：
- 先计算已验证价值的底线
- 再评估未验证预期的概率加权价值
- 最终给出区间估值而非点估值

也与[[安全边际]]概念直接相关：未验证预期越多，安全边际要求越高。

## 边界条件

- 若未验证技术突破速度快于预期，专业估值可能偏低
- 若未验证技术迟迟无法验证，市场估值将回归
- SpaceX的案例特殊性：技术突破往往快于市场预期，这是一个重要风险
