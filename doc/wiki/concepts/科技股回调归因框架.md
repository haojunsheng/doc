# 科技股回调归因框架

## 定义

通过归因分析区分科技股下跌的内因（自身估值过高）与外因（关税/地缘冲击），判断调整性质与持续时间的分析框架。

## 形式化表达

```
归因判定:
- 若少数权重股的负回报 > 指数整体跌幅 → 内因主导（估值泡沫破裂）
- 若全市场普遍下跌 → 外因主导（系统性冲击）
```

## 美股 Q1 案例

晨星对美国市场指数的归因分析发现：

| 证据 | 判断 |
|------|------|
| 10只权重股负回报 > 指数整体跌幅 | 内因主导 |
| 其余股票在涨 | 非系统性下跌 |
| 权重股多为AI产业链公司 | 估值泡沫集中于科技股 |

**结论**：下跌是大型科技股自身估值过高后的自我修正，关税不是主因。

## 归因类型扩展

除内因/外因二分法外，还存在第三种归因：**牛市轮动**——非泡沫破裂、非系统性冲击，而是前期涨幅过大后的估值消化式板块切换。典型特征：权重板块回调幅度远大于指数整体跌幅，防御板块同步获得资金流入。详见 [[美股9月回调是结束还是开始]]（来源：notes/20260628T154138--qa-美股9月回调是结束还是开始__qa.md）。

## 与投资判断的关系

- **内因主导的回调**：调整幅度取决于估值泡沫程度，修复需要盈利增长消化估值
- **外因主导的下跌**：一旦外部冲击缓和，市场可能快速反弹

## 边界条件

- 若关税政策超预期升级，外部因素可能压过内部因素成为主因
- 归因结论具有时效性，需持续跟踪后续走势验证
