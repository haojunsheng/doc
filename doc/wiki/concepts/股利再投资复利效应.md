# 股利再投资复利效应

股利不是"没想象力"的现金流，而是股东收益的发动机。西格尔的核心论点：**股利的复利效应被严重低估。**

## 核心机制

股利再投资形成正反馈循环：

1. 公司派发股利
2. 投资者用股利买入更多股份（按当前价格）
3. 下一轮股利基于更大的份额基数计算
4. 长期复利效应显著，尤其在熊市低估值时期

## 西格尔的独特视角

与季凯帆《解读基金》中从"基金分红方式选择"角度讨论红利再投资不同，西格尔从**股票长期回报**角度论证：

- 股利是熊市保护伞：市场下跌时，股利再投资能用更低价格积累更多份额
- 股利是收益加速器：复利效应使长期回报显著高于只看股价涨幅
- "增长"必须拆成两半：经济增长属于社会，投资回报属于买入价格、股利、利润和预期差

## 应用要点

- 熊市是股利再投资的黄金窗口：价格越低，同样股利买入越多份额
- 长期持有 + 股利再投资，是穿越周期的核心策略
- 与 [[concepts/价格阶梯]] 配合：买入价格决定股利再投资的效率
