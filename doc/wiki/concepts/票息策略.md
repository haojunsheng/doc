# 票息策略

2026年纯债投资的核心主线，以持有至到期获取票息收入为主要收益来源，放弃对资本利得的过度依赖。

## 适用背景

- 利率中枢平稳，波动有限
- 中短端信用利差压缩空间已极其有限
- [[债市震荡格局]] 下波段操作难度大、收益不确定

## 形式化表达

```
利率震荡 × 低利率环境
→ 资本利得↓
→ 票息收入 = 核心收益来源
```

## 边界条件

- 若经济数据大幅超预期或央行突然收紧，利率上行将导致票息策略跑输
