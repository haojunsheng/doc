# 双向定价

地方政府在土地供应中实行**工业用地低价 + 商住用地高价**的双向定价策略，这是解释招商引资竞争与房价高企并存的制度性原因。

## 机制

| 用地类型 | 定价策略 | 目的 | 收益归属 |
|---------|---------|------|---------|
| 工业用地 | 低价出让，甚至零地价+补贴 | 吸引制造业落地，带来就业/GDP/增值税 | 税源（长期） |
| 商住用地 | 高价出让（招拍挂垄断） | 获取土地出让收入，充实地方预算 | 土地出让金（短期现金流） |

## 为什么能同时成立

这两个策略看似矛盾（一边压低地价一边抬高地价），但在[[土地财政]]+[[土地金融]]的框架下高度自洽：

1. 工业用地低价 → 制造业集聚 → 就业增加 → 城市人气上升 → 商住用地需求增加 → 地价上涨
2. 商住用地高价 → 土地出让收入 → 用于基建 → 进一步吸引制造业 → 循环强化
3. 同时，[[土地金融]]以土地为抵押撬动信贷，让地方政府在卖地收入之外还有更大投资能力

## 对房价的解释

双向定价同时解释了两个现象：

- **房价为什么高**：商住用地供给受控，招拍挂制度下价高者得，土地出让金成为地方预算外收入的核心来源。
- **为什么各地还在竞相招商引资**：工业税源是地方核心利益，低价工业用地是有竞争力的招商工具。

这两种策略在财政激励上互补，而非冲突。

## 在因果链中的位置

```
分税制上收财权
  → 地方预算内财力缩水
  → 双向定价（工业低价 + 商住高价）
  → 招商引资竞争 + 房价上涨
  → 宏观后果：区域差距扩大、债务累积
```

双向定价是"以地谋发展"模式中最具操作性的政策工具层。

## 证据强度与局限

- 理论推演强：逻辑链条清晰，能同时解释多个现象。
- 缺乏严格因果识别：房价受人口、货币、预期等多重因素影响，双向定价是重要制度因素但不是唯一因素。
- 数据可得性：工业用地底价和商住用地成交价有公开数据，但实际定价过程中的博弈细节较难精确量化。
