# 分类比较（Comparative Classification）

基金评价不应看绝对排名，而应在**"正确的比较组"**内判断优劣。这是晨星评价体系的方法论根基，也是规避[[冠军魔咒]]的核心工具。

## 定义

分类比较是一种基金评价原则：只有将基金放入与其资产类别、投资风格、市值规模相匹配的比较组中，星级排名和投资决策才有意义。跨类别比较本质上是噪音。

> **操作口诀：先看分类，再看星级。** 分类是基石，星级是上层建筑。

## 三层分类逻辑

```
第一层：资产类别分组（股票 / 债券 / 货币 / 商品）
第二层：投资风格分组（大 / 中 / 小盘 × 价值 / 平衡 / 成长 = 九宫格）
第三层：同类内排名（星级评价）
```

每上一层，比较的颗粒度越细，噪音越少，但样本量也随之缩小。

## 为什么要分类比较

### 冠军魔咒的反面

当年全市场或大类资产排名第一的基金，来年大概率大幅回落。这是因为其优异表现往往源于"押中某一风格"，而非持续选股能力。分类比较剥离了风格的干扰，让评价聚焦于真正的管理阿尔法，而非运气。

### 隐喻框架

文章使用"大考"和"放榜"的教育隐喻：**不要只看总分，要看哪个科目得了多少分**。全市场排名是"总分"，分类比较是"分科得分"。让游泳运动员和跑步运动员同场竞技毫无意义。

## 辩证视角

- **正题**：没有比较就无法判断好与差，绝对收益本身没有参照系。
- **反题**：简单比较（如全市场排名）会误导投资者——不同风格的基金混在一起比，就像苹果和香蕉不能比。
- **合题**：分类比较提供更公平的评价方式，但分类本身也不是绝对的——基金风格会漂移，分类边界有模糊地带。

## 分类的局限

1. **部分过滤**：分类只能"部分过滤"风格影响，同一分类内基金在行业配置、集中度、换手率等方面仍有巨大差异。
2. **滞后性**：晨星分类基于过去三年的平均持仓计算，每半年更新一次；风格漂移发生时，分类会滞后反映。需配合[[晨星投资风格箱]]（基于当前持仓）交叉验证。
3. **边界模糊**：有些基金横跨多个分类，无法简单归入九宫格的某一个格子。
4. **粒度困境**：分类过细则样本量不足，星级评价失去统计意义；过粗则无法剥离风格因素。这个张力目前没有完美解决方案。

## 与相关概念的关系

- [[晨星投资风格箱]] — 基于当前持仓的动态分类，与分类的滞后性形成互补。
- [[星级评级]] — 星级是分类比较的产物，建立在"同类可比"这一前提条件之上。
- [[冠军魔咒]] — 分类比较的核心动机；不看分类而追逐全市场冠军，必然落入魔咒。
- [[风格漂移]] — 分类的滞后性与风格漂移是同一枚硬币的两面；分类 vs 风格箱的不一致是识别漂移的信号。

## 一句话

```
分类比较 = 在正确的比较组中判断优劣，而非在全市场中追逐绝对排名。
```
