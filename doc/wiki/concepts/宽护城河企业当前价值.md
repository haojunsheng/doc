# 宽护城河企业当前价值

## 定义

在经济放缓期，拥有宽阔护城河的企业比缺乏竞争力的企业更具稳定性，且当前估值已降至区间底部，提供较高安全边际。

## 核心逻辑

```
护城河宽 → 经济下行时盈利稳定 + 当前估值底部 → 高安全边际
```

## 护城河的抗风险机制

晨星五维护城河框架在经济放缓期的作用：

| 护城河类型 | 抗风险机制 |
|-----------|-----------|
| 网络效应 | 用户粘性高，流失成本低 |
| 无形资产 | 品牌溢价保护定价权 |
| 成本优势 | 低成本结构应对价格竞争 |
| 转换成本 | 客户锁定减少流失 |
| 有效规模 | 市场容量限制新进入者 |

## 与[[护城河策略]]的关系

[[concepts/护城河策略]]提出护城河选股方法，本文补充了"经济放缓期+估值底部"的当下有效性判断——这是当前环境下护城河策略的最佳介入时机。

## 边界条件

- 护城河本身不能抵御系统性风险，市场整体下跌时仍会回撤
- 需区分"护城河宽但估值合理"与"护城河宽但估值透支"两种情况
