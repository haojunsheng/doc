# 红利再投资

分红不计现金，直接转为基金份额——复利机制，长期持有的关键配件。

## 核心机制

基金分红有两种方式：
- **现金分红**：分红以现金形式发放，投资者账户收到钱
- **红利再投资**：分红自动转换为基金份额，不产生现金流

对于长期投资者，红利再投资是更优选择——分红直接增加持仓份额，下一轮分红基于更大的份额基数计算，形成复利效应。

## 决策要点

| 考量因素 | 现金分红 | 红利再投资 |
|---------|---------|-----------|
| 现金流需求 | 需要当期现金收入 | 无现金需求 |
| 复利效应 | 无 | 有——分红再投入增加份额 |
| 税率影响 | 通常免税或低税 | 通常免税或低税 |
| 长期积累 | 不利于长期增长 | 最大化长期复利 |
