# 催化剂vs根源区分

## 定义

区分市场事件中"催化剂"（加速暴露的触发因素）与"根源"（导致结果的内在原因）的分析框架。错误地将催化剂当作根源，会导致错误的投资判断。

## 形式化表达

```
根源: 估值见顶时间 < 催化剂出现时间
催化剂: DeepSeek等外部事件只是加速暴露，非原因
```

## DeepSeek案例

| 维度 | 判断 |
|------|------|
| AI概念股估值见顶时间 | DeepSeek出现之前 |
| DeepSeek的作用 | 加速泡沫暴露的催化剂 |
| 根源 | 内部估值过高 |
| 结论 | 即使DeepSeek没出现，调整可能延后但幅度未必更小 |

## 投资含义

- 当市场归因于某个催化剂事件时，需追问：根源是什么？
- 催化剂消失后，根源仍存在 → 风险未解除
- 找到根源才能判断调整何时结束
