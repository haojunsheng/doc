# 噪音vs趋势区分

机构面对宏观不确定性时，需在短期防御与长期配置之间找平衡，区分短期新闻噪音与长期结构性趋势是核心方法论。

## 核心形式化

```
噪音: 短期新闻事件 | 趋势: 地缘格局 + 利率周期 + 经济放缓
机构决策: 在防御(短期)与长期配置(趋势)间找平衡
```

## 主要不确定性来源

机构认定的五大不确定性：

1. 俄乌冲突
2. 巴以冲突
3. 中国影响力提升
4. 利率走向
5. 全球多场关键大选

## 与相关框架的关系

- **vs [[长期视角过滤噪音]]**：后者用 10 年维度过滤噪音，是本概念的时间维度具体化
- **vs [[AI投资决策渗透]]**：AI 工具可以帮助处理海量信息以区分噪音与趋势，但也可能因模型同质化导致集体误判
- **vs [[全球机构减持美国配置]]**：关税、美元波动是短期噪音还是长期趋势？机构用不同标尺衡量，导致区域差异

## 边界条件

噪音和趋势的区分本身具有主观性，事后才能准确判断——暗示机构也可能误判。
