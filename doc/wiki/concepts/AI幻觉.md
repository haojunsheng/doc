# AI幻觉

## 定义

生成式AI（ChatGPT、Claude等）输出的内容看似真实、逻辑自洽，但其中包含的数字、文献引用、事实陈述完全虚构或查无此据的现象。在中文语境中也称为"一本正经地胡说八道"。

## 表现形态

| 类型 | 示例 |
|------|------|
| 编造文献引用 | "根据XX大学2023年研究报告……"——报告不存在 |
| 编造数据 | 给出精确到小数点后两位的行业规模数字，但查不到来源 |
| 逻辑自洽但前提错误 | 推理过程严密，但初始假设是错的 |
| 张冠李戴 | 把A公司的数据说成B公司的 |

## 在行研中的风险等级

**最高风险项**。肖璟将AI幻觉列为行研使用AI的"红线约束"：

> 所有AI给的数字和文献 → **必须回到一手来源交叉验证**。

## 适合/不适合AI的场景

| 研究阶段 | ✅ 适合AI | ⚠️ 不适合AI |
|---------|----------|------------|
| 初始扫盲 | ✓ | ✗ |
| 产业链梳理 | ✓ | ✗ |
| 翻译 | ✓ | ✗ |
| 数据分析 | ✓ | — |
| 估值建模 | ✓（搭框架） | ✗（调假设） |
| 研报写作 | ✓（初稿） | ✗（终稿判断） |
| 专家访谈 | ✗ | ✓ |
| 草根调研 | ✗ | ✓ |
| 最终决策 | ✗ | ✓ |

## 核心原则

```
AI 对行研的角色 = "腿"——让你跑得更快
                        +
               "不是你"——方向还是你定
```

AI不会替代分析师，但会用AI的分析师会替代不会用AI的分析师。关键前提是：**AI生成的所有内容，必须回到一手来源交叉验证**。
