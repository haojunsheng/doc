# 高频交易

高频交易（High-Frequency Trading, HFT）是基于短期股价判断、在日内完成买卖以赚取价差的交易方式。它是量化投资的一个子集，但不是全部。

## 与量化投资的关系

```
量化投资 ⊃ 高频交易
```

量化投资包含多种策略形态：高频交易、基本面量化、统计套利等。国内公募量化主要采用基本面量化，持仓周期以月或年计，与高频交易截然不同。[[concepts/量化投资]] 页面有更详细的分类说明。

## 监管关注点

高频交易是监管整治的重点对象，原因包括：

- **信息不对称**：高频交易者拥有更快的执行速度和更优的信息获取能力
- **市场不公平**：普通投资者在速度上无法竞争
- **加剧波动**：可能导致助涨杀跌，放大市场波动——这与 [[concepts/追涨杀跌损益侵蚀]] 中描述的群体行为放大效应机制相关

2024 年 2 月，沪深交易所明确表示将重点整治高频交易和过度运用信息优势等问题。境外市场也普遍对高频交易实施更严格的监管。

## 重要澄清

- 监管整治的是高频交易的问题，**不是禁止量化投资本身**
- 合规的基本面量化投资仍然可以正常运作
- 私募量化可能采用高频策略，但公募量化受监管限制，不能做高频交易
