# 基金清盘常态化

## 定义

基金清盘常态化是指在公募基金市场从增量扩容转入存量竞争阶段后，业绩差、规模小、费率高的基金被自然淘汰，清盘和转型成为行业的常态现象。

## 核心数据

- 2024年内截至12月20日，共有233只基金清盘或转型
- 清盘主因：业绩不佳、投资者赎回、规模持续萎缩

## 形成机制

```
市场成熟 + 同质化竞争加剧
  → 业绩差/规模小/费高的基金被识别
    → 投资者用脚投票（赎回）
      → 规模跌破清盘红线
        → 基金清盘或转型
```

## 市场意义

清盘常态化是市场成熟的标志：它意味着资源从低效基金向高效基金流动，推动了行业整体质量提升。对投资者而言，清盘信号也可作为筛选基金的辅助参考——长期规模过小或业绩持续垫底的基金，清盘风险更高。

## 边界条件

- 如果市场整体向好，清盘数量会减少
- 如果基金公司盲目推出同质化产品，清盘风险会上升
