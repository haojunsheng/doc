# 内地投资海外热情降温

## 定义

内地投资海外热情降温是指内地投资者从海外市场（通过香港互认基金等渠道）撤回或减少配置，转而增加国内市场配置的行为趋势。本质上是投资者风险偏好下降、本土偏好上升的表现。

## 机制

```
全球市场波动加剧 → 投资者风险偏好下降 → 倾向熟悉市场 → 内地投资海外热情降温
```

上述时间序列表明，内地投资者的海外配置意愿呈现顺周期双向波动特征，与全球市场波动节奏密切相关。

## 与 [[风险偏好抬升]] 的关系

[[风险偏好抬升]] 描述的是同一机制的相反方向——投资者从国内市场转向海外市场。两者互为镜像，共同构成内地投资者跨境配置行为的两个极端状态。关键差异在于驱动因素：

- **热情降温**：全球市场波动加剧 → 避险情绪上升
- **风险偏好抬升**：A股回暖 → 全球权益资产吸引力上升

## 表现形式

- 香港互认基金整体流入放缓或转为净流出
- 债券型基金（避险属性）相对权益型基金获得更强的资金承接
- 产品层面呈现分化：高股息/稳健类策略相对受追捧，高风险策略遇冷

## 边界条件

1. **可逆性**：若国内市场出现明显下跌，投资者可能重新转向海外（如2026年2月的情况）
2. **政策干扰**：[[客地销售比例限制]] 可能独立于投资者行为导致资金流出，需区分行为因素与政策因素
3. **汇率因素**：人民币贬值时，港币资产相对升值，可能部分抵消热情降温的影响
