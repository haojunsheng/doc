# 比特币风险属性趋同

**比特币风险属性趋同**是指比特币虽然在理念上被定位为"数字黄金"和避险资产，但在实际价格行为上与科技股等风险资产高度趋同——在市场风险厌恶上升时，比特币跟随科技股一起下跌，而非发挥避险功能。

## 现象描述

| 情境 | 比特币表现 | 科技股表现 | 相关性 |
|------|-----------|-----------|--------|
| 正常风险环境 | 独立/上涨 | 上涨 | 低相关 |
| 风险厌恶上升（如关税恐慌） | 下跌 | 下跌 | 高相关 |
| 监管利好（特朗普称"加密货币总统"） | 预期上涨 | — | 脱钩信号（但未实现） |

## 2025年特朗普回宫100天案例

- 特朗普自称"加密货币总统"，市场预期放松监管，利好比特币
- 但关税恐慌主导市场情绪，风险资产全面抛售
- 比特币走势与科技股高度相关，100天内累计跌9%
- 停战消息刺激短暂反弹，但无法扭转整体下跌趋势

**核心发现**：在极端宏观冲击下，资产的"标签"（如"数字黄金"）无法抵抗风险偏好的系统性下降，相关性结构会发生突变。

## 理论解释

```
风险偏好↓ → 全市场流动性收缩
           → 投资者优先减持流动性好、波动大的资产
           → 比特币（高流动性+高波动）首当其冲
           → 即使有监管利好，也被宏观利空完全压制
```

## 边界条件

- **趋同条件**：宏观风险事件冲击强度足够大（如关税全面升级、衰退概率跃升）时，比特币风险属性与科技股趋同
- **脱钩条件**：当加密监管政策真正落地并放松时，比特币可能脱钩科技股走独立行情
- **阈值效应**：小幅风险事件下比特币仍可独立；只有宏观风险超过某一阈值时，趋同才显著

## 与投资实践的关系

1. **不要迷信资产标签**："数字黄金"是叙事而非现实——在系统性风险面前，相关性结构会突变
2. **分散化需要考虑相关性突变**：传统认为比特币可以分散股票组合风险的论点，在极端市场环境下可能失效
3. **监管是独立的脱钩变量**：加密监管政策是唯一可能让比特币脱离科技股相关性的结构性因素
