# 预期差交易

市场定价的驱动力不是数据的绝对水平，而是数据相对于市场共识的偏差（surprise）。这是理解短期市场波动的核心分析框架。

## 核心定义

**预期差交易**：市场关注的是"数据是否超预期"，而非"数据本身好不好"。即使数据绝对值仍处收缩区间，只要边际改善方向正确，就能驱动上涨。

```
市场反应 = f(实际数据 - 市场共识预期)
           ↑
        预期差（surprise）才是定价变量
```

## 形式化表达

```
预期差 > 0（超预期）→ 价格上涨
预期差 = 0（符合预期）→ 反应钝化
预期差 < 0（不及预期）→ 价格下跌
```

## 典型案例：2026年11月A股

### 上半月上涨：PMI边际改善触发预期差

| 指标 | 数值 | 市场共识 | 预期差 |
|------|------|---------|--------|
| 制造业PMI | 49.2% | 50%以下（收缩区间） | 边际改善（49.0%→49.2%） |
| 政策环境 | 十五五规划+中长期资金入市 | 已知 | 叠加放大效应 |

**结果**：虽然PMI仍在收缩区间，但边际改善方向+政策利好叠加，市场交易"预期差"，上半月上涨并创十年新高。

### 下半月回调：数据修复被提前定价

| 指标 | 数值 | 市场共识 | 预期差 |
|------|------|---------|--------|
| CPI | +0.2% | 温和回升 | 已预期 |
| PPI | -2.1% | 降幅收窄 | 已预期 |

**结果**：数据修复被市场提前定价，落地后"符合预期"而非"超预期"，债市反应钝化，市场转向外部冲击主导。

## 与相关概念的关系

### 与[[近因效应]]的区别

- [[concepts/近因效应]] 解释的是认知偏差——大脑天然给近期信息更高权重
- **预期差交易**解释的是定价机制——市场如何消化信息

两者关联：近因效应使投资者过度关注最新数据（如PMI边际改善），放大预期差交易的短期波动。

### 与[[利好兑现效应]]的关系

- [[concepts/利好兑现效应]] 是预期差交易的**反向应用**：利好落地=预期差归零=卖出信号
- 两者共同构成"买预期、卖事实"的完整行为链条

## 投资决策启示

| 场景 | 策略 |
|------|------|
| 数据未发布前 | 预判市场共识，识别潜在预期差方向 |
| 数据符合预期 | 警惕"利好出尽"或"钝化反应"，不追涨 |
| 数据超预期 | 关注持续性——单次超预期 vs 趋势性反转 |
| 数据不及预期 | 区分暂时性扰动 vs 结构性恶化 |

## 边界条件

- **前提**：市场预期共识需相对稳定；若共识本身频繁变化，预期差框架失效
- **局限**：无法量化"市场共识"的具体水平，判断依赖定性分析
- **风险**：若市场共识判断错误，预期差推论将完全失效
