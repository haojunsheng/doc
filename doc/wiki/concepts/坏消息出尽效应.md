# 坏消息出尽效应

当负面新闻完全被定价后，市场不再关注已发生的坏消息，转而将注意力转向未来——即使经济出现下滑征兆，只要信心仍在，市场仍可能上涨。

## 机制

```
坏消息出现
  → 市场下跌（定价负面信息）
    → 坏消息完全出尽
      → 市场注意力转向未来
        → 若未来预期改善 → 市场上涨（即使经济数据仍在恶化）
```

## 与 [[股市与经济脱钩]] 的关联

这是 [[股市与经济脱钩]] 框架的重要支撑机制之一：

- 经济指标（GDP、PMI、CPI、失业率）反映**过去**一段时间的表现
- 市场定价的是**未来**现金流预期
- 当坏消息"出尽"，市场预期开始提前反应未来好转，而此时经济数据可能仍在显示恶化

## 典型案例

**2020-2021 年疫情冲击**：
- 实体经济被疫情重创，经济数据持续恶化
- 股市在短暂暴跌后大幅上涨
- 原因：投资者认为最坏的时刻已经过去，对复苏预期充满信心
- 此时市场关注的不是"现在经济多差"，而是"未来会好多少"

## 与近因效应的张力

[[近因效应]] 描述大脑天然给近期信息更高权重，倾向于线性外推。坏消息出尽效应表面上与近因效应相反——市场在"坏消息不断"的背景下反而上涨。

但两者并不矛盾：坏消息出尽效应的关键前提是**市场已经充分消化了坏消息**。一旦边际上的坏消息不再更新，投资者的注意力自然转向未来。这个切换点难以精确把握，正是行为偏差的来源。

## 边界条件

1. **信心阈值**：若信心尚未崩溃，坏消息出尽后市场可涨；若信心已经崩盘，即使坏消息出尽，市场仍可能继续下跌
2. **催化剂需求**：市场转向未来需要明确的积极催化剂（如政策刺激、技术突破），否则可能陷入"不涨不跌"的观望状态
3. **预期锚定**：锚定在历史高点的投资者可能持续悲观，锚定在当前位置的投资者更可能转向乐观

## 投资启示

理解坏消息出尽效应有助于避免两类错误：
- **过早悲观**：在坏消息密集期卖出，随后错过市场反弹
- **盲目乐观**：未确认"坏消息是否真正出尽"就追涨，遭遇二次探底
