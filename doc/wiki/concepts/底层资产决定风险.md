# 底层资产决定风险

## 定义

资管产品的真实风险来自其持仓的底层资产类别，而非发行机构的信用背书。投资者判断产品风险时，应看底层投向而非产品形式或发行方名气。

## 形式化表达

```
银行理财 ≈ 债券基金 ≈ 固定收益类资产
风险来源 = 底层资产，不是发行机构
```

## 核心逻辑

1. **资管产品的风险收益特征由底层资产决定**
2. 银行理财 95% 是固定收益类产品，近 70% 投债券、存单、现金
3. 固定收益类资产本质是借贷，风险收益比股票低
4. 但"低风险"不等于"无风险"，债券也有波动和亏损可能

## 与穿透持仓的关系

[[穿透持仓]] 解决"投在哪"的问题（识别产品的实际持仓结构）；[[底层资产决定风险]] 解决"为什么这样投就有这个风险"的问题（理解持仓类别对应的风险属性）。两者互为补充。

## 在银行理财场景的应用

打破刚性兑付后，银行理财的"安全"来自其资产配置（主要投债券），而非银行信用。这与资管新规前的认知形成对比：

| 维度 | 资管新规前（错误认知） | 资管新规后（正确认知） |
|------|---------------------|---------------------|
| 风险来源 | 银行信用背书 | 底层资产类别 |
| 决策依据 | 看发行机构名气 | 看产品实际持仓 |
| 安全判断 | "银行理财 = 安全" | "银行理财 ≈ 债券基金" |

## 风险升级的边界条件

如果银行理财配置了以下资产，风险会显著上升：

- 可转债
- 高收益债
- 加杠杆操作

此时"固收+"可能变成"固收-"，需回归底层资产分析。
