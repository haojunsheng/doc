# 利润捕获能力

## 定义

秩序创造机器将城市分散欲望转化为实时可履约系统后，能从这套秩序中提取多少经济租金留给股东的能力。

## 核心张力

**秩序创造能力 > 利润捕获能力**是美团 2025 年的核心约束。机器让城市运行更高效，但在巨头补贴战和监管约束下，不一定能把全部效率留给股东。

## 利润捕获被压低的来源

| 来源 | 表现 |
|------|------|
| 竞争补贴 | 销售及营销费用从 RMB640 亿（2024）升至 RMB1029 亿（2025），+RMB390 亿 |
| 到店利润池被攻击 | 抖音以内容流量抽走到店广告和佣金收入 |
| 监管要求生态让利 | 商家补贴基金、骑手权益保障等 |
| 新业务持续投入 | 即时零售、海外 Keeta、AI 仍在亏损期 |

## 美团 2025 年利润捕获恶化数据

```
核心本地商业经营利润率: +20.9%（2024）→ -2.6%（2025）
成本收入比: 61.6% → 69.6%
Q4 核心本地商业经营利润率: -15.5%（Q3 为 -21.0%，环比收窄）
```

## 利润捕获恢复的信号

1. 核心本地商业经营亏损明显收窄，接近盈亏平衡
2. 销售及营销费用率从高位回落（2025 Q4 为 34.4%），而交易量/GTV 不明显失速
3. 经营现金流从净流出恢复为接近持平或正流入
4. 管理层披露清晰的投资纪律，而非用"长期价值"覆盖亏损
