# 主动持股比例

## 定义

**主动持股比例**（Active Share）是指基金持仓与业绩基准之间的偏离程度，衡量基金经理主动决策的程度。晨星以 **60%** 为阈值，将主动持股低于此标准的基金划分为"伪主动"。

## 精确公式

```
主动持股比例 = Σ|基金权重 − 基准权重| ÷ 2
```

- **100%**：持仓与基准完全无重合（完全不跟踪基准）
- **0%**：持仓与基准完全一致（如 ETF 完全复制型基金）
- 三个偏离来源：① 对基准内证券赋予不同权重；② 剔除基准内部分证券；③ 纳入基准外证券

> 来源：[[QA — 主动持股比例衡量基金偏离度]]

晨星分类标准：
```
主动持股比例 ≥ 60% → "真主动"
主动持股比例 <  60% → "伪主动"
```

## 国内数据概况（截至 2025 年 6 月底）

| 统计指标 | 数值 |
|---------|------|
| 平均值 | 89.82% |
| 中位数 | 91.73% |
| ≥ 80% 的占比 | 87% |
| ≥ 90% 的占比 | 59% |

说明：国内主动偏股基金主动持股比例普遍极高，大部分基金确实在"主动管理"。

## 三大结构性驱动因素

### 1. 风格偏好中小盘

大部分主动基金经理偏好中小盘风格，明显低配大盘风格。中小盘股票数量庞大，超额收益潜力分散，基金经理更容易通过精选个股形成差异化持仓。

### 2. 行业超配/低配

过去市场环境使基金经理超配电力设备、食品饮料、电子，低配银行和非银金融，导致持仓与基准行业结构显著不同。

### 3. 个股集中追求弹性

为追求组合弹性，很多基金持仓集中在少数股票上，进一步推高主动比例。

## 策略集中度维度

相同基准 ≠ 相同主动比例。**策略集中度**是关键差异变量：

| 基金 | 策略特征 | 主动比例 |
|------|---------|---------|
| 东方岳（东方岳均衡配置） | 均衡配置，单一行业<20%，前十大占比25% | 70% |
| 万家宏观择时（万家宏观择时） | 集中配置，单一行业>70%且大幅轮换，前十大占比80% | 近100% |

→ 参见 [[QA — 主动持股比例衡量基金偏离度]] Q5

## 核心结论

**高主动持股比例 ≠ 高业绩**。主动持股比例是**描述性工具**（告诉你基金有多主动），不是**预测性工具**（不能预测未来业绩）。偏离本身不产生超额收益——能力才产生。

2024年数据显示，主动持股三个区间（0–80%、80–90%、90–100%）的基金战胜率无显著差异。

## 三种需要警惕的信号

### 1. 骤降信号
```
主动持股比例骤降 = 规模↑导致选股困难 ∨ 策略变更
```
案例：[[中欧均衡成长混合]] 从90%降至不足60%，改为对标沪深300的指数增强策略。

### 2. 骤升信号
```
主动持股比例骤升 = 押注单一行业 → 组合风险高度集中
```
案例：[[前海开源沪港深龙头精选]] 从60%升至近100%，84%持仓集中于医药。

### 3. 伪主动信号
```
伪主动 = 主动持股<60% + 高费率（1.2%）→ 扣除费用后几乎不可能跑赢基准
```

## 局限性

1. **高主动不代表能力强**：可通过增加基准外个股持仓提升比例，但能力不足则是"盲目主动" → 参见 [[盲目主动]]
2. **预测性受市场环境极大影响**：晨星对美国市场的研究发现其预测作用受市场环境极大影响
3. **高度依赖基准选择**：若基准选择不当（如成长型基金选价值型指数），主动比例虚高失真 → 与 [[基准不匹配]] 直接关联

## 边界条件

- 主动持股比例高 + 基金经理能力出众 → 可能创造超额收益
- 主动持股比例高 + 基金经理能力不足 → 盲目主动，增加风险不增加收益
- 主动持股比例低 + 费率足够低 → 投资者可接受（如低成本指数增强）
- 晨星60%阈值是经验性标准，边界模糊，需结合其他指标综合判断
