# 资产配置优先原则

资产配置决定了组合 90% 以上的回报波动，产品选择仅解释不到 10%。把精力放在前者才是杠杆点。

## 形式化表达

```
回报波动 ≈ 90% 资产配置 + 10% 产品选择
```

## 证据基础

- **Brinson 经典研究**：用 90 多家养老基金数据验证，机构层面配置归因显著
- **2008 年案例**：60/40 股债组合跌 20%，全仓股票跌 40%——不是产品不行，是配置决定了命运

## 行为偏差边界

对个人投资者，行为偏差（追涨杀跌、频繁调仓）可能放大产品选择的影响，实际归因比例可能低于 90%。但即便计入行为偏差，配置仍是第一优先级。
