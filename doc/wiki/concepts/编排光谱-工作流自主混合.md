# 编排光谱——工作流、自主与混合

## 定义

Agent 编排模式的连续光谱，而非二元对立。三种模式各有适用场景，不存在"最优"，只有"最合适"。

## 三种模式

### 工作流（Workflow）

**特征：**
- 节点顺序不可变
- 攻击面收敛在节点内
- 确定性高、可预测性强

**适用场景：**
- 资金链路、结算流程
- 合规审批流程
- 数据处理管道

**优势：** 确定性高、易于调试、风险可控
**劣势：** 灵活性差、无法处理异常分支

### 自主（Autonomous）

**特征：**
- 意图驱动
- Agent 自行决定执行路径
- 灵活性强

**适用场景：**
- 用户意图理解
- 异常处理
- 探索性任务

**优势：** 灵活、适应性强
**劣势：** 难以预测、调试困难

### 混合（Hybrid）

**特征：**
- 工作流节点内嵌自主 Agent
- 整体框架确定，局部灵活

**典型案例：** n8n 工作流引擎
- 整体流程由工作流定义
- 某些节点是自主 Agent
- 兼顾确定性与灵活性

## 光谱定位方法

按场景属性定位：

| 场景属性 | 推荐模式 | 原因 |
|---------|---------|------|
| 节点顺序不可变 | 工作流 | 顺序错误会导致严重后果 |
| 攻击面需要收敛 | 工作流 | 节点内风险可控 |
| 用户意图多变 | 自主 | 需要灵活响应 |
| 异常处理不确定 | 自主 | 需要动态决策 |
| 混合需求 | 混合 | 兼顾两者优势 |

## 与 Plan-and-Execute 的关系

- **工作流 ≈ Plan-and-Execute**：计划阶段定义固定流程，执行阶段按步骤运行
- **自主 ≈ ReAct**：思考-行动循环，动态决定下一步
- **混合 = 两者共存**：部分步骤预定义，部分步骤动态决策

## 实践含义

- 不要问"工作流好还是自主好"，问"这个场景在光谱的哪个位置"
- 资金场景天然偏向工作流，因为错误代价高
- 用户交互场景天然偏向自主，因为意图多变
- 大多数真实场景是混合模式
