# 杠铃策略

## 定义

杠铃策略是一种组合配置方法：一端配置高弹性的成长/AI资产（进攻端），另一端配置高质量价值股（防御端），通过两端再平衡实现组合优化。

核心逻辑：两端资产相关性低，波动改变相对估值，创造"卖出涨多的、买入跌透的"操作空间。

## 形式化

```
杠铃 = 高弹性资产（科技/AI） + 高质量价值股（防御端）

当前环境（2026Q1）：
  科技↓ → 加仓机会（弹性端性价比提升）
  价值↑ → 止盈机会（安全边际收缩）
  操作：兑现价值 + 加仓科技 = 组合优化
```

## 适用条件与边界

- **前提**：两端资产相关性低；若系统性风险导致所有资产同跌，杠铃的保护效果减弱
- **前提**：波动是暂时的；若演变为持续熊市，"抄底"会变成"接飞刀"
- **区分**：与"核心仓位-vs-卫星仓位框架"不同——杠铃强调两端资产的低相关性而非主次关系

## 实证案例：2026Q1美股回调

晨星将Q1美股-4.27%的跌幅定义为估值机会：成长股21%折价、科技股23%折价（2011年来极值），而价值端（如能源板块）因年内+34%变得最被高估——两端同时出现再平衡信号，构成杠铃策略的典型应用场景。
