# 短债基金被疯抢

**短债基金被疯抢**指2025年Q3 FOF在利率上行环境中大规模增配短债基金的配置行为，是[[concepts/FOF配置转向框架]]五大转向之一。

## 核心机制

```
利率↑ → 组合久期↓需求↑ + 短债=流动性缓冲 → 短债基金被疯抢
```

## 实证数据

- [[entities/海富通]] 中证短融ETF被67只FOF重仓，持仓从18亿升至33亿
- 17只FOF持有该基金比重在10-20%之间
- 该ETF成为FOF第一重仓债基

## 边界条件

若利率转为下行，FOF可能减持短债重新拉长久期。
