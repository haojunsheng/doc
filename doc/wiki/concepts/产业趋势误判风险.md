# 产业趋势误判风险

## 定义

成长型投资策略的核心风险：对产业趋势判断错误或介入时机过早，导致承受巨大回撤。

## 核心逻辑

```
硬核成长派 = 行业萌芽期布局 → 业绩驱动股价
                    ↓
           若产业趋势判断错误或介入太早
                    ↓
             承受巨大回撤（时间成本 + 价格成本双重损失）
```

与 [[周期投资派]] 的风险结构相似：周期派误判经济周期，成长派误判产业趋势。两者都是在"早期判断"上承担风险。

## 与价值陷阱的对比

| 维度 | 价值陷阱（长期价值派风险） | 产业趋势误判（成长派风险） |
|------|--------------------------|--------------------------|
| 风险类型 | 基本面持续恶化 | 趋势判断错误 / 介入过早 |
| 结果 | 坚守反而亏钱 | 时间成本 + 价格成本双重损失 |
| 识别难度 | 相对容易（财务指标恶化可见） | 较难（需判断产业生命周期） |
| 化解方式 | 严格基本面筛选 + 安全边际 | 等待产业趋势验证 + 分批建仓 |

## 典型案例参考

[[谢治宇]]的换手率从早期300%降至约100%，反映了从频繁交易转向陪伴企业成长的过程，也是应对产业趋势不确定性的进化路径。详见 [[基金经理换手率评级]]。
