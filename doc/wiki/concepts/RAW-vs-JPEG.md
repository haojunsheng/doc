# RAW vs JPEG

## 定义对比

| | RAW | JPEG |
|---|---|---|
| 本质 | 传感器原始数据，未经渲染 | 相机算法渲染后的压缩图片 |
| 类比 | 底片 | 冲好的照片 |
| 后期空间 | 大（保留所有信息） | 小（被压缩和渲染过） |
| 文件大小 | 大 | 小 |
| 宽容度体现 | 完整 | 被压缩/杀掉 |

## 核心区别

RAW 是"相机能记录的、不加任何渲染的原始图片格式"。JPEG 是"相机经过自己的系统和算法算出来的图片"。

厂商在 JPEG 渲染时通常"奔着颜色艳丽去调色"——例如把蓝天调得更蓝。这算"欺骗"还是"优化"？

## 认识论延伸

RAW 并非"纯客观真实"——传感器本身有色彩滤镜阵列，RAW 数据也要经过去马赛克算法处理。相机永远在"计算"现实，而不是"记录"现实。

## 实践建议

- 大光比场景（日落、室内窗口）→ 必须用 RAW
- 日常记录、不想后期 → JPEG 方便
- 想学习摄影 → 从 RAW 开始，理解后期空间的重要性
