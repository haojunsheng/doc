# 主流vs小众市场配置优先级

在全球资产配置中，应将研究精力优先放在体量大、占比高的主流市场，小众市场不应重仓配置。

## 核心命题

```
主流市场(美、欧、日): 体量大 → 优先配置
小众(越南、沙特): <1% → 不重仓
```

## 机制

| 市场类型 | 全球市值占比 | 配置建议 | 原因 |
|----------|------------|---------|------|
| 主流市场（美、欧、日） | >70% | 优先配置 | 权重高，偏离成本高 |
| 中等市场（中、韩、印等） | ~15-20% | 适度配置 | 有一定研究价值 |
| 小众市场（越南、沙特等） | <1% | 不重仓 | 重仓意味着大幅超配，承担更高主动风险 |

## 与主动偏离的关系

重仓小众市场 = 大幅超配 = 主动表达强烈的投资观点。这种偏离需要建立在非常充分的认知基础上。

[[偏离标准组合=主动表态]] 提供了判断框架：如果你在重仓小众市场之前无法清晰表达你的投资观点，那么这种偏离可能更多是赌博而非投资。

## 边界条件

- 如果有特殊信息优势或深度研究能力，小众市场可能产生超额收益
- 但这种情况属于少数，不应作为一般性配置策略
- 研究精力有限，优先放在更重要的市场上
