# 收益来源结构分解

将债券基金的超额收益拆解为多个独立维度的分析框架。是 [[业绩归因]] 在固定收益领域的具体应用。

## 形式化定义

```
超额收益 = 行业选择 + 发行主体选择 + 久期操作 + 外汇操作
```

## 四个维度说明

| 维度 | 含义 | 来源性质 |
|------|------|---------|
| 行业选择 | 国家/地区配置 + 行业配置决策 | 自上而下宏观研判 |
| 发行主体选择 | 个券精选，信用利差挖掘 | 自下而上微观研究 |
| 久期操作 | 对各市场债券平均久期的主动调整 | 利率方向判断 |
| 外汇操作 | 汇率敞口管理 | 汇率走势判断 |

## 核心论点

**多元化收益来源是债券基金的结构性优势。** 单一策略（如纯久期）在判断错误时损失大；多元策略在某维度失误时可被其他维度弥补。

### 边界条件

- 全球债券市场相关性大幅上升时（如2022年），行业选择和个券选择的超额收益收窄
- 全球债券市场全面下跌时，多元化也无法避免亏损
- 久期操作是一把双刃剑：判断正确时贡献显著，判断错误时拖累业绩（如2023年Q1案例）

## 与 [[业绩归因]] 的关系

传统业绩归因（如 Brinson 模型）主要面向股票基金，拆解为资产配置效应和选择效应。债券基金的收益来源结构分解在结构上与之平行，但维度更丰富——新增久期操作和外汇操作两个固定收益特有维度。

## 案例参考

[[摩根国际债券基金]] 的超额收益来源即为该框架的典型应用：2021年行业选择贡献大，2022年久期决策贡献大，2024年多个维度共同贡献。
