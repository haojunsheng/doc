# 再平衡收益的数学条件

再平衡能否创造正收益，取决于两个核心变量的组合：两类资产的**长期收益差距**和**波动差距**。

## 核心公式

```
再平衡收益 ≈ (波动差距) × 频率 / (长期收益差距 + 1)
```

**变量含义**：
- **波动差距**：两类资产各自波动率的差值，越大越好
- **频率**：再平衡的执行频率（如年化、季度等）
- **长期收益差距**：两类资产长期年化收益率之差，越小越好（接近 0 最优）

## 最优条件：收益相近 + 波动差距大

当两类资产长期收益接近，但期间波动差距较大时，再平衡效果最好。

**实证案例：A股 + 债券/现金**
- 三者年化收益差距不超 3%
- A 股波动远大于债券和现金
- 结果：年多赚约 0.5%，十年累积 +5%~6%

## 最差条件：长期收益差距大

当一类资产长期显著跑赢另一类时，再平衡反而会拖累收益。

**原因**：再平衡强制减仓表现最好的资产（卖出赢家），等同于主动放弃强势资产的超额收益。

**实证案例**：
- **A股 + 黄金**：黄金长期跑赢 A 股 → 再平衡反而亏
- **A股 + 全球股票**：全球股票长期跑赢 A 股 → 再平衡反而亏

## 边界条件

1. **完全同涨同跌**（如成长 & 价值）：再平衡几乎零收益
2. **历史数据依赖**：上述结论基于过去十年数据，未来收益格局若变化则结论可能反转
3. **单边行情**：固定比例再平衡在极端单边牛市会牺牲部分收益
