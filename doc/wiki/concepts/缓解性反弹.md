# 缓解性反弹

## 定义

央行停止加息后，市场因"加息周期结束"预期而出现的乐观性反弹。本质是风险溢价压缩驱动的修复，而非基本面实质性改善。

## 与相关概念的区别

| 类型 | 触发条件 | 驱动因素 | 持续性 |
|------|---------|---------|--------|
| **缓解性反弹** | 加息周期结束 | 风险溢价压缩，情绪修复 | 中等，依赖后续数据验证 |
| **趋势反转** | 基本面实质性改善 | 盈利增长、经济复苏 | 长期，有基本面支撑 |
| **技术性反弹** | 超卖后修正 | 均值回归、空头回补 | 短期，易反复 |

## 与软着陆的关系

```
软着陆: 通胀↓ + 经济温和放缓
  → 央行停止加息、转向宽松预期形成
  → 缓解性反弹（股市）
  → 若后续经济数据验证软着陆，反弹演变为趋势性行情
  → 若经济加速恶化，反弹失败，市场重新下跌
```

## 边界条件

- 若经济数据突然恶化（软着陆变硬着陆），缓解性反弹迅速终结，转为恐慌性抛售
- 若通胀反弹导致央行重新考虑加息路径，缓解性反弹预期落空
- 缓解性反弹期间不宜过度乐观，需观察后续数据验证
