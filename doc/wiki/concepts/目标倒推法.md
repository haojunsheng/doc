# 目标倒推法

## 定义

**目标倒推法**：一种储蓄规划算法——先确定目标总金额和使用时间，再反推出每月必须储蓄的金额，最后从收入中锁定这笔储蓄，剩余才是可支配生活费。

## 核心公式

```
月储蓄额 = 总预算 ÷ 目标月数
可支配生活费 = 月收入 - 月储蓄额
```

**关键**：储蓄先锁定，生活费后算。而不是反过来"月底剩多少存多少"。

## 正向推导 vs 倒推法对比

| 方式 | 逻辑顺序 | 结果 |
|------|---------|------|
| 正向推导（常见错误） | 收入 → 花掉 → 存剩下的 | "可存"永远被弹性花掉，通常剩不下 |
| **目标倒推法** | 目标 → 月储蓄额 → 生活费上限 | 储蓄有硬上限，生活费被约束 |

## 行为金融学解释

正向推导之所以失败，是因为：

1. **生活方式膨胀**：[[concepts/生活方式膨胀]] 指出，收入增长会被消费自动吸收；如果没有硬性的储蓄上限，生活费会随收入上涨而膨胀
2. **心理账户模糊**：[[concepts/三钱包分配法]] 强调，没有"时间标签"的钱最容易被挪用
3. **双曲贴现**：[[concepts/双曲贴现]] 让人偏好即时消费，倒推法通过预设规则对抗这一倾向

## 操作步骤

```
1. 设定目标：我要去哪里？花多少钱？什么时候去？
2. 计算月储蓄额：总预算 ÷ 距离目标的时间（月）
3. 设置自动转账：发工资当天自动转入目标账户
4. 用剩余生活费生活：这是硬性上限，超支即停止
5. 定期校准：如果月储蓄额压到生活费以下，调降预算或延长时间
```

## 边界条件

- 如果月储蓄额 > 月收入 × 60%，目标不现实，需要调降预算或延长时间
- 如果同时有多个目标（如旅游+置产），每个目标独立倒推，总储蓄额相加
- 紧急情况下（失业、疾病），优先动用应急金，不影响目标倒推的其他目标
