# 地方政府投融资链条

全书核心分析框架：将分税制→土地财政→土地金融→招商竞争→工业化/城市化→宏观后果的完整链条，还原为一套连贯的微观机制。

## 链条结构

```
分税制上收财权
      │
      ▼
土地财政（第二财政，≈预算89%）
      │
      ▼
土地金融：城投以土地抵押撬动信贷
      │
      ▼
招商竞争·下场投资 → 工业化/城市化
      │
      ▼
宏观后果：房价·债务·内外失衡
```

## 各环节说明

| 环节 | 机制 | 关键制度节点 |
|------|------|-------------|
| 分税制上收财权 | 1994年改革，中央上收主要税种 | 事权未相应上收 |
| 土地财政 | 土地出让及相关税收成为地方第二财政 | 法律禁止地方直接贷款 |
| 土地金融 | 城投以土地抵押撬动银行信贷 | 地方政府融资平台兴起 |
| 招商竞争 | 官员晋升与地区经济表现挂钩，刺激各地招商引资 | "官场+市场"体制 |
| 宏观后果 | 低价工业用地 + 限制商住用地 → 高房价、高债务 | 结构性失衡 |

## 方法论意义

本链条体现了 [[DIKW模型-研究方法论]] 的完整路径：从分税制的事实（数据）→ 土地财政机制（信息）→ 产业链条理解（知识）→ "发展过程≠发展目标"的判断（智慧）。
