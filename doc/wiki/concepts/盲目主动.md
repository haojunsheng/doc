# 盲目主动

## 定义

**盲目主动**是指基金经理主动持股比例高（>90%），但实际投资能力不足以将偏离转化为超额收益，导致组合风险增加而收益未相应提升的现象。它与"伪主动"并列，构成主动基金的两种极端陷阱。

## 形式化

```
盲目主动 = 高主动持股（>90%） + 基金经理能力不足
            → 偏离增加风险但不增加收益
            → 净超额收益 ≤ 0（扣除费用后）
```

## 与"伪主动"的对比

| 维度 | 盲目主动 | 伪主动 |
|------|---------|--------|
| 主动持股比例 | 高（>90%） | 低（<60%） |
| 管理费 | 正常水平 | 正常水平 |
| 偏离动机 | 真正想跑赢 | 可能不想偏离，或因规模/能力所限无法偏离 |
| 核心问题 | 能力不足却过度偏离 | 偏离不够却收高费 |
| 投资者损失 | 风险增加 + 高费率 | 高费率却几乎无超额 |

## 形成原因

1. **规模膨胀**：基金规模过大后，基金经理无法像小基金一样灵活调仓，但仍保持高主动风格，导致"船大难掉头"
2. **策略惯性**：基金经理习惯主动操作，即使市场环境变化也不调整策略
3. **业绩压力**：短期排名压力驱使基金经理加大偏离以追求短期超额

## 边界条件

- 若基金经理具备真有能力，高主动持股可能创造超额收益（如 [[詹成]]、[[周蔚文]] 等长期稳定超额案例）
- 规模膨胀是主要原因，而非基金经理能力本身——这是可修复的问题（通过规模控制或策略调整）

## 与 [[风格漂移]] 的关系

盲目主动往往伴随风格漂移：基金经理在无法跑赢基准的压力下，可能通过追逐热点来"证明自己"，导致实际风格偏离宣称风格。

## 投资实践建议

- 识别高主动持股但长期战胜率低的基金
- 关注基金规模变化与主动持股变化的相关性
- 将主动持股比例与基金经理历史超额能力结合判断，而非孤立看待
