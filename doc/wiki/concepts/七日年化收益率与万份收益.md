# 七日年化收益率与万份收益

选择货币基金的两大核心指标，各有侧重，合用才能避免被短期尖峰误导。

## 七日年化收益率

**定义**：按过去 7 天的每万份收益，折算为年度化水平的估算值。

**公式表达**：

```
七日年化收益率 = [(∑(过去7天万份收益) / 7) × 365 / 10000] × 100%
```

**特点**：
- 便于横向对比同类产品的相对收益水平
- 是"向前看"的估算，**不保证未来收益**
- 易受短期波动干扰：某一天的高收益会让七日年化暂时走高

**典型误用**：被单日尖峰误导，认为"这只基金收益最高"，实际上那可能是 transient 的高收益日。

## 万份收益

**定义**：当天每 1 万元持有的货币基金实际获得的收益金额（元）。

**特点**：
- 反映当日真实收益，不受年化折算影响
- 适合纵向观察收益的波动性和稳定性
- 数据颗粒度更高，便于追踪趋势

## 联合使用策略

| 场景 | 推荐用法 |
|------|---------|
| 横向筛选 | 以七日年化收益率初筛，快速比较相对水平 |
| 排除异常 | 查万份收益近 30 天走势，剔除单日尖峰产品 |
| 稳定性评估 | 万份收益波动小 + 七日年化稳步 = 理想标的 |

## 与波动性的关系

[[concepts/波动率不是风险]] 在此场景下尤为适用：货币基金七日年化偶尔波动并不等同于永久亏损风险，但万份收益的大幅跳变值得警惕——可能预示持仓结构变化或流动性压力。

## 局限

两个指标均不反映：
- 基金规模（规模过大 → 策略保守 → 收益摊薄）
- 机构占比（机构占比过高 → 大额赎回冲击剩余持有人）
- 费用结构（管理费、销售服务费等已计入净值，无需额外调整）

选基时需同时关注这两项风险因素，详见 [[concepts/货币基金业绩持续性]] 和 [[concepts/机构持有人风险]]。
