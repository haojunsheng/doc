# 主题投资

主题投资是围绕特定事件、政策、趋势或市场热点构建投资组合的策略，是外延增长投资的主要操作手段。

## 形式化定义

```
主题投资 = 特定主题 × 事件驱动 × 资金流向
```

## 核心特征

1. **主题聚焦**：围绕某一明确主题（如并购重组、国企改革、产业整合）构建组合
2. **事件驱动**：投资决策依赖于特定事件的发生或预期
3. **资金流向敏感**：关注市场资金对主题的偏好变化
4. **时效性强**：主题热度有生命周期，需在正确时点进入和退出

## 常见主题类型

| 主题类型 | 驱动因素 | 典型案例 |
|---------|---------|---------|
| 并购重组主题 | 政策宽松、产业整合 | [[汇添富外延增长主题股票]] |
| 国企改革主题 | 混改政策、资产注入 | 央企重组概念 |
| 产业整合主题 | 行业集中度提升 | 新能源产业链整合 |
| 跨界并购主题 | 多元化扩张 | 传统企业转型 |

## 与外延增长的关系

主题投资是外延增长投资的主要操作手段。外延增长关注的是增长来源（并购/重组），主题投资关注的是操作方式（围绕特定主题选股）。

参见 [[外延增长投资]]。

## 风险与边界

- **主题过热风险**：当主题成为市场共识时，估值可能已透支未来收益
- **主题褪色风险**：事件落地后主题热度消退，资金撤离导致股价回调
- **主题误判风险**：主题逻辑未能如期兑现，或替代主题出现
- **护城河颠覆风险**：技术革新可能颠覆主题内龙头企业的原有竞争优势（如AI对SaaS的冲击），参见 [[sources/5-notes--28-20260628t153258-qa-ai浪潮投资qa--7irwzm]]

参见 [[赛道估值透支]]、[[景气度投资]]。

## 与行业配置的区别

| 维度 | 行业配置 | 主题投资 |
|------|---------|---------|
| 选择依据 | 行业基本面、估值 | 事件/政策/趋势 |
| 时间维度 | 中长期 | 中短期 |
| 触发因素 | 行业景气度变化 | 特定事件发生 |
| 流动性需求 | 较低 | 较高 |
