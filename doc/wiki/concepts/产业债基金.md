# 产业债基金

## 定义

产业债基金是以产业类债券为主要投资对象的债券型基金，区别于以利率债（国债、政策性金融债等）为主的利率债型纯债基金。

## 核心特征

| 特征 | 说明 |
|------|------|
| 产业债占比 | 契约规定≥80%，实际操作一般在85%-90% |
| 信用等级 | AAA级为主，AAA以下债券占比通常<20% |
| 收益来源 | 票息收益为主要超额收益来源 |
| 波动特征 | 波动性低于含转债/权益的基金，但高于纯利率债基金 |
| 回撤目标 | 典型目标<2% |

## 与利率债型纯债基金的区分

```
纯债基金 = 利率债型（以国债/政金债为主）+ 产业债型（以产业债为主）
```

- **利率债型**：如[[工银纯债债券]]、[[万家鑫璟纯债债券]]，以利率债波段操作为主要策略，收益来源于利率走势判断
- **产业债型**：如[[富国产业债债券]]、[[东方添益债券基金]]、[[工银瑞信信用添利]]，以中高等级产业债票息为主要收益来源，收益来源于信用利差和票息积累

## 投资策略范式

产业债基金普遍采用"票息打底-交易增强"策略：

```
总收益 = 票息打底（中高等级产业债稳定票息）+ 交易增强（久期/杠杆/信用利差交易）
```

该策略与[[票息打底-交易增强策略]]概念高度对应。

- [[富国产业债债券]] 和 [[东方添益债券基金]] 是该策略的典型实践案例
- [[工银瑞信信用添利]] 则强调通过独立信用评级能力捕捉利差交易机会，将信用研究作为核心竞争力

## 风险特征

- **信用风险**：中高等级债券违约风险较低，但在信用风险蔓延时期也会受波及
- **利率风险**：加息周期中债券价格下跌
- **流动性风险**：部分产业债流动性较差
- **风格代价**：低转债配置在股市上涨时会错失权益收益

## 典型代表

- [[富国产业债债券]]（100058）：武磊管理，回撤目标<2%，年化4.50%
- [[东方添益债券基金]]（吴萍萍管理）：6年年化回报4.97%，同类前2%
- [[工银瑞信信用添利]]：晨星焦点基金，依托独立信用评级团队作为核心竞争力
