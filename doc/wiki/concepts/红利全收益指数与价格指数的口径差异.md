# 红利全收益指数与价格指数的口径差异

## 核心区别

| 口径 | 计算方式 | 红利策略适用性 |
|------|---------|--------------|
| **全收益指数** | 价格变动 + 分红再投资 | ✅ 最公平——包含分红本身的价值 |
| **价格指数** | 仅价格变动 | ❌ 低估红利优势——忽略分红再投资收益 |

## 为什么这个口径对红利策略至关重要

红利策略的核心价值有两个来源：

1. **价格升值**（与其他策略相同）
2. **分红现金流 + 再投资收益**（红利策略独特来源）

若用价格指数衡量红利策略，第 2 个来源完全被忽略，导致红利的真实优势被系统性低估。

## 实证差异示例

中证红利指数（同一篮子股票）在不同口径下的表现：

```
中证红利全收益指数（2007–2024）：年化 10.32%
中证红利价格指数（估算）：约 8-9%（分红再投资收益被剥离）
差值约 1-2pp，即为分红再投资的长期累积效应
```

## 方法论含义

1. **比较红利策略时必须用全收益口径**——否则与其他策略的比较不公平
2. **阅读基金宣传材料时需确认**使用的是全收益还是价格口径
3. **不同指数编制机构可能采用不同口径**——需仔细核对
