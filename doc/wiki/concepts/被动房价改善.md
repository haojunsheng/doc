# 被动房价改善

## 定义

宏观层面呈现的"购房负担能力改善"信号，实质是房价下跌导致的被动变化，而非居民收入增长带来的真实购买力提升。以房价收入比为例，9.3降至8.5是**分子端（房价）下跌**的结果，而非分母端（收入）上涨。

## 形式化表达

```
房价收入比 = 房价 / 家庭年收入
被动改善 = 房价↓ ÷ 收入持平 → 比值↓
真实改善 = 房价持平（或↑） ÷ 收入↑ → 比值↓
```

## 为什么这个区分重要

- **误导性**：宏观数据呈现"负担改善"容易引发乐观误判，实际购买力并未增强
- **政策含义**：若改善源于房价下跌，则政策目标应是稳房价而非刺激需求——需求刺激可能加速房价反弹、破坏已实现的"改善"
- **资产定价**：租金回报率2.26%仍低于无风险利率，说明资产端定价尚未回到理性区间

## 相关数据点

- 房价收入比：9.3 → 8.5（晨星，2026年6月）
- 租金回报率：2.10% → 2.26%（同期，仍低于无风险利率）
- 央行仍有10–20bp降息空间（可进一步降低融资成本）

## 边界

- 若经济下行导致收入减少或失业率上升，负担能力的"被动改善"可能被抵消
- 若降息充分释放，融资成本下降可部分弥补房价下跌带来的实际购买力损失
