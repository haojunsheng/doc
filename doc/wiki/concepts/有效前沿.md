# 有效前沿（Efficient Frontier）

**有效前沿**是现代投资组合理论（MPT）的核心概念，由 [[哈里-马科维茨-harry-markowitz]] 提出。它表示在给定风险水平下能获得最高预期收益的所有组合的集合。

## 核心定义

在风险-收益坐标系中，有效前沿是一条从左下到右上的曲线：

```
                预期收益
                    ↑
                    │         ● (高风险高收益)
                    │      ●
                    │    ●
                    │   ●  ← 有效前沿
                    │  ●
                    │ ●
                    │● (低风险低收益)
                    └────────────────→ 风险（标准差）
```

位于有效前沿上的组合称为**有效组合**——在相同风险下收益最高，或在相同收益下风险最低。

## 与均值-方差模型的关系

[[concepts/均值-方差模型]] 提供了计算有效前沿的数学框架：

- 投资者需要估计每只资产的预期收益、波动率和相互之间的相关性
- 通过优化算法，找到所有可行组合中位于有效前沿上的部分
- 有效前沿以上的点不可达（不存在）；以下的点效率低下（存在同风险更高收益的组合）

## 实践含义

有效前沿表明：**分散化可以降低风险而不牺牲收益**。当资产间相关性较低时，有效前沿向左弯曲（风险降低），而非简单的线性叠加。

- 投资者应根据自身风险承受能力，选择有效前沿上对应位置的组合
- 风险厌恶型投资者选择左下方组合，风险偏好型选择右上方组合

## 理论局限

- 依赖历史数据估计未来收益和风险，存在参数误差
- 假设投资者理性且只关心风险与收益两个维度
- 未考虑交易成本、税收、流动性等现实约束
