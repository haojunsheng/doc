# 风格轮动（A 股语境）

A 股市场按年份切换领涨风格，导致"短跑冠军"往往只是踩中了当年的风格贝塔，而非基金经理的超额能力。

## A 股近年风格轮动时间线

| 年份 | 领涨风格 |
|------|---------|
| 2012 | 大盘 |
| 2013 | 中小盘 |
| 2016–2018 | 大盘价值 |
| 2019–2021 | 成长 |
| 2022 | 价值 |

## 对基金投资的影响

### 基金经理能力圈周期性失效
- 专注消费/医药的基金经理，在市场切换到新能源/周期股时跑输
- 去年冠军基金今年垫底是常态，非能力退化

### 投资者行为陷阱
- 投资者追逐"短跑冠军" → 在风格高点大量申购
- 风格切换后净值回撤 → 低点赎回
- 形成 Investor Gap 的正反馈循环

## 与投资方法论的关系

- 支持 `[[concepts/排除法优于优选法]]`：风格轮动使选股极难，排除法比优选法更稳健
- 与 `[[concepts/资产配置优先原则]]` 一致：通过资产配置分散风格风险，而非押注单一风格
- 与 `[[concepts/核心-卫星策略]]` 一致：核心仓位持有宽基指数（捕捉风格轮动），卫星仓位做主动选择
