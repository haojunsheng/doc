# 风险认知（Risk Perception）

风险认知是投资者对投资损失的可能性和严重程度的**主观判断与感受**，不同于风险的客观度量（标准差、最大回撤、下行风险）。它描述的是人对"这个风险我能不能承受"的内在体感。

## 核心命题

> 风险认知不是让你不害怕，而是让你害怕得明明白白。

同一组客观风险数字，在不同投资者心中可以产生完全不同的体感——同一个人，在不同情绪状态下对同一风险的感受也可能截然不同。

## 历史脉络

风险认知的现代理论起点：
- 1952 年：马科维茨投资组合理论，用方差（波动）度量风险
- 1970s：夏普 CAPM，将风险拆为系统性风险（不可分散）与非系统性风险（可分散）
- 1980s：行为金融学转折点，Kahneman 与 Tversky 前景理论揭示**损失厌恶系数 λ ≈ 2.25**——人们对损失的痛苦感约为同等收益快乐的 2-2.5 倍

关键发现：风险不是客观数字，而是人的主观感受。

## 形式化表达

```
风险感知 = f(客观风险, 心理偏差, 经验, 知识)

其中：
- 客观风险 = σ（标准差）、MDD（最大回撤）、DR（下行风险）
- 心理偏差 = 损失厌恶系数 λ ≈ 2.25、近期偏差、可得性偏差
- 经验 = 过去经历过市场周期的次数
- 知识 = 对投资标的的理解程度

风险承受力 = g(财务能力, 心理承受力, 投资期限, 收益目标)

当 风险感知 > 风险承受力 → 恐慌性卖出
当 风险感知 < 风险承受力 → 过度冒险
```

## 三种典型错位

| 情形 | 机制 | 后果 |
|------|------|------|
| 风险感知 > 风险承受力 | 过度恐惧，将正常波动放大为灾难 | 恐慌性卖出，低位锁死永久亏损 |
| 风险感知 < 风险承受力 | 风险无感，低估真实风险敞口 | 过度冒险，承受超出承受能力的损失 |
| 极端市场环境 | 心理偏差被放大，风险感知脱离客观风险 | 群体性恐慌，即使客观风险已很低 |

极端市场环境（如 2008 年、2020 年 3 月）是风险认知失效的典型场景——所有人都在恐慌性卖出，即使客观风险已经很低。

## 元反思：风险认知的边界

风险认知能帮你应对"已知的未知"——那些在历史数据中已经出现过的风险事件。但它无法帮你应对"未知的未知"——黑天鹅事件（如 2008 年雷曼兄弟破产）不在任何人的风险清单上，因为它们超出了已知框架。

换一种隐喻：**风险认知 = 免疫系统**。它不能消灭所有疾病，但能让你在大部分时候保持健康。偶尔你会感冒（亏钱），但你知道这是正常的，而且你会恢复。真正的危险不是感冒，而是免疫系统崩溃——那才是你需要避免的。

## 实践含义

1. **理解恐惧而非消除恐惧**：知道自己的基金会经历多大回撤、持续多久、恢复需要多长时间，恐惧就会变成"有预期的不适"
2. **校准风险感知与承受力**：定期审视两者是否匹配，特别是情绪变化时
3. **建立行为纪律**：用预设规则（再平衡、止损线、仓位上限）代替情绪驱动的决策
4. **接受认知局限**：承认"未知的未知"的存在，避免制造虚假的安全感
