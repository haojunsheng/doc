# 刚性兑付

## 定义

**刚性兑付**是指金融机构对资管产品承诺保本保收益，当投资出现亏损或未达到承诺收益时，由机构用其他资金（通常是新募集产品资金）为投资者兜底的行为。

## 形式化表达

```
刚性兑付 = 新产品资金 → 兑付老产品本息
本质 = 庞氏结构，不是无风险
```

## 运作机制

1. 银行或理财子公司承诺产品"保本保收益"
2. 如果某产品投资亏损或未达到承诺收益
3. 就拿新发售产品募集的资金给上一批投资人兑付
4. 只要不断有新投资者加入，前面的人就能拿到钱
5. 一旦后续资金续不上，就会出现巨大风险

## 与资管本质的矛盾

刚性兑付违背资管行业的核心原则：

```
资管本质 = 受人之托、代客理财、投资者风险自担
管理人只拿管理费，赚的钱给客户，赔的钱也该客户自己承担
```

刚性兑付则变成：有人亏损 → 用别人钱补 → 不公平 + 风险积累

## 资管新规打破刚性兑付

2018 年出台的资管新规明确要求打破刚性兑付，核心原因是：

- **公平性**：凭什么有人亏了钱可以拿别人的钱连本带息补上？
- **风险积累**：刚性兑付制造风险积累，不是消除风险
- **系统性风险**：一旦续不上资金，风险会集中爆发

打破刚兑后，投资者需要自己承担风险，这要求投资者具备基本的金融知识和风险意识。

## 边界条件

- 资管新规前，银行理财确实维持了较长时间的刚性兑付，但这只是时间问题
- 打破刚兑后，银行理财不再承诺保本，产品净值会随底层资产波动
- 投资者应关注底层资产而非发行机构信用
