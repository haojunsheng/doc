# 中间策略

## 定义

不纯粹押注价值或成长，以商业模式/基本面质量为核心筛选标准，寻求合理价格的优质成长公司，在风险与收益之间取得平衡的投资策略。

## 核心逻辑

```
中间策略 = 商业模式优先（不纠结标签） → 价值（低估值）+ 成长（高增长）→ 寻找"合理价格的优质成长"

中间策略优势 = 避免价值陷阱（纯价值） + 避免过高溢价（纯成长） → 风险收益比更优
```

## 与纯价值、纯成长的对比

| 维度 | 纯价值 | 中间策略 | 纯成长 |
|------|--------|---------|--------|
| 核心标准 | 低估值 | 商业模式优秀 + 合理价格 | 高增长 |
| 主要风险 | 价值陷阱 | 商业模式判断错误 | 支付过高溢价 |
| 典型表现 | 波动最小，回撤最小 | 波动居中，回撤适中 | 波动最大，回撤最大 |

> **注意：** Q6 关于波动/回撤"居中"的断言来源于晨星分析文章，属于方向性判断，当前缺乏实证数据支撑。

## 方法论

- **自下而上选股**：从个股出发，而非从宏观/行业出发
- **商业模式分析**：评估公司盈利模式是否可持续
- **竞争优势评估**：评估公司是否有护城河
- **估值判断**：以合理价格买入，避免过高溢价

## 边界条件

1. **商业模式判断错误** → 中间策略失效
2. **市场风格极端分化** → 中间策略可能跑输纯价值或纯成长
3. **基金经理更换** → 历史评估结论可能失效
4. **策略容量问题**：随着越来越多投资者采用类似策略，"商业模式优秀+估值合理"的机会可能被套利殆尽（关联 [[策略容量瓶颈]]）
