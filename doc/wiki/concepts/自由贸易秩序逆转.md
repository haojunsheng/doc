# 自由贸易秩序逆转

## 核心定义

关贸总协定（GATT）/ WTO 70年推动的自由贸易正在被逆转，但完全脱钩不太可能——全球经济互联程度前所未有。

## 历史数据

| 时期 | 发达国家平均关税 | 趋势 |
|------|----------------|------|
| 1948年 | 36% | — |
| 1990年代 | 3.8% | 持续下降 |
| 特朗普政策后 | 25.5% | 一步回到世纪最高 |

## 形式化表达

```
GATT/WTO 70年(关税36%→3.8%) → 特朗普逆转(2.5%→25.5%) → 但完全脱钩不可能
```

## 为何不会完全脱钩

- 当前全球经济互联程度前所未有
- 完全脱钩的成本大到不可承受
- 边界条件：如果全球分裂成两个平行贸易体系，"完全脱钩"就不是不可能

## 与投资者关系

[[稳中求进框架]]和[[关税贸易战中的防御性配置框架]]均建立在这一宏观判断之上：自由贸易秩序在逆转，但投资仍需全球分散，不能押注单一市场或单一政策结果。
