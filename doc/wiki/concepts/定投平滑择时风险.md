# 定投平滑择时风险

通过分散买入时间来降低择时错误的系统性方法，是改善投资者回报差的实操路径。

## 核心逻辑

改善路径 = 少择时 + 分散买入 + 选低波动产品 → 回报差收窄

- 研究显示不择时 = 回报差为零
- 分散买入避免单点踩中高点
- 低波动产品天然抑制交易冲动
- 定投是最简单的分散买入方式

## 边界

当市场出现历史性大泡沫时，不择时也会亏钱——只是少亏一点。
