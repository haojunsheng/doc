# 应急金分层存放

应急金分层存放是根据不同时间维度的资金需求，将应急金分配到不同流动性与收益特征的账户中，以同时满足**流动性**和**安全性**要求，同时不浪费收益。

## 分层逻辑

依据"不可能三角"（收益↔流动性↔安全性，最多同时满足两项），应急金优先保流动性和安全性，牺牲收益。

```
第一层（6个月生活费）→ 现金 / 货币基金
  - 随时可能要用的钱
  - 秒取，流动性最高
  - 收益最低

第二层（超出6个月部分）→ 短债基金
  - 不太可能一次性全取
  - T+1到账，流动性略降
  - 收益比货基高1-2%

第三层（总量很大时）→ 中长债 / 理财型保险
  - 进一步牺牲流动性换收益
  - 视个人情况决定是否启用
```

## 应急金规模标准

```
应急金下限 = 月必要开销 × 3
充分保障 = 月必要开销 × (6~12)
```

系数取决于：
- **收入稳定性**：不稳定职业→更厚缓冲
- **家庭负担**：有娃/有贷→更厚缓冲
- **社保/公积金覆盖**：覆盖部分支出时可适当降低

## 与[[分层水池策略]]的关系

应急金分层存放是分层水池策略在**现金流防御**维度的具体应用。分层水池策略更侧重于整体资产配置的时间分层，而应急金分层专注的是短期流动性风险管理，两者逻辑一致、互为补充。
