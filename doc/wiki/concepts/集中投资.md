# 集中投资

集中投资是一种投资策略，主张将资金聚焦于少数高确信度的投资标的，而非广泛分散。这一策略与巴菲特的投资哲学高度相关。

## 核心命题

```
集中投资 = 高确信度 × 长期持有 → 不追求分散，而是深度研究
```

巴菲特名言："分散投资是对无知的保护。如果你知道自己在做什么，分散投资是没有意义的。"

## 与分散投资的对比

| 维度 | 集中投资 | 分散投资 |
|------|---------|---------|
| 前提假设 | 投资者有能力进行深度研究 | 投资者难以判断个别标的优劣 |
| 风险来源 | 个别标的判断失误 | 系统性风险 |
| 收益潜力 | 高（成功时） | 平均（平滑后） |
| 所需能力 | 深度研究 + 判断力 | 资产配置 + 纪律执行 |
| 适用人群 | 专业投资者或有时间研究者 | 普通投资者 |

## 风险边界

- 集中度越高，个别判断失误的代价越大
- 需要极强的行业认知和公司研究能力
- 与 [[concepts/能力圈边界与策略调整]] 密切相关——只有在自己能力圈内才能有效集中

## 与伯克希尔实践

伯克希尔的投资组合以集中著称：
- 核心持仓（苹果、可口可乐、美国运通等）占比极高
- 长期持有，极少换手
- 深度研究后的投资决策，而非被动配置

## 与自下而上选股的关系

集中投资与[[concepts/自下而上选股]]高度契合：两者都强调深入理解单个标的，而非自上而下的行业配置。区别在于：
- 自下而上选股关注的是"选哪个标的"
- 集中投资关注的是"选了多少标的"
