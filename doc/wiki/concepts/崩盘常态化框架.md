# 崩盘常态化框架

崩盘不是"狼来了"的异常事件，而是资本市场的**定期体检**——约每7.9年发生一次（跌幅>20%），是常态而非例外。

## 核心命题

> 150年19次崩盘 → 平均每7.9年一次 → 崩盘是常态，不是例外

## 统计证据（晨星 1871—2025）

| 指标 | 数值 |
|------|------|
| 统计跨度 | 150年 |
| 崩盘次数（跌幅>20%） | 19次 |
| 平均间隔 | 约7.9年/次 |
| 1美元 → 150年后 | 约31,255美元 |

长期正回报与频繁崩盘并不矛盾：市场在剧烈颠簸中整体向上。

## 认知含义

1. **破除非理性恐慌**：当前崩盘恐惧通常源于"这次不一样"的叙事，但历史反复证明每次崩盘都有独特表象，内核规律高度相似
2. **重建时间尺度**：短期（1年以内）的崩盘叙事放大了痛苦感知；以10年维度看，每次崩盘后市场最终都收复失地
3. **应对优先于预测**：既然崩盘是定期到来的常态，与其猜测下一次何时来，不如建立不依赖预测的应对机制

## 行动公式

```
应对 = 风险承受能力 + 资金期限 + 多元化组合
```

不赌方向，以资产配置纪律抵御不可预测的事件冲击。

## 边界条件

- 若全球化彻底逆转、经济结构发生根本性变化，崩盘频率可能上升，历史参照系的有效性会下降
- 当投资者有短期流动性需求（1年内需用钱）时，此框架不能消除短期账面亏损
- 现代央行工具（QE等）改变了崩盘后的修复路径，历史痛苦程度的参照意义需打折扣
