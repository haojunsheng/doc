# 中美利差与资本流动

## 传导机制

```
美联储降息 → 美元↓ + 中美利差缩小 → 人民币压力↓ + 中国资产吸引力↑
```

## 核心逻辑

1. **利率平价效应**：美联储降息降低美元资产收益率，促使资金流向高收益的新兴市场。
2. **汇率渠道**：美元走弱减轻人民币贬值压力，提升中国资产的外币计价回报。
3. **资本流动**：利差收窄后，外资配置中国资产的边际意愿上升。

## 边界条件

- 中国资产的最终表现仍取决于自身基本面，美元走弱的好处可能被中国经济数据疲软所抵消。
- 如果中美利差缩小幅度有限（如美联储降息节奏慢于预期），传导效果将打折扣。
