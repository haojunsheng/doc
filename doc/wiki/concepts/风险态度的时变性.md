# 风险态度的时变性

同一人在牛市末尾和熊市末尾的风险意愿截然不同。风险态度不是固定的人格特质，而是随市场状态动态变化的情境变量。

## 核心命题

风险态度的时变性解释了为什么一次性的"风险测评"在实际操作中常常失效——测评分结果只能反映测评时的市场情绪状态，不能预测你在另一种市场状态下的真实行为。

## 机制

```
市场状态 → 近期盈亏体验 → 风险态度 → 投资决策 → 放大市场状态
```

这是一个正反馈循环：
- **牛市末尾**：近期表现好 → 高估自己风险承受力 → 增加风险暴露 → 买在高点
- **熊市末尾**：近期表现差 → 低估自己风险承受力 → 减少风险暴露 → 卖在低点

这与 [[近因效应]] 和 [[线性外推]] 同构——大脑天然给近期信息更高权重，将短期趋势当作永久状态。

## 与 [[行为风险]] 的关系

[[行为风险]] 描述了"风险态度变化导致追涨杀跌"的行为后果，[[风险态度的时变性]] 则解释了"为什么风险态度会变"的心理机制。两者互为表里：时变性是成因，行为风险是结果。

## 实践启示

1. **风险测评的有效性窗口很短**——测评结果在半年到一年内就可能因市场变化而失效
2. **在冷静期设定规则**——市场平静时预设股债比例调整计划，每年机械执行一次，把决策从情绪场景中移开
3. **识别自身状态**——当想"调整"仓位时，问自己：这是基于规则还是基于最近的市场涨跌？

## 盲区

文章假设投资者可以理性设定规则，但行为金融学表明：自我控制本身也是有限资源，预设规则在压力下同样可能被打破。
