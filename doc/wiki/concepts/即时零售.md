# 即时零售

**即时零售**（Instant Retail / Quick Commerce）指以"本地实体供给 + 即时配送网络"为核心，满足消费者 **30 分钟至 2 小时** 内送达的零售业态。

## 核心界定

| 维度 | 即时零售 | 传统电商 | 社区团购 |
|:---|:---|:---|:---|
| 时效 | ≤ 2 小时（通常 30-60 分钟） | 1-3 天 | 次日达 |
| 供给来源 | 本地实体（商超、便利店、前置仓、药店） | 远程仓发货 | 中心仓→团长→用户 |
| 配送方式 | 专人直送（骑手） | 快递物流 | 社区自提 |

## 生命周期定位：成长期中段

渗透率有多重口径，需明确区分：

| 口径 | 计算方式 | 估算数据 | 含义 |
|:---|:---|:---|:---|
| 社零口径 | 即时零售 GMV ÷ 社会消费品零售总额 | ≈ 4-6%（2025 年） | 占整体消费零售（偏悲观） |
| 网上零售口径 | 即时零售 GMV ÷ 网上零售总额 | ≈ 8-12% | 占线上零售（中间态） |
| 本地生活口径 | 即时零售 ÷ 本地生活总盘子 | ≈ 10-15% | 占整个本地生活场景（偏乐观） |

**判据结论**：无论哪种口径，即时零售渗透率多落在 **8-15%区间** → **成长期**。本报告取交叉验证中间态：**成长期中段**，度过了"模式验证"阶段，正处于规模扩张 + 份额争夺的阶段。

## 三大履约模式

```
即时零售
    │
    ├─→ 平台模式（Platform）
    │    美团闪电仓、京东到家、饿了么、抖音小时达
    │    轻资产：平台连接本地商家 + 配送网络，不持有库存
    │
    ├─→ 自营前置仓模式（Front Warehouse）
    │    叮咚买菜、朴朴超市、美团买菜（小象超市）
    │    重资产：自建前置仓 + 自采自销 + 即时配送
    │
    └─→ 平台 + 商家配送（O2O Marketplace）
         早期美团闪购、京东到家——商家上线、平台导流、骑手配送
```

## 市场规模

**2025 年 GMV ≈ 1.0-1.2 万亿元**，同比增速 20-30%。

### TAM / SAM / SOM 框架

```
TAM（潜在市场）：本地零售全量 ≈ 40-45 万亿元（社零总额）
SAM（可服务市场）：生鲜+日百+医药+快消 ≈ 10-15 万亿元
SOM（可获得）：当前实际 GMV ≈ 1.0 万亿元（2025E）

SOM÷TAM ≈ 2-4%（极小，但代表巨大空间）
SOM÷SAM ≈ 8-12%（渗透率，成长初期）
```

## 核心护城河：网络效应（非资源垄断）

即时零售的核心护城河是**网络效应**而非资源垄断：

| 要素 | 独占性 | 即时零售相关性 |
|:---|:---|:---|
| 劳动力（骑手） | ❌ 不可独占 | 骑手是"公地"，全平台共享；但**算法调度效率**构成事实壁垒 |
| 土地（位置） | 🟡 部分独占 | 前置仓选址有先发优势；但可被后来者以更高租金抢位 |
| 资本 | ✅ 阶段性 | 融资能力决定烧钱存活期 |
| 技术 | ✅ 算法壁垒 | 调度和路径优化（美团超脑系统）是硬壁垒 |
| **数据** | ✅✅ 核心 | 消费者行为数据 → 精准推荐+需求预测+前置备货 → 飞轮 |

**护城河飞轮**（正循环）：

```
更多用户 → 更多订单密度 → 骑手单位时间配送更多单 → 履约成本降低/时效提升
    ↑                                                                    ↓
更多商家入驻 ←———————————————————————————— 平台 GMV 更高 ←———————
```

**护城河风险**：
- 网络效应受**地域限制**——北京的网络效应无法平移广州（本地供给本地化）
- 品类同质化导致**平台可替代性强**（用户切换成本低，补贴敏感）
- 抖音"内容 + 即时配送"有可能用**差异化**打破同质化（发现式消费 vs 目的性消费）

## 五维分析结论

| 维度 | 评估 | 关键证据 |
|:---|:---|:---|
| **可行性** | ✅ 已验证 | 需求永恒（应急购物自古存在），成熟市场有参照（DoorDash/Gopuff/iFood） |
| **规模性** | ✅✅✅ 高 | TAM 40-45 万亿，SOM 仅 1 万亿，空间巨大；渗透率 8-15% 属成长期 |
| **防守性** | ✅ 中等 | 网络效应护城河，但地域分割、品类同质化、可替代性构成风险 |
| **盈利性** | ✅ 初步兑现 | 美团闪购 2024Q4 City-level 主营利润正值；叮咚非 GAAP 持续为正 |
| **估值** | PEG/PS→PE 过渡 | 美团闪购贡献增长溢价，但仍处于战略投入期 |

## 产能周期定位：Stage 3→4 过渡

```
Stage 1          Stage 2          Stage 3          Stage 4
供不应求    →   产能激增    →   产能出清    →   格局改善
                                         ↑
                                    即时零售在这里
                                  （成长期→成熟期过渡）
```

- 2020-2022：Stage 1-2，疫情催化下需求爆发、各路资本涌入
- 2023-2025：Stage 3，部分玩家退出/收缩（每日优鲜破产、叮咚退出多城）
- 2026 年后趋势：Stage 4 格局改善，头部份额进一步强化

## 关键风险因素

- **监管灰犀牛**：人社部三指引 + 职业伤害保障试点（已覆盖 1,000 万+骑手），中长期可能压缩平台利润率 2-4 个百分点
- **下沉市场瓶颈**：三四线城市订单密度不足、骑手意愿低，供需双低
- **抖音差异化冲击**："发现式消费"可能打破美团的"目的性消费"垄断
- **无人配送短期局限**：受空域管制和场景限制，规模化拐点在 2026-2027

## 景气度判断框架

```
即时零售景气度 = f（订单量增速, 单均经济模型, 竞争强度）

判断标准：
  🟢 景气上行：订单量增速 > 20% + UE 持续改善 + 补贴边际递减
  🟡 景气震荡：订单量增速 10-20% + UE 基本持平 + 补贴战持续
  🔴 景气下行：订单量增速 < 10% + UE 恶化 + 补贴强度回升

2025 年中判断：🟡 景气震荡
  - 订单量增速 ≈ 20%（仍高但边际放缓）
  - UE 改善（美团闪购已盈利）
  - 但抖音/京东持续补贴，竞争强度不降反升
```
