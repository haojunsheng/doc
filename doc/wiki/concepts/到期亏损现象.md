# 到期亏损现象

持有期基金在持有期结束时出现账面亏损的市场现象，是2022-2024年A股熊市背景下的集中暴露问题。

## 现象定义

持有期基金的持有期到期日恰好落在市场下跌阶段，导致投资者赎回时面临亏损。这一现象在近三年偏股型基金普遍下跌的背景下尤为突出。

## 本质归因

[[sources/5-notes--35-20260614t215507-qa-持有期基金到期亏损不是骗局qa--1y23zme.md]] 的分析指出：到期亏损主要是市场因素而非机制设计缺陷的结果。持有期基金的平均收益与同类型开放式基金相近，说明持有期本身未造成额外损失。

```
到期亏损 = 市场整体偏弱（2022-2024） × 偏股型基金普跌 × 持有期到期时点随机性
```

## 舆论张力

网络舆论中，部分投资者将持有期基金到期亏损归因为"骗局"或产品设计缺陷。晨星的分析反驳了这一归因，指出这是对市场原因的行为误读——将市场β的损失归咎于流动性约束机制。

## 对投资者的启示

- 到期亏损不应成为回避持有期基金的充分理由
- 关键是评估基金经理的长期能力和自身持有期的匹配度
- 持有期机制的价值在于改善行为纪律，而非保证正收益
