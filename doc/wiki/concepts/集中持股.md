# 集中持股

## 定义

将投资组合的大部分权重集中于少数个股（前十大持仓占比 50%–80%）的持仓策略。与传统"分散降低风险"的认知相反，集中持股的核心逻辑是：通过深度研究提升个股确定性，从而在集中持仓中控制风险。

## 形式化逻辑链

```
集中持股（50%–80% 前十大）
← 风险控制依赖个股安全边际（非行业分散）
→ 深度研究 + 高确定性
→ 敢于重仓
```

## 与分散持股的对比

| 维度 | 集中持股 | 分散持股 |
|------|---------|---------|
| 风险控制方式 | 个股深度研究+安全边际 | 行业/个股分散 |
| 对基金经理要求 | 高研究能力、强判断力 | 相对较低 |
| 极端情况风险 | 重仓股判断错误则损失大 | 单一判断错误影响小 |
| 流动性要求 | 高（调仓成本高） | 相对较低 |
| 业绩特征 | 高波动、高弹性 | 低波动、跟随基准 |

## 与基金经理能力的关系

[[持股集中度评估框架]] 指出：集中本身不是优点也不是缺点，它是基金经理选股能力和投资策略的外化表现。

```
有能力选股 → 集中持股 → 赚大钱
无能力选股 → 集中持股 → 亏大钱
认可贝塔   → 分散持股 → 老老实实赚贝塔
```

高集中度反映基金经理对所持个股的信心，但大赢大输，没有中间地带。集中持股者必须具备深度研究单个公司的能力，否则集中就是风险的放大器而非收益的来源。

## 量化分散 vs 主动集中的对比

| 维度 | 主动集中持股 | 量化分散持股 |
|------|------------|------------|
| 盈利来源 | 个股深度研究 | 统计优势捕捉错误定价 |
| 集中逻辑 | 能力外化，信心体现 | 破坏模型统计逻辑，不适用 |
| 风险来源 | 重仓股判断错误 | 模型未覆盖的极端事件 |
| 规模影响 | 规模过大被迫稀释集中度 | 规模扩张对分散度影响较小 |

两者的集中度差异源于盈利模式不同，而非风险偏好差异。详见 [[持股集中度评估框架]]。

## 实证案例：刘旭与大成高鑫

[[刘旭]] 管理的 [[大成高鑫股票]] 是集中持股的实证案例：

- 前十大持仓占比长期维持 50%–80%
- 风险控制依赖个股安全边际而非行业分散
- 对研究深入的个股给予高权重，对不确定的个股给予低权重
- 9个完整年度均超越同类平均和基准

这一案例为"集中持股≠高风险"提供了反直觉的证据，是对 [[集中度风险]] 和 [[行业集中度风险]] 的必要补充——这两个页面主要从警示角度分析集中风险，而刘旭案例展示了深度研究如何将集中转化为优势。

## 与风格中性的兼容性

[[风格中性选股]] 要求广泛覆盖所有候选股，集中持股要求高度聚焦。二者的兼容性通过"个股确定性"桥接：

```
风格中性 → 广泛评估所有候选股
           ↓
       只对确定性最高的个股重仓
           ↓
       集中持股成为结果而非风险来源
```

## 边界条件

1. **判断错误风险：** 重仓股基本面恶化时集中持股放大风险
2. **流动性风险：** 集中持股调仓成本高，市场流动性不足时尤为突出
3. **规模约束：** 管理规模过大（如 216 亿元）时，集中持股的执行难度上升
4. **研究能力门槛：** 集中持股要求基金经理具备深度研究单个公司的能力，不是所有经理都能驾驭
