# 银行股息差-bottoming框架

提炼自晨星中国对银行股基本面的五维度拆解，核心论点是：银行股低估值高股息的底层逻辑是三重因素叠加，而非单一因素驱动。

## 三重叠加逻辑

```
银行股底部信号 = 净息差见底 + 房地产风险可控 + 股息率相对吸引力上升
```

### 1. 净息差见底

- 银行净息差2023Q4触及1.69%历史低位
- 降幅小于市场预期，部分国有大行展现超预期表现
- 存款利率下调缓解了银行成本端压力
- 央行希望维持银行合理利润和净息差水平，会审慎把握宽松节奏

### 2. 房地产风险可控

- 涉房贷款占不良比例35%-85%（数据区间较宽，参考价值有限）
- 部分银行涉房贷款不良率已在2023年年中开始扭转上升趋势
- 开发商不良贷款率峰值估在4%-8%之间
- 信贷扩张趋于理性 + 政策支持房地产 → 资产质量有望稳固

### 3. 股息率相对吸引力上升

- 大型银行股息率5-6%，且近年有增长
- 利率下行环境中，银行股息率优于替代资产
- 核心机制：[[股息率-无风险利率比价模型]]——利率↓ → 高股息资产相对吸引力↑

## 银行商业模式形式化

```
银行模式: 存款(低价原料) → 风控(加工) → 贷款(高价成品)
净息差 = 毛利率
利率↓ → 存款成本↓ → 净息差压力↓ → 盈利预期改善
```

## 适用条件与边界

- 该框架主要适用于国有大行，股份制银行与城商行需单独评估
- 若贷款利率降幅超过存款利率降幅，息差会继续压缩
- 若房地产市场二次探底，涉房不良率可能回升
- 若经济复苏带动风险偏好回升，银行股"避风港"溢价可能消退
