# 提示注入

## 定义

提示注入是上下文工程的安全对偶面：凡是能进上下文的都是攻击面。当外部输入被插入模型的上下文窗口时，攻击者可以通过构造特定输入来"注入"恶意指令，改变模型的行为。

## 与上下文工程的关系

| 上下文工程 | 提示注入（对偶面） |
|-----------|------------------|
| 通过设计消息结构控制模型行为 | 通过设计输入内容劫持消息结构 |
| 目标是让 Agent 做正确的事 | 目标是让 Agent 做错误的事 |
| 防御方视角 | 攻击方视角 |

## 攻击原理

1. 用户的输入进入上下文窗口（工具结果、知识库检索、用户消息等）
2. 攻击者构造输入，使其包含看似"系统指令"的内容
3. 模型将注入内容当作合法指令执行

## 典型场景

- 工具调用结果中包含用户可控内容（如网页文本、文件内容）
- RAG 检索返回的片段被当作上下文的一部分
- 多轮对话历史中混入恶意历史消息

## 防御原则

- 区分系统消息与用户消息（角色隔离）
- 对工具结果进行结构化解析，不直接将原始文本塞入上下文
- 关键指令使用特殊分隔符保护，不在用户可控区域使用

## 验证方式

跑 `chapter2/` 提示注入攻防实验，亲手注入成功一次，理解攻击路径后针对性加固。
