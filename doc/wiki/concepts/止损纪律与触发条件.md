# 止损纪律与触发条件

止损不是"跌了就卖"的情绪反应，而是基于预设规则在特定触发条件下执行的纪律动作。两者的本质区别在于决策时点和驱动因素：止损是事前规则驱动，情绪卖出是事中恐慌驱动。

## 核心区分

```
止损 = 事前预设规则触发 → 理性执行
情绪卖出 = 下跌过程中恐惧驱动 → 乱卖（往往发生在最低点）
```

## 止损的三个关键原则

### 1. 提前设定，而非临场决策
在买入前就确定止损条件，避免在亏损扩大时因恐惧而失去判断力。没有预设止损的人，往往在账户净值跌破心理底线时被迫"割肉"，而此时恰好是最差时点。

### 2. 触发条件基于买入逻辑，而非价格本身
止损的根本前提是**买入时的核心假设被证伪**，而非单纯的价格下跌。例如：
- 因看好某公司盈利增长而买入 → 盈利不及预期时触发止损
- 因估值修复而买入 → 估值体系发生改变时触发止损
- 因行业景气上行而买入 → 行业景气拐点确认时触发止损

**短期价格波动不等于买入逻辑被证伪**——若基本面未变，短期下跌反而可能是加仓机会。

### 3. 纪律执行优于完美时机
止损可能在"相对高位"被触发（随后价格反弹），但这远优于在"毁灭性低点"被迫清仓。纪律的价值不在于每次都做对，而在于防止灾难性损失。

## 形式化对比

| 维度 | 止损（纪律） | 情绪卖出 |
|------|------------|---------|
| 决策时点 | 买入前预设 | 持仓中实时 |
| 驱动因素 | 规则触发 | 恐惧/panic |
| 执行结果 | 可控损失 | 可能发生在最低点 |
| 后续感受 | 理性接纳 | 后悔/自责 |

## 与止盈陷阱的关系

[[止盈陷阱]] 描述了"只止盈不止损"导致的盈亏不对称：赢时赚得少，输时亏得多。[[规则对抗本能]] 则从更广泛的视角强调用规则对抗本能冲动。止损纪律是这一框架中**亏损端的核心规则**，与止盈规则共同构成完整的退出策略体系。

## 边界与限制

- **止损线设得过紧**：频繁触发止损会在震荡市中不断小额亏损，此时止损规则本身需要优化
- **基本面未变时的正常波动**：不应因短期市场波动而触发止损，否则会错失长期恢复
- **流动性极差的标的**：止损可能导致无法以合理价格成交，需在买入前评估流动性风险

## 行动启示

1. 买入前明确写下：在什么条件下我会认为这次投资失败了？
2. 区分"价格波动"和"逻辑证伪"——前者是正常现象，后者才是止损信号
3. 执行止损时记录原因，用于后续规则迭代优化
4. 与 [[规则对抗本能]] 中的"止损规则"条目形成完整闭环
