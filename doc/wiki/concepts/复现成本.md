# 复现成本

## 定义

"可复现"不等于"容易复现"。一张照片的复现成本越高，它越不可替代，越好。这是对[[可复现概率]]的精确定义。

## 五种复现成本

| 成本类型 | 说明 | 案例 |
|---|---|---|
| 设备成本 | 需要特定器材才能拍出 | 大画幅相机、特殊镜头 |
| 时间成本 | 需要长时间等待 | 布列松等那个骑车人出现的瞬间 |
| 关系成本 | 需要与被摄者建立信任关系 | 荒木经惟拍摄妻子需要深厚的私人关系 |
| 知识成本 | 需要特定知识才能拍出 | 杉本博司理解自己在拍什么 |
| 机会成本 | 需要在正确时间出现在正确地点 | Harry Gruyaert 在街头精确的时机把握 |

## 核心公式

```
复现成本越高 → 照片越不可替代 → 越好
```

## 类比：物理学实验

物理学实验理论上任何人都能做，但需要设备、知识、时间、条件。同理，一张照片"看起来简单"不代表"容易复现"——关键看背后需要支付哪种成本。

## 与[[可复现概率]]的关系

- **可复现概率**：判断标准（能不能被复制？）
- **复现成本**：判断精化（值不值得花成本复制？）

两者本质相同，但"复现成本"更精确——它提醒我们：好照片不是因为"不能复制"，而是因为"复制成本太高，没人愿意付"。

## 跨域迁移

"可复现概率"本质上是**不可替代性**——你值多少钱，取决于多少事只有你能干。这一逻辑可迁移到任何领域：
- 代码：能解决别人解决不了的问题 = 好代码
- 写作：能说出别人说不出的东西 = 好文章
- 设计：能做别人想不到的方案 = 好设计
