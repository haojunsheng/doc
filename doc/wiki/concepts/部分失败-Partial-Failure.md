# 部分失败（Partial Failure）

分布式系统设计的起点概念。单机时代的假设——"调用要么成功要么失败"——在网络分区下全部失效，取而代之的是"部分失败"：系统中某些组件失败，其他组件仍在运行。

## 核心洞察

分布式系统的难点可以归结为"部分失败"——这不是一个抽象概念，而是所有工程决策的出发点。所有弹力设计模式（重试/熔断/限流/降级/幂等/补偿）都是在回应同一个问题：当部分组件失败时，系统如何继续工作？

## 与故障的关系

| 故障类型 | 典型表现 | 对应弹力模式 |
|:---|:---|:---|
| 瞬时故障 | 网络抖动、短暂超时 | 重试 |
| 持续性故障 | 服务不可用 | 熔断/降级 |
| 过载 | 流量洪峰 | 限流 |
| 数据不一致 | 重复请求、并发冲突 | 幂等/补偿 |

## 证伪条件

如果存在某个核心设计动机无法归入"应对部分失败"的框架（例如纯粹的组织复杂度驱动），则 H1 需要修正。
