# 多维风险承受力公式

实际风险承受力是一个多变量函数，而非单一维度的年龄倒数。

## 形式化表达

```
实际风险承受力 = f(投资期限, 收入稳定性, 支出刚性, 负债压力)
```

"100-年龄"法则只取了第一个变量（投资期限），遗漏了其余三个生活风险维度。

## 各维度说明

| 维度 | 说明 |
|------|------|
| 投资期限 | 距离需要用钱的时间跨度 |
| 收入稳定性 | 现金流入的可预测程度（稳定工资 vs 佣金制） |
| 支出刚性 | 必须有支出的部分（房贷、教育、医疗）占总支出比例 |
| 负债压力 | 到期负债对流动性的挤压程度 |

## 典型反例

一个30岁有房贷的人和30岁无债的人，即使投资期限相同，能承受的波动也完全不同。前者支出刚性高、负债压力大，风险承受力更低。

## 边界条件

对收入极低且稳定（如公务员）的人群，年龄可能是唯一有意义的变量——其他维度变化小，"100-年龄"在此场景下近似有效。
