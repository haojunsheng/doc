# 年报红旗信号三件套

年报中需要警惕的三个信号，任何一个出现都要进一步调查。

## 三件套

| 红旗信号 | 位置 | 含义 |
|---------|------|------|
| 会计政策变更 | 脚注 | 公司突然改变折旧方法、收入确认方法等，可能是为了调节利润 |
| MD&A 回避话题 | 管理层讨论与分析 | 对「竞争加剧」「监管风险」「客户流失」等敏感话题一笔带过 |
| 保留 / 无法表示意见 | 审计意见 | 年报有问题——可能是会计造假、信息不完整、或审计范围受限 |

## 逻辑关系

```
红旗信号 = 会计政策变更 ∨ 回避话题 ∨ 保留意见
```

任一条件满足 → 需要进一步调查，但不等于「公司有问题」。

## 使用原则

1. **起点而非终点**：红旗信号是调查的起点，不是结论
2. **合理例外存在**：会计政策变更可能是法规变化导致的合理调整；回避话题可能是因为"太复杂不适合公开讨论"
3. **组合信号更危险**：多个红旗同时出现时，排除概率大幅增加

## 与年报阅读流程的关系

在 [[年报阅读三要素框架]] 中，红旗信号检测贯穿全文：

- 读风险因素时：关注是否有系统性低估或回避
- 读 MD&A 时：对比财务数据，检查是否出现"说得好但做得差"的偏差
- 查脚注时：优先查找"会计政策变更""重大估计变更"条目
- 看审计意见时：将"无保留"作为可信度门槛

## 与排除法的关联

[[排除法优于优选法]]的核心逻辑在此得到具体应用：年报阅读的目的不是找到好股票，而是**排除坏公司**。红旗信号三件套是最直接的排除工具。
