# 反身性

由乔治·索罗斯（George Soros）提出的核心概念：预测本身会改变被预测的对象，预测者成为系统的一部分。

## 形式化表达

```
预测 → 影响参与者行为 → 改变系统状态 → 结果推翻原始预测 → 预测者重新调整
```

这与自然科学中的观察者效应有本质区别：市场参与者的认知直接改变了客观现实。

## 与投资的关系

### 为何市场预测不可靠

| 领域 | 预测是否改变对象 | 原因 |
|------|----------------|------|
| 天气 | 否 | 物理规律独立于观察者 |
| 市场 | 是 | 人的预期改变行为，行为改变结果 |

"天机一旦公开就不再是天机"：一旦某个预测被广泛相信，套利者会迅速消除它试图预测的模式。

### 反身性的两种形态

1. **认知功能**：参与者试图理解世界（单向：世界→认知）
2. **操控功能**：参与者试图改变世界（单向：认知→世界）

两者同时运行且相互干扰，导致预测误差无法收敛。

## 边界与批判

- 反身性解释了为何预测会失败，但并未提供替代方法——解决方案是转向 [[concepts/市场预测的不可靠性]] 中描述的情景推演
