# 主动被动资金流分化

主动被动资金流分化是中国公募基金行业正在经历的结构性转变的核心指标——被动基金持续吸金，主动基金（尤其混合型）连续四年净流出。

## 核心机制

资金流方向比规模排名更能反映行业格局的真实变化。其驱动逻辑如下：

**被动基金吸金**：
> 被动基金 = 低费率 + 透明 + 不依赖基金经理 → 投资者偏好 → 持续净流入

被动产品之所以能穿越市场周期吸纳资金，根本在于其费率优势、策略透明、无需依赖单一基金经理的判断。即使2023-2024年股市下跌，股票型被动仍大幅净流入。

**主动基金失血**：
> 主动偏股基金超额能力↓ + 净值下跌 → 投资者赎回 → 连续四年净流出

2022年以来A股系统性调整，主动基金超额收益难度加大，长时间亏损导致大面积赎回。2025年上半年，混合型（全部为主动）净流出1679亿元；全年合计净流出3761亿元。

| 指标 | 数值 |
|------|------|

### 资金迁移路径

主动股基/混合型/纯债/大盘宽基 → 被动指数/积极债/行业主题/港股QDII/黄金商品

| 类别 | 全年流向 |
|------|---------|
| 主动股基 | -708 亿 |
| 被动股基 | +6424 亿 |
| 混合型基金（全主动） | -3761 亿 |
| 积极债券（含权） | +9039 亿 |
| 信用债ETF + 科创债ETF | +4814 亿 |
| 商品基金 | +1273 亿 |
| 香港股票型（QDII） | +2644 亿 |
| 恒生科技ETF（单品类） | >1100 亿 |

## 标志性拐点：债券ETF超过股票ETF

2025年Q1出现了一个重要信号：**债券型ETF资金流首次超过股票型ETF，占整个ETF资金流一半以上**。

- 2025年Q1发行了8只基准做市信用债ETF，上市后规模均破百亿
- 利率债分类相比2023年底增长1.4倍

这一事件标志着被动产品的扩张从宽基指数跨越到固定收益领域，被动逆袭的边界正在扩展。

## 基金公司层面的分化

资金流分化也重塑了基金公司的竞争格局：

| 指标 | 数据 |
|------|------|
| 2025上半年公募规模 | 29.6万亿 |
| 前20大公司占非货基 | 66% |
| 易方达、华夏非货基规模 | 仅两家破万亿 |
| 华夏被动占比 | 71% |
| 华泰柏瑞被动占比 | 89% |
| 前7大中4家被动>主动 | 4/7 |
| 中欧、兴证全球被动占比 | 不足10% |

**含义**：头部公司加速向被动转型，8-20名仍以主动为主的中小公司生存空间被挤压。

## 边界条件

- 若 2026 年市场风格从极致分化回归均衡，主动基金可能阶段性恢复净流入
- 若利率反转上行，债券ETF面临资金流出和净值下跌风险
- 若黄金价格进入调整期，商品基金的资金流入会快速降温
- 若市场波动加剧、被动基金跟踪误差扩大，流入可能放缓
- **QDII 全年正流入与 H1 负流入的反转**说明需要季度维度而非年度维度的碎片化解读
