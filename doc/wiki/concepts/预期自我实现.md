# 预期自我实现

预期自我实现是指：对未来的信念本身改变了当下的行为，行为改变了现实，现实反过来又强化了最初的信念。在经济周期中，这是最核心的深层结构。

## 核心机制

经济靠预期运转：

- **自我实现的乐观**：当所有人相信经济会好 → 消费和投资增加 → 经济果然变好
- **自我实现的悲观**：当所有人相信经济会差 → 消费和投资减少 → 经济果然变差

这形成了一个永恒的反馈循环：

```
预期 → 行为 → 现实 → 预期
  ↑__________________________↓
```

## 在经济周期中的应用

[[concepts/股市与经济脱钩|股市与经济脱钩]]的核心解释正是预期自我实现：

- 市场预期衰退 → 抛售 → 经济真的受损 → 衰退确认
- 但市场往往**提前一步**定价预期，导致股市与经济数据出现系统性错位

## 2026年2月典型案例：PMI收缩但股市上涨

2026年2月数据显示，PMI连续两个月处于收缩区间（49.0%），但股市依然上涨：
- 中证1000涨3.71%，沪深300涨0.17%
- 原因：政治局会议释放"稳就业、稳企业、稳市场、稳预期"信号，两会推出产业政策

**形式化**：
```
PMI<50（收缩）+ 政策利好（稳增长信号）→ 投资者预期未来改善 → 股市↑
```

**关键洞察**：股市交易的是"未来改善的预期"，而非当下经济数据。PMI是先行指标，但股市是预期的折现器——当政策信号改变预期时，股市可以先于经济数据上涨。

**边界**：如果后续经济数据继续走弱（如PMI跌破48%），投资者的预期会逆转。

## 边界与警示

- 预期自我实现不意味着"想什么来什么"——它需要集体性的信念共振，单个投资者的预期影响有限
- 它与[[concepts/有效市场假说]]的张力：如果预期能自我实现，市场价格是否还能"正确"反映基本面？
- **风险**：当预期逆转时（如PMI持续恶化），自我实现的悲观会导致加速下跌

## 压缩

**一句话**：经济周期不是客观规律，是集体预期的共振——相信我会来，我就真的会来。股市往往领先经济，因为它交易的是预期，而非现实。
