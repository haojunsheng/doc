# 三层业绩归因框架

评估基金业绩的三个层次：绝对业绩、相对业绩、收益来源归因。用于区分基金经理的能力与运气。

## 第一层：绝对业绩

- 基金过去3年/5年的绝对收益率
- 及格线：指数（跑输指数的主动基金缺乏持有价值）

## 第二层：相对业绩

- 与同类基金对比
- 同类排名是否稳定在前1/3或前1/4？

## 第三层：收益来源归因

```
总收益 = 赛道选择贡献 + 选股能力贡献
```

- **押对赛道**：行业/主题基金受益於板块β，不代表基金经理选股能力
- **选对股票**：alpha来源于真正的选股技能
- 两者均为负 → 能力不足 → 赎回信号

## 操作化扩展

回本后的基金去留决策中，第三层归因是关键：

| 收益来源 | 含义 | 决策倾向 |
|---------|------|---------|
| 赛道贡献正 + 选股贡献正 | 能力+运气兼备 | 持有 |
| 赛道贡献正 + 选股贡献负 | 靠运气赢 | 审视是否继续持有 |
| 赛道贡献负 + 选股贡献正 | 风格逆风可能 | 观察，等待轮动 |
| 两者均为负 | 能力不足 | 果断赎回 |

## 与[[风格逆风与能力不足]]的关系

收益来源归因是对"风格逆风vs能力不足"区分问题的操作化回答——通过拆解收益来源，可以判断业绩不佳是短期风格不适还是长期能力缺陷。
