# 铁矿石长期需求下行

**铁矿石长期需求下行**是指中国经济转型和废钢使用比例提升导致钢铁产量难以逆转地下行，进而使铁矿石需求长期承压。

## 核心命题

> 中国经济向消费驱动转型不可逆 + 废钢使用比例提升 → 钢铁产量↓ → 铁矿石需求↓

## 形式化表达

```
中国经济转型（↓钢铁依赖） + 废钢使用比例↑ → 钢铁产量↓ → 铁矿石需求↓
```

## 驱动因素

1. **经济转型**：中国从投资驱动转向消费驱动，降低对大宗商品的依赖
2. **废钢替代**：电炉炼钢比例提升，废钢替代铁矿石
3. **环保政策**：对中小型低效钢铁企业减产

## 边界条件

若中国大规模基建刺激或全球制造业回流，钢铁需求可能阶段性回升。
