# 不追热点作为超额来源

"不追热点"不是一种消极的缺席，而是一种系统性的超额收益来源：避开热点泡沫化的高位风险，在估值合理时买入、高估时卖出。

## 核心论点

```
追热点 → 高位接盘 → 回撤风险↑
不追热点 → 估值合理时买入、高估时卖出 → 下行风险↓ + 长期超额↑
```

## 形式化表达

```
不追热点 ⊃ 在估值合理时买入 ⊥ 估值明显高估时卖出
⇒ 下行风险↓ + 长期超额↑
```

## 典型案例

- [[乔迁]]：明确不追逐市场热点、不盲从趋势，年化17.5%（2018.7–2026.1）
- [[黄珺]]：坚持独立思考，不盲目追逐"明星个股"，任期波动和下行风险均低于同类平均

## 边界条件

- 在纯题材驱动的A股市场中，不追热点可能短期跑输
- 需要极强耐心和持有人理解才能持续执行
- 短期跑输的忍耐力阈值难以量化评估
