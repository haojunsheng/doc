# 市场效率

市场效率是指资产价格已经反映了所有公开信息——因此很难通过研究找到「被低估」的股票。

## 形式化

```
市场效率高 → 价格 ≈ 价值 → 研究不值钱 → 主动管理难以跑赢
市场效率低 → 价格 ≠ 价值 → 存在错误定价 → 主动管理有机会
```

## 市场效率梯度

| 市场/板块 | 效率等级 | 主动基金失败率 |
|-----------|---------|---------------|
| 美国大盘股 | 最高 | ~80% |
| 美国中盘股 | 中高 | ~70% |
| 小盘股 | 中 | ~60% |
| 新兴市场 | 低 | ~50% |
| 债券市场 | 中高 | ~50% |

## 实践含义

- 大盘股被无数分析师盯着，价格很难偏离价值
- 小盘股、新兴市场研究覆盖少，可能存在被忽视的机会
- 高波动市场中，价格偏离价值的幅度和频率更大——给主动管理者更多低买高卖的空间
- 「有机会」不等于「一定能赢」——即使非有效市场，大多数主动基金仍然跑不赢

## 与规模困境的关系

[[concepts/规模困境]] 是市场效率的副产品：规模大的基金被迫买入大盘股，而大盘股正是市场效率最高的部分。

## 与反身性的关系

[[concepts/反身性]] 指出，投资者的认知会改变市场本身——当越来越多主动管理者追逐同一机会时，该机会会被迅速定价，市场效率随之提高，主动管理空间进一步压缩。
