# 风险偏好抬升

风险偏好抬升是指投资者从低风险资产（如债券）转向高风险资产（如股票、权益类基金）的意愿增强的过程。这一行为通常由近期市场上涨带来的"赚钱效应"驱动，属于行为金融学中的顺周期现象。

## 机制

```
A股回暖 → 全球权益资产吸引力上升 → 风险偏好抬升 → 资金从固收转向权益类
```

## 与[[近因效应]]的联系

风险偏好抬升是[[近因效应]]在资产配置行为中的典型表现：投资者过度权重化近期市场走势（上涨），并线性外推至未来，从而低估了回撤风险。

## 表现形式

- **基金层面**：债券型基金遭遇赎回压力，权益型基金获得申购
- **市场层面**：股债跷跷板从"债牛股熊"转向"股债双收"或"股强债弱"
- **相关概念**：[[股债冰火两重天]] 描述了这一现象在特定时间窗口下的表现形态

## 触发条件

风险偏好抬升可由多种因素触发：

| 触发因素 | 传导路径 |
|---------|---------|
| 政策利好（降准降息预期） | 宽松预期↑ → 风险偏好↑ |
| 经济数据企稳 | 基本面改善预期 → 风险偏好↑ |
| 地缘风险降温 | 外部不确定性↓ → 风险偏好↑ |
| 指数创出新高 | 赚钱效应 → 近因效应 → 风险偏好↑ |

## 边界条件

1. **可逆性**：如果市场再次下跌，风险偏好可能迅速回落（顺周期双向）
2. **政策干扰**：债基流出并不总是行为驱动——[[客地销售比例限制]] 表明政策约束同样可导致债基规模下降，两者需区分
3. **追高风险**：风险偏好抬升往往发生在市场上涨之后，此时转向权益类可能买在高点，触发[[收益序列风险]]
4. **不可持续性**：如[[sources/5-notes--29-20260614t220941-qa-11月股债双收qa--bb0mw7]]所示，"股债双收"的理想场景不会永远持续，投资者需做好分化的准备

## 解释张力

将债基流出简单归因为风险偏好抬升是一种行为主义解释。但 [[sources/5-notes--43-20260614t213245-qa-hk-mutual-fund-2026q1qa--13g0ssm]] 的数据显示，政策约束（客地销售额度限制）可能是同等甚至更重要的解释变量。读者应对"风险偏好"和"政策约束"两种路径做双重归因，避免单因果推断。

## 与股债双收的关系

风险偏好抬升是股债双收的核心驱动力之一。当风险偏好抬升与经济数据企稳同时发生时，可形成股债双收的理想场景；若仅有风险偏好抬升而无经济数据支撑，则可能退化为"股强债弱"的分化格局。
