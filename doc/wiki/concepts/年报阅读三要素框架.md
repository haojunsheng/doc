# 年报阅读三要素框架

年报里最重要的三个非财务报表部分，覆盖「是什么」「会怎样」「怎么看」。财务报表是结果，这三个部分是原因。

## 框架

```
年报 = 业务描述 + 风险因素 + MD&A
      是什么   会怎样    怎么看
```

| 部分 | 回答的问题 | 作用 |
|------|-----------|------|
| 业务描述 | 公司靠什么赚钱？产品、客户、市场 | 理解商业模式基础 |
| 风险因素 | 什么可能让公司倒闭？竞争、监管、技术颠覆 | **先行指标**，判断未来亏损可能性 |
| MD&A | 管理层怎么解释业绩？为什么营收涨了？利润跌了？ | 揭示管理层视角和叙事偏差 |

## 与财务报表的关系

财务报表（利润表、资产负债表、现金流量表）是「结果」，三要素是「原因」。先看逻辑（三要素），后看数字（财务报表）。

## 适用边界

- **初次了解一家公司**：三要素足够建立基本认知
- **已持有公司**：还需看财务报表（数字验证）和股东信（战略方向）
- **不适用于 ETF / 指数基金投资**：ETF 五问框架聚焦费率、跟踪误差等指数层面指标，跳过个股年报分析

## 与已有概念的关系

- [[前置信号-财报滞后性]]：本框架中风险因素即"先行指标"的理论基础，美团案例页侧重工具操作，本框架提供通用方法论
- [[年报红旗信号三件套]]：本框架 Q4–Q7 的操作化产出，可直接用于个股初筛
- [[排除法优于优选法]]：Q8「年报是过滤器」与该概念高度一致，是同一种思维范式的不同应用场景
- [[假设驱动研究]]：年报阅读中的红旗信号识别本质上是在检验投资假设

## 未覆盖的缺口

该框架提供了「读什么」和「为什么重要」，但没有给出「怎么读」的具体技术——例如如何交叉验证 MD&A 与财务报表的一致性？是否有量化指标衡量管理层的「回避程度」？
