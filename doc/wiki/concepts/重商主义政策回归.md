# 重商主义政策回归

## 核心定义

第二任期特朗普关税政策的本质特征：从第一任期的"谈判筹码"转变为真正的"重商主义政策"，目标是恢复制造业主导地位。

## 两任期对比

| 维度 | 第一任期 | 第二任期 |
|------|---------|---------|
| 关税性质 | 谈判筹码 | 真实政策 |
| 典型操作 | 加→谈判→撤 | 持续加→制造业回流 |
| 加墨关税案例 | 几天后取消，换取边境安全让步 | 预计长期维持 |
| 政策认同者 | 较少 | 身边认同关税恢复制造业主导的人更多 |
| 特朗普表述 | — | "从80年代就想用关税恢复制造业主导地位" |

## 形式化表达

```
第一任期: 关税↑ → 谈判筹码 → 让步交换 → 关税撤 → 逆差不变
第二任期: 关税↑ → 持续政策 → 制造业回流目标 → 逆差? (自我抵消)
```

## 影响评估

- 持续性：第二任期关税可能比第一任期维持更久、影响更深
- 自我抵消：尽管政策意图更强，但[[关税自我抵消机制]]仍然适用——逆差难以实质性收窄
- 经济代价：晨星预测GDP累计增长下调1.1pp，衰退概率40%-50%

## 与自由贸易秩序的关系

关贸总协定（GATT）70年推动的自由贸易正在逆转：
- 1948年发达国家平均关税：36%
- 1990年代降至：3.8%
- 特朗普政策推高至：25.5%（一个世纪来最高）

但完全脱钩不太可能，因全球经济互联程度前所未有，脱钩成本不可承受。
