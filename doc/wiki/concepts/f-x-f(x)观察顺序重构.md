# f(x) 观察顺序重构

**不是问"政府该不该干预"，而是先问"激励结构是什么"，再追问资源配置会流向哪里。**

这是[[兰小欢]]《置身事内》全书最重要的方法论贡献，其迁移价值高于任何具体机制描述。

## 旧观察顺序（主流经济学框架）

```
现象（房价高/地方债多/产业补贴）
  → 归因：政府干预 vs 市场失灵
  → 判断：好还是坏？该不该管？
```

这个框架的问题是把"政府"当成外生变量，只评估干预的合理性，而不解释政府为什么会这样做。

## 新观察顺序（f(x) 框架）

```
现象（房价高/地方债多/产业补贴）
  → 第一步：谁在决策？它的激励是什么？
  → 第二步：它的资源从哪里来？约束条件是什么？
  → 第三步：资源配置会流向哪里？
  → 结论：现象是该激励结构的必然产物
```

## 应用示例

### 地方债

旧视角："财政纪律松弛，地方政府乱花钱。"

f(x) 视角：城投债的抵押物是土地，偿还来源是未来土地增值。这反映的是一套以土地为信用基础的融资体系，有其内在逻辑。问题不是"该不该借"，而是"这套逻辑在房地产下行期还能不能持续"。

### 房价

旧视角："炒房客推高了房价，政府应该限购。"

f(x) 视角：商住用地和工业用地的价格差异（[[双向定价]]）直接服务于地方财政激励。房价不只是供需问题，更是地方财政模式的产物。

### 产业补贴

旧视角："政府扭曲市场价格。"

f(x) 视角：地方政府本身就是投资者，[[京东方]]合肥案例中政府直接股权投资。问题是：激励结构是否导致重复建设和资源错配？

## 迁移适用性

这个观察顺序重构不仅适用于中国经济分析，也适用于分析任何制度环境下的政策行为——只要关注"激励结构 → 行为 → 资源配置"这条因果链，而不是停留在"该不该干预"的规范性争论上。
