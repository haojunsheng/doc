# 被动收入增长三驱动

晨星提出，被动收入的真正增长来自三条路径：股息增长、新增储蓄、股息再投资。这三条路径全部依赖时间，是红利投资需要耐心的根本原因。

## 核心公式

```
被动收入增长 = 股息增长 + 新储蓄 + 再投资
```

三者都依赖时间，缺一不可。

## 三个驱动逐一拆解

### 1. 股息增长

公司盈利持续增长 → 分红能力增强 → 股息随时间自动增长。这是唯一"不劳而获"的增长路径，但前提是选对公司。

- 能持续增长的股息才能跑赢通胀
- 今天5%的固定股息，二十年后购买力可能只剩2%
- 债券的利息固定，长期会被通胀侵蚀——股息的优势恰恰在于增长潜力
- **边界：** 若公司削减股息或停止增长，"耐心"就变成了"死扛"

### 2. 新储蓄

投资者持续追加投入。这是最可控但边际效应递减的路径。

- 工资增长有限，新增储蓄速度随年龄增长而下降
- 但新增储蓄本身是复利的另一来源：早期投入的每一分钱都在未来产生股息

### 3. 再投资

将收到的股息自动再买入份额，形成复利飞轮。

- 再投资的复利效应在后期才爆发
- 早期再投资的效果不明显，后期份额累积到一定规模后呈现指数级增长
- **边界：** 再投资的前提是公司持续分红且股价未被严重高估

## 时间依赖的深层含义

红利投资最需要耐心，因为三条路径都依赖时间：
- 股息增长需要公司盈利多年持续增长
- 新增储蓄需要多年持续积累
- 再投资的复利需要在时间尽头才充分展现

缺乏耐心将导致红利投资沦为"伪被动收入"——表面有股息，但未能形成结构性收入系统。

## 与高股息陷阱的关系

[[高股息陷阱风险]]描述的现象与此框架直接相关：当投资者追逐当前高股息率时，往往忽略了股息增长这一更重要的驱动——那些股息率5%的公司可能已经停止增长，而股息率2%但持续增长的公司长期回报更高。
