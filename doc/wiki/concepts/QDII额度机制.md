# QDII额度机制

QDII（合格境内机构投资者）额度是外汇管理局审批的、允许境内投资者通过境内金融机构投资境外市场的额度配额。额度控制直接影响QDII基金的申购规模和海外市场配置能力。

## 形式化表达

```
QDII配置价值 = f(海外股市涨幅, 汇率, 额度供给)

额度供给↑ → QDII基金申购放宽 → 资金流入 → 净值上涨
额度供给↓ → QDII基金限购 → 资金流出 → 净值承压（或溢价收缩）
```

## 额度历史脉络

| 时间 | 事件 | 数据 |
|------|------|------|
| 2006年 | 试点启动 | 首批额度发放 |
| 2008年 | 金融危机冲击 | QDII净值普遍腰斩，监管收紧 |
| 2012年 | 总额度冻结 | 冻结在900亿美元 |
| 2018年 | 重启审批 | 额度逐步扩容 |
| 2020年 | 突破1400亿 | 累计额度破1400亿美元 |
| 2025年7月 | 本轮扩容 | 新发30.8亿美元，累计1708.69亿美元（191家机构） |

**监管逻辑**：优先给二级市场溢价高的基金分配额度，结构性释放而非全面放开。

## 额度机制的核心影响

### 对基金净值的影响
- 额度充裕 → 申购顺畅 → 资金流入推高净值
- 额度紧张 → 限购/停购 → 资金外流或转向替代渠道（如港股通）

### 对投资者的影响
- 额度限制使"买得到"成为稀缺资源
- [[concepts/通道摩擦与额度稀缺]] 指出：投资者常误把通道稀缺等同于资产便宜

### 对市场的溢出效应
- QDII额度扩容可能缓解境内资产荒
- 但也可能加剧境内外市场联动风险

## 与汇率风险的关系

QDII基金的收益包含两个来源：
1. 海外资产价格上涨（如美股、港股上涨）
2. 汇率变动（如人民币贬值增厚收益，升值侵蚀收益）

公式化表达：
```
QDII实际收益 = 海外资产收益 + 汇率收益 - 费率 - 额度摩擦成本
```

## 与[[港股通]]的关系

当QDII额度紧张时，资金可能通过港股通等替代渠道流入港股，形成渠道间的此消彼长。

## 边界条件

**额度扩容利好的前提**：
- 海外资产处于上涨趋势
- 汇率相对稳定或人民币贬值
- 无重大地缘政治风险

**额度扩容失效的情景**：
- 海外市场回调（如美股大跌）
- 人民币大幅升值（汇率侵蚀收益）
- 境内资产出现更好机会（如A股牛市）
