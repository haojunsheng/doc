# 爆款基金发行逆周期信号

## 定义

新基金发行规模与市场未来表现呈系统性负相关：**发行高峰 ≈ 市场阶段性顶部**；**发行冰点 ≈ 投资机会**。

这是一个可用于判断市场周期的逆向信号指标。

## 核心机制

```
市场情绪高涨 → 基民追涨 → 新基金募集火爆 → 资金集中入市
→ 市场估值推高 → 后续空间收窄
→ 建仓期完成时市场已调整 → 净值下跌
→ 规模缩水（投资者割肉）
```

### 实证证据（2020年样本）

| 指标 | 数值 |
|------|------|
| 2020年偏股型基金募集规模 | 近1.5万亿元 |
| 5只爆款基金三年平均跌幅 | 40-50% |
| 同期沪深300跌幅 | 约30% |
| 规模缩水幅度 | 68-86%（投资者割肉离场） |

### 反例（规律确认）

- 2018年底发行困难 → 2019-2020年这些基金表现优异
- 2023年平均募集规模仅3.3亿，创10年新低 → 逆向布局信号

## 制度性原因：为什么"卖热"而非"卖好"？

1. **费率差异**：新基金认购费（1-1.5%）远高于老基金申购费（0.1-0.15%），渠道更愿意推广新基金
2. **尾佣机制**：渠道以尾佣为导向，销售导向而非投资者需求导向
3. **基金公司动机**："一次性营销"比持续营销更省事，规模增长带来管理费收入增加
4. **投资者认知偏差**：基民误以为净值1元=低估，把"打新股"思维搬到基金

## 边界条件

- **规律失效于市场周期转折点**：需在发行信号基础上结合估值、政策等多因素判断
- **建仓期的双面性**：顶部时是劣势（高位建仓），底部时是优势（平滑成本）
- **市场成熟度差异**：在成熟市场（如美国），新基金发行主要目的是完善产品线，而非规模扩张

## 与投资行为的关联

此信号解释了[[高位建仓风险]]和[[认购费与申购费差异]]的制度根源，同时是[[逆向投资]]策略在基金选择领域的具体应用。它也与[[基金发行规模与市场估值负相关]]高度重叠，后者更侧重量化框架，前者侧重行为信号。
