# 赎回费政策对配置的影响

**赎回费政策对配置的影响**指2025年9月出台的场外债基赎回费规定对FOF债券配置行为的扭曲效应，是理解[[concepts/FOF配置转向框架]]中"债券配置场外转场内"转向的关键机制。

## 核心机制

```
场外债基<6个月赎回费≥0.5% → FOF转向场内债券ETF
```

## 政策背景

- 2025年9月5日销售费用规定征求意见稿出台
- 场外债基持有期不满6个月需支付至少0.5%赎回费
- FOF作为机构投资者同样受该规定约束

## 政策 unintended consequence

赎回费政策本意是抑制短期交易，但FOF作为机构投资者也被波及，导致配置扭曲（从场外转场内）。这是一种典型的政策 unintended consequence。

## 边界条件

若最终规定豁免FOF的赎回费或降低费率，场外配置可能回流。
