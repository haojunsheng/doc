# 黄金正反馈循环

黄金价格与ETF资金流之间存在**双向放大效应**，既在上涨阶段推高金价，也在下跌阶段加速抛售，形成正反馈循环。

## 机制描述

```
上涨阶段：
金价↑ → ETF资金流入 → 买入实物 → 需求↑ → 金价↑↑

下跌阶段（反向）：
金价↓ → ETF资金流出 → 卖出实物 → 需求↓ → 金价↓↓
```

2026年2月中旬以来黄金ETF持续大量净流入，底层持有实物黄金现货合约，规模越大对实物需求越高，进一步推升金价。

## 关键认知

1. **双向性**：正反馈不是单向上涨引擎，下跌时同样有效。4%级别的单日暴跌即反向正反馈的结果。
2. **触发条件**：政策突变（如关税暂停/恢复）可引发情绪逆转，触发反向正反馈。
3. **与择时陷阱的关联**：正反馈的双向放大效应使得短期价格波动剧烈，进一步强化了[[concepts/择时的心理陷阱]]的论点——试图捕捉这类波动几乎必然失败。

## 边界条件

- 单次大跌不一定是趋势反转，需结合宏观环境判断
- ETF资金流的持续性和规模决定了正反馈的强度
- 当市场进入长期均衡状态后，正反馈效应减弱
