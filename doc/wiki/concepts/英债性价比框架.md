# 英债性价比框架

从英国国债2026Q2配置观点抽象出的分析框架：**当不确定性与收益率曲线波动上升时，中短端品种可能已具备性价比，条件是风险溢价被收益率充分覆盖。**

## 核心判断标准

```
性价比 = 风险溢价是否已被收益率充分定价
        ↑
    若：收益率上行幅度 ≥ 风险补偿要求 → "有吸引力"
    若：收益率上行幅度 < 风险补偿要求 → "中性/回避"
```

## 逻辑链

```
地缘冲突/不确定性上升
    ↓
收益率曲线波动↑（尤其是短端）
    ↓
中短端收益率上行幅度足够大
    ↓
风险溢价已被定价 → 性价比显现 → 配置观点上调
```

## 必要条件

| 条件 | 说明 |
|------|------|
| 收益率已充分上行 | 中短端品种价格已下跌，收益率已上升至足以覆盖新增风险 |
| 不确定性正在缓和 | 长端溢价有望随不确定性缓和而回落 |
| 央行未进一步收紧 | 若央行超预期加息，性价比可能被侵蚀 |

## 边界条件

- 若英国通胀数据持续超预期 → 性价比被侵蚀
- 若财政状况恶化 → 长端压力增大，但中短端相对受益
- 若油价冲击持续时间超预期 → 所有逻辑失效

## 与日债框架的对称性

[[英债性价比框架]] 与 [[日债三重压力框架]] 构成晨星2026Q2配置观点的核心对称判断：

- 英债：收益率上行已覆盖风险 → "有吸引力"
- 日债：收益率未充分覆盖风险 → "中性"

两框架共享同一判断标准——"风险是否已被收益率充分补偿"——但在不同资产上的结论相反。这一对称性是框架最有迁移价值的部分。

## 应用场景

- 任何利率敏感资产的性价比判断
- 地缘冲突或宏观冲击后的资产配置决策
- 短端 vs 长端的收益率曲线选择
