# 晨星风险等级 R1–R4

晨星将基金按风险程度划分为五个等级（R1 至 R4 为当前市场实际可用等级，R5 暂无对应产品），每个等级对应不同的最大回撤参考范围和适用投资者类型。

## 定义与数据

| 风险等级 | 名称 | 最大回撤参考 | 适用投资者 |
|---------|------|------------|----------|
| R1 | 低风险 | ≈ 0% | 极度厌恶风险，资金短期可能动用 |
| R2 | 中低风险 | ≈ -4% | 能接受小幅波动，追求稳健增值 |
| R3 | 中高风险 | ≈ -25% | 能承受中等波动，持有期 ≥ 3 年 |
| R4 | 较高风险 | ≈ -40.28% | 能承受大幅波动，持有期 ≥ 3 年 |
| R5 | 最高风险 | （无数据） | 当前市场无对应产品 |

注：以上数据来自晨星近5年统计，为参考值而非硬边界。

## 核心特征

**风险与收益的正相关**：R1→R4，3年平均收益逐级递增，"风浪越大鱼越贵"成立——但前提是持有期足够长。

**持有期临界点**：6个月和1年无法覆盖 R2–R4 的最大回撤，3年是高风险基金从亏损中恢复并创造正收益的临界持有期。

**R2→R3 分类断层**：R2（约 -4%）到 R3（约 -25%）之间存在巨大跳跃，中间缺乏过渡档位，导致投资者难以找到风险敞口介于两者之间的产品。这是晨星分类体系的设计局限。

## 与投资纪律的关系

投资者必须在投资前（"出海前"）确定自己能承受的风险等级，而非在市场下跌时临时调整。两个常见错误：

1. **选错等级**：选了 R4 但心理只能扛 20% 回撤 → 在底部割肉，策略崩溃
2. **事后调整**：市场下跌后从"应该选 R4"退却到"还是选 R2 吧" → 踏空后续恢复

风险承受能力 ≠ 资金闲置时间。钱能闲置3年不代表心理上能扛住 -25% 的波动。
