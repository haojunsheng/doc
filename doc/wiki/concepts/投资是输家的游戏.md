# 投资是输家的游戏（Loser's Game）

查尔斯·艾里斯（Charles Ellis）在《赢得输家的游戏》中提出的核心隐喻：**投资不是赢家的游戏，而是输家的游戏**。

## 形式化

```
赢家 ≠ 靠打出好球得分
赢家 = 靠对手失误丢分

投资胜率 = f(避免犯错, 对手犯错频率)
         ↓ 机构占比 90% 后
         ↓ 市场定价精准，对手犯错极少
         ↓ 投资者唯一可控变量：减少自己的犯错
```

## 三个支撑论点

### 1. 市场结构变化压缩主动空间

1960 年代机构占比约 10%，信息慢、人手少、只盯蓝筹，主动经理有超额收益空间。如今机构占比超 90%，顶尖人才、全球信息、量化工具齐备，定价效率大幅提升——即便基金经理比前辈更优秀，也赶不上市场对"卓越"的要求水位。

### 2. 成本是确定的负收益

管理费、交易摩擦、税收都是确定的负收益。主动投资者越频繁交易，成本越高，差距越大。

```
1% 管理费 ÷ 7% 年回报 = 15%（占回报比重）
1% 管理费 ÷ 超额收益 0%~1% = 100%+（占超额收益比重）
```

### 3. 行为偏差驱动过度交易

80% 的人自认优于平均——统计上不可能。这种过度自信偏差导致频繁交易，而"无聊"的指数投资恰好隔离了这一偏差。

→ [[concepts/高于平均效应-投资语境]]

## 与投资行为的关联

这一隐喻推导出一个反直觉结论：**无聊是好事**。

- 个股投资有趣 → 高关注 → 高交易 → 高成本 → 收益受损
- 指数投资无聊 → 低关注 → 低交易 → 低成本 → 保护复利

→ [[concepts/无聊的投资]]

## 边界条件

- 在定价效率低的新兴市场或细分领域，主动管理仍可能有超额收益
- 若主动经理能持续创造显著超额收益（年化 3%+），管理费占比不极端
- 前提：投资者能真正接受"无聊"；极端市场环境可能需要再平衡
