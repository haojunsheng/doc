# 三层增强固收策略

以高等级信用债为底仓，通过信用利差交易和利率交易两层增强来获取超额收益的固收+策略框架。由[[宋倩倩]]在景顺长城实践中系统化。

## 框架结构

```
第一层（底层，90–100%）：高等级信用债
  - 久期：3年以内
  - 类型：城投/产业/金融均衡配置

第二层（中层，10–30%）：信用利差交易
  - 标的：银行二级资本债3–5年期
  - 来源：捕捉信用利差收窄/扩大

第三层（顶层，0–20%）：利率交易
  - 标的：地方债
  - 来源：近两年从利率波动获取超额收益
```

## 形式化表达

```
90–100% 高等级信用债底仓 + 10–30% 信用交易 + 0–20% 利率交易
⇒ 年化4.04%，超基准0.71%（宋倩倩，景顺长城）
```

## 与相关策略的区分

| 概念 | 区别 |
|------|------|
| [[固收+增强派]] | 本概念是该流派的精细化操作框架，定义了三层的仓位区间和工具 |
| [[信用债利差]] | 本概念中的信用交易层即通过信用债利差交易获取超额 |

## 边界条件

- 若信用利差持续压缩，信用交易层的超额收益可能消失
- 若利率大幅波动，利率交易层的风险敞口会放大
- 整体表现高度依赖基金经理的交易能力，而非单纯票息积累

## 适用场景

适合追求"稳健收益+小幅超额"的投资者，不适合追求高收益或能承受较大波动的投资者。
