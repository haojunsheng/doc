# 痛苦指数

以**市值蒸发比例**与**回本时长**两个维度量化评估崩盘严重程度的直觉框架，用于横向比较不同历史崩盘的"痛苦"程度。

## 二维评估体系

| 维度 | 说明 |
|------|------|
| 市值蒸发比例 | 从高点到低点的最大回撤幅度 |
| 回本时长 | 从低点到重回前期高点所需时间 |

以 **1929年大崩盘** 作为痛苦基准（100%）：

```
1929年痛苦指数 = 100%（基准）
  - 市值蒸发：89%（100美元 → 21美元）
  - 回本时长：4年+
```

## 历史对照

| 崩盘事件 | 市值蒸发 | 回本时长 | 痛苦指数（相对1929） |
|----------|---------|---------|---------------------|
| 1929年大崩盘 | 89% | 4年+ | 100%（基准） |
| 2000年互联网泡沫（单次） | ~50%（纳指半年腰斩） | ~2年 | 中等 |
| 2008年次贷危机（叠加） | 再砸至46（相对于2000年高点） | 12年累计 | 高（因叠加效应） |
| 2020年熔断 | 19.6%（1个月） | 4个月 | 极低 |

## 关键洞察

1. **短期跌幅大 ≠ 真正痛苦**：2020年1个月跌19.6%（跌幅不小）但仅4个月回本，痛苦指数远低于1929年
2. **叠加崩盘的致命性**：2000年纳斯达克在尚未回本时又遇2008年次贷危机，12年才回本——痛苦指数被二次崩盘大幅放大
3. **痛苦是主观的，但可量化**：同样的跌幅，对长期投资者和对短期需 liquidity 的投资者意味着完全不同的痛苦等级

## 应用边界

- 痛苦指数是直觉框架，非精确数学公式
- 现代央行干预（QE、降息）已改变崩盘后的修复速度，历史痛苦程度的参照需谨慎
- 若全球化彻底逆转，未来崩盘痛苦程度可能系统性高于历史均值

## 与其他概念的关系

- 与 [[concepts/叠加崩盘效应]] 直接相关：叠加崩盘是痛苦指数异常升高的主因
- 与 [[concepts/回本]] 交叉：回本时长是痛苦指数的核心维度之一
- 是 [[concepts/崩盘常态化框架]] 的实证支撑：痛苦程度虽有差异，但崩盘本身是定期发生的常态
