# 费用是复利的反面

费用是少数几个「确定的负回报」——每多付 1% 费用，长期回报就少 1%。

## 量化案例

```
本金：10 万元
年化回报：8%
期限：30 年

费用率 0.1% → 实际回报 7.9% → 30 年后约 102 万元
费用率 1.5% → 实际回报 6.5% → 30 年后约 68 万元
差距：约 34 万元
```

费用差距不大，但复利放大后差距惊人——30% 累计回报差距。

## 核心命题

- 费用是唯一「确定」的负收益来源（不像市场波动、选股失误，有运气成分）
- 高费用基金并不一定带来高回报，因此很可能"既多付了钱，又多承受了风险"
- 费用是复利的反面——复利积累财富，费用侵蚀财富
- **量化实证**：[[sources/5-notes--37-20260614t091504-qa-为什么大多数基金经理跑不赢指数qa--yzydit]] 显示主动基金费用率 1.2% vs 指数基金 0.1%，10年累计差距约12%，是75%主动基金失败率的直接原因之一

## 扩展：真实成本框架

[[sources/5-notes--31-20260614t091505-qa-指数基金的隐性成本qa--1pdszbh]] 将"费用"概念从单一管理费扩展为完整框架：

```
真实成本 = 费用率 + 跟踪误差隐含成本 + 税收成本
```

- **费用率**：账面成本，直接可见
- **跟踪误差隐含成本**：基金回报偏离指数的程度，等价于额外的隐性费用
- **税收成本**：资本利得分配导致的税后回报损失（主要在应税账户中重要）

这个框架的核心洞见：**"便宜"的基金不一定是总成本最低的基金**。

## 边界条件

- **同类比较**：不能拿主动管理基金的费用跟指数基金比，它们提供的东西不一样
- **正确做法**：同策略里选综合成本最低的（费用率 + 跟踪误差 + 税收效率）
