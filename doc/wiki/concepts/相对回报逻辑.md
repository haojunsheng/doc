# 相对回报逻辑

投资者在低利率环境下，以"相对不差"而非"绝对高收益"作为资产配置决策依据的逻辑。

## 定义

相对回报逻辑指：当绝对收益率普遍走低时，投资者的参照系从"历史峰值收益"切换为"替代资产的收益水平"，选择"相对更优"而非"绝对最高"的资产。

## 核心机制

```
绝对收益（自身历史）→ 参照系切换 → 相对收益（替代资产对比）
```

### 货基案例

| 参照系 | 对比对象 | 相对优势 |
|--------|---------|---------|
| 自身历史峰值 | 货基曾达4-6% | 现1.1%，差距大 |
| 活期存款 | 活期0.2%以下 | 1.1% vs 0.2%，5倍优势 |
| 一年定期 | 大型银行<1% | 1.1%略胜，且可随时支取 |

**结果**：货基收益率从4-6%跌至1.1%，但投资者仍选择货基而非活期——因为参照系已从"自己的过去"切换为"别人的现在"。

### 欧洲负利率案例

```
存款利率(-0.5%) < 货基收益(虽低但>存款) → 资金回流货基
```

欧洲负利率政策下，存款利率达-0.5%，货基即使收益很低（接近0%），仍优于深度负收益的银行存款，形成"相对不差"逻辑。

## 边界条件

1. **替代资产收益回升**：若银行存款利率上调至高于货基收益，相对优势消失，资金回流
2. **信用下沉违约风险**：若货基为追求相对优势而过度信用下沉，导致违约事件，逻辑失效
3. **绝对收益锚定**：若投资者心理锚定历史高收益（"以前有5%现在只有1%"），相对回报逻辑难以生效

- [[追涨杀跌损益侵蚀]] 的逆向表现：在利率下行期，投资者反而抱团于"相对优势"产品
