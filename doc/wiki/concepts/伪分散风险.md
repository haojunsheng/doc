# 伪分散风险

## 定义

投资者因基金名称或上市地标签的误导，误以为自己实现了跨市场分散，实际上底层资产高度重合，相关性并未降低，甚至集中度更高。

## 产生机制

1. **标签依赖**：投资者用"美股/QDII/港股"等上市地标签判断资产属性
2. **标签≠基本面**：上市地是法律概念，不决定营收来源和经营风险
3. **隐性集中度**：QDII 基金（尤其是中概股类）穿透后"中国含量"极高
4. **虚假分散**：持有多个 QDII 基金 + A 股基金，实际敞口高度集中在单一国家

## 典型场景

### 场景一：中概股 QDII + A 股

- 中证海外中国互联网指数与沪深 300 相关系数达 **0.71**
- 同时持有两者 = 加倍押注中国，而非分散风险
- 与标普 500 的相关性反而更低

### 场景二：港股基金 ≠ 国际分散

- 恒生指数 60% 以上为中国企业权重
- "港股配置"的实际国际敞口有限

### 场景三：瑞幸式资产被归为"美股"

- 在纳斯达克上市，但营收 100% 来自中国
- 归类错误导致风险测算失真

## 与既有概念的关系

- 是对 [[跨市场分散]] 的必要修正——跨市场分散的前提是底层资产真正来自不同市场，而非同属一国
- 扩展了 [[集中度风险]] 的内涵：从行业集中延伸到隐性国家集中
- 是 [[资产相关性分散]] 的反面例证

## 识别方法

执行 [[穿透持仓]]，以营收来源地替换上市地作为国家敞口判断依据。
