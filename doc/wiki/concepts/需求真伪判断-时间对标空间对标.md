# 需求真伪判断——时间对标 / 空间对标

## 定义

在可行性分析的第一步——判断某商业需求是否真实存在——所采用的两种对标方法。它们是"销售可行性"的核心工具，先于[[需求排序矩阵]]使用。

## 时间对标

**定义**：往前看，历史上是否有同样需求被不同方案满足过。

**底层假设**：需求是永恒的，方案是变化的。成功的商业模式不是创造新需求，是用新方案满足已有需求。

| 永恒需求 | 历代解决方案 |
|---------|------------|
| 在家快速吃饭 | 干粮 → 方便面 → 电话外卖 → 互联网外卖 → 预制菜 |
| 出行 | 走路 → 轿子马车 → 汽车 → 网约车 |
| 传递文字 | 飞鸽传书 → 电报 → 短信微信 |
| 听音频资讯 | 茶馆说书 → 广播电台 → 播客 |

**反例——共享篮球**：以前没有篮球租赁需求（篮球不贵、不占地方、打球总能找到球），共享篮球在满足一个从未存在过的需求 → 伪需求。

## 空间对标

**定义**：横向看，成熟市场（美日韩）有无成功案例。

**底层假设**：人类底层需求相通，成熟市场的经验可作参考。

这就是孙正义的"时光机理论"和C2C（Copy to China）模式的底层逻辑：
- 海外有Yahoo → 搜狐
- 海外有Google → 百度
- 海外有eBay+PayPal → 淘宝+支付宝
- 海外有Twitter → 微博

**失效情形**：
- 对标对象本身也是新生事物（如2021年国内跟风Clubhouse全部失败）
- 政治/经济/技术/社会文化差异过大（教育/医疗/房地产等行业）

## 与需求排序矩阵的关系

```
销售可行性分析流程：
  时间对标/空间对标 → 需求真伪判断 → 需求排序矩阵（频次×弹性）
       │                          │
   "需求是否存在？"           "需求好不好赚钱？"
```

## 与空间对标法（市场规模）的关系

注意区分：本概念中的"空间对标"用于**需求真伪判断**；而在[[TAM-SAM-SOM市场规模口径]]中，空间对标是一种**市场规模测算方法**（用成熟市场的渗透率推算新兴市场的天花板）。两者同名但用途不同。
