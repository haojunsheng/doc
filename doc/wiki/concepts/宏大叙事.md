# 宏大叙事

## 定义

跨时代的、改变世界的投资故事——它能激发强烈的集体想象，驱使大量资本涌入某一领域，往往成为泡沫形成的核心催化剂。

## 机制

```
宏大叙事出现
    → 投资者相信旧规则失效
    → 情绪狂热，FOMO 扩散
    → 资本大规模涌入
    → 产能过剩
    → 泡沫形成与破裂
```

## 历史案例

| 叙事 | 时代 | 结局 |
|------|------|------|
| "铁路将改变美国" | 1840s | 英国铁路泡沫破裂 |
| "互联网将改变一切" | 1990s | 纳斯达克跌 78%，80% 公司消失 |
| "房价永远不会跌" | 2000s | 次贷危机，标普 500 跌 57% |
| "AI 将取代人类" | 当前 | 待验证 |

## 与相关概念的区别

- [[这次不一样叙事陷阱]]：侧重于投资者利用叙事合理化个人持仓的认知偏差。
- [[宏大叙事]]：侧重于叙事本身的规模与跨时代特征，是泡沫形成的宏观驱动因素。
- 两者关系：宏大叙事是"这次不一样"的典型载体。

## 投资启示

1. 叙事越大，风险越高——当投资故事从"改善生活"升级为"改变世界"时，最需警惕。
2. 叙事本身不一定错——创新确实可能改变世界，但路径是"过度炒作→崩溃→重生"，而非直线上升。
3. 逆向投资者应在废墟中寻找机会，而非在狂热中追高。
