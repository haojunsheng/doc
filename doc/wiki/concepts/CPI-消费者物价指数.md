# CPI（消费者物价指数）

CPI（Consumer Price Index）是衡量消费品和服务价格水平的核心指标，用于判断经济是否存在通胀或通缩压力。

## 定义与构成

CPI 衡量一篮子消费品和服务的价格变化。在中国，CPI 中食品烟酒类别占比最大，其中猪肉价格权重尤为突出，因此猪肉价格和猪周期对 CPI 影响显著。

## 与 PPI 的关系

[[PPI-生产者物价指数]] 是 CPI 的先行指标。价格波动通常先出现在生产领域，通过产业链向下游扩散，最终影响消费环节。判断未来几个月 CPI 走势的有效方法是观察当前 PPI：

- PPI 先涨 → 数月后 CPI 跟涨
- PPI 先跌 → 数月后 CPI 跟跌

## 与 [[通缩螺旋]] 的关系

CPI 持续为负或接近零，是判断经济是否进入通缩螺旋的关键信号。[[通缩螺旋]] 的机制会通过 CPI 数据清晰地反映出来——物价持续下跌，而非偶尔波动。
