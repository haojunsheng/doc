# 强制跟投绑定

《基金管理公司绩效考核管理指引》（2026版）的核心制度之一：要求基金管理公司高管和基金经理将其绩效薪酬的一部分强制买入自家基金或自管产品，实现"风险共担、利益共享"。

## 制度设计

| 角色 | 强制跟投比例 | 要求 |
|------|-----------|------|
| 高管 | 30% 绩效薪酬 | 买入自家基金，其中权益类≥60% |
| 基金经理 | 40% 绩效薪酬 | 买入自己管理的产品，持有≥1年 |

## 与基金经理自持的区别

[[基金经理自持]] 是基金经理的个人行为信号，属于自愿性质；强制跟投是监管强制的制度安排，具有法律约束力。两者的核心差异：

- **自持**：行为信号，可选择买或不买，金额由个人决定
- **强制跟投**：制度约束，不买即违规，金额由监管规定

两者都服务于同一个目标：让管理人的利益与持有人利益对齐。

## 核心逻辑

```
真金白银投入 → 风险共担 → 利益绑定 → 抑制短期博弈
```

基金经理的钱和基民的钱在同一个池子里，才能真正实现"吃自家狗粮"。

## 边界条件

- 若基金业绩长期低迷，基金经理的实际薪酬会因跟投亏损而大幅下降，可能导致人才流失
- 新规假设"经理有能力但动机不足"，但若能力本身不足，强制跟投反而造成双输
- 持有期≥1年的限制防止短期套利，但无法解决长期能力问题
