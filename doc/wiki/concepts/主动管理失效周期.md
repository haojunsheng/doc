# 主动管理失效周期

## 定义

主动管理失效周期是指主动型基金战胜基准的比例在一段时间内系统性下降的现象，反映了市场有效性的提升和主动管理竞争优势的结构性削弱。

## 核心数据（来自晨星2024报告）

| 周期 | 2020年战胜率 | 2024年11月战胜率 |
|------|------------|----------------|
| 1年期 | 90% | 14% |
| 3年期 | — | 首次跌破50% |
| 5年期 | — | 57% |

## 驱动因素

1. **风格快速轮动**：市场热点切换频繁，主动基金经理难以持续捕捉风格红利
2. **量化策略普及**：量化模型在信息处理速度和纪律性上逐渐超越人工
3. **信息透明度提高**：市场有效性强，超额收益来源被快速套利消失

## 逻辑链

```
市场有效性提升
  → 超额收益机会减少
    → 主动管理难以持续跑赢基准
      → 战胜率从90% → 14%（1年期）
        → 资金流向被动指数基金
```

## 边界条件

- 如果市场有效性下降（如新兴市场），主动基金可能重新获得超额收益
- 如果经济出现结构性变化，新的投资机会可能出现，主动管理仍有价值
