# 被动投资崛起

## 定义

被动投资崛起是指以指数基金和ETF为代表的被动型产品，在市场中的规模和占比快速提升，投资者从主动管理基金转向被动投资的结构性趋势，逐渐取代主动管理成为主流投资工具。

其驱动力包括：主动基金持续跑输指数、被动基金费率显著更低、市场风格轮动使主动选股难度加大。

## 核心数据

### 2023年

| 指标 | 数值 |
|------|------|
| 主动权益基金前三季度赎回 | 近400亿（不含新基金） |
| ETF和指数基金资金流向 | 自2021年持续吸引资金净流入 |
| 被动基金管理费率 | 0.15-0.5% |
| 主动基金管理费率 | 约1.5% |

### 2024年更新

| 指标 | 数值 |
|------|------|
| 指数基金规模 | 突破5万亿元，较10年前增长10倍 |
| ETF资金流入 | 1.1万亿元，创近20年新高 |
| 主动基金1年期战胜率 | 从2020年的90%降至2024年11月的14% |

## 机制

```
主动基金回撤 > 指数 → 投资者赎回 → ETF资金净流入 → 被动基金规模扩大
```

```
主动基金战胜率持续下降
  → 投资者转向低成本的指数基金
    → ETF成为主流工具
      → 指数基金规模爆发
```

## 底层原因

1. **市场有效性提升**：A股逐渐成熟，主动管理超额收益空间收窄
2. **费率敏感度上升**：无风险利率下行，费率对净收益的影响被放大（见[[显性费率与隐性费率]]）
3. **量化策略普及**：主动管理的执行优势被算法交易削弱
4. **风格轮动加速**：市场风格切换频繁，主动选股难度加大（见[[风格轮动-a股语境]]）

## 对投资者的启示

- 被动指数基金和ETF应成为组合的核心配置
- 仅在市场出现结构性机会时，才考虑适度配置主动基金
- 关注基金的工具化属性，而非历史业绩叙事

## 边界与局限

- 在熊市中，优秀主动基金可以通过择时和选股获得超额收益
- 被动基金只能跟随指数下跌，无法规避系统性风险
- 被动投资的崛起不等于主动投资的消亡，两者各有适用场景

- [[费率复利效应]]：被动基金的低费率在长期持有中具有显著的复利优势，是2023年费率改革受益的主要方向
- [[风格轮动-a股语境]]：风格轮动加速使主动选股难度加大，进一步推动资金流向被动投资
