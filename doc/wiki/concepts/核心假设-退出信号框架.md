# 核心假设-退出信号框架

将投资决策建立在若干核心假设之上，并为每个假设设定明确的退出信号，是避免"凭感觉持有"的有效方法。

## 框架结构

每个核心假设对应一条可观察的退出信号：

| 核心假设 | 退出或降仓信号 |
|---------|--------------|
| AI基础设施投入会转化为纳指头部公司的收入和自由现金流 | 云和AI相关资本开支继续高增，但收入增速、毛利率、自由现金流连续不达预期 |
| 纳指100的赢家筛选机制继续有效 | 指数高度集中于旧赢家，但新技术赢家无法进入或权重无法体现 |
| 广发目标ETF规模和流动性优势能抵消联接结构摩擦 | 目标ETF长期高溢价/折价、成交量流动性下降、跟踪误差扩大 |
| QDII通道仍能支持小额配置 | 限购进一步压低或长期暂停申购，定投执行失去意义 |
| A类长期持有能摊薄前端费用 | 投资者持有期低于1-2年，或需要频繁调仓赎回 |

## 债券增强基金示例：广发增强债券A

| 核心假设 | 退出信号 |
|---------|---------|
| 基金经理能通过类属配置和信用筛选提供持续增强 | 连续4个季度跑输中证全债指数，且组合没有明显降低风险暴露 |
| 信用风险可控 | 企业债、中票、二级资本债占比继续提高，同时出现低评级信用下沉、单一主体集中或持仓债券负面舆情 |
| 机构资金进出不会破坏组合稳定性 | 单季度大额赎回导致规模跌破2亿元，或A类机构占比维持90%以上且规模剧烈波动 |
| 可转债只是增强，不会改变产品风险底色 | 可转债占净值比例显著升至8%-10%以上，且在权益市场波动期净值回撤扩大 |
| 当前收益足以补偿债券风险 | 近一年收益降到与货币基金/短债基金差距很小，但净值波动仍高于它们 |

## 使用原则

1. **假设要具体可检验**：不是"纳指会涨"，而是"AI资本开支会转化为利润"
2. **退出信号要明确可观测**：不是"感觉贵了"，而是"连续两季度自由现金流不达预期"
3. **假设之间相互独立**：避免多个假设依赖同一事实，否则一个事实证伪会同时击垮多个假设

## 与S曲线阶段判定的关系

核心假设-退出信号框架是S曲线阶段判定的操作化：当证据显示资产从加速期进入成熟期（估值高企、通道拥挤），对应的假设会逐一失效，触发退出信号。

参见 [[wiki/concepts/S曲线阶段判定]]。

## 与"市场预测的不可靠性"的关系

[[concepts/市场预测的不可靠性]] 论证了单点预测本质不可靠——预测本身会改变被预测对象（反身性），行业结构性激励导致自信偏差。本框架提供了替代方案：不做"市场会怎样"的单点猜测，而是列出"如果怎样，我该怎么办"的可检验假设组，并为每个假设设定明确的退出信号。

### 为什么需要这个框架

[[concepts/市场预测的不可靠性]] 论证了单点预测本质不可靠——预测本身会改变被预测对象（反身性），行业结构性激励导致自信偏差。金融市场的极端复杂性和反身性使得专业投资者的预测准确率长期低于随机，远低于"有用"的阈值。

本质是**预测者 vs 被预测系统的博弈困境**：预测者成为系统的一部分，一旦某个预测被广泛相信，套利者会迅速消除它试图预测的模式——"天机"一旦公开就不再是天机。

| 来源文章的核心论据 | 对框架的支撑 |
|---|---|
| 中金公司10条预言：2022年错了9条，2023年10条全错 | 说明单点预测失败是常态，需要预设退出条件而非赌单一方向 |
| 达里奥论文《赚钱还是做预测》："大多数做预测的人并没有在市场上赚钱" | 预测能力与投资收益无必然关联，框架用退出信号替代预测判断 |
| 晨星行为金融团队研究：金融预测准确率低于"丢硬币"（50%胜率） | 验证了预测的不可靠性，支持以假设检验替代预测 |
| 策略会是营销行为而非投资指导 | 行业结构性激励导致"确定性幻觉"，框架强制要求可证伪条件 |
| 自信偏差：自信的从业者在行业中更成功，即使预测不准 | 提醒投资者警惕自信信号，用客观退出标准替代主观信心 |
| "如果市场怎样，我该怎么办"比"市场会怎样"更可靠 | 直接对应框架逻辑：核心假设=如果怎样，退出信号=怎么办 |

### 框架如何回应该批判

| 市场预测的陷阱 | 框架的应对 |
|---|---|
| 单点预测不可靠 | 列出多种假设路径，每条路径配独立退出信号 |
| 预测影响结果（反身性） | 退出信号是可观测的事实标准，不依赖预测准确性 |
| 行业激励偏向确定性表述 | 框架强制要求假设可证伪、信号可观测，拒绝模糊断言 |
| 自信偏差掩盖无能 | 用量化阈值（如连续4季度跑输、规模跌破2亿）替代主观信心 |

### 方法论一致性

[[concepts/市场预测的不可靠性]] 提出"情景推演 > 单点预测"，形式化表达为：

```
情景推演 = 列出多种可能路径 → 为每种路径预设应对方案 → 不赌单一结果
```

核心假设-退出信号框架是该理念的操作化：核心假设是"如果怎样"的表达，退出信号是"怎么办"的操作化。二者高度一致——前者提供哲学基础，后者提供执行工具。

参见 [[concepts/市场预测的不可靠性]]、[[concepts/反身性]]。
