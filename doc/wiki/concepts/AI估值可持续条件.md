# AI估值可持续条件

## 定义

AI投资热潮的估值要站得住脚，必须满足"AI真正推动实体经济效率提升"这一条件。仅凭AI支出计划和股价上涨不足以支撑当前估值。

## 形式化表达

```
不成立: AI支出计划 + 股价上涨 ≠ 估值成立
成立: AI提升实体效率 → 估值成立
```

## 核心逻辑

### 为什么支出≠估值成立
1. **支出规模不决定估值可持续性**：关键不是AI支出多少，而是能否推动更广泛经济领域的效率
2. **应用深度不够**：客服自动回复级别的应用不够，需要结构性颠覆
3. **亚洲案例**：营收极低、负现金流、只有概念就能高融资的AI公司大量存在

### 什么条件下估值成立
- AI加速落地到实体经济
- 产生可量化的效率提升
- 从概念走向规模化商业应用

## 关键数据点

- 英伟达占美国指数约8%、全球指数约6%，被动投资者已过度集中
- 亚洲部分AI公司"营收极低、负现金流、只有概念就能高融资"

## 时间框架

"现在还不到时候"——Preston的判断，但未给出具体时间表。这是一个待验证的开放问题。

## 与FOMO的关系

AI热潮中的FOMO表现为：看到AI相关标的上涨 → 追高 → 估值极高 → 回调风险积累。当前估值是否"站得住"是判断FOMO风险程度的关键。

## 与被动投资者困境的关系

AI估值如果不可持续，被动持有AI权重股的投资者将面临双重损失：估值回归 + 指数权重集中风险。

## 开放问题

1. AI估值何时能"站得住"？
2. 如何区分"炒作型AI股"与"基本面型科技龙头"？
3. 如果AI未能推动实体经济效率提升，估值回调的幅度大概多大？
