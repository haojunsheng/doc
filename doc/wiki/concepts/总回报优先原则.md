# 总回报优先原则

## 定义

总回报 = 收益（股息/利息）+ 股价变动。只盯收益率而忽视价格变动会导致严重的认知盲区——高收益可能伴随着更大的本金损失，最终总回报为负。

## 形式化

```
总回报 = 收益率 + 价格变动率
```

**极端案例**：
- 8% 股息率 + 20% 股价跌 = -12% 总回报
- 2% 股息率 + 25% 股价涨 = 27% 总回报

## 核心洞察

投资者常犯的错误是把「收益率」等同于「回报」。当一只股票的股价从 100 跌到 50、股息不变时，股息率从 3% 翻倍到 6%——但这不是公司变好了，而是市场在定价风险。盯住 6% 的收益率买入，可能会遇到股价继续下跌，最终总回报为负。

## 边界条件

- **熊市阶段**：高息股确实能提供现金流缓冲，因为股价普遍下跌，股息是少数正收入来源。
- **长期视角**：总回报始终是唯一真实衡量标准，股息只是回报的组成部分之一。
