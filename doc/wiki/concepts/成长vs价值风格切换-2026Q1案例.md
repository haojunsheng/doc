# 成长vs价值风格切换-2026Q1案例

## 定义

2026年Q1美股市场中，成长股估值溢价从24%收缩至3%，价值股逆势上涨4.59%，呈现典型的高估值成长向低估值价值轮动。

## 数据对比

| 指标 | 成长股 | 价值股 |
|------|--------|--------|
| 估值溢价变化 | 24% → 3% | 低位企稳 |
| Q1涨幅 | 回调 | +4.59% |
| 驱动因素 | 估值泡沫破裂 | 估值修复+基本面改善 |

## 形式化表达

```
成长 < 价值 ← 估值溢价大幅收缩(24%→3%) + 基本面预期分化
```

## 与[[成长-vs-价值风格的驱动因素]]的关系

本文补充了2026Q1美股的具体数据点，丰富了成长vs价值切换的实证案例库。核心驱动机制一致：风险偏好下降 + 估值回归压力 → 资金从成长流向价值。

## 投资启示

- 当前环境价值股优于成长股
- 宽护城河企业估值已至区间底部，具备安全边际
- 不应因科技股下跌而盲目抄底，需区分内因与外因
