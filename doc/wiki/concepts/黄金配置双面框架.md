# 黄金配置双面框架

**黄金配置双面框架**是从推力与风险两个维度理解黄金配置价值的决策框架：一面是去美元化与避险需求驱动的上行推力，另一面是均值回归与极端波动带来的下行风险。黄金是有用的组合分散工具，但绝非"稳赚不赔"的避风港。

## 框架结构

```
           ↑ 推力面                    ↓ 风险面
去美元化 ────────────────────────── 均值回归（经通胀调整后金价超均值2倍）
宏观避险需求 ───────────────────── 暴涨暴跌历史（年均跌17%+）
央行持续增持 ───────────────────── 非生息资产（无现金流支撑）
美元走弱预期 ───────────────────── 避险≠稳定（波动性极高）
美联储降息 ─────────────────────── 相关系数在极端条件下上升
```

## 推力面：为什么黄金还在涨

| 推力 | 机制 | 边界 |
|------|------|------|
| 央行去美元化 | 各国央行增持黄金降低美元储备占比，中国2022-2025年合计增持444吨 | 美元信用恢复则推力减弱 |
| 宏观避险需求 | 地缘政治+经济不确定性→资金涌入，上半年400亿美元流入黄金ETF | 全球局势明朗则推力消退 |
| 美元走弱 | 黄金与美元负相关，美元持续走弱助推金价 | 美元重新走强则利空 |
| 美联储降息 | 降息降低持有黄金的机会成本 | 加息周期则压制金价 |

**牛市延续条件**：四者任一维持即可支撑金价高位；若同时反转，牛市可能终结。

## 风险面：为什么不能追高

### 1. 均值回归风险

[[concepts/金价均值回归框架]]指出，经通胀调整后的金价已超过长期均值两倍。NBER研究表明，历史高位后金价往往进入长期下跌——1980年冲高后十年低迷，2011年达峰值后2013-2015年惨跌。

### 2. 避险≠稳定

黄金的"避险"标签来源于其与股债的低相关性，而非自身表现稳健。历史上有多个年均跌幅超17%的暴跌周期。

### 3. 非生息属性

[[concepts/黄金非生息资产]]强调，黄金不产生现金流，价格上涨完全依赖供需关系变化。巴菲特"黄金什么也不创造"的批评正是指向这一点。

## 配置含义

| 维度 | 建议 |
|------|------|
| 收益预期 | 降低——黄金是保值工具而非增值工具 |
| 配置比例 | 控制在合理区间（参考[[concepts/黄金保险定位框架]]的10-15%） |
| 买卖纪律 | 基于资产配置逻辑，而非追涨杀跌 |
| 组合角色 | 利用[[concepts/黄金-A股低相关性]]（相关系数0.37）降低组合整体风险 |
