# 投顾份额

投顾份额是一种新型基金份额类型，其核心制度设计是**免尾随佣金（客户维护费）**，通过让投顾收入只来自基于账户规模的投顾服务费，解决传统代销渠道中"双重收费"带来的利益冲突问题。

## 核心机制

```
投顾份额 = 免尾佣 + 投顾费（基于账户规模）
→ 投顾收入与基金推荐脱钩
→ 推荐行为更客观，投资者利益对齐
```

## 监管背景

2025年9月，中国证监会发布《公开募集证券投资基金销售费用管理规定（征集意见稿）》，明确**通过投顾渠道销售的基金不得收取客户维护费**。这是投顾份额在中国落地的制度基础。

## 与既有份额类型的关系

投顾份额本质上是**非捆绑式份额**在中国语境下的制度形态——投资者只需支付管理费和运营费，不承担申购费、尾佣等利益冲突费用。对比：

| 份额类型 | 费率结构 | 利益冲突程度 | 典型渠道 |
|---------|---------|-------------|---------|
| A类 | 申购费 + 管理费 + 托管费 | 中高（含尾佣） | 银行、券商 |
| C类 | 销售服务费（按日计提）+ 管理费 + 托管费 | 高（含尾佣） | 互联网平台 |
| Y类 | 管理费×50% + 托管费×50% | 中（含尾佣，但费率更低） | 个人养老金渠道 |
| 投顾份额（非捆绑式） | 管理费 + 运营费 | 最低（免尾佣） | 投顾渠道 |

## 海外参照

投顾份额的制度逻辑与海外"清洁份额"（Clean Share）同源，受英国RDR（2013）和美国《受托人规则》（2017）启发——两者均通过监管强制禁止尾佣支付，推动市场向清洁份额过渡。

## 待澄清问题

- 中国投顾份额试点的实际进展及落地时间线
- 免尾佣后投顾基于账户规模的商业模式在低费率环境下是否可持续
- 投顾份额与[[规模正循环]]之间是否存在新的激励扭曲

## 与 [[基金公司利益冲突]] 的关系

[[基金公司利益冲突]]从宏观层面指出基金公司规模导向与投资者收益最大化的结构性偏差；投顾份额是这一冲突在具体收费机制层面上的制度解法——通过消除尾佣，切断渠道收入与基金推荐之间的利益链条。
