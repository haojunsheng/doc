# 行为损耗框架

基民不赚钱的核心机制：基金回报与投资者实际到手回报之间存在裂口，这个裂口由行为损耗填充。

## 核心公式

```
投资者回报 = 基金回报 − 成本 − 行为损耗
```

其中：
- **成本** = 管理费 + 托管费 + 交易费 + 申赎费（已计入基金净值，外部可见）
- **行为损耗** = 错误的申赎时点选择 + 过高的交易频率 + 费率承担结构不利（外部不可见，但影响实际账户收益）

## 行为损耗的三个来源

### 1. 申赎时点错误

投资者倾向于在市场高点申购、低点赎回——即追涨杀跌。晨星数据显示，中国基金投资者过往买卖决策甚至跑输简单买入持有。

### 2. 交易频率过高

高换手率直接侵蚀收益：
- 主动权益基金年均换手率 350-400%，每年持仓换 3-4 遍
- 交易费用占主动基金总费用的 30%
- 频繁调仓本质是在为券商和税务打工

### 3. 费率承担结构不利

- 投资者年度综合持有成本 2.55%
- 被动基金仅 1.03%
- 如果市场回报 7%，1% 费率就占走 15% 的回报

## 行为损耗的最小化条件

当同时满足以下两个条件时，行为损耗趋近于零：
1. 投资者完全不做任何操作（买入后不动）
2. 持有的是零费率指数基金

此时基金回报 ≈ 投资者回报，裂口消失。

## 与其他概念的关联

- [[战胜率]]：行为损耗是战胜率为零或负的重要原因之一
- [[隐性成本-交易费占比]]：交易费占主动基金总费用 30% 是行为损耗的量化体现
- [[短视性损失厌恶]]：导致投资者在市场下跌时恐慌性赎回，放大行为损耗
- [[嫉妒-追高心理陷阱]]：导致投资者在市场上涨时追入，放大行为损耗
