# 全球化资产配置（香港互认渠道）

## 定义

通过香港互认基金实现全球化资产配置，是指内地投资者利用香港互认机制，购买以港币计价、投资于海外市场的公募基金，从而分散单一市场风险的投资方式。

## 核心逻辑

```
香港互认基金 = 投资海外市场 → 全球化配置 → 分散单一市场风险
```

## 与 [[qdii-出海组合构建框架]] 的关系

[[qdii-出海组合构建框架]] 偏重 QDII 通道，而本概念聚焦香港互认渠道。两者互为补充，共同构成内地投资者配置海外资产的两大制度通道。

## 与 [[跨境理财通]] 的对比

| 维度 | 香港互认基金 | 跨境理财通 |
|------|------------|-----------|
| 投资范围 | 香港注册的公募基金（可投资全球） | 粤港澳跨境银行理财 |
| 额度限制 | 客地销售比例限制 | 个人额度上限 |
| 计价货币 | 港币为主 | 人民币/港币 |
| 主要优势 | 产品线丰富，投研能力较强 | 人民币计价，汇率风险较低 |

## 风险要点

- **汇率风险**：港币计价资产受港元/人民币波动影响；若人民币贬值，港币资产可能增值
- **海外市场风险**：海外市场波动可能大于 A 股市场
- **费率差异**：香港互认基金费率可能高于内地同类基金
- **信息不对称**：投资者对海外市场了解有限，可能增加决策风险

## 配置建议

- 根据风险偏好适当配置，不要过度集中于单一市场
- 全球化配置能分散风险，但需注意汇率和市场双重风险
- 如果投资者不了解海外市场，建议通过专业管理人间接配置
