# 减法哲学

在投资的输家游戏中，胜利不来自"做了什么"，而来自"没做什么"。

## 核心命题

投资本质上是一场减法游戏：

```
加法思维：做更多决策 → 更多机会 → 更好回报
减法思维：做更少错误 → 更少成本 → 更多留存
```

在高度有效市场中，后者远优于前者。

## 四个层次

| 层次 | 内容 | 含义 |
|------|------|------|
| **行为层** | 低换手、低交易、低关注 | 技术执行层面 |
| **经济层** | 低费用、低摩擦 | 成本保护层面 |
| **心理层** | 情绪绝缘体，不受涨跌影响 | 行为风险管理层面 |
| **存在层** | 选择无聊是对即时反馈文化的反叛 | 哲学层面 |

## 与"无聊"的关系

无聊是减法哲学的情绪形态——它不是"不知道做什么"，而是"知道不该做什么，并坚持不做"。**能无聊者，方能富有**。

→ [[concepts/无聊的投资]]

## 与"输家游戏"的关系

"投资是输家的游戏"（[[concepts/投资是输家的游戏]]）是减法哲学的经济学表达：赢家不靠打出更多好球，而靠对手失误丢分。投资者唯一可控变量是减少自己的犯错。
