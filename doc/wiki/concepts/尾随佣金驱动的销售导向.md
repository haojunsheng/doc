# 尾随佣金驱动的销售导向

销售渠道（银行、券商、第三方平台）从基金公司获得的尾随佣金（trailing fee）激励机制，导致其推荐行为以"销售规模最大化"为导向，而非以"投资者利益最大化"为导向。这是"基金赚钱基民不赚钱"现象的制度性根源。

## 核心机制

```
尾佣机制（按规模收取持续性费用）
→ 渠道激励：卖得越多越好，而非卖得越久越好
→ 新基金认购费远高于申购费 → 渠道优先推新基金
→ 热门基金更容易销售 → 渠道跟随市场热度
→ "卖热不卖好" → 投资者在高点买入
```

## 三方利益结构

| 参与方 | 利益诉求 | 与投资者的关系 |
|-------|---------|--------------|
| 基金公司 | 规模增长 → 管理费收入增加 | 短期规模导向，长期声誉受损 |
| 销售渠道 | 尾佣收入最大化 | 销售导向，非投资者需求导向 |
| 基民 | 获得合理回报 | 被"卖热"机制推向高位 |

## 销售扭曲的延伸行为

除"卖热不卖好"外，尾佣机制还导致销售机构有动机**鼓励客户频繁买卖**：
- 每次申赎都产生手续费收入
- 频繁交易意味着持续收取尾佣
- 形成"销售机构赚钱、基民亏钱"的恶性循环

详见 [[基金费率三环节]] 中的赎回费结构和 [[QA — 基金费率结构与降费真相]] 的 Q5 分析。

## 与相关概念的区分

- **[[规模导向与回报导向]]**：更宏观，讨论基金公司的整体战略取向；本文侧重销售渠道的佣金激励结构
- **[[认购费与申购费差异]]**：是尾随佣金驱动销售导向的具体费率体现之一
- **[[基金赚钱基民不赚钱]]**：是尾随佣金驱动销售导向的系统性后果
- **[[尾随佣金]]**：尾随佣金是制度机制，本文侧重其导致的销售行为扭曲后果
- **[[软美元机制]]**：与尾佣机制并列的另一个利益扭曲机制，前者在交易端，后者在销售端

## 边界条件

- 在成熟市场（如美国），基金销售更多以买方顾问模式为主，尾佣激励较弱
- 费率改革（[[基金费率新规影响]]）正在推动从规模导向向回报导向转型
- 投顾份额（[[投顾份额]]）的设计旨在缓解这一利益冲突
- 头部销售机构开始重视投资者教育，但行业整体转型需要时间
