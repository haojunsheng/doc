# 规模逆势攀升悖论

收益率下降但规模上升的现象，反映投资者参照系从绝对收益切换为相对收益的过程。

## 定义

规模逆势攀升悖论指：当某类资产的收益率持续下降时，其资金规模反而逆势增长，表面矛盾实则源于投资者参照系的切换。

## 货基案例

| 指标 | 数值 | 变化趋势 |
|------|------|---------|
| 7日年化（余额宝） | <1% | 持续下行 |
| 全市场货基中位数 | 1.1% | 持续下行 |
| 全市场货基规模 | 15.58万亿 | 逆势攀升 |

## 悖论解构

```
表面矛盾：收益↓ → 规模↑
真实逻辑：参照系切换 → 相对优势仍存 → 规模↑
```

### 参照系切换过程

1. **旧参照系**：自身历史峰值（4-6%）
   - 当前1.1%显得"很差"
   - 投资者心理预期受损

2. **新参照系**：替代资产（活期存款0.2%、一年定期<1%）
   - 当前1.1%相对优势仍达5倍
   - 加上"随时可取"的流动性溢价
   - 资金持续流入

### 形式化表达

```
规模变化 = f(相对收益优势, 流动性溢价, 场景绑定深度)

当：相对收益优势 = 货基收益 - 替代资产收益 > 阈值
且：场景绑定深度 > 阈值
则：规模↑（即使绝对收益率↓）
```

## 与"货基功能重构"的关系

规模逆势攀升是功能重构的**结果信号**，而非原因：
- 功能重构（从赚钱到管钱）是投资者行为变化的本质
- 规模逆势攀升是该变化在数据层面的体现
- 两者互为表里

## 边界条件

- 若替代资产收益大幅上调（加息周期），参照系可能回跳，规模增长逆转
- 若场景绑定被削弱（如支付生态解耦），悖论可能消失
- 若出现"绝对收益锚定"心理（坚持只买历史高收益产品），悖论可能不会发生
