# 投资是性格测试

> 投资不是智力竞赛，是性格测试。最终决定你回报的不是你知道多少，而是你能控制住自己多少。

## 核心公式

**投资回报 = 知识 × 性格**

- 知识可以学（可以通过阅读、课程获得）
- 性格很难改（长期形成的行为倾向，如过度自信、损失厌恶）
- 性格是最终瓶颈

## 与「投资人格」的关系

「投资人格」（MBTI式分类）强调「用性格匹配策略」——适配论。

本文强调「先控制情绪再谈策略」——修炼论。

两者并非矛盾，但角度不同：先修炼（控制恐慌与贪婪），再适配（找到与自己性格相符的策略），顺序上修炼优先。

## 支撑论点（来自 30年投资教训）

| 教训 | 机制 | 关键词 |
|------|------|--------|
| Q1 | 高智商 → 过度自信 → 过度交易 → 低回报 | 自信偏差 |
| Q2 | 「什么都不做」最难，但往往最优 | 执行纪律 |
| Q3 | 损失厌恶驱动恐慌卖出 | 行为代价 |
| Q4 | 复利依赖时间，耐心是核心品质 | 时间维度 |
| Q5 | 简单策略更易坚持，执行率决定回报 | 简单可坚持原则 |
| Q6 | 承认无知 → 分散化 → 减少灾难性错误 | 市场预测的不可靠性 |
| Q7 | 长期投资难在信念，而非时长 | 信念 |
| Q8 | 知识 × 性格 = 回报 | 收口 |

## 适用范围

适用于长期投资者（普通人为主体）。专业交易者策略不依赖长期持有，性格影响相对较小；但对大多数普通人，性格是决定性因素。

## 关键边界

- 把聪明用在「设计好系统」（资产配置、再平衡）而非「预测市场」上，聪明有用
- 「什么都不做」的前提是买入正确标的
- 基本面恶化时卖出是理性决策，不是缺乏耐心
