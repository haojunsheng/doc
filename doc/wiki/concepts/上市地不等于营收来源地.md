# 上市地不等于营收来源地

## 核心观点

上市地主要决定监管和融资环境，不决定公司的基本面风险和营收来源。判断一只基金或股票是否真正分散了地域风险，关键看其底层资产的营收来自哪里，而非在哪里上市。

## 形式化表达

```
上市地 ≠ 公司属性
营收来源 → 决定主要风险敞口 → 决定分散效果
```

## 典型案例

**瑞幸咖啡**：美股上市，但营收几乎全部来自中国，与美国经济基本脱钩。持有一只好似"美国资产"的瑞幸，实际上持有的是中国消费风险。

**恒生指数**：60% 以上上市公司为中国企业，港股 ≠ 海外资产，无法有效对冲 A 股的地域风险。

**中概股基金**：中证海外中国互联网指数与沪深 300 相关系数达 0.71，与标普 500 相关性反而更低。

## 投资含义

全球配置的目标是分散地域风险，因此应关注：

- 底层资产的营收来源地分布
- 与现有持仓的相关性，而非上市地
- 穿透持仓后的真实国家/地区敞口

仅凭基金名称中的"QDII"或上市地判断分散效果，是常见误区。
