# 下滑曲线设计类型：到点型与穿点型

目标日期基金的下滑曲线有两种基本设计类型，区别在于退休后是否继续降仓。

## 到点型（Point-to-Point）

- 权益仓位随时间下降，到达目标退休日期时停止调整，锁定配置不动
- 假设退休时一次性提取所有资金，之后以固收为主
- 退休时权益仓位相对较低
- 适合退休后对流动性需求较大的投资者

## 穿点型（Through-the-Retirement）

- 权益仓位在退休前已开始下降，但退休后继续降仓
- 假设退休后仍需持续投资，应对长寿风险
- 穿点型在退休时权益仓位反而更高（因为后续还要继续降）
- 适合寿命较长、退休后资金需持续增值的投资者

## 形式化表达

```
到点型：权益↓ → 退休时停 ⊥ 穿点型：权益↓ → 退休后继续↓ → 稳定
```

## 与国内监管的关系

国内养老目标基金权益仓位受监管上限约束（最高 80%），导致初始权益仓位远低于美国（90%+）。这一监管约束使国内下滑曲线整体偏保守，牺牲了长期收益潜力。

## 与 [[核心卫星策略FOF应用]] 的关系

下滑曲线确定战略配置基准，基金经理在基准基础上做 ±10% 的战术浮动，通过核心+卫星策略实现超配或低配。
