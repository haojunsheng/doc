# 组合压力测试

用历史极端行情模拟组合最大回撤，检验其"存活能力"。

## 形式化表达

```
压力测试 = 把组合丢进历史最惨的年份 → 看最大回撤 → 问自己「我能扛住吗？」
```

## 操作示例

1. **2008 年测试**：假设组合跌 35%，你当时会恐慌卖出吗？
2. **如果会**：说明配置太激进，需增加债券或加入抗跌资产（公用事业、必需消费品）
3. **调整后**：再跑一次压力测试，直到"最惨情况能睡着"

## 设计目标

目标不是「不亏钱」，而是「在最惨的情况下你还能睡着」——承受力 > 收益率。

## 边界条件

- **历史不会简单重复**：2008 年的跌幅不代表未来最大风险，压力测试是参考而非保证
- **时间稀释短期回撤**：10 年以上投资期限可稀释短期波动影响
- **与行为偏差互动**：压力测试不仅是数学计算，更是心理承受力评估
