# 信用下沉

信用下沉是指通过投资更低评级（但相应收益率更高）的信用债，以获取更高的信用利差收益。它是[[固收+]]策略债券端的核心工具之一。

## 定义

```
信用下沉 = 主动降低持仓债券的信用评级 → 获取更高的信用利差
```

信用利差是信用债收益率与同期限国债收益率的差额，反映市场对信用风险的定价。参见[[concepts/信用债利差]]。

## 形式化表达

```
债券投资收益 = 基准利率收益 + 信用利差
信用下沉策略 = 基准利率收益（久期操作） + 扩大信用利差（下沉评级） → 总收益↑
```

与[[久期操作]]的关系：久期管理应对利率方向风险，信用下沉挖掘信用定价偏差，两者构成债券投资的两个独立维度。

## 收益来源

| 来源 | 说明 | 可控性 |
|------|------|--------|
| 基准利率收益 | 持有至到期获得的票息 | 较高 |
| 信用利差收益 | 买入时信用利差 > 卖出时信用利差 | 中等 |
| 信用利差溢价 | 承担更高风险获得的补偿 | 不确定 |

## 风险与边界

**核心风险**：信用下沉追求更高收益的同时，增加了违约风险。若信用风险上升，低评级债券可能违约，造成实质性损失。

**边界条件**：
- 经济下行期，信用下沉策略的违约风险显著上升
- 2022年[[股债双杀]]期间，信用债市场同步承压，信用下沉的"安全垫"效果减弱
- 信用下沉与[[回撤控制机制]]目标之间存在天然张力——下沉越深，潜在损失越大

## 与"固收+"策略的关系

在[[固收+]]框架中，信用下沉是债券端的"增强"手段，目的是在债券底仓中获取更多收益，为整体组合提供更高的票息覆盖率。与[[concepts/中等波动固收+]]中"高等级债券"的建议不同，信用下沉策略需要更强的信用研究能力和风险承受能力。
