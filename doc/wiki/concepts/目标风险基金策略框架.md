# 目标风险基金策略框架

目标风险基金的真正差异化维度是**投研团队的决策机制**，而非简单的权益仓位。投资者选择产品时应关注策略差异，而非仅看风险等级标签。

## 决策机制三类型

```
纯量化驱动 ⊥ 量化+定性双驱动 ⊥ 风格偏离+优选
```

### 1. 纯量化驱动（交银安享稳健模式）

- 用过去一段时间（如一年）波动率确定配置权重
- 选基只看历史业绩和持仓数据
- 优点：客观、可复现
- 缺点：滞后性强，市场剧变时反应慢
- 适用：市场相对稳定、趋势明确的环境

### 2. 量化+定性双驱动（富国鑫旺稳健模式）

- 建立多因子库（400+因子）进行定量筛选
- 补充人工尽调，了解基金投研团队、投资文化、流程
- 优点：前瞻性更强，能发现量化指标无法捕捉的信号
- 缺点：依赖团队经验，主观性较强
- 适用：市场环境复杂、需要深度判断的场景

### 3. 风格偏离+优选（兴全安泰积极模式）

- 设定权益中枢（如70%），允许±5-10%战术偏离
- 月度打分决定偏离方向
- 控制跟踪误差（<6%）
- 优点：在保证基准跟踪的同时争取超额收益
- 缺点：偏离判断失误可能导致显著跑输（如2021年成长股误判）

## 策略差异的影响因素

| 因素 | 影响 |
|------|------|
| 团队经验 | 平均司龄决定定性判断能力 |
| 内部基金依赖度 | 双重收费豁免驱动内部偏好，但可能拖累收益 |
| 子基金数量 | 覆盖范围决定机会集大小 |
| 跟踪误差约束 | 约束战术偏离空间 |

## 保守混合型占主导的原因

保守混合型（权益≤30%）占养老目标基金规模约55%，因临近退休和低风险偏好人群基数最大。但过度保守可能限制长期财富积累，尤其对寿命较长的退休后阶段。

## 与目标日期基金的关系

目标风险基金与目标日期基金互补：
- 目标日期：自动调仓，适合不愿主动管理的投资者
- 目标风险：恒定风险水平，适合有判断能力的投资者自行切换
