# 央行去美元化

**央行去美元化**指各国央行持续增持黄金、降低美元储备占比的趋势，是本轮黄金牛市的核心驱动力之一。其底层逻辑是对美元信用长期侵蚀的对冲，与中国推动人民币国际化等战略目标相呼应。

## 核心机制

```
地缘政治风险↑ + 美国财政赤字↑ → 央行担忧美元资产风险 → 增持黄金、减持美元
```

中国央行是典型代表：2022-2025年分别增持62.21 / 224.88 / 44.17 / 12.75吨，合计444吨。充足黄金储备增强本国货币国际信用，是人民币国际化的重要支撑。

## 与[[concepts/黄金四轮驱动框架]]的关系

央行去美元化对应四轮驱动中的第三轮（去美元化+央行增持）。这是本轮金价突破3600美元的最强结构性推力，与宏观避险需求（第二轮推力的延续）共同构成双引擎。

## 与[[concepts/黄金货币信用侵蚀镜像]]的关系

央行去美元化是货币信用侵蚀的**主动对冲行为**：各国央行预见到美元信用的缓慢侵蚀，主动增加黄金储备以降低风险敞口。这本身就是货币信用侵蚀镜像的体现。

## 边界条件

- 若美元信用恢复（美国财政纪律改善），去美元化进程可能放缓
- 若人民币国际化超预期进展，黄金需求的边际增速可能下降
- 新兴市场央行购金能力受美元流动性制约——美元走强时购金成本上升

## 配置启示

央行持续购金为金价提供了结构性底部支撑，但这不意味着金价只涨不跌——仍需关注[[concepts/金价均值回归框架]]警示的估值风险。
