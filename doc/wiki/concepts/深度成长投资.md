# 深度成长投资

深度成长是一种注重企业长期竞争力和管理层质量的投资风格，属于内生增长型策略的典型实践。

## 形式化定义

```
深度成长 = 长期竞争力 × 管理层质量 × 时间复利
```

## 核心特征

1. **长期视角**：关注企业 5-10 年甚至更长的竞争优势持续性，而非短期业绩爆发
2. **管理层导向**：将管理层质量视为核心评估维度，包括战略眼光、执行能力、诚信记录
3. **护城河识别**：寻找具有可持续竞争优势（品牌、技术、网络效应等）的企业
4. **合理估值**：在合理价格买入优质企业，避免为增长支付过高溢价

## 与外延增长的区别

| 维度 | 深度成长（内生） | 外延增长 |
|------|-----------------|---------|
| 增长来源 | 企业自身盈利 | 并购/重组 |
| 基金经理作用 | 识别好公司+好管理层 | 识别并购机会+整合能力 |
| 业绩持续性 | 更稳定 | 受并购周期影响大 |
| 风险类型 | 判断风险（看错公司） | 执行风险（并购失败） |
| 适用环境 | 平稳期 | 并购活跃期 |

## 代表实践

[[景顺长城成长之星]] 是深度成长投资的典型代表，由周寒颖管理，采用中观行业配置策略，自上而下选择行业，自下而上精选个股，注重企业管理层质量和长期竞争力。

## 适用边界

- **优势环境**：经济稳定增长期、产业升级期、优质企业盈利持续释放期
- **劣势环境**：并购活跃期（资金可能被外延增长基金捕获更多收益）
- **核心风险**：对管理层和企业长期竞争力的判断失误
