# 货基费率侵蚀效应

低利率环境下，货基固定费率从"零头"变为"命脉"的非对称侵蚀效应，以及由此产生的费率刚性现象。

## 定义

**货基费率侵蚀效应**指：当货基费前收益被利率环境压缩至低位时，固定费率在总收益中的占比急剧上升，从可忽略的"零头"变为决定实际到手收益的关键变量。

核心量化公式：
```
费率侵蚀率 = 费率 / 费前收益
```
当费前收益从3%降至1.5%时，0.5%费率从16.7%升至33%——侵蚀率翻倍。

## 核心特征

### 1. 费率占收益比重急剧上升

| 费前收益 | 费率(0.5%) | 费率占比 | 费后收益 |
|---------|-----------|---------|---------|
| 3.0% | 0.5% | 16.7% | 2.5% |
| 2.0% | 0.5% | 25.0% | 1.5% |
| 1.5% | 0.5% | 33.3% | 1.0% |
| 1.0% | 0.5% | 50.0% | 0.5% |

### 2. 费率刚性

货基费率近三年仅下降9bp（0.58%→0.49%），远低于主动股基的69bp降幅，原因有三：
- 费率已处绝对低位，下调空间有限
- 投资者不敏感导致无竞争压力
- 大规模货基受流动性监管约束，收益弹性有限

### 3. 0.1%差异的巨大影响

```
10万本金 × (1.5% - 0.5%) × 10年复利
= 原本1.6万回报只剩1万
= 5500元被费率损耗 → 36%的潜在收益被吃掉
```

## 与规模的关系

**规模=定价权**：头部货基规模越大，费率反而越高（部分>0.6%），甚至高于某些纯债基金。这与常见的"规模经济→费率下降"逻辑相反。

原因：
- 大规模产品流动性更好，投资者不在乎费率
- 流动性监管约束限制收益弹性，基金公司无需靠低费率竞争
- 场景绑定（如支付宝、微信）使资金被动沉淀，无价格敏感度

## 边界条件

- **利率回升**：若费前收益升至2.5%+，费率侵蚀率下降，该效应减弱
- **替代产品竞争**：若银行现金管理理财或短债基金以更低费率+相近收益形成替代，头部货基可能被迫降费
- **监管干预**：若监管强制要求头部货基降费，僵局可能被打破
- **短期持有**：若持有期很短（几天到几周），费率差异的绝对影响可忽略
