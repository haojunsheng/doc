# 费率生存负相关框架

晨星2019-2024五年实证研究表明：**费率与基金生存能力、跑赢同类概率呈显著负相关**。按费率分五档后，低费率档在各类产品中的存活率与胜率普遍显著高于高费率档，且该效应在固收类产品中最为强烈。

## 核心命题

> 低费率是基金存活和跑赢同类的起跑优势；业绩优秀的产品即使起跑费率高，也能通过规模效应实现费后逆袭。

## 机制分解

### 1. 费率侵蚀路径
- 高费率直接压缩费后净收益
- 高费率产品需在费前获得足够超额收益才能跑赢低费率竞品
- 超额收益的不确定性使高费率产品处于竞争劣势

### 2. 固收类费率敏感放大器
保守混合、积极债券、纯债三类产品的费率-生存负相关最显著，原因在于：
- 债券为核心资产的产品超额收益空间有限
- 费率对费后净收益的影响更直接、更可感知
- 偏股型产品基金经理可通过超额收益弥补高费率，固收类则难以做到

### 3. 小规模量化淘汰机制
积极配置-大盘平衡类中，高费率档近40%为千万级规模量化产品，其被淘汰路径为：
- 规模小无法摊薄固定成本
- 高度分散策略在领涨股行情中持股占比偏低
- 收益不突出 + 费率高双重打击

**数据例证**：大盘平衡类低费率档胜率35.1%，高费率档仅10.8%，差距超三倍。

## 边界条件（反常识发现）

### 被动成长产品陷阱
成长风格低费率档胜率不升反降，原因：
- 被动产品追踪创业板/创业50，两指数50%权重集中在电力设备和医药生物
- 2022年后成长板块大幅回调，被动产品因行业高度集中而无法分散风险
- 高费率主动产品行业配置更均衡（两行业合计约40%），反而有所缓冲

**结论**：低费率不是充分条件——行业集中度高、规模过大同样可以抵消费率优势。

### 费率逆袭良性循环
业绩优秀的高费率产品可通过以下路径实现费后逆袭：
```
高费率产品 → 回报亮眼 → 资金流入 → 规模扩大 → 费率下降 → 净收益提升
```
期末费率与跑赢同类比例呈负相关，说明业绩好的产品即使起跑费率高，也能在过程中降费。

## 选基应用

| 优先级 | 关注点 | 说明 |
|-------|-------|------|
| 首要 | 费率档位 | 固收类产品费率敏感度最高，优先选择低费率档 |
| 次要 | 产品规模 | 千万级规模产品风险更高，尤其是量化策略 |
| 补充 | 行业分散度 | 被动成长产品需警惕行业集中度风险 |
| 动态 | 规模变化趋势 | 高费率但有持续资金流入的产品可能进入良性循环 |
