# 中小盘主动战胜率波动

## 核心现象

2022年晨星中国主动被动晴雨表数据显示，中小盘主动战胜率出现断崖式下跌：

| 年份 | 中小盘主动战胜率 | 大盘成长 | 大盘平衡 |
|------|------------------|----------|----------|
| 2021 | 73% | - | - |
| 2022 | **43%** | 66% | 63% |

## 原因分析

**2022年双重冲击**：
1. **中小盘风格剧烈切换** — 市场风格从中小盘快速轮动到其它风格
2. **市场环境严峻** — 经济下行压力加大，中小盘企业抗风险能力较弱

**主动经理应对逆风能力弱**：
- 中小盘股票流动性差、研究覆盖少，信息获取成本高
- 风格快速轮动时，主动调仓反而增加交易成本和时机风险
- 大盘股（成长/平衡）因研究覆盖充分、流动性好，主动经理更容易获取超额

## 形式化表达

```
中小盘主动: 73% → 43% → 风格轮动↑ + 环境严峻 → 主动失效
```

## 与[[均值回归陷阱]]的关联

从73%暴跌至43%，这一变化是否符合均值回归？需要后续年份数据验证：
- 若2023年回升至50%以上，说明2022年是极端逆风年的临时冲击
- 若持续低迷，则反映中小盘主动策略的结构性困境

## 边界条件

- 若中小盘风格回归稳定，中小盘主动战胜率可能回升
- 需2023-2025年数据验证趋势是持续恶化还是已企稳回升
