# 消融实验 1-1

## 定义

《AI Agent 实战》第一章中的核心实验，证明 Agent 公式三项（LLM、上下文、工具）缺一不可，且 Harness 是拉开生产差距的关键杠杆。

## 实验设计

**基准配置：**
- 模型：Kimi K3（或其他基准模型）
- 配置：完整 Agent 系统（LLM + 上下文 + 工具 + Harness）
- 任务：Terminal Bench 测试集

**消融组：**
1. 去掉上下文 → 测量性能下降
2. 去掉工具结果 → 测量性能下降
3. 去掉系统提示词 → 测量性能下降

## 实验结果

### 结果 1：三项缺一不可

| 消融项 | 性能变化 | 结论 |
|--------|---------|------|
| 去掉上下文 | 显著退化 | 上下文是必要组件 |
| 去掉工具结果 | 显著退化 | 工具结果是必要组件 |
| 去掉系统提示词 | 显著退化 | 系统提示词是必要组件 |

**核心结论：** Agent = LLM + 上下文 + 工具，三者缺一不可。

### 结果 2：Harness 是拉开差距的杠杆

| 对比项 | 准确率 | 说明 |
|--------|--------|------|
| 初始配置 | 52.8% | 基础 Agent |
| 换 Harness | 66.5% | 同模型，只优化 Harness |
| 提升幅度 | +13.7% | **无模型升级下的显著提升** |

**对比实验：**
- OpenAI 工程团队 10 倍效率提升 ≠ 模型升级
- 说明 Harness 工程比模型升级更有效

## 证据强度

- **直接因果证据**：消融实验证明了三项的必要性
- **相关证据**：LangChain Terminal Bench 数据支持 Harness 的有效性
- **局限**：未提供实验细节（数据集大小、任务类型、评估标准）

## 实践含义

1. **不要跳过任何一项**：LLM、上下文、工具三者缺一不可
2. **Harness 是高效杠杆**：在公式完善后，优化 Harness 比升级模型更有效
3. **评估先行**：任何优化前必须建立评估基线
4. **模型不是答案**：换模型不一定能解决问题，先检查 Harness
