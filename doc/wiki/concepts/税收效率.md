# 税收效率

税收效率是指指数基金的分红和资本利得分配频率对税后回报的影响。在应税账户中，税收效率低的指数基金可能不如主动基金。

## 形式化

```
税后回报 = 税前回报 - 税收成本
税收成本 = 分红税 + 资本利得分配税
```

## 核心洞察

- 指数基金通常被认为税收效率高——因为换手率低，不经常实现资本利得
- 但小盘股指数等换手频繁的基金，每年产生大量资本利得分配
- 即使你没卖出基金，也要为分配的资本利得交税

## 账户类型的差异

| 账户类型 | 税收效率的重要性 |
|---------|--------------|
| 应税账户 | 非常重要——税收效率可能比费用率更重要 |
| 免税账户（IRA/401k） | 不重要——税收不是问题 |

## ⚠️ 中国市场的适用性限制

本文的核心分析基于美国税制（IRA、401k 等免税账户）。

对中国 A 股个人投资者：

- 目前股票交易所得暂免征收个人所得税
- 基金分红 tax treatment 取决于基金类型和持有期限
- **税收效率维度在中国基本不适用**——这是一个重要的本地化差异

## 与美国市场的对比

| 维度 | 美国 | 中国 |
|------|------|------|
| 资本利得税 | 有（长期/短期税率不同） | 暂免 |
| 分红税 | 有 | 视情况而定 |
| 免税账户 | IRA、401k 普遍 | 年金/个人养老金试点中 |
| 税收效率重要性 | 高 | 低（当前） |

## 与费用框架的关系

税收效率应纳入 [[concepts/费用是复利的反面]] 扩展后的"真实成本框架"：

```
真实成本 = 费用率 + 跟踪误差隐含成本 + 税收成本
```

在中国当前税制下，税收成本 ≈ 0，真实成本 ≈ 费用率 + 跟踪误差隐含成本。
