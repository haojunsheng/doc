# 清洁份额

清洁份额（Clean Share）是指**不含尾随佣金和申购费**的基金份额类型，投资者只需支付基金管理费和运营费。清洁份额是海外成熟市场的主流形态，其普及是监管强制推动的结果。

## 定义

```
清洁份额 = 管理费 + 运营费
（无申购费、无尾佣、无其他利益关联费用）
```

## 制度起源

清洁份额并非市场自发演化的产物，而是监管强制的结果：

- **英国RDR（Retail Distribution Review，2013）**：禁止基金公司向投顾支付尾佣，清洁份额由此诞生
- **美国《受托人规则》（Fiduciary Rule，2017）**：要求投顾不能因自身可获得尾佣高低而推荐基金，进一步推动清洁份额普及

## 三类份额透明度梯度

清洁份额是"非捆绑式份额"的具体形态，在三类份额中透明度最高：

| 类型 | 费用构成 | 利益冲突程度 | 透明度 |
|------|---------|-------------|--------|
| 非捆绑式（清洁份额） | 管理费 + 运营费 | 最小 | 最高 |
| 半捆绑式 | 管理费 + 运营费 + 其他费用（过户代理服务费、平台使用费等） | 中等 | 中等 |
| 捆绑式 | 管理费 + 运营费 + 申购费 + 尾佣 + 其他费用 | 最大 | 最低 |

## 与中国投顾份额的关系

中国语境下的"投顾份额"是清洁份额理念的制度落地——通过监管规定投顾渠道不得收取客户维护费，使投顾份额在本质上成为清洁份额的中国形态。两者在机制逻辑上完全同构。

## 市场趋势

非捆绑式和半捆绑式份额持续获得资金流入，捆绑式份额持续净流出。这一趋势由投资者认知提升、监管推动、费率透明化三重力量驱动。

## 边界条件

- 清洁份额通常只能通过投顾渠道购买，普通直销渠道难以触及
- 若监管执行不到位，尾佣可能以其他名目存在
- 海外数据不可直接外推至中国市场，需本土化验证
