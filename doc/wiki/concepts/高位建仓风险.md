# 高位建仓风险

## 定义

新基金在发行高峰期募集资金后，因3-6个月的建仓期被迫在市场高位逐步买入，建仓完成时市场往往已开始调整，导致净值从起步就处于不利位置。

## 核心机制

```
发行高峰（市场顶部）→ 建仓期（3-6个月）→ 市场开始调整
→ 建仓完成时持仓成本偏高 → 净值难以回本
```

### 关键特征

1. **时间错配**：建仓期覆盖市场由热转冷的过渡阶段
2. **被动锁定期**：建仓期内投资者无法赎回，只能眼睁睁看着净值下跌
3. **仓位不足**：基金经理不可能短时间满仓，导致错过反弹或无法及时止损

### 实证：2020年案例

- 2020年7月发行的基金，建仓期覆盖7-12月，正好是A股调整期
- 5只爆款基金三年平均跌幅40-50%
- 规模缩水68-86%，说明投资者在底部割肉离场

## 双面性：建仓期的条件依赖

| 市场环境 | 建仓期影响 |
|---------|-----------|
| 市场持续上涨 | 优势：平滑成本，逐步建仓降低均价 |
| 市场先涨后跌（顶部发行） | 劣势：高位建仓，净值难以回本 |
| 市场持续下跌 | 优势：逐步建仓锁定更低成本 |

**关键判断**：建仓期本身是中性的，决定盈亏的是建仓期所处的市场位置。

## 与持有期基金的区分

[[持有期与流动性权衡]]关注的是产品设计中投资者主动锁定期限的流动性代价；[[高位建仓风险]]关注的是新基金建仓期带来的被动持仓风险，两者机制不同，但在"锁定期内无法止损"这一点上有交集。

## 投资建议

- 避免在市场情绪高涨、新基金密集发行时认购新基金
- 若看好某只基金，可优先考虑已建仓的老基金，灵活性更高
- 若坚持买新基金，择时比选基更重要：建仓期处于市场底部时反而是优势
