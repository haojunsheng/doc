# 高收益债违约风险

## 定义

高收益债（又称垃圾债）因发行人信用资质较差而提供高利息，但伴随较高的违约概率和较低的违约回收率。与高息股相比，高收益债的本金风险更高——高息股的股息可以被砍但股票不归零，而高收益债违约后本金可能大幅缩水。

## 核心数据

| 指标 | 数值 | 说明 |
|------|------|------|
| 衰退期违约率 | 5-10% | 经济衰退期间高收益债的年化违约率 |
| 违约回收率 | 40-50% | 违约后平均能收回的本金比例 |
| 正常期表现 | 较好 | 经济复苏期违约风险下降，债券价格上升 |

## 高收益债 vs 高息股对比

```
高收益债 = 高利息 + 高违约风险（本金可能损失 50-60%）
高息股   = 中等利息 + 低违约风险（股息可砍，股票不归零）
```

关键区别在于**本金保护的底线**：股票最低归零（极端情况），但债券违约后即使回收率 40-50%，也意味着超过一半本金可能永久损失。

## 边界条件

- **衰退期**：高收益债特别危险，违约率上升而回收率不确定性增加
- **复苏期**：违约风险下降，高收益债表现良好，但此时追逐收益率的动力本身已减弱（利率回升）
