# 费率复利侵蚀

## 核心论点

管理费不是单次收费，而是每年从本金中抽取的"复利漏损"。费率差异经多年复利放大，对终值的影响远超直觉。

## 形式化公式

```
终值 = 本金 × (1 + 年化收益 − 费率)^年数
```

费率差 Δfee 在 N 年后的终值差异：

```
终值差异比例 ≈ [(1 + r − fee_high)^N − (1 + r − fee_low)^N] / (1 + r − fee_high)^N
```

## 数值示例

假设年化收益 8%，缴费 30 年：

| 费率对比 | 30 年终值差异 | 累计收益侵蚀 |
|---------|------------|------------|
| 1% vs 0.15%（差 0.85%） | 约 26% | 吃掉近 1/4 累计收益 |
| 0.5% vs 0.15%（差 0.35%） | 约 10% | 侵蚀可观 |
| 0.5% vs 0%（差 0.5%） | 约 12.5% | 每 20 年侵蚀约 8% |

## 与"频繁交易成本"的区别

[[频繁交易成本复利侵蚀]] 讨论的是买卖价差、冲击成本等一次性交易摩擦的复利放大；本概念讨论的是**持有期持续抽取**的管理费损耗。两者叠加，实际成本远超单一维度。

## 与[[复利阶段切换]]的关系

前半段（储蓄主导期），费率差影响的是本金积累速度；后半段（投资主导期），费率差影响的是复利增长基数，绝对损失更大。

## 在个人养老金场景中的应用

个人养老金 Y 份额管理费约为普通份额一半（约省 0.5%/年），这是"持有期降费"段的量化来源——[[个人养老金税收套利]]中讨论的三段式收益结构，第二段即由此而来。

## 边界条件

- **高费率≠低质量**：如果高费率基金能持续跑赢指数 2% 以上（扣除费后），高费率也合理——但长期能持续的主动基金极少
- **费率差异需扣除后再比**：看超额收益时要用扣费后的净收益，而非毛收益
- **中国本土数据缺口**：国内指数基金费率仍在下降趋势中，0.15% 可能不是底线

## 行动启示

1. 选指数基金优先选低费率品种（0.15%-0.5% 区间内差异显著）
2. 警惕"包装成指数的主动基金"——名义叫指数但费率 1%+
3. 长期持有比频繁交易更能体现费率优势
