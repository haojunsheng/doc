# 自信偏差

金融从业者中普遍存在的认知偏差：自信程度与预测准确率脱钩，自信本身成为职业成功的预测因子而非能力。

## 核心观察

**自信的金融从业者在行业中更成功，即使预测不准。**

这不是能力问题，而是结构性需求：客户需要听到确定性答案，自信的表达比准确的犹豫更受欢迎。

## 机制

```
客户要确定性 → 自信表达更受欢迎 → 自信者获得更多话语权 → 获得更多客户 → 职业成功
                                    ↑
                        与真实预测准确率无关
```

这是一种**激励错配**：行业奖励的是"看起来知道"的姿态，而非"真正知道"的能力。

## 与投资行为的关系

- 解释为何错误预测者能在行业中长期存活甚至成名
- 与 [[concepts/净值恐高症]] 形成因果链：客户因净值恐高而寻求确定性，催生了自信偏差的供给
- 与 [[concepts/反身性]] 呼应：自信本身就是一种改变系统的力量

## 应对

- 识别"看起来很确定"的信号与真实分析能力的区别
- 将注意力从"谁在说"转向"说了什么、是否有退出信号"
- 参考 [[concepts/核心假设-退出信号框架]]：用可检验的假设替代听信权威
