# 抢跑

抢跑（Front-running of Index Rebalance）是指指数基金在成分股调整前提前买入新成分股、提前卖出即将被剔除的股票，从而在调仓后短期内"跑赢"指数的行为。

## 机制

```
指数调整日：T
基金提前买入：T - N 天
结果：基金在指数正式调仓前已建仓，调仓日买入价更高（被推高），但基金已享受了期间的涨幅
```

看起来像"能力"，实际是**利用调仓公告的信息优势**进行的短期套利。

## 为什么重要

1. **误导性信号**：让指数基金看起来有超额收益，强化"选基金比选指数强"的错误认知
2. **不可持续**：抢跑窗口在调仓公告后快速缩小，竞争加剧后收益归零
3. **由所有人共享的成本**：抢跑行为推高了新成分股的买入价，所有该基金的持有人共同承担

## 与幸存者偏差的关系

抢跑 + 幸存者偏差 + 运气，三者叠加制造了"指数基金跑赢指数"的幻象。单独看任何一个因素都不足以解释，但三者叠加后，统计上的"跑赢"变得非常普遍。

→ [[concepts/幸存者偏差-指数层面]]

## 判断标准

- 短期（1–2 年）跑赢：很可能是抢跑或运气
- 长期（5 年+）跑赢：才可能是真实能力

## 实践启示

不要仅凭短期（1–3 年）的超额收益选择指数基金——那很可能是抢跑的统计学假象。
