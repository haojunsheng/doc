# 风格两端向中间切换

市场风格从极端分化走向均衡的切换逻辑，由基金经理綦缚鹏提出。

## 核心逻辑链

```
低利率 → 债/地产吸引力↓ → 股票性价比↑ → 居民: 利息→股息 → 风格: 两端→中间
```

## 机制解释

在低利率环境下，债券和房地产的吸引力下降，股票的性价比相对提升。居民投资重点将从"利息"转向"股息"，市场投资方向从利润表转向现金流量表，风格从极端走向均衡。

## 边界条件

若利率大幅上行或股市波动过于剧烈，资金可能重新回流固收。
