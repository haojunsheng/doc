# 持有期债基

设有固定持有期的债券型基金，到期前不可赎回，到期后可赎回或自动滚入下一期。是"用流动性换票息"的典型产品形态。

## 核心机制

```
投资者接受持有期约束 → 基金经理获得稳定负债端 → 配置信用债/金融债/利率债 → 赚取票息与利差 → 收益高于货币基金，波动高于纯债
```

## 典型持有期类型

| 持有期 | 常见产品举例 | 适用场景 |
|---|---|---|
| 30天 | 短债/中短债基金 | 短期闲置资金 |
| 90天 | 季频持有债基 | 季度资金使用计划 |
| 180天 | 广发添财180天债券A | 半年期现金管理 |
| 1年 | 一年持有期债基 | 中期稳健配置 |

## 收益-流动性交换

持有期债基是 [[concepts/不可能三角-收益风险流动性]] 在债券品种中的直接体现：

- **流动性**：牺牲——持有期内无法赎回
- **收益**：提升——基金经理可配置期限稍长的信用债，获取票息溢价
- **风险**：略高于货币基金，但通常低于纯债基金（因持有期缓冲了赎回冲击）

## 与秩序搬运的关系

持有期债基是 [[concepts/秩序搬运]] 在主动管理型固收中的典型案例。基金经理通过信用筛选和久期管理可以获得一定超额，但整体而言大部分收益来自债券市场本身的票息和利差，而非阿尔法创造。广发添财180天债券A 的判断为"秩序搬运，可用但不稀缺"。

## 使用注意

1. **滚动机制**：到期未赎回自动进入下一持有期，可能超出资金使用计划
2. **机构集中度**：机构持有比例过高（如超过20%）可能导致负债端不稳定，见 [[concepts/机构持有人风险]]
3. **信用下沉**：部分持有期债基为追求收益而配置较低评级信用债，需关注持仓风险
