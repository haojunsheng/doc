# 资讯料理法

## 定义

肖璟对麦肯锡式研究工作流程的整合命名——将行业研究分为三个阶段：**备菜（输入）→ 烹饪（处理）→ 摆盘（输出）**。是对[[行业资讯料理法]]现有页面的深化补充，记录本章中各子工具的具体操作方法。

## 阶段一：备菜（输入）

### 难点1：信息过载 → 假设驱动

**假设驱动三步法**：
1. **做出假设**：先基于逻辑和常识形成初步判断
2. **MECE拆解**：把假设拆成不重不漏的子假设
3. **指标验证**：用可获取的指标逐一验证

示例："消费降级 = 钱不够花"拆解为4个子假设：
- 主动收入变少了（城镇调查失业率）
- 被动收入变少了（沪深300涨幅、理财收益率）
- 应付本金和利息变多了（居民杠杆率、信用卡逾期率）
- 投资理财变多了（居民新增存款增速、基金发行份额）

### 难点2：观点极化 → 三步解法

| 步骤 | 做法 |
|:---:|------|
| 1️⃣ 拓宽渠道 | 关算法推荐 + 主动找反面观点 |
| 2️⃣ 做好拣选 | 事实判断（新鲜食材）vs 价值判断（加工食品） |
| 3️⃣ 理性赋权 | 用系统2而非系统1 |

## 阶段二：烹饪（处理）

### 金字塔原理四步法

| 步骤 | 做什么 |
|:---:|------|
| 1️⃣ 罗列资讯 | 所有重要资讯写在便笺纸上，写出完整语句 |
| 2️⃣ 寻找规律 | 提炼共性，按逻辑分组 |
| 3️⃣ 提炼要点 | 分别为每组提炼一个要点 |
| 4️⃣ 归纳核心 | 思考每组要点对问题意味着什么 → 提炼最高层级观点 |

### 两个附加要求

**有深度**：学会区分"总结"与"提炼"
- **总结** = 同义互换，没有信息增量
- **提炼** = 多问几次"So what?"，不断提升到更高层级

**有逻辑**：归纳推理 + 演绎推理 + 排序
- 归纳维度：性质(What/Why/How)、影响(正面/负面)、时间(过去/现在/未来)、空间(外部/内部)
- 常见演绎结构：需做到X → 你无法做到X → 你需要建立做X的能力

## 阶段三：摆盘（输出）

### SCQR框架（空雨湿伞模型）

```
S (Situation)    —— 天空飘来一朵云   —— 情景：描述当前状态
C (Complication) —— 很可能要下雨     —— 冲突：出了什么问题/变化
Q (Question)     —— 可能会被淋湿     —— 问题：要回答什么
R (Resolution)   —— 带上伞出门       —— 解答：方案/观点
```

### 四种受众类型 × 四种输出顺序

| 受众类型 | 沟通顺序 | 原因 |
|:------:|:------:|:-----|
| 路人（短视频/陌生网站） | CQSR | 没有背景知识 → 先用冲突吸引眼球 |
| 观众（感兴趣但不了解） | SCQR | 有兴趣 → 适合用完整故事线引入 |
| 大老板（时间宝贵） | RSCQ | 直接给结论 → 有兴趣再补细节 |
| 直属领导（已有深入理解） | R（只给结论） | 只需解答 → 铺垫浪费时间 |
