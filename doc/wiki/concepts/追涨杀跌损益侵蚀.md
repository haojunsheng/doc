# 追涨杀跌损益侵蚀

投资者在基金净值高点时大量申购、在低点时赎回或不敢买入，导致实际买入成本高于基金平均持仓成本，从而系统性侵蚀投资收益的行为机制。

## 核心机制

```
基金净值上涨 → 投资者情绪高涨 → 大量申购（买入成本高）
基金净值下跌 → 投资者恐慌离场 → 赎回/不敢买入（低点割肉）
结果：投资者资金流的加权平均买入时点 >> 基金持仓的平均买入时点
```

## 数据表现

**资金流-收益背离**：某主题基金的累计收益曲线与净申赎份额呈反向关系——
- 收益低点：资金净流出 / 净流入极少
- 收益高点：资金大量流入
- 结果：高位买入的资金在下跌中遭受更大亏损，低位赎回的资金错失反弹

**晨星 2012–2021 数据**：
- 75% 偏股型基金投资者的实际收益 < 基金本身回报
- 这一差距的核心来源之一便是追涨杀跌的行为损耗

## 与相关概念的关系

- [[投资者回报差距]]：追涨杀跌损益侵蚀是造成这一差距的结构性成因之一，与"错过关键交易日"（[[80-20收益时间分布]]）并列
- [[恐慌性离场负反馈循环]]：追涨杀跌的高点买入门槛低于离场的心理门槛，形成不对称行为——更容易在高点冲进去，更难在低点补回来
- [[行为代价-mind-the-gap]]：追涨杀跌损益侵蚀是行为代价的一个具体表现形式
- [[收益集中规律]]：追涨的本质是"买在别人出货的时候"——最佳涨幅已过，后续收益空间有限

## 边界与限制

- 定投可以部分克服这个问题，因为定投会在低点自动买入更多份额，平滑买入成本
- 但若定投过程中因恐慌中断，则效果大打折扣
- 75% 统计数据存在幸存者偏差的可能（是否剔除已清盘基金），具体边界需进一步考证

## 行动启示

- 建立投资纪律：在制定投资计划时预先规定买入/持有规则，避免在情绪波动时做决策
- 使用定投而非一次性重仓：通过定期定额平摊成本，降低择时风险
- 关注底层资产而非短期排名：避免被历史业绩和短期热度吸引
