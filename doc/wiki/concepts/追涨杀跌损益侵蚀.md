# 追涨杀跌损益侵蚀

投资者在市场（基金净值）高点时大量申购、在低点时赎回或不敢买入，导致实际买入成本高于基金平均持仓成本，从而系统性侵蚀投资收益的行为机制。这是 [[基金收益与投资者收益差距扩大机制]] 中的"行为成本"组成部分。

## 核心机制

```
基金净值上涨 → 投资者情绪高涨 → 大量申购（买入成本高）
基金净值下跌 → 投资者恐慌离场 → 赎回/不敢买入（低点割肉）
结果：投资者资金流的加权平均买入时点 >> 基金持仓的平均买入时点
```

## 数据与量化

**资金流-收益背离**：某主题基金的累计收益曲线与净申赎份额呈反向关系——
- 收益低点：资金净流出 / 净流入极少
- 收益高点：资金大量流入
- 结果：高位买入的资金在下跌中遭受更大亏损，低位赎回的资金错失反弹

**晨星 2012–2021 数据**（来源1）：
- 75% 偏股型基金投资者的实际收益 < 基金本身回报
- 这一差距的核心来源之一便是追涨杀跌的行为损耗
- 该统计数据存在幸存者偏差的可能（是否剔除已清盘基金），具体边界需进一步考证

**量化示例**（来源2）：
假设某指数基金净值序列：1.0 → 1.2 → 0.9 → 1.1

- 理性投资者：全程持有，收益 = (1.1 - 1.0) / 1.0 = 10%
- 追涨杀跌投资者：
  - 1.2 时申购（追涨），成本 1.2
  - 0.9 时赎回（杀跌），亏损 (0.9 - 1.2) / 1.2 = -25%
  - 1.1 时再次申购，成本 1.1
  - 最终收益远低于基金净值涨幅

## 行为根源

[[净值恐高症]] 是追涨的心理基础——投资者倾向于认为"涨了的基金以后还会涨"，而忽略均值回归规律。[[追涨杀跌损益侵蚀]] 则是这一偏差在指数基金场景下的直接后果。

## 边界与限制

- 定投可以部分克服这个问题，因为定投会在低点自动买入更多份额，平滑买入成本
- 但若定投过程中因恐慌中断，则效果大打折扣

## 解决方案

避免追涨杀跌的核心纪律：
1. **定期定额**——用纪律替代择时冲动
2. **逆向思维**——在低点敢于买入，在高点保持冷静
3. **长期持有**——减少操作频率，降低犯错概率

具体行动：
- 建立投资纪律：在制定投资计划时预先规定买入/持有规则，避免在情绪波动时做决策
- 使用定投而非一次性重仓：通过定期定额平摊成本，降低择时风险
- 关注底层资产而非短期排名：避免被历史业绩和短期热度吸引

这与 [[ETF的工具属性悖论]] 的解决路径一致：悖论的解不在工具，而在使用者。
