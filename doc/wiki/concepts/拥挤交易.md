# 拥挤交易

拥挤交易是指大量机构使用相似的因子和模型，导致原本有效的策略优势消失、最终引发踩踏的市场现象。

## 发生机制

```
新因子被发现 → 所有人涌入 → 拥挤交易 → 踩踏 → 均值回归
```

1. **因子发现**：某个量化因子（如小盘股超额）被某机构发掘，产生超额收益
2. **模仿涌入**：其他机构发现后纷纷采用相似策略
3. **优势消失**：随着资金集中涌入同一方向，因子Alpha被摊薄
4. **踩踏发生**：一旦市场风向转变，大量机构同时减仓，引发连锁下跌
5. **均值回归**：策略收益回归平均水平，甚至转为亏损

[[concepts/因子投资策略]] 中的因子衰减理论为这一动态过程提供了理论基础：Alpha 随模型扩展而消失。

## 典型案例

2024 年春节前，国内私募量化圈经历了一场噩梦：大批量化产品多米诺式下跌，有的单周跌幅达 20%，抹掉过去两三年收益。原因是多家量化机构不约而同发现了小盘股超额策略，前后脚买入，最后集体踩踏。

## 与追涨杀跌的关系

拥挤交易导致的踩踏与 [[concepts/追涨杀跌损益侵蚀]] 有内在关联——都是群体行为导致的非理性结果。但拥挤交易特指机构层面因策略同质化而产生的踩踏，而追涨杀跌更多指向个人投资者的行为偏差。

## 对普通投资者的启示

- 量化策略的有效性是暂时的，不可永久持续
- 理解量化的逻辑比崇拜工具更重要
- 不要将量化投资视为"稳赚"的保证
