# 假设驱动学习计划——H1/H2/H3/H4 可证伪框架

本框架是一种将「假设驱动验证」引入个人学习路径的方法论，核心思想是：**在学习开始前写下可证伪的假设，并在每个阶段结束时用具体行动检验，让学习成果来自验证而非吸收。**

## 与普通学习计划的本质区别

| 维度 | 普通学习计划 | 假设驱动计划 |
|------|------------|------------|
| 起点 | 我要学什么 | 我相信什么，需要验证什么 |
| 结构 | 章节顺序 | 假设 → 子假设 → 验证方式 → 失败判定 |
| 终点 | 我读了多少 | 我的假设被推翻了多少 |
| 错误处理 | 避免犯错 | 记录失败日志，从错误中学习 |

## H1/H2/H3/H4 完整假设（晨星七大主题版本）

### H1：阿尔法稀缺假设

> 长期稳定跑赢基准（阿尔法）的主动基金是极少数，普通投资者的合理目标应是拿住贝塔。

- **子假设**：
  - 1.1：阿尔法在 A 股主动基金中持续存在比例低 → 验证：用 [[主动vs被动回测框架]] 统计近 5 年偏股基金跑赢沪深 300 比例
  - 1.2：基准比收益排名更客观 → 验证：对比一只基金的「排名」与「相对基准超额」是否背离
  - 1.3：历史业绩对未来预测力弱 → 验证：统计「去年 Top10 基金」次年掉队比例
  - 1.4：费率侵蚀主动收益 → 验证：对比同标的主动基金 vs ETF 费后收益
- **如果错了我会在**：主动基金跑赢基准比例 > 预期阈值时知道

### H2：现金流优先假设

> 个人理财的核心约束不是收益率，而是「支出不确定性/现金流」；资产配置应随人生阶段调整。

- **子假设**：
  - 2.1：FIRE 所需本金由年支出/安全提取率决定，而非收益率 → 验证：用 [[现金流优先于收益率]] 框架测算
  - 2.2：配置应随人生阶段动态调整 → 验证：读锚点《不同人生阶段的资产配置指南》
  - 2.3：支出不确定性是终极风险 → 验证：读锚点《投资理财的终极风险》
- **如果错了我会在**：阶段一做「现金流测算」时发现 FIRE 本金与收益率高度相关而非支出相关时知道

### H3：热点不可择时假设

> 市场热点多数不可作择时依据，需用估值/周期框架降噪。

- **子假设**：
  - 3.1：资金流向看数据不看叙事 → 验证：用 [[热点降噪两栏法]] 拆解《外资真的在加仓中国》
  - 3.2：跌久了不等于能抄底 → 验证：用 [[热点降噪两栏法]] 拆解《白酒可以抄底了吗》
  - 3.3：估值/周期框架比「跌多了」更可靠 → 验证：对照 [[周期有关又无关]]
- **如果错了我会在**：某一类热点经两栏检验后被确认具有前瞻性时知道

### H4：再平衡贡献 > 单基选择假设

> 组合层面的再平衡/仓位管理对最终收益的贡献 > 单基选择。

- **子假设**：
  - 4.1：仓位是可计算的风险旋钮 → 验证：读锚点《仓位多少才能收益最大化》
  - 4.2：纪律化策略 > 单次择时 → 验证：读锚点《牛熊都在赚的人》
  - 4.3：再平衡是纠错机制而非额外成本 → 验证：对比「再平衡 vs 不动」收益回测
- **如果错了我会在**：回测显示「再平衡 vs 不动」收益差异不显著时知道
- **边界条件**：A 股高波动环境下，若回撤超过再平衡触发阈值（通常 ±5%~10%），频繁再平衡可能在单边市中持续"卖出上涨资产"，实际贡献为负。需单独回测验证。

## 方法论四支柱

```
假设驱动 → MECE 拆解 → 动手验证 → DIKW 自检 → 失败日志
    ↑___________________________________________↓
```

螺旋迭代，每周循环一次。

### 1. 假设驱动

在开始学习前先写下 2–4 条核心假设（H1–H4），每条假设必须包含明确的「如果错了我会在什么时候知道」。这是与普通学习计划最关键的区别。

### 2. MECE 拆解

每条主假设拆解为 2–4 条互相独立、完全穷尽的子假设。每条子假设对应一个具体验证动作。

### 3. 动手验证

每周至少一个 demo/验证实验（回测、配置表、溯源报告、体检单）。验证产出物不是笔记，而是可以提交的可复现成果。

### 4. DIKW 自检 + 失败日志

- 每周填入 DIKW 自检表，确认停留在哪一层、是否有证据
- 每周记录 ≥1 条失败日志（哪怕很小）

## 适用范围

本框架适用于任何需要「从知道到能用」的 P+M 型（实践手艺 + 心智判断）学习领域，不限于投资。关键信号：
- 该领域的知识容易以「正确的废话」形式被吸收
- 学习者容易陷入「读了很多但没有判断力」的状态
- 验证结果可以是客观的（数据回测）也可以是主观的（能否在 10 分钟内做出判断）
