# ETF选基多维评估框架

费率触底后，ETF选基应从"唯费率论"转向多维评估框架。费率只是其中一个因素，跟踪误差、流动性、规模、基金公司声誉共同决定ETF的实际投资价值。

## 核心公式

```
选择ETF = f(费率, 跟踪误差, 流动性, 规模, 基金公司)
→ 费率只是其中一个因素
```

## 评估维度

### 1. 费率（显性成本）

- 管理费：主要显性成本，部分产品已降至0.15%以下
- 托管费：托管银行收取，通常较低
- 综合费率：考虑所有显性和隐性成本后的总费率
- **重要性变化**：费率触底后，进一步降费空间有限，重要性相对下降

### 2. 跟踪误差（隐性成本）

- 定义：ETF回报与指数回报的偏离程度
- 影响：直接决定投资者能否获得指数的真实收益
- 来源：
  - 现金拖累：基金留现金应对赎回，牛市少赚、熊市保护
  - 调仓延迟：指数成分股调整后，基金不可能同天完成买卖
  - 分红再投资：分红到账后再投资的时间差
- **重要性提升**：费率差异缩小到0.05%时，跟踪误差0.1%的差异反而更关键

### 3. 流动性（交易成本）

- 影响：流动性差的ETF买卖价差大、冲击成本高
- 衡量指标：
  - 买卖价差：最优买价与卖价之差
  - 日均成交额：反映市场活跃度
  - 资产规模：大规模通常意味着更好的流动性
- **实操建议**：优先选择日均成交额高、买卖价差小的ETF

### 4. 规模（稳定性的代理）

- 规模大通常意味着：
  - 流动性更好
  - 费率更低（规模经济）
  - 产品稳定性更高（清盘风险低）
- 但规模过大可能导致跟踪误差增加（调仓难度大）

### 5. 基金公司声誉（信任成本）

- 影响产品稳定性和服务质量
- 头部基金公司通常在跟踪质量、流动性管理上更有优势
- 声誉也是一种隐性竞争力

## 权重变化（费率触底前后）

| 维度 | 费率竞争阶段权重 | 质量竞争阶段权重 |
|------|-----------------|-----------------|
| 费率 | ★★★★★ | ★★★☆☆ |
| 跟踪误差 | ★★☆☆☆ | ★★★★★ |
| 流动性 | ★★★☆☆ | ★★★★☆ |
| 规模 | ★★★☆☆ | ★★★★☆ |
| 基金公司 | ★★☆☆☆ | ★★★★☆ |

## 实践步骤

1. **确定投资目标**：先问"投什么资产"，而非"哪只ETF便宜"
2. **筛选同指数产品**：找出跟踪同一指数的所有ETF
3. **比较跟踪误差**：选择跟踪误差最小的产品
4. **检查流动性**：优先选择日均成交额高、买卖价差小的产品
5. **确认规模与声誉**：选择规模较大、基金公司声誉良好的产品
6. **最后看费率**：在前几步筛选后，费率差异通常已很小

## 与[[concepts/ETF投资五问框架]]的关系

本框架与[[concepts/ETF投资五问框架]]高度互补：
- 五问框架提供自上而下的决策流程（资产→指数→策略→产品→费率）
- 多维评估框架聚焦于产品选择阶段的具体评估维度
- 在五问框架的"第四问"（基金表现）中，可引入本框架的多维评估方法
- 费率触底后，应调整五问框架的权重——费率的重要性相对下降

## 关键洞察

1. **费率陷阱**：只看费率最低的产品，可能忽视了跟踪误差和流动性等更重要的因素
2. **隐性成本更大**：跟踪误差作为隐性成本，往往比显性费率差异对长期收益的影响更大
3. **流动性溢价**：流动性好的ETF虽然费率可能略高，但交易成本更低，长期来看更划算
