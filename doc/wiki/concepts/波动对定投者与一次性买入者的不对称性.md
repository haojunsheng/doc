# 波动对定投者与一次性买入者的不对称性

同样的波动，对不同买入方式的人意味着完全不同的东西。

## 核心结论

- **波动对一次性买入者 = 风险**：高位买入后遭遇下跌，账户缩水，容易恐慌卖出
- **波动对分批买入者（定投）= 机会**：下跌时买到更多份额，摊薄成本，涨回后回报更高

## 形式化

```
波动 = 价格围绕价值的摆动
长期投资者可以在低价时买入更多 → 降低平均成本
```

## 关键前提

此结论有两个严格前提：
1. 有足够时间等市场回来
2. 能在下跌时真的买入（而非恐慌卖出）

若做不到这两点，波动对你来说就是纯风险。
