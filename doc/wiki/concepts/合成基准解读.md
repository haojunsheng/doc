# 合成基准解读

## 定义

**合成基准**是由多个子指数按不同权重组合而成的业绩比较基准。单个宽基指数只能反映一种风格暴露，而合成基准通过多因子加权直接揭示基金的资产配置策略——股债比例、市场分布、货币敞口。

## 解读方法

将合成基准拆解为各因子权重，即可推断基金的战略定位：

```
沪深300×50% + 中证全债×50%  →  股债均衡型
沪深300×60% + 恒生×30% + 中债×10%  →  A股为主港股为辅债打底
标普500×40% + 恒生×30% + 中债×20% + 黄金×10%  →  全球多元配置
```

## 各成分信号含义

| 合成因子 | 传递的信号 |
|---------|-----------|
| 股债比例 | 进攻性 vs 防守性 |
| 多市场指数叠加 | 跨市场配置意图 |
| 活期利率成分 | 保留现金应对申赎 |
| 黄金/商品成分 | 对冲通胀或分散风险 |

## 边界与局限

- 合成基准越复杂（4-6 因子），投资者越难一眼看懂基金在做什么
- 基准只反映合同约定，若实际持仓大幅偏离则信号失效
- 部分基金基准因子过多导致"什么都测等于什么都没测"，需抓核心配置权重
