# 美债美股预期回报趋同

## 定义

指美股与美债的长期预期回报在2025年全球普涨后逐渐收敛，两者收益预期差显著收窄的现象。这一趋同由两个方向共同驱动：美股预期回报因估值抬升而下调，美债因收益率处于高位而预期回报维持相对优势。

## 形式化表达

```
美股预期回报：3.1% - 6.7%（下调中）
美债预期回报：高位收益率支撑 → 预期回报↑
收敛结果：美股 ≈ 美债（预期回报接近）
```

同时满足波动率约束：

```
美债波动 < 美股波动（结构性特征）
→ 低风险偏好下：美债替代部分美股是合理选择
```

## 驱动机制

1. **估值端**：2025年全球股市两位数涨幅抬高了美股估值，同样的盈利和股息水平对应更高价格，导致股息率下降、预期回报下降。
2. **利率端**：美债收益率处于历史高位，为债券提供了比以往更友好的起点收益。
3. **机构共识**：除先锋领航外，几乎所有机构都下调了美股预期；先锋领航和锐联明确判断未来十年美债整体表现将优于美股。

## 配置含义

| 投资者类型 | 建议 |
|-----------|------|
| 低风险偏好、近期有资金需求 | 可考虑美债替代部分美股，在收益接近时降低波动 |
| 高风险偏好、长期投资者 | 仍应保留一定权益敞口，但不必追求单一资产的高回报 |
| 长期配置者 | 多元配置优于单一押注，与时间站在同一边 |

## 边界条件

- **若美联储大幅降息**：美债收益率下行，收益预期差可能重新扩大，"美债替代"逻辑弱化。
- **若美国企业盈利超预期**：美股预期回报可能重新上升，趋同趋势逆转。
- **若估值继续扩张**：美股预期回报进一步压缩，趋同程度加深。

## 与其他框架的关系

- [[安全边际压缩逻辑]]：美股估值抬升是安全边际被压缩的直接表现，推动了预期回报下降。
- [[长期预期回报率框架]]：美债和美股的预期回报测算均依托此框架，趋同是该框架在2026年的最新发现。
- [[高收益资产稀缺化]]：美债美股趋同是高收益资产稀缺化的具体体现之一——两者相比过去，都失去了"明显占优"的优势。
- [[可持续回报框架]]：在趋同环境下，多元配置和长期持有比追逐单一资产高回报更可持续。
