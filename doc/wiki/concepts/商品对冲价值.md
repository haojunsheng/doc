# 商品对冲价值

**商品对冲价值**是指大宗商品因价格驱动逻辑独立于股市（由供需而非盈利预期决定），在风险资产下跌时仍能提供对冲效果的资产配置属性。随着中国股债相关性从负转正，商品的分散价值日益凸显。

## 核心逻辑

```
商品价格驱动：供需关系 → 独立于股市逻辑
A股下跌时：商品常因供给约束或通胀预期而上涨 → 对冲有效
```

传统债券在2015年后与A股负相关关系弱化（见 [[股债跷跷板脱钩]]），商品成为新的替代分散工具。

## 商品 vs 债券的分散能力对比

| 维度 | 债券 | 商品 |
|------|------|------|
| 价格驱动 | 利率+信用利差 | 供需 |
| 与A股相关性（2015后） | 上升，对冲减弱 | 总体较低 |
| 通胀环境 | 受损（实际收益↓） | 受益 |
| 通缩环境 | 避险（价格上涨） | 可能同跌 |
| 极端危机 | 国债仍有避险属性 | 波动大，不适合重仓 |

## 适用条件

商品对冲价值在以下条件下最强：
- **通胀冲击环境**：关税推高物价，商品受益于价格上涨
- **股债双杀场景**：传统股债组合同时受损，商品提供第三条路
- **供给约束型危机**：地缘冲突、产能瓶颈导致商品供应紧张

## 边界条件

- **通缩环境失效**：通缩时期商品可能与股市同跌，失去对冲作用
- **波动性高**：商品价格波动剧烈，不适合作为组合重仓资产
- **相关性不稳定**：商品与风险资产的相关性会随宏观环境变化，需持续跟踪

## 与投资实践的关系

1. 在关税时代，商品（尤其是黄金）可作为债券的部分替代，提升组合韧性
2. 普通投资者可通过商品ETF（如黄金ETF、大宗商品ETF）低门槛参与
3. 商品在组合中的仓位应适度，不宜过重（高波动特性）
