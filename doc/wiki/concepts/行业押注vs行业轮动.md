# 行业押注 vs 行业轮动

区分基金业绩是来自被动的行业暴露（押注）还是主动的行业轮动能力，是业绩归因的核心难题。两者在数据上高度相似，但能力和可持续性截然不同。

## 定义对比

| 维度 | 行业押注 | 行业轮动 |
|------|---------|---------|
| 本质 | 被动暴露于热门赛道 | 主动预测并切换行业配置 |
| 持续性 | 不可持续（次年风格轮动即失效） | 理论上可持续（如有真能力） |
| 仓位集中度 | 极高（90%+在1-2个行业） | 中等，分散配置 |
| 可归因性 | 业绩=90%仓位×行业β | 业绩=行业α+选股α |
| 结果 | 押中对=翻倍，押错=大跌 | 平滑波动，长期超额 |

## 形式化表达

```
行业押注：基金业绩 ≈ 90%仓位 × 当年最佳行业涨幅
行业轮动：基金业绩 = Σ(各行业权重 × 行业超额收益) + 选股Alpha
```

## 实证案例

**永赢科技智选（2025年翻倍）**：
- 90%+仓位集中在通讯和电子
- 前十大集中度90%
- 本质：被动暴露于当年最强赛道，非主动轮动

**真正的行业轮动**（罕见）：
- 基金经理有明确的历史轮动记录
- 跨越多个行业周期仍能保持超额
- 归因清晰：能说清每个行业切换的逻辑和时机

## 为什么难以区分

1. **数据层面**：短期（1-2年）两者业绩表现高度相似
2. **心理层面**：[[近因效应]]让人将短期行业顺风误认为轮动能力
3. **叙事层面**：基金公司倾向于将押注包装为"前瞻性布局"

## 防御方法

- **穿透持仓**：查看前十大重仓股和行业分布，集中度>80%为押注
- **跨周期验证**：看3年以上行业切换记录，非单次押中
- **业绩归因工具**：通过晨星基金小程序查业绩归因，区分β和α
- **警惕90%仓位**：任何基金90%以上仓位集中在一两个行业，本质是赛道基金
