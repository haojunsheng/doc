# 黄金半小时（Golden Hour）

## 定义

日出后和日落前各约 **30 分钟**，太阳高度角小，光线穿过更厚的大气层，从直射变为散射，光线质量特别完美——这是自然光中最理想的软硬组合：**柔和 + 暖色调 + 斜射方向**。

## 物理成因

- 太阳高度角小 → 光线穿过厚大气层 → 散射增强 → 直射硬光被过滤，变成大面积散射光源
- 蓝光被更多散射掉 → 剩余光线偏暖（金色调）
- 斜射方向 → 产生长阴影，增强立体感

## 为什么"完美"

黄金半小时同时满足光四要素中的多个最优条件：

| 光要素 | 黄金半小时的表现 |
|---|---|
| 质量 | 软光（大气层散射使太阳变相成为大面光源） |
| 方向 | 低角度斜射（产生立体阴影，增强画面层次） |
| 色温 | 偏暖（金色调，传递温馨感） |
| 强度 | 适中（不需要极端曝光补偿） |

## 注意：硬光也能拍人

黄金半小时是自然光中**最理想**的软硬组合，但硬光本身并非"不好"——[[Frank Ockenfels]] 和 [[Bruce Gilden]] 的硬光作品证明，硬光是有意为之的美学选择。"黄金半小时完美"是对自然光条件的描述，不意味着其他光线条件无法创作。

## 与阳光十六法则的关系

黄金半小时属于"日暮"阶段，适用[[阳光十六法则]]中的规则：

> 阳光十六阴天八，**多云十一日暮四**，乌云压顶五点六，雪天落雨同日暮。

即日出/日落附近用 F11，快门 = ISO 倒数。

## 与摄影减法的关系

[[摄影减法论]] 强调"好照片是删出来的"。黄金半小时的光线方向性有助于形成明确的明暗分割，让画面中的主体更容易从背景中分离——这在视觉上是一种天然的"减法"。
