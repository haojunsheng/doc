# 组合视角（vs 单品视角）

投资决策应基于整个投资组合的配置合理性，而非单一标的的盈亏状态。这是避免[[回本心理]]等行为偏差的核心思维框架。

## 定义

**组合视角**是选择基金时的核心认知框架：评估一只新基金的价值，不是看它"本身好不好"，而是看它"是否能填补你现有组合的空白"。

与之相对的是**单品视角**——只看单只基金的历史业绩、策略标签、基金经理资历，而不考虑它在整体组合中的边际贡献；以"这只基金亏了/赚了"为决策单位，容易触发"回本跑路"的非理性操作。

## 核心问题

> 如果你现在持有5只主动基金，能否说出每只基金相对于其他四只的"不可替代性"在哪里？如果有一只被清盘、永远无法申购了，你会用什么来替代它？

这个问题强制将思维从单品切换到组合——每只基金应该在组合中有明确的定位，而非重复覆盖同一风险暴露。

行动的起点是"**我该拿多少钱投资**"，而非单品持有层面的买卖决策。

## 为什么重要

1. **同质化陷阱：** 市场上有大量策略相似的基金（如同为GARP策略、同为红利策略）。新买一只同质化基金不会增加组合价值，只会增加复杂度。
2. **行为损耗放大：** 主题基金本身就是窄领域暴露，叠加投资者追高杀低的行为，双重损耗（参见[[投资者回报差距]]）。
3. **费率复利侵蚀：** 重复持有相似策略的基金，费率叠加效应加速侵蚀收益（参见[[费用是复利的反面]]）。
4. **回本焦虑驱动非理性操作：** 单品层面的盈亏叙事容易触发"回本跑路"，偏离组合整体配置目标。

## 正确提问方式

```
正确问题 = "我的资产配置合理吗？"
       ≠ "要不要卖这只基金？"
```

## 实践方法

- 用晨星小程序的"账户诊断"功能检查持仓基金的行业重叠度
- 对比持仓基金的费率，看是否有同风格但费率更低的替代品
- 问自己：如果某只基金被清盘，我会用什么替代它？如果不能回答，说明它可能不具备不可替代性

### 回本后的组合调整流程

1. **重新锚定配置**：股票/偏股基金仓位是否超出心理承受水平？
2. **赎回刚需资金**：5年内要用的钱（买房、教育）应先从股票类资产赎回
3. **评估剩余持仓**：对仍持有的基金做三维度评估（业绩、收益来源、能力圈）
4. **定期再平衡**：替代择时操作，让组合回归目标配置
