# 假设驱动研究

## 定义

先提出待验证的判断（假设），再有目标地搜集证据来验证或证伪这些假设的研究方法。这是行业研究的认识论基础，区别于"资料堆积式搜索"。

## 核心公式

```
普通搜索：问题 -> 资料 -> 摘抄
专业研究：假设 -> 证据 -> 修正判断
```

## 与相关概念的关系

###  vs [[前置信号-财报滞后性]]

假设驱动提供了认识论层面的框架，前置信号是其在景气度跟踪中的具体应用——当你对某个行业有假设时，前置信号是你验证假设的工具。

###  vs [[报告幻觉]]

报告幻觉是假设驱动的对立面：只收集资料、填空框架，却没有明确的待验证假设。

## 关键约束

书中提出的压力测试问题：**如果一个人没有任何行业经验，他提出的初始假设会不会很差？** 如果初始假设很差，假设驱动是否会把研究带偏？这是书中未充分解决的问题，也是读者需要自己判断的。

## 适用场景

- 投资分析中的行业判断
- 咨询项目中的快速行业了解
- 任何需要在信息不完整时迅速形成可讨论判断的场景

## 操作要点

1. 先问"我现在最需要验证的假设是什么？"
2. 把同一个事实接到不同决策场景里，才会变成判断
3. 用证据修正判断，而非用判断挑选证据
