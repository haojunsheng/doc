# "定价权企业"：保护主义环境下的投资选择

在保护主义抬头、成本上升的环境下，拥有**定价权**的企业是投资首选——即成本上升时仍能维持盈利能力的公司。但定价权并非万能，估值水平同样关键。

## 核心定义

**定价权企业**：在成本上升环境中仍能维持盈利能力的公司，具体表现为：
- 能够将成本上涨转嫁给消费者（提价而不损失销量）
- 或凭借产品差异化、品牌溢价维持利润率
- 或凭借规模效应、效率提升吸收成本冲击

## 投资框架

```
保护主义环境
  → 定价权企业（成本↑仍盈利） × 多元化配置 → 抗波动 ⊃ 长期回报
```

## 沃尔玛案例的修正启示

沃尔玛案例同时给出了重要修正：
- 沃尔玛作为进口依赖型零售企业，理论上具备关税取消后的成本改善预期
- 但裁决当日股价大跌，原因是**估值已处历史高位**
- 结论：**即使拥有定价权或政策受益预期，估值过高时仍需等待合理价格**

## 与"成本优势优先于产品差异化"的关系

[[成本优势优先于产品差异化]] 强调的是企业竞争力的来源排序——成本优势比产品差异化更能抵御价格竞争。"定价权企业"概念在此基础上进一步明确：在保护主义环境下，能够转嫁成本的企业（即具备定价权）是最优投资标的，这与成本优势逻辑高度一致。

## 边界条件

1. **估值约束**：定价权企业若估值过高（如沃尔玛案例），投资回报仍可能为负
2. **定价权衰减**：若全球主要经济体全面转向保护主义，非美市场萎缩，中国出口企业的定价权可能系统性受损
3. **需求弹性**：若产品需求弹性极大，即使有定价权也难以转嫁成本

## 晨星的明确建议

晨星在关税裁决分析中明确指出：保护主义环境下，投资者应关注拥有定价权的企业，并通过多元化配置抵御波动。这是全文给出的最具体、可操作的投资策略建议。
