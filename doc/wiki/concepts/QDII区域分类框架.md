# QDII区域分类框架

QDII区域分类框架揭示了QDII基金按投资地域划分的体系结构，以及分类标签背后隐藏的区域误判风险——**选错区域的代价远大于选错基金经理**。

## 股票型QDII六分类

| 分类 | 主要投资区域 | 典型代表 |
|------|------------|---------|
| 亚太（除日本） | 韩国、台湾、泰国、印尼等 | 相关亚太基金 |
| 大中华 | 中国大陆A股、港股、中概股 | 中概互联QDII |
| 新兴市场 | 印度、巴西、南非等发展中国家 | 新兴市场基金 |
| 环球 | 跨多区域配置（理论上） | 全球精选股票基金 |
| 行业 | 特定行业（科技、医疗等） | 行业主题QDII |
| 美国 | 美股市场 | 标普500 QDII |

## 混合型QDII四分类

| 分类 | 配置特点 |
|------|---------|
| 环球 | 全球股债混合配置 |
| 新兴市场 | 新兴市场股债混合 |
| 亚洲 | 亚洲区域股债混合 |
| 大中华 | 大中华区股债混合 |

## 核心陷阱：环球≠全球配置

这是本框架最重要的警示点。

在"环球股票"分类下，基金的实际投资范围天差地别：

- **真正的全球配置基金**：如基准为60% MSCI全球 + 40%恒生，覆盖多区域分散风险
- **单国ETF**：如CAC 40 ETF（只投法国）、日经225 ETF（只投日本）、富时100 ETF（只投英国）全部被归类在"环球股票"之下

**后果**：投资者看到"环球"标签便下单，实际全仓单一国家，丧失分散化意义。

## 实操建议：用业绩基准验证分类

分类只是第一层标签，真正的投资范围必须通过业绩基准来确认。参见 [[业绩基准作为投资范围说明书]]。

## 边界条件

- 分类体系由晨星制定，其他评级机构可能有不同分类标准
- 同一基金在不同时期的投资范围可能变化（风格漂移）
- 若对海外市场不了解，优先从配置广泛的环球股票QDII入门，避免过早暴露于单国风险
