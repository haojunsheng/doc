# 曝光三角与互易律

## 定义

**曝光三角**是指光圈、快门、ISO 三个参数通过互易律互相补偿、共同决定总曝光量的结构关系。其核心是：**总曝光量不变时，三个参数可以任意组合。**

**互易律**（Reciprocity Law）是曝光三角的数学基础：三参数满足乘法关系，任一参数的变化都可以由其他参数反向补偿以保持曝光量恒定。

## 数学表达

```
总曝光量 ∝ (1 / F²) × 快门时间 × ISO
```

注意：焦段不包含在这个公式中——F 值已经将焦段"约掉"，F8 在 28mm 和 200mm 上的曝光量完全相同。

## 三个参数的副作用权衡

| 参数 | 调整方向 | 获得 | 牺牲（副作用） |
|---|---|---|---|
| 光圈 | 开大（F 值变小） | 更多进光量 | 景深变浅 |
| 光圈 | 缩小（F 值变大） | 景深变大 | 需要更长快门或更高 ISO |
| 快门 | 加快 | 凝固运动 | 进光量减少 |
| 快门 | 放慢 | 更多进光量 | 运动模糊、手震风险 |
| ISO | 提高 | 整体提亮 | 噪点增多（不可逆） |
| ISO | 降低 | 纯净画面 | 需要更长快门或更大光圈 |

## 补偿的本质

**补偿的本质不是"调亮调暗"，而是"用哪个参数的副作用来换取另一个参数的自由"。**

常见操作模式：
- 开大光圈换更快快门：用"景深变浅"换"运动凝固"
- 放慢快门换更小光圈：用"运动模糊风险"换"全景深"
- 提高 ISO 换更快快门或更小光圈：用"噪点"换"曝光充足"

## 与机器视觉的关系

[[机器视觉vs人眼视觉]] 指出：相机的核心价值在于超越人眼的感知边界。曝光三角是实现这种超越的工具——它让我们看到人眼看不到的东西：高速子弹轨迹、星轨、黑暗中积累的光。
