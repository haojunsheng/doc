# 派息率健康阈值

派息率（Payout Ratio）= 每股股息 ÷ 每股盈利，衡量公司赚的钱中有多少分给了股东。是判断股息可持续性的核心指标。

## 健康阈值标准

| 派息率区间 | 健康度 | 说明 |
|-----------|--------|------|
| <60% | 健康 | 有足够留存用于再投资和安全缓冲 |
| 60%-80% | 警戒 | 接近上限，盈利小幅下滑即可威胁股息 |
| >80% | 危险 | 盈利稍有波动即面临砍息风险 |
| >100% | 不可持续 | 用借债或消耗现金储备分红，必然被砍 |

## 行业差异

不同行业的派息率基准差异显著，需结合行业特性判断：

| 行业 | 典型派息率 | 说明 |
|------|-----------|------|
| 公用事业 | 60-80% | 盈利稳定，高派息率正常 |
| 银行 | 50-70% | 受监管资本要求限制，派息率天然偏高 |
| REITs | 90%+ | 法律要求将大部分应税收入分红 |
| MLPs | 高 | 结构性高分红，不适用通用阈值 |
| 科技（传统） | <30% | 高再投资机会，股息增长为主 |
| 科技（成熟） | 逐步提升 | 如苹果、微软近年分红占比上升 |

## 与自由现金流结合

单一派息率不足以下结论，需结合自由现金流（FCF）：

```
派息率_FCF = 每股股息 ÷ 每股自由现金流
```

自由现金流比会计利润更难操纵，是更可靠的股息安全垫指标。两者结合才是完整判断：

- 派息率（盈利基础）适中 + 自由现金流持续为正 = 股息安全
- 派息率低但自由现金流为负 = 盈利质量存疑，不可持续
- 派息率高但自由现金流为正 = 可能处于周期顶部，需警惕

## 与 [[高股息陷阱风险]] 的关系

[[高股息陷阱风险]] 聚焦港股场景下的陷阱识别，本概念页补充普适性的派息率判断标准。两者共同构成完整的高股息股分析框架。
