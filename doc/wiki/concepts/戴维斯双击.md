# 戴维斯双击

戴维斯双击（Double Click）是指股票价格因**盈利增长**和**估值提升**同时发生而产生的超额收益现象。

## 机制

```
股价变动 ≈ 盈利增长率 + 估值（PE）变动率
戴维斯双击 = 盈利↑ × PE↑ → 股价涨幅远超单一因子贡献
戴维斯双杀 = 盈利↓ × PE↓ → 股价跌幅远超单一因子损失
```

## 与深化价值的关系

[[concepts/深化价值]]策略的目标正是实现戴维斯双击：在低估值（低PE/PB）企业中筛选具备可持续成长性的标的，等待市场对其盈利前景重新定价，实现估值扩张与盈利增长的双重收益。

## 反向风险：戴维斯双杀

当企业盈利增速不及预期，或市场整体风险偏好下降时，低估值股票可能因"估值继续压缩+盈利下滑"而遭受双重打击，这区别于单纯的"价值陷阱"——后者是估值长期不修复，前者是估值和盈利同时恶化。

## 与其他概念的关系

- [[concepts/价值陷阱]]：深化价值旨在规避的价值陷阱本质上是"只有低估值、没有成长性"的单因子陷阱，而戴维斯双杀是双因子同时恶化
- [[concepts/业绩信噪比]]：戴维斯双击的效果需通过业绩信噪比来验证，短期股价上涨可能是运气而非能力的体现
