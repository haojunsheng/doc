# 基金拆分和复制

拆分是为了降低净值表象，复制是为了跟踪指数——两者都是基金操作的常见手段，但目的和风险不同。

## 基金拆分

拆分是将现有基金份额按比例拆分为更多份额，同时等比例降低净值。例如：1 份净值 3.0 的基金拆分为 3 份净值 1.0 的基金。

**效果**：
- 净值从 3.0 降到 1.0，看起来"更便宜"
- 持有人资产总值不变
- 与 [[concepts/净值恐高症]] 直接相关——拆分利用了投资者对净值数字的误解

**注意**：拆分本身不改变基金的投资组合和预期收益，只是份额数量的会计调整。

## 基金复制

复制基金是指基金经理通过购买一篮子股票来跟踪某个指数的表现。这是指数基金的基本运作方式。

**效果**：
- 基金净值与目标指数走势一致
- 费用较低（主动管理费 vs 指数管理费）
- 透明度高（持仓与指数基本一致）

## 两者的区别

| | 拆分 | 复制 |
|---|------|------|
| 目的 | 降低净值表象，吸引投资者 | 跟踪指数，提供被动投资工具 |
| 是否改变净值 | 是（等比降低） | 否（由持仓决定） |
| 是否改变持仓 | 否 | 是（构建指数组合） |
| 投资者注意 | 警惕"净值恐高症"陷阱 | 关注跟踪误差和费率 |
