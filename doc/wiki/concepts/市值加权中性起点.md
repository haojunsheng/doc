# 市值加权中性起点

市值加权中性起点是指以各市场流通市值为权重的全球组合，作为全球资产配置的"中立起点"或"不主动下注"的基准。

## 核心命题

```
市值加权 = 不主动下注 → 反映各市场在全球经济中的真实份额
```

国际机构普遍采用市值加权指数（如 MSCI 世界指数）作为基准，因为市值综合反映了市场表现和全球经济份额。

## 机制

| 维度 | 说明 |
|------|------|
| 为什么是中性 | 不押注任何特定市场，完全跟随各市场在经济中的权重 |
| 为什么用市值 | 市值综合反映市场表现和全球经济份额 |
| 为什么是起点 | 以此为基准可以识别自身的主动偏离，从而判断风险来源 |

## 与主动偏离的关系

[[偏离标准组合=主动表态]] 是对本概念的操作化延伸：中性配置不表态，任何偏离都是主动表达投资观点。

```
中性配置（市值加权基准）: 不表态
偏离基准: 主动表态 → 超额收益 or 额外亏损
```

## 边界条件

- 市值加权反映的是**过去和当前的**经济权重，不代表未来表现
- 对偏离的资产没有深入认知的投资者，偏离更多是赌博而非投资
- 市值加权本身可能被被动资金流入（ETF化）自我强化，导致偏离的边际成本越来越高

## 与现有 wiki 的连接

- 与 [[全球配置范式转变]] 互补：前者讨论"往哪里走"（方向），后者讨论"怎么起步"（起点）
- 与 [[债券稳定器]] 关联：债券在全球组合中长期占40%-60%，是本概念的重要组成部分
- 与 [[MSCI金龙指数-伪分散典型案例]] 相关：金龙指数的伪分散暴露了偏离市值加权的风险

# 全球配置历史范式变迁

全球配置的股债黄金配比在不同时代剧烈变化，所谓"标准组合"是动态快照而非永恒答案。

## 核心命题

```
标准组合是时代快照，非永恒答案
历史规律不保证未来重复
```

## 历史数据

| 时代 | 股票 | 债券 | 黄金 | 背景 |
|------|------|------|------|------|
| 70-80年代 | ~50% | ~30% | ~20% | 高通胀，黄金避险需求 |
| 90年代末 | ~60% | ~40% | <5% | 科技泡沫，股票主导 |
| 危机后（2008后） | ~40% | ~60% | <10% | 避险需求，债券为主 |
| 当前 | ~60% | ~40% | <10% | 回至股60债40 |

## 关键洞察

**"最优配置"因时代而异**，资产相对价值持续变动，没有任何一种配比能长期维持最优状态。

当前股60债40的组合结构只是当下的快照，不代表未来也会如此。

## 边界条件

- 历史规律不保证未来重复
- 当前比例只是当下的快照，不代表未来
- 极端环境（如高通胀时期）可能导致组合结构根本性重构

## 与现有 wiki 的连接

- [[黄金保险定位框架]] 补充了黄金在全组合中的约束（占比<10%），与本概念中黄金比例历史变化形成互补
- [[债券稳定器]] 讨论了债券在全球组合中40%-60%的长期占比，是范式变迁中相对稳定的锚点
- [[全球配置范式转变]] 从预期回报角度解释范式变迁的方向性，本概念从历史数据角度描述变迁本身
