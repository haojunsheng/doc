# 美股估值分化框架

美股整体估值合理，但科技板块与其他板块之间存在显著分化。不能以"美股整体"来判断买入时机，必须深入板块层面。

## 核心判断

| 维度 | 判断 |
|------|------|
| 美股整体 | 估值合理，经历2023年上涨后不如之前便宜但未高估 |
| 科技板块 | 目前最贵板块之一，需警惕估值风险 |
| 其他板块 | 仍有估值空间 |

## 分析方法

晨星使用**股价/公平价值比率**（Price-to-Fair Value Ratio）衡量估值水平，而非简单的市盈率（P/E）或市净率（P/B）。这种方法更能反映资产内在价值与市场价格之间的关系。

## 投资决策含义

1. **不笼统买入"美股"**：整体合理≠可以全仓，板块异质性是关键
2. **科技股需警惕**：估值偏贵意味着后续涨幅空间受限，回调风险更大
3. **其他板块存在机会**：非科技板块估值仍合理，可作为配置补充

## 边界条件

- 若美联储进入降息周期，整体估值中枢可能上移，当前偏贵的科技股压力缓解
- 若AI主题降温或七雄业绩不及预期，科技板块估值承压，可能引发大幅回调
