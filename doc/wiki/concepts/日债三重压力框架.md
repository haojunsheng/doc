# 日债三重压力框架

分析资源进口型经济体主权债配置价值的三因素框架：**输入性通胀 + 财政扩张 + 央行偏紧立场**，任一因素恶化都会压缩主权债配置空间。

## 核心公式

```
日债配置价值 = f(油价, 财政路径, 央行政策立场)
           ↓
当三者均不利时：
油价↑ + 财政扩张 + 央行偏紧 → 三重压力 → 配置价值下降
```

## 三因素详解

### 1. 输入性通胀

```
油价↑ → 能源进口成本↑ → 国内通胀↑ → 实际收益率受压
```

日本是能源净进口国，油价上涨直接推升国内通胀，压缩实际收益率。通胀上行又倒逼央行维持偏紧立场，形成负反馈循环。

### 2. 财政扩张

```
大规模财政刺激 → 债务负担↑ → 信用风险溢价↑ → 收益率上行压力
```

财政扩张加重政府债务负担，市场对主权信用风险重新定价，需要更高的收益率补偿。

### 3. 央行偏紧立场

```
通胀↑ → 央行维持偏紧 → 降息无望 → 债券价格承压
```

日本央行在输入性通胀背景下短期维持偏紧政策立场，降息无望，进一步压制债券配置价值。

## 判断标准

| 信号 | 含义 |
|------|------|
| 10Y收益率升至数十年高位 | 表面看已上行，但需判断是否"足够" |
| 收益率上行幅度 < 风险补偿要求 | 三重压力尚未被充分定价 → 回避 |
| 油价回落或央行意外转向宽松 | 三重压力缓解 → 价值重升 |

## 与其他主权债的对比

| 国家 | 输入性通胀 | 财政扩张 | 央行立场 | 综合判断 |
|------|-----------|---------|---------|---------|
| 日本 | 强（能源进口） | 有压力 | 偏紧 | ↓ 中性 |
| 英国 | 弱（能源进口依赖低） | 有中短期压力 | 灵活 | ↑ 有吸引力 |
| 美国 | 中度 | 有压力 | 取决于通胀 | 分化 |

## 边界条件

- 若油价快速回落 → 输入性通胀压力缓解 → 日债价值重升
- 若日本央行意外转向宽松 → 三重压力解除 → 配置价值恢复
- 若油价冲击持续时间超预期 → 三重压力持续 → 日债继续承压

## 应用扩展

该框架可迁移至其他资源进口型经济体的主权债分析，如韩国、印度等能源净进口国。
