# NPS推荐度衡量投顾体验

晨星战略顾问陈鹏提出的投顾体验衡量标准：客户是否愿意推荐投顾服务给亲友，以及是否已向大部分亲友推荐。

## 核心判断

```
投顾体验好 = 愿意推荐(是) + 已推荐多数(是)
```

## 两个判定标准

1. **愿意推荐**: 客户主观上认为投顾服务有价值，愿意推荐给亲朋好友
2. **已推荐多数**: 客户已经实际向大部分朋友亲人推介该投顾服务

两个"是"直接证明投顾体验好。

## 形式化逻辑

```
投顾体验好 → 客户认可价值 → 愿意推荐给亲友
投顾体验好 → 客户认可程度高 → 已主动向多数亲友推荐
```

## 边界条件

若客户推荐是出于奖励机制（如推荐返利）而非真实体验，指标会失真。因此需要区分"自愿推荐"与"激励驱动推荐"。

## 与买方投顾的关系

买方投顾模式下，客户体验是核心指标。NPS推荐度衡量提供了一个简洁可操作的验证方式，直接反映投顾是否真正以客户为中心。
