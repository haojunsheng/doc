# 公用事业AI电力需求泡沫

## 定义

公用事业板块是当前美股唯一估值泡沫加剧的板块。市场将AI对电力的需求增长预期过度定价，即使需求真的增长，价格可能已经提前反映。

## 核心逻辑

```
AI算力需求 → 数据中心用电增加 → 公用事业需求增长预期
                                                    ↓
                        市场过度定价未来增长 → 估值泡沫加剧
```

## 关键判断

- **唯一泡沫加剧板块**：晨星明确点名的少数风险板块之一
- **叙事驱动**：AI电力需求是真实趋势，但当前定价已过度反映
- **即使需求增长也可能亏钱**：价格已提前透支未来数年增长

## 与[[估值隐含过度乐观预期]]的关系

公用事业板块是"估值隐含过度乐观预期"的典型场景——一个真实且长期的结构性趋势（AI电力需求），被市场在当前时点过度定价，形成泡沫。

## 边界条件

- 如果AI电力需求增长远超预期，当前定价可能反而显得合理
- 需要跟踪实际数据中心用电数据与估值的匹配度
