# Agent = LLM + 上下文 + 工具

## 定义

这是全书的核心公式，将 AI Agent 系统拆解为三个独立且必要要素：

| 要素 | 直觉类比 | 学术对应 | 工程职责 |
|------|---------|---------|---------|
| LLM | 大脑 | Policy | 决策、推理、规划 |
| 上下文 | 眼睛 | 观察空间 | 传递信息、维持状态、限制视野 |
| 工具 | 手脚 | 动作空间 | 执行动作、改变环境、获取外部信息 |

## 三层含义

### 实现层
- LLM = 模型调用（API/本地部署）
- 上下文 = 消息列表（messages array）
- 工具 = function calling / tool use 接口

### 直觉层
- 大脑负责想（推理、判断）
- 眼睛负责看（感知、信息输入）
- 手脚负责做（执行、输出）

### 学术层
- Policy π(a|s) 映射观察空间到动作空间
- 上下文工程本质是在设计观察空间的呈现方式
- 工具设计本质是在设计动作空间的可达集合

## 与五层架构的关系

[[Agent五层架构]] 将 Agent 拆成五个功能层，本公式是更简洁的全局锚点——五层架构中的记忆层和感知层可以归入"上下文"范畴，行动层归入"工具"范畴。

## 关键推论

- **上下文就是消息列表**：一切上下文技术都是在操作这个消息列表，理解 KV Cache 原理是基本功
- **工具设计即动作空间设计**：工具的好坏 = 动作空间的质量
- **模型能力固定时，上下文工程是第一杠杆**：同一模型，只改上下文设计就能拉开表现差距
- **公式有真实缺口**：评估、记忆、多 Agent 不在三项之内——引出 [[动态Agent公式]]
