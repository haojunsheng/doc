# 现金拖累

现金拖累（Cash Drag）是指指数基金必须保留 3%–5% 现金应对赎回，导致这部分资金无法跟随市场上涨，从而拖累整体收益的现象。

## 形式化

```
现金拖累 ≈ 现金比例 × 市场年化回报

例：5% 现金 + 8% 年化回报 → 每年少赚 0.4%
```

## 复利放大效应

```
年化差距 0.4%，30 年复利 → 累计差距超过 10%
```

这 10% 不是"损失"，而是"少赚的钱"。

## 双向性（重要边界）

现金拖累不能简单说"坏事"：

| 市场环境 | 现金的作用 |
|---------|----------|
| 牛市 | 拖累收益（钱不在场） |
| 熊市 | 提供保护（钱没亏） |

这是一个权衡，而非单向成本。

## 与中国市场的关联

- 中国指数基金的现金比例通常较低（监管要求预留一定比例应对赎回）
- 定投场景下，现金拖累的影响更小——因为现金流是持续的，基金持仓更接近满仓
- 一次性大额买入时，现金拖累更明显

## 与再平衡的关系

现金拖累与 [[concepts/再平衡]] 存在张力：再平衡会将资产从超配方向调回目标比例，产生交易成本；而保留现金是为了应对赎回，两者都是"非完美跟踪"的成因。
