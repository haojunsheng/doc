# 阶梯化薪酬调节

《基金管理公司绩效考核管理指引》（2026版）中针对主动权益基金经理的不对称薪酬奖惩机制：业绩不达标时刚性降薪，业绩达标时适度奖励。

## 制度设计

**触发条件**：三年累计业绩 < 基准(-10%) 且 公司利润为负

**惩罚力度**：基金经理绩效薪酬降幅 ≥ 30%

**奖励规则**：业绩 > 基准 且 利润为正时，薪酬可适度上调

```
业绩 < 基准(-10%) + 利润率(-) → 薪酬↓≥30%
业绩 > 基准  + 利润率(+)       → 薪酬可↑
```

## 设计特点

- **不对称性**：惩罚幅度（≥30%）远大于奖励幅度，体现"重罚轻奖"原则
- **双重约束**：同时看相对业绩（跑输基准）和绝对业绩（利润为负），避免单一指标的误判
- **周期视角**：以三年为考核窗口，抑制短期博弈

## 与浮动费率的对比

| 维度 | 阶梯化薪酬调节 | [[浮动费率]] |
|------|-------------|------------|
| 作用对象 | 基金经理薪酬 | 基金产品费率 |
| 作用层级 | 机构薪酬制度 | 产品收费结构 |
| 触发条件 | 三年累计跑输基准>10%且利润为负 | 持有期相对基准表现 |
| 不对称性 | 重罚轻奖 | 双向浮动（但中间档占61%） |

## 与降低考核难度的关系

新规则明确禁止基准调整作为降难度手段，是对 [[降低考核难度]] 的直接回应。阶梯化薪酬通过业绩-薪酬硬绑定，堵死了通过调基准来规避惩罚的路径。

## 边界条件

- 若市场整体下行导致几乎所有基金跑输基准，此规则可能一刀切误伤优秀基金经理
- 惩罚刚性可能导致基金经理在熊市中过度保守，错失反弹机会
