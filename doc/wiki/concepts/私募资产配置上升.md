# 私募资产配置上升

私募资产在机构组合中的占比已达 20% 且持续上升，成为机构减持美国公开市场后的主要资金去向之一，其价值在于提高组合多元化与长期回报，但代价是流动性差和估值不透明。

## 核心形式化

```
私募资产: 未上市股权+债券 → 提高多元化 + 提高长期回报
配置占比: 全球20% ↑ 预计+2pp/5年 | 欧洲21.4% > 亚太20.3% > 北美19.0%
```

## 数据锚点

- 全球机构私募资产平均配置比例已达 **20%**
- 欧洲机构配置比例最高（**21.4%**）
- 多数机构预计未来五年目标配置再上升约 **2 个百分点**
- Pitchbook 数据支持全球私募市场持续增长

## 与减持美国的关联

[[全球机构减持美国配置]] 调查发现，机构减持美国并非回归本土，而是转向私募资产 + 非美多元配置。仅 9-11% 的机构选择"聚焦本国资产"。

## 代价与边界

1. **流动性差**：私募资产锁定期长，无法随时变现
2. **估值不透明**：缺乏公开市场价格，NAV 滞后或主观
3. **J 曲线效应**：早期年份可能呈现负回报
4. **不适用于短期投资者**：需要较长的投资周期才能兑现溢价

## 与分散化的关系

私募资产与公开市场相关性较低，理论上能改善组合的风险-回报特征，这与 [[分散化有效性条件]] 中"低相关性资产是有效分散的前提"相呼应。但分散化的代价——流动性折价、信息不对称——在私募领域更为显著。
