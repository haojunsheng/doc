# 保本幻觉

## 定义

**保本幻觉**是指投资者因"保本"二字产生的虚假安全感——将产品名称或营销话术中的"保本"理解为本金不受损失，而忽略了底层风险依然存在。这是刚性兑付时代遗留的认知偏差，在资管新规后仍未完全消散。

## 公式

```
保本幻觉 = 刚性兑付 × 资金池运作 × 风险隐藏 × 系统性积累
```

## 核心特征

1. **语言误导**："保"=保证，"本"=根本——中文比英文"capital preservation"更具确定性暗示
2. **风险转移**：风险并未消失，只是从投资者转移到发行机构，再转移到整个金融系统
3. **期限错配**：用短期资金支撑长期资产，流动性风险持续累积
4. **公平性扭曲**：盈利者拿走超额收益，亏损者由后来者兜底

## 历史脉络

| 时期 | 特征 |
|------|------|
| 2018 年前 | 银行理财普遍承诺"保本保息"，资管新规前形成广泛认知惯性 |
| 2018 年 | 《资管新规》明确打破刚性兑付，"预期收益率"被"业绩比较基准"取代 |
| 2018 年后 | 净值化管理常态化，但"保本"语言惯性仍存在于部分营销话术 |

## 与相关概念的关系

- [[刚性兑付]]：保本幻觉的制度基础，两者互为表里
- [[底层资产决定风险]]：打破保本幻觉后，判断风险的正确路径
- [[净值化管理]]：打破保本幻觉的技术手段，通过每日净值披露让风险显性化
- [[业绩比较基准]]：替代"预期收益率"的合规术语，但投资者仍常误读为承诺

## 深层结构

保本幻觉的存在论根源：人类对确定性的深层渴望。在一个充满不确定性的世界里，"保本"承诺是一种心理安慰剂。金融的本质是风险与收益的交换，消除保本幻觉，就是**接受不确定性作为存在的底色**。

> 不确定的确定性，比确定的不确定性更安全。

## 行为后果

- 投资者忽视底层资产分析，只看产品名称或历史业绩
- 风险从个体投资者转移到整个金融系统，形成系统性风险
- 打破刚兑后，部分投资者产生"净值恐高症"，难以接受正常波动
