# 稳定的平庸 vs 波动的优秀

## 核心公式

```
实际收益 = 产品收益 × 持有行为
持有行为 = f(波动承受力)
```

这个公式揭示了一个关键机制：投资者最终拿到手的收益，不仅取决于产品本身赚了多少，还取决于投资者能否"拿得住"。

## 定义

**稳定的平庸**：波动低、回撤小、收益一般，但投资者能长期持有的策略（如宽基指数基金）。

**波动的优秀**：波动高、回撤深、潜在收益大，但投资者难以承受而中途卖出的策略（如高波动主动基金、行业主题基金）。

## 核心洞见

> 能拿住的稳定平庸策略，实际收益 > 拿不住的波动优秀策略。

这不是说"平庸策略更好"，而是说**持有行为本身调制了最终收益**。波动的产品会触发人类的损失厌恶和近因效应，导致投资者在低点卖出——这就是 [[追涨杀跌损益侵蚀]] 的微观机制。

## 实证支撑

- 晨星数据：被动基金投资者实际收益 > 主动基金投资者实际收益，即使主动基金的产品收益率更高
- [[投资者回报差距]] 的根源之一：高波动产品放大了投资者的行为偏差
- [[香农的魔鬼]] 实验：定期再平衡将零预期收益组合的几何收益率从 0 提升为正数——说明"机械纪律"可以在不依赖预测的情况下改善持有体验

## 边界条件

| 条件 | 适用策略 |
|------|---------|
| 资金量充足，能承受 50% 回撤 | 波动的优秀可能更优 |
| 投资者缺乏耐心，易受情绪干扰 | 稳定的平庸显著更优 |
| 有明确资产配置目标 + 再平衡纪律 | 稳定平庸 + 机械再平衡 = 最优组合 |
