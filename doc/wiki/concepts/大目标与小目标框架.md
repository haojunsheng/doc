# 大目标与小目标框架

Jordan Grumet 提出的目标分类框架，区分"大目标"（结果导向、非此即彼）和"小目标"（过程导向、日常嵌入）两种类型，解释为什么前者导致焦虑而后者带来持续满足。

## 框架来源

Jordan Grumet 区分了"大目标"和"小目标"，指出真正带来幸福的是后者。

## 大目标 vs 小目标 对比矩阵

| 维度 | 大目标 | 小目标 |
|------|--------|--------|
| 导向 | 结果导向 | 过程导向 |
| 性质 | 非此即彼（达成/未达成） | 持续进行（做/不做） |
| 满足感来源 | "我做成了" | "我在做" |
| 依赖条件 | 外在成就（房子、职位、收入） | 内在驱动（兴趣、习惯） |
| 享乐适应 | 强烈——达成后快感迅速消退 | 弱——持续性体验不断 replenish |
| 社交信号 | "我拥有什么" → 吸引功利性关系 | "我是谁" → 吸引同频关系 |
| 焦虑机制 | 未达成则长期焦虑 | 无明确终点，焦虑较低 |

## 形式化表达

> **大目标** = 结果导向 + 非此即彼 + 享乐适应 → 达到后快感短暂，没达到则长期焦虑
>
> **小目标** = 过程导向 + 日常嵌入 + 内在驱动 → 满足感持续、不依赖外在条件

## 核心论断

1. **大目标的陷阱**：一旦没达到就会产生强烈的挫败感——而达到后满足感也会迅速消退（享乐适应）。
2. **小目标的优势**：不依赖外在成就，嵌入日常，满足感来自"我在做"而非"我做成了"。
3. **真实性展示**：小目标展示"我是谁"（兴趣、价值观、热情），大目标展示"我拥有什么"（房子、职位、收入）；前者更易吸引深度连接。

## 边界条件

- 大目标若为自我驱动而非社会强加，焦虑感显著降低
- 小目标若完全脱离长期方向（如每天刷短视频），就变成了逃避而非享受
- 健康/关系类持续性目标的享乐适应影响减弱

## 与投资的关系

该框架可用于反思投资目标设定：
- **大目标式投资**："每年跑赢沪深300"、"三年翻倍" → 结果导向、非此即彼，易导致追涨杀跌
- **小目标式投资**："每月定投、保持在场"、"年化控制回撤<15%" → 过程导向、日常嵌入，更易坚持
