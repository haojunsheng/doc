# 收储机制

## 定义

收储机制是指**政府或央行收购存量住房并转为保障性住房**的政策工具，用于消化房地产市场过剩库存、缓解开发商资金压力、同时补充保障房供给。

## 核心数据

- 央行已批准收储贷款**超 2.2 万亿元**
- 资金拨付进度是决定库存消化速度的关键变量
- 2024 年下半年政策加码后，专项债收购存量房规模显著扩大

## 作用机制

```
央行批准收储贷款 → 地方政府/国企收购存量新房 → 转为保障房
  → 开发商库存去化 → 现金流改善 → 土地市场回暖预期
  → 供需再平衡 → 价格企稳
```

## 与新房-二手房分化的关系

收储针对的是**新房库存**（开发商持有意），对二手房市场的直接影响有限。这强化了新房供给侧的"可控性"——政府可通过收储加速去化，而二手房供给仍由业主分散决策主导。

## 边界条件

- 若收储拨付节奏慢于预期，库存消化将持续到 2026 年
- 若开发商不愿大幅打折，收储规模可能受限于资产估值分歧
- 若销售反弹超预期，收储优先级可能下降

## 触底判断中的位置

晨星以 2025 年年中作为新房价格触底基准，核心假设之一是收储政策累积效应逐步显现。若拨付进度不及预期，触底时点可能延后。
