# 高收益债

## 定义

高收益债（High-Yield Bond），又称垃圾债，是指信用评级低于 BBB- 的债券。投资者以承担更高的信用风险为代价，换取比投资级债券更高的票息收益。

## 收益结构

```
高收益债收益 = 无风险利率 + 信用利差（信用风险溢价）
```

收益由两部分构成：基准利率和补偿违约风险的信用利差。信用利差收窄时，高收益债价格涨幅更大。

## 亚洲高收益债市场结构

```
亚洲高收益债 = 中国地产债（高权重） + 东南亚企业债 + 其他亚洲国家企业债
```

- 中国房地产企业在亚洲高收益债市场中占比较大
- 2021年以来中国地产行业下行对整体市场冲击显著
- 东南亚国家（印尼、印度等）企业债是重要组成部分
- 市场表现与中国地产行业高度绑定

## 风险排序

```
高收益债风险 = 信用风险（违约概率↑） > 利率风险 > 流动性风险
```

### 信用风险
高收益债的违约概率显著高于投资级债券，经济下行时违约率上升，信用利差扩大。参见[[concepts/高收益债违约风险]]。

### 利率风险
利率变动影响债券价格，但高收益债由于信用风险为主导，利率敏感性相对投资级债券较低。

### 流动性风险
高收益债流动性通常较差，大额赎回可能冲击净值。参见[[concepts/机构占比与赎回风险]]。

## 适用场景

在低利率环境下，高收益债基金对追求收益的投资者具有吸引力。但需做好信用研究和风险分散，不适合风险厌恶型投资者。
