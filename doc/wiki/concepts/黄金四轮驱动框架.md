# 黄金四轮驱动框架

**黄金四轮驱动框架**是解释黄金过去50年涨约100倍的底层推力机制：美元脱钩、全球宽松、去美元化、央行持续增持。四重力量共同推动金价长期上行，但也意味着每轮驱动力都有各自的边界条件。

## 四轮驱动结构

```
1971年美元脱钩 → 十年上涨周期
2008金融危机 + 美联储宽松 + 美国负债率攀升 → 金价上行
去美元化 + 全球央行增持（中国2022-2025年合计444吨）→ 新一轮上行
2025年保险资金入场 → 新增需求源
```

### 第一轮：美元与黄金脱钩（1971年起）

尼克松宣布美元与黄金脱钩后，金价迎来第一个十年上涨周期。脱离金本位约束使黄金价格完全由市场供需和货币信用决定。

**边界**：若美元信用重新走强（如美国财政纪律恢复），此轮驱动力减弱。

### 第二轮：全球宽松周期（2008年起）

2008年金融危机后，美联储量化宽松+美国负债率攀升+去美元化叙事叠加，推动金价进入新一轮上行。

**边界**：若美联储收紧货币政策或美国财政纪律改善，驱动力减弱。

### 第三轮：去美元化 + 央行增持

全球央行（尤其新兴市场）持续增持黄金对冲国际风险，推动人民币国际化背景下中国央行连续四年增持：2022-2025年分别增持62.21 / 224.88 / 44.17 / 12.75吨，合计444吨。

**边界**：若人民币国际化超预期进展，黄金需求增速可能放缓。

### 第四轮：保险资金入场（2025年起）

2025年保险资金获准投资黄金，为黄金需求侧注入新的结构性力量，同时推动黄金ETF交易量爆发（2025年前5个月日均成交额超2020年全年）。

## 形式化表达

```
黄金长期上涨 = f(美元信用侵蚀, 全球流动性, 去美元化, 央行增持, 机构资金入场)

四轮驱动中任一力量弱化 → 金价上行斜率放缓
四轮驱动同时强化 → 金价加速上行
```

## 实践启示

黄金50年涨100倍不是"黄金永远涨"的证明，而是货币信用持续缓慢侵蚀的镜像。配置黄金的理由不是赌它涨，而是让组合在极端情景下有退路。
