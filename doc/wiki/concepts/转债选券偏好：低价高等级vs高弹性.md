# 转债选券偏好：低价高等级 vs 高弹性

## 定义

在固收+策略中，可转债选券偏好是产品定位差异的核心载体之一。同一转债大类下，不同的选券标准导致完全不同的风险收益特征。

## 两种典型范式

| 维度 | 低价高等级范式 | 高弹性范式 |
|------|-------------|----------|
| 代表案例 | 华泰保兴尊合债券 | 光大保德信增利收益债券 |
| 转债仓位中枢 | ~25% | ~30% |
| 选券标准 | 低价 + 高等级 + 偏债型为主 | 按转股溢价率历史分位数择时 |
| 转股溢价率特征 | 偏高（债底保护强） | 动态择时（低估时超配） |
| 正股相关性 | 弱（更像债券） | 较强（更像股票） |
| 熊市表现 | 回撤小，抗跌 | 回撤大，跟跌 |
| 牛市表现 | 弹性不足，跑输 | 弹性大，亮眼 |
| 适用场景 | 震荡市、熊市 | 牛市 |
| 均值回归逻辑 | 债底保护即安全边际 | 溢价率偏离中位数时回归 |

## 形式化表达

```
低价高等级范式：
转债价格低 + 信用等级高 + 转股溢价率高
→ 债底保护强 → 权益暴露实际低 → 熊市抗跌

高弹性范式：
转债分类（高/中/低转股价值） × 转股溢价率历史分位数
→ 分位数 << 50% 超配 / 分位数 >> 50% 低配
→ 均值回归预期 → 牛市弹性大
```

## 与产品定位的关系

[[sources/5-notes--08-20260614T213408--qa-固收加攻守之道-qa]] 展示了"产品定位→转债选券→风险收益"的完整因果链：

- 绝对收益导向 → 转债仓位更低 + 低价高等级偏好 → 低波动
- 相对收益导向 → 转债仓位更高 + 分位数择时 → 高弹性

这与 [[concepts/跑赢基准vs绝对收益]] 的产品层面论述相呼应——基金的产品定位直接决定其转债策略的所有参数。

## 实战案例扩展

除华泰保兴尊合与光大保德信增利之外，[[entities/东方红聚利]]（孔令超管理）是"低价高等级+偏债型"范式的另一典型案例——以平衡型和偏债型转债为主，在2022、2024年震荡市中展现强抗跌性。

[[entities/虞淼]] 管理的[[entities/兴全可转债]] 则偏好TMT、化工、有色等高波动行业发行的转债，属于"高弹性"范式的变体——通过正股高波动+转债债底保护，构建"下有保底、上不封顶"的结构。

参见 [[concepts/偏债型vs偏股型转债]] 对两种转债类型的系统对比。

## 边界条件

- 转债市场大幅扩容（如2020-2021年）可能压缩低价高等级转债的容量，迫使管理人调整选券范围
- 在股债双杀极端行情中，"低价高等级"的债底保护也可能失效
- 分位数策略的有效性依赖历史数据的代表性，结构性变化（如新债大量供给）会削弱其参考价值

## 与估值历史分位法的关系

[[concepts/估值历史分位法]] 是光大保德信选券策略的方法论基础——将转股溢价率置于历史时间序列中判断当前位置。该方法的通用性在于：不仅适用于转债，也适用于股债比较（转债估值 vs 正股估值）。

参见 [[concepts/策略适用场景边界]] 中关于不同选券范式适用市场环境的讨论。
