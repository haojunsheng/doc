# 贝塔收益 vs 阿尔法收益

**贝塔收益（Beta）**：来自市场整体上涨的回报，是"随波逐流"的收益。
**阿尔法收益（Alpha）**：来自超额选股/择时能力的回报，是"战胜市场"的收益。

## 关键区分

A股过去20年年化约 **9%**——这是**贝塔收益**，不是 alpha。这意味着：
- 只要你持有市场，就能拿到这9%
- 不需要选股能力，不需要择时能力
- 这就是指数基金的逻辑基础

## 形式化

```
总回报 = 贝塔收益 + 阿尔法收益

贝塔收益 = 市场平均回报（可被动获得）
阿尔法收益 = 超额回报（需要主动能力，且难以持续）
```

## 与主动-被动困境的关系

[[concepts/主动-被动-结构性困境]] 指出，主动基金追求阿尔法，但大多数跑不赢指数——因为阿尔法本身极难获得，且会被费用侵蚀。

[[concepts/投资者回报差距]] 补充：投资者实际回报差距不仅来自行为代价，也来自**把贝塔当阿尔法**的误解。

## 数据支撑

- A股20年年化9% = 贝塔（市场平均）
- 保持20年年化20% = 神话级别阿尔法（几乎无人能持续）
- [[concepts/费用是复利的反面]]：主动基金的阿尔法追求被费用侵蚀后，多数变成负阿尔法

## 实践启示

1. **先拿贝塔，再追阿尔法**：普通人应先通过指数基金获得市场平均回报
2. **不要高估自己的阿尔法能力**：数据显示绝大多数主动投资者跑不赢指数
3. **区分"幸运"和"能力"**：短期超常回报可能是贝塔红利，而非阿尔法能力
