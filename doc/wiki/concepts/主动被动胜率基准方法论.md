# 主动被动胜率基准方法论

## 核心观点

用**被动基金**而非**指数**作为主动基金的比较基准，更贴近投资者实际可获得的收益参考。

## 为什么用被动基金做基准

1. **投资者实际可买的是指数基金/ETF**，而非无成本的指数本身
2. **指数基金有管理费、跟踪误差等成本**，这些成本会侵蚀收益
3. **用同组被动基金做基准更公平**——晨星美国主动被动晴雨表采用类似方法
4. **反映真实的投资收益对比**，避免用理想化的无成本指数做基准造成偏差

## 形式化表达

```
可投资基准 = 被动基金(有成本) ≠ 指数(无成本)
```

## 边界条件

- 若某被动基金费率极高或跟踪误差大，作为基准会有偏差
- 对于超低费率的ETF（如0.03%），与指数的差异可以忽略不计
