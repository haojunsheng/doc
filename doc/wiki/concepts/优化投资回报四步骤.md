# 优化投资回报四步骤

投资者通过四个系统性步骤提高长期投资回报的方法论框架，由晨星中国提出。核心逻辑是"用闲钱做不着急的投资"。

## 四步框架

```
01 制定理财目标     →  回答"我为什么要投资"，量化目标，纳入风险偏好
02 大类资产配置     →  股债配比，揭示保守策略的隐性风险
03 挑选优质基金     →  区分运气与能力，看重投研团队挖掘能力
04 控制投资成本     →  两类费用分类，赎回费机制引导长期持有
```

## 步骤详解

### 01 制定理财目标

- 量化财务目标（旅行、买房、教育、养老）
- 按时间和重要性排优先级
- 纳入三个限制：风险偏好、流动性需求、投资期限
- 最重要的限制是**风险偏好**：高风险背后是高波动

### 02 大类资产配置

以沪深 300 指数和中证全债指数为基准，计算 2016–2022 年间不同股债配比的滚动收益，揭示风险收益差异。

**保守策略的隐性风险**：
- **机会成本**：放弃更高潜在回报，导致收益过低
- **通胀风险**：收益率跑不赢物价上涨，购买力下降

这是对"低风险 = 安全"直觉的系统性反驳。

### 03 挑选优质基金

**核心命题**：历史业绩≠未来能力。

2019–2020 年牛市期间，绝大多数偏股型基金获得出色超额收益；但近年回调中回撤幅度更大，质疑基金经理选股和风控能力。

晨星研究发现：主动基金的长期稳定超额收益，取决于**基金经理及投研团队对个股和行业挖掘能力**。

**判断三维**：
1. 证券选择能力
2. 风险控制能力
3. 择时能力

**择基如交友**：外在（历史业绩）是交往起点，内在（投研能力、投资流程）才是长期关系决定因素。

### 04 控制投资成本

市场变化难测，但成本是唯一可以把握的变量。

**两类费用**：
- **一次性费用**：申购费、赎回费
- **持有成本**：管理费、托管费、销售服务费、交易费（每日计提）

**赎回费机制设计**：
- 赎回费随持有期递减，达到一定期限后免除
- 赎回费归入基金资产，由剩余持有人享有
- 行为金融学意义：通过机制设计引导长期持有行为

## 核心命题

> "市场变化难测，但成本可以把握。"

四步框架的逻辑终点是**"用闲钱做不着急的投资"**——这是对投资者行为纪律的最高层次约束。
