# 高端化提价

用价格增长对冲销量下滑，维持行业或企业收入增长的战略选择。白酒行业是当前典型样本。

## 核心逻辑

```
销量增长↓ + 价格增长↑ → 收入 CAGR = 3.5%（从 4.2% 下降）
```

当需求端结构性萎缩（人口红利消退、消费习惯变迁），供给端企业通过产品升级、品牌溢价和提价来弥补销量缺口，从而在总量下滑的环境中维持利润增长。

## 边界条件

高端化提价并非无限可行，受以下因素约束：

| 约束因素 | 作用机制 |
|----------|----------|
| 需求价格弹性 | 提价过度会导致销量加速下滑 |
| 反腐政策 | 政务/商务消费受政策压制时，高端提价空间受限 |
| 消费文化变迁 | 年轻一代饮酒意愿下降，品牌溢价基础动摇 |
| 宏观经济 | 经济下行期消费者购买力下降，提价遇阻 |

## 白酒行业的现实

- 高端三家（茅台、五粮液、泸州老窖）占行业 95% 份额，提价能力最强
- 晨星明确指出：**提价能保利润，保不住估值**——利润和估值是两套逻辑
- 茅台出厂价 1169 元仍供不应求，是其提价能力最强的体现，但也只是特例

## 投资启示

高端化提价是企业在需求收缩期的生存策略，但不等于投资机会。判断行业底部需看供需再平衡，而非只看利润表。
