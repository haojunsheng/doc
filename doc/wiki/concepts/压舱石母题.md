# 压舱石母题

贯穿全章的设计哲学：LLM 判断需要模型之外的可靠锚点，以对抗系统性错误。

## 锚点类型

- **代码/解释器**：确定性执行，不可欺骗
- **原始记录**：append-only 的轨迹日志
- **原始上下文**：上下文感知检索保留的完整片段
- **原始证据**：知识更新时的异源互审依据

## 工程体现

**Proposer-Reviewer 机制**：知识更新时，提议者生成候选变更，审核者追溯到原始证据验证——两层 LLM 互相审核，降低共同盲区。

**异源互审**：不同家族模型互相审核，进一步降维系统性风险。

## 母题关联

与 [[隔离优于压缩]] 同源：保留冗余（原始记录）换取可追溯性，用结构对抗 LLM 的不确定性。
