# 热手谬误

认为连续事件后下一事件概率更高的认知偏差。在投资中表现为：看到基金连续上涨就认为还会继续涨，看到连跌就认为还会继续跌。

## 定义

**经典场景**：篮球运动员连续进球后，观众觉得他"手感火热"，下一球更可能进——但实际上每次投篮是独立事件，概率不变。

**投资中的同构表现**：
- 基金连续上涨 → 认为还会涨（线性外推）
- 基金连续下跌 → 认为还会跌（恐慌性抛售）
- 股票连涨三天 → 认为是"强势股"（一根阳线改变情绪，两根改变观念，三根改变信仰）

## 与近因效应的关系

热手谬误和线性外推是同构的——三者共享同一个认知结构：**近期信息被赋予不合理的预测权重**。

```
近因效应（认知偏差）
    ↓
看到连续事件
    ↓
热手谬误（误判概率）
    ↓
线性外推（误判趋势）
    ↓
追涨杀跌行为
```

## 边界条件

- **独立事件**：硬币抛掷、彩票开奖、多数基金的短期涨跌——每次都是独立事件，历史不影响未来
- **非独立事件**：真正的技能表现（如职业运动员的命中率在短期内可能有微小变化）——但即使是这些，"热手"效应的实际存在也备受争议

## 对抗方法

- 认清事件的独立性——大多数投资决策的基础事件是独立的
- 用概率思维替代确定性思维
- 不被短期序列迷惑，拉长时间维度看分布
