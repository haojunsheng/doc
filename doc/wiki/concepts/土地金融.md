# 土地金融

城投公司以土地为抵押撬动银行信贷，将"土地财政"从收入层面加杠杆至融资层面，是中国地方政府投融资体系的核心机制节点。

## 制度背景

法律规定地方政府不能直接贷款，因此城投公司（地方政府融资平台）应运而生。城投以政府注入的土地资产为抵押，从银行获得贷款，用于基础设施建设和产业投资。

## 机制链条

```
土地财政（土地出让收入）
        │
        ▼
城投公司获得土地抵押融资能力
        │
        ▼
土地金融：以土地为抵押撬动信贷
        │
        ▼
基础设施建设 + 产业投资
```

## 与城投债的关系

[[城投债-产业债配置权衡]]中涉及的城投债，本质是地方政府的"隐形债务"。[[土地金融]]解释了城投债产生的制度根源：法律禁止直接贷款 → 城投为载体 → 土地为抵押 → 发债融资。

## 宏观后果

土地金融推动了快速工业化与城市化，但也积累了庞大的地方政府隐性债务，构成财政风险的来源之一。
