# 投资者回报差

基金回报（持有不动）与投资者实际回报（含买卖交易）之差，反映交易行为损耗。

## 定义

$$\text{回报差} = \text{基金回报} - \text{投资者实际回报}$$

- 基金回报：仅计算资产净值变化
- 投资者回报：纳入买入卖出时机、申赎交易成本

## 核心发现（晨星中国，2026）

中国公募基金五年期年化投资者回报差**全部为负**：

| 基金类型 | 回报差 |
|---------|-------|
| 行业基金 | -3.59% |
| 主动股票基金 | -2.65% |
| 积极配置基金 | -2.17% |
| 固收基金 | -0.62% |
| 宽基指数 | +3.00%（唯一正值） |

## 归因

- 回报差差距来自交易行为，而非产品本身
- 宽基指数正回报差反证产品本身并非问题根源
- 中国市场更剧烈：赛道轮动快 + 波动大

## 新规的观测锚点

[[公募绩效考核新规]]将"投资者回报差"缩小作为验证改革效果的核心指标之一。新规要求基金公司关注盈利投资者占比，倒逼行业从"规模导向"转向"投资者真实盈利导向"。投资者可通过以下三个维度验证新规效果：投资者回报差↓ + 基金经理换手率↓ + 规模健康增长（非暴增暴减）。预计需3-5年才能充分验证。

## 边界条件

- 如果投资者完全不择时（买入持有），差值归零
- 当宽基指数被当作短期炒作工具（如频繁申赎 ETF）时，正差值消失
