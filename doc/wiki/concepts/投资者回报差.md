# 投资者回报差

基金回报（持有不动）与投资者实际回报（含买卖交易）之差，反映交易行为损耗。

## 定义

$$\text{回报差} = \text{基金回报} - \text{投资者实际回报}$$

- 基金回报：仅计算资产净值变化
- 投资者回报：纳入买入卖出时机、申赎交易成本

## 核心发现（晨星中国，2026）

中国公募基金五年期年化投资者回报差**全部为负**：

| 基金类型 | 回报差 |
|---------|-------|
| 行业基金 | -3.59% |
| 主动股票基金 | -2.65% |
| 积极配置基金 | -2.17% |
| 固收基金 | -0.62% |
| 宽基指数 | +3.00%（唯一正值） |

## 归因

- 回报差差距来自交易行为，而非产品本身
- 宽基指数正回报差反证产品本身并非问题根源
- 中国市场更剧烈：赛道轮动快 + 波动大

## 边界条件

- 如果投资者完全不择时（买入持有），差值归零
- 当宽基指数被当作短期炒作工具（如频繁申赎 ETF）时，正差值消失
