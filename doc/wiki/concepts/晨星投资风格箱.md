# 晨星投资风格箱（Morningstar Style Box）

## 定义

一个 3×3 九宫格矩阵，用**市值规模**（大/中/小盘）和**价值-成长风格**（价值/平衡/成长）两个维度，将基金的投资风格定位到九个格子之一。本质是基金的"风格指纹"读取器。

## 计算逻辑

### 横轴：价值-成长分值（VCG）

- 用 **10因子模型**（价值5因子 + 成长5因子）分别计算价值分值和成长分值
- 每个因子在**对比组内**按大小顺序赋予百分制分值，再结合权重计算综合分值
- **VCG = 成长分值 − 价值分值**，标准化后得到 Raw X，决定九宫格横坐标
- 对比组由股票所处风格区和市值大小决定（如A股大盘股与亚洲不含日本的大盘股对比），确保分类的**相对性**

### 纵轴：市值规模（70/90/10 规则）

| 分区 | 市值累计占比 |
|------|------------|
| 大盘 | 前 70% |
| 中盘 | 70%–90% |
| 小盘 | 后 10% |

动态调整，随市场变化自适应，非固定绝对阈值。

### 纵坐标（Raw Y）

- 用股票市值的自然对数衡量规模，标准化后得到纵坐标
- 中盘股分值控制在100至200之间

### 基金风格确定

- 基金投资风格 = 持仓股票的**资产加权平均**风格
- 由于基金持仓通常分散，极少持有极端VCG股票，导致分值聚集在X轴中间
- 晨星对划分规则做了**防聚集调整**，避免过多基金都标记为"平衡"风格

### A股市值结构与主流指数重合度

截至2023年6月30日，A股市场：**小盘占47%**、中盘41%、大盘仅12%。主流规模指数成分股与风格箱的映射：

| 指数 | 成分股风格箱映射 |
|------|----------------|
| 中证100 / 沪深300 | 100% 大盘 |
| 中证500 | 55% 中盘 + 44% 大盘 |
| 中证1000 | 94% 中盘 + 2% 小盘 |

整体重合度较高。

## 核心用途

1. **降维**：把海量基金压缩到 9 个格子，降低选择焦虑
2. **去伪**：用实际持仓戳破基金名称的伪装（"XX 价值基金"可能全仓成长股）
3. **校准**：检查组合是否真分散——若所有基金挤在同一格，即为伪分散
4. **识别风格漂移**：与[[晨星基金分类]]对比，发现基金经理是否偏离合同约定的投资方向

## 设计初衷

与[[晨星星级评价]]配套使用。只有把风格相似的基金放在一起比较，星级才有意义。同一分类内，星级反映基金经理的投管能力，而非市场环境——剥离风格噪音，看真实 alpha。

## 应用价值

### 客观评估基金经理能力

市场风格切换难以预测，契合市场风格时业绩好，相悖时业绩差。晨星按投资风格分类，剔除短期市场风格干扰，让星级评价更多反映基金经理的真实投管能力，而非市场环境。

### 筛选基金与资产配置

帮助识别基金真实投资风格，解决"名不副实"问题；避免构建的组合风格集中于单一方向，实现真正的分散化配置。

## 与基金分类的时间差关系

[[晨星基金分类]]基于过去三年平均得分，体现基金历史的"类别归属"；[[晨星投资风格箱]]基于当前持仓，体现"当前风格定位"。两者不一致 = **风格漂移信号**。

- 分类稳定，风格箱突变 → 基金经理近期主动调仓
- 分类与风格箱长期背离 → 需警惕该基金是否在"名不副实"
- 同一基金在不同时期的分类与风格箱对比，是判断风格漂移的最直接方法

参见 [[风格漂移]]。

## 九种格子的典型风险收益特征

> 以下描述来自晨星 QA 补充（[2026-06-14 QA](notes/20260614T115950--qa-九宫格风格箱选基__qa.md)），是对本工具的核心补充。

| 格子 | 典型特征 |
|------|---------|
| 大盘价值 | 蓝筹股，波动小，分红高 |
| 大盘成长 | 白马股，业绩稳定增长 |
| 中盘价值 | 介于大盘和小盘之间，估值合理 |
| 中盘成长 | 成长性较好，弹性适中 |
| 小盘价值 | 被低估的小公司，弹性大风险也大 |
| 小盘成长 | 高成长潜力的小公司，波动最大 |
| 平衡类三格 | 价值与成长均衡配置，风格中性 |

**重要认知**：九宫格是**静态分类**，现实中很多基金的风格会漂移，不会一直待在某个格子里。参见 [[风格漂移]]。

## 与风格跷跷板的关系

[[风格跷跷板]]描述风格的周期性轮动，风格箱提供当前风格的静态定位——两者结合可形成完整的风格分析框架：风格箱告诉你"现在在哪里"，风格跷跷板告诉你"接下来可能往哪走"。

## 局限

- 后视镜性质：反映历史持仓，不保证未来不变
- 无法单次捕捉风格漂移，需持续监控
- 隐含假设风格是二元对立，现实中许多基金处于灰色地带
- 原始加权平均与最终风格标签之间存在人为修正（防聚集调整），修正幅度与标准未公开说明
- **动态调整滞后风险**：当A股市场结构发生根本变化时，分界点的自适应调整可能有滞后，造成风格定位失真
