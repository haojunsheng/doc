# 激励结构先于政策判断

面对任何政策或经济现象，先问"激励结构是什么"，再判断"该不该干预"。这是《置身事内》方法论的核心提炼。

## 核心命题

主流分析框架的问题在于把"政府"当作外生变量，只评估干预的好坏。正确顺序是：

```
现象
  → 激励结构（谁在决策？激励是什么？资源从哪里来？）
  → 资源配置流向（必然结果）
  → 政策判断（在理解因果链的基础上评价）
```

跳过第一步直接做规范性判断，会得出错误或片面的结论。

## 典型误判示例

| 现象 | 误判（跳过激励分析） | 正确路径（先看激励） |
|------|------------------|------------------|
| 地方债高企 | "财政纪律松弛" | 城投债以土地为抵押，偿还来源是未来土地增值——是一套有内在逻辑的融资体系 |
| 房价高涨 | "炒房客推高房价" | 商住用地高价出让是土地财政的核心收入来源，激励地方政府控制住宅用地供给 |
| 产业补贴 | "政府扭曲市场" | 地方政府是投资者而非单纯补贴者，京东方合肥案例中政府直接股权投资 |
| 各地建工业园 | "重复建设浪费资源" | 工业税源是地方核心利益，低价工业用地是有竞争力的招商工具 |

## 与相关概念的关系

- **[[f(x) 观察顺序重构]]**：这是该方法论的形式化表述。
- **[[生产型政府]]**：激励结构的结果——政府不仅是规则制定者，还是直接参与者。
- **[[土地财政]]**：激励结构的产物——分税制后地方预算内财力缩水，催生替代性财源需求。

## 适用范围

这个分析顺序不仅适用于中国经济，也适用于任何制度环境下的政策分析——关键在于找到决策主体的激励函数和资源约束，而不是直接套用规范性标准。
