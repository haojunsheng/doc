# 产能周期触发机制

## 定义

解释为什么产能会超调——从需求变化到产能调整之间的**时滞**，是产能周期形成的微观基础。

## 企业家调产能的逻辑链

```
需求提升
    │
    ▼
先满负荷生产（现有产能利用率→100%）
    │
    ▼
确认是长期需求才扩产能（因为投产能是真金白银）
    │
    ▼
调整时滞 → 系统性超调 → 产能周期
```

关键：**产能调整有滞后性**。当企业家确认需求是"长期"的，往往已经过度乐观——因为等他们投了产能，市场可能已经饱和。

## 产能利用率公式

```
产能利用率 = 实际产量 ÷ 最大产能
```

- 供不应求：产能利用率接近100%，毛利率最高
- 产能激增：产能利用率下降，价格战开始
- 产能出清：弱者退出，利用率回升
- 格局改善：龙头利润修复

## 与宏观因素的关系

| 宏观因素 | 对产能周期的影响方向 |
|---------|-------------------|
| 经济下行 | 加速出清，集中度上升 |
| 经济上行 | 延缓出清，集中度下降 |
| 刺激需求政策 | 延缓出清，集中度下降 |
| 限制供给政策 | 加速出清，集中度上升（供给侧改革、双碳） |

## 与[[产能周期四阶段]]的关系

本概念解释的是"为什么会有四阶段"——时滞导致了超调。[[产能周期四阶段]]描述的是"四阶段分别是什么"——供不应求→激增→出清→格局改善。两者互为补充：一个讲因果，一个讲表现。
