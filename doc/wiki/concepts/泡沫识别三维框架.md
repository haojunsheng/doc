# 泡沫识别三维框架

泡沫识别的核心方法论：通过**估值 + 市场情绪 + 资金流入**三个维度综合判断，而非依赖单一指标。

## 三维框架

```
泡沫 = 估值远超历史均值 + 市场情绪极度乐观 + 资金大量涌入
```

### 维度一：估值

- 标普 500 历史平均 P/E 约 15–17 倍。
- P/E 远超历史均值（2–3 倍以上）→ 警惕信号。
- 边界：周期性行业（能源、金融）不适用——盈利低谷时 P/E 自然偏高。

### 维度二：市场情绪

- 所有利好已被定价 → 没有剩余买家 → 价格只能跌。
- 指标：媒体报道热度、散户参与度（出租车司机/退休大妈入场）、社交讨论密度。
- 边界：情绪是先行指标，非精确指标；泡沫可能在情绪过热后仍持续数月。

### 维度三：资金流入

- 指标：杠杆率上升、融资余额创新高、新开户数暴增、新基金发行量激增。
- 逻辑：投机资金涌入 = 后续买家减少 = 泡沫临近。

## 核心原则

**不预测何时破裂，只判断是否太贵。**

这与 [[市场预测的不可靠性]] 完全一致：不做单点时间预测，做维度检查（"现在是否超过合理估值区间"）。

## 与相关概念的关系
