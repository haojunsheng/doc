# Alpha 变 Beta（阿尔法变成贝塔）

当某种投资观点或策略广为人知并成为市场共识时，它就不再是阿尔法（超额收益），而变成了贝塔（系统性风险溢价的一部分）。这是"阿尔法消失"现象的动态机制。

## 核心机制

```
阶段1（发现期）：某策略产生超额收益 → 被视为 Alpha
阶段2（普及期）：策略被广泛认知 → 资金涌入 → 超额收益消失 → 成为 Beta
阶段3（产品化）：策略被包装为 Smart Beta 产品 → 作为"被动"策略收费
```

## 历史案例

| 策略 | 最初状态 | 当前状态 |
|------|---------|---------|
| 价值投资（HML） | Graham 的独到洞见 → Alpha | Fama-French 三因子之一 → Beta |
| 小盘股效应（SMB） | 学术界发现的异象 → Alpha | 标准化因子 → Beta |
| 低波动效应 | 行为金融学的发现 → Alpha | Smart Beta 产品 → Beta |
| 动量策略 | Jegadeesh & Titman 的研究 → Alpha | 因子化产品 → Beta |

## 对投资者的含义

1. **阿尔法永远是短期的**：一旦被广泛认知，就被竞争消除
2. **今天的 Alpha 是明天的 Beta**：追求 Alpha 本质上是在追赶已被消化的机会
3. **Smart Beta 的本质**：用被动包装主动——把已知的因子暴露做成"指数"收费
4. **讽刺性后果**：Alpha 越被追求，越难找到——因为追求本身就在消灭 Alpha

## 与晨星定义的关系

晨星将 Alpha 定义为"当前任何因子模型都无法解释的决策"——这个定义内嵌了自我消解逻辑：随着模型进步，Alpha 的定义域不断收缩，趋近于零。
