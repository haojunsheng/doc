# 学习信号与更新载体矩阵

## 定义

三类学习信号 × 四种更新载体的映射矩阵，是 W8 的核心产出。

## 三类学习信号

| 信号 | 来源 | 描述 |
|------|------|------|
| 环境结果 | 任务执行结果 | 任务完成/失败、奖励信号 |
| 过程规则 | 执行过程中的约束 | 规则违反、安全告警、格式错误 |
| LLM Rubric | 评估模型的判定 | LLM-as-a-Judge 的评分和反馈 |

## 矩阵

| 学习信号 \ 更新载体 | 知识文档 | Prompt 与 Skills | 程序与 Harness | 模型参数 |
|-------------------|---------|-----------------|---------------|---------|
| 环境结果 | 更新 FAQ | 调整 Skill 触发条件 | 改进验证逻辑 | RL 训练 |
| 过程规则 | 新增规则文档 | 添加规则到 Prompt | 实现新约束机制 | 过程奖励 RL |
| LLM Rubric | 修正错误答案 | 调整 rubric 到 Prompt | 改进评判逻辑 | SFT 微调 |

## 核心洞察

- **多数团队应停留在左列**：知识文档和 Prompt 是最高效的迭代方式
- **环境结果信号最强**：直接反映任务成败，但需要结构化提取
- **LLM Rubric 信号最灵活**：可以评估任意维度，但依赖 rubric 设计质量

## 与 W6 评估体系的关系

W6 的评估三维度（环境 × 数据集 × 评判方法）是 W8 学习信号的静态版本——学习信号是评估体系在运行时的动态版本。
