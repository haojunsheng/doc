# 嫉妒-追高心理陷阱

## 定义

芒格称嫉妒为"七宗罪中最糟糕的"，因为在投资中，嫉妒同时带来**金钱损失**和**心理痛苦**双重惩罚——其他情绪（如贪婪、恐惧）至少只伤害一方，而嫉妒让一个人在亏钱的同时还感到不快乐。

## 形式化

```
嫉妒 → 追涨 → 亏钱 + 不快乐 → 双重惩罚
```

## 心理机制拆解

**第一阶段：比较触发**
- 看到他人（尤其是同龄人、同行）获得高回报
- 产生"为什么不是我"的比较心理
- 此时已有持仓被暂时忽略

**第二阶段：认知扭曲**
- 选择性记忆：只记得别人赚钱的案例，忘记失败的案例
- 风险忽视：认为"这次不一样""我能及时退出"
- 时间压缩：用别人的持有期幻觉替代自己的真实处境

**第三阶段：追高行动**
- 在高点买入，承担了不合适的风险
- 若后续下跌，同时承受金钱损失和当初决策失误的痛苦

## 历史证据

- 1999 年后风投规模增长 10 倍，但大部分资金打水漂
- 无数投资者在泡沫顶点冲入，即使明知是泡沫也难以抗拒
- 巴菲特和芒格从不跟风——不是因为缺乏机会识别能力，而是因为不陷入嫉妒陷阱

## 与[[上香行情]]的关联

[[上香行情]]描述的是散户在A股高波动环境下的短期投机行为，本质也是一种情绪驱动而非理性驱动。嫉妒是触发上香行为的深层心理机制之一——别人赚钱了，我也要去。

## 边界条件：嫉妒 vs 学习

**关键区分标准：**
- 嫉妒：别人赚钱→我冲进去→忽视风险→追高
- 学习：别人赚钱→研究他为什么赚→发现可复制的研究方法→按需配置

若对方的回报来自真正的研究发现（而非泡沫或运气），跟进不叫嫉妒叫学习。但普通人很难区分这两种情况——这正是认知纪律的挑战所在。

## 防御机制

1. **提前建立比较标准：** 在平静期定义"什么情况下我会跟进别人"，避免在情绪高涨时临时判断
2. **回顾自己的持仓：** 问自己"如果我当前没有持仓，我还会买这个吗？"
3. **拉长比较周期：** 用3-5年的周期评估，而非1个月或1年的短期回报

## 适用场景

- 社交媒体上出现大量"某某基金一个月涨30%"的讨论时
- 身边投资者频繁炫耀收益时
- 自身对某一资产产生"必须拥有"的冲动时
