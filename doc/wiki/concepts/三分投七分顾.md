# 三分投、七分顾

基金投顾的价值分配比例判断：**投资端占30%，客户教育与信任维护占70%**。投顾的真正价值不是帮客户选到冠军基金，而是让客户变成更理性的投资者。

## 核心判断

```
投顾价值 = 30% 投（投资策略、组合构建） + 70% 顾（客户教育、信任维护、行为干预）
```

这一判断直接否定了将投顾等同于"基金销售换包装"的行业现状——投顾机构若只盯着短期业绩排名、用历史业绩当卖点，本质上仍在卖基金，而非提供投顾服务。

## 支撑逻辑

- **业绩排名导向失效**：在A股贝塔下行、阿尔法稀缺的环境下，以业绩为卖点的模式走得艰难；牛市+主动跑赢时该模式短期有效，但长期仍脆弱
- **大V悖论**：大V的优势在于信任积累（顾），但缺乏专业投研团队（投），规模增长后必然暴露短板
- **投顾行业终局**：大浪淘沙后，把"顾"做重的机构胜出，而非"投"最强的机构

## 与既有框架的关系

- 与[[投顾份额]]形成互补：投顾份额聚焦制度设计（免尾佣），三分投七分顾聚焦服务本质——制度为体，服务为用
- 与[[目标导向vs产品导向]]关联：三分投七分顾是目标导向在投顾服务中的具体体现
- 与[[把波动交给配置把收益交给时间]]呼应：客户拿不住的本质问题正是此文所指

## 边界

- 若投资者整体成熟度提升、不再需要"被顾"，投顾的价值可能从"教育"转向"工具"（如税务优化、组合再平衡）
- "顾"的工作（客户教育、信任维护）难以量化评估，这是投顾行业最难的部分
