# 反内卷政策与投资影响

监管层介入纠偏产业无序价格战，推动行业从恶性竞争转向理性竞争，对投资产生分子端（ROE修复）与分母端（利率驱动资产配置搬家）双重影响。

## 政策信号

- 发改委+市监总局召集汽车、新能源、外卖企业座谈
- 2025年7月24日《价格法修正草案》征求意见，完善低价倾销认定标准
- 发改委发言人明确表态：突破底线的无序竞争损害消费者和企业双方

## 投资影响机制

```
反内卷政策落地
  → 供给端无序竞争减少
  → 企业定价能力恢复
  → 周期行业盈利中枢上移（分子端↑）
```

蒋璆的核心判断：受益最大的是中上游偏周期类资产（煤炭/化工/钢铁/电池）。

## 与[[指数内卷]]的区别

| 维度 | [[指数内卷]] | 本文"反内卷" |
|------|------------|------------|
| 对象 | 基金产品同质化 | 实体产业价格战 |
| 主体 | 基金公司 | 实体企业 |
| 表现 | 费率竞争 | 低价倾销 |
| 监管 | 无 | 有明确政策干预 |

两者共用"内卷"一词但场景完全不同，需注意区分。

## 边界条件

- 地方保护主义干扰可能导致政策执行不力
- 若政策落地慢或全球经济衰退，周期盈利上移推迟
- 新能源产能过剩若通过出口暴增缓解，内卷烈度可自行下降

## 与周云宏观框架的关系

周云的框架将"反内卷→ROE系统性上升"作为分子端核心假设之一，叠加"定存利率<1%驱动储蓄搬家"的分母端逻辑，构建中国资产慢牛的完整论证。蒋璆的策略可以视为周云框架在周期资产上的具体应用，时间跨度更短、焦点更集中。
