# 本金侵蚀（每月派息份额风险）

## 定义

每月派息型基金份额在市场大跌时，为维持既定分红率，动用基金资产净值中的本金（而非投资收益）来补足分红。这种"本金分红"机制直接侵蚀复利增长，是柔性分红策略的隐形杀手。

## 机制

```
市场大跌 → 投资收益不足 → 维持分红率需动用本金
    ↓
本金减少 → 复利基数缩小 → 后续业绩拖累
    ↓
投资者获得"看似稳定"的分红，但资产净值持续缩水
```

## 典型案例：瑞士百达策略收益基金

| 指标 | 正常水平 | 2022年（大跌年） |
|------|---------|-----------------|
| 分红来源中本金占比 | < 20% | 40% |
| 年化分红率 | 约5.5% | 维持不变 |
| 当年业绩分位 | — | 同类后1/4 |

2022年市场大跌，该基金为维持每月派息，动用40%本金补足分红，直接导致2024年业绩跌至同类后1/4——本金侵蚀的滞后效应在两到三年后才充分显现。

## 与普通分红的区别

- **普通分红**：来源于投资收益（股息、利息、资本利得），不影响本金
- **本金分红**：来源于资产净值本身，直接削减复利增长的基础

## 适用边界

### 适合投资者
- 需要稳定现金流的退休人士
- 对短期净值波动不敏感，更看重每月现金流入

### 不适合投资者
- 追求长期复利增长、不依赖分红的投资者
- 无法承受本金被侵蚀风险的投资者
- **应选非派息份额**

## 与相关概念的关系

- 与 [[全球灵活配置策略]] 的交叉：灵活配置策略常搭配每月派息份额，两者叠加形成"业绩驱动型资金飞轮 + 本金侵蚀"的结构性风险
- 与 [[风格漂移]] 的关联：风格切换成功时掩盖本金侵蚀（牛市分红来自收益），切换失败时同时暴露回撤和本金侵蚀双重打击
