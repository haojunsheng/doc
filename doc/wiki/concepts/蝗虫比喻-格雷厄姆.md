# 蝗虫比喻-格雷厄姆

本杰明·格雷厄姆在《聪明的投资者》中使用的经典比喻：投资者在信息过载下像夏日田野里的蝗虫，急不可耐地从一只股票跳到另一只，追逐热点而非基于深入研究做决策。

## 出处

本杰明·格雷厄姆，《聪明的投资者》。

## 比喻内涵

```
夏日田野里的蝗虫
    ↓
急不可耐地从一株植物跳到另一株
    ↓
不是在吃（投资），而是在迁徙（追逐热点）
    ↓
结果：一片狼藉，一无所获
```

对应投资行为：
- 蝗虫 = 急不可耐的交易者
- 从一株跳到另一株 = 追逐热点（元宇宙→科特估→AI→低空经济→地产…）
- 不是在吃 = 没有真正理解标的，只是追逐短期热度
- 一无所获 = 反复打脸后的净亏损

## 与现代投资的关联

- 基金公司不断发行热点主题基金，迎合投资者的蝗虫心态
- 24小时财经信息 + 标题党，持续刺激 FOMO（错失恐惧）
- 利益相关方（媒体、销售）从频繁交易中获利，而投资者承担行为代价
- "核心资产永续增长"、"这次不一样"——每次热点都有人重复线性外推的谬误

## 与近因效应的关系

近因效应是蝗虫行为的认知基础：
- 近因效应让人过度关注近期热点
- 线性外推让人相信热点会永续
- 两者结合，形成"跳蚤市场"式的投资行为

## 边界：蝗虫行为 vs 理性调仓

不是所有交易都是蝗虫行为：
- **蝗虫行为**：追逐热点、缺乏深入研究、因 FOMO 冲动买入
- **理性调仓**：基于深度研究、改变投资决策、有明确逻辑支撑

关键区别在于"为什么买"，而不是"买不买"。
