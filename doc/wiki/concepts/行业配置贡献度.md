# 行业配置贡献度

**行业配置贡献度**是指基金业绩中由行业资产配置决策所带来的收益占比。这是理解"为什么选基金要看经理的行业配置能力"这一核心论断的关键概念。

## 核心命题

> 基金业绩 ≈ 行业配置（~60%）+ 选股能力（~40%）

晨星 2025 年 9 月月报指出，在结构分化市场中，行业配置是基金业绩的主要来源。这意味着：

- 选对了行业方向，基金大概率跑赢基准
- 选错了行业方向，即使选股能力强，整体业绩也可能平庸

## 形成机制

```
经济周期阶段
    → 各行业景气度分化
        → 基金行业配置方向决定相对收益
            → 行业配置贡献度 ≈ 60%（晨星估算）
```

典型例证（2025年9月）：
- A股整体上涨，但行业涨跌互现
- 重仓上涨行业的基金表现好
- 重仓下跌行业的基金表现差
- 结果：权益基金涨跌互现，业绩高度分化

## 与已有框架的关系

### 与 [[三层业绩归因框架]] 的关系

三层业绩归因框架将基金业绩拆解为：
1. 资产配置（大类：股/债/现金）
2. 行业配置（大类内部行业选择）
3. 个股选择（行业内选股）

行业配置贡献度聚焦于第二层，强调其在总业绩中的重要占比。

### 与 [[赛道型基金的三重驱动分析框架]] 的关系

赛道型基金高度集中在某一行业，行业配置贡献度接近 100%——这类基金的业绩几乎完全取决于行业景气度判断，而非选股能力。这放大了行业配置贡献度的含义：赛道型基金本质上是在做行业择时。

### 与 [[基金经理任职稳定性]] 的关系

行业配置能力是基金经理的核心价值之一。换帅往往意味着行业配置逻辑的中断，这也是为什么"选基金 = 选经理"在这一维度上有坚实基础。

## 边界条件与警示

1. **60% 是估算值，非铁律**。不同风格（成长/价值/行业主题/固收+）的基金，行业配置贡献度差异显著。
2. **普涨行情下贡献度下降**。市场整体向上时，行业配置差异缩小，选股能力的相对权重上升。
3. **行业配置≠行业择时**。优秀的行业配置能力不等于预测行业轮动，更多体现为对行业长期逻辑的判断与持仓纪律。
4. **风格漂移会扭曲归因**。若基金发生主动风格漂移，历史行业配置数据将失去参考价值。

## 投资决策启示

- 在结构分化市场中，行业配置能力比选股能力更值得优先考察
- 选择基金时，应审视基金经理的历史行业配置逻辑是否清晰、可重复
- 避免仅凭"今年哪个行业涨"来选基金——行业配置的高贡献度意味着：去年的热门行业，今年可能成为最大拖累
