# 锂产能出清周期

**锂产能出清周期**是指锂价远低于成本支撑位导致低价促使部分生产商暂停投资，未来供应增长将放缓而需求仍增长，价格有望修复。

## 核心命题

> 锂价<成本 → 投资暂停 → 供应增长↓ + 需求↑ → 产能出清 → 价格有望修复

## 形式化表达

```
锂价<成本 → 投资暂停 → 供应增长↓ + 需求↑ → 产能出清 → 价格有望修复
```

## 当前状态

- 锂价本季度环比上涨但仍显著低于成本支撑位
- 低价已促使部分生产商暂停投资
- 电池领域需求（近一半来自电动汽车）仍保持较快增长

## 关键变量

| 变量 | 影响 |
|------|------|
| 电动车渗透率 | 大幅提升可能逆转供需 |
| 新锂矿投产 | 加速投产可能延长出清 |
| 成本支撑位 | 跌破程度决定出清速度 |

## 边界条件

若电动车渗透率大幅提升或新锂矿项目加速投产，供需格局可能快速逆转。
