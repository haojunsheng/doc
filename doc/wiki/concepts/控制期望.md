# 控制期望

控制期望 = 增加收入——降低预期与增加实际收入同等有效地提升幸福感。这是《金钱心理学》对话中最具操作性的结论。

## 核心论点

如果你期望赚的比你实际赚的多，无论你赚多少钱，你永远不满足。

金融行业教怎么赚钱，但不教什么是合理预期。"控制期望"是这个空白的填补方案：不是你赚得不够，而是你想要得太多。

## 与"足够"的关系

"控制期望"是方法，"找到足够"是目标。两者共同构成一个逻辑链：

```
承认无法预测未来 → 控制期望（降低欲望而非提升收入）→ 找到"足够" → 停止追逐 → 获得财务幸福
```
