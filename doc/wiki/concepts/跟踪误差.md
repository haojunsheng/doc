# 跟踪误差

跟踪误差（Tracking Error）衡量的是指数基金「跟上指数」的能力——即基金回报与指数回报之间的偏离程度。它比费用率更值得关注，因为它是隐性的，不直接出现在费用账单上。

## 形式化

```
跟踪误差 = 基金回报与指数回报之差的标准差

0.5% 的跟踪误差 ≈ 每年额外付出 0.5% 的隐性成本
```

## 成因

| 成因 | 说明 |
|------|------|
| 现金拖累 | 基金留 3-5% 现金应对赎回，牛市少赚、熊市保护 |
| 调仓延迟 | 指数成分股调整后，基金不可能同天完成买卖 |
| 抽样复制 | 成分股太多时，基金用抽样而非完全复制，产生跟踪偏差 |
| 市场冲击 | 基金集中买卖推高买入价、压低卖出价 |
| 综合费率 | 管理费+托管费+交易费+运营费的总和——[[concepts/ETF投资五问框架]] 补充：这是跟踪误差的重要来源之一 |

## 量化参考

- **完全复制型**：误差 < 0.1%
- **抽样复制型小盘股**：误差 > 1%

## 边界条件

- 大盘股指数（标普 500）：流动性好，跟踪误差小
- 小盘股/新兴市场指数：流动性差，跟踪误差大
- 不能一概而论——同类指数基金之间，跟踪误差差异可能很大

## 在中国市场的适用性

中国指数基金市场跟踪误差整体较小（多数宽基指数 < 0.5%），但小盘股指数和主题指数的跟踪误差需要具体产品具体分析，暂无公开的统一数据支撑"小盘股指数误差 > 1%"的判断。
