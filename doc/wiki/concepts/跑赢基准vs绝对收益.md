# 跑赢基准 vs 绝对收益

## 核心洞见

**"跑赢基准 ≠ 赚到钱"** 是投资者最常见的认知盲区之一。

这个误区将相对收益（基准超额）等同于绝对收益（真实财富增长），忽视了两个关键问题：
1. 基准本身可能为负——跑赢 -10% 的基准只赚 -5%，仍然是亏损
2. 高收益基准隐含高风险——追求跑赢高基准往往意味着承担超出风险承受能力的波动

## 认知机制

| 误区 | 真相 |
|------|------|
| 基金跑赢基准 = 好基金 | 基准选择本身也是风险声明，高基准=高风险 |
| 跑赢基准就是赚到钱 | 基准为负时跑赢仍是亏损 |
| 基准越高越好 | 基准与自身风险偏好不匹配反而有害 |
| 只看相对收益不看绝对收益 | 投资者最终需要的是绝对财富增长 |

## 与基准的关系

基准的正确定位不是"超越目标"，而是"游戏规则定义器"：
- 基准定义了基金在什么市场上、以什么风格玩这个游戏
- 选基金第一步是看基准是否与自己的目标和风险偏好匹配
- 跑赢基准是基金经理的责任，获取合理绝对回报是投资者的目标

参见 [[业绩比较基准]]。

## 产品层面的绝对收益 vs 相对收益

投资者认知盲区之外，基金本身的产品定位也是绝对收益与相对收益之争。同一策略大类（如固收+）内，定位不同导致配置策略的系统性分化：

**华泰保兴尊合债券**（绝对收益导向）：
- 追求"低波动"，不亏钱优先
- 转债仓位中枢 25%，选低价高等级转债
- 杠杆灵活但保守（平均约110%）

**光大保德信增利收益债券**（相对收益导向）：
- 追求"跑赢中证全债指数"
- 转债仓位中枢 30%，用转股溢价率分位数择时
- 杠杆稳定在 107% 以内

**实证验证**：2023年熊市华泰保兴更抗跌，2021年牛市光大保德信更亮眼（来源：[[sources/5-notes--08-20260614T213408--qa-固收加攻守之道-qa]]）。

**选择框架**：没有永远更好的基金，只有更适合当前市场环境的基金——熊市选绝对收益导向，牛市选相对收益导向。

参见 [[固收加的权益暴露度权衡]] 了解产品定位如何驱动权益暴露度差异。

## 行动准则

1. **先看基准，再看收益**：确认基金基准与你的投资目标匹配
2. **量化基准风险**：高基准意味着高波动，问自己能否承受
3. **区分两类收益**：绝对收益是你的真实回报，相对收益是基金经理的KPI
4. **警惕"基准陷阱"**：不要为了跑赢一个不切实际的高基准而承担过度风险
