# 策略一致性

## 定义

策略一致性是指基金经理的投资框架和执行纪律在时间维度上的稳定程度。它是选流派时最应关注的指标，替代短期业绩排名。

## 核心公式

```
短期排名 = 运气 + 风格适配
策略一致性 = 框架稳定 × 执行纪律
```

## 判断标准

五派共同特质：**清晰框架、严格风控、独立判断**。

典型案例：
- [[谢治宇]]换手率从300%降至约100%，是框架进化的表现，不是风格漂移（参见 [[知行合一（框架稳定性）]]）
- [[刘旭]]随周期动态调整但底层逻辑不变，是好策略有弹性但不变形的典型

与 [[风格漂移识别]] 的关系：风格漂移是策略一致性的反面——基金经理在不同风格之间频繁切换，缺乏清晰的策略锚点。

## 边界条件

- 基金经理变更时，历史策略一致性不再有效
- 核心逻辑改变时，历史策略一致性不再有效
