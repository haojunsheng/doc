# 自下而上选股

从个股基本面出发进行投资决策的方法论，与自上而下（macro-driven）相对。强调深度研究企业质地，而非依赖宏观经济或行业配置判断。

## 核心逻辑

自上而下选股依赖宏观判断，误差较大——经济预测、政策走向、行业轮动都具有高度不确定性。自下而上从个股出发，更依赖对企业的深度研究，聚焦于：

- **企业基本面**：盈利能力、财务健康、护城河
- **行业前景**：所处行业的生命周期和竞争格局
- **估值水平**：安全边际，避免为过度乐观定价买单

## 形式化表达

```
选股框架 = 基本面分析 × 行业前景 × 估值评估 → 高确信度标的
```

## 边界条件

- 行业发生颠覆性变化时，基于历史基本面的分析可能失效
- 需要足够的研究时间和信息获取渠道，对小规模投资者不友好
- 在全面泡沫或系统性崩盘时期，个股选择对最终回报的影响可能被系统性因素淹没

## 与实践案例

[[xingquan-herun-mixed]]（兴全合润混合）采用自下而上的选股框架，通过深度研究挖掘被市场低估的标的，是其主动管理能力的核心支撑。

该方法与 [[mispricing]] 理论紧密相连——自下而上的深度研究是发现错误定价的主要手段。
