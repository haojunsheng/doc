# 实物申赎模式

实物申赎模式是指投资者可以使用底层加密货币（如比特币、以太坊）直接申购ETF份额，或用ETF份额赎回实物加密货币的机制。香港在2024年成为全球首个推出此模式的监管辖区。

## 核心机制

```
传统现金申赎：
投资者用现金申购 → ETF管理人用现金买入加密货币
投资者赎回ETF → ETF管理人卖出加密货币 → 投资者获得现金

实物申赎：
投资者持币申购 → 直接将加密货币交予ETF托管
投资者赎回ETF → 直接获得加密货币
```

## 香港首创

| 属性 | 内容 |
|------|------|
| 时间 | 2024年4月30日 |
| 监管机构 | 香港证监会 |
| 首批产品 | 6只加密货币ETF |
| 代表产品 | 博时HashKey（3008.HK），每份对应1/10000比特币 |
| 支持资产 | 比特币、以太坊 |
| 定位 | 亚太地区首个允许加密货币现货ETF上市的地区 |

## 优势与意义

- **效率提升**：减少中间兑换环节，降低交易成本
- **税务优化**：部分司法管辖区下实物申赎可能享受更优税务处理
- **信号意义**：标志着加密资产获得与传统资产同等地位的制度化认可
- **流动性增强**：做市商可直接参与申赎，提升市场深度

## 边界条件

- 若其他交易所（如新加坡、迪拜）跟进实物申赎模式，香港先发优势可能被削弱
- 实物申赎对托管安全和链上操作提出更高技术要求
- 监管框架尚未统一的背景下，跨境套利存在合规障碍
