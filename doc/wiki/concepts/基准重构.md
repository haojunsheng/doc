# 基准重构

**基准重构**指基金将业绩比较基准从宽泛模糊的通用指数，切换为贴合实际投资策略的细分指数的行业行为。2026年上半年，在证监会《推动公募基金高质量发展行动方案》驱动下，57只基金率先完成基准调整，形成一场"从宽基泛化到细分聚焦"的集体校准。

## 核心方向

基准重构的方向性规律是**贴合实际策略**：

```
旧模式：沪深300 + 中证全债（宽基覆盖，忽略策略差异）
新模式：中证TMT产业指数 + 活期利率 + 港股消费（按真实投资方向细分）
```

## 三类典型调整

### 债基：从粗放到精细

中证全债覆盖所有债券品种，无法区分久期和信用风险。中债系列指数可按期限（<1年、1-3年等）和信用分层精准匹配。

**浦银安盛案例**：
```
中证全债 → 中债综合全价 + 5%可转债 + 10%活期利率
```

### 跨市场基金：权重随真实敞口调整

港股基准权重调整方向取决于基金实际跨市场敞口，不存在模板：

| 基金 | 旧港股权重 | 新港股权重 | 调整逻辑 |
|------|----------|----------|---------|
| 招商蓝筹精选 | 10% | 30% | 重仓港股核心资产 |
| 浙商汇金量化臻选 | 40% | 5% | 主攻A股，港股非核心 |

### FOF：从双因子到多因子

```
旧基准：股 + 债
新基准：股 + 债 + 黄金(Au99.99) + 商品 + 海外(标普500)
```

80%的FOF新增黄金因子，因黄金与股债低相关，是独立收益来源。部分FOF加入标普500对冲单一市场风险。

## 制度驱动力

基准重构并非自愿行为，而是《推动公募基金高质量发展行动方案》的制度性要求。该方案将业绩比较基准与浮动管理费档位绑定，基准选择直接影响管理人收入，从而打破基金公司"维持错误基准"的制度惰性。

参见 [[基准-浮动费率挂钩机制]]。

## 负面效应：降低考核难度

部分基金借基准调整将基准换成更容易超越的组合，实质是制度套利：

- 将固定年化10%的绝对目标转为股债组合基准——数字上更容易跑赢
- 选择与基金真实策略匹配度不足的基准，使基准偏离实际收益特征

参见 [[降低考核难度]]。

## 投资者价值与代价

**价值**：精准基准让产品定位透明，减少投资者错配；基准规范化使风格漂移更难隐藏。

**代价**：多因子基准（4-6个资产类别）增加理解门槛；基准-费率挂钩使基准选择直接影响管理费成本。

## 边界条件

- 基金策略本身不清晰时，再精细的基准也贴不上
- 仅换指数名称而策略未变，属于表面合规
- 基准因子过多则"什么都测等于什么都没测"，需看核心配置权重
- 监管若无审查标准，"降难度"空间将持续存在
