# 已投入资金IRR等效

每月定投在"已投入资金"层面的内部收益率（IRR），与买入持有策略无显著差异。

## 核心结论

- 日常定投是每月从工资中拿出一部分投入，**等于每月做一次"一次性买入"**
- 不考虑资金闲置问题时，定投IRR高于买入持有的概率约在50%上下
- 两种方式的差异主要体现在"未投入资金"的闲置成本上

## 形式化

```
定投流程：每月收入 → 固定比例投入基金
         = 每月做一次及时投资（一次性买入）

IRR(定投, 已投入资金) ≈ IRR(买入持有, 全部资金)

差异来源：
  定投：部分资金在月度间隔期内闲置
  买入持有：全部资金立即暴露
```

## 关键洞察

1. **定投不改变已投入资金的效率**——它只是把"一次性大投入"拆分成"多次小投入"
2. **真正影响整体回报的是闲置成本**——未投入资金若只能放在活期账户，机会成本显著
3. **如果闲置资金能投向货币基金等工具**，整体效率差异进一步缩小

## 与相关概念的关系

- [[concepts/现金闲置成本]] — 补充理解：IRR等效说明差异不在"买入时机"，而在"闲置成本"
- [[concepts/一次性买入vs定投]] — 本概念是该对比中"收益无显著差异"子维度的数学基础

## 边界

- IRR比较忽略了闲置资金的时间价值——若闲置资金有收益，差异更小
- 此结论适用于"每月有稳定现金流"场景，不适用于"有一笔现成资金"场景
