# 长期主义考核框架

买方投顾成功的前提条件是长期主义考核机制。短期考核无法落实长期战略，是投顾业务落地的核心障碍。

## 核心判断

```
投顾成功 = 长期考核 + 监管扶持 + 科技赋能 + 合规意识
```

四个条件缺一不可。其中长期主义考核是关键前提。

## 问题诊断

```
短期考核 → 追求短期业绩排名 → 追逐热点、频繁调仓 → 高换手率 → 高隐性成本 → 客户亏损 → 信任崩塌
```

销售导向模式下，考核机制激励短期行为，导致利益与投资者不一致。

## 解决方案

买方投顾要求建立长期考核机制，使投顾机构的利益与客户长期收益对齐。欧美监管实践表明，制度设计是推动长期主义考核的关键。

## 欧洲参照

欧洲已强制基金销售转型为投顾，通过监管手段推动考核机制转变。

## 边界条件

若投顾机构短期考核压力过大，可能回到销售导向。这是当前中国投顾业务面临的主要障碍。

## 与买方投顾的关系

长期主义考核是买方投顾商业模式落地的基础条件。没有这一制度保障，买方投顾难以真正践行客户利益至上原则。
