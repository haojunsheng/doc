# 生活愿景倒推法

## 定义

一种以"生活愿景"为起点、反向推导投资目标和策略的操作性方法。与常见"从收益率出发"的思维方式相反，该方法要求投资者先明确"想过什么样的生活"，再倒推需要的金额和时间。

## 操作步骤

```
理想生活描述 → 量化金额需求 → 设定时间框架 → 可行性验证 → 动态调整
```

1. **写作描述理想生活**（100字以内）
   - 住在哪里、做什么工作、日常节奏、人际关系质量
   - 关键：具体场景而非抽象数字

2. **倒推金额需求**
   - 日常开销 + 重大支出（买房、教育、医疗）+ 应急储备

3. **设定时间框架**
   - 时间决定风险承受力：3年赚100万 vs 30年赚100万，策略完全不同

4. **可行性验证**
   - 对照当前资产、收入、储蓄率，判断目标是否可实现

5. **动态调整**
   - 不现实时调整生活描述或延长时间框架，而非硬撑

## 与相关概念的关系

### vs [[富有是副产品]]

[[富有是副产品]] 指出致富不应是目标本身；[[生活愿景倒推法]] 提供具体操作方法——如何把"过理想生活"转化为可执行的财务目标。

### vs [[投资指南针模型]]

[[投资指南针模型]] 提供四步框架（生活需求×所需金额×时间×现状评估）；[[生活愿景倒推法]] 更强调"愿景先行"的起点意识和"写作描述"的操作细节。

### vs [[目标三要素框架]]

[[目标三要素框架]]（具体金额 × 时间框架 × 可行性验证）是倒推法的结构化表达——三者缺一不可，否则是白日梦。

## 关键洞见

- 数字本身没有意义，背后的生活才有意义
- "想要什么生活"比"想要多少钱"更难回答，却是整个框架的起点
- 目标的价值不在精准，而在提供方向感和行动动力
- 当目标具体化（写作而非想象），才会产生情感联系和行动动力

## 操作局限

- 假设投资者有稳定的"生活愿景"——但很多人从未认真思考过这个问题
- 目标本身的动态性与静态设定的张力未解决
- 多重目标（退休+教育+购房）需要不同的时间框架，操作复杂度显著增加
