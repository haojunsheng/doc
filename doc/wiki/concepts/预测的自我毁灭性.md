# 预测的自我毁灭性

**定义**：可被公开预测的趋势，一旦被知晓，聪明人提前行动使其失效——预测本身改变了行为，行为改变了结果。

## 核心机制

金融市场不同于天气系统，存在**反身性**（reflexivity）：

1. 预测被公开 → 投资者获知趋势 → 提前行动 → 价格提前反应 → 原预测失效。
2. 市场里很多人不希望自己的行为被别人预测——"聪明人"不会按常理出牌。
3. 任何发现"天机"的人，不能天真相信市场会按剧本演绎，因为"聪明人"不止你一个。

## 经典案例：2019-2020 核心资产抱团

机构价值投资者按"好公司、好行业"逻辑选出同一批股票，认为可以稳坐"长坡厚雪"慢慢赚钱。但当所有人都做出相同选择时，定价已提前透支——最终被冲高回落的价格波动反噬。
