# 主题基金热度循环

描述主题基金从热点兴起至高潮再至衰退的完整生命周期机制，核心风险在于高位申购者承担热潮退却后的损失。

## 机制

```
主题上涨→申购↑→规模↑→热潮退→下跌→高位买家亏损
```

## 阶段分解

| 阶段 | 特征 | 风险 |
|------|------|------|
| 兴起期 | 主题叙事形成，少量基金发行 | 低位布局机会 |
| 热度上升期 | 赛道上涨，基金公司加速发行，投资者大量申购 | 开始拥挤 |
| 高潮期 | 发行量峰值，搜索指数达峰，资金涌入最快 | **最大风险：高位接盘** |
| 退潮期 | 主题叙事褪色，申购转赎回，规模收缩 | 净值下跌 |
| 衰退期 | 基金改名/清盘/偏离主题 | 损失确认 |

## 与相关概念的关系

- **[[羊群效应-资金追逐热门赛道]]**：热度循环的驱动力——投资者和基金公司同时追涨
- **[[赛道轮动]]**：热度循环的时序背景——资金在不同赛道间快速切换
- **[[主题基金存活率模型]]**：热度循环的终局——大部分主题基金在高潮后存活率极低
- **[[主题投资]]**：热度循环的策略层面——围绕叙事主线构建组合

## 关键洞察

1. **指数化加剧风险**：2024年140只主题基金中84只（60%）为指数基金，意味着热潮期的申购资金直接转化为赛道估值压力，而非通过主动管理创造超额收益

2. **主题温度可量化维度**：选基时需评估"主题温度"——包括基金发行数量、搜索指数、资金流入速度等指标，判断是否已进入高潮期

3. **逆向布局机会**：如果投资者在主题热度极低时布局，同样的主题基金反而可能获得较好回报
