# 强势资产压制效应

长期收益差距较大时，再平衡等于强制减仓表现最好的资产，从而拖累整体组合回报。这一反向机制被称为"强势资产压制效应"。

## 机制描述

```
再平衡操作: 强势资产权重 ← 人为压低（定期卖出赢家）
不操作策略: 强势资产权重 ← 自然升高（让赢家继续跑）
```

## 实证案例

| 资产对 | 长期表现 | 再平衡效果 |
|--------|---------|-----------|
| A股 + 债券/现金 | 收益差距 ≤3% | 正面：十年累积 +5%~6% |
| A股 + 黄金 | 黄金长期跑赢 A 股 | 负面：再平衡反而亏 |
| A股 + 全球股票 | 全球股票长期跑赢 A 股 | 负面：再平衡反而亏 |

## 核心洞察

再平衡的"高卖低买"在强势资产压制场景下变成了"高卖赢家、低买输家"，相当于用纪律主动限制最成功资产的增长空间。

## 边界条件

- 若强势资产未来转为跑输弱势资产，压制效应反转，再平衡效果转为正面
- 该结论基于历史数据，未来格局变化时结论可能不成立

## 与投资纪律的关系

尽管存在压制效应，[[再平衡的价值与边界]] 指出再平衡的真正价值在于风险管理——因无人能稳定预判谁会长期胜出，所以需要纪律来防止风险失控。这解释了为何压制效应存在的同时，再平衡仍有其不可替代的作用。
