# 目标导向 vs 产品导向

晨星提出，所有投资决策应从生活需求出发（目标导向），而非从哪个产品收益率最高出发（产品导向）。这是红利投资乃至所有投资决策的逻辑起点。

## 核心公式

```
目标导向: 生活需求 → 投资策略
产品导向: 哪个收益高 → 买哪个
```

## 两种导向的本质区别

| 维度 | 目标导向 | 产品导向 |
|------|---------|---------|
| 出发点 | 生活需求（退休/买房/旅行） | 产品收益数字 |
| 决策顺序 | 先问"为什么"，再问"买什么" | 直接比较收益率排名 |
| 金融业的激励 | 匹配客户需求（理想状态） | 推销产品赚取佣金 |
| 结果 | 策略与目标一致，可持久 | 产品切换频繁，行为成本高 |

## 金融行业的产品导向偏差

- 金融行业习惯推销产品，不关心你的真实需求
- 销售端激励与投资者目标天然错位
- 不同目标（退休/买房/旅行）对应完全不同的策略，但产品导向让投资者把所有目标压缩为"高收益"单一维度

## 边界条件

**适用：** 所有以长期财务目标为核心的投资，包括红利投资。

**不适用：** 纯投机（只想赚差价）的人不需要目标导向，但这类人也不适合红利投资。
