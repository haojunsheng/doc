# 星级是筛选起点而非决策终点

## 核心命题

晨星星级评级是**筛选研究的起点**，而非**买入决策的终点**。正确使用方式是先以星级缩小研究范围，再通过定性分析做出最终投资决策。

## 为什么星级不能直接作为买入依据

1. **历史不代表未来**：星级基于过去3/5/10年的业绩，基金未来表现受投研团队能力、策略有效性、执行情况等多重因素影响
2. **纯量化盲区**：星级是纯量化评级，不考虑基金经理变更、投资流程变化等定性因素
3. **强制分布的相对性**：五星只占前10%，三星意味着击败近40%同类，四星与三星之间的差异并不如直觉感受到的那么大

## 正确使用流程

```
星级筛选（三星以上）→ 进入研究清单
        ↓
叠加定性分析
  ├── 基金经理是否变更？
  ├── 投资风格是否漂移？
  ├── 投研团队是否稳定？
  └── 业绩归因：超额收益来自能力还是风格运气？
        ↓
做出投资决策
```

## 星级下降 ≠ 卖出信号

- 业绩落后可能是**风格逆风**等暂时性因素导致
- 需结合基金经理能力和投资流程来评估
- 单纯因星级下降而赎回，往往错失长期持有带来的复利效应

## 与 [[基金经理自持]] 和 [[增聘基金经理的判断框架]] 的关系

星级无法捕捉基金经理变更等定性信息，投资者需要借助其他维度的分析工具来补充星级评级的盲区。
