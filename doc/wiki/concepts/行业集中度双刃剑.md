# 行业集中度双刃剑

行业集中度高 = 弹性大 + 风险大；行业分散 = 弹性小 + 风险小。押对行业可能让你一年翻倍，也可能让你一年腰斩。

## 核心命题

**行业选择不是"选好的"，是"选对的时候选对的"**

高行业集中度放大了行业β的波动——当行业方向正确时，超额收益被放大；当行业方向错误时，亏损同样被放大。分散不是降低风险的最优解，理解自己在赌什么才是。

## 案例：广发睿毅领先（005233）

2023 年的极端分化提供了典型案例：

| 行业 | 涨幅 | 影响 |
|------|------|------|
| 通信 | +50% | 重仓者超额收益爆炸 |
| 传媒 | +42% | 同上 |
| 房地产 | -14% | 重仓者显著拖累 |
| 商贸零售 | -23% | 重仓者业绩大幅落后 |

广发睿毅领先重仓航空 + 零售，这两个行业基本面持续恶化，基金业绩大幅落后——不是因为选股错误，而是行业方向的系统性逆风。

## 与相关概念的关系

- [[三层业绩归因框架]]：行业配置是第二层，介于风格暴露与选股能力之间
- [[风格顺风与逆风]]：行业集中度会放大风格顺风/逆风的效果
- [[伪分散风险]]：行业分散不等于风险分散——如果所有行业都在同一风格因子上暴露，分散无效

## 投资者应用

1. 评估一只基金时，先看行业集中度——高集中基金的业绩波动主要来自行业β
2. 不要因为某只基金某年行业押注成功就追入——顺风期结束后回归均值
3. 理解"选对的时候选对的"比"选好的"更难，也更难持续
4. 行业分散不是万能药——过度分散会稀释收益，关键是知道自己在赌什么
