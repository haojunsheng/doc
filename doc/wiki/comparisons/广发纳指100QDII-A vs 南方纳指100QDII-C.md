# 广发纳斯达克100QDII-A vs 南方纳斯达克100QDII-C

两只基金追踪同一底层资产（纳斯达克100指数），但在费用结构、限购额度和适用场景上存在差异。

## 基本信息对比

| 维度 | 广发A（270042） | 南方C（016453） |
|------|----------------|----------------|
| 成立日期 | 2012-08-15 | （较晚） |
| 基金经理 | 刘杰 | 张其思 |
| 管理人 | 广发基金 | 南方基金 |
| 净资产规模 | 约97-108亿元 | 较小 |
| 目标ETF | 广发纳指100ETF 159941（约276亿元） | — |

## 费率对比

| 费用项 | 广发A（270042） | 南方C（016453） |
|--------|----------------|----------------|
| 管理费 | 0.80%/年 | 0.50%/年 |
| 托管费 | 0.20%/年 | 0.15%/年 |
| 销售服务费 | 无 | 0.10%/年 |
| **年化合计** | **1.00%/年** | **0.75%/年** |
| 前端申购费 | 1.30%（<100万元，平台常有折扣） | 无 |

**结论**：南方C年化费用低0.25%，且无前端申购费，适合短中期持有。广发A适合长期持有（无销售服务费），但需确认平台申购费折扣足够大以摊薄前端成本。

## 限购对比

| 维度 | 广发A | 南方C |
|------|-------|-------|
| 单日单账户限额 | 100元 | 200元 |
| 限制起始日期 | 2025-10-22 | 2026-04-08 |

**结论**：南方C限购更宽，适合希望通过定期定额积累仓位的投资者。

## 适用场景建议

| 场景 | 推荐选择 |
|------|---------|
| 持有5年以上，平台申购费有大幅折扣 | 广发A（长期持有摊薄前端费） |
| 持有1-3年，或不确定持有期 | 南方C（无申购费，费率更低） |
| 想快速积累仓位 | 南方C（限购200元/日，效率更高） |
| 已有美股/AI敞口，仅想小额配置 | 两者皆可，按费率选 |

## 共同约束

两只基金的底层资产相同，因此面临相同的约束：

1. **估值偏高**：纳指100滚动PE 35-38倍，高于长期中位数24-25倍
2. **集中度风险**：前九大公司权重超过60%
3. **QDII额度稀缺**：限购本身是通道摩擦，不是价值信号
4. **秩序搬运本质**：基金本身不创造阿尔法，价值完全来自纳指100

## 关键结论

- 两只基金都是"秩序搬运"管道，区别只在通道成本和可得性
- 南方C在费用和低限购方面更友好，是当前的更优选择
- 若只能买到广发A，也不应因限购100元而转向场内高溢价ETF
