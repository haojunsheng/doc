# 一次性买入 vs 定投

系统性对比两种入场方式在收益、风险、适用场景上的差异。

## 收益表现

| 维度 | 一次性买入 | 分批定投 |
|------|-----------|---------|
| 预期收益 | 更高 | 更低（资金迟到成本） |
| 跑输概率（5年期） | 基准 | 72%（沪深300，2005-2026） |
| 跑输概率（10年期） | 基准 | 83%（沪深300，2005-2026） |
| IRR（已投入资金） | 基准 | 无显著差异 |

**结论**：在市场长期向上的假设下，一次性买入在收益上占优；差异主要来自"未投入资金的闲置成本"。

## 风险特征

| 维度 | 一次性买入 | 分批定投 |
|------|-----------|---------|
| 账户波动（标准差） | 高 | 低（部分现金缓冲） |
| 高位买入风险 | 一次性承受 | 分散到多个月份 |
| 波动对投资者的意义 | 风险（容易恐慌卖出） | 理论上机会（摊薄成本），但需有钱可投且能坚持 |

**结论**：定投确实降低账户波动，但这是以牺牲收益为代价的；降低波动不等于降低风险。

## 适用场景

```
一次性买入更优：
- 有一笔现成资金需要配置
- 市场长期趋势向上
- 投资者能承受高位波动

定投更优：
- 每月有稳定现金流（工资收入）
- 难以克服"等一等再投"的拖延心理
- 需要在行为层面建立投资纪律
```

## 核心公式

```
投资收益 = 资产选择 × 仓位 × 持有时间
定投方式 × 收益 ≈ 无影响
```
