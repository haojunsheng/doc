# 三种全天候策略对比

## 概述

投资界有三种著名的全天候策略思路：达里欧全天候、布朗永久组合、现代版塔木德。它们共享"不预测宏观环境"的核心理念，但在风险资产配置、调仓频率、最大回撤等关键维度上差异显著。

## 详细对比

| 维度 | 达里欧全天候 | 布朗永久组合 | 现代版塔木德 |
|---|---|---|---|
| 提出者 | 瑞·达里欧 | 哈里·布朗 | 塔木德智慧（现代演绎） |
| 理论基础 | 经济四象限模型 | 三要素（安全/稳定/简单） | 1/3+1/3+1/3分配 |
| 典型配置 | 股30% + 债55% + 金15% + 商品 | 股25% + 债25% + 金25% + 现25% | 约2/3风险资产 + 1/3保守 |
| 风险资产占比 | ~50% | 25% | ~67% |
| 调仓策略 | 会根据经济环境调整比例 | 永不调仓 | 保持比例（现代版） |
| 最大回撤 | 12-16% | 12-16% | 23%（2022），40%（2009） |
| 理念纯度 | 声称被动，但55%债券透露保守偏好 | 真正零偏好，拥抱不确定性 | 积极配置风险资产 |
| 适合人群 | 求稳、能承受~16%回撤 | 极度保守、不信任任何预测 | 能扛波动、投资期限20年+ |
| 滞胀风险 | 所有资产可能同时跌 | 现金提供缓冲，但股债金仍受压 | 高风险敞口，回撤最大 |

## 共同理念

三种策略都试图通过分散配置来应对不确定性，而非预测未来经济走向。它们都隐含了一个共同假设：不同资产在不同经济环境下会轮流表现优异，组合起来可以平滑整体波动。

## 核心差异

三种策略的本质差异不在于理念（都不预测），而在于**风险承受度**：

- 达里欧和布朗的12-16%最大回撤意味着100万最多亏16万，适合大多数普通投资者。
- 塔木德的23-40%最大回撤意味着100万可能亏23-40万，对心理素质要求极高。

## "不预测"的悖论

文章揭示了一个关键矛盾：三种策略都声称"不预测"，但资产选择和比例分配本身就是一种隐性预测。例如：

- 达里欧选55%债券，隐含假设债券在多数环境下能提供正回报。
- 布朗的25%等权，隐含假设四类资产长期都不会归零。
- 塔木德的2/3风险敞口，隐含假设长期来看风险资产收益能补偿波动。

这些假设在利率长期下行+政府信用稳定的前提下成立，但在高债务+低增长环境（如日本90年代）下可能失效。

## 选择建议

| 你的情况 | 推荐策略 |
|---|---|
| 不能接受超过16%回撤 | 达里欧或布朗 |
| 极度保守、不信任任何预测 | 布朗永久组合 |
| 能承受40%回撤、投资20年+ | 塔木德 |
| 连10%回撤都睡不着 | 任何全天候策略都不适合，存定期 |
