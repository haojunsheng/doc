# 周期派 vs 价值派估值框架对比

本文对两种主流估值范式进行系统性对比，帮助投资者理解分歧根源并做出适配选择。

## 核心对比表

| 维度 | 周期投资派 | 内生价值投资派 |
|------|-----------|---------------|
| **价值定义** | 中短期盈利 = f(经济周期) | 内在价值 = 未来现金流折现值 |
| **估值公式** | 股票价值 = f(短期盈利) | DCF：估值 = Σ(CF / (1+r)^t) |
| **时间维度** | 短期（季度/年度） | 长期（十年以上） |
| **核心指标** | 业绩增速、景气度、PE 分位数 | DCF 现金流、ROE、护城河宽度 |
| **代表性人物** | [[巴里-瑞泰兹-barry-ritholtz]] | [[沃伦巴菲特warren-buffett]] |
| **典型行为** | 寻找景气超预期公司，敢于在高 PE 买入 | 等待低估机会，忽视短期波动 |
| **风险来源** | 周期判断错误，在顶部买入 | DCF 假设偏差，长期忍受低估值 |
| **适用性格** | 对市场敏感、能快速反应 | 有耐心、能承受长期波动 |
| **经典案例** | 宁德时代 2021（PE 超 100 倍仍被追捧） | 1970 年代买入成长股的价值投资者 |
| **共同盲区** | 未充分讨论两种方法如何结合，以及景气派高PE在周期反转时的高回撤风险 | |

## 为什么同一只股票，结论不同？

以宁德时代 2021 年为例：

- **周期派视角**：电动车行业景气度持续超预期，当前 PE 高是因为未来盈利增速更高——合理
- **价值派视角**：100 倍 PE 透支了未来多年增长，DCF 模型下当前价格远高于内在价值——泡沫

两种结论都成立，只是时间维度不同。

## 共同误区

| 误区 | 周期派 | 价值派 |
|------|--------|--------|
| 对市场的看法 | 市场是有效的短期定价机器 | 市场长期会回归价值 |
| 对人性看法 | 人性是短期偏好，应顺势利用 | 人性是短期偏好，应逆向对抗 |
| 共同盲点 | 都未充分讨论"如何结合两种方法"的操作性问题 | |

## 适配原则

[[凯恩斯-股票选美比喻]] 提醒我们：投资不是选"最美"的，而是选"最多人投票的"。这恰恰说明了周期派思维的市场现实基础。但价值派也指出，市场可能长期不认可你的判断——如 [[罗伯特-希勒-robert-shiller]] 研究显示，1970 年买入成长股的价值投资者可能要忍受 10 年熊市。

**没有最好的投资方法，只有最适合的方法**——取决于投资者自身的性格、能力和风险偏好。[[伴读：股票估值两门派]] 补充了这一立场的认识论基础：两派分歧的根源是时间维度（短期盈利 vs 长期现金流），而非智力高低或市场有效性争议。
