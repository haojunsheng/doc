# Mem0 v2 vs v3 — 选择式更新 vs 全追加排序

## 对比表

| 维度 | v2（选择式更新） | v3（全追加 + 排序） |
|------|----------------|-------------------|
| 写入策略 | LLM 决定 ADD/UPDATE/DELETE/NOOP | 只 ADD，冲突并存 |
| 检索策略 | 直接读取唯一记忆 | 多路排序（语义+BM25+实体+时间） |
| 存储代价 | 简洁 | 可能爆炸 |
| 错误代价 | 错删不可逆 | 错排可重试 |
| LoCoMo 得分 | 71.4 | 92.5 |

## 深层原则

**错误代价决定存储策略**：错排可重试（低风险），错删不可逆（高风险），故 append-only + 检索时排序更优。

## 未解问题

全保留有账单（记忆爆炸、检索变慢、冲突打架）——第三级答案是**版本化冲突检测 + 场景限定**，不删但分层，用时间戳+场景标出冲突事实各自的适用条件。
