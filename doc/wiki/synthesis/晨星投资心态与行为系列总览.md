# 晨星投资心态与行为系列总览

本合成页面整合14篇晨星文章（作者：屈辰晨）的核心内容，构建完整的投资心态与行为知识地图。

## 核心论点（一句话）

投资的敌人不是市场，是自己；真正的优势不是信息，是行为；最终的回报不来自完美决策，来自"少犯错+长时间+可承受的策略"。

## 五层认知框架

```
第一层（认知基础）：文章7/6/13
  回答"投资为了什么"
  - 目标三要素：具体金额 + 时间界定 + 实现可能性
  - 财务自由关键：现金流，非资产数字
  - 输家的游戏：普通人不需要成为巴菲特，只需少犯错

第二层（策略框架）：文章1/2/5
  回答"用什么策略"
  - 分散而非押注；再平衡而非择时
  - 认知优势框架：信息/分析/行为/结构性四类
  - 72法则：翻倍速度取决于资产配置

第三层（常见陷阱）：文章3/4/8
  回答"什么策略有害"
  - 网格交易：与趋势为敌，牺牲复利赚短期价差
  - 主题基金：双刃剑，三个前提缺一不可
  - 收益序列风险：顺序不同，结果天差地别

第四层（行为修炼）：文章9/10/11/12
  回答"如何驾驭自己"
  - 频繁交易ETF≠被动投资
  - 信息少是优势：噪音少反而能聚焦
  - 什么都不做是能力：需要屏蔽噪音和克制冲动
  - 香农魔鬼：再平衡在零预期收益下也能创造正收益

第五层（终极认知）：文章14
  回答"钱去哪了"
  - 价格波动本质是认知变化
  - 投资是用时间换收益
  - 波动永远存在，需要接受
```

## 反完美主义主线

几乎每篇文章都在劝投资者放弃"完美"：
- 放弃完美择时 → 接受机械再平衡
- 放弃完美赛道 → 接受指数平庸
- 放弃完美策略 → 接受简单可执行
- 放弃完美预测 → 接受"未来里没有事实"
