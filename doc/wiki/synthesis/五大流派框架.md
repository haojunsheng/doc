# 五大流派框架

晨星将权益+固收基金经理分为五大流派，通过代表性人物拆解每种风格穿越牛熊的核心逻辑。选基金不在于追明星，而在于找到与自身风险偏好匹配的策略。

## 核心论点

该框架的真正价值不在于推荐某一流派，而在于为投资者提供一个"看清基金经理靠什么赚钱、在什么环境下有效"的认知透镜。

```
选基金 = 看清赚钱逻辑 × 匹配风险偏好
```

## 五大流派形式化

```
流派1 长期价值派: 低估值好公司 × 低换手长持有 → 熊市抗跌 + 牛市不缺席 → 复利积累
流派2 硬核成长派: 产业萌芽期布局 → 业绩驱动股价 → 波动大但弹性高
流派3 GARP均衡派: 成长性 ≠ 估值 → 两者兼顾 → 放弃极端收益换取极端行情生存
流派4 固收+增强派: 纯债底仓(70-90%) + 权益增强(10-30%) → 债稳股增
流派5 纯债稳健派: 高等级债券 + 低久期 + 低杠杆 → 回撤极小 + 高夏普

选基核心指标: 策略一致性 = 框架稳定 × 执行纪律 > 短期排名(运气×风格适配)
```

## 流派对比

| 流派 | 代表人物 | 赚钱来源 | 核心能力 | 主要风险 |
|------|---------|---------|---------|---------|
| 长期价值派 | [[杨鑫鑫]], [[姜诚]] | 估值修复 | 公司价值判断 + 耐心 | 价值陷阱 |
| 硬核成长派 | [[谢治宇]] | 产业趋势 | 产业趋势判断 | 产业趋势误判风险 |
| GARP均衡派 | [[刘旭]], [[周云]] | 成长性 + 安全边际 | 双重评估能力 | 风格极端分化时两头不沾 |
| 固收+增强派 | [[王晓晨]], [[祝松]] | 债券票息 + 权益增强 | 股债配置 + 转债择时 | 股债双杀 |
| 纯债稳健派 | [[黎颖芳]], [[黄纪亮]] | 债券票息 + 久期操作 | 信用筛选 + 利率判断 | 利率单边下行时落后 |

## 五派共有特质

无论哪一流派，成功的基金经理都具备：
1. 清晰的策略框架
2. 严格的风险控制
3. 独立的判断能力
4. 长期的耐心

## 选流派指标：策略一致性

```
短期排名 = 运气 + 风格适配
策略一致性 = 框架稳定 × 执行纪律
```

典型案例：
- [[谢治宇]]换手率从300%降到100%，是框架进化的表现，不是风格漂移（参见 [[知行合一（框架稳定性）]]）
- [[刘旭]]随周期动态调整但底层逻辑不变，是好策略有弹性但不变形的典型

## 与已有框架的互补关系

- 与 [[晨星投资风格箱]] 互补：风格箱从市值+风格两个维度分类基金，本框架从基金经理行为和赚钱逻辑维度细化，颗粒度更细
- 与 [[周期投资派]] / [[内生价值投资派]] 分类维度不同：前者是估值方法论层面的二分法，本框架是基金经理行为层面的五分类，两者互补而非替代

## 边界条件

| 论断 | 边界条件 |
|------|---------|
| 长期价值派有效 | 公司基本面未恶化，否则陷入价值陷阱 |
| 硬核成长派有效 | 产业趋势判断正确且介入时机合理 |
| GARP均衡派有效 | 市场风格未极端分化 |
| 固收+增强派有效 | 股债不同步下跌（避开 [[股债双杀]]） |
| 纯债稳健派有效 | 利率未单边大幅下行 |
| 策略一致性有效 | 基金经理未变更，核心逻辑未改变 |

## 重要提示

本框架是描述性分类，而非经过统计检验的流派效应研究。来源中各流派的实证案例均来自晨星公开文章，形式化表达相对简洁，缺少具体的量化数据支撑（如各派的历史回撤、年化收益等数字）。投资者应将此框架作为认知透镜，而非直接的选基决策依据。
