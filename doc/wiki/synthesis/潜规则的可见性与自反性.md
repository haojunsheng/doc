# 潜规则的可见性与自反性

跨源综合：把潜规则公开后，它还是潜规则吗？

## 命题

《二号首长》作者黄晓阳声称创作意图是"把潜规则摆上台面"。但一旦潜规则被公开讨论，它就不再是"潜"规则——公开化本身改变了规则的效力结构。这是一种**自反性**。

## 自反性的逻辑

```
潜规则（不成文、隐蔽）
    ↓ 公开讨论
显规则（被知道、被讨论）
    ↓ 行为调整
旧规则失效 → 新规则形成 → 新的"潜规则"出现
```

## 与 wiki 现有内容的对话

### [[专家访谈非公开信息原则]]
本书本质是通过文学形式传递"非公开信息"（潜规则），与专家访谈的信息获取逻辑同构。但区别在于：专家访谈的信息是"私密的"，而文学公开传播后，同一信息成为"公共知识"——这改变了信息的性质。

### [[信息茧房]]
潜规则一旦被公开，可能被不同读者以不同方式"茧房化"解读，形成三种阅读取向：

- **技术取向**：学到如何操作（如[[权力编码解码]]的10级排序）
- **cynicism 取向**：学到体制无可救药（厚黑手册读法）
- **地域八卦取向**：学到江南省=湖南（消费性读法，非理解性读法）

其中：
- 技术取向最接近作者的 literacy 意图；
- cynicism 取向是茧房化的典型表现；
- 地域八卦取向则是降秩化读法。

详见 [[5-notes--31-20260809t111042-伴读-二号首长reading--3g64e8]] 核心主张一。

### [[平衡术]]
"平衡术"作为一种方法论，其有效性依赖于"未被公开"的前提。一旦公开，所有人都知道"平衡术"，那么平衡术就不再是某种人的独特能力——它变成了人人可学的技术，从而失去其稀缺性。

## 作者的未竟之问：literacy vs cynicism

作者声称意图是 literacy（读得懂权力），但大量网络解读将此书当作厚黑术手册（cynicism）。这一分歧本身就是自反性的体现：

- 书提供了 literacy 的工具（编码解码技术栈）
- 但读者可以选择 cynicism 的使用方式
- 作者的意图（literacy）无法控制读者的解读（cynicism）

## 投资领域的类比

基金内部的"非公开信息"（如基金经理的真实持仓意图）与官场"潜规则"具有同构性：

- 当某个策略被公开后，其他人模仿 → 策略失效
- 这是行为金融学中的"阿尔法衰减"现象的同构
